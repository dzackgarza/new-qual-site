3. $A = \left[ \begin{array} { r r r } { 1 } & { - 2 } & { 1 } \\ { 0 } & { 5 } & { - 3 } \\ { 0 } & { 0 } & { 0 } \end{array} \right]$; solving $A\thevector{x_1,x_2,x_3} = 0$ gives $x_1 - 2x_2 + x_3 = 0$ and $5x_2 - 3x_3 = 0$, so $x_2 = \frac35 x_3$ and $x_1 = 2x_2 - x_3 = \frac65 x_3 - x_3 = \frac15 x_3$; hence $\ker A = \mathrm{span}(\thevector{1,3,5})$.

# Notation

Throughout, $G$ is a group, $H\leq G$ is a subgroup, and $g,h,x\in G$.

Each row gives the symbol this chapter uses, the notion it names, and how the symbol reads.

## Subgroups and conjugacy

| Symbol | Notion | Reads as |
| --- | --- | --- |
| $[g,h]$ | [[D-BQ4BQ\|commutator]] | $gh\inverseof{g}\inverseof{h}$ |
| $[G,G]$ | [[D-BQ4BQ\|commutator subgroup]] | the subgroup generated by the $[g,h]$ |
| $[H,K]$ | [[D-BQ4BQ\|commutator]] of two subgroups | the subgroup generated by the $[h,k]$ with $h\in H$, $k\in K$ |
| $Z(G)$ | [[D-NK7G7\|center]] | $\theset{g\in G \st gx = xg \text{ for all } x\in G}$ |
| $C_G(h)$ | [[D-PX64W\|centralizer]] of an element | $\theset{g\in G \st [g,h]=1}$ |
| $C_G(H)$ | [[D-PX64W\|centralizer]] of a subset | $\theset{g\in G \st [g,h]=1 \text{ for all } h\in H} = \Intersect_{h\in H} C_G(h)$ |
| $\Cl_G(x)$ | [[D-HLDEY\|conjugacy class]] | $\theset{gx\inverseof{g} \st g\in G}\subseteq G$ |
| $N_G(H)$ | [[D-OZ2RR\|normalizer]] | $\theset{g\in G \st gH\inverseof{g} = H}\leq G$ |
| $\Inn(G)$ | [[PR-IN9ZP\|inner automorphisms]] | the image of $g\mapsto (x\mapsto gx\inverseof{g})$, a subgroup of $\Aut(G)$ |
| $\Out(G)$ | outer automorphisms | the quotient of $\Aut(G)$ by the inner automorphism group |

## Group actions

For a [[D-WYC7C|group action]] of $G$ on a set $X$ ([[D-3T6O2]]), and for $x\in X$:

| Symbol | Notion | Reads as |
| --- | --- | --- |
| $g\cdot x$ | the [[D-WYC7C\|action]] | the image of $(g,x)$ under $G\times X\to X$ |
| $G\cdot x$ | [[D-WYC7C\|orbit]] of $x$ | $\theset{g\cdot x \st g\in G}\subseteq X$ |
| $G_x$ | [[D-WYC7C\|stabilizer]] of $x$ | $\theset{g\in G \st g\cdot x = x}\leq G$ |
| $X^G$ | [[D-WYC7C\|fixed-point set]] of the action | $\theset{x\in X \st g\cdot x = x \text{ for all } g\in G}\subseteq X$ |
| $X^g$ | [[FD-XRRNZ\|fixed-point set]] of $g$ | $\theset{x\in X \st g\cdot x = x}\subseteq X$ |
| $X/G$ | set of [[D-WYC7C\|orbits]] | $\theset{G\cdot x \st x\in X}\subseteq\mcp(X)$ |

# Littlewood's Principles ("Almost" Theorems)

The useful slogan is that measurable objects become classical after discarding a set of arbitrarily small measure.
Egorov applies that slogan to convergence; Lusin applies it to a single measurable function.
Both are finite-measure statements in the form used here, and neither says the exceptional set can be discarded once and for all.

## Egorov: almost uniform convergence

If $f_n\to f$ almost everywhere on a finite-measure set, then for every $\varepsilon>0$ there is a measurable exceptional set of measure below $\varepsilon$ on whose complement the convergence is uniform.

## Lusin: almost continuity

For a measurable finite-valued function on a finite-measure set, one can discard a set of arbitrarily small measure so that the restriction to what remains is continuous (in the standard regularity setting used for Lebesgue measure).
The theorem is about restriction to a large set, not uniform approximation by a continuous function on the whole domain.

## Coverage of the sets held in this repository

**Math 538 homework solutions**, `tmp/sources/hatcher-math538-homework4-solutions.pdf` (19 pages, scanned
handwriting; retrieved from `tkmd.org/wp/wp-content/uploads/YazOkulu1/AlgebraicTopologyWeek2-part2-3.pdf`).
The sheets name only the course (Math 538) and the homework number, so no author is attributed here.
Cite both locators: the PDF page and the sheet's own handwritten page. Hatcher §3.3 is covered as

| exercise | locator |
| --- | --- |
| 3 | HMW 3 handwritten p.1 = PDF p.13 |
| 4 | HMW 3 p.2 = PDF p.14 |
| 6 | HMW 3 pp.2–4 = PDF pp.14–16 |
| 7 | HMW 4 p.1 = PDF p.17 |
| 8 | HMW 4 pp.1–2 = PDF pp.17–18 |
| 9 (printed there as #8) | HMW 4 p.2 = PDF p.18 |
| 17 | HMW 4 p.3 = PDF p.19 |

Two defects found on checking it against Hatcher and recorded on the cards: the §3.3 Ex.9 sheet concludes
$d=\pm p$ from local signs that are individually $\pm1$ without proving they agree, and the §3.3 Ex.6
sheet reads the pair sequence only for $n\ge3$, where $H_{n-2}(S^{n-1})=0$.

**Steven V. Sam, *Solutions to Algebraic Topology* (2008)**, `tmp/sources/hatcher-solutions-sam-2008.pdf`
(30 pages; obtained from the UC Riverside Math 205B page, where the host warns that some solutions in it
are poor — check every argument against the book). Its printed page numbers run one behind the PDF page
index because of a cover sheet; cite printed pages. It treats the following sections only:

| section | exercises solved |
| --- | --- |
| §1.1, §1.2, §1.3, §1.A | a selection |
| §2.1 | a selection |
| §2.2 | 2, 8, 17, 20, 21, 22 |
| §3.2 | 1, 4, 11 |
| §3.3 | 8 (printed p.14–15), 17 (pp.15–16), 32 (p.16) |
| §3.C | 5 (p.16) |
| §4.1, §4.2, §4.3 | a selection |

It has **no §3.A, §3.B or §3.E at all**, and within §3.3 and §3.C only the exercises listed. So for
Hatcher's chapter-3 sections other than the few above there is no published solution in the checkout,
and a source still to be acquired. Coverage of the Riemannian Hunger set listed above stops at
§2.1, so it does not help for chapter 3 either.

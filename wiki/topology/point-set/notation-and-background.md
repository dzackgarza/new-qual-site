# Notation and background

References: [@Mun00], [@Hat02].

## Notation

::: {.remark title="Conventions"}
\envlist

- Maps between spaces are continuous.
- Maps of spaces are pointed unless stated otherwise, that is, they are morphisms in $\Top_*$.
- Homology and cohomology have $\ZZ$ coefficients unless stated otherwise.

:::

| Notation                                             | Definition                          |
|------------------------------------------------------|-------------------------------------|
| $X\cross Y, \prod_{j\in J} X_j, X^{\cross n}$ | Cartesian products of spaces |
| $M\oplus N, \bigoplus_{j\in J} M_j, M^{\oplus n}$ | Direct sums of modules over a fixed ring $R$ |
| $M\tensor_R N, M_1\tensor_R\cdots\tensor_R M_n$ | Tensor products of $R$-modules |
| $G\ast H, \ast_{j\in J} G_j, G^{\ast n}$ | Free products of groups |
| $\ZZ^n$                                              | The free abelian group of rank $n$  |
| $F_n, \ZZ^{\ast n}$                                  | The free group on $n$ generators    |
| $\pi_0(X)$                                           | The set of path components of $X$ |
| $G=1$                                                | The trivial group, written multiplicatively |
| $G=0$                                                | The trivial group, written additively       |

::: {.remark}
The identity element of a group $G$ is written $e_G$, $1_G$, or $0_G$.

::: {.remark title="Indexing conventions and list notation"}
For path-connected $X$, $\pi_0(X)$ is a point and $H_0(X) \cong \ZZ$ [[FF-2Q7RD|the zeroth homology is free on the path components]]. Homology and cohomology written as a list start in degree $0$, and homotopy groups written as a list start in degree $1$:
$$
\begin{aligned}
H_*(X) &= [H_0(X), H_1(X), H_2(X), \ldots], \\
\pi_*(X) &= [\pi_1(X), \pi_2(X), \pi_3(X), \ldots].
\end{aligned}
$$

:::

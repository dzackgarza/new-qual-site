::: {.theorem}
A metric space is compact if and only if it is complete and [[FF-VWKGM|totally bounded]] [@Mun00].
:::

::: {.remark title="Variations"}
A metric space is sequentially compact if and only if it is complete and totally bounded.
For metric spaces, sequential compactness is equivalent to compactness [@Mun00], so this is the same statement.
:::

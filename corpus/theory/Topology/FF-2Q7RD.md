::: {.fact}
For any space $X$, the group $H_0(X)$ is free abelian with one generator for each [[D-VZFJQ|path component]] of $X$.
In particular $H_0(X)\cong\ZZ$ if $X$ is path connected, and $H_0(X)\cong\ZZ^{b}$ if $X$ has $b<\infty$ path components [@Hat02, Proposition 2.7].
:::

::: {.definition}
Let $m_*$ be the [[D-3XE77|outer measure]] on $\RR^n$.
A set $E\subseteq\RR^n$ is \dfn{measurable} if for every $\varepsilon>0$ there exists an open set $G\supseteq E$ with $m_*(G\setminus E) < \varepsilon$.
:::

::: {.proposition}
There exist a homeomorphism $\psi\colon[0,1]\to[0,2]$ and a [[D-MDJII|Lebesgue measurable]] set $Z\subseteq[0,1]$ such that $\psi(Z)$ is not Lebesgue measurable.
:::

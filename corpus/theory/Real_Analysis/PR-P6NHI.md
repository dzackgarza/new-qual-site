::: {.proposition}
Let $(a_n)_{n\geq1}$ and $(b_n)_{n\geq1}$ be real sequences with $0\leq a_n \leq b_n$ for all $n$.

- If $\sum_n b_n < \infty$, then $\sum_n a_n < \infty$.

- If $\sum_n a_n = \infty$, then $\sum_n b_n = \infty$.
:::

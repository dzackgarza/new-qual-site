::: {.definition}
Let $X$ be a vector space over $\CC$.
A map $L\colon X \to \CC$ is a \dfn{linear functional} if
$$
L(\alpha x + y) = \alpha L(x) + L(y) \quad \text{for all } x,y\in X \text{ and } \alpha\in\CC.
$$
:::

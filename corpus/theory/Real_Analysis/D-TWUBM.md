::: {.definition}
Let $\mu^*$ be an [[D-79EWM|outer measure]] on a set $X$.
A subset $A\subseteq X$ is \dfn{Carathéodory measurable} (or \dfn{$\mu^*$-measurable}) if
$$
\mu^*(E) = \mu^*(E\cap A)+\mu^*(E\setminus A) \qquad \text{for every } E\subseteq X.
$$
:::

::: {.theorem}
Every ideal of $k[x_1,\ldots,x_n]$ generated by monomials is generated by finitely many monomials.

Equivalently: every subset $S\subseteq\NN^n$ has finitely many elements minimal for the componentwise order, so a set of monomials has finitely many elements minimal under divisibility.
:::

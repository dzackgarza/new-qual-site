::: {.definition}
Let $R$ be a ring.
An [[D-NQZUY|$R$-module]] $M$ is \dfn{cyclic} if there exists $m\in M$ such that
$$
M = Rm \coloneqq \theset{ rm \st r\in R }.
$$
:::

::: {.proposition}
An $R$-module $M$ is cyclic if and only if $M\cong R/I$ for some left ideal $I\subseteq R$.
:::

::: {.proof}
If $M=Rm$, the $R$-linear map $R\to M$, $r\mapsto rm$, is surjective with kernel
$$
I=\theset{r\in R\st rm=0},
$$
which is a left ideal. Hence $M\cong R/I$ by the first isomorphism theorem. Conversely, $R/I$ is generated by $1+I$.
:::

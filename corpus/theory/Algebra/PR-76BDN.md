::: {.proposition}
Let $R$ be a commutative ring, and let $\mfm$, $\mfp$, and $J$ be ideals of $R$.

- $R/\mfm$ is a [[D-UI6CU|field]] if and only if $\mfm$ is a [[D-7XH2R|maximal ideal]].

- $R/\mfp$ is an [[D-QJ3QL|integral domain]] if and only if $\mfp$ is a [[D-5BM46|prime ideal]].

- $R/J$ is [[D-PQHHJ|reduced]] if and only if $J$ is [[D-JLCOX|radical]].
:::

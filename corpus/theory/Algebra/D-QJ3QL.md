::: {.definition}
A nonzero commutative ring $R$ is an \dfn{integral domain} if it has no nonzero zero divisors:
$$
\text{for all } a, b\in R,\quad ab = 0 \implies a = 0 \text{ or } b = 0.
$$
:::

::: {.definition}
A ring $R$ is \dfn{reduced} if $R$ contains no nonzero [[D-GIGM2|nilpotent]] elements.
:::

::: {.remark}
A commutative ring $R$ is reduced if and only if its [[D-C2IM4|nilradical]] $\nilrad{R}$ is $0$.
:::

::: {.remark}
Reduced means no nonzero nilpotents.
:::

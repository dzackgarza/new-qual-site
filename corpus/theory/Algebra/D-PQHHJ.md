::: {.definition}
A ring $R$ is \dfn{reduced} if $R$ contains no nonzero [[D-GIGM2|nilpotent]] elements.
:::

::: {.remark}
If $R$ is commutative, this is equivalent to
$$
\nilrad{R}=0,
$$
because the [[D-C2IM4|nilradical]] is exactly the set of nilpotent elements.
:::

::: {.definition}
The complete linear system of $D$ is the set of effective divisors linearly equivalent to it,
\[
\abs{D} = \ts{ D' \geq 0 \st D' \sim D } \cong \PP H^0(X, \OO_X(D)) .
\]
A linear system is a linear subspace of $\abs{D}$, that is, $\PP V$ for a subspace $V \subseteq H^0(X, \OO_X(D))$.
A point $p$ is a base point when $p \in \supp D'$ for every $D'$ in the system; the base locus $\Bs\abs{D}$ is the set of base points, and the system is base-point free when this is empty.
:::

::: {.proposition title="Sections and degree on a curve"}
Let $D$ be a divisor on a nonsingular projective curve $X$ over $k = \bar k$.
If $\abs{D} \neq \emptyset$, that is $\ell(D) \neq 0$, then $\deg D \geq 0$.
If moreover $\deg D = 0$, then $D \sim 0$ and $\mcl(D) \cong \OO_X$.
[@Har10a, Lemma IV.1.2]
:::

::: {.definition title="Degenerate"}
A morphism $X \to \PP^n$, and equivalently the invertible sheaf with sections or the linear system $\abs{V}$ defining it, is \dfn{degenerate} if the image of $X$ is contained in a hyperplane.
:::

::: {.proposition}
$p$ is a base point of $\PP V$ exactly when $s_p \in \mfm_p \mcl_p$ for every $s \in V$.
So $\abs{D}$ is base-point free if and only if $\OO_X(D)$ is generated by global sections.
:::

::: {.remark}
Two translations do all the work here, and an examiner wants both.
First, divisors in $\abs{D}$ are zero loci of sections of one fixed line bundle, so the system is a projective space and its dimension is $h^0(\OO(D)) - 1$ — a number Riemann--Roch computes.
Second, "$p$ lies on every divisor of the system" says every section vanishes at $p$, which is the failure of global generation at $p$.

Base-point free and globally generated are the same condition stated in the two languages, and switching between them on demand is the actual content of these questions.
:::

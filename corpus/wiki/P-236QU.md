::: problem
Let $f: \RR^n\to \RR$ be a Lebesgue measurable function.

a. Prove that for all \( \alpha> 0 \) ,
\[
A_ \alpha  \da \ts{x\in \RR^n \st \abs{ f(x) } > \alpha} \implies m(A_ \alpha) \leq {1\over \alpha} \int \abs{f (x)} \dx
.\]

b. Prove that 
\[
\int \abs{ f(x) } \dx = 0 \iff f = 0 \text{ almost everywhere}
.\]
:::

::: {.solution}
> **AI-Generated Solution**

<1>1. Markov's inequality: for $\alpha > 0$, $m(A_\alpha) \le \frac{1}{\alpha}\int|f|$, where $A_\alpha = \{|f| > \alpha\}$.
    <2>1. On $A_\alpha$, $|f| > \alpha$, so $\int_{A_\alpha}|f| \ge \alpha\, m(A_\alpha)$.
        Proof: $\int_{A_\alpha}|f| \ge \int_{A_\alpha}\alpha = \alpha m(A_\alpha)$.
    <2>2. Q.E.D.
        Proof: $\int_{A_\alpha}|f| \le \int_{\RR^n}|f|$, so $\alpha m(A_\alpha) \le \int|f|$.

<1>2. $\int |f| = 0 \iff f = 0$ a.e.
    <2>1. If $f = 0$ a.e., then $\int|f| = 0$.
        Proof: an integral over a null set vanishes.
    <2>2. If $\int|f| = 0$, then $f = 0$ a.e.
        Proof: $\{|f| > 0\} = \bigcup_k\{|f| > 1/k\}$; if $m\{|f| > 1/k\} > 0$ for some $k$, then $\int|f| \ge \int_{\{|f|>1/k\}}|f| \ge \frac{1}{k}m\{|f| > 1/k\} > 0$ by Markov (<1>1) applied on that set, contradiction.
    <2>3. Q.E.D.
        Proof: <2>1 and <2>2.
:::

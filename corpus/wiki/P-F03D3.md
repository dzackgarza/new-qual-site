::: problem
Show that the function
$$f(x) = \begin{cases} x^2 \sin \frac{1}{x}, & \text{for } x \neq 0 \\ 0, & \text{for } x = 0 \end{cases}$$
is differentiable everywhere in $(-\infty, \infty)$, but that $f'$ is not continuous at $0$.
:::

If $E \geq F$ is a finite extension, then it is algebraic and $E = F[\alpha_1, \cdots, \alpha_n]$.
So we can let $g(x) = \prod_{i=1}^n (x-\alpha_i)$.
By construction, each $\alpha_i$ is a root, and so $E$ is a splitting field for $g$.

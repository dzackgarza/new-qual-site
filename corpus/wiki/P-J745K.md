::: problem
Let $f$ be Lebesgue measurable on $\RR$ and $E \subset \RR$ be measurable such that
$$
0<A=\int_{E} f(x) d x<\infty.
$$

Show that for every $0 < t < 1$, there exists a measurable set $E_t \subset E$ such that
$$
\int_{E_{t}} f(x) d x=t A.
$$
:::
::: {.solution}
> **AI-Generated Solution**

<1>1. WLOG $f \ge 0$ a.e. on $E$: replace $f$ by $f^+ = \max(f, 0)$ on $E$ (if $f$ takes both signs the claim still follows by the same argument on $\int_E f^+$ and $\int_E f^-$; the clean statement assumes the displayed integral is the integral of a signed function — we present the standard proof for $f \ge 0$ and note the general case reduces by considering $F(s) = \int_{E \cap \{f \le s\}} f$ below).
Proof: the displayed hypothesis $0 < \int_E f < \infty$ with a single set $E_t$ target $tA$ is standard for nonnegative $f$; the general signed case follows by continuity of the map $s \mapsto \int_{E \cap \{|f| \le s\}} f$ — presented in <1>4.

<1>2. Define $F(s) = \int_{E \cap \{f \le s\}} f(x)\,dx$ for $s \ge 0$ (with $f \ge 0$). Proof: $F$ is well-defined: $0 \le f \chi_{E \cap \{f \le s\}} \le f \chi_E \in L^1$.

<1>3. $F$ is continuous, $F(0) = 0$, $F(s) \to A$ as $s \to \infty$, and $F$ is nondecreasing.
<2>1. $F(0) = \int_{E \cap \{f \le 0\}} f = 0$ (with $f \ge 0$, $f = 0$ on $\{f \le 0\}$). Proof: direct.
<2>2. $F(s) \uparrow \int_E f = A$ as $s \to \infty$.
Proof: $f\chi_{E\cap\{f\le s\}} \uparrow f\chi_E$ pointwise as $s \to \infty$; monotone convergence.
<2>3. $F$ is continuous: for $s < s'$, $0 \le F(s') - F(s) = \int_{E \cap \{s < f \le s'\}} f \le s'\,m(E \cap \{s < f \le s'\})$, and the latter $\to 0$ as $s' \to s$ (measure continuity from above, since $m(E \cap \{f \le s'\}) < \infty$... more carefully $m(E \cap \{s < f \le s'\}) \to m(E \cap \{f = s\})$-related — use dominated convergence: $f\chi_{E\cap\{s<f\le s'\}} \to 0$ pointwise as $s' \downarrow s$, dominated by $f\chi_E \in L^1$). Proof: dominated convergence on the indicators; the bound $f \le s'$ on the set also works with $s'$ bounded locally.
<2>4. Q.E.D. Proof: <2>1–<2>3.

<1>4. Intermediate value: for every $t \in (0,1)$ there is $s_t$ with $F(s_t) = tA$.
Proof: $F$ is continuous (by <1>3), $F(0) = 0 \le tA$, and $F(s) \to A \ge tA$; the intermediate value theorem gives $s_t$ with $F(s_t) = tA$ (and $F(s) \ge tA$ eventually since $F \uparrow A$).

<1>5. Q.E.D.: $E_t = E \cap \{f \le s_t\}$ satisfies $\int_{E_t} f = tA$.
Proof: $F(s_t) = \int_{E \cap \{f \le s_t\}} f = tA$ by <1>4. (For signed $f$: apply the same argument to the continuous function $G(s) = \int_{E \cap \{|f| \le s\}} f$, which moves continuously from $0$ to $A$; the same IVT conclusion holds.)

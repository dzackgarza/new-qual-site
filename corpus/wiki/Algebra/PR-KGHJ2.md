::: {.proposition}
If $X\in \GSets$, then for any points $x_i\in X$ in the same orbit, the stabilizers $G_{x_0}$ and $G_{x_1}$ are conjugate.

Note that if $G$ acts transitively, this says all stabilizers are conjugate.
:::

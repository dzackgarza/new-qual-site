::: problem
Let $m_*$ be the exterior Lebesgue measure.
Prove that a set $E$ in $\mathbb{R}^d$ is Carathéodory measurable if and only if $E$ is Lebesgue measurable.

A set $E$ is Carathéodory measurable if $m_*(A)=m_*(A\cap E)+m_*(A\cap E^c)$ for any set $A\subset\mathbb{R}^d$.
A set $E$ is Lebesgue measurable if for any $\varepsilon>0$, there exists an open set $O$ with $E\subset O$ and $m_*(O\setminus E)\le\varepsilon$.
:::

::: {.exercise title="Smith 8000e euclidean domains 3"}
If $M$ is any $R$ module, and $x_1, \ldots, x_m$ are any elements of $M$, prove there is a unique $R$ module map $f: R^m \to M$ taking $e_i$ to $x_i$, where $e_1 = (1, 0, \ldots, 0)$, $e_2 = (0, 1, 0, \ldots)$, and so on.

Show moreover that $f$ is surjective if and only if the $\ts{x_i}$ generate $M$, and injective if and only if the $\ts{x_i}$ are linearly independent over $R$.
:::

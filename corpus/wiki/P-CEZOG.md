::: problem
If $A$ is a cyclic module over a commutative ring $R$, so we have $A = Ra$ for some $a\in A$.
By Hungerford's definition, the submodule $A$ has order $r$ $\iff$ the element $a$ has order $r$ $\iff$ the order ideal $\mathcal{O}_a \definedas \theset{x\in R \mid xa = 0} = (r)$.

In particular, $ra = 0$.
:::

:::{.proposition}
If $L/k$ is separable, then
\[
[L: k] = \ts{ L: k } 
.\]
If $L/k$ is a splitting field, then
\[
[L:K] = \size \Aut_{\Fieldsover{k}}(L) \da \size \Gal(L/k)
.\]

:::

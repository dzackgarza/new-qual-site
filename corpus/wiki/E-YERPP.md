::: {.exercise title="Munkres §24.7"}


(a) Let $X$ and $Y$ be ordered sets in the order topology. Show that if $f: X \to Y$ is order preserving and surjective, then $f$ is a homeomorphism.

(b) Let $X = Y = \mathbb{R}_+$. Given a positive integer $n$, show that the function $f(x) = x^n$ is order preserving and surjective. Conclude that its inverse, the $n$th root function, is continuous.

(c) Let $X$ be the subspace $(-\infty, -1) \cup [0, \infty)$ of $\mathbb{R}$. Show that the function $f: X \to \mathbb{R}$ defined by setting $f(x) = x + 1$ if $x < -1$, and $f(x) = x$ if $x \geq 0$, is order preserving and surjective. Is $f$ a homeomorphism? Compare with (a).
:::

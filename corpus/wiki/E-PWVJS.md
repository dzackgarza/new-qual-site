:::{.exercise title="?"}
Show that $\logd(fg) = \logd f + \logd g$, i.e. 
\[
{ (fg)' \over fg} = {f'\over f} + {g' \over g}
.\]

:::

:::{.solution}
\[
{(fg)' \over fg} = { f'g + fg' \over fg} = {f'g \over fg} + {fg' \over fg} = {f'\over f} + {g' \over g}
.\]

:::

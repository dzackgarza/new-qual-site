::: problem
Let $f(z)$ be a nonconstant meromorphic function on $\mathbb{C}$.
A number $\omega\in\mathbb{C}$ is a period for $f(z)$ if $f(z+\omega)=f(z)$ for all $z$.
Show that any bounded set of periods of $f$ must be finite.
:::

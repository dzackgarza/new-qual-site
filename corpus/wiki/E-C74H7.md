::: exercise
Use the fact that intervals are connected to prove the intermediate value theorem.
:::

::: {.solution}
**Goal.** Prove the intermediate value theorem using connectedness of intervals.

<1>1. Let $f: [a,b] \to \RR$ be continuous, and suppose $f(a) < c < f(b)$ (the other case is symmetric).
Proof: setup.

<1>2. $[a,b]$ is connected.
Proof: intervals are connected.

<1>3. $f([a,b])$ is connected.
Proof: the continuous image of a connected space is connected.

<1>4. $f([a,b])$ is a connected subset of $\RR$, hence an interval.
Proof: the connected subsets of $\RR$ are exactly the intervals.

<1>5. $f(a), f(b) \in f([a,b])$, so the interval $f([a,b])$ contains $[f(a), f(b)]$.
Proof: an interval containing $f(a)$ and $f(b)$ contains everything between them.

<1>6. Hence $c \in [f(a), f(b)] \subseteq f([a,b])$, so there is $x \in [a,b]$ with $f(x) = c$.
Proof: $c$ is between $f(a)$ and $f(b)$.

<1>7. Q.E.D.
Proof: <1>6 is the intermediate value theorem.
:::

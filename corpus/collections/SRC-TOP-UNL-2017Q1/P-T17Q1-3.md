::: {.problem}
A space $X$ is completely regular if $X$ is $T_1$ and whenever $C$ is closed in $X$ and $p\in X\setminus C$, then there is a continuous function $f:X\to[0,1]$ such that $f(p)=0$ and $f(C)=\{1\}$.

(3a) Let $X$ be a $T_1$ space with topology $\mathcal T$ generated by a subbasis $\mathcal S$.
Show that $X$ is completely regular if and only if for every $p\in X$ and subbasis element $U\in\mathcal S$ containing $p$, there is a continuous function $f:X\to[0,1]$ such that $f(p)=0$ and $f(X\setminus U)=\{1\}$.

(3b) Show that if $X$ and $Y$ are completely regular spaces, then so is the product space $X\times Y$.
:::

::: {.solution}
Throughout, the condition that a function sends a closed set $C$ to $1$ is understood pointwise:
\[
f(x)=1\qquad(x\in C).
\]
When $C=\varnothing$, this condition is vacuous.

<1>1. If $X$ is completely regular, then it satisfies the subbasis condition in part (3a).
::: {.proof}
Let $p\in X$ and let $U\in\mathcal S$ contain $p$.
Since every subbasis element is open in the topology it generates,
\[
C=X\setminus U
\]
is closed, and $p\notin C$.
Complete regularity gives a continuous map
\[
f:X\longrightarrow[0,1]
\]
such that
\[
f(p)=0
\qquad\text{and}\qquad
f(x)=1\quad(x\in X\setminus U).
\]
This is precisely the required subbasis condition.
:::

<1>2. If $f_1,\ldots,f_n:X\to[0,1]$ are continuous, then
\[
f(x)=\max\{f_1(x),\ldots,f_n(x)\}
\]
is continuous.
::: {.proof}
For two real numbers,
\[
\max\{u,v\}
=
\frac{u+v+|u-v|}{2}.
\]
Thus the maximum of two continuous real-valued functions is continuous because addition, subtraction, absolute value, and multiplication by $1/2$ are continuous.
Iterating the binary maximum proves the finite statement.
:::

Assume now that $X$ is $T_1$ and satisfies the subbasis condition stated in (3a).

<1>3. Let $C\subseteq X$ be closed and let $p\in X\setminus C$, with $C\ne\varnothing$.
There are subbasis elements
\[
U_1,\ldots,U_n\in\mathcal S
\]
such that
\[
p\in U_1\cap\cdots\cap U_n
\subseteq
X\setminus C.
\]
::: {.proof}
The finite intersections of members of a subbasis form a basis for the topology generated by that subbasis.
The set
\[
X\setminus C
\]
is open and contains $p$, so it contains some basic neighborhood $B$ of $p$.
Write
\[
B=U_1\cap\cdots\cap U_n
\]
with $U_i\in\mathcal S$.
Because $C\ne\varnothing$, the open set $X\setminus C$ is a proper subset of $X$, so $B\ne X$ and the intersection may be taken with $n\ge1$.
:::

<1>4. For the closed set $C$ and point $p$ in <1>3, there is a continuous map
\[
f:X\longrightarrow[0,1]
\]
such that
\[
f(p)=0
\qquad\text{and}\qquad
f(x)=1\quad(x\in C).
\]
::: {.proof}
For each $i$, the subbasis hypothesis gives a continuous function
\[
f_i:X\longrightarrow[0,1]
\]
with
\[
f_i(p)=0
\qquad\text{and}\qquad
f_i(x)=1\quad(x\in X\setminus U_i).
\]
Define
\[
f=\max\{f_1,\ldots,f_n\}.
\]
It is continuous by <1>2, and
\[
f(p)=0
\]
because every $f_i(p)=0$.

Now take $x\in C$.
The containment in <1>3 gives
\[
C\subseteq X\setminus(U_1\cap\cdots\cap U_n)
=
\bigcup_{i=1}^n(X\setminus U_i).
\]
Hence $x\notin U_i$ for at least one $i$, so
\[
f_i(x)=1.
\]
All values $f_j(x)$ lie in $[0,1]$, and therefore their maximum is exactly $1$.
Thus $f(x)=1$ for every $x\in C$.
:::

<1>5. The subbasis condition implies that $X$ is completely regular.
::: {.proof}
The $T_1$ condition is part of the hypotheses of (3a).
For every nonempty closed $C$ and every $p\notin C$, <1>4 gives the required separating function.
If $C=\varnothing$, the constant function $f\equiv0$ has $f(p)=0$, and the requirement on points of $C$ is vacuous.
Thus the defining separation property holds for every closed $C$.
Together with <1>1, this proves the equivalence in part (3a).
:::

Now let $X$ and $Y$ be completely regular.

<1>6. The product $X\times Y$ is a $T_1$ space.
::: {.proof}
Complete regularity implies that $X$ and $Y$ are $T_1$.
Thus for any $(x,y)\in X\times Y$, the sets
\[
X\setminus\{x\}
\qquad\text{and}\qquad
Y\setminus\{y\}
\]
are open.
The complement of the singleton $\{(x,y)\}$ is
\[
\bigl((X\setminus\{x\})\times Y\bigr)
\cup
\bigl(X\times(Y\setminus\{y\})\bigr),
\]
which is open in the product topology.
Hence every singleton in $X\times Y$ is closed, so the product is $T_1$.
:::

<1>7. A subbasis for the product topology is
\[
\mathcal S
=
\{U\times Y:U\subseteq X\text{ open}\}
\cup
\{X\times V:V\subseteq Y\text{ open}\}.
\]
::: {.proof}
This is the standard product subbasis: its finite intersections are the basic open rectangles
\[
U\times V.
\]
These rectangles form a basis for the product topology.
:::

<1>8. Let $(x_0,y_0)\in U\times Y$ for an open set $U\subseteq X$.
There is a continuous map
\[
F:X\times Y\longrightarrow[0,1]
\]
such that
\[
F(x_0,y_0)=0
\]
and
\[
F=1
\quad\text{on}\quad
(X\times Y)\setminus(U\times Y).
\]
::: {.proof}
The set
\[
X\setminus U
\]
is closed in $X$ and does not contain $x_0$.
By complete regularity of $X$, choose a continuous function
\[
f_X:X\to[0,1]
\]
such that
\[
f_X(x_0)=0
\qquad\text{and}\qquad
f_X=1\text{ on }X\setminus U.
\]
Let $\pi_X:X\times Y\to X$ be the first-coordinate projection and define
\[
F=f_X\circ\pi_X.
\]
Then $F$ is continuous and
\[
F(x_0,y_0)=f_X(x_0)=0.
\]
Moreover
\[
(X\times Y)\setminus(U\times Y)
=(X\setminus U)\times Y,
\]
so $F=1$ on that complement.
:::

<1>9. The analogous subbasis separation property holds for every subbasic set $X\times V$ containing a point $(x_0,y_0)$.
::: {.proof}
Apply complete regularity of $Y$ to the closed set
\[
Y\setminus V
\]
and the point $y_0$.
Choose
\[
f_Y:Y\to[0,1]
\]
with $f_Y(y_0)=0$ and $f_Y=1$ on $Y\setminus V$.
Then
\[
F=f_Y\circ\pi_Y
\]
is continuous on $X\times Y$, vanishes at $(x_0,y_0)$, and equals $1$ on
\[
(X\times Y)\setminus(X\times V)
=
X\times(Y\setminus V).
\]
:::

<1>10. The product $X\times Y$ is completely regular.
::: {.proof}
By <1>6 it is $T_1$.
By <1>7--<1>9 it satisfies the subbasis condition from part (3a).
The equivalence proved in <1>1--<1>5 therefore implies that $X\times Y$ is completely regular.
This proves part (3b).
:::

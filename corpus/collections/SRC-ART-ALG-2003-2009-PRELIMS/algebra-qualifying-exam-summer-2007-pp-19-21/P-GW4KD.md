::: {.problem}
Let $n>1$ be an integer.
Show that the automorphism group of the cyclic group of order $n$ is isomorphic to the multiplicative group of units mod $n$.
:::

::: {.solution}
<1>1. Endomorphisms of the cyclic group $C_n = \langle g \rangle$:
<2>1. Let $C_n = \langle g \rangle$ be a cyclic group of order $n$ generated by $g$.
Any group homomorphism $\phi: C_n \to C_n$ is uniquely determined by the image of the generator $\phi(g) = g^k$ for some integer $k \in \{0, 1, \dots, n-1\}$.
Proof: universal property of cyclic groups / $C_n \cong \mathbb{Z}/n\mathbb{Z}$.
<2>2. For each $k \in \mathbb{Z}$, the map $\phi_k: C_n \to C_n$ defined by $\phi_k(g^a) = g^{ka}$ is a well-defined group endomorphism since $g^{na} = e \implies \phi_k(g^{na}) = g^{kna} = e$.
Proof: well-definedness on cosets modulo $n$.

<1>2. Criterion for automorphisms:
<2>1. An endomorphism $\phi_k$ of the finite group $C_n$ is an automorphism (bijective) if and only if $\phi_k$ is surjective, which occurs if and only if $\phi_k(g) = g^k$ is a generator of $C_n$.
Proof: finite set surjectivity equals injectivity.
<2>2. In a cyclic group of order $n$, the element $g^k$ has order:
\[
o(g^k) = \frac{n}{\gcd(n, k)}.
\]
Thus $o(g^k) = n$ if and only if $\gcd(n, k) = 1$, which is equivalent to $(k \bmod n) \in (\mathbb{Z}/n\mathbb{Z})^\times$.
Proof: formula for orders of powers in cyclic groups.

<1>3. Group isomorphism $\Psi: (\mathbb{Z}/n\mathbb{Z})^\times \to \operatorname{Aut}(C_n)$:
<2>1. Define $\Psi(k \bmod n) = \phi_k$.
For any $k, \ell \in (\mathbb{Z}/n\mathbb{Z})^\times$:
\[
(\phi_k \circ \phi_\ell)(g) = \phi_k(g^\ell) = (\phi_k(g))^\ell = (g^k)^\ell = g^{k\ell} = \phi_{k\ell}(g).
\]
Since homomorphisms from $C_n$ are determined by the image of $g$, $\phi_k \circ \phi_\ell = \phi_{k\ell}$, so $\Psi$ is a group homomorphism.
Proof: composition of endomorphisms.
<2>2. $\Psi$ is injective: If $\phi_k = \operatorname{id}_{C_n}$, then $g^k = g$, so $g^{k-1} = e$, which implies $k \equiv 1 \pmod n$.
Thus $\ker(\Psi) = \{ 1 \bmod n \}$.
Proof: kernel computation.
<2>3. $\Psi$ is surjective: Every automorphism $\theta \in \operatorname{Aut}(C_n)$ maps $g$ to a generator $g^k$ with $\gcd(k, n) = 1$, so $\theta = \phi_k = \Psi(k \bmod n)$.
Proof: image covers all automorphisms.

<1>4. Conclusion:
$\Psi$ is an isomorphism, so $\operatorname{Aut}(C_n) \cong (\mathbb{Z}/n\mathbb{Z})^\times$. Q.E.D.
Proof: <1>1 through <1>3.
:::

::: problem
1. Prove the Borel-Cantelli lemma: if measurable sets $E_j\subseteq\mathbb R^n$ satisfy $\sum_jm(E_j)<\infty$, then $\limsup_jE_j$ is measurable and has measure zero.

2. Prove that the set of real numbers $x$ for which $|x-a/q|\leq q^{-3}$ for infinitely many coprime pairs $(a,q)$ has Lebesgue measure zero.
:::

::: {.solution}
<1>1. Borel--Cantelli.
::: {.proof}
By definition,
\[
\limsup_{j\to\infty}E_j
=
\bigcap_{k=1}^{\infty}
\bigcup_{j\ge k}E_j.
\]
Hence the limsup is measurable.

For every $k$,
\[
\limsup_jE_j
\subseteq
\bigcup_{j\ge k}E_j,
\]
so countable subadditivity gives
\[
m(\limsup_jE_j)
\le
\sum_{j\ge k}m(E_j).
\]
Since
\[
\sum_{j=1}^{\infty}m(E_j)<\infty,
\]
the tails tend to $0$. Letting $k\to\infty$ yields
\[
m(\limsup_jE_j)=0.
\]
:::

<1>2. Exceptionally good rational approximations form a null set.
::: {.proof}
Fix $N\in\mathbb N$. For each denominator $q\ge1$, let $F_{q,N}$ be the union of the intervals
\[
\left[\frac aq-\frac1{q^3},\frac aq+\frac1{q^3}\right]
\]
over integers $a$ for which this interval meets $[-N,N]$. We may ignore the coprimality condition, since enlarging the sets only strengthens the desired measure estimate.

If such an interval meets $[-N,N]$, then
\[
\left|\frac aq\right|
\le N+1,
\]
so
\[
|a|\le (N+1)q.
\]
Thus at most
\[
2(N+1)q+1
\]
integers $a$ occur. Each interval has length $2q^{-3}$, hence
\[
m(F_{q,N})
\le
\frac{2(2(N+1)q+1)}{q^3}
\le
\frac{4(N+1)}{q^2}+\frac{2}{q^3}.
\]
Therefore
\[
\sum_{q=1}^{\infty}m(F_{q,N})<\infty.
\]
By part <1>1,
\[
m\left(\limsup_{q\to\infty}F_{q,N}\right)=0.
\]

Now suppose $x\in[-N,N]$ satisfies
\[
\left|x-\frac aq\right|\le q^{-3}
\]
for infinitely many coprime pairs $(a,q)$. For a fixed $q$, only finitely many integers $a$ can satisfy this inequality, so infinitely many such pairs force infinitely many distinct denominators $q$. Hence
\[
x\in\limsup_qF_{q,N}.
\]
Thus the exceptional set inside $[-N,N]$ has measure zero.

Finally, every real number lies in some interval $[-N,N]$, so the full exceptional set is a countable union of null sets and therefore has measure zero.
:::

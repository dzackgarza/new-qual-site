::: problem
Construct a generalized Cantor set by removing the open middle $\alpha_j$ fraction from each interval at stage $j$.

1. Prove that $\prod_{j=1}^{\infty}(1-\alpha_j)>0$ if and only if $\sum_{j=1}^{\infty}\alpha_j<\infty$.

2. Given $\beta\in(0,1)$, choose $(\alpha_j)$ with $\prod_j(1-\alpha_j)=\beta$.

3. Construct an open set in $[0,1]$ whose boundary has measure $\beta$.
:::

::: problem
Let $N\subseteq[0,1]$ be a Vitali nonmeasurable set.

1. Prove that each measurable subset of $N$ has measure zero.

2. Prove that $m^*([0,1]\setminus N)=1$.

3. Deduce that Lebesgue outer measure is not additive on all pairs of disjoint sets.
:::

::: {.solution}
Recall the defining property of a Vitali set $N\subset[0,1]$: it contains exactly one representative from each equivalence class for
\[
x\sim y
\quad\Longleftrightarrow\quad
x-y\in\mathbb Q.
\]

<1>1. Every measurable subset of $N$ has measure zero.
::: {.proof}
Let $E\subset N$ be measurable. Suppose, for contradiction, that
\[
m(E)>0.
\]
For distinct rationals $q,r\in\mathbb Q\cap[-1,1]$, the translates $E+q$ and $E+r$ are disjoint. Indeed, if
\[
x+q=y+r
\]
with $x,y\in E\subset N$, then
\[
x-y=r-q\in\mathbb Q.
\]
Since $N$ contains only one representative from each rational-equivalence class, this forces $x=y$, and then $q=r$.

All sets $E+q$, with $q\in\mathbb Q\cap[-1,1]$, lie in
\[
[-1,2].
\]
They are measurable, pairwise disjoint, and by translation invariance all have measure $m(E)>0$. Hence
\[
m([-1,2])
\ge
\sum_{q\in\mathbb Q\cap[-1,1]}m(E+q)
=\infty,
\]
contradicting $m([-1,2])=3$. Therefore
\[
m(E)=0.
\]
:::

<1>2. The complement of $N$ in $[0,1]$ has outer measure $1$.
::: {.proof}
Since
\[
[0,1]\setminus N\subset[0,1],
\]
one has
\[
m^*([0,1]\setminus N)\le1.
\]
Suppose strict inequality held. Choose an open set $G$ such that
\[
[0,1]\setminus N\subset G
\]
and
\[
m(G)<1.
\]
Then
\[
E=[0,1]\setminus G
\]
is measurable, satisfies $E\subset N$, and has
\[
m(E)=1-m(G\cap[0,1])>0.
\]
This contradicts part <1>1. Hence
\[
m^*([0,1]\setminus N)=1.
\]
:::

<1>3. Outer measure is not additive on all disjoint sets.
::: {.proof}
Set
\[
E_1=N,
\qquad
E_2=[0,1]\setminus N.
\]
These sets are disjoint and
\[
E_1\cup E_2=[0,1],
\]
so
\[
m^*(E_1\cup E_2)=1.
\]
By part <1>2,
\[
m^*(E_2)=1.
\]
Also $m^*(E_1)>0$: if $m^*(N)=0$, then $N$ would be Lebesgue measurable, contradicting that it is a Vitali nonmeasurable set. Therefore
\[
m^*(E_1)+m^*(E_2)>1=m^*(E_1\cup E_2).
\]
Thus Lebesgue outer measure is not additive on arbitrary disjoint pairs.
:::
:::

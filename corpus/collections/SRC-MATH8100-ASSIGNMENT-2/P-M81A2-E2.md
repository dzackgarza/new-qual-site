::: {.problem}
Define the outer Jordan content $J^*(E)$ using finite interval covers.

1. Prove that $J^*(E)=J^*(\overline E)$.

2. Give a countable set $E\subseteq[0,1]$ with $J^*(E)=1$ and $m^*(E)=0$.
:::

::: {.solution}

::: pf

::: pf-step
Definition of outer Jordan content:

::: pf-proof

::: pf-step
For a bounded subset $E \subset \mathbb{R}^n$, the outer Jordan content is:
\[
J^*(E) = \inf \left\{ \sum_{k=1}^N |I_k| \;\middle|\; E \subseteq \bigcup_{k=1}^N I_k, \, I_k \text{ bounded intervals}, \, N \in \mathbb{N} \right\}.
\]

::: pf-proof
This is the definition in the source problem, which is stated for subsets of $\mathbb R$.
:::

:::

:::

:::

::: {.pf-step #part1-jordan-content-closure}
Part 1: Proof that $J^*(E) = J^*(\overline{E})$:

::: pf-proof

::: {.pf-step #part1-cover-of-closure-covers-E}
Since $E \subseteq \overline{E}$, any finite cover of $\overline{E}$ is also a finite cover of $E$.
Taking the infimum yields $J^*(E) \le J^*(\overline{E})$.

::: pf-proof
monotonicity of outer Jordan content.
:::

:::

::: pf-step
Let $\epsilon > 0$. By the definition of $J^*(E)$, there exist finitely many bounded intervals $I_1, \ldots, I_N$ such that:
\[
E \subseteq \bigcup_{k=1}^N I_k \quad \text{and} \quad \sum_{k=1}^N |I_k| < J^*(E) + \frac{\epsilon}{2}.
\]

::: pf-proof
definition of infimum.
:::

:::

::: pf-step
Enlarge each $I_k$ to an open interval $J_k$ whose closure contains $I_k$ and such that
\[
\sum_{k=1}^N |J_k|<\sum_{k=1}^N|I_k|+\frac{\epsilon}{2}.
\]
Then
\[
E\subseteq\bigcup_{k=1}^N I_k\subseteq\bigcup_{k=1}^N\overline{J_k}.
\]
Because the latter union is closed,
\[
\overline E\subseteq\bigcup_{k=1}^N\overline{J_k}.
\]

::: pf-proof
For finitely many bounded intervals, enlarge the left and right endpoints by numbers whose total added length is less than $\epsilon/2$. A finite union of closed intervals is closed.
:::

:::

::: {.pf-step #part1-enlarged-intervals-cover-closure}
The intervals $\overline{J_k}$ therefore form a finite cover of $\overline E$, and
\[
J^*(\overline E)
\le \sum_{k=1}^N |\overline{J_k}|
=\sum_{k=1}^N |J_k|
<J^*(E)+\epsilon.
\]
Since $\epsilon > 0$ was arbitrary, $J^*(\overline{E}) \le J^*(E)$.

::: pf-proof
taking $\epsilon \to 0^+$.
:::

:::

::: pf-step
Combining step [](#part1-cover-of-closure-covers-E){.pf-ref} and step [](#part1-enlarged-intervals-cover-closure){.pf-ref} gives $J^*(E) = J^*(\overline{E})$.

::: pf-proof
sandwiching inequalities.
:::

:::

:::

:::

::: {.pf-step #part2-countable-set-example}
Part 2: Countable set with $J^*(E) = 1$ and $m^*(E) = 0$:

::: pf-proof

::: pf-step
Let $E = \mathbb{Q} \cap [0, 1]$ be the set of rational numbers in the unit interval.
$E$ is countable since $\mathbb{Q}$ is countable.

::: pf-proof
countability of $\mathbb{Q}$.
:::

:::

::: pf-step
Since $E$ is countable, it can be enumerated as $\{q_1, q_2, \ldots\}$.
The Lebesgue outer measure is subadditive over countable singletons:
\[
m^*(E) \le \sum_{n=1}^\infty m^*(\{q_n\}) = \sum_{n=1}^\infty 0 = 0 \implies m^*(E) = 0.
\]

::: pf-proof
countable subadditivity of Lebesgue measure.
:::

:::

::: pf-step
The rational numbers are dense in $[0, 1]$, so the closure is $\overline{E} = [0, 1]$.
By Part 1:
\[
J^*(E) = J^*(\overline{E}) = J^*([0, 1]) = 1.
\]
Thus $E = \mathbb{Q} \cap [0, 1]$ satisfies $J^*(E) = 1$ and $m^*(E) = 0$.

::: pf-proof
density of $\mathbb{Q}$ and Part 1.
:::

:::

:::

:::

::: pf-qed
Conclusion:
$J^*(E) = J^*(\overline{E})$, and $E = \mathbb{Q} \cap [0, 1]$ is a countable set with $J^*(E) = 1$ and $m^*(E) = 0$.

:::

::: {.problem}
Define the outer Jordan content $J^*(E)$ using finite interval covers.

1. Prove that $J^*(E)=J^*(\overline E)$.

2. Give a countable set $E\subseteq[0,1]$ with $J^*(E)=1$ and $m^*(E)=0$.
:::

::: {.solution}
<1>1. Definition of outer Jordan content:
<2>1. For a bounded subset $E \subset \mathbb{R}^n$, the outer Jordan content is:
\[
J^*(E) = \inf \left\{ \sum_{k=1}^N |I_k| \;\middle|\; E \subseteq \bigcup_{k=1}^N I_k, \, I_k \text{ bounded intervals}, \, N \in \mathbb{N} \right\}.
\]
::: {.proof}
This is the definition in the source problem, which is stated for subsets of $\mathbb R$.
:::

<1>2. Part 1: Proof that $J^*(E) = J^*(\overline{E})$:
<2>1. Since $E \subseteq \overline{E}$, any finite cover of $\overline{E}$ is also a finite cover of $E$.
Taking the infimum yields $J^*(E) \le J^*(\overline{E})$.
::: {.proof}
monotonicity of outer Jordan content.
:::
<2>2. Let $\epsilon > 0$. By the definition of $J^*(E)$, there exist finitely many bounded intervals $I_1, \ldots, I_N$ such that:
\[
E \subseteq \bigcup_{k=1}^N I_k \quad \text{and} \quad \sum_{k=1}^N |I_k| < J^*(E) + \frac{\epsilon}{2}.
\]
::: {.proof}
definition of infimum.
:::
<2>3. Enlarge each $I_k$ to an open interval $J_k$ whose closure contains $I_k$ and such that
\[
\sum_{k=1}^N |J_k|<\sum_{k=1}^N|I_k|+\frac{\epsilon}{2}.
\]
Then
\[
E\subseteq\bigcup_{k=1}^N I_k\subseteq\bigcup_{k=1}^N\overline{J_k}.
\]
Because the latter union is closed,
\[
\overline E\subseteq\bigcup_{k=1}^N\overline{J_k}.
\]
::: {.proof}
For finitely many bounded intervals, enlarge the left and right endpoints by numbers whose total added length is less than $\epsilon/2$. A finite union of closed intervals is closed.
:::
<2>4. The intervals $\overline{J_k}$ therefore form a finite cover of $\overline E$, and
\[
J^*(\overline E)
\le \sum_{k=1}^N |\overline{J_k}|
=\sum_{k=1}^N |J_k|
<J^*(E)+\epsilon.
\]
Since $\epsilon > 0$ was arbitrary, $J^*(\overline{E}) \le J^*(E)$.
::: {.proof}
taking $\epsilon \to 0^+$.
:::
<2>5. Combining <2>1 and <2>4 gives $J^*(E) = J^*(\overline{E})$.
::: {.proof}
sandwiching inequalities.
:::

<1>3. Part 2: Countable set with $J^*(E) = 1$ and $m^*(E) = 0$:
<2>1. Let $E = \mathbb{Q} \cap [0, 1]$ be the set of rational numbers in the unit interval.
$E$ is countable since $\mathbb{Q}$ is countable.
::: {.proof}
countability of $\mathbb{Q}$.
:::
<2>2. Since $E$ is countable, it can be enumerated as $\{q_1, q_2, \ldots\}$.
The Lebesgue outer measure is subadditive over countable singletons:
\[
m^*(E) \le \sum_{n=1}^\infty m^*(\{q_n\}) = \sum_{n=1}^\infty 0 = 0 \implies m^*(E) = 0.
\]
::: {.proof}
countable subadditivity of Lebesgue measure.
:::
<2>3. The rational numbers are dense in $[0, 1]$, so the closure is $\overline{E} = [0, 1]$.
By Part 1:
\[
J^*(E) = J^*(\overline{E}) = J^*([0, 1]) = 1.
\]
Thus $E = \mathbb{Q} \cap [0, 1]$ satisfies $J^*(E) = 1$ and $m^*(E) = 0$.
::: {.proof}
density of $\mathbb{Q}$ and Part 1.
:::

<1>4. Conclusion:
$J^*(E) = J^*(\overline{E})$, and $E = \mathbb{Q} \cap [0, 1]$ is a countable set with $J^*(E) = 1$ and $m^*(E) = 0$. Q.E.D.
::: {.proof}
<1>2 and <1>3.

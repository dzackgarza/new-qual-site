::: problem
Define the outer Jordan content $J^*(E)$ using finite interval covers.

1. Prove that $J^*(E)=J^*(\overline E)$.

2. Give a countable set $E\subseteq[0,1]$ with $J^*(E)=1$ and $m^*(E)=0$.
:::

::: {.solution}
<1>1. Definition of outer Jordan content:
<2>1. For a bounded subset $E \subset \mathbb{R}^n$, the outer Jordan content is:
\[
J^*(E) = \inf \left\{ \sum_{k=1}^N |I_k| \;\middle|\; E \subseteq \bigcup_{k=1}^N I_k, \, I_k \text{ open/closed bounded intervals/boxes}, \, N \in \mathbb{N} \right\}.
\]
Proof: standard definition of Jordan outer measure.

<1>2. Part 1: Proof that $J^*(E) = J^*(\overline{E})$:
<2>1. Since $E \subseteq \overline{E}$, any finite cover of $\overline{E}$ is also a finite cover of $E$.
Taking the infimum yields $J^*(E) \le J^*(\overline{E})$.
Proof: monotonicity of outer Jordan content.
<2>2. Let $\epsilon > 0$. By the definition of $J^*(E)$, there exist finitely many open intervals $I_1, \ldots, I_N$ such that:
\[
E \subseteq \bigcup_{k=1}^N I_k \quad \text{and} \quad \sum_{k=1}^N |I_k| < J^*(E) + \epsilon.
\]
(If closed intervals are used initially, expanding each by $\frac{\epsilon}{2N}$ yields an open cover with sum $< J^*(E) + \epsilon$).
Proof: definition of infimum and open interval expansion.
<2>3. The union $U = \bigcup_{k=1}^N I_k$ is an open set.
Because $U$ is open, its complement $\mathbb{R} \setminus U$ is closed.
Since $E \subseteq U$, we have $E \cap (\mathbb{R} \setminus U) = \emptyset$, which implies $\overline{E} \cap (\mathbb{R} \setminus U) = \emptyset$, so:
\[
\overline{E} \subseteq U = \bigcup_{k=1}^N I_k.
\]
Proof: closure of a set contained in an open set is contained in the open set.
<2>4. Thus $\{I_1, \ldots, I_N\}$ is a finite interval cover of $\overline{E}$, so:
\[
J^*(\overline{E}) \le \sum_{k=1}^N |I_k| < J^*(E) + \epsilon.
\]
Since $\epsilon > 0$ was arbitrary, $J^*(\overline{E}) \le J^*(E)$.
Proof: taking $\epsilon \to 0^+$.
<2>5. Combining <2>1 and <2>4 gives $J^*(E) = J^*(\overline{E})$.
Proof: sandwiching inequalities.

<1>3. Part 2: Countable set with $J^*(E) = 1$ and $m^*(E) = 0$:
<2>1. Let $E = \mathbb{Q} \cap [0, 1]$ be the set of rational numbers in the unit interval.
$E$ is countable since $\mathbb{Q}$ is countable.
Proof: countability of $\mathbb{Q}$.
<2>2. Since $E$ is countable, it can be enumerated as $\{q_1, q_2, \ldots\}$.
The Lebesgue outer measure is subadditive over countable singletons:
\[
m^*(E) \le \sum_{n=1}^\infty m^*(\{q_n\}) = \sum_{n=1}^\infty 0 = 0 \implies m^*(E) = 0.
\]
Proof: countable subadditivity of Lebesgue measure.
<2>3. The rational numbers are dense in $[0, 1]$, so the closure is $\overline{E} = [0, 1]$.
By Part 1:
\[
J^*(E) = J^*(\overline{E}) = J^*([0, 1]) = 1.
\]
Thus $E = \mathbb{Q} \cap [0, 1]$ satisfies $J^*(E) = 1$ and $m^*(E) = 0$.
Proof: density of $\mathbb{Q}$ and Part 1.

<1>4. Conclusion:
$J^*(E) = J^*(\overline{E})$, and $E = \mathbb{Q} \cap [0, 1]$ is a countable set with $J^*(E) = 1$ and $m^*(E) = 0$. Q.E.D.
Proof: <1>2 and <1>3.

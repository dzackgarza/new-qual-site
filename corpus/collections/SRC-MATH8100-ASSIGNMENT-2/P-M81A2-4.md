::: problem
Let $A\subseteq B$ be compact subsets of $\mathbb R^n$, with $m(A)=a$ and $m(B)=b$.
For each $a<c<b$, prove that there is a compact set $E$ with $A\subseteq E\subseteq B$ and $m(E)=c$.
:::

::: {.solution}
Set
\[
D=B\setminus A.
\]
Since $A\subset B$ and both are measurable with finite measure,
\[
m(D)=b-a.
\]

For $t\in\mathbb R$, define
\[
F(t)=m\bigl(D\cap\{x=(x_1,\ldots,x_n):x_1\le t\}\bigr).
\]
Then $F$ is nondecreasing. Because $B$ is compact, it is bounded, so
\[
F(t)=0
\]
for all sufficiently negative $t$, while
\[
F(t)=b-a
\]
for all sufficiently large $t$.

We claim that $F$ is continuous. If $t_k\downarrow t$, then by continuity of measure from above,
\[
F(t_k)\to F(t).
\]
If $t_k\uparrow t$, then continuity from below gives
\[
F(t_k)
\to
m\bigl(D\cap\{x_1<t\}\bigr).
\]
But
\[
D\cap\{x_1=t\}
\]
lies in an affine hyperplane, which has $n$-dimensional Lebesgue measure zero. Hence
\[
m(D\cap\{x_1<t\})=m(D\cap\{x_1\le t\})=F(t).
\]
Thus $F$ is continuous.

Since
\[
0<c-a<b-a,
\]
the intermediate value theorem gives $t_0\in\mathbb R$ such that
\[
F(t_0)=c-a.
\]
Now define
\[
E=A\cup\bigl(B\cap\{x_1\le t_0\}\bigr).
\]
Both sets in this union are compact, so $E$ is compact, and clearly
\[
A\subseteq E\subseteq B.
\]
Moreover,
\[
E=A\sqcup\bigl((B\setminus A)\cap\{x_1\le t_0\}\bigr),
\]
so
\[
m(E)
=a+F(t_0)
=a+(c-a)
=c.
\]
:::

::: {.problem}
Prove that every $E\subseteq\RR$ with $m^*(E)>0$ contains a nonmeasurable subset.
:::

::: {.solution}
The assignment sheet sets the problem and carries no solutions, so no retained solution set covers it; the argument is the card's own, and it is the Vitali construction confined to a bounded set of positive outer measure. Write $m^{*}$ for Lebesgue outer measure and $m$ for Lebesgue measure on the measurable sets.

::: pf

::: {.pf-step #bounded-piece}
$E$ contains a set $F=E\cap[-N,N]$ with $m^{*}(F)>0$.

::: pf-proof
$E=\bigcup_{N\ge1}(E\cap[-N,N])$, so countable subadditivity gives $m^{*}(E)\le\sum_{N}m^{*}(E\cap[-N,N])$. If every term vanished the sum would be $0$, contradicting $m^{*}(E)>0$; so some $F=E\cap[-N,N]$ has $m^{*}(F)>0$.
:::

:::

::: {.pf-step #classes}
The relation $x\sim y$ iff $x-y\in\QQ$ is an equivalence relation on $F$, and a set $V\subseteq F$ meeting each class in exactly one point exists.

::: pf-proof
Reflexivity, symmetry and transitivity follow from $0\in\QQ$ and from $\QQ$ being closed under negation and addition. The classes are nonempty (each contains its members), so by the axiom of choice there is a function picking one element from each class; its image is the required $V$.
:::

:::

::: {.pf-step #translates-disjoint}
If $q\ne r$ are rational, then $(V+q)\cap(V+r)=\varnothing$.

::: pf-proof
If $z=v+q=w+r$ with $v,w\in V$ then $v-w=r-q\in\QQ$, so $v\sim w$; since $V$ meets the class of $v$ in exactly one point, $v=w$, hence $q=r$.
:::

:::

::: {.pf-step #not-positive-measure}
If $V$ is measurable then $m(V)=0$.

::: pf-proof
Suppose $V$ is measurable with $m(V)>0$. Take distinct rationals $q_{k}\in[-1,1]$, $k=1,2,\dots$, which exist since $\QQ\cap[-1,1]$ is infinite. By step [](#translates-disjoint){.pf-ref} the sets $V+q_{k}$ are pairwise disjoint and measurable, each with measure $m(V)$, and each lies in $[-N-1,N+1]$ because $V\subseteq[-N,N]$. Finite additivity and monotonicity give $M\,m(V)=\sum_{k\le M}m(V+q_{k})=m\bigl(\bigcup_{k\le M}(V+q_{k})\bigr)\le m([-N-1,N+1])=2N+2$ for every $M$, which fails for $M$ large since $m(V)>0$. So a measurable $V$ cannot have positive measure.
:::

:::

::: {.pf-step #not-null}
If $V$ were measurable, then $m^{*}(F)=0$; hence $V$ is not measurable.

::: pf-proof
Suppose $V$ were measurable; step [](#not-positive-measure){.pf-ref} then gives $m(V)=0$. Every $x\in F$ satisfies $x-v\in\QQ$ for the selected representative $v$ of its class, and $\abs{x-v}\le 2N$ because $x,v\in[-N,N]$; so $x\in V+q$ for some $q\in\QQ\cap[-2N,2N]$. Hence $F\subseteq\bigcup_{q\in\QQ\cap[-2N,2N]}(V+q)$, a countable union of translates of the null set $V$, which is null by countable subadditivity. Then $m^{*}(F)\le0$, contradicting step [](#bounded-piece){.pf-ref}.
:::

:::

::: {.pf-step #answer}
Every $E\subseteq\RR$ with $m^{*}(E)>0$ contains a nonmeasurable subset.

::: pf-proof
By step [](#bounded-piece){.pf-ref} there is $F\subseteq E$ with $m^{*}(F)>0$, and by step [](#classes){.pf-ref} a set $V\subseteq F$ meeting each class of $\sim$ once. If $V$ were measurable, step [](#not-null){.pf-ref} would force $m^{*}(F)=0$, so $V$ is nonmeasurable, and $V\subseteq F\subseteq E$ is the required nonmeasurable subset.
:::

::: problem
Prove that every $E\subseteq\mathbb R$ with $m^*(E)>0$ contains a nonmeasurable subset.
:::

::: {.solution}
Since
\[
E=\bigcup_{N=1}^\infty (E\cap[-N,N]),
\]
some bounded piece
\[
F:=E\cap[-N,N]
\]
must satisfy $m^*(F)>0$; otherwise countable subadditivity would give $m^*(E)=0$.

On $F$, define
\[
x\sim y\iff x-y\in\mathbb Q.
\]
Using the axiom of choice, select one representative from each equivalence class and call the resulting set $V\subseteq F$.

We claim that $V$ is not Lebesgue measurable. Suppose it were measurable.

First suppose $m(V)>0$. For distinct rationals $q,r$, the translates $V+q$ and $V+r$ are disjoint: if
\[
v+q=w+r,
\]
then $v-w=r-q\in\mathbb Q$, so $v$ and $w$ lie in the same equivalence class, and the choice of one representative forces $v=w$, hence $q=r$.

Choose infinitely many distinct rationals $q_k\in[-1,1]$. Then the measurable sets $V+q_k$ are pairwise disjoint, all have measure $m(V)>0$, and all lie in the bounded interval $[-N-1,N+1]$. Hence
\[
m([-N-1,N+1])
\ge
\sum_{k=1}^M m(V+q_k)
=M\,m(V)
\]
for every $M$, impossible. Therefore $m(V)$ cannot be positive.

Thus, if $V$ were measurable, we would have $m(V)=0$. But every $x\in F$ is rationally equivalent to the selected representative of its class, so
\[
F\subseteq\bigcup_{q\in\mathbb Q\cap[-2N,2N]}(V+q).
\]
The right-hand side is a countable union of null sets and hence has measure zero. Therefore $m^*(F)=0$, contradicting the choice of $F$.

Hence $V\subseteq F\subseteq E$ is nonmeasurable.
:::

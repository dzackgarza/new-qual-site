::: {.problem}
Let $E\subseteq\mathbb R$ have Lebesgue outer measure zero.
Prove that $E^2=\{x^2:x\in E\}$ also has outer measure zero.
Determine how far this result generalizes.
:::

::: {.solution}
**Goal.** Show $E^2 = \theset{x^2 : x \in E}$ has outer measure zero when $E$ does, and discuss generalization.

::: pf

::: pf-step
$E^2 = \theset{x^2 : x \in E} = \theset{x^2 : x \in E \cap [0,\infty)} \cup \theset{x^2 : x \in E \cap (-\infty, 0]}$.

::: pf-proof
split $E$ into its nonnegative and nonpositive parts.
:::

:::

::: {.pf-step #squaring-lipschitz-on-bounded}
The map $x \mapsto x^2$ is Lipschitz on any bounded interval.

::: pf-proof
on $[-M, M]$, $|x^2 - y^2| = |x+y||x-y| \le 2M |x-y|$.
:::

:::

::: {.pf-step #lipschitz-sends-null-to-null}
A Lipschitz map sends null sets to null sets.

::: pf-proof
if $E$ is covered by intervals of total length $< \eps$, its image under an $L$-Lipschitz map is covered by intervals of total length $< L\eps$.
:::

:::

::: {.pf-step #E2-outer-measure-zero}
Hence $E^2$ has outer measure zero.

::: pf-proof

::: pf-step
Write $E = \bigcup_{n} (E \cap [-n, n])$.

::: pf-proof
$\RR = \bigcup_n [-n, n]$.
:::

:::

::: pf-step
Each $E \cap [-n, n]$ has measure zero, and $x \mapsto x^2$ is Lipschitz on $[-n, n]$, so its image has measure zero.

::: pf-proof
step [](#squaring-lipschitz-on-bounded){.pf-ref} and step [](#lipschitz-sends-null-to-null){.pf-ref}.
:::

:::

::: pf-step
Hence $E^2 = \bigcup_n \theset{x^2 : x \in E \cap [-n,n]}$ is a countable union of null sets, so it has measure zero.

::: pf-proof
countable unions of null sets are null.
:::

:::

:::

:::

::: {.pf-step #generalization-locally-lipschitz}
Generalization: any locally Lipschitz map $f: \RR \to \RR$ sends null sets to null sets.

::: pf-proof
the same argument: on each bounded interval $f$ is Lipschitz, and $\RR$ is a countable union of bounded intervals.
:::

:::

::: pf-qed
Step [](#E2-outer-measure-zero){.pf-ref} proves the claim; step [](#generalization-locally-lipschitz){.pf-ref} gives the generalization.
:::

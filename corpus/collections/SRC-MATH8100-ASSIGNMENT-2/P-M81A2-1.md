::: problem
Let $E\subseteq\mathbb R$ have Lebesgue outer measure zero.
Prove that $E^2=\{x^2:x\in E\}$ also has outer measure zero.
Determine how far this result generalizes.
:::

::: {.solution}
**Goal.** Show $E^2 = \theset{x^2 : x \in E}$ has outer measure zero when $E$ does, and discuss generalization.

<1>1. $E^2 = \theset{x^2 : x \in E} = \theset{x^2 : x \in E \cap [0,\infty)} \cup \theset{x^2 : x \in E \cap (-\infty, 0]}$.
::: {.proof}
split $E$ into its nonnegative and nonpositive parts.
:::

<1>2. The map $x \mapsto x^2$ is Lipschitz on any bounded interval.
::: {.proof}
on $[-M, M]$, $|x^2 - y^2| = |x+y||x-y| \le 2M |x-y|$.
:::

<1>3. A Lipschitz map sends null sets to null sets.
::: {.proof}
if $E$ is covered by intervals of total length $< \eps$, its image under an $L$-Lipschitz map is covered by intervals of total length $< L\eps$.
:::

<1>4. Hence $E^2$ has outer measure zero.
<2>1. Write $E = \bigcup_{n} (E \cap [-n, n])$.
::: {.proof}
$\RR = \bigcup_n [-n, n]$.
:::
<2>2. Each $E \cap [-n, n]$ has measure zero, and $x \mapsto x^2$ is Lipschitz on $[-n, n]$, so its image has measure zero.
::: {.proof}
<1>2 and <1>3.
:::
<2>3. Hence $E^2 = \bigcup_n \theset{x^2 : x \in E \cap [-n,n]}$ is a countable union of null sets, so it has measure zero.
::: {.proof}
countable unions of null sets are null.
:::

<1>5. Generalization: any locally Lipschitz map $f: \RR \to \RR$ sends null sets to null sets.
::: {.proof}
the same argument: on each bounded interval $f$ is Lipschitz, and $\RR$ is a countable union of bounded intervals.
:::

<1>6. Q.E.D.
::: {.proof}
<1>4 proves the claim; <1>5 gives the generalization.
:::
:::

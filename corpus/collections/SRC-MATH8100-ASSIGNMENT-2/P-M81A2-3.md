::: problem
Suppose $A\subseteq E\subseteq B$, where $A,B\subseteq\mathbb R^n$ are measurable.

1. Prove that $E$ is measurable if $m(A)=m(B)<\infty$.

2. Give a counterexample when $A$ and $B$ have infinite measure.
:::

::: {.solution}
<1>1. Part 1: Proof that $E$ is measurable when $m(A) = m(B) < \infty$:
<2>1. Decompose the set $E$ as the disjoint union:
\[
E = A \cup (E \setminus A).
\]
::: {.proof}
set-theoretic decomposition.
:::
<2>2. Since $A \subseteq E \subseteq B$, we have $E \setminus A \subseteq B \setminus A$.
::: {.proof}
monotonicity of set difference.
:::
<2>3. Since $A$ and $B$ are Lebesgue measurable with $m(A) < \infty$, the set difference $B \setminus A$ is measurable, and its measure is:
\[
m(B \setminus A) = m(B) - m(A) = 0.
\]
::: {.proof}
additivity of measure on disjoint sets.
:::
<2>4. The Lebesgue measure on $\mathbb{R}^n$ is complete: every subset of a null set is Lebesgue measurable and has measure zero.
Since $E \setminus A \subseteq B \setminus A$ and $m(B \setminus A) = 0$, $E \setminus A$ is measurable with $m(E \setminus A) = 0$.
::: {.proof}
completeness of the Lebesgue $\sigma$-algebra.
:::
<2>5. The union of two measurable sets is measurable, so:
\[
E = A \cup (E \setminus A)
\]
is Lebesgue measurable, with $m(E) = m(A) + m(E \setminus A) = m(A)$.
::: {.proof}
closure under finite unions.
:::

<1>2. Part 2: Counterexample when $m(A) = m(B) = \infty$:
<2>1. Let $V \subset [0, 1]$ be a non-measurable Vitali set.
::: {.proof}
existence of non-measurable Vitali sets.
:::
<2>2. Define the sets in $\mathbb{R}$:
\[
A = (1, \infty), \qquad B = [0, \infty), \qquad E = V \cup A = V \cup (1, \infty).
\]
::: {.proof}
setup.
:::
<2>3. $A$ and $B$ are measurable intervals with $m(A) = \infty$ and $m(B) = \infty$.
We have $A \subseteq E \subseteq B$: the first inclusion is $A = (1,\infty) \subseteq V \cup (1,\infty) = E$, and the second is $E = V \cup (1,\infty) \subseteq [0,1] \cup (1,\infty) = [0,\infty) = B$, using $V \subset [0,1]$.
::: {.proof}
$V \subset [0, 1] \subset [0, \infty)$.
:::
<2>4. The intersection of $E$ with the measurable set $[0, 1]$ is:
\[
E \cap [0, 1] = (V \cup (1, \infty)) \cap [0, 1] = V \cap [0, 1] = V.
\]
If $E$ were measurable, then $E \cap [0, 1] = V$ would be measurable, which is a contradiction.
Thus $E$ is non-measurable.
::: {.proof}
intersection of measurable sets is measurable.
:::

<1>3. Conclusion:
$E$ is measurable when $m(A) = m(B) < \infty$, and $E = V \cup (1, \infty)$ provides a counterexample when the measures are infinite. Q.E.D.
::: {.proof}
<1>1 and <1>2.
:::
:::

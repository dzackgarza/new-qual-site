::: {.problem}
Suppose $A\subseteq E\subseteq B$, where $A,B\subseteq\mathbb R^n$ are measurable.

1. Prove that $E$ is measurable if $m(A)=m(B)<\infty$.

2. Give a counterexample when $A$ and $B$ have infinite measure.
:::

::: {.solution}

::: pf

::: {.pf-step #part1-E-measurable}
Part 1: Proof that $E$ is measurable when $m(A) = m(B) < \infty$:

::: pf-proof

::: pf-step
Decompose the set $E$ as the disjoint union:
\[
E = A \cup (E \setminus A).
\]

::: pf-proof
set-theoretic decomposition.
:::

:::

::: pf-step
Since $A \subseteq E \subseteq B$, we have $E \setminus A \subseteq B \setminus A$.

::: pf-proof
monotonicity of set difference.
:::

:::

::: pf-step
Since $A$ and $B$ are Lebesgue measurable with $m(A) < \infty$, the set difference $B \setminus A$ is measurable, and its measure is:
\[
m(B \setminus A) = m(B) - m(A) = 0.
\]

::: pf-proof
additivity of measure on disjoint sets.
:::

:::

::: pf-step
The Lebesgue measure on $\mathbb{R}^n$ is complete: every subset of a null set is Lebesgue measurable and has measure zero.
Since $E \setminus A \subseteq B \setminus A$ and $m(B \setminus A) = 0$, $E \setminus A$ is measurable with $m(E \setminus A) = 0$.

::: pf-proof
completeness of the Lebesgue $\sigma$-algebra.
:::

:::

::: pf-step
The union of two measurable sets is measurable, so:
\[
E = A \cup (E \setminus A)
\]
is Lebesgue measurable, with $m(E) = m(A) + m(E \setminus A) = m(A)$.

::: pf-proof
closure under finite unions.
:::

:::

:::

:::

::: {.pf-step #part2-counterexample-infinite-measure}
Part 2: Counterexample when $m(A) = m(B) = \infty$:

::: pf-proof

::: pf-step
Let $V \subset [0, 1]$ be a non-measurable Vitali set.

::: pf-proof
existence of non-measurable Vitali sets.
:::

:::

::: pf-step
Define the sets in $\mathbb{R}$:
\[
A = (1, \infty), \qquad B = [0, \infty), \qquad E = V \cup A = V \cup (1, \infty).
\]

::: pf-proof
setup.
:::

:::

::: pf-step
$A$ and $B$ are measurable intervals with $m(A) = \infty$ and $m(B) = \infty$.
We have $A \subseteq E \subseteq B$: the first inclusion is $A = (1,\infty) \subseteq V \cup (1,\infty) = E$, and the second is $E = V \cup (1,\infty) \subseteq [0,1] \cup (1,\infty) = [0,\infty) = B$, using $V \subset [0,1]$.

::: pf-proof
$V \subset [0, 1] \subset [0, \infty)$.
:::

:::

::: pf-step
The intersection of $E$ with the measurable set $[0, 1]$ is:
\[
E \cap [0, 1] = (V \cup (1, \infty)) \cap [0, 1] = V \cap [0, 1] = V.
\]
If $E$ were measurable, then $E \cap [0, 1] = V$ would be measurable, which is a contradiction.
Thus $E$ is non-measurable.

::: pf-proof
intersection of measurable sets is measurable.
:::

:::

:::

:::

::: pf-qed
Conclusion:
$E$ is measurable when $m(A) = m(B) < \infty$, and $E = V \cup (1, \infty)$ provides a counterexample when the measures are infinite.

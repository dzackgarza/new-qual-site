::: {.problem}
Show that $\RR[x]/\langle x^{2} + 1 \rangle$ is a field.
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **Gallian, *Contemporary Abstract Algebra*, seventh edition, Chapter 14 solution outlines, exercise 28** (`assets/attachments/Ch14Sltns.pdf`), restructured into steps. Two things are made explicit that the outline leaves implicit: that $\RR[x]$ is a principal ideal domain, so every ideal containing $\langle x^{2}+1\rangle$ arises from a single polynomial, and that a nonzero constant in an ideal generates the whole ring.

::: pf

::: {.pf-step #maximal}
It suffices to show that $\langle x^{2}+1\rangle$ is a maximal ideal of $\RR[x]$.

::: pf-proof
For a commutative ring with $1$, an ideal $M$ is maximal exactly when $R/M$ is a field; so proving maximality proves that $\RR[x]/\langle x^{2}+1\rangle$ is a field.
:::

:::

::: {.pf-step #strict}
Let $J$ be an ideal with $\langle x^{2}+1\rangle \subsetneq J\subseteq\RR[x]$, and choose $f\in J\setminus\langle x^{2}+1\rangle$.

::: pf-proof
This is the hypothesis of strictness: an ideal strictly larger than $\langle x^{2}+1\rangle$ contains an element not in it.
:::

:::

::: {.pf-step #remainder}
Division with remainder gives $f=q(x)(x^{2}+1)+r(x)$ with $\deg r<2$ and $r\ne0$; so $r=ax+b$ with $a,b$ real, not both zero, and $r\in J$.

::: pf-proof
$\RR[x]$ is a Euclidean domain with the degree as norm, so division by the monic $x^{2}+1$ gives $q,r$ with $\deg r<2$. If $r=0$ then $f=q(x)(x^{2}+1)\in\langle x^{2}+1\rangle$, contrary to the choice of $f$; so $r\ne0$ and $r=ax+b$ with $(a,b)\ne(0,0)$. Finally $r=f-q(x)(x^{2}+1)\in J$ because $f\in J$ and $q(x)(x^{2}+1)\in\langle x^{2}+1\rangle\subseteq J$.
:::

:::

::: {.pf-step #constant}
$a^{2}+b^{2}\in J$, and it is nonzero.

::: pf-proof
$ax-b\in\RR[x]$, so $(ax+b)(ax-b)=a^{2}x^{2}-b^{2}\in J$ since $J$ is closed under multiplication by ring elements; and $a^{2}(x^{2}+1)=a^{2}x^{2}+a^{2}\in J$ since $x^{2}+1\in J$. Subtracting, $a^{2}+b^{2}=(a^{2}x^{2}+a^{2})-(a^{2}x^{2}-b^{2})\in J$. It is nonzero because $a,b$ are real and not both zero, so $a^{2}+b^{2}>0$.
:::

:::

::: {.pf-step #unit}
$1\in J$ and $J=\RR[x]$.

::: pf-proof
The nonzero constant $c=a^{2}+b^{2}$ lies in $J$, so its inverse $c^{-1}\in\RR$ is in $\RR[x]$ and $1=c^{-1}c\in J$ because $J$ is closed under multiplication by ring elements. An ideal containing $1$ is the whole ring.
:::

:::

::: {.pf-step}
$\RR[x]/\langle x^{2}+1\rangle$ is a field.

::: pf-proof
Step [](#unit){.pf-ref} shows that no ideal lies strictly between $\langle x^{2}+1\rangle$ and $\RR[x]$, so the ideal is maximal; by step [](#maximal){.pf-ref} the quotient is a field:
$$
\boxed{\RR[x]/\langle x^{2}+1\rangle\text{ is a field (it is isomorphic to }\CC\text{).}}
$$
:::

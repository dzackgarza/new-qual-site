::: {.problem}
Let $R = \ZZ_{27}$. Find:

(a) $N(\langle 0 \rangle)$.

(b) $N(\langle 3 \rangle)$.

(c) $N(\langle 9 \rangle)$.

Here, for an ideal $A$ of $R$, $N(A) = \{a \in R \mid a^n \in A \text{ for some positive integer } n\}$.
:::

::: {.solution}

The answers are those of the retained solution outline for Chapter 14, Exercise 47, PDF pp. 2-3 of `assets/attachments/Ch14Sltns.pdf`; the outline gives the reason for (a) only and states the answers to (b) and (c) bare, so the arguments for those two are supplied here. Here $R=\ZZ_{27}$, an ideal of $R$ is identified with its set of residues, $\langle a\rangle$ is the ideal generated by the residue $a$, and $N(A)=\theset{a\in R\mid a^{n}\in A\ \text{for some positive integer}\ n}$.

::: pf

::: {.pf-step #a}

(a) $N(\langle0\rangle)=\langle3\rangle$.

::: pf-proof

$N(\langle0\rangle)$ is the set of $a$ with $a^{n}\equiv0\pmod{27}$ for some $n\geq1$. If $3\mid a$ write $a=3c$; then $a^{3}=27c^{3}\equiv0$, so $a\in N(\langle0\rangle)$. If $3\nmid a$ then $3\nmid a^{n}$ for every $n$, so $a^{n}\not\equiv0\pmod{27}$; hence no such $a$ lies in $N(\langle0\rangle)$. The residues divisible by $3$ are exactly the elements of $\langle3\rangle$.

:::

:::

::: {.pf-step #b}

(b) $N(\langle3\rangle)=\langle3\rangle$.

::: pf-proof

$9\in\langle3\rangle$, but the argument does not need it: $a^{n}\in\langle3\rangle$ means $3\mid a^{n}$, which for the prime $3$ is equivalent to $3\mid a$. So $N(\langle3\rangle)=\theset{a\mid3\mid a}=\langle3\rangle$.

:::

:::

::: {.pf-step #c}

(c) $N(\langle9\rangle)=\langle3\rangle$.

::: pf-proof

$a^{n}\in\langle9\rangle$ means $9\mid a^{n}$. If $3\mid a$ then $a=3c$ and $a^{2}=9c^{2}\in\langle9\rangle$, so $a\in N(\langle9\rangle)$ with $n=2$. If $3\nmid a$ then $3\nmid a^{n}$, so $9\nmid a^{n}$ for every $n$, and $a\notin N(\langle9\rangle)$. Hence $N(\langle9\rangle)=\theset{a\mid3\mid a}=\langle3\rangle$.

:::

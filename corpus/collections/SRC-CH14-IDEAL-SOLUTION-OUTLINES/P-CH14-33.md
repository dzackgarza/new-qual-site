::: {.problem}
How many elements are in $\mathbb { Z } [ i ] / < 3 + i > ?$ Give reasons for your answer.
:::

::: {.solution}
Since $( 3 + i ) ( 3 - i ) = 1 0 \in < 3 + i >$, we have $1 0 + < 3 + i > = < 3 + i >$. The coset of $i$ is an integer coset: $i + < 3 + i > = i + ( - 3 - i ) + < 3 + i > = - 3 + < 3 + i > = 7 + < 3 + i >$ . Hence $a + b i + < 3 + i >$ can be expressed as just $a + < 3 + i >$ , and a ranges from 0 to 9. Moreover, $1 + < 3 + i >$ has (additive) order 10: if an integer $k$ equals $(3+i)w$ with $w \in \mathbb Z[i]$, then taking norms gives $k^2 = 10\,N(w)$, so $2 \mid k$ and $5 \mid k$, hence $10 \mid k$. Thus the quotient ring is simply $\{ k + < 3 + i > | k \in \{ 0 , 1 , \ldots , 9 \} \}$ . So there are 10 elements in the quotient ring.
:::

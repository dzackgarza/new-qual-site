::: {.problem}
Prove that the intersection of any set of ideals of a ring is an ideal.
:::

::: {.solution}

The exercise is Gallian, *Contemporary Abstract Algebra* (7th ed.), Chapter 14 exercise 8,
printed p. 269, and is the retained solution outline's item 8 (`assets/attachments/Ch14Sltns.pdf`,
PDF p. 1). The outline's argument is restated below as steps, with the ideal test it uses
named and the empty family of ideals supplied.

Throughout, $R$ is a ring, $\theset{A_{i}}_{i\in I}$ is a set of ideals of $R$, and
$J=\bigcap_{i\in I}A_{i}$.

::: pf

::: {.pf-step #nonempty}

When $I\ne\emptyset$, $0\in J$; in particular $J\ne\emptyset$.

::: pf-proof

An ideal of $R$ is a subring of $R$ (Definition, printed p. 262), and a subring of $R$ is a
ring whose zero element is $0\in R$. So $0\in A_{i}$ for every $i\in I$, and since $I$ is
nonempty, $0$ lies in the intersection $J$.

:::

:::

::: {.pf-step #subtraction}

If $a,b\in J$ then $a-b\in J$.

::: pf-proof

Let $a,b\in J$ and fix $i\in I$. Then $a,b\in A_{i}$, and $A_{i}$ is a subring of $R$,
hence closed under subtraction, so $a-b\in A_{i}$. As $i$ was arbitrary,
$a-b\in\bigcap_{i\in I}A_{i}=J$.

:::

:::

::: {.pf-step #absorption}

If $a\in J$ and $r\in R$ then $ra\in J$ and $ar\in J$.

::: pf-proof

Let $a\in J$ and $r\in R$. For each $i\in I$ we have $a\in A_{i}$, and $A_{i}$ is an ideal,
so $ra,ar\in A_{i}$ by the definition of ideal (printed p. 262). Hence $ra$ and $ar$ lie in
every $A_{i}$, that is in $J$.

:::

:::

::: {.pf-step #intersection}

$J$ is an ideal of $R$.

::: pf-proof

By step [](#nonempty){.pf-ref}, $J$ is nonempty; by step [](#subtraction){.pf-ref},
$a-b\in J$ whenever $a,b\in J$; by step [](#absorption){.pf-ref}, $ra,ar\in J$ whenever
$a\in J$ and $r\in R$. These are exactly the two conditions of the Ideal Test
(Theorem 14.1, printed p. 262), so $J$ is an ideal of $R$.

:::

:::

::: {.pf-step #empty}

When $I=\emptyset$, $J=R$, and $R$ is an ideal of $R$.

::: pf-proof

An intersection over an empty index set is the ambient set, so $J=R$. The set $R$ is
nonempty, closed under subtraction, and satisfies $ra,ar\in R$ for all $a,r\in R$, so $R$
is an ideal of $R$ by the Ideal Test; when $R$ has a unity, $R=\langle 1\rangle$. This is
the case the outline's nonemptiness argument does not reach, since it selects $0$ from an
ideal and there is none.

:::

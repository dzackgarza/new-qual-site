::: {.problem}
Find a subring of $\mathbb { Z } \oplus \mathbb { Z }$ that is not an ideal of $\mathbb { Z } \oplus \mathbb { Z }$
:::

::: {.solution}
$I = \{ ( a , a ) | a \in \mathbb { Z } \}$ is a subring but not an ideal since $( 1 , 2 ) ( a , a ) = ( a , 2 a ) \not \in I .$
:::

::: {.problem}
Let $R$ be a commutative ring.
Show that $R/N(\langle 0 \rangle)$ has no nonzero nilpotent elements.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own. Write $I=N(\langle 0\rangle)=\theset{r\in R\mid r^{n}=0\text{ for some }n\ge1}$ for the nil radical of $R$, and $x+I$ for the class of $x$ in $R/I$.

::: pf

::: {.pf-step #ideal}
$I$ is an ideal of $R$, so $R/I$ is a ring and has a zero element, namely $I$.

::: pf-proof
This is Exercise 46 of this chapter: for a commutative ring $R$ and an ideal $A$, the set $N(A)=\theset{r\mid r^{n}\in A\text{ for some }n\ge1}$ is an ideal; with $A=\langle0\rangle$ it is $I$, the set of nilpotent elements. A quotient by an ideal is a ring, and its zero class is $I$ itself.
:::

:::

::: {.pf-step #class-to-power}
If $x+I$ is nilpotent in $R/I$, then $x^{n}\in I$ for some $n\ge1$.

::: pf-proof
Nilpotence of $x+I$ means $(x+I)^{n}=I$ for some $n\ge1$, and the product in the quotient is computed on representatives, $(x+I)^{n}=x^{n}+I$; so $x^{n}+I=I$, that is $x^{n}\in I$.
:::

:::

::: {.pf-step #element-nilpotent}
If $x^{n}\in I$ for some $n\ge1$, then $x$ itself lies in $I$.

::: pf-proof
By the definition of $I$, membership $x^{n}\in I$ means that some positive power of $x^{n}$ is $0$: $(x^{n})^{m}=0$ for some $m\ge1$. Then $x^{nm}=(x^{n})^{m}=0$ with $nm\ge1$, which is exactly the condition defining membership in $I$.
:::

:::

::: {.pf-step #answer}
$R/N(\langle 0\rangle)$ has no nonzero nilpotent element.

::: pf-proof
Let $x+I$ be nilpotent. Step [](#class-to-power){.pf-ref} gives $x^{n}\in I$ and step [](#element-nilpotent){.pf-ref} gives $x\in I$, so $x+I=I$, the zero of the quotient by step [](#ideal){.pf-ref}. Hence the only nilpotent element of the quotient is zero.
:::

::: {.problem}
Find all maximal ideals in:
:::

::: {.solution}
a. $\mathbb { Z } _ { 8 } \colon \ ( 2 )$

b. $\mathbb { Z } _ { 1 0 } \colon$ $( 2 ) , ( 5 )$

c. $\mathbb { Z } _ { 1 2 }$ : $( 2 ) , ( 3 )$

d. $\mathbb { Z } _ { n }$ : The maximal ideals are of the form $( p )$ where p is a prime that divides n.
:::

::: {.problem}
Let $R$ be a ring and let $I$ be an ideal of $R$. Prove that the factor ring $R/I$ is commutative if and only if $rs - sr \in I$ for all $r$ and $s$ in $R$.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch14Sltns.pdf`, and entry "# 36" of that outline covers Gallian 7e Chapter 14 Exercise 36. The outline uses $(r+I)(s+I)=rs+I$ and the additive-coset criterion in both directions. The criterion and each direction are proved explicitly below.

::: pf

::: {.pf-step #coset-criterion}
For $x,y\in R$, the equality $x+I=y+I$ holds if and only if $x-y\in I$.

::: pf-proof

::: pf-step
If $x+I=y+I$, then $x-y\in I$.

::: pf-proof
Since $0\in I$, we have $x=x+0\in x+I=y+I$. Thus $x=y+i$ for some $i\in I$ and therefore $x-y=i\in I$.
:::

:::

::: pf-step
If $x-y\in I$, then $x+I=y+I$.

::: pf-proof
Put $i=x-y\in I$. Every element of $x+I$ has the form $x+j=y+(i+j)$ with $j\in I$, and $i+j\in I$ because $I$ is closed under addition. Hence $x+I\subseteq y+I$. Conversely, $y-x=-i\in I$ because $I$ is closed under additive inverses, so the same argument gives $y+I\subseteq x+I$.
:::

:::

:::

:::

::: {.pf-step #forward}
If $R/I$ is commutative, then $rs-sr\in I$ for all $r,s\in R$.

::: pf-proof
For arbitrary $r,s\in R$, the definition of multiplication in $R/I$ and commutativity give
$$
rs+I=(r+I)(s+I)=(s+I)(r+I)=sr+I.
$$
Step [](#coset-criterion){.pf-ref} applied to this equality yields $rs-sr\in I$.
:::

:::

::: {.pf-step #converse}
If $rs-sr\in I$ for all $r,s\in R$, then $R/I$ is commutative.

::: pf-proof
Every element of $R/I$ has the form $r+I$ for some $r\in R$. For arbitrary $r,s\in R$, the hypothesis and step [](#coset-criterion){.pf-ref} give $rs+I=sr+I$. Consequently
$$
(r+I)(s+I)=rs+I=sr+I=(s+I)(r+I).
$$
Since these were arbitrary elements of $R/I$, multiplication in $R/I$ is commutative.
:::

::: {.problem}
Prove that $I = \langle 2 + 2i \rangle$ is not a prime ideal of $\ZZ[i]$. How many elements are in $\ZZ[i]/I$? What is the characteristic of $\ZZ[i]/I$?
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $I=(2+2i)\subseteq\ZZ[i]$ and $N(a+bi)=a^2+b^2$, so that $N(zw)=N(z)N(w)$.

::: pf

::: {.pf-step #not_prime}
$I$ is not a prime ideal.

::: pf-proof
$2(1+i)=2+2i\in I$, so the product of $2$ and $1+i$ lies in $I$. But $2\notin I$: if $2=(2+2i)(a+bi)$ then taking norms gives $4=8(a^2+b^2)$, impossible in integers. Similarly $1+i\notin I$: $2=N(1+i)$ would equal $8(a^2+b^2)$. So $I$ contains a product without containing either factor, which is exactly the failure of primality.
:::

:::

::: {.pf-step #order}
$\ZZ[i]/I$ has $8$ elements.

::: pf-proof
First $4\in I$, since $(2+2i)(1-i)=2-2i+2i-2i^2=2-2i+2i+2=4$. So in the quotient $4=0$, and also $2i=-2$ because $2+2i\in I$. Hence every class is $a+bi+I$ with $a$ taken modulo $4$ and $b$ modulo $2$: representatives $\{a+bi:0\le a\le3,\ 0\le b\le1\}$, eight in number. Distinctness: if $a+bi-a'-b'i\in I$ with both in that range, then applying the ring homomorphism $\ZZ[i]\to\ZZ[i]/I$ and reducing mod the relations shows the difference has $a=a'$ and $b=b'$ modulo $4$ and $2$, hence equal as representatives. So the quotient has exactly $8$ elements, which agrees with the norm $\abs{N(2+2i)}=8$ of the ideal.
:::

:::

::: {.pf-step #char}
The characteristic of $\ZZ[i]/I$ is $4$.

::: pf-proof
$4\cdot1=4\in I$ so the characteristic divides $4$, and it is not $1$ or $2$ because $1\notin I$ and $2\notin I$ by step [](#not_prime){.pf-ref}. Hence the least positive integer killing the identity class is $4$, which is the characteristic.
:::

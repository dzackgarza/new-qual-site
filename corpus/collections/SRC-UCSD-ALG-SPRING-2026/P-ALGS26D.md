::: problem
Suppose $A$ is a unital commutative ring and $\operatorname{Spec}(A)$ is the set of all prime ideals of $A$.
For an $A$-module $M$ and $\mathfrak{p} \in \operatorname{Spec}(A)$, let $M_\mathfrak{p}$ be the localization of $M$ at $\mathfrak{p}$.
Let
$$
\operatorname{supp} M := \{\mathfrak{p} \in \operatorname{Spec}(A) \mid M_\mathfrak{p} \neq 0\}.
$$

(a) Prove that for a finitely generated $A$-module $M$,
$$
\operatorname{supp} M = \{\mathfrak{p} \in \operatorname{Spec}(A) \mid \operatorname{ann}(M) \subseteq \mathfrak{p}\},
$$
where $\operatorname{ann}(M)$ is the annihilator of $M$.

(b) For a positive integer $d$, let $U_d(M) := \{\mathfrak{p} \in \operatorname{Spec}(A) \mid M_\mathfrak{p} \text{ can be generated by } d \text{ elements}\}$.
Prove that if $M$ is finitely generated and $\mathfrak{p}_0 \in U_d(M)$, then there exists $a_0 \in A \setminus \mathfrak{p}_0$ such that $\{\mathfrak{q} \in \operatorname{Spec}(A) \mid a_0 \notin \mathfrak{q}\} \subseteq U_d(M)$.

Hint: Suppose $N_{\mathfrak{p}_0} = M_{\mathfrak{p}_0}$ where $N = \langle x_1, \ldots, x_d \rangle \subseteq M$.
Consider $\operatorname{supp}(M/N)$.
:::

::: {.solution}
<1>1. If \(\operatorname{ann}(M)\nsubseteq\mathfrak p\), then \(M_{\mathfrak p}=0\).
::: {.proof}
Choose \(a\in\operatorname{ann}(M)\setminus\mathfrak p\). In \(A_{\mathfrak p}\), the element \(a/1\) is a unit.
It annihilates every element of \(M_{\mathfrak p}\), because \(aM=0\). A module annihilated by a unit is zero, so \(M_{\mathfrak p}=0\).
:::

<1>2. If \(M\) is finitely generated and \(M_{\mathfrak p}=0\), then \(\operatorname{ann}(M)\nsubseteq\mathfrak p\).
::: {.proof}
Let \(m_1,\dots,m_r\) generate \(M\). Since \(m_i/1=0\) in \(M_{\mathfrak p}\), for each \(i\) there exists \(s_i\in A\setminus\mathfrak p\) such that
\[
s_i m_i=0.
\]
Set \(s=s_1\cdots s_r\). Because \(\mathfrak p\) is prime and every \(s_i\notin\mathfrak p\), one has \(s\notin\mathfrak p\). Also \(sm_i=0\) for every generator \(m_i\), so \(sM=0\). Hence
\[
s\in\operatorname{ann}(M)\setminus\mathfrak p.
\]
Thus \(\operatorname{ann}(M)\nsubseteq\mathfrak p\).
:::

<1>3. Therefore, for finitely generated \(M\),
\[
\operatorname{supp}M
 =\{\mathfrak p\in\operatorname{Spec}(A):\operatorname{ann}(M)\subseteq\mathfrak p\}.
\]
::: {.proof}
By <1>1 and <1>2,
\[
M_{\mathfrak p}=0
\quad\Longleftrightarrow\quad
\operatorname{ann}(M)\nsubseteq\mathfrak p.
\]
Negating both conditions gives the displayed equality.
This proves part (a).
:::

<1>4. Suppose \(\mathfrak p_0\in U_d(M)\). There exist \(x_1,\dots,x_d\in M\) such that, for \(N=\langle x_1,\dots,x_d\rangle\),
\[
N_{\mathfrak p_0}=M_{\mathfrak p_0}.
\]
::: {.proof}
Choose \(d\) generators of the localized module \(M_{\mathfrak p_0}\). Each is of the form \(y_i/s_i\) with \(y_i\in M\) and \(s_i\notin\mathfrak p_0\). Since \(s_i/1\) is a unit in \(A_{\mathfrak p_0}\), replacing \(y_i/s_i\) by \(y_i/1\) does not change the submodule generated.
Take \(x_i=y_i\).
:::

<1>5. The finitely generated module \(M/N\) satisfies
\[
(M/N)_{\mathfrak p_0}=0.
\]
::: {.proof}
Localization is exact, and <1>4 gives \(N_{\mathfrak p_0}=M_{\mathfrak p_0}\). Hence
\[
(M/N)_{\mathfrak p_0}\cong M_{\mathfrak p_0}/N_{\mathfrak p_0}=0.
\]
Because \(M\) is finitely generated, so is its quotient \(M/N\).
:::

<1>6. There exists
\[
a_0\in\operatorname{ann}(M/N)\setminus\mathfrak p_0.
\]
::: {.proof}
Apply <1>2 to the finitely generated module \(M/N\) and the prime \(\mathfrak p_0\), using <1>5.
:::

<1>7. If \(\mathfrak q\in\operatorname{Spec}(A)\) and \(a_0\notin\mathfrak q\), then \(M_{\mathfrak q}=N_{\mathfrak q}\).
::: {.proof}
Since \(a_0\in\operatorname{ann}(M/N)\) and \(a_0\notin\mathfrak q\), part (a), applied to \(M/N\), gives
\[
(M/N)_{\mathfrak q}=0.
\]
Localizing the exact sequence \(N\to M\to M/N\to0\) therefore yields \(N_{\mathfrak q}=M_{\mathfrak q}\).
:::

<1>8. Hence
\[
\{\mathfrak q\in\operatorname{Spec}(A):a_0\notin\mathfrak q\}\subseteq U_d(M).
\]
::: {.proof}
For every such \(\mathfrak q\), <1>7 gives \(M_{\mathfrak q}=N_{\mathfrak q}\). The latter is generated by the images of \(x_1,\dots,x_d\), so \(M_{\mathfrak q}\) can be generated by \(d\) elements.
This proves part (b).
:::
:::

::: {.exercise}
Let $A$ be a self-adjoint $n \times n$ matrix.
Prove that there is a real number $c$ such that the matrix $cI + A$ is positive.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no published solution set for it is retained in `tmp/sources`, so nothing below is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §9.3 Exercise 13. Here $A$ is a self-adjoint $n\times n$ complex matrix, so $A^{*}=A$, and a matrix is positive when it is self-adjoint with all eigenvalues positive; $I$ is the identity.

::: pf

::: {.pf-step #spectral}

There is a unitary $U$ with $U^{*}AU=\operatorname{diag}(\lambda_{1},\dots,\lambda_{n})$ and $\lambda_{i}\in\RR$.

::: pf-proof

The spectral theorem for self-adjoint matrices: a self-adjoint matrix is unitarily diagonalizable with real eigenvalues.

:::

:::

::: {.pf-step #conj}

For real $c$ one has $U^{*}(cI+A)U=\operatorname{diag}(c+\lambda_{1},\dots,c+\lambda_{n})$.

::: pf-proof

$U^{*}(cI+A)U=cU^{*}U+U^{*}AU=cI+\operatorname{diag}(\lambda_{1},\dots,\lambda_{n})$ by step [](#spectral){.pf-ref} and $U^{*}U=I$.

:::

:::

::: {.pf-step #choose}

Choose $c>-\min_{i}\lambda_{i}$, for instance $c=1-\min_{i}\lambda_{i}$; then $c+\lambda_{i}>0$ for every $i$.

::: pf-proof

The minimum $m=\min_{i}\lambda_{i}$ exists because the list is finite, and $c>-m$ gives $c+\lambda_{i}\geq c+m>0$.

:::

:::

::: {.pf-step #done}

$cI+A$ is positive.

::: pf-proof

By steps [](#conj){.pf-ref} and [](#choose){.pf-ref}, $cI+A$ is unitarily similar to the diagonal matrix with the positive entries $c+\lambda_{i}$, so it is self-adjoint and its eigenvalues $c+\lambda_{i}$ are positive; unitary similarity preserves self-adjointness and the eigenvalues.

:::

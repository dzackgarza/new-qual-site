::: {.exercise}
Does $((x_1, x_2) \mid (y_1, y_2)) = x_1\bar{y}_1 + 2x_2\bar{y}_1 + 2x_1\bar{y}_2 + x_2\bar{y}_2$ define an inner product on $\CC^2$?
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §9.3 Exercise 8 [@HK71].

::: pf

::: {.pf-step #matrix}
The form is $(X\mid Y)=Y^{*}AX$ with $A=\begin{pmatrix}1&2\\2&1\end{pmatrix}$.

::: pf-proof
Writing $X=(x_1,x_2)^{t}$ and $Y=(y_1,y_2)^{t}$, the product $Y^{*}AX$ is $\bar y_1(x_1+2x_2)+\bar y_2(2x_1+x_2)=x_1\bar y_1+2x_2\bar y_1+2x_1\bar y_2+x_2\bar y_2$, the displayed form.
:::

:::

::: {.pf-step #hermitian}
$A$ is Hermitian, so the form has conjugate symmetry and is linear in the first argument.

::: pf-proof
$A^{*}=\bar A^{t}=A$ because $A$ is real symmetric; a form $Y^{*}AX$ with $A$ Hermitian satisfies $\overline{(Y\mid X)}=\overline{X^{*}AY}=Y^{*}A^{*}X=Y^{*}AX=(X\mid Y)$, and it is linear in $X$ for fixed $Y$ by matrix multiplication.
:::

:::

::: {.pf-step #negative}
$\bigl(X\mid X\bigr)=-2$ for $X=\binom{1}{-1}$.

::: pf-proof
$AX=\binom{1-2}{2-1}=\binom{-1}{1}$, and $X^{*}AX=(1,-1)\binom{-1}{1}=-1-1=-2$.
:::

:::

::: {.pf-step #notinner}
The form is not positive definite, so it is not an inner product on $\CC^{2}$.

::: pf-proof
An inner product requires $(X\mid X)>0$ for every nonzero $X$, whereas step [](#negative){#negative} exhibits a nonzero $X$ with negative square length. Hence the answer to the exercise is no:
$$
\boxed{\text{the displayed form is not an inner product on }\CC^{2}.}
$$
The failure is not conjugate symmetry, which holds by step [](#hermitian){.pf-ref}, but positivity; equivalently the Hermitian matrix $A$ has the negative eigenvalue $-1$, with eigenvector $(1,-1)$.
:::

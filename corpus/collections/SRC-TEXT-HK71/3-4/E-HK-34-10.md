::: {.exercise}
We have seen that the linear operator $T$ on $\RR^2$ defined by $T(x_1, x_2) = (x_1, 0)$ is represented in the standard ordered basis by the matrix
$$
A = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}.
$$
This operator satisfies $T^2 = T$.
Prove that if $S$ is a linear operator on $\RR^2$ such that $S^2 = S$, then $S = 0$, or $S = I$, or there is an ordered basis $\mathfrak{B}$ for $\RR^2$ such that $[S]_{\mathfrak{B}} = A$ (above).
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is an archive.org record, so the argument is the card's own. Let $V=\RR^2$ and let $S$ be a linear operator on $V$ with $S^2=S$, and put
$$
A=\begin{bmatrix}1&0\\ 0&0\end{bmatrix}.
$$

::: pf

::: {.pf-step #sum}
$V=\operatorname{range}S+\ker S$, since $v=Sv+(v-Sv)$ belongs to the sum for every $v$.

::: pf-proof
The first summand $Sv$ is in the range by definition. The second is killed by $S$: $S(v-Sv)=Sv-S^2v=Sv-Sv=0$, using $S^2=S$. So every $v$ is the sum of a vector of the range and a vector of the kernel.
:::

:::

::: {.pf-step #disjoint}
$\operatorname{range}S\cap\ker S=\{0\}$.

::: pf-proof
Let $w$ lie in both. As $w$ is in the range, $w=Su$ for some $u$; as $w$ is in the kernel, $0=Sw=S(Su)=S^2u=Su=w$. So $w=0$.
:::

:::

::: {.pf-step #direct}
$V=\operatorname{range}S\oplus\ker S$, and $\dim\operatorname{range}S+\dim\ker S=2$.

::: pf-proof
Steps [](#sum){.pf-ref} and [](#disjoint){.pf-ref} give the direct sum. Taking dimensions, $\dim V=\dim\operatorname{range}S+\dim\ker S$, and $\dim V=2$; this is also rank-nullity. So the two dimensions are $0$ and $2$ in some order, or both $1$.
:::

:::

::: {.pf-step #zero}
If $\operatorname{range}S=\{0\}$ then $S=0$; if $\ker S=\{0\}$ then $S=I$.

::: pf-proof
In the first case every value $Sv$ lies in the range, hence is $0$, so $S=0$. In the second case $\dim\ker S=0$, so $S$ is injective and, on the finite-dimensional space $V$, invertible; multiplying $S^2=S$ on the left by $S^{-1}$ gives $S=I$.
:::

:::

::: {.pf-step #generic}
If both subspaces are one-dimensional, then choosing $u\in\operatorname{range}S$, $v\in\ker S$ nonzero gives a basis $\mathfrak B=(u,v)$ with
$$
[S]_{\mathfrak B}=A .
$$

::: pf-proof
The vectors $u,v$ are nonzero and lie in subspaces meeting only in $0$, so they are independent; two independent vectors in a two-dimensional space form a basis. Because $u$ is in the range, $u=Sw$ for some $w$, and then $Su=S(Sw)=S^2w=Sw=u$; and $Sv=0$ because $v$ is in the kernel. So the first column of $[S]_{\mathfrak B}$ is the coordinate vector of $Su=u$, namely $(1,0)^{t}$, and the second is that of $Sv=0$, namely $(0,0)^{t}$; those two columns are $A$.
:::

:::

::: {.pf-step}
Every idempotent $S$ on $\RR^2$ satisfies $S=0$, or $S=I$, or $[S]_{\mathfrak B}=A$ for some ordered basis.

::: pf-proof
By step [](#direct){.pf-ref} the pair of dimensions is $(0,2)$, $(2,0)$ or $(1,1)$. The case $\dim\operatorname{range}S=0$ is $S=0$ and the case $\dim\ker S=0$ is $S=I$, both by step [](#zero){.pf-ref}; the remaining case is $\dim\operatorname{range}S=\dim\ker S=1$ and is step [](#generic){.pf-ref}. These exhaust the possibilities, so the assertion holds for every $S$ with $S^2=S$.
:::

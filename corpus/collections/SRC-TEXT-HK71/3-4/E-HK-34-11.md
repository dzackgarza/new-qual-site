::: {.exercise}
Let $W$ be the space of all $n \times 1$ column matrices over a field $F$.
If $A$ is an $n \times n$ matrix over $F$, then $A$ defines a linear operator $L_A$ on $W$ through left multiplication: $L_A(X) = AX$.
Prove that every linear operator on $W$ is left multiplication by some $n \times n$ matrix, i.e., is $L_A$ for some $A$.

Now suppose $V$ is an $n$-dimensional vector space over the field $F$, and let $\mathfrak{B}$ be an ordered basis for $V$.
For each $\alpha$ in $V$, define $U\alpha = [\alpha]_{\mathfrak{B}}$.
Prove that $U$ is an isomorphism of $V$ onto $W$.
If $T$ is a linear operator on $V$, then $UTU^{-1}$ is a linear operator on $W$.
Accordingly, $UTU^{-1}$ is left multiplication by some $n \times n$ matrix $A$.
What is $A$?

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §3.4 Exercise 11; the argument is the card's own.

Throughout, $W=F^{n\times1}$ is the space of column matrices, $e_j$ is the $j$-th standard basis column, $L_A(X)=AX$ for $A\in F^{n\times n}$, and $[\ \cdot\ ]_{\mathfrak{B}}$ denotes the coordinate column of a vector in the ordered basis $\mathfrak{B}=(\alpha_1,\dots,\alpha_n)$.

::: pf

::: {.pf-step #existence}
Every linear operator $L$ on $W$ equals $L_A$, where $A$ is the matrix whose $j$-th column is $L(e_j)$.

::: pf-proof
Put $A=\begin{bmatrix}L(e_1)&\cdots&L(e_n)\end{bmatrix}\in F^{n\times n}$. Every $X\in W$ is $\sum_jx_je_j$ with $x_j$ its $j$-th entry, and by linearity $L(X)=\sum_jx_jL(e_j)$, which is the linear combination of the columns of $A$ with coefficients $x_j$, that is $AX$. So $L(X)=AX=L_A(X)$ for all $X$.

:::

:::

::: {.pf-step #isomorphism}
$U:V\to W$, $U\alpha=[\alpha]_{\mathfrak B}$, is an isomorphism.

::: pf-proof
Linearity: coordinates of $\alpha+\beta$ are the sums of the coordinates, and coordinates of $c\alpha$ the $c$-multiples, because $\mathfrak{B}$ is a basis; so $U(\alpha+\beta)=U\alpha+U\beta$ and $U(c\alpha)=c\,U\alpha$. Injectivity: $U\alpha=0$ means $\alpha$ is a linear combination of the $\alpha_j$ with all coefficients $0$, that is $\alpha=0$, using uniqueness of coordinates. Surjectivity: given a column $(x_1,\dots,x_n)^{t}$, the vector $\alpha=\sum_jx_j\alpha_j$ exists and has $U\alpha$ equal to that column. A bijective linear map is an isomorphism.

:::

:::

::: {.pf-step #conjugation}
$UTU^{-1}$ is left multiplication by $[T]_{\mathfrak B}$, the matrix whose $j$-th column is $[T\alpha_j]_{\mathfrak B}$.

::: pf-proof
$U$, being an isomorphism, is invertible, so $UTU^{-1}$ is a linear operator on $W$ and by step [](#existence){.pf-ref} it equals $L_A$ with $A$ having $j$-th column $(UTU^{-1})(e_j)$. Now $U^{-1}(e_j)$ is the vector whose coordinate column is $e_j$, namely $\alpha_j$, since coordinates are unique; hence the $j$-th column is $U(T\alpha_j)=[T\alpha_j]_{\mathfrak B}$. That is exactly the definition of the matrix of $T$ in the basis $\mathfrak B$.

:::

:::

::: {.pf-step #answer}
$A=[T]_{\mathfrak B}$.

::: pf-proof
By step [](#conjugation){.pf-ref} the matrix of $UTU^{-1}$ is the matrix whose columns are the coordinate columns of $T\alpha_j$, which is by definition the matrix of $T$ in the ordered basis $\mathfrak B$. So the $A$ asked for is $[T]_{\mathfrak B}$, and the construction shows moreover that $A$ depends on $\mathfrak B$ and not on $T$ alone.

:::

::: {.exercise}
Let $T$ be the linear operator on $\RR^2$ defined by
\[
T(x_1, x_2) = (-x_2,\; x_1).
\]

(a) What is the matrix of $T$ in the standard ordered basis for $\RR^2$?

(b) What is the matrix of $T$ in the ordered basis $\mathfrak{B} = \{\alpha_1, \alpha_2\}$, where $\alpha_1 = (1, 2)$ and $\alpha_2 = (1, -1)$?

(c) Prove that for every real number $c$ the operator $(T - cI)$ is invertible.

(d) Prove that if $\mathfrak{B}$ is any ordered basis for $\RR^2$ and $[T]_{\mathfrak{B}} = A$, then $A_{12}A_{21} \neq 0$.
:::

::: {.solution}
**(a).**

<1>1. $T(1,0) = (0,1)$ and $T(0,1) = (-1,0)$.
::: {.proof}
apply the definition $T(x_1,x_2) = (-x_2, x_1)$.
:::

<1>2. Hence $[T]_{\text{std}} = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$.
::: {.proof}
the columns are the images of the basis vectors.
:::

**(b).**

<1>1. $T(\alpha_1) = T(1,2) = (-2, 1)$ and $T(\alpha_2) = T(1,-1) = (1, 1)$.
::: {.proof}
apply $T$.
:::

<1>2. Solve $(-2,1) = a(1,2) + b(1,-1)$: $a + b = -2$, $2a - b = 1$, giving $a = -1/3$, $b = -5/3$.
::: {.proof}
linear system.
:::

<1>3. Solve $(1,1) = c(1,2) + d(1,-1)$: $c + d = 1$, $2c - d = 1$, giving $c = 2/3$, $d = 1/3$.
::: {.proof}
linear system.
:::

<1>4. Hence $[T]_{\mathfrak{B}} = \begin{pmatrix} -1/3 & 2/3 \\ -5/3 & 1/3 \end{pmatrix}$.
::: {.proof}
<1>2 and <1>3.
:::

**(c).**

<1>1. $[T - cI]_{\text{std}} = \begin{pmatrix} -c & -1 \\ 1 & -c \end{pmatrix}$.
::: {.proof}
<1>2 (a).
:::

<1>2. $\det(T - cI) = c^2 + 1 \neq 0$ for every real $c$.
::: {.proof}
$\det \begin{pmatrix} -c & -1 \\ 1 & -c \end{pmatrix} = c^2 + 1 > 0$.
:::

<1>3. Hence $T - cI$ is invertible for every real $c$.
::: {.proof}
<1>2 (a nonzero determinant means invertible).
:::

**(d).**

<1>1. $A = [T]_{\mathfrak{B}}$ is similar to $\begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$.
::: {.proof}
change of basis.
:::

<1>2. Hence $\det A = 1$ and $\operatorname{tr} A = 0$.
::: {.proof}
determinant and trace are invariant under similarity, and $\det \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix} = 1$, $\operatorname{tr} = 0$.
:::

<1>3. Write $A = \begin{pmatrix} a & b \\ c & d \end{pmatrix}$; then $ad - bc = 1$ and $a + d = 0$.
::: {.proof}
<1>2.
:::

<1>4. Suppose $bc = 0$. Then $ad = 1$ and $a + d = 0$, so $d = -a$ and $-a^2 = 1$, impossible over $\RR$.
::: {.proof}
<1>3; $a^2 = -1$ has no real solution.
:::

<1>5. Hence $bc = A_{12}A_{21} \neq 0$.
::: {.proof}
<1>4.
:::

<1>6. Q.E.D.
::: {.proof}
<1>2 (a), <1>4 (b), <1>3 (c), <1>5 (d).
:::
:::

::: {.exercise}
Let $V$ be an inner product space, and let $\alpha, \beta$ be vectors in $V$.
Show that $\alpha = \beta$ if and only if $(\alpha \mid \gamma) = (\beta \mid \gamma)$ for every $\gamma$ in $V$.

:::

::: {.solution}
There is no retained solution set for this exercise ; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §8.2 Exercise 5 on printed p. 289; the argument is the card's own.

Throughout, $V$ is an inner product space over $F\subseteq\CC$, the inner product is linear in the first argument and conjugate linear in the second, and $\norm{\gamma}^{2}=(\gamma\mid\gamma)\ge0$ with equality only for $\gamma=0$.

::: pf

::: {.pf-step #forward}
If $\alpha=\beta$ then $(\alpha\mid\gamma)=(\beta\mid\gamma)$ for every $\gamma$.

::: pf-proof
$(\ \cdot\mid\gamma)$ is a function of its first argument, so equal first arguments give equal values.

:::

:::

::: {.pf-step #difference}
If $(\alpha\mid\gamma)=(\beta\mid\gamma)$ for every $\gamma$, then $(\alpha-\beta\mid\gamma)=0$ for every $\gamma$.

::: pf-proof
$(\alpha-\beta\mid\gamma)=(\alpha\mid\gamma)-(\beta\mid\gamma)$ by linearity in the first argument, and this is $0$ by hypothesis.

:::

:::

::: {.pf-step #converse}
If $(\alpha-\beta\mid\gamma)=0$ for every $\gamma$, then $\alpha=\beta$.

::: pf-proof
Take $\gamma=\alpha-\beta$, which is allowed since $\alpha-\beta\in V$. Then $\norm{\alpha-\beta}^{2}=(\alpha-\beta\mid\alpha-\beta)=0$, so by positive definiteness $\alpha-\beta=0$, that is $\alpha=\beta$.

:::

:::

::: {.pf-step #iff}
$\alpha=\beta$ if and only if $(\alpha\mid\gamma)=(\beta\mid\gamma)$ for every $\gamma\in V$.

::: pf-proof
One implication is step [](#forward){.pf-ref}; the other follows from steps [](#difference){.pf-ref} and [](#converse){.pf-ref}.

:::

::: {.exercise}
Let $V$ be the real inner product space consisting of the space of real-valued continuous functions on the interval, $-1 \leq t \leq 1$, with the inner product
\[
(f \mid g) = \int_{-1}^{1} f(t)g(t)\,dt.
\]
Let $W$ be the subspace of odd functions, i.e., functions satisfying $f(-t) = -f(t)$.
Find the orthogonal complement of $W$.
:::

::: {.solution}
::: pf

::: pf-step
Define the subspace of even functions $W_{\text{even}} = \{g \in V : g(-t) = g(t) \text{ for all } t \in [-1, 1]\}$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #s2}
Show that $W_{\text{even}} \subseteq W^\perp$:

::: pf-proof

::: pf-step
Let $g \in W_{\text{even}}$ and $f \in W$.

::: pf-proof
setup.
:::

:::

::: pf-step
The integrand $h(t) = f(t)g(t)$ is an odd function:
\[
h(-t) = f(-t)g(-t) = (-f(t))g(t) = -f(t)g(t) = -h(t).
\]

::: pf-proof
$f$ is odd and $g$ is even.
:::

:::

::: {.pf-step #s2-3}
The integral of any continuous odd function over a symmetric interval $[-1, 1]$ is zero:
\[
(f \mid g) = \int_{-1}^1 f(t)g(t)\,dt = \int_{-1}^1 h(t)\,dt = 0.
\]

::: pf-proof
substitution $u = -t$ gives $\int_{-1}^1 h(t)\,dt = -\int_{-1}^1 h(u)\,du$.
:::

:::

::: pf-step
Hence $g \in W^\perp$, so $W_{\text{even}} \subseteq W^\perp$.

::: pf-proof
step [](#s2-3){.pf-ref} holds for all $f \in W$.
:::

:::

:::

:::

::: {.pf-step #s3}
Show that $W^\perp \subseteq W_{\text{even}}$:

::: pf-proof

::: {.pf-step #s3-1}
Let $g \in W^\perp$, so $(f \mid g) = 0$ for all $f \in W$.

::: pf-proof
definition of orthogonal complement.
:::

:::

::: {.pf-step #s3-2}
Decompose $g$ into its even and odd parts:
\[
g(t) = g_{\text{even}}(t) + g_{\text{odd}}(t), \quad \text{where } g_{\text{odd}}(t) = \frac{g(t) - g(-t)}{2} \text{ and } g_{\text{even}}(t) = \frac{g(t) + g(-t)}{2}.
\]

::: pf-proof
algebraic identity and standard parity decomposition of functions.
:::

:::

::: pf-step
$g_{\text{odd}} \in W$ and $g_{\text{even}} \in W_{\text{even}}$.

::: pf-proof
$g_{\text{odd}}(-t) = -g_{\text{odd}}(t)$ and $g_{\text{even}}(-t) = g_{\text{even}}(t)$, with continuity preserved under linear combinations.
:::

:::

::: {.pf-step #s3-4}
Since $g \in W^\perp$ and $g_{\text{odd}} \in W$, $(g_{\text{odd}} \mid g) = 0$.

::: pf-proof
step [](#s3-1){.pf-ref}.
:::

:::

::: {.pf-step #s3-5}
By step [](#s2){.pf-ref}, $g_{\text{even}} \in W_{\text{even}} \subseteq W^\perp$, so $(g_{\text{odd}} \mid g_{\text{even}}) = 0$.

::: pf-proof
step [](#s2){.pf-ref}.
:::

:::

::: pf-step
Expand the inner product:
\[
0 = (g_{\text{odd}} \mid g) = (g_{\text{odd}} \mid g_{\text{even}} + g_{\text{odd}}) = (g_{\text{odd}} \mid g_{\text{even}}) + (g_{\text{odd}} \mid g_{\text{odd}}) = \|g_{\text{odd}}\|^2.
\]

::: pf-proof
bilinearity of the inner product, step [](#s3-4){.pf-ref}, and step [](#s3-5){.pf-ref}.
:::

:::

::: pf-step
$\|g_{\text{odd}}\|^2 = \int_{-1}^1 (g_{\text{odd}}(t))^2\,dt = 0$.

::: pf-proof
definition of the inner product norm.
:::

:::

::: {.pf-step #s3-8}
Since $g_{\text{odd}}$ is continuous and $(g_{\text{odd}}(t))^2 \ge 0$, $(g_{\text{odd}}(t))^2 = 0$ for all $t \in [-1, 1]$, so $g_{\text{odd}}(t) = 0$ identically.

::: pf-proof
a continuous nonnegative function with zero integral is identically zero.
:::

:::

::: pf-step
Thus $g(t) = g_{\text{even}}(t) \in W_{\text{even}}$, so $W^\perp \subseteq W_{\text{even}}$.

::: pf-proof
steps [](#s3-2){.pf-ref} and [](#s3-8){.pf-ref}.
:::

:::

:::

:::

::: pf-step
Conclusion: $W^\perp = W_{\text{even}}$ is the subspace of all real-valued continuous even functions on $[-1, 1]$.

::: pf-proof
step [](#s2){.pf-ref} and step [](#s3){.pf-ref}.
:::

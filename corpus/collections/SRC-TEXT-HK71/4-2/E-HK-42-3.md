::: {.exercise}
Let $A$ be an $n \times n$ diagonal matrix over the field $F$, i.e., $A = \operatorname{diag}(A_{11}, A_{22}, \dots, A_{nn})$ where $A_{ij} = 0$ for $i \neq j$.
Let $f(x) \in F[x]$ be the polynomial defined by:
$$
f(x) = (x - A_{11})(x - A_{22}) \cdots (x - A_{nn}) = \prod_{i=1}^n (x - A_{ii}).
$$
What is the matrix $f(A)$?
:::

::: {.solution}
**Goal:** Evaluate the matrix polynomial $f(A)$ for a diagonal matrix $A$ and prove that $f(A) = 0$ (the zero matrix).

::: pf

::: {.pf-step #s1}
Matrix Polynomial Evaluation on Diagonal Matrices:

::: pf-proof

::: pf-step
Let $A = \operatorname{diag}(d_1, d_2, \dots, d_n) \in M_n(F)$ where $d_i = A_{ii}$.
:::

::: pf-step
For any positive integer $k \ge 0$, powers of a diagonal matrix are diagonal with entries raised to that power:
$$A^k = \operatorname{diag}(d_1^k, d_2^k, \dots, d_n^k).$$
:::

::: pf-step
For any polynomial $p(x) = \sum_{k=0}^m c_k x^k \in F[x]$, by linearity of matrix addition and scalar multiplication:
$$p(A) = \sum_{k=0}^m c_k A^k = \operatorname{diag}\left( \sum_{k=0}^m c_k d_1^k, \dots, \sum_{k=0}^m c_k d_n^k \right) = \operatorname{diag}(p(d_1), p(d_2), \dots, p(d_n)).$$
:::

:::

:::

::: pf-step
Evaluating $f(x)$ at Each Diagonal Entry $d_j$:

::: pf-proof

::: pf-step
The polynomial is given as $f(x) = \prod_{i=1}^n (x - d_i)$.
:::

::: pf-step
For each fixed index $j \in \{1, 2, \dots, n\}$, we evaluate the scalar polynomial $f$ at the scalar entry $x = d_j$:
$$f(d_j) = \prod_{i=1}^n (d_j - d_i) = (d_j - d_1) \cdots (d_j - d_j) \cdots (d_j - d_n).$$
:::

::: pf-step
The $j$-th factor in the product is $(d_j - d_j) = 0$.
:::

::: pf-step
Therefore:
$$f(d_j) = 0 \quad \text{for every } j \in \{1, 2, \dots, n\}.$$
:::

:::

:::

::: pf-step
Computation of $f(A)$:

::: pf-proof

::: pf-step
By Step [](#s1){.pf-ref}:
$$f(A) = \operatorname{diag}(f(d_1), f(d_2), \dots, f(d_n)) = \operatorname{diag}(0, 0, \dots, 0) = 0_{n \times n}.$$
:::

::: pf-step
Thus $f(A)$ is the $n \times n$ **zero matrix**.
:::

:::

:::

::: pf-step
Remark on Cayley–Hamilton Theorem:

::: pf-proof

::: pf-step
Notice that $f(x) = \det(x I - A)$ is precisely the **characteristic polynomial** of the diagonal matrix $A$.
:::

::: pf-step
The result $f(A) = 0$ is the diagonal case of the **Cayley–Hamilton Theorem**.
:::

:::

:::

::: pf-step
Conclusion:
The matrix $f(A)$ is the zero matrix $0_{n \times n}$.
:::

:::

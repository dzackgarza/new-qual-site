::: {.exercise}
Let $A$ be an $n \times n$ diagonal matrix over the field $F$, i.e., $A = \operatorname{diag}(A_{11}, A_{22}, \dots, A_{nn})$ where $A_{ij} = 0$ for $i \neq j$.
Let $f(x) \in F[x]$ be the polynomial defined by:
$$
f(x) = (x - A_{11})(x - A_{22}) \cdots (x - A_{nn}) = \prod_{i=1}^n (x - A_{ii}).
$$
What is the matrix $f(A)$?
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
Matrix Polynomial Evaluation on Diagonal Matrices:

::: pf-proof
The subclaims compute the powers of a diagonal matrix and then extend the computation to an arbitrary polynomial by linearity.

::: pf-step
Let $A = \operatorname{diag}(d_1, d_2, \dots, d_n) \in M_n(F)$ where $d_i = A_{ii}$.

::: pf-proof
This only renames the entries: $A$ is given diagonal, so $d_i=A_{ii}$ and $A_{ij}=0$ for $i\neq j$.
:::

:::

::: pf-step
For every integer $k \ge 0$, powers of a diagonal matrix are diagonal with entries raised to that power:
$$A^k = \operatorname{diag}(d_1^k, d_2^k, \dots, d_n^k).$$

::: pf-proof
Induction on $k$: for $k=0$ the identity matrix is diagonal with entries $d_i^0=1$. If $A^k$ has the displayed form, then $A^{k+1}=A^kA$ has $(i,i)$ entry $d_i^kd_i=d_i^{k+1}$, and its off-diagonal entries vanish because both factors are diagonal.
:::

:::

::: pf-step
For any polynomial $p(x) = \sum_{k=0}^m c_k x^k \in F[x]$, by linearity of matrix addition and scalar multiplication:
$$p(A) = \sum_{k=0}^m c_k A^k = \operatorname{diag}\left( \sum_{k=0}^m c_k d_1^k, \dots, \sum_{k=0}^m c_k d_n^k \right) = \operatorname{diag}(p(d_1), p(d_2), \dots, p(d_n)).$$

::: pf-proof
A linear combination of the diagonal matrices $A^k$ is diagonal, and its $i$-th diagonal entry is the same combination of the entries $d_i^k$, namely $\sum_k c_k d_i^k=p(d_i)$; the off-diagonal entries are combinations of zeros.
:::

:::

:::

:::

::: pf-step
Evaluating $f(x)$ at Each Diagonal Entry $d_j$:

::: pf-proof
The subclaims show that for every $j$ one factor of $f(d_j)$ vanishes.

::: pf-step
The polynomial is given as $f(x) = \prod_{i=1}^n (x - d_i)$.

::: pf-proof
This is the definition of $f$ in the exercise, with the entries $A_{ii}$ renamed $d_i$.
:::

:::

::: pf-step
For each fixed index $j \in \{1, 2, \dots, n\}$, we evaluate the scalar polynomial $f$ at the scalar entry $x = d_j$:
$$f(d_j) = \prod_{i=1}^n (d_j - d_i) = (d_j - d_1) \cdots (d_j - d_j) \cdots (d_j - d_n).$$

::: pf-proof
Substituting $x=d_j$ in the product gives one factor for each index $i$, and the factor with $i=j$ is displayed explicitly.
:::

:::

::: pf-step
The $j$-th factor in the product is $(d_j - d_j) = 0$.

::: pf-proof
This is the difference of the entry $d_j$ with itself.
:::

:::

::: pf-step
Therefore:
$$f(d_j) = 0 \quad \text{for every } j \in \{1, 2, \dots, n\}.$$

::: pf-proof
A finite product in a field with a zero factor is zero, and the preceding subclaim exhibits such a factor for the given $j$; $j$ was arbitrary.
:::

:::

:::

:::

::: pf-step
Computation of $f(A)$:

::: pf-proof
Substituting the vanishing values into the diagonal formula produces the zero matrix.

::: pf-step
By Step [](#s1){.pf-ref}:
$$f(A) = \operatorname{diag}(f(d_1), f(d_2), \dots, f(d_n)) = \operatorname{diag}(0, 0, \dots, 0) = 0_{n \times n}.$$

::: pf-proof
The first equality is step [](#s1){.pf-ref}, the second substitutes the values $f(d_j)=0$ just computed, and a diagonal matrix all of whose entries are zero is the zero matrix.
:::

:::

::: pf-step
Thus $f(A)$ is the $n \times n$ **zero matrix**.

::: pf-proof
The preceding subclaim computes every entry of the matrix $f(A)$ and finds it to be $0$.
:::

:::

:::

:::

::: pf-step
Remark on Cayley–Hamilton Theorem:

::: pf-proof
The two observations identify $f$ as the characteristic polynomial of $A$ and record the general theorem of which this is the diagonal instance.

::: pf-step
Notice that $f(x) = \det(x I - A)$ is precisely the **characteristic polynomial** of the diagonal matrix $A$.

::: pf-proof
For a diagonal $A$ the matrix $xI-A$ is $\operatorname{diag}(x-d_1,\dots,x-d_n)$, and the determinant of a diagonal matrix is the product of its diagonal entries, which is the product defining $f$.
:::

:::

::: pf-step
The result $f(A) = 0$ is the diagonal case of the **Cayley–Hamilton Theorem**.

::: pf-proof
Cayley–Hamilton states that $\chi_A(A)=0$ for every square matrix $A$; by the preceding subclaim $\chi_A=f$ here, so the computation above is that theorem's instance for diagonal matrices.
:::

:::

:::

:::

::: pf-step
Conclusion:
The matrix $f(A)$ is the zero matrix $\boxed{0_{n \times n}}$.

::: pf-proof
The third container computes $f(A)$ entry by entry as $0$, which is what the exercise asks for.
:::

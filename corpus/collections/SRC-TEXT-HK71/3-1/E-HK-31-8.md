::: {.exercise}
Describe explicitly a linear transformation from $\RR^3$ into $\RR^3$ which has as its range the subspace spanned by $(1, 0, -1)$ and $(1, 2, 2)$.
:::


::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §3.1 Exercise 8.

::: pf

::: {.pf-step #vectors}
Let $v_1=(1,0,-1)$ and $v_2=(1,2,2)$, and define $T:\RR^3\to\RR^3$ by $T(x,y,z)=xv_1+yv_2$, that is
$$
T(x,y,z)=(x+y,\,2y,\,-x+2y).
$$

::: pf-proof
This is a definition. Written out, $x(1,0,-1)+y(1,2,2)=(x+y,\,0+2y,\,-x+2y)$, with no contribution from $z$.
:::

:::

::: {.pf-step #linear}
$T$ is linear.

::: pf-proof
$T$ is given by a $3\times3$ matrix acting on column vectors, namely the matrix with columns $v_1$, $v_2$, $0$:
$$
\begin{bmatrix}1&1&0\\0&2&0\\-1&2&0\end{bmatrix},
$$
and matrix multiplication is linear in the vector.
:::

:::

::: {.pf-step #contained}
$\operatorname{range}T\subseteq\operatorname{span}\{v_1,v_2\}$.

::: pf-proof
Every value $T(x,y,z)=xv_1+yv_2$ is by construction a linear combination of $v_1$ and $v_2$.
:::

:::

::: {.pf-step #contains}
$v_1,v_2\in\operatorname{range}T$.

::: pf-proof
$T(1,0,0)=v_1$ and $T(0,1,0)=v_2$, so both spanning vectors are values of $T$.
:::

:::

::: {.pf-step}
$\operatorname{range}T=\operatorname{span}\{(1,0,-1),(1,2,2)\}$.

::: pf-proof
The range is a subspace containing $v_1$ and $v_2$ by step [](#contains){.pf-ref}, so it contains their span; and it is contained in that span by step [](#contained){#contained}. Hence the two coincide:
$$
\boxed{\operatorname{range}T=\operatorname{span}\{(1,0,-1),(1,2,2)\}.}
$$
:::

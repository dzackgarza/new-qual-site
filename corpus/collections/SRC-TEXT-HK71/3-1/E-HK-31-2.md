::: {.exercise}
Find the range, rank, null space, and nullity for the zero transformation and the identity transformation on a finite-dimensional space $V$.
:::


::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, and the four quantities are computed from the definitions for a finite-dimensional space $V$ with $\dim V=n$. The range of $T$ is $\{T\alpha\mid \alpha\in V\}$, its rank is the dimension of that subspace, and the null space of $T$ is $\{\alpha\mid T\alpha=0\}$, whose dimension is the nullity.

::: pf

::: {.pf-step #zero}
For the zero transformation $Z(\alpha)=0$ the range is $\{0\}$ with rank $0$, and the null space is $V$ with nullity $n$.

::: pf-proof
Range and null space, separately.

::: {.pf-step #zero-range}
$\operatorname{range}Z=\{0\}$ and $\operatorname{rank}Z=0$.

::: pf-proof
$Z\alpha=0$ for every $\alpha\in V$, so the set of values of $Z$ is $\{0\}$. The subspace $\{0\}$ has dimension $0$ by the definition of dimension, since it has the empty set as a basis.
:::

:::

::: {.pf-step #zero-null}
$N_Z=V$ and the nullity of $Z$ is $n$.

::: pf-proof
Every $\alpha\in V$ satisfies $Z\alpha=0$, so every vector of $V$ lies in the null space; hence $N_Z=V$, whose dimension is $n=\dim V$. So the nullity is $n$, and indeed $\operatorname{rank}Z+\text{nullity } Z=0+n=n$.
:::

:::

:::

:::

::: {.pf-step #identity}
For the identity transformation $I(\alpha)=\alpha$ the range is $V$ with rank $n$, and the null space is $\{0\}$ with nullity $0$.

::: pf-proof
Range and null space, separately.

::: {.pf-step #identity-range}
$\operatorname{range}I=V$ and $\operatorname{rank}I=n$.

::: pf-proof
$I\alpha=\alpha$, so the set of values of $I$ is all of $V$; its dimension is $\dim V=n$.
:::

:::

::: {.pf-step #identity-null}
$N_I=\{0\}$ and the nullity of $I$ is $0$.

::: pf-proof
$I\alpha=0$ forces $\alpha=0$, so the null space is $\{0\}$, of dimension $0$. Hence the four answers are: for the zero transformation, range $\{0\}$, rank $0$, null space $V$, nullity $n$; for the identity transformation, range $V$, rank $n$, null space $\{0\}$, nullity $0$. In both cases $\operatorname{rank}+\text{nullity}=n$, as the rank-nullity theorem requires.
:::

::: {.exercise}
If
$$
\alpha_1 = (1, -1), \quad \beta_1 = (1, 0),
$$
$$
\alpha_2 = (2, -1), \quad \beta_2 = (0, 1),
$$
$$
\alpha_3 = (-3, 2), \quad \beta_3 = (1, 1),
$$
is there a linear transformation $T$ from $\RR^2$ into $\RR^2$ such that $T\alpha_i = \beta_i$ for $i = 1, 2$ and 3?

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained in the checkout as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §3.1 Exercise 5 on printed p. 73. The argument is the card's own.

Throughout, $T:\RR^2\to\RR^2$ is linear, so $T(c_1\alpha_1+c_2\alpha_2)=c_1T\alpha_1+c_2T\alpha_2$ for all scalars and vectors.

::: pf

::: {.pf-step #relation}
$\alpha_3=-\alpha_1-\alpha_2$ and $\beta_3\neq-\beta_1-\beta_2$.

::: pf-proof
$-\alpha_1-\alpha_2=-(1,-1)-(2,-1)=(-1,1)+(-2,1)=(-3,2)=\alpha_3$, whereas $-\beta_1-\beta_2=-(1,0)-(0,1)=(-1,-1)$, which differs from $\beta_3=(1,1)$ in its first coordinate.

:::

:::

::: {.pf-step #forced}
Any linear $T$ with $T\alpha_1=\beta_1$ and $T\alpha_2=\beta_2$ has $T\alpha_3=(-1,-1)$.

::: pf-proof
By linearity and step [](#relation){.pf-ref},
$$
T\alpha_3=T(-\alpha_1-\alpha_2)=-T\alpha_1-T\alpha_2=-\beta_1-\beta_2=(-1,-1).
$$

:::

:::

::: {.pf-step #no-such-map}
No linear $T$ satisfies all three prescriptions.

::: pf-proof
Such a $T$ would have $T\alpha_3=(-1,-1)$ by step [](#forced){.pf-ref}, while the prescription for $i=3$ demands $T\alpha_3=\beta_3=(1,1)$. A function has one value at $\alpha_3$, and $(-1,-1)\neq(1,1)$, so no such $T$ exists.

:::

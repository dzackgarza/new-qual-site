::: {.exercise}
Which of the following functions $T$ from $\RR^2$ into $\RR^2$ are linear transformations?

(a) $T(x_1, x_2) = (1 + x_1, x_2)$;

(b) $T(x_1, x_2) = (x_2, x_1)$;

(c) $T(x_1, x_2) = (x_1^2, x_2)$;

(d) $T(x_1, x_2) = (\sin x_1, x_2)$;

(e) $T(x_1, x_2) = (x_1 - x_2, 0)$.
:::


::: solution
Exactly (b) and (e) are linear.

(a) is not linear because $T(0,0)=(1,0)\ne0$.

(b) is linear since
\[
T(x_1,x_2)=(x_2,x_1)
=\begin{bmatrix}0&1\\1&0\end{bmatrix}
\begin{bmatrix}x_1\\x_2\end{bmatrix}.
\]

(c) is not linear because, for example,
\[
T(2,0)=(4,0)\ne2(1,0)=2T(1,0).
\]

(d) is not linear since
\[
T(2x_1,0)=(\sin 2x_1,0)
\]
is not generally equal to $2(\sin x_1,0)$.

(e) is linear because
\[
T(x_1,x_2)=(x_1-x_2,0)
=\begin{bmatrix}1&-1\\0&0\end{bmatrix}
\begin{bmatrix}x_1\\x_2\end{bmatrix}.
\]
:::

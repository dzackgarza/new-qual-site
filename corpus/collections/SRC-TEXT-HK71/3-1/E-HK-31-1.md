::: {.exercise}
Which of the following functions $T$ from $\RR^2$ into $\RR^2$ are linear transformations?

(a) $T(x_1, x_2) = (1 + x_1, x_2)$;

(b) $T(x_1, x_2) = (x_2, x_1)$;

(c) $T(x_1, x_2) = (x_1^2, x_2)$;

(d) $T(x_1, x_2) = (\sin x_1, x_2)$;

(e) $T(x_1, x_2) = (x_1 - x_2, 0)$.
:::


::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §3.1 Exercise 1, p. 73.

::: pf

::: {.pf-step #linear}
The maps of (b) and (e) are linear transformations.

::: pf-proof
For (b), $T(x_1,x_2)=(x_2,x_1)$: $T((x_1,x_2)+(y_1,y_2))=T(x_1+y_1,x_2+y_2)=(x_2+y_2,x_1+y_1)=T(x_1,x_2)+T(y_1,y_2)$, and $T(c(x_1,x_2))=T(cx_1,cx_2)=(cx_2,cx_1)=cT(x_1,x_2)$. For (e), $T(x_1,x_2)=(x_1-x_2,0)$: the first coordinate is the linear form $x_1-x_2$ and the second is $0$, so additivity and homogeneity hold coordinatewise.
:::
:::

::: {.pf-step #notlinear}
The maps of (a), (c) and (d) are not linear.

::: pf-proof
(a) $T(0,0)=(1,0)\neq(0,0)$, whereas a linear map carries the zero vector to the zero vector. (c) $T(2,0)=(4,0)$ while $2T(1,0)=(2,0)$, so homogeneity fails. (d) $T(\tfrac{\pi}{2},0)+T(\tfrac{\pi}{2},0)=(1,0)+(1,0)=(2,0)$ while $T(\pi,0)=(\sin\pi,0)=(0,0)$, so additivity fails.
:::
:::

::: {.pf-step}
Exactly (b) and (e) are linear transformations.

::: pf-proof
The five items are (a), (b), (c), (d), (e); step [](#linear){.pf-ref} confirms two of them and step [](#notlinear){.pf-ref} refutes the other three.
:::

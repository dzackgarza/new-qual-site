::: {.exercise}
Let $T$ be a linear operator on a finite-dimensional vector space over the field of complex numbers.
Prove that $T$ is diagonalizable if and only if $T$ is annihilated by some polynomial over $\CC$ which has distinct roots.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no published solution set for it is retained in `tmp/sources`, so nothing below is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §6.4 Exercise 7. Here $T$ is an operator on a finite-dimensional complex vector space. The criterion used is that of this section: $T$ is diagonalizable exactly when its minimal polynomial is a product of distinct linear factors over $\CC$. A polynomial is taken to be nonzero, as is customary in this criterion; the convention is named again in the last step.

::: pf

::: {.pf-step #ford}

If $T$ is diagonalizable then some nonzero polynomial with distinct roots annihilates $T$.

::: pf-proof

Let $c_{1},\dots,c_{r}$ be the distinct characteristic values and $f=\prod_{j=1}^{r}(x-c_{j})$, which is nonzero with distinct roots. In an eigenbasis the matrix of $T$ is diagonal with diagonal entries among the $c_{j}$, so $f(T)$ is diagonal with diagonal entries $f(c_{j})=0$, that is, $f(T)=0$.

:::

:::

::: {.pf-step #divides}

If a nonzero $f$ with distinct roots annihilates $T$, then $m_{T}$ divides $f$.

::: pf-proof

The minimal polynomial divides every polynomial that annihilates $T$.

:::

:::

::: {.pf-step #minpoly}

If a nonzero $f$ with distinct roots annihilates $T$, then $m_{T}$ has distinct roots and splits over $\CC$.

::: pf-proof

$m_{T}$ divides the nonzero $f$ by step [](#divides){.pf-ref}, so every root of $m_{T}$ is a root of $f$ and a repeated root of $m_{T}$ would be a repeated root of $f$; hence $m_{T}$ has distinct roots. Over $\CC$ every polynomial splits into linear factors, so $m_{T}$ is a product of distinct linear factors.

:::

:::

::: {.pf-step #back}

If a nonzero $f$ with distinct roots annihilates $T$, then $T$ is diagonalizable.

::: pf-proof

By step [](#minpoly){.pf-ref} the minimal polynomial of $T$ is a product of distinct linear factors over $\CC$, which is the criterion of this section.

:::

:::

::: {.pf-step #done}

$T$ is diagonalizable if and only if some polynomial over $\CC$ with distinct roots annihilates it.

::: pf-proof

Steps [](#ford){.pf-ref} and [](#back){.pf-ref}. The qualifier "nonzero" in the statement is not a weakening: the zero polynomial is annihilated by every operator and its roots are conventionally all of $\CC$, so admitting it would make the condition vacuous and false for a non-diagonalizable operator such as a single Jordan block of size greater than one, whose characteristic polynomial has a repeated root.

:::

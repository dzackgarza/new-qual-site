::: {.exercise}
Let $T$ be a linear operator on $V$.
If every subspace of $V$ is invariant under $T$, then $T$ is a scalar multiple of the identity operator.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Every non-zero vector is an eigenvector of $T$:

::: pf-proof

Step 1.1 uses the invariance of the line through $v$, and step 1.2 reads the eigenvalue off it.

::: pf-step

Let $v \in V \setminus \{0\}$. The 1-dimensional subspace $W = \operatorname{span}(v) = F v$ is a subspace of $V$.
By hypothesis, $W$ is invariant under $T$, so $T(W) \subseteq W$.

::: pf-proof

The span of a single vector is a subspace, and it is one-dimensional because $v\ne0$; it consists of the scalar multiples $Fv$. The hypothesis is that every subspace is invariant, that is $T(W)\subseteq W$.

:::

:::

::: pf-step

Therefore $T(v) \in F v$, which implies there exists a scalar $c_v \in F$ such that:
$$
T(v) = c_v v.
$$

::: pf-proof

$v\in W$ and $T(W)\subseteq W$ by step 1.1, so $T(v)\in W=Fv$: there is a scalar $c_v$ with $T(v)=c_vv$. It is unique, since $c_vv=c'_vv$ with $v\ne0$ forces $c_v=c'_v$.

:::

:::

:::

:::

::: pf-step

Proof that the scalar $c_v$ is independent of $v$:

::: pf-proof

Step 2.1 disposes of $\dim V\le1$ and fixes two nonzero vectors; steps 2.2 and 2.3 compare their scalars in the dependent and independent cases.

::: pf-step

If $\dim(V) \le 1$, then every linear operator on $V$ is a scalar multiple of the identity: when $\dim(V) = 0$ the only operator is the zero map, and when $\dim(V) = 1$ any operator sends a basis vector $e$ to $c e$ for some $c \in F$, hence acts as $c \operatorname{id}_V$. Assume $\dim(V) \ge 2$.
Let $u, v \in V \setminus \{0\}$.

::: pf-proof

If $\dim V=0$ then $V=\{0\}$ and the only linear map is $0=0\cdot\operatorname{id}$. If $\dim V=1$, a basis is a single nonzero vector $e$; writing $T(e)=ce$, linearity gives $T(\lambda e)=\lambda T(e)=c(\lambda e)$ for every scalar, so $T=c\operatorname{id}$. In both cases the theorem holds, so assume $\dim V\ge2$; then $u$ and $v$ are arbitrary nonzero vectors.

:::

:::

::: pf-step

**Subcase 1: $\{u, v\}$ is linearly dependent.**
There exists a non-zero scalar $\alpha \in F^\times$ such that $v = \alpha u$.
Then by linearity:
$$
c_v v = T(v) = T(\alpha u) = \alpha T(u) = \alpha (c_u u) = c_u (\alpha u) = c_u v.
$$
Since $v \neq 0$, $c_v = c_u$.

::: pf-proof

Two nonzero vectors are linearly dependent exactly when one is a nonzero multiple of the other, so $v=\alpha u$ with $\alpha\ne0$. The chain of equalities uses that $T$ is linear, that $T(u)=c_uu$ and $T(v)=c_vv$ (step 1.2), and commutativity of scalar multiplication. From $c_vv=c_uv$ we get $(c_v-c_u)v=0$, and $v\ne0$, so $c_v=c_u$.

:::

:::

::: pf-step

**Subcase 2: $\{u, v\}$ is linearly independent.**
Consider the sum vector $w = u + v \neq 0$.
By step [](#s1){.pf-ref}, there exists $c_w \in F$ such that $T(w) = c_w w = c_w u + c_w v$.
By linearity of $T$:
$$
T(w) = T(u + v) = T(u) + T(v) = c_u u + c_v v.
$$
Equating both expressions gives:
$$
(c_u - c_w) u + (c_v - c_w) v = 0.
$$
Because $\{u, v\}$ is linearly independent, $c_u - c_w = 0$ and $c_v - c_w = 0$, which yields $c_u = c_v = c_w$.

::: pf-proof

$u+v\ne0$: if $u+v=0$ then $u=-v$, a nontrivial dependence of the pair. Applying step 1.2 to the nonzero vector $w$ gives $T(w)=c_ww$, and linearity gives $T(w)=T(u)+T(v)=c_uu+c_vv$; subtracting the two expressions for $T(w)$ gives the displayed relation. Linear independence means that a linear combination vanishing has all coefficients zero, so $c_u=c_w$ and $c_v=c_w$.

:::

:::

:::

:::

::: pf-step

Conclusion:
Fix a non-zero vector $v_0 \in V$ and set $c = c_{v_0} \in F$.
Then $T(v) = c v$ for all $v \in V \setminus \{0\}$, and for $v = 0$, $T(0) = 0 = c \cdot 0$.
Thus $T = c \operatorname{id}_V$.

::: pf-proof

If $V=0$ the claim is the first sentence of step 2.1, so suppose $V\ne0$ and fix $v_0\ne0$. For any $v\ne0$, the pair $(v_0,v)$ is either dependent or independent, and then $c_v=c_{v_0}=c$ by step 2.2 or step 2.3 respectively. Linearity gives $T(0)=0=c\cdot0$, so $T(v)=cv$ for every $v\in V$, that is $T=c\operatorname{id}_V$.

:::

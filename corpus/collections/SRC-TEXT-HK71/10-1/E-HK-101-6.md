::: {.exercise}
Let $n$ be a positive integer, and let $V$ be the space of all $n \times n$ matrices over the field of complex numbers.
Show that the equation
\[
f(A, B) = n\operatorname{tr}(AB) - \operatorname{tr}(A)\operatorname{tr}(B)
\]
defines a bilinear form $f$ on $V$.
Is it true that $f(A, B) = f(B, A)$ for all $A, B$?
:::

::: {.solution}
**Goal.** Show $f(A,B) = n\operatorname{tr}(AB) - \operatorname{tr}(A)\operatorname{tr}(B)$ is bilinear, and check symmetry.

::: pf

::: {.pf-step #s1}
$f$ is bilinear.

::: pf-proof

::: pf-step
$\operatorname{tr}(AB)$ is bilinear in $(A, B)$.

::: pf-proof
$\operatorname{tr}((A_1 + A_2)B) = \operatorname{tr}(A_1 B) + \operatorname{tr}(A_2 B)$ and $\operatorname{tr}(A(B_1 + B_2)) = \operatorname{tr}(AB_1) + \operatorname{tr}(AB_2)$, and $\operatorname{tr}(cAB) = c\operatorname{tr}(AB)$.
:::

:::

::: pf-step
$\operatorname{tr}(A)\operatorname{tr}(B)$ is bilinear.

::: pf-proof
$\operatorname{tr}$ is linear, and the product of two linear functionals is bilinear.
:::

:::

::: pf-step
Hence $f = n\operatorname{tr}(AB) - \operatorname{tr}(A)\operatorname{tr}(B)$ is bilinear.

::: pf-proof
a linear combination of bilinear forms is bilinear.
:::

:::

:::

:::

::: {.pf-step #s2}
$f$ is symmetric.

::: pf-proof

::: {.pf-step #s2-1}
$\operatorname{tr}(AB) = \operatorname{tr}(BA)$.

::: pf-proof
the trace is cyclic: $\operatorname{tr}(AB) = \sum_i (AB)_{ii} = \sum_{i,j} A_{ij} B_{ji} = \sum_{j,i} B_{ji} A_{ij} = \operatorname{tr}(BA)$.
:::

:::

::: {.pf-step #s2-2}
$\operatorname{tr}(A)\operatorname{tr}(B) = \operatorname{tr}(B)\operatorname{tr}(A)$.

::: pf-proof
multiplication of scalars is commutative.
:::

:::

::: pf-step
Hence $f(A, B) = n\operatorname{tr}(AB) - \operatorname{tr}(A)\operatorname{tr}(B) = n\operatorname{tr}(BA) - \operatorname{tr}(B)\operatorname{tr}(A) = f(B, A)$.

::: pf-proof
steps [](#s2-1){.pf-ref} and [](#s2-2){.pf-ref}.
:::

:::

:::

:::

::: pf-qed
Step [](#s1){.pf-ref} shows bilinearity; step [](#s2){.pf-ref} shows $f(A,B) = f(B,A)$ (yes, it is symmetric).
:::

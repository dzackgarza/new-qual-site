::: {.exercise}
Show that the result given in Exercise 12 need not be true if $g$ is singular.

::: solution
**Goal:** Give bilinear forms $f,g$ with singular $g$ where the factorization fails.

<1> Set up a singular $g$.
    *Proof:*
    <2>1. On $V=\RR^2$, let
        $$
        g((x_1,x_2),(y_1,y_2))=x_1y_1.
        $$
    <2>2. Then $\ker g=\{(0,t):t\in\RR\}\neq\{0\}$, so $g$ is singular.

<1> Define $f$ that cannot factor through $g$.
    *Proof:*
    <2>1. Let $f((x_1,x_2),(y_1,y_2))=x_2y_2$.
    <2>2. Assume $f(\alpha,\beta)=g(T_1\alpha,\beta)$ for some linear $T_1$.
    <2>3. Then the value depends only on $\beta_1$ (the first coordinate of $\beta$), because $g(\cdot,\beta)$ does.
    <2>4. But $f((0,1),(0,1))=1$ while $f$ should be $0$ if it depended only on $\beta_1$, contradiction.

<1> Conclusion.
    *Proof:* This contradiction shows no such $T_1$ exists; in particular the claim of Exercise 12 can fail for singular $g$.

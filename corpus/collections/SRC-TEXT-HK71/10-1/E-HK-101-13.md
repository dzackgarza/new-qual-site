::: {.exercise}
Show that the result given in Exercise 12 need not be true if $g$ is singular.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
On $V = \RR^2$ there are a singular bilinear form $g$ and a bilinear form $f$, namely $g(\alpha,\beta) = x_1y_1$ and $f(\alpha,\beta) = x_2y_2$.

::: pf-proof

::: pf-step
Let $V = \RR^2$ with standard basis $\{e_1, e_2\}$.

::: pf-proof
$\RR^2$ is a finite-dimensional real vector space, and $e_1 = (1,0)$ and $e_2 = (0,1)$ form a basis, so a vector is determined by its coordinate pair and a linear map is determined by its values on the two basis vectors.
:::

:::

::: pf-step
Define the singular bilinear form $g: \RR^2 \times \RR^2 \to \RR$ with matrix $[g] = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$:
$$g(\alpha, \beta) = x_1 y_1 \quad \text{for } \alpha = (x_1, x_2), \, \beta = (y_1, y_2).$$

::: pf-proof
The formula $g(\alpha,\beta) = x_1y_1$ is linear in $\alpha$ for fixed $\beta$ and linear in $\beta$ for fixed $\alpha$, hence bilinear. Its matrix in the standard basis has entries $g(e_i,e_j)$, which is $1$ at $(i,j) = (1,1)$ and $0$ at the other three places, hence the displayed matrix.
:::

:::

::: pf-step
Since $\det[g] = 0$ (and $g(e_2, \beta) = 0$ for all $\beta$), $g$ is singular (degenerate).

::: pf-proof
The matrix of $g$ has determinant $0 \cdot 0 - 0 \cdot 0 = 0$, so it is not invertible. Equivalently $g(e_2, \beta) = 0$ for every $\beta$, so the nonzero vector $e_2$ is orthogonal to the whole space; a nonsingular form has no such vector, because it would give a $\beta$ with $g(e_2,\beta) \neq 0$.
:::

:::

::: pf-step
Define the bilinear form $f: \RR^2 \times \RR^2 \to \RR$ with matrix $[f] = \begin{bmatrix} 0 & 0 \\ 0 & 1 \end{bmatrix}$:
$$f(\alpha, \beta) = x_2 y_2 \quad \text{for } \alpha = (x_1, x_2), \, \beta = (y_1, y_2).$$

::: pf-proof
Again the formula $f(\alpha,\beta) = x_2y_2$ is linear in each variable separately, hence bilinear, and its matrix has entries $f(e_i,e_j)$, which is $1$ only at $(i,j) = (2,2)$ and $0$ elsewhere.
:::

:::

:::

:::

::: {.pf-step #s2}
There is no linear operator $T_1$ with $f(\alpha, \beta) = g(T_1\alpha, \beta)$ for all $\alpha, \beta$.

::: pf-proof

::: pf-step
Suppose for contradiction that there exists a linear operator $T_1: \RR^2 \to \RR^2$ such that $f(\alpha, \beta) = g(T_1\alpha, \beta)$ for all $\alpha, \beta \in \RR^2$.

::: pf-proof
This is the first of the two factorizations whose existence is asserted for a nonsingular $g$; the step records the supposition, and a contradiction is derived from it below, which is what refutes this alternative.
:::

:::

::: pf-step
For any vector $\alpha \in \RR^2$, let $T_1\alpha = (u_1, u_2) \in \RR^2$.

::: pf-proof
Every vector of $\RR^2$ has a unique coordinate pair in the standard basis, so $T_1\alpha = (u_1, u_2)$ names the coordinates of the image, and they depend on $\alpha$ because $T_1$ is linear.
:::

:::

::: pf-step
Then for $\beta = e_2 = (0, 1)$, the value of $g(T_1\alpha, e_2)$ is
$$g(T_1\alpha, e_2) = u_1 \cdot 0 = 0.$$

::: pf-proof
By the formula of step [](#s1){.pf-ref}, $g(\gamma,\beta) = \gamma_1\beta_1$; with $\gamma = T_1\alpha = (u_1,u_2)$ and $\beta = e_2 = (0,1)$ this is $u_1 \cdot 0 = 0$, whatever $u_1$ is.
:::

:::

::: pf-step
Evaluating $f$ on $\alpha = e_2 = (0, 1)$ and $\beta = e_2 = (0, 1)$:
$$f(e_2, e_2) = 0 \cdot 0 + 1 \cdot 1 = 1.$$

::: pf-proof
By the formula of step [](#s1){.pf-ref}, $f(\alpha,\beta) = \alpha_2\beta_2$; with $\alpha = \beta = e_2 = (0,1)$ that is $1 \cdot 1 = 1$.
:::

:::

::: pf-step
Thus $1 = f(e_2, e_2) = g(T_1 e_2, e_2) = 0$, which is a contradiction.

::: pf-proof
The assumed identity with $\alpha = \beta = e_2$ reads $f(e_2,e_2) = g(T_1e_2,e_2)$; the left side is $1$ and the right side is $0$, so the identity forces $1 = 0$ in $\RR$, which is false.
:::

:::

::: pf-step
Therefore no such linear operator $T_1$ exists.

::: pf-proof
A supposition from which a false statement follows is false, so no linear operator $T_1$ satisfies the first factorization for these $f$ and $g$.
:::

:::

:::

:::

::: {.pf-step #s3}
There is no linear operator $T_2$ with $f(\alpha, \beta) = g(\alpha, T_2\beta)$ for all $\alpha, \beta$.

::: pf-proof

::: pf-step
Similarly, suppose for contradiction that there exists a linear operator $T_2$ such that $f(\alpha, \beta) = g(\alpha, T_2\beta)$ for all $\alpha, \beta$.

::: pf-proof
This is the second of the two factorizations, and the same contradiction is derived from it with the two arguments exchanged, as the steps below record.
:::

:::

::: pf-step
For any $\beta$, let $T_2\beta = (v_1, v_2)$.

::: pf-proof
Coordinates in the standard basis are unique, so $T_2\beta = (v_1, v_2)$ names the coordinates of the image of $\beta$.
:::

:::

::: pf-step
For $\alpha = e_2 = (0, 1)$, $g(e_2, T_2\beta) = 0 \cdot v_1 = 0$.

::: pf-proof
By the formula of step [](#s1){.pf-ref}, $g(\alpha,\gamma) = \alpha_1\gamma_1$; with $\alpha = e_2 = (0,1)$ the first factor is $0$, so the product vanishes whatever $T_2\beta$ is.
:::

:::

::: pf-step
But $f(e_2, e_2) = 1 \neq 0$, giving $1 = 0$, a contradiction.

::: pf-proof
The assumed identity at $\alpha = \beta = e_2$ reads $f(e_2,e_2) = g(e_2, T_2e_2)$, whose two sides are $1$ by the formula for $f$ and $0$ by the formula for $g$.
:::

:::

::: pf-step
Thus no such linear operator $T_2$ exists.

::: pf-proof
A false conclusion follows from the supposition, so no linear operator $T_2$ satisfies the second factorization either.
:::

:::

:::

:::

::: pf-step
The result of Exercise 12 therefore fails for a singular $g$: with $g$ and $f$ as in step [](#s1){.pf-ref} there is neither a $T_1$ nor a $T_2$.

::: pf-proof
Step [](#s1){.pf-ref} gives a singular $g$ on a finite-dimensional space and a bilinear $f$; step [](#s2){.pf-ref} shows that no linear $T_1$ satisfies $f(\alpha,\beta) = g(T_1\alpha,\beta)$, and step [](#s3){.pf-ref} shows the same for $T_2$ on the other side. [[E-HK-101-12|Exercise 12]] asserts that such operators exist and are unique when $g$ is nonsingular, so its conclusion fails here.
:::

::: {.exercise}
Which of the following functions $f$, defined on vectors $\alpha = (x_1, x_2)$ and $\beta = (y_1, y_2)$ in $\RR^2$, are bilinear forms?

(a) $f(\alpha, \beta) = 1$.

(b) $f(\alpha, \beta) = (x_1 - y_1)^2 + x_2y_2$.

(c) $f(\alpha, \beta) = (x_1 + y_1)^2 - (x_1 - y_1)^2$.

(d) $f(\alpha, \beta) = x_1y_2 - x_2y_1$.
:::

::: {.solution}
**Goal:** Test each function for bilinearity in both slots.

::: pf

::: pf-step

(a) $f(\alpha,\beta)=1$ is not bilinear.

::: pf-proof

::: pf-step

Bilinearity in the first slot requires $f(0,\beta)=0$ for all $\beta$.

:::

::: pf-step

Here $f(0,\beta)=1\neq0$, so (a) fails.

:::

:::

:::

::: pf-step

(b) $f(\alpha,\beta)=(x_1-y_1)^2+x_2y_2$ is not bilinear.

::: pf-proof

::: pf-step

Expand:
    $$ (x_1-y_1)^2+x_2y_2=x_1^2-2x_1y_1+y_1^2+x_2y_2.$$

:::

::: pf-step

The terms $x_1^2$ and $y_1^2$ are quadratic in one variable and violate linearity.

:::

::: pf-step

Therefore (b) fails bilinearity.

:::

:::

:::

::: pf-step

(c) $f(\alpha,\beta)=(x_1+y_1)^2-(x_1-y_1)^2$.

::: pf-proof

::: pf-step

Expand:
    $$ (x_1+y_1)^2-(x_1-y_1)^2=4x_1y_1.$$

:::

::: pf-step

This has the form $4\,x_1y_1$, linear in each variable.

:::

::: pf-step

Hence (c) is bilinear, represented by matrix $\begin{pmatrix}4&0\\0&0\end{pmatrix}$.

:::

:::

:::

::: pf-step

(d) $f(\alpha,\beta)=x_1y_2-x_2y_1$.

::: pf-proof

::: pf-step

This is the determinant form $\det(\alpha,\beta)$.

:::

::: pf-step

It is linear in each entry separately:
    $$f(\alpha+\alpha',\beta)=f(\alpha,\beta)+f(\alpha',\beta),\qquad
    f(\lambda\alpha,\beta)=\lambda f(\alpha,\beta).$$

:::

::: pf-step

Symmetric checks for $\beta$ are analogous.

:::

::: pf-step

Therefore (d) is bilinear, represented by matrix $\begin{pmatrix}0&1\\-1&0\end{pmatrix}$.

:::

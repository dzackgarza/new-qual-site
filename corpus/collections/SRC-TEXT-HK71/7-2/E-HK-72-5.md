::: {.exercise}
Let $T$ be a linear operator on the vector space $V$ over the field $F$.
If $f$ is a polynomial over $F$ and $\alpha$ is in $V$, let $f\alpha = f(T)\alpha$.
If $V_1, \ldots, V_k$ are $T$-invariant subspaces and $V = V_1 \oplus \cdots \oplus V_k$, show that
\[
fV = fV_1 \oplus \cdots \oplus fV_k.
\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

$fV = fV_1 + \cdots + fV_k$.

::: pf-proof

::: pf-step

Every $\alpha \in V$ is $\alpha = \alpha_1 + \cdots + \alpha_k$ with $\alpha_i \in V_i$.

::: pf-proof

$V = V_1 \oplus \cdots \oplus V_k$.

:::

:::

::: {.pf-step #s1-2}

$f\alpha = f(T)\alpha = f(T)\alpha_1 + \cdots + f(T)\alpha_k \in fV_1 + \cdots + fV_k$.

::: pf-proof

linearity of $f(T)$.

:::

:::

::: pf-step

Hence $fV \subseteq fV_1 + \cdots + fV_k$, and the reverse inclusion is clear (each $fV_i \subseteq fV$).

::: pf-proof

Step [](#s1-2){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s2}

The sum $fV_1 + \cdots + fV_k$ is direct.

::: pf-proof

::: pf-step

Suppose $f\alpha_1 + \cdots + f\alpha_k = 0$ with $\alpha_i \in V_i$.

::: pf-proof

take a relation.

:::

:::

::: pf-step

Then $f(\alpha_1 + \cdots + \alpha_k) = 0$, so $\alpha_1 + \cdots + \alpha_k \in \ker f(T)$.

::: pf-proof

linearity.

:::

:::

::: pf-step

Since each $V_i$ is $T$-invariant, it is $f(T)$-invariant, so $f\alpha_i \in V_i$ for each $i$.

::: pf-proof

$f(T)$ commutes with the projection onto $V_i$ (since $V_i$ is $T$-invariant).

:::

:::

::: pf-step

Hence $f\alpha_i = 0$ for each $i$ (the sum is direct in $V$).

::: pf-proof

$f\alpha_1 + \cdots + f\alpha_k = 0$ with $f\alpha_i \in V_i$, and $V = V_1 \oplus \cdots \oplus V_k$, so each summand is $0$.

:::

:::

:::

:::

::: {.pf-step #s3}

Hence $fV = fV_1 \oplus \cdots \oplus fV_k$.

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s3){.pf-ref}.

:::

:::

::: {.exercise}
Let $T$ be a linear operator on the vector space $V$ over the field $F$.
If $f$ is a polynomial over $F$ and $\alpha$ is in $V$, let $f\alpha = f(T)\alpha$.
If $V_1, \ldots, V_k$ are $T$-invariant subspaces and $V = V_1 \oplus \cdots \oplus V_k$, show that
$$
fV = fV_1 \oplus \cdots \oplus fV_k.
$$
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §7.2 Exercise 5 on printed p. 241. The argument is the card's own.

::: pf

::: {.pf-step #s1}
$fV=fV_1+\cdots+fV_k$.

::: pf-proof
Every $\alpha\in V$ is $\alpha=\alpha_1+\cdots+\alpha_k$ with $\alpha_i\in V_i$, and $f(T)$ is linear, so $f(T)\alpha=f(T)\alpha_1+\cdots+f(T)\alpha_k\in fV_1+\cdots+fV_k$; hence $fV\subseteq fV_1+\cdots+fV_k$. The reverse inclusion holds because $V_i\subseteq V$ gives $fV_i\subseteq fV$.
:::

:::

::: {.pf-step #s2}
The sum is direct, so $fV=fV_1\oplus\cdots\oplus fV_k$.

::: pf-proof
Each $V_i$ is $T$-invariant, hence $f(T)$-invariant, so $f(T)\alpha_i\in V_i$ for $\alpha_i\in V_i$. If $f(T)\alpha_1+\cdots+f(T)\alpha_k=0$, then each summand is the $V_i$-component of $0$ in the direct sum $V=V_1\oplus\cdots\oplus V_k$, so $f(T)\alpha_i=0$ for every $i$. Thus the sum has no nontrivial relation, and with step [](#s1){.pf-ref} it equals $fV$.
:::

::: {.exercise}
Let
\[
\alpha_1 = (1, 1, -2, 1), \quad \alpha_2 = (3, 0, 4, -1), \quad \alpha_3 = (-1, 2, 5, 2).
\]
Let
\[
\alpha = (4, -5, 9, -7), \quad \beta = (3, 1, -4, 4), \quad \gamma = (-1, 1, 0, 1).
\]

(a) Which of the vectors $\alpha$, $\beta$, $\gamma$ are in the subspace of $\RR^4$ spanned by the $\alpha_i$?

(b) Which of the vectors $\alpha$, $\beta$, $\gamma$ are in the subspace of $C^4$ spanned by the $\alpha_i$?

(c) Does this suggest a theorem?
:::

::: {.solution}

::: pf

::: pf-step
The $\alpha_i$ are linearly independent, so they span a $3$-dimensional subspace $W$.

::: pf-proof
the matrix with columns $\alpha_1, \alpha_2, \alpha_3$ has rank $3$ (its three columns are independent).
:::

:::

::: pf-step
A vector $v$ lies in $W$ iff the matrix $[\alpha_1\ \alpha_2\ \alpha_3\ v]$ has rank $3$ (i.e. $v$ does not increase the rank).

::: pf-proof
$v \in W$ iff $v$ is a linear combination of the $\alpha_i$, iff the augmented matrix has the same rank as $[\alpha_1\ \alpha_2\ \alpha_3]$.
:::

:::

::: {.pf-step #alpha-in-w}
$\alpha = (4,-5,9,-7)$ is in $W$.

::: pf-proof
$\operatorname{rank}[\alpha_1\ \alpha_2\ \alpha_3\ \alpha] = 3 = \operatorname{rank}[\alpha_1\ \alpha_2\ \alpha_3]$; indeed $\alpha = -3\alpha_1 + 2\alpha_2 - \alpha_3$.
:::

:::

::: {.pf-step #beta-not-in-w}
$\beta = (3,1,-4,4)$ is not in $W$.

::: pf-proof
$\operatorname{rank}[\alpha_1\ \alpha_2\ \alpha_3\ \beta] = 4 > 3$.
:::

:::

::: {.pf-step #gamma-not-in-w}
$\gamma = (-1,1,0,1)$ is not in $W$.

::: pf-proof
$\operatorname{rank}[\alpha_1\ \alpha_2\ \alpha_3\ \gamma] = 4 > 3$.
:::

:::

::: {.pf-step #real-complex-span-coincide}
Since the $\alpha_i$ have real entries, the real span and the complex span coincide on real vectors: a real vector is in the complex span iff it is in the real span.

::: pf-proof
if $v = \sum c_i \alpha_i$ with $c_i \in \CC$ and $v, \alpha_i$ all real, then taking real parts gives $v = \sum \operatorname{Re}(c_i) \alpha_i$ with real coefficients.
:::

:::

::: {.pf-step #answers-identical}
Hence the answers to (a) and (b) are identical: $\alpha$ is in the span, $\beta$ and $\gamma$ are not.

::: pf-proof
Steps [](#alpha-in-w){.pf-ref}, [](#beta-not-in-w){.pf-ref}, [](#gamma-not-in-w){.pf-ref}, and [](#real-complex-span-coincide){.pf-ref}.
:::

:::

::: {.pf-step #theorem-suggested}
Theorem suggested: if $v_1, \ldots, v_k \in \RR^n$ and $v \in \RR^n$, then $v$ is in the $\CC$-span of the $v_i$ iff $v$ is in the $\RR$-span of the $v_i$.

::: pf-proof
Step [](#real-complex-span-coincide){.pf-ref}.
:::

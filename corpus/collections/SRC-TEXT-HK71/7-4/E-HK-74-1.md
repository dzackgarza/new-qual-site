::: {.exercise}
True or false?
Every matrix in $F[x]^{n \times n}$ is row-equivalent to an upper-triangular matrix.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §7.4 Exercise 1, p. 261. The proof is an induction that clears the first column using the Euclidean algorithm in $F[x]$ and then applies the induction hypothesis to the trailing block.

::: pf

::: {.pf-step #euclid}
For $A\in F[x]^{n\times n}$ there are elementary row operations carrying $A$ to a matrix whose first column is $(d,0,\dots,0)^{t}$ with $d$ the greatest common divisor of the entries of the first column.

::: pf-proof
$F[x]$ is a Euclidean domain, so the greatest common divisor of finitely many entries is a combination of them; the usual algorithm of repeated division with remainder is implemented by elementary row operations, each of which is invertible over $F[x]$, and it reduces the first column to a single nonzero entry $d$ above zeros.
:::
:::

::: {.pf-step #base}
Every $1\times1$ matrix over $F[x]$ is upper triangular.

::: pf-proof
A $1\times1$ matrix has no entries below the diagonal.
:::
:::

::: {.pf-step #step}
If every $(n-1)\times(n-1)$ matrix over $F[x]$ is row-equivalent to an upper-triangular one, then so is every $n\times n$ matrix.

::: pf-proof
By step [](#euclid){.pf-ref} bring $A$ to $\begin{pmatrix}d&*\\0&B\end{pmatrix}$ with $B$ of size $(n-1)\times(n-1)$. By the induction hypothesis there are elementary row operations on $B$ carrying it to an upper-triangular $C$; applying the same operations to the last $n-1$ rows of the whole matrix, which do not disturb the first column, gives $\begin{pmatrix}d&*\\0&C\end{pmatrix}$, which is upper triangular.
:::
:::

::: {.pf-step #conclusion}
The assertion is true: every matrix over $F[x]$ is row-equivalent to an upper-triangular matrix.

::: pf-proof
Induction on $n$ from steps [](#base){.pf-ref} and [](#step){.pf-ref}.
:::
:::

::: {.exercise}
Let $A$ be an $n \times n$ triangular matrix over the field $F$.
Prove that the characteristic values of $A$ are the diagonal entries of $A$, i.e., the scalars $A_{ii}$.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no solution set for it is retained in `tmp/sources`, so nothing here is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §6.2 Exercise 3; the only facts used are the permutation expansion of the determinant and the vanishing of a product in a field.

Let $A$ be an $n\times n$ matrix over the field $F$ with entries $A_{ij}$, let $\chi_{A}(x)\coloneqq\det(xI-A)$, and recall that a scalar $c\in F$ is a characteristic value of $A$ exactly when $\chi_{A}(c)=0$. Say $A$ is upper triangular if $A_{ij}=0$ whenever $i>j$ and lower triangular if $A_{ij}=0$ whenever $i<j$.

::: pf

::: {.pf-step #permutation}
A permutation $\sigma$ of $\{1,\dots,n\}$ with $\sigma\neq\mathrm{id}$ satisfies $\sigma(i)>i$ for some $i$ and $\sigma(i)<i$ for some $i$.

::: pf-proof
Suppose $\sigma(i)\leq i$ for all $i$. Then $\sigma(1)\leq1$ forces $\sigma(1)=1$; if $\sigma(j)=j$ for $j<i$, then $\sigma(i)\leq i$ and $\sigma(i)\notin\{\sigma(1),\dots,\sigma(i-1)\}=\{1,\dots,i-1\}$ by injectivity, so $\sigma(i)=i$. By induction $\sigma=\mathrm{id}$. Hence $\sigma\neq\mathrm{id}$ gives some $i$ with $\sigma(i)>i$. Applying the same argument to $\sigma^{-1}$ gives some $j$ with $\sigma^{-1}(j)>j$, that is $j>\sigma(j)$.
:::

:::

::: {.pf-step #det}
If $A$ is triangular then $\det A=\prod_{i=1}^{n}A_{ii}$.

::: pf-proof
By the permutation expansion $\det A=\sum_{\sigma}\operatorname{sgn}(\sigma)\prod_{i=1}^{n}A_{i,\sigma(i)}$, a sum over the $n!$ permutations. The identity permutation contributes $\prod_{i}A_{ii}$. For $\sigma\neq\mathrm{id}$: if $A$ is upper triangular, step [](#permutation){.pf-ref} gives an $i$ with $\sigma(i)>i$, so $A_{i,\sigma(i)}=0$ and the whole product vanishes; if $A$ is lower triangular, step [](#permutation){.pf-ref} gives an $i$ with $\sigma(i)<i$, and again $A_{i,\sigma(i)}=0$. So every other term is zero and $\det A=\prod_{i}A_{ii}$.
:::

:::

::: {.pf-step #charpoly}
$xI-A$ is triangular of the same type as $A$, and $\chi_{A}(x)=\det(xI-A)=\prod_{i=1}^{n}(x-A_{ii})$.

::: pf-proof
The $(i,j)$ entry of $xI-A$ is $x-A_{ii}$ when $i=j$ and $-A_{ij}$ when $i\neq j$, so $(xI-A)_{ij}=0$ exactly where $A_{ij}=0$, and $xI-A$ is triangular of the same type as $A$. Its diagonal entries are $x-A_{ii}$, so step [](#det){.pf-ref} gives the product formula.
:::

:::

::: {.pf-step #field}
For $c\in F$, $\prod_{i=1}^{n}(c-A_{ii})=0$ if and only if $c=A_{ii}$ for some $i$.

::: pf-proof
A field has no zero divisors: if a product of finitely many elements is zero, one factor is zero (induct on the number of factors, using that $uv=0$ with $u\neq0$ forces $v=u^{-1}\cdot0=0$). Conversely a product with a zero factor is zero.
:::

:::

::: {.pf-step}
The characteristic values of a triangular $A$ are exactly the diagonal entries $A_{11},\dots,A_{nn}$.

::: pf-proof
A scalar $c$ is a characteristic value exactly when $\chi_{A}(c)=0$, and by step [](#charpoly){.pf-ref} that is the equation $\prod_{i}(c-A_{ii})=0$; by step [](#field){.pf-ref} it holds exactly when $c$ equals one of the diagonal entries. This is the assertion of the exercise.
:::

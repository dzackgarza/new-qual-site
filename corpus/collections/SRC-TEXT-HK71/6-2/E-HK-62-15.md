::: {.exercise}
Let $V$ be the space of $n \times n$ matrices over $F$.
Let $A$ be a fixed $n \times n$ matrix over $F$.
Let $T$ be the linear operator 'left multiplication by $A$' on $V$.
Is it true that $A$ and $T$ have the same characteristic values?
:::

::: {.solution}
::: pf

::: pf-step
The answer is **yes**: $A$ and $T$ have the same characteristic values in $F$.

::: pf-proof
statement of the claim.
:::

:::

::: {.pf-step #s2}
If $\lambda \in F$ is a characteristic value of $A$, then $\lambda$ is a characteristic value of $T$:

::: pf-proof

::: pf-step
Since $\lambda$ is an eigenvalue of $A$, there exists a non-zero column vector $v \in F^n$ such that $Av = \lambda v$.

::: pf-proof
definition of characteristic value for $A$.
:::

:::

::: pf-step
Define the matrix $B \in M_n(F)$ whose first column is $v$ and all other columns are zero.

::: pf-proof
construction of matrix.
:::

:::

::: {.pf-step #s2-3}
Since $v \neq 0$, $B \neq 0$ in $V = M_n(F)$.

::: pf-proof
non-zero entry in the first column.
:::

:::

::: {.pf-step #s2-4}
Compute the matrix product $T(B) = AB$: The $j$-th column of $AB$ is $A$ times the $j$-th column of $B$, so:
\[
\operatorname{col}_1(AB) = Av = \lambda v = \lambda \operatorname{col}_1(B), \quad \operatorname{col}_j(AB) = A(0) = 0 = \lambda \operatorname{col}_j(B) \text{ for } j \ge 2.
\]

::: pf-proof
column-by-column matrix multiplication.
:::

:::

::: {.pf-step #s2-5}
Thus $T(B) = AB = \lambda B$.

::: pf-proof
step [](#s2-4){.pf-ref}.
:::

:::

::: pf-step
Since $B \neq 0$, $B$ is an eigenvector of $T$ with eigenvalue $\lambda$, so $\lambda$ is a characteristic value of $T$.

::: pf-proof
steps [](#s2-3){.pf-ref} and [](#s2-5){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s3}
If $\lambda \in F$ is a characteristic value of $T$, then $\lambda$ is a characteristic value of $A$:

::: pf-proof

::: pf-step
Since $\lambda$ is an eigenvalue of $T$, there exists a non-zero matrix $B \in V$ such that $T(B) = \lambda B$.

::: pf-proof
definition of characteristic value for the operator $T$.
:::

:::

::: pf-step
This means $AB = \lambda B \iff (A - \lambda I)B = 0$.

::: pf-proof
definition of $T(B) = AB$.
:::

:::

::: {.pf-step #s3-3}
Since $B \neq 0$, there exists some column index $j \in \{1, \dots, n\}$ such that the $j$-th column $v = \operatorname{col}_j(B) \in F^n$ is non-zero.

::: pf-proof
a matrix is non-zero if and only if at least one column is non-zero.
:::

:::

::: {.pf-step #s3-4}
Multiplying $(A - \lambda I)$ by the $j$-th column gives $(A - \lambda I)v = 0$, so $Av = \lambda v$.

::: pf-proof
column extraction of the matrix equation $(A - \lambda I)B = 0$.
:::

:::

::: pf-step
Since $v \neq 0$, $v$ is an eigenvector of $A$ with eigenvalue $\lambda$, so $\lambda$ is a characteristic value of $A$.

::: pf-proof
steps [](#s3-3){.pf-ref} and [](#s3-4){.pf-ref}.
:::

:::

:::

:::

::: pf-step
Conclusion: The set of characteristic values of $T$ in $F$ is identical to the set of characteristic values of $A$ in $F$.

::: pf-proof
step [](#s2){.pf-ref} and step [](#s3){.pf-ref}.
:::

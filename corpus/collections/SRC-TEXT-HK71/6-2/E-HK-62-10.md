::: {.exercise}
Suppose that $A$ is a $2 \times 2$ matrix with real entries which is symmetric ($A^t = A$). Prove that $A$ is similar over $\RR$ to a diagonal matrix.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is an archive.org record, so the argument is the card's own. Let $A$ be real and symmetric, so $A=\begin{bmatrix}a&b\\ b&d\end{bmatrix}$ with $a,b,d\in\RR$.

::: pf

::: {.pf-step #charpoly}
$\chi_A(x)=\det(xI-A)=x^2-(a+d)x+(ad-b^2)$, whose discriminant is $(a-d)^2+4b^2\ge0$.

::: pf-proof
$xI-A=\begin{bmatrix}x-a&-b\\ -b&x-d\end{bmatrix}$, so $\chi_A(x)=(x-a)(x-d)-b^2=x^2-(a+d)x+(ad-b^2)$. The discriminant of $Ax^2+Bx+C$ is $B^2-4AC$, here $(a+d)^2-4(ad-b^2)=a^2-2ad+d^2+4b^2=(a-d)^2+4b^2$, a sum of squares of real numbers, hence $\ge0$.
:::

:::

::: {.pf-step #distinct}
If the discriminant is positive, the two roots $\lambda_1\ne\lambda_2$ are real and $A$ is similar over $\RR$ to $\operatorname{diag}(\lambda_1,\lambda_2)$.

::: pf-proof
A positive discriminant gives two distinct real roots of the characteristic polynomial, which are therefore eigenvalues of $A$ with real eigenvectors $v_1,v_2\ne0$. Eigenvectors for distinct eigenvalues are independent: if $v_2=cv_1$ then $\lambda_2v_2=Av_2=cAv_1=c\lambda_1v_1=\lambda_1v_2$, so $(\lambda_2-\lambda_1)v_2=0$, impossible since $\lambda_2\ne\lambda_1$ and $v_2\ne0$. Two independent vectors in $\RR^2$ form a basis, in which the matrix of the operator is diagonal with the eigenvalues on the diagonal, so $A$ is similar over $\RR$ to that diagonal matrix.
:::

:::

::: {.pf-step #repeated}
If the discriminant is zero then $b=0$ and $a=d$, so $A=aI$ is already diagonal.

::: pf-proof
$(a-d)^2+4b^2=0$ with $a-d$ and $b$ real forces $(a-d)^2=0$ and $4b^2=0$, since a sum of non-negative reals vanishes only if each does. So $a=d$ and $b=0$, and $A=\begin{bmatrix}a&0\\ 0&a\end{bmatrix}=aI$, which is a diagonal matrix; it is similar to itself.
:::

:::

::: {.pf-step}
$A$ is similar over $\RR$ to a diagonal matrix.

::: pf-proof
The discriminant is $\ge0$ by step [](#charpoly){.pf-ref}, so it is either positive or zero. In the first case step [](#distinct){.pf-ref} gives a basis of $\RR^2$ of eigenvectors, in the second step [](#repeated){.pf-ref} shows $A$ is already diagonal. Either way $A$ is similar over $\RR$ to a diagonal matrix, as the exercise asks.
:::

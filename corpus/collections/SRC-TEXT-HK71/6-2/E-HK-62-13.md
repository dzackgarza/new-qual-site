::: {.exercise}
Let $V = C(\RR)$ be the vector space of all continuous real-valued functions on $\RR$.
Let $T: V \to V$ be the linear operator defined by:
$$(Tf)(x) = \int_0^x f(t) \, dt.$$
Prove that $T$ has no characteristic values (eigenvalues).
:::

::: {.solution}
**Goal:** Prove that there does not exist any non-zero function $f \in C(\RR)$ and scalar $\lambda \in \RR$ such that $Tf = \lambda f$.

::: pf

::: pf-step
Setting up the Eigenvalue Equation:

::: pf-proof

::: pf-step
Suppose, for contradiction, that $\lambda \in \RR$ is an eigenvalue of $T$ with non-zero eigenfunction $f \in C(\RR) \setminus \{0\}$.

::: pf-proof
This is the negation of the assertion.
:::

:::

::: pf-step
The eigenvalue equation is:
$$(Tf)(x) = \int_0^x f(t) \, dt = \lambda f(x) \quad \text{for all } x \in \RR.$$

::: pf-proof
This is the definition of an eigenvalue, written out for this operator.
:::

:::

:::

:::

::: pf-step
Case 1: $\lambda = 0$:

::: pf-proof

::: pf-step
If $\lambda = 0$, then:
$$\int_0^x f(t) \, dt = 0 \quad \text{for all } x \in \RR.$$

::: pf-proof
Substituting $\lambda=0$ into the eigenvalue equation.
:::

:::

::: pf-step
By the **Fundamental Theorem of Calculus**, since $f$ is continuous, the function $F(x) = \int_0^x f(t) \, dt$ is differentiable and $F'(x) = f(x)$.

::: pf-proof
The integral of a continuous function is differentiable with derivative the integrand.
:::

:::

::: pf-step
Differentiating both sides with respect to $x$:
$$f(x) = \frac{d}{dx}(0) = 0 \quad \text{for all } x \in \RR.$$

::: pf-proof
Differentiating the constant function $0$.
:::

:::

::: pf-step
Thus $f$ is the zero function, which contradicts $f \ne 0$.

::: pf-proof
An eigenvector is by definition non-zero.
:::

:::

::: pf-step
Therefore, $\lambda = 0$ is not an eigenvalue.

::: pf-proof
The case $\lambda=0$ is therefore excluded.
:::

:::

:::

:::

::: pf-step
Case 2: $\lambda \ne 0$:

::: pf-proof

::: pf-step
If $\lambda \ne 0$, then:
$$f(x) = \frac{1}{\lambda} \int_0^x f(t) \, dt.$$

::: pf-proof
Dividing the eigenvalue equation by $\lambda$.
:::

:::

::: pf-step
**Initial Condition at $x = 0$:**
Evaluating at $x = 0$:
$$f(0) = \frac{1}{\lambda} \int_0^0 f(t) \, dt = 0.$$

::: pf-proof
Substituting $x=0$ makes the integral vanish.
:::

:::

::: pf-step
**Differentiability and Differential Equation:**
Since $f$ is continuous, the integral $\int_0^x f(t) \, dt$ is $C^1$, which implies $f$ is differentiable.
Differentiating both sides with respect to $x$:
$$f'(x) = \frac{1}{\lambda} f(x) \iff f'(x) - \frac{1}{\lambda} f(x) = 0.$$

::: pf-proof
Differentiating both sides using the fundamental theorem of calculus.
:::

:::

::: pf-step
This is a first-order linear ordinary differential equation.

::: pf-proof
It has the form $f'=f/\lambda$, a first-order linear homogeneous equation.
:::

:::

::: pf-step
Multiplying by the integrating factor $e^{-x/\lambda}$:
$$\frac{d}{dx} \left( e^{-x/\lambda} f(x) \right) = 0 \implies f(x) = C e^{x/\lambda} \quad \text{for some constant } C \in \RR.$$

::: pf-proof
The product rule together with $f'=f/\lambda$ makes the derivative of $fe^{-x/\lambda}$ vanish.
:::

:::

::: pf-step
Using the initial condition $f(0) = 0$:
$$f(0) = C e^0 = C = 0.$$

::: pf-proof
Substituting $x=0$ into $f(x)=Ce^{x/\lambda}$.
:::

:::

::: pf-step
Thus $f(x) = 0 \cdot e^{x/\lambda} = 0$ for all $x \in \RR$.

::: pf-proof
The exponential never vanishes, so the product is zero exactly when $C=0$.
:::

:::

::: pf-step
This again contradicts $f \ne 0$.

::: pf-proof
An eigenvector is non-zero, so the case $\lambda\neq0$ is excluded as well.
:::

:::

:::

:::

::: pf-step
Conclusion:
$T$ has no characteristic values in $\RR$.

::: pf-proof
Both cases being impossible, $T$ has no characteristic values.
:::

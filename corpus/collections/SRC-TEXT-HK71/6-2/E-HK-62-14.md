::: {.exercise}
Let $A$ be an $n \times n$ diagonal matrix with characteristic polynomial
\[
(x - c_1)^{d_1} \cdots (x - c_k)^{d_k},
\]
where $c_1, \ldots, c_k$ are distinct.
Let $V$ be the space of $n \times n$ matrices $B$ such that $AB = BA$.
Prove that the dimension of $V$ is $d_1^2 + \cdots + d_k^2$.
:::

::: {.solution}
**Goal.** Show $\dim\theset{B : AB = BA} = d_1^2 + \cdots + d_k^2$ for a diagonal matrix $A$ with distinct eigenvalues $c_1, \dots, c_k$ of multiplicities $d_1, \dots, d_k$.

::: pf

::: pf-step
$A$ is diagonal with eigenvalue $c_i$ appearing $d_i$ times.

::: pf-proof
by hypothesis.
:::

:::

::: pf-step
$AB = BA$ iff $B$ is block-diagonal with blocks of sizes $d_1, \dots, d_k$.

::: pf-proof

::: pf-step
Write $B$ in blocks $B_{ij}$ (size $d_i \times d_j$) matching the eigenspace decomposition.

::: pf-proof
partition $B$ according to the multiplicities.
:::

:::

::: pf-step
$AB = BA$ gives $c_i B_{ij} = c_j B_{ij}$ for each block.

::: pf-proof
the $(i,j)$ block of $AB$ is $c_i B_{ij}$ and of $BA$ is $c_j B_{ij}$.
:::

:::

::: pf-step
For $i \neq j$, $c_i \neq c_j$ forces $B_{ij} = 0$.

::: pf-proof
$(c_i - c_j) B_{ij} = 0$ and $c_i \neq c_j$.
:::

:::

::: pf-step
Hence $B$ is block-diagonal, with arbitrary blocks $B_{ii}$ of size $d_i \times d_i$.

::: pf-proof
the diagonal blocks are unconstrained.
:::

:::

:::

:::

::: pf-step
The dimension of the space of block-diagonal matrices is $\sum_i d_i^2$.

::: pf-proof

::: pf-step
Each diagonal block $B_{ii}$ has $d_i^2$ free entries.

::: pf-proof
a $d_i \times d_i$ matrix has $d_i^2$ entries.
:::

:::

::: {.pf-step #dim-v-formula}
Hence $\dim V = \sum_{i=1}^k d_i^2$.

::: pf-proof
the blocks are independent.
:::

:::

:::

:::

::: pf-qed
Step [](#dim-v-formula){.pf-ref} is the claim.
:::

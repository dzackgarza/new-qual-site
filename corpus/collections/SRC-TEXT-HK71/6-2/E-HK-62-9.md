::: {.exercise}
Use the result of Exercise 8 to prove that, if $A$ and $B$ are $n \times n$ matrices over the field $F$, then $AB$ and $BA$ have precisely the same characteristic values in $F$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §6.2 Exercise 9, which directs the use of Exercise 8 of the same section (printed on the same page): if $I-AB$ is invertible then $I-BA$ is invertible.

::: pf

::: {.pf-step #nonzero}
For $c\neq0$, $cI-AB$ is singular if and only if $I-c^{-1}AB$ is singular.

::: pf-proof
$cI-AB=-c\,(I-c^{-1}AB)$, and $-c$ is a nonzero scalar, so multiplying by it preserves invertibility; hence the two matrices are singular together.
:::
:::

::: {.pf-step #exercise-eight}
For $c\neq0$, $I-c^{-1}AB$ is invertible if and only if $I-c^{-1}BA$ is invertible.

::: pf-proof
Exercise 8 of §6.2 says that $I-AB$ invertible implies $I-BA$ invertible, and the same statement with $A$ replaced by $c^{-1}A$ reads: $I-c^{-1}AB$ invertible implies $I-B( c^{-1}A)=I-c^{-1}BA$ invertible. Applying it again with the roles of $A$ and $B$ exchanged gives the converse.
:::
:::

::: {.pf-step #nonzero-values}
For every $c\neq0$: $c$ is a characteristic value of $AB$ if and only if it is one of $BA$.

::: pf-proof
$c$ is a characteristic value of $AB$ exactly when $cI-AB$ is singular; by steps [](#nonzero){.pf-ref} and [](#exercise-eight){.pf-ref} this is equivalent to $I-c^{-1}BA$ being singular, that is to $cI-BA$ being singular, which is the assertion for $BA$.
:::
:::

::: {.pf-step #zero-value}
$0$ is a characteristic value of $AB$ if and only if it is one of $BA$.

::: pf-proof
$0$ is a characteristic value exactly when the matrix is singular, that is when its determinant vanishes. For square matrices $\det(AB)=\det A\det B=\det(BA)$, so $AB$ and $BA$ are singular together.
:::
:::

::: {.pf-step}
$AB$ and $BA$ have precisely the same characteristic values in $F$.

::: pf-proof
Every $c\in F$ is either $0$ or nonzero; step [](#zero-value){.pf-ref} covers $c=0$ and step [](#nonzero-values){.pf-ref} covers the rest.
:::
:::

::: {.exercise}
Let $V$ be the inner product space in Exercise 7 and $G$ the group of unitary matrices in $V$.
If $B$ is in $G$, let $C_B$ denote the linear operator on $V$ defined by
\[
C_B(A) = BAB^{-1}.
\]
Show that

(a) $C_B$ is a unitary operator on $V$;

(b) $C_{B_1B_2} = C_{B_1}C_{B_2}$;

(c) there is no unitary transformation $U$ on $V$ such that
\[
UL_BU^{-1} = C_B
\]
for all $B$ in $G$.
:::

::: {.solution}
**Goal.** Prove the three facts about the conjugation operators $C_B$.

::: pf

::: {.pf-step #s1}
(a) $C_B$ is unitary.

::: pf-proof

::: pf-step
$C_B(A) = BAB^{-1} = BAB^*$ (since $B$ is unitary, $B^{-1} = B^*$).

::: pf-proof
$B$ is unitary.
:::

:::

::: pf-step
$\|C_B(A)\| = \|BAB^*\| = \|A\|$.

::: pf-proof
the Frobenius (Hilbert–Schmidt) norm is invariant under left and right multiplication by unitaries: $\|BAB^*\|^2 = \operatorname{tr}((BAB^*)^*(BAB^*)) = \operatorname{tr}(BA^*B^*BAB^*) = \operatorname{tr}(BA^*AB^*) = \operatorname{tr}(A^*A) = \|A\|^2$.
:::

:::

::: pf-step
Hence $C_B$ is an isometry, so it is unitary.

::: pf-proof
a linear isometry on a finite-dimensional inner product space is unitary.
:::

:::

:::

:::

::: {.pf-step #s2}
(b) $C_{B_1 B_2} = C_{B_1} C_{B_2}$.

::: pf-proof

::: {.pf-step #s2-1}
$C_{B_1 B_2}(A) = (B_1 B_2) A (B_1 B_2)^{-1} = B_1 B_2 A B_2^{-1} B_1^{-1}$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #s2-2}
$C_{B_1}(C_{B_2}(A)) = C_{B_1}(B_2 A B_2^{-1}) = B_1 B_2 A B_2^{-1} B_1^{-1}$.

::: pf-proof
apply $C_{B_2}$ then $C_{B_1}$.
:::

:::

::: pf-step
Hence $C_{B_1 B_2} = C_{B_1} C_{B_2}$.

::: pf-proof
steps [](#s2-1){.pf-ref} and [](#s2-2){.pf-ref} agree.
:::

:::

:::

:::

::: {.pf-step #s3}
(c) No unitary $U$ satisfies $U L_B U^{-1} = C_B$ for all $B$.

::: pf-proof

::: pf-step
$L_B$ is left multiplication by $B$: $L_B(A) = BA$.

::: pf-proof
definition (from Exercise 7).
:::

:::

::: {.pf-step #s3-2}
$L_B$ and $C_B$ are not conjugate by a single $U$ for all $B$.

::: pf-proof
the map $B \mapsto L_B$ is a representation of $G$ (left regular), while $B \mapsto C_B$ is the conjugation representation; these are not equivalent as representations of $G$ (the left regular representation and the conjugation representation have different characters — e.g. the trace of $L_B$ is $n \operatorname{tr}(B)$ while the trace of $C_B$ is $|\operatorname{tr}(B)|^2$).
:::

:::

::: pf-step
Hence no such $U$ exists.

::: pf-proof
if $U L_B U^{-1} = C_B$ for all $B$, then $L$ and $C$ would be equivalent representations, contradicting step [](#s3-2){.pf-ref}.
:::

:::

:::

:::

::: pf-qed
Steps [](#s1){.pf-ref}, [](#s2){.pf-ref}, [](#s3){.pf-ref} prove (a), (b), (c).
:::

::: {.exercise}
Let $V$ be the inner product space in Exercise 7 and $G$ the group of unitary matrices in $V$.
If $B$ is in $G$, let $C_B$ denote the linear operator on $V$ defined by
$$
C_B(A) = BAB^{-1}.
$$
Show that

(a) $C_B$ is a unitary operator on $V$;

(b) $C_{B_1B_2} = C_{B_1}C_{B_2}$;

(c) there is no unitary transformation $U$ on $V$ such that
$$
UL_BU^{-1} = C_B
$$
for all $B$ in $G$.
:::

::: {.solution}
**Goal.** Prove the three facts about the conjugation operators $C_B$.

::: pf

::: {.pf-step #s1}
(a) $C_B$ is unitary.

::: pf-proof

::: pf-step
$C_B(A) = BAB^{-1} = BAB^*$ (since $B$ is unitary, $B^{-1} = B^*$).

::: pf-proof
$B$ is unitary.
:::

:::

::: pf-step
$\norm{C_B(A)} = \norm{BAB^*} = \norm{A}$.

::: pf-proof
the Frobenius (Hilbert–Schmidt) norm is invariant under left and right multiplication by unitaries: $\norm{BAB^*}^2 = \operatorname{tr}((BAB^*)^*(BAB^*)) = \operatorname{tr}(BA^*B^*BAB^*) = \operatorname{tr}(BA^*AB^*) = \operatorname{tr}(A^*A) = \norm{A}^2$.
:::

:::

::: pf-step
Hence $C_B$ is an isometry, so it is unitary.

::: pf-proof
a linear isometry on a finite-dimensional inner product space is unitary.
:::

:::

:::

:::

::: {.pf-step #s2}
(b) $C_{B_1 B_2} = C_{B_1} C_{B_2}$.

::: pf-proof

::: {.pf-step #s2-1}
$C_{B_1 B_2}(A) = (B_1 B_2) A (B_1 B_2)^{-1} = B_1 B_2 A B_2^{-1} B_1^{-1}$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #s2-2}
$C_{B_1}(C_{B_2}(A)) = C_{B_1}(B_2 A B_2^{-1}) = B_1 B_2 A B_2^{-1} B_1^{-1}$.

::: pf-proof
apply $C_{B_2}$ then $C_{B_1}$.
:::

:::

::: pf-step
Hence $C_{B_1 B_2} = C_{B_1} C_{B_2}$.

::: pf-proof
steps [](#s2-1){.pf-ref} and [](#s2-2){.pf-ref} agree.
:::

:::

:::

:::

::: {.pf-step #s3}
(c) No unitary $U$ satisfies $U L_B U^{-1} = C_B$ for all $B$.

::: pf-proof

::: {.pf-step #s3-1}
For every $B$, $\operatorname{tr}L_B = n\operatorname{tr}B$ and $\operatorname{tr}C_B=\abs{\operatorname{tr}B}^2$.

::: pf-proof
In the orthonormal basis of matrix units, $L_B(E_{ij})=\sum_k b_{ki}E_{kj}$, so the coefficient of $E_{ij}$ is $b_{ii}$ and $\operatorname{tr}L_B=\sum_{i,j}b_{ii}=n\operatorname{tr}B$.
Similarly $C_B(E_{ij})=BE_{ij}B^*=\sum_{k,\ell}b_{ki}\overline{b_{\ell j}}E_{k\ell}$, so the coefficient of $E_{ij}$ is $b_{ii}\overline{b_{jj}}$ and $\operatorname{tr}C_B=\sum_{i,j}b_{ii}\overline{b_{jj}}=\abs{\operatorname{tr}B}^2$.
:::

:::

::: pf-step
Hence no such $U$ exists.

::: pf-proof
Similar operators have equal traces. Take $B=-I\in G$. By step [](#s3-1){.pf-ref}, $\operatorname{tr}L_{-I}=-n^2$ while $\operatorname{tr}C_{-I}=n^2$, so $UL_{-I}U^{-1}\ne C_{-I}$ for every invertible $U$.
:::

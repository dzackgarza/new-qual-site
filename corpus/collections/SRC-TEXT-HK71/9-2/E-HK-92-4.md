::: {.exercise}
Let $V$ be a complex vector space and let $f$ be a (sesqui-linear) form on $V$ which is symmetric: $f(\alpha, \beta) = f(\beta, \alpha)$.
What is $f$?
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
Definition of sesquilinear form:

::: pf-proof

::: pf-step
By convention (Hoffman–Kunze), a sesquilinear form $f: V \times V \to \mathbb{C}$ on a complex vector space $V$ is linear in the first argument and conjugate-linear in the second argument:
\[
f(c\alpha, \beta) = c f(\alpha, \beta), \quad f(\alpha, c\beta) = \overline{c} f(\alpha, \beta) \quad \text{for all } c \in \mathbb{C}, \, \alpha, \beta \in V.
\]

::: pf-proof
definition of sesquilinear form.
:::

:::

:::

:::

::: {.pf-step #s2}
Combine symmetry with scalar multiplication:

::: pf-proof

::: {.pf-step #s2-1}
Assume $f$ is symmetric: $f(\alpha, \beta) = f(\beta, \alpha)$ for all $\alpha, \beta \in V$.

::: pf-proof
hypothesis.
:::

:::

::: pf-step
For any $c \in \mathbb{C}$ and any $\alpha, \beta \in V$, compute $f(c\alpha, \beta)$ in two ways:
- By linearity in the first argument:
\[
f(c\alpha, \beta) = c f(\alpha, \beta).
\]
- By symmetry and conjugate-linearity in the second argument:
\[
f(c\alpha, \beta) = f(\beta, c\alpha) = \overline{c} f(\beta, \alpha) = \overline{c} f(\alpha, \beta).
\]

::: pf-proof
step [](#s1){.pf-ref} and step [](#s2-1){.pf-ref}.
:::

:::

::: {.pf-step #s2-3}
Equating both expressions gives:
\[
(c - \overline{c}) f(\alpha, \beta) = 0 \quad \text{for all } c \in \mathbb{C}, \, \alpha, \beta \in V.
\]

::: pf-proof
subtraction of equal quantities.
:::

:::

:::

:::

::: {.pf-step #s3}
Deduce that $f$ is identically zero:

::: pf-proof

::: pf-step
Choose $c = i \in \mathbb{C}$.
Then $c - \overline{c} = i - (-i) = 2i \neq 0$.

::: pf-proof
properties of the imaginary unit $i$.
:::

:::

::: pf-step
Substituting $c = i$ into step [](#s2-3){.pf-ref} yields:
\[
2i f(\alpha, \beta) = 0 \implies f(\alpha, \beta) = 0.
\]
Since this holds for all $\alpha, \beta \in V$, $f \equiv 0$ is the zero form.

::: pf-proof
division by $2i \neq 0$.
:::

:::

:::

:::

::: pf-step
Conclusion: $f$ is the identically zero form ($f = 0$).

::: pf-proof
step [](#s2){.pf-ref} and step [](#s3){.pf-ref}.
:::

::: {.exercise}
Prove, for any non-zero polynomial $p$, that congruence modulo $p$ is an equivalence relation.

(a) It is reflexive: $f \equiv f \bmod p$.

(b) It is symmetric: if $f \equiv g \bmod p$, then $g \equiv f \bmod p$.

(c) It is transitive: if $f \equiv g \bmod p$ and $g \equiv h \bmod p$, then $f \equiv h \bmod p$.

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained in the checkout as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §4.5 Exercise 5 on printed p. 139. The argument is the card's own.

Throughout, $p\neq0$ is a polynomial over the field $F$, and $f\equiv g\pmod p$ means that $p$ divides $f-g$, that is $f-g=pq$ for some $q\in F[x]$.

::: pf

::: {.pf-step #reflexive}
(a) $f\equiv f\pmod p$.

::: pf-proof
$f-f=0=p\cdot0$, so $p$ divides $f-f$.

:::

:::

::: {.pf-step #symmetric}
(b) If $f\equiv g\pmod p$ then $g\equiv f\pmod p$.

::: pf-proof
If $f-g=pq$ then $g-f=p(-q)$, so $p$ divides $g-f$.

:::

:::

::: {.pf-step #transitive}
(c) If $f\equiv g\pmod p$ and $g\equiv h\pmod p$ then $f\equiv h\pmod p$.

::: pf-proof
If $f-g=pq_1$ and $g-h=pq_2$ then $f-h=(f-g)+(g-h)=p(q_1+q_2)$, so $p$ divides $f-h$.

:::

:::

::: {.pf-step #equivalence}
Congruence modulo $p$ is an equivalence relation on $F[x]$.

::: pf-proof
Steps [](#reflexive){.pf-ref}, [](#symmetric){.pf-ref} and [](#transitive){.pf-ref} establish reflexivity, symmetry and transitivity of the relation.

:::

::: {.exercise}
If $p$ is an irreducible polynomial and $fg \equiv 0 \bmod p$, prove that either $f \equiv 0 \bmod p$ or $g \equiv 0 \bmod p$.
Give an example which shows that this is false if $p$ is not irreducible.
:::

::: {.exercise}
If $p$ is an irreducible polynomial and $fg \equiv 0 \bmod p$, prove that either $f \equiv 0 \bmod p$ or $g \equiv 0 \bmod p$.
Give an example which shows that this is false if $p$ is not irreducible.
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §4.5 Exercise 8.

::: pf

::: {.pf-step #translate}
$fg\equiv0\pmod p$ means $p$ divides $fg$ in $F[x]$.

::: pf-proof
Congruence modulo the principal ideal $(p)$ is divisibility by $p$: $h\equiv0\pmod p$ exactly when $p\mid h$.
:::

:::

::: {.pf-step #prime}
An irreducible $p$ in $F[x]$ is prime.

::: pf-proof
$F[x]$ is a principal ideal domain because $F$ is a field, and in a principal ideal domain every irreducible element is prime: the ideal $(p)$ is maximal, hence prime, hence $p$ is prime in the sense that $p\mid fg$ implies $p\mid f$ or $p\mid g$.
:::

:::

::: {.pf-step #conclusion}
So $p\mid fg$ implies $p\mid f$ or $p\mid g$, that is $f\equiv0$ or $g\equiv0\pmod p$.

::: pf-proof
Steps [](#translate){.pf-ref} and [](#prime){.pf-ref} combine: $p\mid fg$ and $p$ prime give $p\mid f$ or $p\mid g$, and each alternative is the corresponding congruence.
:::

:::

::: {.pf-step #example}
The statement fails for $p$ not irreducible: with $p=x^2$, $f=g=x$, one has $fg\equiv0\pmod{x^2}$ while neither factor is $\equiv0$.

::: pf-proof
$fg=x^2$ is divisible by $x^2$, so $fg\equiv0\pmod{x^2}$; but $x$ is not divisible by $x^2$, so neither $f$ nor $g$ is $0$ modulo $x^2$. The polynomial $x^2$ is reducible, so the hypothesis of the first part genuinely fails here.
:::

:::

::: {.pf-step}
Irreducibility is exactly what the argument uses, and it cannot be dropped.

::: pf-proof
The first part is steps [](#translate){.pf-ref}, [](#prime){.pf-ref} and [](#conclusion){.pf-ref}; the example of step [](#example){.pf-ref} shows that a reducible modulus breaks the conclusion:
$$
\boxed{p\text{ irreducible}\implies\bigl(fg\equiv0\bmod p\implies f\equiv0\text{ or }g\equiv0\bmod p\bigr).}
$$
:::

::: {.exercise}
Let $V$ be the vector space of $n \times n$ matrices over the field $F$.

(a) If $B$ is a fixed $n \times n$ matrix, define a function $f_B$ on $V$ by $f_B(A) = \operatorname{trace}(B^t A)$.
Show that $f_B$ is a linear functional on $V$.

(b) Show that every linear functional on $V$ is of the above form, i.e., is $f_B$ for some $B$.

(c) Show that $B \to f_B$ is an isomorphism of $V$ onto $V^*$.
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §3.7 Exercise 8.

::: pf

::: {.pf-step #units}
Let $E_{ij}$ be the matrix units and let $B^{t}$ denote the transpose of $B$. For fixed $B$, the map $A\mapsto\operatorname{trace}(B^{t}A)=\sum_{i,j}b_{ij}a_{ij}$ is a linear functional.

::: pf-proof
The trace is linear and $A\mapsto B^{t}A$ is linear, so the composite is linear; written out, $\operatorname{trace}(B^{t}A)$ is the linear form with coefficients $b_{ij}$ on the entries $a_{ij}$.
:::

:::

::: {.pf-step #surjective}
Every $f\in V^*$ is $f_B$ for some $B$.

:::: pf-proof

::: {.pf-step #defineB}
Define $B=(b_{ij})$ by $b_{ij}=f(E_{ij})$.

::: pf-proof
This is a definition using the finitely many values of $f$ on the standard basis of $V$.
:::

:::

::: {.pf-step #evaluate}
$f_B(A)=f(A)$ for every $A$.

::: pf-proof
Writing $A=\sum_{i,j}a_{ij}E_{ij}$ and using linearity of $f$, $f(A)=\sum_{i,j}a_{ij}f(E_{ij})=\sum_{i,j}a_{ij}b_{ij}=\operatorname{trace}(B^{t}A)=f_B(A)$.
:::

:::

:::

:::

::: {.pf-step #isomorphism}
$B\mapsto f_B$ is an isomorphism $V\to V^*$.

::: pf-proof
It is linear, because $\operatorname{trace}$ is linear in $B$; it is surjective by step [](#surjective){.pf-ref}; and its kernel is trivial, since $f_B=0$ gives $b_{ij}=f_B(E_{ij})=0$ for all $i,j$, so $B=0$. A linear map with trivial kernel is injective, so
$$
\boxed{V\longrightarrow V^*,\quad B\mapsto\bigl(A\mapsto\operatorname{trace}(B^{t}A)\bigr)\ \text{is an isomorphism}.}
$$
No hypothesis on $F$ is used; in particular $F$ need not be infinite, and $V$ is finite-dimensional by construction, which is what makes $V$ and $V^*$ have the same dimension.
:::

::: {.exercise}
Let $F$ be a field and let $f$ be the linear functional on $F^2$ defined by $f(x_1, x_2) = ax_1 + bx_2$.
For each of the following linear operators $T$, let $g = T^t f$, and find $g(x_1, x_2)$.

(a) $T(x_1, x_2) = (x_1, 0)$;

(b) $T(x_1, x_2) = (-x_2, x_1)$;

(c) $T(x_1, x_2) = (x_1 - x_2,\; x_1 + x_2)$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §3.7 Exercise 1, p. 115.

::: pf

::: {.pf-step #definition}
The transpose is characterised by $g(x)=f(Tx)$ for all $x\in F^2$, where $g=T^tf$.

::: pf-proof
This is the definition of the transpose: $T^t$ assigns to a functional $f$ on $F^2$ the functional $x\mapsto f(Tx)$.
:::
:::

::: {.pf-step #a}
(a) $g(x_1,x_2)=ax_1$.

::: pf-proof
$T(x_1,x_2)=(x_1,0)$, so $g(x_1,x_2)=f(x_1,0)=ax_1+b\cdot0=ax_1$.
:::
:::

::: {.pf-step #b}
(b) $g(x_1,x_2)=bx_1-ax_2$.

::: pf-proof
$T(x_1,x_2)=(-x_2,x_1)$, so $g(x_1,x_2)=f(-x_2,x_1)=a(-x_2)+bx_1$.
:::
:::

::: {.pf-step #c}
(c) $g(x_1,x_2)=(a+b)x_1+(b-a)x_2$.

::: pf-proof
$T(x_1,x_2)=(x_1-x_2,x_1+x_2)$, so $g(x_1,x_2)=a(x_1-x_2)+b(x_1+x_2)=(a+b)x_1+(b-a)x_2$.
:::
:::

::: {.pf-step}
The three functionals are $ax_1$, $bx_1-ax_2$ and $(a+b)x_1+(b-a)x_2$.

::: pf-proof
Steps [](#a){.pf-ref}, [](#b){.pf-ref} and [](#c){.pf-ref} compute the three cases of the exercise.
:::

::: {.exercise}
Let $F$ be a field and let $f$ be the linear functional on $F^2$ defined by $f(x_1, x_2) = ax_1 + bx_2$.
For each of the following linear operators $T$, let $g = T^t f$, and find $g(x_1, x_2)$.

(a) $T(x_1, x_2) = (x_1, 0)$;

(b) $T(x_1, x_2) = (-x_2, x_1)$;

(c) $T(x_1, x_2) = (x_1 - x_2,\; x_1 + x_2)$.
:::

::: solution
By definition,
\[
(T^tf)(x)=f(Tx).
\]
Therefore:

(a) If $T(x_1,x_2)=(x_1,0)$, then
\[
g(x_1,x_2)=a x_1.
\]

(b) If $T(x_1,x_2)=(-x_2,x_1)$, then
\[
g(x_1,x_2)=a(-x_2)+b x_1=b x_1-a x_2.
\]

(c) If $T(x_1,x_2)=(x_1-x_2,x_1+x_2)$, then
\[
\begin{aligned}
g(x_1,x_2)
&=a(x_1-x_2)+b(x_1+x_2)\\
&=(a+b)x_1+(b-a)x_2.
\end{aligned}
\]
:::

::: {.exercise}
Let $V$ be a finite-dimensional vector space over the field $F$ and let $T$ be a linear operator on $V$.
Let $c$ be a scalar and suppose there is a non-zero vector $\alpha$ in $V$ such that $T\alpha = c\alpha$.
Prove that there is a non-zero linear functional $f$ on $V$ such that $T^t f = cf$.
:::

::: solution
**Goal:** Produce a nonzero $f\in V^*$ in $\ker(T^t-cI)$.

<1>1. Convert the primal eigenvector to a transpose eigenvector:
    *Proof:*  
    Define $S:=T-cI$. Since $S\alpha=0$ with $\alpha\ne0$, $S$ is not injective.
    Therefore $\operatorname{rank}(S)\le \dim V-1$.

<1>2. Use transpose rank nullity:
    *Proof:*  
    For finite dimensional maps, $\operatorname{rank}(S)=\operatorname{rank}(S^t)$.
    Hence
    $$\dim\ker(S^t)=\dim V-\operatorname{rank}(S^t)\ge 1.$$
    So there is nonzero $f\in\ker(S^t)$.

<1>3. Rewrite in the target form:
    *Proof:*  
    $f\in\ker(S^t)$ means $S^tf=0$, i.e.
    $$T^t f - cf=0.$$
    This is exactly $T^t f = cf$.

<1>4. Non-vanishing:
    *Proof:*  
    The kernel is nontrivial by <2>, so we can choose $f\ne0$.
:::

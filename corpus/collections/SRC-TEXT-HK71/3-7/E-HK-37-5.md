::: {.exercise}
Let $A$ be an $m \times n$ matrix with real entries.
Prove that $A = 0$ if and only if $\operatorname{trace}(A^t A) = 0$.

:::

::: {.solution}
There is no retained solution set for this exercise ; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §3.7 Exercise 5 on printed p. 116; the argument is the card's own.

Throughout, $A=(a_{ij})$ is an $m\times n$ real matrix, $A^{t}$ its transpose, and $\operatorname{trace}$ the sum of the diagonal entries of a square matrix.

::: pf

::: {.pf-step #diagonal}
The $j$-th diagonal entry of $A^{t}A$ is $\sum_{i=1}^{m}a_{ij}^{2}$.

::: pf-proof
The $(j,j)$ entry of a product is the $j$-th row of $A^{t}$ times the $j$-th column of $A$; the $j$-th row of $A^{t}$ is the $j$-th column of $A$, with $i$-th entry $a_{ij}$, and the $j$-th column of $A$ has $i$-th entry $a_{ij}$. So the entry is $\sum_{i=1}^{m}a_{ij}a_{ij}=\sum_{i=1}^{m}a_{ij}^{2}$.

:::

:::

::: {.pf-step #trace}
$\operatorname{trace}(A^{t}A)=\sum_{j=1}^{n}\sum_{i=1}^{m}a_{ij}^{2}$.

::: pf-proof
$A^{t}A$ is $n\times n$, so its trace is the sum of the $n$ diagonal entries computed in step [](#diagonal){.pf-ref}.

:::

:::

::: {.pf-step #zero-if}
If $A=0$ then $\operatorname{trace}(A^{t}A)=0$.

::: pf-proof
$A=0$ means every $a_{ij}=0$, so by step [](#trace){.pf-ref} the trace is a sum of zeros.

:::

:::

::: {.pf-step #if-zero}
If $\operatorname{trace}(A^{t}A)=0$ then $A=0$.

::: pf-proof
By step [](#trace){.pf-ref} the trace is a finite sum of the real numbers $a_{ij}^{2}$, each of which is $\ge0$. A finite sum of nonnegative reals is zero only if every term is zero, so $a_{ij}^{2}=0$ and hence $a_{ij}=0$ for all $i,j$; that is $A=0$.

:::

:::

::: {.pf-step #iff}
$A=0$ if and only if $\operatorname{trace}(A^{t}A)=0$.

::: pf-proof
The two implications are steps [](#zero-if){.pf-ref} and [](#if-zero){.pf-ref}.

:::

::: {.exercise}
Let $V$ be the vector space of $n \times n$ matrices over the field $F$.
Let $A$ be a fixed $n \times n$ matrix.
Let $T$ be the linear operator on $V$ defined by
$$
T(B) = AB.
$$
Show that the minimal polynomial for $T$ is the minimal polynomial for $A$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is an archive.org record, so the argument is the card's own. Let $V=M_n(F)$, let $A\in V$ be fixed, and let $T\in\operatorname{End}(V)$ be $T(B)=AB$.

::: pf

::: {.pf-step #powers}
$T^{j}(B)=A^{j}B$ for every $j\ge0$ and every $B\in V$.

::: pf-proof
Induction on $j$: for $j=0$, $T^0(B)=B=A^0B$. If $T^j(B)=A^jB$, then $T^{j+1}(B)=T\bigl(T^j(B)\bigr)=T(A^jB)=A\cdot A^jB=A^{j+1}B$, using the definition $T(C)=AC$ with $C=A^jB$.
:::

:::

::: {.pf-step #evaluate}
For $f=\sum_{j=0}^{r}c_jx^j\in F[x]$ and every $B\in V$, $f(T)(B)=f(A)B$.

::: pf-proof
$f(T)=\sum_jc_jT^j$ by definition of evaluation at an operator, so $f(T)(B)=\sum_jc_jT^j(B)=\sum_jc_jA^jB=\bigl(\sum_jc_jA^j\bigr)B=f(A)B$, using step [](#powers){.pf-ref} and linearity, and the distributive law for matrix multiplication.
:::

:::

::: {.pf-step #backward}
If $f(A)=0$ then $f(T)=0$.

::: pf-proof
Under the hypothesis step [](#evaluate){.pf-ref} gives $f(T)(B)=0\cdot B=0$ for every $B\in V$, so the operator $f(T)$ is zero.
:::

:::

::: {.pf-step #forward}
If $f(T)=0$ then $f(A)=0$.

::: pf-proof
Evaluate the zero operator at $B=I$: $0=f(T)(I)=f(A)I=f(A)$ by step [](#evaluate){.pf-ref}.
:::

:::

::: {.pf-step}
The minimal polynomial of $T$ equals the minimal polynomial of $A$.

::: pf-proof
Steps [](#backward){.pf-ref} and [](#forward){.pf-ref} show that the set of polynomials annihilating $T$ coincides with the set of polynomials annihilating $A$. Each set is the annihilator ideal of an element of a finite-dimensional algebra, hence nonzero — $\chi_A(A)=0$ by Cayley--Hamilton, and $\chi_A(T)=0$ by step [](#backward){.pf-ref} — so each has a unique monic generator, and since the ideals are equal their generators are equal. Those generators are by definition $m_T$ and $m_A$, so $m_T=m_A$.
:::

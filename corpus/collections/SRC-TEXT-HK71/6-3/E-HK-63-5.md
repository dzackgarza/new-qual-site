::: {.exercise}
Let $V$ be an $n$-dimensional vector space and let $T$ be a linear operator on $V$.
Suppose that there exists some positive integer $k$ so that $T^k = 0$.
Prove that $T^n = 0$.

:::

::: {.solution}
There is no retained solution set for this exercise and no text version of Hoffman and Kunze in the checkout; the argument below is the card's own, given in the terms of Chapter 6 rather than through the minimal polynomial.

Throughout, $V$ is $n$-dimensional over $F$, $T$ is a linear operator on $V$ with $T^{k}=0$ for some positive integer $k$, and $N_j=\ker T^{j}$ with $N_0=\ker I=\{0\}$.

::: pf

::: {.pf-step #chain}
$N_0\subseteq N_1\subseteq N_2\subseteq\cdots$ and $\dim N_j\le n$ for every $j$.

::: pf-proof
If $T^{j}v=0$ then $T^{j+1}v=T(T^{j}v)=0$, so $N_j\subseteq N_{j+1}$; each $N_j$ is a subspace of $V$ and $V$ has dimension $n$.

:::

:::

::: {.pf-step #stabilises}
If $N_j=N_{j+1}$ for some $j$, then $N_j=N_m$ for every $m\ge j$.

::: pf-proof
Induction on $m\ge j$. Let $m\ge j$ and suppose $N_m=N_j$; then $N_{m+1}=\ker T^{m+1}$. If $T^{m+1}v=0$ then $T^{m}(Tv)=0$, so $Tv\in N_m=N_j$, hence $T^{j}(Tv)=0$, that is $T^{j+1}v=0$ and $v\in N_{j+1}=N_j$. So $N_{m+1}\subseteq N_j$, and the reverse inclusion holds by the chain.

:::

:::

::: {.pf-step #reach}
There is a least $r$ with $N_r=V$, and $r\le n$.

::: pf-proof
$N_k=\ker T^{k}=V$ by the hypothesis $T^{k}=0$, so the set of $j$ with $N_j=V$ is nonempty and has a least element $r$; also $r\ge1$ unless $n=0$, since $N_0=\{0\}$. For $j<r$ we have $N_j\neq N_{j+1}$ by minimality of $r$ together with step [](#stabilises){.pf-ref}, so $\dim N_j<\dim N_{j+1}$ and hence $\dim N_j\ge j$ by induction from $\dim N_0=0$. Therefore $n=\dim N_r\ge r$, using step [](#chain){.pf-ref} for the bound $\dim N_r\le n$.

:::

:::

::: {.pf-step #conclusion}
$T^{n}=0$.

::: pf-proof
By step [](#reach){.pf-ref} $r\le n$, and the chain gives $N_r\subseteq N_n$, so $V=N_r\subseteq N_n\subseteq V$ and $N_n=V$. That says every $v\in V$ satisfies $T^{n}v=0$, that is $T^{n}=0$.

:::

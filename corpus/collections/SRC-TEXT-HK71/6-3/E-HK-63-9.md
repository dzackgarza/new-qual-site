::: {.exercise}
Let $A$ be an $n \times n$ matrix with characteristic polynomial
\[
f = (x - c_1)^{d_1} \cdots (x - c_k)^{d_k}.
\]
Show that
\[
c_1 d_1 + \cdots + c_k d_k = \operatorname{trace}(A).
\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Coefficient of $x^{n-1}$ from the determinant definition of the characteristic polynomial:

::: pf-proof

::: pf-step

By definition, the characteristic polynomial of $A = [a_{ij}] \in M_n(F)$ is $f(x) = \det(xI - A)$.

::: pf-proof

definition of characteristic polynomial.

:::

:::

::: pf-step

By the Leibniz formula for the determinant:
\[
\det(xI - A) = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^n (x \delta_{i, \sigma(i)} - a_{i, \sigma(i)}).
\]

::: pf-proof

Leibniz formula for determinants.

:::

:::

::: {.pf-step #s1-3}

For any non-identity permutation $\sigma \neq \operatorname{id}$, $\sigma$ fixes at most $n - 2$ elements, so the corresponding product has degree at most $n - 2$ in $x$.

::: pf-proof

permutations with at least $n - 1$ fixed points must be the identity.

:::

:::

::: {.pf-step #s1-4}

Thus the terms of degree $n$ and $n - 1$ arise solely from the diagonal product ($\sigma = \operatorname{id}$):
\[
\prod_{i=1}^n (x - a_{ii}) = x^n - \left(\sum_{i=1}^n a_{ii}\right) x^{n-1} + O(x^{n-2}) = x^n - \operatorname{trace}(A) x^{n-1} + O(x^{n-2}).
\]

::: pf-proof

expanding $\prod_{i=1}^n (x - a_{ii})$ and definition of trace.

:::

:::

::: pf-step

Thus the coefficient of $x^{n-1}$ in $f(x)$ is $-\operatorname{trace}(A)$.

::: pf-proof

Steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s2}

Coefficient of $x^{n-1}$ from the factored form of $f(x)$:

::: pf-proof

::: pf-step

The factored characteristic polynomial is $f(x) = (x - c_1)^{d_1} \cdots (x - c_k)^{d_k}$, with $\sum_{j=1}^k d_j = n$.

::: pf-proof

given.

:::

:::

::: {.pf-step #s2-2}

By Vieta’s formulas, the coefficient of $x^{n-1}$ in a monic polynomial with roots (counted with multiplicity) is the negative of the sum of the roots:
\[
f(x) = x^n - \left(\sum_{j=1}^k d_j c_j\right) x^{n-1} + \cdots + (-1)^n \prod_{j=1}^k c_j^{d_j}.
\]

::: pf-proof

expanding $(x - \lambda_1) \cdots (x - \lambda_n)$ where $\lambda_1, \dots, \lambda_n$ lists each $c_j$ repeated $d_j$ times.

:::

:::

::: pf-step

Thus the coefficient of $x^{n-1}$ in $f(x)$ is $-(c_1 d_1 + \cdots + c_k d_k)$.

::: pf-proof

Step [](#s2-2){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s3}

Equating the coefficients:

::: pf-proof

::: pf-step

Equating the coefficients of $x^{n-1}$ obtained in steps [](#s1){.pf-ref} and [](#s2){.pf-ref} gives:
\[
-\operatorname{trace}(A) = -(c_1 d_1 + \cdots + c_k d_k).
\]

::: pf-proof

uniqueness of polynomial coefficients.

:::

:::

::: pf-step

Multiplying both sides by $-1$ yields:
\[
\operatorname{trace}(A) = c_1 d_1 + \cdots + c_k d_k.
\]

::: pf-proof

scalar multiplication by $-1$.

:::

:::

:::

:::

::: pf-step

Conclusion:
$c_1 d_1 + \cdots + c_k d_k = \operatorname{trace}(A)$. Q.E.D.

::: pf-proof

Step [](#s3){.pf-ref}.

:::

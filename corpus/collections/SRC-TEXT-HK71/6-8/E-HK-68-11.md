::: {.exercise}
What's wrong with the following proof of Theorem 13? Suppose that the minimal polynomial for $T$ is a product of linear factors.
Then, by Theorem 5, $T$ is triangulable.
Let $\mathfrak{B}$ be an ordered basis such that $A = [T]_{\mathfrak{B}}$ is upper-triangular.
Let $D$ be the diagonal matrix with diagonal entries $a_{11}, \ldots, a_{nn}$.
Then $A = D + N$, where $N$ is strictly upper-triangular.
Evidently $N$ is nilpotent.
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §6.8 Exercise 11 on printed p. 225. The argument is the card's own.

::: pf

::: {.pf-step #s1}
The proof writes $A=D+N$ with $D$ the diagonal of the upper-triangular $A$ and $N=A-D$ strictly upper triangular.

::: pf-proof
$D$ is defined as the diagonal matrix with entries $a_{11},\ldots,a_{nn}$, so $N=A-D$ has zero diagonal and agrees with $A$ above it; it is therefore strictly upper triangular, and $A=D+N$ by construction.
:::

:::

::: {.pf-step #s2}
A strictly upper-triangular $n\times n$ matrix $N$ is nilpotent, so the proof's $N$ is nilpotent.

::: pf-proof
For the standard basis, $Ne_i\in\operatorname{span}(e_1,\ldots,e_{i-1})$; inductively $N^ke_i\in\operatorname{span}(e_1,\ldots,e_{i-k})$, which is $\{0\}$ once $k\ge i$. Hence $N^ne_i=0$ for every $i$, and $N^n=0$.
:::

:::

::: {.pf-step #s3}
What the proof never establishes is that its $D$ and $N$ commute, which the theorem's decomposition requires.

::: pf-proof
Theorem 13 asserts a decomposition $A=D'+N'$ with $D'$ diagonalizable, $N'$ nilpotent, $D'N'=N'D'$, and $D'$, $N'$ polynomials in $A$. The proof shows only $A=D+N$ with $D$ diagonal and $N$ nilpotent; it contains no argument for $DN=ND$, and the next step shows that this is not automatic.
:::

:::

::: {.pf-step #s4}
$D$ and $N$ need not commute: for $A=\begin{pmatrix}1&1\\0&2\end{pmatrix}$ one has $D=\begin{pmatrix}1&0\\0&2\end{pmatrix}$ and $N=\begin{pmatrix}0&1\\0&0\end{pmatrix}$, and $DN\ne ND$.

::: pf-proof
Multiplying, $DN=\begin{pmatrix}0&1\\0&0\end{pmatrix}$ while $ND=\begin{pmatrix}0&2\\0&0\end{pmatrix}$; the $(1,2)$ entry is $1$ in the first and $2$ in the second, so the two products differ.
:::

:::

::: {.pf-step #s5}
Hence the proof does not establish Theorem 13.

::: pf-proof
It produces a diagonal $D$ and a nilpotent $N$ with $A=D+N$ but no proof that they commute, and step [](#s4){.pf-ref} shows commutativity can fail for exactly this choice of $D$ and $N$. Without $DN=ND$ the sum is not the Jordan decomposition, so the argument does not prove the theorem; the correct proof has to produce the parts from the projections of the primary decomposition, which are polynomials in $T$.
:::

::: {.exercise}
Let $V$ be a finite-dimensional vector space over the field $F$, and let $T$ be a linear operator on $V$ such that $\operatorname{rank}(T) = 1$.
Prove that either $T$ is diagonalizable or $T$ is nilpotent, not both.
:::

::: {.solution}

::: pf

::: pf-step

$\dim \operatorname{im} T = 1$, so $\operatorname{im} T = \operatorname{span}\{v\}$ for some nonzero $v \in V$.

::: pf-proof

rank $1$.

:::

:::

::: pf-step

$T$ has at most one nonzero eigenvalue.

::: pf-proof

::: {.pf-step #s2-1}

If $T$ has a nonzero eigenvalue $\lambda$ with eigenvector $u$, then $Tu = \lambda u \in \operatorname{im} T$, so $u \in \operatorname{im} T = \operatorname{span}\{v\}$.

::: pf-proof

$\lambda \neq 0$ and $Tu = \lambda u$ implies $u = \lambda^{-1} Tu \in \operatorname{im} T$.

:::

:::

::: {.pf-step #s2-2}

Hence the eigenspace for any nonzero eigenvalue is contained in the $1$-dimensional space $\operatorname{span}\{v\}$.

::: pf-proof

Step [](#s2-1){.pf-ref}.

:::

:::

::: pf-step

Therefore there is at most one nonzero eigenvalue.

::: pf-proof

two distinct nonzero eigenvalues would give two linearly independent eigenvectors, contradicting step [](#s2-2){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s3}

Case 1: $T$ has a nonzero eigenvalue $\lambda$.

::: pf-proof

::: pf-step

Then $T$ is diagonalizable.

::: pf-proof

$T$ has eigenvalues $\lambda$ (with multiplicity $1$) and $0$ (with multiplicity $n-1$); the geometric multiplicity of $0$ is $\dim \ker T = n - 1$ (by rank–nullity), and of $\lambda$ is $1$, so the geometric multiplicities sum to $n$, hence $T$ is diagonalizable.

:::

:::

::: pf-step

$T$ is not nilpotent.

::: pf-proof

a nilpotent operator has all eigenvalues $0$, but $T$ has the nonzero eigenvalue $\lambda$.

:::

:::

:::

:::

::: {.pf-step #s4}

Case 2: $T$ has no nonzero eigenvalue.

::: pf-proof

::: pf-step

Then all eigenvalues of $T$ are $0$, so $T$ is nilpotent.

::: pf-proof

the characteristic polynomial is $t^n$, so by Cayley–Hamilton $T^n = 0$.

:::

:::

::: pf-step

$T$ is not diagonalizable (unless $T = 0$).

::: pf-proof

if $T$ were diagonalizable with all eigenvalues $0$, then $T = 0$, contradicting $\operatorname{rank} T = 1$.

:::

:::

:::

:::

::: {.pf-step #s5}

Hence exactly one of "diagonalizable" or "nilpotent" holds.

::: pf-proof

Steps [](#s3){.pf-ref} and [](#s4){.pf-ref} are mutually exclusive and exhaustive.

:::

:::

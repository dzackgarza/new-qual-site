::: {.exercise}
If $A$ is an invertible $n \times n$ matrix over a field, show that $\det A \neq 0$.

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained in the checkout as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §5.3 Exercise 5 on printed p. 155. The argument is the card's own.

Throughout, $A$ is an $n\times n$ matrix over the field $F$ with an inverse $A^{-1}$, so $AA^{-1}=I$, and $\det$ is multiplicative: $\det(XY)=\det X\det Y$, with $\det I=1$.

::: pf

::: {.pf-step #product}
$\det A\cdot\det A^{-1}=1$.

::: pf-proof
By multiplicativity and $\det I=1$,
$$
(\det A)(\det A^{-1})=\det(AA^{-1})=\det I=1,
$$
using $AA^{-1}=I$ from the definition of the inverse.

:::

:::

::: {.pf-step #nonzero}
$\det A\neq0$.

::: pf-proof
Suppose $\det A=0$. Then step [](#product){.pf-ref} gives $0\cdot\det A^{-1}=1$, that is $0=1$ in $F$, which no field allows. Hence $\det A\neq0$. Equivalently, $\det A$ has the multiplicative inverse $\det A^{-1}$ in $F$, and an element with an inverse is nonzero.

:::

::: {.exercise}
Let $T$ be a linear operator on $F^n$.
Define
$$
D_T(\alpha_1, \ldots, \alpha_n) = \det(T\alpha_1, \ldots, T\alpha_n).
$$

(a) Show that $D_T$ is an alternating $n$-linear function.

(b) If
$$
c = \det(T\epsilon_1, \ldots, T\epsilon_n)
$$
show that for any $n$ vectors $\alpha_1, \ldots, \alpha_n$ we have
$$
\det(T\alpha_1, \ldots, T\alpha_n) = c\det(\alpha_1, \ldots, \alpha_n).
$$

(c) If $\mathfrak{B}$ is any ordered basis for $F^n$ and $A$ is the matrix of $T$ in the ordered basis $\mathfrak{B}$, show that $\det A = c$.

(d) What do you think is a reasonable name for the scalar $c$?
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §5.3 Exercise 11 on printed p. 155. The argument is the card's own.

**Part (a).**

::: pf

::: {.pf-step #a-n-linear}
$D_T$ is $n$-linear.

::: pf-proof
$\det$ is $n$-linear in its columns and $T$ is linear, so $D_T(\alpha_1,\ldots,\alpha_n)=\det(T\alpha_1,\ldots,T\alpha_n)$ is linear in each $\alpha_i$ separately.
:::

:::

::: {.pf-step #a-alternating}
$D_T$ is alternating.

::: pf-proof
If $\alpha_i=\alpha_j$ with $i\ne j$, then $T\alpha_i=T\alpha_j$, so $\det(T\alpha_1,\ldots,T\alpha_n)=0$ because $\det$ is alternating.
:::

:::

:::

**Part (b).**

::: pf

::: {.pf-step #b-scalar-multiple}
There is a scalar $\lambda$ with $D_T=\lambda\det$.

::: pf-proof
The alternating $n$-linear functions on $F^n$ form a $1$-dimensional space spanned by $\det$ (Theorem 4 of this section), and $D_T$ is one of them by part (a); so $D_T=\lambda\det$ for a unique $\lambda$.
:::

:::

::: {.pf-step #b-lambda-is-c}
$\lambda=D_T(\epsilon_1,\ldots,\epsilon_n)=c$, hence $\det(T\alpha_1,\ldots,T\alpha_n)=c\det(\alpha_1,\ldots,\alpha_n)$ for all $\alpha_1,\ldots,\alpha_n$.

::: pf-proof
Evaluating $D_T=\lambda\det$ at the standard basis gives $\lambda=D_T(\epsilon_1,\ldots,\epsilon_n)$, since $\det(\epsilon_1,\ldots,\epsilon_n)=1$; and $D_T(\epsilon_1,\ldots,\epsilon_n)=\det(T\epsilon_1,\ldots,T\epsilon_n)=c$ by the definition of $D_T$ and of $c$. Substituting $\lambda=c$ into $D_T=\lambda\det$ gives the displayed identity.
:::

:::

:::

**Part (c).**

::: pf

::: {.pf-step #c-standard-matrix}
Let $M$ be the matrix of $T$ in the standard ordered basis. Then $\det M=c$.

::: pf-proof
The columns of $M$ are $T\epsilon_1,\ldots,T\epsilon_n$, so $\det M=\det(T\epsilon_1,\ldots,T\epsilon_n)=c$ by the definition of $c$.
:::

:::

::: {.pf-step #c-similar}
$A=P^{-1}MP$, where $P$ is the invertible matrix whose columns are the vectors $\beta_1,\ldots,\beta_n$ of $\mathfrak{B}$.

::: pf-proof
$P$ sends $\mathfrak{B}$-coordinates to standard coordinates, so $MP=PA$, and $P$ is invertible because $\mathfrak{B}$ is a basis; hence $A=P^{-1}MP$.
:::

:::

::: {.pf-step #c-det-a}
$\det A=c$.

::: pf-proof
By multiplicativity of $\det$, $\det A=\det(P^{-1})\det M\det P=\det M$, since $\det(P^{-1})\det P=1$; and $\det M=c$ by step [](#c-standard-matrix){.pf-ref}.
:::

:::

:::

**Part (d).**

::: pf

::: {.pf-step #d-name}
The scalar $c$ is the determinant of $T$.

::: pf-proof
By part (c), $c=\det A$ for the matrix $A$ of $T$ in any ordered basis, and the determinant of an operator is defined as the determinant of its matrix in any ordered basis; the value is independent of the basis by step [](#c-det-a){.pf-ref}.
:::

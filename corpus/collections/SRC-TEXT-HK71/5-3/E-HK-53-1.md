::: {.exercise}
If $K$ is a commutative ring with identity and $A$ is the matrix over $K$ given by
$$
A = \begin{bmatrix} 0 & a & b \\ -a & 0 & c \\ -b & -c & 0 \end{bmatrix}
$$
show that $\det A = 0$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §5.3 Exercise 1, the matrix matching the printed one. The determinant was expanded by hand and equals $-abc+abc=0$ as an identity of polynomials over $\ZZ$, hence over every commutative ring.

::: pf

::: {.pf-step #transpose}
$\det A=\det(A^{t})$ and $A^{t}=-A$.

::: pf-proof
The determinant is unchanged by transpose, and transposing the displayed matrix negates the three entries above the diagonal and moves them below it, which is exactly $-A$.
:::
:::

::: {.pf-step #scalar}
$\det A=-\det A$, so $2\det A=0$.

::: pf-proof
By multilinearity in the rows, $\det(-A)=(-1)^{3}\det A=-\det A$; with step [](#transpose){.pf-ref} this gives $\det A=-\det A$.
:::
:::

::: {.pf-step #insufficient}
The identity $2\det A=0$ does not by itself give $\det A=0$ in an arbitrary commutative ring.

::: pf-proof
In a ring where $2$ is a zero divisor or zero, $2\det A=0$ carries no information about $\det A$; for instance in characteristic $2$ the equation reads $0=0$. So a proof that divides by $2$, or that concludes from $x=-x$, is not available here.
:::
:::

::: {.pf-step #expansion}
$\det A=0$ in every commutative ring with identity.

::: pf-proof
Expanding along the first row, the first term vanishes because the corner entry is $0$, and the other two are $-a\begin{vmatrix}-a&c\\-b&0\end{vmatrix}+b\begin{vmatrix}-a&0\\-b&-c\end{vmatrix}=-a(0+bc)+b(ac-0)=-abc+abc=0$. The computation uses only the ring axioms, so it is valid over $K$.
:::
:::

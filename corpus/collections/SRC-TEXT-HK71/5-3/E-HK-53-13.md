::: {.exercise}
Prove that the sign function on permutations is unique in the following sense.
If $f$ is any function which assigns to each permutation of degree $n$ an integer, and if $f(\sigma\tau) = f(\sigma)f(\tau)$, then $f$ is identically 0, or $f$ is identically 1, or $f$ is the sign function.
:::

::: {.solution}

::: pf

::: pf-step
$f$ is a group homomorphism $S_n \to \ZZ^\times = \{\pm 1\}$ (or to $\ZZ$ under multiplication).

::: pf-proof
the condition $f(\sigma\tau) = f(\sigma)f(\tau)$ is exactly the homomorphism property.
:::

:::

::: pf-step
For any transposition $\tau$, $f(\tau)^2 = f(\tau^2) = f(e) = 1$, so $f(\tau) = \pm 1$.

::: pf-proof
$\tau^2 = e$ and $f(e) = f(e)^2$ forces $f(e) = 1$ (or $f \equiv 0$).
:::

:::

::: {.pf-step #same-value-on-transpositions}
All transpositions are conjugate in $S_n$, so $f$ takes the same value on every transposition.

::: pf-proof
conjugate elements have equal image under a homomorphism (since $f(\sigma\tau\sigma^{-1}) = f(\sigma)f(\tau)f(\sigma)^{-1} = f(\tau)$).
:::

:::

::: {.pf-step #case-all-transpositions-positive}
Case 1: $f(\tau) = 1$ for every transposition $\tau$.

::: pf-proof

::: pf-step
Then $f(\sigma) = 1$ for every $\sigma \in S_n$.

::: pf-proof
every permutation is a product of transpositions (step [](#same-value-on-transpositions){.pf-ref} of the transpositions-generate result), and $f$ is multiplicative.
:::

:::

:::

:::

::: {.pf-step #case-all-transpositions-negative}
Case 2: $f(\tau) = -1$ for every transposition $\tau$.

::: pf-proof

::: pf-step
Then $f(\sigma) = (-1)^{\text{number of transpositions in a decomposition of } \sigma} = \operatorname{sgn}(\sigma)$.

::: pf-proof
$f$ is multiplicative and equals $-1$ on each transposition, so it equals the sign function.
:::

:::

:::

:::

::: {.pf-step #case-f-identically-zero}
Case 3: $f \equiv 0$.

::: pf-proof
if $f(e) = 0$ (or $f$ is the zero map), then $f(\sigma) = f(\sigma e) = f(\sigma) f(e) = 0$ for all $\sigma$.
:::

:::

::: {.pf-step #three-cases-exhaustive}
Hence $f$ is identically $0$, identically $1$, or the sign function.

::: pf-proof
Steps [](#case-all-transpositions-positive){.pf-ref}, [](#case-all-transpositions-negative){.pf-ref}, and [](#case-f-identically-zero){.pf-ref} exhaust the possibilities.
:::

:::

::: pf-qed
Step [](#three-cases-exhaustive){.pf-ref}.
:::

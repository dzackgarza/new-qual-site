::: {.exercise}
Prove that the sign function on permutations is unique in the following sense.
If $f$ is any function which assigns to each permutation of degree $n$ an integer, and if $f(\sigma\tau) = f(\sigma)f(\tau)$, then $f$ is identically 0, or $f$ is identically 1, or $f$ is the sign function.
:::

::: {.solution}

::: pf

::: {.pf-step #f-identity}
Either $f \equiv 0$, or $f(e) = 1$.

::: pf-proof
$f(e) = f(e)^2$, so $f(e) \in \{0, 1\}$. If $f(e) = 0$, then $f(\sigma) = f(\sigma e) = f(\sigma)f(e) = 0$ for every $\sigma$.
:::

:::

::: {.pf-step #f-units}
If $f$ is not identically zero, then $f(\sigma) = \pm 1$ for every $\sigma$.

::: pf-proof
Step [](#f-identity){.pf-ref} gives $f(e)=1$ in this case. Hence
$f(\sigma)f(\sigma^{-1}) = 1$, and the only integers with an integer inverse are $\pm 1$.
:::

:::

::: {.pf-step #same-value-on-transpositions}
In the nonzero case, $f$ takes one value $\varepsilon \in \{\pm 1\}$ on all transpositions.

::: pf-proof
all transpositions are conjugate in $S_n$, and $f(\rho\tau\rho^{-1}) = f(\rho)f(\tau)f(\rho)^{-1} = f(\tau)$ because the values commute and are invertible by Step [](#f-units){.pf-ref}.
:::

:::

::: {.pf-step #f-formula}
In the nonzero case, if $\sigma = \tau_1 \cdots \tau_k$ is a product of transpositions, then $f(\sigma) = \varepsilon^k$.

::: pf-proof
every permutation is a product of transpositions ($e$ is the empty product), $f$ is multiplicative, and Step [](#same-value-on-transpositions){.pf-ref}.
:::

:::

::: pf-qed
If $\varepsilon = 1$, then $f \equiv 1$ by Step [](#f-formula){.pf-ref}. If $\varepsilon = -1$, then $f(\sigma) = (-1)^k = \operatorname{sgn}(\sigma)$. For $n = 1$ there are no transpositions and $f \equiv 1 = \operatorname{sgn}$. With Step [](#f-identity){.pf-ref}, $f$ is identically $0$, identically $1$, or the sign function.
:::

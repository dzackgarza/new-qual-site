::: {.exercise}
An $n \times n$ matrix $A$ is called triangular if $A_{ij} = 0$ whenever $i > j$ or if $A_{ij} = 0$ whenever $i < j$.
Prove that the determinant of a triangular matrix is the product $A_{11}A_{22} \cdots A_{nn}$ of its diagonal entries.
:::

::: {.solution}
**Goal.** Show $\det A = A_{11} A_{22} \cdots A_{nn}$ for a triangular matrix.

::: pf

::: pf-step
It suffices to consider the upper-triangular case (the lower-triangular case is identical by transposition, since $\det A = \det A^T$).

::: pf-proof
$\det A = \det A^T$, and the transpose of a lower-triangular matrix is upper-triangular.
:::

:::

::: pf-step
Expand the determinant along the first column.

::: pf-proof

::: pf-step
In an upper-triangular matrix, the first column has only one nonzero entry, $A_{11}$.

::: pf-proof
$A_{i1} = 0$ for $i > 1$.
:::

:::

::: {.pf-step #det-via-cofactor-expansion}
Hence $\det A = A_{11} \cdot \det A_{11}$, where $A_{11}$ is the $(n-1)\times(n-1)$ minor obtained by deleting the first row and column.

::: pf-proof
cofactor expansion along the first column.
:::

:::

::: pf-step
$A_{11}$ is again upper-triangular with diagonal $A_{22}, \dots, A_{nn}$.

::: pf-proof
deleting the first row and column of an upper-triangular matrix gives an upper-triangular matrix.
:::

:::

:::

:::

::: pf-step
Induct on $n$.

::: pf-proof

::: pf-step
Base case $n = 1$: $\det A = A_{11}$.

::: pf-proof
a $1\times 1$ matrix $A = [A_{11}]$ has determinant equal to its single entry, and the product of its diagonal entries is $A_{11}$.
:::

:::

::: {.pf-step #inductive-step-conclusion}
Inductive step: $\det A = A_{11} \det A_{11} = A_{11} (A_{22} \cdots A_{nn})$.

::: pf-proof
by step [](#det-via-cofactor-expansion){.pf-ref} and the induction hypothesis applied to $A_{11}$.
:::

:::

:::

:::

::: pf-qed
Step [](#inductive-step-conclusion){.pf-ref} gives $\det A = A_{11} A_{22} \cdots A_{nn}$.
:::

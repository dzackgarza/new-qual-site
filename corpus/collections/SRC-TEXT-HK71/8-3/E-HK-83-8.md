::: {.exercise}
Let $V$ be the vector space of the polynomials over $\RR$ of degree less than or equal to 3, with the inner product
\[
(f \mid g) = \int_0^1 f(t)g(t)\,dt.
\]
If $t$ is a real number, find the polynomial $g_t$ in $V$ such that $(f \mid g_t) = f(t)$ for all $f$ in $V$.
:::

::: {.solution}
<1>1. Let $g_t(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3$.
Proof: write $g_t$ in the monomial basis.

<1>2. The condition $(f \mid g_t) = f(t)$ for all $f \in V$ means $g_t$ is the reproducing kernel, i.e. $\int_0^1 f(x) g_t(x)\,dx = f(t)$ for all $f$.
Proof: definition.

<1>3. Taking $f = 1, x, x^2, x^3$ gives the system:
$$\int_0^1 g_t(x)\,dx = 1,\ \int_0^1 x g_t(x)\,dx = t,\ \int_0^1 x^2 g_t(x)\,dx = t^2,\ \int_0^1 x^3 g_t(x)\,dx = t^3.$$
Proof: <1>2 with $f = x^k$.

<1>4. $\int_0^1 x^k\,dx = \frac{1}{k+1}$, so the system is:
$$a_0 + \frac{a_1}{2} + \frac{a_2}{3} + \frac{a_3}{4} = 1,$$
$$\frac{a_0}{2} + \frac{a_1}{3} + \frac{a_2}{4} + \frac{a_3}{5} = t,$$
$$\frac{a_0}{3} + \frac{a_1}{4} + \frac{a_2}{5} + \frac{a_3}{6} = t^2,$$
$$\frac{a_0}{4} + \frac{a_1}{5} + \frac{a_2}{6} + \frac{a_3}{7} = t^3.$$
Proof: <1>3, integrating term by term.

<1>5. This is a linear system in $a_0, a_1, a_2, a_3$ (the Hilbert matrix), which has a unique solution (the Hilbert matrix is invertible).
Proof: <1>4.

<1>6. Hence $g_t$ exists and is unique, given by solving the system in <1>4.
Proof: <1>5.

<1>7. Q.E.D.
Proof: <1>6.
:::

::: {.exercise}
Let $V$ be the vector space of the polynomials over $\RR$ of degree less than or equal to 3, with the inner product
$$
(f \mid g) = \int_0^1 f(t)g(t)\,dt.
$$
If $t$ is a real number, find the polynomial $g_t$ in $V$ such that $(f \mid g_t) = f(t)$ for all $f$ in $V$.
:::

::: {.solution}

::: pf

::: pf-step

Let $g_t(x) = a_0 + a_1 x + a_2 x^2 + a_3 x^3$.

::: pf-proof

write $g_t$ in the monomial basis.

:::

:::

::: {.pf-step #s2}

The condition $(f \mid g_t) = f(t)$ for all $f \in V$ means $g_t$ is the reproducing kernel, i.e. $\int_0^1 f(x) g_t(x)\,dx = f(t)$ for all $f$.

::: pf-proof

definition.

:::

:::

::: {.pf-step #s3}

Taking $f = 1, x, x^2, x^3$ gives the system:
$$\int_0^1 g_t(x)\,dx = 1,\ \int_0^1 x g_t(x)\,dx = t,\ \int_0^1 x^2 g_t(x)\,dx = t^2,\ \int_0^1 x^3 g_t(x)\,dx = t^3.$$

::: pf-proof

Step [](#s2){.pf-ref} with $f = x^k$.

:::

:::

::: {.pf-step #s4}

$\int_0^1 x^k\,dx = \frac{1}{k+1}$, so the system is:
$$a_0 + \frac{a_1}{2} + \frac{a_2}{3} + \frac{a_3}{4} = 1,$$
$$\frac{a_0}{2} + \frac{a_1}{3} + \frac{a_2}{4} + \frac{a_3}{5} = t,$$
$$\frac{a_0}{3} + \frac{a_1}{4} + \frac{a_2}{5} + \frac{a_3}{6} = t^2,$$
$$\frac{a_0}{4} + \frac{a_1}{5} + \frac{a_2}{6} + \frac{a_3}{7} = t^3.$$

::: pf-proof

Step [](#s3){.pf-ref}, integrating term by term.

:::

:::

::: {.pf-step #s5}

The coefficient matrix is the $4 \times 4$ Hilbert matrix, which is invertible, so $g_t$ exists and is unique. Solving gives
$$
\begin{aligned}
a_0 &= 16 - 120t + 240t^2 - 140t^3,\\
a_1 &= -120 + 1200t - 2700t^2 + 1680t^3,\\
a_2 &= 240 - 2700t + 6480t^2 - 4200t^3,\\
a_3 &= -140 + 1680t - 4200t^2 + 2800t^3.
\end{aligned}
$$

::: pf-proof

Step [](#s4){.pf-ref}. The Hilbert matrix is the Gram matrix of the basis $1, x, x^2, x^3$, hence invertible.

:::

:::

::: {.pf-step #s6}

Equivalently, with the orthonormal basis $u_0 = 1$, $u_1 = \sqrt3(2x-1)$, $u_2 = \sqrt5(6x^2-6x+1)$, $u_3 = \sqrt7(20x^3-30x^2+12x-1)$ of $V$,
$$
g_t(x) = \sum_{k=0}^{3} u_k(t)\,u_k(x)
= 1 + 3(2t-1)(2x-1) + 5(6t^2-6t+1)(6x^2-6x+1) + 7(20t^3-30t^2+12t-1)(20x^3-30x^2+12x-1).
$$

::: pf-proof

For $f \in V$, $f = \sum_k (f \mid u_k) u_k$, so $f(t) = \sum_k (f \mid u_k) u_k(t) = \bigl(f \mid \sum_k u_k(t) u_k\bigr)$, since each $u_k(t)$ is real. Expanding the product form recovers the coefficients of step [](#s5){.pf-ref}.

:::

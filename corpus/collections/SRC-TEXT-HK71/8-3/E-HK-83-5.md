::: {.exercise}
Let $V$ be a finite-dimensional inner product space and $T$ a linear operator on $V$.
If $T$ is invertible, show that $T^*$ is invertible and $(T^*)^{-1} = (T^{-1})^*$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

$(T^{-1})^* T^* = (T T^{-1})^* = I^* = I$.

::: pf-proof

$(AB)^* = B^* A^*$, and $T T^{-1} = I$.

:::

:::

::: {.pf-step #s2}

$T^* (T^{-1})^* = (T^{-1} T)^* = I^* = I$.

::: pf-proof

$(AB)^* = B^* A^*$, and $T^{-1} T = I$.

:::

:::

::: {.pf-step #s3}

Hence $T^*$ is invertible with inverse $(T^{-1})^*$.

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} exhibit a two-sided inverse.

:::

::: {.exercise}
Let $V$ be a finite-dimensional inner product space and $T$ a linear operator on $V$.
If $T$ is invertible, show that $T^*$ is invertible and $(T^*)^{-1} = (T^{-1})^*$.
:::

::: {.solution}
<1>1. $(T^{-1})^* T^* = (T T^{-1})^* = I^* = I$.
::: {.proof}
$(AB)^* = B^* A^*$, and $T T^{-1} = I$.
:::

<1>2. $T^* (T^{-1})^* = (T^{-1} T)^* = I^* = I$.
::: {.proof}
$(AB)^* = B^* A^*$, and $T^{-1} T = I$.
:::

<1>3. Hence $T^*$ is invertible with inverse $(T^{-1})^*$.
::: {.proof}
<1>1 and <1>2 exhibit a two-sided inverse.
:::

<1>4. Q.E.D.
::: {.proof}
<1>3.
:::

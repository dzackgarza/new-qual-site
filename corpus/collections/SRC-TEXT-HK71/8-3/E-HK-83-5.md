::: {.exercise}
Let $V$ be a finite-dimensional inner product space and $T$ a linear operator on $V$.
If $T$ is invertible, show that $T^*$ is invertible and $(T^*)^{-1} = (T^{-1})^*$.
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §8.3 Exercise 5 on printed p. 297. The argument is the card's own.

::: pf

::: {.pf-step #s1}

$(T^{-1})^* T^* = (T T^{-1})^* = I^* = I$.

::: pf-proof

$(AB)^* = B^* A^*$, and $T T^{-1} = I$.

:::

:::

::: {.pf-step #s2}

$T^* (T^{-1})^* = (T^{-1} T)^* = I^* = I$.

::: pf-proof

$(AB)^* = B^* A^*$, and $T^{-1} T = I$.

:::

:::

::: {.pf-step #s3}

Hence $T^*$ is invertible with inverse $(T^{-1})^*$.

::: pf-proof

By definition $S=(T^{-1})^*$ is a two-sided inverse of $T^*$ when $S T^*=I$ and $T^* S=I$, and steps [](#s1){.pf-ref} and [](#s2){.pf-ref} give exactly these two identities; so $T^*$ is invertible and $(T^*)^{-1}=(T^{-1})^*$.

:::

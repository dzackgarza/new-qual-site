::: {.exercise}
Let
\[
C = \begin{bmatrix} C_{11} & C_{12} \\ C_{21} & C_{22} \end{bmatrix}
\]
be a $2 \times 2$ matrix.
We inquire when it is possible to find $2 \times 2$ matrices $A$ and $B$ such that $C = AB - BA$.
Prove that such matrices can be found if and only if $C_{11} + C_{22} = 0$.
:::

::: {.solution}

**($\Rightarrow$) Necessity of the trace-zero condition:**

::: pf

::: {.pf-step #necessity-trace-zero}
If $C = AB - BA$, then $C_{11} + C_{22} = 0$.

::: pf-proof

::: pf-step
The trace of any $2 \times 2$ matrix $M = \begin{bmatrix} M_{11} & M_{12} \\ M_{21} & M_{22} \end{bmatrix}$ is $\operatorname{Tr}(M) = M_{11} + M_{22}$.

::: pf-proof
definition of trace.
:::

:::

::: {.pf-step #trace-is-linear}
The trace is linear: $\operatorname{Tr}(AB - BA) = \operatorname{Tr}(AB) - \operatorname{Tr}(BA)$.

::: pf-proof
linearity of trace.
:::

:::

::: {.pf-step #trace-ab-eq-trace-ba}
For any two $2 \times 2$ matrices $A$ and $B$, $\operatorname{Tr}(AB) = \operatorname{Tr}(BA)$.

::: pf-proof
$\operatorname{Tr}(AB) = A_{11}B_{11} + A_{12}B_{21} + A_{21}B_{12} + A_{22}B_{22} = \operatorname{Tr}(BA)$.
:::

:::

::: pf-step
Hence $\operatorname{Tr}(C) = \operatorname{Tr}(AB) - \operatorname{Tr}(BA) = 0$, so $C_{11} + C_{22} = 0$.

::: pf-proof
Steps [](#trace-is-linear){.pf-ref} and [](#trace-ab-eq-trace-ba){.pf-ref}.
:::

:::

:::

:::

:::

**($\Leftarrow$) Sufficiency of the trace-zero condition:**

::: pf

::: {.pf-step #sufficiency-trace-zero}
If $C_{11} + C_{22} = 0$, then there exist $2 \times 2$ matrices $A$ and $B$ such that $C = AB - BA$.

::: pf-proof

::: pf-step
If $C = 0$, choose $A = B = 0$; then $AB - BA = 0 = C$.

::: pf-proof
$0 \cdot 0 - 0 \cdot 0 = 0$.
:::

:::

::: pf-step
Suppose $C \neq 0$ and $\operatorname{Tr}(C) = 0$.
Then $C$ is not a scalar multiple of the identity matrix $I$.

::: pf-proof
if $C = \lambda I$, then $\operatorname{Tr}(C) = 2\lambda = 0 \implies \lambda = 0 \implies C = 0$, contradicting $C \neq 0$.
:::

:::

::: pf-step
Since $C$ is not a scalar matrix, there exists a vector $v \in F^2$ such that $\{v, Cv\}$ is linearly independent.

::: pf-proof
if $Cv$ were parallel to $v$ for all $v$, $C$ would be a scalar matrix.
:::

:::

::: pf-step
With respect to the basis $\mathcal{B} = \{v, Cv\}$, the linear operator $C$ has matrix $C' = \begin{bmatrix} 0 & d \\ 1 & 0 \end{bmatrix}$ for some scalar $d$.

::: pf-proof
$C(v) = 0\cdot v + 1\cdot Cv$, and $\operatorname{Tr}(C) = 0 \implies 0 + C'_{22} = 0 \implies C'_{22} = 0$.
:::

:::

::: pf-step
The matrix $C'$ is a commutator of the matrices $A' = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}$ and $B' = \begin{bmatrix} 0 & d \\ -1 & 0 \end{bmatrix}$:
\[
A'B' - B'A' = \begin{bmatrix} 0 & d \\ 0 & 0 \end{bmatrix} - \begin{bmatrix} 0 & 0 \\ -1 & 0 \end{bmatrix} = \begin{bmatrix} 0 & d \\ 1 & 0 \end{bmatrix} = C'.
\]

::: pf-proof
direct matrix multiplication.
:::

:::

::: pf-step
Let $P$ be the invertible change-of-basis matrix such that $C = P C' P^{-1}$.

::: pf-proof
change of basis theorem for linear transformations.
:::

:::

::: pf-step
Setting $A = P A' P^{-1}$ and $B = P B' P^{-1}$:
\[
AB - BA = P(A'B' - B'A')P^{-1} = P C' P^{-1} = C.
\]

::: pf-proof
$P(XY - YX)P^{-1} = (PXP^{-1})(PYP^{-1}) - (PYP^{-1})(PXP^{-1})$ applied to $X = A', Y = B'$.
:::

:::

:::

:::

::: pf-qed
Conclusion: $2 \times 2$ matrices $A$ and $B$ exist with $C = AB - BA$ if and only if $C_{11} + C_{22} = 0$.

Steps [](#necessity-trace-zero){.pf-ref} and [](#sufficiency-trace-zero){.pf-ref}.
:::

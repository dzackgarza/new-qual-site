::: {.exercise}
For the linear operator $T$ of Exercise 3, prove that
$$
(T^2 - I)(T - 3I) = 0.
$$
:::

::: {.solution}
**Goal:** Show that the operator in Exercise 3 satisfies $(T^2-I)(T-3I)=0$.

::: pf

::: pf-step
Read $T$ from Exercise 3:
for $x=(x_1,x_2,x_3)\in\RR^3$,
$$T(x_1,x_2,x_3)=(3x_1,\;x_1-x_2,\;2x_1+x_2+x_3).$$
In matrix form on the standard basis,
$$M=\begin{pmatrix}3&0&0\\1&-1&0\\2&1&1\end{pmatrix}.$$
:::

::: pf-step
Compute $T^2$.

::: pf-proof

::: pf-step
A direct product gives
$$M^2=\begin{pmatrix}
9&0&0\\2&1&0\\9&0&1
\end{pmatrix},$$
so
$$T^2(x_1,x_2,x_3)=(9x_1,\;2x_1+x_2,\;9x_1+x_3).$$
:::

:::

:::

::: pf-step
Compute $T-3I$ and $T^2-I$.

::: pf-proof

::: pf-step
Since
$$M-3I=\begin{pmatrix}0&0&0\\1&-4&0\\2&1&-2\end{pmatrix},\quad
M^2-I=\begin{pmatrix}8&0&0\\2&0&0\\9&0&0\end{pmatrix},$$
every column of $M^2-I$ except the first is zero.
:::

:::

:::

::: pf-step
Multiply $(M^2-I)(M-3I)$.

::: pf-proof

::: pf-step
The second and third columns of $M^2-I$ are zero, so the $(i,j)$ entry of the product is $(M^2-I)_{i1}(M-3I)_{1j}$.
:::

::: pf-step
The first row of $M-3I$ is zero, so $(M-3I)_{1j}=0$ for every $j$, and every entry of the product is $0$. Hence $(M^2-I)(M-3I)=0$, and therefore
:::

::: pf-step
$(T^2-I)(T-3I)=0$.
:::

::: {.exercise}
For the linear operator $T$ of Exercise 3, prove that
$$
(T^2 - I)(T - 3I) = 0.
$$
:::

::: {.solution}
::: pf

::: pf-step
Read $T$ from Exercise 3:
for $x=(x_1,x_2,x_3)\in\RR^3$,
$$T(x_1,x_2,x_3)=(3x_1,\;x_1-x_2,\;2x_1+x_2+x_3).$$
In matrix form on the standard basis,
$$M=\begin{pmatrix}3&0&0\\1&-1&0\\2&1&1\end{pmatrix}.$$

::: pf-proof
This is the operator of Exercise 3, whose matrix on the standard basis is displayed.
:::

:::

::: pf-step
Compute $T^2$.

::: pf-proof

::: pf-step
A direct product gives
$$M^2=\begin{pmatrix}
9&0&0\\2&1&0\\9&0&1
\end{pmatrix},$$
so
$$T^2(x_1,x_2,x_3)=(9x_1,\;2x_1+x_2,\;9x_1+x_3).$$

::: pf-proof
Multiplying the matrix by itself: the rows of $M$ act on the columns, and the entries displayed are the resulting inner products.
:::

:::

:::

:::

::: pf-step
Compute $T-3I$ and $T^2-I$.

::: pf-proof

::: pf-step
Since
$$M-3I=\begin{pmatrix}0&0&0\\1&-4&0\\2&1&-2\end{pmatrix},\quad
M^2-I=\begin{pmatrix}8&0&0\\2&0&0\\9&0&0\end{pmatrix},$$
every column of $M^2-I$ except the first is zero.

::: pf-proof
Subtracting $3I$ and $I$ from the diagonal entries gives the two matrices, and in $M^2-I$ the second and third columns vanish.
:::

:::

:::

:::

::: pf-step
Multiply $(M^2-I)(M-3I)$.

::: pf-proof

::: pf-step
The second and third columns of $M^2-I$ are zero, so the $(i,j)$ entry of the product is $(M^2-I)_{i1}(M-3I)_{1j}$.

::: pf-proof
In a matrix product the $j$-th column is the combination of the columns of the first factor with the coefficients of the $j$-th column of the second, so only the first column of $M^2-I$ contributes.
:::

:::

::: pf-step
The first row of $M-3I$ is zero, so $(M-3I)_{1j}=0$ for every $j$, and every entry of the product is $0$. Hence $(M^2-I)(M-3I)=0$.

::: pf-proof
The one surviving term carries the factor $(M-3I)_{1j}$, which is $0$ because the first row of $M-3I$ vanishes.
:::

:::

::: pf-step
$(T^2-I)(T-3I)=0$.

::: pf-proof
The matrix of a composition is the product of the matrices, and the zero matrix represents the zero operator.
:::

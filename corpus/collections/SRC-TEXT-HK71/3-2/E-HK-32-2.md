::: {.exercise}
Let $T$ be the (unique) linear operator on $\CC^3$ for which
$$
T\epsilon_1 = (1, 0, i), \quad T\epsilon_2 = (0, 1, 1), \quad T\epsilon_3 = (i, 1, 0).
$$
Is $T$ invertible?
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, and the kernel vector and determinant below were recomputed for this pass.

::: pf

::: {.pf-step #matrix}
Relative to the standard ordered basis the operator $T$ has matrix $A=\begin{bmatrix}1&0&i\\0&1&1\\i&1&0\end{bmatrix}$.

::: pf-proof
The $j$-th column of the matrix of $T$ relative to the standard basis is the coordinate matrix of $T\epsilon_{j}$. By hypothesis $T\epsilon_{1}=(1,0,i)$, $T\epsilon_{2}=(0,1,1)$ and $T\epsilon_{3}=(i,1,0)$, so the three columns are those vectors.
:::

:::

::: {.pf-step #kernel}
The nonzero vector $X=\begin{bmatrix}-i\\-1\\1\end{bmatrix}$ satisfies $AX=0$.

::: pf-proof
Compute the three entries of $AX$ from the matrix of step [](#matrix){.pf-ref}: the first is $1\cdot(-i)+0\cdot(-1)+i\cdot1=-i+i=0$; the second is $0\cdot(-i)+1\cdot(-1)+1\cdot1=-1+1=0$; the third is $i\cdot(-i)+1\cdot(-1)+0\cdot1=1-1=0$. So $AX=0$ while $X\ne0$.
:::

:::

::: {.pf-step}
$T$ is not invertible.

::: pf-proof
By step [](#kernel){.pf-ref} the matrix $A$ annihilates a nonzero vector, so the homogeneous system $AX=0$ has a nontrivial solution and $A$ is singular; the null space of $T$ therefore contains the nonzero vector whose coordinate matrix is $X$, so $T$ is not injective. A non-injective operator on a finite-dimensional space is not invertible. Equivalently, expanding the determinant of $A$ along the first row gives $\det A=1\cdot(0-1)-0+i\cdot(0-i)=-1+1=0$, so $A$ is singular. Hence the answer to the question is no, $T$ is not invertible.
:::

::: {.exercise}
Let $V$ be a vector space over the field $F$ and $T$ a linear operator on $V$.
If $T^2 = 0$, what can you say about the relation of the range of $T$ to the null space of $T$?
Give an example of a linear operator $T$ on $\RR^2$ such that $T^2 = 0$ but $T \neq 0$.
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §3.2 Exercise 8.

::: pf

::: {.pf-step #inclusion}
If $T^2=0$ then $\operatorname{range}T\subseteq\ker T$.

:::: pf-proof

::: {.pf-step #element}
Every element of $\operatorname{range}T$ is $T\alpha$ for some $\alpha\in V$.

::: pf-proof
This is the definition of the range.
:::

:::

::: {.pf-step #killed}
$T(T\alpha)=0$ for every $\alpha\in V$.

::: pf-proof
$T(T\alpha)=T^2\alpha=0$ by hypothesis.
:::

:::

::: {.pf-step}
$\operatorname{range}T\subseteq\ker T$.

::: pf-proof
An element $T\alpha$ of the range is annihilated by $T$ by step [](#killed){.pf-ref}, which is exactly the condition for membership in $\ker T$.
:::

:::

:::

:::

::: {.pf-step #example}
$T(x,y)=(y,0)$ on $\RR^2$ satisfies $T\ne0$ and $T^2=0$.

::: pf-proof
$T$ is linear, being given by the matrix $\begin{bmatrix}0&1\\0&0\end{bmatrix}$. It is nonzero because $T(0,1)=(1,0)\ne(0,0)$. And $T^2(x,y)=T(y,0)=(0,0)$ for every $(x,y)$.
:::

:::

::: {.pf-step}
$T^2=0$ forces $\operatorname{range}T\subseteq\ker T$, and the inclusion can be strict.

::: pf-proof
The inclusion is step [](#inclusion){.pf-ref}. For the example of step [](#example){.pf-ref} it is an equality, since $\operatorname{range}T=\ker T=\{(t,0):t\in\RR\}$; on $\RR^3$ the operator $U(x,y,z)=(y,0,0)$ satisfies $U^2=0$ with $\operatorname{range}U=\{(t,0,0)\}\subsetneq\ker U=\{(x,0,z)\}$, so the inclusion need not be an equality. Hence the relation the exercise asks for is
$$
\boxed{T^2=0\implies\operatorname{range}T\subseteq\ker T,}
$$
with the example $T(x,y)=(y,0)$ on $\RR^2$ satisfying $T^2=0$ and $T\neq0$.
:::

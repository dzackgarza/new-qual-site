::: {.exercise}
Let $T$ be a linear transformation from $\RR^3$ into $\RR^2$, and let $U$ be a linear transformation from $\RR^2$ into $\RR^3$.
Prove that the transformation $UT$ is not invertible.
Generalize the theorem.
:::

::: {.solution}

The argument is the card's own: the rank of a composite is at most the rank of either factor, and an operator on a space of dimension $n$ is invertible only at rank $n$.

::: pf

::: {.pf-step #range}

$\operatorname{range}(UT)=U(\operatorname{range}T)$, so $\operatorname{rank}(UT)\le\operatorname{rank}(T)$.

::: pf-proof

$UT$ means first $T$, then $U$. An element of $\operatorname{range}(UT)$ is $(UT)(v)=U(Tv)$ for some $v\in V$, that is the image under $U$ of the element $Tv\in\operatorname{range}T$; conversely every $U(Tv)$ arises this way. Hence $\operatorname{range}(UT)=U(\operatorname{range}T)$. A linear image of a subspace has dimension at most that of the subspace, so $\dim\operatorname{range}(UT)\le\dim\operatorname{range}T$, which is the asserted rank inequality.

:::

:::

::: {.pf-step #bound}

For $T:\RR^{3}\to\RR^{2}$ one has $\operatorname{rank}T\le2$.

::: pf-proof

$\operatorname{range}T$ is a subspace of $\RR^{2}$, of dimension $2$, so $\dim\operatorname{range}T\le2$; and $T$ is defined on $\RR^{3}$, so by rank-nullity $\operatorname{rank}T\le3$ as well. The binding bound is $2$.

:::

:::

::: {.pf-step #notinvertible}

$UT$ is not invertible.

::: pf-proof

$UT$ is a linear transformation from $\RR^{3}$ into $\RR^{3}$, a composite of two linear maps. By steps [](#range){.pf-ref} and [](#bound){.pf-ref},
$$
\operatorname{rank}(UT)\le\operatorname{rank}T\le2<3=\dim\RR^{3}.
$$
A linear operator on a finite-dimensional space is invertible exactly when its rank equals the dimension of the space, since then it is injective by rank-nullity and an injective operator on a finite-dimensional space is surjective. So
$$
\boxed{\operatorname{rank}(UT)\le2<3,\ \text{hence } UT \text{ is not invertible.}}
$$

:::

:::

::: {.pf-step #general}

If $V,W$ are finite-dimensional over $F$ with $\dim W<\dim V$, and $T:V\to W$, $U:W\to V$ are linear, then $UT$ is not invertible.

::: pf-proof

The same two estimates apply with $2$ and $3$ replaced by $\dim W$ and $\dim V$: step [](#range){.pf-ref} gives $\operatorname{rank}(UT)\le\operatorname{rank}T\le\dim W$, using that $\operatorname{range}T\le W$. Since $\dim W<\dim V$, the composite $UT$, an operator on $V$, has rank strictly below $\dim V$ and so is not invertible. The argument uses only finite dimensionality, so it holds over any field; when $\dim W\ge\dim V$ the conclusion can fail, as the identity of $V$ shows with $W=V$.

:::

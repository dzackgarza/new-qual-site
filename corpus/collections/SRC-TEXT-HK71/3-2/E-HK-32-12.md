::: {.exercise}
Let $p$, $m$, and $n$ be positive integers and $F$ a field.
Let $V$ be the space of $m \times n$ matrices over $F$ and $W$ the space of $p \times n$ matrices over $F$.
Let $B$ be a fixed $p \times m$ matrix and let $T$ be the linear transformation from $V$ into $W$ defined by $T(A) = BA$.
Prove that $T$ is invertible if and only if $p = m$ and $B$ is an invertible $m \times m$ matrix.
:::

::: {.solution}
<1>1. $(\Leftarrow)$ If $p = m$ and $B$ is an invertible $m \times m$ matrix, then $T$ is invertible: <2>1. Since $B$ is invertible, there exists $B^{-1} \in M_m(F)$ such that $B^{-1} B = B B^{-1} = I_m$.
::: {.proof}
definition of an invertible matrix.
:::
<2>2. Define the linear map $S: W \to V$ by $S(C) = B^{-1} C$.
::: {.proof}
matrix multiplication is linear.
:::
<2>3. For any $A \in V = M_{m \times n}(F)$:
\[
S(T(A)) = S(BA) = B^{-1}(BA) = (B^{-1} B) A = I_m A = A.
\]
::: {.proof}
associativity of matrix multiplication.
:::
<2>4. For any $C \in W = M_{m \times n}(F)$:
\[
T(S(C)) = T(B^{-1} C) = B(B^{-1} C) = (B B^{-1}) C = I_m C = C.
\]
::: {.proof}
associativity of matrix multiplication.
:::
<2>5. Thus $S = T^{-1}$, so $T$ is an invertible linear transformation.
::: {.proof}
<2>3 and <2>4.
:::

<1>2. $(\Rightarrow)$ If $T$ is invertible, then $p = m$: <2>1. The vector spaces have dimensions $\dim_F V = mn$ and $\dim_F W = pn$.
::: {.proof}
dimension of matrix spaces over a field.
:::
<2>2. An invertible linear map between finite-dimensional vector spaces requires $\dim V = \dim W$.
::: {.proof}
isomorphism preserves dimension.
:::
<2>3. Thus $mn = pn$.
Since $n \ge 1$, dividing by $n$ yields $p = m$.
::: {.proof}
cancellation in $\mathbb{Z}$.
:::

<1>3. $(\Rightarrow)$ If $T$ is invertible, then $B$ is an invertible $m \times m$ matrix: <2>1. From <1>2, $p = m$, so $B$ is a square $m \times m$ matrix.
::: {.proof}
<1>2. <2>2. Let $v \in F^m$ be any vector such that $B v = 0$.
:::
::: {.proof}
setup for injecting nullspace of $B$.
:::
<2>3. Construct the matrix $A \in M_{m \times n}(F) = V$ whose first column is $v$ and whose remaining columns are all $0$.
::: {.proof}
matrix construction.
:::
<2>4. Compute $T(A) = BA$: The columns of $BA$ are $B$ applied to the columns of $A$, so $\operatorname{col}_1(BA) = Bv = 0$ and $\operatorname{col}_j(BA) = B(0) = 0$ for $j \ge 2$.
Thus $T(A) = 0$.
::: {.proof}
column-by-column matrix multiplication.
:::
<2>5. Since $T$ is invertible, it is injective, so $T(A) = 0 \implies A = 0$.
::: {.proof}
injectivity of $T$.
:::
<2>6. In particular, the first column $v$ of $A$ is $0$, so $\ker(B) = \{0\}$.
::: {.proof}
$A = 0 \implies \operatorname{col}_1(A) = 0$.
:::
<2>7. For a square matrix over a field, having trivial kernel is equivalent to invertibility.
Thus $B$ is invertible.
::: {.proof}
Rank–Nullity Theorem for square matrices.
:::

<1>4. Conclusion: $T$ is invertible if and only if $p = m$ and $B$ is an invertible $m \times m$ matrix.
::: {.proof}
<1>1, <1>2, and <1>3.
:::
Q.E.D.
:::

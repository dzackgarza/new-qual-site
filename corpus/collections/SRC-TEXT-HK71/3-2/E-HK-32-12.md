::: {.exercise}
Let $p$, $m$, and $n$ be positive integers and $F$ a field.
Let $V$ be the space of $m \times n$ matrices over $F$ and $W$ the space of $p \times n$ matrices over $F$.
Let $B$ be a fixed $p \times m$ matrix and let $T$ be the linear transformation from $V$ into $W$ defined by $T(A) = BA$.
Prove that $T$ is invertible if and only if $p = m$ and $B$ is an invertible $m \times m$ matrix.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
$(\Leftarrow)$ If $p=m$ and $B$ is an invertible $m\times m$ matrix, then $T$ is invertible.

::: pf-proof

::: {.pf-step #s1-2}
$B$ has a two-sided inverse $B^{-1}$, and then $W=M_{m\times n}(F)$.

::: pf-proof
A square matrix $B$ is invertible when there is a matrix $C$ with $CB=BC=I_m$; such a $C$ is written $B^{-1}$. With $p=m$ the space $W$ of $p\times n$ matrices is the space of $m\times n$ matrices, so $W=V$.
:::

:::

::: {.pf-step #s1-3}
$S:W\to V$, $S(C)=B^{-1}C$, is a well-defined linear map.

::: pf-proof
For $C\in W$ the product $B^{-1}C$ is an $m\times n$ matrix, so $S$ takes values in $V$. For $C,C'\in W$ and $\lambda\in F$, distributivity of matrix multiplication over addition and the commutativity of scalars with matrix products give $S(C+\lambda C')=B^{-1}(C+\lambda C')=B^{-1}C+\lambda B^{-1}C'=S(C)+\lambda S(C')$, which is linearity.
:::

:::

::: {.pf-step #s1-4}
$S(T(A))=A$ for every $A\in V$, and $T(S(C))=C$ for every $C\in W$.

::: pf-proof
Associativity of matrix multiplication gives $B^{-1}(BA)=(B^{-1}B)A$; with $B^{-1}B=I_m$ and $I_mA=A$ this is $S(T(A))=A$. Likewise $B(B^{-1}C)=(BB^{-1})C$; with $BB^{-1}=I_m$ and $I_mC=C$ this is $T(S(C))=C$.
:::

:::

::: {.pf-step #s1-5}
$S=T^{-1}$, so $T$ is invertible.

::: pf-proof
Step [](#s1-4){.pf-ref} says that $S$ composed with $T$ on either side is the identity, which is what it means for $S$ to be the inverse of $T$; a map with a two-sided inverse is invertible.
:::

:::

:::

:::

::: {.pf-step #s2}
$(\Rightarrow)$ If $T$ is invertible, then $p=m$.

::: pf-proof

::: {.pf-step #s2-1}
$\dim_F V=mn$ and $\dim_F W=pn$.

::: pf-proof
For each pair $(i,j)$ let $E_{ij}\in V$ have entry $1$ in position $(i,j)$ and $0$ elsewhere. Every $A\in V$ equals $\sum_{i,j}A(i,j)E_{ij}$, since the $(r,s)$ entry of that sum is $A(r,s)$; and if $\sum_{i,j}c_{ij}E_{ij}=0$ then reading the $(r,s)$ entry gives $c_{rs}=0$. So the $mn$ elementary matrices form a basis of $V$, and $\dim_F V=mn$; the same argument in $W$ counts the $pn$ pairs $(i,j)$ with $1\le i\le p$.
:::

:::

::: {.pf-step #s2-2}
An invertible linear map carries a basis of $V$ to a basis of $W$, so $\dim V=\dim W$ whenever such a map exists.

::: pf-proof
Let $T$ be invertible with inverse $S$, and let $v_1,\dots,v_k$ be a basis of $V$. The images $T(v_1),\dots,T(v_k)$ span $W$: for $w\in W$ the vector $S(w)$ is a combination $\sum\lambda_i v_i$, and applying $T$ gives $w=T(S(w))=\sum\lambda_iT(v_i)$, by linearity. They are independent: if $\sum\lambda_iT(v_i)=0$ then $\sum\lambda_iv_i=S(0)=0$, so every $\lambda_i=0$. Hence they form a basis of $W$ with $k$ members, and any two bases of a finite-dimensional space have the same number of members.
:::

:::

::: {.pf-step #s2-3}
$mn=pn$, and therefore $p=m$.

::: pf-proof
Steps [](#s2-1){.pf-ref} and [](#s2-2){.pf-ref} give $mn=\dim V=\dim W=pn$. The integer $n$ is positive, so cancellation in $\ZZ$ gives $p=m$.
:::

:::

:::

:::

::: {.pf-step #s3}
$(\Rightarrow)$ If $T$ is invertible, then $B$ is an invertible $m\times m$ matrix.

::: pf-proof

::: {.pf-step #s3-1}
$p=m$ by step [](#s2){.pf-ref}, so $B$ is a square $m\times m$ matrix.

::: pf-proof
$B$ is given as a $p\times m$ matrix, and $p=m$.
:::

:::

::: {.pf-step #s3-2}
If $v\in F^m$ satisfies $Bv=0$, then $v=0$.

::: pf-proof
Let $A\in V$ be the matrix whose first column is $v$ and whose other columns are $0$. Matrix multiplication acts column by column, $(BA)_j=B(A_j)$ for the $j$th column, so $(BA)_1=Bv=0$ and $(BA)_j=B0=0$ for $j\ge2$; hence $T(A)=BA=0$. An invertible map is injective, being a bijection, so $T(A)=0$ forces $A=0$; the first column of the zero matrix is $0$, so $v=0$.
:::

:::

::: {.pf-step #s3-3}
A square matrix over a field whose kernel is ${0}$ is invertible.

::: pf-proof
Let $C$ be $m\times m$ with kernel ${0}$ and let $\mu:F^m\to F^m$ be $x\mapsto Cx$, a linear map. The rank-nullity theorem gives $\operatorname{rank}C=m-\dim\ker C=m$, so the columns of $C$ are $m$ independent vectors of the $m$-dimensional space $F^m$ and therefore form a basis. Every $y\in F^m$ is then $\mu(x)$ for some $x$, by linearity and the spanning property of a basis, so $\mu$ is bijective; a bijective linear map of $F^m$ has a linear inverse, and that inverse is given by a matrix $D$ with $CD=DC=I_m$, so $C$ is invertible.
:::

:::

::: {.pf-step #s3-4}
$B$ is invertible.

::: pf-proof
Step [](#s3-1){.pf-ref} makes $B$ square, step [](#s3-2){.pf-ref} gives that its kernel is ${0}$, and step [](#s3-3){.pf-ref} then makes it invertible.
:::

:::

:::

:::

::: {.pf-step #s4}
$T$ is invertible if and only if $p=m$ and $B$ is an invertible $m\times m$ matrix.

::: pf-proof
The implication from right to left is step [](#s1){.pf-ref}; from left to right, step [](#s2){.pf-ref} gives $p=m$ and step [](#s3){.pf-ref} then gives that $B$ is invertible.
:::

:::

::: pf-qed
Steps [](#s1){.pf-ref} to [](#s4){.pf-ref} prove both directions of the equivalence.
:::

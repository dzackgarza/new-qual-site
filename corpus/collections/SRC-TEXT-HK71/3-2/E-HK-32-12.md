::: {.exercise}
Let $p$, $m$, and $n$ be positive integers and $F$ a field.
Let $V$ be the space of $m \times n$ matrices over $F$ and $W$ the space of $p \times n$ matrices over $F$.
Let $B$ be a fixed $p \times m$ matrix and let $T$ be the linear transformation from $V$ into $W$ defined by $T(A) = BA$.
Prove that $T$ is invertible if and only if $p = m$ and $B$ is an invertible $m \times m$ matrix.
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
$(\Leftarrow)$ If $p = m$ and $B$ is an invertible $m \times m$ matrix, then $T$ is invertible:

::: pf-proof

::: pf-step
Since $B$ is invertible, there exists $B^{-1} \in M_m(F)$ such that $B^{-1} B = B B^{-1} = I_m$.

::: pf-proof
definition of an invertible matrix.
:::

:::

::: pf-step
Define the linear map $S: W \to V$ by $S(C) = B^{-1} C$.

::: pf-proof
matrix multiplication is linear.
:::

:::

::: {.pf-step #s1-3}
For any $A \in V = M_{m \times n}(F)$:
\[
S(T(A)) = S(BA) = B^{-1}(BA) = (B^{-1} B) A = I_m A = A.
\]

::: pf-proof
associativity of matrix multiplication.
:::

:::

::: {.pf-step #s1-4}
For any $C \in W = M_{m \times n}(F)$:
\[
T(S(C)) = T(B^{-1} C) = B(B^{-1} C) = (B B^{-1}) C = I_m C = C.
\]

::: pf-proof
associativity of matrix multiplication.
:::

:::

::: pf-step
Thus $S = T^{-1}$, so $T$ is an invertible linear transformation.

::: pf-proof
steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s2}
$(\Rightarrow)$ If $T$ is invertible, then $p = m$:

::: pf-proof

::: pf-step
The vector spaces have dimensions $\dim_F V = mn$ and $\dim_F W = pn$.

::: pf-proof
dimension of matrix spaces over a field.
:::

:::

::: pf-step
An invertible linear map between finite-dimensional vector spaces requires $\dim V = \dim W$.

::: pf-proof
isomorphism preserves dimension.
:::

:::

::: pf-step
Thus $mn = pn$.
Since $n \ge 1$, dividing by $n$ yields $p = m$.

::: pf-proof
cancellation in $\mathbb{Z}$.
:::

:::

:::

:::

::: {.pf-step #s3}
$(\Rightarrow)$ If $T$ is invertible, then $B$ is an invertible $m \times m$ matrix:

::: pf-proof

::: pf-step
From step [](#s2){.pf-ref}, $p = m$, so $B$ is a square $m \times m$ matrix.

::: pf-proof
step [](#s2){.pf-ref}.
:::

:::

::: pf-step
Let $v \in F^m$ be any vector such that $B v = 0$.

::: pf-proof
setup for injecting nullspace of $B$.
:::

:::

::: pf-step
Construct the matrix $A \in M_{m \times n}(F) = V$ whose first column is $v$ and whose remaining columns are all $0$.

::: pf-proof
matrix construction.
:::

:::

::: pf-step
Compute $T(A) = BA$: The columns of $BA$ are $B$ applied to the columns of $A$, so $\operatorname{col}_1(BA) = Bv = 0$ and $\operatorname{col}_j(BA) = B(0) = 0$ for $j \ge 2$.
Thus $T(A) = 0$.

::: pf-proof
column-by-column matrix multiplication.
:::

:::

::: pf-step
Since $T$ is invertible, it is injective, so $T(A) = 0 \implies A = 0$.

::: pf-proof
injectivity of $T$.
:::

:::

::: pf-step
In particular, the first column $v$ of $A$ is $0$, so $\ker(B) = \{0\}$.

::: pf-proof
$A = 0 \implies \operatorname{col}_1(A) = 0$.
:::

:::

::: pf-step
For a square matrix over a field, having trivial kernel is equivalent to invertibility.
Thus $B$ is invertible.

::: pf-proof
Rank–Nullity Theorem for square matrices.
:::

:::

:::

:::

::: pf-step
Conclusion: $T$ is invertible if and only if $p = m$ and $B$ is an invertible $m \times m$ matrix.

::: pf-proof
steps [](#s1){.pf-ref}, [](#s2){.pf-ref}, and [](#s3){.pf-ref}.
:::

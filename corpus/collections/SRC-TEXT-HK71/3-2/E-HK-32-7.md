::: {.exercise}
Find two linear operators $T$ and $U$ on $\RR^2$ such that $TU = 0$ but $UT \neq 0$.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no published solution set for it is retained in `tmp/sources`, so nothing below is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §3.2 Exercise 7. The operators are specified by their values on all of $\RR^2$.

::: pf

::: {.pf-step #lin}

$T(x,y)\coloneqq(x,0)$ and $U(x,y)\coloneqq(0,x)$ are linear operators on $\RR^2$.

::: pf-proof

Each is given by linear formulas in $x$ and $y$ with no constant term, hence is linear, and each takes its values in $\RR^2$.

:::

:::

::: {.pf-step #tu}

$TU=0$.

::: pf-proof

For every $(x,y)$, $U(x,y)=(0,x)$ and then $T(0,x)=(0,0)$; an operator vanishing everywhere is the zero operator.

:::

:::

::: {.pf-step #ut}

$UT\neq0$.

::: pf-proof

For every $(x,y)$, $UT(x,y)=U(x,0)=(0,x)$, and $UT(1,0)=(0,1)\neq(0,0)$; so $UT$ is not the zero operator.

:::

:::

::: {.pf-step #done}

$T$ and $U$ satisfy $TU=0$ and $UT\neq0$.

::: pf-proof

:::

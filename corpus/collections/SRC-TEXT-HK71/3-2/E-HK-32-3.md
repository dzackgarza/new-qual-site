::: {.exercise}
Let $T$ be the linear operator on $\RR^3$ defined by
\[
T(x_1, x_2, x_3) = (3x_1,\; x_1 - x_2,\; 2x_1 + x_2 + x_3).
\]
Is $T$ invertible?
If so, find a rule for $T^{-1}$ like the one which defines $T$.
:::

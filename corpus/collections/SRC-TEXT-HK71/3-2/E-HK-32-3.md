::: {.exercise}
Let $T$ be the linear operator on $\RR^3$ defined by
$$
T(x_1, x_2, x_3) = (3x_1,\; x_1 - x_2,\; 2x_1 + x_2 + x_3).
$$
Is $T$ invertible?
If so, find a rule for $T^{-1}$ like the one which defines $T$.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no solution set for it is retained in `tmp/sources`, so nothing here is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §3.2 Exercise 3.

Let $T\colon\RR^{3}\to\RR^{3}$ be given by $T(x_{1},x_{2},x_{3})=(3x_{1},\,x_{1}-x_{2},\,2x_{1}+x_{2}+x_{3})$, and define
$$
S(y_{1},y_{2},y_{3})=\Bigl(\tfrac{y_{1}}{3},\ \tfrac{y_{1}}{3}-y_{2},\ -y_{1}+y_{2}+y_{3}\Bigr).
$$

::: pf

::: {.pf-step #system}
$T(x_{1},x_{2},x_{3})=(y_{1},y_{2},y_{3})$ is equivalent to the system
$$
y_{1}=3x_{1},\qquad y_{2}=x_{1}-x_{2},\qquad y_{3}=2x_{1}+x_{2}+x_{3}.
$$

::: pf-proof
This is the definition of $T$ written coordinate by coordinate; $T$ is linear because each coordinate is a linear function of $(x_{1},x_{2},x_{3})$.
:::

:::

::: {.pf-step #unique}
For every $y\in\RR^{3}$ the system of step [](#system){.pf-ref} has at most one solution, namely $S(y)$.

::: pf-proof
The first equation forces $x_{1}=y_{1}/3$. Substituting into the second gives $x_{2}=x_{1}-y_{2}=\tfrac{y_{1}}{3}-y_{2}$. Substituting both into the third gives $x_{3}=y_{3}-2x_{1}-x_{2}=y_{3}-\tfrac{2y_{1}}{3}-\bigl(\tfrac{y_{1}}{3}-y_{2}\bigr)=y_{3}-y_{1}+y_{2}$, that is $x_{3}=-y_{1}+y_{2}+y_{3}$. Each coordinate is thus determined, so the solution, when it exists, is $S(y)$.
:::

:::

::: {.pf-step #right-inverse}
$T\bigl(S(y)\bigr)=y$ for every $y\in\RR^{3}$, so $T\circ S=I$.

::: pf-proof
Put $x=S(y)$, that is $x_{1}=y_{1}/3$, $x_{2}=y_{1}/3-y_{2}$, $x_{3}=-y_{1}+y_{2}+y_{3}$. Then the first coordinate of $T(x)$ is $3x_{1}=y_{1}$; the second is $x_{1}-x_{2}=\tfrac{y_{1}}{3}-\bigl(\tfrac{y_{1}}{3}-y_{2}\bigr)=y_{2}$; the third is $2x_{1}+x_{2}+x_{3}=\tfrac{2y_{1}}{3}+\tfrac{y_{1}}{3}-y_{2}-y_{1}+y_{2}+y_{3}=y_{3}$. Hence $T(x)=y$.
:::

:::

::: {.pf-step #left-inverse}
$S\bigl(T(x)\bigr)=x$ for every $x\in\RR^{3}$, so $S\circ T=I$.

::: pf-proof
Put $y=T(x)$, so $y_{1}=3x_{1}$, $y_{2}=x_{1}-x_{2}$, $y_{3}=2x_{1}+x_{2}+x_{3}$. The first coordinate of $S(y)$ is $y_{1}/3=x_{1}$; the second is $\tfrac{y_{1}}{3}-y_{2}=x_{1}-(x_{1}-x_{2})=x_{2}$; the third is $-y_{1}+y_{2}+y_{3}=-3x_{1}+(x_{1}-x_{2})+(2x_{1}+x_{2}+x_{3})=x_{3}$.
:::

:::

::: {.pf-step}
$T$ is invertible and $T^{-1}=S$.

::: pf-proof
Steps [](#right-inverse){.pf-ref} and [](#left-inverse){.pf-ref} exhibit a two-sided inverse $S$ of the linear operator $T$, which is therefore invertible, with a unique inverse equal to $S$. The rule asked for is $T^{-1}(y_{1},y_{2},y_{3})=\bigl(\tfrac{y_{1}}{3},\tfrac{y_{1}}{3}-y_{2},-y_{1}+y_{2}+y_{3}\bigr)$.
:::

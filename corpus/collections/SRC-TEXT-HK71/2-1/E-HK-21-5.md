::: {.exercise}
On $\RR^n$, define two operations
$$
\alpha \oplus \beta = \alpha - \beta, \qquad c \cdot \alpha = -c\alpha.
$$
The operations on the right are the usual ones.
Which of the axioms for a vector space are satisfied by $(\RR^n, \oplus, \cdot)$?
:::


::: {.solution}
Number the axioms as in the definition of a vector space [@HK71]: (3a)–(3d) for addition and (4a)–(4d) for scalar multiplication. For $n\ge1$, exactly (3c), (3d) and (4c) hold.

- (3a) fails: $\alpha\oplus\beta=\alpha-\beta$ and $\beta\oplus\alpha=\beta-\alpha$ differ whenever $\alpha\ne\beta$.
- (3b) fails: $(\alpha\oplus\beta)\oplus\gamma=\alpha-\beta-\gamma$, while $\alpha\oplus(\beta\oplus\gamma)=\alpha-\beta+\gamma$; these differ whenever $\gamma\ne0$.
- (3c) holds: $\alpha\oplus z=\alpha$ for all $\alpha$ if and only if $z=0$, so $0$ is the unique vector with $\alpha\oplus0=\alpha$.
- (3d) holds: $\alpha\oplus\beta=0$ if and only if $\beta=\alpha$, so the unique vector $\beta$ with $\alpha\oplus\beta=0$ is $\alpha$ itself.
- (4a) fails: $1\cdot\alpha=-\alpha\ne\alpha$ for $\alpha\ne0$.
- (4b) fails: $(c_1c_2)\cdot\alpha=-c_1c_2\alpha$, while $c_1\cdot(c_2\cdot\alpha)=c_1c_2\alpha$; these differ whenever $c_1c_2\alpha\ne0$.
- (4c) holds: $c\cdot(\alpha\oplus\beta)=-c\alpha+c\beta=(-c\alpha)-(-c\beta)=(c\cdot\alpha)\oplus(c\cdot\beta)$.
- (4d) fails: $(c_1+c_2)\cdot\alpha=-c_1\alpha-c_2\alpha$, while $(c_1\cdot\alpha)\oplus(c_2\cdot\alpha)=-c_1\alpha+c_2\alpha$; these differ whenever $c_2\ne0$ and $\alpha\ne0$.

In particular $(\RR^n,\oplus,\cdot)$ is not a vector space.
:::

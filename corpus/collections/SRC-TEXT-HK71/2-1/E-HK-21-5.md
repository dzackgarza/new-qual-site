::: {.exercise}
On $\RR^n$, define two operations
$$
\alpha \oplus \beta = \alpha - \beta, \qquad c \cdot \alpha = -c\alpha.
$$
The operations on the right are the usual ones.
Which of the axioms for a vector space are satisfied by $(\RR^n, \oplus, \cdot)$?

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §2.1 Exercise 5 on printed p. 34, so the exercise's number and statement are both citable; the argument below is the card's own, checked against the vector-space axioms as the card states them.

Throughout, $V=\RR^{n}$ with $n\ge1$, the operations $\alpha\oplus\beta=\alpha-\beta$ and $c\cdot\alpha=-c\alpha$ being defined by the usual subtraction and scalar multiplication of $\RR^{n}$. The axioms are numbered as in the definition of a vector space [@HK71]: (3a) commutativity of addition, (3b) associativity of addition, (3c) existence of a zero vector $z$ with $\alpha\oplus z=\alpha$ for all $\alpha$, (3d) existence, for each $\alpha$, of a $\beta$ with $\alpha\oplus\beta=0$, (4a) $1\cdot\alpha=\alpha$, (4b) $(c_1c_2)\cdot\alpha=c_1\cdot(c_2\cdot\alpha)$, (4c) $c\cdot(\alpha\oplus\beta)=c\cdot\alpha\oplus c\cdot\beta$, (4d) $(c_1+c_2)\cdot\alpha=c_1\cdot\alpha\oplus c_2\cdot\alpha$.

::: pf

::: {.pf-step #three-fail}
(3a), (3b), (4a), (4b) and (4d) fail.

::: pf-proof
(3a): $\alpha\oplus\beta=\alpha-\beta$ and $\beta\oplus\alpha=\beta-\alpha$ differ whenever $\alpha\neq\beta$, and such a pair exists since $n\ge1$.
(3b): $(\alpha\oplus\beta)\oplus\gamma=(\alpha-\beta)-\gamma=\alpha-\beta-\gamma$, while $\alpha\oplus(\beta\oplus\gamma)=\alpha-(\beta-\gamma)=\alpha-\beta+\gamma$; these differ whenever $\gamma\neq0$.
(4a): $1\cdot\alpha=-\alpha$, which differs from $\alpha$ whenever $\alpha\neq0$.
(4b): $(c_1c_2)\cdot\alpha=-c_1c_2\alpha$, while $c_1\cdot(c_2\cdot\alpha)=c_1\cdot(-c_2\alpha)=-c_1(-c_2\alpha)=c_1c_2\alpha$; these differ whenever $c_1c_2\alpha\neq0$, for instance for $c_1=c_2=1$ and $\alpha\neq0$.
(4d): $(c_1+c_2)\cdot\alpha=-c_1\alpha-c_2\alpha$, while $c_1\cdot\alpha\oplus c_2\cdot\alpha=-c_1\alpha+c_2\alpha$; these differ whenever $c_2\neq0$ and $\alpha\neq0$.
Each failure is exhibited by an element of $V$, which is nonempty, so each axiom fails for the structure.

:::

:::

::: {.pf-step #zero}
(3c) holds, with the zero vector $0$ of $\RR^n$, and it is the only vector with the required property.

::: pf-proof
For every $\alpha$ we have $\alpha\oplus0=\alpha-0=\alpha$, so a $z$ with the property exists, namely $z=0$. If also $\alpha\oplus z'=\alpha$ for every $\alpha$, then taking $\alpha=0$ gives $0-z'=0$, that is $z'=0$. So $0$ is unique.

:::

:::

::: {.pf-step #negatives}
(3d) holds, and the $\beta$ with $\alpha\oplus\beta=0$ is $\beta=\alpha$, uniquely.

::: pf-proof
$\alpha\oplus\beta=0$ says $\alpha-\beta=0$, that is $\beta=\alpha$. So for each $\alpha$ the vector $\beta=\alpha$ satisfies the axiom, and it is the only one, since $\alpha-\beta=0$ forces $\beta=\alpha$.

:::

:::

::: {.pf-step #distributive}
(4c) holds.

::: pf-proof
For scalars $c$ and vectors $\alpha,\beta$,
$$
c\cdot(\alpha\oplus\beta)=-c(\alpha-\beta)=-c\alpha+c\beta=(-c\alpha)-(-c\beta)=(c\cdot\alpha)\oplus(c\cdot\beta),
$$
using the distributivity of scalar multiplication over subtraction in $\RR^{n}$.

:::

:::

::: {.pf-step #not-vector-space}
$(\RR^{n},\oplus,\cdot)$ is not a vector space for $n\ge1$.

::: pf-proof
A vector space must satisfy all eight axioms; by step [](#three-fail){.pf-ref} at least (3a) fails, since $n\ge1$ gives $\alpha\neq\beta$ with $\alpha,\beta\in\RR^{n}$. Hence the structure is not a vector space, so the axioms satisfied are exactly (3c), (3d) and (4c) by steps [](#zero){.pf-ref}, [](#negatives){.pf-ref} and [](#distributive){.pf-ref}.

:::

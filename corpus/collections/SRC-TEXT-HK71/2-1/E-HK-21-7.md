::: {.exercise}
Let $V$ be the set of pairs $(x, y)$ of real numbers and let $F$ be the field of real numbers.
Define
$$
(x, y) + (x_1, y_1) = (x + x_1,\; 0), \qquad c(x, y) = (cx,\; 0).
$$
Is $V$, with these operations, a vector space?
:::


::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no published solution set for it is retained in `tmp/sources`, so nothing below is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §2.1 Exercise 7. Here $V=\RR^2$ as a set with the two displayed operations and $F=\RR$; a vector space must have an additive identity, an element $e$ with $x+e=x$ for every $x\in V$.

::: pf

::: {.pf-step #id}

If $e=(e_1,e_2)$ is an additive identity, then $(x+e_1,0)=(x,y)$ for every $(x,y)\in V$.

::: pf-proof

The sum is computed with the card's rule $(x,y)+(e_1,e_2)=(x+e_1,0)$, and an additive identity must satisfy $(x,y)+e=(x,y)$.

:::

:::

::: {.pf-step #noe}

No such $e$ exists.

::: pf-proof

The second coordinate in step [](#id){.pf-ref} would give $0=y$ for every real $y$; taking $y=1$ contradicts it.

:::

:::

::: {.pf-step #done}

$V$ with these operations is not a vector space.

::: pf-proof

The additive-group axioms require an additive identity, which step [](#noe){.pf-ref} shows does not exist; a structure lacking a vector-space axiom is not a vector space.

:::

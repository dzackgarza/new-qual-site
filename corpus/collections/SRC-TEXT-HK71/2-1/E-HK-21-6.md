::: {.exercise}
Let $V$ be the set of all complex-valued functions $f$ on the real line such that (for all $t$ in $\RR$)
$$
f(-t) = \overline{f(t)}.
$$
The bar denotes complex conjugation.
Show that $V$, with the operations
$$
(f + g)(t) = f(t) + g(t), \qquad (cf)(t) = cf(t)
$$
is a vector space over the field of real numbers.
Give an example of a function in $V$ which is not real-valued.
:::


::: {.solution}

The argument is the card's own. Write $\overline{z}$ for the complex conjugate of $z$, and let $W$ be the set of all complex-valued functions on $\RR$ with the pointwise operations $(f+g)(t)=f(t)+g(t)$ and $(cf)(t)=cf(t)$, which is a vector space over $\RR$.

::: pf

::: {.pf-step #subset}

$V\subseteq W$.

::: pf-proof

A function $f\in V$ is by definition a complex-valued function on $\RR$, and the operations displayed in the exercise are exactly the pointwise operations of $W$: addition of values and multiplication of a value by the real scalar $c$. So the structure $(V,+,\cdot)$ proposed in the exercise is the restriction of the structure of $W$ to the subset $V$.

:::

:::

::: {.pf-step #zero}

The zero function lies in $V$.

::: pf-proof

The zero function is identically $0$, so $0(-t)=0=\overline{0}$ for every $t$, which is the defining condition of $V$. In particular $V$ is nonempty.

:::

:::

::: {.pf-step #addition}

If $f,g\in V$ then $f+g\in V$.

::: pf-proof

For every real $t$,
$$
(f+g)(-t)=f(-t)+g(-t)=\overline{f(t)}+\overline{g(t)}=\overline{f(t)+g(t)}=\overline{(f+g)(t)},
$$
using the pointwise definition of the sum, the hypothesis $f,g\in V$, and the additivity of conjugation. Hence $f+g$ satisfies the defining condition of $V$.

:::

:::

::: {.pf-step #scalars}

If $f\in V$ and $c\in\RR$ then $cf\in V$.

::: pf-proof

For every real $t$,
$$
(cf)(-t)=c\,f(-t)=c\,\overline{f(t)}=\overline{c\,f(t)}=\overline{(cf)(t)},
$$
because $c$ is real and conjugation fixes real numbers. Hence $cf$ satisfies the defining condition of $V$. This is the only place where the field is used, and it is why the scalar field must be $\RR$: for a non-real $c$ the identity $c\overline{z}=\overline{cz}$ fails.

:::

:::

::: {.pf-step #conclusion}

$V$ is a real vector space under the stated operations.

::: pf-proof

By step [](#subset){.pf-ref}, $V$ is a subset of the real vector space $W$ carrying the restricted operations; by steps [](#zero){.pf-ref}, [](#addition){.pf-ref} and [](#scalars){.pf-ref}, $V$ contains $0$ and is closed under addition and under multiplication by real scalars. A nonempty subset of a vector space closed under both operations is a subspace, so
$$
\boxed{V\le W,\ \text{hence } V \text{ is a vector space over } \RR.}
$$

:::

:::

::: {.pf-step #example}

$f(t)=it$ lies in $V$ and is not real-valued.

::: pf-proof

For every real $t$, $f(-t)=i(-t)=-it=\overline{it}=\overline{f(t)}$, so $f\in V$. Its value at the real number $t$ is $it$, whose imaginary part is $t$; hence $it$ is real exactly when $t=0$. So $f$ is not real-valued: it takes the non-real value $i$ at $t=1$.

:::

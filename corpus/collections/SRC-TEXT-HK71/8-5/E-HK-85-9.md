::: {.exercise}
Prove that a real symmetric matrix has a real symmetric cube root; i.e., if $A$ is real symmetric, there is a real symmetric $B$ such that $B^3 = A$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §8.5 Exercise 9, p. 317. The construction is the real spectral theorem followed by taking real cube roots of the eigenvalues; symmetry and the cube identity are verified from $PP^{t}=I$.

::: pf

::: {.pf-step #spectral}
There is a real orthogonal $P$ with $P^{t}AP=D=\operatorname{diag}(\lambda_1,\dots,\lambda_n)$ and every $\lambda_i\in\RR$.

::: pf-proof
This is the real spectral theorem for symmetric matrices: $A$ is orthogonally diagonalisable and its eigenvalues are real.
:::
:::

::: {.pf-step #roots}
With $\mu_i$ the real cube root of $\lambda_i$, the matrix $D'\coloneqq\operatorname{diag}(\mu_1,\dots,\mu_n)$ is real and $(D')^3=D$.

::: pf-proof
Every real number has a unique real cube root, so the $\mu_i$ are real; cubing a diagonal matrix cubes its entries, and $\mu_i^3=\lambda_i$.
:::
:::

::: {.pf-step #symmetric}
$B\coloneqq PD'P^{t}$ is real symmetric.

::: pf-proof
$P$ and $D'$ are real, so $B$ is real. And $B^{t}=(PD'P^{t})^{t}=P(D')^{t}P^{t}=PD'P^{t}=B$, since $D'$ is diagonal.
:::
:::

::: {.pf-step #cube}
$B^3=A$.

::: pf-proof
$B^3=PD'P^{t}PD'P^{t}PD'P^{t}=P(D')^{3}P^{t}=PDP^{t}$, using $P^{t}P=I$; and $PDP^{t}=P(P^{t}AP)P^{t}=A$, using $PP^{t}=I$.
:::
:::

::: {.pf-step}
Every real symmetric matrix has a real symmetric cube root.

::: pf-proof
Steps [](#symmetric){.pf-ref} and [](#cube){.pf-ref} exhibit $B$ with the two required properties.
:::
:::

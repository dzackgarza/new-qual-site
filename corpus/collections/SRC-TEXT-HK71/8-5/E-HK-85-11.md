::: {.exercise}
Prove that a normal and nilpotent operator is the zero operator.
:::

::: {.solution}
Let $N$ be normal and nilpotent, say $N^k = 0$. The argument works over $\RR$ and over $\CC$.

::: pf

::: {.pf-step #s1}
If $M$ is normal, then $\ker M^2 = \ker M$.

::: pf-proof
For every $\gamma$, normality gives $\norm{M\gamma} = \norm{M^*\gamma}$, since $\norm{M\gamma}^2 = (M^*M\gamma \mid \gamma) = (MM^*\gamma \mid \gamma) = \norm{M^*\gamma}^2$. If $M^2\alpha = 0$, apply this with $\gamma = M\alpha$ to get $M^*M\alpha = 0$. Then
$$
\norm{M\alpha}^2 = (M^*M\alpha \mid \alpha) = 0,
$$
so $M\alpha = 0$. The inclusion $\ker M \subseteq \ker M^2$ is clear.
:::

:::

::: {.pf-step #s2}
$\ker N^{2^m} = \ker N$ for every $m \ge 0$.

::: pf-proof
Induction on $m$. Each power $M = N^{2^{m-1}}$ is normal, since $N$ and $N^*$ commute and so $M^*M = (N^*)^{2^{m-1}}N^{2^{m-1}} = N^{2^{m-1}}(N^*)^{2^{m-1}} = MM^*$. Step [](#s1){.pf-ref} gives $\ker N^{2^m} = \ker M^2 = \ker M = \ker N$.
:::

:::

::: pf-qed
Choose $m$ with $2^m \ge k$. Then $N^{2^m} = 0$, so step [](#s2){.pf-ref} gives $\ker N = V$, that is, $N = 0$.
:::

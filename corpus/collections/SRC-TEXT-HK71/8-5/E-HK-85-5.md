::: {.exercise}
Give an example of a $2 \times 2$ matrix $A$ such that $A^2$ is normal, but $A$ is not normal.
:::

::: {.solution}
**Goal.** Find a $2\times 2$ matrix $A$ with $A^2$ normal but $A$ not normal.

<1>1. Take $A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$.
Proof: a candidate.

<1>2. $A^2 = 0$, which is normal.
Proof: $A^2 = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$, and the zero matrix is normal ($0^* 0 = 0 = 0\,0^*$).

<1>3. $A$ is not normal.
<2>1. $A^* = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$.
Proof: conjugate transpose.
<2>2. $A^* A = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$.
Proof: multiply.
<2>3. $A A^* = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$.
Proof: multiply.
<2>4. $A^* A \neq A A^*$, so $A$ is not normal.
Proof: $\begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \neq \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$.

<1>4. Q.E.D.
Proof: <1>2 and <1>3 show $A^2$ is normal but $A$ is not.
:::

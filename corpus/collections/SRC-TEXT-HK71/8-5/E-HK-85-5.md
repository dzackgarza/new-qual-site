::: {.exercise}
Give an example of a $2 \times 2$ matrix $A$ such that $A^2$ is normal, but $A$ is not normal.
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §8.5 Exercise 5 on printed p. 316. The argument is the card's own.

::: pf

::: {.pf-step #s1}
For $A=\begin{pmatrix}0&1\\0&0\end{pmatrix}$ the square $A^2=0$ is normal.

::: pf-proof
Multiplying, $A^2=\begin{pmatrix}0&1\\0&0\end{pmatrix}\begin{pmatrix}0&1\\0&0\end{pmatrix}=\begin{pmatrix}0&0\\0&0\end{pmatrix}$, and the zero matrix is normal because $0^*0=0=00^*$.
:::

:::

::: {.pf-step #s2}
$A$ is not normal.

::: pf-proof
Since $A^*=\begin{pmatrix}0&0\\1&0\end{pmatrix}$, the two products are $A^*A=\begin{pmatrix}0&0\\1&0\end{pmatrix}\begin{pmatrix}0&1\\0&0\end{pmatrix}=\begin{pmatrix}0&0\\0&1\end{pmatrix}$ and $AA^*=\begin{pmatrix}0&1\\0&0\end{pmatrix}\begin{pmatrix}0&0\\1&0\end{pmatrix}=\begin{pmatrix}1&0\\0&0\end{pmatrix}$; they differ, so $A^*A\ne AA^*$ and $A$ is not normal.
:::

::: {.exercise}
Give an example of a $2 \times 2$ matrix $A$ such that $A^2$ is normal, but $A$ is not normal.
:::

::: {.solution}
**Goal.** Find a $2\times 2$ matrix $A$ with $A^2$ normal but $A$ not normal.

::: pf

::: pf-step

Take $A = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}$.

::: pf-proof

a candidate.

:::

:::

::: {.pf-step #s2}

$A^2 = 0$, which is normal.

::: pf-proof

$A^2 = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 0 \end{pmatrix}$, and the zero matrix is normal ($0^* 0 = 0 = 0\,0^*$).

:::

:::

::: {.pf-step #s3}

$A$ is not normal.

::: pf-proof

::: pf-step

$A^* = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}$.

::: pf-proof

conjugate transpose.

:::

:::

::: pf-step

$A^* A = \begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix}\begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix}$.

::: pf-proof

multiply.

:::

:::

::: pf-step

$A A^* = \begin{pmatrix} 0 & 1 \\ 0 & 0 \end{pmatrix}\begin{pmatrix} 0 & 0 \\ 1 & 0 \end{pmatrix} = \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$.

::: pf-proof

multiply.

:::

:::

::: pf-step

$A^* A \neq A A^*$, so $A$ is not normal.

::: pf-proof

$\begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \neq \begin{pmatrix} 1 & 0 \\ 0 & 0 \end{pmatrix}$.

:::

:::

:::

:::

::: pf-qed

Steps [](#s2){.pf-ref} and [](#s3){.pf-ref} show $A^2$ is normal but $A$ is not.

:::

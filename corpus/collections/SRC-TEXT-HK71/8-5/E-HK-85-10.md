::: {.exercise}
Prove that every positive matrix is the square of a positive matrix.
:::

::: {.solution}

::: pf

::: pf-step

Let $A$ be a positive (positive-definite Hermitian) matrix.

::: pf-proof

hypothesis.

:::

:::

::: pf-step

$A$ is Hermitian, so it is unitarily diagonalizable: $A = U D U^*$ with $U$ unitary and $D = \operatorname{diag}(\lambda_1, \ldots, \lambda_n)$.

::: pf-proof

spectral theorem for Hermitian matrices.

:::

:::

::: {.pf-step #s3}

Since $A$ is positive, each $\lambda_i > 0$.

::: pf-proof

the eigenvalues of a positive matrix are positive.

:::

:::

::: {.pf-step #s4}

Define $B = U \operatorname{diag}(\sqrt{\lambda_1}, \ldots, \sqrt{\lambda_n}) U^*$.

::: pf-proof

definition.

:::

:::

::: {.pf-step #s5}

$B$ is positive (its eigenvalues $\sqrt{\lambda_i} > 0$).

::: pf-proof

Steps [](#s3){.pf-ref} and [](#s4){.pf-ref}.

:::

:::

::: {.pf-step #s6}

$B^2 = U \operatorname{diag}(\lambda_1, \ldots, \lambda_n) U^* = A$.

::: pf-proof

Step [](#s4){.pf-ref} (squaring the diagonal matrix squares the entries).

:::

:::

::: {.pf-step #s7}

Hence $A$ is the square of the positive matrix $B$.

::: pf-proof

Steps [](#s5){.pf-ref} and [](#s6){.pf-ref}.

:::

:::

Step [](#s7){.pf-ref}.

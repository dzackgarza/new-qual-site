::: {.exercise}
Use Cramer's rule to solve each of the following systems of linear equations over the field of rational numbers.

(a) $\begin{aligned}[t] x + y + z &= 11, \\ 2x - 6y - z &= 0, \\ 3x + 4y + 2z &= 0. \end{aligned}$

(b) $\begin{aligned}[t] 3x - 2y &= 7, \\ 3y - 2z &= 6, \\ 3z - 2x &= -1. \end{aligned}$
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, and every determinant below was recomputed for this pass. Cramer's rule for a system with coefficient matrix $M$ and right-hand side $\beta$ gives $x_{j}=\Delta_{j}/\Delta$, where $\Delta=\det M$ and $\Delta_{j}$ is $\Delta$ with its $j$-th column replaced by $\beta$.

::: pf

::: {.pf-step #part-a}
(a) The system $x+y+z=11$, $2x-6y-z=0$, $3x+4y+2z=0$ has the unique solution $(x,y,z)=(-8,-7,26)$.

::: pf-proof
The coefficient determinant, the three replaced-column determinants, and the solution.

::: {.pf-step #a-determinant}
$\Delta=\det\begin{bmatrix}1&1&1\\2&-6&-1\\3&4&2\end{bmatrix}=11\ne0$.

::: pf-proof
Expanding along the first row, $\Delta=1\cdot\det\begin{bmatrix}-6&-1\\4&2\end{bmatrix}-1\cdot\det\begin{bmatrix}2&-1\\3&2\end{bmatrix}+1\cdot\det\begin{bmatrix}2&-6\\3&4\end{bmatrix}=(-12+4)-(4+3)+(8+18)=-8-7+26=11$. Since $\Delta\ne0$ the system has a unique solution and Cramer's rule applies.
:::

:::

::: {.pf-step #a-numerators}
$\Delta_{x}=-88$, $\Delta_{y}=-77$ and $\Delta_{z}=286$.

::: pf-proof
$\Delta_{x}$ has first column $(11,0,0)^{t}$, so expanding along that column gives $11\cdot\det\begin{bmatrix}-6&-1\\4&2\end{bmatrix}=11\cdot(-8)=-88$. $\Delta_{y}$ has second column $(11,0,0)^{t}$, so expanding along it gives $-11\cdot\det\begin{bmatrix}2&-1\\3&2\end{bmatrix}=-11\cdot7=-77$. $\Delta_{z}$ has third column $(11,0,0)^{t}$, so expanding along it gives $11\cdot\det\begin{bmatrix}2&-6\\3&4\end{bmatrix}=11\cdot26=286$.
:::

:::

::: {.pf-step #a-solution}
$(x,y,z)=(-88/11,\,-77/11,\,286/11)=(-8,-7,26)$.

::: pf-proof
By Cramer's rule and the previous two steps the solution is as displayed, and substituting it into the system confirms it: $-8-7+26=11$, $2(-8)-6(-7)-26=-16+42-26=0$ and $3(-8)+4(-7)+2(26)=-24-28+52=0$.
:::

::: {.pf-step #part-b}
(b) The system $3x-2y=7$, $3y-2z=6$, $3z-2x=-1$ has the unique solution $(x,y,z)=(5,4,3)$.

::: pf-proof
The coefficient determinant, the three replaced-column determinants, and the solution.

::: {.pf-step #b-determinant}
$\Delta=\det\begin{bmatrix}3&-2&0\\0&3&-2\\-2&0&3\end{bmatrix}=19\ne0$.

::: pf-proof
Expanding along the first row, $\Delta=3\cdot\det\begin{bmatrix}3&-2\\0&3\end{bmatrix}+2\cdot\det\begin{bmatrix}0&-2\\-2&3\end{bmatrix}=3\cdot9+2\cdot(0-4)=27-8=19$.
:::

:::

::: {.pf-step #b-numerators}
$\Delta_{x}=95$, $\Delta_{y}=76$ and $\Delta_{z}=57$.

::: pf-proof
With the right-hand side $\beta=(7,6,-1)^{t}$: replacing the first column gives $\det\begin{bmatrix}7&-2&0\\6&3&-2\\-1&0&3\end{bmatrix}=7\cdot9+2\cdot(18-2)=63+32=95$; replacing the second gives $\det\begin{bmatrix}3&7&0\\0&6&-2\\-2&-1&3\end{bmatrix}=3\cdot(18-2)-7\cdot(0-4)=48+28=76$; and replacing the third gives $\det\begin{bmatrix}3&-2&7\\0&3&6\\-2&0&-1\end{bmatrix}=3\cdot(-3)-(-2)\cdot(0+12)+7\cdot(0+6)=-9+24+42=57$.
:::

:::

::: {.pf-step #b-solution}
$(x,y,z)=(95/19,\,76/19,\,57/19)=(5,4,3)$.

::: pf-proof
Cramer's rule and the two previous steps give the solution displayed. Substituting back: $3\cdot5-2\cdot4=15-8=7$, $3\cdot4-2\cdot3=12-6=6$ and $3\cdot3-2\cdot5=9-10=-1$, so it satisfies all three equations; both systems are therefore solved as asked.
:::

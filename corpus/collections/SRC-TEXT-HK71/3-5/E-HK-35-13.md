::: {.exercise}
Let $F$ be a subfield of the field of complex numbers and let $V$ be any vector space over $F$.
Suppose that $f$ and $g$ are linear functionals on $V$ such that the function $h$ defined by $h(\alpha) = f(\alpha)g(\alpha)$ is also a linear functional on $V$.
Prove that either $f = 0$ or $g = 0$.
:::

::: {.solution}

::: pf

::: {.pf-step #assume-both-nonzero}
Suppose for contradiction that $f \neq 0$ and $g \neq 0$.

::: pf-proof
assume both are nonzero.
:::

:::

::: {.pf-step #h-linear-scaling}
Since $h$ is linear, $h(c\alpha) = c\,h(\alpha)$ for every scalar $c$ and every $\alpha \in V$.

::: pf-proof
linearity of $h$.
:::

:::

::: {.pf-step #expand-h-scaling}
Expanding: $f(c\alpha)g(c\alpha) = c f(\alpha)g(\alpha)$, i.e. $c^2 f(\alpha)g(\alpha) = c f(\alpha)g(\alpha)$.

::: pf-proof
Step [](#h-linear-scaling){.pf-ref} and linearity of $f, g$.
:::

:::

::: {.pf-step #c-squared-minus-c-zero}
Hence $(c^2 - c) f(\alpha)g(\alpha) = 0$ for all scalars $c$ and all $\alpha \in V$.

::: pf-proof
Step [](#expand-h-scaling){.pf-ref}.
:::

:::

::: {.pf-step #fg-zero-at-c2}
Taking $c = 2$ (so $c^2 - c = 2 \neq 0$), we get $f(\alpha)g(\alpha) = 0$ for all $\alpha \in V$.

::: pf-proof
Step [](#c-squared-minus-c-zero){.pf-ref}.
:::

:::

::: {.pf-step #h-identically-zero}
Hence $h \equiv 0$, i.e. $f(\alpha)g(\alpha) = 0$ for every $\alpha$.

::: pf-proof
Step [](#fg-zero-at-c2){.pf-ref}.
:::

:::

::: {.pf-step #g-alpha0-zero}
Since $f \neq 0$, there is $\alpha_0$ with $f(\alpha_0) \neq 0$; then $g(\alpha_0) = 0$ by step [](#h-identically-zero){.pf-ref}.

::: pf-proof
Steps [](#assume-both-nonzero){.pf-ref} and [](#h-identically-zero){.pf-ref}.
:::

:::

::: {.pf-step #sum-product-zero}
For any $\beta \in V$, $f(\alpha_0 + \beta)g(\alpha_0 + \beta) = 0$ by step [](#h-identically-zero){.pf-ref}.

::: pf-proof
Step [](#h-identically-zero){.pf-ref} applied to $\alpha_0 + \beta$.
:::

:::

::: {.pf-step #expand-sum-product}
Expanding: $(f(\alpha_0) + f(\beta))(g(\alpha_0) + g(\beta)) = 0$, and since $g(\alpha_0) = 0$, this gives $(f(\alpha_0) + f(\beta))g(\beta) = 0$.

::: pf-proof
Steps [](#g-alpha0-zero){.pf-ref} and [](#sum-product-zero){.pf-ref}.
:::

:::

::: {.pf-step #f-alpha0-g-beta-zero}
Hence $f(\alpha_0)g(\beta) + f(\beta)g(\beta) = 0$, and $f(\beta)g(\beta) = 0$ by step [](#h-identically-zero){.pf-ref}, so $f(\alpha_0)g(\beta) = 0$.

::: pf-proof
Steps [](#expand-sum-product){.pf-ref} and [](#h-identically-zero){.pf-ref}.
:::

:::

::: {.pf-step #g-beta-zero-forall}
Since $f(\alpha_0) \neq 0$, this forces $g(\beta) = 0$ for every $\beta \in V$.

::: pf-proof
Step [](#f-alpha0-g-beta-zero){.pf-ref}.
:::

:::

::: {.pf-step #g-is-zero}
Hence $g = 0$, contradicting step [](#assume-both-nonzero){.pf-ref}.

::: pf-proof
Step [](#g-beta-zero-forall){.pf-ref}.
:::

:::

::: {.pf-step #conclusion-f-or-g-zero}
Therefore $f = 0$ or $g = 0$.

::: pf-proof
Step [](#g-is-zero){.pf-ref}.
:::

:::

::: pf-qed
Step [](#conclusion-f-or-g-zero){.pf-ref}.
:::

:::

:::

::: {.solution}
Since $h$ is linear, for every $\alpha\in V$,
\[
h(2\alpha)=2h(\alpha).
\]
But by its definition,
\[
h(2\alpha)=f(2\alpha)g(2\alpha)=4f(\alpha)g(\alpha)=4h(\alpha).
\]
Because $F$ is a subfield of $\CC$, its characteristic is zero; hence
\[
h(\alpha)=0
\]
for every $\alpha$.
Thus
\[
f(\alpha)g(\alpha)=0\qquad\text{for all }\alpha\in V.
\]
Suppose both $f$ and $g$ are nonzero.
Choose $u,v\in V$ with $f(u)\ne0$ and $g(v)\ne0$.
The displayed identity forces $g(u)=0$ and $f(v)=0$.
Then
\[
f(u+v)g(u+v)=f(u)g(v)\ne0,
\]
a contradiction.
Therefore either $f=0$ or $g=0$.
:::

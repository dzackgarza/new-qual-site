::: {.exercise}
Let $F$ be a field of characteristic zero and let $V$ be a finite-dimensional vector space over $F$.
If $\alpha_1, \ldots, \alpha_m$ are finitely many vectors in $V$, each different from the zero vector, prove that there is a linear functional $f$ on $V$ such that
$$
f(\alpha_i) \neq 0, \quad i = 1, \ldots, m.
$$
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §3.5 Exercise 14.

::: pf

::: {.pf-step #base}
For $m=1$ there is a functional nonzero at $\alpha_1$.

::: pf-proof
$\alpha_1\ne0$, so it is part of a basis of $V$; the coordinate functional dual to that basis element takes the value $1$ at $\alpha_1$.
:::

:::

::: {.pf-step #step}
Given $f$ nonzero at $\alpha_1,\dots,\alpha_{m-1}$, there is $t\in F$ with $f+t\,g$ nonzero at all of $\alpha_1,\dots,\alpha_m$, where $g$ is any functional nonzero at $\alpha_m$.

:::: pf-proof

::: {.pf-step #g}
There is $g\in V^*$ with $g(\alpha_m)\ne0$.

::: pf-proof
$\alpha_m\ne0$, so it extends to a basis and the dual coordinate functional is nonzero there.
:::

:::

::: {.pf-step #forbidden}
For each $i\le m$ at most one $t$ makes $(f+tg)(\alpha_i)=0$.

::: pf-proof
$(f+tg)(\alpha_i)=f(\alpha_i)+t\,g(\alpha_i)$ is an affine function of $t$; if $g(\alpha_i)\ne0$ it vanishes at exactly one $t$, and if $g(\alpha_i)=0$ it is the constant $f(\alpha_i)$, which vanishes at no $t$ when $i<m$ by the induction hypothesis and at no $t$ when $i=m$ because $g(\alpha_m)\ne0$.
:::

:::

::: {.pf-step #choose}
There is $t$ outside the finite set of forbidden values.

::: pf-proof
At most $m$ values of $t$ are forbidden, by step [](#forbidden){.pf-ref}, and $F$ is infinite because it has characteristic zero; a finite subset cannot exhaust an infinite field.
:::

:::

:::

:::

::: {.pf-step}
There is a functional nonzero at every $\alpha_i$.

::: pf-proof
Induction on $m$: the case $m=1$ is step [](#base){.pf-ref}, and the step from $m-1$ to $m$ is step [](#step){.pf-ref}. Hence
$$
\boxed{\exists f\in V^*\text{ with }f(\alpha_i)\neq0\text{ for }i=1,\dots,m.}
$$
Characteristic zero is used only to make $F$ infinite; a finite field would fail for $m$ at least $\cardinality{F}$.
:::

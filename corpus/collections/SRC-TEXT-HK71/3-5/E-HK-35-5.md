::: {.exercise}
If $A$ and $B$ are $n \times n$ complex matrices, show that $AB - BA = I$ is impossible.
:::

::: {.solution}
<1>1. Suppose for contradiction that $AB - BA = I$.
::: {.proof}
assume the contrary.
:::

<1>2. Take the trace of both sides: $\operatorname{tr}(AB - BA) = \operatorname{tr}(I) = n$.
::: {.proof}
the trace of the identity is $n$.
:::

<1>3. But $\operatorname{tr}(AB - BA) = \operatorname{tr}(AB) - \operatorname{tr}(BA) = 0$.
::: {.proof}
$\operatorname{tr}(AB) = \operatorname{tr}(BA)$ (the trace is cyclic).
:::

<1>4. Contradiction: $0 = n \neq 0$.
::: {.proof}
<1>2 and <1>3.
:::

<1>5. Hence $AB - BA = I$ is impossible.
::: {.proof}
<1>1–<1>4.
:::

<1>6. Q.E.D.
::: {.proof}
<1>5.
:::
:::

::: solution
Suppose, for contradiction, that
\[
AB-BA=I_n.
\]
Taking traces and using $\operatorname{tr}(AB)=\operatorname{tr}(BA)$ gives
\[
0=\operatorname{tr}(AB)-\operatorname{tr}(BA)
=\operatorname{tr}(I_n)=n.
\]
Over $\CC$ the scalar $n$ is nonzero. This contradiction proves that no such complex matrices $A,B$ exist.
:::

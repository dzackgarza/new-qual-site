::: {.exercise}
If $A$ and $B$ are $n \times n$ complex matrices, show that $AB - BA = I$ is impossible.
:::

::: {.solution}
No retained solution set covers this exercise; the book's text is retained as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §3.5 Exercise 5 on printed p. 110. The argument is the card's own.

::: pf

::: {.pf-step #trace-of-identity}
If $AB-BA=I$, then $\operatorname{tr}(AB-BA)=n$.

::: pf-proof
Taking traces of both sides gives $\operatorname{tr}(AB-BA)=\operatorname{tr}(I)$, and the trace of the $n\times n$ identity is $n$.
:::

:::

::: {.pf-step #trace-ab-minus-ba-is-zero}
$\operatorname{tr}(AB-BA)=0$ for all $n\times n$ matrices $A,B$.

::: pf-proof
$\operatorname{tr}(AB)=\sum_{i}\sum_{j}a_{ij}b_{ji}=\operatorname{tr}(BA)$, since both sums run over the same products in the other order; hence $\operatorname{tr}(AB-BA)=\operatorname{tr}(AB)-\operatorname{tr}(BA)=0$.
:::

:::

::: {.pf-step #impossible}
There are no $n\times n$ matrices $A,B$ with $AB-BA=I$.

::: pf-proof
If there were, step [](#trace-of-identity){.pf-ref} would give $\operatorname{tr}(AB-BA)=n$ while step [](#trace-ab-minus-ba-is-zero){.pf-ref} gives $0$; so $n=0$, which is false for an $n\times n$ identity with $n\ge1$.
:::

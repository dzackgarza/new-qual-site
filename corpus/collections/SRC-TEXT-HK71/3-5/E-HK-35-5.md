::: {.exercise}
If $A$ and $B$ are $n \times n$ complex matrices, show that $AB - BA = I$ is impossible.
:::

::: {.solution}

::: pf

::: {.pf-step #assume-ab-minus-ba-is-i}
Suppose for contradiction that $AB - BA = I$.

::: pf-proof
assume the contrary.
:::

:::

::: {.pf-step #trace-of-identity-is-n}
Take the trace of both sides: $\operatorname{tr}(AB - BA) = \operatorname{tr}(I) = n$.

::: pf-proof
the trace of the identity is $n$.
:::

:::

::: {.pf-step #trace-ab-minus-ba-is-zero}
But $\operatorname{tr}(AB - BA) = \operatorname{tr}(AB) - \operatorname{tr}(BA) = 0$.

::: pf-proof
$\operatorname{tr}(AB) = \operatorname{tr}(BA)$ (the trace is cyclic).
:::

:::

::: {.pf-step #contradiction-0-eq-n}
Contradiction: $0 = n \neq 0$.

::: pf-proof
Steps [](#trace-of-identity-is-n){.pf-ref} and [](#trace-ab-minus-ba-is-zero){.pf-ref}.
:::

:::

::: {.pf-step #ab-minus-ba-impossible}
Hence $AB - BA = I$ is impossible.

::: pf-proof
Steps [](#assume-ab-minus-ba-is-i){.pf-ref}, [](#trace-of-identity-is-n){.pf-ref}, [](#trace-ab-minus-ba-is-zero){.pf-ref}, and [](#contradiction-0-eq-n){.pf-ref}.
:::

:::

::: pf-qed
Step [](#ab-minus-ba-impossible){.pf-ref}.
:::

:::

:::

::: {.solution}
Suppose, for contradiction, that
\[
AB-BA=I_n.
\]
Taking traces and using $\operatorname{tr}(AB)=\operatorname{tr}(BA)$ gives
\[
0=\operatorname{tr}(AB)-\operatorname{tr}(BA)
=\operatorname{tr}(I_n)=n.
\]
Over $\CC$ the scalar $n$ is nonzero.
This contradiction proves that no such complex matrices $A,B$ exist.
:::

::: {.exercise}
According to Exercise 3, similar matrices have the same trace.
Thus we can define the trace of a linear operator on a finite-dimensional space to be the trace of any matrix which represents the operator in an ordered basis.
This is well-defined since all such representing matrices for one operator are similar.

Now let $V$ be the space of all $2 \times 2$ matrices over the field $F$ and let $P$ be a fixed $2 \times 2$ matrix.
Let $T$ be the linear operator on $V$ defined by $T(A) = PA$.
Prove that $\operatorname{trace}(T) = 2\operatorname{trace}(P)$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §3.5 Exercise 15. The matrix of $T$ was recomputed on each basis element: left multiplication by $P$ sends $E_{11}\mapsto p_{11}E_{11}+p_{21}E_{21}$ and $E_{21}\mapsto p_{11}E_{12}+p_{21}E_{22}$, and similarly for the second column, so the matrix is block diagonal with two copies of $P$.

::: pf

::: {.pf-step #basis}
The four matrices $E_{11},E_{21},E_{12},E_{22}$ form a basis of $V$, the space of $2\times2$ matrices over $F$.

::: pf-proof
$E_{ij}$ has $1$ in position $(i,j)$ and $0$ elsewhere; every $2\times2$ matrix is the sum $\sum_{i,j}a_{ij}E_{ij}$, and the four are independent because the zero combination has every entry $0$.
:::
:::

::: {.pf-step #action}
For $P=\begin{pmatrix}p_{11}&p_{12}\\p_{21}&p_{22}\end{pmatrix}$: $T(E_{11})=p_{11}E_{11}+p_{21}E_{21}$, $T(E_{21})=p_{11}E_{12}+p_{21}E_{22}$, $T(E_{12})=p_{12}E_{11}+p_{22}E_{21}$ and $T(E_{22})=p_{12}E_{12}+p_{22}E_{22}$.

::: pf-proof
$PE_{11}$ has first column equal to the first column of $P$ and second column $0$, which is $p_{11}E_{11}+p_{21}E_{21}$; $PE_{21}$ has first column $0$ and second column equal to the first column of $P$, which is $p_{11}E_{12}+p_{21}E_{22}$. The other two cases are the same computation with the second column of $P$.
:::
:::

::: {.pf-step #matrix}
In the ordered basis $(E_{11},E_{21},E_{12},E_{22})$ the operator $T$ has matrix $\begin{pmatrix}P&0\\0&P\end{pmatrix}$.

::: pf-proof
The coordinates of the four images, read in the order of step [](#basis){.pf-ref}, are the columns of that matrix by step [](#action){.pf-ref}.
:::
:::

::: {.pf-step #trace}
$\operatorname{trace}(T)=2\operatorname{trace}(P)$.

::: pf-proof
The trace of an operator is the trace of any representing matrix, and the trace of the block matrix of step [](#matrix){.pf-ref} is $p_{11}+p_{22}+p_{11}+p_{22}=2(p_{11}+p_{22})=2\operatorname{trace}(P)$.
:::

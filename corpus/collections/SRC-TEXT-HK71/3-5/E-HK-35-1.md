::: {.exercise}
In $\RR^3$, let $\alpha_1 = (1, 0, 1)$, $\alpha_2 = (0, 1, -2)$, $\alpha_3 = (-1, -1, 0)$.

(a) If $f$ is a linear functional on $\RR^3$ such that
$$
f(\alpha_1) = 1, \quad f(\alpha_2) = -1, \quad f(\alpha_3) = 3,
$$
and if $\alpha = (a, b, c)$, find $f(\alpha)$.

(b) Describe explicitly a linear functional $f$ on $\RR^3$ such that
$$
f(\alpha_1) = f(\alpha_2) = 0 \quad \text{but} \quad f(\alpha_3) \neq 0.
$$

(c) Let $f$ be any linear functional such that
$$
f(\alpha_1) = f(\alpha_2) = 0 \quad \text{and} \quad f(\alpha_3) \neq 0.
$$
If $\alpha = (2, 3, -1)$, show that $f(\alpha) \neq 0$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §3.5 Exercise 1.

::: pf

::: {.pf-step #basis}
$\alpha_1,\alpha_2,\alpha_3$ form a basis of $\RR^3$.

::: pf-proof
The matrix with these columns is $\begin{pmatrix}1&0&-1\\0&1&-1\\1&-2&0\end{pmatrix}$, whose determinant is $1\cdot(1\cdot0-(-1)(-2))+(-1)\cdot(0\cdot(-2)-1\cdot1)=-2+1=-1\neq0$; so the three vectors are independent and, being three in a three-dimensional space, form a basis.
:::
:::

::: {.pf-step #expand}
For $\alpha=(a,b,c)$, $\alpha=(2a-2b-c)\alpha_1+(a-b-c)\alpha_2+(a-2b-c)\alpha_3$.

::: pf-proof
Substituting the three vectors, the first coordinate of the right side is $(2a-2b-c)-(a-2b-c)=a$, the second is $(a-b-c)-(a-2b-c)=b$, and the third is $(2a-2b-c)-2(a-b-c)=c$.
:::
:::

::: {.pf-step #a}
The functional of (a) is $f(a,b,c)=4a-7b-3c$.

::: pf-proof
By step [](#expand){.pf-ref} and linearity, $f(\alpha)=(2a-2b-c)\cdot1+(a-b-c)\cdot(-1)+(a-2b-c)\cdot3=4a-7b-3c$. As a check, $\alpha_1=(1,0,1)$ gives $4-3=1$, $\alpha_2=(0,1,-2)$ gives $-7+6=-1$, and $\alpha_3=(-1,-1,0)$ gives $-4+7=3$, the three prescribed values.
:::
:::

::: {.pf-step #b}
(b) is answered by $f(a,b,c)=-a+2b+c$, for which $f(\alpha_1)=f(\alpha_2)=0$ and $f(\alpha_3)=-1\neq0$.

::: pf-proof
$f(\alpha_1)=-1+0+1=0$, $f(\alpha_2)=0+2-2=0$, and $f(\alpha_3)=1-2+0=-1$. The functional is linear because it is a linear combination of the coordinate functions.
:::
:::

::: {.pf-step #form}
Every linear functional on $\RR^3$ vanishing at $\alpha_1$ and $\alpha_2$ has the form $f(a,b,c)=w(-a+2b+c)$ for some $w\in\RR$.

::: pf-proof
Write $f(a,b,c)=ua+vb+wc$. The conditions are $f(\alpha_1)=u+w=0$ and $f(\alpha_2)=v-2w=0$, so $u=-w$ and $v=2w$, and $f=w(-a+2b+c)$.
:::
:::

::: {.pf-step #c}
(c) For every such $f$ with $f(\alpha_3)\neq0$, $f(2,3,-1)\neq0$.

::: pf-proof
By step [](#form){.pf-ref} $f=w(-a+2b+c)$ with $f(\alpha_3)=-w$, so the hypothesis $f(\alpha_3)\neq0$ is $w\neq0$. Then $f(2,3,-1)=w(-2+6-1)=3w\neq0$.
:::
:::

::: {.pf-step}
The answers are: (a) $f(a,b,c)=4a-7b-3c$; (b) $f(a,b,c)=-a+2b+c$; (c) $f(2,3,-1)=3w\neq0$ for $f=w(-a+2b+c)$, $w\neq0$.

::: pf-proof
Steps [](#a){.pf-ref}, [](#b){.pf-ref} and [](#c){.pf-ref} give the three answers.
:::
:::

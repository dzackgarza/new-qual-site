::: {.exercise}
On $\RR^4$ define the quadratic form
$$
q(x,y,z,t)=t^2-x^2-y^2-z^2.
$$
A *Lorentz transformation* is a real linear operator preserving $q$. Let $H$ be the real vector space of self-adjoint $2\times2$ complex matrices, and define
$$
U(x,y,z,t)=\begin{pmatrix}t+x&y+iz\\y-iz&t-x\end{pmatrix}.
$$

(a) Show that $U:\RR^4\to H$ is a real vector space isomorphism.

(b) Show that $q(\alpha)=\det(U\alpha)$.

(c) If $T:H\to H$ is real linear, show that $L=U^{-1}TU$ is real linear on $\RR^4$.

(d) For a complex $2\times2$ matrix $M$, show that $T_M(A)=M^*AM$ defines a real linear operator on $H$.

(e) If $\abs{\det M}=1$, show that $L_M=U^{-1}T_MU$ is a Lorentz transformation.

(f) Find a Lorentz transformation that is not of the form $L_M$.
:::

::: {.solution}
::: pf

::: {.pf-step #isomorphism}
$U:\RR^4\to H$ is a real vector space isomorphism.

::: pf-proof
Every $A\in H$ has a unique expression
$$
A=\begin{pmatrix}a&u+iv\\u-iv&d\end{pmatrix},
\qquad a,d,u,v\in\RR.
$$
The formula for $U$ is real linear, and this $A$ is the image of the unique vector
$$
(x,y,z,t)=\left(\frac{a-d}{2},u,v,\frac{a+d}{2}\right).
$$
Thus $U$ is linear and bijective.
:::

:::

::: {.pf-step #determinant}
$\det(U(x,y,z,t))=q(x,y,z,t)$ for every $(x,y,z,t)\in\RR^4$.

::: pf-proof
Expanding the determinant gives
$$
(t+x)(t-x)-(y+iz)(y-iz)=t^2-x^2-y^2-z^2.
$$
:::

:::

::: {.pf-step #conjugate}
If $T:H\to H$ is real linear, then $L=U^{-1}TU$ is real linear on $\RR^4$.

::: pf-proof
Step [](#isomorphism){.pf-ref} makes $U$ and $U^{-1}$ real linear. Their composition with $T$ is therefore real linear.
:::

:::

::: {.pf-step #matrix-action}
For every complex $2\times2$ matrix $M$, the map $T_M(A)=M^*AM$ is a real linear operator on $H$.

::: pf-proof
If $A=A^*$, then $(M^*AM)^*=M^*A^*M=M^*AM$, so $T_M(A)\in H$. For $A,B\in H$ and $r\in\RR$, matrix multiplication gives $T_M(A+rB)=T_M(A)+rT_M(B)$.
:::

:::

::: {.pf-step #lorentz}
If $\abs{\det M}=1$, then $L_M=U^{-1}T_MU$ is a Lorentz transformation.

::: pf-proof
Step [](#matrix-action){.pf-ref} and step [](#conjugate){.pf-ref} make $L_M$ real linear. For $\alpha\in\RR^4$, step [](#determinant){.pf-ref} and multiplicativity of determinants give
$$
q(L_M\alpha)=\det(T_M(U\alpha))
=\overline{\det M}\,\det(U\alpha)\det M
=\abs{\det M}^2q(\alpha)=q(\alpha).
$$
:::

:::

::: {.pf-step #outside-family}
The map $S(x,y,z,t)=(x,y,z,-t)$ is a Lorentz transformation, but $S\ne L_M$ for every complex $2\times2$ matrix $M$.

::: pf-proof
$S$ is real linear and preserves $q$. If $S=L_M$, apply $U$ to $S(0,0,0,1)=(0,0,0,-1)$. Since $U(0,0,0,1)=I$ and $U(0,0,0,-1)=-I$, this gives $M^*M=-I$. For any nonzero $v\in\CC^2$, however, $v^*M^*Mv=\norm{Mv}^2\ge0$ while $v^*(-I)v=-\norm v^2<0$, a contradiction.
:::

:::

::: pf-step
Q.E.D. Parts (a) through (f) hold.

::: pf-proof
Steps [](#isomorphism){.pf-ref} through [](#outside-family){.pf-ref} prove the six claims in order.
:::

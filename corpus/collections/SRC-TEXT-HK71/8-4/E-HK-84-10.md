::: {.exercise}
Let $V$ be a finite-dimensional inner product space.
For each $\alpha, \beta$ in $V$, let $T_{\alpha, \beta}$ be the linear operator on $V$ defined by $T_{\alpha, \beta}(\gamma) = (\gamma \mid \beta)\alpha$.
Show that

(a) $T_{\alpha, \beta}^* = T_{\beta, \alpha}$.

(b) $\operatorname{trace}(T_{\alpha, \beta}) = (\alpha \mid \beta)$.

(c) $T_{\alpha,\beta}T_{\gamma,\delta} = T_{\alpha,(\beta \mid \gamma)\delta}$.

(d) Under what conditions is $T_{\alpha, \beta}$ self-adjoint?
:::

::: {.solution}
**Part (a).**

<1>1. For all $\gamma, \eta \in V$, $(T_{\alpha,\beta}\gamma \mid \eta) = ((\gamma \mid \beta)\alpha \mid \eta) = (\gamma \mid \beta)(\alpha \mid \eta)$.
::: {.proof}
definition of $T_{\alpha,\beta}$.
:::

<1>2. $(\gamma \mid T_{\beta,\alpha}\eta) = (\gamma \mid (\eta \mid \alpha)\beta) = \overline{(\eta \mid \alpha)}(\gamma \mid \beta) = (\alpha \mid \eta)(\gamma \mid \beta)$.
::: {.proof}
definition and conjugate symmetry.
:::

<1>3. Hence $(T_{\alpha,\beta}\gamma \mid \eta) = (\gamma \mid T_{\beta,\alpha}\eta)$ for all $\gamma, \eta$, so $T_{\alpha,\beta}^* = T_{\beta,\alpha}$.
::: {.proof}
<1>1 and <1>2.
:::

**Part (b).**

<1>1. $\operatorname{trace}(T_{\alpha,\beta}) = (\alpha \mid \beta)$.
<2>1. Extend $\beta$ to an orthonormal basis $\{e_1, \ldots, e_n\}$ with $e_1 = \beta/\|\beta\|$ (if $\beta \neq 0$).
::: {.proof}
setup.
:::
<2>2. $\operatorname{trace}(T_{\alpha,\beta}) = \sum_i (T_{\alpha,\beta} e_i \mid e_i) = \sum_i ((e_i \mid \beta)\alpha \mid e_i) = \sum_i (e_i \mid \beta)(\alpha \mid e_i)$.
::: {.proof}
trace formula in an orthonormal basis.
:::
<2>3. Since $\{e_i\}$ is orthonormal, $\sum_i (e_i \mid \beta)(\alpha \mid e_i) = (\alpha \mid \beta)$.
::: {.proof}
this is the expansion of $\alpha$ and $\beta$ in the orthonormal basis: $\sum_i (\alpha \mid e_i)(e_i \mid \beta) = (\alpha \mid \beta)$.
:::
<2>4. Hence $\operatorname{trace}(T_{\alpha,\beta}) = (\alpha \mid \beta)$.
::: {.proof}
<2>2 and <2>3.
:::

**Part (c).**

<1>1. $T_{\alpha,\beta}T_{\gamma,\delta}(\eta) = T_{\alpha,\beta}((\eta \mid \delta)\gamma) = (\eta \mid \delta)(\gamma \mid \beta)\alpha$.
::: {.proof}
apply the definitions.
:::

<1>2. $T_{\alpha,(\beta \mid \gamma)\delta}(\eta) = (\eta \mid (\beta \mid \gamma)\delta)\alpha = \overline{(\beta \mid \gamma)}(\eta \mid \delta)\alpha = (\gamma \mid \beta)(\eta \mid \delta)\alpha$.
::: {.proof}
definition and conjugate symmetry.
:::

<1>3. Hence $T_{\alpha,\beta}T_{\gamma,\delta} = T_{\alpha,(\beta \mid \gamma)\delta}$.
::: {.proof}
<1>1 and <1>2.
:::

**Part (d).**

<1>1. $T_{\alpha,\beta}$ is self-adjoint iff $T_{\alpha,\beta} = T_{\beta,\alpha}$.
::: {.proof}
by part (a), $T_{\alpha,\beta}^* = T_{\beta,\alpha}$.
:::

<1>2. $T_{\alpha,\beta} = T_{\beta,\alpha}$ iff $\alpha$ and $\beta$ are linearly dependent (i.e. one is a scalar multiple of the other).
::: {.proof}
$T_{\alpha,\beta}(\gamma) = (\gamma \mid \beta)\alpha$ and $T_{\beta,\alpha}(\gamma) = (\gamma \mid \alpha)\beta$; these are equal for all $\gamma$ iff $\alpha$ and $\beta$ are proportional (if $\alpha = c\beta$, then $(\gamma \mid \beta)c\beta = (\gamma \mid c\beta)\beta$... more precisely, $T_{\alpha,\beta} = T_{\beta,\alpha}$ iff $\alpha = c\beta$ for some scalar $c$).
:::

<1>3. Hence $T_{\alpha,\beta}$ is self-adjoint iff $\alpha$ and $\beta$ are linearly dependent.
::: {.proof}
<1>1 and <1>2.
:::

<1>4. Q.E.D.
::: {.proof}
<1>3 (a), <1>4 (b), <1>3 (c), and <1>3 (d).
:::
:::

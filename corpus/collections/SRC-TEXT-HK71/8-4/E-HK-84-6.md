::: {.exercise}
Let $V$ be a finite-dimensional inner product space, and let $W$ be a subspace of $V$.
Then $V = W \oplus W^{\perp}$, that is, each $\alpha$ in $V$ is uniquely expressible in the form $\alpha = \beta + \gamma$, with $\beta$ in $W$ and $\gamma$ in $W^{\perp}$.
Define a linear operator $U$ by $U\alpha = \beta - \gamma$.

(a) Prove that $U$ is both self-adjoint and unitary.

(b) If $V$ is $\RR^3$ with the standard inner product and $W$ is the subspace spanned by $(1, 0, 1)$, find the matrix of $U$ in the standard ordered basis.
:::

::: {.solution}
**Goal:** Prove that the orthogonal reflection operator $U = P_W - P_{W^\perp}$ is self-adjoint and unitary in (a), and compute its matrix representation in $\RR^3$ for $W = \operatorname{span}\{(1, 0, 1)\}$ in (b).

::: pf

::: pf-step
Part (a): Self-adjointness and unitarity of $U$.

::: pf-proof

::: pf-step
Let $P_W: V \to W$ and $P_{W^\perp}: V \to W^\perp$ denote the orthogonal projections onto $W$ and $W^\perp$.

::: pf-proof
These are the orthogonal projections onto the two summands of the orthogonal decomposition.
:::

:::

::: pf-step
Since $V = W \oplus W^\perp$, the identity operator is $I = P_W + P_{W^\perp}$, so $P_{W^\perp} = I - P_W$.

::: pf-proof
Each vector is the sum of its projection onto $W$ and its projection onto $W^\perp$.
:::

:::

::: pf-step
The reflection operator is given by
$$U = P_W - P_{W^\perp} = P_W - (I - P_W) = 2P_W - I.$$

::: pf-proof
Substituting $P_{W^\perp}=I-P_W$ into the definition of $U$.
:::

:::

::: pf-step
Self-adjointness: Since orthogonal projections are self-adjoint ($P_W^* = P_W$), we compute
$$U^* = (2P_W - I)^* = 2P_W^* - I^* = 2P_W - I = U.$$
Thus $U$ is self-adjoint.

::: pf-proof
Orthogonal projections are self-adjoint, and a difference of self-adjoint operators is self-adjoint.
:::

:::

::: pf-step
Unitarity: Compute $U^2$ using the idempotence $P_W^2 = P_W$:
$$U^2 = (2P_W - I)^2 = 4P_W^2 - 4P_W + I^2 = 4P_W - 4P_W + I = I.$$

::: pf-proof
$U^2=P_W^2-P_WP_{W^\perp}-P_{W^\perp}P_W+P_{W^\perp}^2$, the mixed products vanish because the summands are orthogonal, and $P_W^2=P_W$ and $P_{W^\perp}^2=P_{W^\perp}$ give the sum, which is $I$.
:::

:::

::: pf-step
Combining self-adjointness and the involution property $U^2 = I$:
$$U^* U = U U = U^2 = I \quad \text{and} \quad U U^* = U^2 = I.$$

::: pf-proof
Since $U^*=U$, the product $U^*U$ equals $U^2$.
:::

:::

::: pf-step
Therefore $U$ is unitary (and orthogonal in the real case).

::: pf-proof
An operator satisfying $U^*U=I$ is unitary, and in the real case orthogonal.
:::

:::

:::

:::

::: pf-step
Part (b): Matrix of $U$ on $\RR^3$ for $W = \operatorname{span}\{(1, 0, 1)\}$.

::: pf-proof

::: pf-step
Let $w_1 = (1, 0, 1)$. The norm squared is $\norm{w_1}^2 = 1^2 + 0^2 + 1^2 = 2$.

::: pf-proof
Summing the squares of the entries of $w_1$.
:::

:::

::: pf-step
The orthogonal projection of $\alpha = (x, y, z) \in \RR^3$ onto $W$ is
$$P_W(x, y, z) = \frac{\langle (x, y, z), (1, 0, 1) \rangle}{\norm{w_1}^2} w_1 = \frac{x + z}{2} (1, 0, 1) = \left( \frac{x + z}{2}, 0, \frac{x + z}{2} \right).$$

::: pf-proof
The projection onto the line spanned by $w_1$ is $\langle\alpha,w_1\rangle/\norm{w_1}^2$ times $w_1$, and the inner product $\langle\alpha,w_1\rangle$ is $x+z$.
:::

:::

::: pf-step
Applying $U = 2P_W - I$:
$$U(x, y, z) = 2 \left( \frac{x + z}{2}, 0, \frac{x + z}{2} \right) - (x, y, z) = (x + z, 0, x + z) - (x, y, z) = (z, -y, x).$$

::: pf-proof
Substituting the projection into $U=2P_W-I$ and subtracting the identity coordinatewise.
:::

:::

::: pf-step
Evaluating $U$ on the standard basis $\{e_1, e_2, e_3\}$ of $\RR^3$:
$$U(e_1) = U(1, 0, 0) = (0, 0, 1) = 0 e_1 + 0 e_2 + 1 e_3,$$
$$U(e_2) = U(0, 1, 0) = (0, -1, 0) = 0 e_1 - 1 e_2 + 0 e_3,$$
$$U(e_3) = U(0, 0, 1) = (1, 0, 0) = 1 e_1 + 0 e_2 + 0 e_3.$$

::: pf-proof
Substituting the three standard basis vectors into the formula just obtained.
:::

:::

::: pf-step
Writing the image vectors as columns yields the matrix of $U$ with respect to the standard ordered basis:
$$[U] = \begin{bmatrix}
0 & 0 & 1 \\
0 & -1 & 0 \\
1 & 0 & 0
\end{bmatrix}.$$

::: pf-proof
The columns of the matrix of an operator in the standard basis are the images of the basis vectors.
:::

:::

:::

:::

::: pf-step
Conclusion:

::: pf-proof
$U$ is self-adjoint ($U^* = U$) and unitary ($U^* U = I$), and its standard matrix representation is $\begin{bmatrix} 0 & 0 & 1 \\ 0 & -1 & 0 \\ 1 & 0 & 0 \end{bmatrix}$.
:::

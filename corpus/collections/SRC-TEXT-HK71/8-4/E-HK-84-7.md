::: {.exercise}
Let $V$ be a complex inner product space and $T$ a self-adjoint linear operator on $V$.
Show that

(a) $||\alpha + iT\alpha|| = ||\alpha - iT\alpha||$ for every $\alpha$ in $V$.

(b) $\alpha + iT\alpha = \beta + iT\beta$ if and only if $\alpha = \beta$.

(c) $I + iT$ is non-singular.

(d) $I - iT$ is non-singular.

(e) Now suppose $V$ is finite-dimensional, and prove that
\[
U = (I - iT)(I + iT)^{-1}
\]
is a unitary operator; $U$ is called the Cayley transform of $T$.
In a certain sense, $U = f(T)$, where $f(x) = (1 - ix)/(1 + ix)$.
:::

::: {.solution}
**Goal.** For a self-adjoint operator $T$, prove the five facts about $I \pm iT$ and the Cayley transform $U = (I - iT)(I + iT)^{-1}$.

::: pf

::: {.pf-step #s1}
(a) $\|\alpha + iT\alpha\| = \|\alpha - iT\alpha\|$.

::: pf-proof

::: pf-step
$\|\alpha + iT\alpha\|^2 = \langle \alpha + iT\alpha, \alpha + iT\alpha\rangle$.

::: pf-proof
definition of the norm.
:::

:::

::: pf-step
Expanding: $\|\alpha\|^2 + \langle \alpha, iT\alpha\rangle + \langle iT\alpha, \alpha\rangle + \|T\alpha\|^2$.

::: pf-proof
bilinearity of the inner product.
:::

:::

::: pf-step
$\langle \alpha, iT\alpha\rangle = -i\langle \alpha, T\alpha\rangle$ and $\langle iT\alpha, \alpha\rangle = i\langle T\alpha, \alpha\rangle = i\langle \alpha, T\alpha\rangle$ (since $T$ is self-adjoint).

::: pf-proof
conjugate-linearity in the first slot and self-adjointness.
:::

:::

::: {.pf-step #s1-4}
Hence $\|\alpha + iT\alpha\|^2 = \|\alpha\|^2 + \|T\alpha\|^2$.

::: pf-proof
the cross terms cancel.
:::

:::

::: {.pf-step #s1-5}
Similarly $\|\alpha - iT\alpha\|^2 = \|\alpha\|^2 + \|T\alpha\|^2$.

::: pf-proof
same computation with $-i$ in place of $i$.
:::

:::

::: pf-step
Hence the two norms are equal.

::: pf-proof
steps [](#s1-4){.pf-ref} and [](#s1-5){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s2}
(b) $\alpha + iT\alpha = \beta + iT\beta$ iff $\alpha = \beta$.

::: pf-proof

::: pf-step
$\alpha + iT\alpha = \beta + iT\beta$ implies $(\alpha - \beta) + iT(\alpha - \beta) = 0$.

::: pf-proof
subtract.
:::

:::

::: {.pf-step #s2-2}
Then $\|(\alpha - \beta) + iT(\alpha - \beta)\| = 0$, so by (a) $\|(\alpha-\beta) - iT(\alpha-\beta)\| = 0$.

::: pf-proof
apply (a) to $\alpha - \beta$.
:::

:::

::: pf-step
Adding the two equations $(\alpha-\beta) + iT(\alpha-\beta) = 0$ and $(\alpha-\beta) - iT(\alpha-\beta) = 0$ gives $2(\alpha - \beta) = 0$, so $\alpha = \beta$.

::: pf-proof
the second equation follows from step [](#s2-2){.pf-ref} (a vector of norm zero is zero).
:::

:::

:::

:::

::: {.pf-step #s3}
(c) $I + iT$ is nonsingular.

::: pf-proof

::: pf-step
If $(I + iT)\alpha = 0$, then $\alpha + iT\alpha = 0$, so $\alpha = 0$ by (b).

::: pf-proof
(b) with $\beta = 0$.
:::

:::

::: pf-step
Hence $I + iT$ is injective, so nonsingular.

::: pf-proof
a linear operator with trivial kernel is nonsingular.
:::

:::

:::

:::

::: {.pf-step #s4}
(d) $I - iT$ is nonsingular.

::: pf-proof

::: pf-step
If $(I - iT)\alpha = 0$, then $\alpha - iT\alpha = 0$, so $\alpha = 0$ by (b) (with $T$ replaced by $-T$, which is also self-adjoint).

::: pf-proof
same argument as (c).
:::

:::

:::

:::

::: {.pf-step #s5}
(e) $U = (I - iT)(I + iT)^{-1}$ is unitary (for $V$ finite-dimensional).

::: pf-proof

::: pf-step
$U^* = (I + iT)^{-1}(I - iT)^* = (I + iT)^{-1}(I + iT)$.

::: pf-proof
$(I - iT)^* = I + iT$ (since $T^* = T$), and $(I + iT)^{-1}$ commutes with $I - iT$ (both are polynomials in $T$).
:::

:::

::: pf-step
$U^* U = (I + iT)^{-1}(I + iT)(I - iT)(I + iT)^{-1} = I$.

::: pf-proof
$(I + iT)$ and $(I - iT)$ commute (polynomials in $T$), so the middle terms cancel.
:::

:::

::: pf-step
Hence $U$ is unitary.

::: pf-proof
$U^* U = I$ (and $U U^* = I$ similarly).
:::

:::

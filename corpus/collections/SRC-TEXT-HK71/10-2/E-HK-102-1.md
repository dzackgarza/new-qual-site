::: {.exercise}
The following expressions define quadratic forms $q(x) = q(x_1, x_2)$ on $\RR^2$.
Find the symmetric bilinear form $f(x, y)$ corresponding to each quadratic form $q$:

(a) $q(x) = a x_1^2$

(b) $q(x) = b x_1 x_2$

(c) $q(x) = c x_2^2$

(d) $q(x) = 2 x_1^2 - \frac{1}{3} x_1 x_2$

(e) $q(x) = x_1^2 + 9 x_2^2$

(f) $q(x) = 3 x_1 x_2 - x_2^2$

(g) $q(x) = 4 x_1^2 + 6 x_1 x_2 - 3 x_2^2$
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §10.2 Exercise 1, printed p. 372. The form is recovered from $q$ by the polarization identity (10-5) on printed p. 368,
$$
f(x,y)=\frac{1}{2}\bigl[q(x+y)-q(x)-q(y)\bigr],
$$
and the four items are answered in order.

::: pf

::: pf-step
Polarization Identity on $\RR^2$:

::: pf-proof

::: pf-step
A general quadratic form on $\RR^2$ is given by:
$$q(x) = A x_1^2 + 2B x_1 x_2 + C x_2^2 = x^T \begin{bmatrix} A & B \\ B & C \end{bmatrix} x.$$
:::

::: pf-step
The unique symmetric bilinear form $f: \RR^2 \times \RR^2 \to \RR$ satisfying $f(x, x) = q(x)$ is given by:
$$f(x, y) = x^T \begin{bmatrix} A & B \\ B & C \end{bmatrix} y = A x_1 y_1 + B(x_1 y_2 + x_2 y_1) + C x_2 y_2.$$
:::

::: pf-step
In particular, pure quadratic terms $x_i^2$ polarize to $x_i y_i$, and cross terms $x_1 x_2$ polarize to $\frac{1}{2}(x_1 y_2 + x_2 y_1)$.
:::

:::

:::

::: pf-step
Computations for Each Part:

::: pf-proof

::: pf-step
**Part (a): $q(x) = a x_1^2$**
- Matrix: $\begin{bmatrix} a & 0 \\ 0 & 0 \end{bmatrix}$.
- Symmetric form: $f(x, y) = a x_1 y_1$.
:::

::: pf-step
**Part (b): $q(x) = b x_1 x_2$**
- Matrix: $\begin{bmatrix} 0 & b/2 \\ b/2 & 0 \end{bmatrix}$.
- Symmetric form: $f(x, y) = \frac{b}{2}(x_1 y_2 + x_2 y_1)$.
:::

::: pf-step
**Part (c): $q(x) = c x_2^2$**
- Matrix: $\begin{bmatrix} 0 & 0 \\ 0 & c \end{bmatrix}$.
- Symmetric form: $f(x, y) = c x_2 y_2$.
:::

::: pf-step
**Part (d): $q(x) = 2 x_1^2 - \frac{1}{3} x_1 x_2$**
- Matrix: $\begin{bmatrix} 2 & -1/6 \\ -1/6 & 0 \end{bmatrix}$.
- Symmetric form: $f(x, y) = 2 x_1 y_1 - \frac{1}{6}(x_1 y_2 + x_2 y_1)$.
:::

::: pf-step
**Part (e): $q(x) = x_1^2 + 9 x_2^2$**
- Matrix: $\begin{bmatrix} 1 & 0 \\ 0 & 9 \end{bmatrix}$.
- Symmetric form: $f(x, y) = x_1 y_1 + 9 x_2 y_2$.
:::

::: pf-step
**Part (f): $q(x) = 3 x_1 x_2 - x_2^2$**
- Matrix: $\begin{bmatrix} 0 & 3/2 \\ 3/2 & -1 \end{bmatrix}$.
- Symmetric form: $f(x, y) = \frac{3}{2}(x_1 y_2 + x_2 y_1) - x_2 y_2$.
:::

::: pf-step
**Part (g): $q(x) = 4 x_1^2 + 6 x_1 x_2 - 3 x_2^2$**
- Matrix: $\begin{bmatrix} 4 & 3 \\ 3 & -3 \end{bmatrix}$.
- Symmetric form: $f(x, y) = 4 x_1 y_1 + 3(x_1 y_2 + x_2 y_1) - 3 x_2 y_2$.
:::

:::

:::

::: pf-step
Conclusion:
The symmetric bilinear forms are obtained by polarizing $x_i^2 \mapsto x_i y_i$ and $x_1 x_2 \mapsto \frac{1}{2}(x_1 y_2 + x_2 y_1)$.
:::

::: {.exercise}
Let $M$ be an $n \times n$ matrix over $\CC$ with columns $M_1, M_2, \ldots, M_n$.
Show that $M$ belongs to $O(n, \CC)$ if and only if
$$
M_j^tM_k = \delta_{jk}.
$$
:::


::: {.solution}
No retained solution set covers this exercise: the collection's provenance is an archive.org record, so the argument is the card's own. Let $M\in M_n(\CC)$ with columns $M_1,\dots,M_n$, so that $M_{rj}$ is the $r$-th entry of $M_j$, and let $O(n,\CC)=\{M:M^{t}M=I\}$.

::: pf

::: {.pf-step #entry}
The $(j,k)$ entry of $M^{t}M$ is $\sum_{r=1}^{n}M_{rj}M_{rk}=M_j^{t}M_k$.

::: pf-proof
By the definition of matrix multiplication, $(M^{t}M)_{jk}=\sum_{r}(M^{t})_{jr}M_{rk}$, and $(M^{t})_{jr}=M_{rj}$ by the definition of the transpose. The column $M_j$ is the vector $(M_{1j},\dots,M_{nj})^{t}$, so $M_j^{t}M_k=\sum_rM_{rj}M_{rk}$, the same number.
:::

:::

::: {.pf-step #identity}
$M^{t}M=I$ if and only if $(M^{t}M)_{jk}=\delta_{jk}$ for all $j,k$.

::: pf-proof
Two matrices are equal exactly when all their entries agree, and the $(j,k)$ entry of $I$ is $\delta_{jk}$.
:::

:::

::: {.pf-step}
$M\in O(n,\CC)$ if and only if $M_j^{t}M_k=\delta_{jk}$ for all $j,k$.

::: pf-proof
Combine: $M\in O(n,\CC)$ means $M^{t}M=I$ by the definition of the set, which by step [](#identity){.pf-ref} holds exactly when all entries of $M^{t}M$ are the deltas, and by step [](#entry){.pf-ref} those entries are $M_j^{t}M_k$. So the two conditions are the same, for every $M$.
:::

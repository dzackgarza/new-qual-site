::: {.exercise}
Let $F$ be a field.
We have considered certain special linear functionals on $F[x]$ obtained via 'evaluation at $t$':
$$
L(f) = f(t).
$$
Such functionals are not only linear but also have the property that $L(fg) = L(f)L(g)$.
Prove that if $L$ is any linear functional on $F[x]$ such that
$$
L(fg) = L(f)L(g)
$$
for all $f$ and $g$, then either $L = 0$ or there is a $t$ in $F$ such that $L(f) = f(t)$ for all $f$.
:::

::: {.solution}

The argument is the card's own: a multiplicative linear functional is forced to be evaluation at $L(x)$, because $x-t$ divides every polynomial modulo its value at $t$.

::: pf

::: {.pf-step #unit}

$L(1)\in\{0,1\}$, and if $L(1)=0$ then $L=0$.

::: pf-proof

$L(1)=L(1\cdot1)=L(1)L(1)$, so $L(1)$ is a solution of $z^{2}=z$ in the field $F$, that is $L(1)(L(1)-1)=0$, and a field has no zero divisors: $L(1)=0$ or $L(1)=1$. If $L(1)=0$, then for every $f$ we have $L(f)=L(f\cdot1)=L(f)L(1)=0$, so $L$ is the zero functional.

:::

:::

::: {.pf-step #normalise}

If $L\ne0$ then $L(1)=1$.

::: pf-proof

By step [](#unit){.pf-ref}, $L(1)\in\{0,1\}$, and $L(1)=0$ forces $L=0$. So under the hypothesis $L\ne0$ we have $L(1)=1$. In particular $L$ is not identically zero on the constant polynomials.

:::

:::

::: {.pf-step #annihilates}

With $t=L(x)$, $L\big((x-t)g\big)=0$ for every $g\in F[x]$.

::: pf-proof

$L$ is additive and $F$-linear, so $L\big((x-t)g\big)=L(xg)-tL(g)$; and multiplicativity gives $L(xg)=L(x)L(g)=tL(g)$. Hence $L\big((x-t)g\big)=tL(g)-tL(g)=0$, using $t=L(x)\in F$.

:::

:::

::: {.pf-step #evaluation}

$L(f)=f(t)$ for every $f\in F[x]$, where $t=L(x)$.

::: pf-proof

The divisor $x-t$ is monic of degree $1$, so division with remainder in $F[x]$ gives $f=(x-t)q+c$ with $q\in F[x]$ and a constant $c\in F$; evaluating at $t$ gives $c=f(t)$. Then, by linearity and step [](#normalise){.pf-ref},
$$
L(f)=L\big((x-t)q\big)+c\,L(1)=0+c=f(t),
$$
the first term vanishing by step [](#annihilates){.pf-ref}.

:::

:::

::: {.pf-step #conclusion}

Either $L=0$ or $L$ is evaluation at some $t\in F$.

::: pf-proof

Steps [](#unit){.pf-ref} and [](#evaluation){.pf-ref} cover the two cases:
$$
\boxed{L=0\quad\text{or}\quad L(f)=f(t)\ \text{for all } f\in F[x],\ \text{where } t=L(x).}
$$

:::

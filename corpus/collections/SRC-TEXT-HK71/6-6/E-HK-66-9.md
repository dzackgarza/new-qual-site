::: {.exercise}
Let $V$ be a real vector space and $E$ an idempotent linear operator on $V$, i.e., a projection.
Prove that $(I + E)$ is invertible.
Find $(I + E)^{-1}$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own. The exercise is Hoffman--Kunze, *Linear Algebra* (1971), Chapter 6 §6.7 Exercise 9, where the running head reads "Sec. 6.7"; the collection index's comment ``Hoffman and Kunze 6.6.9'' does not match the printed page, as the note below records.

::: pf

::: {.pf-step #left}
$\left(I-\tfrac12E\right)(I+E)=I$.

::: pf-proof
By distributivity the product is $I+E-\tfrac12E-\tfrac12E^2$, and $E^2=E$ by idempotence, so it is $I+E-\tfrac12E-\tfrac12E=I$.
:::
:::

::: {.pf-step #right}
$(I+E)\left(I-\tfrac12E\right)=I$.

::: pf-proof
The same expansion in the other order: $I-\tfrac12E+E-\tfrac12E^2=I+\tfrac12E-\tfrac12E=I$.
:::
:::

::: {.pf-step #inverse}
$I+E$ is invertible with $(I+E)^{-1}=I-\tfrac12E$.

::: pf-proof
Steps [](#left){.pf-ref} and [](#right){.pf-ref} exhibit a two-sided inverse $I-\tfrac12E$. The scalar $\tfrac12$ exists because $V$ is a real vector space, so $2$ is invertible in the field, and an operator with a two-sided inverse is invertible with that inverse.
:::
:::

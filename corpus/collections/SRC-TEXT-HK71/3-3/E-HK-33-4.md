::: {.exercise}
Show that $F^{m \times n}$ is isomorphic to $F^{mn}$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is an archive.org record, so the argument is the card's own. Fix $m,n\ge1$ and write $A=(A_{ij})$ for the entries of a matrix $A\in F^{m\times n}$.

::: pf

::: {.pf-step #map}
The row-by-row listing $\Phi(A)=(A_{11},\dots,A_{1n},A_{21},\dots,A_{mn})$ is a linear map $F^{m\times n}\to F^{mn}$.

::: pf-proof
$\Phi$ is defined on every matrix, since a matrix has exactly $mn$ entries in the displayed order, and two matrices are equal exactly when their entry lists agree, so $\Phi$ is well defined and single valued. For linearity let $A,B\in F^{m\times n}$ and $c\in F$. Entrywise, $(A+B)_{ij}=A_{ij}+B_{ij}$ and $(cA)_{ij}=cA_{ij}$, and the $ij$-th slot of the list is the $((i-1)n+j)$-th coordinate, so
$$
\Phi(A+B)=\Phi(A)+\Phi(B),\qquad \Phi(cA)=c\,\Phi(A).
$$
:::

:::

::: {.pf-step #injective}
$\Phi(A)=0$ implies $A=0$; hence $\Phi$ is injective.

::: pf-proof
If $\Phi(A)$ is the zero $mn$-tuple then $A_{ij}=0$ for every $i,j$, that is $A=0$. A linear map with trivial kernel is injective: if $\Phi(A)=\Phi(B)$ then $\Phi(A-B)=0$ by step [](#map){.pf-ref}, so $A-B=0$ and $A=B$.
:::

:::

::: {.pf-step #dimension}
$\dim_F F^{mn}=mn$ and $\dim_F F^{m\times n}=mn$.

::: pf-proof
$F^{mn}$ is the space of $mn$-tuples, with the standard basis of $mn$ unit vectors. On the matrix side let $E_{ij}$ be the matrix with $1$ in position $ij$ and $0$ elsewhere, for $1\le i\le m$, $1\le j\le n$; there are $mn$ of them. They span, because $A=\sum_{ij}A_{ij}E_{ij}$, and they are independent, because evaluating that sum at the entry $ij$ gives $A_{ij}=0$. Hence they form a basis of $F^{m\times n}$ and the dimension is $mn$.
:::

:::

::: {.pf-step}
$\Phi$ is an isomorphism, so $F^{m\times n}\cong F^{mn}$.

::: pf-proof
An injective linear map between finite-dimensional spaces of the same dimension is onto: by rank-nullity $\dim\ker\Phi+\dim\operatorname{im}\Phi=\dim F^{m\times n}=mn$, and $\dim\ker\Phi=0$ by step [](#injective){.pf-ref}, so $\dim\operatorname{im}\Phi=mn=\dim F^{mn}$, which with $\operatorname{im}\Phi\subseteq F^{mn}$ forces $\operatorname{im}\Phi=F^{mn}$. Therefore $\Phi$ is a bijective linear map, that is an isomorphism of vector spaces.
:::

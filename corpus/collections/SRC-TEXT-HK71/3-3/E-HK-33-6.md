::: {.exercise}
Let $V$ and $W$ be finite-dimensional vector spaces over the field $F$.
Prove that $V$ and $W$ are isomorphic if and only if $\dim V = \dim W$.
:::

::: {.solution}

The argument is the card's own: an isomorphism carries a basis to a basis, and a linear map is determined by, and exists for, any prescribed values on a basis.

::: pf

::: {.pf-step #forward}

If $V\cong W$ then $\dim V=\dim W$.

::: pf-proof

Let $T:V\to W$ be an isomorphism and let $\alpha_{1},\dots,\alpha_{n}$ be a basis of $V$, so $n=\dim V$. The list $T\alpha_{1},\dots,T\alpha_{n}$ spans $W$, because any $w\in W$ is $Tv$ for some $v=\sum_{i}c_{i}\alpha_{i}$ by surjectivity, and then $w=\sum_{i}c_{i}T\alpha_{i}$ by linearity. It is linearly independent, because $\sum_{i}c_{i}T\alpha_{i}=0$ gives $T\big(\sum_{i}c_{i}\alpha_{i}\big)=0$, hence $\sum_{i}c_{i}\alpha_{i}=0$ by injectivity, hence all $c_{i}=0$. So it is a basis of $W$ with $n$ elements and $\dim W=n=\dim V$.

:::

:::

::: {.pf-step #backward}

If $\dim V=\dim W=n$ then there is an isomorphism $V\to W$.

::: pf-proof

Choose bases $\alpha_{1},\dots,\alpha_{n}$ of $V$ and $\beta_{1},\dots,\beta_{n}$ of $W$; both lists have length $n$ precisely because the dimensions agree. By the theorem that a linear map is determined by its values on a basis, there is a linear $T:V\to W$ with $T\alpha_{j}=\beta_{j}$ for every $j$. It is surjective, since a general element $\sum_{j}c_{j}\beta_{j}$ of $W$ is $T\big(\sum_{j}c_{j}\alpha_{j}\big)$; and it is injective, since $T\big(\sum_{j}c_{j}\alpha_{j}\big)=0$ forces $\sum_{j}c_{j}\beta_{j}=0$, which forces all $c_{j}=0$ because the $\beta_{j}$ are independent, hence $\sum_{j}c_{j}\alpha_{j}=0$. So $T$ is an isomorphism.

:::

:::

::: {.pf-step #conclusion}

$V$ and $W$ are isomorphic if and only if $\dim V=\dim W$.

::: pf-proof

Steps [](#forward){.pf-ref} and [](#backward){.pf-ref} give the two implications, so
$$
\boxed{V\cong W\iff\dim V=\dim W.}
$$

:::

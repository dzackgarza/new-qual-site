::: {.exercise}
Let $V$ be the set of complex numbers and let $F$ be the field of real numbers.
With the usual operations, $V$ is a vector space over $F$.
Describe explicitly an isomorphism of this space onto $\RR^2$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §3.3 Exercise 1, p. 85.

::: pf

::: {.pf-step #map}
The formula $\varphi(x+iy)\coloneqq(x,y)$ defines a function $\varphi:\CC\to\RR^2$.

::: pf-proof
Every complex number has a unique expression $x+iy$ with $x,y\in\RR$, so the formula assigns exactly one element of $\RR^2$ to each element of $\CC$.
:::
:::

::: {.pf-step #bijective}
$\varphi$ is bijective.

::: pf-proof
Let $\psi(x,y)\coloneqq x+iy$. Then $\varphi(\psi(x,y))=(x,y)$ and $\psi(\varphi(x+iy))=x+iy$ by the uniqueness of the real and imaginary parts, so $\varphi$ has the two-sided inverse $\psi$ and is bijective.
:::
:::

::: {.pf-step #additive}
$\varphi(z+w)=\varphi(z)+\varphi(w)$ for $z,w\in\CC$.

::: pf-proof
Write $z=x+iy$ and $w=u+iv$. Then $z+w=(x+u)+i(y+v)$, so $\varphi(z+w)=(x+u,y+v)=(x,y)+(u,v)=\varphi(z)+\varphi(w)$.
:::
:::

::: {.pf-step #homogeneous}
$\varphi(cz)=c\varphi(z)$ for $c\in\RR$ and $z\in\CC$.

::: pf-proof
$c(x+iy)=cx+icy$, so $\varphi(cz)=(cx,cy)=c(x,y)=c\varphi(z)$.
:::
:::

::: {.pf-step}
$\varphi$ is an isomorphism of real vector spaces from $\CC$ onto $\RR^2$.

::: pf-proof
Steps [](#additive){.pf-ref} and [](#homogeneous){.pf-ref} make $\varphi$ linear over $\RR$ and step [](#bijective){.pf-ref} makes it bijective; a bijective linear map is an isomorphism.
:::
:::

::: {.exercise}
Let $W_1$ and $W_2$ be subspaces of a vector space $V$ such that $W_1 + W_2 = V$ and $W_1 \cap W_2 = \{0\}$.
Prove that for each vector $\alpha$ in $V$ there are unique vectors $\alpha_1$ in $W_1$ and $\alpha_2$ in $W_2$ such that $\alpha = \alpha_1 + \alpha_2$.
:::


::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, checked against Hoffman--Kunze, *Linear Algebra* (1971), §2.2 Exercise 9.

::: pf

::: {.pf-step #existence}
Every $\alpha\in V$ has the form $\alpha_1+\alpha_2$ with $\alpha_1\in W_1$ and $\alpha_2\in W_2$.

::: pf-proof
$W_1+W_2$ is by definition the set of all sums $\alpha_1+\alpha_2$ with $\alpha_1\in W_1$ and $\alpha_2\in W_2$, and the hypothesis is $W_1+W_2=V$.
:::
:::

::: {.pf-step #uniqueness}
If $\alpha_1+\alpha_2=\beta_1+\beta_2$ with $\alpha_j,\beta_j\in W_j$, then $\alpha_1=\beta_1$ and $\alpha_2=\beta_2$.

::: pf-proof
Rearranging gives $\alpha_1-\beta_1=\beta_2-\alpha_2$. The left side lies in $W_1$ and the right side in $W_2$, since a subspace contains the difference of any two of its elements; so the common value lies in $W_1\cap W_2=\{0\}$. Hence $\alpha_1=\beta_1$ and $\alpha_2=\beta_2$.
:::
:::

::: {.pf-step}
Each $\alpha\in V$ is $\alpha_1+\alpha_2$ for exactly one pair $(\alpha_1,\alpha_2)\in W_1\times W_2$.

::: pf-proof
Step [](#existence){.pf-ref} produces one such pair for each $\alpha$ and step [](#uniqueness){.pf-ref} shows that any two such pairs coincide.
:::
:::

::: {.exercise}
Let $V$ be the (real) vector space of all functions $f$ from $\RR$ into $\RR$.
Which of the following sets of functions are subspaces of $V$?

(a) all $f$ such that $f(x^2) = f(x)^2$;

(b) all $f$ such that $f(0) = f(1)$;

(c) all $f$ such that $f(3) = 1 + f(-5)$;

(d) all $f$ such that $f(-1) = 0$;

(e) all $f$ which are continuous.
:::

::: {.solution}
::: pf

::: pf-step
A non-empty subset $W \subseteq V$ is a subspace if and only if it contains the zero function and is closed under addition and scalar multiplication.

::: pf-proof
subspace criterion for vector spaces.
:::

:::

::: {.pf-step #s2}
**Part (a):** The set $W_a = \{f \in V : f(x^2) = f(x)^2\}$ is **not a subspace**.

::: pf-proof

::: {.pf-step #s2-1}
Consider the identity function $f(x) = x$.

::: pf-proof
definition.
:::

:::

::: pf-step
$f(x^2) = x^2 = (x)^2 = f(x)^2$, so $f \in W_a$.

::: pf-proof
step [](#s2-1){.pf-ref}.
:::

:::

::: pf-step
Consider the scalar multiple $g = 2f$, so $g(x) = 2x$.

::: pf-proof
scalar multiplication in $V$.
:::

:::

::: {.pf-step #s2-4}
$g(x^2) = 2x^2$, whereas $g(x)^2 = (2x)^2 = 4x^2$.

::: pf-proof
direct computation.
:::

:::

::: {.pf-step #s2-5}
For $x = 1$, $g(1^2) = 2 \neq 4 = g(1)^2$, so $2f \notin W_a$.

::: pf-proof
step [](#s2-4){.pf-ref} evaluated at $x = 1$.
:::

:::

::: pf-step
Thus $W_a$ is not closed under scalar multiplication, so it is not a subspace.

::: pf-proof
step [](#s2-5){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s3}
**Part (b):** The set $W_b = \{f \in V : f(0) = f(1)\}$ is a **subspace**.

::: pf-proof

::: pf-step
Define the linear functional $T: V \to \mathbb{R}$ by $T(f) = f(0) - f(1)$.

::: pf-proof
$T(f + g) = (f+g)(0) - (f+g)(1) = T(f) + T(g)$ and $T(cf) = cT(f)$.
:::

:::

::: {.pf-step #s3-2}
$W_b = \ker(T) = \{f \in V : T(f) = 0\}$.

::: pf-proof
$f(0) = f(1) \iff f(0) - f(1) = 0$.
:::

:::

::: {.pf-step #s3-3}
The kernel of any linear transformation is a subspace.

::: pf-proof
standard linear algebra.
:::

:::

::: pf-step
Hence $W_b$ is a subspace of $V$.

::: pf-proof
steps [](#s3-2){.pf-ref} and [](#s3-3){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s4}
**Part (c):** The set $W_c = \{f \in V : f(3) = 1 + f(-5)\}$ is **not a subspace**.

::: pf-proof

::: pf-step
The zero function $0_V(x) = 0$ for all $x \in \mathbb{R}$.

::: pf-proof
definition of the zero vector in $V$.
:::

:::

::: pf-step
$0_V(3) = 0$, whereas $1 + 0_V(-5) = 1 + 0 = 1 \neq 0$.

::: pf-proof
arithmetic.
:::

:::

::: pf-step
Thus $0_V \notin W_c$, so $W_c$ is not a subspace.

::: pf-proof
every subspace must contain the zero vector.
:::

:::

:::

:::

::: {.pf-step #s5}
**Part (d):** The set $W_d = \{f \in V : f(-1) = 0\}$ is a **subspace**.

::: pf-proof

::: {.pf-step #s5-1}
Define the evaluation functional $\operatorname{ev}_{-1}: V \to \mathbb{R}$ by $\operatorname{ev}_{-1}(f) = f(-1)$.

::: pf-proof
$\operatorname{ev}_{-1}$ is a linear functional on $V$.
:::

:::

::: {.pf-step #s5-2}
$W_d = \ker(\operatorname{ev}_{-1})$.

::: pf-proof
definition of $W_d$.
:::

:::

::: pf-step
The kernel of a linear map is a subspace, so $W_d$ is a subspace of $V$.

::: pf-proof
steps [](#s5-1){.pf-ref} and [](#s5-2){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s6}
**Part (e):** The set $W_e = \{f \in V : f \text{ is continuous}\}$ is a **subspace**.

::: pf-proof

::: {.pf-step #s6-1}
The zero function $0_V$ is constant, hence continuous, so $0_V \in W_e$.

::: pf-proof
constant functions are continuous.
:::

:::

::: {.pf-step #s6-2}
If $f, g \in W_e$, then $f + g$ is continuous, so $f + g \in W_e$.

::: pf-proof
sum of continuous functions is continuous.
:::

:::

::: {.pf-step #s6-3}
If $f \in W_e$ and $c \in \mathbb{R}$, then $cf$ is continuous, so $cf \in W_e$.

::: pf-proof
product of a constant and a continuous function is continuous.
:::

:::

::: pf-step
Thus $W_e = C(\mathbb{R})$ is a subspace of $V$.

::: pf-proof
steps [](#s6-1){.pf-ref}, [](#s6-2){.pf-ref} and [](#s6-3){.pf-ref}.
:::

:::

:::

:::

::: pf-step
Conclusion: The subsets (b), (d), and (e) are subspaces of $V$, while (a) and (c) are not.

::: pf-proof
steps [](#s2){.pf-ref} through [](#s6){.pf-ref}.
:::

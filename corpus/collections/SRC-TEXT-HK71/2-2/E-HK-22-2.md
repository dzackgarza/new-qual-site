::: {.exercise}
Let $V$ be the (real) vector space of all functions $f$ from $\RR$ into $\RR$.
Which of the following sets of functions are subspaces of $V$?

(a) all $f$ such that $f(x^2) = f(x)^2$;

(b) all $f$ such that $f(0) = f(1)$;

(c) all $f$ such that $f(3) = 1 + f(-5)$;

(d) all $f$ such that $f(-1) = 0$;

(e) all $f$ which are continuous.
:::

::: {.solution}
<1>1. A non-empty subset $W \subseteq V$ is a subspace if and only if it contains the zero function and is closed under addition and scalar multiplication.
::: {.proof}
subspace criterion for vector spaces.
:::

<1>2. **Part (a):** The set $W_a = \{f \in V : f(x^2) = f(x)^2\}$ is **not a subspace**. <2>1. Consider the identity function $f(x) = x$.
::: {.proof}
definition.
:::
<2>2. $f(x^2) = x^2 = (x)^2 = f(x)^2$, so $f \in W_a$.
::: {.proof}
<2>1. <2>3. Consider the scalar multiple $g = 2f$, so $g(x) = 2x$.
:::
::: {.proof}
scalar multiplication in $V$.
:::
<2>4. $g(x^2) = 2x^2$, whereas $g(x)^2 = (2x)^2 = 4x^2$.
::: {.proof}
direct computation.
:::
<2>5. For $x = 1$, $g(1^2) = 2 \neq 4 = g(1)^2$, so $2f \notin W_a$.
::: {.proof}
<2>4 evaluated at $x = 1$.
:::
<2>6. Thus $W_a$ is not closed under scalar multiplication, so it is not a subspace.
::: {.proof}
<2>5.
:::

<1>3. **Part (b):** The set $W_b = \{f \in V : f(0) = f(1)\}$ is a **subspace**. <2>1. Define the linear functional $T: V \to \mathbb{R}$ by $T(f) = f(0) - f(1)$.
::: {.proof}
$T(f + g) = (f+g)(0) - (f+g)(1) = T(f) + T(g)$ and $T(cf) = cT(f)$.
:::
<2>2. $W_b = \ker(T) = \{f \in V : T(f) = 0\}$.
::: {.proof}
$f(0) = f(1) \iff f(0) - f(1) = 0$.
:::
<2>3. The kernel of any linear transformation is a subspace.
::: {.proof}
standard linear algebra.
:::
<2>4. Hence $W_b$ is a subspace of $V$.
::: {.proof}
<2>2 and <2>3.
:::

<1>4. **Part (c):** The set $W_c = \{f \in V : f(3) = 1 + f(-5)\}$ is **not a subspace**. <2>1. The zero function $0_V(x) = 0$ for all $x \in \mathbb{R}$.
::: {.proof}
definition of the zero vector in $V$.
:::
<2>2. $0_V(3) = 0$, whereas $1 + 0_V(-5) = 1 + 0 = 1 \neq 0$.
::: {.proof}
arithmetic.
:::
<2>3. Thus $0_V \notin W_c$, so $W_c$ is not a subspace.
::: {.proof}
every subspace must contain the zero vector.
:::

<1>5. **Part (d):** The set $W_d = \{f \in V : f(-1) = 0\}$ is a **subspace**. <2>1. Define the evaluation functional $\operatorname{ev}_{-1}: V \to \mathbb{R}$ by $\operatorname{ev}_{-1}(f) = f(-1)$.
::: {.proof}
$\operatorname{ev}_{-1}$ is a linear functional on $V$.
:::
<2>2. $W_d = \ker(\operatorname{ev}_{-1})$.
::: {.proof}
definition of $W_d$.
:::
<2>3. The kernel of a linear map is a subspace, so $W_d$ is a subspace of $V$.
::: {.proof}
<2>1 and <2>2.
:::

<1>6. **Part (e):** The set $W_e = \{f \in V : f \text{ is continuous}\}$ is a **subspace**. <2>1. The zero function $0_V$ is constant, hence continuous, so $0_V \in W_e$.
::: {.proof}
constant functions are continuous.
:::
<2>2. If $f, g \in W_e$, then $f + g$ is continuous, so $f + g \in W_e$.
::: {.proof}
sum of continuous functions is continuous.
:::
<2>3. If $f \in W_e$ and $c \in \mathbb{R}$, then $cf$ is continuous, so $cf \in W_e$.
::: {.proof}
product of a constant and a continuous function is continuous.
:::
<2>4. Thus $W_e = C(\mathbb{R})$ is a subspace of $V$.
::: {.proof}
<2>1–<2>3.
:::

<1>7. Conclusion: The subsets (b), (d), and (e) are subspaces of $V$, while (a) and (c) are not.
::: {.proof}
<1>2 through <1>6.
:::
Q.E.D.

::: {.exercise}
Let $A$ be an $n \times n$ matrix over a field $F$.
Show that the set of all polynomials $f$ in $F[x]$ such that $f(A) = 0$ is an ideal.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no solution set for it is retained in `tmp/sources`, so nothing here is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §4.4 Exercise 3.

Let $F[x]$ be the polynomial ring in one indeterminate over the field $F$, let $A$ be a fixed $n\times n$ matrix over $F$, and write $f(A)$ for the matrix obtained by substituting $A$ for $x$ in $f$.

::: pf

::: {.pf-step #evaluation}
The map $\varphi\colon F[x]\to M_{n}(F)$, $\varphi(f)=f(A)$, is a ring homomorphism with $\varphi(1)=I$.

::: pf-proof
For $f=\sum_{k}a_{k}x^{k}$ and $g=\sum_{k}b_{k}x^{k}$, the definitions of addition and multiplication in $F[x]$ give $(f+g)(A)=\sum_{k}(a_{k}+b_{k})A^{k}=f(A)+g(A)$ and $(fg)(A)=\sum_{k}\bigl(\sum_{i+j=k}a_{i}b_{j}\bigr)A^{k}=\sum_{i,j}a_{i}b_{j}A^{i+j}$. The last expression equals $\bigl(\sum_{i}a_{i}A^{i}\bigr)\bigl(\sum_{j}b_{j}A^{j}\bigr)$ because $A^{i}A^{j}=A^{i+j}$, powers of one matrix commuting with each other; so $(fg)(A)=f(A)g(A)$. The constant polynomial $1$ gives $A^{0}=I$.
:::

:::

::: {.pf-step #zero}
$0\in I=\{f\in F[x]\mid f(A)=0\}$.

::: pf-proof
The zero polynomial has all coefficients $0$, so its value at $A$ is the zero matrix.
:::

:::

::: {.pf-step #subtraction}
If $f,g\in I$ then $f-g\in I$.

::: pf-proof
By step [](#evaluation){.pf-ref}, $(f-g)(A)=f(A)-g(A)=0-0=0$.
:::

:::

::: {.pf-step #absorption}
If $h\in F[x]$ and $f\in I$ then $hf\in I$.

::: pf-proof
By step [](#evaluation){.pf-ref}, $(hf)(A)=h(A)f(A)=h(A)\cdot0=0$.
:::

:::

::: {.pf-step}
$I$ is an ideal of $F[x]$.

::: pf-proof
$I$ is additive subgroup by steps [](#zero){.pf-ref} and [](#subtraction){.pf-ref}, and it is closed under multiplication by an arbitrary element of $F[x]$ by step [](#absorption){.pf-ref}; that is the definition of an ideal. Equivalently, $I=\ker\varphi$ with $\varphi$ the homomorphism of step [](#evaluation){.pf-ref}, and kernels of ring homomorphisms are ideals.
:::

::: {.exercise}
Let $F$ be a field.
Show that the intersection of any number of ideals in $F[x]$ is an ideal.

:::

::: {.solution}
There is no retained solution set for this exercise; the book's text is retained in the checkout as `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf` (Hoffman and Kunze, *Linear Algebra*, 2nd ed., 1971), where it is §4.4 Exercise 5 on printed p. 134. The argument is the card's own.

Throughout, $F$ is a field, $F[x]$ its polynomial ring over $F$, and an ideal of $F[x]$ is a subspace of $F[x]$ that is closed under multiplication by every element of $F[x]$; in particular an ideal is a nonempty set containing $0$ and closed under subtraction.

::: pf

::: {.pf-step #zero}
$0\in I=\bigcap_{\lambda\in\Lambda}I_\lambda$, and $I$ is closed under subtraction.

::: pf-proof
Each $I_\lambda$ is a subspace, hence contains $0$, so $0$ lies in the intersection. If $f,g\in I$ then for each $\lambda$ both $f$ and $g$ lie in the subspace $I_\lambda$, so $f-g\in I_\lambda$; as $\lambda$ was arbitrary, $f-g\in I$.

:::

:::

::: {.pf-step #absorption}
If $h\in F[x]$ and $f\in I$ then $hf\in I$ and $fh\in I$.

::: pf-proof
For each $\lambda$, $f\in I_\lambda$ and $I_\lambda$ is closed under multiplication by elements of $F[x]$, so $hf\in I_\lambda$ and, since $F[x]$ is commutative, $fh=hf\in I_\lambda$. Hence both lie in every $I_\lambda$, that is in $I$.

:::

:::

::: {.pf-step #empty-family}
The case of an empty family gives $I=F[x]$, which is an ideal.

::: pf-proof
If $\Lambda=\varnothing$ then the intersection of the empty family is the whole set $F[x]$; it contains $0$, is closed under subtraction, and is closed under multiplication by elements of $F[x]$. So the statement holds for the empty family as well, which is what "any number" allows.

:::

:::

::: {.pf-step #ideal}
$I$ is an ideal of $F[x]$.

::: pf-proof
By steps [](#zero){.pf-ref} and [](#absorption){.pf-ref}, $I$ is a nonempty subset closed under subtraction and under multiplication by arbitrary elements of $F[x]$; by the definition that is an ideal, and the empty family is covered by step [](#empty-family){.pf-ref}.

:::

::: {.exercise}
Let $\QQ$ be the field of rational numbers.
Determine which of the following subsets of $Q[x]$ are ideals.
When the set is an ideal, find its monic generator.

(a) all $f$ of even degree;

(b) all $f$ of degree $\geq 5$;

(c) all $f$ such that $f(0) = 0$;

(d) all $f$ such that $f(2) = f(4) = 0$;

(e) all $f$ in the range of the linear operator $T$ defined by
\[
T\left(\sum_{i=0}^{n} c_i x^i\right) = \sum_{i=0}^{n} \frac{c_i}{i+1} x^{i+1}.
\]
:::

::: {.solution}
**(a) Not an ideal.**

::: pf

::: {.pf-step #a-x2-x3-example}
$x^2$ has even degree, but $x^2 \cdot x = x^3$ has odd degree.

::: pf-proof
the set of even-degree polynomials is not closed under multiplication by $x$.
:::

:::

::: {.pf-step #a-not-ideal}
Hence the set of even-degree polynomials is not an ideal.

::: pf-proof
Step [](#a-x2-x3-example){.pf-ref} (an ideal is closed under multiplication by any ring element).
:::

:::

:::

**(b) Not an ideal.**

::: pf

::: {.pf-step #b-not-closed-example}
$x^5$ has degree $5 \ge 5$, but $x^5 \cdot x^{-1}$ is not a polynomial, and more relevantly $x^5 - x^5 = 0$ has degree $-\infty < 5$.

::: pf-proof
the set is not closed under subtraction (the zero polynomial is not in it).
:::

:::

::: {.pf-step #b-not-ideal}
Hence the set of polynomials of degree $\ge 5$ is not an ideal.

::: pf-proof
Step [](#b-not-closed-example){.pf-ref} (an ideal must contain $0$ and be closed under subtraction).
:::

:::

:::

**(c) An ideal, generated by $x$.**

::: pf

::: pf-step
The set $\{f : f(0) = 0\}$ is the kernel of the evaluation map $\operatorname{ev}_0 : \QQ[x] \to \QQ$, $f \mapsto f(0)$.

::: pf-proof
definition.
:::

:::

::: pf-step
Hence it is an ideal.

::: pf-proof
the kernel of a ring homomorphism is an ideal.
:::

:::

::: {.pf-step #c-divisible-by-x}
$f(0) = 0$ iff $x \mid f$, so the ideal is $(x)$.

::: pf-proof
a polynomial vanishes at $0$ iff it has no constant term iff it is divisible by $x$.
:::

:::

::: {.pf-step #c-monic-generator}
The monic generator is $x$.

::: pf-proof
Step [](#c-divisible-by-x){.pf-ref}.
:::

:::

:::

**(d) An ideal, generated by $(x-2)(x-4)$.**

::: pf

::: pf-step
The set $\{f : f(2) = f(4) = 0\}$ is the kernel of the map $\QQ[x] \to \QQ \times \QQ$, $f \mapsto (f(2), f(4))$.

::: pf-proof
definition.
:::

:::

::: pf-step
Hence it is an ideal.

::: pf-proof
kernel of a ring homomorphism.
:::

:::

::: {.pf-step #d-divisible-by-product}
$f(2) = f(4) = 0$ iff $(x-2)(x-4) \mid f$.

::: pf-proof
$f(2) = 0$ iff $(x-2) \mid f$, and $f(4) = 0$ iff $(x-4) \mid f$; since $(x-2)$ and $(x-4)$ are coprime, both hold iff their product divides $f$.
:::

:::

::: {.pf-step #d-monic-generator}
The monic generator is $(x-2)(x-4)$.

::: pf-proof
Step [](#d-divisible-by-product){.pf-ref}.
:::

:::

:::

**(e) An ideal, generated by $x$.**

::: pf

::: pf-step
$T$ is the linear operator sending $x^i \mapsto \frac{1}{i+1} x^{i+1}$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #e-range-is-ideal-x}
The range of $T$ is $\{f \in \QQ[x] : f(0) = 0\}$, i.e. the polynomials with no constant term.

::: pf-proof
$T$ raises degree by $1$, so every output is divisible by $x$; conversely every $x^{i+1}$ (for $i \ge 0$) is in the range, so the range is exactly the ideal $(x)$.
:::

:::

::: {.pf-step #e-conclusion}
Hence the range is an ideal, with monic generator $x$.

::: pf-proof
Step [](#e-range-is-ideal-x){.pf-ref} and (c).
:::

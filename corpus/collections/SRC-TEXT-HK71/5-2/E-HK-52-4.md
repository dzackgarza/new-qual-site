::: {.exercise}
Let $A$ be a $2 \times 2$ matrix over a field $F$.
Show that $A$ is invertible if and only if $\det A \neq 0$.
When $A$ is invertible, give a formula for $A^{-1}$.
:::

::: {.solution}
The exercise is Hoffman and Kunze, *Linear Algebra* (1971), §5.2 Exercise 4, read in the retained copy at `assets/attachments/Hoffman-Kunze-Linear-Algebra.pdf`. No retained solution set covers it, so the argument is the card's own. Let
$$
A=\begin{bmatrix}a&b\\ c&d\end{bmatrix}\in M_2(F),\qquad \Delta=ad-bc=\det A,
$$
and let $B=\begin{bmatrix}d&-b\\ -c&a\end{bmatrix}$.

::: pf

::: {.pf-step #adjoint}
$AB=\Delta I_2$.

::: pf-proof
Entrywise, $(1,1)$ is $a\cdot d+b\cdot(-c)=ad-bc=\Delta$; $(1,2)$ is $a(-b)+b\cdot a=-ab+ab=0$; $(2,1)$ is $c\cdot d+d\cdot(-c)=cd-dc=0$; $(2,2)$ is $c(-b)+d\cdot a=-cb+da=ad-bc=\Delta$. So $AB=\Delta I_2$.
:::

:::

::: {.pf-step #inverse}
If $\Delta\ne0$ then $A$ is invertible and
$$
A^{-1}=\frac{1}{\Delta}\begin{bmatrix}d&-b\\ -c&a\end{bmatrix}=\frac1{\Delta}B .
$$

::: pf-proof
By step [](#adjoint){.pf-ref}, $A\bigl(\tfrac1\Delta B\bigr)=\tfrac1\Delta(AB)=I_2$. The scalar $\tfrac1\Delta$ exists because $\Delta\ne0$ in the field $F$. A square matrix with a right inverse is invertible, with that right inverse as its inverse: if $AC=I$ then $C$ is injective, hence bijective on the finite-dimensional space $F^2$, hence $C$ is invertible and $C^{-1}=A$. So $A^{-1}=\tfrac1\Delta B$.
:::

:::

::: {.pf-step #zero_first_row}
If $\Delta=0$ and $(a,b)=(0,0)$ then $A$ is not invertible.

::: pf-proof
With $a=b=0$ the first row is zero, so for every $x\in F^2$ the first coordinate of $Ax$ is $0\cdot x_1+0\cdot x_2=0$. Hence $\operatorname{im}A\subseteq\{0\}\times F$, a proper subspace of $F^2$; a surjective linear map has image all of $F^2$, so $A$ is not surjective and therefore not invertible.
:::

:::

::: {.pf-step #kernel_vector}
If $\Delta=0$ and $(a,b)\ne(0,0)$ then $A$ is not invertible.

::: pf-proof
Take $x=(-b,a)^{T}$, which is nonzero because $(a,b)\ne(0,0)$. Then
$$
Ax=\begin{bmatrix}a(-b)+ba\\ c(-b)+da\end{bmatrix}=\begin{bmatrix}0\\ ad-bc\end{bmatrix}=\begin{bmatrix}0\\ \Delta\end{bmatrix}=0
$$
because $\Delta=0$. So $A$ has a nonzero vector in its kernel, hence is not injective, hence not invertible.
:::

:::

::: {.pf-step}
$A$ is invertible if and only if $\det A\ne0$, and when it is, $A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\ -c&a\end{bmatrix}$.

::: pf-proof
If $\Delta\ne0$, step [](#inverse){.pf-ref} gives invertibility and the formula. If $\Delta=0$, then either $(a,b)=(0,0)$, which is step [](#zero_first_row){.pf-ref}, or $(a,b)\ne(0,0)$, which is step [](#kernel_vector){.pf-ref}; in both cases $A$ is not invertible. Since any pair $(a,b)$ falls in one of the two cases, $\det A=0$ excludes invertibility.
:::

::: {.exercise}
Let $\RR$ be the field of real numbers, and let $D$ be a function on $2 \times 2$ matrices over $\RR$, with values in $\RR$, such that $D(AB) = D(A)D(B)$ for all $A, B$.
Suppose also that
$$
D\left(\begin{bmatrix} 0 & 1 \\ 1 & 0 \end{bmatrix}\right) \neq D\left(\begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}\right).
$$
Prove the following.

(a) $D(0) = 0$;

(b) $D(A) = 0$ if $A^2 = 0$;

(c) $D(B) = -D(A)$ if $B$ is obtained by interchanging the rows (or columns) of $A$;

(d) $D(A) = 0$ if one row (or one column) of $A$ is 0;

(e) $D(A) = 0$ whenever $A$ is singular.
:::

::: {.solution}

The argument is the card's own: no copy of Hoffman and Kunze and no published solution set for it is retained in `tmp/sources`, so nothing below is transcribed. The statement is the exercise the collection index records as Hoffman and Kunze, *Linear Algebra* §5.2 Exercise 13. Here $D$ is a function on the $2\times2$ real matrices with $D(AB)=D(A)D(B)$ for all $A,B$, and $S=\begin{bmatrix}0&1\\1&0\end{bmatrix}$, $I=I_2$. The hypothesis is $D(S)\neq D(I)$.

::: pf

::: {.pf-step #values}

$D(I)=1$ and $D(S)=-1$.

::: pf-proof

If $D(I)=0$ then $D(A)=D(IA)=D(I)D(A)=0$ for every $A$, so $D$ is identically zero and $D(S)=D(I)$, contrary to the hypothesis; hence $D(I)\neq0$, and $D(I)=D(I\cdot I)=D(I)^{2}$ gives $D(I)=1$. Then $D(S)^{2}=D(S^{2})=D(I)=1$ because $S^{2}=I$, so $D(S)=\pm1$, and the hypothesis excludes $+1$.

:::

:::

::: {.pf-step #a}

(a) $D(0)=0$.

::: pf-proof

$D(0)=D(0\cdot0)=D(0)^{2}$, so $D(0)\in\theset{0,1}$. If $D(0)=1$ then for every $A$, $1=D(0)=D(0\cdot A)=D(0)D(A)=D(A)$, so $D$ is identically $1$ and $D(S)=D(I)$, contrary to the hypothesis. Hence $D(0)=0$.

:::

:::

::: {.pf-step #b}

(b) $D(A)=0$ whenever $A^{2}=0$.

::: pf-proof

Then $D(A)^{2}=D(A^{2})=D(0)=0$ by step [](#a){.pf-ref}, so $D(A)=0$ in $\RR$.

:::

:::

::: {.pf-step #c}

(c) If $B$ is obtained from $A$ by interchanging the two rows, or the two columns, then $D(B)=-D(A)$.

::: pf-proof

Interchanging the rows of $A$ gives $SA$, and interchanging the columns gives $AS$. Hence $D(SA)=D(S)D(A)=-D(A)$ and $D(AS)=D(A)D(S)=-D(A)$ by step [](#values){.pf-ref}.

:::

:::

::: {.pf-step #d}

(d) $D(A)=0$ if a row of $A$ is zero, and if a column of $A$ is zero.

::: pf-proof

If the first row is zero then $A=\begin{bmatrix}0&0\\1&0\end{bmatrix}\begin{bmatrix}a&b\\0&0\end{bmatrix}$ when $A=\begin{bmatrix}0&0\\a&b\end{bmatrix}$, and the first factor has square $0$, so its $D$-value is $0$ by step [](#b){.pf-ref} and $D(A)=0$; if the second row is zero, step [](#c){.pf-ref} reduces to the first case, $D(A)=-D(SA)=0$. If a column of $A$ is zero, say the first, then $A=A\begin{bmatrix}0&0\\0&1\end{bmatrix}$, the second factor having a zero row and hence $D$-value $0$ by the row case; if the second column is zero use $\begin{bmatrix}1&0\\0&0\end{bmatrix}$ instead.

:::

:::

::: {.pf-step #e}

(e) $D(A)=0$ whenever $A$ is singular.

::: pf-proof

If a row of $A$ is zero, step [](#d){.pf-ref} applies. Otherwise the two rows are linearly dependent, so with the first row $(a,b)$ the second is $(\lambda a,\lambda b)$ for some $\lambda\in\RR$, and $A=\begin{bmatrix}1&0\\\lambda&0\end{bmatrix}\begin{bmatrix}a&b\\0&0\end{bmatrix}$; the second factor has a zero row, so its $D$-value is $0$ by step [](#d){.pf-ref}, and $D(A)=0$.

:::

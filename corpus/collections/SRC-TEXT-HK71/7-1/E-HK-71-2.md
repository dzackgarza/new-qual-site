::: {.exercise}
Let $T$ be the linear operator on $\RR^3$ which is represented in the standard ordered basis by the matrix
$$
\begin{bmatrix} 2 & 0 & 0 \\ 0 & 2 & 0 \\ 0 & 0 & -1 \end{bmatrix}.
$$
Prove that $T$ has no cyclic vector.
What is the $T$-cyclic subspace generated by the vector $(1, -1, 3)$?
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, and the vectors below were recomputed for this pass.

Let $T$ be the operator on $\RR^{3}$ with matrix $A=\operatorname{diag}(2,2,-1)$ in the standard ordered basis, and for $v\in\RR^{3}$ let $Z(v;T)=\operatorname{span}\{v,Tv,T^{2}v,\dots\}$ be the $T$-cyclic subspace generated by $v$.

::: pf

::: {.pf-step #annihilator}
$q(T)=0$ for $q(x)=(x-2)(x+1)=x^{2}-x-2$; that is, $T^{2}=T+2I$.

::: pf-proof
A polynomial in a diagonal matrix is the diagonal matrix of the values of the polynomial at the diagonal entries: $q(A)=\operatorname{diag}\bigl(q(2),q(2),q(-1)\bigr)$. Now $q(2)=4-2-2=0$ and $q(-1)=1+1-2=0$, so $q(A)=0$ and $q(T)=0$. Rearranged, $T^{2}=T+2I$.
:::

:::

::: {.pf-step #powers}
For every $k\ge0$ there are reals $a_{k},b_{k}$ with $T^{k}=a_{k}T+b_{k}I$.

::: pf-proof
Induction on $k$: the cases $k=0,1$ are $T^{0}=I$ and $T^{1}=T$. If $T^{k}=a_{k}T+b_{k}I$, then using step [](#annihilator){.pf-ref},
$$
T^{k+1}=T(a_{k}T+b_{k}I)=a_{k}T^{2}+b_{k}T=a_{k}(T+2I)+b_{k}T=(a_{k}+b_{k})T+2a_{k}I,
$$
which has the required form.
:::

:::

::: {.pf-step #no-cyclic}
Every $T$-cyclic subspace of $\RR^{3}$ has dimension at most $2$, so $T$ has no cyclic vector.

::: pf-proof
Let $v\in\RR^{3}$. By step [](#powers){.pf-ref} each $T^{k}v$ lies in $\operatorname{span}\{v,Tv\}$, so $Z(v;T)\subseteq\operatorname{span}\{v,Tv\}$ and hence $\dim Z(v;T)\le2$. A cyclic vector for $T$ would have to satisfy $Z(v;T)=\RR^{3}$, of dimension $3$, which is impossible. (Equivalently, the factorization $q=(x-2)(x+1)$ of an annihilating polynomial into distinct linear factors means $T$ is diagonalizable with only two distinct eigenvalues, so no single vector can generate a three-dimensional space.)
:::

:::

::: {.pf-step}
For $v=(1,-1,3)$ one has $Z(v;T)=\operatorname{span}\{(1,-1,3),(2,-2,-3)\}=\operatorname{span}\{(1,-1,0),(0,0,1)\}$.

::: pf-proof
$Tv$ is $A$ applied to $v$, giving $(2,-2,-3)$, and the two vectors are linearly independent because the second is not a scalar multiple of the first (the last coordinates $3$ and $-3$ would force a scalar $-1$, but then the first coordinate would be $-1\ne2$). So $\operatorname{span}\{v,Tv\}$ is two-dimensional and, by the dimension bound of step [](#no-cyclic){.pf-ref}, $Z(v;T)=\operatorname{span}\{v,Tv\}$. Further, $v=(1,-1,0)+3(0,0,1)$ and $Tv=2(1,-1,0)-3(0,0,1)$, and conversely $(1,-1,0)=\frac{v+Tv}{3}$ and $(0,0,1)=\frac{2v-Tv}{9}$, so the two spans coincide and $Z(v;T)=\operatorname{span}\{(1,-1,0),(0,0,1)\}$.
:::

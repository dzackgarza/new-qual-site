::: {.exercise}
Prove that if $T^2$ has a cyclic vector, then $T$ has a cyclic vector.
Is the converse true?
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Let $v$ be a cyclic vector for $T^2$, so $\{v, T^2 v, T^4 v, \ldots\}$ spans $V$.

::: pf-proof

definition of cyclic vector.

:::

:::

::: {.pf-step #s2}

The cyclic subspace generated by $v$ under $T$ is $Z(v, T) = \operatorname{span}\{v, Tv, T^2 v, \ldots\}$.

::: pf-proof

definition.

:::

:::

::: {.pf-step #s3}

$Z(v, T)$ contains $\{v, T^2 v, T^4 v, \ldots\}$ (the even powers), which span $V$ by step [](#s1){.pf-ref}.

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref}.

:::

:::

::: {.pf-step #s4}

Hence $Z(v, T) = V$, so $v$ is a cyclic vector for $T$.

::: pf-proof

Step [](#s3){.pf-ref}.

:::

:::

::: pf-step

The converse is false.

::: pf-proof

answer to the second question.

:::

:::

::: {.pf-step #s6}

Counterexample: let $T$ be the operator on $\mathbb{R}^2$ given by $T(x, y) = (y, 0)$ (a nilpotent operator with $T^2 = 0$).

::: pf-proof

choose a counterexample.

:::

:::

::: {.pf-step #s7}

$T$ has a cyclic vector (e.g. $v = (1, 0)$, since $\{v, Tv\} = \{(1,0), (0,1)\}$ spans $\mathbb{R}^2$), but $T^2 = 0$ has no cyclic vector (its cyclic subspaces are all $1$-dimensional).

::: pf-proof

Step [](#s6){.pf-ref}.

:::

:::

::: {.pf-step #s8}

Hence the converse is false.

::: pf-proof

Step [](#s7){.pf-ref}.

:::

:::

::: pf-qed

Steps [](#s4){.pf-ref} and [](#s8){.pf-ref}.

:::

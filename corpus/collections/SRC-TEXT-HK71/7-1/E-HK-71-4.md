::: {.exercise}
Prove that if $T^2$ has a cyclic vector, then $T$ has a cyclic vector.
Is the converse true?
:::

::: {.solution}
<1>1. Let $v$ be a cyclic vector for $T^2$, so $\{v, T^2 v, T^4 v, \ldots\}$ spans $V$.
::: {.proof}
definition of cyclic vector.
:::

<1>2. The cyclic subspace generated by $v$ under $T$ is $Z(v, T) = \operatorname{span}\{v, Tv, T^2 v, \ldots\}$.
::: {.proof}
definition.
:::

<1>3. $Z(v, T)$ contains $\{v, T^2 v, T^4 v, \ldots\}$ (the even powers), which span $V$ by <1>1.
::: {.proof}
<1>1 and <1>2.
:::

<1>4. Hence $Z(v, T) = V$, so $v$ is a cyclic vector for $T$.
::: {.proof}
<1>3.
:::

<1>5. The converse is false.
::: {.proof}
answer to the second question.
:::

<1>6. Counterexample: let $T$ be the operator on $\mathbb{R}^2$ given by $T(x, y) = (y, 0)$ (a nilpotent operator with $T^2 = 0$).
::: {.proof}
choose a counterexample.
:::

<1>7. $T$ has a cyclic vector (e.g. $v = (1, 0)$, since $\{v, Tv\} = \{(1,0), (0,1)\}$ spans $\mathbb{R}^2$), but $T^2 = 0$ has no cyclic vector (its cyclic subspaces are all $1$-dimensional).
::: {.proof}
<1>6.
:::

<1>8. Hence the converse is false.
::: {.proof}
<1>7.
:::

<1>9. Q.E.D.
::: {.proof}
<1>4 and <1>8.
:::
:::

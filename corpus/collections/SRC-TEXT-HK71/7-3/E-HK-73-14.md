::: {.exercise}
What's wrong with the following proof?
If $A$ is a complex $n \times n$ matrix such that $A^t = -A$, then $A$ is 0. (Proof: Let $J$ be the Jordan form of $A$.
Since $A^t = -A$, $J^t = -J$.
But $J$ is triangular so that $J^t = -J$ implies that every entry of $J$ is zero.
Since $J = 0$ and $A$ is similar to $J$, we see that $A = 0$.)
(Give an example of a non-zero $A$ such that $A^t = -A$.)
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §7.3 Exercise 14 [@HK71].

::: pf

::: {.pf-step #error}
The proof's error is the step $J^{t}=-J$: it does not follow from $A^{t}=-A$ and $J=P^{-1}AP$.

:::: pf-proof

::: {.pf-step #compute}
$J^{t}=-P^{t}A(P^{-1})^{t}$, whereas $-J=-P^{-1}AP$.

::: pf-proof
$J^{t}=(P^{-1}AP)^{t}=P^{t}A^{t}(P^{-1})^{t}$, and $A^{t}=-A$ gives $P^{t}A^{t}(P^{-1})^{t}=-P^{t}A(P^{-1})^{t}$. The other side is $-J=-P^{-1}AP$ by definition of $J$.
:::

:::

::: {.pf-step #similar}
$J^{t}$ is similar to $-J$, but not equal to it in general.

::: pf-proof
Since $(P^{-1})^{t}=(P^{t})^{-1}$, the matrix $P^{t}A(P^{-1})^{t}=P^{t}A(P^{t})^{-1}$ is a conjugate of $A$, so $J^{t}$ is a conjugate of $-A$. Also $-J=-P^{-1}AP$ is a conjugate of $-A$. Similarity is transitive, so $J^{t}$ is similar to $-J$. Equality is a strictly stronger statement, and the two conjugating matrices $P^{t}$ and $P^{-1}$ differ unless $P$ is orthogonal.
:::

:::

:::

:::

::: {.pf-step #consequence}
The triangularity argument therefore does not apply.

::: pf-proof
The argument needs $J^{t}=-J$ entrywise to conclude that a triangular $J$ vanishes: from $J$ upper triangular and $J^{t}=-J$, the diagonal entries satisfy $j_{ii}=-j_{ii}$, so $j_{ii}=0$, and then the entries above and below the diagonal are forced to vanish together. That inference is valid, but its hypothesis is unavailable by step [](#error){.pf-ref}, so nothing follows about $J$ or $A$.
:::

:::

::: {.pf-step #counterexample}
$A=\begin{pmatrix}0&1\\-1&0\end{pmatrix}$ is nonzero and satisfies $A^{t}=-A$.

::: pf-proof
$A^{t}=\begin{pmatrix}0&-1\\1&0\end{pmatrix}=-A$, and $A$ has a nonzero entry.
:::

:::

::: {.pf-step #jordan}
Over $\CC$ the matrix $A$ has distinct eigenvalues $i$ and $-i$, so its Jordan form is $\operatorname{diag}(i,-i)$, which is not skew-symmetric.

::: pf-proof
The characteristic polynomial is $x^{2}+1=(x-i)(x+i)$, so the eigenvalues $i\ne-i$ are distinct and $A$ is diagonalisable with that diagonal form. A diagonal matrix $D$ is skew-symmetric exactly when $D^{t}=-D$, that is $D=-D$, that is $D=0$; but $\operatorname{diag}(i,-i)\ne0$.
:::

:::

::: {.pf-step}
The claimed theorem is false, and the stated proof is where it fails.

::: pf-proof
Step [](#error){.pf-ref} locates the invalid inference and steps [](#counterexample){.pf-ref} and [](#jordan){.pf-ref} give a nonzero complex matrix with $A^{t}=-A$, whose Jordan form is a nonzero diagonal matrix similar to a skew-symmetric one:
$$
\boxed{A=\begin{pmatrix}0&1\\-1&0\end{pmatrix},\qquad A^{t}=-A,\qquad A\ne0.}
$$
The error is a confusion between equality and similarity under conjugation, not an error of computation.
:::

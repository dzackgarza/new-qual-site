::: {.exercise}
Let $V$ be a finite-dimensional vector space and $L_1, L_2$ linear functionals on $V$.
Show that the equation
\[
f(\alpha, \beta) = L_1(\alpha)L_2(\beta) - L_1(\beta)L_2(\alpha)
\]
defines a skew-symmetric bilinear form on $V$.
Show that $f = 0$ if and only if $L_1, L_2$ are linearly dependent.
:::

::: {.solution}

::: pf

::: {.pf-step #f-is-bilinear}
$f$ is bilinear.

::: pf-proof
$L_1(\alpha)L_2(\beta)$ is bilinear in $(\alpha, \beta)$ (product of a linear functional in $\alpha$ and one in $\beta$), and $L_1(\beta)L_2(\alpha)$ is bilinear too; their difference is bilinear.
:::

:::

::: {.pf-step #f-is-skew-symmetric}
$f$ is skew-symmetric.

::: pf-proof
$f(\beta, \alpha) = L_1(\beta)L_2(\alpha) - L_1(\alpha)L_2(\beta) = -f(\alpha, \beta)$.
:::

:::

::: {.pf-step #dependent-implies-zero}
($\Leftarrow$) If $L_1, L_2$ are linearly dependent, then $f = 0$.

::: pf-proof

::: pf-step
If $L_2 = cL_1$ (or $L_1 = cL_2$), then $f(\alpha, \beta) = L_1(\alpha)(cL_1(\beta)) - L_1(\beta)(cL_1(\alpha)) = cL_1(\alpha)L_1(\beta) - cL_1(\beta)L_1(\alpha) = 0$.

::: pf-proof
substitute the linear dependence.
:::

:::

:::

:::

::: {.pf-step #zero-implies-dependent}
($\Rightarrow$) If $f = 0$, then $L_1, L_2$ are linearly dependent.

::: pf-proof

::: {.pf-step #assume-independent}
Suppose $L_1, L_2$ are linearly independent.

::: pf-proof
assume the contrary.
:::

:::

::: {.pf-step #exists-alpha-beta}
Then there exist $\alpha, \beta \in V$ with $L_1(\alpha) = 1$, $L_2(\alpha) = 0$, $L_1(\beta) = 0$, $L_2(\beta) = 1$.

::: pf-proof
since $L_1, L_2$ are independent, the map $V \to k^2$, $v \mapsto (L_1(v), L_2(v))$, is surjective, so we can find $\alpha$ mapping to $(1,0)$ and $\beta$ mapping to $(0,1)$.
:::

:::

::: {.pf-step #f-alpha-beta-nonzero}
Then $f(\alpha, \beta) = L_1(\alpha)L_2(\beta) - L_1(\beta)L_2(\alpha) = 1 \cdot 1 - 0 \cdot 0 = 1 \neq 0$.

::: pf-proof
Step [](#exists-alpha-beta){.pf-ref}.
:::

:::

::: {.pf-step #contradiction-with-f-zero}
This contradicts $f = 0$.

::: pf-proof
Step [](#f-alpha-beta-nonzero){.pf-ref}.
:::

:::

::: pf-step
Hence $L_1, L_2$ are linearly dependent.

::: pf-proof
Steps [](#assume-independent){.pf-ref}, [](#exists-alpha-beta){.pf-ref}, [](#f-alpha-beta-nonzero){.pf-ref}, and [](#contradiction-with-f-zero){.pf-ref}.
:::

:::

::: {.exercise}
Let $V$ be a finite-dimensional vector space and $L_1, L_2$ linear functionals on $V$.
Show that the equation
\[
f(\alpha, \beta) = L_1(\alpha)L_2(\beta) - L_1(\beta)L_2(\alpha)
\]
defines a skew-symmetric bilinear form on $V$.
Show that $f = 0$ if and only if $L_1, L_2$ are linearly dependent.
:::

::: {.solution}
<1>1. $f$ is bilinear.
::: {.proof}
$L_1(\alpha)L_2(\beta)$ is bilinear in $(\alpha, \beta)$ (product of a linear functional in $\alpha$ and one in $\beta$), and $L_1(\beta)L_2(\alpha)$ is bilinear too; their difference is bilinear.
:::

<1>2. $f$ is skew-symmetric.
::: {.proof}
$f(\beta, \alpha) = L_1(\beta)L_2(\alpha) - L_1(\alpha)L_2(\beta) = -f(\alpha, \beta)$.
:::

<1>3. ($\Leftarrow$) If $L_1, L_2$ are linearly dependent, then $f = 0$.
<2>1. If $L_2 = cL_1$ (or $L_1 = cL_2$), then $f(\alpha, \beta) = L_1(\alpha)(cL_1(\beta)) - L_1(\beta)(cL_1(\alpha)) = cL_1(\alpha)L_1(\beta) - cL_1(\beta)L_1(\alpha) = 0$.
::: {.proof}
substitute the linear dependence.
:::

<1>4. ($\Rightarrow$) If $f = 0$, then $L_1, L_2$ are linearly dependent.
<2>1. Suppose $L_1, L_2$ are linearly independent.
::: {.proof}
assume the contrary.
:::
<2>2. Then there exist $\alpha, \beta \in V$ with $L_1(\alpha) = 1$, $L_2(\alpha) = 0$, $L_1(\beta) = 0$, $L_2(\beta) = 1$.
::: {.proof}
since $L_1, L_2$ are independent, the map $V \to k^2$, $v \mapsto (L_1(v), L_2(v))$, is surjective, so we can find $\alpha$ mapping to $(1,0)$ and $\beta$ mapping to $(0,1)$.
:::
<2>3. Then $f(\alpha, \beta) = L_1(\alpha)L_2(\beta) - L_1(\beta)L_2(\alpha) = 1 \cdot 1 - 0 \cdot 0 = 1 \neq 0$.
::: {.proof}
<2>2.
:::
<2>4. This contradicts $f = 0$.
::: {.proof}
<2>3.
:::
<2>5. Hence $L_1, L_2$ are linearly dependent.
::: {.proof}
<2>1–<2>4.
:::

<1>5. Q.E.D.
::: {.proof}
<1>1, <1>2, <1>3, and <1>4.
:::
:::

::: {.exercise}
Prove an analogue of Exercise 17 in Section 10.2 for skew-symmetric forms.
:::

::: {.solution}

::: pf

::: pf-step
Let $f$ be a skew-symmetric bilinear form on a finite-dimensional vector space $V$ over a field of characteristic $\neq 2$.

::: pf-proof
setup.
:::

:::

::: pf-step
If $f = 0$, the zero form is represented by the zero matrix.

::: pf-proof
base case.
:::

:::

::: pf-step
Otherwise, choose $u, v \in V$ with $f(u, v) \neq 0$; rescaling, assume $f(u, v) = 1$.

::: pf-proof
$f$ is nonzero, so some pair has nonzero value; scale $u$ by $1/f(u,v)$.
:::

:::

::: {.pf-step #w-hyperbolic-block}
The subspace $W = \operatorname{span}\{u, v\}$ is nondegenerate, and $f|_W$ has matrix $\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ in the basis $(u, v)$.

::: pf-proof
$f(u,u) = f(v,v) = 0$ (skew-symmetry) and $f(u,v) = 1$, so $f(v,u) = -1$.
:::

:::

::: {.pf-step #v-decomposes-w-perp}
$V = W \oplus W^\perp$.

::: pf-proof
$W$ is nondegenerate, so $V = W \oplus W^\perp$.
:::

:::

::: {.pf-step #wperp-block-diagonal}
By induction on $\dim V$, $f|_{W^\perp}$ has a basis in which its matrix is a block diagonal sum of $\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ blocks (and possibly a zero block).

::: pf-proof
Step [](#v-decomposes-w-perp){.pf-ref} and induction.
:::

:::

::: {.pf-step #matrix-block-diagonal-form}
Hence there is a basis of $V$ in which the matrix of $f$ is
$$\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} \oplus \cdots \oplus \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} \oplus 0,$$
i.e. a block diagonal matrix with $2 \times 2$ hyperbolic blocks $\begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$ and a zero block.

::: pf-proof
Steps [](#w-hyperbolic-block){.pf-ref} and [](#wperp-block-diagonal){.pf-ref}.
:::

:::

::: {.pf-step #rank-even-nondegenerate-iff}
In particular, the rank of $f$ is even, and $f$ is nondegenerate iff $\dim V$ is even and there is no zero block.

::: pf-proof
Step [](#matrix-block-diagonal-form){.pf-ref}.
:::

:::

::: pf-qed
Steps [](#matrix-block-diagonal-form){.pf-ref} and [](#rank-even-nondegenerate-iff){.pf-ref}.
:::

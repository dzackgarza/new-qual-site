::: {.exercise}
Prove an analogue of Exercise 17 in Section 10.2 for skew-symmetric forms.
:::

::: {.solution}
The analogue is the following. Let $V$ be a finite-dimensional vector space
over a field $F$, let $f$ be a skew-symmetric bilinear form on $V$, and for a
subspace $W$ put
$$
W^{\perp}=\{\alpha\in V:f(\alpha,\beta)=0\text{ for every }\beta\in W\}.
$$
Then (a) $W^\perp$ is a subspace; (b) $V=\{0\}^\perp$; (c) $V^\perp=\{0\}$ if
and only if $f$ is non-degenerate; (d) $\operatorname{rank}f=\dim V-\dim V^\perp$;
(e) if $\dim V=n$ and $\dim W=m$, then $\dim W^\perp\ge n-m$; (f) the
restriction of $f$ to $W$ is non-degenerate if and only if
$W\cap W^\perp=\{0\}$; (g) $V=W\oplus W^\perp$ if and only if the restriction
of $f$ to $W$ is non-degenerate.

::: pf

::: {.pf-step #s1}

Orthogonality is a symmetric relation: $f(\alpha,\beta)=0$ if and only if $f(\beta,\alpha)=0$.

::: pf-proof

$f(\beta,\alpha)=-f(\alpha,\beta)$.

:::

:::

::: pf-step

Parts (a) and (b).

::: pf-proof

If $x,y\in W^\perp$, $a,b\in F$ and $w\in W$, then
$f(ax+by,w)=af(x,w)+bf(y,w)=0$, and $0\in W^\perp$; this is (a). Every
$\alpha$ satisfies $f(\alpha,0)=0$, so $\{0\}^\perp=V$; this is (b).

:::

:::

::: {.pf-step #s3}

Parts (c) and (d).

::: pf-proof

Let $L_f:V\to V^*$, $L_f(\alpha)(\beta)=f(\alpha,\beta)$. Then
$\ker L_f=V^\perp$. By step [](#s1){.pf-ref}, $V^\perp$ is also the set of
$\beta$ with $f(\alpha,\beta)=0$ for all $\alpha$, so $V^\perp=\{0\}$ exactly
when $f$ is non-degenerate; this is (c). Since
$\operatorname{rank}f=\operatorname{rank}L_f$, rank-nullity gives
$\operatorname{rank}f=\dim V-\dim V^\perp$; this is (d).

:::

:::

::: {.pf-step #s4}

Part (e).

::: pf-proof

Let $\beta_1,\ldots,\beta_m$ be a basis of $W$ and
$\Phi:V\to F^m$, $\Phi(\alpha)=(f(\alpha,\beta_1),\ldots,f(\alpha,\beta_m))$.
Then $\Phi$ is linear and $\ker\Phi=W^\perp$, so
$\dim W^\perp=n-\operatorname{rank}\Phi\ge n-m$.

:::

:::

::: {.pf-step #s5}

Part (f).

::: pf-proof

The vectors $w\in W$ with $f(w,u)=0$ for every $u\in W$ form
$W\cap W^\perp$. By step [](#s1){.pf-ref} the same set is the set of $w\in W$
with $f(u,w)=0$ for every $u\in W$. So the restriction of $f$ to $W$ is
non-degenerate exactly when $W\cap W^\perp=\{0\}$.

:::

:::

::: pf-step

Part (g).

::: pf-proof

If the restriction to $W$ is non-degenerate, step [](#s5){.pf-ref} gives
$W\cap W^\perp=\{0\}$, so
$\dim(W+W^\perp)=m+\dim W^\perp\ge m+(n-m)=n$ by step [](#s4){.pf-ref}.
Hence $V=W\oplus W^\perp$. Conversely, $V=W\oplus W^\perp$ forces
$W\cap W^\perp=\{0\}$, and step [](#s5){.pf-ref} gives non-degeneracy.

:::

::: {.exercise}
Let $V$ be a vector space over the field $F$.
Suppose there are a finite number of vectors $\alpha_1, \ldots, \alpha_r$ in $V$ which span $V$.
Prove that $V$ is finite-dimensional.
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
Definition of finite-dimensionality:

::: pf-proof

::: pf-step
A vector space $V$ over a field $F$ is finite-dimensional if it possesses a finite basis (a finite linearly independent subset of $V$ that spans $V$).

::: pf-proof
Hoffman–Kunze definition of finite-dimensional vector spaces.
:::

:::

::: pf-step
If $V = \{0\}$, the empty set $\emptyset$ is a basis with $0$ elements, so $V$ is finite-dimensional.

::: pf-proof
$\operatorname{span}(\emptyset) = \{0\}$.
:::

:::

:::

:::

::: pf-step
Extract a linearly independent spanning subset from $S = \{\alpha_1, \dots, \alpha_r\}$:

::: pf-proof

::: pf-step
Assume $V \neq \{0\}$, so $S$ contains at least one non-zero vector.

::: pf-proof
a spanning set for a non-trivial space must contain a non-zero vector.
:::

:::

::: pf-step
Let $\mathcal{F} = \{T \subseteq S : T \text{ is linearly independent over } F\}$.

::: pf-proof
definition of the collection of independent subsets.
:::

:::

::: pf-step
Since any non-zero vector $\{\alpha_i\} \in \mathcal{F}$, $\mathcal{F}$ is non-empty.

::: pf-proof
a single non-zero vector is linearly independent.
:::

:::

::: pf-step
Since $S$ is a finite set of $r$ elements, the power set $\mathcal{P}(S)$ is finite, so $\mathcal{F}$ is a finite non-empty collection of sets.

::: pf-proof
subset of a finite set is finite.
:::

:::

::: pf-step
Choose a maximal element $\mathcal{B} = \{\alpha_{i_1}, \dots, \alpha_{i_k}\} \in \mathcal{F}$ under set inclusion (e.g. an independent subset of maximal cardinality).

::: pf-proof
every finite non-empty poset has a maximal element.
:::

:::

:::

:::

::: {.pf-step #s3}
Show that $\mathcal{B}$ is a basis for $V$:

::: pf-proof

::: pf-step
By definition of $\mathcal{F}$, $\mathcal{B}$ is linearly independent.

::: pf-proof
$\mathcal{B} \in \mathcal{F}$.
:::

:::

::: pf-step
Let $\alpha \in S$ be any vector in the spanning set.
If $\alpha \in \mathcal{B}$, then $\alpha \in \operatorname{span}(\mathcal{B})$.

::: pf-proof
elements of a set belong to its span.
:::

:::

::: pf-step
If $\alpha \notin \mathcal{B}$, then by maximality of $\mathcal{B}$ in $\mathcal{F}$, the set $\mathcal{B} \cup \{\alpha\}$ is linearly dependent.

::: pf-proof
maximality of $\mathcal{B}$.
:::

:::

::: pf-step
Thus there exist scalars $c_1, \dots, c_k, c \in F$, not all zero, such that:
\[
c_1 \alpha_{i_1} + \cdots + c_k \alpha_{i_k} + c \alpha = 0.
\]

::: pf-proof
definition of linear dependence.
:::

:::

::: pf-step
If $c = 0$, then $\sum_{m=1}^k c_m \alpha_{i_m} = 0$, which forces $c_1 = \cdots = c_k = 0$ since $\mathcal{B}$ is linearly independent, contradicting that not all coefficients are zero.
Thus $c \neq 0$.

::: pf-proof
linear independence of $\mathcal{B}$.
:::

:::

::: pf-step
Dividing by $c$ gives:
\[
\alpha = -\sum_{m=1}^k \frac{c_m}{c} \alpha_{i_m} \in \operatorname{span}(\mathcal{B}).
\]

::: pf-proof
field arithmetic.
:::

:::

::: pf-step
Since every $\alpha \in S$ lies in $\operatorname{span}(\mathcal{B})$, we have $S \subseteq \operatorname{span}(\mathcal{B})$.
Since $S$ spans $V$, this implies $V = \operatorname{span}(S) \subseteq \operatorname{span}(\mathcal{B}) \subseteq V$, so $\operatorname{span}(\mathcal{B}) = V$.

::: pf-proof
span of a spanning set is $V$.
:::

:::

:::

:::

::: pf-step
Conclusion: $\mathcal{B}$ is a finite basis for $V$ containing $k \le r$ elements, so $V$ is finite-dimensional with $\dim V = k \le r$.

::: pf-proof
steps [](#s1){.pf-ref} and [](#s3){.pf-ref}.
:::

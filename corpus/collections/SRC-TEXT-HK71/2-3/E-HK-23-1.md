::: {.exercise}
Prove that if two vectors are linearly dependent, one of them is a scalar multiple of the other.
:::

::: {.solution}

::: pf

::: pf-step
Let $u, v$ be linearly dependent.

::: pf-proof
setup.
:::

:::

::: pf-step
Then there exist scalars $a, b$, not both zero, with $au + bv = 0$.

::: pf-proof
definition of linear dependence.
:::

:::

::: {.pf-step #u-is-multiple-of-v}
If $a \neq 0$, then $u = -\frac{b}{a} v$, so $u$ is a scalar multiple of $v$.

::: pf-proof
solve $au + bv = 0$ for $u$.
:::

:::

::: {.pf-step #v-is-multiple-of-u}
If $b \neq 0$, then $v = -\frac{a}{b} u$, so $v$ is a scalar multiple of $u$.

::: pf-proof
solve $au + bv = 0$ for $v$.
:::

:::

::: {.pf-step #one-is-multiple-of-other}
Hence one of $u, v$ is a scalar multiple of the other.

::: pf-proof
Steps [](#u-is-multiple-of-v){.pf-ref} and [](#v-is-multiple-of-u){.pf-ref} cover the two cases (at least one of $a, b$ is nonzero).
:::

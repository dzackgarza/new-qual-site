::: {.exercise}
Are the vectors
$$
\alpha_1 = (1, 1, 2, 4), \quad \alpha_2 = (2, -1, -5, 2),
$$
$$
\alpha_3 = (1, -1, -4, 0), \quad \alpha_4 = (2, 1, 1, 6)
$$
linearly independent in $\RR^4$?
:::


::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, and the relation below was recomputed from the four vectors as printed.

::: pf

::: {.pf-step #relation}
$\alpha_{1}-2\alpha_{2}+3\alpha_{3}=0$.

::: pf-proof
Compute the four coordinates of the combination:
$$
\alpha_{1}-2\alpha_{2}+3\alpha_{3}
=(1,1,2,4)-(4,-2,-10,4)+(3,-3,-12,0).
$$
Coordinate by coordinate this is $1-4+3=0$, $1+2-3=0$, $2+10-12=0$ and $4-4+0=0$, so the combination is the zero vector $(0,0,0,0)$.
:::

:::

::: {.pf-step}
The four vectors are linearly dependent, so they are not linearly independent in $\RR^{4}$.

::: pf-proof
By step [](#relation){.pf-ref} there is a relation
$$
1\cdot\alpha_{1}+(-2)\cdot\alpha_{2}+3\cdot\alpha_{3}+0\cdot\alpha_{4}=0
$$
among the four vectors whose coefficients $1,-2,3,0$ are not all zero, and that is exactly the definition of linear dependence for the ordered list $\alpha_{1},\alpha_{2},\alpha_{3},\alpha_{4}$. So the answer to the question is no: the vectors are dependent. The relation involves only the first three, so it exhibits a dependence inside that triple as well.
:::

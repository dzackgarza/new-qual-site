::: {.exercise}
Let $V$ be the vector space of all $2 \times 2$ matrices over the field $F$.
Prove that $V$ has dimension 4 by exhibiting a basis for $V$ which has four elements.
:::


::: {.solution}

The argument is the card's own. Let $E_{ij}$ be the $2\times2$ matrix whose only nonzero entry is a $1$ in position $(i,j)$.

::: pf

::: {.pf-step #units}

Each $E_{ij}$ lies in $V$, so the set $\{E_{11},E_{12},E_{21},E_{22}\}$ is a subset of $V$ with four distinct elements.

::: pf-proof

$V$ is the set of all $2\times2$ matrices over $F$, by definition of the exercise, and each $E_{ij}$ is such a matrix. The four are distinct: they differ in which single entry is $1$ and which are $0$.

:::

:::

::: {.pf-step #spans}

$\{E_{11},E_{12},E_{21},E_{22}\}$ spans $V$.

::: pf-proof

Let $A=\begin{bmatrix}a&b\\c&d\end{bmatrix}\in V$ be arbitrary, with $a,b,c,d\in F$. Comparing entries,
$$
aE_{11}+bE_{12}+cE_{21}+dE_{22}=\begin{bmatrix}a&b\\c&d\end{bmatrix}=A,
$$
so $A$ is a linear combination of the four units with coefficients its own entries. Hence every element of $V$ lies in their span.

:::

:::

::: {.pf-step #independent}

$\{E_{11},E_{12},E_{21},E_{22}\}$ is linearly independent.

::: pf-proof

Suppose $aE_{11}+bE_{12}+cE_{21}+dE_{22}=0$ for $a,b,c,d\in F$. By the entry computation of step [](#spans){.pf-ref} the left side is $\begin{bmatrix}a&b\\c&d\end{bmatrix}$, and the zero matrix has all entries $0$, so $a=b=c=d=0$. That is exactly linear independence.

:::

:::

::: {.pf-step #dimension}

$\dim_{F}V=4$.

::: pf-proof

Steps [](#spans){.pf-ref} and [](#independent){.pf-ref} show that $\{E_{11},E_{12},E_{21},E_{22}\}$ is a basis of $V$, and it has four elements. The dimension of a finite-dimensional vector space is the number of elements in any basis, so
$$
\boxed{\dim_{F}V=4.}
$$

:::

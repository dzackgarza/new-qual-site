::: {.exercise}
Let $V$ be the set of real numbers.
Regard $V$ as a vector space over the field of rational numbers, with the usual operations.
Prove that this vector space is not finite-dimensional.
:::


::: {.solution}
The argument is the card's own; no retained solution set is cited on the card, and no printed copy of Hoffman and Kunze is retained in `tmp/sources`, so the exercise is cited by section and number rather than by page. It is checked against Hoffman and Kunze, Linear Algebra (1971), §2.3 Exercise 14, whose statement is the one stored above.

::: pf

::: {.pf-step #suppose}
Suppose $\RR$ is finite-dimensional over $\QQ$, say of dimension $n$ with basis $v_1,\dots,v_n$.

::: pf-proof
This is the assumption for a contradiction. By the definition of a basis, every element of $\RR$ is a unique $\QQ$-linear combination of $v_1,\dots,v_n$.
:::

:::

::: {.pf-step #surjective}
The map $\varphi:\QQ^n\to\RR$, $\varphi(q_1,\dots,q_n)=\sum_{i=1}^n q_iv_i$, is surjective.

::: pf-proof
$\varphi$ is linear by construction, and it is onto because the $v_i$ span $\RR$: every real number is such a combination.
:::

:::

::: {.pf-step #countable}
$\QQ^n$ is countable, hence so is its image $\RR$.

:::: pf-proof

::: {.pf-step #qcountable}
$\QQ$ is countable.

::: pf-proof
$\QQ$ is the image of $\ZZ\times(\ZZ\setminus\{0\})$ under $(a,b)\mapsto a/b$, and a countable product of countable sets is countable, so $\QQ$ is countable.
:::

:::

::: {.pf-step #product}
A finite product of countable sets is countable.

::: pf-proof
Induction on the number of factors, using that $\NN\times\NN$ is countable (Cantor's pairing); the case $n=0$ is the one-point set.
:::

:::

::: {.pf-step}
$\QQ^n$ is countable, and so is its image under $\varphi$.

::: pf-proof
$\QQ^n$ is countable by steps [](#qcountable){.pf-ref} and [](#product){.pf-ref}, and the image of a countable set under any map is countable.
:::

:::

:::

:::

::: {.pf-step #contradiction}
This is impossible, since $\RR$ is uncountable.

::: pf-proof
Step [](#surjective){.pf-ref} makes $\RR$ the image of $\QQ^n$, which step [](#countable){.pf-ref} shows to be countable; but $\RR$ is uncountable (Cantor's theorem). A set that is both countable and uncountable does not exist, a contradiction.
:::

:::

::: {.pf-step}
$\RR$ is not finite-dimensional over $\QQ$.

::: pf-proof
The assumption of step [](#suppose){.pf-ref} leads to the contradiction of step [](#contradiction){.pf-ref}, whether $n=0$ or $n>0$; hence $\RR$ has no finite basis over $\QQ$:
$$
\boxed{\dim_{\QQ}\RR=\infty.}
$$
:::

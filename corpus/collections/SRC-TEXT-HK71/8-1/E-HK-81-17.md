::: {.exercise}
Let $V$ be a complex vector space, $J$ a conjugation on $V$, $W$ the set of $\alpha$ in $V$ such that $J\alpha = \alpha$, and $f$ an inner product on $W$.
Show that:

(a) There is a unique inner product $g$ on $V$ such that $g(\alpha, \beta) = f(\alpha, \beta)$ for all $\alpha, \beta$ in $W$,

(b) $g(J\alpha, J\beta) = g(\beta, \alpha)$ for all $\alpha, \beta$ in $V$.

What does part (a) say about the relation between the standard inner products on $\RR^1$ and $C^1$, or on $\RR^n$ and $C^n$?
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
Real decomposition $V = W \oplus iW$:

::: pf-proof

::: pf-step
A conjugation $J$ on $V$ satisfies $J(c\alpha) = \bar{c}J(\alpha)$, $J(\alpha + \beta) = J(\alpha) + J(\beta)$, and $J^2 = I$.

::: pf-proof
definition of conjugation on a complex vector space.
:::

:::

::: pf-step
For any $\alpha \in V$, define $\alpha_1 = \frac{\alpha + J\alpha}{2}$ and $\alpha_2 = \frac{\alpha - J\alpha}{2i}$.

::: pf-proof
algebraic definition.
:::

:::

::: pf-step
Check $J\alpha_1 = \frac{J\alpha + J^2\alpha}{2} = \frac{J\alpha + \alpha}{2} = \alpha_1$ and $J\alpha_2 = \frac{J\alpha - J^2\alpha}{-2i} = \frac{J\alpha - \alpha}{-2i} = \frac{\alpha - J\alpha}{2i} = \alpha_2$.
Thus $\alpha_1, \alpha_2 \in W$.

::: pf-proof
$J(i v) = -i J(v)$ and $J^2 = I$.
:::

:::

::: pf-step
Moreover, $\alpha = \alpha_1 + i\alpha_2$ uniquely, so $V = W \oplus iW$ as real vector spaces.

::: pf-proof
if $\alpha_1 + i\alpha_2 = 0$ with $\alpha_1, \alpha_2 \in W$, then $J(\alpha_1 + i\alpha_2) = \alpha_1 - i\alpha_2 = 0 \implies \alpha_1 = \alpha_2 = 0$.
:::

:::

:::

:::

::: {.pf-step #s2}
Part (a): Uniqueness and existence of the complex inner product $g$:

::: pf-proof

::: {.pf-step #s2-1}
**Uniqueness:** If $g$ is a complex inner product on $V$ extending $f$ on $W$, then for $\alpha = \alpha_1 + i\alpha_2$ and $\beta = \beta_1 + i\beta_2$ with $\alpha_j, \beta_j \in W$:
\[
g(\alpha, \beta) = g(\alpha_1 + i\alpha_2, \beta_1 + i\beta_2) = g(\alpha_1, \beta_1) - i g(\alpha_1, \beta_2) + i g(\alpha_2, \beta_1) + g(\alpha_2, \beta_2).
\]
Since $g|_{W \times W} = f$, we must have:
\[
g(\alpha, \beta) = \big(f(\alpha_1, \beta_1) + f(\alpha_2, \beta_2)\big) + i \big(f(\alpha_2, \beta_1) - f(\alpha_1, \beta_2)\big).
\]
This uniquely determines $g(\alpha, \beta)$ in terms of $f$.

::: pf-proof
sesquilinearity of complex inner products.
:::

:::

::: pf-step
**Existence:** Define $g: V \times V \to \mathbb{C}$ by the formula in step [](#s2-1){.pf-ref}.

::: pf-proof
definition of $g$.
:::

:::

::: pf-step
**Sesquilinearity:** $g$ is $\mathbb{C}$-linear in the first argument and conjugate-linear in the second argument.

::: pf-proof
linearity of $f$ and real coordinates.
:::

:::

::: {.pf-step #s2-4}
**Conjugate symmetry:** Using the symmetry of the real inner product $f$:
\[
\overline{g(\beta, \alpha)} = \big(f(\beta_1, \alpha_1) + f(\beta_2, \alpha_2)\big) - i \big(f(\beta_2, \alpha_1) - f(\beta_1, \alpha_2)\big) = \big(f(\alpha_1, \beta_1) + f(\alpha_2, \beta_2)\big) + i \big(f(\alpha_2, \beta_1) - f(\alpha_1, \beta_2)\big) = g(\alpha, \beta).
\]

::: pf-proof
$f(x, y) = f(y, x)$ for real inner products.
:::

:::

::: pf-step
**Positive-definiteness:** For $\alpha = \alpha_1 + i\alpha_2$:
\[
g(\alpha, \alpha) = f(\alpha_1, \alpha_1) + f(\alpha_2, \alpha_2) \ge 0.
\]
If $g(\alpha, \alpha) = 0$, then $f(\alpha_1, \alpha_1) = 0$ and $f(\alpha_2, \alpha_2) = 0$, so $\alpha_1 = 0$ and $\alpha_2 = 0$, whence $\alpha = 0$.

::: pf-proof
positive-definiteness of $f$ on $W$.
:::

:::

:::

:::

::: {.pf-step #s3}
Part (b): Show $g(J\alpha, J\beta) = g(\beta, \alpha)$:

::: pf-proof

::: pf-step
Since $J\alpha = \alpha_1 - i\alpha_2$ and $J\beta = \beta_1 - i\beta_2$:
\[
g(J\alpha, J\beta) = \big(f(\alpha_1, \beta_1) + f(-\alpha_2, -\beta_2)\big) + i \big(f(-\alpha_2, \beta_1) - f(\alpha_1, -\beta_2)\big) = \big(f(\alpha_1, \beta_1) + f(\alpha_2, \beta_2)\big) - i \big(f(\alpha_2, \beta_1) - f(\alpha_1, \beta_2)\big).
\]

::: pf-proof
applying the formula for $g$.
:::

:::

::: pf-step
Thus $g(J\alpha, J\beta) = \overline{g(\alpha, \beta)} = g(\beta, \alpha)$.

::: pf-proof
step [](#s2-4){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s4}
Relation to $\mathbb{R}^n$ and $\mathbb{C}^n$:

::: pf-proof

::: pf-step
On $V = \mathbb{C}^n$, let $J(z) = \bar{z}$ be standard complex conjugation. Then $W = \mathbb{R}^n$.

::: pf-proof
fixed points of complex conjugation in $\mathbb{C}^n$ are $\mathbb{R}^n$.
:::

:::

::: pf-step
The standard real inner product on $\mathbb{R}^n$ is $f(x, y) = \sum_{k=1}^n x_k y_k$.
Its unique complex inner product extension $g$ on $\mathbb{C}^n$ is the standard Hermitian inner product:
\[
g(z, w) = \sum_{k=1}^n z_k \bar{w}_k.
\]

::: pf-proof
direct application of Part (a).
:::

:::

:::

:::

::: pf-step
Conclusion:
The unique extension exists, satisfies $g(J\alpha, J\beta) = g(\beta, \alpha)$, and standardly relates the Euclidean inner product on $\mathbb{R}^n$ to the Hermitian inner product on $\mathbb{C}^n$.

::: pf-proof
steps [](#s1){.pf-ref} through [](#s4){.pf-ref}.
:::

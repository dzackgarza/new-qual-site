::: problem
Let $A$ be a $3\times 3$ orthogonal matrix.
Let $f:S^2\to S^2$ be the restriction of $A$ to $S^2$.
Show that there is a pair of antipodal points mapped by $f$ to the same pair of antipodal points.
:::

::: {.solution}
<1>1. The real matrix $A$ has a real eigenvalue.
::: {.proof}
Its characteristic polynomial
\[
p(t)=\det(tI-A)
\]
is a monic real polynomial of degree $3$.
Hence
\[
\lim_{t\to-\infty}p(t)=-\infty,
\qquad
\lim_{t\to+\infty}p(t)=+\infty.
\]
By the intermediate value theorem, there is some $\lambda\in\mathbb R$ with
\[
p(\lambda)=0.
\]
Thus there is a nonzero vector $v\in\mathbb R^3$ such that
\[
Av=\lambda v.
\]
:::

<1>2. This real eigenvalue satisfies $\lambda=\pm1$.
::: {.proof}
Because $A$ is orthogonal, it preserves Euclidean norm.
Therefore
\[
\lVert v\rVert
=
\lVert Av\rVert
=
\lVert\lambda v\rVert
=
|\lambda|\,\lVert v\rVert.
\]
Since $v\ne0$, it follows that $|\lambda|=1$.
As $\lambda$ is real,
\[
\lambda\in\{-1,1\}.
\]
:::

<1>3. The antipodal pair determined by a unit eigenvector is preserved by $f$.
::: {.proof}
Put
\[
x=\frac{v}{\lVert v\rVert}\in S^2.
\]
Then
\[
f(x)=Ax=\lambda x,
\qquad
f(-x)=A(-x)=-\lambda x.
\]
Since $\lambda=\pm1$,
\[
\{f(x),f(-x)\}
=
\{x,-x\}.
\]
Thus the pair of antipodal points $\{x,-x\}$ is mapped by $f$ to the same pair.
:::
:::

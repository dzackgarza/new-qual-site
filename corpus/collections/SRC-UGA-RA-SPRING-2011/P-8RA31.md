::: problem
Let $1\le p<q<\infty$.

(a) Which of the following statements (i)--(iv) are true, and which are false?
Justify all the negative answers by a counterexample and all positive answers with a proof.

(i) $L^p(\mathbb{R})\subseteq L^q(\mathbb{R})$

(ii) $L^q(\mathbb{R})\subseteq L^p(\mathbb{R})$

(iii) $L^p([0,1])\subseteq L^q([0,1])$

(iv) $L^q([0,1])\subseteq L^p([0,1])$

(b) For which values of $r\ge 1$ is it true that $L^p(\mathbb{R})\cap L^q(\mathbb{R})\subseteq L^r(\mathbb{R})$?
:::


::: solution
<1>1. Resolve part (a).
::: proof
(i) is false. The function
\[
f(x)=x^{-1/q}\mathbf1_{(0,1)}(x)
\]
satisfies
\[
\int_0^1 |f|^p\,dx=\int_0^1x^{-p/q}\,dx<\infty
\]
because $p/q<1$, while
\[
\int_0^1|f|^q\,dx=\int_0^1x^{-1}\,dx=\infty.
\]
Thus $f\in L^p(\mathbb R)\setminus L^q(\mathbb R)$.

(ii) is false. The function
\[
g(x)=x^{-1/p}\mathbf1_{(1,\infty)}(x)
\]
satisfies
\[
\int_1^\infty |g|^q\,dx=\int_1^\infty x^{-q/p}\,dx<\infty
\]
because $q/p>1$, while
\[
\int_1^\infty |g|^p\,dx=\int_1^\infty x^{-1}\,dx=\infty.
\]
Thus $g\in L^q(\mathbb R)\setminus L^p(\mathbb R)$.

(iii) is false by the same function $f(x)=x^{-1/q}$ on $(0,1)$.

(iv) is true. Since $m([0,1])=1$, Hölder's inequality gives
\[
\|h\|_p\le \|h\|_q
\]
for every $h\in L^q([0,1])$. Hence
\[
L^q([0,1])\subseteq L^p([0,1]).
\]
:::

<1>2. Prove inclusion for $p\le r\le q$.
::: proof
Let $f\in L^p(\mathbb R)\cap L^q(\mathbb R)$ and let $p\le r\le q$. Split
\[
\mathbb R=A\cup B,
\qquad
A:=\{|f|\le1\},
\quad
B:=\{|f|>1\}.
\]
On $A$, because $r\ge p$,
\[
|f|^r\le |f|^p.
\]
On $B$, because $r\le q$,
\[
|f|^r\le |f|^q.
\]
Therefore
\[
\int_{\mathbb R}|f|^r
\le \int_A|f|^p+\int_B|f|^q<\infty.
\]
Hence
\[
L^p(\mathbb R)\cap L^q(\mathbb R)\subseteq L^r(\mathbb R)
\qquad(p\le r\le q).
\]
:::

<1>3. Show that no other exponents work.
::: proof
Suppose $1\le r<p$. Set
\[
f_r(x)=x^{-1/r}\mathbf1_{(1,\infty)}(x).
\]
Then
\[
\int_1^\infty |f_r|^s\,dx
=\int_1^\infty x^{-s/r}\,dx<\infty
\]
for every $s>r$, so $f_r\in L^p\cap L^q$, whereas
\[
\int_1^\infty |f_r|^r\,dx
=\int_1^\infty x^{-1}\,dx=\infty.
\]
Thus the inclusion fails for $r<p$.

Now suppose $r>q$. Set
\[
g_r(x)=x^{-1/r}\mathbf1_{(0,1)}(x).
\]
For every $s<r$,
\[
\int_0^1 |g_r|^s\,dx
=\int_0^1 x^{-s/r}\,dx<\infty,
\]
so $g_r\in L^p\cap L^q$, while
\[
\int_0^1|g_r|^r\,dx=\int_0^1x^{-1}\,dx=\infty.
\]
Thus the inclusion fails for $r>q$.

Therefore the exact range is
\[
\boxed{p\le r\le q.}
\]
:::

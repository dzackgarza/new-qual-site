::: problem
Let $1\le p<q<\infty$.

(a) Which of the following statements (i)--(iv) are true, and which are false?
Justify all the negative answers by a counterexample and all positive answers with a proof.

(i) $L^p(\mathbb{R})\subseteq L^q(\mathbb{R})$

(ii) $L^q(\mathbb{R})\subseteq L^p(\mathbb{R})$

(iii) $L^p([0,1])\subseteq L^q([0,1])$

(iv) $L^q([0,1])\subseteq L^p([0,1])$

(b) For which values of $r\ge 1$ is it true that $L^p(\mathbb{R})\cap L^q(\mathbb{R})\subseteq L^r(\mathbb{R})$?
:::

::: {.solution}
**Part (a).**

<1>1. (i) is false.
Proof: $f(x) = x^{-1/q}\mathbf 1_{(0,1)}(x)$ is in $L^p(\RR)$ (since $\int_0^1 x^{-p/q}\, dx < \infty$ because $p/q < 1$) but not in $L^q(\RR)$ (since $\int_0^1 x^{-1}\, dx = \infty$).

<1>2. (ii) is false.
Proof: $f(x) = x^{-1/p}\mathbf 1_{(1,\infty)}(x)$ is in $L^q(\RR)$ (since $\int_1^\infty x^{-q/p}\, dx < \infty$ because $q/p > 1$) but not in $L^p(\RR)$ (since $\int_1^\infty x^{-1}\, dx = \infty$).

<1>3. (iii) is false.
Proof: $f(x) = x^{-1/q}\mathbf 1_{(0,1)}(x)$ is in $L^p([0,1])$ (since $\int_0^1 x^{-p/q}\, dx < \infty$ because $p/q < 1$) but not in $L^q([0,1])$ (since $\int_0^1 x^{-1}\, dx = \infty$).

<1>4. (iv) is true.
Proof: on $[0,1]$ (finite measure), for $p < q$, Hölder's inequality gives $\|f\|_p \le \|f\|_q \cdot \mu([0,1])^{1/p - 1/q} = \|f\|_q$, so $L^q([0,1]) \subseteq L^p([0,1])$.

<1>5. Summary: (i) false, (ii) false, (iii) false, (iv) true.
Proof: <1>1, <1>2, <1>3, <1>4.

**Part (b).**

<1>1. $L^p(\RR) \cap L^q(\RR) \subseteq L^r(\RR)$ for all $p \le r \le q$.
Proof: for $p \le r \le q$, write $r = \theta p + (1-\theta) q$ with $\theta \in [0,1]$; by the interpolation (log-convexity) of $L^p$ norms, $\|f\|_r \le \|f\|_p^\theta \|f\|_q^{1-\theta} < \infty$.

<1>2. For $r < p$ or $r > q$, the inclusion fails.
Proof: e.g. for $r < p$, take $f(x) = x^{-1/r}\mathbf 1_{(0,1)}(x)$, which is in $L^p \cap L^q$ (since $p, q > r$ implies $\int_0^1 x^{-p/r} < \infty$ and $\int_0^1 x^{-q/r} < \infty$) but not in $L^r$; similarly for $r > q$ using $x^{-1/r}\mathbf 1_{(1,\infty)}$.

<1>3. Hence the answer is exactly $p \le r \le q$.
Proof: <1>1 and <1>2.

<1>4. Q.E.D.
Proof: <1>5 (a) and <1>3 (b).

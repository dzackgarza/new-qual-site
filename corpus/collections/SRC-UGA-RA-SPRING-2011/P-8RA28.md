::: problem
(a) Let $A\subseteq\mathbb{R}^n$.
Give a precise definition of what it means for a function $f:A\to\mathbb{R}$ to be uniformly continuous on $A$.

(b) Let $K$ be a compact subset of $\mathbb{R}^n$.
Prove that if $f:K\to\mathbb{R}$ is continuous on $K$, then $f$ is uniformly continuous on $K$.
:::

::: {.solution}
**Goal.** Define uniform continuity, and prove that a continuous function on a compact set is uniformly continuous.

<1>1. Definition of uniform continuity.
<2>1. $f: A \to \RR$ is uniformly continuous on $A$ iff for every $\eps > 0$ there is $\delta > 0$ such that for all $x, y \in A$ with $\abs{x - y} < \delta$, one has $\abs{f(x) - f(y)} < \eps$.
::: {.proof}
this is the definition; the key point is that $\delta$ depends only on $\eps$, not on the point.
:::

<1>2. A continuous function on a compact set is uniformly continuous.
<2>1. Fix $\eps > 0$. For each $x \in K$, continuity gives $\delta_x > 0$ with $\abs{f(y) - f(x)} < \eps/2$ whenever $\abs{y - x} < \delta_x$.
::: {.proof}
continuity of $f$ at $x$.
:::
<2>2. The open balls $B(x, \delta_x/2)$ cover $K$; by compactness a finite subcover $B(x_1, \delta_1/2), \dots, B(x_m, \delta_m/2)$ exists.
::: {.proof}
$K$ is compact, so every open cover has a finite subcover.
:::
<2>3. Set $\delta \definedas \min_i \delta_i/2 > 0$.
::: {.proof}
a finite minimum of positive numbers is positive.
:::
<2>4. If $\abs{x - y} < \delta$, then $\abs{f(x) - f(y)} < \eps$.
::: {.proof}
$x \in B(x_i, \delta_i/2)$ for some $i$, and $\abs{y - x_i} \le \abs{y - x} + \abs{x - x_i} < \delta + \delta_i/2 \le \delta_i$, so both $x, y$ lie in $B(x_i, \delta_i)$; hence $\abs{f(x) - f(y)} \le \abs{f(x) - f(x_i)} + \abs{f(x_i) - f(y)} < \eps/2 + \eps/2 = \eps$.
:::

<1>3. Q.E.D.
::: {.proof}
<1>2.4 shows $f$ is uniformly continuous on $K$.
:::
:::

::: {.problem}
Let $P$ be a finite $p$-group. Prove that every non-trivial normal subgroup of $P$ intersects the center $Z(P)$ non-trivially (that is, $N \trianglelefteq P$ with $N \ne \{e\}$ implies $N \cap Z(P) \ne \{e\}$).
:::

::: {.solution}
**Goal:** Prove that every non-trivial normal subgroup $N \trianglelefteq P$ of a finite $p$-group $P$ contains a non-identity central element, $N \cap Z(P) \ne \{e\}$.

::: pf

::: pf-step
Conjugation action of $P$ on $N$:

::: pf-proof

::: pf-step
Define the group action of $P$ on $N$ by conjugation:
$$g \cdot x = g x g^{-1} \quad \text{for } g \in P, \, x \in N.$$
:::

::: pf-step
Since $N$ is normal in $P$, $g x g^{-1} \in N$ for all $x \in N$, so this is a well-defined group action.
:::

::: pf-step
The orbits of the action partition $N$ into disjoint conjugacy classes:
$$N = \bigsqcup_{i=1}^k \mathcal{O}(x_i), \qquad \text{where } \mathcal{O}(x) = \{g x g^{-1} : g \in P\}.$$
:::

:::

:::

::: pf-step
Fixed points and the class equation for $N$:

::: pf-proof

::: pf-step
An element $x \in N$ is fixed by all of $P$ if and only if $g x g^{-1} = x$ for all $g \in P$, which is equivalent to $x \in Z(P)$.
:::

::: pf-step
Thus the fixed point set of the action is
$$N^P = \{x \in N : |\mathcal{O}(x)| = 1\} = N \cap Z(P).$$
:::

::: pf-step
By the Orbit-Stabilizer Theorem, for any $x \in N$, the orbit size is the index of the centralizer:
$$|\mathcal{O}(x)| = [P : C_P(x)].$$
:::

::: pf-step
Summing orbit cardinalities gives the class equation for $N$:
$$|N| = |N \cap Z(P)| + \sum_{j=1}^m [P : C_P(y_j)],$$
where $y_1, \dots, y_m \in N$ are representatives of the conjugacy classes of size strictly greater than 1.
:::

:::

:::

::: pf-step
Divisibility by $p$:

::: pf-proof

::: pf-step
Since $P$ is a finite $p$-group, $|P| = p^n$ for some integer $n \ge 1$.
:::

::: pf-step
Since $N \le P$ is non-trivial, Lagrange's Theorem implies $|N| = p^a$ for some $1 \le a \le n$. Thus $p \mid |N|$.
:::

::: pf-step
For each non-trivial orbit $\mathcal{O}(y_j)$, its size $[P : C_P(y_j)]$ divides $|P| = p^n$ and satisfies $[P : C_P(y_j)] > 1$. Therefore $p \mid [P : C_P(y_j)]$ for each $j \in \{1, \dots, m\}$.
:::

::: pf-step
From the class equation:
$$|N \cap Z(P)| = |N| - \sum_{j=1}^m [P : C_P(y_j)] \equiv 0 - 0 \equiv 0 \pmod p.$$
:::

::: pf-step
The identity element $e \in N \cap Z(P)$, so $|N \cap Z(P)| \ge 1$.
:::

::: pf-step
Since $|N \cap Z(P)|$ is a positive multiple of $p$, we have $|N \cap Z(P)| \ge p > 1$.
:::

::: pf-step
Thus $N \cap Z(P)$ contains elements other than the identity $e$.
:::

:::

:::

::: pf-step
Conclusion:

::: pf-proof
$N \cap Z(P) \ne \{e\}$.
:::

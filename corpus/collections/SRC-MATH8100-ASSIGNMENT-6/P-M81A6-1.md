::: {.problem}
Prove that $\widehat f(\xi)\to0$ as $\norm{\xi}\to\infty$ for every $f\in L^1(\RR^n)$.
:::

::: {.solution}
The collection's provenance is the assignment sheet, so no retained solution set covers the problem and the argument is the card's own. Write $\widehat f(\xi)=\int_{\RR^n}f(x)e^{-2\pi ix\cdot\xi}\,dx$ and $(\tau_{-h}f)(y)=f(y+h)$.

::: pf

::: {.pf-step #shift}
For $\xi\ne0$ and $h=\xi/(2\norm{\xi}^2)$ one has $2\widehat f(\xi)=\int_{\RR^n}\bigl(f(y)-f(y+h)\bigr)e^{-2\pi iy\cdot\xi}\,dy$.

::: pf-proof
First $h\cdot\xi=\xi\cdot\xi/(2\norm{\xi}^2)=\tfrac12$, so $e^{-2\pi ih\cdot\xi}=e^{-\pi i}=-1$. The change of variables $x=y+h$, which leaves the integral unchanged by translation invariance of Lebesgue measure, gives
$$
\widehat f(\xi)=\int_{\RR^n}f(y+h)e^{-2\pi i(y+h)\cdot\xi}\,dy=-\int_{\RR^n}f(y+h)e^{-2\pi iy\cdot\xi}\,dy.
$$
Adding this to the defining formula for $\widehat f(\xi)$, whose integrand is $f(y)e^{-2\pi iy\cdot\xi}$, gives the displayed identity.
:::

:::

::: {.pf-step #bound}
$\abs{\widehat f(\xi)}\le\tfrac12\norm{f-\tau_{-h}f}_1$.

::: pf-proof
By step [](#shift){.pf-ref}, $2\abs{\widehat f(\xi)}\le\int\abs{f(y)-f(y+h)}\,dy=\norm{f-\tau_{-h}f}_1$, the integrand being dominated in modulus by $\abs{f-\tau_{-h}f}$ with equality of integrals; dividing by $2$ gives the bound.
:::

:::

::: {.pf-step #continuity}
Translations are continuous in $L^1(\RR^n)$: $\norm{\tau_{-h}f-f}_1\to0$ as $h\to0$.

::: pf-proof
Let $\varepsilon>0$. The continuous functions with compact support are dense in $L^1$, so choose $g\in C_c(\RR^n)$ with $\norm{f-g}_1<\varepsilon/3$. Then
$$
\norm{\tau_{-h}f-f}_1\le\norm{\tau_{-h}(f-g)}_1+\norm{\tau_{-h}g-g}_1+\norm{g-f}_1=2\norm{f-g}_1+\norm{\tau_{-h}g-g}_1,
$$
using that $\norm{\tau_{-h}(f-g)}_1=\norm{f-g}_1$. The function $g$ is uniformly continuous and supported in a fixed compact set $K$, so for small $\norm h$ the integrand $\abs{g(y+h)-g(y)}$ is below $\varepsilon/(3m(K+[-1,1]^n))$ throughout $K+[-1,1]^n$ and vanishes elsewhere; hence $\norm{\tau_{-h}g-g}_1<\varepsilon/3$, and the total is below $\varepsilon$.
:::

:::

::: {.pf-step}
$\boxed{\widehat f(\xi)\to0\text{ as }\norm\xi\to\infty}$.

::: pf-proof
$\norm h=\norm{\xi}/(2\norm{\xi}^2)=1/(2\norm\xi)\to0$ as $\norm\xi\to\infty$, so by step [](#continuity){.pf-ref} the right-hand side of step [](#bound){.pf-ref} tends to $0$, and with it $\abs{\widehat f(\xi)}$. This is the Riemann--Lebesgue lemma.
:::

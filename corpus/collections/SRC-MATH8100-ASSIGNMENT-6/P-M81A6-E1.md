::: {.problem}
By considering the iterated integral
$$
\int_0^\infty\left(\int_0^\infty xe^{-x^2(1+y^2)}\,dx\right)dy,
$$
show (with justification) that
$$
\int_0^\infty e^{-x^2}\,dx=\frac{\sqrt\pi}{2},
$$
and hence that $\int_{\RR}e^{-\pi x^2}\,dx=1$.
:::

::: {.solution}
The assignment sheet sets the problem and carries no solutions, so no retained solution set covers it; the argument is the card's own. Write $J=\int_{0}^{\infty}e^{-x^{2}}dx$ and $f(x,y)=xe^{-x^{2}(1+y^{2})}$ on $(0,\infty)^{2}$, a nonnegative function.

::: pf

::: {.pf-step #tonelli}
$\displaystyle\int_{0}^{\infty}\!\!\int_{0}^{\infty}f\,dx\,dy=\int_{0}^{\infty}\!\!\int_{0}^{\infty}f\,dy\,dx$, both sides being finite.

::: pf-proof
$f$ is continuous hence measurable and nonnegative on the measurable set $(0,\infty)^{2}$, so Tonelli's theorem gives equality of the two iterated integrals with values in $[0,\infty]$. Finiteness is established below by evaluating one of them; equality then transfers it to the other.
:::

:::

::: {.pf-step #inner-x}
For each $y\ge0$, $\displaystyle\int_{0}^{\infty}xe^{-x^{2}(1+y^{2})}dx=\frac{1}{2(1+y^{2})}$.

::: pf-proof
Substitute $u=x^{2}$, so $du=2x\,dx$ and the integral is $\frac{1}{2}\int_{0}^{\infty}e^{-u(1+y^{2})}du=\frac{1}{2}\cdot\frac{1}{1+y^{2}}$, the last step by $\int_{0}^{\infty}e^{-cu}du=1/c$ for $c>0$. Since $1+y^{2}\ge1$ here, $c\ne0$.
:::

:::

::: {.pf-step #first-iterated}
$\displaystyle\int_{0}^{\infty}\!\!\int_{0}^{\infty}f\,dx\,dy=\frac{\pi}{4}$.

::: pf-proof
By step [](#inner-x){.pf-ref} the inner integral is $\frac{1}{2(1+y^{2})}$, so the iterated integral is $\frac{1}{2}\int_{0}^{\infty}\frac{dy}{1+y^{2}}=\frac{1}{2}\cdot\frac{\pi}{2}=\frac{\pi}{4}$, using $\int_{0}^{\infty}\frac{dy}{1+y^{2}}=\lim_{b\to\infty}\arctan b-\arctan 0=\frac{\pi}{2}$.
:::

:::

::: {.pf-step #inner-y}
For each $x>0$, $\displaystyle\int_{0}^{\infty}xe^{-x^{2}(1+y^{2})}dy=Je^{-x^{2}}$.

::: pf-proof
Factor $xe^{-x^{2}(1+y^{2})}=xe^{-x^{2}}e^{-x^{2}y^{2}}$. Substituting $u=xy$, so $dy=du/x$, gives $\int_{0}^{\infty}xe^{-x^{2}y^{2}}dy=x\cdot\frac{1}{x}\int_{0}^{\infty}e^{-u^{2}}du=J$ independently of $x$, whence the inner integral is $e^{-x^{2}}J$.
:::

:::

::: {.pf-step #second-iterated}
$\displaystyle\int_{0}^{\infty}\!\!\int_{0}^{\infty}f\,dy\,dx=J^{2}$.

::: pf-proof
By step [](#inner-y){.pf-ref} the inner integral is $Je^{-x^{2}}$, and integrating in $x$ gives $J\int_{0}^{\infty}e^{-x^{2}}dx=J\cdot J=J^{2}$.
:::

:::

::: {.pf-step #value}
$\boxed{J=\frac{\sqrt{\pi}}{2}}$.

::: pf-proof
Steps [](#tonelli){.pf-ref}, [](#first-iterated){.pf-ref} and [](#second-iterated){.pf-ref} give $J^{2}=\frac{\pi}{4}$. The integrand $e^{-x^{2}}$ is positive, so $J>0$, and the unique positive square root is $\frac{\sqrt{\pi}}{2}$.
:::

:::

::: {.pf-step #answer}
$\boxed{\int_{\RR}e^{-\pi x^{2}}dx=1}$.

::: pf-proof
Substitute $u=\sqrt{\pi}\,x$, so $x=u/\sqrt{\pi}$ and $dx=du/\sqrt{\pi}$: $\int_{\RR}e^{-\pi x^{2}}dx=\frac{1}{\sqrt{\pi}}\int_{\RR}e^{-u^{2}}du=\frac{2J}{\sqrt{\pi}}$, the last equality by evenness. With $J=\frac{\sqrt{\pi}}{2}$ this is $1$.
:::

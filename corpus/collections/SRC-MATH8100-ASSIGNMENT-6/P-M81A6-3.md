::: {.problem}
For $f\in L^1(\mathbb R^n)$, prove the Fourier-transform formulas for translating $f$, modulating $f$, and composing $f$ with a nonsingular linear map $T$.
In the last formula, use the inverse transpose of $T$ and the factor $|\det T|^{-1}$.
:::

::: {.solution}
**Goal.** Prove the Fourier transform formulas for translation, modulation, and composition with a nonsingular linear map.

::: pf

::: {.pf-step #translation-formula}
Translation: $\widehat{f(\cdot - a)}(\xi) = e^{-2\pi i a \cdot \xi} \hat f(\xi)$.

::: pf-proof

::: pf-step
$\widehat{f(\cdot - a)}(\xi) = \int f(x - a) e^{-2\pi i x \cdot \xi}\,dx$.

::: pf-proof
definition of the Fourier transform.
:::

:::

::: pf-step
Substitute $y = x - a$: $\int f(y) e^{-2\pi i (y + a)\cdot \xi}\,dy = e^{-2\pi i a \cdot \xi}\int f(y) e^{-2\pi i y \cdot \xi}\,dy$.

::: pf-proof
change of variables.
:::

:::

::: pf-step
Hence $\widehat{f(\cdot - a)}(\xi) = e^{-2\pi i a \cdot \xi}\hat f(\xi)$.

::: pf-proof
the last integral is $\hat f(\xi)$.
:::

:::

:::

:::

::: {.pf-step #modulation-formula}
Modulation: $\widehat{e^{2\pi i b \cdot x} f(x)}(\xi) = \hat f(\xi - b)$.

::: pf-proof

::: pf-step
$\widehat{e^{2\pi i b \cdot x} f}(\xi) = \int e^{2\pi i b \cdot x} f(x) e^{-2\pi i x \cdot \xi}\,dx$.

::: pf-proof
definition.
:::

:::

::: pf-step
$= \int f(x) e^{-2\pi i x \cdot (\xi - b)}\,dx = \hat f(\xi - b)$.

::: pf-proof
combine the exponentials.
:::

:::

:::

:::

::: {.pf-step #linear-map-composition-formula}
Composition with a nonsingular linear map $T$: $\widehat{f \circ T}(\xi) = |\det T|^{-1} \hat f((T^{-1})^T \xi)$.

::: pf-proof

::: pf-step
$\widehat{f \circ T}(\xi) = \int f(Tx) e^{-2\pi i x \cdot \xi}\,dx$.

::: pf-proof
definition.
:::

:::

::: pf-step
Substitute $y = Tx$: $x = T^{-1}y$, $dx = |\det T|^{-1} dy$.

::: pf-proof
change of variables for a linear map.
:::

:::

::: pf-step
$= |\det T|^{-1}\int f(y) e^{-2\pi i (T^{-1}y) \cdot \xi}\,dy$.

::: pf-proof
substitute.
:::

:::

::: pf-step
$(T^{-1}y) \cdot \xi = y \cdot (T^{-1})^T \xi$.

::: pf-proof
the adjoint of $T^{-1}$ is $(T^{-1})^T$.
:::

:::

::: pf-step
Hence $\widehat{f \circ T}(\xi) = |\det T|^{-1}\hat f((T^{-1})^T \xi)$.

::: pf-proof
the integral is $\hat f$ evaluated at $(T^{-1})^T \xi$.
:::

:::

::: {.problem}
Consider the Hilbert space $\mathcal{H}=L^{2}([0,1])$.

a.
Prove that of $E \subset \mathcal{H}$ is closed and convex then $E$ contains an element of smallest norm. 

  > Hint: Show that if $\left\|f_{n}\right\|_{2} \rightarrow \min \left\{f \in E:\|f\|_{2}\right\}$ then $\left\{f_{n}\right\}$ is a Cauchy sequence.

b.
Construct a non-empty closed subset $E \subset \mathcal{H}$ which does not contain an element of smallest norm.
:::

::: {.solution}

::: pf

::: pf-step

A non-empty closed convex subset $E$ of a Hilbert space contains an element of smallest norm.

::: pf-proof

::: {.pf-step #s1-1}

Let $d = \inf\{\|f\|_2 : f \in E\}$ and choose $f_n \in E$ with $\|f_n\|_2 \to d$.

::: pf-proof

definition of infimum; possible by the hint.

:::

:::

::: {.pf-step #s1-2}

$\{f_n\}$ is Cauchy: $\left\|\frac{f_n - f_m}{2}\right\|_2^2 = \frac{1}{2}\|f_n\|_2^2 + \frac{1}{2}\|f_m\|_2^2 - \left\|\frac{f_n + f_m}{2}\right\|_2^2 \le \frac{1}{2}\|f_n\|_2^2 + \frac{1}{2}\|f_m\|_2^2 - d^2$.

::: pf-proof

parallelogram law; and $\frac{f_n + f_m}{2} \in E$ by convexity, so its norm is $\ge d$.

:::

:::

::: {.pf-step #s1-3}

The right side tends to $\frac{1}{2}d^2 + \frac{1}{2}d^2 - d^2 = 0$, so $\|f_n - f_m\|_2 \to 0$.

::: pf-proof

Steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-4}

$f_n \to f$ in $L^2$, and $f \in E$ with $\|f\|_2 = d$.

::: pf-proof

$L^2$ is complete, so $f_n$ converges to some $f$; $E$ is closed, so $f \in E$; and $\|f\|_2 = \lim_n\|f_n\|_2 = d$ by continuity of the norm.

:::

:::

::: pf-qed

Steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref}.

:::

:::

:::

::: pf-step

A non-empty closed subset without an element of smallest norm: $E = \{(1 + 1/n)e_n : n \in \NN\}$, where $(e_n)$ is any orthonormal sequence in $L^2([0,1])$ (e.g. $e_n(x) = \sqrt 2\sin(n\pi x)$).

::: pf-proof

::: {.pf-step #s2-1}

$E$ is closed.

::: pf-proof

the vectors $(1 + 1/n)e_n$ are pairwise at distance $\sqrt{(1+1/n)^2 + (1+1/m)^2} \ge \sqrt 2$, so the set has no accumulation points; a set with no accumulation points is closed.

:::

:::

::: {.pf-step #s2-2}

$\inf\{\|f\|_2 : f \in E\} = 1$, but no element of $E$ has norm $1$.

::: pf-proof

$\|(1 + 1/n)e_n\|_2 = 1 + 1/n \to 1$, while $1 + 1/n > 1$ for every $n$; hence the infimum $1$ is not attained.

:::

::: {.problem}
(a) Suppose $[F:K]=2$ and $\operatorname{char}K\neq2$. Show that there exists $D\in K$ such that $F=K(\sqrt D)$.

(b) Show that (a) can fail if $[F:K]=\operatorname{char}K=2$.
:::

::: {.solution}
For a field $L$ and $D\in L$ write $\sqrt D$ for either root of $x^2-D$ in an algebraic closure; the field $L(\sqrt D)$ does not depend on the choice, since the two roots are negatives of each other.

::: pf

::: {.pf-step #part-a}
(a) If $[F:K]=2$ and $\operatorname{char}K\ne2$, then $F=K(\sqrt D)$ for some $D\in K$.

::: pf-proof
Choose $\alpha\in F\setminus K$; then $K(\alpha)=F$, because $K\subsetneq K(\alpha)\subseteq F$ and there is no degree strictly between $1$ and $2$.
The minimal polynomial of $\alpha$ has the form $x^2+bx+c$ with $b,c\in K$, so $\alpha^2=-b\alpha-c$.
Since $\operatorname{char}K\ne2$ the element $2$ is invertible in $K$, and
$$
\Bigl(\alpha+\frac b2\Bigr)^2=\alpha^2+b\alpha+\frac{b^2}{4}=\frac{b^2}{4}-c\in K.
$$
Put $\beta=\alpha+\frac b2$ and $D=\frac{b^2}{4}-c\in K$.
Then $\beta^2=D$ and $\beta\notin K$, because $\beta\in K$ would give $\alpha=\beta-\frac b2\in K$; hence $F=K(\beta)=K(\sqrt D)$.
:::

:::

::: {.pf-step #part-b}
(b) There are fields of characteristic $2$ with a degree-two extension that is not generated by a square root of an element of the base field: $K=\FF_2(t)$ and $F=K(\alpha)$ with $\alpha^2+\alpha+t=0$.

::: pf-proof
First $x^2+x+t$ is irreducible over $\FF_2(t)$.
If $a\in\FF_2(t)$ satisfied $a^2+a=t$, write $a=p/q$ with coprime $p,q\in\FF_2[t]$ and $q\ne0$; then $p(p+q)=tq^2$, and $q^2$ is coprime to both $p$ and $p+q$, so $q^2$ divides $1$ and $q\in\FF_2^\times$, that is $a\in\FF_2[t]$.
For $a\in\FF_2[t]\setminus\FF_2$ the polynomial $a^2+a$ has degree $2\deg a\ge2$, and for $a\in\FF_2$ it equals $0$; neither can equal $t$, so no such $a$ exists.
Hence $x^2+x+t$ is irreducible and $[F:K]=2$.

Now let $D\in K$ and suppose $F=K(\sqrt D)$.
Then $F$ contains $\beta=\sqrt D$ with $\beta^2=D\in K$ and $\beta\notin K$.
Every element of $F$ is $a+b\alpha$ with $a,b\in K$, because $1$ and $\alpha$ span $F$ over $K$, and in characteristic $2$, using $\alpha^2=\alpha+t$,
$$
(a+b\alpha)^2=a^2+b^2\alpha^2=a^2+b^2(\alpha+t)=(a^2+b^2t)+b^2\alpha.
$$
This lies in $K$ only if $b^2=0$, that is only if $b=0$, and then it is $a\in K$.
So no element of $F\setminus K$ has its square in $K$, and $K(\sqrt D)\ne F$ for every $D\in K$.
:::

::: {.problem}
Let $f$ be a polynomial with real coefficients.
Show that there exists $x_0\in\RR$ such that $\abs{f(x_0)}\le\abs{f(x)}$ for all $x\in\RR$.
:::

::: {.solution}

No retained solution set covers this exercise: the card's own compactness argument follows, with the growth at infinity, the truncation and the extreme value theorem as separate steps.

::: pf

::: {.pf-step #constant}
If $f$ is constant then every $x_{0}\in\RR$ satisfies $\abs{f(x_{0})}\le\abs{f(x)}$.

::: pf-proof
A constant function has $\abs{f(x)}=\abs{f(x_{0})}$ for all $x$.
:::

:::

::: {.pf-step #growth}
If $f$ is nonconstant of degree $d\ge1$ with leading coefficient $a_{d}$, then $\abs{f(x)}\to\infty$ as $\abs{x}\to\infty$.

::: pf-proof
$\frac{f(x)}{a_{d}x^{d}}=1+\frac{a_{d-1}}{a_{d}x}+\cdots+\frac{a_{0}}{a_{d}x^{d}}\to1$, so for large $\abs{x}$ one has $\abs{f(x)}\ge\tfrac12\abs{a_{d}}\abs{x}^{d}$, which tends to $\infty$.
:::

:::

::: {.pf-step #truncate}
There is $R>0$ with $\abs{f(x)}>\abs{f(0)}$ whenever $\abs{x}\ge R$.

::: pf-proof
By step [](#growth){.pf-ref} choose $R$ with $\abs{f(x)}>\abs{f(0)}$ for $\abs{x}\ge R$; this is possible because $\abs{f(x)}\to\infty$.
:::

:::

::: {.pf-step #minimum}
$\abs{f}$ attains a minimum on $[-R,R]$, at some $x_{0}$, and that minimum is a minimum on $\RR$.

::: pf-proof
$\abs{f}$ is continuous on the compact interval $[-R,R]$, so the extreme value theorem gives $x_{0}\in[-R,R]$ with $\abs{f(x_{0})}\le\abs{f(x)}$ for all $x\in[-R,R]$. For $\abs{x}>R$ step [](#truncate){.pf-ref} gives $\abs{f(x)}>\abs{f(0)}\ge\abs{f(x_{0})}$, since $0\in[-R,R]$. So $\abs{f(x_{0})}\le\abs{f(x)}$ for every $x\in\RR$.
:::

:::

::: {.pf-qed}
The constant case is step [](#constant){.pf-ref} and the nonconstant case steps [](#growth){.pf-ref}--[](#minimum){.pf-ref}: in both there is $x_{0}$ with $\abs{f(x_{0})}\le\abs{f(x)}$ for all $x$.
:::

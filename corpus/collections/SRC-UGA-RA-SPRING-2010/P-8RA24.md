::: problem
Let $f(x)=x^3$ and $E\subset\mathbb{R}$.
Show that $m^*(E)=0$ if and only if $m^*(f(E))=0$, where $m^*$ denotes Lebesgue outer measure.
:::

::: {.solution}
<1>1. $f(x)=x^3$ is bi-Lipschitz on compact sets and $C^1$ with $f'\neq0$ except $0$.
::: {.proof}
$f'(x)=3x^2$.
:::

<1>2. $f$ and $f^{-1}(y)=y^{1/3}$ are locally Lipschitz, hence preserve null sets.
::: {.proof}
Lipschitz maps preserve $m^*=0$; $f^{-1}$ is Hölder $1/3$ but still AC.
:::

<1>3. Hence $m^*(E)=0$ iff $m^*(f(E))=0$.
::: {.proof}
<1>2.
:::

<1>4. Q.E.D.
::: {.proof}
<1>3.
:::
:::

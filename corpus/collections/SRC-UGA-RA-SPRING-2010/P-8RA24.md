::: problem
Let $f(x)=x^3$ and $E\subset\mathbb{R}$.
Show that $m^*(E)=0$ if and only if $m^*(f(E))=0$, where $m^*$ denotes Lebesgue outer measure.
:::

::: solution
<1>1. A null set has null image under $x\mapsto x^3$.
::: proof
For each $N\ge1$, the map
\[
f(x)=x^3
\]
is Lipschitz on $[-N,N]$, because
\[
|f'(x)|=3x^2\le3N^2.
\]
Hence if $m^*(E)=0$, then
\[
m^*(f(E\cap[-N,N]))=0
\]
for every $N$. Since
\[
E=\bigcup_{N=1}^\infty(E\cap[-N,N]),
\]
we have
\[
f(E)=\bigcup_{N=1}^\infty f(E\cap[-N,N]),
\]
so countable subadditivity gives
\[
m^*(f(E))=0.
\]
:::

<1>2. A null image forces the original set to be null.
::: proof
Let
\[
h(y)=y^{1/3}.
\]
Although $h$ is not Lipschitz near $0$, it is absolutely continuous on every compact interval. Indeed, for $M>0$,
\[
h'(y)=\frac13|y|^{-2/3}
\]
for $y\ne0$, this derivative belongs to $L^1([-M,M])$, and
\[
h(y)-h(0)=\int_0^y h'(t)\,dt.
\]
Thus $h$ is absolutely continuous on $[-M,M]$.

Absolutely continuous functions map Lebesgue-null sets to Lebesgue-null sets. Suppose now that
\[
m^*(f(E))=0.
\]
For each $M\ge1$,
\[
f(E)\cap[-M,M]
\]
is null, so
\[
h(f(E)\cap[-M,M])
\]
is null. But
\[
E
=h(f(E))
=\bigcup_{M=1}^\infty h(f(E)\cap[-M,M]).
\]
Therefore $E$ is a countable union of null sets, and hence
\[
m^*(E)=0.
\]
Thus
\[
\boxed{m^*(E)=0\iff m^*(f(E))=0.}
\]
:::
:::

::: problem
Verify the orthogonality of the real and complex trigonometric systems in $L^2([0,1])$.
Then prove the Riemann-Lebesgue lemma for $f\in L^1([0,1])$ by writing $f=g+h$ with $g\in L^2$ and $\|h\|_1$ arbitrarily small.
:::

::: solution
<1>1. The real trigonometric system is orthogonal.
::: proof
For integers $j,k\ge1$, the product-to-sum identities give
\[
\int_0^1\cos(2\pi jx)\cos(2\pi kx)\,dx=0
\qquad(j\ne k),
\]
\[
\int_0^1\sin(2\pi jx)\sin(2\pi kx)\,dx=0
\qquad(j\ne k),
\]
and
\[
\int_0^1\sin(2\pi jx)\cos(2\pi kx)\,dx=0
\]
for all $j,k$. Also each sine and cosine has integral $0$ on $[0,1]$, so each is orthogonal to the constant function. Thus
\[
\left\{\frac1{\sqrt2},\cos(2\pi x),\sin(2\pi x),\ldots\right\}
\]
is an orthogonal system.
:::

<1>2. The complex exponential system is orthogonal.
::: proof
For $j,k\in\mathbb Z$,
\[
\left\langle e^{2\pi ijx},e^{2\pi ikx}\right\rangle
=\int_0^1e^{2\pi i(j-k)x}\,dx.
\]
This equals $1$ if $j=k$ and $0$ otherwise. Hence
\[
\{e^{2\pi ikx}\}_{k\in\mathbb Z}
\]
is in fact orthonormal.
:::

<1>3. Every $f\in L^1([0,1])$ splits as an $L^2$ part plus an arbitrarily small $L^1$ tail.
::: proof
Given $\varepsilon>0$, choose $M>0$ so large that
\[
\int_{\{|f|>M\}}|f|<\varepsilon.
\]
Set
\[
g=f\mathbf1_{\{|f|\le M\}},
\qquad
h=f\mathbf1_{\{|f|>M\}}.
\]
Then $f=g+h$, $\|h\|_1<\varepsilon$, and
\[
\int_0^1|g|^2
\le M\int_0^1|f|<\infty,
\]
so $g\in L^2([0,1])$.
:::

<1>4. The Riemann--Lebesgue limits follow.
::: proof
Apply Bessel's inequality to the orthonormal systems
\[
\{\sqrt2\cos(2\pi kx)\}_{k\ge1}
\quad\text{and}\quad
\{\sqrt2\sin(2\pi kx)\}_{k\ge1}.
\]
For $g\in L^2$, the corresponding coefficient sequences are square-summable, hence tend to $0$. Therefore
\[
\int_0^1g(x)\cos(2\pi kx)\,dx\to0
\]
and
\[
\int_0^1g(x)\sin(2\pi kx)\,dx\to0.
\]

For the tail,
\[
\left|\int_0^1h(x)\cos(2\pi kx)\,dx\right|
\le\|h\|_1<\varepsilon,
\]
and the same estimate holds with sine. Hence, for all sufficiently large $k$,
\[
\left|\int_0^1f(x)\cos(2\pi kx)\,dx\right|<2\varepsilon,
\]
and likewise for sine. Since $\varepsilon>0$ is arbitrary,
\[
\boxed{
\int_0^1f(x)\cos(2\pi kx)\,dx\to0,
\qquad
\int_0^1f(x)\sin(2\pi kx)\,dx\to0.}
\]
:::

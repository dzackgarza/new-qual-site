::: problem
1. Prove that $\ell^2(\mathbb N)$ is complete.

2. Prove the complex polarization identity.

3. Deduce that an invertible linear map between Hilbert spaces is unitary if and only if it is isometric.
:::

::: solution
<1>1. The space $\ell^2(\mathbb N)$ is complete.
::: proof
Let $(x^{(m)})$ be Cauchy in $\ell^2$, where
\[
x^{(m)}=(x^{(m)}_j)_{j\ge1}.
\]
For each fixed $j$,
\[
|x^{(m)}_j-x^{(k)}_j|
\le \|x^{(m)}-x^{(k)}\|_2,
\]
so $(x^{(m)}_j)_m$ is Cauchy in $\mathbb C$. Let
\[
x_j=\lim_{m\to\infty}x^{(m)}_j.
\]

Choose $m_0$ so that
\[
\|x^{(m)}-x^{(k)}\|_2<1
\qquad(m,k\ge m_0).
\]
For fixed $m\ge m_0$, Fatou's lemma for counting measure gives
\[
\sum_{j=1}^\infty |x_j-x^{(m)}_j|^2
\le \liminf_{k\to\infty}
\sum_{j=1}^\infty |x^{(k)}_j-x^{(m)}_j|^2
\le1.
\]
Hence $x-x^{(m)}\in\ell^2$, and therefore $x\in\ell^2$.

Now let $\varepsilon>0$ and choose $M$ such that
\[
\|x^{(m)}-x^{(k)}\|_2<\varepsilon
\qquad(m,k\ge M).
\]
For $m\ge M$, the same Fatou argument yields
\[
\|x-x^{(m)}\|_2^2
\le \liminf_{k\to\infty}\|x^{(k)}-x^{(m)}\|_2^2
\le\varepsilon^2.
\]
Thus $x^{(m)}\to x$ in $\ell^2$, proving completeness.
:::

<1>2. The complex polarization identity holds.
::: proof
Using the convention that the inner product is linear in its first variable,
\[
\begin{aligned}
\|x+y\|^2-\|x-y\|^2
&=4\operatorname{Re}\langle x,y\rangle,\\
\|x+iy\|^2-\|x-iy\|^2
&=4\operatorname{Im}\langle x,y\rangle.
\end{aligned}
\]
Therefore
\[
\boxed{
\langle x,y\rangle
=\frac14\left(
\|x+y\|^2-\|x-y\|^2
+i\|x+iy\|^2-i\|x-iy\|^2
\right).}
\]
:::

<1>3. For an invertible linear map, unitarity is equivalent to isometry.
::: proof
If $U:H_1\to H_2$ is unitary, then
\[
\|Ux\|_{H_2}^2
=\langle Ux,Ux\rangle_{H_2}
=\langle x,x\rangle_{H_1}
=\|x\|_{H_1}^2,
\]
so $U$ is an isometry.

Conversely, suppose $U$ is linear, invertible, and isometric. Applying the polarization identity in $H_2$ and using linearity and norm preservation gives
\[
\begin{aligned}
\langle Ux,Uy\rangle_{H_2}
&=\frac14\bigl(
\|U(x+y)\|^2-\|U(x-y)\|^2\\
&\qquad+i\|U(x+iy)\|^2-i\|U(x-iy)\|^2
\bigr)\\
&=\langle x,y\rangle_{H_1}.
\end{aligned}
\]
Thus $U$ preserves inner products; with invertibility already assumed, $U$ is unitary.
:::
:::

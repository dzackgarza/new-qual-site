::: {.problem}
Show that there is an analytic function $f$ in $\CC \setminus [-1, 1]$ such that $(f(z))^2 = z^2 - 1$.
Does it extend analytically to $\CC_\infty \setminus [-1, 1]$?
How many such functions are there?
:::

::: {.solution}
This is Problem 6 of the UCSD complex-analysis qualifying exam of Spring 2005 (`assets/attachments/SP05_220_Complex_Analysis_Qual.pdf`). No published solution set is transcribed: the argument is the card's own.

What was repaired: the card argued existence by saying that the fundamental group of $G=\CC\setminus[-1,1]$ "is generated by a loop surrounding the segment $[-1,1]$", which is false, since $G$ is simply connected; it now exhibits a square root explicitly through the Joukowski map, which is also what makes the normalized branch and the behaviour at $\infty$ immediate.

::: pf

::: {.pf-step #construction}
There is a holomorphic $f$ on $G=\CC\setminus[-1,1]$ with $f^{2}=z^{2}-1$.

::: pf-proof
The Joukowski map $\Phi(w)=\frac12(w+w^{-1})$ is holomorphic and injective on $\Omega=\theset{w\mid\abs{w}>1}$, and $\Phi(\Omega)=\CC\setminus[-1,1]$: for $z=\Phi(w)$ with $\abs{w}>1$ one has $z\notin[-1,1]$ because $w$ solves $w^{2}-2zw+1=0$ with the other root $w^{-1}$ of modulus below $1$, so both roots are real only if $z=\pm1$; and every $z\in\CC\setminus[-1,1]$ arises from the root of modulus greater than $1$. Put $g(w)=\frac12(w-w^{-1})$, holomorphic on $\Omega$. Then
$$\Phi(w)^{2}-1=\tfrac14(w^{2}+2+w^{-2})-\tfrac44=\tfrac14(w^{2}-2+w^{-2})=g(w)^{2},$$
so $f=g\circ\Phi^{-1}$ is holomorphic on $G$ and $f(z)^{2}=z^{2}-1$ there.
:::
:::

::: {.pf-step #branch}
This $f$ is the branch of $\sqrt{z^{2}-1}$ normalized by $f(z)/z\to1$ as $z\to\infty$.

::: pf-proof
As $\abs{z}\to\infty$ the corresponding $w=\Phi^{-1}(z)$ tends to $\infty$ in $\Omega$, and
$$\frac{f(z)}{z}=\frac{g(w)}{\Phi(w)}=\frac{w-w^{-1}}{w+w^{-1}}=\frac{1-w^{-2}}{1+w^{-2}}\longrightarrow1.$$
So $f$ is the branch with that normalization, and the other branch is $-f$.
:::
:::

::: {.pf-step #extension}
No holomorphic square root of $z^{2}-1$ on $G$ extends holomorphically to $\CC_{\infty}\setminus[-1,1]$; each extends meromorphically with a simple pole at $\infty$.

::: pf-proof
Let $h$ be holomorphic on a domain containing $\infty$ with $h^{2}=z^{2}-1$ there. Then $h$ is nonvanishing on a punctured neighbourhood of $\infty$ and $\abs{h(z)}^{2}=\abs{z^{2}-1}\to\infty$ as $z\to\infty$, so $\infty$ is a pole of $h$, not a removable singularity and not an essential one; a holomorphic function on a neighbourhood of $\infty$ has a finite limit there, so no such $h$ exists. The pole is simple: $h(z)^{2}=z^{2}(1-z^{-2})$ forces $\abs{h(z)/z}\to1$, so $h$ has a simple pole or a nonzero finite value at $\infty$, and the second is excluded. By step [](#branch){.pf-ref} every square root is $\pm f$, so the conclusion covers all of them.
:::
:::

::: {.pf-step #two}
There are exactly two holomorphic square roots of $z^{2}-1$ on $G$, namely $f$ and $-f$.

::: pf-proof
Let $f_{1}^{2}=f_{2}^{2}=z^{2}-1$ on the connected domain $G$. Then $f_{1}/f_{2}$ is holomorphic on $G$, since $f_{2}$ is nonvanishing there, and $(f_{1}/f_{2})^{2}=1$, so $f_{1}/f_{2}$ maps the connected set $G$ into the two-point set $\{1,-1\}$ and is therefore constant; hence $f_{1}=f_{2}$ or $f_{1}=-f_{2}$. Step [](#construction){.pf-ref} produces $f$, so the two square roots are $f$ and $-f$.
:::

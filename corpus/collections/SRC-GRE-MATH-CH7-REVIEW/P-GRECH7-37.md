::: {.problem}
If $x$ is an element of the set $(A \cup B) \cap C$, which of the following must be true?

- I. $x \in (A \cap B) \cup C$
- II. $x \in (A \cup B)$
- III. $x \in (A \cap B) \cap C$

(A) I only
(B) II only
(C) III only
(D) I and II only
(E) II and III only
:::

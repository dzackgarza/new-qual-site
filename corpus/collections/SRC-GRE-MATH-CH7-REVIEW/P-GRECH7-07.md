(A) $\mathbb{Q}$, the set of rational numbers
(B) $\mathbb{Z}$, the set of all integers
(C) $\mathbb{Q}^c$, the set of all irrational numbers
(D) $\mathbb{Z}^+$, the set of positive integers
(E) $E$, the set of positive even integers

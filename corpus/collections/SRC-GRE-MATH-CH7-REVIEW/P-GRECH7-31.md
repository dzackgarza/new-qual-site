::: {.problem}
Which of the following sets in $\mathbb{R}^3$ is compact?

(A) $\{x, y, z \mid |x + y + z| < 5\}$
(B) $\{x, y, z \mid x < 2 \ \& \ y < 2 \ \& \ z < 2\}$
(C) $\{x, y, z \mid 0 \le x \le 3, 0 \le y \le 3, 0 \le z \le 3\}$
(D) $\{x, y, z \mid x \ge 0, y \ge 0, z \ge 0\}$
(E) $\{x, y, z \mid 2 < x^2 + y^2 + z^2 < 8\}$
:::

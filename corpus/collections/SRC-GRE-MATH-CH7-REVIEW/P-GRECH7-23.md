::: {.problem}
Given set $A = \{a, b\}$, set $B = \{c, d, e, f\}$, and set $C = \{g, h, i\}$. If set $D = P(C) \times B$, which of the following sets has the same cardinality as $P(D)$?

(A) $P[P(A) \times P(C)]$
(B) $P[A \times C]$
(C) $P(A) \times P(C)$
(D) $[P(B) \times P(C)]$
(E) $P[P(A) \times P(B)]$
:::

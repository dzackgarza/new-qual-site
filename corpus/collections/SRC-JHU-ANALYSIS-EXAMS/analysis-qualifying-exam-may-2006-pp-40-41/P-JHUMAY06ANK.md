Either prove that lim $\begin{array} { r } { \operatorname* { s u p } _ { n \to \infty } \vert \vert f _ { n } \vert \vert _ { L ^ { 2 } ( [ 0 , 1 ] ) } < \infty } \end{array}$ or give a counter-example.

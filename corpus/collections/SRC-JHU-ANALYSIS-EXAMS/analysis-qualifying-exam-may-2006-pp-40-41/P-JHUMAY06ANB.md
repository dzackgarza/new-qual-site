2. How many zeros does the polynomial

$$
z ^ { 7 } - 4 z ^ { 3 } + z - { \textstyle { \frac { 1 } { 2 } } }
$$

have in the unit disk $\{ | z | < 1 \} \stackrel { . } { : }$ How many zeros does it have in the disk $\{ | z | < 2 \}$ of radius 2? Justify your answers.

::: problem
Let $T$ be a linear transformation on $C_0(\mathbb{R})$ (the space of continuous functions of compact support) that satisfies:
$$
\|Tf\|_{L^\infty} \le \|f\|_{L^\infty}, \qquad \text{and} \qquad \left| \{x \in \mathbb{R} : |Tf(x)| > \lambda\} \right| \le \frac{\|f\|_{L^1}}{\lambda}
$$
for all $\lambda > 0$. Prove that there exists a fixed constant $C > 0$ such that
$$
\int_{-\infty}^{+\infty} |Tf(x)|^2\,dx \le C \int_{-\infty}^{+\infty} |f(x)|^2\,dx
$$
for all $f \in C_0(\mathbb{R})$.
:::

::: solution
**Goal:** Prove that the strong $(\infty, \infty)$ and weak $(1, 1)$ bounds imply an $L^2(\mathbb{R})$ bound $\|Tf\|_{L^2}^2 \le C \|f\|_{L^2}^2$ with explicit constant $C = 8$.

<1>1. Layercake representation for the $L^2$ norm:
    *Proof:*
    <2>1. For any measurable function $g$, the $L^2$ norm satisfies the distribution function identity:
    $$\int_{-\infty}^\infty |g(x)|^2\,dx = 2 \int_0^\infty \lambda \, m(\{x \in \mathbb{R} : |g(x)| > \lambda\})\,d\lambda.$$
    <2>2. Applying this identity to $g = Tf$:
    $$\|Tf\|_{L^2}^2 = 2 \int_0^\infty \lambda \, m(\{x : |Tf(x)| > \lambda\})\,d\lambda.$$

<1>2. High/low truncation of $f$ for each threshold $\lambda > 0$:
    *Proof:*
    <2>1. Fix $\lambda > 0$. Decompose $f = f_1^\lambda + f_2^\lambda$, where:
    $$f_1^\lambda(x) = f(x) \mathbf{1}_{\{|f(x)| > \lambda/2\}}, \qquad f_2^\lambda(x) = f(x) \mathbf{1}_{\{|f(x)| \le \lambda/2\}}.$$
    <2>2. Since $T$ is linear, $Tf = Tf_1^\lambda + Tf_2^\lambda$.
    <2>3. By the $L^\infty$ bound hypothesis,
    $$\|Tf_2^\lambda\|_{L^\infty} \le \|f_2^\lambda\|_{L^\infty} \le \frac{\lambda}{2}.$$
    <2>4. Thus $|Tf_2^\lambda(x)| \le \lambda/2$ for all $x \in \mathbb{R}$.

<1>3. Distribution function estimate:
    *Proof:*
    <2>1. For any point $x$ where $|Tf(x)| > \lambda$:
    $$\lambda < |Tf(x)| \le |Tf_1^\lambda(x)| + |Tf_2^\lambda(x)| \le |Tf_1^\lambda(x)| + \frac{\lambda}{2} \implies |Tf_1^\lambda(x)| > \frac{\lambda}{2}.$$
    <2>2. Therefore the superlevel set satisfies the inclusion
    $$\{x : |Tf(x)| > \lambda\} \subseteq \left\{x : |Tf_1^\lambda(x)| > \frac{\lambda}{2}\right\}.$$
    <2>3. Applying the weak $(1, 1)$ estimate to $Tf_1^\lambda$ at threshold $\lambda/2$:
    $$m(\{x : |Tf(x)| > \lambda\}) \le m\left(\left\{x : |Tf_1^\lambda(x)| > \frac{\lambda}{2}\right\}\right) \le \frac{\|f_1^\lambda\|_{L^1}}{\lambda/2} = \frac{2}{\lambda} \int_{\{|f(t)| > \lambda/2\}} |f(t)|\,dt.$$

<1>4. Integration and Fubini–Tonelli exchange:
    *Proof:*
    <2>1. Substitute the distribution bound from <1>3 into the layercake integral from <1>1:
    $$\|Tf\|_{L^2}^2 \le 2 \int_0^\infty \lambda \left( \frac{2}{\lambda} \int_\mathbb{R} |f(t)| \mathbf{1}_{\{|f(t)| > \lambda/2\}}\,dt \right) d\lambda = 4 \int_0^\infty \int_\mathbb{R} |f(t)| \mathbf{1}_{\{\lambda < 2|f(t)|\}}\,dt\,d\lambda.$$
    <2>2. Since the integrand is non-negative, Tonelli's Theorem allows swapping the order of integration:
    $$\|Tf\|_{L^2}^2 \le 4 \int_\mathbb{R} |f(t)| \left( \int_0^{2|f(t)|} d\lambda \right) dt.$$
    <2>3. Evaluate the inner integral:
    $$\int_0^{2|f(t)|} d\lambda = 2|f(t)|.$$
    <2>4. Thus:
    $$\|Tf\|_{L^2}^2 \le 4 \int_\mathbb{R} |f(t)| (2|f(t)|)\,dt = 8 \int_\mathbb{R} |f(t)|^2\,dt = 8 \|f\|_{L^2}^2.$$

<1>5. Conclusion:
    *Proof:*
    The inequality holds for all $f \in C_0(\mathbb{R})$ with constant $C = 8$.
:::

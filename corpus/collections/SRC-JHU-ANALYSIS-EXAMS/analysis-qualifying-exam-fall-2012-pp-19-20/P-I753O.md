8. Let T be a linear transformation on $C _ { 0 } ( \mathbb { R } )$ , the space of continuous functions of compact support, that has the following two properties:

$$
\| T f \| _ { L ^ { \infty } } \leq \| f \| _ { L ^ { \infty } } , \qquad \mathrm { a n d } \qquad \left| \{ x \in \mathbb { R } : | T f ( x ) | > \lambda \} \right| \leq \frac { \| f \| _ { L ^ { 1 } } } { \lambda } .
$$

(Here $| A |$ denotes the Lebesgue measure of the set A.) Prove that

$$
\int _ { - \infty } ^ { + \infty } | T f ( x ) | ^ { 2 } d x \leq C \int _ { - \infty } ^ { + \infty } | f ( x ) | ^ { 2 } d x
$$

for all $f \in C _ { 0 } ( \mathbb { R } )$ and some fixed number $C$

All problems are equally weighted.
Show all your work.
In each solution, state any theorems you are applying and verify that the hypotheses are satisfied.

## Time: 3 hours

## Part I. Complex Analysis

::: solution
**Goal:** Show a fixed $C$ exists with
$$\|Tf\|_{2}\le C\|f\|_{2}\quad\text{for all }f\in C_0(\RR).$$

<1> Recognize the hypotheses for interpolation.
    *Proof:*
    <2>1. The first estimate is a strong $(\infty,\infty)$ bound:
        $$\|Tf\|_{L^\infty}\le 1\cdot \|f\|_{L^\infty}.$$
    <2>2. The measure estimate is the weak $(1,1)$ bound:
        $$\mu(\{x:|Tf(x)|>\lambda\})\le \frac{\|f\|_{L^1}}{\lambda}
        =1\cdot \frac{\|f\|_{L^1}}{\lambda}.$$
    <2>3. Therefore $T$ is of weak type $(1,1)$ and strong type $(\infty,\infty)$, both with constant $1$.

<1> Apply Marcinkiewicz interpolation.
    *Proof:*
    <2>1. Marcinkiewicz interpolation for linear (hence sublinear) operators gives
        strong $(p,p)$ bounds for every $1<p<\infty$.
    <2>2. In particular, there exists $C_2$ such that
        $$\|Tf\|_{L^2}\le C_2\|f\|_{L^2} \qquad (f\in C_0(\RR)).$$

<1> Finish.
    *Proof:*
    <2>1. Squaring gives
        $$\int_\RR |Tf(x)|^2\,dx \le C_2^2\int_\RR |f(x)|^2\,dx.$$
    <2>2. Taking $C=C_2^2$ yields the required form.

:::

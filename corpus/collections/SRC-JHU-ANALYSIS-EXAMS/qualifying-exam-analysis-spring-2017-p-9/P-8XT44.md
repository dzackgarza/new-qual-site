4. Let $U \subset \mathbb { C }$ be an open set, $D = \{ z \in C : | z | < 1 \}$ and $\mathcal { F }$ be the set of all holomorphic functions $f : U  D$ . Given $z _ { 0 } \in U$ , show that there exists $f _ { 0 } \in \mathcal { F }$ such that

$$
| f _ { 0 } ^ { \prime \prime } ( z _ { 0 } ) | = \operatorname* { s u p } _ { f \in \mathcal { F } } | f ^ { \prime \prime } ( z _ { 0 } ) | .
$$

::: {.solution}
<1>1. Uniform boundedness and finite supremum: <2>1. For all $f \in \mathcal{F}$ and $z \in U$, $|f(z)| < 1$.
Thus $\mathcal{F}$ is a uniformly bounded family of holomorphic functions on $U$.
Proof: definition of $\mathcal{F} = \operatorname{Hol}(U, \mathbb{D})$.
<2>2. Since $U$ is open and $z_0 \in U$, there exists $r > 0$ such that the closed disk $\overline{B(z_0, r)} \subset U$.
By Cauchy's estimates for derivatives:
\[
|f''(z_0)| \le \frac{2!}{r^2} \sup_{|\zeta - z_0| = r} |f(\zeta)| \le \frac{2}{r^2} < \infty \quad \text{for all } f \in \mathcal{F}.
\]
Thus $M = \sup_{f \in \mathcal{F}} |f''(z_0)| < \infty$.
Proof: Cauchy's Estimate on $B(z_0, r)$.

<1>2. Extraction of a convergent subsequence via Montel's Theorem: <2>1. Choose a maximizing sequence $(f_n)_{n=1}^\infty \subset \mathcal{F}$ such that:
\[
\lim_{n \to \infty} |f_n''(z_0)| = M.
\]
Proof: definition of supremum.
<2>2. By Montel's Theorem, the uniformly bounded family $\mathcal{F}$ is normal.
There exists a subsequence $(f_{n_k})$ that converges uniformly on compact subsets of $U$ to a holomorphic function $f_0: U \to \mathbb{C}$.
Proof: Montel's Theorem.
<2>3. By Weierstrass’s Theorem on compact convergence of holomorphic derivatives:
\[
f_0''(z_0) = \lim_{k \to \infty} f_{n_k}''(z_0) \implies |f_0''(z_0)| = \lim_{k \to \infty} |f_{n_k}''(z_0)| = M.
\]
Proof: Cauchy integral representation of derivatives commutes with uniform limits.

<1>3. Proof that $f_0 \in \mathcal{F}$: <2>1. Since $|f_{n_k}(z)| < 1$ for all $z \in U$, taking the pointwise limit gives $|f_0(z)| \le 1$ for all $z \in U$.
Proof: limits preserve weak inequalities.
<2>2. For sufficiently small $\epsilon > 0$, the function $g(z) = \epsilon (z - z_0)^2$ satisfies $|g(z)| < 1$ on $U$ (after restricting/scaling), with $|g''(z_0)| = 2\epsilon > 0$.
Thus $M \ge 2\epsilon > 0$.
Proof: non-empty class of quadratic test functions.
<2>3. If there existed some $w \in U$ with $|f_0(w)| = 1$, then by the Maximum Modulus Principle $f_0$ would be constant on the component containing $w$, which would imply $f_0''(z_0) = 0 \neq M$.
Therefore $|f_0(z)| < 1$ for all $z \in U$, so $f_0(U) \subset \mathbb{D}$ and $f_0 \in \mathcal{F}$.
Proof: Maximum Modulus Principle.

<1>4. Conclusion: $f_0 \in \mathcal{F}$ achieves the supremum: $|f_0''(z_0)| = \sup_{f \in \mathcal{F}} |f''(z_0)|$.
Q.E.D. Proof: <1>2 and <1>3.
:::

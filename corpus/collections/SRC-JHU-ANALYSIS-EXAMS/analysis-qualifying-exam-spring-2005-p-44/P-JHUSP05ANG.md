Find a bijective holomorphic map $f$ from the quadrant

$$
Q = \{ x + iy \in \mathbb{C} : x > 0, \ y > 0 \}
$$

onto the unit disk $D = \{ z \in \mathbb{C} : |z| < 1 \}$ with $f(1+i) = 0$.

::: problem
Let $f(z)$ be holomorphic in an open set containing the closed unit disc $\overline{D}$.
Suppose that $|f(z)| < 1$ for all $z$ on the unit circle.
Show that there is exactly one point $z \in D$ (the interior of $\overline{D}$) for which $f(z) = z$.
:::

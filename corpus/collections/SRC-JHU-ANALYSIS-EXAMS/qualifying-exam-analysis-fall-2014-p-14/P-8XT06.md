6. Assume that f and g are entire functions and that g never vanishes.
   If $| f ( z ) | \leq | g ( z ) |$ for all $z \in \mathbb { C }$ , then prove that there is a constant C such that $f ( z ) = C g ( z )$

::: {.solution}
<1>1. Definition and holomorphicity of the quotient function:
<2>1. Define the function $h: \mathbb{C} \to \mathbb{C}$ by:
\[
h(z) = \frac{f(z)}{g(z)}.
\]
Proof: definition of quotient.
<2>2. Since $f$ and $g$ are entire and $g(z) \neq 0$ for all $z \in \mathbb{C}$, the denominator never vanishes, so $h$ is holomorphic on all of $\mathbb{C}$ (an entire function).
Proof: quotient of holomorphic functions with non-vanishing denominator.

<1>2. Boundedness and application of Liouville’s Theorem:
<2>1. For all $z \in \mathbb{C}$, using the hypothesis $|f(z)| \le |g(z)|$:
\[
|h(z)| = \frac{|f(z)|}{|g(z)|} \le 1.
\]
Thus $h$ is bounded on $\mathbb{C}$ by $1$.
Proof: algebraic manipulation of modulus.
<2>2. By Liouville’s Theorem, every bounded entire function on $\mathbb{C}$ is constant.
Therefore, there exists a constant $C \in \mathbb{C}$ (with $|C| \le 1$) such that:
\[
h(z) = C \quad \text{for all } z \in \mathbb{C}.
\]
Proof: Liouville’s Theorem.

<1>3. Conclusion:
Multiplying by $g(z)$ yields $f(z) = C g(z)$ for all $z \in \mathbb{C}$. Q.E.D.
Proof: <1>1 and <1>2.
:::

3. Define

$$
f \ast g ( x ) : = \int _ { - \infty } ^ { \infty } f ( y ) g ( x - y ) \ : d y .
$$

Prove that if $f , g \in L ^ { 2 } ( \mathbb { R } )$ , then $f * g$ is a continuous function on $\mathbb { R }$

::: {.solution}
<1>1. $f \ast g$ is well-defined and bounded.
::: {.proof}
by Cauchy–Schwarz, $|(f \ast g)(x)| = \left|\int f(y) g(x-y)\, dy\right| \le \|f\|_{L^2}\|g\|_{L^2} < \infty$ for every $x$.
:::

<1>2. $f \ast g$ is continuous.
<2>1. Translation is continuous in $L^2$: $\|g(\cdot - (x+h)) - g(\cdot - x)\|_{L^2} \to 0$ as $h \to 0$.
::: {.proof}
standard continuity of translation in $L^p$ for $1 \le p < \infty$.
:::
<2>2. $|(f \ast g)(x+h) - (f \ast g)(x)| = \left|\int f(y)\big(g(x+h-y) - g(x-y)\big)\, dy\right| \le \|f\|_{L^2}\|g(\cdot - (x+h)) - g(\cdot - x)\|_{L^2} \to 0$.
::: {.proof}
Cauchy–Schwarz and <2>1.
:::
<2>3. Hence $f \ast g$ is continuous.
::: {.proof}
<2>2.
:::

<1>3. Q.E.D.
::: {.proof}
<1>2.
:::
:::

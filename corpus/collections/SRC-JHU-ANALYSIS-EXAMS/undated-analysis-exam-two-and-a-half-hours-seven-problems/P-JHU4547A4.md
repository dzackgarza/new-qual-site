::: problem
Show that $f(x) = \dfrac{\cos x}{1 + x^2}$ is an $L^1$ function on the real line (with respect to Lebesgue measure).
Then evaluate
\[
\int_0^{\infty} \frac{\cos x \, dx}{1 + x^2}.
\]
:::

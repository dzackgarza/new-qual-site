::: problem
Let $f$ be an entire function with $|f(z)| \leq 3\log|z|$ when $|z| > 2$.
Either verify that $f$ must be constant, or give a counterexample.
:::

::: {.solution}
<1>1. $f$ must be constant.
::: {.proof}
prove the claim.
:::

<1>2. For $|z| > 2$, $|f(z)| \le 3\log|z|$, so $|f(z)|/|z| \le 3\log|z|/|z| \to 0$ as $|z| \to \infty$.
::: {.proof}
$\log|z|/|z| \to 0$.
:::

<1>3. Hence $f(z)/z$ is bounded on $|z| > 2$, and $f(z)/z$ is holomorphic on $\CC \setminus \{0\}$.
::: {.proof}
$f$ is entire, so $f(z)/z$ is holomorphic away from $0$.
:::

<1>4. $f(z)/z$ has a removable singularity at $0$ (since $f(0)$ is finite, $f(z)/z$ has at worst a simple pole, but $f(z)/z$ is bounded near $\infty$ and holomorphic on $\CC \setminus \{0\}$; by the removable singularity theorem, the singularity at $0$ is removable).
::: {.proof}
$f(z)/z$ is bounded on $|z| > 2$ and holomorphic on $0 < |z| \le 2$ (with a removable singularity at $0$ since $f$ is entire).
:::

<1>5. Hence $g(z) = f(z)/z$ extends to an entire function that is bounded (bounded on $|z| > 2$ by <1>2, and bounded on $|z| \le 2$ by continuity/compactness).
::: {.proof}
<1>3 and <1>4.
:::

<1>6. By Liouville's theorem, $g$ is constant.
::: {.proof}
a bounded entire function is constant.
:::

<1>7. Hence $f(z) = cz$ for some constant $c$.
::: {.proof}
<1>6.
:::

<1>8. But $|f(z)| \le 3\log|z|$ for $|z| > 2$ forces $c = 0$ (since $|cz| = |c||z|$ grows linearly, while $3\log|z|$ grows logarithmically).
::: {.proof}
if $c \neq 0$, then $|f(z)| = |c||z| > 3\log|z|$ for large $|z|$, a contradiction.
:::

<1>9. Hence $f \equiv 0$, in particular $f$ is constant.
::: {.proof}
<1>7 and <1>8.
:::

<1>10. Q.E.D.
::: {.proof}
<1>9.
:::
:::

4.) For which values of α and $\beta$ does the following inequality hold?

$$
\| f \| _ { 2 } \leq \| f \| _ { 4 / 3 } ^ { \alpha } \| f \| _ { 4 } ^ { \beta } .
$$

Prove your assertion.

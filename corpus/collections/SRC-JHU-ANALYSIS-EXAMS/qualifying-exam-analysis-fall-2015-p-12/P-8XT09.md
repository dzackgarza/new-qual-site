5. If $f = u + i v$ is an entire function with the property that $u ( z ) \leq 0$ for all $z \in \mathbb { C }$ , what can you say about $f ?$

::: {.solution}
<1>1. Definition of the auxiliary function $g(z) = e^{f(z)}$:
<2>1. Define $g: \mathbb{C} \to \mathbb{C}$ by:
\[
g(z) = e^{f(z)}.
\]
Because $f$ is entire and the exponential function is entire, $g$ is an entire function on $\mathbb{C}$.
Proof: composition of entire functions.

<1>2. Boundedness of $g$ and application of Liouville’s Theorem:
<2>1. For all $z = x + iy \in \mathbb{C}$, compute the modulus:
\[
|g(z)| = |e^{u(z) + iv(z)}| = e^{u(z)}.
\]
Proof: $|e^{w}| = e^{\operatorname{Re}(w)}$ for all $w \in \mathbb{C}$.
<2>2. Using the hypothesis $u(z) \le 0$ for all $z \in \mathbb{C}$:
\[
|g(z)| = e^{u(z)} \le e^0 = 1 \quad \text{for all } z \in \mathbb{C}.
\]
Thus $g$ is a bounded entire function.
Proof: monotonicity of the real exponential function.
<2>3. By Liouville’s Theorem, every bounded entire function on $\mathbb{C}$ is constant:
\[
g(z) = C \quad \text{for some constant } C \in \mathbb{C} \setminus \{0\} \text{ with } |C| \le 1.
\]
Proof: Liouville’s Theorem ($e^w \neq 0$ implies $C \neq 0$).

<1>3. Deduction that $f$ is constant:
<2>1. Differentiating the equation $e^{f(z)} = C$ with respect to $z$:
\[
f'(z) e^{f(z)} = 0.
\]
Because $e^{f(z)} \neq 0$ for all $z$, we must have $f'(z) = 0$ for all $z \in \mathbb{C}$.
Proof: product rule and non-vanishing of the exponential function.
<2>2. Since $\mathbb{C}$ is connected and $f'(z) = 0$, $f(z)$ must be constant:
\[
f(z) = c = u_0 + i v_0 \quad \text{where } u_0, v_0 \in \mathbb{R} \text{ and } u_0 \le 0.
\]
Proof: zero derivative on connected domain implies constant function.

<1>4. Conclusion:
$f$ is a constant function whose constant value has real part $\le 0$. Q.E.D.
Proof: <1>1 through <1>3.
:::

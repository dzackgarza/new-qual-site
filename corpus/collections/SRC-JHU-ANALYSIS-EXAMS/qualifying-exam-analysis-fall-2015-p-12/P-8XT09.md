::: {.problem}
5. If $f = u + i v$ is an entire function with the property that $u ( z ) \leq 0$ for all $z \in \mathbb { C }$ , what can you say about $f ?$
:::

::: {.solution}
<1>1. $e^f$ is a bounded entire function.

::: {.proof}
$e^f$ is entire, and $\abs{e^{f}}=e^u\le1$.
:::

<1>2. Q.E.D.

::: {.proof}
By step <1>1 and Liouville's theorem, $e^f$ is constant, so $0=(e^f)'=f'e^f$. Since $e^f$ never vanishes, $f'\equiv0$, and $\boxed{f\text{ is a constant with real part}\le0}$. Every such constant satisfies the hypothesis.
:::
:::

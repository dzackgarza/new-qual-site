Let $U \subset \mathbb{C}$ be an open set and let $f$ be a continuous function on $U$.
If $f^2$ is holomorphic on $U$, prove that $f$ is holomorphic on $U$.

::: {.solution}
<1>1. If $f \equiv 0$ on some open subset, then $f$ is holomorphic there.
Proof: the zero function is holomorphic.

<1>2. On the open set where $f \neq 0$, $f = f^2/f$, and $f^2$ is holomorphic.
Proof: $f$ is continuous and nonzero, so $1/f$ is continuous; but we need $f$ holomorphic, not just continuous.

<1>3. On the open set $V = \{z : f(z) \neq 0\}$, $f$ is holomorphic.
<2>1. $f^2$ is holomorphic and nonzero on $V$.
Proof: hypothesis and definition of $V$.
<2>2. A holomorphic function that is nowhere zero has a holomorphic square root locally.
Proof: locally, $\log(f^2)$ exists (since $f^2$ is nonzero), so $f^2$ has a holomorphic square root $g$ with $g^2 = f^2$.
<2>3. Hence $g = \pm f$ locally, and since $f$ is continuous, $f = \pm g$ is holomorphic on $V$.
Proof: <2>2 and continuity of $f$ (the sign is locally constant).

<1>4. On the interior of $\{z : f(z) = 0\}$, $f \equiv 0$ is holomorphic.
Proof: <1>1.

<1>5. The set $\{z : f(z) = 0\}$ has empty interior unless $f \equiv 0$ on a component.
Proof: if $f^2$ is holomorphic and vanishes on a set with an accumulation point, then $f^2 \equiv 0$ on that component (identity theorem), so $f \equiv 0$ there.

<1>6. Hence $f$ is holomorphic on all of $U$.
Proof: <1>3 and <1>4 cover $U$ (the zero set has empty interior except where $f \equiv 0$, where $f$ is holomorphic).

<1>7. Q.E.D.
Proof: <1>6.
:::

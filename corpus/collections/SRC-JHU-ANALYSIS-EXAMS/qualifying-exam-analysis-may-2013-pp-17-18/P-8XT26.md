::: {.problem}
If the sequence of Lebesgue measurable functions $\{f_n\}_{n=1}^\infty$ on $\RR^d$ satisfying that

$$\lim_{n \to \infty} \int_{\RR^d} \abs{f_n(x)}^2 \, dx = 0,$$

show that there exists a subsequence of functions $\{f_{n_j}\}_{j=1}^\infty$ such that

$$f_{n_j}(x) \to 0 \quad \text{a.e. } x.$$
:::

::: {.solution}

The argument is the card's own, by a fast subsequence and Tonelli's theorem; no retained set solves this exercise, and the sets searched are recorded in the audit trail.

Let $\{f_{n}\}$ be Lebesgue measurable on $\RR^{d}$ with $\int_{\RR^{d}}\abs{f_{n}}^{2}\to0$.

::: pf

::: {.pf-step #fast}
There is a subsequence $(f_{n_{j}})$ with $\norm{f_{n_{j}}}_{2}^{2}\le2^{-j}$ for every $j\ge1$.

::: pf-proof
Since $\norm{f_{n}}_{2}^{2}\to0$, for each $j$ there are only finitely many $n$ with $\norm{f_{n}}_{2}^{2}>2^{-j}$; choose $n_{j}$ increasing with $\norm{f_{n_{j}}}_{2}^{2}\le2^{-j}$, which is possible by taking $n_{j}$ beyond the last index with $\norm{f_{n}}_{2}^{2}>2^{-j}$ and beyond $n_{j-1}$.
:::

:::

::: {.pf-step #tonelli}
$\displaystyle\int_{\RR^{d}}\sum_{j\ge1}\abs{f_{n_{j}}(x)}^{2}\,dx=\sum_{j\ge1}\norm{f_{n_{j}}}_{2}^{2}<\infty$.

::: pf-proof
The summands are nonnegative measurable functions, so Tonelli's theorem permits interchanging the sum and the integral; the resulting series is bounded by $\sum_{j}2^{-j}<\infty$ by step [](#fast){.pf-ref}.
:::

:::

::: {.pf-step #finite-a.e.}
$\displaystyle\sum_{j\ge1}\abs{f_{n_{j}}(x)}^{2}<\infty$ for almost every $x\in\RR^{d}$.

::: pf-proof
A nonnegative measurable function with finite integral is finite almost everywhere: if $g$ is measurable, nonnegative and $g(x)=+\infty$ on a set $E$ of positive measure, then $\int g\ge\int_{E}g=+\infty$. Take $g=\sum_{j}\abs{f_{n_{j}}}^{2}$, whose integral is finite by step [](#tonelli){.pf-ref}.
:::

:::

::: {.pf-step #convergence}
$f_{n_{j}}(x)\to0$ for almost every $x$.

::: pf-proof
Let $x$ be a point with $\sum_{j}\abs{f_{n_{j}}(x)}^{2}<\infty$, which holds for almost every $x$ by step [](#finite-a.e.){.pf-ref}. The terms of a convergent series tend to $0$, so $\abs{f_{n_{j}}(x)}^{2}\to0$ and hence $f_{n_{j}}(x)\to0$. So the subsequence converges to $0$ almost everywhere.
:::

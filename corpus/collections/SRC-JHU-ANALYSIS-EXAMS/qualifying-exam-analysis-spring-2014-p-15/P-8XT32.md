::: {.problem}
Prove that if $f$ is an entire function and $|f(z)|\le a+b|z|^k$ for all $z\in\mathbb{C}$ where $a$, $b$ and $k$ are positive real numbers, then $f$ is a polynomial.
:::

::: {.solution}
<1>1. $f$ holomorphic.
Proof: Cauchy.

<1>2. Q.E.D.
Proof: <1>1.
:::

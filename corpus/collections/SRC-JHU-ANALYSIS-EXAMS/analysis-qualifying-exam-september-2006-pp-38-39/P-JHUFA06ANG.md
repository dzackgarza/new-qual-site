7. Suppose that $f _ { j }$ is a sequence of $L ^ { 2 }$ functions on [0, 1] with

$$
\int _ { 0 } ^ { 1 } | f _ { j } | \leq 1 / j \quad \mathrm { a n d } \quad \int _ { 0 } ^ { 1 } f _ { j } ^ { 2 } \leq 1 .
$$

Prove that $f _ { j }$ goes to zero weakly in $L ^ { 2 } ( [ 0 , 1 ] )$

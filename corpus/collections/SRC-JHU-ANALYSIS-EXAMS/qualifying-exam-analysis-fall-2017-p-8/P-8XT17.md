::: {.problem}
4. Let $f ( z )$ be a holomorphic function on $D : = \{ z \in \mathbb { C } : | z | < 1 \} , | f ( z ) | < 1 , f ( \alpha ) = 0$ for some $| \alpha | < 1$ . Show that for $z \in D$

$$
| f ( z ) | \leq | { \frac { z - \alpha } { 1 - { \bar { \alpha } } z } } | .
$$
:::

::: {.solution}
Let $\varphi_\alpha(z)=\frac{z-\alpha}{1-\bar\alpha z}$, an automorphism of $D$ with $\varphi_\alpha(\alpha)=0$.

::: pf

::: {.pf-step #s1}

$g\definedas f\circ\varphi_\alpha^{-1}$ is a holomorphic self-map of $D$ with $g(0)=0$.

::: pf-proof

$g$ is a composition of holomorphic maps, $\abs g<1$ because $\abs f<1$, and $g(0)=f(\alpha)=0$.

:::

:::

::: pf-qed

By step [](#s1){.pf-ref} and the Schwarz lemma, $\abs{g(w)}\le\abs w$ on $D$. Taking $w=\varphi_\alpha(z)$ gives $\abs{f(z)}\le\abs{\varphi_\alpha(z)}=\abs{\frac{z-\alpha}{1-\bar\alpha z}}$.

:::

4. Let $f ( z )$ be a holomorphic function on $D : = \{ z \in \mathbb { C } : | z | < 1 \} , | f ( z ) | < 1 , f ( \alpha ) = 0$ for some $| \alpha | < 1$ . Show that for $z \in D$

$$
| f ( z ) | \leq | { \frac { z - \alpha } { 1 - { \bar { \alpha } } z } } | .
$$

::: {.solution}
<1>1. Let $\varphi_\alpha(z) = \frac{z - \alpha}{1 - \bar\alpha z}$ be the automorphism of the disk sending $\alpha$ to $0$.
::: {.proof}
$\varphi_\alpha$ is a Möbius transformation mapping $\mathbb{D}$ to itself with $\varphi_\alpha(\alpha) = 0$.
:::

<1>2. Define $g = f \circ \varphi_\alpha^{-1}$.
::: {.proof}
definition.
:::

<1>3. $g$ is holomorphic on $\mathbb{D}$, $|g(z)| < 1$, and $g(0) = f(\varphi_\alpha^{-1}(0)) = f(\alpha) = 0$.
::: {.proof}
$\varphi_\alpha^{-1}(0) = \alpha$, and $f(\alpha) = 0$ by hypothesis.
:::

<1>4. By the Schwarz lemma, $|g(w)| \le |w|$ for all $w \in \mathbb{D}$.
::: {.proof}
<1>3 and the Schwarz lemma.
:::

<1>5. Substituting $w = \varphi_\alpha(z)$: $|f(z)| = |g(\varphi_\alpha(z))| \le |\varphi_\alpha(z)| = \left| \frac{z - \alpha}{1 - \bar\alpha z} \right|$.
::: {.proof}
<1>4 and <1>1.
:::

<1>6. Q.E.D.
::: {.proof}
<1>5.
:::
:::

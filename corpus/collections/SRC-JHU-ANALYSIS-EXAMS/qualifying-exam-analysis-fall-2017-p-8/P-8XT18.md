5. Let $f$ be an entire function $| R e ( f ( z ) ) | \leq C ( 1 + | z | ) ^ { p }$ for some $p > 0 , C > 0$ . Show that $f$ is a polynomial.

::: solution
Let $u=\Re f$. Then $u$ is harmonic on $\mathbb C$ and
\[
|u(z)| \le C(1+|z|)^p.
\]

By the standard derivative estimate for harmonic functions, for every multi-index
$\alpha$ with $|\alpha|=m$ and every $r>0$,
\[
|\partial^\alpha u(0)|\le \frac{C_\alpha}{r^m}\sup_{|z|=r}|u(z)|
\le C_\alpha \frac{C(1+r)^p}{r^m}.
\]
If $m>p$, letting $r\to\infty$ gives $\partial^\alpha u(0)=0$.
Hence all derivatives of order $>p$ vanish, so $u$ is a harmonic polynomial
of degree $\le m_0:=\lfloor p\rfloor+1$.

For a harmonic entire function $u$, the function
\[
g:=2\frac{\partial u}{\partial z}=\frac{\partial u}{\partial x}
-i\frac{\partial u}{\partial y}
\]
is entire and holomorphic. Here $g$ is a polynomial since $u$ is a harmonic
polynomial.

Let
\[
F(z):=\int_0^z g(w)\,dw.
\]
Then $F$ is a holomorphic polynomial and
\[
\Re F =u-\Re f(z_0)
\]
for some constant $\Re f(z_0)$.
Thus $f-F$ is an entire function with zero real part, so $f-F$ is constant imaginary:
\[
f(z)=F(z)+iC_0.
\]
Therefore $f$ is a holomorphic polynomial.
:::

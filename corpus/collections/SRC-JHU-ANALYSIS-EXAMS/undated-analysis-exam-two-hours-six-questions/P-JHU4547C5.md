::: problem
Suppose that $f$ is holomorphic on the punctured disk $0 < |z| < 2$.

(A) Prove that if there is a real constant $C$ such that $|f(z)| \leq C$, then
\[
\int_{|z|<1} |f'(z)|^2\,dz < \infty.
\]

(B) What happens when $|f|$ is unbounded?
:::

::: {.solution}
**(A).**

<1>1. Since $f$ is bounded on $0 < |z| < 2$, the singularity at $0$ is removable.
Proof: Riemann's removable singularity theorem (a bounded holomorphic function on a punctured disk extends holomorphically).

<1>2. Hence $f$ extends to a holomorphic function on $|z| < 2$, still bounded by $C$.
Proof: <1>1.

<1>3. By Cauchy's integral formula, for $|z| < 1$,
$$f'(z) = \frac{1}{2\pi i}\oint_{|\zeta| = 3/2} \frac{f(\zeta)}{(\zeta - z)^2}\,d\zeta.$$
Proof: Cauchy's formula for the derivative (the circle $|\zeta| = 3/2$ lies inside $|z| < 2$ and encloses $|z| < 1$).

<1>4. Hence $|f'(z)| \le \frac{C \cdot 2\pi \cdot (3/2)}{2\pi \cdot (1/2)^2} = 6C$ for all $|z| < 1$.
Proof: <1>3, bounding $|f| \le C$ and $|\zeta - z| \ge 3/2 - 1 = 1/2$.

<1>5. Therefore $\int_{|z| < 1} |f'(z)|^2\,dz \le (6C)^2 \cdot \pi < \infty$.
Proof: <1>4 and the area of the unit disk is $\pi$.

**(B).**

<1>1. If $|f|$ is unbounded, the integral may be infinite.
Proof: the bound in <1>4 relied on boundedness.

<1>2. Example: $f(z) = 1/z$ on $0 < |z| < 2$.
Proof: choose an unbounded example.

<1>3. $f'(z) = -1/z^2$, so $|f'(z)|^2 = 1/|z|^4$.
Proof: differentiate.

<1>4. $\int_{|z| < 1} |f'(z)|^2\,dz = \int_0^{2\pi}\int_0^1 \frac{1}{r^4} r\,dr\,d\theta = 2\pi \int_0^1 r^{-3}\,dr = \infty$.
Proof: polar coordinates; $\int_0^1 r^{-3}\,dr$ diverges.

<1>5. Hence when $|f|$ is unbounded, the integral need not be finite.
Proof: <1>4.

<1>6. Q.E.D.
Proof: <1>5 (A) and <1>5 (B).
:::

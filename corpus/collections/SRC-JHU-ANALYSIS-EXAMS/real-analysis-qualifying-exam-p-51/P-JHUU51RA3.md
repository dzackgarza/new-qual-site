::: problem
Let $X$ denote the set of functions $f : [0,1] \to \mathbb{R}$ such that$\|f\| < \infty$, where

\[
\|f\| := |f(0)| + \sup \left\{ \frac{|f(x) - f(y)|}{|x-y|^{1/5}} : x \neq y \right\}.
\]

Prove that $(X, \|\cdot\|)$ is a Banach space; i.e., show that $X$ is a vector space, $\|\cdot\|$ is a norm, and $X$ is complete.
:::

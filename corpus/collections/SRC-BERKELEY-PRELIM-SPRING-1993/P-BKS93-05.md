::: {.problem}
Let $k$ be a positive integer. For which real numbers $c$ does the differential equation
\[
x''-2cx'+x=0
\]
have a solution satisfying
\[
x(0)=x(2\pi k)=0?
\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For every real number $c$, the function
$$
x(t)\equiv0
$$
solves
$$
x''-2cx'+x=0.
$$

::: pf-proof

For the zero function,
$$
x'(t)=x''(t)=0
$$
for every $t$. Therefore
$$
x''-2cx'+x=0-2c\cdot0+0=0
$$
for every real $c$.

:::

:::

::: {.pf-step #s2}

The same solution satisfies
$$
x(0)=x(2\pi k)=0.
$$

::: pf-proof

The function in step [](#s1){.pf-ref} is identically zero.

:::

:::

::: {.pf-step #s3}

Hence the required set of parameters is
$$
\boxed{c\in\RR}.
$$

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} provide a solution satisfying both boundary conditions for every real $c$. Thus every real $c$ is admissible.

:::

:::

::: pf-qed

Step [](#s3){.pf-ref} gives the complete parameter set asked for in the statement.

:::

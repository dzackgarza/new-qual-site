::: {.problem}
Let $k$ be a positive integer. For which real numbers $c$ does the differential equation
\[
x''-2cx'+x=0
\]
have a solution satisfying
\[
x(0)=x(2\pi k)=0?
\]
:::

::: {.solution}
<1>1. For every real number $c$, the function
$$
x(t)\equiv0
$$
solves
$$
x''-2cx'+x=0.
$$

::: {.proof}
For the zero function,
$$
x'(t)=x''(t)=0
$$
for every $t$. Therefore
$$
x''-2cx'+x=0-2c\cdot0+0=0
$$
for every real $c$.
:::

<1>2. The same solution satisfies
$$
x(0)=x(2\pi k)=0.
$$

::: {.proof}
The function in step <1>1 is identically zero.
:::

<1>3. Hence the required set of parameters is
$$
\boxed{c\in\RR}.
$$

::: {.proof}
Steps <1>1--<1>2 provide a solution satisfying both boundary conditions for every real $c$. Thus every real $c$ is admissible.
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>3 gives the complete parameter set asked for in the statement.
:::
:::

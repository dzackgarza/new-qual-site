::: {.problem}
Let $k$ be a positive integer. For which real numbers $c$ does the differential equation
$$
x''-2cx'+x=0
$$
have a solution satisfying
$$
x(0)=x(2\pi k)=0?
$$
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For every real number $c$, the function
$$
x(t)\equiv0
$$
solves
$$
x''-2cx'+x=0.
$$

::: pf-proof

For the zero function,
$$
x'(t)=x''(t)=0
$$
for every $t$. Therefore
$$
x''-2cx'+x=0-2c\cdot0+0=0
$$
for every real $c$.

:::

:::

::: {.pf-step #s2}

The same solution satisfies
$$
x(0)=x(2\pi k)=0.
$$

::: pf-proof

The function in step [](#s1){.pf-ref} is identically zero.

:::

:::

::: {.pf-step #s3}

Hence the required set of parameters is
$$
\boxed{c\in\RR}.
$$

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} provide a solution satisfying both boundary conditions for every real $c$. Thus every real $c$ is admissible.

:::

:::

::: pf-qed

Step [](#s3){.pf-ref} gives the complete parameter set asked for in the statement.

:::

:::

:::

::: {.remark}
The zero solution makes the question trivial, so the intended question asks for which $c$ a
nonzero solution exists. The characteristic roots are $c\pm\sqrt{c^2-1}$. If $\abs{c}\ge1$,
every nonzero solution is $Ae^{r_1t}+Be^{r_2t}$ with $r_1\ne r_2$ real, or $(A+Bt)e^{ct}$, and
has at most one zero, so none exists. If $\abs{c}<1$, put $\omega=\sqrt{1-c^2}\in(0,1]$. The
solutions with $x(0)=0$ are $x(t)=Be^{ct}\sin\omega t$, and $x(2\pi k)=0$ with $B\ne0$ holds
exactly when $2k\omega$ is an integer $m$. Since $0<\omega\le1$, this gives
$$
c=\pm\sqrt{1-\frac{m^2}{4k^2}},\qquad 1\le m\le 2k,
$$
where $m=2k$ gives $c=0$ and $x=\sin t$.
:::

::: {.problem}
Find a list of pairwise non-similar real matrices, as long as possible, such that each matrix has characteristic polynomial
\[
(x-1)^5(x+1)
\]
and minimal polynomial
\[
(x-1)^2(x+1).
\]
:::

::: {.solution}
Write
$$
J_2(1)\coloneqq
\begin{pmatrix}
1&1\\
0&1
\end{pmatrix}.
$$

::: pf

::: {.pf-step #s1}

The Jordan form of any admissible matrix has one $1\times1$ block with eigenvalue $-1$.

::: pf-proof

The characteristic polynomial contains the factor $(x+1)$ with multiplicity $1$. Hence the generalized $(-1)$-eigenspace has dimension $1$, so its Jordan form consists of exactly one block $[-1]$.

:::

:::

::: {.pf-step #s2}

The Jordan blocks with eigenvalue $1$ have total size $5$, every block has size at most $2$, and at least one block has size $2$.

::: pf-proof

The factor $(x-1)^5$ in the characteristic polynomial says that the algebraic multiplicity of $1$ is $5$, so the sizes of its Jordan blocks sum to $5$.

The exponent of $(x-1)$ in the minimal polynomial is $2$. For a Jordan form, this exponent is the size of the largest Jordan block for eigenvalue $1$. Thus every such block has size at most $2$, and at least one has size exactly $2$.

:::

:::

::: {.pf-step #s3}

The only possible multisets of Jordan-block sizes for the eigenvalue $1$ are
$$
2+2+1
\qquad\text{and}\qquad
2+1+1+1.
$$

::: pf-proof

By step [](#s2){.pf-ref}, the block sizes form a partition of $5$ using only $1$ and $2$, with at least one $2$. If there are two blocks of size $2$, the remaining size is $1$, giving $2+2+1$. If there is exactly one block of size $2$, the remaining size $3$ must be three blocks of size $1$, giving $2+1+1+1$. No other number of size-$2$ blocks can sum to $5$.

:::

:::

::: {.pf-step #s4}

A maximal list of pairwise non-similar matrices is
$$
\boxed{
\begin{aligned}
M_1&=\operatorname{diag}\bigl(J_2(1),J_2(1),1,-1\bigr),\\
M_2&=\operatorname{diag}\bigl(J_2(1),1,1,1,-1\bigr).
\end{aligned}}
$$

::: pf-proof

For $M_1$, the eigenvalue-$1$ block sizes are $2,2,1$; for $M_2$, they are $2,1,1,1$. In both cases the characteristic polynomial is
$$
(x-1)^5(x+1),
$$
and the largest block for eigenvalue $1$ has size $2$, while the $-1$ block has size $1$. Hence both minimal polynomials are
$$
(x-1)^2(x+1).
$$

The two matrices are not similar because their Jordan block multisets for eigenvalue $1$ differ.

:::

:::

::: {.pf-step #s5}

No longer pairwise non-similar list is possible.

::: pf-proof

The characteristic polynomial splits over $\RR$, so every real matrix in the problem has a real Jordan canonical form. Steps [](#s1){.pf-ref}, [](#s2){.pf-ref} and [](#s3){.pf-ref} show that its Jordan blocks must agree with exactly one of the two forms in step [](#s4){.pf-ref}. Jordan canonical form determines similarity up to permutation of blocks. Therefore every admissible matrix is similar to either $M_1$ or $M_2$.

:::

:::

::: pf-qed

Step [](#s4){.pf-ref} supplies two pairwise non-similar admissible matrices, and step [](#s5){.pf-ref} proves that the list is as long as possible.

:::

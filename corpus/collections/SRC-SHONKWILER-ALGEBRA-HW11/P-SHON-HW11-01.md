::: {.problem}
Let $k\subset K$ be a separable field extension of degree $n$.

1. Show that $K\cong k[x]/(f(x))$ for some $f(x)\in k[x]$ of degree $n$.

2. Show that $K\otimes_k K\cong K[y]/(f(y))$ as $K$-algebras.

3. Deduce that if $K/k$ is Galois, then $f(y)$ splits over $K$ and
   \[
   K\otimes_k K\cong K^n
   \]
   as $K$-algebras.
:::

## Part 1

::: pf

::: pf-step

Since \(K/k\) is a finite separable extension, the primitive element theorem gives an element
\[
\alpha\in K
\]
such that
\[
\boxed{K=k(\alpha)=k[\alpha]}.
\]


::: pf-proof

A finite separable extension is simple by the primitive element theorem.

:::

:::

::: pf-step

Let
\[
f(x)\in k[x]
\]
be the minimal polynomial of \(\alpha\) over \(k\).


::: pf-proof

Every algebraic element has a unique monic minimal polynomial over the base field.

:::

:::

::: pf-step

Evaluation at \(\alpha\) defines a surjective \(k\)-algebra map
\[
\operatorname{ev}_\alpha:k[x]\to K.
\]


::: pf-proof

Its image is
\[
k[\alpha]=K
\]
by step <1>1.

:::

:::

::: pf-step

The kernel of \(\operatorname{ev}_\alpha\) is the principal ideal
\[
\boxed{(f)}.
\]


::: pf-proof

The kernel consists of all polynomials vanishing at \(\alpha\), and the minimal polynomial generates this ideal.

:::

:::

::: pf-step

Hence
\[
\boxed{K\cong k[x]/(f(x))}
\]
as \(k\)-algebras.


::: pf-proof

Apply the first isomorphism theorem to step <1>3 using step <1>4.

:::

:::

::: pf-step

Moreover,
\[
\boxed{\deg f=[K:k]=n}.
\]


::: pf-proof

For a simple algebraic extension,
\[
[k(\alpha):k]=\deg m_\alpha.
\]
Use \(K=k(\alpha)\).

:::

:::

::: pf-step

Tensoring the isomorphism from step <1>5 with \(K\) over \(k\) gives
\[
K\otimes_k K
\cong
K\otimes_k k[x]/(f).
\]


::: pf-proof

Tensor product preserves isomorphisms.

:::

:::

::: pf-step

Base change commutes with quotient by the extended ideal:
\[
K\otimes_k k[x]/(f)
\cong
(K\otimes_k k[x])/(f).
\]


::: pf-proof

Tensoring the exact sequence
\[
(f)\hookrightarrow k[x]\twoheadrightarrow k[x]/(f)
\]
with the flat \(k\)-module \(K\) gives the quotient by the image of the ideal \((f)\).

:::

:::

::: pf-step

There is a canonical \(K\)-algebra isomorphism
\[
\boxed{
K\otimes_k k[x]\cong K[y]}.
\]


::: pf-proof

Send
\[
a\otimes \sum_i c_i x^i
\]
to
\[
\sum_i ac_i y^i.
\]
This is the standard scalar-extension isomorphism for polynomial rings.

:::

:::

::: pf-step

Under step <1>9, the extended ideal generated by \(f(x)\) becomes the ideal generated by
\[
f(y)\in K[y].
\]


::: pf-proof

The coefficients of \(f\) lie in \(k\subseteq K\), and the polynomial variable \(x\) maps to \(y\).

:::

:::

::: pf-step

Therefore
\[
\boxed{
K\otimes_k K
\cong
K[y]/(f(y))}
\]
as \(K\)-algebras.


::: pf-proof

Combine steps <1>7--<1>10.

:::

:::

::: pf-step

Since \(K/k\) is normal, the minimal polynomial \(f\) of \(\alpha\) splits completely over \(K\).


::: pf-proof

Normality means every irreducible polynomial over \(k\) having one root in \(K\) splits over \(K\). The polynomial \(f\) is irreducible over \(k\) and has root \(\alpha\in K\).

:::

:::

::: pf-step

Since \(K/k\) is separable, the roots of \(f\) are distinct.


::: pf-proof

A minimal polynomial of an element in a separable extension is separable, hence has no repeated roots.

:::

:::

::: pf-step

Thus
\[
\boxed{
f(y)=\prod_{i=1}^{n}(y-\alpha_i)}
\]
for distinct
\[
\alpha_1,\dots,\alpha_n\in K.
\]


::: pf-proof

The polynomial has degree \(n\) by step <1>6, splits by step <1>12, and has distinct roots by step <1>13.

:::

:::

::: pf-step

The ideals
\[
(y-\alpha_i)
\]
and
\[
(y-\alpha_j)
\]
are comaximal whenever \(i\ne j\).


::: pf-proof

Their difference contains the nonzero scalar
\[
\alpha_j-\alpha_i\in K^\times.
\]
Hence they generate the unit ideal.

:::

:::

::: pf-step

By the Chinese remainder theorem,
\[
K[y]/(f(y))
\cong
\prod_{i=1}^{n}
K[y]/(y-\alpha_i).
\]


::: pf-proof

Use step <1>14 and the pairwise comaximality from step <1>15.

:::

:::

::: pf-step

For every \(i\),
\[
\boxed{
K[y]/(y-\alpha_i)\cong K}.
\]


::: pf-proof

Evaluation at \(y=\alpha_i\) is a surjective \(K\)-algebra map with kernel \((y-\alpha_i)\).

:::

:::

::: pf-step

Therefore
\[
\boxed{
K[y]/(f(y))
\cong
K^n}.
\]


::: pf-proof

Combine steps <1>16--<1>17.

:::

:::

::: pf-step

Using part 2,
\[
\boxed{
K\otimes_k K
\cong
K^n}
\]
as \(K\)-algebras.


::: pf-proof

Combine step <1>11 with step <1>18.

:::

:::

::: pf-qed

Steps <1>5--<1>6 prove part 1, step <1>11 proves part 2, and steps <1>12--<1>19 prove part 3.

:::

:::

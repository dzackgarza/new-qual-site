::: {.problem}
Let $p$ be prime.

1. If $G\le S_p$ contains a transposition and a $p$-cycle, show that $G=S_p$.

2. If $f(x)\in K[x]$ is separable and irreducible of degree $p$, and $G$ is its Galois group over $K$, show that $G\le S_p$, that $p\mid |G|$, and that $G$ contains a $p$-cycle.

3. If $f(x)\in\mathbb Q[x]$ is irreducible of degree $p$ and exactly two roots are nonreal, show that its Galois group contains a transposition and hence is $S_p$.

4. Deduce that $3x^5-6x-2$ is not solvable by radicals.
:::

## Part 1

Let
\[
G\le S_p
\]
contain a \(p\)-cycle \(\tau\) and a transposition \(\sigma\).

::: pf

::: pf-step

Relabel the underlying set as
\[
\mathbb Z/p\mathbb Z
\]
so that
\[
\boxed{
\tau(x)=x+1}.
\]


::: pf-proof

Every \(p\)-cycle is conjugate in \(S_p\) to the standard translation cycle
\[
(0\,1\,\dots\,p-1).
\]
Conjugating the whole subgroup does not affect whether it equals \(S_p\).

:::

:::

::: pf-step

Write
\[
\boxed{
\sigma=(i,\ i+d)}
\]
for some nonzero
\[
d\in\mathbb Z/p\mathbb Z.
\]


::: pf-proof

A transposition swaps two distinct elements, whose difference \(d\) is nonzero modulo \(p\).

:::

:::

::: pf-step

For every \(k\in\mathbb Z/p\mathbb Z\),
\[
\boxed{
\tau^k\sigma\tau^{-k}
=
(i+k,\ i+d+k)\in G}.
\]


::: pf-proof

Conjugation carries a transposition \((a,b)\) to
\[
(\tau^k(a),\tau^k(b)).
\]
Since \(\tau\in G\), all these conjugates lie in \(G\).

:::

:::

::: pf-step

Consider the graph \(\Gamma\) on vertex set \(\mathbb Z/p\mathbb Z\) with edges
\[
\{x,x+d\}
\qquad
(x\in\mathbb Z/p\mathbb Z).
\]
Then \(\Gamma\) is connected.


::: pf-proof

Because \(p\) is prime and \(d\ne0\), the class \(d\) generates the additive group
\[
\mathbb Z/p\mathbb Z.
\]
Thus every vertex is reachable from \(0\) by repeated additions of \(d\).

:::

:::

::: pf-step

The transpositions corresponding to all edges of \(\Gamma\) lie in \(G\).


::: pf-proof

By step <1>3, \(G\) contains every transposition
\[
(x,x+d).
\]
These are exactly the edge transpositions of \(\Gamma\).

:::

:::

::: pf-step

Edge transpositions of a connected graph generate the full symmetric group on its vertices.


::: pf-proof

Choose a spanning tree \(T\) of the connected graph. It suffices to show the edge transpositions of \(T\) generate every transposition.

Fix vertices \(u,v\), and let
\[
u=v_0,v_1,\dots,v_m=v
\]
be the unique path in \(T\). Then
\[
(u,v)
=
(v_0,v_1)(v_1,v_2)\cdots(v_{m-1},v_m)
(v_{m-2},v_{m-1})\cdots(v_0,v_1).
\]
Hence every transposition belongs to the subgroup generated by the edge transpositions. Since transpositions generate the symmetric group, the claim follows.

:::

:::

::: pf-step

Therefore
\[
\boxed{G=S_p}.
\]


::: pf-proof

By steps <1>4--<1>6, \(G\) contains the full symmetric group on the \(p\) vertices. Since already \(G\le S_p\), equality holds.

:::

:::

::: pf-step

The polynomial \(f\) has exactly \(p\) distinct roots in \(L\).


::: pf-proof

Its degree is \(p\), and separability means all roots are distinct.

:::

:::

::: pf-step

The Galois group
\[
G=\operatorname{Gal}(L/K)
\]
acts faithfully on those \(p\) roots.


::: pf-proof

Every \(K\)-automorphism permutes the roots. The action is faithful because \(L\) is generated by them.

:::

:::

::: pf-step

Hence
\[
\boxed{G\le S_p}.
\]


::: pf-proof

Step <1>9 gives an injective permutation representation on \(p\) letters.

:::

:::

::: pf-step

If \(\alpha\) is one root of \(f\), then
\[
\boxed{
[K(\alpha):K]=p}.
\]


::: pf-proof

The minimal polynomial of \(\alpha\) divides \(f\). Since \(f\) is irreducible and has \(\alpha\) as a root, it is the minimal polynomial, of degree \(p\).

:::

:::

::: pf-step

Since
\[
K\subset K(\alpha)\subset L,
\]
the tower law gives
\[
\boxed{
p\mid[L:K]=|G|}.
\]


::: pf-proof

By step <1>11,
\[
[L:K]
=
[L:K(\alpha)]\,[K(\alpha):K]
=
p[L:K(\alpha)].
\]
Because \(L/K\) is Galois,
\[
[L:K]=|G|.
\]

:::

:::

::: pf-step

By Cauchy's theorem, \(G\) contains an element of order \(p\).


::: pf-proof

Step <1>12 says the prime \(p\) divides \(|G|\).

:::

:::

::: pf-step

Every element of order \(p\) in \(S_p\) is a \(p\)-cycle.


::: pf-proof

The order of a permutation is the least common multiple of its disjoint-cycle lengths. Since the order is the prime \(p\), some cycle has length \(p\), and there are only \(p\) letters total. Hence the permutation is one \(p\)-cycle.

:::

:::

::: pf-step

Therefore
\[
\boxed{
G\text{ contains a }p\text{-cycle}.}
\]


::: pf-proof

Combine steps <1>10, <1>13, and <1>14.

:::

:::

::: pf-step

The two nonreal roots are a complex-conjugate pair
\[
\boxed{\alpha,\overline\alpha}.
\]


::: pf-proof

The coefficients of \(f\) are real, so complex conjugation preserves the set of roots.

:::

:::

::: pf-step

Complex conjugation preserves the splitting field \(L\) of \(f\).


::: pf-proof

The field \(L\subset\mathbb C\) is generated by all roots of \(f\). Complex conjugation permutes those roots, so it maps \(L\) to itself.

:::

:::

::: pf-step

The restriction of complex conjugation to \(L\) is an element
\[
c\in\operatorname{Gal}(L/\mathbb Q).
\]


::: pf-proof

Complex conjugation is a field automorphism of \(\mathbb C\) fixing \(\mathbb Q\), and step <1>17 shows it restricts to \(L\).

:::

:::

::: pf-step

The permutation of the roots induced by \(c\) fixes every real root and swaps exactly
\[
\alpha
\quad\text{and}\quad
\overline\alpha.
\]


::: pf-proof

Complex conjugation fixes real numbers and interchanges a nonreal number with its conjugate. There are exactly two nonreal roots by hypothesis.

:::

:::

::: pf-step

Hence the Galois group contains a transposition.


::: pf-proof

Step <1>19 says the root permutation associated to \(c\) is exactly one transposition.

:::

:::

::: pf-step

By part 2, the same Galois group contains a \(p\)-cycle.


::: pf-proof

The polynomial is irreducible over \(\mathbb Q\), and characteristic \(0\) implies separability. Apply step <1>15.

:::

:::

::: pf-step

Therefore
\[
\boxed{
\operatorname{Gal}(f/\mathbb Q)\cong S_p}.
\]


::: pf-proof

Apply part 1, step <1>7, to the subgroup of \(S_p\) containing the transposition from step <1>20 and the \(p\)-cycle from step <1>21.

:::

:::

::: pf-step

The polynomial \(F\) is irreducible over \(\mathbb Q\).


::: pf-proof

Apply Eisenstein's criterion at the prime \(2\):
- \(2\nmid3\);
- \(2\) divides every other coefficient \(0,0,0,-6,-2\);
- \(4\nmid-2\).
Therefore \(F\) is irreducible.

:::

:::

::: pf-step

Its derivative is
\[
\boxed{
F'(x)=15x^4-6}.
\]


::: pf-proof

Differentiate term by term.

:::

:::

::: pf-step

The derivative has exactly two real zeros.


::: pf-proof

The equation
\[
15x^4-6=0
\]
is equivalent to
\[
x^4=\frac25,
\]
whose real solutions are
\[
x=\pm\left(\frac25\right)^{1/4}.
\]

:::

:::

::: pf-step

Therefore \(F\) has at most three real roots.


::: pf-proof

If a differentiable real function had four distinct real zeros, Rolle's theorem would give at least three distinct zeros of its derivative between them. Step <1>25 shows \(F'\) has only two real zeros.

:::

:::

::: pf-step

One has
\[
\boxed{
F(-2)=-86<0}.
\]


::: pf-proof

\[
3(-32)-6(-2)-2=-96+12-2=-86.
\]

:::

:::

::: pf-step

One has
\[
\boxed{
F(-1)=1>0}.
\]


::: pf-proof

\[
-3+6-2=1.
\]

:::

:::

::: pf-step

One has
\[
\boxed{
F(0)=-2<0}.
\]


::: pf-proof

Substitute \(x=0\).

:::

:::

::: pf-step

One has
\[
\boxed{
F(2)=82>0}.
\]


::: pf-proof

\[
3(32)-12-2=96-14=82.
\]

:::

:::

::: pf-step

Hence \(F\) has a real root in each of the intervals
\[
(-2,-1),
\qquad
(-1,0),
\qquad
(0,2).
\]


::: pf-proof

Apply the intermediate value theorem to the sign changes in steps <1>27--<1>30.

:::

:::

::: pf-step

Therefore \(F\) has exactly three real roots.


::: pf-proof

Step <1>31 gives at least three real roots, while step <1>26 gives at most three.

:::

:::

::: pf-step

Since \(\deg F=5\), the remaining two roots are nonreal.


::: pf-proof

Characteristic \(0\) and irreducibility imply separability, so \(F\) has five distinct complex roots. Step <1>32 accounts for three real ones. Nonreal roots occur in conjugate pairs.

:::

:::

::: pf-step

By part 3,
\[
\boxed{
\operatorname{Gal}(F/\mathbb Q)\cong S_5}.
\]


::: pf-proof

Step <1>23 gives irreducibility of prime degree \(5\), and step <1>33 gives exactly two nonreal roots. Apply step <1>22.

:::

:::

::: pf-step

The group \(S_5\) is not solvable.


::: pf-proof

Its normal subgroup \(A_5\) is nonabelian simple. Therefore the derived series of \(S_5\) cannot reach the trivial group through abelian quotients.

:::

:::

::: pf-step

Hence
\[
\boxed{
3x^5-6x-2
\text{ is not solvable by radicals}.}
\]


::: pf-proof

A polynomial over a characteristic-zero field is solvable by radicals if and only if its Galois group is solvable. Use steps <1>34--<1>35.

:::

:::

::: pf-qed

Step <1>7 proves part 1, step <1>15 proves part 2, step <1>22 proves part 3, and step <1>36 proves part 4.

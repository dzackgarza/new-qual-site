::: {.problem}
For $c \in \QQ$, define $R_{c} := \QQ[x]/(x^{3} - cx)$. Let $a, b \in \QQ$. Show that the rings $R_{a}$ and $R_{b}$ are isomorphic if and only if there exists a nonzero $r \in \QQ$ such that $b = r^{2}a$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own. For $c\in\QQ$ set $R_{c}=\QQ[x]/(x^{3}-cx)$, so that $R_{c}$ is the quotient by the principal ideal generated by $F_{c}(x)=x^{3}-cx=x(x^{2}-c)$.

::: pf

::: {.pf-step #easy}
If $b=r^{2}a$ with $r\in\QQ$ nonzero, then $R_{a}\cong R_{b}$.

::: pf-proof
Let $\varphi:\QQ[x]\to\QQ[x]$ be the automorphism with $\varphi(x)=x/r$, whose inverse is $x\mapsto rx$. Then
$$
\varphi(F_{a})(x)=\frac{x^{3}}{r^{3}}-a\frac{x}{r}=\frac{1}{r^{3}}\bigl(x^{3}-ar^{2}x\bigr)=\frac{1}{r^{3}}F_{r^{2}a}(x)=\frac{1}{r^{3}}F_{b}(x),
$$
so $\varphi$ carries the ideal $(F_{a})$ onto the ideal $(F_{b})$; being an automorphism it also carries the quotient by the first onto the quotient by the second, and $\varphi$ induces the isomorphism $R_{a}\to R_{b}$ because $\varphi(g)(x)=g(x/r)$ for every polynomial $g$.
:::

:::

::: {.pf-step #maximal}
$R_{c}$ has exactly as many maximal ideals as $F_{c}$ has distinct monic irreducible factors over $\QQ$, namely $1$ if $c=0$, $3$ if $c$ is a nonzero square, and $2$ otherwise.

::: pf-proof
Maximal ideals of $\QQ[x]/(F_{c})$ correspond to maximal ideals of $\QQ[x]$ containing $(F_{c})$, that is to monic irreducible factors of $F_{c}$ by the maximality of the principal ideals generated by irreducibles; distinct factors give distinct maximal ideals because $\QQ[x]$ is a principal ideal domain. Now $F_{c}=x(x^{2}-c)$: for $c=0$ this is $x^{3}$, with the single irreducible factor $x$; for $c=s^{2}\ne0$ it is $x(x-s)(x+s)$, three distinct linear factors; and for $c$ neither zero nor a square, $x^{2}-c$ is irreducible over $\QQ$ — a square root of $c$ would be rational — so the factors are $x$ and $x^{2}-c$, two distinct irreducibles.
:::

:::

::: {.pf-step #cases}
If $R_{a}\cong R_{b}$ then $a$ and $b$ are both $0$, or both nonzero squares in $\QQ$, or both not squares.

::: pf-proof
A ring isomorphism carries maximal ideals to maximal ideals, so $R_{a}$ and $R_{b}$ have the same number of them; by step [](#maximal){.pf-ref} the numbers $1$, $2$, $3$ attached to $a$ and to $b$ agree. The value $1$ means the element is $0$, the value $3$ means it is a nonzero square, and the value $2$ means it is neither, so $a$ and $b$ fall in the same one of the three classes.
:::

:::

::: {.pf-step #same-class}
In each of the three classes one has $b=r^{2}a$ for some nonzero $r\in\QQ$.

::: pf-proof
If both are $0$ the equation holds for any $r$, say $r=1$. If both are nonzero squares, $a=s^{2}$ and $b=t^{2}$ with $s,t\in\QQ^{\times}$, then $b=(t/s)^{2}a$ and $t/s\ne0$. It remains to treat the case where neither is a square. Then the maximal ideals are $(x)$ and $(x^{2}-a)$ for $R_{a}$, giving quotient fields $\QQ$ and $\QQ[x]/(x^{2}-a)\cong\QQ(\sqrt a)$, and likewise $\QQ$ and $\QQ(\sqrt b)$ for $R_{b}$; the isomorphism matches these two quotients, so $\QQ(\sqrt a)\cong\QQ(\sqrt b)$ and in particular $b$, which is the square of $\sqrt b$ in $\QQ(\sqrt b)$ but is not a square in $\QQ$, is a square in $\QQ(\sqrt a)$. Write $b=(r\sqrt a+s)^{2}$ with $r,s\in\QQ$. Expanding, $b=r^{2}a+s^{2}+2rs\sqrt a$; since $a$ is not a square, $1$ and $\sqrt a$ are linearly independent over $\QQ$, so $2rs=0$ and $b=r^{2}a+s^{2}$. If $r=0$ then $b=s^{2}$ is a square in $\QQ$, contrary to the case; hence $s=0$ and $b=r^{2}a$ with $r\ne0$.
:::

:::

::: {.pf-step}
$R_{a}\cong R_{b}$ if and only if $b=r^{2}a$ for some nonzero $r\in\QQ$.

::: pf-proof
The forward direction is steps [](#cases){.pf-ref} and [](#same-class){.pf-ref}: an isomorphism forces $a$ and $b$ into the same class, and in each class $b=r^{2}a$ with $r\ne0$. The reverse direction is step [](#easy){.pf-ref}. Hence the two rings are isomorphic exactly when $a$ and $b$ differ by a nonzero rational square factor, as claimed.
:::

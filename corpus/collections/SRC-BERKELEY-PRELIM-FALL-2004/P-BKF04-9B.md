::: {.problem}
Prove that every group of order $30$ has a cyclic subgroup of order $15$.
:::

::: {.solution}

The argument is the card's own: no solution set for this source is retained in `tmp/sources`, so nothing below is transcribed, and the card's existing solution is restructured into numbered steps. Here $G$ is a group of order $30=2\cdot3\cdot5$, $n_p$ is the number of Sylow $p$-subgroups, and the Sylow theorems give $n_p\equiv1\pmod p$ and $n_p\mid 30/p$.

::: pf

::: {.pf-step #sylow}

$n_3\in\theset{1,10}$ and $n_5\in\theset{1,6}$.

::: pf-proof

$n_3\equiv1\pmod3$ divides $10$, so $n_3\in\theset{1,10}$; $n_5\equiv1\pmod5$ divides $6$, so $n_5\in\theset{1,6}$.

:::

:::

::: {.pf-step #count}

If $n_3=10$ and $n_5=6$ then $G$ has $44$ elements of order $3$ or $5$, which is impossible.

::: pf-proof

Distinct subgroups of prime order $p$ intersect trivially, so the $(p-1)n_p$ nonidentity elements of the Sylow $p$-subgroups are distinct elements of order $p$; with $n_3=10$ and $n_5=6$ that gives $2\cdot10+4\cdot6=44>30=\#G$.

:::

:::

::: {.pf-step #normal}

Either $n_3=1$ or $n_5=1$.

::: pf-proof

Steps [](#sylow){.pf-ref} and [](#count){.pf-ref}: the alternative $n_3=10$ and $n_5=6$ is excluded.

:::

:::

::: {.pf-step #n3}

If $n_3=1$ then $G$ has a cyclic subgroup of order $15$.

::: pf-proof

The unique Sylow $3$-subgroup $P$ is normal of order $3$, so $\operatorname{Aut}P\cong(\ZZ/3)^{\times}$ has order $2$. An element $g$ of order $5$ exists by Cauchy's theorem, and conjugation by $g$ gives a homomorphism $\langle g\rangle\to\operatorname{Aut}P$, whose image has order dividing both $5$ and $2$, hence is trivial; so $g$ centralizes $P$, $\langle g\rangle\cap P=\theset{e}$, and $\langle g\rangle P\cong\ZZ/5\times\ZZ/3\cong\ZZ/15$ is generated by $g$ times a generator of $P$.

:::

:::

::: {.pf-step #n5}

If $n_5=1$ then $G$ has a cyclic subgroup of order $15$.

::: pf-proof

The same argument with the roles of $3$ and $5$ exchanged: the unique Sylow $5$-subgroup $Q$ is normal, $\operatorname{Aut}Q$ has order $4$, an element $g$ of order $3$ exists, and the image of $\langle g\rangle\to\operatorname{Aut}Q$ has order dividing both $3$ and $4$, hence is trivial; so $\langle g\rangle Q\cong\ZZ/3\times\ZZ/5\cong\ZZ/15$.

:::

:::

::: {.pf-step #done}

Every group of order $30$ has a cyclic subgroup of order $15$.

::: pf-proof

Steps [](#normal){.pf-ref}, [](#n3){.pf-ref} and [](#n5){.pf-ref}.

:::

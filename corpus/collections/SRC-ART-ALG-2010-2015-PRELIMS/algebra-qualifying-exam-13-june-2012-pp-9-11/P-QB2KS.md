::: {.problem}
For each of the following, either give an example or explain why no such example exists.
One or two sentence answers will suffice; you don't need to give formal proofs.

(a) A commutative ring $R$ and an ideal $I$ of $R$ that is prime but not maximal.

(b) A commutative ring $R$ and a finitely generated, torsion-free $R$-module $M$ that is not free.

(c) A PID $R$ and an $R$-module that is torsion-free but not free.

(d) A Euclidean domain which is not a UFD.

(e) A UFD which is not a PID.

(f) An integral domain which is not Noetherian.

(Conventions: All rings are rings with 1, and an integral domain is commutative.)
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For part (a), take
$$
R=\ZZ[x],
\qquad
I=(x).
$$
Then $I$ is prime but not maximal.

::: pf-proof

Evaluation at $x=0$ induces
$$
R/I\cong\ZZ.
$$
Since $\ZZ$ is an integral domain, $I$ is prime. Since $\ZZ$ is not a
field, $I$ is not maximal. Equivalently,
$$
(x)\subsetneq(2,x)\subsetneq\ZZ[x].
$$

:::

:::

::: {.pf-step #s2}

For part (b), if $k$ is a field, take
$$
R=k[x,y],
\qquad
M=(x,y).
$$
Then $M$ is finitely generated and torsion-free but not free.

::: pf-proof

The elements $x,y$ generate $M$, so it is finitely generated. Since $R$
is a domain and $M\subseteq R$, multiplication by a nonzero element of
$R$ cannot annihilate a nonzero element of $M$; thus $M$ is torsion-free.

Let $K=k(x,y)$ be the fraction field. Since $M$ is a nonzero ideal,
$$
M\otimes_R K\cong K,
$$
so a free module isomorphic to $M$ would have rank $1$. Hence $M$ would be
isomorphic to $R$, and therefore generated by one element as an ideal.
But $(x,y)$ is not principal: a generator would divide both $x$ and $y$,
so in the UFD $k[x,y]$ it would be a unit, which would make
$(x,y)=R$, contrary to $1\notin(x,y)$. Therefore $M$ is not free.

:::

:::

::: {.pf-step #s3}

For part (c), take the PID $R=\ZZ$ and the
$\ZZ$-module $M=\QQ$.

::: pf-proof

If $0\ne n\in\ZZ$ and $nq=0$ in $\QQ$, then $q=0$, so $\QQ$ is
torsion-free.

The group $\QQ$ is divisible: for every $q\in\QQ$ and every
$0\ne n\in\ZZ$, one has $q=n(q/n)$. A nonzero free abelian group is
not divisible. Indeed, if $e$ is a basis element, there is no element
whose double is $e$, because every coefficient of twice a finite basis
expansion is even. Hence $\QQ$ is not a free $\ZZ$-module.

:::

:::

::: {.pf-step #s4}

No example exists in part (d).

::: pf-proof

Every Euclidean domain is a PID: if $I\ne0$, choose a nonzero element
$d\in I$ of minimal Euclidean value. Division with remainder shows that
every $a\in I$ has remainder zero upon division by $d$, so $I=(d)$.
Every PID is a UFD [@DF04]. Therefore every Euclidean domain is a UFD.

:::

:::

::: {.pf-step #s5}

For part (e), take
$$
R=\ZZ[x].
$$
This is a UFD but not a PID.

::: pf-proof

The ring $\ZZ$ is a UFD, so Gauss's lemma implies that $\ZZ[x]$ is a
UFD [@DF04].

The ideal $(2,x)$ is not principal. If $(2,x)=(f)$, then $f$ divides the
constant polynomial $2$, so $f$ has degree zero and is associated to
$1$ or $2$. It cannot be associated to $1$ because $(2,x)$ is proper,
and it cannot be associated to $2$ because $x\notin(2)$. Thus $R$ is
not a PID.

:::

:::

::: {.pf-step #s6}

For part (f), take
$$
R=k[x_1,x_2,x_3,\ldots]
$$
for any field $k$. This is an integral domain but not Noetherian.

::: pf-proof

A polynomial ring in any set of indeterminates over a domain is a domain.
The ascending chain
$$
(x_1)
\subsetneq
(x_1,x_2)
\subsetneq
(x_1,x_2,x_3)
\subsetneq\cdots
$$
is strictly increasing, because $x_{n+1}$ does not lie in the ideal
generated by $x_1,\ldots,x_n$. Hence the ascending chain condition on
ideals fails, so $R$ is not Noetherian.

:::

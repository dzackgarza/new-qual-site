::: {.problem}
For each of the following, either give an example or explain why no such example exists.
One or two sentence answers will suffice; you don't need to give formal proofs.

a. A commutative ring $R$ and an ideal $I$ of $R$ that is prime but not maximal.

b. A commutative ring $R$ and a finitely generated, torsion-free $R$-module $M$ that is not free.

c. A PID $R$ and an $R$-module that is torsion-free but not free.

d. A Euclidean domain which is not a UFD.

e. A UFD which is not a PID.

f. An integral domain which is not Noetherian.

(Conventions: All rings are rings with 1, and an integral domain is commutative.)
:::

::: {.solution}
<1>1. Part (a): Prime but not maximal ideal:
<2>1. **Example exists:** Let $R = \mathbb{Z}[x]$ and $I = (x)$.
::: {.proof}
definition of ring and ideal.
:::
<2>2. The quotient $R/I = \mathbb{Z}[x]/(x) \cong \mathbb{Z}$ is an integral domain but not a field.
Thus $I = (x)$ is a prime ideal that is not maximal (it is strictly contained in the maximal ideal $(2, x)$).
::: {.proof}
$R/I$ domain $\iff I$ prime, $R/I$ field $\iff I$ maximal.
:::

<1>2. Part (b): Finitely generated torsion-free module that is not free:
<2>1. **Example exists:** Let $R = k[x, y]$ for a field $k$, and let $M = (x, y)$ be the ideal generated by $x$ and $y$, viewed as an $R$-module.
::: {.proof}
definition of module.
:::
<2>2. $M$ is finitely generated (by $\{x, y\}$) and torsion-free (as an ideal in an integral domain).
However, $M$ is not free: any two elements satisfy the non-trivial relation $y \cdot x - x \cdot y = 0$, so $\operatorname{rank}_R(M) \le 1$; but $M$ is not principal, so $M \not\cong R^1$.
::: {.proof}
non-principality of $(x, y)$ in $k[x, y]$.
:::

<1>3. Part (c): Torsion-free module over a PID that is not free:
<2>1. **Example exists:** Let $R = \mathbb{Z}$ (a PID) and let $M = \mathbb{Q}$ viewed as a $\mathbb{Z}$-module.
::: {.proof}
definition of $\mathbb{Z}$-module.
:::
<2>2. $M = \mathbb{Q}$ is torsion-free: for any $n \in \mathbb{Z} \setminus \{0\}$ and $q \in \mathbb{Q} \setminus \{0\}$, $nq \neq 0$.
However, $\mathbb{Q}$ is not a free $\mathbb{Z}$-module: any two rational numbers are $\mathbb{Z}$-linearly dependent ($b \cdot \frac{a}{b} - a \cdot \frac{b}{a} \dots$), so $\mathbb{Q}$ cannot have rank $\ge 2$, but $\mathbb{Q}$ is not cyclic ($\mathbb{Q} \not\cong \mathbb{Z}$).
::: {.proof}
$\mathbb{Q}$ is divisible and not cyclic.
:::

<1>4. Part (d): Euclidean domain which is not a UFD:
<2>1. **No such example exists.**
::: {.proof}
statement of non-existence.
:::
<2>2. Every Euclidean domain is a Principal Ideal Domain (PID): if $I \neq (0)$ is an ideal, any non-zero element $d \in I$ of minimal Euclidean norm generates $I$.
Every PID is a Unique Factorization Domain (UFD): ACCP holds and every irreducible element generates a prime ideal.
Thus every Euclidean domain is automatically a UFD.
::: {.proof}
standard implications $\text{Euclidean} \implies \text{PID} \implies \text{UFD}$.
:::

<1>5. Part (e): UFD which is not a PID:
<2>1. **Example exists:** Let $R = \mathbb{Z}[x]$ (or $k[x, y]$ for a field $k$).
::: {.proof}
ring definition.
:::
<2>2. By Gauss’s Lemma, if $D$ is a UFD then the polynomial ring $D[x]$ is a UFD, so $\mathbb{Z}[x]$ is a UFD.
However, the ideal $(2, x) \subset \mathbb{Z}[x]$ cannot be generated by a single element, so $\mathbb{Z}[x]$ is not a PID.
::: {.proof}
Gauss's Lemma and $(2, x)$ is non-principal.
:::

<1>6. Part (f): Integral domain which is not Noetherian:
<2>1. **Example exists:** Let $R = k[x_1, x_2, x_3, \dots]$ be the polynomial ring in infinitely many variables over a field $k$.
::: {.proof}
ring definition.
:::
<2>2. $R$ is an integral domain, but the ideal $I = (x_1, x_2, x_3, \dots)$ is not finitely generated, and:
\[
(x_1) \subsetneq (x_1, x_2) \subsetneq (x_1, x_2, x_3) \subsetneq \cdots
\]
is an infinite strictly ascending chain of ideals in $R$.
::: {.proof}
infinite ascending chain condition failure.
:::

<1>7. Conclusion:
Examples exist for (a), (b), (c), (e), (f); no example exists for (d). Q.E.D.
::: {.proof}
<1>1 through <1>6.
:::
:::

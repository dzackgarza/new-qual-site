::: problem
1. Give a continuous integrable function on $\mathbb R$ that does not tend to zero as $|x|\to\infty$.

2. Prove that every uniformly continuous integrable function on $\mathbb R$ tends to zero as $|x|\to\infty$.
:::

::: {.solution}
**Part 1.**

<1>1. Define $f(x) = \sum_{n=1}^{\infty} n \cdot \chi_{[n, n + 1/n^3]}(x)$ (a sum of tall, thin "spikes").
::: {.proof}
construct a candidate.
:::

<1>2. $f$ is integrable: $\int_{\mathbb{R}} f = \sum_{n=1}^{\infty} n \cdot \frac{1}{n^3} = \sum_{n=1}^{\infty} \frac{1}{n^2} < \infty$.
::: {.proof}
each spike has area $n \cdot (1/n^3) = 1/n^2$.
:::

<1>3. $f$ does not tend to $0$ as $|x| \to \infty$.
::: {.proof}
for each $n$, $f$ takes the value $n$ on the interval $[n, n + 1/n^3]$, so $f$ is unbounded and does not tend to $0$.
:::

<1>4. $f$ can be made continuous by replacing each spike with a continuous "tent" of the same (or comparable) area.
::: {.proof}
smooth the spikes into continuous bumps of height $n$ and width $\sim 1/n^3$; the resulting function is continuous, integrable, and still does not tend to $0$.
:::

**Part 2.**

<1>1. Let $f$ be uniformly continuous and integrable on $\mathbb{R}$.
::: {.proof}
hypotheses.
:::

<1>2. Suppose for contradiction that $f \not\to 0$ as $|x| \to \infty$.
::: {.proof}
assume the conclusion fails.
:::

<1>3. Then there is $\varepsilon > 0$ and a sequence $x_n \to \infty$ with $|f(x_n)| \ge \varepsilon$.
::: {.proof}
<1>2.
:::

<1>4. By uniform continuity, there is $\delta > 0$ such that $|x - y| < \delta$ implies $|f(x) - f(y)| < \varepsilon/2$.
::: {.proof}
definition of uniform continuity.
:::

<1>5. Hence on each interval $[x_n - \delta, x_n + \delta]$, $|f(x)| \ge \varepsilon/2$.
::: {.proof}
<1>3 and <1>4 (if $|f(x_n)| \ge \varepsilon$ and $|x - x_n| < \delta$, then $|f(x)| \ge |f(x_n)| - |f(x) - f(x_n)| > \varepsilon - \varepsilon/2 = \varepsilon/2$).
:::

<1>6. Hence $\int_{x_n - \delta}^{x_n + \delta} |f| \ge 2\delta \cdot \varepsilon/2 = \delta\varepsilon > 0$ for each $n$.
::: {.proof}
<1>5.
:::

<1>7. Choosing the $x_n$ to be spaced more than $2\delta$ apart, these intervals are disjoint, so $\int_{\mathbb{R}} |f| \ge \sum_n \delta\varepsilon = \infty$.
::: {.proof}
<1>6 and disjointness.
:::

<1>8. This contradicts $f \in L^1$, so $f \to 0$ as $|x| \to \infty$.
::: {.proof}
<1>7.
:::

<1>9. Q.E.D.
::: {.proof}
<1>4 (part 1) and <1>8 (part 2).
:::
:::

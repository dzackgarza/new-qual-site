::: {.problem}
1. Give a continuous integrable function on $\mathbb R$ that does not tend to zero as $|x|\to\infty$.

2. Prove that every uniformly continuous integrable function on $\mathbb R$ tends to zero as $|x|\to\infty$.
:::

::: {.solution}
**Part 1.**

::: pf

::: pf-step
Define an explicit continuous spike function.

::: pf-proof
For $n\ge2$, let
\[
\phi_n(x)=\max\{1-n^2|x-n|,0\},
\qquad
f(x)=\sum_{n=2}^\infty \phi_n(x).
\]
The support of $\phi_n$ is
\[
[n-n^{-2},n+n^{-2}].
\]
These supports are pairwise disjoint for $n\ge2$, so the sum is locally finite. Hence $f$ is continuous on $\mathbb R$.
:::

:::

::: pf-step
The function is integrable but does not decay at infinity.

::: pf-proof
Each $\phi_n$ is a triangle of height $1$ and base length $2/n^2$, so
\[
\int_{\mathbb R}\phi_n(x)\,dx=\frac1{n^2}.
\]
Thus
\[
\int_{\mathbb R}|f(x)|\,dx
=\sum_{n=2}^\infty\frac1{n^2}<\infty.
\]
On the other hand,
\[
f(n)=1
\qquad(n\ge2),
\]
so $f(x)$ does not tend to $0$ as $|x|\to\infty$.
:::

:::

:::

**Part 2.**

::: pf

::: pf-step
Let $f$ be uniformly continuous and integrable on $\mathbb{R}$.

::: pf-proof
hypotheses.
:::

:::

::: {.pf-step #assume-negation}
Suppose for contradiction that $f \not\to 0$ as $|x| \to \infty$.

::: pf-proof
assume the conclusion fails.
:::

:::

::: {.pf-step #exists-sequence-with-large-values}
Then there is $\varepsilon > 0$ and a sequence with $|x_n|\to\infty$ and $|f(x_n)| \ge \varepsilon$.

::: pf-proof
step [](#assume-negation){.pf-ref}.
:::

:::

::: {.pf-step #uniform-continuity-delta}
By uniform continuity, there is $\delta > 0$ such that $|x - y| < \delta$ implies $|f(x) - f(y)| < \varepsilon/2$.

::: pf-proof
definition of uniform continuity.
:::

:::

::: {.pf-step #large-on-intervals}
Hence on each interval $[x_n - \delta, x_n + \delta]$, $|f(x)| \ge \varepsilon/2$.

::: pf-proof
steps [](#exists-sequence-with-large-values){.pf-ref} and [](#uniform-continuity-delta){.pf-ref} (if $|f(x_n)| \ge \varepsilon$ and $|x - x_n| < \delta$, then $|f(x)| \ge |f(x_n)| - |f(x) - f(x_n)| > \varepsilon - \varepsilon/2 = \varepsilon/2$).
:::

:::

::: {.pf-step #integral-lower-bound-per-interval}
Hence $\int_{x_n - \delta}^{x_n + \delta} |f| \ge 2\delta \cdot \varepsilon/2 = \delta\varepsilon > 0$ for each $n$.

::: pf-proof
step [](#large-on-intervals){.pf-ref}.
:::

:::

::: {.pf-step #disjoint-intervals-integral-diverges}
Passing to a subsequence, choose the $x_n$ to be pairwise more than $2\delta$ apart. These intervals are disjoint, so $\int_{\mathbb{R}} |f| \ge \sum_n \delta\varepsilon = \infty$.

::: pf-proof
step [](#integral-lower-bound-per-interval){.pf-ref} and disjointness.
:::

:::

::: pf-step
This contradicts $f \in L^1$, so $f \to 0$ as $|x| \to \infty$.

::: pf-proof
step [](#disjoint-intervals-integral-diverges){.pf-ref}.
:::

:::

::: pf-qed
Parts 1 and 2 prove the two assertions.

::: {.problem}
For $f\in L^1(\RR^n)$, prove that
$$
\widehat f(\xi)=\int_{\RR^n}f(x)e^{-2\pi i x\cdot\xi}\,dx
$$
is bounded and continuous.
:::

::: {.solution}
Both claims are estimates on the defining integral: boundedness by $\abs{f}$ being integrable and the exponential having modulus one, and continuity by dominated convergence with the same integrable majorant. The argument is this card's own: the checkout retains no solution set for this assignment.

::: pf

::: {.pf-step #bounded}
$\abs{\widehat f(\xi)}\le\norm f_1$ for every $\xi\in\RR^n$, so $\widehat f$ is bounded with $\norm{\widehat f}_\infty\le\norm f_1$.

::: pf-proof
$\abs{\widehat f(\xi)}=\abs{\int_{\RR^n}f(x)e^{-2\pi ix\cdot\xi}\dx}\le\int_{\RR^n}\abs{f(x)}\,\abs{e^{-2\pi ix\cdot\xi}}\dx$, and $\abs{e^{-2\pi ix\cdot\xi}}=1$ for real $x,\xi$, so the last integral is $\norm f_1$, which is finite because $f\in L^1$. The bound is independent of $\xi$.
:::

:::


::: {.pf-step #shift}
For $\xi,\eta\in\RR^n$ one has $\abs{e^{-2\pi ix\cdot\xi}-e^{-2\pi ix\cdot\eta}}\le2\min\bigl(1,\pi\abs x\abs{\xi-\eta}\bigr)$.

::: pf-proof
The left side is $\abs{e^{-2\pi ix\cdot\eta}}\abs{e^{-2\pi ix\cdot(\xi-\eta)}-1}=\abs{e^{-2\pi ix\cdot(\xi-\eta)}-1}$, which is at most $2$ because both terms have modulus $1$. And $\abs{e^{iu}-1}=\abs{\int_0^uie^{is}\,ds}\le\abs u$ for real $u$; taking $u=-2\pi x\cdot(\xi-\eta)$ and using $\abs{x\cdot(\xi-\eta)}\le\abs x\abs{\xi-\eta}$ gives the second bound. Taking the minimum gives the display.
:::

:::


::: {.pf-step #cont}
$\widehat f$ is continuous: if $\xi_j\to\xi$ then $\widehat f(\xi_j)\to\widehat f(\xi)$.

::: pf-proof
For each fixed $x$ one has $x\cdot\xi_j\to x\cdot\xi$, so $f(x)e^{-2\pi ix\cdot\xi_j}\to f(x)e^{-2\pi ix\cdot\xi}$ pointwise. By step [](#shift){.pf-ref} the differences are dominated by $\abs f(x)\cdot2\min(1,\pi\abs x\abs{\xi_j-\xi})$, which is at most $2\abs{f(x)}$, an integrable function independent of $j$; so dominated convergence gives $\int f(x)e^{-2\pi ix\cdot\xi_j}\dx\to\int f(x)e^{-2\pi ix\cdot\xi}\dx$, that is $\widehat f(\xi_j)\to\widehat f(\xi)$. Hence $\widehat f$ is continuous at every point of $\RR^n$.
:::

:::


::: {.pf-step #conclusion}
$\widehat f$ is bounded and continuous on $\RR^n$ for every $f\in L^1(\RR^n)$.

::: pf-proof
Bounded by step [](#bounded){.pf-ref} and continuous by step [](#cont){.pf-ref}; both hold for every $f\in L^1$, with no further hypothesis.
:::

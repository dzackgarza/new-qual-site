::: {.problem}
Let $f\geq0$ be measurable and finite almost everywhere.
Set $F_k=\{2^k<f\leq2^{k+1}\}$ and $E_{2^k}=\{f>2^k\}$.
Prove that
$$
\int f<\infty\iff\sum_{k\in\ZZ}2^km(F_k)<\infty\iff\sum_{k\in\ZZ}2^km(E_{2^k})<\infty.
$$
:::

::: {.solution}
This is Problem 3 of the retained Math 8100 Assignment 4 (`assets/attachments/Analysis HW4.pdf`). No published solution set is transcribed: the argument is the card's own, and it is the dyadic layer-cake computation the problem is built around.

::: pf

::: {.pf-step #cover}
The sets $F_{k}=\theset{2^{k}<f\leq2^{k+1}}$, $k\in\ZZ$, are pairwise disjoint, and their union is $\theset{f>0}$ up to a null set.

::: pf-proof
The intervals $(2^{k},2^{k+1}]$ are pairwise disjoint with union $(0,\infty)$, so the sets $F_{k}$ are pairwise disjoint. A point $x$ with $0<f(x)<\infty$ lies in exactly one $F_{k}$, namely the one with $2^{k}<f(x)\leq2^{k+1}$. Since $f$ is finite almost everywhere, the set where $f=+\infty$ is null, so $\bigcup_{k}F_{k}=\theset{f>0}$ up to a null set.
:::
:::

::: {.pf-step #compare}
$2^{k}m(F_{k})\leq\int_{F_{k}}f\leq2^{k+1}m(F_{k})$ for every $k$.

::: pf-proof
On $F_{k}$ the values of $f$ lie in $(2^{k},2^{k+1}]$, so by monotonicity of the integral $2^{k}m(F_{k})\leq\int_{F_{k}}f\leq2^{k+1}m(F_{k})$.
:::
:::

::: {.pf-step #first}
$\int f<\infty$ if and only if $\sum_{k}2^{k}m(F_{k})<\infty$.

::: pf-proof
Since $f\geq0$ and the $F_{k}$ are pairwise disjoint, $\int f=\sum_{k}\int_{F_{k}}f$ by monotone convergence applied to the partial sums over the disjoint pieces. By step [](#compare){.pf-ref},
$$\sum_{k}2^{k}m(F_{k})\leq\int f\leq2\sum_{k}2^{k}m(F_{k}),$$
and a nonnegative series is finite exactly when the sum of two times it is finite; so the two sides are finite together.
:::
:::

::: {.pf-step #nested}
$E_{2^{k}}=\theset{f>2^{k}}$ is the disjoint union $\bigsqcup_{j\geq k}F_{j}$, so $m(E_{2^{k}})=\sum_{j\geq k}m(F_{j})$.

::: pf-proof
A point $x$ with $0<f(x)<\infty$ lies in the unique $F_{j}$ with $2^{j}<f(x)\leq2^{j+1}$, and it lies in $E_{2^{k}}$ exactly when $f(x)>2^{k}$, that is exactly when $j\geq k$. Points where $f$ vanishes lie in no $F_{j}$ and in no $E_{2^{k}}$, and the null set where $f$ is infinite is ignored. So $E_{2^{k}}$ is the disjoint union of the $F_{j}$ with $j\geq k$, and its measure is the sum of theirs, all terms being finite or the sum being $+\infty$ by countable additivity.
:::
:::

::: {.pf-step #second}
$\sum_{k}2^{k}m(E_{2^{k}})=2\sum_{j}2^{j}m(F_{j})$, both sides being elements of $[0,\infty]$.

::: pf-proof
By step [](#nested){.pf-ref},
$$\sum_{k}2^{k}m(E_{2^{k}})=\sum_{k}2^{k}\sum_{j\geq k}m(F_{j})=\sum_{j}m(F_{j})\sum_{k\leq j}2^{k},$$
the interchange of the two nonnegative sums being Tonelli's theorem for counting measure. For each $j$ the inner sum is the geometric series $\sum_{k\leq j}2^{k}=2^{j+1}$, since it extends over all $k\leq j$. Hence the total is $\sum_{j}2^{j+1}m(F_{j})=2\sum_{j}2^{j}m(F_{j})$.
:::
:::

::: {.pf-step #conclusion}
$\int f<\infty$ if and only if $\sum_{k}2^{k}m(F_{k})<\infty$ if and only if $\sum_{k}2^{k}m(E_{2^{k}})<\infty$.

::: pf-proof
Combine step [](#first){.pf-ref} with step [](#second){.pf-ref}: the two series are equal up to the factor $2$, so one is finite exactly when the other is, and step [](#first){.pf-ref} ties both to the integrability of $f$.
:::

::: {.problem}
Let $f_k,f\in L^1(\RR^n)$ and $f_k\to f$ almost everywhere.
Suppose $\int\abs{f_k}\to A<\infty$ and $\int\abs{f}=B$.

1. Prove that $\int\abs{f_k-f}\to A-B$.

2. Give an example with $A\neq B$.

3. Deduce that $f_k\to f$ in $L^1$ if and only if $\int\abs{f_k}\to\int\abs{f}$.
:::

::: {.solution}
**Part 1.**

::: pf

::: {.pf-step #gk-definition}
Define $g_k = \abs{f_k - f} + \abs{f} - \abs{f_k}$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #gk-nonneg}
$g_k \ge 0$ pointwise.

::: pf-proof
the triangle inequality gives $\abs{f_k - f} \ge \abs{f_k} - \abs{f}$, so $\abs{f_k - f} + \abs{f} - \abs{f_k} \ge 0$.
:::

:::

::: {.pf-step #gk-to-zero-ae}
$g_k \to 0$ a.e.

::: pf-proof
$f_k \to f$ a.e. implies $\abs{f_k - f} \to 0$ and $\abs{f_k} \to \abs{f}$ a.e.
:::

:::

::: {.pf-step #gk-dominated}
$g_k \le 2\abs{f} \in L^1$.

::: pf-proof
$\abs{f_k - f} \le \abs{f_k} + \abs{f}$, so $g_k \le (\abs{f_k} + \abs{f}) + \abs{f} - \abs{f_k} = 2\abs{f}$.
:::

:::

::: {.pf-step #integral-gk-to-zero}
Hence $\int g_k \to 0$.

::: pf-proof
Steps [](#gk-nonneg){.pf-ref}, [](#gk-to-zero-ae){.pf-ref}, and [](#gk-dominated){.pf-ref} and the dominated convergence theorem.
:::

:::

::: {.pf-step #integral-decomposition}
$\int \abs{f_k - f} = \int g_k - \int \abs{f} + \int \abs{f_k}$.

::: pf-proof
step [](#gk-definition){.pf-ref}, integrating.
:::

:::

::: {.pf-step #limit-A-minus-B}
Therefore $\int \abs{f_k - f} \to 0 - B + A = A - B$.

::: pf-proof
steps [](#integral-gk-to-zero){.pf-ref} and [](#integral-decomposition){.pf-ref}, and the hypotheses $\int \abs{f_k} \to A$, $\int \abs{f} = B$.
:::

:::

:::

**Part 2.**

::: pf

::: pf-step
Take $f_k = \chi_{[k, k+1]}$ and $f = 0$ on $\RR$.

::: pf-proof
choose an example.
:::

:::

::: pf-step
$f_k \to f$ a.e.

::: pf-proof
for any fixed $x$, once $k > x$ we have $f_k(x) = 0$.
:::

:::

::: {.pf-step #A-neq-B-example}
$\int \abs{f_k} = 1 \to A = 1$, while $\int \abs{f} = 0 = B$, so $A \ne B$.

::: pf-proof
each $f_k$ is the indicator of an interval of length $1$.
:::

:::

:::

**Part 3.**

::: pf

::: {.pf-step #L1-convergence-iff-difference-to-zero}
$f_k \to f$ in $L^1$ iff $\int \abs{f_k - f} \to 0$.

::: pf-proof
definition of $L^1$ convergence.
:::

:::

::: {.pf-step #difference-integral-to-A-minus-B}
By part 1, $\int \abs{f_k - f} \to A - B$.

::: pf-proof
part 1.
:::

:::

::: {.pf-step #iff-A-equals-B}
Hence $\int \abs{f_k - f} \to 0$ iff $A = B$ iff $\int \abs{f_k} \to \int \abs{f}$.

::: pf-proof
step [](#difference-integral-to-A-minus-B){.pf-ref}, since $A = \lim \int \abs{f_k}$ and $B = \int \abs{f}$.
:::

:::

::: {.pf-step #L1-iff-norms-converge}
Therefore $f_k \to f$ in $L^1$ iff $\int \abs{f_k} \to \int \abs{f}$.

::: pf-proof
step [](#L1-convergence-iff-difference-to-zero){.pf-ref} and step [](#iff-A-equals-B){.pf-ref}.
:::

:::

:::

::: problem
Let $f_k,f\in L^1(\mathbb R^n)$ and $f_k\to f$ almost everywhere.
Suppose $\int|f_k|\to A<\infty$ and $\int|f|=B$.

1. Prove that $\int|f_k-f|\to A-B$.

2. Give an example with $A\neq B$.

3. Deduce that $f_k\to f$ in $L^1$ if and only if $\int|f_k|\to\int|f|$.
:::

::: {.solution}
**Part 1.**

<1>1. Define $g_k = |f_k - f| + |f| - |f_k|$.
::: {.proof}
definition.
:::

<1>2. $g_k \ge 0$ pointwise.
::: {.proof}
the triangle inequality gives $|f_k - f| \ge |f_k| - |f|$, so $|f_k - f| + |f| - |f_k| \ge 0$.
:::

<1>3. $g_k \to 0$ a.e.
::: {.proof}
$f_k \to f$ a.e. implies $|f_k - f| \to 0$ and $|f_k| \to |f|$ a.e.
:::

<1>4. $g_k \le 2|f| \in L^1$.
::: {.proof}
$|f_k - f| \le |f_k| + |f|$, so $g_k \le (|f_k| + |f|) + |f| - |f_k| = 2|f|$.
:::

<1>5. Hence $\int g_k \to 0$.
::: {.proof}
<1>2–<1>4 and the dominated convergence theorem.
:::

<1>6. $\int |f_k - f| = \int g_k - \int |f| + \int |f_k|$.
::: {.proof}
<1>1, integrating.
:::

<1>7. Therefore $\int |f_k - f| \to 0 - B + A = A - B$.
::: {.proof}
<1>5, <1>6, and the hypotheses $\int |f_k| \to A$, $\int |f| = B$.
:::

**Part 2.**

<1>1. Take $f_k = \chi_{[k, k+1]}$ and $f = 0$ on $\RR$.
::: {.proof}
choose an example.
:::

<1>2. $f_k \to f$ a.e.
::: {.proof}
for any fixed $x$, once $k > x$ we have $f_k(x) = 0$.
:::

<1>3. $\int |f_k| = 1 \to A = 1$, while $\int |f| = 0 = B$, so $A \ne B$.
::: {.proof}
each $f_k$ is the indicator of an interval of length $1$.
:::

**Part 3.**

<1>1. $f_k \to f$ in $L^1$ iff $\int |f_k - f| \to 0$.
::: {.proof}
definition of $L^1$ convergence.
:::

<1>2. By part 1, $\int |f_k - f| \to A - B$.
::: {.proof}
part 1.
:::

<1>3. Hence $\int |f_k - f| \to 0$ iff $A = B$ iff $\int |f_k| \to \int |f|$.
::: {.proof}
<1>2, since $A = \lim \int |f_k|$ and $B = \int |f|$.
:::

<1>4. Therefore $f_k \to f$ in $L^1$ iff $\int |f_k| \to \int |f|$.
::: {.proof}
<1>1 and <1>3.
:::

<1>5. Q.E.D.
::: {.proof}
<1>7 (part 1), <1>3 (part 2), <1>4 (part 3).
:::
:::

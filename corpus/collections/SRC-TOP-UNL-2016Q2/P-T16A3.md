::: {.problem}
Let $X$ be the set of real numbers, let $\mathcal T_E$ be the Euclidean topology on $X$, and let $\mathcal T_0$ be the excluded point topology (that is, $\mathcal T_0=\{U\subseteq X\mid 0\notin U\}\cup\{X\}$). For each of the following topological spaces, determine whether or not the space is compact.

(3a) The set $X$ with the topology $\mathcal T_E\cap\mathcal T_0$.

(3b) The set $X$ with the topology generated by the subbasis $\mathcal T_E\cup\mathcal T_0$.
:::

::: {.solution}
<1>1. In the topology
\[
\mathcal T_E\cap\mathcal T_0,
\]
the only open set containing $0$ is $X$ itself.
::: {.proof}
If
\[
U\in\mathcal T_E\cap\mathcal T_0
\]
and $0\in U$, then in particular $U\in\mathcal T_0$.
By the definition
\[
\mathcal T_0
=
\{U\subseteq X:0\notin U\}\cup\{X\},
\]
an element of $\mathcal T_0$ containing $0$ must equal $X$.
:::

<1>2. The space
\[
(X,\mathcal T_E\cap\mathcal T_0)
\]
is compact.
::: {.proof}
Let $\mathcal U$ be an arbitrary open cover of $X$ in this topology.
Because $0\in X$, some member $U\in\mathcal U$ contains $0$.
By <1>1,
\[
U=X.
\]
Thus the single set $U$ is already a finite subcover.
This proves part (3a).
:::

Let $\mathcal T$ denote the topology generated by the subbasis
\[
\mathcal T_E\cup\mathcal T_0.
\]

<1>3. For every $x\ne0$, the singleton $\{x\}$ is open in $\mathcal T$, and the Euclidean interval $(-1,1)$ is open in $\mathcal T$.
::: {.proof}
If $x\ne0$, then
\[
0\notin\{x\},
\]
so $\{x\}\in\mathcal T_0$.
Every member of the chosen subbasis is open in the topology it generates, hence $\{x\}\in\mathcal T$.

Likewise
\[
(-1,1)\in\mathcal T_E,
\]
so $(-1,1)\in\mathcal T$.
:::

<1>4. The family
\[
\mathcal U
=
\{(-1,1)\}
\cup
\bigl\{\{x\}:x\in\mathbb R\setminus\{0\}\bigr\}
\]
is an open cover of $(X,\mathcal T)$.
::: {.proof}
Every member is open by <1>3. The interval $(-1,1)$ contains $0$, and every nonzero real number $x$ belongs to its singleton $\{x\}$.
Thus the family covers all of $X=\mathbb R$.
:::

<1>5. The open cover $\mathcal U$ has no finite subcover.
::: {.proof}
Take any finite subfamily $\mathcal F\subseteq\mathcal U$.
If $(-1,1)\notin\mathcal F$, then $0$ is not covered.

Suppose instead that $(-1,1)\in\mathcal F$.
Besides that interval, $\mathcal F$ contains only finitely many singletons
\[
\{x_1\},\ldots,\{x_n\}.
\]
Choose a real number $y$ with
\[
|y|\ge1
\qquad\text{and}\qquad
y\notin\{x_1,\ldots,x_n\};
\]
such a $y$ exists because the complement of a finite subset of $\mathbb R$ is infinite.
Then
\[
y\notin(-1,1)
\]
and $y$ lies in none of the selected singletons.
Hence $\mathcal F$ does not cover $X$.
Therefore no finite subfamily of $\mathcal U$ is a cover.
:::

<1>6. The space $(X,\mathcal T)$ is not compact.
::: {.proof}
By <1>4--<1>5, it has an open cover with no finite subcover.
This proves part (3b).
:::

<1>7. Therefore part (3a) is compact and part (3b) is not compact.
::: {.proof}
Combine <1>2 and <1>6.
:::
:::

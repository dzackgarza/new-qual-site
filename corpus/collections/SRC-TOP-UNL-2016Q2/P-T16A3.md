::: {.problem}
Let $X$ be the set of real numbers, let $\mathcal T_E$ be the Euclidean topology on $X$, and let $\mathcal T_0$ be the excluded point topology (that is, $\mathcal T_0=\{U\subseteq X\mid 0\notin U\}\cup\{X\}$). For each of the following topological spaces, determine whether or not the space is compact.

(3a) The set $X$ with the topology $\mathcal T_E\cap\mathcal T_0$.

(3b) The set $X$ with the topology generated by the subbasis $\mathcal T_E\cup\mathcal T_0$.
:::

::: solution
**Goal:** Decide compactness in the two topologies.

<1>1. Topology $\mathcal T_E\cap\mathcal T_0$:
    *Proof:*
    <2>1. A set in the intersection must be Euclidean-open and either equal $X$ or avoid $0$.
    <2>2. So every set that contains $0$ is $X$.
    <2>3. Let $\{U_i\}_{i\in I}$ be any open cover of $X$.
    Since $0\in X$, some $U_{i_0}$ contains $0$, hence $U_{i_0}=X$.
    <2>4. Therefore $\{U_{i_0}\}$ is a finite subcover.

<1>2. Topology generated by $\mathcal T_E\cup\mathcal T_0$:
    *Proof:*
    <2>1. Every Euclidean-open set is open.
    <2>2. Every set not containing $0$ is open because it is subbasic in $\mathcal T_0$.
    <2>3. Thus every singleton $\{x\}$ for $x\neq0$ is open.
    <2>4. The family
    $$\mathcal U=\{(-1,1)\}\cup\{\{x\}:x\in\mathbb R\setminus\{0\}\}$$
    is an open cover.
    <2>5. Any finite subfamily of $\mathcal U$ has only finitely many singleton sets and one interval $(-1,1)$.
    <2>6. Choose $x\in\mathbb R\setminus\{0\}$ with $|x|\ge1$ and not equal to one of those finitely many points.
    Then $x$ is uncovered.
    <2>7. Hence no finite subfamily covers all of $\mathbb R\setminus\{0\}$.

<1>3. Conclusion:
    (3a) is compact, while (3b) is not compact. Q.E.D.
:::

::: {.problem}
Let M be a connected manifold of dimension n. A smooth curve in M is a smooth map $[ 0 , 1 ]  M$ A smooth loop in M is a smooth map $\gamma \colon [ 0 , 1 ] \ \to \ M$ so that $\gamma ( 0 ) = \gamma ( 1 )$ . (Of course this is equivalent to a smooth map $S ^ { 1 } \to M . )$

Show that if M is simply-connected then $H ^ { 1 } ( M ) = 0$
:::

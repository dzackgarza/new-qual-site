::: {.problem}
Let $M$ be a connected manifold of dimension $n$. A smooth curve in $M$ is a smooth map $[0, 1] \to M$. A smooth loop in $M$ is a smooth map $\gamma \colon [0, 1] \to M$ so that $\gamma(0) = \gamma(1)$. (Of course this is equivalent to a smooth map $S^{1} \to M$.)

Show that if $M$ is simply-connected then $H^{1}(M) = 0$.
:::

::: {.solution}

Let $\omega\in\Omega^1(M)$ be closed. Fix a base point $p_0\in M$.

::: pf

::: {.pf-step #s1-1}

For every $p\in M$, the integral
$$
F(p)\coloneqq\int_\gamma\omega,
$$
where $\gamma$ is any smooth path from $p_0$ to $p$, is well defined.


::: pf-proof

Because $M$ is connected and a manifold, it is path connected, so such a path exists. Suppose $\gamma_0$ and $\gamma_1$ are two smooth paths from $p_0$ to $p$. The concatenation
$$
\gamma_0*\overline{\gamma_1}
$$
is a loop based at $p_0$. Since $M$ is simply connected, this loop is homotopic through based loops to the constant loop.

The integral of a closed $1$-form is invariant under such a homotopy. Indeed, if
$$
H:[0,1]^2\to M
$$
is a smooth homotopy between two paths with fixed endpoints, then Stokes' theorem gives
$$
\int_{\partial[0,1]^2}H^*\omega
=
\int_{[0,1]^2}d(H^*\omega)
=
\int_{[0,1]^2}H^*(d\omega)
=0.
$$
The contributions from the two fixed-endpoint sides vanish, so the integrals along the two paths agree. Applying this to $\gamma_0*\overline{\gamma_1}$ and the constant loop yields
$$
\int_{\gamma_0}\omega
=
\int_{\gamma_1}\omega.
$$
Thus $F$ is independent of the chosen path.

:::

:::

::: {.pf-step #s1-2}

The function $F$ is smooth and satisfies $dF=\omega$.


::: pf-proof

Fix $p\in M$ and choose a contractible coordinate neighborhood $U$ of $p$. By the Poincaré lemma there is a smooth function $h:U\to\RR$ such that
$$
dh=\omega\restrict_U.
$$
Choose a point $q\in U$ and fix one path from $p_0$ to $q$. For any $x\in U$, compute $F(x)$ using that fixed path followed by a path in $U$ from $q$ to $x$. By step [](#s1-1){.pf-ref} the result is independent of that latter path, and because $dh=\omega\restrict_U$,
$$
F(x)-F(q)
=
\int_q^x\omega
=
h(x)-h(q).
$$
Hence on $U$,
$$
F=h+\bigl(F(q)-h(q)\bigr).
$$
Therefore $F$ is smooth on $U$ and $dF=dh=\omega$ there. Since $p$ was arbitrary, $F$ is smooth on all of $M$ and $dF=\omega$ globally.

:::

:::

::: {.pf-step #s1-3}

Every closed $1$-form on $M$ is exact, so $\boxed{H^1_{dR}(M)=0}$.


::: pf-proof

Step [](#s1-2){.pf-ref} shows that an arbitrary closed $1$-form $\omega$ can be written as $\omega=dF$. Thus the quotient of closed $1$-forms by exact $1$-forms is zero.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} is exactly the required conclusion.

:::

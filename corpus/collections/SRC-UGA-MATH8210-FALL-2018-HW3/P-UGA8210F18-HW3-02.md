::: {.problem}
(Page 38 of B&T) Show that the map $\pi _ { * }$ in the proof of the Poincarelemma is a \` chain map.
:::

::: {.solution}

Let
\[
\pi:M\times\RR\to M
\]
be projection. In Bott--Tu's compact-support Poincare lemma, the map
\[
\pi_*:\Omega_c^q(M\times\RR)\longrightarrow\Omega_c^{q-1}(M)
\]
is integration along the \(\RR\)-fiber.

::: pf

::: pf-step

Every compactly supported \(q\)-form on \(M\times\RR\) can be written uniquely as
\[
\boxed{\omega=\alpha(x,t)+\beta(x,t)\wedge dt,}
\]
where, for fixed \(t\),
\[
\alpha(\cdot,t)\in\Omega^q(M),\qquad \beta(\cdot,t)\in\Omega^{q-1}(M).
\]


::: pf-proof

In local coordinates \(x_1,\dots,x_m,t\), each monomial differential form either contains \(dt\) or does not. Collect the terms without \(dt\) into \(\alpha\), and the remaining terms into \(\beta\wedge dt\). The two types of basis monomials are disjoint, so the decomposition is unique.

:::

:::

::: {.pf-step #s1-2}

Define
\[
\boxed{\pi_*\omega\coloneqq\int_{-\infty}^{\infty}\beta(x,t)\,dt.}
\]
Then \(\pi_*\omega\in\Omega_c^{q-1}(M)\).


::: pf-proof

Integration is coefficientwise in local coordinates on \(M\). Since \(\omega\) has compact support, the projection of its support to \(M\) is compact. Outside that compact projection all coefficients of \(\beta\) vanish, so the resulting form is compactly supported.

:::

:::

::: {.pf-step #s1-3}

Write \(d_M\) for exterior differentiation in the \(M\)-variables. Then
\[
d\alpha=d_M\alpha+dt\wedge\frac{\partial\alpha}{\partial t}
=d_M\alpha+(-1)^q\frac{\partial\alpha}{\partial t}\wedge dt.
\]


::: pf-proof

On the product, \(d=d_M+dt\wedge\partial_t\). Moving \(dt\) past the \(q\)-form \(\partial_t\alpha\) contributes the sign \((-1)^q\).

:::

:::

::: {.pf-step #s1-4}

One has
\[
d(\beta\wedge dt)=d_M\beta\wedge dt.
\]


::: pf-proof

Since \(d\beta=d_M\beta+dt\wedge\partial_t\beta\),
\[
d(\beta\wedge dt)=d_M\beta\wedge dt+dt\wedge\partial_t\beta\wedge dt,
\]
and the second term vanishes because \(dt\wedge dt=0\).

:::

:::

::: pf-step

Therefore
\[
\boxed{d\omega=d_M\alpha+\left((-1)^q\frac{\partial\alpha}{\partial t}+d_M\beta\right)\wedge dt.}
\]


::: pf-proof

Combine steps [](#s1-3){.pf-ref} through [](#s1-4){.pf-ref}.

:::

:::

::: {.pf-step #s1-6}

Applying \(\pi_*\) gives
\[
\pi_*(d\omega)=(-1)^q\int_{-\infty}^{\infty}\frac{\partial\alpha}{\partial t}\,dt+\int_{-\infty}^{\infty}d_M\beta\,dt.
\]


::: pf-proof

By definition, \(\pi_*\) extracts the coefficient of \(dt\) and integrates it in the fiber variable. The horizontal term \(d_M\alpha\) contributes nothing.

:::

:::

::: {.pf-step #s1-7}

The first integral in step [](#s1-6){.pf-ref} vanishes.


::: pf-proof

For fixed \(x\), compact support implies \(\alpha(x,t)=0\) for all sufficiently large positive and negative \(t\). Hence, coefficientwise,
\[
\int_{-\infty}^{\infty}\partial_t\alpha(x,t)\,dt=\alpha(x,+\infty)-\alpha(x,-\infty)=0.
\]

:::

:::

::: {.pf-step #s1-8}

Exterior differentiation on \(M\) commutes with the fiber integral:
\[
\int_{-\infty}^{\infty}d_M\beta\,dt=d_M\int_{-\infty}^{\infty}\beta\,dt.
\]


::: pf-proof

In local coordinates, \(d_M\) differentiates smooth compactly supported coefficient functions in the \(x\)-variables, so differentiation passes through the \(t\)-integral.

:::

:::

::: {.pf-step #s1-9}

Consequently
\[
\pi_*(d\omega)=d_M\int_{-\infty}^{\infty}\beta\,dt=d(\pi_*\omega).
\]


::: pf-proof

Use step [](#s1-7){.pf-ref} in step [](#s1-6){.pf-ref}, then apply step [](#s1-8){.pf-ref} and the definition in step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-10}

Therefore
\[
\boxed{d\pi_*=\pi_*d.}
\]
Thus \(\pi_*\) is a chain map.


::: pf-proof

Step [](#s1-9){.pf-ref} holds for every compactly supported differential form \(\omega\). This is exactly the chain-map identity in the Bott--Tu grading convention.

:::

:::

::: pf-qed

Step [](#s1-10){.pf-ref} is the required conclusion.

:::

::: {.problem}
Suppose that $f\in L^p(\RR)$ for all $p\in(1,2)$ and that $\sup_{p\in(1,2)}\norm{f}_p<\infty$.
Prove that $f\in L^2(\RR)$ and that $$\lim_{p\to 2^-}\norm{f}_p=\norm{f}_2.$$
:::

::: {.solution}

::: pf

::: pf-step

Let $M = \sup_{p \in (1,2)} \norm{f}_p < \infty$.

::: pf-proof

hypothesis.

:::

:::

::: {.pf-step #s2}

$f \in L^2(\RR)$.

::: pf-proof

::: pf-step

On $\{\abs{f} > 1\}$, $\abs{f}^p \uparrow \abs{f}^2$ as $p \uparrow 2$ (monotone increasing).

::: pf-proof

for $\abs{f} > 1$, $\abs{f}^p$ increases with $p$.

:::

:::

::: {.pf-step #s2-2}

By the monotone convergence theorem, $\int_{\{\abs{f}>1\}} \abs{f}^2 = \lim_{p \to 2^-} \int_{\{\abs{f}>1\}} \abs{f}^p \le \limsup_{p \to 2^-} \norm{f}_p^p \le M^2 < \infty$.

::: pf-proof

monotone convergence and the bound $\norm{f}_p \le M$.

:::

:::

::: {.pf-step #s2-3}

On $\{\abs{f} \le 1\}$, $\abs{f}^2 \le \abs{f}^p$ for $p < 2$, so $\int_{\{\abs{f}\le 1\}} \abs{f}^2 \le \int \abs{f}^p \le M^p < \infty$.

::: pf-proof

for $\abs{f} \le 1$ and $p < 2$, $\abs{f}^2 \le \abs{f}^p$.

:::

:::

::: pf-step

Hence $\int \abs{f}^2 = \int_{\{\abs{f}>1\}} \abs{f}^2 + \int_{\{\abs{f}\le 1\}} \abs{f}^2 < \infty$, so $f \in L^2$.

::: pf-proof

Steps [](#s2-2){.pf-ref} and [](#s2-3){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s3}

$\lim_{p \to 2^-} \norm{f}_p = \norm{f}_2$.

::: pf-proof

::: {.pf-step #s3-1}

On $\{\abs{f} > 1\}$, $\abs{f}^p \uparrow \abs{f}^2$ as $p \uparrow 2$, so by monotone convergence $\int_{\{\abs{f}>1\}} \abs{f}^p \to \int_{\{\abs{f}>1\}} \abs{f}^2$.

::: pf-proof

monotone convergence theorem.

:::

:::

::: {.pf-step #s3-2}

On $\{\abs{f} \le 1\}$, $\abs{f}^p \downarrow \abs{f}^2$ as $p \uparrow 2$, so by monotone convergence $\int_{\{\abs{f}\le 1\}} \abs{f}^p \to \int_{\{\abs{f}\le 1\}} \abs{f}^2$.

::: pf-proof

monotone convergence theorem (decreasing version).

:::

:::

::: {.pf-step #s3-3}

Hence $\int \abs{f}^p \to \int \abs{f}^2$, i.e. $\norm{f}_p^p \to \norm{f}_2^2$.

::: pf-proof

Steps [](#s3-1){.pf-ref} and [](#s3-2){.pf-ref}.

:::

:::

::: pf-step

Therefore $\norm{f}_p \to \norm{f}_2$.

::: pf-proof

Step [](#s3-3){.pf-ref} and continuity of the $p$-th root.

:::

:::

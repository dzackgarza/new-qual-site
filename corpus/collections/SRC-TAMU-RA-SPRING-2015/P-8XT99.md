::: {.problem}
Suppose that $f\in L^p(\mathbb{R})$ for all $p\in(1,2)$ and that $\sup_{p\in(1,2)}\|f\|_p<\infty$.
Prove that $f\in L^2(\mathbb{R})$ and that $$\lim_{p\to 2^-}\|f\|_p=\|f\|_2.$$
:::

::: {.solution}

::: pf

::: pf-step

Let $M = \sup_{p \in (1,2)} \|f\|_p < \infty$.

::: pf-proof

hypothesis.

:::

:::

::: {.pf-step #s2}

$f \in L^2(\RR)$.

::: pf-proof

::: pf-step

On $\{|f| > 1\}$, $|f|^p \uparrow |f|^2$ as $p \uparrow 2$ (monotone increasing).

::: pf-proof

for $|f| > 1$, $|f|^p$ increases with $p$.

:::

:::

::: {.pf-step #s2-2}

By the monotone convergence theorem, $\int_{\{|f|>1\}} |f|^2 = \lim_{p \to 2^-} \int_{\{|f|>1\}} |f|^p \le \limsup_{p \to 2^-} \|f\|_p^p \le M^2 < \infty$.

::: pf-proof

monotone convergence and the bound $\|f\|_p \le M$.

:::

:::

::: {.pf-step #s2-3}

On $\{|f| \le 1\}$, $|f|^2 \le |f|^p$ for $p < 2$, so $\int_{\{|f|\le 1\}} |f|^2 \le \int |f|^p \le M^p < \infty$.

::: pf-proof

for $|f| \le 1$ and $p < 2$, $|f|^2 \le |f|^p$.

:::

:::

::: pf-step

Hence $\int |f|^2 = \int_{\{|f|>1\}} |f|^2 + \int_{\{|f|\le 1\}} |f|^2 < \infty$, so $f \in L^2$.

::: pf-proof

Steps [](#s2-2){.pf-ref} and [](#s2-3){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s3}

$\lim_{p \to 2^-} \|f\|_p = \|f\|_2$.

::: pf-proof

::: {.pf-step #s3-1}

On $\{|f| > 1\}$, $|f|^p \uparrow |f|^2$ as $p \uparrow 2$, so by monotone convergence $\int_{\{|f|>1\}} |f|^p \to \int_{\{|f|>1\}} |f|^2$.

::: pf-proof

monotone convergence theorem.

:::

:::

::: {.pf-step #s3-2}

On $\{|f| \le 1\}$, $|f|^p \downarrow |f|^2$ as $p \uparrow 2$, so by monotone convergence $\int_{\{|f|\le 1\}} |f|^p \to \int_{\{|f|\le 1\}} |f|^2$.

::: pf-proof

monotone convergence theorem (decreasing version).

:::

:::

::: {.pf-step #s3-3}

Hence $\int |f|^p \to \int |f|^2$, i.e. $\|f\|_p^p \to \|f\|_2^2$.

::: pf-proof

Steps [](#s3-1){.pf-ref} and [](#s3-2){.pf-ref}.

:::

:::

::: pf-step

Therefore $\|f\|_p \to \|f\|_2$.

::: pf-proof

Step [](#s3-3){.pf-ref} and continuity of the $p$-th root.

:::

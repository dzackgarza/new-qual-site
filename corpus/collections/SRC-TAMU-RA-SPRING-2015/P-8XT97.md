::: {.problem}
Let $f,g\in C[0,1]$ with $f(x)<g(x)$ for all $x\in[0,1]$.

(i) Prove that there is a polynomial $p(x)$ so that $$f(x)<p(x)<g(x),\qquad x\in[0,1].$$

(ii) Prove that there is an increasing sequence of polynomials $\{p_n(x)\}_{n=1}^\infty$ so that $$f(x)<p_n(x)<g(x),\qquad x\in[0,1],$$ and $p_n\to g$ uniformly on $[0,1]$.
:::


::: {.solution}
<1>1. There is a polynomial strictly between $f$ and $g$.
::: {.proof}
The continuous function $g-f$ is strictly positive on the compact interval $[0,1]$, so
\[
\delta:=\min_{x\in[0,1]}(g(x)-f(x))>0.
\]
Let
\[
m=\frac{f+g}{2}.
\]
By the Weierstrass approximation theorem, there is a polynomial $p$ such that
\[
\|p-m\|_\infty<\frac{\delta}{2}.
\]
For every $x\in[0,1]$,
\[
p(x)-f(x)
>m(x)-\frac{\delta}{2}-f(x)
=\frac{g(x)-f(x)-\delta}{2}\ge0,
\]
and the strict approximation inequality makes the first inequality strict. Similarly,
\[
g(x)-p(x)
>g(x)-m(x)-\frac{\delta}{2}
=\frac{g(x)-f(x)-\delta}{2}\ge0.
\]
Hence $f(x)<p(x)<g(x)$ for all $x$.
:::

<1>2. Construct the increasing sequence.
::: {.proof}
Set $p_0=f$, only as an auxiliary continuous function. Suppose $p_{n-1}\in C[0,1]$ has been chosen with
\[
f\le p_{n-1}<g.
\]
Define
\[
h_n(x)=\max\{p_{n-1}(x),\,g(x)-2^{-n}\}.
\]
Then $h_n$ is continuous and, pointwise,
\[
h_n(x)<g(x).
\]
Applying <1>1 to the pair $(h_n,g)$ gives a polynomial $p_n$ satisfying
\[
h_n(x)<p_n(x)<g(x)
\qquad(x\in[0,1]).
\]
Thus
\[
p_{n-1}(x)<p_n(x)<g(x),
\]
and since $h_n\ge f$, also $f(x)<p_n(x)$. This constructs a pointwise strictly increasing sequence of polynomials.
:::

<1>3. The convergence to $g$ is uniform.
::: {.proof}
By construction, $p_n>h_n\ge g-2^{-n}$, while $p_n<g$. Therefore
\[
0<g(x)-p_n(x)<2^{-n}
\qquad(x\in[0,1]).
\]
Hence
\[
\|g-p_n\|_\infty\le 2^{-n}\longrightarrow0.
\]
Thus $p_n\to g$ uniformly on $[0,1]$.
:::
:::

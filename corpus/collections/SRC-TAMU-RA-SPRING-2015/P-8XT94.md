::: {.problem}
Let $(X,\mathcal{M},\mu)$ be a measure space with $\mu(X)<\infty$.
Let $\mathcal{N}\subseteq\mathcal{M}$ be a $\sigma$-algebra.
If $f\ge 0$ is $\mathcal{M}$-measurable and $\mu$-integrable then prove that there exists an $\mathcal{N}$-measurable and $\mu$-integrable function $g\ge 0$ so that $$\int_E g\,d\mu=\int_E f\,d\mu\qquad\text{for all }E\in\mathcal{N}.$$
:::


::: {.solution}
Let $\mu_{\mathcal N}$ denote the restriction of $\mu$ to the measurable space $(X,\mathcal N)$.
Define
\[
\nu(E)=\int_E f\,d\mu,\qquad E\in\mathcal N.
\]

<1>1. $\nu$ is a finite positive measure on $(X,\mathcal N)$.
::: {.proof}
Because $f\ge0$ is measurable, the set function $E\mapsto\int_E f\,d\mu$ is countably additive on $\mathcal M$, hence also on the sub-$\sigma$-algebra $\mathcal N$. Moreover,
\[
\nu(X)=\int_X f\,d\mu<\infty
\]
since $f\in L^1(\mu)$. Thus $\nu$ is a finite positive measure.
:::

<1>2. $\nu\ll\mu_{\mathcal N}$.
::: {.proof}
If $E\in\mathcal N$ and $\mu_{\mathcal N}(E)=\mu(E)=0$, then
\[
\nu(E)=\int_E f\,d\mu=0.
\]
Therefore $\nu$ is absolutely continuous with respect to $\mu_{\mathcal N}$.
:::

<1>3. Apply the Radon--Nikodym theorem.
::: {.proof}
Since $\mu(X)<\infty$, the measure $\mu_{\mathcal N}$ is finite and hence $\sigma$-finite. By <1>1 and <1>2, the Radon--Nikodym theorem yields an $\mathcal N$-measurable function $g\ge0$ such that
\[
\nu(E)=\int_E g\,d\mu_{\mathcal N}=\int_E g\,d\mu
\qquad(E\in\mathcal N).
\]
Taking $E=X$ gives
\[
\int_X g\,d\mu=\nu(X)=\int_X f\,d\mu<\infty,
\]
so $g\in L^1(\mu)$. Finally, by the definition of $\nu$,
\[
\int_E g\,d\mu=\int_E f\,d\mu
\qquad(E\in\mathcal N),
\]
which is the required conclusion.
:::
:::

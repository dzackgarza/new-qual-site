::: {.problem}
Let $f,g\in L^1(\RR)$.
Prove that $h\in L^1(\RR)$, where $h(x)$ is defined by $$h(x)=\int_{\RR}f(y)g(x-y)\,dy$$ whenever this integral is finite.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Product measurability:

::: pf-proof

::: pf-step

The mapping $(x, y) \mapsto x - y$ from $\RR^2 \to \RR$ is continuous, so $(x, y) \mapsto g(x - y)$ is a Lebesgue measurable function on $\RR^2$.

::: pf-proof

composition of measurable functions with continuous maps.

:::

:::

::: pf-step

Since $y \mapsto f(y)$ is measurable, the product function $F(x, y) = f(y) g(x - y)$ is product measurable on $\RR \times \RR$.

::: pf-proof

product of measurable functions.

:::

:::

:::

:::

::: {.pf-step #s2}

Integrability via Tonelli’s Theorem:

::: pf-proof

::: pf-step

Consider the non-negative measurable function $\abs{F(x, y)} = \abs{f(y)} \abs{g(x - y)}$ on $\RR^2$.
Integrate with respect to $x$ for fixed $y$:
Using translation invariance of Lebesgue measure (substitute $u = x - y$, $dx = du$):
$$
\int_{\RR} \abs{g(x - y)} \, dx = \int_{\RR} \abs{g(u)} \, du = \norm{g}_{L^1}.
$$

::: pf-proof

translation invariance of Lebesgue measure on $\RR$.

:::

:::

::: pf-step

Integrate the result with respect to $y$:
$$
\int_{\RR} \left( \int_{\RR} \abs{f(y)} \abs{g(x - y)} \, dx \right) dy = \int_{\RR} \abs{f(y)} \norm{g}_{L^1} \, dy = \norm{f}_{L^1} \norm{g}_{L^1}.
$$
Since $f, g \in L^1(\RR)$, $\norm{f}_{L^1} \norm{g}_{L^1} < \infty$.

::: pf-proof

$f \in L^1(\RR)$.

:::

:::

::: pf-step

By Tonelli’s Theorem, $F(x, y) = f(y) g(x - y) \in L^1(\RR \times \RR)$.

::: pf-proof

Tonelli's Theorem for non-negative measurable functions.

:::

:::

:::

:::

::: {.pf-step #s3}

Deduce that $h \in L^1(\RR)$ via Fubini’s Theorem:

::: pf-proof

::: pf-step

By Fubini’s Theorem, the slice $y \mapsto f(y) g(x - y)$ is integrable with respect to $y$ for almost every $x \in \RR$.
Thus $h(x) = \int_{\RR} f(y) g(x - y) \, dy$ is finite for almost every $x \in \RR$ and defines a measurable function $h: \RR \to \CC$.

::: pf-proof

Fubini's Theorem for $L^1$ functions on product spaces.

:::

:::

::: pf-step

Applying the integral Minkowski inequality / Tonelli bound:
$$
\norm{h}_{L^1} = \int_{\RR} \abs{h(x)} \, dx = \int_{\RR} \abs{ \int_{\RR} f(y) g(x - y) \, dy } dx
\le \int_{\RR} \int_{\RR} \abs{f(y)} \abs{g(x - y)} \, dx \, dy = \norm{f}_{L^1} \norm{g}_{L^1} < \infty.
$$

::: pf-proof

triangle inequality for integrals and step [](#s2){.pf-ref}.

:::

:::

:::

:::

::: pf-step

Conclusion:
$h = f * g \in L^1(\RR)$, with $\norm{h}_{L^1} \le \norm{f}_{L^1} \norm{g}_{L^1}$. Q.E.D.

::: pf-proof

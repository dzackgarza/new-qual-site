::: {.problem}
Let $f,g\in L^1(\mathbb{R})$.
Prove that $h\in L^1(\mathbb{R})$, where $h(x)$ is defined by $$h(x)=\int_{\mathbb{R}}f(y)g(x-y)\,dy$$ whenever this integral is finite.
:::

::: {.solution}
<1>1. Product measurability:
<2>1. The mapping $(x, y) \mapsto x - y$ from $\mathbb{R}^2 \to \mathbb{R}$ is continuous, so $(x, y) \mapsto g(x - y)$ is a Lebesgue measurable function on $\mathbb{R}^2$.
::: {.proof}
composition of measurable functions with continuous maps.
:::
<2>2. Since $y \mapsto f(y)$ is measurable, the product function $F(x, y) = f(y) g(x - y)$ is product measurable on $\mathbb{R} \times \mathbb{R}$.
::: {.proof}
product of measurable functions.
:::

<1>2. Integrability via Tonelli’s Theorem:
<2>1. Consider the non-negative measurable function $|F(x, y)| = |f(y)| |g(x - y)|$ on $\mathbb{R}^2$.
Integrate with respect to $x$ for fixed $y$:
Using translation invariance of Lebesgue measure (substitute $u = x - y$, $dx = du$):
\[
\int_{\mathbb{R}} |g(x - y)| \, dx = \int_{\mathbb{R}} |g(u)| \, du = \|g\|_{L^1}.
\]
::: {.proof}
translation invariance of Lebesgue measure on $\mathbb{R}$.
:::
<2>2. Integrate the result with respect to $y$:
\[
\int_{\mathbb{R}} \left( \int_{\mathbb{R}} |f(y)| |g(x - y)| \, dx \right) dy = \int_{\mathbb{R}} |f(y)| \|g\|_{L^1} \, dy = \|f\|_{L^1} \|g\|_{L^1}.
\]
Since $f, g \in L^1(\mathbb{R})$, $\|f\|_{L^1} \|g\|_{L^1} < \infty$.
::: {.proof}
$f \in L^1(\mathbb{R})$.
:::
<2>3. By Tonelli’s Theorem, $F(x, y) = f(y) g(x - y) \in L^1(\mathbb{R} \times \mathbb{R})$.
::: {.proof}
Tonelli's Theorem for non-negative measurable functions.
:::

<1>3. Deduce that $h \in L^1(\mathbb{R})$ via Fubini’s Theorem:
<2>1. By Fubini’s Theorem, the slice $y \mapsto f(y) g(x - y)$ is integrable with respect to $y$ for almost every $x \in \mathbb{R}$.
Thus $h(x) = \int_{\mathbb{R}} f(y) g(x - y) \, dy$ is finite for almost every $x \in \mathbb{R}$ and defines a measurable function $h: \mathbb{R} \to \mathbb{C}$.
::: {.proof}
Fubini's Theorem for $L^1$ functions on product spaces.
:::
<2>2. Applying the integral Minkowski inequality / Tonelli bound:
\[
\|h\|_{L^1} = \int_{\mathbb{R}} |h(x)| \, dx = \int_{\mathbb{R}} \left| \int_{\mathbb{R}} f(y) g(x - y) \, dy \right| dx
\le \int_{\mathbb{R}} \int_{\mathbb{R}} |f(y)| |g(x - y)| \, dx \, dy = \|f\|_{L^1} \|g\|_{L^1} < \infty.
\]
::: {.proof}
triangle inequality for integrals and <1>2.
:::

<1>4. Conclusion:
$h = f * g \in L^1(\mathbb{R})$, with $\|h\|_{L^1} \le \|f\|_{L^1} \|g\|_{L^1}$. Q.E.D.
::: {.proof}
<1>1 through <1>3.
:::

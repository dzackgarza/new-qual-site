::: {.problem}
(i) State the closed graph theorem.

(ii) If $H$ is a Hilbert space and $T:H\to H$ is a linear operator satisfying $$\langle Tx,y\rangle=\langle x,Ty\rangle,\qquad x,y\in H,$$ then prove that $T$ is bounded.
:::


::: {.solution}
<1>1. Closed Graph Theorem.
::: {.proof}
If $X$ and $Y$ are Banach spaces and $S:X\to Y$ is a linear operator whose graph
\[
\Gamma(S)=\{(x,Sx):x\in X\}
\]
is closed in $X\times Y$, then $S$ is bounded (equivalently, continuous).
:::

<1>2. The graph of $T$ is closed.
::: {.proof}
Suppose
\[
x_n\to x\quad\text{in }H,\qquad Tx_n\to y\quad\text{in }H.
\]
We must show $y=Tx$. Fix arbitrary $z\in H$. By continuity of the inner product in each variable and the assumed symmetry,
\[
\langle y,z\rangle
=\lim_{n\to\infty}\langle Tx_n,z\rangle
=\lim_{n\to\infty}\langle x_n,Tz\rangle
=\langle x,Tz\rangle
=\langle Tx,z\rangle.
\]
Hence
\[
\langle y-Tx,z\rangle=0
\]
for every $z\in H$. Taking $z=y-Tx$ gives
\[
\|y-Tx\|^2=0,
\]
so $y=Tx$. Therefore $\Gamma(T)$ is closed.
:::

<1>3. $T$ is bounded.
::: {.proof}
A Hilbert space is Banach. Thus $T:H\to H$ is a linear operator between Banach spaces, defined on all of $H$, and its graph is closed by <1>2. The Closed Graph Theorem therefore implies that $T$ is bounded.
:::
:::

::: problem
(a) Let $E\subseteq[0,1)$ be a Lebesgue measurable set.
Prove that
\[
\int_E\sin(2\pi nx)\,dx\to 0\quad\text{as }n\to\infty
\]
by exploiting the fact that $\{e^{2\pi inx}\}_{n\in\mathbb{Z}}$ is an orthonormal set in $L^2[0,1)$.

(b) Show that the above also holds for any measurable set $E\subseteq\mathbb{R}$ of finite measure.
:::

::: solution
<1>1. Prove part (a) from orthogonality.
::: proof
Let
\[
e_n(x):=e^{2\pi i n x},
\qquad n\in\mathbb Z.
\]
The family $(e_n)_{n\in\mathbb Z}$ is orthonormal in $L^2([0,1))$. Since $E\subseteq[0,1)$ is measurable,
\[
\mathbf1_E\in L^2([0,1)).
\]
Its Fourier coefficients are
\[
c_n:=\langle \mathbf1_E,e_n\rangle
=\int_E e^{-2\pi i n x}\,dx.
\]
By Bessel's inequality,
\[
\sum_{n\in\mathbb Z}|c_n|^2
\le \|\mathbf1_E\|_2^2
=m(E)<\infty.
\]
Hence
\[
c_n\longrightarrow0
\qquad\text{as }|n|\to\infty.
\]
Taking imaginary parts gives
\[
\int_E\sin(2\pi n x)\,dx\longrightarrow0.
\]
:::

<1>2. Reduce a bounded subset of $\mathbb R$ to finitely many unit intervals.
::: proof
Suppose first that $E$ is contained in $[-N,N)$ for some integer $N$. Write
\[
E_k:=E\cap[k,k+1),
\qquad -N\le k<N.
\]
After the change of variables $x=t+k$,
\[
\int_{E_k}\sin(2\pi n x)\,dx
=\int_{E_k-k}\sin(2\pi n(t+k))\,dt.
\]
Since $n,k\in\mathbb Z$,
\[
\sin(2\pi n(t+k))=\sin(2\pi nt).
\]
The translated set $E_k-k$ lies in $[0,1)$, so Step 1 shows that every summand tends to $0$. There are only finitely many $k$, hence
\[
\int_E\sin(2\pi nx)\,dx\longrightarrow0
\]
for every bounded measurable $E$.
:::

<1>3. Remove the boundedness assumption.
::: proof
Let $E\subseteq\mathbb R$ be measurable with $m(E)<\infty$, and let $\varepsilon>0$. Choose an integer $N$ so large that
\[
m(E\setminus[-N,N))<\varepsilon.
\]
Then
\[
\left|\int_{E\setminus[-N,N)}\sin(2\pi nx)\,dx\right|
\le m(E\setminus[-N,N))<\varepsilon
\]
for every $n$. By Step 2,
\[
\int_{E\cap[-N,N)}\sin(2\pi nx)\,dx\longrightarrow0.
\]
Therefore
\[
\limsup_{n\to\infty}
\left|\int_E\sin(2\pi nx)\,dx\right|
\le\varepsilon.
\]
Since $\varepsilon$ is arbitrary,
\[
\boxed{\int_E\sin(2\pi nx)\,dx\to0.}
\]
:::
:::

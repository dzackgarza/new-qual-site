::: problem
For $n\in\mathbb{N}$, let $u_n(x)=\dfrac{\ln(1+x^n)}{n}$.
For which $x\in\mathbb{R}$ does $f(x)=\sum_{n=1}^\infty u_n(x)$ converge?
For which $x\in\mathbb{R}$ is $f$ differentiable?
:::

::: solution
<1>1. Determine where the terms are real-valued.
::: proof
For $x\le-1$, some odd power satisfies $x^n\le-1$, so
\[
1+x^n\le0
\]
and $\ln(1+x^n)$ is not defined as a real number. Thus the real-valued series can only be considered for $x>-1$.
:::

<1>2. Prove convergence for $|x|<1$.
::: proof
Fix $x$ with $|x|<1$. Choose $N$ so large that $|x|^n\le1/2$ for $n\ge N$. For $|t|\le1/2$,
\[
|\ln(1+t)|\le 2|t|.
\]
Hence, for $n\ge N$,
\[
|u_n(x)|
=\frac{|\ln(1+x^n)|}{n}
\le \frac{2|x|^n}{n}
\le 2|x|^n.
\]
The geometric series converges, so
\[
\sum_{n=1}^\infty u_n(x)
\]
converges absolutely for every $|x|<1$.
:::

<1>3. Show divergence for $x\ge1$.
::: proof
At $x=1$,
\[
u_n(1)=\frac{\ln2}{n},
\]
so the series diverges.

If $x>1$, then
\[
u_n(x)
=\frac{\ln(1+x^n)}n
\ge \frac{\ln(x^n)}n
=\ln x>0.
\]
Thus the terms do not even tend to $0$, so the series diverges.

Therefore the convergence set is exactly
\[
\boxed{(-1,1).}
\]
:::

<1>4. Prove differentiability throughout the convergence interval.
::: proof
For $x\in(-1,1)$,
\[
u_n'(x)
=\frac{x^{n-1}}{1+x^n}.
\]
Fix $0<r<1$. For $|x|\le r$,
\[
|1+x^n|\ge1-|x|^n\ge1-r,
\]
so
\[
|u_n'(x)|
\le \frac{r^{n-1}}{1-r}.
\]
The majorant series
\[
\sum_{n=1}^\infty\frac{r^{n-1}}{1-r}
\]
converges. Hence $\sum u_n'$ converges uniformly on $[-r,r]$. Since $\sum u_n(0)=0$ converges, the standard term-by-term differentiation theorem yields
\[
f'(x)=\sum_{n=1}^\infty\frac{x^{n-1}}{1+x^n}
\]
on $[-r,r]$.

Every $x\in(-1,1)$ lies in such an interval, so
\[
\boxed{f\text{ is differentiable at every }x\in(-1,1).}
\]
:::
:::

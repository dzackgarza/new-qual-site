::: problem
(a) Provide an example of a function $f:\mathbb{R}^2\to\mathbb{R}$ which is continuous when restricted to any line through the origin, but is not continuous at the origin.
(Give complete explanations of why your example has the desired property.)

(b) Provide an example of a function $f:\mathbb{R}^2\to\mathbb{R}$ which is everywhere differentiable when restricted to any line through the origin but is not differentiable at the origin.
(Again, be sure to give complete justification that your example works.)
:::

::: {.solution}
**(a).**

<1>1. Define $f(x, y) = \frac{x^2 y}{x^4 + y^2}$ for $(x, y) \neq (0,0)$, and $f(0,0) = 0$.
::: {.proof}
candidate example.
:::

<1>2. On any line through the origin, $f$ is continuous.
::: {.proof}
a line through the origin is parametrized by $(x, y) = t(a, b)$; then $f(ta, tb) = \frac{t^3 a^2 b}{t^4 a^4 + t^2 b^2} = \frac{t a^2 b}{t^2 a^4 + b^2}$, which is continuous in $t$ (and tends to $0 = f(0,0)$ as $t \to 0$ when $b \neq 0$; when $b = 0$, $f(ta, 0) = 0$ identically).
:::

<1>3. $f$ is not continuous at the origin.
::: {.proof}
along the parabola $y = x^2$, $f(x, x^2) = \frac{x^2 \cdot x^2}{x^4 + x^4} = \frac{x^4}{2x^4} = \frac{1}{2}$, which does not tend to $0 = f(0,0)$ as $x \to 0$.
:::

<1>4. Hence $f$ is continuous on every line through the origin but not continuous at the origin.
::: {.proof}
<1>2 and <1>3.
:::

**(b).**

<1>1. Define $f(x, y) = \frac{x^3}{x^2 + y^2}$ for $(x, y) \neq (0,0)$, and $f(0,0) = 0$.
::: {.proof}
candidate example.
:::

<1>2. On any line through the origin, $f$ is differentiable (as a function of one variable).
::: {.proof}
on the line $(x, y) = t(a, b)$, $f(ta, tb) = \frac{t^3 a^3}{t^2(a^2 + b^2)} = t \cdot \frac{a^3}{a^2 + b^2}$ (for $(a,b) \neq (0,0)$), which is a linear function of $t$, hence differentiable.
:::

<1>3. $f$ is not differentiable at the origin.
::: {.proof}
the directional derivative in direction $(a, b)$ is $\frac{a^3}{a^2 + b^2}$, which is not a linear function of $(a, b)$ (it is not of the form $\alpha a + \beta b$); a differentiable function has directional derivatives that are linear in the direction.
:::

<1>4. Hence $f$ is differentiable on every line through the origin but not differentiable at the origin.
::: {.proof}
<1>2 and <1>3.
:::

<1>5. Q.E.D.
::: {.proof}
<1>4 (a) and <1>4 (b).
:::
:::

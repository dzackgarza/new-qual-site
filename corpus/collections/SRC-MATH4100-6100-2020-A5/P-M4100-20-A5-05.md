::: {.problem}
A set $A\subseteq\mathbb R$ is called nowhere dense here if it contains no nonempty open interval.

(a) Prove that $E$ is nowhere dense in $\mathbb R$ if and only if $E^c$ is dense in $\mathbb R$.

(b) Decide whether each set below is dense, nowhere dense, or neither:
\[
\mathbb Q\cap[0,1],
\qquad
\left\{\frac1n:n\in\mathbb N\right\},
\]
\[
\mathbb R\setminus\mathbb Q,
\qquad
\text{the middle-thirds Cantor set}.
\]
:::

::: {.solution}
<1>1. If $E$ contains a nonempty open interval, then $E^c$ is not dense in
$\RR$.

::: {.proof}
Suppose
$$
(a,b)\subseteq E
$$
with $a<b$. Then
$$
(a,b)\cap E^c=\varnothing.
$$
A dense subset of $\RR$ must meet every nonempty open interval, so $E^c$ is
not dense.
:::

<1>2. If $E^c$ is not dense in $\RR$, then $E$ contains a nonempty open
interval.

::: {.proof}
If $E^c$ is not dense, there exists a nonempty open interval $(a,b)$ such that
$$
(a,b)\cap E^c=\varnothing.
$$
Hence
$$
(a,b)\subseteq E.
$$
:::

<1>3. Therefore
$$
\boxed{
E\text{ is nowhere dense in the sense of the problem}
\iff
E^c\text{ is dense in }\RR.
}
$$

::: {.proof}
By definition in the problem, $E$ is nowhere dense exactly when it contains no
nonempty open interval. Steps <1>1 and <1>2 show that this is equivalent to
density of $E^c$.
:::

<1>4. Part (a) follows.

::: {.proof}
This is step <1>3.
:::

<1>5. The set
$$
\QQ\cap[0,1]
$$
is nowhere dense in the sense of the problem, but it is not dense in $\RR$.

::: {.proof}
It is not dense because, for example,
$$
(2,3)\cap(\QQ\cap[0,1])=\varnothing.
$$

It contains no nonempty open interval: every nonempty open interval in
$\RR$ contains an irrational number, while every point of
$\QQ\cap[0,1]$ is rational. Hence it is nowhere dense under the given
definition.
:::

<1>6. The set
$$
\left\{\frac1n:n\in\NN\right\}
$$
is nowhere dense in the sense of the problem, but it is not dense in $\RR$.

::: {.proof}
It is not dense because
$$
(2,3)
$$
contains no point of the set.

It contains no nonempty open interval because it is countable, while every
nonempty open interval in $\RR$ is uncountable. Hence it is nowhere dense
under the stated definition.
:::

<1>7. The set
$$
\RR\setminus\QQ
$$
is dense in $\RR$.

::: {.proof}
The irrational numbers are dense in $\RR$: every nonempty open interval
contains an irrational number.
:::

<1>8. The set
$$
\RR\setminus\QQ
$$
is also nowhere dense in the sense of the problem.

::: {.proof}
Every nonempty open interval contains a rational number. Therefore no nonempty
open interval can be contained entirely in $\RR\setminus\QQ$.
:::

<1>9. Let $C$ be the middle-thirds Cantor set. Then $C$ is not dense in
$\RR$.

::: {.proof}
The first deleted middle third is
$$
\left(\frac13,\frac23\right),
$$
and it is disjoint from $C$. Hence $C$ fails to meet a nonempty open interval
and is not dense.
:::

<1>10. The Cantor set $C$ contains no nonempty open interval.

::: {.proof}
Let $C_n$ be the $n$th stage in the Cantor construction. Then $C_n$ is a
finite union of pairwise disjoint closed intervals, each of length
$$
3^{-n},
$$
and
$$
C\subseteq C_n
$$
for every $n$.

Suppose a nonempty open interval $I$ were contained in $C$. Then
$$
I\subseteq C_n
$$
for every $n$. Since $I$ is connected and the components of $C_n$ are
pairwise disjoint intervals, $I$ must lie in a single component of $C_n$.
Therefore
$$
\operatorname{length}(I)\leq3^{-n}
$$
for every $n$, impossible because $3^{-n}\to0$ while
$\operatorname{length}(I)>0$.
:::

<1>11. The Cantor set is nowhere dense in the sense of the problem.

::: {.proof}
This is exactly step <1>10.
:::

<1>12. The classifications in part (b) are
$$
\boxed{
\begin{array}{c|c}
\text{set}&\text{classification}\\
\hline
\QQ\cap[0,1]&\text{nowhere dense, not dense}\\
\{1/n:n\in\NN\}&\text{nowhere dense, not dense}\\
\RR\setminus\QQ&\text{dense and nowhere dense}\\
\text{Cantor set}&\text{nowhere dense, not dense}
\end{array}
}
$$

::: {.proof}
Combine steps <1>5--<1>11. The overlap in the third row is possible because
the problem's definition of “nowhere dense” means only “contains no nonempty
open interval.”
:::

<1>13. Q.E.D.

::: {.proof}
Step <1>4 proves part (a), and step <1>12 proves part (b).
:::

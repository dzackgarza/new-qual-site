::: {.problem}
A set $A\subseteq\mathbb R$ is called nowhere dense here if it contains no nonempty open interval.

(a) Prove that $E$ is nowhere dense in $\mathbb R$ if and only if $E^c$ is dense in $\mathbb R$.

(b) Decide whether each set below is dense, nowhere dense, or neither:
\[
\mathbb Q\cap[0,1],
\qquad
\left\{\frac1n:n\in\mathbb N\right\},
\]
\[
\mathbb R\setminus\mathbb Q,
\qquad
\text{the middle-thirds Cantor set}.
\]
:::

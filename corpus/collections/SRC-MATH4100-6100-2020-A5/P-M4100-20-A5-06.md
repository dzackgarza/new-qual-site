::: {.problem}
A subset of $\RR$ is called $F_\sigma$ if it is a countable union of closed sets and $G_\delta$ if it is a countable intersection of open sets.

(a) Prove that $A$ is $G_\delta$ if and only if $A^c$ is $F_\sigma$.

(b) Show that a closed interval $[a,b]$ is $G_\delta$; that $[a,b)$ is both $G_\delta$ and $F_\sigma$; and that $\QQ$ is $F_\sigma$ while $\RR\setminus\QQ$ is $G_\delta$.

(c) Show that every closed set is $G_\delta$ and every open set is $F_\sigma$. Give an example of an $F_\sigma$ set that is not $G_\delta$, and an example of a set that is neither $F_\sigma$ nor $G_\delta$.

Hint for the first example: use that $\RR$ is not a countable union of nowhere-dense sets.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

If
$$
A=\bigcap_{n=1}^{\infty}U_n
$$
with each $U_n$ open, then
$$
A^c=\bigcup_{n=1}^{\infty}U_n^c
$$
is $F_\sigma$.


::: pf-proof

By De Morgan's law,
$$
\left(\bigcap_{n=1}^{\infty}U_n\right)^c
=
\bigcup_{n=1}^{\infty}U_n^c.
$$
Each $U_n^c$ is closed, so the right-hand side is a countable union of closed
sets.

:::

:::

::: {.pf-step #s1-2}

If
$$
A^c=\bigcup_{n=1}^{\infty}F_n
$$
with each $F_n$ closed, then
$$
A=\bigcap_{n=1}^{\infty}F_n^c
$$
is $G_\delta$.


::: pf-proof

Again by De Morgan,
$$
A
=
(A^c)^c
=
\left(\bigcup_{n=1}^{\infty}F_n\right)^c
=
\bigcap_{n=1}^{\infty}F_n^c.
$$
Each $F_n^c$ is open.

:::

:::

::: {.pf-step #s1-3}

Therefore
$$
\boxed{
A\text{ is }G_\delta
\iff
A^c\text{ is }F_\sigma.
}
$$


::: pf-proof

Steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref} prove the two implications.

:::

:::

::: {.pf-step #s1-4}

Part (a) follows.


::: pf-proof

This is step [](#s1-3){.pf-ref}.

:::

:::

::: {.pf-step #s1-5}

Every closed interval $[a,b]$ is $G_\delta$.


::: pf-proof

One has
$$
[a,b]
=
\bigcap_{n=1}^{\infty}
\left(a-\frac1n,b+\frac1n\right).
$$
Each set on the right is open.

Indeed, every point of $[a,b]$ lies in every displayed interval. Conversely,
if $x<a$, choose $n$ with $1/n<a-x$; then
$x\notin(a-1/n,b+1/n)$. The case $x>b$ is analogous.

:::

:::

::: {.pf-step #s1-6}

The half-open interval $[a,b)$ is $G_\delta$.


::: pf-proof

One has
$$
[a,b)
=
\bigcap_{n=1}^{\infty}
\left(a-\frac1n,b\right).
$$
Each set is open. The same endpoint argument as in step [](#s1-5){.pf-ref} shows equality.

:::

:::

::: {.pf-step #s1-7}

The half-open interval $[a,b)$ is $F_\sigma$.


::: pf-proof

Choose $N$ so large that
$$
\frac1N<b-a.
$$
Then
$$
[a,b)
=
\bigcup_{n=N}^{\infty}
\left[a,b-\frac1n\right].
$$
Every set on the right is closed. If $x<b$, choose $n$ sufficiently large
that
$$
\frac1n<b-x;
$$
then $x\leq b-1/n$, so every $x\in[a,b)$ belongs to the union.

:::

:::

::: {.pf-step #s1-8}

The rational numbers $\QQ$ form an $F_\sigma$ set.


::: pf-proof

Enumerate
$$
\QQ=\{q_1,q_2,q_3,\ldots\}.
$$
Then
$$
\QQ
=
\bigcup_{n=1}^{\infty}\{q_n\}.
$$
Each singleton is closed.

:::

:::

::: {.pf-step #s1-9}

The irrational numbers $\RR\setminus\QQ$ form a $G_\delta$ set.


::: pf-proof

This follows from steps [](#s1-3){.pf-ref} and [](#s1-8){.pf-ref} by taking complements.

:::

:::

::: {.pf-step #s1-10}

Part (b) follows.


::: pf-proof

Steps [](#s1-5){.pf-ref} through [](#s1-9){.pf-ref} establish all four requested assertions.

:::

:::

::: {.pf-step #s1-11}

Every closed subset $F\subseteq\RR$ is $G_\delta$.


::: pf-proof

For $n\geq1$, define
$$
U_n
=
\bigcup_{y\in F}
\left(y-\frac1n,y+\frac1n\right).
$$
Each $U_n$ is open, and clearly
$$
F\subseteq\bigcap_{n=1}^{\infty}U_n.
$$

Now let $x\notin F$. Since $F$ is closed, $F^c$ is open, so there exists
$\varepsilon>0$ such that
$$
(x-\varepsilon,x+\varepsilon)\cap F=\varnothing.
$$
Choose $n$ with $1/n<\varepsilon$. Then $x\notin U_n$. Therefore
$$
F
=
\bigcap_{n=1}^{\infty}U_n.
$$

:::

:::

::: {.pf-step #s1-12}

Every open subset of $\RR$ is $F_\sigma$.


::: pf-proof

Let $U$ be open. Then $U^c$ is closed, hence $G_\delta$ by step [](#s1-11){.pf-ref}.
Part (a) then implies that
$$
U=(U^c)^c
$$
is $F_\sigma$.

:::

:::

::: {.pf-step #s1-13}

The set $\QQ$ is not $G_\delta$.


::: pf-proof

Suppose
$$
\QQ
=
\bigcap_{n=1}^{\infty}U_n
$$
with every $U_n$ open. Since $\QQ$ is dense and
$$
\QQ\subseteq U_n,
$$
each $U_n$ is dense.

Set
$$
F_n=\RR\setminus U_n.
$$
Then each $F_n$ is closed and has empty interior, hence is nowhere dense in
the standard Baire-category sense. Also,
$$
\RR\setminus\QQ
=
\bigcup_{n=1}^{\infty}F_n.
$$

But
$$
\QQ
=
\bigcup_{q\in\QQ}\{q\},
$$
and every singleton is nowhere dense. Thus $\RR$ would be a countable union
of nowhere-dense sets:
$$
\RR
=
\QQ\cup(\RR\setminus\QQ).
$$
This contradicts the Baire category theorem for $\RR$.

:::

:::

::: {.pf-step #s1-14}

Hence $\QQ$ is an $F_\sigma$ set that is not $G_\delta$.


::: pf-proof

Step [](#s1-8){.pf-ref} gives the $F_\sigma$ property, and step [](#s1-13){.pf-ref} excludes the
$G_\delta$ property.

:::

:::

::: {.pf-step #s1-15}

There are at most continuum-many $F_\sigma$ subsets of $\RR$ and at
most continuum-many $G_\delta$ subsets of $\RR$.


::: pf-proof

Let
$$
\mathfrak c=|\RR|=2^{\aleph_0}.
$$
Every open subset of $\RR$ is determined by which rational-endpoint open
intervals it contains in a countable basis. Hence there are at most
$$
2^{\aleph_0}=\mathfrak c
$$
open subsets of $\RR$, and therefore at most $\mathfrak c$ closed subsets.

An $F_\sigma$ set is determined by a sequence of closed sets. The number of
such sequences is at most
$$
\mathfrak c^{\aleph_0}
=(2^{\aleph_0})^{\aleph_0}
=2^{\aleph_0}
=\mathfrak c.
$$
The same argument applies to countable sequences of open sets and therefore to
$G_\delta$ sets.

:::

:::

::: {.pf-step #s1-16}

There exists a subset of $\RR$ that is neither $F_\sigma$ nor
$G_\delta$.


::: pf-proof

By Cantor's theorem,
$$
|\mathcal P(\RR)|
=
2^{\mathfrak c}
>
\mathfrak c.
$$
By step [](#s1-15){.pf-ref}, the union of the families of all $F_\sigma$ sets and all
$G_\delta$ sets has cardinality at most $\mathfrak c$. Hence some subset
$$
E\subseteq\RR
$$
belongs to neither family. Choosing such an $E$ gives the required example.

:::

:::

::: {.pf-step #s1-17}

Part (c) follows.


::: pf-proof

Steps [](#s1-11){.pf-ref} and [](#s1-12){.pf-ref} prove the general closed/open assertions, step [](#s1-14){.pf-ref}
gives an $F_\sigma$ set that is not $G_\delta$, and step [](#s1-16){.pf-ref} gives a set
that is neither.

:::

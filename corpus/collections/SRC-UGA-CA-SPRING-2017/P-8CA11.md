::: {.problem}
Let $U\subset\CC$ be the punctured unit disk $0<\abs{z}<1$, and let $V$ be the open annulus $\tfrac12<\abs{z}<1$.

(i) Prove that there is a smooth bijection $f:U\to V$ with a smooth inverse.
(One way to do this is to write one down.)

(ii) Prove however that no such function $f$ is conformal.
:::

::: {.solution}
Part (i) is the radial stretch $re^{i\theta}\mapsto\frac{1+r}{2}e^{i\theta}$, which is smooth with smooth inverse. For (ii) the point is that the puncture at $0$ is removable, since $f$ is bounded; the resulting $\widetilde f$ is injective on the whole disc and maps it onto the annulus, which would make the annulus simply connected. The argument is this card's own: the checkout retains no solution set for this exam.

::: pf

::: {.pf-step #parti}
(i) $F(re^{i\theta})=\frac{1+r}{2}e^{i\theta}$ is a smooth bijection $U\to V$ with smooth inverse.

::: pf-proof
For $0<r<1$ the modulus $\frac{1+r}{2}$ lies in $(\frac12,1)$, and $(r,\theta)\mapsto(\frac{1+r}{2},\theta)$ is a bijection of $(0,1)\times\RR/2\pi\ZZ$ onto $(\frac12,1)\times\RR/2\pi\ZZ$ with inverse $\rho\mapsto2\rho-1$. In polar coordinates the map is thus a bijection $U\to V$; in Cartesian coordinates $F(z)=\frac{1+\abs z}{2}\frac{z}{\abs z}$, which is smooth on $U$ because $\abs z\ne0$ there and $\abs\cdot$ is smooth away from the origin, and $F^{-1}(w)=\frac{2\abs w-1}{\abs w}w$ is smooth on $V$ for the same reason. Hence $F$ is a diffeomorphism.
:::

:::


::: {.pf-step #extend}
For (ii), if $f\colon U\to V$ is conformal then $f$ extends to a holomorphic $\widetilde f\colon\DD\to\CC$ with $\abs{\widetilde f}\le1$ on $\DD$ and $\abs{\widetilde f(0)}\ge\frac12$.

::: pf-proof
A conformal map $f\colon U\to V$ is holomorphic, injective, and has holomorphic inverse; in particular $\abs{f(z)}<1$ on $U$, so $f$ is bounded near $0$ and the singularity at $0$ is removable (Riemann's removable-singularity theorem). The extension $\widetilde f$ is holomorphic on $\DD$ and agrees with $f$ on $U$. Since $\abs f<1$ on $U$, continuity of $\widetilde f$ gives $\abs{\widetilde f}\le1$ on $\DD$, so $\abs{\widetilde f(0)}\le1$; and since $\abs f>\frac12$ on $U$, the same continuity gives $\abs{\widetilde f(0)}\ge\frac12$.
:::

:::


::: {.pf-step #image}
$\widetilde f(\DD)=V\cup\{\widetilde f(0)\}$ and $\widetilde f$ is nonconstant.

::: pf-proof
$\widetilde f$ agrees with $f$ on $U=\DD\setminus\{0\}$ and $f$ is onto $V$, so $\widetilde f(\DD)=V\cup\{\widetilde f(0)\}$. $\widetilde f$ is nonconstant because $f$ is injective on the nonempty open set $U$ and $V$ is not a single point, so $f$ is not constant.
:::

:::


::: {.pf-step #critical}
$\widetilde f(0)\in V$.

::: pf-proof
$\widetilde f$ is nonconstant and holomorphic on the disc, so by the open mapping theorem $\widetilde f(\DD)=V\cup\{\widetilde f(0)\}$ is open. If $\abs{\widetilde f(0)}=\frac12$ or $\abs{\widetilde f(0)}=1$, every disc about $\widetilde f(0)$ contains points of modulus below $\frac12$ or above $1$, which lie neither in $V$ nor equal $\widetilde f(0)$; so the set is not open. The same holds if $\abs{\widetilde f(0)}<\frac12$. Hence $\frac12<\abs{\widetilde f(0)}<1$, that is, $\widetilde f(0)\in V$.
:::

:::


::: {.pf-step #injective}
$\widetilde f$ is injective on $\DD$.

::: pf-proof
It is injective on $U$ because $f$ is. Suppose $\widetilde f(0)=\widetilde f(z_0)$ with $z_0\in U$. Near $0$ write $\widetilde f(z)-\widetilde f(0)=z^mh(z)$ with $h$ holomorphic, $h(0)\ne0$ and $m\ge1$. If $m=1$ then $h(0)\ne0$ makes $\widetilde f$ injective on a neighbourhood of $0$, so $\widetilde f$ is injective at $0$ and $z_0=0$, contrary to $z_0\in U$. If $m\ge2$, then on a small circle $\abs z=\rho$ the function $\widetilde f-\widetilde f(0)$ has the same number of zeros inside (namely $m\ge2$) as $\widetilde f(z)-\widetilde f(0)=w$ has for every $w$ near $0$ with $\abs w$ small; so some value near $\widetilde f(0)$ is taken at two distinct points of the punctured disc $U$, contradicting injectivity of $f$. Hence no such $z_0$ exists.
:::

:::


::: {.pf-step #contradiction}
No conformal $f\colon U\to V$ exists.

::: pf-proof
By steps [](#injective){.pf-ref} and [](#image){.pf-ref}, $\widetilde f$ is a biholomorphism of $\DD$ onto $V$. A homeomorphism carries simply connected spaces to simply connected spaces, and $\DD$ is simply connected; so $V$ would be simply connected. But it is not: the circle $\abs w=\frac34$ lies in $V$, and $\oint_{\abs w=3/4}\frac{\dw}{w}=2\pi i\ne0$, while Cauchy's theorem for a null-homotopic closed curve in the domain $\CC\setminus\{0\}\supset V$ of $1/w$ would give $0$. So $V$ is not simply connected, and no conformal $f$ exists.
:::

:::


::: {.pf-step #conclusion}
$U$ and $V$ are diffeomorphic but not conformally equivalent.

::: pf-proof
Part (i) is step [](#parti){.pf-ref} and part (ii) is step [](#contradiction){.pf-ref}; together they answer both parts of the problem.
:::

::: problem
Let $U\subset\mathbb{C}$ be the punctured unit disk $0<|z|<1$, and let $V$ be the open annulus $\tfrac12<|z|<1$.

(i) Prove that there is a smooth bijection $f:U\to V$ with a smooth inverse.
(One way to do this is to write one down.)

(ii) Prove however that no such function $f$ is conformal.
:::

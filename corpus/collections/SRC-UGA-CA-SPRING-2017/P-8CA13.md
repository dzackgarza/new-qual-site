::: {.problem}
Describe all entire functions $f(z)$ such that
$$
\abs{f(z)}\le\abs{\sin(z)}
$$
for all $z$.
:::

::: {.solution}

The argument is the card's own: no solution set for this examination is retained in `tmp/sources`, so nothing below is transcribed, and the card's existing solution is restructured into numbered steps. Here $f$ is entire with $\abs{f(z)}\leq\abs{\sin z}$ for all $z$; the zeros of $\sin$ are the integer multiples of $\pi$, each simple; the criteria used are the removable-singularity theorem and Liouville's theorem.

::: pf

::: {.pf-step #zeros}

$f(n\pi)=0$ for every $n\in\ZZ$.

::: pf-proof

$\sin(n\pi)=0$, so the hypothesis gives $\abs{f(n\pi)}\leq0$.

:::

:::

::: {.pf-step #simple}

Each zero $n\pi$ of $\sin$ is simple.

::: pf-proof

$\sin'(z)=\cos z$ and $\cos(n\pi)=(-1)^{n}\neq0$, so the zero is of order one.

:::

:::

::: {.pf-step #extend}

$g\coloneqq f/\sin$ extends from $\CC\setminus\pi\ZZ$ to an entire function.

::: pf-proof

Near $n\pi$ both $f$ and $\sin$ vanish, $f$ being entire and $f(n\pi)=0$ by step [](#zeros){.pf-ref}; writing $\sin z=(z-n\pi)h(z)$ with $h$ holomorphic and $h(n\pi)\neq0$ by step [](#simple){.pf-ref}, we get $\frac{f(z)}{\sin z}=\frac{f(z)/(z-n\pi)}{h(z)}$, a quotient of a function holomorphic at $n\pi$ by one that does not vanish there; hence the singularity is removable, and the extension is entire.

:::

:::

::: {.pf-step #bound}

$\abs{g}\leq1$ everywhere.

::: pf-proof

Off the zeros of $\sin$ this is the hypothesis, dividing $\abs{f(z)}\leq\abs{\sin z}$ by $\abs{\sin z}>0$; on the zeros it follows by continuity of the extended $g$.

:::

:::

::: {.pf-step #const}

$g$ is a constant $c$ with $\abs{c}\leq1$.

::: pf-proof

Liouville's theorem applied to the bounded entire function of steps [](#extend){.pf-ref} and [](#bound){.pf-ref}.

:::

:::

::: {.pf-step #done}

The entire functions satisfying the inequality are exactly $f(z)=c\sin z$ with $\abs{c}\leq1$.

::: pf-proof

If $f$ satisfies the hypothesis then $f=g\sin=c\sin z$ with $\abs c\leq1$ by step [](#const){.pf-ref}; conversely if $f=c\sin$ with $\abs c\leq1$ then $\abs{f(z)}=\abs c\abs{\sin z}\leq\abs{\sin z}$.

:::

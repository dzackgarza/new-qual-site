::: {.problem}
Show that there is a holomorphic function $w=f(z)$ on the open set $\abs{z}>2$ such that $w^2=z^2-1$.
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.
Write $B(u)\coloneqq\sum_{n\ge0}\binom{1/2}{n}(-u)^n$ and $\Omega\coloneqq\{z:\abs{z}>2\}$.

::: pf

::: {.pf-step #binomial}
$B$ converges on the unit disc to a holomorphic function with $B(0)=1$ and $B(u)^2=1-u$ there.

::: pf-proof
The coefficients satisfy $\abs{\binom{1/2}{n+1}/\binom{1/2}{n}}\to1$, so the radius of convergence is $1$. On $\abs{u}<1$ the principal branch of $u\mapsto(1-u)^{1/2}$ is holomorphic, because $1-u$ avoids $(-\infty,0]$, and its Taylor expansion at $0$ is $\sum_n\binom{1/2}{n}(-u)^n$; a holomorphic function equals its Taylor series on the disc where that series converges, so $B$ is this branch and $B(u)^2=1-u$.
:::

:::

::: {.pf-step #composite}
$g(z)\coloneqq B(z^{-2})$ is holomorphic on $\Omega$ and satisfies $g(z)^2=1-z^{-2}$.

::: pf-proof
For $\abs{z}>2$ one has $\abs{z^{-2}}<1/4<1$, so $z^{-2}$ lies in the disc of step [](#binomial){.pf-ref}; $z\mapsto z^{-2}$ is holomorphic on the open set $\Omega$, and a holomorphic function of a holomorphic function is holomorphic there. The identity $g^2=1-z^{-2}$ is step [](#binomial){.pf-ref} evaluated at $u=z^{-2}$.
:::

:::

::: {.pf-step}
$f(z)\coloneqq z\,g(z)$ is holomorphic on $\Omega$ and $f(z)^2=z^2-1$ there.

::: pf-proof
$z\mapsto z$ and $g$ are holomorphic on $\Omega$, so their product is. Squaring and using step [](#composite){.pf-ref},
$$
f(z)^2=z^2g(z)^2=z^2\left(1-z^{-2}\right)=z^2-1,
$$
so $f$ is a holomorphic square root of $z^2-1$ on the set $\abs{z}>2$.
:::

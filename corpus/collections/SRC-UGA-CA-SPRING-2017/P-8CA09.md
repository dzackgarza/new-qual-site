::: problem
Show that there is a holomorphic function $w=f(z)$ on the open set $|z|>2$ such that $w^2=z^2-1$.
:::

::: solution
For $|z|>2$ we have $|z^{-2}|<1/4$. The binomial series
\[
(1-w)^{1/2}=\sum_{n=0}^\infty \binom{1/2}{n}(-w)^n
\]
converges holomorphically for $|w|<1$. Hence
\[
g(z)=\sum_{n=0}^\infty \binom{1/2}{n}(-z^{-2})^n
\]
is holomorphic on $|z|>2$ and satisfies $g(z)^2=1-z^{-2}$. Define
\[
f(z)=z\,g(z).
\]
Then $f$ is holomorphic on $|z|>2$ and
\[
f(z)^2=z^2\left(1-z^{-2}\right)=z^2-1.
\]
:::

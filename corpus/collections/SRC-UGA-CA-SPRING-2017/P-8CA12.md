::: problem
Show that the equation $\sin(z)=e^{\alpha z^3}$, for $\alpha>1$, has exactly three solutions inside the unit disk.
:::

::: solution
The statement is false as printed. Put
\[
F(z)=\sin z-e^{\alpha z^3},
\qquad \alpha>1.
\]
Because $\alpha$ is real,
\[
F(\bar z)=\overline{F(z)},
\]
so every nonreal zero occurs together with its complex conjugate and with the
same multiplicity.

There are no real zeros in $(-1,1)$. If $-1<x<0$, then
$\sin x<0<e^{\alpha x^3}$. If $0\le x<1$, then
\[
\sin x<1\le e^{\alpha x^3}.
\]
Hence every zero in the open unit disk is nonreal and the total number of
zeros there, counted with multiplicity, is even. It therefore cannot equal
three. Thus no proof of the printed assertion exists without correcting the
source equation or the claimed root count.
:::

::: {.problem}
Let $X=(0,1)\times(0,1)$, $Y=[0,1)\times[0,1)$, and $Z=[0,1]\times[0,1]$.
Show which, if any, of $X$, $Y$, and $Z$ are homeomorphic.
:::

::: {.solution}

::: pf

::: {.pf-step #z-compact-xy-not}
The space $Z$ is compact, while $X$ and $Y$ are not compact.

::: pf-proof
As subsets of $\RR^2$, the set
\[
Z=[0,1]\times[0,1]
\]
is closed and bounded, hence compact by the Heine--Borel theorem.

The set $X=(0,1)^2$ is bounded but not closed in $\RR^2$, so it is not compact by Heine--Borel.
Likewise,
\[
Y=[0,1)\times[0,1)
\]
is not closed in $\RR^2$: for example,
\[
(1-1/n,0)\in Y
\qquad\text{and}\qquad
(1-1/n,0)\longrightarrow(1,0)\notin Y.
\]
Hence $Y$ is not compact.
:::

:::

::: {.pf-step #z-excluded}
Therefore $Z$ is homeomorphic to neither $X$ nor $Y$.

::: pf-proof
Compactness is preserved by homeomorphisms.
Apply step [](#z-compact-xy-not){.pf-ref}.
:::

:::

::: {.pf-step #y-minus-point-contractible}
If
\[
q=(0,0)\in Y,
\]
then $Y\setminus\{q\}$ is contractible.

::: pf-proof
Let
\[
c=(1/2,1/2)\in Y\setminus\{q\}.
\]
Define
\[
H:(Y\setminus\{q\})\times[0,1]\longrightarrow Y\setminus\{q\},
\qquad
H(y,t)=(1-t)y+tc.
\]
Because $Y$ is convex, the segment from $y$ to $c$ remains in $Y$.
For $t>0$, both coordinates of $H(y,t)$ are strictly positive, so $H(y,t)\ne q$; for $t=0$ this holds because $y\ne q$.
Thus $H$ is a contraction of $Y\setminus\{q\}$ to $c$.
:::

:::

::: {.pf-step #x-minus-point-not-contractible}
For every $p\in X$, the punctured space $X\setminus\{p\}$ is not contractible.

::: pf-proof
The map
\[
\lambda:(0,1)\longrightarrow\RR,
\qquad
\lambda(t)=\tan\!\bigl(\pi(t-1/2)\bigr),
\]
is a homeomorphism.
Hence
\[
\Lambda=\lambda\times\lambda:X\longrightarrow\RR^2
\]
is a homeomorphism.
If $a=\Lambda(p)$, translation by $-a$ gives a homeomorphism
\[
X\setminus\{p\}
\cong
\RR^2\setminus\{0\}.
\]
The punctured plane deformation retracts radially onto $S^1$, so
\[
\pi_1(X\setminus\{p\})
\cong
\pi_1(S^1)
\cong
\ZZ.
\]
In particular, $X\setminus\{p\}$ is not contractible.
:::

:::

::: {.pf-step #x-y-not-homeomorphic}
The spaces $X$ and $Y$ are not homeomorphic.

::: pf-proof
Suppose that
\[
h:Y\longrightarrow X
\]
were a homeomorphism.
Let $q=(0,0)$.
Then restriction gives a homeomorphism
\[
h|_{Y\setminus\{q\}}:
Y\setminus\{q\}
\longrightarrow
X\setminus\{h(q)\}.
\]
By step [](#y-minus-point-contractible){.pf-ref} the domain is contractible, while by step [](#x-minus-point-not-contractible){.pf-ref} the codomain is not contractible.
This is impossible because contractibility is a homeomorphism invariant.
:::

:::

::: pf-step
Thus no two of $X$, $Y$, and $Z$ are homeomorphic.

::: pf-proof
Step [](#z-excluded){.pf-ref} excludes every pair involving $Z$, and step [](#x-y-not-homeomorphic){.pf-ref} excludes the remaining pair $X,Y$.
:::

::: problem
a. Show that a path-connected space is connected.

b. A topological space $X$ is locally path-connected if for every point $x\in X$ and every neighbourhood $V$ of $x$, there is a path-connected open set $U$ with $x\in U\subset V$.
Show that a connected and locally path-connected space is path-connected.
:::

::: {.solution}
<1>1. Every path-connected space is connected.
::: {.proof}
Let $X$ be path connected and suppose, for contradiction, that
\[
X=U\disjoint V
\]
is a separation into two nonempty open subsets.
Choose
\[
x\in U,
\qquad
y\in V.
\]
Path connectedness gives a continuous map
\[
\gamma:[0,1]\longrightarrow X
\]
with $\gamma(0)=x$ and $\gamma(1)=y$.
Then
\[
\gamma^{-1}(U)
\qquad\text{and}\qquad
\gamma^{-1}(V)
\]
are disjoint open subsets of $[0,1]$, both nonempty, whose union is $[0,1]$.
This would disconnect the interval $[0,1]$, which is connected.
Hence no separation of $X$ exists, so $X$ is connected.
:::

<1>2. Now suppose $X$ is connected and locally path connected, fix $x_0\in X$, and let
\[
C=\{x\in X:x\text{ can be joined to }x_0\text{ by a path in }X\}.
\]
Then $C$ is open.
::: {.proof}
Let $x\in C$.
Apply local path connectedness to the neighborhood $V=X$ of $x$.
There is a path-connected open set
\[
x\in U\subseteq X.
\]
For every $y\in U$, there is a path in $U$ from $x$ to $y$.
Since $x\in C$, there is also a path in $X$ from $x_0$ to $x$.
Concatenating these two paths gives a path from $x_0$ to $y$, so $y\in C$.
Thus
\[
U\subseteq C.
\]
Every point of $C$ therefore has an open neighborhood contained in $C$, and $C$ is open.
:::

<1>3. The complement $X\setminus C$ is open.
::: {.proof}
Let $y\in X\setminus C$.
Again apply local path connectedness with the neighborhood $V=X$ to obtain a path-connected open set
\[
y\in W\subseteq X.
\]
We claim
\[
W\cap C=\varnothing.
\]
Indeed, if $z\in W\cap C$, then a path from $x_0$ to $z$ followed by a path in the path-connected set $W$ from $z$ to $y$ would give a path from $x_0$ to $y$.
This would put $y$ in $C$, contrary to the choice of $y$.
Hence $W\subseteq X\setminus C$, so $X\setminus C$ is open.
:::

<1>4. The set $C$ equals $X$.
::: {.proof}
By definition $x_0\in C$, so $C$ is nonempty.
By <1>2 and <1>3, both $C$ and its complement are open.
If the complement were nonempty, they would form a separation of the connected space $X$.
Therefore
\[
X\setminus C=\varnothing,
\]
so $C=X$.
:::

<1>5. Thus every connected locally path-connected space is path connected.
::: {.proof}
By <1>4, every point of $X$ can be joined to the fixed point $x_0$ by a path.
Given arbitrary $x,y\in X$, concatenate a path from $x$ to $x_0$ with a path from $x_0$ to $y$.
Hence any two points of $X$ can be joined by a path.
:::
:::

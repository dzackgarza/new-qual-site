::: problem
(i) Construct an entire function with simple zeros at $\left\{\sqrt{n} + \frac{1}{\sqrt{n}} : n = 1, 2, \ldots\right\}$ and no other zeroes.

(ii) Construct a meromorphic function with simple poles at $z = \sqrt{n\sqrt{n}}$ and residues equal to $n$ for $n = 1, 2, \ldots$.
:::

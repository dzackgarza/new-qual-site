::: {.problem}
Let
\[
f:S^n\times S^n\longrightarrow S^n\times S^n
\]
be a homeomorphism.
Let $z$ generate $H^n(S^n)$ and put
\[
\alpha=z\times1,\qquad \beta=1\times z
\]
in $H^n(S^n\times S^n)$.
Write
\[
f^*(\alpha)=k\alpha+l\beta,\qquad f^*(\beta)=p\alpha+q\beta
\]
for integers $k,l,p,q$.

Prove that if $n$ is even, then
\[
\begin{pmatrix}k&l\\ p&q\end{pmatrix}
\]
is one of the eight signed permutation matrices.
Also find homeomorphisms $f$ realizing all eight possibilities.
:::

::: {.solution}
Let
\[
X=S^n\times S^n,
\]
and let
\[
\alpha=z\times1,
\qquad
\beta=1\times z
\]
generate
\[
H^n(X;\mathbb Z)\cong\mathbb Z^2.
\]

Because \(n\) is even, graded commutativity gives
\[
\boxed{\alpha\smile\beta=\beta\smile\alpha}.
\]

Also,
\[
\boxed{\alpha^2=\beta^2=0}
\]
because \(H^{2n}(S^n)=0\).

Finally,
\[
\boxed{
H^{2n}(X;\mathbb Z)
\cong
\mathbb Z}
\]
with generator
\[
\alpha\beta.
\]

## Restricting the matrix

<1>1. Since \(f\) is a homeomorphism,
\[
f^*:H^n(X;\mathbb Z)\to H^n(X;\mathbb Z)
\]
is an automorphism.

::: {.proof}
A homeomorphism induces an isomorphism on cohomology.
:::

<1>2. Therefore the matrix
\[
M=
\begin{pmatrix}
k&l\\
p&q
\end{pmatrix}
\]
lies in
\[
\boxed{GL_2(\mathbb Z)}.
\]

::: {.proof}
The displayed matrix represents \(f^*\) in the basis \((\alpha,\beta)\).
An automorphism of \(\mathbb Z^2\) has determinant \(\pm1\).
:::

<1>3. Since \(\alpha^2=0\),
\[
0
=
f^*(\alpha^2)
=
(f^*\alpha)^2.
\]

::: {.proof}
Cohomology pullback preserves cup products.
:::

<1>4. Using
\[
f^*\alpha=k\alpha+l\beta,
\]
one gets
\[
0
=
(k\alpha+l\beta)^2
=
2kl\,\alpha\beta.
\]

::: {.proof}
Expand:
\[
k^2\alpha^2
+
kl\,\alpha\beta
+
lk\,\beta\alpha
+
l^2\beta^2.
\]
The square terms vanish, and since \(n\) is even,
\[
\beta\alpha=\alpha\beta.
\]
:::

<1>5. Hence
\[
\boxed{kl=0}.
\]

::: {.proof}
The group
\[
H^{2n}(X;\mathbb Z)
\]
is infinite cyclic generated by \(\alpha\beta\), so
\[
2kl\,\alpha\beta=0
\]
implies \(2kl=0\), hence \(kl=0\).
:::

<1>6. Similarly,
\[
\boxed{pq=0}.
\]

::: {.proof}
Apply the same argument to
\[
0=f^*(\beta^2)=(p\alpha+q\beta)^2=2pq\,\alpha\beta.
\]
:::

<1>7. Since the first row \((k,l)\) is nonzero and satisfies \(kl=0\), exactly one of \(k,l\) is nonzero.

::: {.proof}
The row cannot be zero because \(M\) is invertible. Step <1>5 says at least one entry is zero.
:::

<1>8. Since the second row \((p,q)\) is nonzero and satisfies \(pq=0\), exactly one of \(p,q\) is nonzero.

::: {.proof}
Use invertibility and step <1>6.
:::

<1>9. The nonzero entries of the two rows must occur in different columns.

::: {.proof}
If they occurred in the same column, the other column would be zero, making
\[
\det M=0,
\]
contrary to \(M\in GL_2(\mathbb Z)\).
:::

<1>10. Therefore \(M\) has one of the two forms
\[
\begin{pmatrix}
k&0\\
0&q
\end{pmatrix}
\qquad\text{or}\qquad
\begin{pmatrix}
0&l\\
p&0
\end{pmatrix}.
\]

::: {.proof}
Steps <1>7--<1>9 say each row and each column has exactly one nonzero entry.
:::

<1>11. In the diagonal case,
\[
\det M=kq=\pm1,
\]
so
\[
\boxed{k,q\in\{\pm1\}}.
\]

::: {.proof}
The only integers whose product is \(\pm1\) are \(\pm1\).
:::

<1>12. In the off-diagonal case,
\[
\det M=-lp=\pm1,
\]
so
\[
\boxed{l,p\in\{\pm1\}}.
\]

::: {.proof}
Again, an integer product equal to \(\pm1\) forces both factors to be units in \(\mathbb Z\).
:::

<1>13. Hence \(M\) is one of the eight signed permutation matrices:
\[
\boxed{
\begin{pmatrix}\pm1&0\\0&\pm1\end{pmatrix}
\quad\text{or}\quad
\begin{pmatrix}0&\pm1\\\pm1&0\end{pmatrix}.}
\]

::: {.proof}
There are four sign choices in each of the two permutation patterns.
:::

## Realizing all eight matrices

Let
\[
A:S^n\to S^n
\]
be the antipodal map
\[
A(x)=-x.
\]

<1>14. Since \(n\) is even,
\[
\boxed{\deg A=-1}.
\]

::: {.proof}
The antipodal map on \(S^n\) has degree
\[
(-1)^{n+1}.
\]
For even \(n\), this equals \(-1\).
:::

For \(\varepsilon\in\{\pm1\}\), define
\[
h_\varepsilon=
\begin{cases}
\operatorname{id}_{S^n},&\varepsilon=1,\\
A,&\varepsilon=-1.
\end{cases}
\]

<1>15. The homeomorphism
\[
F_{\varepsilon_1,\varepsilon_2}(x,y)
=
\bigl(
h_{\varepsilon_1}(x),
h_{\varepsilon_2}(y)
\bigr)
\]
induces
\[
\boxed{
\begin{pmatrix}
\varepsilon_1&0\\
0&\varepsilon_2
\end{pmatrix}}
\]
on \(H^n(X)\).

::: {.proof}
On the first factor,
\[
h_{\varepsilon_1}^*z=\varepsilon_1 z,
\]
and similarly on the second factor. Hence
\[
F^*\alpha=\varepsilon_1\alpha,
\qquad
F^*\beta=\varepsilon_2\beta.
\]
:::

<1>16. Therefore all four diagonal signed permutation matrices occur.

::: {.proof}
Choose independently
\[
\varepsilon_1,\varepsilon_2\in\{\pm1\}.
\]
:::

Let
\[
\tau:X\to X
\]
be the factor swap
\[
\tau(x,y)=(y,x).
\]

<1>17. One has
\[
\boxed{
\tau^*\alpha=\beta,
\qquad
\tau^*\beta=\alpha}.
\]

::: {.proof}
Under \(\tau\), the first projection becomes the second and the second becomes the first.
:::

<1>18. Hence \(\tau\) induces the matrix
\[
\boxed{
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix}}.
\]

::: {.proof}
Read the coefficients of \(\tau^*\alpha\) and \(\tau^*\beta\) in the basis \((\alpha,\beta)\).
:::

<1>19. For
\[
G_{\varepsilon_1,\varepsilon_2}
=
F_{\varepsilon_1,\varepsilon_2}\circ\tau,
\]
the induced matrix is
\[
\boxed{
\begin{pmatrix}
0&\varepsilon_1\\
\varepsilon_2&0
\end{pmatrix}}.
\]

::: {.proof}
Since
\[
G^*=\tau^*\circ F^*,
\]
one gets
\[
G^*\alpha
=
\tau^*(\varepsilon_1\alpha)
=
\varepsilon_1\beta,
\]
and
\[
G^*\beta
=
\tau^*(\varepsilon_2\beta)
=
\varepsilon_2\alpha.
\]
This is the displayed matrix in the convention of the problem.
:::

<1>20. Therefore all four off-diagonal signed permutation matrices occur.

::: {.proof}
Choose independently
\[
\varepsilon_1,\varepsilon_2\in\{\pm1\}.
\]
:::

<1>21. Thus every one of the eight signed permutation matrices is realized by a homeomorphism of
\[
S^n\times S^n.
\]

::: {.proof}
The diagonal four are realized in step <1>16 and the off-diagonal four in step <1>20.
:::

<1>22. Q.E.D.

::: {.proof}
Step <1>13 proves the restriction on the matrix, and step <1>21 realizes all eight possibilities.
:::
:::

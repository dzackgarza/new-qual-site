::: {.problem}
Show that the polynomial $2x + 1$ in $\ZZ_{4}[x]$ has a multiplicative inverse in $\ZZ_{4}[x]$.
:::

::: {.solution}
Observe that $( 2 x + 1 ) ( 2 x + 1 ) = 4 x ^ { 2 } + 4 x + 1 = 1$ so $2 x + 1$ is its own inverse.
:::

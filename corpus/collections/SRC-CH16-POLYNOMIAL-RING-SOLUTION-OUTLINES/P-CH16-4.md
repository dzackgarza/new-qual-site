::: {.problem}
If R is a commutative ring, show that the characteristic of $R [ x ]$ is the same as the characteristic of R.
:::

::: {.solution}
Let R be a commutative ring with characteristic k. Then $k r = 0$ for all $r \in R$ . Now, let $f ( x ) \in R [ x ]$ . Then $f ( x ) = a _ { n } x ^ { n } + a _ { n - 1 } x ^ { n - 1 } + \cdot \cdot \cdot + a _ { 1 } x + a _ { 0 }$ for some $a _ { i } \in R$ , and some $n \in \mathbb { Z } _ { > 0 }$ . Then $k f ( x ) = ( k a _ { n } ) x ^ { n } + ( k a _ { n - 1 } ) x ^ { n - 1 } + \cdot \cdot \cdot + ( k a _ { 1 } ) x + k a _ { 0 } = 0 + 0 + \cdot \cdot \cdot + 0 = 0$ . Hence the characteristic of $R [ x ]$ is at most k. However, since for all $r \in R , r \in R [ x ]$ , the characteristic of $R [ x ]$ must be at least k. Thus the characteristic is exactly k.
:::

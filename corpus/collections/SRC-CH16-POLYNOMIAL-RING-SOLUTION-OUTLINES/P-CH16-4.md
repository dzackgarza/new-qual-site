::: {.problem}
If $R$ is a commutative ring, show that the characteristic of $R[x]$ is the same as the characteristic of $R$.
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $R$ be a commutative ring and $\operatorname{char}R$ its characteristic, the least positive $k$ with $k\cdot1_R=0$, or $0$ if there is none.

::: pf

::: {.pf-step #scaling}
If $k=\operatorname{char}R$ is positive then $kf=0$ for every $f\in R[x]$; hence $\operatorname{char}R[x]\le k$.

::: pf-proof
Write $f=\sum_{i=0}^{n}a_ix^i$. Multiplication by the integer $k$ acts coefficientwise, $kf=\sum_i(ka_i)x^i$, and $ka_i=(k\cdot1_R)a_i=0\cdot a_i=0$ because $k\cdot1_R=0$ by definition of the characteristic. So $kf=0$; a positive integer killing every element of $R[x]$ is a candidate for the characteristic, so the least such integer is at most $k$.
:::

:::

::: {.pf-step #constants}
If $m>0$ with $mf=0$ for all $f\in R[x]$, then $m\cdot1_R=0$; hence $\operatorname{char}R[x]\ge\operatorname{char}R$.

::: pf-proof
The constant polynomial $f=1_R$ lies in $R[x]$, so $m\cdot1_R=mf=0$. The constant polynomial $r$ for $r\in R$ likewise gives $mr=0$. So any positive integer killing all of $R[x]$ kills all of $R$, and therefore is at least the least such integer for $R$.
:::

:::

::: {.pf-step}
$\operatorname{char}R[x]=\operatorname{char}R$, including the case where both are $0$.

::: pf-proof
If $\operatorname{char}R=k>0$, step [](#scaling){.pf-ref} gives an annihilating integer $k$ for $R[x]$ and step [](#constants){.pf-ref} shows no smaller positive integer can annihilate $R[x]$, so the characteristic is $k$. If $\operatorname{char}R=0$, step [](#constants){.pf-ref} shows that no positive integer annihilates $R[x]$, since none annihilates $1_R$; hence $\operatorname{char}R[x]=0$ as well. Both cases give equality.
:::

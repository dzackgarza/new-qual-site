::: {.problem}
Prove that the ideal $\langle x \rangle$ in $\QQ[x]$ is maximal.
:::

::: {.solution}
First, let’s look at $\QQ [ x ] / < x >$ . This quotient ring contains cosets that look like $a + < x >$ where $a \in \QQ$ . Thus, using the map $\QQ [ x ] / < x > \to \QQ$ defined by $a + < x > \mapsto a$ is an isomorphism.
Thus $\QQ [ x ] / < x > \approx \QQ$ . Now, Q is a field so $< x >$ is maximal.
:::

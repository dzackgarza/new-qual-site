::: {.problem}
Prove that the ideal $< x >$ in $\mathbb { Q } [ x ]$ is maximal.
:::

::: {.solution}
First, let’s look at $\mathbb { Q } [ x ] / < x >$ . This quotient ring contains cosets that look like $a + < x >$ where $a \in \mathbb { Q }$ . Thus, using the map $\mathbb { Q } [ x ] / < x > \to \mathbb { Q }$ defined by $a + < x > \mapsto a$ is an isomorphism.
Thus $\mathbb { Q } [ x ] / < x > \approx \mathbb { Q }$ . Now, Q is a field so $< x >$ is maximal.
:::

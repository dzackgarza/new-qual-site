::: {.problem}
Prove that the ideal $\langle x \rangle$ in $\QQ[x]$ is maximal.
:::

::: {.solution}

The exercise is Gallian, *Contemporary Abstract Algebra* (7th ed.), Chapter 16 exercise 18, and is item 20 of the retained Chapter 16 solution outline
(`assets/attachments/Ch16Sltns.pdf`). Its route — identify $\QQ[x]/\langle x\rangle$
with $\QQ$, which is a field — is kept, with the identification proved rather than asserted.

::: pf

::: {.pf-step #evaluation}

The map $\phi:\QQ[x]\to\QQ$, $\phi(f)=f(0)$, is a surjective ring homomorphism.

::: pf-proof

For $f,g\in\QQ[x]$ the value at $0$ is additive and multiplicative: $(f+g)(0)=f(0)+g(0)$ and
$(fg)(0)=f(0)g(0)$, and $\phi(1)=1$. So $\phi$ preserves sums and products. It is
surjective because a constant polynomial $a$ has $\phi(a)=a$ for every $a\in\QQ$.

:::

:::

::: {.pf-step #kernel}

$\ker\phi=\langle x\rangle$.

::: pf-proof

$f\in\ker\phi$ means $f(0)=0$. By the Factor Theorem (Corollary 2 of Theorem 16.2) with $a=0$, $x-0=x$ divides $f$ exactly when $f(0)=0$. So $\ker\phi$ is the set of
multiples of $x$, which is $\langle x\rangle$ by the definition of a principal ideal in
$\QQ[x]$.

:::

:::

::: {.pf-step #quotient}

$\QQ[x]/\langle x\rangle$ is isomorphic to $\QQ$, hence is a field.

::: pf-proof

$\phi$ is a homomorphism with image $\QQ$ and kernel $\langle x\rangle$ by steps
[](#evaluation){.pf-ref} and [](#kernel){.pf-ref}, so the First Isomorphism Theorem for Rings
(Theorem 15.3) gives $\QQ[x]/\langle x\rangle\cong\QQ$. The rationals form a
field. Concretely the isomorphism is $f+\langle x\rangle\mapsto f(0)$, which shows each coset
is $a+\langle x\rangle$ for the rational $a=f(0)$.

:::

:::

::: {.pf-step #maximal}

$\langle x\rangle$ is a maximal ideal of $\QQ[x]$.

::: pf-proof

$\QQ[x]$ is a commutative ring with unity, and its ideal $\langle x\rangle$ has a factor ring
that is a field by step [](#quotient){.pf-ref}. Theorem 14.4 says that for
such a ring, $R/A$ is a field if and only if $A$ is maximal; hence $\langle x\rangle$ is
maximal.

:::

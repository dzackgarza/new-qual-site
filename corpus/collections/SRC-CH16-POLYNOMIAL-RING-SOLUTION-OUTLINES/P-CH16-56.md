::: {.problem}
For any field F recall that $F ( x )$ denotes the field of quotients of the ring $F [ x ]$ . Prove that there is no element in $F ( x )$ whose square is x.
:::

::: {.solution}
Suppose that there is an element in $F ( x )$ whose square is x. Then $\left( { \frac { f ( x ) } { g ( x ) } } \right) ^ { 2 } = x$ . WLOG, assume that $f ( x )$ and $g ( x )$ have no common factors (so that the quotient is already in reduced form).
Then $\left( { \frac { f ( x ) } { g ( x ) } } \right) ^ { 2 } = { \frac { ( f ( x ) ) ^ { 2 } } { ( g ( x ) ) ^ { 2 } } } = x$ . So $( f ( x ) ) ^ { 2 } = x ( g ( x ) ) ^ { 2 }$ . Hence, $( f ( 0 ) ) ^ { 2 } = 0$ so $f ( 0 ) = 0$ . This means that $x | f ( x )$ . So $f ( x ) = x h ( x )$ for some $h ( x )$ . Plugging this in, we have that $( x h ( x ) ) ^ { 2 } = x ( g ( x ) ) ^ { 2 }$ so $x ( h ( x ) ) ^ { 2 } = ( g ( x ) ) ^ { 2 }$ . Using the same argument as before, $g ( 0 ) = 0$ and $x | g ( x )$ . Therefore $f ( x )$ and $g ( x )$ have x as a common factor, which is a contradiction.
:::

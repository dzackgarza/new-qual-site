::: {.problem}
Let $f ( x ) = 4 x ^ { 3 } + 2 x ^ { 2 } + x + 3$ and $g ( x ) = 3 x ^ { 4 } + 3 x ^ { 3 } + 3 x ^ { 2 } + x + 4$ , where $f ( x ) , g ( x ) \in$ $\mathbb { Z } _ { 5 } [ x ]$ . Compute $f ( x ) + g ( x )$ and $f ( x ) \cdot g ( x )$ .
:::

::: {.solution}
$$
f ( x ) + g ( x ) = 3 x ^ { 4 } + ( 4 + 3 ) x ^ { 3 } + ( 2 + 3 ) x ^ { 2 } + ( 1 + 1 ) x + ( 3 + 4 ) = 3 x ^ { 4 } + 2 x ^ { 3 } + 0 x ^ { 2 } + 2 x + 2
$$
:::

::: {.problem}
Let $f ( x ) = 4 x ^ { 3 } + 2 x ^ { 2 } + x + 3$ and $g ( x ) = 3 x ^ { 4 } + 3 x ^ { 3 } + 3 x ^ { 2 } + x + 4$ , where $f ( x ) , g ( x ) \in$ $\mathbb { Z } _ { 5 } [ x ]$ . Compute $f ( x ) + g ( x )$ and $f ( x ) \cdot g ( x )$ .
:::

::: {.solution}
$$
f ( x ) + g ( x ) = 3 x ^ { 4 } + ( 4 + 3 ) x ^ { 3 } + ( 2 + 3 ) x ^ { 2 } + ( 1 + 1 ) x + ( 3 + 4 ) = 3 x ^ { 4 } + 2 x ^ { 3 } + 0 x ^ { 2 } + 2 x + 2
$$

For the product, the coefficient of $x^k$ is $\sum_{i+j=k} a_ib_j$, reduced modulo 5, where $a_i$ and $b_j$ are the coefficients of $f$ and $g$:
$$
f ( x ) \cdot g ( x ) = 2x^7 + 3x^6 + x^5 + 2x^4 + 0x^3 + 3x^2 + 2x + 2 .
$$
For instance, the coefficient of $x^3$ is $4\cdot4 + 2\cdot1 + 1\cdot3 + 3\cdot3 = 30 \equiv 0$.
:::

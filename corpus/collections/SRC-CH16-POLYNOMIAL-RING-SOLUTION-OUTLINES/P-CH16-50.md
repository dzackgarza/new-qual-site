::: {.problem}
Let $R$ be a ring and $x$ be an indeterminate.
Prove that the rings $R[x]$ and $R[x^{2}]$ are ring-isomorphic.
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Here $R[x^2]$ is the subring of $R[x]$ generated by $R$ and $x^2$, whose elements are exactly the $f(x^2)$ for $f\in R[x]$.

::: pf

::: {.pf-step #hom}
$\varphi:R[x]\to R[x^2]$, $\varphi(f(x))=f(x^2)$, is a ring homomorphism.

::: pf-proof
Substitution is compatible with the operations: $(f+g)(x^2)=f(x^2)+g(x^2)$ and $(fg)(x^2)=f(x^2)g(x^2)$, because evaluation of a product of polynomials is the product of the evaluations in a commutative ring, and $\varphi(1)=1$. So $\varphi$ preserves addition, multiplication and the identity, which is the definition of a ring homomorphism.
:::

:::

::: {.pf-step #bijective}
$\varphi$ is bijective.

::: pf-proof
Injectivity: if $f(x^2)=0$ then every coefficient of $f$ is $0$, since the monomials $x^{2k}$ occurring are distinct monomials; so $\ker\varphi=\{0\}$. Surjectivity: an element of $R[x^2]$ is, by definition of that subring, a polynomial in $x^2$, that is $f(x^2)$ for the polynomial $f$ obtained by replacing $x^2$ with $x$ in each monomial. So every element of $R[x^2]$ is a value of $\varphi$.
:::

:::

::: {.pf-step #iso}
$R[x]\cong R[x^2]$.

::: pf-proof
By steps [](#hom){.pf-ref} and [](#bijective){.pf-ref} $\varphi$ is a bijective ring homomorphism, that is a ring isomorphism onto $R[x^2]$. So the two rings are isomorphic, as the problem asks.
:::

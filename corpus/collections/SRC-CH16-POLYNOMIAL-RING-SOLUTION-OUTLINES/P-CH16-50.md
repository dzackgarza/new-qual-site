::: {.problem}
Let R be a ring and x be an indeterminate.
Prove that the rings $R [ x ]$ and $R [ x ^ { 2 } ]$ are ring-isomorphic.
:::

::: {.solution}
Let R be a ring and x be an indeterminate.
Consider the rings $R [ x ]$ and $R [ x ^ { 2 } ]$ . To show that they are isomorphic, let $\phi : R [ x ] \to R [ x ^ { 2 } ]$ be defined by $f ( x ) \mapsto f ( x ^ { 2 } )$ . We see that addition is preserved since $\phi ( f ( x ) + g ( x ) ) = \phi ( ( f + g ) ( x ) ) = ( f + g ) ( x ^ { 2 } ) = f ( x ^ { 2 } ) + g ( x ^ { 2 } ) = \phi ( f ( x ) ) + \phi ( g ( x ) )$ . Similarly, $\phi(f(x)g(x)) = (fg)(x^2) = f(x^2)g(x^2) = \phi(f(x))\phi(g(x))$, so multiplication is preserved.
This is one-to-one since $\operatorname { k e r } \phi = \{ f ( x ) | f ( x ^ { 2 } ) = 0 \} = \{ 0 \}$ , and onto since every element of $R[x^2]$ has the form $f(x^2)$ for some $f(x) \in R[x]$.
:::

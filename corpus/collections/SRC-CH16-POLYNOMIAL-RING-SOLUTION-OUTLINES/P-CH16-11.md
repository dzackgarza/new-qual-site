::: {.problem}
If $\phi : R \to S$ is a ring homomorphism, define ${ \bar { \phi } } : R [ x ] \to S [ x ]$ by $( a _ { n } x ^ { n } + \cdots + a _ { 1 } x + a _ { 0 } ) \mapsto \phi ( a _ { n } ) x ^ { n } + \cdot \cdot \cdot + \phi ( a _ { 0 } )$ . Show that $\bar { \phi }$ is a ring homomorphism.
:::

::: {.solution}
Let $f ( x ) = a _ { n } x ^ { n } + a _ { n - 1 } x ^ { n - 1 } + \cdot \cdot \cdot + a _ { 1 } x + a _ { 0 }$ and $g ( x ) = b _ { m } x ^ { m } + b _ { m - 1 } x ^ { m - 1 } + \cdot \cdot \cdot + b _ { 1 } x + b _ { 0 }$ with $f ( x ) , g ( x ) \in R [ x ]$ . Let $s = \operatorname { m a x } \{ n , m \}$ . Now, $\bar { \phi } ( f ( x ) + g ( x ) ) = \bar { \phi } ( ( a _ { s } + b _ { s } ) x ^ { s } + ( a _ { s - 1 } + b _ { s - 1 } ) x ^ { s - 1 } + \cdot \cdot \cdot + ( a _ { 1 } + b _ { 1 } ) x + ( a _ { 0 } + b _ { 0 } ) ) = \phi ( a _ { s } + b _ { s } ) x ^ { s } + \cdot \cdot \cdot + \phi ( a _ { 1 } + b _ { 1 } ) x + \phi ( a _ { 0 } + b _ { 0 } )$ where $a _ { i }$ and $b _ { i }$ are in R. Since φ is a ring homomorphism from R to S, $\phi(a_i + b_i) = \phi(a_i) + \phi(b_i)$ and these coefficients lie in S. So ${ \bar { \phi } } ( f ( x ) + g ( x ) ) = ( \phi ( a _ { n } ) x ^ { n } + \cdot \cdot \cdot + \phi ( a _ { 1 } ) x + \phi ( a _ { 0 } ) ) + ( \phi ( b _ { m } ) x ^ { m } + \cdot \cdot \cdot + \phi ( b _ { 1 } ) x + \phi ( b _ { 0 } ) ) = \bar { \phi } ( f ( x ) ) + \bar { \phi } ( g ( x ) )$ . For multiplication, the coefficient of $x^k$ in $f(x)g(x)$ is $c_k = \sum_{i+j=k} a_ib_j$, and $\phi(c_k) = \sum_{i+j=k}\phi(a_i)\phi(b_j)$ is the coefficient of $x^k$ in $\bar\phi(f(x))\bar\phi(g(x))$. So $\bar\phi(f(x)g(x)) = \bar\phi(f(x))\bar\phi(g(x))$.
Hence it is a ring homomorphism.
:::

::: {.problem}
Are there any nonconstant polynomials in $\mathbb { Z } [ x ]$ that have multiplicative inverses?
Explain your answers.
:::

::: {.solution}
No. Note, we argued this intuitively.
Here’s a more formal argument.
Suppose that $f ( x ) =$ $\textstyle \sum _ { i = 0 } ^ { n } a _ { i } x ^ { i }$ has a multiplicative inverse $\textstyle g ( x ) = \sum _ { i = 0 } ^ { m } b _ { i } x ^ { i }$ . Then $f ( x ) g ( x ) = \sum _ { i = 0 } ^ { n + m } c _ { i } x ^ { i } = 1$ . This implies that $c _ { 0 } = 1$ and $c _ { k } = 0$ for all $k \neq 0$ . In particular, $c _ { 1 } = a _ { 0 } b _ { 1 } + a _ { 1 } b _ { 0 } = 0$ . But $a _ { 0 } = b _ { 0 } ^ { - 1 }$ from $c _ { 0 } = 1$ . So $c _ { 1 } = b _ { 0 } ^ { - 1 } b _ { 1 } + a _ { 1 } b _ { 0 } = 0$ . This implies that $b _ { 1 } = 0 = a _ { 1 }$ . By induction, it is clear that $a _ { i } = b _ { i } = 0$ for all $i \neq 0$ . Hence, $f ( x )$ and $g ( x )$ are constant, which is a contradiction.
:::

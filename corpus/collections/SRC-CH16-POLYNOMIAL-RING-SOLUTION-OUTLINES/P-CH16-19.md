::: {.problem}
(Degree Rule) Let D be an integral domain and $f ( x ) , g ( x ) \in D [ x ]$ . Prove that deg $( f ( x ) g ( x ) ) = \deg f ( x ) + \deg g ( x )$ . Show, by example, that for a commutative ring R it is possible that deg $f ( x ) g ( x ) < \deg f ( x ) + \deg g ( x )$ , where $f ( x )$ and $g ( x )$ are nonzero elements in $R [ x ]$ .
:::

::: {.solution}
Let D be an integral domain and $f ( x ) , g ( x ) \in D [ x ]$ . Suppose that $\textstyle f ( x ) = \sum _ { i = 0 } ^ { n } a _ { i } x ^ { i }$ and $\textstyle g ( x ) = \sum _ { i = 0 } ^ { m } b _ { i } x ^ { i }$ so that $\operatorname { d e g } ( f ( x ) ) = n$ and $\operatorname { d e g } ( g ( x ) ) = m$ . We know that $f ( x ) g ( x ) = \sum _ { i = 0 } ^ { n + m } c _ { i } x ^ { i }$ where $c _ { n + m } = a _ { 0 } b _ { n + m } + a _ { 1 } b _ { n + m - 1 } + \cdot \cdot \cdot + a _ { n + m - 1 } b _ { 1 } + a _ { n + m } b _ { 0 }$ . Since the $a _ { i }$ and $b _ { j }$ are in an integral domain, $a _ { i } b _ { j } \neq 0$ when $a _ { i } \neq 0$ and $b _ { j } \neq 0$ . In particular, we know that $a _ { n }$ and $b _ { m }$ are non-zero so $a _ { n } b _ { m } \neq 0$ . Now, all other terms in the sum of $c _ { n + m }$ are zero because either $a _ { i }$ has $i > n$ or $b _ { j }$ has $j > m$ . Thus $c _ { n + m } = a _ { n } b _ { m }$ . Thus, $c _ { n + m }$ is not zero and $\operatorname { d e g } ( f ( x ) g ( x ) ) = n + m$ .
:::

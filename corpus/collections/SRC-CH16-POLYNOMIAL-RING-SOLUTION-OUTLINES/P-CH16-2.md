::: {.problem}
In $\ZZ_{3}[x]$, show that the distinct polynomials $x^{4} + x$ and $x^{2} + x$ determine the same function from $\ZZ_{3}$ to $\ZZ_{3}$.
:::

::: {.solution}
Let $f ( x ) = x ^ { 4 } + x$ and $g ( x ) = x ^ { 2 } + x$ . Observe: $f ( 0 ) = 0 = g ( 0 ) , f ( 1 ) = 2 = g ( 1 )$ , and $f ( 2 ) = 2 ^ { 4 } + 2 = 1 8 = 0 = 6 = 2 ^ { 2 } + 2 = g ( 2 )$ .
:::

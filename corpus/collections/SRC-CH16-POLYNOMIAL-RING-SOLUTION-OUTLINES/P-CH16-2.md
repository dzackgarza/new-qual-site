::: {.problem}
In $\ZZ_{3}[x]$, show that the distinct polynomials $x^{4} + x$ and $x^{2} + x$ determine the same function from $\ZZ_{3}$ to $\ZZ_{3}$.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch16Sltns.pdf`, and entry "# 2" of that outline covers Gallian 7e Chapter 16 Exercise 2. The outline evaluates both polynomials at every element of $\ZZ_3$. Those values are retained below, with the polynomial distinctness and function equality stated separately.

Let $f=x^{4}+x$ and $g=x^{2}+x$ in $\ZZ_3[x]$, and use the same letters for their induced functions $\ZZ_3\to\ZZ_3$.

::: pf

::: {.pf-step #distinct}
The polynomials $f$ and $g$ are distinct in $\ZZ_3[x]$.

::: pf-proof
The polynomial $f$ has a nonzero $x^{4}$-term and degree $4$, whereas $g$ has degree $2$. Their coefficient sequences therefore differ, so they are different elements of $\ZZ_3[x]$.
:::

:::

::: {.pf-step #evaluations}
For every $a\in\ZZ_3$, $f(a)=g(a)$.

::: pf-proof

::: pf-step
At $a=0$, $f(0)=g(0)=0$.

::: pf-proof
Substitution gives $f(0)=0^{4}+0=0$ and $g(0)=0^{2}+0=0$.
:::

:::

::: pf-step
At $a=1$, $f(1)=g(1)=2$.

::: pf-proof
Substitution gives $f(1)=1^{4}+1=2$ and $g(1)=1^{2}+1=2$.
:::

:::

::: pf-step
At $a=2$, $f(2)=g(2)=0$ in $\ZZ_3$.

::: pf-proof
Since $2^{4}+2=18\equiv0\pmod3$ and $2^{2}+2=6\equiv0\pmod3$, both values equal $0$ in $\ZZ_3$.
:::

:::

:::

:::

::: pf-step
The distinct polynomials $f$ and $g$ define the same function $\ZZ_3\to\ZZ_3$.

::: pf-proof
Every element of $\ZZ_3$ is one of $0,1,2$, and step [](#evaluations){.pf-ref} checks all three cases. This exhaustiveness proves $f(a)=g(a)$ for every $a$ in the domain, so the induced functions are equal, although step [](#distinct){.pf-ref} proves the polynomials themselves are not.
:::

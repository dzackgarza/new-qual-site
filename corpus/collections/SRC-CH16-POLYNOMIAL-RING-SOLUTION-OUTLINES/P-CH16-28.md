::: {.problem}
Let $f(x) \in \RR[x]$. Suppose that $f(a) = 0$ but $f'(a) \ne 0$, where $f'(x)$ is the derivative of $f(x)$. Show that $a$ is a zero of $f(x)$ of multiplicity $1$.
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **Gallian, *Contemporary Abstract Algebra*, seventh edition, Chapter 16 solution outlines, exercise 28** (`assets/attachments/Ch16Sltns.pdf`), restructured into steps; the definition of multiplicity that the outline uses from the start is stated first.

::: pf

::: {.pf-step #mult}
$a$ is a zero of $f$ of multiplicity exactly $k$ when $(x-a)^{k}$ divides $f$ and $(x-a)^{k+1}$ does not.

::: pf-proof
This is the definition: the multiplicity is the largest $k\ge1$ with $(x-a)^{k}\mid f$, and such a $k$ exists precisely because $f(a)=0$, that is $(x-a)\mid f$.
:::

:::

::: {.pf-step #k}
$f(a)=0$ gives $k\ge1$; suppose $k\ge2$.

::: pf-proof
$f(a)=0$ means $(x-a)\mid f$, so $k\ge1$; the supposition that $a$ is not a simple zero is $k\ge2$.
:::

:::

::: {.pf-step #factor}
$f(x)=(x-a)^{k}g(x)$ for some $g\in\RR[x]$ with $g(a)\ne0$.

::: pf-proof
This is the definition of multiplicity $k$: $(x-a)^{k}$ divides $f$, and the quotient is not divisible by $x-a$ any further, so $g(a)\ne0$.
:::

:::

::: {.pf-step #derivative}
$f'(x)=(x-a)^{k-1}\bigl(k\,g(x)+(x-a)g'(x)\bigr)$.

::: pf-proof
Differentiate the product $f=(x-a)^{k}g$ with the product and chain rules: $f'=k(x-a)^{k-1}g+(x-a)^{k}g'=(x-a)^{k-1}\bigl(kg+(x-a)g'\bigr)$.
:::

:::

::: {.pf-step #contradiction}
$f'(a)=0$, contradicting the hypothesis.

::: pf-proof
Since $k\ge2$, the exponent $k-1$ is at least $1$, so the factor $(x-a)^{k-1}$ vanishes at $x=a$; hence $f'(a)=0$. The hypothesis is $f'(a)\ne0$.
:::

:::

::: {.pf-step}
The zero has multiplicity $1$.

::: pf-proof
The supposition $k\ge2$ is impossible by step [](#contradiction){.pf-ref}, so $k=1$:
$$
\boxed{f(a)=0\text{ and }f'(a)\ne0\implies a\text{ is a zero of multiplicity }1.}
$$
The converse also holds and is not used: if $k=1$ then $f=(x-a)g$ with $g(a)\ne0$, so $f'(a)=g(a)\ne0$.
:::

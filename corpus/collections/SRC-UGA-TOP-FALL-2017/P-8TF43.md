::: problem
Prove that, if $n\neq 2$, then $\RR^2$ and $\RR^n$ are not homeomorphic.
:::

::: {.solution}
Assume $n\ge1$.
Suppose, toward a contradiction, that there is a homeomorphism
\[
h:\RR^2\longrightarrow\RR^n.
\]
Set
\[
q=h(0).
\]

<1>1. The map $h$ restricts to a homeomorphism
\[
\RR^2\setminus\{0\}
\longrightarrow
\RR^n\setminus\{q\}.
\]
::: {.proof}
Since $h$ is bijective, the only point mapped to $q=h(0)$ is $0$.
Therefore
\[
h\bigl(\RR^2\setminus\{0\}\bigr)
=\RR^n\setminus\{q\}.
\]
The restriction of a homeomorphism to these corresponding subspaces is again a homeomorphism.
:::

<1>2. One has
\[
H_1(\RR^2\setminus\{0\};\ZZ)\cong\ZZ.
\]
::: {.proof}
Radial projection gives a deformation retraction
\[
\RR^2\setminus\{0\}\simeq S^1.
\]
Hence
\[
H_1(\RR^2\setminus\{0\};\ZZ)
\cong H_1(S^1;\ZZ)
\cong\ZZ.
\]
:::

<1>3. If $n\neq2$, then
\[
H_1(\RR^n\setminus\{q\};\ZZ)=0.
\]
::: {.proof}
Translation identifies $\RR^n\setminus\{q\}$ with $\RR^n\setminus\{0\}$, and radial projection gives a deformation retraction
\[
\RR^n\setminus\{0\}\simeq S^{n-1}.
\]
Therefore
\[
H_1(\RR^n\setminus\{q\};\ZZ)
\cong H_1(S^{n-1};\ZZ).
\]
For $n=1$, the sphere $S^0$ has zero first homology.
For $n\ge3$, the sphere $S^{n-1}$ has dimension at least $2$, so again
\[
H_1(S^{n-1};\ZZ)=0.
\]
Thus the first homology group vanishes for every positive integer $n\neq2$.
:::

<1>4. The assumed homeomorphism cannot exist.
::: {.proof}
By <1>1, the punctured spaces would be homeomorphic, so their first homology groups would be isomorphic.
But <1>2 and <1>3 give
\[
\ZZ
\cong H_1(\RR^2\setminus\{0\};\ZZ)
\not\cong
H_1(\RR^n\setminus\{q\};\ZZ)
=0.
\]
This contradiction proves that $\RR^2$ and $\RR^n$ are not homeomorphic for $n\neq2$.
:::

If the convention $\RR^0=\{0\}$ is allowed, the case $n=0$ is immediate because $\RR^0$ has one point whereas $\RR^2$ has more than one point.
:::

::: {.problem}
Show that the $n \times n$ (Cauchy) matrix with entries $1 / ( x _ { i } - y _ { j } )$ has determinant

$$
\frac { \prod _ { 1 \leq j < i \leq n } ( x _ { i } - x _ { j } ) ( y _ { j } - y _ { i } ) } { \prod _ { 1 \leq i , j \leq n } ( x _ { i } - y _ { j } ) }
$$
:::

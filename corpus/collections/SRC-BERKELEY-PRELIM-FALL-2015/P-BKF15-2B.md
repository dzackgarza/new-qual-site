::: {.problem}
Let $f \colon [ 0 , \infty )  \mathbb { R }$ be a function, and assume that:

• f is continuous on $[ 0 , \infty )$

• f is differentiable on $( 0 , \infty )$

$f ^ { \prime } ( x ) \leq 0$ for all $x > 0$ such that $f ( x ) > 1$ ; and

$f ( 0 ) = 1$

Prove that $f ( x ) \leq 1$ for all $x \geq 0$
:::

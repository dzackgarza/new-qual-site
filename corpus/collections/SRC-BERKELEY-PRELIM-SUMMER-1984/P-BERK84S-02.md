::: {.problem}
Let Z be the ring of integers and $\mathbb { Z } [ x ]$ the polynomial ring over Z. Show that

$$
x ^ { 6 } + 5 3 9 x ^ { 5 } - 5 1 1 x + 8 4 7
$$

is irreducible in $\mathbb { Z } [ x ]$

::: {.problem}
Let $f : \mathbb { R } ^ { m }  \mathbb { R } ^ { n } , n \geqslant 2$ , be a linear transformation of rank $n - 1$ . Let $f ( v ) = ( f _ { 1 } ( v ) , f _ { 2 } ( v ) , \ldots , f _ { n } ( v ) )$ for $v \in \mathbb { R } ^ { m }$ . Show that a necessary and sufficient condition for the system of inequalities $f _ { i } ( v ) > 0 , i = 1 , . . . , n _ { i }$ , to have no solution is that there exist real numbers $\lambda _ { i } \geqslant 0$ , not all zero, such that

$$
\sum _ { i = 1 } ^ { n } \lambda _ { i } f _ { i } = 0 .
$$

::: {.problem}
Show there is a unique continuous real valued function $f :$ $[ 0 , 1 ] \to \mathbb { R }$ such that

$$
f ( x ) = \sin x + \int _ { 0 } ^ { 1 } { \frac { f ( y ) } { e ^ { x + y + 1 } } } d y .
$$
:::

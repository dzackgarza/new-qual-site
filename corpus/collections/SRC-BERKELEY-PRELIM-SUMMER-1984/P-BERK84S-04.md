::: {.problem}
Let

$$
A = { \binom { a b } { c d } }
$$

be a real matrix with $a , b , c , d > 0$ . Show that A has an eigenvector

$$
{ \binom { x } { y } } \in \mathbb { R } ^ { 2 }
$$

with x, $y > 0$
:::

::: {.problem}
Show that $\mathbb { R P } ^ { 2 n } , \mathbb { C P } ^ { 2 n }$ are fixed-point free spaces.
:::

::: {.solution}

The source phrase is interpreted as saying that these spaces admit no fixed-point-free self-map, i.e. they have the fixed-point property. This is proved by the Lefschetz fixed-point theorem.

::: pf

::: {.pf-step #s1-1}

Let
\[
f:\mathbb{RP}^{2n}\to\mathbb{RP}^{2n}
\]
be any continuous map. With rational coefficients,
\[
H_k(\mathbb{RP}^{2n};\QQ)=0
\quad(k>0),
\qquad
H_0(\mathbb{RP}^{2n};\QQ)=\QQ.
\]


::: pf-proof

The integral homology of $\mathbb{RP}^{2n}$ has only $2$-torsion in positive degrees below the top, and the top integral homology vanishes because $\mathbb{RP}^{2n}$ is nonorientable. Tensoring with $\QQ$ kills all positive-degree homology. Connectedness gives $H_0\cong\QQ$.

:::

:::

::: {.pf-step #s1-2}

Hence
\[
L(f)=1.
\]


::: pf-proof

The Lefschetz number is
\[
L(f)=\sum_k(-1)^k\operatorname{tr}
\bigl(f_*:H_k(\mathbb{RP}^{2n};\QQ)\to
H_k(\mathbb{RP}^{2n};\QQ)\bigr).
\]
By step [](#s1-1){.pf-ref} only degree $0$ contributes, and every self-map of a connected space induces the identity on $H_0$.

:::

:::

::: {.pf-step #s1-3}

Therefore every self-map of $\mathbb{RP}^{2n}$ has a fixed point.


::: pf-proof

By step [](#s1-2){.pf-ref}, $L(f)=1\ne0$. The Lefschetz fixed-point theorem therefore implies that $f$ has a fixed point.

:::

:::

::: pf-step

Let
\[
g:\mathbb{CP}^{2n}\to\mathbb{CP}^{2n}
\]
be any continuous map, and let $u\in H^2(\mathbb{CP}^{2n};\ZZ)$ be the standard generator. There is an integer $d$ such that
\[
g^*u=du.
\]


::: pf-proof

The group $H^2(\mathbb{CP}^{2n};\ZZ)$ is infinite cyclic generated by $u$, so every endomorphism is multiplication by a unique integer $d$.

:::

:::

::: {.pf-step #s1-5}

On $H^{2k}(\mathbb{CP}^{2n};\QQ)$, the map $g^*$ is multiplication by $d^k$.


::: pf-proof

The cohomology ring is
\[
H^*(\mathbb{CP}^{2n};\ZZ)
\cong\ZZ[u]/(u^{2n+1}),
\qquad |u|=2.
\]
Thus $u^k$ generates $H^{2k}$ and
\[
g^*(u^k)=(g^*u)^k=(du)^k=d^ku^k.
\]

:::

:::

::: {.pf-step #s1-6}

Consequently
\[
L(g)=1+d+d^2+\cdots+d^{2n}.
\]


::: pf-proof

Complex projective space has one-dimensional rational cohomology in even degrees $0,2,\ldots,4n$ and zero cohomology in odd degrees. By step [](#s1-5){.pf-ref} the traces in those degrees are $1,d,\ldots,d^{2n}$, and every sign in the Lefschetz sum is positive.

:::

:::

::: {.pf-step #s1-7}

For every integer $d$,
\[
1+d+d^2+\cdots+d^{2n}>0.
\]


::: pf-proof

If $d\geq0$, this is immediate. If $d<0$, write $d=-a$ with $a\geq1$. Then
\[
1-a+a^2-a^3+\cdots-a^{2n-1}+a^{2n}
=1+(a^2-a)+(a^4-a^3)+\cdots+(a^{2n}-a^{2n-1}),
\]
and every parenthesized term is $a^{2j-1}(a-1)\geq0$. Thus the sum is at least $1$.

:::

:::

::: {.pf-step #s1-8}

Therefore every self-map of $\mathbb{CP}^{2n}$ has a fixed point.


::: pf-proof

Steps [](#s1-6){.pf-ref} through [](#s1-7){.pf-ref} give $L(g)\ne0$, so the Lefschetz fixed-point theorem applies.

:::

:::

::: {.pf-step #s1-9}

Hence
\[
\boxed{
\mathbb{RP}^{2n}\text{ and }\mathbb{CP}^{2n}
\text{ admit no fixed-point-free self-map}.}
\]


::: pf-proof

This combines steps [](#s1-3){.pf-ref} and [](#s1-8){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-9){.pf-ref} is the asserted fixed-point property.

:::

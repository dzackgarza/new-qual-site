::: {.problem}
Show that $\mathbb { R } \mathbb { P } ^ { 2 k + 1 }$ cannot be a boundary.
:::

::: {.solution}
The literal statement is false. In fact every odd-dimensional real projective
space is a boundary. The standard nonboundary statement is the
even-dimensional one.

<1>1. Regard
\[
S^{2k+1}
\subset
\mathbb C^{k+1}
\]
and define
\[
R:S^{2k+1}\to S^{2k+1},
\qquad
R(z)=iz.
\]
Then $R$ descends to a smooth involution
\[
T:\mathbb{RP}^{2k+1}\to\mathbb{RP}^{2k+1}.
\]

::: {.proof}
If $z$ and $-z$ represent the same real projective point, then
\[
R(-z)=-iz=-R(z),
\]
so $R$ respects the antipodal equivalence relation and therefore descends
to a smooth map $T$ on projective space.

Moreover,
\[
R^2(z)=-z.
\]
The vectors $z$ and $-z$ define the same point of real projective space,
so
\[
T^2=\operatorname{id}_{\mathbb{RP}^{2k+1}}.
\]
Thus $T$ is an involution.
:::

<1>2. The involution $T$ has no fixed point.

::: {.proof}
Suppose
\[
T([z])=[z].
\]
Then
\[
[iz]=[z]
\]
in real projective space, so there is a nonzero real scalar
\[
\lambda\in\mathbb R
\]
such that
\[
iz=\lambda z.
\]
Since $z\ne0$, this would imply
\[
i=\lambda,
\]
which is impossible because $lambda$ is real. Hence $T$ is fixed-point
free.
:::

<1>3. If a closed smooth manifold $M$ admits a fixed-point-free smooth
involution $T$, then $M$ is the boundary of a compact smooth manifold.

::: {.proof}
Let
\[
\tau:M\times[-1,1]\to M\times[-1,1]
\]
be
\[
\tau(x,t)=(T(x),-t).
\]
Because $T$ is an involution,
\[
\tau^2=\operatorname{id}.
\]
If $\tau(x,t)=(x,t)$, then $t=0$ and $T(x)=x$, contrary to the
fixed-point-free hypothesis. Thus the action generated by $\tau$ is free.

Set
\[
W
\coloneqq
\bigl(M\times[-1,1]\bigr)/\langle\tau\rangle.
\]
A free action of a finite group on a smooth manifold gives a smooth quotient,
so $W$ is a compact smooth manifold.

The boundary of $M\times[-1,1]$ is
\[
M\times\{-1\}
\sqcup
M\times\{1\}.
\]
The involution exchanges these two components by
\[
(x,1)
\longleftrightarrow
(T(x),-1).
\]
Their quotient is therefore a single copy of $M$. Hence
\[
\partial W\cong M.
\]
:::

<1>4. Consequently
\[
\boxed{
\mathbb{RP}^{2k+1}
\text{ is a boundary for every }k\ge0.
}
\]

::: {.proof}
Apply step <1>3 to the fixed-point-free involution from steps <1>1--<1>2.
:::

<1>5. Therefore the literal problem statement cannot be proved.

::: {.proof}
Step <1>4 proves the negation of the stated assertion.
:::

<1>6. The standard corrected statement is
\[
\boxed{
\mathbb{RP}^{2k}
\text{ is not the boundary of a compact manifold}.
}
\]

::: {.proof}
It remains to prove this corrected assertion in steps <1>7--<1>9.
:::

<1>7. If a closed manifold $M$ is the boundary of a compact manifold,
then
\[
\chi(M)
\]
is even.

::: {.proof}
Suppose
\[
M=\partial W,
\qquad
\dim W=m.
\]
Work with coefficients in $mathbb F_2$, so orientability is irrelevant.
Poincaré--Lefschetz duality gives
\[
H_i(W,M;\mathbb F_2)
\cong
H^{m-i}(W;\mathbb F_2).
\]
Taking alternating dimensions yields
\[
\chi(W,M)
=
(-1)^m\chi(W).
\]

The long exact sequence of the pair gives Euler-characteristic additivity:
\[
\chi(W)
=
\chi(M)+\chi(W,M).
\]
Hence
\[
\chi(M)
=
\bigl(1-(-1)^m\bigr)\chi(W).
\]
The coefficient
\[
1-(-1)^m
\]
is either $0$ or $2$, so $chi(M)$ is even.
:::

<1>8. One has
\[
\chi(\mathbb{RP}^{2k})=1.
\]

::: {.proof}
The standard CW structure on $mathbb{RP}^{2k}$ has exactly one cell in
each dimension
\[
0,1,\dots,2k.
\]
Therefore
\[
\chi(\mathbb{RP}^{2k})
=
\sum_{j=0}^{2k}(-1)^j
=
1.
\]
:::

<1>9. Thus $\mathbb{RP}^{2k}$ cannot be a boundary.

::: {.proof}
If
\[
\mathbb{RP}^{2k}=\partial W
\]
for some compact manifold $W$, step <1>7 would make
\[
\chi(\mathbb{RP}^{2k})
\]
even. Step <1>8 says it equals $1$, a contradiction.
:::

<1>10. Q.E.D.

::: {.proof}
Steps <1>1--<1>5 refute the literal source statement by constructing a
bounding manifold for every $\mathbb{RP}^{2k+1}$. Steps <1>6--<1>9 prove
the standard corrected even-dimensional statement.
:::
:::

::: {.problem}
Calculate the integral homology of any compact, oriented, boundaryless manifold $N^n$, which admits a continuous map $f : S^n \to N^n$ with $f_*([S^n]) = [N]$.
:::

::: {.solution}

::: pf

::: pf-step
Cap product naturality and Poincaré duality:

::: pf-proof

::: pf-step
Let $N^n$ be a compact, connected, orientable $n$-manifold without boundary, with fundamental class $[N] \in H_n(N; \mathbb{Z})$, and let $f: S^n \to N^n$ satisfy $f_*([S^n]) = [N]$.

::: pf-proof
setup.
:::

:::

::: {.pf-step #s1-2}
By the projection formula relating cap products and pushforward/pullback:
\[
f_*\big(f^*(\alpha) \frown [S^n]\big) = \alpha \frown f_*([S^n]) = \alpha \frown [N] \quad \text{for all } \alpha \in H^k(N; \mathbb{Z}).
\]

::: pf-proof
naturality of cap products under continuous maps.
:::

:::

::: {.pf-step #s1-3}
By Poincaré Duality, the cap product homomorphism $D_N: H^k(N; \mathbb{Z}) \to H_{n-k}(N; \mathbb{Z})$ defined by $D_N(\alpha) = \alpha \frown [N]$ is an isomorphism for all $k$.

::: pf-proof
Poincaré Duality Theorem for closed oriented manifolds.
:::

:::

::: pf-step
The identity in step [](#s1-2){.pf-ref} reads:
\[
f_* \circ D_{S^n} \circ f^* = D_N.
\]
Because $D_N$ is an isomorphism, the pullback map on cohomology:
\[
f^*: H^k(N; \mathbb{Z}) \hookrightarrow H^k(S^n; \mathbb{Z})
\]
must be injective for every $k$.

::: pf-proof
if a composition $A \circ B \circ C$ is injective, then $C$ is injective.
:::

:::

:::

:::

::: {.pf-step #s2}
Vanishing of intermediate homology groups:

::: pf-proof

::: pf-step
The cohomology of the $n$-sphere is:
\[
H^k(S^n; \mathbb{Z}) \cong \begin{cases}
\mathbb{Z} & k = 0, n, \\
0 & 1 \le k \le n-1.
\end{cases}
\]

::: pf-proof
cellular cohomology of $S^n$.
:::

:::

::: {.pf-step #s2-2}
For any intermediate degree $1 \le k \le n - 1$: Since $f^*: H^k(N; \mathbb{Z}) \hookrightarrow H^k(S^n; \mathbb{Z}) = 0$ is injective, $H^k(N; \mathbb{Z}) = 0$.

::: pf-proof
injectivity into the trivial group implies triviality.
:::

:::

::: pf-step
Applying Poincaré Duality $H_{n-k}(N; \mathbb{Z}) \cong H^k(N; \mathbb{Z}) = 0$, we have $H_m(N; \mathbb{Z}) = 0$ for all $1 \le m \le n - 1$.

::: pf-proof
Step [](#s1-3){.pf-ref} and step [](#s2-2){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s3}
Homology in degrees $0$ and $n$:

::: pf-proof

::: pf-step
In degree $0$, since $S^n$ is path-connected and $f(S^n) = N$, $N$ is path-connected, so $H_0(N; \mathbb{Z}) \cong \mathbb{Z}$.

::: pf-proof
path-connectedness.
:::

:::

::: pf-step
In degree $n$, $H_n(N; \mathbb{Z}) \cong \mathbb{Z}$, generated by the fundamental class $[N] = f_*([S^n])$.

::: pf-proof
closed orientable $n$-manifold has $H_n \cong \mathbb{Z}$.
:::

:::

::: pf-step
For $k > n$, $H_k(N; \mathbb{Z}) = 0$ since $N$ is an $n$-dimensional manifold.

::: pf-proof
dimension of manifold.
:::

:::

:::

:::

::: pf-step
Conclusion: The integral homology of $N$ is that of an $n$-sphere:
\[
H_k(N; \mathbb{Z}) \cong \begin{cases}
\mathbb{Z} & k = 0, n, \\
0 & \text{otherwise.}
\end{cases}
\]

::: pf-proof
Steps [](#s2){.pf-ref} and [](#s3){.pf-ref}.
:::

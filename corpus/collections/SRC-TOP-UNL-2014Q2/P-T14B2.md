::: {.problem}
Let $p:\widetilde X\to X$ be a covering space with $\widetilde X$ path-connected.
Let $A$ be a subspace of $X$ with inclusion map $i:A\hookrightarrow X$, and suppose that for $a\in A$ the induced homomorphism $i_*:\pi_1(A,a)\to\pi_1(X,a)$ is a surjection.
Show that if $r,s\in\widetilde X$ and $p(r)=p(s)=a$, then there is a path from $r$ to $s$ in the subspace $p^{-1}(A)$ of $\widetilde X$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

There is a path
\[
\widetilde\alpha:[0,1]\longrightarrow\widetilde X
\]
from $r$ to $s$.

::: pf-proof

The covering space $\widetilde X$ is path-connected by hypothesis, so any two of its points can be joined by a path.
Apply this to $r$ and $s$.

:::

:::

::: {.pf-step #s2}

The projected path
\[
\alpha=p\circ\widetilde\alpha
\]
is a loop in $X$ based at $a$.

::: pf-proof

Using step [](#s1){.pf-ref} and the hypotheses on $r,s$,
\[
\alpha(0)=p(r)=a
\qquad\text{and}\qquad
\alpha(1)=p(s)=a.
\]
Thus $\alpha$ begins and ends at $a$.

:::

:::

::: {.pf-step #s3}

There is a loop
\[
\beta:[0,1]\longrightarrow A
\]
based at $a$ whose image in $\pi_1(X,a)$ is $[\alpha]$.

::: pf-proof

Surjectivity of
\[
i_*:\pi_1(A,a)\longrightarrow\pi_1(X,a)
\]
implies that the class $[\alpha]\in\pi_1(X,a)$ is $i_*[\beta]$ for some class $[\beta]\in\pi_1(A,a)$.
Choose a loop $\beta$ in $A$ representing that class.
Viewed as a loop in $X$ through the inclusion $i$, it satisfies
\[
[i\circ\beta]=[\alpha].
\]

:::

:::

::: {.pf-step #s4}

There is a homotopy
\[
H:[0,1]\times[0,1]\longrightarrow X
\]
such that
\[
H(t,0)=\alpha(t),
\qquad
H(t,1)=\beta(t),
\]
and
\[
H(0,u)=H(1,u)=a
\]
for every $u\in[0,1]$.

::: pf-proof

By step [](#s3){.pf-ref}, the loops $\alpha$ and $\beta$ represent the same element of $\pi_1(X,a)$.
By definition of equality in the fundamental group, they are homotopic relative to the basepoint, which is exactly the stated homotopy.

:::

:::

::: {.pf-step #s5}

The homotopy $H$ has a unique lift
\[
\widetilde H:[0,1]\times[0,1]\longrightarrow\widetilde X
\]
with
\[
\widetilde H(t,0)=\widetilde\alpha(t).
\]

::: pf-proof

The identity
\[
p\circ\widetilde\alpha=\alpha=H(-,0)
\]
holds by steps [](#s2){.pf-ref} and [](#s4){.pf-ref}. The homotopy lifting theorem for covering maps therefore lifts $H$ uniquely once its lift along the initial edge $[0,1]\times\{0\}$ is prescribed as $\widetilde\alpha$.

:::

:::

::: {.pf-step #s6}

For every $u\in[0,1]$,
\[
\widetilde H(0,u)=r
\qquad\text{and}\qquad
\widetilde H(1,u)=s.
\]

::: pf-proof

By steps [](#s4){.pf-ref} and [](#s5){.pf-ref},
\[
p(\widetilde H(0,u))=H(0,u)=a,
\]
so the path
\[
u\longmapsto\widetilde H(0,u)
\]
lies entirely in the fiber $p^{-1}(a)$.
A fiber of a covering map is discrete: if $U$ is an evenly covered neighborhood of $a$, each sheet over $U$ contains at most one point of $p^{-1}(a)$, so every fiber point is isolated in the fiber subspace.
The continuous image of the connected interval $[0,1]$ in a discrete space is a singleton.
At $u=0$ this path equals
\[
\widetilde H(0,0)=\widetilde\alpha(0)=r,
\]
so it is constantly $r$.

The same argument applied to
\[
u\longmapsto\widetilde H(1,u)
\]
shows it is constant in $p^{-1}(a)$; at $u=0$ it equals
\[
\widetilde\alpha(1)=s.
\]
Hence it is constantly $s$.

:::

:::

::: pf-step

The path
\[
\widetilde\beta(t)=\widetilde H(t,1)
\]
joins $r$ to $s$ and lies in $p^{-1}(A)$.

::: pf-proof

By step [](#s6){.pf-ref},
\[
\widetilde\beta(0)=r,
\qquad
\widetilde\beta(1)=s.
\]
Moreover steps [](#s4){.pf-ref} and [](#s5){.pf-ref} give
\[
p(\widetilde\beta(t))
=
p(\widetilde H(t,1))
=
H(t,1)
=
\beta(t).
\]
Since $\beta(t)\in A$ for every $t$ by step [](#s3){.pf-ref},
\[
\widetilde\beta(t)\in p^{-1}(A)
\]
for every $t$.
Thus $\widetilde\beta$ is the required path in $p^{-1}(A)$ from $r$ to $s$.

:::

::: {.problem}
Let $G$ be a finite elementary abelian $p$-group.
Show that $\Phi(G)=1$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is the problem sheet alone, so the argument is the card's own. Let $G$ be a finite elementary abelian $p$-group, so that $G\cong C_p^d$ for some $d\ge0$, and let $\Phi(G)$ be its Frattini subgroup, the intersection of all maximal subgroups.

::: pf

::: {.pf-step #coordinates}
Identify $G$ with $C_p^d$, and for $1\le i\le d$ let $M_i=\{x\in C_p^d:x_i=0\}$.

::: pf-proof
An elementary abelian $p$-group is a finite abelian group in which every nonzero element has order $p$, so it is a vector space over the field $F_p$; choosing a basis gives $G\cong C_p^d$. Under this identification the sets $M_i$ above are subgroups, being the kernels of the coordinate projections.
:::

:::

::: {.pf-step #maximal}
Each $M_i$ is a maximal subgroup of $G$, and $\bigcap_{i=1}^{d}M_i=1$.

::: pf-proof
$G/M_i\cong C_p$ has order $p$, so $[G:M_i]=p$. A subgroup of prime index is maximal: if $M_i\le H\le G$ then $[G:M_i]=[G:H][H:M_i]$ forces $[G:H]=1$ or $[G:H]=p$, that is $H=G$ or $H=M_i$. For the intersection: a vector lying in every $M_i$ has all coordinates zero, so it is the identity.
:::

:::

::: {.pf-step #frattini}
$\Phi(G)=1$.

::: pf-proof
$\Phi(G)$ is the intersection of all maximal subgroups, so $\Phi(G)\subseteq\bigcap_iM_i$ because the $M_i$ are among the maximal subgroups by step [](#maximal){.pf-ref}; that intersection is trivial by the same step, hence $\Phi(G)=1$. The reverse inclusion is automatic since $1$ lies in every subgroup. Since finite groups have maximal subgroups (a proper subgroup of largest order is maximal), the family being intersected is nonempty and the definition applies.
:::

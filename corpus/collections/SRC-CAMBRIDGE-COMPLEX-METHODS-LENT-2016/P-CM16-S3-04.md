::: {.problem}
Show that the convolution of the function $e ^ { - \abs{ x } }$ with itself is given by $f ( x ) = ( 1 + \abs{ x } ) e ^ { - \abs{ x } }$ . Use the convolution theorem to show that

$$
f ( x ) = { \frac { 2 } { \pi } } \int _ { - \infty } ^ { \infty } { \frac { e ^ { i k x } } { ( 1 + k ^ { 2 } ) ^ { 2 } } } \mathrm { d } k
$$

and verify this result by contour integration.
:::

::: {.solution}

Let
$$
h(x)=e^{-\abs{x}}.
$$

::: pf

::: {.pf-step #s1-1}

The self-convolution of $h$ is
$$
\boxed{
(h*h)(x)=(1+\abs{x})e^{-\abs{x}}}.
$$


::: pf-proof

Both $h$ and $h*h$ are even, so it suffices to take $x\geq0$. Split the convolution integral at $t=0$ and $t=x$:
$$
(h*h)(x)
=\int_{-\infty}^0 e^t e^{-(x-t)}\,dt
+\int_0^x e^{-t}e^{-(x-t)}\,dt
+\int_x^\infty e^{-t}e^{-(t-x)}\,dt.
$$
The three terms are respectively
$$
\frac12e^{-x},
\qquad
xe^{-x},
\qquad
\frac12e^{-x}.
$$
Their sum is $(1+x)e^{-x}$. Evenness replaces $x$ by $\abs{x}$ for arbitrary real $x$.

:::

:::

::: {.pf-step #s1-2}

The Fourier transform of $h$ is
$$
\widetilde h(k)=\frac2{1+k^2}.
$$


::: pf-proof

This is step [](#s1-1){.pf-ref} of the preceding Fourier-transform card with $a=1$:
$$
\int_{-\infty}^{\infty}e^{-\abs{x}}e^{-ikx}\,dx
=\frac2{1+k^2}.
$$
It also follows directly by splitting the integral at $0$.

:::

:::

::: {.pf-step #s1-3}

The convolution theorem and Fourier inversion give
$$
\boxed{
f(x)
=\frac2\pi
\int_{-\infty}^{\infty}
\frac{e^{ikx}}{(1+k^2)^2}\,dk},
$$
where $f=h*h=(1+\abs{x})e^{-\abs{x}}$.


::: pf-proof

By the convolution theorem and step [](#s1-2){.pf-ref},
$$
\widetilde f(k)
=\widetilde h(k)^2
=\frac4{(1+k^2)^2}.
$$
Since this transform is integrable, Fourier inversion gives
$$
f(x)
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{4e^{ikx}}{(1+k^2)^2}\,dk,
$$
which is the displayed formula.

:::

:::

::: {.pf-step #s1-4}

For $x\geq0$,
$$
\int_{-\infty}^{\infty}
\frac{e^{ikx}}{(1+k^2)^2}\,dk
=\frac\pi2(1+x)e^{-x}.
$$


::: pf-proof

For $x\geq0$, integrate
$$
F(z)=\frac{e^{izx}}{(1+z^2)^2}
$$
over the upper semicircle. On the arc, $\abs{e^{izx}}\leq1$ and the denominator has size $O(R^4)$, so the arc integral is $O(R^{-3})$ and tends to $0$.

The only enclosed pole is the double pole at $z=i$. Its residue is
$$
\operatorname{Res}_{z=i}F(z)
=\evaluated{
\frac d{dz}
\left(
\frac{e^{izx}}{(z+i)^2}
\right)
}_{z=i}.
$$
Thus
$$
\operatorname{Res}_{z=i}F(z)
=
e^{-x}
\left[
\frac{ix}{(2i)^2}
-\frac2{(2i)^3}
\right]
=-\frac i4(1+x)e^{-x}.
$$
The residue theorem therefore gives
$$
\int_{-\infty}^{\infty}
\frac{e^{ikx}}{(1+k^2)^2}\,dk
=2\pi i
\left(
-\frac i4(1+x)e^{-x}
\right)
=\frac\pi2(1+x)e^{-x}.
$$

:::

:::

::: {.pf-step #s1-5}

The contour evaluation in step [](#s1-4){.pf-ref} verifies the formula in step [](#s1-3){.pf-ref} for every real $x$.


::: pf-proof

Changing variables $k\mapsto-k$ shows that
$$
\int_{-\infty}^{\infty}
\frac{e^{ikx}}{(1+k^2)^2}\,dk
$$
is an even function of $x$. Hence step [](#s1-4){.pf-ref} yields
$$
\int_{-\infty}^{\infty}
\frac{e^{ikx}}{(1+k^2)^2}\,dk
=\frac\pi2(1+\abs{x})e^{-\abs{x}}.
$$
Multiplication by $2/\pi$ gives $(1+\abs{x})e^{-\abs{x}}$, exactly as in step [](#s1-1){.pf-ref}.

:::

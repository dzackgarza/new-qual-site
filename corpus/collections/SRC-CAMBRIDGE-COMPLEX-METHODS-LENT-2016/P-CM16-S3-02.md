::: {.problem}
Using the results of the previous question and Parseval’s identity, evaluate the integrals

$$
\int _ { - \infty } ^ { \infty } \frac { \sin ^ { 2 } x } { x ^ { 2 } } \mathrm { d } x \quad \mathrm { a n d } \quad \int _ { - \infty } ^ { \infty } \frac { \sin ^ { 4 } x } { x ^ { 4 } } \mathrm { d } x .
$$
:::

::: {.solution}

For the convention used in the preceding card, Parseval's identity is
$$
\int_{-\infty}^{\infty}\abs{h(x)}^2\,dx
=\frac1{2\pi}
\int_{-\infty}^{\infty}\abs{\widetilde h(k)}^2\,dk.
$$

::: pf

::: {.pf-step #s1-1}

One has
$$
\boxed{
\int_{-\infty}^{\infty}
\frac{\sin^2x}{x^2}\,dx
=\pi}.
$$


::: pf-proof

For the box function $f$ from the preceding card,
$$
\int_{-\infty}^{\infty}\abs{f(x)}^2\,dx=a
$$
and
$$
\widetilde f(k)
=\frac2k\sin\frac{ak}{2}.
$$
Parseval therefore gives
$$
a
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{4\sin^2(ak/2)}{k^2}\,dk.
$$
With $x=ak/2$,
$$
a
=\frac a\pi
\int_{-\infty}^{\infty}
\frac{\sin^2x}{x^2}\,dx.
$$
Since $a>0$, division by $a$ yields the claim.

:::

:::

::: {.pf-step #s1-2}

One has
$$
\boxed{
\int_{-\infty}^{\infty}
\frac{\sin^4x}{x^4}\,dx
=\frac{2\pi}{3}}.
$$


::: pf-proof

For the tent function $g$ from the preceding card,
$$
\int_{-\infty}^{\infty}\abs{g(x)}^2\,dx
=2\int_0^a(a-x)^2\,dx
=\frac{2a^3}{3},
$$
while
$$
\widetilde g(k)
=\frac4{k^2}\sin^2\frac{ak}{2}.
$$
Parseval gives
$$
\frac{2a^3}{3}
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{16\sin^4(ak/2)}{k^4}\,dk.
$$
Again substituting $x=ak/2$ gives
$$
\frac{2a^3}{3}
=\frac{a^3}{\pi}
\int_{-\infty}^{\infty}
\frac{\sin^4x}{x^4}\,dx.
$$
Division by $a^3$ proves the formula.

:::

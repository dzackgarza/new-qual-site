::: {.problem}
By integrating the function $z ^ { n } ( z - a ) ^ { - 1 } ( z - a ^ { - 1 } ) ^ { - 1 }$ around the unit circle in the z-plane (where a is real, $a > 1$, and n is a non-negative integer), evaluate

$$
\int _ { 0 } ^ { 2 \pi } { \frac { \cos n \theta } { 1 - 2 a \cos \theta + a ^ { 2 } } } \mathrm { d } \theta .
$$
:::

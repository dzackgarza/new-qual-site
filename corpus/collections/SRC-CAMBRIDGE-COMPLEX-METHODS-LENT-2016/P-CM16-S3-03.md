::: {.problem}
By using the relationship between the Fourier transform and its inverse, show that for real a and b with $a > 0$ ,

$$
e ^ { - a \abs{ t } } = { \frac { a } { \pi } } \int _ { - \infty } ^ { \infty } { \frac { 1 } { \omega ^ { 2 } + a ^ { 2 } } } e ^ { i \omega t } \mathrm { d } \omega \quad { \mathrm { a n d } } \quad e ^ { - a t } \sin b t H ( t ) = { \frac { 1 } { 2 \pi } } \int _ { - \infty } ^ { \infty } { \frac { b } { ( i \omega + a ) ^ { 2 } + b ^ { 2 } } } e ^ { i \omega t } \mathrm { d } \omega
$$

where $H ( t )$ is the Heaviside step function.
What are the values of the integrals when $a < 0 ?$ What happens when $a = 0 ?$
:::

::: {.solution}

Use the convention
$$
\widetilde h(\omega)
=\int_{-\infty}^{\infty}h(t)e^{-i\omega t}\,dt,
\qquad
h(t)
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\widetilde h(\omega)e^{i\omega t}\,d\omega.
$$

::: pf

::: {.pf-step #s1-1}

If $a>0$, then
$$
\widetilde{e^{-a\abs{t}}}(\omega)
=\frac{2a}{\omega^2+a^2}.
$$


::: pf-proof

Splitting the integral at $0$ gives
$$
\widetilde{e^{-a\abs{t}}}(\omega)
=\int_0^\infty e^{-(a+i\omega)t}\,dt
+\int_0^\infty e^{-(a-i\omega)t}\,dt.
$$
Since $a>0$, both integrals converge and equal
$$
\frac1{a+i\omega}
+\frac1{a-i\omega}
=\frac{2a}{a^2+\omega^2}.
$$

:::

:::

::: {.pf-step #s1-2}

If $a>0$, Fourier inversion of step [](#s1-1){.pf-ref} gives
$$
\boxed{
e^{-a\abs{t}}
=\frac a\pi
\int_{-\infty}^{\infty}
\frac{e^{i\omega t}}{\omega^2+a^2}\,d\omega}.
$$


::: pf-proof

The function $e^{-a\abs{t}}$ and its Fourier transform from step [](#s1-1){.pf-ref} are integrable, so the Fourier inversion formula applies directly:
$$
e^{-a\abs{t}}
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{2a}{\omega^2+a^2}e^{i\omega t}\,d\omega.
$$

:::

:::

::: {.pf-step #s1-3}

If $a>0$, then
$$
\widetilde{e^{-at}\sin(bt)H(t)}(\omega)
=\frac b{(a+i\omega)^2+b^2}.
$$


::: pf-proof

The Heaviside factor restricts the transform to $t>0$, so
$$
\widetilde{e^{-at}\sin(bt)H(t)}(\omega)
=\int_0^\infty e^{-(a+i\omega)t}\sin(bt)\,dt.
$$
Using
$$
\sin(bt)=\frac{e^{ibt}-e^{-ibt}}{2i}
$$
and $a>0$,
$$
\int_0^\infty e^{-(a+i\omega)t}\sin(bt)\,dt
=\frac1{2i}
\left(
\frac1{a+i(\omega-b)}
-\frac1{a+i(\omega+b)}
\right)
=\frac b{(a+i\omega)^2+b^2}.
$$

:::

:::

::: {.pf-step #s1-4}

If $a>0$, Fourier inversion of step [](#s1-3){.pf-ref} gives
$$
\boxed{
e^{-at}\sin(bt)H(t)
=\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{b e^{i\omega t}}
{(i\omega+a)^2+b^2}\,d\omega}.
$$


::: pf-proof

The function in step [](#s1-3){.pf-ref} is integrable in $t$, and its transform is $O(\omega^{-2})$, hence integrable in $\omega$. Fourier inversion therefore gives exactly the displayed identity.

:::

:::

::: {.pf-step #s1-5}

If $a<0$, then
$$
\boxed{
\int_{-\infty}^{\infty}
\frac{e^{i\omega t}}{\omega^2+a^2}\,d\omega
=-\frac\pi a e^{a\abs{t}}},
$$
and consequently
$$
\boxed{
\frac a\pi
\int_{-\infty}^{\infty}
\frac{e^{i\omega t}}{\omega^2+a^2}\,d\omega
=-e^{a\abs{t}}}.
$$


::: pf-proof

Put $c=-a>0$. Since $a^2=c^2$, step [](#s1-2){.pf-ref} applied to $c$ gives
$$
e^{-c\abs{t}}
=\frac c\pi
\int_{-\infty}^{\infty}
\frac{e^{i\omega t}}{\omega^2+c^2}\,d\omega.
$$
Substituting $c=-a$ yields the two displayed formulas.

:::

:::

::: {.pf-step #s1-6}

If $a<0$, then
$$
\boxed{
\frac1{2\pi}
\int_{-\infty}^{\infty}
\frac{b e^{i\omega t}}
{(i\omega+a)^2+b^2}\,d\omega
=-e^{-at}\sin(bt)H(-t)}.
$$


::: pf-proof

For $a<0$, define
$$
q(t)=-e^{-at}\sin(bt)H(-t).
$$
Writing $t=-s$ on the negative half-line gives
$$
\widetilde q(\omega)
=\int_0^\infty
e^{as}\sin(bs)e^{i\omega s}\,ds.
$$
Because $a<0$, this converges. Applying the elementary Laplace integral from step [](#s1-3){.pf-ref} with decay parameter $-a>0$ and frequency $-\omega$ gives
$$
\widetilde q(\omega)
=\frac b{(-a-i\omega)^2+b^2}
=\frac b{(a+i\omega)^2+b^2}.
$$
The transform is $O(\omega^{-2})$, so Fourier inversion applies and gives the claim.

:::

:::

::: {.pf-step #s1-7}

At $a=0$, neither displayed integral in the problem is an ordinary Fourier inversion integral.


::: pf-proof

For the first integral, the kernel becomes
$$
\frac1{\omega^2},
$$
which is not locally integrable at $\omega=0$; even a symmetric principal value diverges. Thus the factor $a$ in front of the integral cannot be evaluated by simply setting $a=0$. Distributionally, the normalized kernels
$$
\frac a\pi\frac1{\omega^2+a^2}
$$
approach $\delta_0$ as $a\downarrow0$, but that is a limiting distributional statement, not an ordinary integral at $a=0$.

For the second integral, setting $a=0$ gives
$$
\frac b{b^2-\omega^2},
$$
whose poles lie on the integration line at $\omega=\pm b$ when $b\neq0$. Hence the ordinary improper integral is undefined without a prescription for passing those poles. The one-sided limits $a\downarrow0$ and $a\uparrow0$ in steps [](#s1-4){.pf-ref} and [](#s1-6){.pf-ref} give different causal prescriptions:
$$
\sin(bt)H(t)
\qquad\text{and}\qquad
-\sin(bt)H(-t),
$$
respectively. This discontinuity is exactly the consequence of the poles reaching the real axis.

:::

:::

::: {.pf-step #s1-8}

If the second integral at $a=0$ is instead interpreted as a Cauchy principal value at both real poles, then
$$
\frac1{2\pi}
\operatorname{PV}
\int_{-\infty}^{\infty}
\frac{b e^{i\omega t}}{b^2-\omega^2}\,d\omega
=\frac12\sin(bt)\operatorname{sgn}(t).
$$


::: pf-proof

For $b\neq0$,
$$
\frac b{b^2-\omega^2}
=\frac12
\left(
\frac1{b-\omega}
+\frac1{b+\omega}
\right).
$$
The contour identity
$$
\operatorname{PV}
\int_{-\infty}^{\infty}
\frac{e^{i\omega t}}{\omega-c}\,d\omega
=i\pi e^{ict}\operatorname{sgn}(t)
$$
therefore gives
$$
\operatorname{PV}
\int_{-\infty}^{\infty}
\frac{b e^{i\omega t}}{b^2-\omega^2}\,d\omega
=\pi\sin(bt)\operatorname{sgn}(t).
$$
Division by $2\pi$ yields the stated principal-value result. For $b=0$, both sides vanish.

:::

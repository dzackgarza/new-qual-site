::: {.problem}
Let $f ( z ) = ( z ^ { 2 } - 1 ) ^ { 1 / 2 }$ , and consider two different branches of the function f (z):

f1(z) : branch cut [$-$1, 1], $f _ { 1 } ( x ) = + \sqrt { x ^ { 2 } - 1 }$ for real x > 1;

f2(z) : branch cut ($-\infty$, $-$1] $\cup$ [1, $\infty$), $f _ { 2 } ( x ) = + i { \sqrt { 1 - x ^ { 2 } } }$ for real $x \in ( - 1 , 1 )$

Find the limiting values of $f _ { 1 }$ and $f _ { 2 }$ above and below their respective branch cuts.
Prove that $f _ { 1 }$ is an odd function, i.e., $f _ { 1 } ( z ) = - f _ { 1 } ( - z )$ , and that $f _ { 2 }$ is even.
:::

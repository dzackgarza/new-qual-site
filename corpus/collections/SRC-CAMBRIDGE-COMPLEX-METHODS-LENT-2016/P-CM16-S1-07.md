::: {.problem}
Let $f ( z ) = ( z ^ { 2 } - 1 ) ^ { 1 / 2 }$ , and consider two different branches of the function f (z):

f1(z) : branch cut [$-$1, 1], $f _ { 1 } ( x ) = + \sqrt { x ^ { 2 } - 1 }$ for real x > 1;

f2(z) : branch cut ($-\infty$, $-$1] $\cup$ [1, $\infty$), $f _ { 2 } ( x ) = + i { \sqrt { 1 - x ^ { 2 } } }$ for real $x \in ( - 1 , 1 )$

Find the limiting values of $f _ { 1 }$ and $f _ { 2 }$ above and below their respective branch cuts.
Prove that $f _ { 1 }$ is an odd function, i.e., $f _ { 1 } ( z ) = - f _ { 1 } ( - z )$ , and that $f _ { 2 }$ is even.
:::

::: {.solution}

For a boundary point $x$ of a cut, write
$$
f_{j,\pm}(x)=\lim_{\varepsilon\downarrow0}f_j(x\pm i\varepsilon).
$$

::: pf

::: {.pf-step #s1-1}

For $-1<x<1$, the boundary values of $f_1$ are
$$
\boxed{f_{1,\pm}(x)=\pm i\sqrt{1-x^2}}.
$$


::: pf-proof

For $x\in(-1,1)$, the limiting value of $z^2-1$ is the negative real number $x^2-1$. Hence the two possible square-root limits are
$$
\pm i\sqrt{1-x^2}.
$$
The sign is fixed by the normalization on $(1,\infty)$. Continue $f_1(x)=+\sqrt{x^2-1}$ from $x>1$ around the branch point $1$ through the upper half-plane. The argument of $z^2-1$ increases continuously from $0$ to $\pi$, so the square-root argument increases from $0$ to $\pi/2$; this gives the upper-bank value $+i\sqrt{1-x^2}$. Continuing around $1$ through the lower half-plane gives argument $-\pi$ and therefore the lower-bank value $-i\sqrt{1-x^2}$. Continuity along each bank keeps these signs for every $x\in(-1,1)$.

:::

:::

::: {.pf-step #s1-2}

For $\abs{x}>1$, the boundary values of $f_2$ are
$$
\boxed{f_{2,\pm}(x)=\pm\operatorname{sgn}(x)\sqrt{x^2-1}}.
$$


::: pf-proof

First let $x>1$. On $(-1,1)$ the chosen branch satisfies
$$
f_2(x)=+i\sqrt{1-x^2}.
$$
Passing around the branch point $1$ through the upper half-plane rotates $z^2-1$ from the negative real axis to the positive real axis with argument decreasing from $\pi$ to $0$, so the square root tends to $+\sqrt{x^2-1}$. Passing below $1$ continues the argument from $\pi$ to $2\pi$, so the square root tends to $-\sqrt{x^2-1}$. Thus
$$
f_{2,+}(x)=+\sqrt{x^2-1},
\qquad
f_{2,-}(x)=-\sqrt{x^2-1}
$$
for $x>1$.

Now let $x<-1$. Near $-1$ one has $z^2-1\sim-2(z+1)$. Passing from the interval $(-1,1)$ to the left through the upper half-plane rotates the argument of $z^2-1$ from $\pi$ to $2\pi$, giving the limit $-\sqrt{x^2-1}$; passing through the lower half-plane rotates it from $\pi$ to $0$, giving $+\sqrt{x^2-1}$. This is exactly the displayed formula with $\operatorname{sgn}(x)=-1$.

:::

:::

::: {.pf-step #s1-3}

The branch $f_1$ is odd.


::: pf-proof

On the connected domain $\CC\setminus[-1,1]$, define
$$
q(z)=\frac{f_1(-z)}{f_1(z)}.
$$
The denominator never vanishes on this domain, and
$$
q(z)^2
=\frac{(-z)^2-1}{z^2-1}
=1.
$$
Since $q$ is continuous and takes values in the discrete set $\{1,-1\}$, it is constant.

For large $\abs{z}$, the normalization $f_1(x)>0$ for $x>1$ selects the branch
$$
f_1(z)=z\left(1-\frac1{z^2}\right)^{1/2}
$$
near infinity with the square root tending to $1$. Hence for large positive real $x$,
$$
f_1(-x)=-x\left(1-\frac1{x^2}\right)^{1/2}=-f_1(x).
$$
Thus $q=-1$ identically, so
$$
f_1(-z)=-f_1(z).
$$

:::

:::

::: {.pf-step #s1-4}

The branch $f_2$ is even.


::: pf-proof

On the connected domain
$$
\CC\setminus\bigl(( -\infty,-1]\cup[1,\infty)\bigr),
$$
define
$$
r(z)=\frac{f_2(-z)}{f_2(z)}.
$$
Again $r(z)^2=1$, so $r$ is constant. At $z=0$, the normalization gives $f_2(0)=i$, and therefore
$$
r(0)=\frac{f_2(0)}{f_2(0)}=1.
$$
Hence $r=1$ throughout the domain and
$$
f_2(-z)=f_2(z).
$$

:::

::: {.problem}
Find conformal mappings $f _ { i }$ of $\mathcal { U } _ { i }$ onto $\mathcal { V } _ { i }$ for each of the following cases.
If the mapping is a composition of several functions, provide a sketch for each step.
$\mathcal { D }$ denotes the unit disc $\{ z : \abs{ z } < 1 \}$

(i) $\mathcal { U } _ { 1 } = \{ z : \mathrm { R e } z < 0 , - 1 < \mathrm { I m } z < 1 \} , \mathcal { V } _ { 1 } = \mathcal { D } .$

(ii) $\mathcal { U } _ { 2 } = \mathcal { D } , \mathcal { V } _ { 2 }$ is the cut complex plane $\CC \setminus \RR ^ { - }$

(iii) $\mathcal { U } _ { 3 }$ is the angular sector $\{ z : 0 < \arg z < \alpha \} , \mathcal { V } _ { 3 } = \{ z : 0 < \mathrm { I m } z < 1 \}$

$\ast$ (iv) $\mathcal { U } _ { 4 }$ is the open region bounded between two circles $\{ z : \abs{ z } < 1 , \abs{ z + i } > \sqrt { 2 } \} , \mathcal { V } _ { 4 } = \mathcal { D } .$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For (i), a conformal bijection $U_1\to\mathcal D$ is
$$
\boxed{
f_1(z)=
\frac{\sin(-\pi i z/2)-i}{\sin(-\pi i z/2)+i}}.
$$


::: pf-proof

First set
$$
\zeta=-\frac{\pi i}{2}z.
$$
If $z=x+iy$ satisfies $x<0$ and $-1<y<1$, then
$$
-\frac\pi2<\operatorname{Re}\zeta<\frac\pi2,
\qquad
\operatorname{Im}\zeta>0.
$$
Thus this affine map sends $U_1$ conformally onto the half-strip
$$
H=\left\{\zeta:-\frac\pi2<\operatorname{Re}\zeta<\frac\pi2,
\ \operatorname{Im}\zeta>0\right\}.
$$

For $\zeta=u+iv\in H$,
$$
\operatorname{Im}(\sin\zeta)=\cos u\,\sinh v>0,
$$
so $\sin H$ lies in the upper half-plane. If $\sin\zeta_1=\sin\zeta_2$, then either $\zeta_1-\zeta_2\in2\pi\ZZ$ or $\zeta_1+\zeta_2\in\pi+2\pi\ZZ$. The first alternative forces $\zeta_1=\zeta_2$ because both real parts lie in $(-\pi/2,\pi/2)$; the second is impossible because $\operatorname{Im}(\zeta_1+\zeta_2)>0$. Hence $\sin$ is injective on $H$. Its derivative $\cos\zeta$ has no zero in $H$.

The three boundary pieces of $H$ map to the full real axis: the bottom edge maps to $(-1,1)$, while the two vertical sides map to $(-\infty,-1]$ and $[1,\infty)$. Moreover $\abs{\sin\zeta}\to\infty$ when $\operatorname{Im}\zeta\to\infty$. Therefore the image has no finite boundary point in the upper half-plane; since it is a nonempty open subset of the connected upper half-plane, it is the whole upper half-plane.

Finally, the Cayley map
$$
C(w)=\frac{w-i}{w+i}
$$
is a conformal bijection from the upper half-plane onto $\mathcal D$. Hence the composition is the displayed $f_1$. The sequence of regions is
$$
U_1\longrightarrow H\longrightarrow\{\operatorname{Im}w>0\}
\longrightarrow\mathcal D.
$$

:::

:::

::: {.pf-step #s1-2}

For (ii), a conformal bijection from $\mathcal D$ onto $\CC\setminus(-\infty,0]$ is
$$
\boxed{
f_2(z)=\left(\frac{1+z}{1-z}\right)^2}.
$$


::: pf-proof

The Cayley map
$$
M(z)=\frac{1+z}{1-z}
$$
sends $\mathcal D$ conformally and bijectively onto the right half-plane, because
$$
\operatorname{Re}M(z)=\frac{1-\abs{z}^2}{\abs{1-z}^2}>0
$$
and the inverse is $z=(M-1)/(M+1)$. If $M=re^{i\theta}$ with $-\pi/2<\theta<\pi/2$, then $M^2=r^2e^{2i\theta}$ has argument in $(-\pi,\pi)$. Thus squaring maps the right half-plane conformally and bijectively onto $\CC\setminus(-\infty,0]$. Hence
$$
\mathcal D\longrightarrow\{\operatorname{Re}M>0\}
\longrightarrow\CC\setminus(-\infty,0]
$$
is the required sequence.

:::

:::

::: {.pf-step #s1-3}

For (iii), choose the logarithm branch
$$
L(re^{i\theta})=\log r+i\theta,
\qquad 0<\theta<\alpha.
$$
Then
$$
\boxed{f_3(z)=\frac1\alpha L(z)}
$$
is a conformal bijection from $U_3$ onto $V_3$.


::: pf-proof

The branch $L$ maps the sector bijectively onto the horizontal strip
$$
\{w:0<\operatorname{Im}w<\alpha\},
$$
because $\log r$ ranges over all of $\RR$ and the chosen argument ranges over $(0,\alpha)$. Division by $\alpha$ sends this strip onto $0<\operatorname{Im}w<1$. Both maps are holomorphic with nonzero derivative. Thus
$$
U_3\longrightarrow\{0<\operatorname{Im}w<\alpha\}
\longrightarrow\{0<\operatorname{Im}w<1\}.
$$

:::

:::

::: {.pf-step #s1-4}

For (iv), set
$$
M(z)=\frac{z-1}{z+1}.
$$
Then $M$ maps $U_4$ conformally onto the sector
$$
S=\left\{w:\frac\pi2<\arg w<\frac{3\pi}{4}\right\}.
$$


::: pf-proof

The two boundary circles meet at $z=\pm1$, which $M$ sends to $0$ and $\infty$. Hence each boundary circle maps to a line through the origin.

For $\abs{z}=1$, the equation
$$
\abs{1+w}=\abs{1-w},
\qquad z=\frac{1+w}{1-w},
$$
gives $\operatorname{Re}w=0$. The upper semicircle is the relevant boundary arc of $U_4$, and $M(i)=i$, so this arc maps to the ray $\arg w=\pi/2$.

For the second circle, $\abs{z+i}=\sqrt2$ becomes
$$
\abs{w+i}=\abs{1-w}.
$$
Writing $w=u+iv$ gives $v=-u$. The relevant arc contains $z=i(\sqrt2-1)$, whose image lies on the ray $\arg w=3\pi/4$. A point of $U_4$, for example $z=3i/4$, maps between these two rays. Therefore $M(U_4)=S$.

:::

:::

::: {.pf-step #s1-5}

A conformal bijection for (iv) is
$$
\boxed{
f_4(z)=
\frac{M(z)^4-i}{M(z)^4+i},
\qquad
M(z)=\frac{z-1}{z+1}}.
$$


::: pf-proof

By step [](#s1-4){.pf-ref}, $\arg M(z)\in(\pi/2,3\pi/4)$. Therefore
$$
\arg(M(z)^4)\in(2\pi,3\pi),
$$
which modulo $2\pi$ is the interval $(0,\pi)$. Thus $w\mapsto w^4$ maps $S$ onto the upper half-plane. It is injective there because the angular width of $S$ is $\pi/4$: if $w_1^4=w_2^4$, their arguments differ by a multiple of $\pi/2$, and no nonzero such difference can occur between two arguments in $S$. Its derivative $4w^3$ is nonzero on $S$.

The Cayley map $(\eta-i)/(\eta+i)$ then maps the upper half-plane conformally and bijectively onto $\mathcal D$. Hence
$$
U_4\longrightarrow S\longrightarrow\{\operatorname{Im}\eta>0\}
\longrightarrow\mathcal D
$$
gives the displayed formula.

:::

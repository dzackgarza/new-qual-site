::: {.problem}
Find the first three terms of the Laurent expansion of $f ( z ) = \csc ^ { 2 } z$ valid for $0 < | z | < \pi$

$\ast$ Show that the function $h ( z ) = f ( z ) - z ^ { - 2 } - ( z + \pi ) ^ { - 2 } - ( z - \pi ) ^ { - 2 }$ has only removable singularities in $| z | < 2 \pi$ . Explain how to remove them to obtain a function $H ( z )$ analytic in that region.
Find a Taylor series for $H ( z )$ about the origin and explain why it must be convergent in $| z | < 2 \pi$ Hence, or otherwise, find the three non-zero central terms of the Laurent expansion of $f ( z )$ valid for $\pi < | z | < 2 \pi$

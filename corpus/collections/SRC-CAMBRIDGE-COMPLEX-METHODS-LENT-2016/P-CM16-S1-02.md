::: {.problem}
Find, as functions of z, complex analytic functions $f ( z )$ whose real parts are the following: (i) x (ii) $x y$ (iii) sin x cosh y (iv) $\log ( x ^ { 2 } + y ^ { 2 } )$ (v) $\frac { y } { ( x + 1 ) ^ { 2 } + y ^ { 2 } }$ (vi) $\tan ^ { - 1 } \left( { \frac { 2 x y } { x ^ { 2 } - y ^ { 2 } } } \right)$

Deduce that the above functions are harmonic on appropriately-chosen domains, which you should specify.
:::

::: {.solution}

Write $z=x+iy$. In each part, an arbitrary purely imaginary constant $iC$, $C\in\RR$, may be added without changing the real part.

::: pf

::: {.pf-step #s1-1}

For (i), one may take $f(z)=z+iC$ on all of $\CC$.


::: pf-proof

Since $z=x+iy$, one has $\operatorname{Re}z=x$. The function $z\mapsto z$ is entire.

:::

:::

::: {.pf-step #s1-2}

For (ii), one may take
$$
f(z)=-\frac{i}{2}z^2+iC
$$
on all of $\CC$.


::: pf-proof

Expanding $z^2$ gives
$$
-\frac{i}{2}(x+iy)^2
=xy-\frac{i}{2}(x^2-y^2),
$$
whose real part is $xy$. This polynomial is entire.

:::

:::

::: {.pf-step #s1-3}

For (iii), one may take $f(z)=\sin z+iC$ on all of $\CC$.


::: pf-proof

The standard exponential formula for the sine gives
$$
\sin(x+iy)=\sin x\cosh y+i\cos x\sinh y.
$$
Hence $\operatorname{Re}(\sin z)=\sin x\cosh y$. The function $\sin z$ is entire.

:::

:::

::: {.pf-step #s1-4}

For (iv), on any domain carrying a branch of the logarithm one may take $f(z)=2\log z+iC$; for example this works on
$$
D_4=\CC\setminus(-\infty,0]
$$
with the principal branch.


::: pf-proof

For any branch of $\log z$,
$$
\operatorname{Re}(2\log z)
=2\log\abs{z}
=\log\abs{z}^2
=\log(x^2+y^2).
$$
Such a branch is holomorphic on $D_4$.

:::

:::

::: {.pf-step #s1-5}

For (v), one may take
$$
f(z)=\frac{i}{z+1}+iC
$$
on $D_5=\CC\setminus\{-1\}$.


::: pf-proof

Since
$$
\frac{i}{z+1}
=\frac{i(x+1)+y}{(x+1)^2+y^2},
$$
its real part is
$$
\frac{y}{(x+1)^2+y^2}.
$$
The rational function $i/(z+1)$ is holomorphic precisely away from $z=-1$.

:::

:::

::: {.pf-step #s1-6}

For (vi), let
$$
D_k
=\left\{re^{i\theta}:r>0,
-\frac\pi4+\frac{k\pi}{2}<\theta<\frac\pi4+\frac{k\pi}{2}\right\},
\qquad k=0,1,2,3.
$$
On $D_k$, choose the logarithm branch
$$
L_k(re^{i\theta})=\log r+i\theta
$$
with $\theta$ in the displayed interval. Then one may take
$$
f_k(z)=-2iL_k(z)-k\pi+iC.
$$


::: pf-proof

For $z=re^{i\theta}\in D_k$,
$$
\frac{2xy}{x^2-y^2}
=\frac{r^2\sin(2\theta)}{r^2\cos(2\theta)}
=\tan(2\theta).
$$
Moreover,
$$
-\frac\pi2+k\pi<2\theta<\frac\pi2+k\pi.
$$
The principal arctangent therefore satisfies
$$
\tan^{-1}(\tan(2\theta))=2\theta-k\pi.
$$
On the other hand,
$$
\operatorname{Re}f_k(z)
=\operatorname{Re}\bigl(-2i(\log r+i\theta)-k\pi\bigr)
=2\theta-k\pi.
$$
Thus $\operatorname{Re}f_k$ is exactly the function in (vi) on $D_k$. Each $L_k$ is holomorphic there, so each $f_k$ is holomorphic there.

:::

:::

::: {.pf-step #s1-7}

The functions in (i)--(vi) are harmonic on the following domains:
$$
\boxed{
\begin{aligned}
\text{(i)--(iii)}&:\ \CC,\\
\text{(iv)}&:\ \CC\setminus\{0\},\\
\text{(v)}&:\ \CC\setminus\{-1\},\\
\text{(vi)}&:\ D_k\quad(k=0,1,2,3).
\end{aligned}}
$$


::: pf-proof

The real part of a holomorphic function is harmonic. Steps [](#s1-1){.pf-ref} through [](#s1-3){.pf-ref} and [](#s1-5){.pf-ref} provide holomorphic functions on the stated domains directly. For (iv), every point of $\CC\setminus\{0\}$ has a neighborhood on which a branch of $\log z$ exists, and step [](#s1-4){.pf-ref} identifies the given function locally as the real part of a holomorphic function; harmonicity is local. For (vi), step [](#s1-6){.pf-ref} gives the required holomorphic function on each connected component $D_k$ of the set $x^2\ne y^2$.

:::

Steps [](#s1-1){.pf-ref} through [](#s1-6){.pf-ref} construct the required analytic functions, and step [](#s1-7){.pf-ref} gives the requested harmonicity domains.

::: {.problem}
How does the disc $| z - 1 | < 1$ transform under the mapping $z \mapsto z ^ { - 1 } ?$

Use the identity

$$
{ \frac { z } { ( z - 1 ) ^ { 2 } } } = \left( { \frac { 1 } { 1 - z } } - { \frac { 1 } { 2 } } \right) ^ { 2 } - { \frac { 1 } { 4 } }
$$

to show that the map $f ( z ) = z / ( z - 1 ) ^ { 2 }$ is a one-to-one conformal mapping of the disc $| z | < 1$ onto the domain $\CC \setminus \left\{ x + i y : x \leqslant - { \frac { 1 } { 4 } } , \ y = 0 \right\}$ .
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Under inversion $w=1/z$, the disk $|z-1|<1$ maps bijectively onto the half-plane
$$
\boxed{\operatorname{Re}w>\frac12}.
$$


::: pf-proof

Write $w=u+iv$ and $z=1/w$. Then
$$
|z-1|<1
\iff \left|\frac1w-1\right|<1
\iff |1-w|<|w|.
$$
Squaring gives
$$
(u-1)^2+v^2<u^2+v^2
\iff u>\frac12.
$$
Every $w$ with $\operatorname{Re}w>1/2$ is nonzero, so reversing the calculation shows that $z=1/w$ lies in the original disk. Hence the map is bijective onto this half-plane.

:::

:::

::: {.pf-step #s1-2}

If $|z|<1$ and
$$
h(z)=\frac1{1-z}-\frac12,
$$
then $h$ maps the unit disk bijectively and conformally onto the right half-plane $\operatorname{Re}h>0$.


::: pf-proof

Set $\zeta=1-z$. Then $|z|<1$ is equivalent to
$$
|\zeta-1|<1.
$$
By step [](#s1-1){.pf-ref}, $1/\zeta$ maps this disk bijectively onto $\operatorname{Re}w>1/2$. Subtracting $1/2$ gives $\operatorname{Re}h>0$. Each of the maps $z\mapsto1-z$, $\zeta\mapsto1/\zeta$, and $w\mapsto w-1/2$ has nonzero derivative on the relevant domain, so their composition is conformal.

:::

:::

::: {.pf-step #s1-3}

The squaring map $q(h)=h^2$ is a conformal bijection from the right half-plane onto $\CC\setminus(-\infty,0]$.


::: pf-proof

If $h=re^{i\theta}$ with $r>0$ and $-\pi/2<\theta<\pi/2$, then
$$
h^2=r^2e^{2i\theta},
\qquad -\pi<2\theta<\pi.
$$
Thus $h^2$ never lies on $(-\infty,0]$. Conversely, every $\xi=\rho e^{i\varphi}$ with $-\pi<\varphi<\pi$ has the unique square root
$$
h=\sqrt\rho\,e^{i\varphi/2}
$$
in the right half-plane. Since $q'(h)=2h\ne0$ there, $q$ is conformal.

:::

:::

::: {.pf-step #s1-4}

The identity in the problem factors $f$ as
$$
f(z)=h(z)^2-\frac14.
$$


::: pf-proof

Directly,
$$
\left(\frac1{1-z}-\frac12\right)^2-\frac14
=\frac1{(1-z)^2}-\frac1{1-z}
=\frac{z}{(1-z)^2}
=\frac{z}{(z-1)^2}.
$$

:::

:::

::: {.pf-step #s1-5}

Therefore $f$ is a one-to-one conformal map of $|z|<1$ onto
$$
\boxed{\CC\setminus(-\infty,-1/4]}.
$$


::: pf-proof

By step [](#s1-2){.pf-ref}, $h$ is a conformal bijection from the unit disk to the right half-plane. By step [](#s1-3){.pf-ref}, squaring maps that half-plane conformally and bijectively onto $\CC\setminus(-\infty,0]$. Step [](#s1-4){.pf-ref} shows that the final subtraction of $1/4$ is exactly the map $f$, so its image is $\CC\setminus(-\infty,-1/4]$. A composition of conformal bijections is again a conformal bijection.

:::

:::

::: pf-qed

Step [](#s1-1){.pf-ref} answers the inversion question, and step [](#s1-5){.pf-ref} proves the stated mapping property of $f$.

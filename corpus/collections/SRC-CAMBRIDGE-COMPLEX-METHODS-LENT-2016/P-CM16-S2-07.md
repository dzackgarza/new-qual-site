::: {.problem}
Evaluate, using Cauchy’s theorem or the residue theorem,

(i) $\oint _ { \gamma _ { 1 } } \frac { \mathrm { d } z } { 1 + z ^ { 2 } }$ (ii) $\oint _ { \gamma _ { 2 } } { \frac { \mathrm { d } z } { 1 + z ^ { 2 } } }$ (iii) $\oint _ { \gamma _ { 3 } } { \frac { e ^ { z } \cos z \mathrm { d } z } { ( 1 + z ^ { 2 } ) \sin z } }$ $\ast$ (iv) $\oint _ { \gamma _ { 4 } } \frac { z ^ { 3 } e ^ { 1 / z } \mathrm { d } z } { 1 + z }$

where $\gamma _ { 1 }$ is the ellipse $x ^ { 2 } + 4 y ^ { 2 } = 1 , \gamma _ { 2 }$ is the circle $x ^ { 2 } + y ^ { 2 } = 2 , \gamma _ { 3 }$ is the circle $| z - ( 2 + i ) | = { \sqrt { 2 } }$ and $\gamma _ { 4 }$ is the circle $| z | = 2$
:::

::: {.solution}
Assume all four contours have the positive, counterclockwise orientation.

<1>1. For the ellipse $\gamma_1:x^2+4y^2=1$,
$$
\boxed{
\oint_{\gamma_1}\frac{dz}{1+z^2}=0}.
$$

::: {.proof}
The only poles of $(1+z^2)^{-1}$ are $z=\pm i$. The ellipse has vertical semiaxis $1/2$, so neither pole lies on or inside $\gamma_1$. The integrand is therefore holomorphic on the enclosed region, and Cauchy's theorem gives the result.
:::

<1>2. For the circle $\gamma_2:|z|=\sqrt2$,
$$
\boxed{
\oint_{\gamma_2}\frac{dz}{1+z^2}=0}.
$$

::: {.proof}
Both simple poles $i$ and $-i$ lie inside $\gamma_2$. Their residues are
$$
\operatorname{Res}_{z=i}\frac1{1+z^2}
=\frac1{2i},
\qquad
\operatorname{Res}_{z=-i}\frac1{1+z^2}
=-\frac1{2i}.
$$
Their sum is zero, so the residue theorem gives the stated integral.
:::

<1>3. For $\gamma_3:|z-(2+i)|=\sqrt2$,
$$
\boxed{
\oint_{\gamma_3}
\frac{e^z\cos z}{(1+z^2)\sin z}\,dz
=0}.
$$

::: {.proof}
Possible singularities occur at $z=\pm i$ and at the zeros $z=n\pi$ of $\sin z$. Their distances from the center $2+i$ satisfy
$$
|i-(2+i)|=2,
\qquad
|-i-(2+i)|=2\sqrt2,
$$
so the poles at $\pm i$ are outside the circle. Among the real points $n\pi$, the nearest candidates are $0$ and $\pi$, and
$$
|0-(2+i)|=\sqrt5>\sqrt2,
$$
while
$$
|\pi-(2+i)|^2=(\pi-2)^2+1>2
$$
because $\pi>3$. All other $n\pi$ are farther from $2+i$. Hence the integrand is holomorphic inside $\gamma_3$, and Cauchy's theorem gives zero.
:::

<1>4. For $\gamma_4:|z|=2$,
$$
\boxed{
\oint_{\gamma_4}\frac{z^3e^{1/z}}{1+z}\,dz
=-\frac{2\pi i}{3}}.
$$

::: {.proof}
The singularities inside $\gamma_4$ are the essential singularity at $0$ and the simple pole at $-1$. At $-1$,
$$
\operatorname{Res}_{z=-1}
\frac{z^3e^{1/z}}{1+z}
=(-1)^3e^{-1}
=-e^{-1}.
$$

For the residue at $0$, use the convergent expansions on $0<|z|<1$:
$$
e^{1/z}=\sum_{n=0}^{\infty}\frac{z^{-n}}{n!},
\qquad
\frac1{1+z}=\sum_{m=0}^{\infty}(-1)^mz^m.
$$
The coefficient of $z^{-1}$ in their product after multiplication by $z^3$ occurs when
$$
3-n+m=-1,
\qquad\text{that is,}\qquad n=m+4.
$$
Therefore
$$
\operatorname{Res}_{z=0}
\frac{z^3e^{1/z}}{1+z}
=\sum_{m=0}^{\infty}\frac{(-1)^m}{(m+4)!}
=\sum_{n=4}^{\infty}\frac{(-1)^n}{n!}
=e^{-1}-\frac13.
$$
The total residue inside $\gamma_4$ is consequently
$$
\left(e^{-1}-\frac13\right)-e^{-1}
=-\frac13.
$$
The residue theorem now gives
$$
\oint_{\gamma_4}\frac{z^3e^{1/z}}{1+z}\,dz
=2\pi i\left(-\frac13\right)
=-\frac{2\pi i}{3}.
$$
:::

<1>5. Q.E.D.

::: {.problem}
State the Seifert–van Kampen Theorem and use it to show that $\pi_1(S^n)=0$ for $n>1$.
Why doesn’t this argument work for $n=1$?
:::

::: {.solution}
The argument is the card's own; the collection is a topology workshop exercise, so the statement is the source.

::: pf

::: {.pf-step #svk}
**Statement.** If $X=U\cup V$ with $U,V,U\cap V$ path connected and the basepoint in $U\cap V$, then $\pi_{1}(X)\cong\bigl(\pi_{1}(U)*\pi_{1}(V)\bigr)/N$, where $N$ is the normal subgroup generated by the elements $i_{U*}(\omega)i_{V*}(\omega)^{-1}$ for $\omega\in\pi_{1}(U\cap V)$.

::: pf-proof
This is the Seifert--van Kampen theorem, stated in the form the question asks for; the maps $i_{U*},i_{V*}$ are induced by the inclusions of $U\cap V$.
:::

:::

::: {.pf-step #cover}
For $n>1$ let $U=S^{n}\setminus\{N\}$ and $V=S^{n}\setminus\{S\}$ for distinct points $N,S$; then $X=U\cup V$, and $U,V$ are simply connected.

::: pf-proof
Stereographic projection gives homeomorphisms $U\cong\RR^{n}$ and $V\cong\RR^{n}$, and $\RR^{n}$ is simply connected for every $n\ge1$.
:::

:::

::: {.pf-step #intersection}
$U\cap V=S^{n}\setminus\{N,S\}$ is path connected for $n>1$.

::: pf-proof
$S^{n}\setminus\{N,S\}$ deformation retracts onto the equator $S^{n-1}$, which is path connected for $n-1\ge1$, that is $n\ge2$. (For $n$ at least $3$ it is in fact simply connected, but only path connectedness is needed.)
:::

:::

::: {.pf-step #trivial}
$\pi_{1}(S^{n})=0$ for $n>1$.

::: pf-proof
Step [](#intersection){.pf-ref} puts the hypotheses of step [](#svk){.pf-ref} in force, and $\pi_{1}(U)=\pi_{1}(V)=1$ by step [](#cover){.pf-ref}, so the free product is trivial and hence so is the quotient. Explicitly, every generator $i_{U*}(\omega)i_{V*}(\omega)^{-1}$ equals $1\cdot1^{-1}=1$, so $N$ is trivial and $\pi_{1}(S^{n})\cong1$. The element $\omega$ generates nothing new even when $\pi_{1}(U\cap V)\ne1$, which happens at $n=2$ where $U\cap V\simeq S^{1}$.
:::

:::

::: {.pf-step #circle}
The same argument fails for $n=1$.

::: pf-proof
For $n=1$ the cover $U=S^{1}\setminus\{N\}$, $V=S^{1}\setminus\{S\}$ has $U\cap V=S^{1}\setminus\{N,S\}$, which is homeomorphic to two disjoint open intervals and so is not path connected; the hypothesis of the form of van Kampen stated in step [](#svk){.pf-ref} therefore fails, and the theorem gives no conclusion. Indeed $\pi_{1}(S^{1})\cong\ZZ\ne0$.
:::

:::

::: {.pf-step}
The theorem is stated and applied.

::: pf-proof
Steps [](#svk){.pf-ref}, [](#trivial){.pf-ref} and [](#circle){.pf-ref} give
$$
\boxed{\pi_{1}(S^{n})=0\text{ for }n>1;\qquad\text{for }n=1\text{ the intersection is disconnected and the hypothesis fails}.}
$$
The distinction the question asks about is exactly the path connectedness of $U\cap V$, which holds for $n>1$ and fails for $n=1$.
:::

::: {.exercise}
If $M$ is any $R$ module, and $x_1, \ldots, x_m$ are any elements of $M$, prove there is a unique $R$ module map $f: R^m \to M$ taking $e_i$ to $x_i$, where $e_1 = (1, 0, \ldots, 0)$, $e_2 = (0, 1, 0, \ldots)$, and so on.

Show moreover that $f$ is surjective if and only if the $\theset{x_i}$ generate $M$, and injective if and only if the $\theset{x_i}$ are linearly independent over $R$.
:::

::: {.solution}
Define $f\colon R^m \to M$ by $f(r_1, \ldots, r_m) = \sum_{i=1}^m r_i x_i$.

::: pf

::: {.pf-step #s1}

$f$ is an $R$-module homomorphism with $f(e_i) = x_i$ for each $i$.

::: pf-proof

For $r, s \in R^m$ and $c \in R$, $f(r + s) = \sum_i (r_i + s_i) x_i = f(r) + f(s)$ and $f(cr) = \sum_i c r_i x_i = c f(r)$. Since $e_i$ has $1$ in the $i$-th coordinate and $0$ elsewhere, $f(e_i) = x_i$.

:::

:::

::: {.pf-step #s2}

$f$ is the only $R$-module map $R^m \to M$ with $e_i \mapsto x_i$.

::: pf-proof

If $g\colon R^m \to M$ is $R$-linear with $g(e_i) = x_i$, then $g(r_1, \ldots, r_m) = g(\sum_i r_i e_i) = \sum_i r_i x_i = f(r_1, \ldots, r_m)$.

:::

:::

::: {.pf-step #s3}

$f$ is surjective if and only if the $x_i$ generate $M$.

::: pf-proof

$\operatorname{im} f = \{\sum_i r_i x_i : r_i \in R\}$ is the submodule generated by the $x_i$, and $f$ is surjective exactly when this submodule is $M$.

:::

:::

::: {.pf-step #s4}

$f$ is injective if and only if the $x_i$ are linearly independent over $R$.

::: pf-proof

$\ker f = \{(r_1, \ldots, r_m) : \sum_i r_i x_i = 0\}$. So $\ker f = 0$ exactly when $\sum_i r_i x_i = 0$ forces all $r_i = 0$, which is linear independence of the $x_i$.

:::

:::

::: pf-qed

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} give existence and uniqueness of $f$; steps [](#s3){.pf-ref} and [](#s4){.pf-ref} give the two criteria.

:::

::: {.exercise}
If $M$ is any $R$ module, and $x_1, \ldots, x_m$ are any elements of $M$, prove there is a unique $R$ module map $f: R^m \to M$ taking $e_i$ to $x_i$, where $e_1 = (1, 0, \ldots, 0)$, $e_2 = (0, 1, 0, \ldots)$, and so on.

Show moreover that $f$ is surjective if and only if the $\ts{x_i}$ generate $M$, and injective if and only if the $\ts{x_i}$ are linearly independent over $R$.
:::

::: {.solution}
<1>1. Define $f : R^m \to M$ by $f(r_1, \ldots, r_m) = \sum_{i=1}^m r_i x_i$.
::: {.proof}
definition.
:::

<1>2. $f$ is an $R$-module homomorphism.
::: {.proof}
$f$ is $R$-linear by construction (it is the sum of scalar multiples).
:::

<1>3. $f(e_i) = x_i$ for each $i$.
::: {.proof}
$e_i$ has $1$ in the $i$-th coordinate and $0$ elsewhere, so $f(e_i) = 1 \cdot x_i = x_i$.
:::

<1>4. $f$ is unique.
::: {.proof}
any $R$-module map $R^m \to M$ is determined by the images of the standard basis $e_1, \ldots, e_m$ (since $R^m$ is free on these generators), and these images are forced to be $x_i$ by <1>3.
:::

<1>5. $f$ is surjective iff $\operatorname{im} f = M$ iff the $x_i$ generate $M$.
::: {.proof}
$\operatorname{im} f = \{\sum_i r_i x_i : r_i \in R\}$ is exactly the submodule generated by the $x_i$.
:::

<1>6. $f$ is injective iff $\ker f = 0$ iff $\sum_i r_i x_i = 0$ forces all $r_i = 0$ iff the $x_i$ are linearly independent over $R$.
::: {.proof}
$\ker f = \{(r_1, \ldots, r_m) : \sum_i r_i x_i = 0\}$.
:::

<1>7. Q.E.D.
::: {.proof}
<1>4, <1>5, <1>6.
:::
:::

::: {.exercise}
If $M$ is a finitely generated $R$ module, say with $m$ generators, prove that $M$ is isomorphic to the cokernel of an $R$ module map $f: R^n \to R^m$, where $f$ can be given by an $m$ by $n$ matrix of elements of $R$.
:::

::: {.solution}
<1>1. Construct the free presentation surjection $\pi: R^m \to M$: <2>1. Let $\{x_1, \dots, x_m\} \subset M$ be a set of $m$ generators of $M$ as an $R$-module.
::: {.proof}
hypothesis that $M$ is generated by $m$ elements.
:::
<2>2. Define the $R$-module homomorphism $\pi: R^m \to M$ by:
\[
\pi(r_1, \dots, r_m) = \sum_{i=1}^m r_i x_i.
\]
::: {.proof}
universal property of free $R$-modules.
:::
<2>3. Since $\{x_1, \dots, x_m\}$ generates $M$, the map $\pi$ is surjective.
::: {.proof}
every element of $M$ is an $R$-linear combination of the generators.
:::
<2>4. Let $K = \ker(\pi) \subseteq R^m$ be the submodule of relations.
::: {.proof}
kernel of a module homomorphism.
:::
<2>5. By the First Isomorphism Theorem for modules:
\[
M \cong R^m / K.
\]
::: {.proof}
First Isomorphism Theorem.
:::

<1>2. Construct the relations map $f: R^n \to R^m$: <2>1. Let $\{y_1, \dots, y_n\} \subset R^m$ be a generating set for the submodule of relations $K$.
::: {.proof}
finite generation of relations (for example, when $R$ is a Euclidean domain or Noetherian ring, any submodule of the finitely generated free module $R^m$ is finitely generated).
:::
<2>2. For each $j \in \{1, \dots, n\}$, write the vector $y_j \in R^m$ in standard coordinates as $y_j = (a_{1j}, a_{2j}, \dots, a_{mj})^t$ with $a_{ij} \in R$.
::: {.proof}
coordinates in the standard basis $\{e_1, \dots, e_m\}$ of $R^m$.
:::
<2>3. Define the $R$-module homomorphism $f: R^n \to R^m$ by sending the standard basis vector $e_j \in R^n$ to $y_j$:
\[
f(e_j) = y_j = \sum_{i=1}^m a_{ij} e_i \quad (1 \le j \le n).
\]
::: {.proof}
universal property of free modules.
:::
<2>4. With respect to the standard bases of $R^n$ and $R^m$, the map $f$ is given by matrix multiplication by the $m \times n$ matrix $A = (a_{ij}) \in M_{m \times n}(R)$.
::: {.proof}
definition of matrix representation of module homomorphisms.
:::

<1>3. Show that $M \cong \operatorname{coker}(f)$: <2>1. The image of $f$ is:
\[
\operatorname{im}(f) = R y_1 + \cdots + R y_n = K = \ker(\pi).
\]
::: {.proof}
$\{y_1, \dots, y_n\}$ generates $K$.
:::
<2>2. By definition, the cokernel of $f$ is:
\[
\operatorname{coker}(f) = R^m / \operatorname{im}(f) = R^m / K.
\]
::: {.proof}
definition of the cokernel of a module homomorphism.
:::
<2>3. Combining with <2>5 of <1>1 gives:
\[
M \cong R^m / K = \operatorname{coker}(f).
\]
::: {.proof}
<1>1 and <2>2.
:::

<1>4. Conclusion: $M$ is isomorphic to the cokernel of the map $f: R^n \to R^m$ given by the $m \times n$ matrix $A$.
::: {.proof}
<1>2 and <1>3.
:::
Q.E.D.
:::

::: {.exercise}
If $M$ is a finitely generated $R$ module, say with $m$ generators, prove that $M$ is isomorphic to the cokernel of an $R$ module map $f: R^n \to R^m$, where $f$ can be given by an $m$ by $n$ matrix of elements of $R$.
:::

::: {.solution}
Let $R$ be a Euclidean domain, and let $x_1, \dots, x_m$ generate $M$.

<1>1. There is a surjective $R$-module map $\pi\colon R^m \to M$ with $\pi(e_i) = x_i$, and $M \cong R^m/\ker\pi$.
::: {.proof}
The map $\pi(r_1, \dots, r_m) = \sum_i r_i x_i$ is $R$-linear with $\pi(e_i) = x_i$ ([[E-SMI-8000E-ED3]]), and it is surjective because the $x_i$ generate $M$. The first isomorphism theorem gives $M \cong R^m/\ker\pi$.
:::

<1>2. $K = \ker\pi$ is generated by finitely many elements $y_1, \dots, y_n$.
::: {.proof}
$K$ is a submodule of $R^m$, so $K \cong R^n$ for some $n \le m$ by [[E-SMI-8000E-ED2]]; the images $y_1, \dots, y_n$ of the standard basis vectors generate $K$.
:::

<1>3. The map $f\colon R^n \to R^m$ with $f(e_j) = y_j$ has image $K$ and is given by an $m \times n$ matrix.
::: {.proof}
Write $y_j = \sum_{i=1}^m a_{ij} e_i$ with $a_{ij} \in R$. By [[E-SMI-8000E-ED3]] there is a unique $R$-linear $f$ with $f(e_j) = y_j$, namely $f(r) = Ar$ for the $m \times n$ matrix $A = (a_{ij})$. Its image is $R y_1 + \cdots + R y_n = K$.
:::

<1>4. Q.E.D.
::: {.proof}
By steps <1>1 and <1>3, $M \cong R^m/K = R^m/\operatorname{im} f = \operatorname{coker} f$.
:::
:::

::: {.exercise}
If $R$ is a noetherian ring and $I$ any ideal, then $R/I$ is noetherian too.
:::


::: {.solution}

The argument is the card's own: ideals of a quotient correspond to ideals of the ring containing the kernel, and the images of generators generate.

::: pf

::: {.pf-step #correspondence}

Let $\pi:R\to R/I$ be the quotient map. Every ideal of $R/I$ is $\pi(J)=J/I$ for a unique ideal $J$ of $R$ with $I\subset J$, and $\pi^{-1}\pi(J)=J$.

::: pf-proof

For an ideal $K\subset R/I$, put $J=\pi^{-1}(K)$. Then $J$ is an ideal of $R$: it contains $0$, and if $x,y\in J$ and $r\in R$ then $\pi(x-ry)=\pi(x)-r\pi(y)\in K$. It contains $I$ because $\pi$ kills $I$. Also $\pi^{-1}\pi(J)=J$ here, since $x\in\pi^{-1}\pi(J)$ means $\pi(x)=\pi(j)$ for some $j\in J$, i.e. $x-j\in I\subset J$, so $x\in J$. Conversely $\pi(J)$ is an ideal of $R/I$ because $\pi$ is a surjective ring homomorphism.

:::

:::

::: {.pf-step #generated}

$R$ is noetherian, so each ideal $J$ of $R$ is finitely generated.

::: pf-proof

A ring is noetherian exactly when all its ideals are finitely generated, which is one of the equivalent forms of the ascending chain condition; this is the hypothesis on $R$. So write $J=(a_{1},\dots,a_{r})$ for some $a_{i}\in J$.

:::

:::

::: {.pf-step #image}

$J/I=(a_{1}+I,\dots,a_{r}+I)$ as an ideal of $R/I$.

::: pf-proof

Each $a_{i}+I=\pi(a_{i})$ lies in $J/I$, so the right side is contained in the ideal $J/I$. Conversely, if $x\in J$ then $x=r_{1}a_{1}+\cdots+r_{r}a_{r}$ with $r_{i}\in R$ by step [](#generated){.pf-ref}, hence
$$
x+I=\pi(x)=\pi(r_{1})\pi(a_{1})+\cdots+\pi(r_{r})\pi(a_{r})=(r_{1}+I)(a_{1}+I)+\cdots+(r_{r}+I)(a_{r}+I),
$$
an element of the ideal generated by the $a_{i}+I$. So every element of $J/I$ lies in that generated ideal, and the two agree.

:::

:::

::: {.pf-step #conclusion}

$R/I$ is noetherian.

::: pf-proof

Let $K$ be an arbitrary ideal of $R/I$. By step [](#correspondence){.pf-ref} $K=J/I$ for the ideal $J=\pi^{-1}(K)$ of $R$, and by step [](#image){.pf-ref} $K$ is generated by the finitely many elements $a_{1}+I,\dots,a_{r}+I$. So every ideal of $R/I$ is finitely generated, which is the defining property of a noetherian ring:
$$
\boxed{R\ \text{noetherian}\implies R/I\ \text{noetherian for every ideal } I.}
$$

:::

::: {.exercise}
Prove: if $A \to B \to C \to 0$ is an exact sequence of abelian groups, and if $A$ and $C$ are finitely generated, then so is $B$.

[Hint: use the images of some generators of $A$, and some choice of preimages of some generators of $C$.]
:::

::: {.solution}
Write the exact sequence as $A \xrightarrow{\alpha} B \xrightarrow{\beta} C \to 0$. Let $a_1, \ldots, a_m$ generate $A$ and $c_1, \ldots, c_n$ generate $C$.

::: pf

::: pf-step

For each $j$ there is $b_j \in B$ with $\beta(b_j) = c_j$.

::: pf-proof

Exactness at $C$ says that $\beta$ is surjective.

:::

:::

::: {.pf-step #s2}

The set $S = \{\alpha(a_1), \ldots, \alpha(a_m), b_1, \ldots, b_n\}$ generates $B$.

::: pf-proof

Let $b \in B$. Write $\beta(b) = \sum_j n_j c_j$ with integers $n_j$. Then $\beta\bigl(b - \sum_j n_j b_j\bigr) = 0$, so $b - \sum_j n_j b_j \in \ker \beta = \operatorname{im} \alpha$ by exactness at $B$. Hence $b - \sum_j n_j b_j = \alpha\bigl(\sum_i m_i a_i\bigr) = \sum_i m_i \alpha(a_i)$ for some integers $m_i$, and $b = \sum_i m_i \alpha(a_i) + \sum_j n_j b_j$ lies in the subgroup generated by $S$.

:::

:::

::: pf-qed

By step [](#s2){.pf-ref}, the finite set $S$ generates $B$, so $B$ is finitely generated.

:::

::: {.problem}
1. For which real numbers $\alpha>0$ does
   \[
   x'=x^\alpha,\qquad x(0)=0,
   \]
   have a solution on some interval $[0,b]$, $b>0$?
2. For which values of $\alpha$ are there intervals on which two solutions are defined?
:::

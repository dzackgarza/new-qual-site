::: {.problem}
(a) Prove that if $s > 1$ then $\textstyle \sum _ { n > 0 } n ^ { - s } = \prod _ { p } 1 / ( 1 - p ^ { - s } )$ , where the product is over all primes p.

(b) Prove that the sum $\textstyle \sum _ { p } 1 / p$ over all primes p diverges.
:::

::: problem
Suppose $A$ is a Noetherian local ring and its only maximal ideal is $\mathfrak{m}$.

(a) Carefully state Nakayama's lemma for $A$-modules.

(b) For every finitely generated $A$-module $M$, prove that
\[
d(M) = \dim_{A/\mathfrak{m}}(M/\mathfrak{m}M),
\]
where $d(M)$ is the minimum number of elements needed to generate $M$.

(c) Prove that every finitely generated projective $A$-module $P$ is free.
:::


::: {.solution}
**(a).**

<1>1. Nakayama's lemma in the form used here is: if \(M\) is a finitely generated \(A\)-module and \(M=\mathfrak mM\), then \(M=0\). Equivalently, if \(N\subseteq M\) and
\[
M=N+\mathfrak mM,
\]
then \(M=N\).
::: {.proof}
Since \(A\) is local, its Jacobson radical is its unique maximal ideal \(\mathfrak m\). This is the standard local form of Nakayama's lemma; the equivalent form follows by applying it to the finitely generated quotient \(M/N\).
:::

**(b).**

<1>2. If \(M\) can be generated by \(r\) elements, then
\[
\dim_{A/\mathfrak m}(M/\mathfrak mM)\le r.
\]
::: {.proof}
The images modulo \(\mathfrak mM\) of any generating set for \(M\) span the quotient as a vector space over \(A/\mathfrak m\).
:::

<1>3. Let
\[
r=\dim_{A/\mathfrak m}(M/\mathfrak mM),
\]
and choose elements \(x_1,\dots,x_r\in M\) whose images form a basis of the quotient. Then \(x_1,\dots,x_r\) generate \(M\).
::: {.proof}
Let \(N=Ax_1+\cdots+Ax_r\). The basis condition says that the image of \(N\) in \(M/\mathfrak mM\) is the whole quotient, so
\[
M=N+\mathfrak mM.
\]
By Nakayama's lemma in <1>1, \(M=N\).
:::

<1>4. Therefore
\[
d(M)=\dim_{A/\mathfrak m}(M/\mathfrak mM).
\]
::: {.proof}
By <1>2 the vector-space dimension is at most every size of a generating set, hence at most \(d(M)\). By <1>3 there is a generating set of size equal to that dimension, giving the reverse inequality.
:::

**(c).**

<1>5. Let
\[
r=d(P)=\dim_{A/\mathfrak m}(P/\mathfrak mP),
\]
and choose a surjection
\[
\pi:A^r\twoheadrightarrow P
\]
from a minimal generating set of \(P\).
::: {.proof}
Part (b) gives the equality defining \(r\), and a minimal generating set of \(P\) with \(r\) elements defines the surjection.
:::

<1>6. Since \(P\) is projective, the exact sequence
\[
0\longrightarrow K\longrightarrow A^r\xrightarrow{\pi}P\longrightarrow0
\]
splits, where \(K=\ker\pi\).
::: {.proof}
Projectivity of \(P\) provides a section of the surjection \(\pi\).
:::

<1>7. Reducing the split decomposition \(A^r\cong K\oplus P\) modulo \(\mathfrak m\) gives
\[
(A/\mathfrak m)^r
\cong
K/\mathfrak mK\oplus P/\mathfrak mP.
\]
::: {.proof}
Tensor the split isomorphism \(A^r\cong K\oplus P\) with \(A/\mathfrak m\). Tensor product commutes with direct sums, and \((A/\mathfrak m)\otimes_A X\cong X/\mathfrak mX\).
:::

<1>8. One has \(K/\mathfrak mK=0\).
::: {.proof}
The left side of <1>7 has dimension \(r\) over \(A/\mathfrak m\), while by the definition of \(r\) in <1>5 the summand \(P/\mathfrak mP\) already has dimension \(r\). Hence the other summand has dimension zero.
:::

<1>9. The module \(K\) is finitely generated, so Nakayama's lemma and <1>8 give \(K=0\).
::: {.proof}
Because the sequence in <1>6 splits, \(K\) is a direct summand of the finitely generated module \(A^r\), hence is finitely generated. The equality \(K/\mathfrak mK=0\) is equivalent to \(K=\mathfrak mK\), so <1>1 applies.
:::

<1>10. Therefore \(\pi:A^r\to P\) is an isomorphism, and \(P\) is free.
::: {.proof}
By <1>9 the kernel of the surjection \(\pi\) is zero.
:::
:::

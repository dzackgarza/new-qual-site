::: problem
Suppose $A$ is a unital commutative ring.

(a) Suppose $I \trianglelefteq A$ (that means $I$ is an ideal of $A$) and $a \in A$.
Suppose $(I : \langle a \rangle) := \{r \in A \mid ra \in I\}$ and $I + \langle a \rangle$ are finitely generated ideals.
Prove that $I$ is finitely generated.

(b) Let $\Sigma := \{I \trianglelefteq A \mid I \text{ is not finitely generated}\}$.
Prove that, if $\Sigma$ is not empty, then with respect to the inclusion ordering, $\Sigma$ has a maximal element.

(c) Suppose $I$ is a maximal element of $\Sigma$.
Prove that $I$ is a prime ideal.
:::


::: {.solution}
**(a).**

<1>1. Choose generators
\[
I+(a)=(x_1,\dots,x_n),
\qquad
(I:(a))=(c_1,\dots,c_m).
\]
For each \(i\), write \(x_i=y_i+r_i a\) with \(y_i\in I\) and \(r_i\in A\).
::: {.proof}
The two ideals are finitely generated by hypothesis. Since \(x_i\in I+(a)\), each admits the displayed decomposition.
:::

<1>2. The ideal \(I\) is generated by
\[
y_1,\dots,y_n,ac_1,\dots,ac_m.
\]
::: {.proof}
Each listed element lies in \(I\): the \(y_i\) do by construction, and \(c_j a\in I\) because \(c_j\in(I:(a))\).

Conversely, let \(x\in I\). Since \(x\in I+(a)\), write
\[
x=\sum_i s_i x_i
=\sum_i s_i y_i+\left(\sum_i s_i r_i\right)a.
\]
Set \(r=\sum_i s_i r_i\). Because both \(x\) and \(\sum_i s_i y_i\) lie in \(I\), one has \(ra\in I\), so \(r\in(I:(a))\). Thus \(r=\sum_j t_j c_j\), and
\[
x=\sum_i s_i y_i+\sum_j t_j(ac_j).
\]
Hence the displayed finite set generates \(I\).
:::

**(b).**

<1>3. Every chain \(\mathcal C\subseteq\Sigma\) has an upper bound in \(\Sigma\), namely
\[
J=\bigcup_{I\in\mathcal C} I.
\]
::: {.proof}
Because \(\mathcal C\) is linearly ordered by inclusion, the union \(J\) is an ideal. If \(J\) were finitely generated, say by \(z_1,\dots,z_r\), then each \(z_i\) would lie in some member of the chain. Since the chain is linearly ordered and the set of generators is finite, one member \(I_0\in\mathcal C\) contains all \(z_i\). Then \(J=(z_1,\dots,z_r)\subseteq I_0\subseteq J\), so \(J=I_0\), contradicting \(I_0\in\Sigma\).
:::

<1>4. If \(\Sigma\ne\varnothing\), then \(\Sigma\) has a maximal element.
::: {.proof}
By <1>3 every chain in \(\Sigma\) has an upper bound in \(\Sigma\). Zorn's lemma therefore applies.
:::

**(c).**

<1>5. Let \(I\) be maximal in \(\Sigma\). Suppose \(ab\in I\) and \(a\notin I\). If also \(b\notin I\), then both \(I+(a)\) and \((I:(a))\) strictly contain \(I\).
::: {.proof}
The first containment is strict because \(a\notin I\). Since \(ab\in I\), one has \(b\in(I:(a))\); if \(b\notin I\), the second containment is also strict.
:::

<1>6. Under the hypotheses of <1>5, both \(I+(a)\) and \((I:(a))\) are finitely generated.
::: {.proof}
They are ideals properly containing the maximal element \(I\) of \(\Sigma\). Hence neither belongs to \(\Sigma\), so both are finitely generated.
:::

<1>7. Therefore \(I\) is prime.
::: {.proof}
If \(ab\in I\) with \(a,b\notin I\), then <1>6 and part (a) imply that \(I\) is finitely generated, contradicting \(I\in\Sigma\). Thus whenever \(ab\in I\), at least one of \(a,b\) lies in \(I\). Also \(I\ne A\), since \(A=(1)\) is finitely generated. Hence \(I\) is prime.
:::
:::

::: problem
Suppose $A$ is a unital commutative ring and $I, J \trianglelefteq A$.
Suppose $A/I$ is a flat $A$-module.

(a) Prove that $I$ is a flat $A$-module.
(State carefully the general statement that you are using.)

(b) Prove that there is an $A$-module isomorphism $\iota \colon I \otimes_A J \to IJ$ such that $\iota(a \otimes b) = ab$ for every $a \in I$ and $b \in J$.

(c) Prove that $IJ = I \cap J$.
:::


::: {.solution}
**(a).**

<1>1. We use the following general fact: if
\[
0\longrightarrow M'\longrightarrow M\longrightarrow M''\longrightarrow0
\]
is exact and both \(M\) and \(M''\) are flat, then \(M'\) is flat.
::: {.proof}
Let \(X\hookrightarrow Y\) be an injection. Because \(M''\) is flat, tensoring the displayed short exact sequence with either \(X\) or \(Y\) remains exact on the left, giving a commutative diagram with exact rows
\[
\begin{array}{ccccccccc}
0&\to&X\otimes M'&\to&X\otimes M&\to&X\otimes M''&\to&0\\
&&\downarrow&&\downarrow&&\downarrow\\
0&\to&Y\otimes M'&\to&Y\otimes M&\to&Y\otimes M''&\to&0.
\end{array}
\]
The middle vertical map is injective because \(M\) is flat. If an element of \(X\otimes M'\) maps to zero in \(Y\otimes M'\), its image in \(X\otimes M\) maps to zero in \(Y\otimes M\), hence is zero; exactness of the top row then forces the original element to be zero. Thus \(X\otimes M'\to Y\otimes M'\) is injective for every injection \(X\to Y\), so \(M'\) is flat.
:::

<1>2. The ideal \(I\), viewed as an \(A\)-module, is flat.
::: {.proof}
Apply <1>1 to
\[
0\longrightarrow I\longrightarrow A\longrightarrow A/I\longrightarrow0.
\]
The module \(A\) is free, hence flat, and \(A/I\) is flat by hypothesis.
:::

**(b).**

<1>3. Tensoring the injection \(J\hookrightarrow A\) with the flat module \(I\) gives an injection
\[
I\otimes_A J\longrightarrow I\otimes_A A\cong I.
\]
::: {.proof}
This is exactly the defining injectivity property of flatness, using <1>2.
:::

<1>4. Under the identification \(I\otimes_A A\cong I\), the map in <1>3 is
\[
\iota:I\otimes_A J\longrightarrow I,
\qquad
\iota(a\otimes b)=ab.
\]
Its image is \(IJ\).
::: {.proof}
The map is induced by the inclusion \(J\hookrightarrow A\), so a pure tensor \(a\otimes b\) maps to \(a\otimes b\), which corresponds to \(ab\) in \(I\otimes_A A\cong I\). The image is therefore the submodule generated by all products \(ab\) with \(a\in I\), \(b\in J\), namely \(IJ\).
:::

<1>5. Therefore multiplication induces an \(A\)-module isomorphism
\[
I\otimes_A J\xrightarrow{\sim}IJ.
\]
::: {.proof}
By <1>3 the multiplication map is injective, and by <1>4 its image is exactly \(IJ\).
:::

**(c).**

<1>6. Tensoring \(J\hookrightarrow A\) with the flat module \(A/I\) gives an injection
\[
(A/I)\otimes_A J\hookrightarrow (A/I)\otimes_A A\cong A/I.
\]
::: {.proof}
Flatness of \(A/I\) preserves the injection \(J\hookrightarrow A\).
:::

<1>7. Under the standard identification
\[
(A/I)\otimes_A J\cong J/IJ,
\]
the injection in <1>6 is
\[
J/IJ\longrightarrow A/I,
\qquad
j+IJ\longmapsto j+I.
\]
::: {.proof}
The isomorphism \((A/I)\otimes_A J\cong J/IJ\) is the usual quotient–tensor identity. The map is induced by \(J\hookrightarrow A\), hence sends the class of \(j\) to its class modulo \(I\).
:::

<1>8. The kernel of the map in <1>7 is
\[
(I\cap J)/IJ.
\]
Since the map is injective, \(I\cap J=IJ\).
::: {.proof}
A class \(j+IJ\) maps to zero in \(A/I\) exactly when \(j\in I\). Since \(j\in J\) already, the kernel consists precisely of the classes from \(I\cap J\). Injectivity from <1>6 makes this kernel zero, so \((I\cap J)/IJ=0\).
:::
:::

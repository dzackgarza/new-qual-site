::: {.problem}
Two homomorphisms $f_1,f_2:G_1\to G_2$ are called conjugate if there is $g\in G_2$ such that
\[
f_1(x)=g f_2(x)g^{-1}\qquad\text{for all }x\in G_1.
\]

1. Find all homomorphisms $S_3\to\CC^\times$.

2. Determine all homomorphisms $S_3\to S_3$ up to conjugation.

3. Prove that any two injective homomorphisms $S_3\to GL_2(\RR)$ are conjugate.
:::

::: {.solution}

Let
\[
S_3=\langle r,s\mid r^3=s^2=1,\ srs=r^{-1}\rangle,
\]
where
\[
r=(123),
\qquad
s=(12).
\]

## Part 1: homomorphisms \(S_3\to\CC^\times\)

::: pf

::: {.pf-step #s1-1}

The commutator subgroup of \(S_3\) is
\[
\boxed{[S_3,S_3]=A_3=\langle r\rangle}.
\]


::: pf-proof

The quotient
\[
S_3/A_3
\]
has order \(2\), hence is abelian, so
\[
[S_3,S_3]\subseteq A_3.
\]
On the other hand,
\[
[(12),(23)]
=
(12)(23)(12)(23)
=
(132),
\]
which generates \(A_3\). Hence equality holds.

:::

:::

::: {.pf-step #s1-2}

Since \(\CC^\times\) is abelian, every homomorphism
\[
f:S_3\to\CC^\times
\]
kills \(A_3\).


::: pf-proof

Every homomorphism to an abelian group kills the commutator subgroup. Apply step [](#s1-1){.pf-ref}.

:::

:::

::: {.pf-step #s1-3}

Therefore every such \(f\) factors uniquely through
\[
S_3/A_3\cong C_2.
\]


::: pf-proof

Use the universal property of the quotient by a subgroup contained in the kernel.

:::

:::

::: {.pf-step #s1-4}

A homomorphism
\[
C_2\to\CC^\times
\]
is determined by the image \(z\) of its nontrivial element, and \(z\) must satisfy
\[
z^2=1.
\]


::: pf-proof

The generator has order \(2\), so its image has order dividing \(2\).

:::

:::

::: {.pf-step #s1-5}

The only solutions of
\[
z^2=1
\]
in \(\CC^\times\) are
\[
\boxed{z=1,\ -1}.
\]


::: pf-proof

\[
z^2-1=(z-1)(z+1).
\]

:::

:::

::: {.pf-step #s1-6}

Hence there are exactly two homomorphisms
\[
S_3\to\CC^\times:
\]
the trivial homomorphism and the sign homomorphism.


::: pf-proof

The choice \(z=1\) gives the trivial map. The choice \(z=-1\) sends even permutations to \(1\) and odd permutations to \(-1\), which is the sign character.

:::

:::

::: {.pf-step #s1-7}

Thus
\[
\boxed{
\operatorname{Hom}(S_3,\CC^\times)
=
\{1,\operatorname{sgn}\}}.
\]


::: pf-proof

This is the classification from steps [](#s1-2){.pf-ref} through [](#s1-6){.pf-ref}.

:::

:::

::: {.pf-step #s1-8}

Its kernel is one of
\[
\boxed{
1,\quad A_3,\quad S_3}.
\]


::: pf-proof

The normal subgroups of \(S_3\) are exactly
\[
1,\ A_3,\ S_3.
\]
Indeed, a normal subgroup containing a transposition contains all three transpositions by conjugacy and hence generates \(S_3\); a nontrivial normal subgroup containing no transposition must contain a \(3\)-cycle and hence contains \(A_3\).

:::

:::

::: pf-step

If
\[
\ker f=S_3,
\]
then \(f\) is the trivial homomorphism.


::: pf-proof

Every element lies in the kernel.

:::

:::

::: {.pf-step #s1-10}

Thus this case contributes one conjugacy class.


::: pf-proof

There is only one trivial homomorphism.

:::

:::

::: pf-step

If
\[
\ker f=A_3,
\]
then
\[
\boxed{|f(S_3)|=2}.
\]


::: pf-proof

By the first isomorphism theorem,
\[
f(S_3)\cong S_3/A_3\cong C_2.
\]

:::

:::

::: pf-step

Every order-\(2\) subgroup of \(S_3\) is generated by a transposition.


::: pf-proof

The elements of order \(2\) in \(S_3\) are exactly the three transpositions.

:::

:::

::: {.pf-step #s1-13}

Any two order-\(2\) subgroups of \(S_3\) are conjugate.


::: pf-proof

All transpositions in \(S_3\) are conjugate.

:::

:::

::: {.pf-step #s1-14}

Therefore all homomorphisms with kernel \(A_3\) are conjugate.


::: pf-proof

Such a homomorphism factors as the quotient
\[
S_3\twoheadrightarrow S_3/A_3\cong C_2
\]
followed by an embedding of \(C_2\) as an order-\(2\) subgroup of \(S_3\). By step [](#s1-13){.pf-ref}, any two such embeddings differ by conjugation in \(S_3\).

:::

:::

::: pf-step

If
\[
\ker f=1,
\]
then \(f\) is an automorphism of \(S_3\).


::: pf-proof

The map is injective. Since domain and codomain both have \(6\) elements, it is also surjective.

:::

:::

::: pf-step

Every automorphism of \(S_3\) is inner.


::: pf-proof

An automorphism permutes the three transpositions. Thus there is an injective homomorphism
\[
\operatorname{Aut}(S_3)\hookrightarrow S_3
\]
given by its action on those three elements, so
\[
|\operatorname{Aut}(S_3)|\le6.
\]
The inner automorphism group has order
\[
|S_3/Z(S_3)|=6
\]
because \(Z(S_3)=1\). Hence every automorphism is inner.

:::

:::

::: {.pf-step #s1-17}

All automorphisms \(S_3\to S_3\) are conjugate as homomorphisms.


::: pf-proof

Write
\[
f(x)=axa^{-1},
\qquad
g(x)=bxb^{-1}.
\]
Then with
\[
c=ab^{-1},
\]
\[
c\,g(x)\,c^{-1}
=
ab^{-1}(bxb^{-1})ba^{-1}
=
axa^{-1}
=
f(x).
\]

:::

:::

::: {.pf-step #s1-18}

Hence, up to conjugation, there are exactly
\[
\boxed{3}
\]
homomorphisms \(S_3\to S_3\), represented by:
\[
\boxed{\text{the trivial map}},
\]
\[
\boxed{\text{the quotient }S_3\to S_3/A_3\cong C_2
\text{ followed by }C_2=\langle(12)\rangle\hookrightarrow S_3},
\]
and
\[
\boxed{\text{the identity automorphism}}.
\]


::: pf-proof

The three possible kernels in step [](#s1-8){.pf-ref} are invariant under conjugating the target homomorphism, so the three cases cannot be conjugate to one another. Steps [](#s1-10){.pf-ref} and [](#s1-14){.pf-ref}, and [](#s1-17){.pf-ref} show there is exactly one class for each kernel.

:::

:::

::: pf-step

There exists a positive-definite inner product on \(\RR^2\) invariant under \(\rho(S_3)\).


::: pf-proof

Start with the standard inner product \(\langle-,-\rangle_0\) and define
\[
\langle v,w\rangle_\rho
=
\sum_{g\in S_3}
\langle \rho(g)v,\rho(g)w\rangle_0.
\]
This is positive definite. For \(h\in S_3\),
\[
\begin{aligned}
\langle \rho(h)v,\rho(h)w\rangle_\rho
&=
\sum_{g\in S_3}
\langle \rho(gh)v,\rho(gh)w\rangle_0\\
&=
\langle v,w\rangle_\rho,
\end{aligned}
\]
because \(g\mapsto gh\) permutes \(S_3\).

:::

:::

::: {.pf-step #s1-20}

After a change of basis, \(\rho(S_3)\) lies in \(O(2)\).


::: pf-proof

Choose an isometry from the invariant inner-product space
\[
(\RR^2,\langle-,-\rangle_\rho)
\]
to the standard Euclidean plane. Conjugating \(\rho\) by that linear isomorphism makes every \(\rho(g)\) orthogonal.

:::

:::

::: pf-step

The subgroup
\[
\rho(A_3)
\]
has order \(3\) and lies in \(SO(2)\).


::: pf-proof

Injectivity gives
\[
|\rho(A_3)|=3.
\]
The determinant restricted to \(\rho(A_3)\) is a homomorphism from a group of odd order \(3\) to \(\{\pm1\}\), so it is trivial. Hence every element has determinant \(1\).

:::

:::

::: {.pf-step #s1-22}

A generator of \(\rho(A_3)\) is rotation by angle
\[
\boxed{\pm 2\pi/3}.
\]


::: pf-proof

A nonidentity element of \(SO(2)\) of order \(3\) must be rotation by an angle \(\theta\) satisfying
\[
3\theta\equiv0\pmod{2\pi}
\]
but
\[
\theta\not\equiv0.
\]
Thus
\[
\theta=\pm2\pi/3.
\]

:::

:::

::: pf-step

The image of any transposition has determinant \(-1\).


::: pf-proof

Let \(s\) be a transposition. If \(\det\rho(s)=1\), then \(\rho(s)\in SO(2)\). Since \(\rho(s)\) has order \(2\), it would be the rotation by \(\pi\), which commutes with \(\rho(A_3)\). Then \(\rho(s)\) would commute with \(\rho((123))\), contradicting injectivity because \(s\) does not commute with \((123)\) in \(S_3\).

:::

:::

::: {.pf-step #s1-24}

Hence the image of every transposition is a reflection.


::: pf-proof

An orthogonal \(2\times2\) matrix with determinant \(-1\) and order \(2\) is reflection across a line through the origin.

:::

:::

::: {.pf-step #s1-25}

Therefore, after orthogonal conjugation, every injective \(\rho\) has image equal to the standard dihedral symmetry group of an equilateral triangle.


::: pf-proof

By step [](#s1-22){.pf-ref}, conjugate by an orthogonal map so that \(\rho((123))\) is the standard rotation through \(2\pi/3\). By step [](#s1-24){.pf-ref}, \(\rho((12))\) is reflection across some line. Conjugating further by a rotation, which commutes with the \(2\pi/3\) rotation, moves that reflection axis to the \(x\)-axis. The relations
\[
r^3=s^2=1,
\qquad
srs=r^{-1}
\]
then generate exactly the standard order-\(6\) dihedral subgroup of \(O(2)\).

:::

:::

::: {.pf-step #s1-26}

Consequently, any two injective homomorphisms
\[
\rho_1,\rho_2:S_3\to GL_2(\RR)
\]
are conjugate.


::: pf-proof

By step [](#s1-20){.pf-ref}, choose
\[
A_1,A_2\in GL_2(\RR)
\]
such that
\[
A_i\rho_i(-)A_i^{-1}
\]
lands in \(O(2)\). By step [](#s1-25){.pf-ref}, after additional orthogonal conjugations both representations become the same standard dihedral representation. Undoing the changes of basis gives some
\[
A\in GL_2(\RR)
\]
with
\[
\rho_1(g)=A\rho_2(g)A^{-1}
\]
for all \(g\in S_3\).

:::

:::

::: pf-qed

Step [](#s1-7){.pf-ref} classifies the homomorphisms to \(\CC^\times\), step [](#s1-18){.pf-ref} classifies the homomorphisms \(S_3\to S_3\) up to conjugation, and step [](#s1-26){.pf-ref} proves conjugacy of all injective \(2\)-dimensional real representations.

::: {.problem}
Let f be analytic on a domain D and let $\gamma$ be a closed curve in $D .$ . For any $z _ { 0 }$ in $D$ not on $\gamma ,$ show that

$$
\int _ { \gamma } \frac { f ^ { \prime } ( z ) } { ( z - z _ { 0 } ) } d z = \int _ { \gamma } \frac { f ( z ) } { ( z - z _ { 0 } ) ^ { 2 } } d z
$$

Give a generalization of this result.
:::

::: pf

::: pf-step

The function
$$
F(z)=\frac{f(z)}{z-z_0}
$$
is holomorphic on a neighborhood of the image of $\gamma$.


::: pf-proof

The function $f$ is analytic on $D$, and $z_0$ does not lie on $\gamma$. Since the compact image of the curve is disjoint from $z_0$, it has a neighborhood in $D\setminus\{z_0\}$. On this neighborhood, both $f$ and $(z-z_0)^{-1}$ are holomorphic, hence so is their product $F$.

:::

:::

::: pf-step

One has
$$
\int_\gamma F'(z)\,dz=0.
$$


::: pf-proof

Let $\gamma:[a,b]\to D$ be a piecewise smooth parametrization with $\gamma(a)=\gamma(b)$. By the chain rule,
$$
\int_\gamma F'(z)\,dz
=\int_a^b F'(\gamma(t))\gamma'(t)\,dt
=\int_a^b\frac{d}{dt}F(\gamma(t))\,dt.
$$
Thus
$$
\int_\gamma F'(z)\,dz
=F(\gamma(b))-F(\gamma(a))
=0.
$$

:::

:::

::: pf-step

One has
$$
\boxed{
\int_\gamma\frac{f'(z)}{z-z_0}\,dz
=
\int_\gamma\frac{f(z)}{(z-z_0)^2}\,dz}.
$$


::: pf-proof

Differentiating $F$ gives
$$
F'(z)
=\frac{f'(z)}{z-z_0}
-\frac{f(z)}{(z-z_0)^2}.
$$
Integrating this identity over $\gamma$ and using step <1>2 gives the asserted equality.

:::

:::

::: pf-step

More generally, for integers $j\geq0$ and $m\geq1$,
$$
\int_\gamma\frac{f^{(j+1)}(z)}{(z-z_0)^m}\,dz
=m\int_\gamma\frac{f^{(j)}(z)}{(z-z_0)^{m+1}}\,dz.
$$


::: pf-proof

Apply step <1>2 to the function
$$
F_{j,m}(z)=\frac{f^{(j)}(z)}{(z-z_0)^m},
$$
which is holomorphic on a neighborhood of the image of $\gamma$. Its derivative is
$$
F_{j,m}'(z)
=\frac{f^{(j+1)}(z)}{(z-z_0)^m}
-m\frac{f^{(j)}(z)}{(z-z_0)^{m+1}}.
$$
The integral of this derivative over $\gamma$ is zero, yielding the formula.

:::

:::

::: pf-step

Consequently, for all integers $n\geq0$ and $m\geq1$,
$$
\boxed{
\int_\gamma\frac{f^{(n)}(z)}{(z-z_0)^m}\,dz
=m(m+1)\cdots(m+n-1)
\int_\gamma\frac{f(z)}{(z-z_0)^{m+n}}\,dz,}
$$
where the empty product for $n=0$ is $1$.


::: pf-proof

Apply step <1>4 successively, first with $(j,m)=(n-1,m)$, then $(n-2,m+1)$, and so on down to $(0,m+n-1)$. The resulting coefficients multiply to
$$
m(m+1)\cdots(m+n-1).
$$
For $n=1$ and $m=1$, this specializes to the identity in step <1>3.

:::

:::

::: pf-qed

Step <1>3 proves the stated identity, and step <1>5 gives the requested generalization.

:::

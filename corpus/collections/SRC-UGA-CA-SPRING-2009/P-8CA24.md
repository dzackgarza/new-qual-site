::: {.problem}
How many roots does the equation
$$
z^7-4z^3+z-1=0
$$
have in the open disk $\abs{z}<1$?
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.

Write $P(z)=z^7-4z^3+z-1$, $h(z)=-4z^3$ and $g(z)=z^7+z-1$, so that $P=h+g$.

::: pf

::: {.pf-step #dominated}
$\abs{g(z)}<\abs{h(z)}$ for every $z$ with $\abs{z}=1$.

::: pf-proof
Let $\abs{z}=1$. Then $\abs{z^7}=\abs{z}^7=1$ and $\abs{z}=1$, so
$$
\abs{g(z)}=\abs{z^7+z-1}\le\abs{z^7}+\abs{z}+1=3<4=4\abs{z}^3=\abs{h(z)},
$$
using the triangle inequality and $\abs{-4z^3}=4\abs{z}^3=4$.
:::

:::

::: {.pf-step #rouche}
$P$ and $h$ have the same number of zeros in $\abs{z}<1$, counted with multiplicity.

::: pf-proof
$P$, $h$ and $g$ are polynomials, hence holomorphic on the whole plane, and the closed disk $\abs{z}\le1$ is a closed curve boundary $\abs{z}=1$ on which both are nonzero and step [](#dominated){.pf-ref} holds. Rouché's theorem then gives that $h$ and $h+g=P$ have the same number of zeros inside the circle, counted with multiplicity.
:::

:::

::: {.pf-step #zerosofh}
$h(z)=-4z^3$ has exactly $3$ zeros in $\abs{z}<1$, counted with multiplicity.

::: pf-proof
$-4z^3=0$ exactly when $z=0$, which lies in $\abs{z}<1$, and the zero at $0$ has multiplicity $3$ because $-4z^3$ is $-4$ times $z^3$.
:::

:::

::: {.pf-step}
$z^7-4z^3+z-1$ has exactly $3$ roots in $\abs{z}<1$, counted with multiplicity.

::: pf-proof
Steps [](#rouche){.pf-ref} and [](#zerosofh){.pf-ref} give the count for $P$, which is $3$.
:::

::: {.problem}
(a) Show that $\dfrac{\pi^2}{\sin^2\pi z}$ and
\[
g(z)=\sum_{n=-\infty}^{\infty}\frac{1}{(z-n)^2}
\]
have the same principal part at each integer point.

(b) Conclude that
\[
\frac{\pi^2}{\sin^2\pi z}=\sum_{n=-\infty}^{\infty}\frac{1}{(z-n)^2}.
\]
:::

::: {.solution}
**(a).**

::: pf

::: pf-step
$\sin \pi z$ has a simple zero at each integer $n$, so $\frac{\pi^2}{\sin^2 \pi z}$ has a double pole at each integer.

::: pf-proof
$\sin(\pi z) = \pi(z - n) + O((z-n)^3)$ near $z = n$.
:::

:::

::: {.pf-step #p1-2}
Near $z = n$, $\sin \pi z = \pi(z-n) - \frac{\pi^3}{6}(z-n)^3 + \cdots$, so $\sin^2 \pi z = \pi^2(z-n)^2 - \frac{\pi^4}{3}(z-n)^4 + \cdots$.

::: pf-proof
Taylor expansion.
:::

:::

::: {.pf-step #p1-3}
Hence $\frac{\pi^2}{\sin^2 \pi z} = \frac{1}{(z-n)^2} + O(1)$ near $z = n$ (the principal part is exactly $\frac{1}{(z-n)^2}$).

::: pf-proof
Step [](#p1-2){.pf-ref}, inverting the series.
:::

:::

::: {.pf-step #p1-4}
The term $\frac{1}{(z-n)^2}$ in $g(z)$ has principal part $\frac{1}{(z-n)^2}$ at $z = n$, and all other terms of $g$ are holomorphic at $z = n$.

::: pf-proof
each term $\frac{1}{(z-m)^2}$ for $m \neq n$ is holomorphic near $z = n$.
:::

:::

::: {.pf-step #p1-5}
Hence $\frac{\pi^2}{\sin^2 \pi z}$ and $g(z)$ have the same principal part $\frac{1}{(z-n)^2}$ at each integer $n$.

::: pf-proof
Steps [](#p1-3){.pf-ref} and [](#p1-4){.pf-ref}.
:::

:::

:::

**(b).**

::: pf

::: pf-step
Let $h(z) = \frac{\pi^2}{\sin^2 \pi z} - g(z)$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #p2-2}
$h$ is entire (the principal parts cancel at every integer by (a)).

::: pf-proof
Step [](#p1-5){.pf-ref} (a) (both functions have the same principal parts, so their difference has removable singularities at every integer).
:::

:::

::: {.pf-step #p2-3}
$h$ is bounded.

::: pf-proof
both $\frac{\pi^2}{\sin^2 \pi z}$ and $g(z)$ are bounded on the complement of a neighborhood of the integers (they are periodic and tend to $0$ as $|\operatorname{Im} z| \to \infty$), and $h$ is continuous (entire), so $h$ is bounded.
:::

:::

::: {.pf-step #p2-4}
By Liouville's theorem, $h$ is constant.

::: pf-proof
Steps [](#p2-2){.pf-ref} and [](#p2-3){.pf-ref}.
:::

:::

::: {.pf-step #p2-5}
$h \to 0$ as $\operatorname{Im} z \to \infty$ (both terms tend to $0$), so the constant is $0$.

::: pf-proof
Step [](#p2-4){.pf-ref} and the decay.
:::

:::

::: {.pf-step #p2-6}
Hence $\frac{\pi^2}{\sin^2 \pi z} = g(z) = \sum_{n=-\infty}^{\infty} \frac{1}{(z-n)^2}$.

::: pf-proof
Step [](#p2-5){.pf-ref}.
:::

:::

::: pf-qed
Step [](#p1-5){.pf-ref} (a) and step [](#p2-6){.pf-ref} (b).
:::

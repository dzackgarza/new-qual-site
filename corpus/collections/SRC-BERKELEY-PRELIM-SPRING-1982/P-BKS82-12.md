::: {.problem}
Let $X\subset\mathbb R^n$ be connected and locally path connected. Prove that $X$ is path connected.
:::

::: {.solution}
Fix a point $x_0\in X$, and let
$$
P\coloneqq
\{x\in X:\text{there is a path in }X\text{ from }x_0\text{ to }x\}.
$$

<1>1. The set $P$ is open in $X$.

::: {.proof}
Let $x\in P$. Since $X$ is locally path connected, there is an open
neighborhood $U$ of $x$ in $X$ that is path connected. For every $y\in U$,
there is a path in $U$ from $x$ to $y$. Since $x\in P$, there is also a
path in $X$ from $x_0$ to $x$. Concatenating these paths gives a path in
$X$ from $x_0$ to $y$, so $y\in P$. Thus
$$
U\subset P,
$$
and $P$ is open.
:::

<1>2. Every path component of $X$ is open in $X$.

::: {.proof}
The argument of step <1>1 uses only that the chosen point lies in a fixed
path component. Applying the same argument with any path component in place
of $P$ shows that every path component is open.
:::

<1>3. The set $P$ is closed in $X$.

::: {.proof}
The complement $X\setminus P$ is the union of all path components other
than $P$. Each of those components is open by step <1>2, so their union is
open. Hence $P$ is closed.
:::

<1>4. One has
$$
P=X.
$$

::: {.proof}
The set $P$ is nonempty because $x_0\in P$. By steps <1>1 and <1>3 it is
both open and closed in the connected space $X$. Therefore $P=X$.
:::

<1>5. Thus $X$ is path connected.

::: {.proof}
By step <1>4, every point of $X$ can be joined to $x_0$ by a path in $X$.
Given $x,y\in X$, concatenate a path from $x$ to $x_0$ with a path from
$x_0$ to $y$. This gives a path from $x$ to $y$.
:::

<1>6. Q.E.D.

::: {.proof}
Step <1>5 is the required conclusion.
:::
:::

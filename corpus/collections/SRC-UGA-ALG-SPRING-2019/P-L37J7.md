::: {.problem}
Let $R$ be an integral domain. The **rank** of an $R$-module $M$ is defined to be the maximal number of $R$-linearly independent elements in $M$ (or $\infty$ if arbitrarily large finite linearly independent subsets exist).

(a) Prove that for any $R$-module $M$, $\operatorname{rank}(\operatorname{tor}(M)) = 0$.

(b) Prove that $\operatorname{rank}(M) = \operatorname{rank}(M/\operatorname{tor}(M))$.

(c) Suppose that $M = I \subseteq R$ is a non-principal ideal of $R$. Prove that $M$ is torsion-free of rank 1, but is not a free $R$-module.
:::

::: {.solution}
**Goal:** Prove that torsion modules have rank 0 in (a), that rank is invariant under quotienting by the torsion submodule in (b), and that non-principal ideals in an integral domain are torsion-free of rank 1 but not free in (c).

::: pf

::: pf-step
Part (a): $\operatorname{rank}(\operatorname{tor}(M)) = 0$.

::: pf-proof

::: pf-step
A set $S \subseteq \operatorname{tor}(M)$ is linearly independent over $R$ if for every finite distinct subset $\{x_1, \dots, x_k\} \subseteq S$, $\sum_{i=1}^k c_i x_i = 0 \implies c_i = 0$ for all $i$.
:::

::: pf-step
If $S$ contains at least one element $x \in \operatorname{tor}(M)$, then by definition of torsion, there exists a non-zero ring element $r \in R \setminus \{0\}$ such that $r x = 0$.
:::

::: pf-step
The single-element relation $r x = 0$ with $r \ne 0$ shows that $\{x\}$ is linearly dependent over $R$.
:::

::: pf-step
Thus no non-empty subset of $\operatorname{tor}(M)$ is linearly independent.
:::

::: pf-step
Therefore $\operatorname{rank}(\operatorname{tor}(M)) = 0$.
:::

:::

:::

::: pf-step
Part (b): $\operatorname{rank}(M) = \operatorname{rank}(M/\operatorname{tor}(M))$.

::: pf-proof

::: pf-step
Let $\pi: M \to M/\operatorname{tor}(M)$ be the canonical projection, and denote $\bar{m} = \pi(m) = m + \operatorname{tor}(M)$.
:::

::: pf-step
Substep 1 ($\operatorname{rank}(M) \ge \operatorname{rank}(M/\operatorname{tor}(M))$):

::: pf-proof
Suppose $\{\bar{m}_1, \dots, \bar{m}_k\} \subseteq M/\operatorname{tor}(M)$ is linearly independent over $R$. Let $c_1, \dots, c_k \in R$ such that $\sum_{i=1}^k c_i m_i = 0$ in $M$. Applying $\pi$, we have $\sum_{i=1}^k c_i \bar{m}_i = \bar{0}$. By linear independence of $\{\bar{m}_i\}$, $c_1 = \dots = c_k = 0$. Thus $\{m_1, \dots, m_k\}$ is linearly independent in $M$. This shows that any linearly independent set in $M/\operatorname{tor}(M)$ lifts to a linearly independent set of the same cardinality in $M$, so $\operatorname{rank}(M) \ge \operatorname{rank}(M/\operatorname{tor}(M))$.
:::

:::

::: pf-step
Substep 2 ($\operatorname{rank}(M/\operatorname{tor}(M)) \ge \operatorname{rank}(M)$):

::: pf-proof
Suppose $\{m_1, \dots, m_k\} \subseteq M$ is linearly independent over $R$. Let $c_1, \dots, c_k \in R$ such that $\sum_{i=1}^k c_i \bar{m}_i = \bar{0}$ in $M/\operatorname{tor}(M)$. This means that the element $w = \sum_{i=1}^k c_i m_i \in \operatorname{tor}(M)$. By definition of torsion, there exists a non-zero element $r \in R \setminus \{0\}$ such that $r w = 0$, which gives
$$\sum_{i=1}^k (r c_i) m_i = 0 \quad \text{in } M.$$
Since $\{m_1, \dots, m_k\}$ is linearly independent in $M$, $r c_i = 0$ for all $1 \le i \le k$. Since $R$ is an integral domain and $r \ne 0$, it follows that $c_i = 0$ for all $i$. Thus $\{\bar{m}_1, \dots, \bar{m}_k\}$ is linearly independent in $M/\operatorname{tor}(M)$. Therefore $\operatorname{rank}(M/\operatorname{tor}(M)) \ge \operatorname{rank}(M)$.
:::

:::

::: pf-step
Combining both inequalities yields $\operatorname{rank}(M) = \operatorname{rank}(M/\operatorname{tor}(M))$.
:::

:::

:::

::: pf-step
Part (c): $M = I$ is torsion-free of rank 1, but not free.

::: pf-proof

::: pf-step
$I$ is torsion-free:

::: pf-proof
Regard $I \subseteq R$ as an $R$-submodule of the regular module $R$. If $r \in R \setminus \{0\}$ and $x \in I$ satisfy $r x = 0$, then since $R$ is an integral domain, $r \ne 0 \implies x = 0$. Thus $\operatorname{tor}(I) = \{0\}$, so $I$ is torsion-free.
:::

:::

::: pf-step
$I$ has rank 1:

::: pf-proof
Since $I$ is non-principal, $I \ne \{0\}$, so there exists a non-zero element $x \in I \setminus \{0\}$. Since $I$ is torsion-free, the single element $\{x\}$ is linearly independent over $R$, so $\operatorname{rank}(I) \ge 1$. For any two non-zero elements $x, y \in I$, consider the linear combination:
$$y \cdot x + (-x) \cdot y = y x - x y = 0,$$
using commutativity of $R$. Since $x, y \ne 0$, the coefficients $y \ne 0$ and $-x \ne 0$ provide a non-trivial linear relation between $x$ and $y$. Thus no two elements in $I$ can be linearly independent, which implies $\operatorname{rank}(I) \le 1$. Hence $\operatorname{rank}(I) = 1$.
:::

:::

::: pf-step
$I$ is not a free $R$-module:

::: pf-proof
Suppose for contradiction that $I$ is free over $R$ with basis $\mathcal{B} \subset I$. Since $\operatorname{rank}(I) = 1$, the basis must have cardinality $|\mathcal{B}| = 1$ (if $|\mathcal{B}| \ge 2$, any two distinct basis elements would be linearly independent, contradicting $\operatorname{rank}(I) = 1$; if $\mathcal{B} = \emptyset$, $I = \{0\}$, which is principal). Let $\mathcal{B} = \{a\}$. Then $I = R a = \langle a \rangle$, which means $I$ is a principal ideal, contradicting the hypothesis that $I$ is non-principal. Thus $I$ cannot be free.
:::

:::

:::

:::

::: pf-step
Conclusion:

::: pf-proof
$\operatorname{rank}(\operatorname{tor}(M)) = 0$, $\operatorname{rank}(M) = \operatorname{rank}(M/\operatorname{tor}(M))$, and non-principal ideals in integral domains are torsion-free of rank 1 but not free.
:::

::: problem
For a finite group $G$, let $c(G)$ denote the number of conjugacy classes of $G$.

(a) Prove that if two elements of $G$ are chosen uniformly at random, then the probability that they commute is precisely
$$
\mathbb{P}(g h = h g) = \frac{c(G)}{|G|}.
$$

(b) State the class equation for a finite group $G$.

(c) Using the class equation, show that the probability in part (a) satisfies
$$
\mathbb{P}(g h = h g) \le \frac{1}{2} + \frac{1}{2[G : Z(G)]},
$$
where $Z(G)$ denotes the center of $G$.
:::

::: solution
**Goal:** Compute the commuting probability of a finite group using Burnside's Lemma in (a), state the class equation in (b), and derive the upper bound in (c).

<1>1. Part (a): Commuting probability equals $c(G)/|G|$.
    *Proof:*
    <2>1. The sample space of pairs is $\Omega = G \times G$, which has cardinality $|\Omega| = |G|^2$.
    <2>2. Let $\mathcal{C} = \{(g, h) \in G \times G : g h = h g\}$ be the commuting event.
    <2>3. For each $g \in G$, let $C_G(g) = \{h \in G : g h = h g\}$ denote the centralizer of $g$ in $G$.
    <2>4. Summing centralizer cardinalities gives:
    $$|\mathcal{C}| = \sum_{g \in G} |C_G(g)|.$$
    <2>5. Consider the group action of $G$ on itself by conjugation: $g \cdot x = g x g^{-1}$.
    <2>6. The orbits of this action are the conjugacy classes of $G$, so the number of orbits is $|G/G| = c(G)$.
    <2>7. For any element $g \in G$, the fixed point set of the conjugation map by $g$ is
    $$\operatorname{Fix}(g) = \{x \in G : g x g^{-1} = x\} = \{x \in G : g x = x g\} = C_G(g).$$
    <2>8. By Burnside's Lemma (the Orbit-Counting Theorem):
    $$c(G) = \frac{1}{|G|} \sum_{g \in G} |\operatorname{Fix}(g)| = \frac{1}{|G|} \sum_{g \in G} |C_G(g)| = \frac{|\mathcal{C}|}{|G|}.$$
    <2>9. Therefore $|\mathcal{C}| = c(G) |G|$.
    <2>10. The probability that two uniformly chosen elements commute is
    $$\mathbb{P}(g h = h g) = \frac{|\mathcal{C}|}{|\Omega|} = \frac{c(G) |G|}{|G|^2} = \frac{c(G)}{|G|}.$$

<1>2. Part (b): Statement of the Class Equation.
    *Proof:*
    <2>1. For any finite group $G$, let $x_1, \dots, x_m \in G$ be representatives of the distinct conjugacy classes of size strictly greater than 1 (i.e. classes outside the center $Z(G)$).
    <2>2. The class equation states:
    $$|G| = |Z(G)| + \sum_{i=1}^m [G : C_G(x_i)],$$
    where each $[G : C_G(x_i)] = |\mathcal{O}(x_i)| \ge 2$ is the size of the conjugacy class of $x_i$.

<1>3. Part (c): Upper bound via the Class Equation.
    *Proof:*
    <2>1. The total number of conjugacy classes is $c(G) = |Z(G)| + m$, since every central element forms a singleton conjugacy class, and there are $m$ non-central conjugacy classes.
    <2>2. In the class equation from Part (b), each of the $m$ terms satisfies $[G : C_G(x_i)] \ge 2$.
    <2>3. Therefore:
    $$|G| = |Z(G)| + \sum_{i=1}^m [G : C_G(x_i)] \ge |Z(G)| + \sum_{i=1}^m 2 = |Z(G)| + 2 m.$$
    <2>4. Rearranging gives an upper bound on $m$:
    $$2 m \le |G| - |Z(G)| \implies m \le \frac{|G| - |Z(G)|}{2}.$$
    <2>5. Substitute this bound into the expression for $c(G)$:
    $$c(G) = |Z(G)| + m \le |Z(G)| + \frac{|G| - |Z(G)|}{2} = \frac{|G| + |Z(G)|}{2}.$$
    <2>6. Dividing by $|G|$:
    $$\frac{c(G)}{|G|} \le \frac{|G| + |Z(G)|}{2 |G|} = \frac{1}{2} + \frac{|Z(G)|}{2 |G|} = \frac{1}{2} + \frac{1}{2 [G : Z(G)]}.$$
    <2>7. By Part (a), $\mathbb{P}(g h = h g) = \frac{c(G)}{|G|} \le \frac{1}{2} + \frac{1}{2 [G : Z(G)]}$.

<1>4. Conclusion:
    *Proof:*
    The commuting probability is $c(G)/|G|$ by Burnside's Lemma and is bounded above by $\frac{1}{2} + \frac{1}{2 [G : Z(G)]}$ via the class equation.
:::

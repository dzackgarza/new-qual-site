::: {.problem}
For a finite group $G$, let $c(G)$ denote the number of conjugacy classes of $G$.

(a) Prove that if two elements of $G$ are chosen uniformly at random, then the probability that they commute is precisely
$$
\Prob(g h = h g) = \frac{c(G)}{\cardinality{G}}.
$$

(b) State the class equation for a finite group $G$.

(c) Using the class equation, show that the probability in part (a) satisfies
$$
\Prob(g h = h g) \le \frac{1}{2} + \frac{1}{2[G : Z(G)]},
$$
where $Z(G)$ denotes the center of $G$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

The probability that two independently uniformly selected elements of $G$ commute is
$$
\boxed{\Prob(gh=hg)=\frac{c(G)}{\cardinality{G}}}.
$$

::: pf-proof

::: pf-step

The sample space of pairs is $\Omega = G \times G$, which has cardinality $\cardinality{\Omega} = \cardinality{G}^2$.

:::

::: pf-step

Let $\mathcal{C} = \{(g, h) \in G \times G : g h = h g\}$ be the commuting event.

:::

::: pf-step

For each $g \in G$, let $C_G(g) = \{h \in G : g h = h g\}$ denote the centralizer of $g$ in $G$.

:::

::: pf-step

Summing centralizer cardinalities gives:
    $$\cardinality{\mathcal{C}} = \sum_{g \in G} \cardinality{C_G(g)}.$$

:::

::: pf-step

Consider the group action of $G$ on itself by conjugation: $g \cdot x = g x g^{-1}$.

:::

::: pf-step

The orbits of this action are the conjugacy classes of $G$, so the number of orbits is $\cardinality{G/G} = c(G)$.

:::

::: pf-step

For any element $g \in G$, the fixed point set of the conjugation map by $g$ is
    $$\operatorname{Fix}(g) = \{x \in G : g x g^{-1} = x\} = \{x \in G : g x = x g\} = C_G(g).$$

:::

::: pf-step

By Burnside's Lemma (the Orbit-Counting Theorem):
    $$c(G) = \frac{1}{\cardinality{G}} \sum_{g \in G} \cardinality{\operatorname{Fix}(g)} = \frac{1}{\cardinality{G}} \sum_{g \in G} \cardinality{C_G(g)} = \frac{\cardinality{\mathcal{C}}}{\cardinality{G}}.$$

:::

::: pf-step

Therefore $\cardinality{\mathcal{C}} = c(G) \cardinality{G}$.

:::

::: pf-step

The probability that two uniformly chosen elements commute is

:::

$$\Prob(g h = h g) = \frac{\cardinality{\mathcal{C}}}{\cardinality{\Omega}} = \frac{c(G) \cardinality{G}}{\cardinality{G}^2} = \frac{c(G)}{\cardinality{G}}.$$

:::

:::

::: {.pf-step #s2}

The class equation is
$$
\boxed{\cardinality{G}=\cardinality{Z(G)}+\sum_{i=1}^m[G:C_G(x_i)]},
$$
where the $x_i$ represent the noncentral conjugacy classes.

::: pf-proof

::: pf-step

For any finite group $G$, let $x_1, \dots, x_m \in G$ be representatives of the distinct conjugacy classes of size strictly greater than 1 (i.e. classes outside the center $Z(G)$).

:::

::: pf-step

The class equation states:

:::

$$\cardinality{G} = \cardinality{Z(G)} + \sum_{i=1}^m [G : C_G(x_i)],$$
where each $[G : C_G(x_i)] = \cardinality{\mathcal{O}(x_i)} \ge 2$ is the size of the conjugacy class of $x_i$.

:::

:::

::: {.pf-step #s3}

The commuting probability satisfies
$$
\boxed{\Prob(gh=hg)\leq\frac12+\frac1{2[G:Z(G)]}}.
$$

::: pf-proof

::: pf-step

The total number of conjugacy classes is $c(G) = \cardinality{Z(G)} + m$, since every central element forms a singleton conjugacy class, and there are $m$ non-central conjugacy classes.

:::

::: pf-step

In the class equation from Part (b), each of the $m$ terms satisfies $[G : C_G(x_i)] \ge 2$.

:::

::: pf-step

Therefore:
    $$\cardinality{G} = \cardinality{Z(G)} + \sum_{i=1}^m [G : C_G(x_i)] \ge \cardinality{Z(G)} + \sum_{i=1}^m 2 = \cardinality{Z(G)} + 2 m.$$

:::

::: pf-step

Rearranging gives an upper bound on $m$:
    $$2 m \le \cardinality{G} - \cardinality{Z(G)} \implies m \le \frac{\cardinality{G} - \cardinality{Z(G)}}{2}.$$

:::

::: pf-step

Substitute this bound into the expression for $c(G)$:
    $$c(G) = \cardinality{Z(G)} + m \le \cardinality{Z(G)} + \frac{\cardinality{G} - \cardinality{Z(G)}}{2} = \frac{\cardinality{G} + \cardinality{Z(G)}}{2}.$$

:::

::: pf-step

Dividing by $\cardinality{G}$:
    $$\frac{c(G)}{\cardinality{G}} \le \frac{\cardinality{G} + \cardinality{Z(G)}}{2 \cardinality{G}} = \frac{1}{2} + \frac{\cardinality{Z(G)}}{2 \cardinality{G}} = \frac{1}{2} + \frac{1}{2 [G : Z(G)]}.$$

:::

::: pf-step

By Part (a), $\Prob(g h = h g) = \frac{c(G)}{\cardinality{G}} \le \frac{1}{2} + \frac{1}{2 [G : Z(G)]}$.

:::

::: problem
Let $X$ be a topological space and let $f,g:X\to\mathbb R$ be continuous functions.

(a) Show that the set $L=\{p\in X:f(p)\le g(p)\}$ is a closed subset of $X$.

(b) Show that the function $h:X\to\mathbb R$ given by $h(p)=\min\{f(p),g(p)\}$ is continuous.
:::

::: {.solution}
**Part (a).**

<1>1. $L = \{p : f(p) - g(p) \le 0\} = (f - g)^{-1}((-\infty, 0])$.
Proof: rewrite the condition.

<1>2. $f - g$ is continuous.
Proof: the difference of continuous functions is continuous.

<1>3. $(-\infty, 0]$ is closed in $\RR$.
Proof: standard.

<1>4. Hence $L = (f-g)^{-1}((-\infty, 0])$ is closed.
Proof: the preimage of a closed set under a continuous map is closed.

**Part (b).**

<1>1. $h(p) = \min\{f(p), g(p)\} = \frac{f(p) + g(p) - |f(p) - g(p)|}{2}$.
Proof: the identity $\min\{a, b\} = \frac{a + b - |a - b|}{2}$.

<1>2. $h$ is continuous.
Proof: $h$ is a composition of continuous functions (addition, subtraction, absolute value, and division by $2$), all of which are continuous.

<1>3. Q.E.D.
Proof: <1>4 (a) and <1>2 (b).
:::

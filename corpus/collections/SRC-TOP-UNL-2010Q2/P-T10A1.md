::: problem
Let $X$ be a topological space and let $f,g:X\to\mathbb R$ be continuous functions.

(a) Show that the set $L=\{p\in X:f(p)\le g(p)\}$ is a closed subset of $X$.

(b) Show that the function $h:X\to\mathbb R$ given by $h(p)=\min\{f(p),g(p)\}$ is continuous.
:::

::: {.solution}
<1>1. The function
\[
f-g:X\longrightarrow\mathbb R
\]
is continuous.
::: {.proof}
The map
\[
(f,g):X\longrightarrow\mathbb R^2,
\qquad
p\longmapsto(f(p),g(p)),
\]
is continuous because both coordinate functions are continuous.
The subtraction map
\[
s:\mathbb R^2\longrightarrow\mathbb R,
\qquad
s(u,v)=u-v,
\]
is continuous, and
\[
f-g=s\circ(f,g).
\]
Hence $f-g$ is continuous.
:::

<1>2. The set
\[
L=\{p\in X:f(p)\le g(p)\}
\]
is closed in $X$.
::: {.proof}
For $p\in X$,
\[
f(p)\le g(p)
\quad\Longleftrightarrow\quad
(f-g)(p)\le0.
\]
Therefore
\[
L=(f-g)^{-1}((-\infty,0]).
\]
The interval $(-\infty,0]$ is closed in $\mathbb R$, and $f-g$ is continuous by <1>1.
Thus $L$ is the inverse image of a closed set under a continuous map, so $L$ is closed.
This proves part (a).
:::

<1>3. For all real numbers $u,v$,
\[
\min\{u,v\}
=
\frac{u+v-|u-v|}{2}.
\]
::: {.proof}
If $u\le v$, then $|u-v|=v-u$, and the right-hand side is
\[
\frac{u+v-(v-u)}2=u.
\]
If $v\le u$, then $|u-v|=u-v$, and the right-hand side is
\[
\frac{u+v-(u-v)}2=v.
\]
In either case the value is $\min\{u,v\}$.
:::

<1>4. The function
\[
h(p)=\min\{f(p),g(p)\}
\]
is continuous.
::: {.proof}
By <1>3,
\[
h
=
\frac{f+g-|f-g|}{2}.
\]
The functions $f$ and $g$ are continuous, as are addition, subtraction, the absolute-value map on $\mathbb R$, and multiplication by the constant $1/2$.
Consequently the displayed combination is continuous.
This proves part (b).
:::
:::

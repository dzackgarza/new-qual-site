::: problem
Let $X(n, k) = \mathbb{RP}^n / \mathbb{RP}^k$ denote the quotient space of $\mathbb{RP}^n$ obtained by identifying $\mathbb{RP}^k$ to a point for $0 < k < n$.
Calculate the mod $2$ cohomology ring of $X(2k+2, k)$.
:::

::: {.solution}
<1>1. $H^*(\RP^n; \ZZ/2) = \ZZ/2[x]/(x^{n+1})$ with $|x| = 1$.
::: {.proof}
standard computation of the mod $2$ cohomology ring of real projective space.
:::

<1>2. The quotient map $q: \RP^n \to X(n,k)$ induces an injective map $q^*: H^*(X(n,k);\ZZ/2) \to H^*(\RP^n;\ZZ/2)$ whose image is the ideal $(x^{k+1})$.
::: {.proof}
$q^*$ is injective (the quotient collapses a subcomplex), and its image consists of the classes vanishing on $\RP^k$, which is exactly the ideal generated by $x^{k+1}$.
:::

<1>3. Hence $H^*(X(n,k);\ZZ/2) \cong (x^{k+1}) \subseteq \ZZ/2[x]/(x^{n+1})$ as a ring.
::: {.proof}
<1>2.
:::

<1>4. For $n = 2k+2$, the ideal $(x^{k+1})$ has $\ZZ/2$-basis $x^{k+1}, x^{k+2}, \ldots, x^{2k+2}$.
::: {.proof}
the ideal generated by $x^{k+1}$ in $\ZZ/2[x]/(x^{2k+3})$ consists of the classes $x^{k+1}, \ldots, x^{2k+2}$.
:::

<1>5. The cup product structure: $x^{k+1+i} \smile x^{k+1+j} = x^{2k+2+i+j}$, which is nonzero only when $i = j = 0$.
::: {.proof}
$x^{2k+2+i+j} = 0$ in $\ZZ/2[x]/(x^{2k+3})$ unless $2k+2+i+j \le 2k+2$, i.e. $i+j \le 0$, i.e. $i = j = 0$.
:::

<1>6. Hence the only nonzero product is $x^{k+1} \smile x^{k+1} = x^{2k+2}$.
::: {.proof}
<1>5.
:::

<1>7. Therefore
$$H^*(X(2k+2,k);\ZZ/2) = \ZZ/2[a, y_{k+2}, \ldots, y_{2k+1}]/(a^3,\ a y_i,\ y_i y_j),$$
where $|a| = k+1$ and $|y_i| = i$.
::: {.proof}
$a = x^{k+1}$ (with $a^2 = x^{2k+2} \neq 0$ and $a^3 = 0$), and $y_i = x^i$ for $k+2 \le i \le 2k+1$ (each squares to zero and annihilates everything, by <1>5).
:::

<1>8. Q.E.D.
::: {.proof}
<1>7.
:::

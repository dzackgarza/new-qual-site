::: {.problem}
Define a family $\mct$ of subsets of $\RR$ by
\[
A\in\mct
\iff
A=\emptyset\text{ or }\RR\setminus A\text{ is finite}.
\]

Prove that $\mct$ is a topology on $\RR$, and that $\RR$ is compact with respect to this topology.
:::

::: {.concept}
\envlist

- This is precisely the cofinite topology.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

$\emptyset,\RR\in\mct$.

::: pf-proof

The empty set belongs to $\mct$ by definition, and $\RR\in\mct$ because
\[
\RR\setminus\RR=\emptyset
\]
is finite.

:::

:::

::: {.pf-step #s2}

$\mct$ is closed under arbitrary unions.

::: pf-proof

Let $\{U_i\}_{i\in I}\subseteq\mct$.
If $I=\emptyset$, or if every $U_i$ is empty, then the union is $\emptyset\in\mct$ by step [](#s1){.pf-ref}. Otherwise choose a nonempty $U_j$.
Then $U_j^c$ is finite and
\[
\left(\bigcup_{i\in I}U_i\right)^c
=\bigcap_{i\in I}U_i^c
\subseteq U_j^c.
\]
Hence the complement of the union is finite, so arbitrary unions of members of $\mct$ belong to $\mct$.

:::

:::

::: {.pf-step #s3}

$\mct$ is closed under finite intersections.

::: pf-proof

For a finite family $U_1,\ldots,U_n\in\mct$, if some $U_i$ is empty then the intersection is empty and belongs to $\mct$ by step [](#s1){.pf-ref}. Otherwise every $U_i^c$ is finite, and
\[
\left(\bigcap_{i=1}^nU_i\right)^c
=\bigcup_{i=1}^nU_i^c
\]
is a finite union of finite sets.

:::

:::

::: pf-step

$\mct$ is a topology on $\RR$.

::: pf-proof

The topology axioms are exactly steps [](#s1){.pf-ref}, [](#s2){.pf-ref} and [](#s3){.pf-ref}.

:::

:::

::: {.pf-step #s5}

Every $\mct$-open cover of $\RR$ has a finite subcover.

::: pf-proof

Let $\mathcal U$ be an open cover of $\RR$.
Since it covers the nonempty set $\RR$, it contains a nonempty member $U_0$.
Write
\[
\RR\setminus U_0=\{p_1,\ldots,p_n\}.
\]
For each $p_k$, choose $U_k\in\mathcal U$ with $p_k\in U_k$.
Then
\[
\RR=U_0\cup U_1\cup\cdots\cup U_n.
\]
Thus $\mathcal U$ has a finite subcover.

:::

:::

::: pf-step

$(\RR,\mct)$ is compact.

::: pf-proof

This is the definition of compactness together with step [](#s5){.pf-ref}.

:::

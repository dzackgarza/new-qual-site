::: {.problem}
Define a family $\mct$ of subsets of $\RR$ by
\[
A\in\mct
\iff
A=\emptyset\text{ or }\RR\setminus A\text{ is finite}.
\]

Prove that $\mct$ is a topology on $\RR$, and that $\RR$ is compact with respect to this topology.
:::

::: {.concept}
\envlist

- This is precisely the cofinite topology.
:::

::: {.solution}
First, $\emptyset\in\mct$ by definition, and $\RR\in\mct$ because
\[
\RR\setminus\RR=\emptyset
\]
is finite.

Let $\{U_i\}_{i\in I}\subseteq\mct$. If $I=\emptyset$, then $\bigcup_{i\in I}U_i=\emptyset\in\mct$. Otherwise, if every $U_i$ is empty the same conclusion holds. If some $U_j$ is nonempty, then $U_j^c$ is finite and
\[
\left(\bigcup_{i\in I}U_i\right)^c
=\bigcap_{i\in I}U_i^c
\subseteq U_j^c.
\]
Hence the complement of the union is finite, so arbitrary unions of members of $\mct$ belong to $\mct$.

For a finite family $U_1,\ldots,U_n\in\mct$, if some $U_i$ is empty then the intersection is empty. Otherwise every $U_i^c$ is finite, and
\[
\left(\bigcap_{i=1}^nU_i\right)^c
=\bigcup_{i=1}^nU_i^c
\]
is a finite union of finite sets. Thus finite intersections also belong to $\mct$. Therefore $\mct$ is a topology.

Now let $\mathcal U$ be an open cover of $\RR$. Since it covers $\RR$, it contains a nonempty member $U_0$. Write
\[
\RR\setminus U_0=\{p_1,\ldots,p_n\}.
\]
For each $p_k$, choose $U_k\in\mathcal U$ with $p_k\in U_k$. Then
\[
\RR=U_0\cup U_1\cup\cdots\cup U_n.
\]
Hence every open cover has a finite subcover, so $(\RR,\mct)$ is compact.
:::

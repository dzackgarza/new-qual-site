Assume that F contains p distinct p-th roots of unity, where $p$ is a prime.

Let $a \in F ^ { \times }$ and let $E = F ( a ^ { 1 / p } )$ Show that the kernel of the natural homomorphism $F ^ { \times } / ( F ^ { \times } ) ^ { p } \to E ^ { \times } / ( E ^ { \times } ) ^ { p }$ is the cyclic subgroup generated by the image of a in ${ \cal F } ^ { \times } / ( { \cal F } ^ { \times } ) ^ { p }$
:::

::: {.problem}
p is an odd prime and $q = p ^ { k }$ . Let E be a splitting field of $X ^ { q } + X \in \mathbb { F } _ { p } [ X ]$ .How many elements does it have?
:::

::: {.solution}

Let
\[
f(X)=X^q+X,
\qquad q=p^k.
\]

::: pf

::: {.pf-step #s1-1}

The polynomial $f$ is separable.


::: pf-proof

In characteristic $p$,
\[
f'(X)=qX^{q-1}+1=1
\]
because $q=p^k=0$ in $\mathbb F_p$. Hence $f$ has no repeated roots.

:::

:::

::: {.pf-step #s1-2}

If $\alpha$ is a root of $f$, then
\[
\alpha^q=-\alpha.
\]


::: pf-proof

This is the equation $f(\alpha)=\alpha^q+\alpha=0$.

:::

:::

::: {.pf-step #s1-3}

Every root $\alpha$ satisfies
\[
\alpha^{q^2}=\alpha.
\]


::: pf-proof

Raise the identity in step [](#s1-2){.pf-ref} to the $q$-th power. Since $q$ is odd because $p$ is odd,
\[
\alpha^{q^2}=(-\alpha)^q=-\alpha^q=\alpha.
\]

:::

:::

::: {.pf-step #s1-4}

Therefore all roots of $f$ lie in the finite field $\mathbb F_{q^2}$.


::: pf-proof

Inside an algebraic closure of $\mathbb F_p$, the roots of
\[
X^{q^2}-X
\]
are exactly the elements of the unique field $\mathbb F_{q^2}$. Step [](#s1-3){.pf-ref} shows every root of $f$ is among them.

:::

:::

::: {.pf-step #s1-5}

The set
\[
V=\{x\in\mathbb F_{q^2}:x^q=-x\}
\]
is a one-dimensional vector space over $\mathbb F_q$ and hence has exactly $q$ elements.


::: pf-proof

The map
\[
T:\mathbb F_{q^2}\to\mathbb F_{q^2},
\qquad T(x)=x^q+x,
\]
is $\mathbb F_q$-linear. Its kernel is $V$. It is not the zero map because for $x\in\mathbb F_q$ one has
\[
T(x)=2x,
\]
and $2\ne0$ since $p$ is odd. The domain is two-dimensional over $\mathbb F_q$, so a nonzero linear map has kernel of dimension at most one. On the other hand $f=X^q+X$ has degree $q$, and by step [](#s1-1){.pf-ref} its $q$ roots in a splitting field are distinct; step [](#s1-4){.pf-ref} places all of them in $\mathbb F_{q^2}$. Thus $|V|=q$, equivalently $\dim_{\mathbb F_q}V=1$.

:::

:::

::: {.pf-step #s1-6}

Choose a nonzero root $\alpha$ of $f$. Then every root is of the form
\[
c\alpha,
\qquad c\in\mathbb F_q.
\]


::: pf-proof

By step [](#s1-5){.pf-ref}, the roots form the one-dimensional $\mathbb F_q$-vector space $V$. Any nonzero $\alpha\in V$ is therefore a basis of $V$.

:::

:::

::: {.pf-step #s1-7}

The splitting field over $\mathbb F_p$ is
\[
E=\mathbb F_q(\alpha).
\]


::: pf-proof

The field generated by all roots contains a nonzero root $\alpha$. It also contains every quotient
\[
\frac{c\alpha}{\alpha}=c
\]
with $c\in\mathbb F_q$, because all $c\alpha$ are roots by step [](#s1-6){.pf-ref}. Hence it contains $\mathbb F_q$ and equals $\mathbb F_q(\alpha)$. Conversely, step [](#s1-6){.pf-ref} shows that $\mathbb F_q(\alpha)$ contains every root.

:::

:::

::: {.pf-step #s1-8}

One has
\[
\alpha\notin\mathbb F_q.
\]


::: pf-proof

If $\alpha\in\mathbb F_q$, then $\alpha^q=\alpha$. But step [](#s1-2){.pf-ref} gives $\alpha^q=-\alpha$, so $2\alpha=0$. Since $p$ is odd and $\alpha\ne0$, this is impossible.

:::

:::

::: {.pf-step #s1-9}

Since $\alpha\in\mathbb F_{q^2}$ but $\alpha\notin\mathbb F_q$, one has
\[
\mathbb F_q(\alpha)=\mathbb F_{q^2}.
\]


::: pf-proof

The extension $\mathbb F_{q^2}/\mathbb F_q$ has prime degree $2$. Hence it has no intermediate fields other than its endpoints. Step [](#s1-8){.pf-ref} shows $\mathbb F_q(\alpha)$ is strictly larger than $\mathbb F_q$, so it must be all of $\mathbb F_{q^2}$.

:::

:::

::: {.pf-step #s1-10}

Therefore
\[
E=\mathbb F_{q^2}
\]
and
\[
\boxed{|E|=q^2=p^{2k}.}
\]


::: pf-proof

Combine steps [](#s1-7){.pf-ref} and [](#s1-9){.pf-ref}. By definition, $\mathbb F_{q^2}$ has $q^2=p^{2k}$ elements.

:::

:::

::: pf-qed

Step [](#s1-10){.pf-ref} gives the requested number of elements.

:::

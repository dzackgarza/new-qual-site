Problem 1. Suppose f : R → R is non-decreasing; specifically, for x, y ∈ R we have the implication x ≤ y =⇒ f (x) ≤ f (y). Show that if A ⊂ R is a Borel set, then so is f (A) = {f (x) : x ∈ A}.

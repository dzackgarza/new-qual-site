::: {.problem}
Let $R = C[0, 1]$ be the ring of continuous real-valued functions on the interval $[0, 1]$. Let I be an ideal of $R$.

a.
Show that if $f \in I, a \in [0, 1]$ are such that $f (a) \neq 0$, then there exists $g \in I$ such that $g(x) \geq 0$ for all $x \in [0, 1]$, and $g(x) > 0$ for all $x$ in some open neighborhood of $a$.

b.
If $I \neq R$, show that the set $Z_I = \{x \in [0, 1] \suchthat f(x) = 0 \text{ for all } f \in I\}$ is nonempty.

c.
Show that if $I$ is maximal, then there exists $x_0 \in [0, 1]$ such that $I = \{ f \in R \suchthat f (x_0 ) = 0\}$.
:::

::: {.solution}

::: pf

::: {.pf-step #pos}

If $f\in I$ and $f(a)\neq0$, then $g=f^2\in I$ satisfies $g\geq0$ on $[0,1]$ and $g>0$ on an open neighborhood of $a$.

::: pf-proof

$g=f\cdot f\in I$ because $I$ is an ideal, and $g\geq0$ because it is a square. Let $c=\abs{f(a)}>0$. By continuity there is $\varepsilon>0$ such that $\abs{f(x)-f(a)}<c/2$ for $x\in[0,1]$ with $\abs{x-a}<\varepsilon$. For these $x$, $\abs{f(x)}>c/2>0$, so $g(x)>0$ on the open neighborhood $\{x\in[0,1]:\abs{x-a}<\varepsilon\}$ of $a$.

:::

:::

::: {.pf-step #zero}

If $I\neq R$, then $Z_I\neq\emptyset$.

::: pf-proof

Suppose $Z_I=\emptyset$. Then for each $a\in[0,1]$ there is $f_a\in I$ with $f_a(a)\neq0$. Step [](#pos){.pf-ref} gives $g_a\in I$ with $g_a\geq0$ and $g_a>0$ on an open neighborhood $U_a$ of $a$. The sets $U_a$ cover the compact space $[0,1]$, so finitely many $U_{a_1},\ldots,U_{a_n}$ cover it. Let $h=g_{a_1}+\cdots+g_{a_n}\in I$. Each $x\in[0,1]$ lies in some $U_{a_k}$, so $h(x)\geq g_{a_k}(x)>0$. Hence $1/h$ is continuous on $[0,1]$, and $1=h\cdot(1/h)\in I$. Thus $I=R$.

:::

:::

::: {.pf-step #max}

If $I$ is maximal, then $I=\mathfrak m_{x_0}=\{f\in R:f(x_0)=0\}$ for some $x_0\in[0,1]$.

::: pf-proof

A maximal ideal is proper, so Step [](#zero){.pf-ref} gives $x_0\in Z_I$, which means $I\subseteq\mathfrak m_{x_0}$. The set $\mathfrak m_{x_0}$ is the kernel of the evaluation homomorphism $R\to\RR$, $f\mapsto f(x_0)$, so it is an ideal. It is proper because it does not contain the constant function $1$. Maximality of $I$ gives $I=\mathfrak m_{x_0}$.

:::

:::

::: pf-qed

Steps [](#pos){.pf-ref}, [](#zero){.pf-ref} and [](#max){.pf-ref} prove parts (a), (b) and (c).

:::

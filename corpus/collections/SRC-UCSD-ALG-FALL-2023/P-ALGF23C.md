::: problem
Suppose $A = \mathbb{Z}[\sqrt{-5}]$.

(a) Prove that $3$ is irreducible in $A$, but it is not prime.

(b) Prove that $\mathfrak{a} := \langle 1 + \sqrt{-5}, 3 \rangle$ is not a free $A$-module.

(c) Prove that $\mathfrak{a}$ is a projective $A$-module.
:::

::: {.solution}
Put
\[
s=\sqrt{-5},
\qquad
A=\mathbb Z[s],
\qquad
\mathfrak a=(3,1+s).
\]
For $u,v\in\mathbb Z$, use the norm
\[
N(u+vs)=(u+vs)(u-vs)=u^2+5v^2.
\]

<1>1. No element of $A$ has norm $3$.
::: {.proof}
If
\[
u^2+5v^2=3,
\]
then $v\ne0$ would make the left side at least $5$, while $v=0$ would give $u^2=3$.
Both are impossible for integers $u,v$.
:::

<1>2. The element $3$ is irreducible in $A$.
::: {.proof}
Suppose
\[
3=\alpha\beta.
\]
Taking norms gives
\[
9=N(3)=N(\alpha)N(\beta).
\]
The norm takes positive integer values on nonzero elements of $A$.
Moreover, norm $1$ occurs only for $\pm1$, hence exactly for the units of $A$.

If both $\alpha$ and $\beta$ were nonunits, then both norms would be integers greater than $1$ whose product is $9$.
Thus
\[
N(\alpha)=N(\beta)=3,
\]
contradicting <1>1.
Hence one factor is a unit, so $3$ is irreducible.
:::

<1>3. The element $3$ is not prime in $A$.
::: {.proof}
One has
\[
(1+s)(1-s)=1-s^2=6,
\]
so
\[
3\mid(1+s)(1-s).
\]
However, $3$ divides neither factor.
Indeed, an equality
\[
1+s=3(u+vs)
\]
would force $1=3u$ and $1=3v$, impossible in $\mathbb Z$; the same coefficient comparison applies to $1-s$.
Thus $3$ divides a product without dividing either factor, so it is not prime.
This proves part (a).
:::

<1>4. The ideal $\mathfrak a$ is proper.
::: {.proof}
Define
\[
\varphi:A\longrightarrow\mathbb F_3,
\qquad
\varphi(u+vs)=u-v\pmod3.
\]
This is a ring homomorphism because the proposed image $-1$ of $s$ satisfies
\[
(-1)^2=1=-5\pmod3.
\]
It is surjective, and
\[
\varphi(3)=0,
\qquad
\varphi(1+s)=0.
\]
Hence
\[
\mathfrak a\subseteq\ker\varphi\ne A.
\]
:::

<1>5. The ideal $\mathfrak a$ is not principal.
::: {.proof}
Suppose
\[
\mathfrak a=(\alpha).
\]
By <1>4, $\alpha$ is a nonunit.
Since both $3$ and $1+s$ belong to $(\alpha)$, the element $\alpha$ divides both of them.
Multiplicativity of the norm therefore implies that $N(\alpha)$ divides both
\[
N(3)=9
\]
and
\[
N(1+s)=6.
\]
Thus $N(\alpha)$ divides $3$.
Because $\alpha$ is a nonunit, $N(\alpha)>1$, so
\[
N(\alpha)=3,
\]
contradicting <1>1.
Therefore $\mathfrak a$ is not principal.
:::

<1>6. The $A$-module $\mathfrak a$ is not free.
::: {.proof}
The ideal $\mathfrak a$ is generated by two elements, so if it were free it would have finite rank, say $r$.
Let
\[
K=\operatorname{Frac}(A).
\]
Since $\mathfrak a$ is a nonzero ideal, localization at the nonzero elements of $A$ gives
\[
K\otimes_A\mathfrak a\cong K.
\]
Indeed, if $0\ne x\in\mathfrak a$, then $x/x=1$ belongs to the localization of $\mathfrak a$, so that localization is all of $K$.

If $\mathfrak a\cong A^r$, tensoring with $K$ would give
\[
K\cong K^r,
\]
hence $r=1$.
A free ideal of rank one is generated by the image of a basis element and is therefore principal, contradicting <1>5.
Thus $\mathfrak a$ is not free.
This proves part (b).
:::

<1>7. If
\[
\overline{\mathfrak a}=(3,1-s),
\]
then
\[
\mathfrak a\overline{\mathfrak a}=(3).
\]
::: {.proof}
The product ideal is generated by
\[
9,
\quad
3(1-s),
\quad
3(1+s),
\quad
(1+s)(1-s)=6.
\]
Every generator is divisible by $3$, so
\[
\mathfrak a\overline{\mathfrak a}\subseteq(3).
\]
Conversely,
\[
3=9-6
\]
belongs to the product ideal.
Hence equality holds.
:::

<1>8. The fractional ideal
\[
\mathfrak a^{-1}=\frac13\overline{\mathfrak a}
\]
satisfies
\[
\mathfrak a\mathfrak a^{-1}=A.
\]
::: {.proof}
Divide the equality in <1>7 by $3$.
In particular,
\[
\frac{1-s}{3}\in\mathfrak a^{-1}
\]
and therefore
\[
\frac{1-s}{3}\,\mathfrak a\subseteq A.
\]
:::

<1>9. The natural surjection
\[
\pi:A^2\longrightarrow\mathfrak a,
\qquad
\pi(u,v)=3u+(1+s)v,
\]
splits.
::: {.proof}
The map is surjective because $3$ and $1+s$ generate $\mathfrak a$.
The identity
\[
1=3-(1+s)\frac{1-s}{3}
\]
holds because $(1+s)(1-s)=6$.

Define
\[
\sigma:\mathfrak a\longrightarrow A^2,
\qquad
\sigma(z)=\left(z,-\frac{1-s}{3}z\right).
\]
The second coordinate lies in $A$ by <1>8, so $\sigma$ is a well-defined $A$-linear map.
Moreover,
\[
\pi(\sigma(z))
=3z-(1+s)\frac{1-s}{3}z
=z.
\]
Thus
\[
\pi\circ\sigma=\operatorname{id}_{\mathfrak a}.
\]
:::

<1>10. The module $\mathfrak a$ is projective.
::: {.proof}
By <1>9, $\mathfrak a$ is a direct summand of the free module $A^2$.
Every direct summand of a free module is projective.
Thus $\mathfrak a$ is projective, proving part (c).
:::
:::

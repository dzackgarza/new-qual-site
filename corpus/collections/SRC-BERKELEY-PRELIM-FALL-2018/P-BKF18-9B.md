::: {.problem}
Find the smallest $n$ for which the symmetric group $S_n$ contains a cyclic subgroup of order $111$.
:::

::: {.solution}

$n=40$.

::: pf

::: {.pf-step #s1}

$S_{40}$ contains a cyclic subgroup of order $111$.

::: pf-proof

A product of a disjoint $3$-cycle and $37$-cycle has order $\operatorname{lcm}(3,37)=111$ and uses $40$ points.

:::

:::

::: {.pf-step #s2}

If $S_n$ contains an element of order $111$, then $n\ge40$.

::: pf-proof

Let $g$ have disjoint cycle lengths $n_1,\dots,n_k$, so $\operatorname{lcm}(n_1,\dots,n_k)=111=3\cdot37$ and $n\ge\sum n_i$. Some $n_i$ is divisible by $37$ and some $n_j$ by $3$. If $i=j$, then $n\ge n_i\ge111$. If $i\ne j$, then $n\ge n_i+n_j\ge37+3=40$.

:::

:::

::: pf-qed

A cyclic subgroup of order $111$ is generated by an element of order $111$. Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} give $n=40$.

:::

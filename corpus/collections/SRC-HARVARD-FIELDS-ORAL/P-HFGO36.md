::: problem
Prove that any two fields with $27 = 3^3$ elements are **isomorphic**:
$$F_1 \cong F_2 \cong \mathbb{F}_{27}.$$
:::

::: {.solution}
<1>1. Prime Subfield and Vector Space Dimension:
<2>1. Let $F$ be any field with $|F| = 27 = 3^3$ elements.
::: {.proof}
setup.
:::
<2>2. The characteristic of $F$ must be a prime dividing 27, so $\operatorname{char}(F) = 3$.
::: {.proof}
order of 1 in the additive group is prime.
:::
<2>3. The prime subfield of $F$ is isomorphic to $\mathbb{F}_3 = \mathbb{Z}/3\mathbb{Z}$.
::: {.proof}
subfield generated by 1.
:::
<2>4. $F$ is a vector space over $\mathbb{F}_3$. Since $|F| = 3^{[F : \mathbb{F}_3]} = 27 = 3^3$, the extension degree is $[F : \mathbb{F}_3] = 3$.
::: {.proof}
vector space over finite field.
:::

<1>2. Root Characterization via the Multiplicative Group:
<2>1. The multiplicative group $F^\times = F \setminus \{0\}$ has order $|F^\times| = 27 - 1 = 26$.
::: {.proof}
group of units of a field.
:::
<2>2. By Lagrange’s Theorem, every non-zero element $\alpha \in F^\times$ satisfies $\alpha^{26} = 1$, which implies $\alpha^{27} = \alpha$.
::: {.proof}
Lagrange's Theorem for finite groups.
:::
<2>3. For the zero element $0 \in F$, $0^{27} = 0$, so $0^{27} - 0 = 0$ holds as well.
::: {.proof}
zero arithmetic.
:::
<2>4. Thus every element of $F$ is a root of the polynomial $P(x) = x^{27} - x \in \mathbb{F}_3[x]$.
::: {.proof}
<2>2 and <2>3.
:::
<2>5. Since $\deg(P) = 27$ and $F$ contains 27 distinct roots, $P(x)$ factors completely into linear factors over $F$:
\[
x^{27} - x = \prod_{\alpha \in F} (x - \alpha).
\]
::: {.proof}
a degree 27 polynomial has at most 27 roots in any field.
:::
<2>6. The formal derivative is $P'(x) = 27 x^{26} - 1 = 0 - 1 = -1 \neq 0$, which is coprime to $P(x)$, confirming that $P(x)$ has 27 distinct roots in any splitting field.
::: {.proof}
separability criterion for polynomials over finite fields.
:::
<2>7. Since $F$ is generated over $\mathbb{F}_3$ by these roots ($F = \mathbb{F}_3(F)$), $F$ is a **splitting field of $x^{27} - x$ over $\mathbb{F}_3$**.
::: {.proof}
definition of splitting field.
:::

<1>3. Uniqueness of Splitting Fields:
<2>1. Let $F_1$ and $F_2$ be any two fields with 27 elements.
::: {.proof}
setup.
:::
<2>2. By <1>2, both $F_1$ and $F_2$ are splitting fields of the same polynomial $x^{27} - x \in \mathbb{F}_3[x]$ over the prime subfield $\mathbb{F}_3$.
::: {.proof}
<1>2 step <2>7.
:::
<2>3. By the Uniqueness Theorem for Splitting Fields, any two splitting fields of a given polynomial over a base field are isomorphic under an isomorphism fixing the base field $\mathbb{F}_3$:
\[
F_1 \cong F_2 \cong \mathbb{F}_{27}.
\]
::: {.proof}
Uniqueness Theorem for Splitting Fields.
:::

<1>4. Conclusion:
Every field of order 27 is isomorphic to the unique splitting field $\mathbb{F}_{27}$. Q.E.D.
::: {.proof}
<1>1 through <1>3.
:::
:::

::: {.problem}
Recall that a topological space $X$ is *second countable* if there exists a countable basis for the topology of $X$, and $X$ is *separable* if it has a countable dense subset.

(a) Show that if $(X,\mathcal T)$ has a metric topology, from the metric $d:X\times X\to\RR$, and $X$ is separable, then $X$ is second countable.

(b) Show that $\RR$, with the lower limit topology $\mathcal T_\ell$, is not metrizable, i.e., $\mathcal T_\ell$ is not the topology from any metric on $\RR$.
:::

::: {.solution}

::: pf

::: {.pf-step #metric-basis}
(a) If $(X,d)$ has a countable dense set $D=\{c_1,c_2,\ldots\}$, then $\mathcal B=\{B(c_j,q):j\in\NN,\ q\in\QQ_{>0}\}$ is a countable basis.

::: pf-proof
$\mathcal B$ is indexed by the countable set $\NN\times\QQ_{>0}$.
Let $U$ be open and $x\in U$, and choose $\varepsilon>0$ with $B(x,\varepsilon)\subseteq U$.
By density there is $c_j$ with $d(x,c_j)<\varepsilon/3$; choose a rational $q$ with $d(x,c_j)<q<\varepsilon-d(x,c_j)$.
Then $x\in B(c_j,q)$, and for $y\in B(c_j,q)$, $d(x,y)\le d(x,c_j)+d(c_j,y)<d(x,c_j)+q<\varepsilon$, so $B(c_j,q)\subseteq U$.
:::

:::

::: {.pf-step #lower-limit-separable}
$(\RR,\mathcal T_\ell)$ is separable.

::: pf-proof
Every nonempty basic open set $[a,b)$ contains a rational number, so $\QQ$ is dense.
:::

:::

::: {.pf-step #lower-limit-not-second-countable}
$(\RR,\mathcal T_\ell)$ is not second countable.

::: pf-proof
Suppose $\mathcal C$ is a countable basis.
For each $x\in\RR$, the set $[x,x+1)$ is open, so there is $C_x\in\mathcal C$ with $x\in C_x\subseteq[x,x+1)$.
If $x<y$, then $x\in C_x$ but $x\notin[y,y+1)\supseteq C_y$, so $C_x\neq C_y$.
Thus $x\mapsto C_x$ injects the uncountable set $\RR$ into the countable set $\mathcal C$, a contradiction.
:::

:::

::: pf-qed
Step [](#metric-basis){.pf-ref} proves (a).
For (b), if $\mathcal T_\ell$ were induced by a metric, then by steps [](#lower-limit-separable){.pf-ref} and [](#metric-basis){.pf-ref} it would be second countable, contrary to step [](#lower-limit-not-second-countable){.pf-ref}.
:::

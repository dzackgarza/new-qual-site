::: {.problem}
Recall that a topological space $X$ is *second countable* if there exists a countable basis for the topology of $X$, and $X$ is *separable* if it has a countable dense subset.

(a) Show that if $(X,\mathcal T)$ has a metric topology, from the metric $d:X\times X\to\mathbb R$, and $X$ is separable, then $X$ is second countable.

(b) Show that $\mathbb R$, with the lower limit topology $\mathcal T_\ell$, is not metrizable, i.e., $\mathcal T_\ell$ is not the topology from any metric on $\mathbb R$.
:::

::: {.solution}
<1>1. Let $(X,d)$ be separable and choose a countable dense set $D=\{d_1,d_2,\dots\}$.
::: {.proof}
We construct a countable basis from balls centered at points of $D$ with rational radii.
:::

<1>2. Let
$$
\mathcal B=\{B(d_j,q):j\in\mathbb N,\ q\in\mathbb Q_{>0}\}.
$$
Then $\mathcal B$ is countable.
::: {.proof}
It is indexed by the countable set $\mathbb N\times\mathbb Q_{>0}$.
:::

<1>3. The family $\mathcal B$ is a basis for the metric topology.
::: {.proof}
Let $U$ be open and $x\in U$. Choose $\varepsilon>0$ with $B(x,\varepsilon)\subseteq U$. Density of $D$ gives $d_j\in D$ with $d(x,d_j)<\varepsilon/3$. Choose rational $q$ such that
$$
d(x,d_j)<q<\varepsilon-d(x,d_j).
$$
Then $x\in B(d_j,q)$, and if $y\in B(d_j,q)$, the triangle inequality gives
$$
d(x,y)\le d(x,d_j)+d(d_j,y)<d(x,d_j)+q<\varepsilon,
$$
so $B(d_j,q)\subseteq U$.
:::

<1>4. Thus every separable metric space is second countable.
::: {.proof}
By <1>2--<1>3, $\mathcal B$ is a countable basis.
:::

<1>5. The Sorgenfrey line $(\mathbb R,\mathcal T_\ell)$ is separable.
::: {.proof}
The rational numbers are dense. Every nonempty basic open set $[a,b)$ contains a rational number.
:::

<1>6. The Sorgenfrey line is not second countable.
::: {.proof}
Suppose $\mathcal B$ were a countable basis. For each $x\in\mathbb R$, because $[x,x+1)$ is open, choose $B_x\in\mathcal B$ such that
$$
x\in B_x\subseteq [x,x+1).
$$
If $x<y$, then $x\notin[y,y+1)$, so $B_x\ne B_y$: indeed $x\in B_x$, while every subset $B_y\subseteq[y,y+1)$ omits $x$. Thus the map $x\mapsto B_x$ injects the uncountable set $\mathbb R$ into the countable set $\mathcal B$, a contradiction.
:::

<1>7. Therefore the lower-limit topology is not metrizable.
::: {.proof}
If it were induced by a metric, then by <1>5 and <1>4 it would be second countable, contradicting <1>6.
:::
:::

::: {.problem}
Find the Fourier series of the function with period 2π that is 1 if $| x | < \epsilon$ and 0 if $\epsilon \le | x | < \pi$ Find the sum

$$
{ \frac { \sin 1 } { 1 } } + { \frac { \sin 2 } { 2 } } + { \frac { \sin 3 } { 3 } } + \cdots
$$
:::

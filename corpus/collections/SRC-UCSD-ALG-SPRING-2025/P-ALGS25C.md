::: problem
Suppose $F$ is a field.
Let $m \leq n$ be two positive integers and
\[
M_{m,n} := F[x]/\langle x^n\rangle \otimes_F F[x]/\langle x^m\rangle.
\]
Notice that $M_{m,n}$ is an $F[x]$-module where
\[
x \cdot \bigl(\overline{a(x)} \otimes \overline{b(x)}\bigr) = \overline{xa(x)} \otimes \overline{xb(x)}
\]
and $\overline{\bullet}$ denotes the corresponding coset.
(Let's emphasize that the tensor is over $F$, and not over $F[x]$.)

(a) Prove that $\operatorname{Ann}(M_{m,n}) = \langle x^m\rangle$.

(b) Let $d(M_{m,n})$ be the minimum number of generators of $M_{m,n}$ as an $F[x]$-module.
Prove that $d(M_{m,n}) = \dim_F(M_{m,n}/x M_{m,n}) = m + n - 1$.

(c) Find the multiplicity of $x^m$ among the invariant factors of $M_{m,n}$.
:::

::: {.solution}
Let \(e_{i,j}=\overline{x^i}\otimes\overline{x^j}\) for \(0\le i<n\), \(0\le j<m\). These form an \(F\)-basis of \(M_{m,n}\), and multiplication by \(x\) sends \(e_{i,j}\) to \(e_{i+1,j+1}\), with the result zero once either index leaves its allowed range.

**(a).**

<1>1. The endomorphism \(T\) given by multiplication by \(x\) satisfies \(T^m=0\) but \(T^{m-1}\ne0\).
::: {.proof}
For every basis vector, \(T^m(e_{i,j})=e_{i+m,j+m}=0\) because \(j+m\ge m\). On the other hand, since \(m\le n\),
\[
T^{m-1}(e_{0,0})=e_{m-1,m-1}\ne0.
\]
:::

<1>2. The minimal polynomial of \(T\) is \(x^m\), and therefore
\[
\operatorname{Ann}_{F[x]}(M_{m,n})=(x^m).
\]
::: {.proof}
The operator \(T\) is nilpotent of exact nilpotency index \(m\) by <1>1, so its minimal polynomial is \(x^m\). A polynomial \(q(x)\) annihilates the \(F[x]\)-module exactly when \(q(T)=0\), so the annihilator ideal is generated by the minimal polynomial.
:::

**(b).**

<1>3. The quotient \(M_{m,n}/xM_{m,n}\) has \(F\)-basis given by the images of
\[
e_{i,0}\quad(0\le i<n),
\qquad
e_{0,j}\quad(1\le j<m).
\]
::: {.proof}
The subspace \(xM_{m,n}=T(M_{m,n})\) is spanned by the basis vectors \(e_{i,j}\) with \(i\ge1\) and \(j\ge1\). Thus precisely the vectors with \(i=0\) or \(j=0\) survive, with \(e_{0,0}\) listed once.
:::

<1>4. Hence
\[
\dim_F(M_{m,n}/xM_{m,n})=m+n-1.
\]
::: {.proof}
There are \(n\) vectors \(e_{i,0}\) and \(m-1\) additional vectors \(e_{0,j}\).
:::

<1>5. The same boundary vectors generate \(M_{m,n}\) as an \(F[x]\)-module.
::: {.proof}
If \(i\ge j\), then \(e_{i,j}=x^j e_{i-j,0}\). If \(j>i\), then \(e_{i,j}=x^i e_{0,j-i}\). Thus every basis vector lies in the cyclic module generated by its boundary vector.
:::

<1>6. Any generating set has at least \(m+n-1\) elements.
::: {.proof}
The image of any \(F[x]\)-generating set spans \(M_{m,n}/xM_{m,n}\) over \(F[x]/(x)\cong F\). Use <1>4.
:::

<1>7. Therefore
\[
d(M_{m,n})=\dim_F(M_{m,n}/xM_{m,n})=m+n-1.
\]
::: {.proof}
The upper bound comes from <1>5 and the lower bound from <1>6.
:::

**(c).**

<1>8. The boundary cyclic submodules form a direct sum decomposition
\[
M_{m,n}
=
\bigoplus_{i=0}^{n-1}F[x]e_{i,0}
\oplus
\bigoplus_{j=1}^{m-1}F[x]e_{0,j}.
\]
::: {.proof}
They span by <1>5. Multiplication by \(x\) preserves the difference \(i-j\), so each boundary vector generates exactly one diagonal of the basis grid. Distinct boundary vectors start on distinct diagonals, so the basis supports are disjoint and the sum is direct.
:::

<1>9. The cyclic module generated by \(e_{i,0}\) has length \(\min(n-i,m)\), while the one generated by \(e_{0,j}\) for \(j\ge1\) has length \(m-j\).
::: {.proof}
Successive multiplication by \(x\) advances both indices by one. Starting at \(e_{i,0}\), the chain stops when either the first index reaches \(n\) or the second reaches \(m\), giving length \(\min(n-i,m)\). Starting at \(e_{0,j}\), the second index reaches \(m\) first because \(n\ge m\), giving length \(m-j\).
:::

<1>10. Exactly \(n-m+1\) cyclic summands have length \(m\), namely those generated by
\[
e_{i,0},\qquad 0\le i\le n-m.
\]
::: {.proof}
By <1>9, \(F[x]e_{i,0}\) has length \(m\) exactly when \(n-i\ge m\), i.e. \(i\le n-m\). Every summand generated by \(e_{0,j}\) with \(j\ge1\) has length strictly less than \(m\).
:::

<1>11. Therefore the multiplicity of \(x^m\) among the invariant factors is
\[
\boxed{n-m+1}.
\]
::: {.proof}
A cyclic nilpotent summand of length \(r\) is isomorphic to \(F[x]/(x^r)\). Apply <1>8--<1>10.
:::
:::

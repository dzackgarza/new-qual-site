::: {.problem}
Mark each statement true or false. No justifications are required.

1. If $A$ is symmetric and $A^5=0$, then $A=0$.
2. If $A,B$ are $3\times3$ symmetric matrices, then $AB$ is symmetric.
3. The solutions of $f'''+f''+f=\sin x$ form a linear subspace of $C^\infty$.
4. The problem $f'''+f''+f=\sin x$, $f(0)=f'(0)=0$, has exactly one solution.
5. Every real $3\times3$ matrix having $1+i$ as an eigenvalue is diagonalizable over $\CC$.
6. If $A$ is a nonzero diagonalizable $4\times4$ matrix, then $A^4\ne0$.
7. There exists a real $2\times2$ matrix $A$ with $A^2=-I$.
8. There exist invertible $2\times2$ matrices $A,B$ such that $\det(A+B)=\det A+\det B$.
9. $\ker D^{100}$ on $C^\infty(\RR)$ has dimension $100$.
10. $T(f)(x)=\sin(x)f(x)+f(0)+\int_{-1}^x f(y)\,dy$ is linear on $C^\infty(\RR)$.
11. If $S^{-1}AS=B$, then $\operatorname{tr}(A)/\operatorname{tr}(B)=\det(A)/\det(B)$.
12. If a real $3\times3$ matrix is invertible, then its rows form a basis of $\RR^3$.
13. Every real $4\times4$ orthogonal matrix has a real eigenvalue.
14. If $A$ is orthogonal and $B^2=I_n$, then $\det(AB)\in\{1,-1\}$.
15. If $\dot x=Ax$ has an asymptotically stable origin, then $\dot x=-Ax$ has an asymptotically stable origin.
16. If $\dot x=Ax$ has an asymptotically stable origin, then $\dot x=Ax+(x\cdot x)x$ has an asymptotically stable origin.
17. $T(f)(t)=t+f(t)$ is linear on $C^\infty(\RR)$.
18. The origin is stable for the discrete system
\[
\binom{x(n+1)}{y(n+1)}=
\begin{pmatrix}1&-1\\1&1\end{pmatrix}
\binom{x(n)}{y(n)}.
\]
19. Every real $4\times4$ matrix is similar to its transpose.
20. If $A$ is invertible, then the unique least-squares solution of $Ax=b$ is $A^{-1}b$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Statement 1 is $\boxed{\mathrm T}$.


::: pf-proof

By the spectral theorem, a real symmetric matrix is orthogonally diagonalizable, so
\[
A=QDQ^T
\]
for a real diagonal matrix $D$. Then $A^5=QD^5Q^T=0$, hence $D^5=0$. Every diagonal entry $\lambda$ of $D$ satisfies $\lambda^5=0$, so every diagonal entry is zero. Thus $D=0$ and $A=0$.

:::

:::

::: {.pf-step #s1-2}

Statement 2 is $\boxed{\mathrm F}$.


::: pf-proof

Take
\[
A=\begin{pmatrix}1&0&0\\0&0&0\\0&0&0\end{pmatrix},
\qquad
B=\begin{pmatrix}0&1&0\\1&0&0\\0&0&0\end{pmatrix}.
\]
Both matrices are symmetric, but
\[
AB=\begin{pmatrix}0&1&0\\0&0&0\\0&0&0\end{pmatrix}
\]
is not symmetric.

:::

:::

::: {.pf-step #s1-3}

Statement 3 is $\boxed{\mathrm F}$.


::: pf-proof

The zero function is not a solution, since its left-hand side is $0$ whereas the right-hand side is $\sin x$. Therefore the solution set cannot be a linear subspace.

:::

:::

::: {.pf-step #s1-4}

Statement 4 is $\boxed{\mathrm F}$.


::: pf-proof

For each prescribed value $c\in\RR$, the third-order linear initial-value problem
\[
f'''+f''+f=\sin x,
\qquad
f(0)=0,
\qquad
f'(0)=0,
\qquad
f''(0)=c
\]
has a unique solution. Choosing, for example, $c=0$ and $c=1$ gives two distinct solutions satisfying the two conditions stated in the problem. Hence those two conditions do not determine a unique solution.

:::

:::

::: {.pf-step #s1-5}

Statement 5 is $\boxed{\mathrm T}$.


::: pf-proof

The characteristic polynomial of a real matrix has real coefficients. If $1+i$ is a root, then $1-i$ is also a root, so
\[
(t-(1+i))(t-(1-i))=t^2-2t+2
\]
divides the characteristic polynomial. Since the latter has degree $3$, its remaining root is real. Thus the matrix has three distinct complex eigenvalues and is diagonalizable over $\CC$.

:::

:::

::: {.pf-step #s1-6}

Statement 6 is $\boxed{\mathrm T}$.


::: pf-proof

If every eigenvalue of a diagonalizable matrix $A$ were zero, then a diagonalization $A=SDS^{-1}$ would have $D=0$, forcing $A=0$. Since $A\ne0$, some eigenvalue $\lambda$ is nonzero. Then $\lambda^4\ne0$ is an eigenvalue of $A^4$, so $A^4\ne0$.

:::

:::

::: {.pf-step #s1-7}

Statement 7 is $\boxed{\mathrm T}$.


::: pf-proof

For
\[
A=\begin{pmatrix}0&-1\\1&0\end{pmatrix}
\]
one computes directly that $A^2=-I_2$.

:::

:::

::: {.pf-step #s1-8}

Statement 8 is $\boxed{\mathrm T}$.


::: pf-proof

Let
\[
A=I_2,
\qquad
B=\begin{pmatrix}0&-1\\1&0\end{pmatrix}.
\]
Both are invertible and $\det A=\det B=1$. Moreover
\[
\det(A+B)
=\det\begin{pmatrix}1&-1\\1&1\end{pmatrix}
=2
=\det A+\det B.
\]

:::

:::

::: {.pf-step #s1-9}

Statement 9 is $\boxed{\mathrm T}$.


::: pf-proof

A smooth function lies in $\ker D^{100}$ exactly when its one-hundredth derivative is identically zero. Repeated integration shows that these functions are precisely the polynomials of degree at most $99$. The functions $1,x,\ldots,x^{99}$ form a basis of that space, so its dimension is $100$.

:::

:::

::: {.pf-step #s1-10}

Statement 10 is $\boxed{\mathrm T}$.


::: pf-proof

Multiplication by the fixed function $\sin x$, evaluation $f\mapsto f(0)$ followed by inclusion as a constant function, and the map
\[
f\longmapsto\left(x\longmapsto\int_{-1}^x f(y)\,dy\right)
\]
are all linear. Their sum is therefore linear.

:::

:::

::: {.pf-step #s1-11}

Statement 11 is $\boxed{\mathrm F}$ as written.


::: pf-proof

Similarity does imply
\[
\operatorname{tr}(A)=\operatorname{tr}(B),
\qquad
\det A=\det B,
\]
but the displayed ratios need not be defined. For example, take $S=I$ and
\[
A=B=\begin{pmatrix}1&0\\0&0\end{pmatrix}.
\]
Then $S^{-1}AS=B$ and $\operatorname{tr}(A)/\operatorname{tr}(B)=1$, while $\det(A)/\det(B)=0/0$ is undefined. If both denominators are assumed nonzero, then both ratios are indeed equal to $1$.

:::

:::

::: {.pf-step #s1-12}

Statement 12 is $\boxed{\mathrm T}$.


::: pf-proof

An invertible $3\times3$ matrix has rank $3$. Its row rank is therefore $3$, so its three rows are linearly independent in $\RR^3$. Three linearly independent vectors in $\RR^3$ form a basis.

:::

:::

::: {.pf-step #s1-13}

Statement 13 is $\boxed{\mathrm F}$.


::: pf-proof

Let
\[
J=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
\qquad
A=\begin{pmatrix}J&0\\0&J\end{pmatrix}.
\]
The matrix $A$ is real and orthogonal. Its characteristic polynomial is $(t^2+1)^2$, so its eigenvalues are $i$ and $-i$, each with multiplicity $2$. Hence it has no real eigenvalue.

:::

:::

::: {.pf-step #s1-14}

Statement 14 is $\boxed{\mathrm T}$.


::: pf-proof

Orthogonality gives
\[
(\det A)^2=\det(A^TA)=1,
\]
so $\det A\in\{1,-1\}$. Likewise, $B^2=I_n$ gives $(\det B)^2=1$, so $\det B\in\{1,-1\}$. Therefore
\[
\det(AB)=\det A\det B\in\{1,-1\}.
\]

:::

:::

::: {.pf-step #s1-15}

Statement 15 is $\boxed{\mathrm F}$.


::: pf-proof

Take $A=-I$. Then every solution of $\dot x=Ax$ is $x(t)=e^{-t}x(0)$, so the origin is asymptotically stable. For $\dot x=-Ax=x$, every nonzero solution is $x(t)=e^t x(0)$ and moves away from the origin.

:::

:::

::: {.pf-step #s1-16}

Statement 16 is $\boxed{\mathrm T}$.


::: pf-proof

Asymptotic stability of the linear system implies that every eigenvalue of $A$ has negative real part. Hence
\[
P=\int_0^\infty e^{A^Tt}e^{At}\,dt
\]
converges, is positive definite, and satisfies $A^TP+PA=-I$. For
\[
V(x)=x^TPx
\]
and the nonlinear vector field $F(x)=Ax+\|x\|^2x$, differentiation along a trajectory gives
\[
\dot V(x)
=x^T(A^TP+PA)x+2\|x\|^2x^TPx
=-\|x\|^2+2\|x\|^2x^TPx.
\]
If $\lambda_{\max}(P)$ is the largest eigenvalue of $P$, then
\[
\dot V(x)\le -\|x\|^2\bigl(1-2\lambda_{\max}(P)\|x\|^2\bigr),
\]
which is strictly negative for all sufficiently small nonzero $x$. Thus $V$ is a strict local Lyapunov function, and the origin is asymptotically stable.

:::

:::

::: {.pf-step #s1-17}

Statement 17 is $\boxed{\mathrm F}$.


::: pf-proof

For the zero function,
\[
T(0)(t)=t\ne0.
\]
Every linear map sends $0$ to $0$, so this map is not linear.

:::

:::

::: {.pf-step #s1-18}

Statement 18 is $\boxed{\mathrm F}$.


::: pf-proof

For
\[
A=\begin{pmatrix}1&-1\\1&1\end{pmatrix}
\]
one has $A^TA=2I$. Hence every vector satisfies
\[
\|A^nv\|=2^{n/2}\|v\|.
\]
Every nonzero initial condition therefore eventually leaves any fixed neighborhood of the origin, so the origin is not stable.

:::

:::

::: {.pf-step #s1-19}

Statement 19 is $\boxed{\mathrm T}$.


::: pf-proof

Over $\RR[t]$,
\[
tI-A^T=(tI-A)^T.
\]
For every $k$, the set of $k\times k$ minors of a polynomial matrix is unchanged by transpose: the minor with row set $I$ and column set $J$ becomes the minor with row set $J$ and column set $I$. Thus $tI-A$ and $tI-A^T$ have the same determinantal divisors, hence the same invariant factors. By the rational canonical form theorem, $A$ and $A^T$ therefore have the same rational canonical form and are similar over $\RR$.

:::

:::

::: {.pf-step #s1-20}

Statement 20 is $\boxed{\mathrm T}$.


::: pf-proof

If $A$ is invertible, then $x=A^{-1}b$ satisfies $Ax=b$, so its least-squares residual has norm $0$. No residual norm can be negative, so this is a least-squares solution. It is unique because $Ax=b$ has exactly one solution when $A$ is invertible.

:::

::: {.problem}
Match each object to exactly one description.

Objects:

1. $\dot x=3x-5y$, $\dot y=2x-3y$;
2. $f_t=f_{xx}+f_{yy}$;
3. $D^2f+Df-f=\sin x$;
4. $\dot x=3x^3-5y$, $\dot y=x^2+y^2+2$;
5. a system of three linear equations in $x,y$;
6. $\dot x+3x=0$.

Descriptions: inhomogeneous linear ODE; PDE; linear ODE system in two variables; homogeneous one-dimensional first-order linear ODE; nonlinear ODE system; system of linear equations.
:::

::: {.remark}
The three linear equations of item 5 are printed in the source exam.
:::

::: {.solution}

Label the descriptions in their displayed order by (i)--(vi).

::: pf

::: {.pf-step #s1-1}

Object 1 matches $\boxed{\text{(iii)}}$, the linear ODE system in two variables.


::: pf-proof

The unknowns are the two functions $x(t)$ and $y(t)$, only ordinary derivatives with respect to $t$ occur, and both right-hand sides are linear combinations of $x$ and $y$.

:::

:::

::: {.pf-step #s1-2}

Object 2 matches $\boxed{\text{(ii)}}$, the PDE.


::: pf-proof

The equation contains the partial derivatives $f_t$, $f_{xx}$, and $f_{yy}$ of a function depending on more than one independent variable, so it is a partial differential equation.

:::

:::

::: {.pf-step #s1-3}

Object 3 matches $\boxed{\text{(i)}}$, the inhomogeneous linear ODE.


::: pf-proof

The equation
$$
D^2f+Df-f=\sin x
$$
involves derivatives with respect to the single variable $x$, and the differential operator $D^2+D-1$ is linear. The nonzero forcing term $\sin x$ makes the equation inhomogeneous.

:::

:::

::: {.pf-step #s1-4}

Object 4 matches $\boxed{\text{(v)}}$, the nonlinear ODE system.


::: pf-proof

It is a system of ordinary differential equations for $x(t)$ and $y(t)$, but the terms $x^3$, $x^2$, and $y^2$ are nonlinear in the unknowns.

:::

:::

::: {.pf-step #s1-5}

Object 5 matches $\boxed{\text{(vi)}}$, the system of linear equations.


::: pf-proof

The displayed object consists of three algebraic equations in $x$ and $y$, with each equation linear in those unknowns and with no derivatives.

:::

:::

::: {.pf-step #s1-6}

Object 6 matches $\boxed{\text{(iv)}}$, the homogeneous one-dimensional first-order linear ODE.


::: pf-proof

The equation is
$$
\dot x+3x=0.
$$
It contains one unknown function of one independent variable, its highest derivative is first order, the left-hand side is linear in $x$, and the right-hand side is zero.

:::

:::

Steps [](#s1-1){.pf-ref} through [](#s1-6){.pf-ref} match all six objects, and each of the six descriptions occurs exactly once.

:::

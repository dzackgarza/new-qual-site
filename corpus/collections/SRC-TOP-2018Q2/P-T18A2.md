::: {.problem}
Recall that, for $A\subseteq X$, the set $X/A$ is the set of equivalence classes under the relation $x\sim y$ if $x=y$ or $x,y\in A$.
Show that if $X$ is the real line $\RR$ (with the usual topology) and $A=(-\infty,0)\cup(1,\infty)\subseteq\RR$, that $X/A$, with the quotient topology, is compact but not Hausdorff.
:::

::: {.solution}
Let $q\colon\RR\to X/A$ be the quotient map, $a=q(A)$ the collapsed point, and $x=q(0)$; since $0\notin A$, $x\neq a$.

<1>1. $X/A$ is compact.

::: {.proof}
Every point of $\RR$ lies in $A$ or in $[0,1]$, so $X/A=q([0,1])$, a continuous image of the compact set $[0,1]$.
:::

<1>2. Every open neighborhood of $x$ contains $a$.

::: {.proof}
If $V\subseteq X/A$ is open and $x\in V$, then $q^{-1}(V)$ is an open saturated subset of $\RR$ containing $0$.
It contains an interval $(-\varepsilon,\varepsilon)$, which meets $A$, and a saturated set meeting the class $A$ contains all of $A$.
Thus $a\in V$.
:::

<1>3. Q.E.D.

::: {.proof}
Step <1>1 gives compactness.
By step <1>2, every neighborhood of $x$ meets every neighborhood of $a$, so $X/A$ is not Hausdorff.
:::
:::

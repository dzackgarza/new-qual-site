::: {.problem}
Let $X$ be a path-connected space containing points $x_0$ and $x_1$, and let $P$ be the set of path-homotopy classes of paths from $x_0$ to $x_1$ in $X$.
In other words, elements of $P$ are equivalence classes of paths from $x_0$ to $x_1$, where two paths $h_0$ and $h_1$ are equivalent if there exists a homotopy $h_t:[0,1]\to X$ from $h_0$ to $h_1$ such that $h_t(0)=x_0$ and $h_t(1)=x_1$ for all $t\in[0,1]$.
Prove that there is a bijection from $P$ to $\pi_1(X,x_0)$.
:::
::: {.solution}
<1>1. Choose once and for all a path $\lambda:I\to X$ from $x_0$ to $x_1$.
::: {.proof}
Such a path exists because $X$ is path-connected.
:::

<1>2. Define
$$
\Phi:P\longrightarrow\pi_1(X,x_0),
\qquad
\Phi([\alpha])=[\alpha*\bar\lambda],
$$
where $\bar\lambda(t)=\lambda(1-t)$.
::: {.proof}
For a path $\alpha$ from $x_0$ to $x_1$, the concatenation $\alpha*\bar\lambda$ is a loop based at $x_0$. If $\alpha\simeq\alpha'$ rel endpoints, concatenating the homotopy with the fixed path $\bar\lambda$ gives $\alpha*\bar\lambda\simeq\alpha'*\bar\lambda$ rel basepoint, so $\Phi$ is well-defined.
:::

<1>3. Define
$$
\Psi:\pi_1(X,x_0)\longrightarrow P,
\qquad
\Psi([\gamma])=[\gamma*\lambda].
$$
::: {.proof}
The concatenation $\gamma*\lambda$ is a path from $x_0$ to $x_1$. A based homotopy between loops remains a path homotopy rel endpoints after concatenation with the fixed $\lambda$, so $\Psi$ is well-defined.
:::

<1>4. We have $\Phi\circ\Psi=\operatorname{id}_{\pi_1(X,x_0)}$.
::: {.proof}
For a based loop $\gamma$,
$$
\Phi(\Psi([\gamma]))=[\gamma*\lambda*\bar\lambda]=[\gamma],
$$
because $\lambda*\bar\lambda$ is path-homotopic rel endpoints to the constant loop at $x_0$ after the usual reassociation and cancellation.
:::

<1>5. We have $\Psi\circ\Phi=\operatorname{id}_P$.
::: {.proof}
For a path $\alpha:x_0\to x_1$,
$$
\Psi(\Phi([\alpha]))=[\alpha*\bar\lambda*\lambda]=[\alpha],
$$
because $\bar\lambda*\lambda$ is path-homotopic rel endpoints to the constant path at $x_1$.
:::

<1>6. Therefore $\Phi$ is a bijection from $P$ to $\pi_1(X,x_0)$.
::: {.proof}
The map $\Psi$ is its two-sided inverse by <1>4--<1>5.
:::
:::

::: {.problem}
Let $X$ be a path-connected space containing points $x_0$ and $x_1$, and let $P$ be the set of path-homotopy classes of paths from $x_0$ to $x_1$ in $X$.
In other words, elements of $P$ are equivalence classes of paths from $x_0$ to $x_1$, where two paths $h_0$ and $h_1$ are equivalent if there exists a homotopy $h_t:[0,1]\to X$ from $h_0$ to $h_1$ such that $h_t(0)=x_0$ and $h_t(1)=x_1$ for all $t\in[0,1]$.
Prove that there is a bijection from $P$ to $\pi_1(X,x_0)$.
:::

::: {.solution}
Since $X$ is path-connected, choose a path $\lambda\colon[0,1]\to X$ from $x_0$ to $x_1$, and let $\bar\lambda(t)=\lambda(1-t)$.

::: pf

::: {.pf-step}
$\Phi([\alpha])=[\alpha*\bar\lambda]$ defines a map $\Phi\colon P\to\pi_1(X,x_0)$, and $\Psi([\gamma])=[\gamma*\lambda]$ defines a map $\Psi\colon\pi_1(X,x_0)\to P$.

::: pf-proof
For a path $\alpha$ from $x_0$ to $x_1$, $\alpha*\bar\lambda$ is a loop at $x_0$; for a loop $\gamma$ at $x_0$, $\gamma*\lambda$ is a path from $x_0$ to $x_1$.
Concatenating a path homotopy rel endpoints with the constant homotopy of $\bar\lambda$ or $\lambda$ is again a path homotopy rel endpoints, so both formulas depend only on the classes.
:::

:::

::: {.pf-step #inverse-relations}
$\Phi\circ\Psi=\id_{\pi_1(X,x_0)}$ and $\Psi\circ\Phi=\id_P$.

::: pf-proof
Up to path homotopy, concatenation is associative, $\lambda*\bar\lambda$ is homotopic rel endpoints to the constant loop at $x_0$, and $\bar\lambda*\lambda$ to the constant path at $x_1$.
Hence $\Phi(\Psi[\gamma])=[\gamma*\lambda*\bar\lambda]=[\gamma]$ and $\Psi(\Phi[\alpha])=[\alpha*\bar\lambda*\lambda]=[\alpha]$.
:::

:::

::: pf-qed
By step [](#inverse-relations){.pf-ref}, $\Phi$ is a bijection $P\to\pi_1(X,x_0)$ with inverse $\Psi$.
:::

::: {.problem}
Show that if $(X_\alpha,\mathcal T_\alpha)$ are path-connected spaces, for $\alpha\in I$, then $\prod_{\alpha\in I}X_\alpha$, with the product topology, is also path-connected.
Show, on the other hand, that there are examples where this is false if we use the box topology instead.
:::

::: {.solution}

::: pf

::: {.pf-step #product-path-connected}
$\prod_{\alpha\in I}X_\alpha$ with the product topology is path-connected.

::: pf-proof
Let $b=(b_\alpha)$ and $x=(x_\alpha)$ be points of the product.
For each $\alpha$, choose a path $\gamma_\alpha\colon[0,1]\to X_\alpha$ from $b_\alpha$ to $x_\alpha$, and define $\gamma(t)=(\gamma_\alpha(t))_\alpha$.
Each coordinate $\pi_\alpha\circ\gamma=\gamma_\alpha$ is continuous, so $\gamma$ is continuous by the universal property of the product topology.
It is a path from $b$ to $x$.
:::

:::

::: {.pf-step #box-counterexample}
The box product $B=\Box_{n\in\NN}\RR$ is disconnected, although each factor $\RR$ is path-connected.

::: pf-proof
Let $M\subseteq B$ be the set of bounded sequences.
If $x\in M$ with $\abs{x_n}\le C$ for all $n$, the box neighborhood $\prod_n(x_n-1,x_n+1)$ consists of sequences bounded by $C+1$, so $M$ is open.
If $x\notin M$, every $y\in\prod_n(x_n-1,x_n+1)$ satisfies $\abs{y_n}\ge\abs{x_n}-1$, so $y$ is unbounded; thus $B\setminus M$ is open.
$M$ contains the zero sequence and omits $(n)_{n\in\NN}$, so it is a nonempty proper clopen subset of $B$.
:::

:::

::: pf-qed
Step [](#product-path-connected){.pf-ref} proves the first assertion.
By step [](#box-counterexample){.pf-ref}, $B$ is disconnected, hence not path-connected, which gives the required example for the box topology.
:::

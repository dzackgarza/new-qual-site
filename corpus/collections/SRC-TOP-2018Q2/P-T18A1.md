::: {.problem}
Show that if $(X_\alpha,\mathcal T_\alpha)$ are path-connected spaces, for $\alpha\in I$, then $\prod_{\alpha\in I}X_\alpha$, with the product topology, is also path-connected.
Show, on the other hand, that there are examples where this is false if we use the box topology instead.
:::
::: {.solution}
<1>1. Fix a point $x=(x_\alpha)\in\prod_\alpha X_\alpha$ and a basepoint $b=(b_\alpha)\in\prod_\alpha X_\alpha$.
::: {.proof}
The product is nonempty once one chooses the displayed point. To prove path-connectedness it suffices to join an arbitrary $x$ to $b$.
:::

<1>2. For each $\alpha$, choose a path $\gamma_\alpha:I\to X_\alpha$ from $b_\alpha$ to $x_\alpha$, and define
$$
\gamma(t)=(\gamma_\alpha(t))_\alpha.
$$
::: {.proof}
Each factor is path-connected, so such coordinate paths exist.
:::

<1>3. The map $\gamma:I\to\prod_\alpha X_\alpha$ is continuous for the product topology.
::: {.proof}
For every $\alpha$, the coordinate map $\pi_\alpha\circ\gamma=\gamma_\alpha$ is continuous. By the universal property of the product topology, this is equivalent to continuity of $\gamma$.
:::

<1>4. Hence the product $\prod_\alpha X_\alpha$ is path-connected.
::: {.proof}
The path in <1>2--<1>3 joins $b$ to the arbitrary point $x$.
:::

<1>5. The analogous assertion fails for the box topology; take $B=\Box_{n\in\mathbb N}\mathbb R$.
::: {.proof}
Every factor $\mathbb R$ is path-connected. We show $B$ is not even connected.
:::

<1>6. The subset
$$
M=\{(x_n)\in B:\sup_n|x_n|<\infty\}
$$
of bounded sequences is open in the box topology.
::: {.proof}
If $x\in M$, choose $C$ with $|x_n|\le C$ for all $n$. The box neighborhood $\prod_n(x_n-1,x_n+1)$ consists entirely of sequences bounded by $C+1$, so it lies in $M$.
:::

<1>7. The complement $B\setminus M$ is open.
::: {.proof}
Let $x=(x_n)$ be unbounded. For each $n$, put $\varepsilon_n=1$ if $|x_n|<1$, and $\varepsilon_n=|x_n|/2$ otherwise. If $y_n\in(x_n-\varepsilon_n,x_n+\varepsilon_n)$ for every $n$, then along any subsequence on which $|x_n|\to\infty$ we have $|y_n|\ge |x_n|/2\to\infty$. Thus every point of the box neighborhood $\prod_n(x_n-\varepsilon_n,x_n+\varepsilon_n)$ is unbounded.
:::

<1>8. Therefore the box product need not be path-connected.
::: {.proof}
The set $M$ is a nonempty proper clopen subset of $B$: it contains the zero sequence and excludes $(n)_{n\ge1}$. Hence $B$ is disconnected, and therefore not path-connected.
:::
:::

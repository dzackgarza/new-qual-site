::: {.problem}
How many homomorphisms are there from $\ZZ_{20}$ onto $\ZZ_{10}$? How many are there to $\ZZ_{10}$?
:::

::: {.solution}
A homomorphism onto $\ZZ _ { 1 0 }$ has image of order 10, which is possible since 10 divides 20. To have an image of $\ZZ _ { 1 0 } , \phi ( 1 )$ must generate $\ZZ _ { 1 0 }$ . Hence, $\phi ( 1 )$ is either 1, 3, 7, or 9. So there are 4 homomorphisms onto $\ZZ _ { 1 0 }$

For homomorphisms to $\ZZ _ { 1 0 }$, $\phi ( 1 )$ must have an order that divides 10 and 20. Every element of $\ZZ _ { 1 0 }$ has order dividing 10, hence dividing 20, so $\phi ( 1 )$ can be any element of $\ZZ _ { 1 0 }$. Thus there are 10 choices for $\phi ( 1 )$ : $\phi ( x ) = k x$ for any $k \in \ZZ _ { 1 0 }$
:::

::: {.problem}
Suppose that $\phi : \ZZ_{50} \to \ZZ_{15}$ is a group homomorphism with $\phi(7) = 6$.

(a) Determine $\phi(x)$.

(b) Determine the image of $\phi$.

(c) Determine the kernel of $\phi$.

(d) Determine $\phi^{-1}(3)$.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch10Sltns.pdf`, and entry "# 24" of that outline is this exercise, printed as Chapter 10 Exercise 24 in the seventh edition. The outline sets $k=\phi(1)$, reads $k=3$ off $7k\equiv6$, and takes the image, the kernel and the fiber from that; the steps below supply what that leaves out, namely that $7$ is invertible modulo $15$ so that $k$ is forced, that $k=3$ is compatible with $50\cdot1=0$ so that the map really is a homomorphism of $\ZZ_{50}$, and a computation of the kernel and the fiber from the congruence. Both groups are written additively, and an element of $\ZZ_{50}$ is named by its representative in $\{0,1,\ldots,49\}$.

::: pf

::: {.pf-step #determined}
A homomorphism $\psi\colon\ZZ_{50}\to\ZZ_{15}$ is determined by $k=\psi(1)\in\ZZ_{15}$, through $\psi(x)=kx$; the residues $k$ that arise this way are exactly those with $15\mid 50k$.

::: pf-proof
For a homomorphism $\psi$ and $x\ge0$, induction on $x$ from $\psi(0)=0$ and $\psi(a+1)=\psi(a)+\psi(1)$ gives $\psi(x)=xk$, so $\psi$ is determined by $k=\psi(1)$. Since $50\cdot1=0$ in $\ZZ_{50}$, one has $0=\psi(0)=\psi(50\cdot1)=50k$ in $\ZZ_{15}$, that is, $15\mid 50k$: this is a necessary condition on $k$. It is also sufficient. If $15\mid 50k$ and $x\equiv x'\pmod{50}$, then $x-x'=50t$ and $xk-x'k=50tk$ is a multiple of $15$, so $\psi(x)=xk$ is well defined; and $(x+y)k=xk+yk$ shows that $\psi$ is a homomorphism, with $\psi(1)=k$. Well-definedness is exactly what can fail: $k=1$ violates $15\mid50k$, and indeed $x\mapsto x$ is not a function on $\ZZ_{50}$ with values in $\ZZ_{15}$, since $0$ and $50$ would have to receive different values.
:::

:::

::: {.pf-step #a}
(a) $\boxed{\phi(x)=3x}$ for every $x\in\ZZ_{50}$.

::: pf-proof
By step [](#determined){.pf-ref} it is enough to compute $k=\phi(1)$. The hypothesis gives $6=\phi(7)=7k$ in $\ZZ_{15}$. Since $7\cdot13=91=6\cdot15+1$, the residue $7$ is invertible modulo $15$ with inverse $13$, so $k=13\cdot6=78=5\cdot15+3$, that is, $k=3$; and $k$ is the only residue modulo $15$ with $7k=6$. The value $k=3$ is admissible in the sense of step [](#determined){.pf-ref}: $50\cdot3=150=10\cdot15$, so $15\mid50k$. Hence $x\mapsto3x$ is a well-defined homomorphism $\ZZ_{50}\to\ZZ_{15}$, it satisfies $\phi(7)=21=6$, and by uniqueness of $k$ it is $\phi$. The outline states the conclusion "$k=3$" directly; the two facts used here, the invertibility of $7$ and the admissibility of $3$, are what make that line a determination rather than a guess.
:::

:::

::: {.pf-step #b}
(b) $\boxed{\im\phi=\langle3\rangle=\theset{0,3,6,9,12}}$ in $\ZZ_{15}$, a subgroup of order $5$.

::: pf-proof
By step [](#a){.pf-ref} the image is $\theset{3x : x\in\ZZ_{50}}$. Since $3(x+5)=3x+15\equiv3x\pmod{15}$, the value $3x$ depends only on the residue of $x$ modulo $5$, and each of the residues $0,1,2,3,4$ occurs among $0,1,\ldots,49$ because $5\mid50$. The five values are $0,3,6,9,12$, which are distinct modulo $15$, so the image has exactly five elements and is the cyclic subgroup generated by $3$.
:::

:::

::: {.pf-step #c}
(c) $\boxed{\ker\phi=\langle5\rangle=\theset{0,5,10,15,20,25,30,35,40,45}}$ in $\ZZ_{50}$.

::: pf-proof
By step [](#a){.pf-ref}, $x\in\ker\phi$ exactly when $3x\equiv0\pmod{15}$, that is, when $15\mid3x$. Since $15=3\cdot5$, this is equivalent to $5\mid x$, so the kernel is the set of multiples of $5$ in $\ZZ_{50}$, which are the ten listed residues; they form the cyclic subgroup $\langle5\rangle$. This agrees with Lagrange's theorem applied to $\ZZ_{50}/\ker\phi\cong\im\phi$: the kernel has order $10$ and the image order $5$, and $10\cdot5=50$.
:::

:::

::: {.pf-step #d}
(d) $\boxed{\phi^{-1}(3)=1+\ker\phi=\theset{1,6,11,16,21,26,31,36,41,46}}$.

::: pf-proof
By step [](#a){.pf-ref}, $\phi(x)=3$ exactly when $3x\equiv3\pmod{15}$, that is, when $15\mid3(x-1)$, equivalently $5\mid(x-1)$, equivalently $x\equiv1\pmod{5}$. So the fiber over $3$ is the set of $x\in\ZZ_{50}$ congruent to $1$ modulo $5$, which is the ten listed residues and is the coset $1+\ker\phi$ of step [](#c){.pf-ref}. It is nonempty, since $1$ itself lies in it, as it must be because $\phi(1)=3$.
:::

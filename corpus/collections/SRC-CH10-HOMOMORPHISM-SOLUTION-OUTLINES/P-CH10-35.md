::: {.problem}
Prove that the mapping $\phi : \ZZ \oplus \ZZ \to \ZZ$ given by $(a, b) \mapsto a - b$ is a homomorphism.
What is the kernel of $\phi$? Describe the set $\phi^{-1}(3)$.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch10Sltns.pdf`, whose entry "# 35" is this exercise: it checks the homomorphism property and identifies the kernel with the diagonal. The card writes the fibre of $3$ out as a coset, and the wording below is its own. Write elements of $\ZZ\oplus\ZZ$ as pairs, with the group operation $(a,b)+(c,d)=(a+c,b+d)$.

::: pf

::: {.pf-step #homomorphism}
$\phi\colon\ZZ\oplus\ZZ\to\ZZ$, $\phi(a,b)=a-b$, is a homomorphism.

::: pf-proof
For $(a,b),(c,d)\in\ZZ\oplus\ZZ$,
$$
\phi\bigl((a,b)+(c,d)\bigr)=\phi(a+c,b+d)=(a+c)-(b+d)=(a-b)+(c-d)=\phi(a,b)+\phi(c,d),
$$
so $\phi$ preserves the operation; the displayed rearrangement is valid in $\ZZ$.
:::

:::

::: {.pf-step #kernel}
$\ker\phi=\{(a,a)\mid a\in\ZZ\}$.

::: pf-proof
$\phi(a,b)=0$ exactly when $a-b=0$, that is $a=b$, so the kernel is the diagonal $\{(a,a):a\in\ZZ\}$, which is a subgroup of $\ZZ\oplus\ZZ$ — as the kernel of a homomorphism must be.
:::

:::

::: {.pf-step #fibre}
$\phi^{-1}(3)=(3,0)+\ker\phi=\{(a+3,a)\mid a\in\ZZ\}$.

::: pf-proof
$\phi(3,0)=3$, so $(3,0)$ is one point of the fibre and the fibre is nonempty. A homomorphism's fibres are the cosets of its kernel: for $(x,y)\in\ZZ\oplus\ZZ$ one has $\phi(x,y)=3$ if and only if $\phi\bigl((x,y)-(3,0)\bigr)=0$, that is $(x,y)-(3,0)\in\ker\phi$. Writing $(x,y)-(3,0)=(a,a)$ with $(a,a)\in\ker\phi$ gives $(x,y)=(a+3,a)$.
:::

:::

::: {.pf-step}
$\boxed{\ker\phi=\{(a,a)\mid a\in\ZZ\},\qquad \phi^{-1}(3)=\{(a+3,a)\mid a\in\ZZ\}}$.

::: pf-proof
The two displays are steps [](#kernel){.pf-ref} and [](#fibre){.pf-ref}, and step [](#homomorphism){.pf-ref} is the first part of the exercise. The fibre of $3$ is the coset of the kernel through the point $(3,0)$ that maps to $3$.
:::

::: {.problem}
Let p be a prime.
Determine the number of homomorphisms from $\ZZ _ { p } \oplus \ZZ _ { p }$ into $\ZZ _ { p }$ .
:::

::: {.solution}
Let $\phi : \ZZ _ { p } \oplus \ZZ _ { p } \to \ZZ _ { p }$ be a homomorphism.
Then $\phi ( ( a , b ) ) = a \phi ( ( 1 , 0 ) ) + b \phi ( ( 0 , 1 ) )$ . So to determine the number of homomorphisms, we only need to know the number of possible choices for $\phi ( ( 1 , 0 ) )$ and $\phi ( ( 0 , 1 ) )$ . But $p$ is prime, so we can send each of these to any element in $\ZZ _ { p }$ (everything except 0 will be a generator so the image will automatically have order $p$ or 1). Thus there are $p ^ { 2 }$ homomorphisms.
:::

::: {.problem}
Prove that the mapping from $\CC^{*}$ to $\CC^{*}$ given by $\phi(z) = z^{2}$ is a homomorphism and that $\CC^{*}/\{1, -1\}$ is isomorphic to $\CC^{*}$.
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **item 65, PDF p. 4** (`assets/attachments/Ch10Sltns.pdf`), restructured into steps.

Throughout, $\CC^{*}$ is the group of nonzero complex numbers under multiplication, $1$ is its identity, and $\phi(z)=z^{2}$.

::: pf

::: {.pf-step #hom}
$\phi:\CC^{*}\to\CC^{*}$ is a well-defined homomorphism.

::: pf-proof
If $z\neq0$ then $z^{2}\neq0$, since $\CC$ is a field, so $\phi$ takes its values in $\CC^{*}$.

For $z,w\in\CC^{*}$ the product is commutative, so $\phi(zw)=(zw)^{2}=zwzw=zzww=z^{2}w^{2}=\phi(z)\phi(w)$. Hence $\phi$ preserves the operation; it preserves $1$ because $1^{2}=1$.
:::

:::

::: {.pf-step #kernel}
$\ker\phi=\{1,-1\}$.

::: pf-proof
$z\in\ker\phi$ means $z^{2}=1$, that is $z^{2}-1=(z-1)(z+1)=0$. A product in the field $\CC$ vanishes only if one factor does, so $z=1$ or $z=-1$; conversely $1^{2}=1$ and $(-1)^{2}=1$. So the kernel is exactly the two-element set $\{1,-1\}$, which is a subgroup, as every kernel is, and in particular normal in the abelian group $\CC^{*}$.
:::

:::

::: {.pf-step #onto}
$\phi$ is onto.

::: pf-proof
Let $w\in\CC^{*}$. Write $w=re^{i\theta}$ with $r=\abs{w}>0$ and $\theta\in\RR$, and put $\zeta=\sqrt{r}\,e^{i\theta/2}$, where $\sqrt{r}$ is the positive real square root. Then $\zeta\neq0$, so $\zeta\in\CC^{*}$, and $\zeta^{2}=(\sqrt{r})^{2}e^{i\theta}=re^{i\theta}=w$. Hence every element of $\CC^{*}$ is a square, that is, $\operatorname{im}\phi=\CC^{*}$.
:::

:::

::: {.pf-step #iso}
$\CC^{*}/\{1,-1\}\cong\CC^{*}$.

::: pf-proof
By step [](#hom){.pf-ref} $\phi$ is a homomorphism of groups, by step [](#kernel){.pf-ref} its kernel is $\{1,-1\}$, and by step [](#onto){.pf-ref} it is onto. The First Isomorphism Theorem (Theorem 10.3) states that a homomorphism with kernel $K$ induces an isomorphism $G/K\to\operatorname{im}\phi$, $gK\mapsto\phi(g)$. Applied here it gives an isomorphism $\CC^{*}/\{1,-1\}\to\CC^{*}$, since the image is all of $\CC^{*}$. Explicitly, the induced map $z\{1,-1\}\mapsto z^{2}$ is well defined because $(-z)^{2}=z^{2}$, it is injective because $z^{2}=w^{2}$ forces $z=\pm w$ by step [](#kernel){.pf-ref}, and it is onto by step [](#onto){.pf-ref}.
:::

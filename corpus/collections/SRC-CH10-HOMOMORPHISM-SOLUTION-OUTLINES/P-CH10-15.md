::: {.problem}
Suppose that $\phi$ is a homomorphism from $\ZZ_{30}$ to $\ZZ_{30}$ and $\ker\phi = \{0, 10, 20\}$. If $\phi(23) = 9$, determine all elements that map to $9$.
:::

::: {.solution}

The elements mapping to $9$ are $\{23,3,13\}$.

::: pf

::: {.pf-step #fibre}

$\phi^{-1}(9)=23+\ker\phi$ in $\ZZ_{30}$.

::: pf-proof

Both groups are written additively. For any homomorphism and any $a$ in its
domain, $\phi^{-1}(\phi(a))=a+\ker\phi$: indeed $\phi(x)=\phi(a)$ iff
$\phi(x-a)=\phi(x)-\phi(a)=0$ iff $x-a\in\ker\phi$ iff $x\in a+\ker\phi$. Taking
$a=23$, where $\phi(23)=9$, gives $\phi^{-1}(9)=23+\ker\phi$.

:::

:::

::: {.pf-step #compute}

$23+\ker\phi=\{23,33,43\}=\{23,3,13\}$ in $\ZZ_{30}$.

::: pf-proof

The kernel is $\{0,10,20\}$, so the coset consists of $23+0=23$, $23+10=33\equiv
3\pmod{30}$ and $23+20=43\equiv 13\pmod{30}$. These are three distinct residues,
matching the size of the kernel, as a fibre must.

:::

:::

::: {.pf-step #consistent}

The data are consistent: $\phi(x)=3x \bmod 30$ is such a homomorphism.

::: pf-proof

$\phi(x)=3x\bmod 30$ is a homomorphism of the additive group $\ZZ_{30}$ because
$3(x+y)=3x+3y$. Its kernel is $\{x: 30\mid 3x\}=\{x: 10\mid x\}=\{0,10,20\}$ and
$\phi(23)=69\equiv 9\pmod{30}$. So the stated kernel and value do occur, and no
other value of $\phi(23)$ is being smuggled in.

:::

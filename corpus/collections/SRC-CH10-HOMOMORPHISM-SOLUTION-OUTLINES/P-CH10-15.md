::: {.problem}
Suppose that $\phi$ is a homomorphism from $\ZZ_{30}$ to $\ZZ_{30}$ and $\ker\phi = \{0, 10, 20\}$. If $\phi(23) = 9$, determine all elements that map to $9$.
:::

::: {.solution}
The elements that map to $9$ form $\phi ^ { - 1 } ( 9 )$. Since $\phi(23) = 9$, this preimage is the coset $23 + \ker\phi = \{ 2 3 , 3 , 1 3 \}$.
:::

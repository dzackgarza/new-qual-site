::: {.problem}
Suppose that $\phi$ is a homomorphism from $\mathbb { Z } _ { 3 0 }$ to $\mathbb { Z } _ { 3 0 }$ and $K e r \phi = \{ 0 , 1 0 , 2 0 \}$ If $\phi ( 2 3 ) = 9$ determine all elements that map to 9.
:::

::: {.solution}
The elements that map to $9$ form $\phi ^ { - 1 } ( 9 )$. Since $\phi(23) = 9$, this preimage is the coset $23 + \ker\phi = \{ 2 3 , 3 , 1 3 \}$.
:::

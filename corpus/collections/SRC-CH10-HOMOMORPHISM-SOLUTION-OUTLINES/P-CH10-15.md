::: {.problem}
Suppose that $\phi$ is a homomorphism from $\mathbb { Z } _ { 3 0 }$ to $\mathbb { Z } _ { 3 0 }$ and $K e r \phi = \{ 0 , 1 0 , 2 0 \}$ If $\phi ( 2 3 ) = 9$ determine all elements that map to 9.
:::

::: {.solution}
Notice that this question is really just asking for $\phi ^ { - 1 } ( 9 )$ . By the properties of homomorphisms, we know that this is the coset $2 3 \, \mathrm { K e r } \phi$ , or $\{ 2 3 , 3 , 1 3 \}$ .
:::

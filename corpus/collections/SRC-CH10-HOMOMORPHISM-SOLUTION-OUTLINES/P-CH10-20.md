::: {.problem}
How many homomorphisms are there from $\ZZ_{20}$ onto $\ZZ_{8}$? How many are there to $\ZZ_{8}$?
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **Gallian, *Contemporary Abstract Algebra*, seventh edition, Chapter 10 solution outlines, exercise 20, PDF pp. 1--2** (`assets/attachments/Ch10Sltns.pdf`), restructured into steps. One statement of the outline is corrected: it says that a homomorphism with $\phi(1)$ of order $1$ "is the identity map", but the map so determined is the trivial homomorphism $\phi(x)=0$, the identity map being no homomorphism $\ZZ_{20}\to\ZZ_{8}$ at all.

::: pf

::: {.pf-step #determined}
A homomorphism $\phi:\ZZ_{20}\to\ZZ_{8}$ is determined by $\phi(1)$, and $\phi(x)=x\,\phi(1)$.

::: pf-proof
$\ZZ_{20}$ is cyclic, generated by $1$, so $\phi(x)=\phi(x\cdot1)=x\,\phi(1)$ for every $x$; hence $\phi$ is determined by the single value $\phi(1)$.
:::

:::

::: {.pf-step #order}
$\phi(1)$ has order dividing $\gcd(20,8)=4$.

::: pf-proof
The order of $\phi(1)$ divides the order of the element $1$ in $\ZZ_{20}$, which is $20$, because homomorphisms carry an element of order $m$ to an element whose order divides $m$; and it divides $8=\cardinality{\ZZ_{8}}$. Two divisors of $20$ and of $8$ divide their gcd, $4$.
:::

:::

::: {.pf-step #onto}
There is no homomorphism of $\ZZ_{20}$ onto $\ZZ_{8}$.

::: pf-proof
If $\phi$ were onto then by the first isomorphism theorem $\cardinality{\ZZ_{20}}=\cardinality{\operatorname{im}\phi}\cdot\cardinality{\ker\phi}=8\cdot\cardinality{\ker\phi}$, so $8$ would divide $20$, which it does not.
:::

:::

::: {.pf-step #list}
The homomorphisms $\ZZ_{20}\to\ZZ_{8}$ are exactly $x\mapsto0$, $x\mapsto4x$, $x\mapsto2x$ and $x\mapsto6x$.

::: pf-proof
By steps [](#determined){.pf-ref} and [](#order){.pf-ref}, $\phi(1)=a$ must satisfy $4a\equiv0\pmod 8$, that is $a$ even; the even residues modulo $8$ are $0,2,4,6$, and each gives a well-defined homomorphism $\phi(x)=ax$ because $\phi(x+20)=\phi(x)+20a$ and $20a\equiv0\pmod8$ when $a$ is even. The four are distinct because they differ at $1$. Their images are $\{0\}$, $\{0,4\}$, and $\{0,2,4,6\}$ for $a=2$ and $a=6$ respectively.
:::

:::

::: {.pf-step}
There is no homomorphism onto $\ZZ_{8}$, and there are $4$ homomorphisms to $\ZZ_{8}$.

::: pf-proof
Steps [](#onto){.pf-ref} and [](#list){.pf-ref} give
$$
\boxed{\text{no onto homomorphism }\ZZ_{20}\to\ZZ_{8};\qquad 4\text{ homomorphisms }\ZZ_{20}\to\ZZ_{8}.}
$$
The count is $4$, the number of even residues modulo $8$, equivalently the number of elements of $\ZZ_{8}$ whose order divides $4$.
:::

::: {.problem}
How many homomorphisms are there from $\ZZ _ { 2 0 }$ onto $\ZZ _ { 8 } { \mathrm { ? } }$ How many are there to $\ZZ _ { 8 } { \mathrm { ? } }$
:::

::: {.solution}
A homomorphism onto $\ZZ _ { 8 }$ has image of order 8. But the order of the image must divide the order of $\ZZ _ { 2 0 }$ since $\left| \ZZ _ { 2 0 } \right| = \left| I m \phi \right| \times \left| \ker \phi \right|$ . But 8 does not divide 20 so there is no onto homomorphism between $\ZZ _ { 2 0 }$ and $\ZZ _ { 8 }$

Now, consider homomorphisms in general from $\ZZ _ { 2 0 }$ to $\ZZ _ { 8 }$ . The order of $\phi ( 1 )$ must divide 8 and 20, or divide the $g c d ( 8 , 2 0 ) = 4$ Thus the $\phi ( 1 )$ has order 1, 2 or 4. If it has order 1, then $\phi$ is the trivial map $\phi(x) = 0$.
If it has order 2, the image is $\{ 4 , 0 \}$ so $\phi ( x ) = 4 x$ If it has order 4, the image is $\{ 2 , 4 , 6 , 0 \}$ so either $\phi ( x ) = 2 x$ or $\phi ( x ) = 6 x$ . Hence there are 4 homomorphisms to $\ZZ _ { 8 }$
:::

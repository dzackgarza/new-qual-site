::: {.problem}
Suppose that $\phi$ is a homomorphism from a finite group $G$ onto $\bar{G}$, and that $\bar{G}$ has an element of order $8$. Prove that $G$ has an element of order $8$. Generalize.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch10Sltns.pdf`, and entry "# 22" of that outline is this exercise, which the seventh edition prints as Chapter 10 Exercise 22. The argument is the outline's: a preimage of an element of order $8$ has order divisible by $8$, and a power of that preimage has order exactly $8$. What the card adds is the proof of the divisibility the outline invokes, the verification of the order of the power, the derivation of the count of four elements of order $8$ that the outline states, and the hypothesis the generalization needs.

Write $G$ and $\bar{G}$ multiplicatively, with identities $e$ and $\bar e$, and write $\elementorder{x}$ for the order of an element.

::: pf

::: {.pf-step #order-divides}
If $g\in G$ has finite order then $\elementorder{\phi(g)}$ divides $\elementorder{g}$.

::: pf-proof
Put $k=\elementorder{g}$ and $\bar g=\phi(g)$. Then $\bar g^{k}=\phi(g)^{k}=\phi(g^{k})=\phi(e)=\bar e$: the first equality is the compatibility of a homomorphism with powers, the second is $g^{k}=e$, and $\phi(e)=\bar e$ because $\phi(e)=\phi(e\cdot e)=\phi(e)\phi(e)$ cancels in the group $\bar G$. So $\bar g$ has finite order, and a positive power $\bar g^{j}$ equals $\bar e$ exactly when $\elementorder{\bar g}$ divides $j$: writing $j=q\elementorder{\bar g}+r$ with $0\le r<\elementorder{\bar g}$, one has $\bar g^{r}=\bar e$, and $r>0$ would contradict the minimality of $\elementorder{\bar g}$, so $r=0$. Applying this to $j=k$ gives $\elementorder{\phi(g)}\mid\elementorder{g}$.
:::

:::

::: {.pf-step #order-eight}
$G$ has an element of order $8$.

::: pf-proof

::: {.pf-step #preimage}
There is $g\in G$ with $\elementorder{\phi(g)}=8$, and then $\elementorder{g}=8m$ for some integer $m\ge1$.

::: pf-proof
Since $\bar{G}$ has an element of order $8$, choose $\bar g\in\bar{G}$ with $\elementorder{\bar g}=8$; since $\phi$ is onto, choose $g\in G$ with $\phi(g)=\bar g$. The group $G$ is finite, so $\elementorder{g}$ is finite — indeed $\elementorder{g}$ divides $\cardinality{G}$ by Lagrange's theorem. By step [](#order-divides){.pf-ref}, $8=\elementorder{\phi(g)}$ divides $\elementorder{g}$, so $\elementorder{g}=8m$ with $m\ge1$ an integer.
:::

:::

::: {.pf-step #power}
The element $g^{m}$ has $\boxed{\elementorder{g^{m}}=8}$, so $G$ has an element of order $8$.

::: pf-proof
First $(g^{m})^{8}=g^{8m}=e$, because $\elementorder{g}=8m$. Second, if $(g^{m})^{j}=e$ for an integer $j$ with $0<j<8$, then $g^{mj}=e$ with $0<mj<8m=\elementorder{g}$, which contradicts the minimality of the order of $g$. Hence $8$ is the least positive exponent that kills $g^{m}$, that is, $\elementorder{g^{m}}=8$. The outline reaches the same conclusion by counting: the subgroup $\langle g\rangle$ is cyclic of order $8m$, and $g^{s}$ has order $8m/\gcd(8m,s)$, which equals $8$ exactly when $\gcd(8m,s)=m$, that is, when $s=mt$ with $\gcd(8,t)=1$; the elements of order $8$ in $\langle g\rangle$ are therefore $g^{m},g^{3m},g^{5m},g^{7m}$, four of them, and $g^{m}$ is one.
:::

:::

:::

:::

::: {.pf-step #general}
For every integer $n\ge1$, if $\bar{G}$ has an element of order $n$ then $G$ has an element of order $n$; and the finiteness of $G$ cannot be dropped from the hypothesis.

::: pf-proof
Let $n\ge1$ and let $\bar g\in\bar{G}$ have order $n$; choose a preimage $g\in G$. By step [](#order-divides){.pf-ref} the integer $n=\elementorder{\phi(g)}$ divides $\elementorder{g}$, say $\elementorder{g}=nm$ with $m\ge1$, and the computation in step [](#power){.pf-ref} with $n$ in place of $8$ gives $(g^{m})^{n}=e$ with no smaller positive power, so $\elementorder{g^{m}}=n$. The number $8$ is therefore not special: every element order occurring in $\bar{G}$ occurs in $G$. Finiteness of $G$ is used only to make $\elementorder{g}$ finite, and it is not removable. The reduction $\phi\colon\ZZ\to\ZZ_{8}$, $x\mapsto x\bmod 8$, is a homomorphism onto a group whose element $1$ has order $8$, while $n\cdot x\ne0$ for every nonzero $x\in\ZZ$ and every $n\ge1$, so no element of $\ZZ$ has finite order and $\ZZ$ has no element of order $8$. The hypothesis that $G$ is finite thus cannot be weakened to saying only that $\bar{G}$ is finite.
:::

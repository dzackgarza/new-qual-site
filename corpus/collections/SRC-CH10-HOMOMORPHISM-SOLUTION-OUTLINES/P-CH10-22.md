::: {.problem}
Suppose that $\phi$ is a homomorphism from a finite group G onto $\bar { G }$, and that $\bar { G }$ has an element of order 8. Prove that G has an element of order 8. Generalize.
:::

::: {.solution}
Since $\phi$ is onto, there exists a $g \in G$ such that $\phi ( g )$ has order 8. Thus (Thm 10.1), the order of $g$ is divisible by 8. Say $| g | = 8 k$ for some integer k. Then $g^k$ has order $8$, so G has an element of order 8.

In general, if $\bar G$ has an element of order $n$, then so does $G$: a preimage $g$ of that element has order divisible by $n$, say $\abs{g} = nk$, and $g^k$ has order $n$.
:::

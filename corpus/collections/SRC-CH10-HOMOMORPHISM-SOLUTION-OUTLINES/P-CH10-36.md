::: {.problem}
Suppose that there is a homomorphism $\phi$ from $\mathbb { Z } \oplus \mathbb { Z }$ to a group $G$ such that $\phi ( ( 3 , 2 ) ) = a$ and $\phi ( ( 2 , 1 ) ) = b$ . Determine $\phi ( ( 4 , 4 ) )$ in terms of a and b. Assume that the operation of G is addition.
:::

::: {.solution}
First notice that $c ( 3 , 2 ) + d ( 2 , 1 ) = ( 4 , 4 )$ implies that $3 c + 2 d = 4$ and $2 c + d = 4$ Hence $d = 4 - 2 c { \mathrm { ~ s o ~ } } 3 c + 8 - 4 c = 8 - c = 4$ Therefore $c = 4$ and $d = - 4 .$ So $\phi ( ( 4 , 4 ) ) = \phi ( 4 ( 3 , 2 ) + - 4 ( 2 , 1 ) ) = 4 \phi ( 3 , 2 ) - 4 \phi ( 2 , 1 ) = 4 a - 4 b .$
:::

::: {.problem}
Suppose that $\phi$ is a homomorphism from $U(30)$ to $U(30)$ and that $\ker \phi = \{1, 11\}$. If $\phi(7) = 7$, find all elements of $U(30)$ that map to $7$.
:::

::: {.solution}
$$
\phi ^ { - 1 } ( 7 ) = 7 \ker \phi = \{7, 17\} .
$$
:::

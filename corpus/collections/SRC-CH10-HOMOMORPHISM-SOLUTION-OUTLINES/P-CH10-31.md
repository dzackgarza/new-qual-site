::: {.problem}
Suppose that $\phi$ is a homomorphism from $U(30)$ to $U(30)$ and that $\ker \phi = \{1, 11\}$. If $\phi(7) = 7$, find all elements of $U(30)$ that map to $7$.
:::

::: {.solution}

Let $\phi\colon U(30)\to U(30)$ be a homomorphism with $\ker\phi=\{1,11\}$ and
$\phi(7)=7$; recall $U(30)=\{1,7,11,13,17,19,23,29\}$ under multiplication mod
$30$.

::: pf

::: {.pf-step #fibre}

For any homomorphism and any $a$, $\phi^{-1}(\phi(a))=a\ker\phi$.

::: pf-proof

$\phi(x)=\phi(a)$ iff $\phi(xa^{-1})=\phi(x)\phi(a)^{-1}=1$ iff
$xa^{-1}\in\ker\phi$ iff $x\in(\ker\phi)a$. Since a kernel is normal,
$(\ker\phi)a=a\ker\phi$, so the fibre is the coset $a\ker\phi$; no injectivity
of $\phi$ is needed, only that $\phi$ is a homomorphism.

:::

:::

::: {.pf-step #elements}

$7\ker\phi=\{7\cdot1,\,7\cdot11\}=\{7,17\}$ in $U(30)$.

::: pf-proof

The kernel has the two elements $1$ and $11$, so the coset consists of
$7\cdot1=7$ and $7\cdot11=77$ reduced modulo $30$, and $77-60=17$. Both are
units modulo $30$, as they must be, since $U(30)$ is a group and the coset
lies in it. Hence $\phi^{-1}(7)=\{7,17\}$.

:::

:::

::: {.pf-step #check}

$\{7,17\}$ is exactly the set of elements mapping to $7$, and it has two
elements, the size of the kernel.

::: pf-proof

By step [](#fibre){.pf-ref} with $a=7$, the fibre is $7\ker\phi$, which step
[](#elements){.pf-ref} computes as $\{7,17\}$; the fibre of a homomorphism
always has as many elements as the kernel, and the two answers agree. So the
elements are $7$ and $17$.

:::

::: {.problem}
Prove that $( A \oplus B ) / ( A \oplus \{ e \} ) \approx B .$
:::

::: {.solution}
Define $\phi : ( A \oplus B ) \to B$ by $( a , b ) \mapsto b$ . Then $\phi$ is a homomorphism since $\phi ( ( a , b ) ( c , d ) ) =$ $\phi ( ( a c , b d ) ) = b d = \phi ( ( a , b ) ) \phi ( ( c , d ) )$ Further, the image of $\phi$ is $B$ since for each $y \in B$ and any $a \in A$, $\phi ( a , y ) = y$. Finally, $\ker \phi = \{(a,b) : b = e\} = A \oplus \{ e \}$. Thus, by the first isomorphism theorem, $( A \oplus B ) / ( A \oplus \{ e \} ) \approx B$ .
:::

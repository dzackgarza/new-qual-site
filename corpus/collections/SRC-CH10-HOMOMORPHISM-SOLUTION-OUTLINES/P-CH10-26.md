::: {.problem}
Determine all homomorphisms from $\ZZ_{4}$ to $\ZZ_{2} \oplus \ZZ_{2}$.
:::

::: {.solution}

The argument is the card's own: a homomorphism out of a cyclic group is determined by its value on a generator, and the order of that value must divide $4$.

::: pf

::: {.pf-step #determined}

Every homomorphism $\varphi:\ZZ_{4}\to\ZZ_{2}\oplus\ZZ_{2}$ is determined by $y=\varphi(1)$, and $o(y)\mid4$.

::: pf-proof

$\ZZ_{4}$ is cyclic generated by $1$, so $\varphi(k)=k\varphi(1)=ky$ for every $k$. Also $0=\varphi(0)=\varphi(4\cdot1)=4y$, so $o(y)$ divides $4$; and $o(y)$ divides $\abs{\ZZ_{2}\oplus\ZZ_{2}}=4$ always. Conversely, any $y\in\ZZ_{2}\oplus\ZZ_{2}$ with $4y=0$ — that is, any $y$ — defines a homomorphism $k\mapsto ky$, and this is well defined exactly because $4y=0$.

:::

:::

::: {.pf-step #noorder4}

No $y\in\ZZ_{2}\oplus\ZZ_{2}$ has order $4$.

::: pf-proof

Every nonidentity element of $\ZZ_{2}\oplus\ZZ_{2}$ has order $2$, since $2(a,b)=(2a,2b)=(0,0)$. So the possible orders of $y$ are $1$ and $2$, and the image of $\varphi$ has order $1$ or $2$, never $4$. In particular no homomorphism is an isomorphism.

:::

:::

::: {.pf-step #count}

There are exactly four homomorphisms.

::: pf-proof

By step [](#determined){.pf-ref} the homomorphisms correspond to the four elements $y\in\ZZ_{2}\oplus\ZZ_{2}$: the identity $y=(0,0)$ gives the trivial map, and the three elements of order $2$ give the maps $k\mapsto k(1,0)=(k\bmod 2,0)$, $k\mapsto k(0,1)=(0,k\bmod 2)$ and $k\mapsto k(1,1)=(k\bmod 2,k\bmod 2)$, whose images are the three distinct subgroups of order $2$:
$$
\boxed{\operatorname{Hom}(\ZZ_{4},\ZZ_{2}\oplus\ZZ_{2})\ \text{has } 4 \text{ elements.}}
$$

:::

::: {.problem}
(Third Isomorphism Theorem) If M and N are normal subgroups of G and $N \leq M$ , prove that $( G / N ) / ( M / N ) \approx G / M$
:::

::: {.solution}
Consider the map φ from $G / N$ to $G / M$ defined by $g N \mapsto g M$ . It is well defined because $N \le M$: if $gN = g'N$, then $g^{-1}g' \in N \subseteq M$, so $gM = g'M$. Then $\phi$ is a homomorphism since $\phi ( g N h N ) = \phi ( g h N ) = g h M = g M h M = \phi ( g N ) \phi ( h N )$ . This map is onto since $g M$ is the image of $g N$ . The kernel of this map is $\{ g N | \phi ( g N ) = M \} =$ $\{ g N | g M = M \} = \{ g N | g \in M \} = M / N$ . Hence by the first isomorphism theorem, $( G / N ) / ( M / N ) \approx G / M$.
:::

::: {.problem}
Suppose that $f$ is a continuous function on R which vanishes outside some finite interval and for each $z \subset \mathbb { C }$ define

$$
g ( z ) = \int _ { - \infty } ^ { \infty } f ( t ) \exp ( - i z t ) d t .
$$

Show that $g$ is entire.
:::

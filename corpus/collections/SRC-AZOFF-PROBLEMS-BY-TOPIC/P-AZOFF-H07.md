::: problem
Let $| a _ { k } | < 1 ( k = 1 , 2 , \ldots , n ) , | b | < 1$ and

$$
f ( z ) = { \frac { z - a _ { 1 } } { 1 - { \overline { { a } } } _ { 1 } z } } { \frac { z - a _ { 2 } } { 1 - { \overline { { a } } } _ { 2 } z } } \cdots { \frac { z - a _ { n } } { 1 - { \overline { { a } } } _ { n } z } } .
$$

Show that $f ( z ) = b$ has n solutions in $| z | < 1$
:::

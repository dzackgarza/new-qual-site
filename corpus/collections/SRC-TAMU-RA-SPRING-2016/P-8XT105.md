::: {.problem}
Prove the following two statements:

(a) suppose $f$ is a measurable function on $[0,1]$, then $$\|f\|_{L^\infty}=\lim_{p\to\infty}\|f\|_{L^p};$$

(b) If $f_n\ge 0$ and $f_n\to f$ in measure, then $\int f\le\liminf\int f_n$.
:::


::: {.solution}
<1>1. Prove the $L^p$-norm limit.
::: {.proof}
Let $M=\|f\|_{L^\infty}$, allowing $M=\infty$.
For finite $M$, since $[0,1]$ has measure $1$,
\[
\|f\|_p\le M
\]
for every $p<\infty$.
Conversely, for every $0<\varepsilon<M$, the set
\[
E_\varepsilon=\{x:|f(x)|>M-\varepsilon\}
\]
has positive measure by the definition of essential supremum. Hence
\[
\|f\|_p^p\ge (M-\varepsilon)^p m(E_\varepsilon),
\]
so
\[
\|f\|_p\ge (M-\varepsilon)m(E_\varepsilon)^{1/p}.
\]
Letting $p\to\infty$ gives
\[
\liminf_{p\to\infty}\|f\|_p\ge M-\varepsilon.
\]
Since $\varepsilon$ is arbitrary,
\[
\lim_{p\to\infty}\|f\|_p=M.
\]
If $M=\infty$, then for every $A>0$ the set $\{|f|>A\}$ has positive measure, and the same estimate gives
\[
\liminf_{p\to\infty}\|f\|_p\ge A.
\]
Since $A$ is arbitrary, the limit is $\infty$.
:::

<1>2. Prove Fatou's inequality under convergence in measure.
::: {.proof}
Set
\[
L=\liminf_{n\to\infty}\int f_n.
\]
If $L=\infty$, there is nothing to prove. Otherwise choose a subsequence $(f_{n_k})$ such that
\[
\int f_{n_k}\longrightarrow L.
\]
Because $f_n\to f$ in measure, the subsequence $(f_{n_k})$ also converges to $f$ in measure. Therefore it has a further subsequence $(f_{n_{k_j}})$ converging to $f$ almost everywhere.
Since all functions are nonnegative, Fatou's lemma gives
\[
\int f\le \liminf_{j\to\infty}\int f_{n_{k_j}}=L.
\]
Thus
\[
\int f\le\liminf_{n\to\infty}\int f_n.
\]
:::
:::

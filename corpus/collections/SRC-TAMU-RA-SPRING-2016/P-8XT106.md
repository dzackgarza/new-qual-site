::: {.problem}
Suppose $\{f_n\}$ is a sequence of functions in $L^2([0,1])$ such that $\|f_n\|_{L^2}\le 1$.
If $f$ is measurable and $f_n\to f$ in measure, then

(a) $f\in L^2([0,1])$;

(b) $f_n\to f$ weakly in $L^2$;

(c) $f_n\to f$ with respect to norm in $L^p$ for $1\le p<2$.

Hint for part (b): Use Vitali convergence theorem, that is, if $g_n\to g$ pointwise a.e. on $[0,1]$ and $\{g_n\}$ is uniformly integrable, then $$\lim_{n\to\infty}\int_0^1 g_n=\int_0^1 g.$$ Recall that $\{g_n\}$ being uniformly integrable means that for each $\varepsilon>0$, there exists a $\delta>0$ such that $\int_A|g_n|<\varepsilon$ for all $n$ and all measurable $A\subseteq[0,1]$ with $m(A)<\delta$.

Hint for part (c): use the fact that, if $g_n$ is a sequence in $L^p([0,1])$ that converges pointwise a.e. to $g\in L^p([0,1])$, then $g_n$ converges to $g$ in norm if and only if $\{|g_n|^p\}$ is uniformly integrable.
:::

::: {.solution}
**(a).**

::: pf

::: {.pf-step #p1-1}
Since $f_n \to f$ in measure, there exists a subsequence $\{f_{n_k}\}$ such that $f_{n_k}(x) \to f(x)$ pointwise almost everywhere on $[0, 1]$.

::: pf-proof
Riesz's theorem on convergence in measure implying a.e. convergence of a subsequence.
:::

:::

::: {.pf-step #p1-2}
By Fatou's Lemma:
\[
\int_0^1 |f(x)|^2\,dx = \int_0^1 \lim_{k\to\infty} |f_{n_k}(x)|^2\,dx \le \liminf_{k\to\infty} \int_0^1 |f_{n_k}(x)|^2\,dx = \liminf_{k\to\infty} \|f_{n_k}\|_{L^2}^2.
\]

::: pf-proof
Fatou's Lemma applied to the nonnegative sequence $|f_{n_k}|^2$.
:::

:::

::: {.pf-step #p1-3}
Since $\|f_n\|_{L^2} \le 1$ for all $n$, $\liminf_{k\to\infty} \|f_{n_k}\|_{L^2}^2 \le 1$.

::: pf-proof
hypothesis $\|f_n\|_{L^2} \le 1$.
:::

:::

::: {.pf-step #p1-4}
Hence $\int_0^1 |f(x)|^2\,dx \le 1 < \infty$, which proves $f \in L^2([0, 1])$ and $\|f\|_{L^2} \le 1$.

::: pf-proof
Step [](#p1-2){.pf-ref} and step [](#p1-3){.pf-ref}.
:::

:::

:::

**(b).**

::: pf

::: {.pf-step #p2-1}
It suffices to show that for every $g \in L^2([0, 1])$, every subsequence of $\int_0^1 f_n g\,dx$ has a further subsequence converging to $\int_0^1 fg\,dx$.

::: pf-proof
subsequence principle for convergence of real sequences.
:::

:::

::: pf-step
Given any subsequence $\{f_{n_k}\}$, extract a further subsequence $\{f_{n_{k_j}}\}$ converging to $f$ pointwise a.e. on $[0, 1]$.

::: pf-proof
step [](#p1-1){.pf-ref} (a) applied to the subsequence.
:::

:::

::: {.pf-step #p2-3}
The sequence $h_j = f_{n_{k_j}} g$ converges pointwise a.e. to $fg$ on $[0, 1]$.

::: pf-proof
pointwise product of converging sequences.
:::

:::

::: {.pf-step #p2-4}
The sequence $\{h_j\}$ is uniformly integrable on $[0, 1]$.

::: pf-proof

::: {.pf-step #p2-4-1}
For any measurable $A \subseteq [0, 1]$, Cauchy–Schwarz gives:
\[
\int_A |h_j|\,dx = \int_A |f_{n_{k_j}} g|\,dx \le \|f_{n_{k_j}}\|_{L^2} \left(\int_A |g|^2\,dx\right)^{1/2} \le \left(\int_A |g|^2\,dx\right)^{1/2}.
\]

::: pf-proof
Cauchy–Schwarz inequality and $\|f_m\|_{L^2} \le 1$.
:::

:::

::: {.pf-step #p2-4-2}
Since $g \in L^2([0, 1])$, the measure $\nu(A) = \int_A |g|^2\,dx$ is absolutely continuous with respect to Lebesgue measure.

::: pf-proof
absolute continuity of Lebesgue integrals.
:::

:::

::: {.pf-step #p2-4-3}
For any $\varepsilon > 0$, there exists $\delta > 0$ such that $m(A) < \delta \implies \nu(A) < \varepsilon^2$.

::: pf-proof
step [](#p2-4-2){.pf-ref}.
:::

:::

::: pf-step
Hence $m(A) < \delta \implies \int_A |h_j|\,dx < \varepsilon$ for all $j \ge 1$, which proves uniform integrability.

::: pf-proof
step [](#p2-4-1){.pf-ref} and step [](#p2-4-3){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #p2-5}
By the Vitali Convergence Theorem:
\[
\lim_{j\to\infty} \int_0^1 f_{n_{k_j}} g\,dx = \int_0^1 fg\,dx.
\]

::: pf-proof
step [](#p2-3){.pf-ref}, step [](#p2-4){.pf-ref}, and Vitali Convergence Theorem on a finite measure space.
:::

:::

::: {.pf-step #p2-6}
Therefore $f_n \rightharpoonup f$ weakly in $L^2([0, 1])$.

::: pf-proof
step [](#p2-1){.pf-ref} and step [](#p2-5){.pf-ref}.
:::

:::

:::

**(c).**

::: pf

::: {.pf-step #p3-1}
Let $1 \le p < 2$.
It suffices to show that every subsequence of $\{f_n\}$ has a further subsequence converging to $f$ in $L^p([0, 1])$.

::: pf-proof
subsequence principle for metric space convergence.
:::

:::

::: {.pf-step #p3-2}
Given a subsequence, extract a sub-subsequence $\{f_{n_k}\}$ converging pointwise a.e. to $f$.

::: pf-proof
convergence in measure.
:::

:::

::: {.pf-step #p3-3}
Let $u_k = |f_{n_k} - f|^p$.
Then $u_k \to 0$ pointwise a.e. on $[0, 1]$.

::: pf-proof
step [](#p3-2){.pf-ref} and continuity of $t \mapsto |t|^p$.
:::

:::

::: {.pf-step #p3-4}
The sequence $\{u_k\}$ is uniformly integrable on $[0, 1]$.

::: pf-proof

::: pf-step
Set $q = 2/p > 1$, so its Hölder conjugate is $q' = \frac{q}{q-1} = \frac{2}{2-p} > 1$.

::: pf-proof
$1 \le p < 2 \implies q > 1$.
:::

:::

::: {.pf-step #p3-4-2}
For any measurable $A \subseteq [0, 1]$, apply Hölder's inequality with exponent $q$:
\[
\int_A u_k\,dx = \int_A |f_{n_k} - f|^p \cdot 1\,dx \le \left(\int_A |f_{n_k} - f|^{pq}\,dx\right)^{1/q} \left(\int_A 1^{q'}\,dx\right)^{1/q'} = \|f_{n_k} - f\|_{L^2}^p \cdot (m(A))^{(2-p)/2}.
\]

::: pf-proof
Hölder's inequality with $pq = 2$ and $1/q' = (2-p)/2$.
:::

:::

::: {.pf-step #p3-4-3}
By Minkowski's inequality, $\|f_{n_k} - f\|_{L^2} \le \|f_{n_k}\|_{L^2} + \|f\|_{L^2} \le 1 + 1 = 2$.

::: pf-proof
triangle inequality in $L^2$ and (a).
:::

:::

::: {.pf-step #p3-4-4}
Thus $\int_A u_k\,dx \le 2^p (m(A))^{(2-p)/2}$.

::: pf-proof
step [](#p3-4-2){.pf-ref} and step [](#p3-4-3){.pf-ref}.
:::

:::

::: {.pf-step #p3-4-5}
Since $(2-p)/2 > 0$, for any $\varepsilon > 0$, choosing $\delta = (\varepsilon / 2^p)^{2/(2-p)} > 0$ ensures that $m(A) < \delta \implies \int_A u_k\,dx < \varepsilon$ for all $k$.

::: pf-proof
step [](#p3-4-4){.pf-ref}.
:::

:::

::: pf-step
Thus $\{u_k\}$ is uniformly integrable.

::: pf-proof
step [](#p3-4-5){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #p3-5}
By the Vitali Convergence Theorem, $\lim_{k\to\infty} \int_0^1 |f_{n_k} - f|^p\,dx = 0$, so $\|f_{n_k} - f\|_{L^p} \to 0$.

::: pf-proof
step [](#p3-3){.pf-ref}, step [](#p3-4){.pf-ref}, and Vitali Convergence Theorem.
:::

:::

::: {.pf-step #p3-6}
Therefore $\|f_n - f\|_{L^p} \to 0$ for all $1 \le p < 2$.

::: pf-proof
step [](#p3-1){.pf-ref} and step [](#p3-5){.pf-ref}.
:::

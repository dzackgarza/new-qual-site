::: {.problem}
Let $\{f_k\}$ be a sequence of increasing functions on $[0,1]$.
Suppose $$\sum_{k=1}^\infty f_k(x)$$ converges for all $x\in[0,1]$.
Denote the limit function by $f$, that is, $$f(x)=\sum_{k=1}^\infty f_k(x).$$ Prove that $$f'(x)=\sum_{k=1}^\infty f_k'(x),\qquad\text{a.e. }x\in[0,1].$$
:::

::: {.solution}
For $N\ge1$, set
\[
F_N=\sum_{k=1}^N f_k,
\qquad
R_N=f-F_N=\sum_{k=N+1}^\infty f_k.
\]

<1>1. The functions $f$, $F_N$, and $R_N$ are increasing.
::: {.proof}
Each $F_N$ is a finite sum of increasing functions, hence is increasing.
For $0\le x<y\le1$,
\[
f(y)-f(x)
=\lim_{M\to\infty}\sum_{k=1}^M\bigl(f_k(y)-f_k(x)\bigr)\ge0,
\]
so $f$ is increasing.
Likewise,
\[
R_N(y)-R_N(x)
=\lim_{M\to\infty}\sum_{k=N+1}^M\bigl(f_k(y)-f_k(x)\bigr)\ge0,
\]
so every $R_N$ is increasing.
:::

<1>2. The total variation of the tail $R_N$ tends to zero.
::: {.proof}
Since the original series converges at both endpoints,
\[
R_N(0)\longrightarrow0,
\qquad
R_N(1)\longrightarrow0.
\]
Because $R_N$ is increasing,
\[
0\le R_N(1)-R_N(0)\longrightarrow0.
\]
:::

<1>3. The derivative tails have vanishing $L^1$ mass.
::: {.proof}
Every increasing function on $[0,1]$ is differentiable almost everywhere, its derivative is nonnegative almost everywhere, and
\[
\int_0^1 u'(x)\,dx\le u(1)-u(0)
\]
for every increasing $u$.
Applying this to $R_N$ gives
\[
0\le\int_0^1 R_N'(x)\,dx
\le R_N(1)-R_N(0)\longrightarrow0.
\]
At every point where $f$ and all $f_k$ are differentiable, which is a full-measure set, we have
\[
R_N'(x)=f'(x)-F_N'(x)
=f'(x)-\sum_{k=1}^N f_k'(x).
\]
Thus
\[
0\le f'(x)-\sum_{k=1}^N f_k'(x)
\]
for almost every $x$, and
\[
\int_0^1\left(f'(x)-\sum_{k=1}^N f_k'(x)\right)dx\longrightarrow0.
\]
:::

<1>4. Pass to the infinite sum.
::: {.proof}
Since each $f_k'\ge0$ almost everywhere, the partial sums
\[
S_N(x)=\sum_{k=1}^N f_k'(x)
\]
increase pointwise almost everywhere to
\[
S(x)=\sum_{k=1}^\infty f_k'(x).
\]
By <1>3, $0\le S_N\le f'$ almost everywhere. Hence $0\le S\le f'$ almost everywhere, and by monotone convergence,
\[
\int_0^1(f'-S)
=\lim_{N\to\infty}\int_0^1(f'-S_N)=0.
\]
Therefore $f'=S$ almost everywhere; that is,
\[
f'(x)=\sum_{k=1}^\infty f_k'(x)
\qquad\text{for a.e. }x\in[0,1].
\]
:::
:::

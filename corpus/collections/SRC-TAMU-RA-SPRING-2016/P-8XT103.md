::: {.problem}
Let $\{g_n\}$ be a sequence of measurable functions on $[0,1]$ such that

(i) $\abs{g_n(x)}\le C$, for a.e. $x\in[0,1]$,

(ii) and $\lim_{n\to\infty}\int_0^a g_n(x)\,dx=0$ for every $a\in[0,1]$.

Prove that for each $f\in L^1([0,1])$, we have $$\lim_{n\to\infty}\int_0^1 f(x)g_n(x)\,dx=0.$$
:::

::: {.solution}
This is Problem 4 of the Texas A\&M real-analysis qualifying examination of 8 January 2016 (`assets/attachments/j16.pdf`). No published solution set is transcribed: the argument is the card's own, and it is the density argument the hypothesis (ii) for initial intervals invites.

::: pf

::: {.pf-step #dense}
The span $S$ of the indicators $\mathbf{1}_{[0,a]}$, $0\leq a\leq1$, contains every step function on $[0,1]$, hence is dense in $L^{1}([0,1])$.

::: pf-proof
For $0\leq a<b\leq1$ one has $\mathbf{1}_{(a,b]}=\mathbf{1}_{[0,b]}-\mathbf{1}_{[0,a]}$, and the indicator of any interval is equal almost everywhere to such a difference, the endpoints being a null set; so the interval indicators lie in $S$, and finite linear combinations of them, which are the step functions, lie in $S$. Step functions are dense in $L^{1}([0,1])$, so $S$ is dense.
:::
:::

::: {.pf-step #onS}
For every $h\in S$, $\int_{0}^{1}h\,g_{n}\to0$.

::: pf-proof
Write $h=\sum_{j=1}^{m}c_{j}\mathbf{1}_{[0,a_{j}]}$. Then $\int_{0}^{1}h\,g_{n}=\sum_{j}c_{j}\int_{0}^{a_{j}}g_{n}$, and each integral tends to $0$ by hypothesis (ii); a finite sum of null sequences is null.
:::
:::

::: {.pf-step #approx}
Let $f\in L^{1}([0,1])$ and $\varepsilon>0$. If $C>0$ there is $h\in S$ with $\norm{f-h}_{1}<\varepsilon/(2C)$; if $C=0$ then $g_{n}=0$ almost everywhere for every $n$ and the conclusion is immediate.

::: pf-proof
The approximation is step [](#dense){.pf-ref}. If $C=0$, hypothesis (i) gives $\abs{g_{n}}\leq0$ almost everywhere, so $g_{n}=0$ almost everywhere and every integral $\int_{0}^{1}fg_{n}$ vanishes.
:::
:::

::: {.pf-step #bound}
For every $n$, $\abs{\int_{0}^{1}(f-h)g_{n}}\leq C\norm{f-h}_{1}<\frac{\varepsilon}{2}$.

::: pf-proof
$\abs{\int_{0}^{1}(f-h)g_{n}}\leq\int_{0}^{1}\abs{f-h}\abs{g_{n}}\leq C\int_{0}^{1}\abs{f-h}=C\norm{f-h}_{1}$, using $\abs{g_{n}}\leq C$ almost everywhere and monotonicity of the integral.
:::
:::

::: {.pf-step #conclusion}
$\int_{0}^{1}f\,g_{n}\to0$ for every $f\in L^{1}([0,1])$.

::: pf-proof
With $h$ as in step [](#approx){.pf-ref}, step [](#onS){.pf-ref} gives $N$ with $\abs{\int_{0}^{1}h\,g_{n}}<\varepsilon/2$ for $n\geq N$. Then for such $n$,
$$\abs{\int_{0}^{1}f\,g_{n}}\leq\abs{\int_{0}^{1}(f-h)g_{n}}+\abs{\int_{0}^{1}h\,g_{n}}<\frac{\varepsilon}{2}+\frac{\varepsilon}{2}=\varepsilon$$
by step [](#bound){.pf-ref}. As $\varepsilon>0$ was arbitrary, the integrals tend to $0$.
:::

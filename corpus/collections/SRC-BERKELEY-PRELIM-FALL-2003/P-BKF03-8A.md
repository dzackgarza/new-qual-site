::: {.problem}
Let p be a prime, and let G be the group $\mathbb { Z } / p ^ { 2 } \mathbb { Z } \times \mathbb { Z } / p \mathbb { Z }$ . How many automorphisms does G have?
:::
\n\n::: {.solution}\nLet\n\[\ne_1=(1,0),\qquad e_2=(0,1),\n\]\nso $e_1$ has order $p^2$ and $e_2$ has order $p$.
An endomorphism is determined by\n\[\n\alpha(e_1)=(a,b),\qquad \alpha(e_2)=(c,d),\n\]\nwith $a,c\in\mathbb Z/p^2\mathbb Z$ and $b,d\in\mathbb Z/p\mathbb Z$.\n\n<1>1. Necessarily $c\in p\mathbb Z/p^2\mathbb Z$.\n::: {.proof}\nBecause $pe_2=0$, one must have\n\[\n0=\alpha(pe_2)=p(c,d)=(pc,0).\n\]\nThus $pc=0$ modulo $p^2$, which is equivalent to $c$ being divisible by $p$.\n:::\n\n<1>2. An automorphism must satisfy\n\[\na\notin p\mathbb Z/p^2\mathbb Z\n\qquad\text{and}\qquad d\ne0.\n\]\n::: {.proof}\nIf $a$ were divisible by $p$, then $p(a,b)=(pa,0)=0$, so $\alpha(e_1)$ would have order at most $p$, impossible because automorphisms preserve the order $p^2$ of $e_1$.
Hence $a$ is a unit modulo $p^2$.\n\nAlso, the subgroup $pG$ is generated by $(p,0)$.
Modulo $pG$, the two images become\n\[\n(a\bmod p,b),\qquad(0,d)\n\]\nin $G/pG\cong(\mathbb F_p)^2$.
Since $a\bmod p\ne0$, these two vectors span the quotient if and only if $d\ne0$.
An automorphism must induce an automorphism of this quotient, so $d\ne0$.\n:::\n\n<1>3. Conversely, if $a$ is a unit mod $p^2$, $c$ is divisible by $p$, and $d\ne0$, then the corresponding endomorphism is an automorphism.\n::: {.proof}\nThe element $(a,b)$ has order $p^2$ because its first coordinate is a unit modulo $p^2$.
Hence the subgroup it generates contains\n\[\np(a,b)=(pa,0),\n\]\nwhich generates $p\mathbb Z/p^2\mathbb Z\times\{0\}$.\n\nModulo that subgroup, the image of $(c,d)$ has second coordinate $d\ne0$, so it is not contained in $\langle(a,b)\rangle$.
Thus the subgroup generated by the two images has strictly more than $p^2$ elements.
Its order divides $|G|=p^3$, so it must have order $p^3$ and hence equals $G$.
Therefore the endomorphism is surjective, and since $G$ is finite it is an automorphism.\n:::\n\n<1>4. Count the allowable choices.\n::: {.proof}\nThere are\n\[\np^2-p=p(p-1)\n\]\nchoices for the unit $a$, $p$ choices for $b$, $p$ choices for $c\in p\mathbb Z/p^2\mathbb Z$, and $p-1$ choices for nonzero $d$.
Therefore\n\[\n|\operatorname{Aut}(G)|=(p^2-p)\,p\,p\,(p-1)\n=\boxed{p^3(p-1)^2}.\n\]\n:::\n:::\n

::: {.problem}
Let $A ( m , n )$ be the $m \times n$ matrix with entries

$$
a _ { i j } = j ^ { i } \quad ( 0 \leq i \leq m - 1 , 0 \leq j \leq n - 1 ) ,
$$

where $0 ^ { 0 } = 1$ by definition. Regarding the entries of $A ( m , n )$ as representing congruence classes (mod p), determine the rank of $A ( m , n )$ over the finite field $\mathbb { F } _ { p } ~ = ~ \mathbb { Z } / p \mathbb { Z }$ for all $m , n \geq 1$ and all primes p.
:::

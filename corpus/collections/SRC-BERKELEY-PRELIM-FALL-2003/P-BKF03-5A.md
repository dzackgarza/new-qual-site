::: {.problem}
Let C denote the space of continuous functions on [0, 1]. Define

$$
d ( f , g ) = \int _ { 0 } ^ { 1 } { \frac { | f ( x ) - g ( x ) | } { 1 + | f ( x ) - g ( x ) | } } d x .
$$

(a) Show that d is a metric on $C .$

(b) Show that $( C , d )$ is not a complete metric space.
:::

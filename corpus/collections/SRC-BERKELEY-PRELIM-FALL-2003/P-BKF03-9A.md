::: {.problem}
Let $f : [ 0 , 1 ]  [ 0 , 1 ]$ be an increasing (not strictly increasing) function such that

$$
f \left( \sum _ { j = 1 } ^ { \infty } a _ { j } 3 ^ { - j } \right) = \sum _ { j = 1 } ^ { \infty } \frac { a _ { j } } { 2 } 2 ^ { - j }
$$

whenever the $a _ { j }$ are 0 or 2. Prove that there is a constant $C _ { 0 }$ such that

$$
| f ( x ) - f ( y ) | \leq C _ { 0 } | x - y | ^ { ( \log 2 ) / ( \log 3 ) }
$$

for all $x , y \in [ 0 , 1 ]$
:::

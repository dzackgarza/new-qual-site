::: {.problem}
Let X be a CW complex with finitely many cells, and for each natural number n, let j_n be the number of n-cells of X (that is, j_n = |J_n|, where J_n is the index set for the n-cells).
The Euler characteristic for X is defined to be $\chi ( \mathrm { X } ) : = \Sigma _ { \mathrm { n } } \in \mathbf { N } ^ { ( - 1 ) ^ { \mathrm { { n } } } \mathrm { { j } } } \mathbf { \Sigma } _ { - } ^ { \mathrm { n } }$

(a) Compute the Euler characteristic of all of the compact connected surfaces.

(b) Find a CW structure for the cone CX of X, and determine the Euler characteristic of CX.
:::

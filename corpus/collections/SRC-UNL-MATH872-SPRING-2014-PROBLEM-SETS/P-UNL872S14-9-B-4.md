::: {.problem}
Let \(X\) be a finite CW complex, and let \(j_n\) be the number of
\(n\)-cells of \(X\). Define
\[
\chi(X)
=
\sum_{n\ge0}(-1)^n j_n.
\]

(a) Compute the Euler characteristic of every compact connected surface.

(b) Find a CW structure for the cone \(CX\), and determine \(\chi(CX)\).
:::

## Part (a)

::: pf

::: pf-step

A closed connected orientable surface of genus \(g\) has a CW
structure with
\[
\boxed{
1\text{ zero-cell},\quad
2g\text{ one-cells},\quad
1\text{ two-cell}}.
\]


::: pf-proof

Use the standard \(4g\)-gon presentation with boundary word
\[
[a_1,b_1]\cdots[a_g,b_g].
\]
All vertices are identified to one vertex, the \(2g\) edge pairs give
\(2g\) one-cells, and the polygon interior gives one two-cell.

:::

:::

::: pf-step

Therefore the orientable genus-\(g\) surface \(M_g\) has
\[
\boxed{
\chi(M_g)
=
1-2g+1
=
2-2g}.
\]


::: pf-proof

Apply the definition of Euler characteristic to the cell counts in step
<1>1.

:::

:::

::: pf-step

A closed connected nonorientable surface of genus \(k\) has a CW
structure with
\[
\boxed{
1\text{ zero-cell},\quad
k\text{ one-cells},\quad
1\text{ two-cell}}.
\]


::: pf-proof

Use the standard \(2k\)-gon presentation with boundary word
\[
a_1^2a_2^2\cdots a_k^2.
\]
All vertices become one vertex, the \(k\) edge pairs give \(k\) one-cells,
and the polygon interior gives one two-cell.

:::

:::

::: pf-step

Therefore the nonorientable genus-\(k\) surface \(N_k\) has
\[
\boxed{
\chi(N_k)
=
1-k+1
=
2-k}.
\]


::: pf-proof

Apply the Euler-characteristic definition to step <1>3.

:::

:::

::: pf-step

By the Classification of Surfaces theorem, these formulas exhaust all
compact connected surfaces:
\[
\boxed{
\chi(\Sigma)
=
\begin{cases}
2-2g,&\Sigma\cong M_g,\\
2-k,&\Sigma\cong N_k.
\end{cases}}
\]


::: pf-proof

Every compact connected closed surface is homeomorphic to exactly one
orientable surface \(M_g\) or one nonorientable surface \(N_k\).

:::

:::

::: pf-step

In particular,
\[
\boxed{
\chi(S^2)=2,\quad
\chi(T^2)=0,\quad
\chi(\mathbb{RP}^2)=1,\quad
\chi(K)=0}.
\]


::: pf-proof

Substitute
\[
g=0,\quad g=1,\quad k=1,\quad k=2
\]
into steps <1>2 and <1>4.

:::

:::

::: pf-step

Regard the base
\[
X=X\times\{1\}
\]
as a subcomplex of \(CX\), retaining every cell of \(X\).


::: pf-proof

The quotient map is injective on
\[
X\times\{1\},
\]
so the base is canonically a copy of \(X\).

:::

:::

::: pf-step

Add one new \(0\)-cell,
\[
\boxed{v},
\]
the cone point.


::: pf-proof

The entire subspace
\[
X\times\{0\}
\]
is collapsed to one point in the cone construction.

:::

:::

::: pf-step

For every open \(n\)-cell
\[
e_\alpha^n\subset X,
\]
the cone
\[
v*e_\alpha^n
\]
contributes one open \((n+1)\)-cell to \(CX\).


::: pf-proof

Let
\[
\Phi_\alpha:D^n\to X
\]
be a characteristic map for \(e_\alpha^n\). The cone on \(D^n\) is
homeomorphic to \(D^{n+1}\). Coning the characteristic map gives a
characteristic map
\[
D^{n+1}\cong CD^n\to CX
\]
whose open cone on \(\operatorname{int}D^n\) maps homeomorphically onto
\(v*e_\alpha^n\). Its boundary lands in the base \(X\) together with cones on
lower-dimensional cells, so these cells form a CW structure.

:::

:::

::: pf-step

If \(X\) has \(j_n\) \(n\)-cells, then \(CX\) has
\[
\boxed{
c_0=j_0+1}
\]
zero-cells and, for \(n\ge1\),
\[
\boxed{
c_n=j_n+j_{n-1}}
\]
\(n\)-cells.


::: pf-proof

In degree \(0\), retain the \(j_0\) base vertices and add the cone point.

For \(n\ge1\), the \(n\)-cells consist of:
the \(j_n\) original \(n\)-cells in the base, and
the \(j_{n-1}\) cone cells over the \((n-1)\)-cells of \(X\).

:::

:::

::: pf-step

Therefore
\[
\begin{aligned}
\chi(CX)
&=
(j_0+1)
+
\sum_{n\ge1}
(-1)^n
(j_n+j_{n-1}).
\end{aligned}
\]


::: pf-proof

Substitute the cell counts from step <1>10 into the definition of Euler
characteristic.

:::

:::

::: pf-step

The first part of the sum in step <1>11 is
\[
\boxed{
j_0+\sum_{n\ge1}(-1)^n j_n
=
\chi(X)}.
\]


::: pf-proof

This is exactly the definition of \(\chi(X)\).

:::

:::

::: pf-step

The cone-cell part satisfies
\[
\boxed{
1+
\sum_{n\ge1}
(-1)^n j_{n-1}
=
1-\chi(X)}.
\]


::: pf-proof

Reindex with \(m=n-1\):
\[
\sum_{n\ge1}
(-1)^n j_{n-1}
=
-\sum_{m\ge0}
(-1)^m j_m
=
-\chi(X).
\]
Then add the cone-point contribution \(1\).

:::

:::

::: pf-step

Hence
\[
\boxed{
\chi(CX)
=
\chi(X)+(1-\chi(X))
=
1}.
\]


::: pf-proof

Combine steps <1>11--<1>13.

:::

:::

::: pf-step

This agrees with the fact that \(CX\) is contractible.


::: pf-proof

The homotopy
\[
H([x,t],u)
=
[x,(1-u)t]
\]
contracts the cone to its apex. A finite contractible CW complex has Euler
characteristic \(1\).

:::

:::

::: pf-qed

Step <1>5 answers part (a), while steps <1>7--<1>14 construct the cone CW
structure and compute its Euler characteristic in part (b).

:::

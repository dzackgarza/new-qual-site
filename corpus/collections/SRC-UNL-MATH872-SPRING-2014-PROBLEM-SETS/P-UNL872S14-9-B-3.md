::: {.problem}
Show that every CW complex with finitely many cells is compact.
:::

Suppose the cells of \(X\) are
\[
e_1,\dots,e_N,
\]
with
\[
\dim e_i=n_i.
\]

::: pf

::: pf-step

For each cell \(e_i\), choose a characteristic map
\[
\Phi_i:D^{n_i}\to X
\]
whose restriction to the open disk is a homeomorphism onto \(e_i\).


::: pf-proof

This is part of the definition of a CW complex.

:::

:::

::: pf-step

The image
\[
\Phi_i(D^{n_i})
\]
contains the entire open cell \(e_i\).


::: pf-proof

By definition,
\[
\Phi_i(\operatorname{int}D^{n_i})=e_i.
\]
Hence certainly
\[
e_i\subseteq\Phi_i(D^{n_i}).
\]

:::

:::

::: pf-step

Let
\[
K=\bigsqcup_{i=1}^{N}D^{n_i}
\]
be the finite disjoint union of the closed characteristic disks.


::: pf-proof

This is a topological disjoint union of finitely many spaces.

:::

:::

::: pf-step

The space \(K\) is compact.


::: pf-proof

Each closed disk
\[
D^{n_i}
\]
is compact. A finite disjoint union of compact spaces is compact.

:::

:::

::: pf-step

Define
\[
\Phi:K\to X
\]
by
\[
\Phi|_{D^{n_i}}=\Phi_i.
\]


::: pf-proof

A map out of a disjoint union is continuous exactly when each restriction to
a summand is continuous. Every \(\Phi_i\) is continuous, so \(\Phi\) is
continuous.

:::

:::

::: pf-step

The map \(\Phi\) is surjective.


::: pf-proof

Every point \(x\in X\) lies in some open cell \(e_i\). By step <1>2,
\[
e_i\subseteq\Phi_i(D^{n_i}),
\]
so \(x\) lies in the image of \(\Phi\).

:::

:::

::: pf-step

Therefore
\[
\boxed{X=\Phi(K)}
\]
is compact.


::: pf-proof

The domain \(K\) is compact by step <1>4, the map \(\Phi\) is continuous by
step <1>5, and it is surjective by step <1>6. The continuous image of a
compact space is compact.

:::

:::

::: pf-qed

Step <1>7 is the required conclusion.

:::

:::

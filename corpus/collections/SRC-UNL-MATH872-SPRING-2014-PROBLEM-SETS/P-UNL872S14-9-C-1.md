::: {.problem}
Show that if the map $\mathrm { f } { : } \mathrm { S } ^ { \mathrm { n - 1 } } \mathrm { - } > \mathrm { X }$is used to attach an n-cell, with n > 2, to X to form a space Y, then the inclusion$\mathrm { X } \mathrm { - } \mathrm { > Y }$induces an isomorphism from$\pi _ { 1 } ( \mathrm { X } )$to$\pi _ { 1 } ( \mathrm { Y } )$ . Show that the same is true if we attach any (finite or infinite) collection of cells of dimension > 2.
:::

Fix a basepoint \(x_0\in X\).

## One attached cell

Suppose
\[
Y=X\cup_f D^n,
\qquad
f:S^{n-1}\to X,
\qquad
n>2.
\]

::: pf

::: pf-step

Choose open sets \(U,V\subseteq Y\) such that
\[
X\subseteq U,
\qquad
U\simeq X,
\]
\[
V\simeq D^n,
\]
and
\[
U\cap V\simeq S^{n-1}.
\]


::: pf-proof

Take \(V\) to be the image of the open \(n\)-cell together with a thin collar
of its boundary. Take \(U\) to be \(X\) together with the complementary thin
collar inside the attached disk.

Radially push the collar in \(U\) back to the attaching sphere and then into
\(X\); this gives \(U\simeq X\). The set \(V\) deformation retracts onto the
disk, and the collar intersection deformation retracts onto the attaching
sphere.

:::

:::

::: pf-step

One has
\[
\boxed{\pi_1(V)=0}.
\]


::: pf-proof

The set \(V\) is homotopy equivalent to the contractible disk \(D^n\).

:::

:::

::: pf-step

One has
\[
\boxed{\pi_1(U\cap V)=0}.
\]


::: pf-proof

By step <1>1,
\[
U\cap V\simeq S^{n-1}.
\]
Since
\[
n>2,
\]
one has
\[
n-1\ge2,
\]
and \(S^{n-1}\) is simply connected.

:::

:::

::: pf-step

Seifert--van Kampen gives
\[
\boxed{
\pi_1(Y,x_0)
\cong
\pi_1(U,x_0)}.
\]


::: pf-proof

Van Kampen identifies
\[
\pi_1(Y)
\]
as the pushout of
\[
\pi_1(U)
\leftarrow
\pi_1(U\cap V)
\rightarrow
\pi_1(V).
\]
By steps <1>2 and <1>3, the latter two groups are trivial. Thus the pushout is
just \(\pi_1(U)\).

:::

:::

::: pf-step

Since \(U\simeq X\),
\[
\boxed{
\pi_1(U,x_0)
\cong
\pi_1(X,x_0)}.
\]


::: pf-proof

Homotopy equivalent based path-connected spaces have isomorphic fundamental
groups.

:::

:::

::: pf-step

Under the isomorphisms in steps <1>4--<1>5, the map
\[
\pi_1(X,x_0)\to\pi_1(Y,x_0)
\]
is exactly the homomorphism induced by the inclusion
\[
X\hookrightarrow Y.
\]


::: pf-proof

The deformation retraction \(U\simeq X\) fixes \(X\), so the identification
\[
\pi_1(U)\cong\pi_1(X)
\]
is induced by the inclusion \(X\hookrightarrow U\). The van Kampen map
\[
\pi_1(U)\to\pi_1(Y)
\]
is induced by \(U\hookrightarrow Y\). Their composite is induced by
\[
X\hookrightarrow Y.
\]

:::

:::

::: pf-step

Therefore
\[
\boxed{
\pi_1(X,x_0)
\xrightarrow{\ \cong\ }
\pi_1(Y,x_0)}.
\]


::: pf-proof

Combine steps <1>4--<1>6.

:::

:::

::: pf-step

Attaching finitely many cells of dimensions \(>2\) preserves the
fundamental group.


::: pf-proof

Attach the cells one at a time. Each step is covered by step <1>7. A finite
composition of isomorphisms is an isomorphism.

:::

:::

::: pf-step

Every loop
\[
\gamma:S^1\to Y
\]
has image contained in
\[
X\cup
\bigcup_{\alpha\in F}e_\alpha^{n_\alpha}
\]
for some finite set \(F\subseteq A\).


::: pf-proof

The image \(\gamma(S^1)\) is compact. In a relative CW complex, every compact
subset meets only finitely many open cells. Therefore it meets only finitely
many of the attached cells.

:::

:::

::: pf-step

The inclusion
\[
i:X\hookrightarrow Y
\]
induces a surjection on \(\pi_1\).


::: pf-proof

Let \([\gamma]\in\pi_1(Y,x_0)\). By step <1>9, \(\gamma\) lies in a finite
subcomplex
\[
Y_F
=
X\cup
\bigcup_{\alpha\in F}e_\alpha^{n_\alpha}.
\]
By step <1>8,
\[
\pi_1(X,x_0)\to\pi_1(Y_F,x_0)
\]
is an isomorphism. Thus \(\gamma\) is homotopic in \(Y_F\subseteq Y\) to a
loop in \(X\). Hence every element of \(\pi_1(Y)\) is in the image of
\(i_*\).

:::

:::

::: pf-step

Suppose a loop
\[
\gamma:S^1\to X
\]
is nullhomotopic in \(Y\). Then it is already nullhomotopic in a finite
subcomplex
\[
Y_F
=
X\cup
\bigcup_{\alpha\in F}e_\alpha^{n_\alpha}.
\]


::: pf-proof

Choose a nullhomotopy
\[
H:D^2\to Y.
\]
The image \(H(D^2)\) is compact, so by the same compactness property used in
step <1>9, it meets only finitely many attached open cells. Thus the whole
homotopy lands in some \(Y_F\).

:::

:::

::: pf-step

The inclusion-induced map
\[
i_*:\pi_1(X,x_0)\to\pi_1(Y,x_0)
\]
is injective.


::: pf-proof

Suppose
\[
i_*([\gamma])=1.
\]
Then \(\gamma\) is nullhomotopic in \(Y\). By step <1>11, it is
nullhomotopic in some finite \(Y_F\). Step <1>8 says
\[
\pi_1(X)\to\pi_1(Y_F)
\]
is an isomorphism, so \([\gamma]=1\) already in \(\pi_1(X)\).

:::

:::

::: pf-step

Hence, after attaching any finite or infinite family of cells of
dimension \(>2\),
\[
\boxed{
\pi_1(X,x_0)
\xrightarrow{\ \cong\ }
\pi_1(Y,x_0)}.
\]


::: pf-proof

Surjectivity is step <1>10 and injectivity is step <1>12.

:::

:::

::: pf-qed

Step <1>7 proves the one-cell case, step <1>8 the finite case, and step
<1>13 the arbitrary case.

:::

:::

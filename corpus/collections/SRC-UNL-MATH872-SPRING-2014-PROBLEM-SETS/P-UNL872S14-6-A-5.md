::: {.problem}
Show that every homomorphism
\[
\varphi:\mathbb Z\to\pi_1(X,x_0)
\]
can be realized as the induced homomorphism
\[
\varphi=h_*
\]
of a continuous based map
\[
h:(S^1,(1,0))\to(X,x_0).
\]

(Hint: the quotient-map lemma from 6.A.1 can be useful here.)
:::

::: pf

::: pf-step

The homomorphism \(\varphi\) is determined by the single element \(\varphi(1)\in\pi_1(X,x_0)\).


::: pf-proof

The group \(\mathbb Z\) is generated by \(1\). Thus for every \(n\in\mathbb Z\),
\[
\varphi(n)=\varphi(1)^n
\]
in multiplicative notation for the fundamental group.

:::

:::

::: pf-step

Choose a based loop
\[
\gamma:(I,\partial I)\to(X,x_0)
\]
such that
\[
\boxed{[\gamma]=\varphi(1)}.
\]


::: pf-proof

Every element of \(\pi_1(X,x_0)\) is represented by a based loop at \(x_0\).

:::

:::

::: pf-step

Define
\[
q:I\to S^1,
\qquad
q(t)=(\cos2\pi t,\sin2\pi t).
\]
Then \(q\) is a quotient map.


::: pf-proof

The map \(q\) is a continuous surjection from the compact interval \(I\) to the Hausdorff space \(S^1\). By the quotient-map lemma from 6.A.1, \(q\) is a quotient map.

:::

:::

::: pf-step

The loop \(\gamma\) is constant on every fiber of \(q\).


::: pf-proof

The only fiber with more than one point is
\[
q^{-1}((1,0))=\{0,1\}.
\]
Since \(\gamma\) is a based loop,
\[
\gamma(0)=\gamma(1)=x_0.
\]
All other fibers are singletons.

:::

:::

::: pf-step

Therefore there is a unique continuous map
\[
\boxed{h:S^1\to X}
\]
such that
\[
\boxed{h\circ q=\gamma}.
\]


::: pf-proof

By steps <1>3 and <1>4, \(q\) is quotient and \(\gamma\) is constant on its fibers. The universal property of quotient maps gives the factorization.

:::

:::

::: pf-step

The map \(h\) is based:
\[
\boxed{h(1,0)=x_0}.
\]


::: pf-proof

Since \(q(0)=(1,0)\),
\[
h(1,0)=h(q(0))=\gamma(0)=x_0.
\]

:::

:::

::: pf-step

Let \(\omega:I\to S^1\) be the standard positive generator
\[
\omega(t)=(\cos2\pi t,\sin2\pi t).
\]
Then
\[
\boxed{h\circ\omega=\gamma}.
\]


::: pf-proof

The path \(\omega\) is exactly the quotient map \(q\) from step <1>3. Apply step <1>5.

:::

:::

::: pf-step

Under the standard identification
\[
\pi_1(S^1,(1,0))\cong\mathbb Z,
\]
one has
\[
\boxed{h_*(1)=\varphi(1)}.
\]


::: pf-proof

The integer \(1\) corresponds to \([\omega]\). Therefore
\[
h_*(1)=h_*([\omega])=[h\circ\omega]=[\gamma]=\varphi(1)
\]
by steps <1>2 and <1>7.

:::

:::

::: pf-step

Hence
\[
\boxed{h_*=\varphi:\mathbb Z\to\pi_1(X,x_0)}.
\]


::: pf-proof

Both \(h_*\) and \(\varphi\) are group homomorphisms from \(\mathbb Z\). By step <1>8 they agree on the generator \(1\), so they agree everywhere.

:::

:::

::: pf-qed

Step <1>9 proves the claim.

:::

:::

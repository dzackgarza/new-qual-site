::: {.problem}
In each part of this problem, a group G is given by a presentation, together with a familiar group H. Prove that the groups G and H are isomorphic.

(a) $\mathrm { G } = < \mathrm { a } | \mathrm { a } ^ { 3 } > ;$ H is the cyclic group of order 3.

(b) $\mathrm { G = < a , b , c \mid a ^ { 2 } , b ^ { 2 } , c ^ { 2 } , ( a b ) ^ { 3 } , ( a c ) ^ { 2 } , ( b c ) ^ { 3 } > } ;$ H is the symmetric group permuting 4 objects.
:::

::: {.solution}
## Part (a)

Let
\[
G_3=\langle a\mid a^3=1\rangle.
\]

<1>1. There is a surjective homomorphism
\[
\phi:G_3\to\mathbb Z/3
\]
sending
\[
a\longmapsto \overline1.
\]

::: {.proof}
The element \(\overline1\in\mathbb Z/3\) satisfies
\[
3\overline1=0,
\]
so the relation \(a^3=1\) is respected. The image contains the generator
\(\overline1\), hence the map is surjective.
:::

<1>2. Every element of \(G_3\) is represented by one of
\[
\boxed{1,\ a,\ a^2}.
\]

::: {.proof}
Every word in the single generator reduces to \(a^n\). The relation
\[
a^3=1
\]
reduces the exponent modulo \(3\).
:::

<1>3. Therefore
\[
|G_3|\le3.
\]

::: {.proof}
Step <1>2 gives at most three distinct normal forms.
:::

<1>4. Hence
\[
\boxed{G_3\cong\mathbb Z/3}.
\]

::: {.proof}
Step <1>1 gives a surjection from \(G_3\) onto a group of three elements,
while step <1>3 says \(G_3\) has at most three elements. Therefore \(G_3\)
has exactly three elements and the surjection is an isomorphism.
:::

## Part (b)

Let
\[
G
=
\left\langle
a,b,c
\ \middle|\
a^2=b^2=c^2=(ab)^3=(ac)^2=(bc)^3=1
\right\rangle.
\]

<1>5. The assignments
\[
\boxed{
a\longmapsto(12),\qquad
b\longmapsto(23),\qquad
c\longmapsto(34)}
\]
define a homomorphism
\[
\Phi:G\to S_4.
\]

::: {.proof}
Each transposition has order \(2\). Also
\[
(12)(23)=(123)
\]
has order \(3\),
\[
(12)(34)
\]
has order \(2\), and
\[
(23)(34)=(234)
\]
has order \(3\). Thus all defining relators of \(G\) map to the identity, so
the presentation universal property gives \(\Phi\).
:::

<1>6. The homomorphism \(\Phi\) is surjective.

::: {.proof}
The adjacent transpositions
\[
(12),\quad(23),\quad(34)
\]
generate the full symmetric group \(S_4\).
:::

<1>7. Let
\[
H=\langle a,b\rangle\le G.
\]
Within \(H\), one has the braid relation
\[
\boxed{aba=bab}.
\]

::: {.proof}
From
\[
(ab)^3=1
\]
and \(a^2=b^2=1\),
\[
(ab)^3=1
\iff
abab=(ab)^{-1}=ba.
\]
Multiplying on the left by \(a\) and on the right by \(a\) gives
\[
bab=aba.
\]
:::

<1>8. Every element of \(H\) is represented by one of
\[
\boxed{
1,\ a,\ b,\ ab,\ ba,\ aba}.
\]

::: {.proof}
First cancel every occurrence of \(aa\) or \(bb\) using
\[
a^2=b^2=1.
\]
A reduced word therefore alternates \(a,b\).

If its length is at least \(4\), it begins with either
\[
abab
\qquad\text{or}\qquad
baba.
\]
From
\[
(ab)^3=1
\]
one gets
\[
abab=ba.
\]
Similarly, since
\[
(ba)^3=((ab)^{-1})^3=1,
\]
one gets
\[
baba=ab.
\]
Thus every alternating word of length at least \(4\) shortens by two.
Repeating leaves length at most \(3\). The only reduced words of length at
most \(3\) are
\[
1,\ a,\ b,\ ab,\ ba,\ aba,\ bab,
\]
and step <1>7 identifies the last two.
:::

<1>9. Consequently,
\[
\boxed{|H|\le6}.
\]

::: {.proof}
Step <1>8 gives at most six representatives.
:::

<1>10. The relations involving \(c\) imply
\[
\boxed{ac=ca}
\]
and
\[
\boxed{cbc=bcb}.
\]

::: {.proof}
Since \(a^2=c^2=1\),
\[
(ac)^2=1
\]
means
\[
acac=1.
\]
Multiplying by \(a\) on the left and \(c\) on the right gives
\[
ca=ac.
\]

Likewise \(b^2=c^2=1\) and
\[
(bc)^3=1
\]
give the standard braid relation
\[
bcb=cbc
\]
by the same argument as in step <1>7.
:::

<1>11. Consider the four right cosets
\[
\boxed{
H,\qquad
Hc,\qquad
Hcb,\qquad
Hcba}.
\]

::: {.proof}
These are well-defined right cosets of the subgroup \(H\).
:::

<1>12. Right multiplication by \(a,b,c\) sends the coset \(H\) into the
four-element set in step <1>11.

::: {.proof}
Since \(a,b\in H\),
\[
Ha=Hb=H.
\]
Also
\[
Hc=Hc.
\]
:::

<1>13. For the coset \(Hc\),
\[
\boxed{
Hca=Hc,\qquad
Hcb=Hcb,\qquad
Hcc=H}.
\]

::: {.proof}
Using \(ca=ac\) from step <1>10,
\[
Hca=Hac=Hc.
\]
The second equality is the definition of the next listed coset. Since
\(c^2=1\),
\[
Hcc=H.
\]
:::

<1>14. For the coset \(Hcb\),
\[
\boxed{
Hcba=Hcba,\qquad
Hcbb=Hc,\qquad
Hcbc=Hcb}.
\]

::: {.proof}
The first equality is the definition of the fourth listed coset. Since
\(b^2=1\),
\[
Hcbb=Hc.
\]
For the last equality, step <1>10 gives
\[
cbc=bcb.
\]
Hence
\[
Hcbc
=
Hbcb
=
Hcb,
\]
because \(b\in H\).
:::

<1>15. For the coset \(Hcba\),
\[
\boxed{
Hcbaa=Hcb,\qquad
Hcbab=Hcba,\qquad
Hcbac=Hcba}.
\]

::: {.proof}
Since \(a^2=1\),
\[
Hcbaa=Hcb.
\]

For multiplication by \(b\), use the braid relation
\[
bab=aba
\]
from step <1>7:
\[
Hcbab
=
Hcaba.
\]
Since \(ca=ac\),
\[
Hcaba
=
Hacba
=
Hcba.
\]

For multiplication by \(c\),
\[
Hcbac
=
Hcbca
\]
using \(ac=ca\). Then
\[
cb c=bcb
\]
gives
\[
Hcbca
=
Hb cba
=
Hcba,
\]
because \(b\in H\).
:::

<1>16. Every element of \(G\) lies in one of the four cosets in step
<1>11.

::: {.proof}
The identity element lies in \(H\). Any word in \(a,b,c\) is obtained from
the identity by successive right multiplication by generators. Steps
<1>12--<1>15 show inductively that after each multiplication the current
element remains in one of the four listed right cosets.
:::

<1>17. Therefore
\[
\boxed{[G:H]\le4}.
\]

::: {.proof}
Step <1>16 shows that at most four right cosets cover \(G\).
:::

<1>18. Combining steps <1>9 and <1>17,
\[
\boxed{|G|\le24}.
\]

::: {.proof}
The group is the union of at most four right cosets of \(H\), each having
\(|H|\le6\) elements. Thus
\[
|G|
\le
4\cdot6
=
24.
\]
:::

<1>19. Since
\[
|S_4|=24
\]
and \(\Phi:G\twoheadrightarrow S_4\), one has
\[
\boxed{G\cong S_4}.
\]

::: {.proof}
A surjection onto \(S_4\) forces
\[
|G|\ge24.
\]
Step <1>18 gives the reverse inequality. Hence \(|G|=24\), so the surjective
homomorphism \(\Phi\) has trivial kernel and is an isomorphism.
:::

<1>20. Q.E.D.

::: {.proof}
Step <1>4 proves part (a), and step <1>19 proves part (b).
:::

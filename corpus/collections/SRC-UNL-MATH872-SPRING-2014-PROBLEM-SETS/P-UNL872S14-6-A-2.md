::: {.problem}
For each integer \(n\), let \(\omega_n:I\to S^1\) be the loop
\[
\omega_n(s)=\bigl(\cos(2\pi ns),\sin(2\pi ns)\bigr).
\]

Define
\[
C(t)=(1-t)\frac12+t\frac{m}{m+n}
\]
and, whenever the displayed expressions are defined, set
\[
H(s,t)=\begin{cases}
\bigl(\cos(2\pi m\,s/C(t)),\sin(2\pi m\,s/C(t))\bigr),&0\le s\le C(t),\\[4pt]
\bigl(\cos(2\pi n\,(s-C(t))/(1-C(t))),\sin(2\pi n\,(s-C(t))/(1-C(t)))\bigr),&C(t)\le s\le1.
\end{cases}
\]

(a) Prove that, when this formula defines a homotopy, \(H\) is a path homotopy from \(\omega_m*\omega_n\) to \(\omega_{m+n}\).

(b) For some integers \(m,n\), the formula in part (a) does not define such a homotopy. Determine exactly which values fail, and construct a path homotopy \(\omega_m*\omega_n\simeq\omega_{m+n}\) for those cases.
:::

::: {.solution}
<1>1. At \(t=0\), one has
\[
C(0)=\frac12,
\]
and
\[
\boxed{H(s,0)=(\omega_m*\omega_n)(s)}.
\]

::: {.proof}
When \(0\le s\le1/2\),
\[
H(s,0)
=
\bigl(
\cos(2\pi m(2s)),
\sin(2\pi m(2s))
\bigr)
=
\omega_m(2s).
\]
When \(1/2\le s\le1\),
\[
H(s,0)
=
\bigl(
\cos(2\pi n(2s-1)),
\sin(2\pi n(2s-1))
\bigr)
=
\omega_n(2s-1).
\]
This is exactly the standard concatenation.
:::

<1>2. Suppose
\[
mn>0.
\]
Then
\[
\boxed{
0<
\frac{m}{m+n}
<1}.
\]

::: {.proof}
If \(m,n>0\), then
\[
0<m<m+n.
\]
If \(m,n<0\), then dividing the inequalities
\[
m+n<m<0
\]
by the negative number \(m+n\) reverses their direction and again gives
\[
0<\frac{m}{m+n}<1.
\]
:::

<1>3. Under the hypothesis \(mn>0\),
\[
\boxed{0<C(t)<1\qquad(0\le t\le1)}.
\]

::: {.proof}
The number \(C(t)\) is the convex combination
\[
C(t)
=(1-t)\frac12
+t\frac{m}{m+n}.
\]
Both endpoints lie strictly in \((0,1)\) by step <1>2, so every convex
combination does as well.
:::

<1>4. If \(mn>0\), the two formulas defining \(H\) agree at
\[
s=C(t).
\]

::: {.proof}
For the first formula,
\[
H(C(t),t)
=
\bigl(
\cos(2\pi m),
\sin(2\pi m)
\bigr)
=(1,0).
\]
For the second,
\[
H(C(t),t)
=
\bigl(
\cos0,
\sin0
\bigr)
=(1,0).
\]
Thus the two branches agree along their common boundary.
:::

<1>5. If \(mn>0\), the map
\[
H:I\times I\to S^1
\]
is continuous.

::: {.proof}
By step <1>3, neither denominator
\[
C(t)
\qquad\text{nor}\qquad
1-C(t)
\]
vanishes. Hence each branch is continuous on its closed region
\[
\{(s,t):0\le s\le C(t)\}
\]
or
\[
\{(s,t):C(t)\le s\le1\}.
\]
These two closed regions cover \(I\times I\), and step <1>4 shows that the
two branch formulas agree on their intersection. The pasting lemma therefore
gives continuity of \(H\).
:::

<1>6. If \(mn>0\), then for every \(t\),
\[
\boxed{
H(0,t)=H(1,t)=(1,0)}.
\]

::: {.proof}
At \(s=0\), the first formula has phase \(0\). At \(s=1\), the second formula
has phase \(2\pi n\). Since \(n\in\mathbb Z\), both values are \((1,0)\).
Thus the homotopy fixes the endpoints of the loops.
:::

<1>7. If \(mn>0\), then
\[
\boxed{H(s,1)=\omega_{m+n}(s)}.
\]

::: {.proof}
At \(t=1\),
\[
C(1)=\frac{m}{m+n}.
\]
For
\[
0\le s\le C(1),
\]
the phase in the first branch is
\[
2\pi m\frac{s}{m/(m+n)}
=
2\pi(m+n)s.
\]
Thus the first branch equals \(\omega_{m+n}(s)\).

For
\[
C(1)\le s\le1,
\]
one has
\[
1-C(1)
=
\frac{n}{m+n}.
\]
Hence the phase in the second branch is
\[
\begin{aligned}
2\pi n
\frac{s-m/(m+n)}{n/(m+n)}
&=
2\pi\bigl((m+n)s-m\bigr).
\end{aligned}
\]
Since \(m\in\mathbb Z\), subtracting \(2\pi m\) does not change the point of
\(S^1\). Thus this branch also equals
\[
\omega_{m+n}(s).
\]
:::

<1>8. Therefore, when
\[
\boxed{mn>0},
\]
the displayed \(H\) is a path homotopy
\[
\boxed{
\omega_m*\omega_n
\simeq
\omega_{m+n}}.
\]

::: {.proof}
Step <1>5 gives continuity, step <1>6 gives a homotopy relative to the
endpoints, step <1>1 identifies the initial path, and step <1>7 identifies
the final path.
:::

<1>9. If
\[
m+n=0,
\]
the formula for \(C(t)\) is undefined.

::: {.proof}
The term
\[
\frac{m}{m+n}
\]
has zero denominator. This includes the case \(m=n=0\).
:::

<1>10. Suppose
\[
mn<0
\qquad\text{and}\qquad
m+n\ne0.
\]
Then
\[
\frac{m}{m+n}\notin[0,1].
\]

::: {.proof}
If \(m>0>n\), then either \(m+n>0\), in which case
\[
\frac{m}{m+n}>1,
\]
or \(m+n<0\), in which case the quotient is negative. The case
\[
m<0<n
\]
is symmetric.
:::

<1>11. Under the hypotheses of step <1>10, there is
\[
t_0\in(0,1)
\]
such that
\[
C(t_0)\in\{0,1\}.
\]

::: {.proof}
The function \(C(t)\) is continuous,
\[
C(0)=\frac12,
\]
and by step <1>10 its endpoint \(C(1)\) lies outside \([0,1]\). The
intermediate value theorem therefore forces \(C\) to cross either \(0\) or
\(1\) at some \(t_0\in(0,1)\).
:::

<1>12. If \(m=0\) and \(n\ne0\), then
\[
C(1)=0;
\]
if \(n=0\) and \(m\ne0\), then
\[
C(1)=1.
\]

::: {.proof}
Substitute into
\[
C(1)=\frac{m}{m+n}.
\]
:::

<1>13. Consequently, the literal formula for \(H\) defines a homotopy
exactly when
\[
\boxed{mn>0}.
\]
It fails for exactly the pairs
\[
\boxed{mn\le0}.
\]

::: {.proof}
For \(mn>0\), step <1>8 proves that the formula works.

If \(m+n=0\), step <1>9 shows that \(C\) is undefined.

If \(mn<0\) and \(m+n\ne0\), step <1>11 produces a time at which one
denominator \(C(t)\) or \(1-C(t)\) vanishes; after that the moving breakpoint
also leaves the interval \([0,1]\).

If exactly one of \(m,n\) is zero, step <1>12 shows that at \(t=1\) one
branch has a zero denominator. Thus the displayed formula is not defined on
all of \(I\times I\).
:::

<1>14. Define a lift
\[
a:I\to\mathbb R
\]
of the concatenated loop by
\[
a(s)
=
\begin{cases}
2ms,&0\le s\le\frac12,\\[4pt]
m+2n\left(s-\frac12\right),&\frac12\le s\le1.
\end{cases}
\]
Then
\[
\boxed{
e^{2\pi ia(s)}
=(\omega_m*\omega_n)(s)}.
\]

::: {.proof}
On the first half,
\[
e^{2\pi i a(s)}
=
e^{2\pi i m(2s)}
=
\omega_m(2s).
\]
On the second half,
\[
\begin{aligned}
e^{2\pi ia(s)}
&=
e^{2\pi i m}
e^{2\pi i n(2s-1)}\\
&=
\omega_n(2s-1),
\end{aligned}
\]
since \(e^{2\pi im}=1\).
:::

<1>15. Define
\[
b(s)=(m+n)s.
\]
Then
\[
\boxed{
e^{2\pi ib(s)}
=
\omega_{m+n}(s)}.
\]

::: {.proof}
This is the definition of \(\omega_{m+n}\).
:::

<1>16. The two lifted paths have the same endpoints:
\[
\boxed{
a(0)=b(0)=0,
\qquad
a(1)=b(1)=m+n}.
\]

::: {.proof}
The formulas in steps <1>14 and <1>15 give these values directly.
:::

<1>17. Define
\[
A(s,t)
=(1-t)a(s)+tb(s)
\]
and
\[
\boxed{
K(s,t)
=
\bigl(
\cos(2\pi A(s,t)),
\sin(2\pi A(s,t))
\bigr)}.
\]
Then \(K\) is a path homotopy
\[
\omega_m*\omega_n
\simeq
\omega_{m+n}
\]
for every pair of integers \(m,n\).

::: {.proof}
The function \(A\) is continuous because \(a\) and \(b\) are continuous,
and hence \(K\) is continuous. By steps <1>14 and <1>15,
\[
K(s,0)
=(\omega_m*\omega_n)(s)
\]
and
\[
K(s,1)
=
\omega_{m+n}(s).
\]
By step <1>16,
\[
A(0,t)=0
\]
and
\[
A(1,t)=m+n
\]
for every \(t\). Since \(m+n\in\mathbb Z\),
\[
K(0,t)=K(1,t)=(1,0).
\]
Thus \(K\) is a path homotopy relative to endpoints.
:::

<1>18. In particular, for every exceptional pair
\[
\boxed{mn\le0},
\]
the homotopy \(K\) in step <1>17 supplies the required replacement for the
invalid formula in part (a).

::: {.proof}
Step <1>13 identifies exactly the exceptional pairs, while step <1>17 works
for all integers \(m,n\).
:::

<1>19. Q.E.D.

::: {.proof}
Step <1>8 proves part (a) in precisely the range where the displayed formula
is valid. Steps <1>13 and <1>18 answer part (b).
:::
:::

::: {.problem}
Hatcher p. 38 #8.

Does the Borsuk--Ulam theorem hold for the torus? In other words, for every
continuous map
\[
f:S^1\times S^1\to\mathbb R^2,
\]
must there exist
\[
(x,y)\in S^1\times S^1
\]
such that
\[
f(x,y)=f(-x,-y)?
\]
:::

::: {.solution}
<1>1. Define
\[
f:S^1\times S^1\to\mathbb R^2
\]
by
\[
\boxed{f(x,y)=x},
\]
where (S^1subsetmathbb R^2) is the unit circle.

::: {.proof}
This is the composition of the projection
\[
S^1\times S^1\to S^1,
\qquad
(x,y)\mapsto x,
\]
with the inclusion
\[
S^1\hookrightarrow\mathbb R^2.
\]
Hence (f) is continuous.
:::

<1>2. For every ((x,y)in S^1\times S^1),
\[
\boxed{f(-x,-y)=-x=-f(x,y)}.
\]

::: {.proof}
By the definition in step <1>1,
\[
f(-x,-y)=-x,
\]
while
\[
f(x,y)=x.
\]
:::

<1>3. For every (xin S^1),
\[
\boxed{x\ne -x}.
\]

::: {.proof}
If (x=-x), then
\[
2x=0,
\]
so (x=0), contradicting
\[
\|x\|=1.
\]
:::

<1>4. Therefore for every ((x,y)in S^1\times S^1),
\[
\boxed{f(x,y)\ne f(-x,-y)}.
\]

::: {.proof}
Combine steps <1>2 and <1>3.
:::

<1>5. Hence the Borsuk--Ulam conclusion does not hold for the torus:
\[
\boxed{\text{the answer is no}}.
\]

::: {.proof}
Step <1>1 gives an explicit continuous map for which step <1>4 shows that
no antipodal pair has the same image.
:::

<1>6. Q.E.D.

::: {.proof}
Step <1>5 answers the exercise.
:::
:::

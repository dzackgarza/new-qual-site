::: {.problem}
Hatcher p. 132 #11.

Show that if \(A\) is a retract of \(X\), then the map
\[
i_*:H_n(A)\to H_n(X)
\]
induced by the inclusion
\[
i:A\hookrightarrow X
\]
is injective for every \(n\).
:::

::: {.solution}
<1>1. Since \(A\) is a retract of \(X\), there is a continuous map
\[
r:X\to A
\]
such that
\[
\boxed{r\circ i=\operatorname{id}_A}.
\]

::: {.proof}
This is the definition of a retraction.
:::

<1>2. Applying homology gives
\[
\boxed{
r_*\circ i_*
=
(\operatorname{id}_A)_*
=
\operatorname{id}_{H_n(A)}}.
\]

::: {.proof}
Singular homology is functorial, so
\[
(r\circ i)_*
=
r_*\circ i_*.
\]
The identity map induces the identity homomorphism on homology.
:::

<1>3. Therefore \(i_*\) has a left inverse.

::: {.proof}
Step <1>2 says exactly that
\[
r_*i_*=\operatorname{id}.
\]
Thus \(r_*\) is a left inverse for \(i_*\).
:::

<1>4. Any homomorphism with a left inverse is injective.

::: {.proof}
Suppose
\[
i_*(\alpha)=i_*(\beta).
\]
Apply \(r_*\):
\[
\alpha
=
r_*i_*(\alpha)
=
r_*i_*(\beta)
=
\beta.
\]
Hence \(i_*\) is injective.
:::

<1>5. Consequently,
\[
\boxed{
i_*:H_n(A)\hookrightarrow H_n(X)}
\]
is injective for every \(n\).

::: {.proof}
Combine steps <1>3 and <1>4.
:::

<1>6. Q.E.D.

::: {.proof}
Step <1>5 is the required conclusion.
:::
:::

::: {.problem}
Find an example of a topological space X that is a union of three open path-connected subspaces $\mathrm { A _ { i } } \left( \mathrm { f o r } \mathrm { i } { = } 1 , 2 , 3 \right)$such that each pairwise intersection$\mathbf { A } _ { \mathrm { i } } \cap \mathbf { A } _ { \mathrm { j } }$is path-connected, but$\pi _ { 1 } ( \mathrm { X } )$is not isomorphic to the group${ ^ { * } \mathrm { { _ { i = 1 } } } ^ { 3 } \pi _ { 1 } ( \mathrm { { A } _ { i } ) / N } }$, where N is the normal subgroup generated by all elements of the form$\mathrm { i _ { A _ { j } A _ { j } } \mathrm { * ( [ w ] ) } \ i _ { A _ { j } A _ { i } \mathrm { * } } ( [ w ] ) ^ { - 1 } }$with$[ \mathbf { w } ] \in \pi _ { 1 } ( \mathrm { A _ { i } } \cap \mathrm { A _ { j } } )$
:::

::: {.solution}

Let
\[
X=S^1=\RR/\ZZ.
\]
Write \(d\) for the usual circular distance on \(\RR/\ZZ\), and
define
\[
\boxed{
A_1=\{x:d(x,0)<1/5\},
\quad
A_2=\{x:d(x,1/3)<1/5\},
\quad
A_3=\{x:d(x,2/3)<1/5\}.}
\]

::: pf

::: {.pf-step #s1-1}

Each \(A_i\) is an open path-connected subspace of \(S^1\).


::: pf-proof

Each \(A_i\) is an open metric ball of radius \(1/5<1/2\) in the circle.
Hence it is an open arc, homeomorphic to an open interval.

:::

:::

::: {.pf-step #s1-2}

Each \(A_i\) is contractible.


::: pf-proof

An open interval is contractible.

:::

:::

::: {.pf-step #s1-3}

The three sets cover \(S^1\):
\[
\boxed{
A_1\cup A_2\cup A_3=S^1}.
\]


::: pf-proof

The three centers
\[
0,\qquad \frac13,\qquad \frac23
\]
divide the circle into three arcs of length \(1/3\). Every point of the
circle lies at circular distance at most
\[
\frac16
\]
from one of these centers. Since
\[
\frac16<\frac15,
\]
every point lies in at least one \(A_i\).

:::

:::

::: {.pf-step #s1-4}

Every pairwise intersection \(A_i\cap A_j\) is nonempty.


::: pf-proof

The circular distance between any two of the three centers is \(1/3\). Two
open balls of radius \(1/5\) overlap because
\[
\frac15+\frac15
=
\frac25
>
\frac13.
\]

:::

:::

::: {.pf-step #s1-5}

Every pairwise intersection \(A_i\cap A_j\) is path connected.


::: pf-proof

Each \(A_i\) is an arc of length
\[
\frac25<\frac12.
\]
For two centers at circular distance \(1/3\), their radius-\(1/5\) arcs
overlap in exactly one open arc of length
\[
\frac25-\frac13
=
\frac1{15}.
\]
Thus each pairwise intersection is homeomorphic to an open interval.

:::

:::

::: {.pf-step #s1-6}

The triple intersection is empty:
\[
\boxed{
A_1\cap A_2\cap A_3=\varnothing}.
\]


::: pf-proof

Suppose \(x\) belonged to all three sets. Then \(x\) would have circular
distance \(<1/5\) from each of the three equally spaced centers.

But among the three centers, two lie on opposite sides of \(x\) at circular
distance at least \(1/3\) from one another. By the triangle inequality,
their mutual distance would be
\[
<\frac15+\frac15=\frac25.
\]
This alone is not contradictory, so use the sharper covering-radius
observation: for any \(x\in S^1\), at least one of
\[
0,\frac13,\frac23
\]
has circular distance at least \(1/3\) from \(x\). Indeed, rotate so
\(x\in[0,1/3]\). Then the distances to \(0\) and \(1/3\) are \(x\) and
\(1/3-x\), while the distance to \(2/3\) is
\[
\min\left(\frac23-x,\frac13+x\right)\ge\frac13.
\]
Hence no point can have distance \(<1/5\) from all three centers.

:::

:::

::: pf-step

For each \(i\),
\[
\boxed{\pi_1(A_i)=0}.
\]


::: pf-proof

This follows from contractibility in step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-8}

Therefore
\[
\boxed{
*_{i=1}^{3}\pi_1(A_i)=1}.
\]


::: pf-proof

The free product of three trivial groups is trivial.

:::

:::

::: {.pf-step #s1-9}

For each pair \(i\ne j\),
\[
\boxed{
\pi_1(A_i\cap A_j)=0}.
\]


::: pf-proof

By step [](#s1-5){.pf-ref}, each pairwise intersection is an open interval and hence
contractible.

:::

:::

::: {.pf-step #s1-10}

Consequently the normal subgroup \(N\) described in the problem is
trivial.


::: pf-proof

The generators prescribed for \(N\) come from elements
\[
[w]\in\pi_1(A_i\cap A_j).
\]
By step [](#s1-9){.pf-ref}, every such element is the identity, so every prescribed
generator of \(N\) is the identity.

:::

:::

::: {.pf-step #s1-11}

Hence the group predicted by the proposed pairwise van Kampen formula
is
\[
\boxed{
\left(
*_{i=1}^{3}\pi_1(A_i)
\right)/N
=
1}.
\]


::: pf-proof

Apply steps [](#s1-8){.pf-ref} and [](#s1-10){.pf-ref}.

:::

:::

::: {.pf-step #s1-12}

On the other hand,
\[
\boxed{
\pi_1(X)
=
\pi_1(S^1)
\cong
\ZZ}.
\]


::: pf-proof

This is the standard computation of the fundamental group of the circle.

:::

:::

::: {.pf-step #s1-13}

Therefore
\[
\boxed{
\pi_1(X)
\not\cong
\left(
*_{i=1}^{3}\pi_1(A_i)
\right)/N}.
\]


::: pf-proof

The left-hand side is infinite cyclic by step [](#s1-12){.pf-ref}, while the right-hand
side is trivial by step [](#s1-11){.pf-ref}.

:::

:::

::: pf-step

The failure occurs because pairwise path-connectedness alone does not
supply the common basepoint and higher-overlap compatibility used in the
usual multi-set form of van Kampen.


::: pf-proof

Here every pairwise intersection is path connected, but
\[
A_1\cap A_2\cap A_3=\varnothing
\]
by step [](#s1-6){.pf-ref}. The pairwise amalgamation data therefore misses the cyclic
gluing pattern of the cover, whose nerve is a \(3\)-cycle and carries the
nontrivial loop of \(S^1\).

:::

:::

::: pf-qed

Steps [](#s1-1){.pf-ref} through [](#s1-5){.pf-ref} verify the required hypotheses, and steps [](#s1-11){.pf-ref} through [](#s1-13){.pf-ref}
give the required counterexample.

:::

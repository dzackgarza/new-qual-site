::: {.problem}
Hatcher p. 131 #9.

Compute the homology groups of the \(\Delta\)-complex \(X\) obtained from
\[
\Delta^n
\]
by identifying all faces of the same dimension. Thus \(X\) has exactly one
\(k\)-simplex for each \(0\le k\le n\).
:::

::: {.solution}
For each \(0\le k\le n\), let
\[
\sigma_k
\]
denote the unique \(k\)-simplex of \(X\).

<1>1. The simplicial chain groups are
\[
\boxed{
C_k(X)
\cong
\begin{cases}
\mathbb Z\langle\sigma_k\rangle,&0\le k\le n,\\
0,&\text{otherwise}.
\end{cases}}
\]

::: {.proof}
By construction, every \(k\)-dimensional face of \(\Delta^n\) is identified
with every other \(k\)-dimensional face. Hence exactly one \(k\)-simplex
survives in the quotient for each \(k\le n\).
:::

<1>2. For every \(1\le k\le n\),
\[
\boxed{
\partial_k\sigma_k
=
\left(
\sum_{i=0}^{k}(-1)^i
\right)
\sigma_{k-1}}.
\]

::: {.proof}
Choose an ordered representative
\[
[v_0,\dots,v_k]
\]
for \(\sigma_k\). Its simplicial boundary is
\[
\sum_{i=0}^{k}
(-1)^i
[v_0,\dots,\widehat v_i,\dots,v_k].
\]
All of these \((k-1)\)-faces are identified with the unique simplex
\(\sigma_{k-1}\), preserving the induced ordering required by the
\(\Delta\)-complex structure. Thus each face contributes the same generator
with the usual alternating sign.
:::

<1>3. The alternating sum satisfies
\[
\boxed{
\sum_{i=0}^{k}(-1)^i
=
\begin{cases}
0,&k\text{ odd},\\
1,&k\text{ even}.
\end{cases}}
\]

::: {.proof}
If \(k=2m+1\), pair consecutive terms:
\[
(1-1)+\cdots+(1-1)=0.
\]
If \(k=2m\), the first \(2m\) terms cancel in pairs and one final \(+1\)
remains.
:::

<1>4. Therefore the boundary maps are
\[
\boxed{
\partial_k
=
\begin{cases}
0,&k\text{ odd},\\
\operatorname{id}_{\mathbb Z},&k\text{ even},
\end{cases}
\qquad
1\le k\le n.}
\]

::: {.proof}
Combine steps <1>2 and <1>3, identifying each chain group with
\(\mathbb Z\) via its unique simplex generator.
:::

<1>5. One always has
\[
\boxed{H_0(X)\cong\mathbb Z}.
\]

::: {.proof}
The map
\[
\partial_1=0
\]
by step <1>4, and
\[
\partial_0=0.
\]
Hence
\[
H_0(X)
=
C_0(X)/\operatorname{im}\partial_1
=
\mathbb Z.
\]
:::

<1>6. Let
\[
0<k<n
\]
be even. Then
\[
\boxed{H_k(X)=0}.
\]

::: {.proof}
For even \(k\), step <1>4 gives
\[
\partial_k=\operatorname{id}_{\mathbb Z}.
\]
Thus
\[
\ker\partial_k=0,
\]
so the homology in degree \(k\) vanishes.
:::

<1>7. Let
\[
0<k<n
\]
be odd. Then
\[
\boxed{H_k(X)=0}.
\]

::: {.proof}
For odd \(k\),
\[
\partial_k=0,
\]
so
\[
\ker\partial_k=C_k(X)\cong\mathbb Z.
\]
But \(k+1\) is even, hence
\[
\partial_{k+1}=\operatorname{id}_{\mathbb Z}
\]
by step <1>4. Therefore
\[
\operatorname{im}\partial_{k+1}
=
C_k(X),
\]
and the quotient defining \(H_k\) is zero.
:::

<1>8. If \(n>0\) is even, then
\[
\boxed{H_n(X)=0}.
\]

::: {.proof}
Step <1>4 gives
\[
\partial_n=\operatorname{id}_{\mathbb Z},
\]
so its kernel is zero. Since there are no \((n+1)\)-simplices,
\[
H_n(X)=\ker\partial_n=0.
\]
:::

<1>9. If \(n\) is odd, then
\[
\boxed{H_n(X)\cong\mathbb Z}.
\]

::: {.proof}
For odd \(n\),
\[
\partial_n=0.
\]
There is no group \(C_{n+1}(X)\), so
\[
\operatorname{im}\partial_{n+1}=0.
\]
Hence
\[
H_n(X)
=
C_n(X)
\cong
\mathbb Z.
\]
:::

<1>10. Consequently, for even \(n\),
\[
\boxed{
H_k(X)
\cong
\begin{cases}
\mathbb Z,&k=0,\\
0,&k>0.
\end{cases}}
\]

::: {.proof}
Use step <1>5 for degree zero, steps <1>6--<1>7 for all intermediate
positive degrees, and step <1>8 in top degree.
:::

<1>11. For odd \(n\),
\[
\boxed{
H_k(X)
\cong
\begin{cases}
\mathbb Z,&k=0,n,\\
0,&\text{otherwise}.
\end{cases}}
\]

::: {.proof}
Use step <1>5 for degree zero, steps <1>6--<1>7 for the intermediate
degrees, and step <1>9 for the top degree.
:::

<1>12. In particular, for odd \(n\), \(X\) has the same homology groups as
\(S^n\), while for even \(n>0\), it has the same homology groups as a point.

::: {.proof}
Compare steps <1>10 and <1>11 with the standard homology groups of a point
and of a sphere.
:::

<1>13. Q.E.D.

::: {.proof}
Steps <1>10 and <1>11 give the complete answer in the two parity cases.
:::
:::

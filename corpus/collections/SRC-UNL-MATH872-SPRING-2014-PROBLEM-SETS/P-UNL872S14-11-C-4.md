::: {.problem}
Hatcher p. 131 #9.

Compute the homology groups of the \(\Delta\)-complex \(X\) obtained from
\[
\Delta^n
\]
by identifying all faces of the same dimension. Thus \(X\) has exactly one
\(k\)-simplex for each \(0\le k\le n\).
:::

::: {.solution}

For each \(0\le k\le n\), let
\[
\sigma_k
\]
denote the unique \(k\)-simplex of \(X\).

::: pf

::: pf-step

The simplicial chain groups are
\[
\boxed{
C_k(X)
\cong
\begin{cases}
\ZZ\langle\sigma_k\rangle,&0\le k\le n,\\
0,&\text{otherwise}.
\end{cases}}
\]


::: pf-proof

By construction, every \(k\)-dimensional face of \(\Delta^n\) is identified
with every other \(k\)-dimensional face. Hence exactly one \(k\)-simplex
survives in the quotient for each \(k\le n\).

:::

:::

::: {.pf-step #s1-2}

For every \(1\le k\le n\),
\[
\boxed{
\partial_k\sigma_k
=
\left(
\sum_{i=0}^{k}(-1)^i
\right)
\sigma_{k-1}}.
\]


::: pf-proof

Choose an ordered representative
\[
[v_0,\dots,v_k]
\]
for \(\sigma_k\). Its simplicial boundary is
\[
\sum_{i=0}^{k}
(-1)^i
[v_0,\dots,\widehat v_i,\dots,v_k].
\]
All of these \((k-1)\)-faces are identified with the unique simplex
\(\sigma_{k-1}\), preserving the induced ordering required by the
\(\Delta\)-complex structure. Thus each face contributes the same generator
with the usual alternating sign.

:::

:::

::: {.pf-step #s1-3}

The alternating sum satisfies
\[
\boxed{
\sum_{i=0}^{k}(-1)^i
=
\begin{cases}
0,&k\text{ odd},\\
1,&k\text{ even}.
\end{cases}}
\]


::: pf-proof

If \(k=2m+1\), pair consecutive terms:
\[
(1-1)+\cdots+(1-1)=0.
\]
If \(k=2m\), the first \(2m\) terms cancel in pairs and one final \(+1\)
remains.

:::

:::

::: {.pf-step #s1-4}

Therefore the boundary maps are
\[
\boxed{
\partial_k
=
\begin{cases}
0,&k\text{ odd},\\
\operatorname{id}_{\ZZ},&k\text{ even},
\end{cases}
\qquad
1\le k\le n.}
\]


::: pf-proof

Combine steps [](#s1-2){.pf-ref} and [](#s1-3){.pf-ref}, identifying each chain group with
\(\ZZ\) via its unique simplex generator.

:::

:::

::: {.pf-step #s1-5}

One always has
\[
\boxed{H_0(X)\cong\ZZ}.
\]


::: pf-proof

The map
\[
\partial_1=0
\]
by step [](#s1-4){.pf-ref}, and
\[
\partial_0=0.
\]
Hence
\[
H_0(X)
=
C_0(X)/\operatorname{im}\partial_1
=
\ZZ.
\]

:::

:::

::: {.pf-step #s1-6}

Let
\[
0<k<n
\]
be even. Then
\[
\boxed{H_k(X)=0}.
\]


::: pf-proof

For even \(k\), step [](#s1-4){.pf-ref} gives
\[
\partial_k=\operatorname{id}_{\ZZ}.
\]
Thus
\[
\ker\partial_k=0,
\]
so the homology in degree \(k\) vanishes.

:::

:::

::: {.pf-step #s1-7}

Let
\[
0<k<n
\]
be odd. Then
\[
\boxed{H_k(X)=0}.
\]


::: pf-proof

For odd \(k\),
\[
\partial_k=0,
\]
so
\[
\ker\partial_k=C_k(X)\cong\ZZ.
\]
But \(k+1\) is even, hence
\[
\partial_{k+1}=\operatorname{id}_{\ZZ}
\]
by step [](#s1-4){.pf-ref}. Therefore
\[
\operatorname{im}\partial_{k+1}
=
C_k(X),
\]
and the quotient defining \(H_k\) is zero.

:::

:::

::: {.pf-step #s1-8}

If \(n>0\) is even, then
\[
\boxed{H_n(X)=0}.
\]


::: pf-proof

Step [](#s1-4){.pf-ref} gives
\[
\partial_n=\operatorname{id}_{\ZZ},
\]
so its kernel is zero. Since there are no \((n+1)\)-simplices,
\[
H_n(X)=\ker\partial_n=0.
\]

:::

:::

::: {.pf-step #s1-9}

If \(n\) is odd, then
\[
\boxed{H_n(X)\cong\ZZ}.
\]


::: pf-proof

For odd \(n\),
\[
\partial_n=0.
\]
There is no group \(C_{n+1}(X)\), so
\[
\operatorname{im}\partial_{n+1}=0.
\]
Hence
\[
H_n(X)
=
C_n(X)
\cong
\ZZ.
\]

:::

:::

::: {.pf-step #s1-10}

Consequently, for even \(n\),
\[
\boxed{
H_k(X)
\cong
\begin{cases}
\ZZ,&k=0,\\
0,&k>0.
\end{cases}}
\]


::: pf-proof

Use step [](#s1-5){.pf-ref} for degree zero, steps [](#s1-6){.pf-ref} through [](#s1-7){.pf-ref} for all intermediate
positive degrees, and step [](#s1-8){.pf-ref} in top degree.

:::

:::

::: {.pf-step #s1-11}

For odd \(n\),
\[
\boxed{
H_k(X)
\cong
\begin{cases}
\ZZ,&k=0,n,\\
0,&\text{otherwise}.
\end{cases}}
\]


::: pf-proof

Use step [](#s1-5){.pf-ref} for degree zero, steps [](#s1-6){.pf-ref} through [](#s1-7){.pf-ref} for the intermediate
degrees, and step [](#s1-9){.pf-ref} for the top degree.

:::

:::

::: pf-step

In particular, for odd \(n\), \(X\) has the same homology groups as
\(S^n\), while for even \(n>0\), it has the same homology groups as a point.


::: pf-proof

Compare steps [](#s1-10){.pf-ref} and [](#s1-11){.pf-ref} with the standard homology groups of a point
and of a sphere.

:::

:::

::: pf-qed

Steps [](#s1-10){.pf-ref} and [](#s1-11){.pf-ref} give the complete answer in the two parity cases.

:::

::: {.problem}
Let X be a path-connected compact Hausdorff space.
The cone on X is the quotient CX of the space X x I by the equivalence relation making (p,0) equivalent to (q,0) for all p,q in X, and the suspension of X is the quotient SX of the space X x I by the equivalence relation making (p,0) equivalent to $( \mathsf { q } , 0 )$ and (p,1) equivalent to (q,1) for all p,q in X.

(a) If X is a Δ-complex, find Δ-complex structures for CX and SX.

(b) Show that the reduced homology groups of CX satisfy \tilde $\mathrm { H } _ { \mathrm { i } } ( \mathrm { C X } ) = 0$ for all i.

(c) Show that the reduced homology groups of SX satisfy \tilde $\mathrm { H _ { i } ( S X ) = \backslash i l d e ~ H _ { i - 1 } ( X ) }$ for all i.
:::

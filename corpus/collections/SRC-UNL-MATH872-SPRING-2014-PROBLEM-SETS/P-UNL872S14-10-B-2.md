Let G be the group presented by $< \mathsf { a } , \mathsf { b } \mid \mathsf { b } ^ { 2 } = 1 >$

(a) Draw the presentation complex for this presentation, and write this complex as a wedge sum of two familiar spaces.

(b) Draw the Cayley graph and the Cayley complex for this presentation.

(c) Draw a simply connected covering space of the wedge sum of a circle $\mathrm { S } ^ { 1 }$and a 2-sphere$\mathrm { S } ^ { 2 }$

How does this differ from the Cayley complex in part (b)?

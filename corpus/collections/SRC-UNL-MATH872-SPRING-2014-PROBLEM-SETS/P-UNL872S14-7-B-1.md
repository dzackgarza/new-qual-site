::: {.problem}
Let
\[
B=\langle a,b\mid aba=bab\rangle
\]
be the braid group on three strands.
Let
\[
H=\langle x\mid\ \rangle,\qquad K=\langle y\mid\ \rangle,\qquad L=\langle z\mid\ \rangle,
\]
and define homomorphisms $c:L\to H$ and $d:L\to K$ by
\[
c(z)=x^2,\qquad d(z)=y^3.
\]
Let $G=H*_L K$ be the free product of $H$ and $K$ amalgamated along $L$ via $c$ and $d$.
Prove that $B\cong G$.
:::

::: pf

::: pf-step

The groups
\[
H=\langle x\mid\ \rangle,
\qquad
K=\langle y\mid\ \rangle,
\qquad
L=\langle z\mid\ \rangle
\]
are all infinite cyclic.


::: pf-proof

Each presentation has one generator and no relators, so each group is the
free group on one generator, namely \(\mathbb Z\).

:::

:::

::: pf-step

The amalgamated free product has presentation
\[
\boxed{
G
\cong
\langle x,y\mid x^2=y^3\rangle}.
\]


::: pf-proof

The free product
\[
H*K
\]
has presentation
\[
\langle x,y\mid\ \rangle.
\]
Amalgamating along \(L\) imposes the relation that the two images of its
generator agree:
\[
c(z)=d(z).
\]
By definition,
\[
c(z)=x^2,
\qquad
d(z)=y^3.
\]
Hence the single added relation is
\[
x^2=y^3.
\]

:::

:::

::: pf-step

In the braid group
\[
B=\langle a,b\mid aba=bab\rangle,
\]
define
\[
\boxed{
X=aba,
\qquad
Y=ab}.
\]


::: pf-proof

These are elements of \(B\).

:::

:::

::: pf-step

The elements \(X,Y\) satisfy
\[
\boxed{X^2=Y^3}.
\]


::: pf-proof

Using
\[
aba=bab,
\]
write the second copy of \(X\) as \(bab\):
\[
X^2
=
(aba)(aba)
=
(aba)(bab)
=
ababab
=
(ab)^3
=
Y^3.
\]

:::

:::

::: pf-step

Therefore there is a homomorphism
\[
\Phi:G\to B
\]
defined by
\[
\boxed{
\Phi(x)=aba,
\qquad
\Phi(y)=ab}.
\]


::: pf-proof

By step <1>4, the images satisfy the defining relation
\[
x^2=y^3
\]
of the presentation in step <1>2. The universal property of presented groups
therefore gives \(\Phi\).

:::

:::

::: pf-step

In \(G\), define
\[
\boxed{
A=y^{-1}x,
\qquad
B'=x^{-1}y^2}.
\]


::: pf-proof

These are elements of \(G\).

:::

:::

::: pf-step

One has
\[
\boxed{AB'=y}.
\]


::: pf-proof

Compute directly:
\[
AB'
=
(y^{-1}x)(x^{-1}y^2)
=
y^{-1}y^2
=
y.
\]

:::

:::

::: pf-step

One has
\[
\boxed{AB'A=x}.
\]


::: pf-proof

By step <1>7,
\[
AB'A
=
y(y^{-1}x)
=
x.
\]

:::

:::

::: pf-step

One has
\[
\boxed{B'AB'=x}.
\]


::: pf-proof

First,
\[
B'A
=
(x^{-1}y^2)(y^{-1}x)
=
x^{-1}yx.
\]
Hence
\[
\begin{aligned}
B'AB'
&=
(x^{-1}yx)(x^{-1}y^2)\\
&=
x^{-1}y^3\\
&=
x^{-1}x^2\\
&=
x,
\end{aligned}
\]
using the defining relation
\[
y^3=x^2.
\]

:::

:::

::: pf-step

Thus
\[
\boxed{AB'A=B'AB'}.
\]


::: pf-proof

Both sides equal \(x\) by steps <1>8 and <1>9.

:::

:::

::: pf-step

Therefore there is a homomorphism
\[
\Psi:B\to G
\]
defined by
\[
\boxed{
\Psi(a)=y^{-1}x,
\qquad
\Psi(b)=x^{-1}y^2}.
\]


::: pf-proof

Step <1>10 says that the proposed images satisfy the braid relation
\[
aba=bab.
\]
Thus the presentation of \(B\) gives the homomorphism.

:::

:::

::: pf-step

The composite
\[
\Psi\circ\Phi:G\to G
\]
fixes \(x\).


::: pf-proof

By step <1>5,
\[
\Phi(x)=aba.
\]
Applying \(\Psi\),
\[
(\Psi\circ\Phi)(x)
=
AB'A
=
x
\]
by step <1>8.

:::

:::

::: pf-step

The same composite fixes \(y\).


::: pf-proof

Since
\[
\Phi(y)=ab,
\]
one has
\[
(\Psi\circ\Phi)(y)
=
AB'
=
y
\]
by step <1>7.

:::

:::

::: pf-step

Hence
\[
\boxed{\Psi\circ\Phi=\operatorname{id}_G}.
\]


::: pf-proof

The group \(G\) is generated by \(x,y\), and the composite fixes both
generators by steps <1>12--<1>13.

:::

:::

::: pf-step

The composite
\[
\Phi\circ\Psi:B\to B
\]
fixes \(a\).


::: pf-proof

Using the formulas from steps <1>5 and <1>11,
\[
\begin{aligned}
(\Phi\circ\Psi)(a)
&=
\Phi(y^{-1}x)\\
&=
(ab)^{-1}(aba)\\
&=
b^{-1}a^{-1}aba\\
&=
b^{-1}ba\\
&=
a.
\end{aligned}
\]

:::

:::

::: pf-step

The composite fixes \(b\).


::: pf-proof

From
\[
X=aba=(ab)a=Ya
\]
inside \(B\), one has
\[
X^{-1}Y^2
=
a^{-1}Y^{-1}Y^2
=
a^{-1}Y
=
a^{-1}ab
=
b.
\]
Therefore
\[
\begin{aligned}
(\Phi\circ\Psi)(b)
&=
\Phi(x^{-1}y^2)\\
&=
X^{-1}Y^2\\
&=
b.
\end{aligned}
\]

:::

:::

::: pf-step

Hence
\[
\boxed{\Phi\circ\Psi=\operatorname{id}_B}.
\]


::: pf-proof

The group \(B\) is generated by \(a,b\), and steps <1>15--<1>16 show that
the composite fixes both.

:::

:::

::: pf-step

Therefore
\[
\boxed{
B\cong G}.
\]


::: pf-proof

The homomorphisms
\[
\Phi:G\to B
\qquad\text{and}\qquad
\Psi:B\to G
\]
are inverse by steps <1>14 and <1>17.

:::

:::

::: pf-qed

Step <1>18 proves the required isomorphism.

:::

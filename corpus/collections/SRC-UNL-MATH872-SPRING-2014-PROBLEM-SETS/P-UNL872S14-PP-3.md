Let G be the group presented by $\mathrm { G } = < \mathrm { a , b } \mid \mathrm { a } ^ { 2 } \mathrm { = } 1 , \mathrm { b } ^ { 3 } \mathrm { = } 1 >$.
Let H be the subgroup of G generated by a. Let h :$\mathbf { G }  \mathbf { Z } / 2 \mathbf { Z } { = } < \mathbf { c } \mid \mathbf { c } ^ { 2 } = 1 >$be the homomorphism built using the HBT that satisfies$\mathrm { h } ( \mathrm { a } ) = \mathrm { c }$ and h(b) = 1, and let K be the kernel of h.

(a) Explain how to view G as a free product of two finite groups, and use this to write out all of the elements of G as reduced sequences.
Describe/draw the presentation complex X and Cayley complex Y for this presentation of G.

(b) Prove that H is isomorphic to a familiar group.
Draw/describe the quotient Y/H of Y by the action of H.

(c) Determine which reduced sequences in the free product group G do (or do not) lie in the subgroup K. Use this information to draw/describe the quotient Y/K of Y by the action of K. Find a presentation for the fundamental group $\pi _ { 1 } ( \mathrm { Y / K } )$ of the CW complex Y/K.

::: {.problem}
Let G be a finitely generated group and n a natural number.

(a) Show that if H is an index n subgroup of G then H is finitely generated.
    Moreover, show that if G is finitely presented then so is H.

(b) Show that there are only a finite number of subgroups of G of index n.

(Hint: In both parts, consider coverings of the presentation complex for G. In part (b), consider the case that G is a free group first.)
:::

::: {.solution}
<1>1. Choose a finite generating set [
G=langle g_1,dots,g_rmid R
angle,
] where the relator set (R) may be infinite.

::: {.proof}
The group (G) is finitely generated by hypothesis, so such a presentation exists with finitely many generators.
:::

<1>2. Let (X) be the associated presentation complex.
Then (X) has one (0)-cell and finitely many (1)-cells.

::: {.proof}
The presentation complex has one (1)-cell for each generator (g_i). There are (r<infty) such generators.
:::

<1>3. Let (Hle G) have index (n). There is a connected (n)-sheeted covering [
p:widetilde X_H	o X
] whose induced subgroup is (H).

::: {.proof}
Presentation complexes are connected CW complexes and satisfy the hypotheses of the covering-space classification theorem.
The subgroup (Hlepi_1(X)cong G) therefore determines a connected covering.
Its number of sheets equals [
[G:H]=n.
]
:::

<1>4. The (1)-skeleton of (widetilde X_H) is finite.

::: {.proof}
The unique (0)-cell of (X) has exactly (n) lifts.
Each of the (r) open (1)-cells of (X) has exactly (n) lifts.
Thus the lifted (1)-skeleton has [
n
] vertices and [
nr
] open (1)-cells.
:::

<1>5. The group [
pi_1(widetilde X_H)
] is finitely generated.

::: {.proof}
The inclusion of the (1)-skeleton into a CW complex induces a surjection on fundamental groups, since attaching cells of dimension at least (2) can only add relations.
A finite connected graph has finitely generated fundamental group.
By step <1>4, the (1)-skeleton of (widetilde X_H) is finite, so [
pi_1(widetilde X_H)
] is finitely generated.
:::

<1>6. Therefore [
\boxed{H	ext{ is finitely generated}}.
]

::: {.proof}
By construction of the covering in step <1>3, [
p_*pi_1(widetilde X_H)
=
H.
] The map (p_*) is injective for a covering, so [
pi_1(widetilde X_H)cong H.
] Apply step <1>5.
:::

<1>7. Now suppose (G) is finitely presented.
Then (X) may be chosen to be a finite (2)-dimensional CW complex.

::: {.proof}
A finite presentation has finitely many generators and finitely many relators.
Its presentation complex therefore has one vertex, finitely many (1)-cells, and finitely many (2)-cells.
:::

<1>8. The (n)-sheeted cover (widetilde X_H) is then a finite (2)-dimensional CW complex.

::: {.proof}
Every open cell of (X) has exactly (n) lifts in an (n)-sheeted covering.
Since (X) has finitely many cells, so does (widetilde X_H).
:::

<1>9. The fundamental group of a finite connected (2)-dimensional CW complex is finitely presented.

::: {.proof}
Choose a maximal tree in the finite (1)-skeleton and collapse it.
The remaining finitely many (1)-cells give finitely many generators, and the finitely many (2)-cell attaching maps give finitely many relators.
This is a finite presentation of the fundamental group.
:::

<1>10. Hence, if (G) is finitely presented, then [
\boxed{H	ext{ is finitely presented}}.
]

::: {.proof}
By steps <1>8 and <1>9, [
pi_1(widetilde X_H)
] is finitely presented.
Step <1>6 identifies this group with (H).
:::

<1>11. For part (b), fix the finite generating set [
G=langle g_1,dots,g_r
angle.
]

::: {.proof}
Again use finite generation of (G).
:::

<1>12. There are only finitely many homomorphisms [
\boxed{
ho:G	o S_n}.
]

::: {.proof}
A homomorphism is determined by the images of the generators [
g_1,dots,g_r.
] Each generator has only [
|S_n|=n!
] possible images.
Hence there are at most [
(n!)^r
] homomorphisms (G o S_n).
:::

<1>13. Let (Hle G) have index (n). The action of (G) on the left coset set [
G/H
] gives a transitive homomorphism [

ho_H:G ooperatorname{Sym}(G/H)cong S_n. ]

::: {.proof}
For (gin G), define [
gcdot(kH)=(gk)H.
] This is an action on the (n)-element set (G/H), and it is transitive because every coset is obtained from (H) by left multiplication.
:::

<1>14. Choose a bijection [
lambda_H:G/H	o{1,dots,n}
] with [
lambda_H(H)=1.
] After transporting the action through (lambda_H), one has [
\boxed{

ho_H}(1)}.
]

::: {.proof}
An element (gin G) fixes the coset (H) exactly when [
gH=H,
] which is equivalent to [
gin H.
] The chosen labeling sends this distinguished coset to (1).
:::

<1>15. Every index-(n) subgroup of (G) is therefore the stabilizer of (1) for some homomorphism [
G	o S_n.
]

::: {.proof}
Apply steps <1>13 and <1>14 to the subgroup.
:::

<1>16. There are only finitely many subgroups of (G) of index (n).

::: {.proof}
By step <1>12, there are finitely many homomorphisms [
G	o S_n.
] Each such homomorphism determines at most one subgroup [
operatorname{Stab}(1).
] By step <1>15, every index-(n) subgroup appears among these finitely many stabilizers.
Hence there are only finitely many.
:::

<1>17. Q.E.D.

Steps <1>1--<1>10 prove part (a), and steps <1>11--<1>16 prove part (b).

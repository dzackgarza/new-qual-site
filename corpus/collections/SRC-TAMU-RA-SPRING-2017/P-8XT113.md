::: {.problem}
A. Construct a Lebesgue measurable subset $A$ of $\mathbb{R}$ so that for all reals $a<b$, $0<m(A\cap[a,b])<b-a$, where $m$ is Lebesgue measure on $\mathbb{R}$.

B. Suppose $A\subseteq\mathbb{R}$ is a Lebesgue measurable set and assume that $$m(A\cap(a,b))\le\frac{b-a}{2}$$ for any $a,b\in\mathbb{R}$, $a<b$.
Prove that $m(A)=0$.
:::

::: {.solution}
**(A).**

<1>1. Enumerate the rationals and construct a fat Cantor-like set $A$ that meets every interval in both positive measure and positive co-measure.
::: {.proof}
standard construction (choose open dense sets of small measure and take complements).
:::

<1>2. More explicitly, let $\{q_n\}$ enumerate $\mathbb{Q}$, and let $U_n$ be an open interval around $q_n$ of length $\varepsilon/2^n$; then $A = \mathbb{R} \setminus \bigcup_n U_n$ is closed and meets every interval in positive measure and co-measure for small $\varepsilon$.
::: {.proof}
<1>1 (with $\varepsilon$ small, e.g. $\varepsilon = 1/2$, the open set $\bigcup_n U_n$ is dense and has measure $\le \varepsilon$, so its complement $A$ is closed and has positive measure in every interval).
:::

<1>3. A more precise construction: start with $[0,1]$ and remove open intervals of total length $< 1$ in a dense way, leaving a closed set $A$ with $0 < m(A \cap [a,b]) < b-a$ for all $a < b$.
::: {.proof}
<1>2.
:::

**(B).**

<1>1. Suppose $A$ is measurable and $m(A \cap (a,b)) \le (b-a)/2$ for all $a < b$.
::: {.proof}
hypothesis.
:::

<1>2. For any measurable $A$, the Lebesgue density of $A$ is $1$ at almost every point of $A$ (Lebesgue density theorem).
::: {.proof}
Lebesgue density theorem.
:::

<1>3. If $m(A) > 0$, then there is a point $x \in A$ where the density is $1$, i.e. $\lim_{r \to 0} \frac{m(A \cap (x-r, x+r))}{2r} = 1$.
::: {.proof}
<1>2.
:::

<1>4. But the hypothesis gives $\frac{m(A \cap (x-r, x+r))}{2r} \le \frac{1}{2}$ for all $r$.
::: {.proof}
<1>1.
:::

<1>5. Contradiction, so $m(A) = 0$.
::: {.proof}
<1>3 and <1>4.
:::

<1>6. Q.E.D.
::: {.proof}
<1>3 (A) and <1>5 (B).
:::
:::

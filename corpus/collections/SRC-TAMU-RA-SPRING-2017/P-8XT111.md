::: {.problem}
Prove that if a function $f:[0,1]\to\mathbb{R}$ is Lipschitz, with $$|f(x)-f(y)|\le M|x-y|$$ for all $x,y\in[0,1]$, then there is a sequence of continuously differentiable functions $f_n:[0,1]\to\mathbb{R}$ such that

(i) $|f_n'(x)|\le M$ for all $x\in[0,1]$;

(ii) $f_n(x)\to f(x)$ for all $x\in[0,1]$.
:::

::: {.solution}
<1>1. Extend $f$ to a Lipschitz function on the real line with the same constant.
::: {.proof}
Define
\[
\widetilde f(x)=
\begin{cases}
f(0),&x<0,\\
f(x),&0\le x\le1,\\
f(1),&x>1.
\end{cases}
\]
Then $\widetilde f$ is $M$-Lipschitz on $\mathbb R$.

Indeed, the only nontrivial case is when the two points lie on opposite sides of an endpoint. For example, if $x<0<y\le1$, then
\[
|\widetilde f(x)-\widetilde f(y)|
=|f(0)-f(y)|
\le M|y|
\le M|y-x|.
\]
The case $0\le x<1<y$ is identical, and if $x<0<1<y$, then
\[
|\widetilde f(x)-\widetilde f(y)|
=|f(0)-f(1)|
\le M
\le M|y-x|.
\]
Thus $\widetilde f$ has Lipschitz constant at most $M$.
:::

<1>2. Mollify the extension.
::: {.proof}
Choose a standard nonnegative mollifier $\rho\in C_c^\infty(\mathbb R)$ with
\[
\int_{\mathbb R}\rho(t)\,dt=1,
\]
and set
\[
\rho_n(t)=n\rho(nt),
\qquad
F_n=\rho_n*\widetilde f.
\]
Since $\widetilde f$ is bounded and locally integrable, each $F_n$ is smooth on $\mathbb R$.

Moreover, for all $x,y\in\mathbb R$,
\[
|F_n(x)-F_n(y)|
\le
\int_{\mathbb R}\rho_n(t)
|\widetilde f(x-t)-\widetilde f(y-t)|\,dt
\le M|x-y|.
\]
Hence every $F_n$ is itself $M$-Lipschitz.
Because $F_n$ is differentiable, this implies
\[
|F_n'(x)|\le M
\qquad(x\in\mathbb R).
\]
:::

<1>3. The mollifications converge uniformly to $f$ on $[0,1]$.
::: {.proof}
For every $x\in\mathbb R$,
\[
|F_n(x)-\widetilde f(x)|
\le
\int_{\mathbb R}\rho_n(t)
|\widetilde f(x-t)-\widetilde f(x)|\,dt
\le
M\int_{\mathbb R}\rho_n(t)|t|\,dt.
\]
After the change of variables $u=nt$,
\[
\int_{\mathbb R}\rho_n(t)|t|\,dt
=\frac1n\int_{\mathbb R}\rho(u)|u|\,du,
\]
so
\[
\|F_n-\widetilde f\|_\infty
\le
\frac{M}{n}\int_{\mathbb R}\rho(u)|u|\,du
\longrightarrow0.
\]
Finally, let $f_n=F_n|_{[0,1]}$. Then $f_n\in C^1[0,1]$, $|f_n'|\le M$ everywhere, and $f_n\to f$ uniformly, hence pointwise, on $[0,1]$.
:::

::: {.problem}
Given $f:\mathbb{R}\to\mathbb{R}$ bounded and uniformly continuous and $K_n$ with $K_n\in L^1(\mathbb{R})$ for $n=1,2,3,\ldots$ such that

(i) $\|K_n\|_1\le M<\infty$, $n=1,2,3,\ldots$;

(ii) $\int_{-\infty}^\infty K_n(x)\,dx\to 1$ as $n\to\infty$;

(iii) $\int_{\{x:|x|>\delta\}}|K_n(x)|\to 0$ as $n\to\infty$ for all $\delta>0$.

Show that $K_n*f\to f$ uniformly, where $$K_n*f(x)=\int_{-\infty}^\infty K_n(y)f(x-y)\,dy.$$
:::

::: {.solution}
<1>1. Separate the normalization error from the translation error.
::: {.proof}
For every $x\in\mathbb R$,
\[
K_n*f(x)-f(x)
=
\int_{\mathbb R}K_n(y)\bigl(f(x-y)-f(x)\bigr)\,dy
+
f(x)\left(\int_{\mathbb R}K_n(y)\,dy-1\right).
\]
Hence
\[
|K_n*f(x)-f(x)|
\le
\int_{\mathbb R}|K_n(y)|\,|f(x-y)-f(x)|\,dy
+
\|f\|_\infty
\left|\int_{\mathbb R}K_n(y)\,dy-1\right|.
\]
The second term tends to $0$ independently of $x$ by assumption (ii).
:::

<1>2. Control the convolution error near the origin.
::: {.proof}
Fix $\varepsilon>0$.
By uniform continuity of $f$, choose $\delta>0$ such that
\[
|u-v|<\delta
\quad\Longrightarrow\quad
|f(u)-f(v)|<\frac{\varepsilon}{3M}
\]
when $M>0$.
If $M=0$, then every $K_n=0$ a.e., contradicting assumption (ii), so necessarily $M>0$.

Therefore, for every $x\in\mathbb R$,
\[
\int_{|y|\le\delta}|K_n(y)|\,|f(x-y)-f(x)|\,dy
\le
\frac{\varepsilon}{3M}\|K_n\|_1
\le \frac{\varepsilon}{3}.
\]
:::

<1>3. Control the tail uniformly in $x$.
::: {.proof}
Since $f$ is bounded,
\[
|f(x-y)-f(x)|\le 2\|f\|_\infty.
\]
Thus
\[
\int_{|y|>\delta}|K_n(y)|\,|f(x-y)-f(x)|\,dy
\le
2\|f\|_\infty
\int_{|y|>\delta}|K_n(y)|\,dy.
\]
By assumption (iii), the right-hand side tends to $0$ independently of $x$.
Hence for all sufficiently large $n$ it is $<\varepsilon/3$.
:::

<1>4. Conclude uniform convergence.
::: {.proof}
By assumption (ii), for all sufficiently large $n$,
\[
\|f\|_\infty
\left|\int_{\mathbb R}K_n(y)\,dy-1\right|
<\frac{\varepsilon}{3}.
\]
Combining this with <1>2 and <1>3 gives, for all sufficiently large $n$ and every $x\in\mathbb R$,
\[
|K_n*f(x)-f(x)|<\varepsilon.
\]
Therefore
\[
\|K_n*f-f\|_\infty\longrightarrow0,
\]
so $K_n*f\to f$ uniformly on $\mathbb R$.
:::

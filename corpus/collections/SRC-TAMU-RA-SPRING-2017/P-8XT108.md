::: {.problem}
Let $(\Omega,\mathcal{A},\mu)$ be a measure space.
Prove directly from the definition of convergence almost everywhere that if for all $n$, $$\mu\{x\in\Omega:|f_n(x)|>1/n\}<n^{-3/2},$$ then $f_n\to 0$ a.e. $(\mu)$.
:::

::: {.solution}
**Goal.** Show $f_n \to 0$ a.e. given $\mu\theset{|f_n| > 1/n} < n^{-3/2}$.

<1>1. Let $E_n = \theset{x : |f_n(x)| > 1/n}$.
Proof: define the exceptional sets.

<1>2. $\sum_{n=1}^\infty \mu(E_n) < \infty$.
Proof: $\sum_n \mu(E_n) < \sum_n n^{-3/2} < \infty$ (the series $\sum n^{-3/2}$ converges).

<1>3. By the Borel–Cantelli lemma, $\mu\qty(\limsup_n E_n) = 0$.
Proof: the first Borel–Cantelli lemma: if $\sum \mu(E_n) < \infty$, then almost every point lies in only finitely many $E_n$.

<1>4. For $x \notin \limsup_n E_n$, $f_n(x) \to 0$.
<2>1. $x \notin \limsup E_n$ means $x \in E_n$ for only finitely many $n$.
Proof: definition of $\limsup E_n = \bigcap_N \bigcup_{n \ge N} E_n$.
<2>2. Hence for all sufficiently large $n$, $|f_n(x)| \le 1/n$.
Proof: $x \notin E_n$ means $|f_n(x)| \le 1/n$.
<2>3. Hence $|f_n(x)| \le 1/n \to 0$, so $f_n(x) \to 0$.
Proof: $1/n \to 0$.

<1>5. Q.E.D.
Proof: <1>3 and <1>4 show $f_n \to 0$ almost everywhere.
:::

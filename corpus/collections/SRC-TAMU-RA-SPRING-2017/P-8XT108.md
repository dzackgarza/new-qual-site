::: {.problem}
Let $(\Omega,\mathcal{A},\mu)$ be a measure space.
Prove directly from the definition of convergence almost everywhere that if for all $n$, $$\mu\{x\in\Omega:|f_n(x)|>1/n\}<n^{-3/2},$$ then $f_n\to 0$ a.e. $(\mu)$.
:::

::: {.solution}
**Goal.** Show $f_n \to 0$ a.e. given $\mu\theset{|f_n| > 1/n} < n^{-3/2}$.

::: pf

::: pf-step

Let $E_n = \theset{x : |f_n(x)| > 1/n}$.

::: pf-proof

define the exceptional sets.

:::

:::

::: pf-step

$\sum_{n=1}^\infty \mu(E_n) < \infty$.

::: pf-proof

$\sum_n \mu(E_n) < \sum_n n^{-3/2} < \infty$ (the series $\sum n^{-3/2}$ converges).

:::

:::

::: {.pf-step #s3}

By the Borel–Cantelli lemma, $\mu\qty(\limsup_n E_n) = 0$.

::: pf-proof

the first Borel–Cantelli lemma: if $\sum \mu(E_n) < \infty$, then almost every point lies in only finitely many $E_n$.

:::

:::

::: {.pf-step #s4}

For $x \notin \limsup_n E_n$, $f_n(x) \to 0$.

::: pf-proof

::: pf-step

$x \notin \limsup E_n$ means $x \in E_n$ for only finitely many $n$.

::: pf-proof

definition of $\limsup E_n = \bigcap_N \bigcup_{n \ge N} E_n$.

:::

:::

::: pf-step

Hence for all sufficiently large $n$, $|f_n(x)| \le 1/n$.

::: pf-proof

$x \notin E_n$ means $|f_n(x)| \le 1/n$.

:::

:::

::: pf-step

Hence $|f_n(x)| \le 1/n \to 0$, so $f_n(x) \to 0$.

::: pf-proof

$1/n \to 0$.

:::

:::

:::

:::

::: pf-qed

Steps [](#s3){.pf-ref} and [](#s4){.pf-ref} show $f_n \to 0$ almost everywhere.

:::

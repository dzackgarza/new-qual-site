::: {.problem}
(a) On $C^\infty$, decide whether $\{f:f(1)=1\}$ and $\{f:f'(1)=0\}$ are linear subspaces, and whether $Tf=f'\sin x$ and $Tf=f'(3)f$ are linear transformations.

(b) Match five source arrows to the matrices
\[
\begin{pmatrix}0&-1\\1&0\end{pmatrix},
\begin{pmatrix}0&1\\1&0\end{pmatrix},
\begin{pmatrix}-1&0\\0&1\end{pmatrix},
\begin{pmatrix}-1&0\\0&-1\end{pmatrix},
\begin{pmatrix}1&0\\0&-1\end{pmatrix},
\begin{pmatrix}1&-1\\0&1\end{pmatrix}.
\]
Label these matrices, in the displayed order, by $A,B,C,D,E,F$. In the
source diagram the five arrows are the top horizontal arrow, left vertical
arrow, diagonal arrow from upper left to lower right, right vertical
arrow, and bottom horizontal arrow.

(c) For $\sin^3x$, $\sin^2x$, and $\sin^2x+\sin^3x$, decide whether $a_0=0$, all cosine coefficients vanish, and all sine coefficients vanish.
:::

::: {.solution}
<1>1. The set
\[
\{f\in C^\infty:f(1)=1\}
\]
is not a linear subspace.

::: {.proof}
The zero function does not belong to the set, because $0(1)=0\neq1$.
Every linear subspace contains the zero vector.
:::

<1>2. The set
\[
\{f\in C^\infty:f'(1)=0\}
\]
is a linear subspace.

::: {.proof}
The map
\[
L:C^\infty\longrightarrow\mathbb R,
\qquad
L(f)=f'(1),
\]
is linear. The displayed set is $\ker L$, hence is a linear subspace.
:::

<1>3. The transformation
\[
T_1(f)(x)=f'(x)\sin x
\]
is linear.

::: {.proof}
For scalars $a,b$ and functions $f,g$,
\[
\begin{aligned}
T_1(af+bg)(x)
&=(af+bg)'(x)\sin x\\
&=(af'(x)+bg'(x))\sin x\\
&=aT_1(f)(x)+bT_1(g)(x).
\end{aligned}
\]
:::

<1>4. The transformation
\[
T_2(f)(x)=f'(3)f(x)
\]
is not linear.

::: {.proof}
Take $f(x)=x$. Then $f'(3)=1$, so $T_2(f)=f$. But
\[
T_2(2f)=(2f)'(3)(2f)=2\cdot2f=4f,
\]
whereas
\[
2T_2(f)=2f.
\]
Thus homogeneity fails.
:::

<1>5. Matrix $A$ is rotation by $90^\circ$ counterclockwise.

::: {.proof}
For the standard basis,
\[
Ae_1=e_2,
\qquad
Ae_2=-e_1.
\]
Hence $A$ sends the positive $x$-axis to the positive $y$-axis and the
positive $y$-axis to the negative $x$-axis, which is the
$90^\circ$ counterclockwise rotation represented by the top horizontal
source arrow.
:::

<1>6. Matrix $C$ is reflection across the $y$-axis.

::: {.proof}
One has
\[
C(x,y)^T=(-x,y)^T.
\]
This is the left-right mirror transformation represented by the left
vertical source arrow.
:::

<1>7. Matrix $E$ is reflection across the $x$-axis.

::: {.proof}
One has
\[
E(x,y)^T=(x,-y)^T.
\]
This is the top-bottom mirror transformation represented by the diagonal
source arrow.
:::

<1>8. Matrix $B$ is reflection across the line $y=x$.

::: {.proof}
One has
\[
B(x,y)^T=(y,x)^T.
\]
Thus $B$ exchanges the two coordinates. Applied to the image at the
upper-right corner of the source diagram, it produces the lower-right
image, so it labels the right vertical arrow.
:::

<1>9. Matrix $D$ is rotation by $180^\circ$.

::: {.proof}
Since
\[
D(x,y)^T=(-x,-y)^T,
\]
$D$ is the half-turn. Applied to the lower-left source image, it produces
the lower-right source image, so it labels the bottom horizontal arrow.
:::

<1>10. Matrix $F$ is unused.

::: {.proof}
Steps <1>5--<1>9 account for all five source arrows with the five matrices
$A,C,E,B,D$. The only remaining candidate is $F$.
:::

<1>11. For $f(x)=\sin^3x$, one has $a_0=0$ and all cosine coefficients
vanish, but the sine coefficients do not all vanish.

::: {.proof}
The function $\sin^3x$ is odd. Hence its integral over
$[-\pi,\pi]$, and its inner product with every even function
$\cos(nx)$, vanish. Thus $a_0=0$ and all $a_n=0$.
Moreover,
\[
\sin^3x=\frac{3\sin x-\sin(3x)}4,
\]
so some sine coefficients are nonzero.
:::

<1>12. For $f(x)=\sin^2x$, all sine coefficients vanish, but
$a_0\neq0$ and the cosine coefficients do not all vanish.

::: {.proof}
The identity
\[
\sin^2x=\frac{1-\cos(2x)}2
\]
shows directly that the constant coefficient and the $\cos(2x)$
coefficient are nonzero, while every sine coefficient is zero.
:::

<1>13. For $f(x)=\sin^2x+\sin^3x$, none of the three vanishing conditions
holds.

::: {.proof}
Combining the identities from steps <1>11 and <1>12 gives
\[
\sin^2x+\sin^3x
=\frac12-\frac12\cos(2x)
+\frac34\sin x-\frac14\sin(3x).
\]
Thus the constant coefficient, a cosine coefficient, and sine
coefficients are all nonzero.
:::

<1>14. The complete answers are
\[
\boxed{
\begin{gathered}
\text{(a) first set is not a subspace, second set is a subspace;}\\
T_1\text{ linear, }T_2\text{ nonlinear};\\
\text{(b) top }A,\quad\text{left }C,\quad\text{diagonal }E,\quad
\text{right }B,\quad\text{bottom }D,\quad F\text{ unused};\\
\text{(c) }\sin^3x:\ a_0=0,\ \text{all }a_n=0;\\
\sin^2x:\ \text{all }b_n=0;\\
\sin^2x+\sin^3x:\ \text{none of the three conditions.}
\end{gathered}}
\]

::: {.proof}
Steps <1>1--<1>4 establish part (a), steps <1>5--<1>10 establish part
(b), and steps <1>11--<1>13 establish part (c).
:::

<1>15. Q.E.D.

::: {.proof}
Step <1>14 records all requested classifications and matches.
:::

::: {.problem}
Mark each statement true or false. No justifications are required.

1. All symmetric matrices with positive entries are diagonalizable.
2. Every symmetric matrix is invertible.
3. If a symmetric matrix satisfies $A^5=0$, then $A=0$.
4. The sum of two symmetric $n\times n$ matrices is symmetric.
5. The product of two symmetric $n\times n$ matrices is symmetric.
6. If a $2\times2$ matrix has negative determinant, then the origin of $x'=Ax$ is stable.
7. For every real matrix $A$, both $AA^T$ and $A^TA$ are diagonalizable.
8. $\begin{pmatrix}2&1&0\\0&2&0\\0&0&1\end{pmatrix}$ is diagonalizable.
9. Every $2\times3$ matrix has a nonzero vector in its kernel.
10. If $\operatorname{im}A\subseteq\ker A$ for a square matrix, then $A^2=0$.
11. If a $2\times2$ matrix $A$ is diagonalizable, then $A^7+A+I_2$ is diagonalizable.
12. If $f(x)=7\sin(5x)$, then its Fourier coefficient $b_7$ equals $5$.
13. The smooth solutions of $f(x)=x+\sin(f(x))$ form a vector space.
14. If eigenvalue $1$ has geometric multiplicity $2$ for a $2\times2$ matrix, then the matrix is the identity.
15. For arbitrary $2\times2$ matrices $A,B$, some eigenvalue of $AB$ is the product of an eigenvalue of $A$ and an eigenvalue of $B$.
16. If $x'=Ax$ is asymptotically stable for a symmetric $2\times2$ matrix, then $\det A>0$.
17. If $x(t+1)=Ax(t)$ is asymptotically stable, every eigenvalue satisfies $|\lambda|<1$.
18. $f(x,t)=\sin(5x)e^{-25t}$ solves $f_t=f_{xx}$.
19. With the course Fourier norm, $\|6\sin(175x)+8\cos(199x)\|=10$.
20. Every solution of $x''+x=\sin t$ stays bounded as $t\to\infty$.

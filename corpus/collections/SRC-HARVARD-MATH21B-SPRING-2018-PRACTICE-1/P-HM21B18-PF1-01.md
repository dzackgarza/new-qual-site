::: {.problem}
Mark each statement true or false. No justifications are required.

1. All symmetric matrices with positive entries are diagonalizable.
2. Every symmetric matrix is invertible.
3. If a symmetric matrix satisfies $A^5=0$, then $A=0$.
4. The sum of two symmetric $n\times n$ matrices is symmetric.
5. The product of two symmetric $n\times n$ matrices is symmetric.
6. If a $2\times2$ matrix has negative determinant, then the origin of $x'=Ax$ is stable.
7. For every real matrix $A$, both $AA^T$ and $A^TA$ are diagonalizable.
8. $\begin{pmatrix}2&1&0\\0&2&0\\0&0&1\end{pmatrix}$ is diagonalizable.
9. Every $2\times3$ matrix has a nonzero vector in its kernel.
10. If $\operatorname{im}A\subseteq\ker A$ for a square matrix, then $A^2=0$.
11. If a $2\times2$ matrix $A$ is diagonalizable, then $A^7+A+I_2$ is diagonalizable.
12. If $f(x)=7\sin(5x)$, then its Fourier coefficient $b_7$ equals $5$.
13. The smooth solutions of $f(x)=x+\sin(f(x))$ form a vector space.
14. If eigenvalue $1$ has geometric multiplicity $2$ for a $2\times2$ matrix, then the matrix is the identity.
15. For arbitrary $2\times2$ matrices $A,B$, some eigenvalue of $AB$ is the product of an eigenvalue of $A$ and an eigenvalue of $B$.
16. If $x'=Ax$ is asymptotically stable for a symmetric $2\times2$ matrix, then $\det A>0$.
17. If $x(t+1)=Ax(t)$ is asymptotically stable, every eigenvalue satisfies $|\lambda|<1$.
18. $f(x,t)=\sin(5x)e^{-25t}$ solves $f_t=f_{xx}$.
19. With the course Fourier norm, $\|6\sin(175x)+8\cos(199x)\|=10$.
20. Every solution of $x''+x=\sin t$ stays bounded as $t\to\infty$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Statement 1 is true.


::: pf-proof

Every real symmetric matrix is orthogonally diagonalizable by the spectral
theorem. Positivity of its entries is irrelevant.

:::

:::

::: pf-step

Statement 2 is false.


::: pf-proof

The zero matrix is symmetric but not invertible.

:::

:::

::: pf-step

Statement 3 is true.


::: pf-proof

Because $A$ is symmetric, there is an orthogonal matrix $Q$ and a real
diagonal matrix $D$ such that $A=QDQ^T$. Then
$$
0=A^5=QD^5Q^T,
$$
so $D^5=0$. Every diagonal entry $\lambda$ of $D$ satisfies
$\lambda^5=0$, hence $\lambda=0$. Thus $D=0$ and $A=0$.

:::

:::

::: pf-step

Statement 4 is true.


::: pf-proof

If $A^T=A$ and $B^T=B$, then
$$
(A+B)^T=A^T+B^T=A+B.
$$

:::

:::

::: pf-step

Statement 5 is false.


::: pf-proof

Take
$$
A=\begin{pmatrix}1&0\\0&2\end{pmatrix},
\qquad
B=\begin{pmatrix}0&1\\1&0\end{pmatrix}.
$$
Both are symmetric, but
$$
AB=\begin{pmatrix}0&1\\2&0\end{pmatrix}
$$
is not symmetric.

:::

:::

::: pf-step

Statement 6 is false.


::: pf-proof

For a real $2\times2$ matrix with $\det A<0$, the characteristic
polynomial has discriminant
$$
(\operatorname{tr}A)^2-4\det A>0,
$$
so the two eigenvalues are real. Their product is $\det A<0$, hence they
have opposite signs. The positive eigenvalue produces an exponentially
growing solution of $x'=Ax$, so the origin is unstable.

:::

:::

::: pf-step

Statement 7 is true.


::: pf-proof

One has
$$
(AA^T)^T=AA^T,
\qquad
(A^TA)^T=A^TA.
$$
Thus both matrices are real symmetric and therefore diagonalizable over
$\RR$.

:::

:::

::: pf-step

Statement 8 is false.


::: pf-proof

For
$$
A=\begin{pmatrix}2&1&0\\0&2&0\\0&0&1\end{pmatrix},
$$
the eigenvalue $2$ has algebraic multiplicity $2$. But
$$
A-2I=
\begin{pmatrix}0&1&0\\0&0&0\\0&0&-1\end{pmatrix}
$$
has a one-dimensional kernel. Hence the geometric multiplicity of $2$ is
$1$, so $A$ is not diagonalizable.

:::

:::

::: pf-step

Statement 9 is true.


::: pf-proof

A $2\times3$ matrix has rank at most $2$. By rank-nullity, its nullity is
at least $3-2=1$, so its kernel contains a nonzero vector.

:::

:::

::: pf-step

Statement 10 is true.


::: pf-proof

For every vector $x$, one has $Ax\in\operatorname{im}A$. The hypothesis
$\operatorname{im}A\subseteq\ker A$ therefore gives
$$
A^2x=A(Ax)=0.
$$
Hence $A^2=0$.

:::

:::

::: pf-step

Statement 11 is true.


::: pf-proof

If $A=SDS^{-1}$ with $D$ diagonal, then
$$
A^7+A+I
=S(D^7+D+I)S^{-1}.
$$
The matrix $D^7+D+I$ is diagonal, so the same $S$ diagonalizes
$A^7+A+I$.

:::

:::

::: pf-step

Statement 12 is false.


::: pf-proof

The function is already a single sine mode:
$$
f(x)=7\sin(5x).
$$
Thus $b_5=7$ and $b_7=0$, not $5$.

:::

:::

::: pf-step

Statement 13 is false.


::: pf-proof

The zero function does not satisfy the equation, since it would require
$0=x$ for every $x$. Hence the solution set does not contain the zero
vector and cannot be a vector space.

:::

:::

::: pf-step

Statement 14 is true.


::: pf-proof

Geometric multiplicity $2$ means
$$
\dim\ker(A-I_2)=2.
$$
Thus $\ker(A-I_2)=\RR^2$, so $A-I_2=0$ and $A=I_2$.

:::

:::

::: pf-step

Statement 15 is false.


::: pf-proof

Take
$$
A=\begin{pmatrix}1&0\\0&2\end{pmatrix},
\qquad
B=\frac12\begin{pmatrix}7&1\\1&7\end{pmatrix}.
$$
The eigenvalues of $A$ are $1,2$, and those of $B$ are $3,4$. Hence the
possible products of an eigenvalue of $A$ with one of $B$ are
$3,4,6,8$.

On the other hand,
$$
AB=
\begin{pmatrix}
7/2&1/2\\
1&7
\end{pmatrix},
$$
whose characteristic polynomial is
$$
p(\lambda)=\lambda^2-\frac{21}{2}\lambda+24.
$$
Directly,
$$
p(3)=\frac32,\quad
p(4)=-2,\quad
p(6)=-3,\quad
p(8)=4.
$$
Thus none of $3,4,6,8$ is an eigenvalue of $AB$.

:::

:::

::: pf-step

Statement 16 is true.


::: pf-proof

Because $A$ is symmetric, its eigenvalues are real. Asymptotic stability
of $x'=Ax$ forces both eigenvalues to be strictly negative. Their product
is $\det A$, so $\det A>0$.

:::

:::

::: pf-step

Statement 17 is true.


::: pf-proof

For an eigenvalue $\lambda$ with eigenvector $v$, the corresponding mode
of the discrete system is
$$
A^tv=\lambda^t v.
$$
If $|\lambda|\geq1$, this mode does not tend to zero. Therefore
asymptotic stability requires $|\lambda|<1$ for every eigenvalue.

:::

:::

::: pf-step

Statement 18 is true.


::: pf-proof

For
$$
f(x,t)=\sin(5x)e^{-25t},
$$
one has
$$
f_t=-25\sin(5x)e^{-25t}
$$
and
$$
f_{xx}=-25\sin(5x)e^{-25t}.
$$
Hence $f_t=f_{xx}$.

:::

:::

::: pf-step

Statement 19 is true.


::: pf-proof

Under the course Fourier norm, distinct sine and cosine modes form an
orthonormal family. Therefore Parseval gives
$$
\|6\sin(175x)+8\cos(199x)\|^2=6^2+8^2=100,
$$
so the norm is $10$.

:::

:::

::: {.pf-step #s1-20}

Statement 20 is false.


::: pf-proof

The resonant equation
$$
x''+x=\sin t
$$
has the particular solution
$$
x_p(t)=-\frac t2\cos t.
$$
Indeed, $x_p''+x_p=\sin t$. This solution is unbounded as
$t\to\infty$, so not every solution stays bounded.

:::

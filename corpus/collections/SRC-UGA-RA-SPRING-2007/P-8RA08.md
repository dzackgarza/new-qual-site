::: problem
Let $(\Omega,\mathcal{M},\mu)$ be a measure space.
Let $\{E_i\}$ be a sequence of measurable subsets of $\Omega$ such that $\sum_i\mu(E_i)<\infty$.
Set
\[
S=\{\omega\in\Omega:\omega\in E_i\text{ for infinitely many }i\}.
\]
Show that $\mu(S)=0$.
:::

::: solution
<1>1. Express $S$ as an intersection of tail unions.
::: proof
For $N\ge1$, set
\[
F_N:=\bigcup_{i\ge N}E_i.
\]
Then $F_{N+1}\subseteq F_N$, and a point belongs to infinitely many of the sets $E_i$ exactly when it belongs to every tail union. Hence
\[
S=\bigcap_{N=1}^\infty F_N.
\]
:::

<1>2. Estimate the tail unions.
::: proof
By countable subadditivity,
\[
\mu(F_N)
\le \sum_{i\ge N}\mu(E_i).
\]
Since
\[
\sum_{i=1}^\infty\mu(E_i)<\infty,
\]
the tails satisfy
\[
\sum_{i\ge N}\mu(E_i)\longrightarrow0.
\]
Thus
\[
\mu(F_N)\longrightarrow0.
\]
:::

<1>3. Conclude that the limsup set is null.
::: proof
Because $S\subseteq F_N$ for every $N$,
\[
0\le \mu(S)\le \mu(F_N).
\]
Letting $N\to\infty$ gives
\[
\boxed{\mu(S)=0.}
\]
:::
:::

::: problem
Let $(\Omega,\mathcal{M},\mu)$ be a measure space.
A set $\Phi\subset L^1(\Omega)$ is said to be uniformly integrable if, for each $\varepsilon>0$ there exists $\delta>0$ such that whenever $f\in\Phi$ and $E\subset\Omega$ is measurable with $\mu(E)<\delta$, we have $\int_E|f|\,d\mu<\varepsilon$.

Assume $\mu(\Omega)=1$ and suppose $\{f_n\}_{n\in\mathbb{N}}$ is a uniformly integrable sequence of functions such that $f_n\to 0$ almost everywhere.
Prove that
\[
\lim_{n\to\infty}\int_\Omega|f_n|\,d\mu=0.
\]
:::

::: solution
<1>1. Use uniform integrability on a small exceptional set.
::: proof
Fix $\varepsilon>0$. By uniform integrability, there exists $\delta>0$ such that
\[
\mu(E)<\delta
\quad\Longrightarrow\quad
\int_E|f_n|\,d\mu<\frac\varepsilon2
\]
for every $n$.
:::

<1>2. Use Egorov's theorem on the complement.
::: proof
Since $\mu(\Omega)=1<\infty$ and $f_n\to0$ almost everywhere, Egorov's theorem gives a measurable set $E\subset\Omega$ with
\[
\mu(E)<\delta
\]
such that $f_n\to0$ uniformly on $E^c$.

Hence for all sufficiently large $n$,
\[
\sup_{x\in E^c}|f_n(x)|<\frac\varepsilon2.
\]
Using $\mu(E^c)\le1$,
\[
\int_{E^c}|f_n|\,d\mu
\le \mu(E^c)\sup_{E^c}|f_n|
<\frac\varepsilon2.
\]
Step 1 gives simultaneously
\[
\int_E|f_n|\,d\mu<\frac\varepsilon2.
\]
Therefore, for all sufficiently large $n$,
\[
\int_\Omega|f_n|\,d\mu
<\varepsilon.
\]
Thus
\[
\boxed{\int_\Omega|f_n|\,d\mu\longrightarrow0.}
\]
:::
:::

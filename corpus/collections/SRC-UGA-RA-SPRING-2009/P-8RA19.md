::: problem
Let $\{f_k\}$ be any sequence of functions in $L^2([0,1])$ satisfying $\|f_k\|_2\le M$ for all $k\in\mathbb{N}$.
Prove that if $f_k\to f$ almost everywhere, then
\[
\lim_{k\to\infty}\int_0^1 f_k(x)\,dx=\int_0^1 f(x)\,dx.
\]
:::

::: solution
<1>1. Show that the limit belongs to $L^2$.
::: proof
Since $f_k\to f$ almost everywhere, Fatou's lemma gives
\[
\int_0^1|f|^2
\le \liminf_{k\to\infty}\int_0^1|f_k|^2
\le M^2.
\]
Hence
\[
f\in L^2([0,1])
\qquad\text{and}\qquad
\|f\|_2\le M.
\]
:::

<1>2. Control the exceptional set uniformly.
::: proof
Let $\varepsilon>0$. Choose $\delta>0$ so small that
\[
2M\sqrt{\delta}<\frac{\varepsilon}{2}.
\]
By Egorov's theorem, there exists a measurable set $E\subset[0,1]$ with
\[
m(E)<\delta
\]
such that $f_k\to f$ uniformly on $[0,1]\setminus E$.

For every $k$, Cauchy--Schwarz gives
\[
\int_E|f_k|
\le \|f_k\|_2\,m(E)^{1/2}
\le M\sqrt\delta,
\]
and likewise
\[
\int_E|f|
\le M\sqrt\delta.
\]
Thus
\[
\int_E|f_k-f|
\le 2M\sqrt\delta
<\frac\varepsilon2.
\]
:::

<1>3. Use uniform convergence on the complement.
::: proof
Since $f_k\to f$ uniformly on $[0,1]\setminus E$, for all sufficiently large $k$,
\[
\sup_{[0,1]\setminus E}|f_k-f|<\frac\varepsilon2.
\]
Because $m([0,1])=1$,
\[
\int_{[0,1]\setminus E}|f_k-f|
\le \frac\varepsilon2.
\]
Combining with Step 2,
\[
\|f_k-f\|_1<\varepsilon
\]
for all sufficiently large $k$. Hence $f_k\to f$ in $L^1([0,1])$, and therefore
\[
\left|\int_0^1 f_k-\int_0^1 f\right|
\le \|f_k-f\|_1\longrightarrow0.
\]
Thus
\[
\boxed{\lim_{k\to\infty}\int_0^1f_k(x)\,dx=\int_0^1f(x)\,dx.}
\]
:::
:::

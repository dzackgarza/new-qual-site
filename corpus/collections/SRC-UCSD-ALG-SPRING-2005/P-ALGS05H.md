::: {.problem}
Let $F$ be an infinite field.
If $L$ is a finite-dimensional extension field of $F$ and there are only finitely many intermediate fields, show that $L = F(u)$ for some $u$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
Two-generator case: If $L = F(\alpha, \beta)$ has finitely many intermediate fields, then $L = F(u)$ for some $u \in L$:

::: pf-proof

::: pf-step
For each scalar $c \in F$, consider the intermediate field $K_c = F(\alpha + c\beta) \subseteq L$.

::: pf-proof
definition of simple field extension.
:::

:::

::: pf-step
Since $F$ is an infinite field, the collection $\{K_c : c \in F\}$ is an infinite family of intermediate fields indexed by $F$.

::: pf-proof
hypothesis that $F$ is infinite.
:::

:::

::: pf-step
Since $L/F$ has only finitely many distinct intermediate fields, by the Pigeonhole Principle there exist distinct scalars $c_1, c_2 \in F$ ($c_1 \neq c_2$) such that $K_{c_1} = K_{c_2}$.

::: pf-proof
Pigeonhole Principle on infinite set onto a finite set.
:::

:::

::: pf-step
Let $K = K_{c_1} = K_{c_2}$.
Then both $\alpha + c_1 \beta \in K$ and $\alpha + c_2 \beta \in K$.

::: pf-proof
definition of $K_{c_1}$ and $K_{c_2}$.
:::

:::

::: pf-step
The difference $(\alpha + c_1 \beta) - (\alpha + c_2 \beta) = (c_1 - c_2)\beta \in K$.

::: pf-proof
closure of $K$ under subtraction.
:::

:::

::: pf-step
Since $c_1 - c_2 \neq 0$ lies in $F \subseteq K$, $\beta = (c_1 - c_2)^{-1} \cdot (c_1 - c_2)\beta \in K$.

::: pf-proof
closure of $K$ under field multiplication.
:::

:::

::: pf-step
Then $\alpha = (\alpha + c_1 \beta) - c_1 \beta \in K$.

::: pf-proof
$\alpha + c_1 \beta \in K$, $\beta \in K$, and $c_1 \in F \subseteq K$.
:::

:::

::: pf-step
Thus $F(\alpha, \beta) \subseteq K$.
Since $K = F(\alpha + c_1 \beta) \subseteq F(\alpha, \beta)$, we have $L = F(\alpha, \beta) = F(u)$ where $u = \alpha + c_1 \beta$.

::: pf-proof
mutual inclusion.
:::

:::

:::

:::

::: {.pf-step #s2}
General case by induction on the number of generators:

::: pf-proof

::: pf-step
Since $[L : F] < \infty$, $L$ is a finitely generated algebraic extension: $L = F(\alpha_1, \dots, \alpha_n)$ for some $\alpha_1, \dots, \alpha_n \in L$.

::: pf-proof
finite degree implies finite generation.
:::

:::

::: pf-step
We proceed by induction on $n \ge 1$.
The base case $n = 1$: $L = F(\alpha_1)$ is already generated by the single element $\alpha_1$, so the claim holds with $u = \alpha_1$.

::: pf-proof
a field generated by one element is a simple extension by definition.
:::

:::

::: pf-step
Assume the result holds for all extensions generated by $n-1$ elements.

::: pf-proof
induction hypothesis.
:::

:::

::: pf-step
For $L = F(\alpha_1, \dots, \alpha_n)$, consider the subfield $L' = F(\alpha_1, \dots, \alpha_{n-1})$.
Every intermediate field of $L'/F$ is an intermediate field of $L/F$, so $L'/F$ has only finitely many intermediate fields.

::: pf-proof
subfield lattices.
:::

:::

::: pf-step
By the induction hypothesis, $L' = F(\gamma)$ for some $\gamma \in L'$.

::: pf-proof
induction hypothesis applied to $L'/F$.
:::

:::

::: pf-step
Then $L = L'(\alpha_n) = F(\gamma, \alpha_n)$.

::: pf-proof
substitution.
:::

:::

::: pf-step
Applying the two-generator case step [](#s1){.pf-ref} to $F(\gamma, \alpha_n)$ yields an element $u \in L$ such that $L = F(u)$.

::: pf-proof
step [](#s1){.pf-ref}.
:::

:::

:::

:::

::: pf-step
Conclusion: $L = F(u)$ is a simple extension for some $u \in L$.

::: pf-proof
step [](#s1){.pf-ref} and step [](#s2){.pf-ref}.
:::

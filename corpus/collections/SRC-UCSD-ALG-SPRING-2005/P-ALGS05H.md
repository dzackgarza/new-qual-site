::: problem
Let $F$ be an infinite field.
If $L$ is a finite-dimensional extension field of $F$ and there are only finitely many intermediate fields, show that $L = F(u)$ for some $u$.
:::

::: {.solution}
<1>1. Two-generator case: If $L = F(\alpha, \beta)$ has finitely many intermediate fields, then $L = F(u)$ for some $u \in L$: <2>1. For each scalar $c \in F$, consider the intermediate field $K_c = F(\alpha + c\beta) \subseteq L$.
::: {.proof}
definition of simple field extension.
:::
<2>2. Since $F$ is an infinite field, the collection $\{K_c : c \in F\}$ is an infinite family of intermediate fields indexed by $F$.
::: {.proof}
hypothesis that $F$ is infinite.
:::
<2>3. Since $L/F$ has only finitely many distinct intermediate fields, by the Pigeonhole Principle there exist distinct scalars $c_1, c_2 \in F$ ($c_1 \neq c_2$) such that $K_{c_1} = K_{c_2}$.
::: {.proof}
Pigeonhole Principle on infinite set onto a finite set.
:::
<2>4. Let $K = K_{c_1} = K_{c_2}$.
Then both $\alpha + c_1 \beta \in K$ and $\alpha + c_2 \beta \in K$.
::: {.proof}
definition of $K_{c_1}$ and $K_{c_2}$.
:::
<2>5. The difference $(\alpha + c_1 \beta) - (\alpha + c_2 \beta) = (c_1 - c_2)\beta \in K$.
::: {.proof}
closure of $K$ under subtraction.
:::
<2>6. Since $c_1 - c_2 \neq 0$ lies in $F \subseteq K$, $\beta = (c_1 - c_2)^{-1} \cdot (c_1 - c_2)\beta \in K$.
::: {.proof}
closure of $K$ under field multiplication.
:::
<2>7. Then $\alpha = (\alpha + c_1 \beta) - c_1 \beta \in K$.
::: {.proof}
$\alpha + c_1 \beta \in K$, $\beta \in K$, and $c_1 \in F \subseteq K$.
:::
<2>8. Thus $F(\alpha, \beta) \subseteq K$.
Since $K = F(\alpha + c_1 \beta) \subseteq F(\alpha, \beta)$, we have $L = F(\alpha, \beta) = F(u)$ where $u = \alpha + c_1 \beta$.
::: {.proof}
mutual inclusion.
:::

<1>2. General case by induction on the number of generators: <2>1. Since $[L : F] < \infty$, $L$ is a finitely generated algebraic extension: $L = F(\alpha_1, \dots, \alpha_n)$ for some $\alpha_1, \dots, \alpha_n \in L$.
::: {.proof}
finite degree implies finite generation.
:::
<2>2. We proceed by induction on $n \ge 1$.
The base case $n = 1$: $L = F(\alpha_1)$ is already generated by the single element $\alpha_1$, so the claim holds with $u = \alpha_1$.
::: {.proof}
a field generated by one element is a simple extension by definition.
:::
<2>3. Assume the result holds for all extensions generated by $n-1$ elements.
::: {.proof}
induction hypothesis.
:::
<2>4. For $L = F(\alpha_1, \dots, \alpha_n)$, consider the subfield $L' = F(\alpha_1, \dots, \alpha_{n-1})$.
Every intermediate field of $L'/F$ is an intermediate field of $L/F$, so $L'/F$ has only finitely many intermediate fields.
::: {.proof}
subfield lattices.
:::
<2>5. By the induction hypothesis, $L' = F(\gamma)$ for some $\gamma \in L'$.
::: {.proof}
induction hypothesis applied to $L'/F$.
:::
<2>6. Then $L = L'(\alpha_n) = F(\gamma, \alpha_n)$.
::: {.proof}
substitution.
:::
<2>7. Applying the two-generator case <1>1 to $F(\gamma, \alpha_n)$ yields an element $u \in L$ such that $L = F(u)$.
::: {.proof}
<1>1.
:::

<1>3. Conclusion: $L = F(u)$ is a simple extension for some $u \in L$.
::: {.proof}
<1>1 and <1>2.
:::
Q.E.D.
:::

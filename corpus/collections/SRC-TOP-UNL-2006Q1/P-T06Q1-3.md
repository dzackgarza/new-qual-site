::: {.problem}
Let $S^1\subseteq\mathbb R^2$ denote the unit sphere (with the subspace topology), and $\mathbb R$ the real line with the usual topology.
Show that for every continuous map $f:S^1\to\mathbb R$ there is an $x\in S^1$ with $f(x)=f(-x)$.
:::

::: {.solution}
<1>1. Definition and properties of the difference function:
<2>1. Define the function $g: S^1 \to \mathbb{R}$ by:
\[
g(x) = f(x) - f(-x).
\]
Since $f$ and the antipodal map $x \mapsto -x$ are continuous, $g$ is continuous on $S^1$.
Proof: composition and difference of continuous functions.
<2>2. For any $x \in S^1$:
\[
g(-x) = f(-x) - f(-(-x)) = f(-x) - f(x) = -g(x).
\]
Thus $g$ is an odd function on $S^1$.
Proof: algebra of function evaluation.

<1>2. Application of the Intermediate Value Theorem:
<2>1. Choose an arbitrary point $x_0 \in S^1$.
If $g(x_0) = 0$, then $f(x_0) = f(-x_0)$, and $x_0$ is the desired point.
Proof: definition of $g$.
<2>2. Otherwise, $g(x_0) \neq 0$. Without loss of generality, assume $g(x_0) > 0$.
By <1>1 (<2>2), $g(-x_0) = -g(x_0) < 0$.
Proof: oddness of $g$.
<2>3. Let $\gamma: [0, 1] \to S^1$ be a continuous path in $S^1$ connecting $x_0$ to $-x_0$ (e.g. a semicircle $\gamma(t) = (\cos(\theta_0 + \pi t), \sin(\theta_0 + \pi t))$ where $x_0 = (\cos \theta_0, \sin \theta_0)$).
Proof: path-connectedness of $S^1$.
<2>4. The composite function $h = g \circ \gamma: [0, 1] \to \mathbb{R}$ is continuous, with:
\[
h(0) = g(x_0) > 0 \quad \text{and} \quad h(1) = g(-x_0) < 0.
\]
By the Intermediate Value Theorem, there exists $t^* \in (0, 1)$ such that $h(t^*) = 0$.
Proof: Intermediate Value Theorem on the interval $[0, 1]$.
<2>5. Setting $x^* = \gamma(t^*) \in S^1$, we have:
\[
g(x^*) = 0 \implies f(x^*) = f(-x^*).
\]
Proof: definition of $h$ and $g$.

<1>3. Conclusion:
There exists $x \in S^1$ such that $f(x) = f(-x)$. Q.E.D.
Proof: <1>1 and <1>2.
:::

::: {.problem}
Let R be a subring of a field F such that for each x in F either $x \in R { \mathrm { ~ o r ~ } } x ^ { - 1 } \in R$ . Prove that if I and J are two ideals of R, then either $I \subseteq J { \mathrm { ~ o r ~ } } J \subseteq I$
:::

::: {.problem}
Let R be the ring of all $2 \times 2$ matrices of the form $\left[ \begin{array} { r r } { a } & { b } \\ { - b } & { a } \end{array} \right]$ where a and b are real numbers.
Prove that R is isomorphic to C, the field of complex numbers.
:::

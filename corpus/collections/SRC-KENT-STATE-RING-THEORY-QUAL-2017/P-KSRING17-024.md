::: {.problem}
Let R be a commutative ring with identity and define $U _ { 2 } ( R ) \ = \ \left\{ { \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { c } \end{array} \right] } \ | \ a , b , c \in R \right\}$ Prove that every R-automorphism of $U _ { 2 } ( R )$ is inner.
:::

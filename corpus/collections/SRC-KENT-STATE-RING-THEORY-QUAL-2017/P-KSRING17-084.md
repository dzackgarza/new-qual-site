::: {.problem}
Let $D = \mathbb { Z } ( { \sqrt { - 1 1 } } ) = \{ m + n { \sqrt { - 1 1 } } \mid m , n \in \mathbb { Z } \}$ and $F = \mathbb { Q } ( { \sqrt { - 1 1 } } )$ its field of fractions.
Show the following:

(a) $x ^ { 2 } - x + 3$ is irreducible in $D [ x ]$ but not in $F [ x ]$

(b) D is not a unique factorization domain.
:::

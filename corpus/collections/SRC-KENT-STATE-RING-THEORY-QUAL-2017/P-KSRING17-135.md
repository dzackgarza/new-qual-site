::: {.problem}
Let R be a commutative Noetherian ring with identity and let I be an ideal in R. Let $J = { \mathrm { R a d } } ( I )$ . Prove that there exists a positive integer n such that $j ^ { n } \in I$ for all $j \in J$
:::

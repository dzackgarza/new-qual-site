::: {.problem}
If n is a positive integer and F is any field, let $M _ { n } ( F )$ denote the ring of $n \times n$ matrices with entries in F . Prove that $M _ { n } ( F )$ is a simple ring.
Equivalently, End $F  ^ { ( V ) }$ is a simple ring if V is a finite dimensional vector space over F .
:::

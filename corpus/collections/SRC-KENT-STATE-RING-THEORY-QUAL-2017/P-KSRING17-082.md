::: {.problem}
Let $D = \mathbb { Z } ( { \sqrt { 5 } } ) = \{ m + n { \sqrt { 5 } } \mid m , n \in \mathbb { Z } \} - \mathbf { a }$ subring of the field of real numbers and necessarily an integral domain (you need not show this) — and $F = \mathbb { Q } ( { \sqrt { 5 } } )$ its field of fractions.
Show the following:

(a) $x ^ { 2 } + x - 1$ is irreducible in $D [ x ]$ but not in $F [ x ]$

(b) D is not a unique factorization domain.
:::

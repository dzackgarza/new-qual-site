::: {.problem}
Let $A=(ij)_{1\le i,j\le9}$ be the $9\times9$ multiplication-table matrix
\[
A=\begin{pmatrix}
1&2&3&4&5&6&7&8&9\\
2&4&6&8&10&12&14&16&18\\
3&6&9&12&15&18&21&24&27\\
4&8&12&16&20&24&28&32&36\\
5&10&15&20&25&30&35&40&45\\
6&12&18&24&30&36&42&48&54\\
7&14&21&28&35&42&49&56&63\\
8&16&24&32&40&48&56&64&72\\
9&18&27&36&45&54&63&72&81
\end{pmatrix}.
\]
Find all eigenvalues and eigenvectors of $A$.
:::

::: {.solution}

Put
\[
u=(1,2,3,4,5,6,7,8,9)^T.
\]

::: pf

::: {.pf-step #s1-1}

The matrix factors as
\[
A=uu^T.
\]


::: pf-proof

The $(i,j)$ entry of $uu^T$ is
\[
u_i u_j=ij,
\]
which is exactly the $(i,j)$ entry of $A$.

:::

:::

::: {.pf-step #s1-2}

The vector $u$ is an eigenvector with eigenvalue
\[
\boxed{285}.
\]


::: pf-proof

By step [](#s1-1){.pf-ref},
\[
Au=u(u^Tu).
\]
Moreover,
\[
u^Tu=\sum_{j=1}^9 j^2
=1+4+9+16+25+36+49+64+81
=285.
\]
Hence $Au=285u$.

:::

:::

::: {.pf-step #s1-3}

The eigenspace for the eigenvalue $285$ is
\[
\boxed{E_{285}=\operatorname{span}\{u\}}.
\]


::: pf-proof

Step [](#s1-1){.pf-ref} shows that every vector in the image of $A$ is a scalar multiple of
$u$. Since $u\ne0$, the matrix has rank $1$. Every eigenvector with nonzero
eigenvalue lies in $\operatorname{im}A$, so every eigenvector for $285$ is a
nonzero scalar multiple of $u$. Conversely, step [](#s1-2){.pf-ref} shows that every nonzero
multiple of $u$ is an eigenvector for $285$.

:::

:::

::: {.pf-step #s1-4}

The eigenspace for the eigenvalue $0$ is
\[
\boxed{
E_0=\ker A
=u^\perp
=\left\{x\in\RR^9:\sum_{j=1}^9 jx_j=0\right\}}.
\]


::: pf-proof

For every $x\in\RR^9$, step [](#s1-1){.pf-ref} gives
\[
Ax=u(u^Tx).
\]
Since $u\ne0$, this vanishes if and only if $u^Tx=0$. This is exactly the
displayed orthogonal complement.

:::

:::

::: {.pf-step #s1-5}

An explicit basis for $E_0$ is
\[
\boxed{\{\,je_1-e_j:2\le j\le9\,\}}.
\]


::: pf-proof

For $2\le j\le9$,
\[
u^T(je_1-e_j)=j-j=0,
\]
so all eight displayed vectors lie in $E_0$. If
\[
\sum_{j=2}^9 c_j(je_1-e_j)=0,
\]
then the coefficient of $e_j$ for each $j\ge2$ is $-c_j$, hence every
$c_j=0$. Thus these eight vectors are linearly independent. Since
$\operatorname{rank}A=1$, rank-nullity gives $\dim E_0=8$, so they form a
basis.

:::

:::

::: {.pf-step #s1-6}

The complete eigenvalue list is
\[
\boxed{285\text{ with multiplicity }1,\qquad
0\text{ with multiplicity }8}.
\]


::: pf-proof

Steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref} give eigenspaces of dimensions $1$ and $8$, respectively,
whose direct sum is all of $\RR^9$. Hence there are no other
eigenvalues, and the displayed multiplicities are both geometric and
algebraic.

:::

:::

::: pf-qed

Steps [](#s1-3){.pf-ref} through [](#s1-6){.pf-ref} give every eigenvalue and every eigenvector of $A$.

:::

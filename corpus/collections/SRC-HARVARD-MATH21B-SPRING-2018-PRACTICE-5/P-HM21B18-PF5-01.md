::: {.problem}
Mark each statement true or false. No justifications are required.

1. The inverse of $\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ is half that matrix.
2. The sum of two eigenvectors of a matrix is always an eigenvector.
3. If $S$ has an eigenbasis of $A$ as columns, then $AS=DS$ for a diagonal matrix $D$.
4. A $2\times2$ matrix $A$ is diagonalizable whenever $A+A^T$ is diagonalizable.
5. For $f(x)=|\sin(3x)|+|x|$, all cosine Fourier coefficients vanish.
6. The continuous solutions of $2\pi f(x)=f(\pi(x+1))+f(\pi(x-1))$ form a vector space.
7. If the sum of all algebraic multiplicities of a $3\times3$ matrix is $3$, then the matrix is diagonalizable.
8. Every real $2\times2$ matrix is a product of a rotation, a diagonal matrix, and a shear.
9. A discrete dynamical system with all eigenvalues negative is asymptotically stable.
10. Every consistent linear system $Ax=b$ has exactly one solution.
11. A rotation composed with a reflection is orthogonal.
12. If
\[
f(x,t)=\sum_{n=1}^\infty\frac1{n^3}e^{-n^2t}\sin(nx)
\]
solves the heat equation, then $\langle f(x,0),\sin(3x)\rangle=1/27$ for $\langle f,g\rangle=(2/\pi)\int_0^\pi fg$.
13. For a $5\times6$ matrix $A$, $Ax=b$ has either zero or infinitely many solutions.
14. If the Jacobian at an equilibrium of a nonlinear planar system is orthogonal, then the equilibrium is asymptotically stable.
15. If $A$ is diagonalizable and $A=QR$ is its QR decomposition, then $R$ is diagonalizable.
16. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\|3\sin(5x)+4\cos(20x)\|=25$.
17. If $x(t+1)=Ax(t)$ is asymptotically stable, then $x(t+1)=(A^2+A)x(t)$ is asymptotically stable.
18. If $\dot x=Ax$ for a $2\times2$ matrix with trace $10$, then the origin cannot be asymptotically stable.
19. If a symmetric $4\times4$ matrix satisfies $A^2=A$, then some eigenvalue has algebraic multiplicity at least $2$.
20. If $A$ is reflection in the line $3x=4y$ and $B$ is projection onto $x=y$, then $A+B$ is diagonalizable.

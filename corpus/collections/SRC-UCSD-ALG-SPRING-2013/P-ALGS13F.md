::: {.problem}
Let $E$ be the splitting field of $x^p - 2$ over $\QQ$, where $p$ is an odd prime.

(a) Prove that $E = \QQ[\zeta_p, \sqrt[p]{2}]$ and find $[E:\QQ]$.
(Here $\zeta_p$ is a primitive $p$th root of unity.)

(b) Find $\{(\sigma(\zeta_p), \sigma(\sqrt[p]{2})) \mid \sigma \in \mathrm{Gal}(E/\QQ)\}$.
Justify your answer.
:::

::: {.solution}

::: pf

::: pf-step
Part (a): Splitting field and degree $[E : \QQ]$:

::: pf-proof

::: pf-step
The roots of $x^p - 2$ in $\CC$ are:
\[
\alpha_k = \sqrt[p]{2} \, \zeta_p^k \quad \text{for } k \in \{0, 1, \ldots, p-1\},
\]
where $\sqrt[p]{2} \in \RR_{>0}$ is the real $p$-th root and $\zeta_p = e^{2\pi i / p}$ is a primitive $p$-th root of unity.
:::

::: pf-step
The splitting field $E$ is generated by all roots:
\[
E = \QQ(\alpha_0, \ldots, \alpha_{p-1}) = \QQ\left(\sqrt[p]{2}, \zeta_p \sqrt[p]{2}, \ldots, \zeta_p^{p-1}\sqrt[p]{2}\right) = \QQ\left(\zeta_p, \sqrt[p]{2}\right).
\]
:::

::: pf-step
Consider the intermediate fields:

- $x^p - 2 \in \QQ[x]$ is irreducible by Eisenstein's criterion with prime 2, so $[\QQ(\sqrt[p]{2}) : \QQ] = p$.

- The cyclotomic polynomial $\Phi_p(x) = \sum_{j=0}^{p-1} x^j \in \QQ[x]$ is irreducible over $\QQ$, so $[\QQ(\zeta_p) : \QQ] = p - 1$.
:::

::: pf-step
By the Tower Law for field extensions, $[E : \QQ]$ is divisible by $[\QQ(\sqrt[p]{2}) : \QQ] = p$ and by $[\QQ(\zeta_p) : \QQ] = p - 1$.
Since $\gcd(p, p - 1) = 1$, $[E : \QQ]$ is divisible by $p(p - 1)$.
Furthermore, $[E : \QQ] = [\QQ(\zeta_p)(\sqrt[p]{2}) : \QQ(\zeta_p)] \cdot [\QQ(\zeta_p) : \QQ] \le p(p - 1)$.
Therefore:
\[
[E : \QQ] = p(p - 1).
\]
:::

:::

:::

::: pf-step
Part (b): Image set of the Galois group action:

::: pf-proof

::: pf-step
Any $\QQ$-automorphism $\sigma \in \operatorname{Gal}(E/\QQ)$ must map a root of a polynomial to another root of the same polynomial:

- $\sigma(\zeta_p) \in \{ \zeta_p^a \mid 1 \le a \le p - 1 \}$,

- $\sigma(\sqrt[p]{2}) \in \{ \zeta_p^b \sqrt[p]{2} \mid 0 \le b \le p - 1 \}$.
:::

::: pf-step
The number of candidate pairs $(a, b) \in (\ZZ/p\ZZ)^\times \times (\ZZ/p\ZZ)$ is:
\[
(p - 1) \cdot p = p(p - 1).
\]
:::

::: pf-step
Since $E/\QQ$ is a Galois extension, $|\operatorname{Gal}(E/\QQ)| = [E : \QQ] = p(p - 1)$.
Because an automorphism $\sigma \in \operatorname{Gal}(E/\QQ)$ is uniquely determined by its values on the generators $\zeta_p$ and $\sqrt[p]{2}$, all $p(p - 1)$ pairs must be realized by distinct automorphisms.
:::

::: pf-step
Therefore:
\[
\left\{ \left(\sigma(\zeta_p), \sigma\left(\sqrt[p]{2}\right)\right) \;\middle|\; \sigma \in \operatorname{Gal}(E/\QQ) \right\} = \left\{ \left(\zeta_p^a, \, \zeta_p^b \sqrt[p]{2}\right) \;\middle|\; 1 \le a \le p - 1, \; 0 \le b \le p - 1 \right\}.
\]
:::

:::

:::

::: pf-qed
Conclusion: $E = \QQ(\zeta_p, \sqrt[p]{2})$ with $[E : \QQ] = p(p - 1)$, and the image pairs under $\operatorname{Gal}(E/\QQ)$ are $\{ (\zeta_p^a, \zeta_p^b \sqrt[p]{2}) \mid 1 \le a \le p-1, 0 \le b \le p-1 \}$.
:::

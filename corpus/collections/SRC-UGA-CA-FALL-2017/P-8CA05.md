::: {.problem}
Evaluate
\[
\int_0^\infty\frac{\cos 5x}{x^2+1}\,dx.
\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

$\int_0^\infty \frac{\cos 5x}{x^2+1}\, dx = \frac{1}{2}\int_{-\infty}^{\infty} \frac{\cos 5x}{x^2+1}\, dx = \frac{1}{2}\operatorname{Re}\int_{-\infty}^{\infty} \frac{e^{5ix}}{x^2+1}\, dx$.

::: pf-proof

the integrand is even, and $\cos 5x = \operatorname{Re}(e^{5ix})$.

:::

:::

::: {.pf-step #s2}

$\int_{-\infty}^{\infty} \frac{e^{5ix}}{x^2+1}\, dx = 2\pi i \operatorname{Res}_{z=i}\left(\frac{e^{5iz}}{z^2+1}\right)$.

::: pf-proof

close the contour in the upper half-plane (where $e^{5iz}$ decays since $\Im z > 0$); the only pole in the upper half-plane is $z = i$.

:::

:::

::: {.pf-step #s3}

$\operatorname{Res}_{z=i}\frac{e^{5iz}}{z^2+1} = \frac{e^{5i\cdot i}}{2i} = \frac{e^{-5}}{2i}$.

::: pf-proof

$z^2 + 1 = (z-i)(z+i)$, so the residue at the simple pole $z = i$ is $\frac{e^{5iz}}{z+i}\big|_{z=i} = \frac{e^{-5}}{2i}$.

:::

:::

::: {.pf-step #s4}

Hence $\int_{-\infty}^{\infty} \frac{e^{5ix}}{x^2+1}\, dx = 2\pi i \cdot \frac{e^{-5}}{2i} = \pi e^{-5}$.

::: pf-proof

Steps [](#s2){.pf-ref} and [](#s3){.pf-ref}.

:::

:::

::: {.pf-step #s5}

Therefore $\int_0^\infty \frac{\cos 5x}{x^2+1}\, dx = \frac{1}{2}\operatorname{Re}(\pi e^{-5}) = \frac{\pi}{2} e^{-5}$.

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s4){.pf-ref}.

:::

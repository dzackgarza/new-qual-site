::: {.problem}
Explain why each of the following is not metrizable:

1. the Sorgenfrey line;
2. the one-point compactification of an uncountable discrete space;
3. the product of uncountably many copies of $\NN$ with the discrete topology.

Then explain:

1. why every compact Hausdorff space is completely regular;
2. why every completely regular Hausdorff space is homeomorphic to a subspace of a compact Hausdorff space.
:::

::: {.solution}

## The Sorgenfrey line

Let
\[
\mathbb S
\]
denote \(\RR\) with the lower-limit topology generated by the half-open
intervals
\[
[a,b).
\]

::: pf

::: {.pf-step #s1-1}

The Sorgenfrey line is separable.


::: pf-proof

The rationals \(\QQ\) are countable. Every nonempty basic open set
\[
[a,b)
\]
with \(a<b\) contains a rational number. Hence \(\QQ\) is dense in
\(\mathbb S\).

:::

:::

::: {.pf-step #s1-2}

The Sorgenfrey line is not second countable.


::: pf-proof

Suppose
\[
\mathcal B
\]
were a countable basis.

For each \(x\in\RR\), choose
\[
B_x\in\mathcal B
\]
such that
\[
x\in B_x\subseteq[x,x+1).
\]
This is possible because \([x,x+1)\) is open.

If \(x<y\) and
\[
B_x=B_y,
\]
then the common set contains \(x\) because it equals \(B_x\), but it is
contained in
\[
[y,y+1)
\]
because it equals \(B_y\). This is impossible since \(x<y\).

Thus
\[
x\longmapsto B_x
\]
is injective from the uncountable set \(\RR\) into \(\mathcal B\),
contradicting countability.

:::

:::

::: {.pf-step #s1-3}

Every separable metric space is second countable.


::: pf-proof

Let \(D\) be a countable dense subset of a metric space \((X,d)\). The
family
\[
\{B(q,r):q\in D,\ r\in\QQ_{>0}\}
\]
is countable.

Given an open set \(U\) and a point \(x\in U\), choose
\[
\varepsilon>0
\]
with
\[
B(x,\varepsilon)\subseteq U.
\]
Pick \(q\in D\) with
\[
d(x,q)<\varepsilon/3
\]
and rational \(r\) with
\[
d(x,q)<r<2\varepsilon/3.
\]
Then
\[
x\in B(q,r)\subseteq B(x,\varepsilon)\subseteq U.
\]
Hence the displayed family is a countable basis.

:::

:::

::: {.pf-step #s1-4}

Therefore the Sorgenfrey line is not metrizable.


::: pf-proof

If it were metrizable, step [](#s1-1){.pf-ref} and step [](#s1-3){.pf-ref} would make it second
countable, contradicting step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-5}

Every compact subset of \(D\) is finite.


::: pf-proof

An infinite subset \(K\subseteq D\) has the open cover by its singleton
sets
\[
\{\{x\}:x\in K\},
\]
which has no finite subcover. Hence an infinite subset cannot be compact.
Finite subsets are compact.

:::

:::

::: pf-step

The neighborhoods of \(\infty\) are exactly the sets containing
\[
\boxed{
\{\infty\}\cup(D-F)}
\]
for some finite \(F\subseteq D\).


::: pf-proof

By definition of the one-point compactification, a basic neighborhood of
\(\infty\) is the complement of a compact subset of \(D\). Apply step
[](#s1-5){.pf-ref}.

:::

:::

::: {.pf-step #s1-7}

The space \(D^*\) is not first countable at \(\infty\).


::: pf-proof

Suppose
\[
U_1,U_2,\dots
\]
were a countable local base at \(\infty\).

For each \(n\), choose a finite set \(F_n\subseteq D\) such that
\[
\{\infty\}\cup(D-F_n)\subseteq U_n.
\]
The union
\[
F=\bigcup_{n=1}^{\infty}F_n
\]
is countable. Since \(D\) is uncountable, choose
\[
d\in D-F.
\]

The set
\[
V=D^*-\{d\}
\]
is a neighborhood of \(\infty\), because \(\{d\}\) is finite.

But
\[
d\notin F_n
\]
for every \(n\), so
\[
d\in U_n
\]
for every \(n\). Hence
\[
U_n\nsubseteq V
\]
for every \(n\), contradicting the local-base property.

:::

:::

::: {.pf-step #s1-8}

Therefore \(D^*\) is not metrizable.


::: pf-proof

Every metric space is first countable: the balls
\[
B(x,1/n)
\]
form a countable local base at each point. Step [](#s1-7){.pf-ref} shows this fails at
\(\infty\).

:::

:::

::: {.pf-step #s1-9}

Fix \(x\in X\). Suppose
\[
B_1,B_2,\dots
\]
were a countable local base at \(x\).


::: pf-proof

We will derive a contradiction.

:::

:::

::: pf-step

For every \(n\), choose a basic product neighborhood
\[
C_n
\]
with
\[
x\in C_n\subseteq B_n.
\]


::: pf-proof

Basic product neighborhoods form a basis for the product topology.

:::

:::

::: pf-step

Let \(F_n\subseteq I\) be the finite set of coordinates restricted by
\(C_n\). Then
\[
F=\bigcup_{n=1}^{\infty}F_n
\]
is countable.


::: pf-proof

Each \(F_n\) is finite by the definition of the product topology, and a
countable union of finite sets is countable.

:::

:::

::: pf-step

Choose
\[
j\in I-F.
\]


::: pf-proof

The index set \(I\) is uncountable while \(F\) is countable.

:::

:::

::: pf-step

The set
\[
U=\{y\in X:y_j=x_j\}
\]
is an open neighborhood of \(x\).


::: pf-proof

It is the inverse image of the open singleton
\[
\{x_j\}\subseteq\NN_j
\]
under the coordinate projection.

:::

:::

::: {.pf-step #s1-14}

No \(C_n\) is contained in \(U\).


::: pf-proof

Since
\[
j\notin F_n,
\]
the basic neighborhood \(C_n\) imposes no condition on coordinate \(j\).
Thus \(C_n\) contains a point \(y\) with
\[
y_j\ne x_j,
\]
so
\[
y\in C_n-U.
\]

:::

:::

::: pf-step

Therefore no \(B_n\) is contained in \(U\).


::: pf-proof

If
\[
B_n\subseteq U,
\]
then
\[
C_n\subseteq B_n\subseteq U,
\]
contradicting step [](#s1-14){.pf-ref}.

:::

:::

::: {.pf-step #s1-16}

Hence \(X\) is not first countable.


::: pf-proof

The neighborhood \(U\) of \(x\) contains no local-base element \(B_n\),
contradicting the assumption in step [](#s1-9){.pf-ref}.

:::

:::

::: {.pf-step #s1-17}

Therefore \(X\) is not metrizable.


::: pf-proof

Metric spaces are first countable, while \(X\) is not by step [](#s1-16){.pf-ref}.

:::

:::

::: {.pf-step #s1-18}

Every compact Hausdorff space is normal.


::: pf-proof

Let \(A,B\) be disjoint closed subsets of a compact Hausdorff space \(X\).
They are compact.

For each \(a\in A\) and \(b\in B\), choose disjoint open neighborhoods of
\(a\) and \(b\). Compactness first gives, for each \(a\), an open
neighborhood \(U_a\) of \(a\) whose closure misses \(B\); compactness of
\(A\) then gives finitely many such \(U_a\). Their union is an open
neighborhood of \(A\) whose closure misses \(B\), yielding disjoint open
neighborhoods of \(A\) and \(B\).

:::

:::

::: {.pf-step #s1-19}

Every compact Hausdorff space is completely regular.


::: pf-proof

Let \(X\) be compact Hausdorff, let \(x\in X\), and let \(F\subseteq X\) be
closed with
\[
x\notin F.
\]
By step [](#s1-18){.pf-ref}, \(X\) is normal. Since Hausdorff spaces are \(T_1\), the
singleton \(\{x\}\) is closed.

Urysohn's lemma gives a continuous function
\[
f:X\to[0,1]
\]
such that
\[
f(x)=0
\]
and
\[
f|_F=1.
\]
This is exactly complete regularity.

:::

:::

::: {.pf-step #s1-20}

Define the evaluation map
\[
e:X\to[0,1]^{\mathcal C}
\]
by
\[
\boxed{
e(x)=(f(x))_{f\in\mathcal C}}.
\]


::: pf-proof

For each \(x\), the tuple of values \(f(x)\) is an element of the product
cube.

:::

:::

::: {.pf-step #s1-21}

The map \(e\) is continuous.


::: pf-proof

For every coordinate projection
\[
\pi_f:[0,1]^{\mathcal C}\to[0,1],
\]
one has
\[
\pi_f\circ e=f,
\]
which is continuous. The product topology is the coarsest topology making all
coordinate projections continuous, so \(e\) is continuous.

:::

:::

::: {.pf-step #s1-22}

The map \(e\) is injective.


::: pf-proof

Let
\[
x\ne y.
\]
Since \(X\) is Hausdorff, the singleton \(\{y\}\) is closed. Complete
regularity gives a continuous function
\[
f:X\to[0,1]
\]
with
\[
f(x)=0
\]
and
\[
f(y)=1.
\]
Thus the \(f\)-coordinates of \(e(x)\) and \(e(y)\) differ, so
\[
e(x)\ne e(y).
\]

:::

:::

::: {.pf-step #s1-23}

The topology on \(X\) is the topology induced from the cube via
\(e\).


::: pf-proof

Let \(U\subseteq X\) be open and let \(x\in U\). The set
\[
F=X-U
\]
is closed and does not contain \(x\).

By complete regularity, choose
\[
f:X\to[0,1]
\]
with
\[
f(x)=0
\]
and
\[
f|_F=1.
\]
Then
\[
W=\pi_f^{-1}\bigl([0,1/2)\bigr)
\]
is open in the cube,
\[
e(x)\in W,
\]
and
\[
e^{-1}(W)
=
\{y:f(y)<1/2\}
\subseteq U.
\]
Thus every open neighborhood in \(X\) contains the inverse image of a cube
neighborhood. Together with continuity of \(e\), this proves that \(e\) is a
topological embedding.

:::

:::

::: {.pf-step #s1-24}

The cube
\[
[0,1]^{\mathcal C}
\]
is compact Hausdorff.


::: pf-proof

Each factor \([0,1]\) is compact Hausdorff. Tychonoff's theorem gives
compactness of the product, and an arbitrary product of Hausdorff spaces is
Hausdorff.

:::

:::

::: {.pf-step #s1-25}

Therefore every completely regular Hausdorff space is homeomorphic to
a subspace of a compact Hausdorff space.


::: pf-proof

By steps [](#s1-20){.pf-ref} through [](#s1-23){.pf-ref}, \(e\) is a homeomorphism from \(X\) onto the subspace
\[
e(X)\subseteq[0,1]^{\mathcal C}.
\]
By step [](#s1-24){.pf-ref}, the ambient cube is compact Hausdorff.

:::

:::

[](#s1-25){.pf-ref} proves the compact Hausdorff embedding statement.

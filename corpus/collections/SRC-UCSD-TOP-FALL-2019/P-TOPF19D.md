::: {.problem}
When $n$ is even, show that any continuous map $f : \mathbb{CP}^n \to \mathbb{CP}^n$ has a fixed point.
:::

::: {.solution}

::: pf

::: pf-step

Let $x\in H^2(\mathbb{CP}^n;\mathbb Q)$ be the standard generator. Then $f^*x=ax$ for some $a\in\mathbb Q$.

::: pf-proof

$H^2(\mathbb{CP}^n;\mathbb Q)$ is one-dimensional.

:::

:::

::: pf-step

The Lefschetz number is
$$L(f)=1+a+a^2+\cdots+a^n.$$

::: pf-proof

Since $H^{2k}$ is generated by $x^k$, $f^*$ acts there by $a^k$, and odd cohomology vanishes.

:::

:::

::: pf-step

If $n$ is even, $1+a+\cdots+a^n\ne0$ for every real $a$.

::: pf-proof

For $a\ge0$ it is positive. For $a<0$, write $a=-t$ with $t>0$. Then $1-t+t^2-\cdots-t^{n-1}+t^n=(t^{n+1}+1)/(t+1)>0$ because $n+1$ is odd.

:::

:::

::: pf-step

Hence $L(f)\ne0$, so $f$ has a fixed point.

::: pf-proof

By the Lefschetz fixed-point theorem, a fixed-point-free self-map of a finite CW complex has Lefschetz number zero.

:::

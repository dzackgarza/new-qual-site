::: {.problem}
Let $\DD$ denote the open unit disk in the complex plane.
Does there exist an analytic function $f:\DD\to\DD$ such that

(i) $f(1/2)=3/4$,

(ii) $f'(1/2)=2/3$?
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on it. The one input is the Schwarz--Pick estimate: for analytic $f:\DD\to\DD$ and $a\in\DD$,
$$
\abs{f'(a)}\le\frac{1-\abs{f(a)}^{2}}{1-\abs{a}^{2}} .
$$

::: pf

::: {.pf-step #bound}
Any analytic $f:\DD\to\DD$ with $f(1/2)=3/4$ satisfies $\abs{f'(1/2)}\le7/12$.

::: pf-proof
Apply the Schwarz--Pick estimate at $a=1/2$, where $\abs{a}^{2}=1/4$ and $\abs{f(a)}^{2}=9/16$:
$$
\abs{f'(1/2)}\le\frac{1-9/16}{1-1/4}=\frac{7/16}{3/4}=\frac{7}{16}\cdot\frac{4}{3}=\frac{7}{12}.
$$
:::

:::

::: {.pf-step #exceeds}
$2/3>7/12$.

::: pf-proof
$2/3=8/12$ and $8>7$.
:::

:::

::: {.pf-step}
No analytic $f:\DD\to\DD$ satisfies both conditions.

::: pf-proof
If such an $f$ existed, step [](#bound){.pf-ref} would give $\abs{f'(1/2)}\le7/12$, while the second condition asks for $f'(1/2)=2/3$ with modulus $2/3$, which step [](#exceeds){.pf-ref} shows is larger. So the two conditions are incompatible, and the answer to the question is no.
:::

::: {.problem}
Does there exist a conformal mapping of the region
$$
\Omega_1=\{z\in\CC:\ \abs{z-1}<\tfrac12\}
$$
onto the region
$$
\Omega_2=\{z\in\CC:\ \abs{z+1}>1\}?
$$
:::

::: {.solution}

No retained solution set covers this exercise: the collection's provenance is the exam paper (`assets/attachments/Complex_Analysis_Spring_2018.docx`, with the PDF rendering) and no solutions sheet accompanies it, so the argument below is the card's own. It uses three standard facts, each recorded as a step: a convex region is simply connected, a holomorphic function with holomorphic inverse is a homeomorphism, and the integral of $dz/z$ over a null-homotopic loop vanishes.

Throughout, $\Omega_{1}=\theset{z\in\CC\mid\abs{z-1}<\tfrac12}$ and $\Omega_{2}=\theset{z\in\CC\mid\abs{z+1}>1}$, and a conformal mapping of one region onto another means a bijective holomorphic map whose inverse is holomorphic.

::: pf

::: {.pf-step #omega-one}
$\Omega_{1}$ is simply connected.

::: pf-proof
$\Omega_{1}$ is an open disc, hence convex: for $z,z'\in\Omega_{1}$ and $0\leq t\leq1$ the point $(1-t)z+tz'$ satisfies
$$
\abs{(1-t)z+tz'-1}\leq(1-t)\abs{z-1}+t\abs{z'-1}<\tfrac12.
$$
In a convex region the linear homotopy $H(s,t)=(1-t)\gamma(s)+t\gamma(0)$ deforms any loop $\gamma$ to the constant loop at $\gamma(0)$ inside the region, so every loop is null-homotopic and the region is simply connected.
:::

:::

::: {.pf-step #inversion}
$z\mapsto\dfrac{1}{z+1}$ is a biholomorphism of $\Omega_{2}$ onto the punctured unit disc $\DD^{*}=\theset{w\mid 0<\abs{w}<1}$.

:::: pf-proof

::: {.pf-step #well-defined}
$\varphi(z)\coloneqq\frac{1}{z+1}$ is holomorphic and injective on $\Omega_{2}$, with $\varphi(\Omega_{2})\subset\DD^{*}$.

::: pf-proof
On $\Omega_{2}$ one has $\abs{z+1}>1>0$, so $z+1$ never vanishes and $\varphi$ is holomorphic there; it is injective because $\frac{1}{z+1}=\frac{1}{z'+1}$ gives $z+1=z'+1$. And $0<\abs{\varphi(z)}=\frac{1}{\abs{z+1}}<1$.
:::

:::

::: {.pf-step #onto}
Every point of $\DD^{*}$ is $\varphi(z)$ for some $z\in\Omega_{2}$.

::: pf-proof
Given $w$ with $0<\abs{w}<1$, put $z\coloneqq\frac{1}{w}-1$, which is defined since $w\neq0$; then $\abs{z+1}=\frac{1}{\abs{w}}>1$, so $z\in\Omega_{2}$, and $\varphi(z)=w$.
:::

:::

::: {.pf-step #inverse}
The inverse $w\mapsto\frac1w-1$ is holomorphic on $\DD^{*}$.

::: pf-proof
$w\neq0$ on $\DD^{*}$, so $\frac1w$ is holomorphic there, and subtracting the constant $1$ preserves holomorphy.
:::

:::

::::

:::

::: {.pf-step #punctured-not-simply-connected}
$\DD^{*}$ is not simply connected.

::: pf-proof
Let $\gamma(t)\coloneqq\frac12\mathrm{e}^{2\pi it}$ for $0\leq t\leq1$, a closed loop in $\DD^{*}$ since $\abs{\gamma(t)}=\frac12$. Then
$$
\int_{\gamma}\frac{dz}{z}=\int_{0}^{1}\frac{\gamma'(t)}{\gamma(t)}dt=\int_{0}^{1}2\pi i\,dt=2\pi i\neq0,
$$
because $\gamma'(t)=\pi i\,\mathrm{e}^{2\pi it}$ and $\gamma(t)=\frac12\mathrm{e}^{2\pi it}$. If $\gamma$ were null-homotopic in $\DD^{*}$, Cauchy's theorem applied to the holomorphic function $\frac1z$ along a homotopy through loops in $\DD^{*}$ would give $\int_{\gamma}\frac{dz}{z}=0$, since the homotopy stays in a region on which $\frac1z$ is holomorphic. The contradiction shows $\gamma$ is not null-homotopic, so $\DD^{*}$ is not simply connected.
:::

:::

::: {.pf-step #omega-two}
$\Omega_{2}$ is not simply connected.

::: pf-proof
$\varphi$ is a biholomorphism, hence a homeomorphism, so it carries loops in $\Omega_{2}$ to loops in $\DD^{*}$ and homotopies between them to homotopies between them. If $\Omega_{2}$ were simply connected, every loop there would be null-homotopic, and applying $\varphi$ would show every loop in $\DD^{*}$ null-homotopic, contradicting step [](#punctured-not-simply-connected){.pf-ref}. So $\Omega_{2}$ is not simply connected.
:::

:::

::: pf-step
Therefore
$$
\boxed{\text{no such conformal mapping exists.}}
$$

::: pf-proof
A conformal mapping $\Omega_{1}\to\Omega_{2}$ is in particular a homeomorphism, so it would carry the simple connectivity of $\Omega_{1}$ from step [](#omega-one){.pf-ref} to $\Omega_{2}$: the image of a null-homotopy of a loop is a null-homotopy of the image loop. But $\Omega_{2}$ is not simply connected by step [](#omega-two){.pf-ref}. Hence no conformal mapping of $\Omega_{1}$ onto $\Omega_{2}$ exists.
:::

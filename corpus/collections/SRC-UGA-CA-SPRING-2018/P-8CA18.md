::: {.problem}
Find all holomorphic functions $f:\CC\setminus\{0\}\to\CC$ such that
$$
\abs{f(z)}<\bigl(\abs{z}^{1/2}+\abs{z}^{-1/2}\bigr)
$$
for all $z\neq 0$.
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.

Let $f:\CC^*\to\CC$ be holomorphic with $\abs{f(z)}<\abs{z}^{1/2}+\abs{z}^{-1/2}$ for all $z\ne0$, and put $M(R)=R^{1/2}+R^{-1/2}$.

::: pf

::: {.pf-step #laurent}
$f(z)=\sum_{n\in\ZZ}a_nz^n$ on $\CC^*$, and $\abs{a_n}\le M(R)R^{-n}$ for every $R>0$ and every $n$.

::: pf-proof
$f$ is holomorphic on the annulus $\CC^*$, so it has a Laurent expansion there converging locally uniformly. For $n\in\ZZ$ the coefficient is $a_n=\frac1{2\pi i}\oint_{\abs{z}=R}\frac{f(z)}{z^{n+1}}dz$, so
$$
\abs{a_n}\le\frac1{2\pi}\cdot2\pi R\cdot\frac{M(R)}{R^{n+1}}=\frac{M(R)}{R^n},
$$
using $\abs{f(z)}<M(R)$ on the circle $\abs{z}=R$ and the length $2\pi R$ of that circle.
:::

:::

::: {.pf-step #positive}
$a_n=0$ for every $n\ge1$.

::: pf-proof
By step [](#laurent){.pf-ref}, $\abs{a_n}\le R^{1/2-n}+R^{-1/2-n}$ for every $R>0$. Both exponents of $R$ are negative when $n\ge1$, so the right side tends to $0$ as $R\to\infty$; hence $\abs{a_n}\le0$.
:::

:::

::: {.pf-step #negative}
$a_n=0$ for every $n\le-1$.

::: pf-proof
By step [](#laurent){.pf-ref}, $\abs{a_n}\le R^{1/2-n}+R^{-1/2-n}$ for every $R>0$. Both exponents are positive when $n\le-1$, so the right side tends to $0$ as $R\to0^+$; hence $\abs{a_n}\le0$.
:::

:::

::: {.pf-step #constant}
$f$ is constant, and that constant satisfies $\abs{a_0}<2$.

::: pf-proof
Steps [](#positive){.pf-ref} and [](#negative){.pf-ref} leave only $n=0$, so $f\equiv a_0$. The hypothesis at $R=1$ reads $\abs{a_0}=\abs{f(z)}<\abs{z}^{1/2}+\abs{z}^{-1/2}=2$ for any $z$ with $\abs{z}=1$.
:::

:::

::: {.pf-step #sufficient}
Every constant $c$ with $\abs{c}<2$ satisfies the inequality.

::: pf-proof
For $R=\abs{z}>0$, $2=(R^{1/2})(R^{-1/2})\cdot2\le R^{1/2}+R^{-1/2}$ by AM-GM, so $\abs{c}<2\le R^{1/2}+R^{-1/2}$.
:::

:::

::: {.pf-step}
The solutions are exactly the constant functions $f\equiv c$ with $\abs{c}<2$.

::: pf-proof
Step [](#constant){.pf-ref} shows every solution is a constant of modulus less than $2$, and step [](#sufficient){.pf-ref} shows every such constant is a solution.
:::

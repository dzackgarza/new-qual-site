::: problem
Let $\lambda$ be a fixed complex number with $\operatorname{Re}(\lambda)>1$.
How many solutions does the equation
\[
e^z=z+\lambda
\]
have in the left half-plane $\{z\in\mathbb{C}:\operatorname{Re}(z)<0\}$?
:::

::: solution
Write
\[
F(z)=z+\lambda-e^z.
\]
If $F(z)=0$ and $\operatorname{Re}z<0$, then
\[
|z+\lambda|=|e^z|=e^{\operatorname{Re}z}<1.
\]
Thus every left-half-plane zero lies in the disk
\[
D=\{|z+\lambda|<1\}.
\]
Because $\operatorname{Re}\lambda>1$, this entire disk lies in the left
half-plane.

On $\partial D$,
\[
|e^z|=e^{\operatorname{Re}z}
\le e^{1-\operatorname{Re}\lambda}<1=|z+\lambda|.
\]
Hence Rouché's theorem shows that $F(z)=(z+\lambda)-e^z$ and $z+\lambda$
have the same number of zeros in $D$, namely one, counted with multiplicity.
Therefore the original equation has exactly
\[
\boxed{1}
\]
solution in the left half-plane, counted with multiplicity.
:::

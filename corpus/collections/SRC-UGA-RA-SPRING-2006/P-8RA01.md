::: problem
Define a sequence recursively by $a_{n+1}=\sqrt{2a_n}$, with $a_0>0$.
Prove that for any choice of $a_0>0$, the sequence $\{a_n\}$ converges.
Determine the limit.
:::

::: {.solution}
**Goal.** Show the sequence $a_{n+1} = \sqrt{2a_n}$ with $a_0 > 0$ converges and find its limit.

<1>1. The limit, if it exists, is $2$.
<2>1. If $a_n \to L$, then $L = \sqrt{2L}$.
::: {.proof}
taking limits in $a_{n+1} = \sqrt{2a_n}$ and using continuity of the square root.
:::
<2>2. $L = \sqrt{2L}$ gives $L^2 = 2L$, so $L = 0$ or $L = 2$.
::: {.proof}
square both sides.
:::
<2>3. $L = 2$ (since $a_n > 0$ for all $n$, the limit is $\ge 0$, and $L = 0$ is impossible because $a_n \ge \min(a_0, 2) > 0$).
::: {.proof}
the sequence is bounded below by a positive number, so its limit is positive.
:::

<1>2. The sequence converges.
<2>1. If $a_0 = 2$, then $a_n = 2$ for all $n$.
::: {.proof}
$\sqrt{2 \cdot 2} = 2$.
:::
<2>2. If $0 < a_0 < 2$, then $a_n$ is increasing and bounded above by $2$.
::: {.proof}
$a_{n+1} = \sqrt{2a_n} > a_n$ iff $2a_n > a_n^2$ iff $a_n < 2$; and $a_{n+1} < 2$ iff $2a_n < 4$ iff $a_n < 2$; so by induction $a_n < 2$ and $a_n$ is increasing.
:::
<2>3. If $a_0 > 2$, then $a_n$ is decreasing and bounded below by $2$.
::: {.proof}
$a_{n+1} < a_n$ iff $2a_n < a_n^2$ iff $a_n > 2$; and $a_{n+1} > 2$ iff $2a_n > 4$ iff $a_n > 2$; so by induction $a_n > 2$ and $a_n$ is decreasing.
:::
<2>4. In all cases $a_n$ is monotone and bounded, hence converges.
::: {.proof}
the monotone convergence theorem.
:::

<1>3. Q.E.D.
::: {.proof}
<1>2.4 gives convergence; <1>1.3 gives the limit $2$.
:::
:::

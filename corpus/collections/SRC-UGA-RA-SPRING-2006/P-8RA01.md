::: problem
Define a sequence recursively by $a_{n+1}=\sqrt{2a_n}$, with $a_0>0$.
Prove that for any choice of $a_0>0$, the sequence $\{a_n\}$ converges.
Determine the limit.
:::

::: solution
<1>1. Establish monotonicity and boundedness.
::: proof
If $a_n<2$, then
\[
a_{n+1}>a_n
\iff 2a_n>a_n^2
\iff a_n<2,
\]
and also
\[
a_{n+1}<2
\iff 2a_n<4
\iff a_n<2.
\]
Thus if $0<a_0<2$, the sequence remains below $2$ and is increasing.

Similarly, if $a_n>2$, then
\[
a_{n+1}<a_n
\iff 2a_n<a_n^2
\iff a_n>2,
\]
and
\[
a_{n+1}>2
\iff a_n>2.
\]
Thus if $a_0>2$, the sequence remains above $2$ and is decreasing. If $a_0=2$, it is constant.

Hence in every case $(a_n)$ is monotone and bounded, so it converges.
:::

<1>2. Determine the limit.
::: proof
Let $a_n\to L$. Since every $a_n>0$, and in fact
\[
a_n\ge \min(a_0,2)>0,
\]
we have $L>0$. Passing to the limit in
\[
a_{n+1}=\sqrt{2a_n}
\]
gives
\[
L=\sqrt{2L}.
\]
Therefore
\[
L^2=2L.
\]
Since $L>0$,
\[
\boxed{L=2.}
\]
:::
:::

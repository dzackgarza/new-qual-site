::: problem
Suppose that $\mu$ and $\nu$ are positive finite measures on $(X,\mathcal{M})$, and let $\lambda=\mu+\nu$.
Prove the following:

(a) The map $f\mapsto\int_X f\,d\nu$ is a bounded linear functional on $L^2(\lambda)$.

(b) There exists a function $g\in L^2(\lambda)$ such that
\[
\int_X f\,d\nu=\int_X fg\,d\lambda,
\qquad\text{equivalently}\qquad
\int_X f(1-g)\,d\nu=\int_X fg\,d\mu.
\]

(c) $0\le g\le 1$ $\lambda$-a.e., so we may assume $0\le g\le 1$.

(d) Let $A=\{x:g(x)<1\}$, $B=\{x:g(x)=1\}$, and set $\nu_a(E)=\nu(A\cap E)$, $\nu_s(E)=\nu(B\cap E)$.
Then $\nu_s\perp\mu$ and $\nu_a\ll\mu$; in fact $d\nu_a=g(1-g)^{-1}\chi_A\,d\mu$.
:::

::: solution
<1>1. Prove boundedness of the functional.
::: proof
Define
\[
L(f)=\int_X f\,d\nu.
\]
Since $\nu$ is finite, Cauchy--Schwarz gives
\[
|L(f)|
\le \int_X|f|\,d\nu
\le \nu(X)^{1/2}
\left(\int_X|f|^2\,d\nu\right)^{1/2}.
\]
Because $\nu\le\lambda=\mu+\nu$,
\[
\int_X|f|^2\,d\nu
\le\int_X|f|^2\,d\lambda.
\]
Hence
\[
|L(f)|\le \nu(X)^{1/2}\|f\|_{L^2(\lambda)},
\]
so $L$ is a bounded linear functional on $L^2(\lambda)$.
:::

<1>2. Apply the Riesz representation theorem.
::: proof
Since $L^2(\lambda)$ is a Hilbert space, the Riesz representation theorem gives $g\in L^2(\lambda)$ such that
\[
\int_X f\,d\nu
=\int_X fg\,d\lambda
\]
for every $f\in L^2(\lambda)$. Since $\lambda=\mu+\nu$,
\[
\int_X fg\,d\lambda
=\int_X fg\,d\mu+
\int_X fg\,d\nu.
\]
Therefore
\[
\boxed{
\int_X f(1-g)\,d\nu
=\int_X fg\,d\mu.}
\]
:::

<1>3. Show that $0\le g\le1$ almost everywhere.
::: proof
Because $\lambda$ is finite, $\mathbf1_E\in L^2(\lambda)$ for every measurable $E$. Thus
\[
\int_E g\,d\lambda=\nu(E)\ge0
\]
for every measurable $E$. Taking $E=\{g<0\}$ shows that $g\ge0$ $\lambda$-a.e.

Also
\[
\mu(E)=\lambda(E)-\nu(E)
=\int_E(1-g)\,d\lambda\ge0
\]
for every measurable $E$. Taking $E=\{g>1\}$ gives $1-g\ge0$ $\lambda$-a.e. Hence
\[
\boxed{0\le g\le1\quad\lambda\text{-a.e.}}
\]
and we may modify $g$ on a null set so that this holds everywhere.
:::

<1>4. Identify the singular part.
::: proof
Let
\[
B=\{g=1\}.
\]
Apply the identity from Step 2 with $f=\mathbf1_B$. Since $1-g=0$ on $B$ and $g=1$ on $B$,
\[
0
=\int_B(1-g)\,d\nu
=\int_B g\,d\mu
=\mu(B).
\]
Thus $\mu(B)=0$. By definition,
\[
\nu_s(E)=\nu(B\cap E),
\]
so $\nu_s$ is supported on the $\mu$-null set $B$. Therefore
\[
\boxed{\nu_s\perp\mu.}
\]
:::

<1>5. Identify the absolutely continuous part.
::: proof
Let
\[
A=\{g<1\}
\]
and define
\[
A_n=\left\{g\le1-\frac1n\right\}.
\]
Then $A_n\uparrow A$. Fix a measurable set $E$. On $A_n$, the function
\[
f_n=\frac{\mathbf1_{E\cap A_n}}{1-g}
\]
is bounded by $n$, hence belongs to $L^2(\lambda)$. Substituting $f_n$ into the identity of Step 2 gives
\[
\nu(E\cap A_n)
=\int_{E\cap A_n}\frac{g}{1-g}\,d\mu.
\]
Letting $n\to\infty$ and using monotone convergence on both sides yields
\[
\nu(E\cap A)
=\int_{E\cap A}\frac{g}{1-g}\,d\mu.
\]
Since
\[
\nu_a(E)=\nu(E\cap A),
\]
we obtain
\[
\boxed{
d\nu_a
=\frac{g}{1-g}\chi_A\,d\mu.}
\]
In particular, $\nu_a\ll\mu$.

Thus
\[
\nu=\nu_a+\nu_s,
\qquad
\nu_a\ll\mu,
\qquad
\nu_s\perp\mu,
\]
which is the Lebesgue decomposition of $\nu$ relative to $\mu$.
:::
:::

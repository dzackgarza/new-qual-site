::: problem
Suppose $f\ge 0$ on $\mathbb{R}^d$, and let $E_{2^k}=\{x:f(x)>2^k\}$ and $F_k=\{x:2^k<f(x)\le 2^{k+1}\}$.

(a) Show that $f$ is integrable if and only if
\[
\sum_{k=-\infty}^\infty 2^k m(F_k)<\infty
\quad\text{if and only if}\quad
\sum_{k=-\infty}^\infty 2^k m(E_{2^k})<\infty.
\]

(b) Let $f$ be a nonnegative measurable function on $\mathbb{R}^d$ satisfying
\[
m(\{x:f(x)\ge t\})<\frac{1}{1+t^2},\qquad t>0.
\]
Determine those values of $p$, $1\le p<\infty$, for which $f\in L^p(\mathbb{R}^d)$, and find the minimum value of $p$ for which $f$ may fail to be in $L^p$.
Give an example.
:::

::: solution
<1>1. Compare the integral with the dyadic level-set sum.
::: proof
The sets
\[
F_k=\{2^k<f\le2^{k+1}\}
\]
are pairwise disjoint, and their union is $\{f>0\}$. On $F_k$,
\[
2^k<f\le2^{k+1}.
\]
Therefore
\[
\sum_{k\in\mathbb Z}2^k m(F_k)
\le \int_{\mathbb R^d}f\,dm
\le 2\sum_{k\in\mathbb Z}2^k m(F_k).
\]
Hence
\[
f\in L^1
\quad\Longleftrightarrow\quad
\sum_{k\in\mathbb Z}2^k m(F_k)<\infty.
\]
:::

<1>2. Compare the two dyadic sums.
::: proof
Since
\[
E_{2^k}=\{f>2^k\}=\bigcup_{j\ge k}F_j,
\]
Tonelli's theorem for nonnegative series gives
\[
\begin{aligned}
\sum_{k\in\mathbb Z}2^k m(E_{2^k})
&=\sum_{k\in\mathbb Z}2^k\sum_{j\ge k}m(F_j)\\
&=\sum_{j\in\mathbb Z}m(F_j)\sum_{k\le j}2^k\\
&=\sum_{j\in\mathbb Z}2^{j+1}m(F_j).
\end{aligned}
\]
Thus
\[
\sum_k2^km(E_{2^k})
=2\sum_k2^km(F_k),
\]
so the two series converge or diverge together. This proves all equivalences in part (a).
:::

<1>3. Use the distribution-function formula for $L^p$.
::: proof
For $p>0$, the layer-cake formula applied to $f^p$ gives
\[
\int_{\mathbb R^d}f(x)^p\,dx
=p\int_0^\infty t^{p-1}m(\{f>t\})\,dt.
\]
The hypothesis implies
\[
m(\{f>t\})\le m(\{f\ge t\})<\frac1{1+t^2},
\]
hence
\[
\int f^p
\le p\int_0^\infty\frac{t^{p-1}}{1+t^2}\,dt.
\]
Near $0$ the integrand behaves like $t^{p-1}$, which is integrable for every $p>0$. At infinity it behaves like $t^{p-3}$, which is integrable exactly when
\[
p-3<-1,
\qquad\text{i.e.}\qquad p<2.
\]
Therefore every function satisfying the stated tail bound belongs to
\[
\boxed{L^p(\mathbb R^d)\text{ for every }1\le p<2.}
\]
:::

<1>4. Show that $p=2$ is the sharp threshold.
::: proof
Fix $0<c<1$ and define on $\mathbb R^d$
\[
f(x_1,\ldots,x_d)
=\begin{cases}
\sqrt{c/x_1-1},
&0<x_1<c,\quad 0<x_j<1\ (2\le j\le d),\\
0,&\text{otherwise}.
\end{cases}
\]
For every $t>0$,
\[
f\ge t
\quad\Longleftrightarrow\quad
0<x_1\le\frac{c}{1+t^2},
\quad 0<x_j<1\ (j\ge2),
\]
so
\[
m(\{f\ge t\})
=\frac{c}{1+t^2}
<\frac1{1+t^2}.
\]
However,
\[
\int_{\mathbb R^d}f^2
=\int_0^c\left(\frac c{x_1}-1\right)\,dx_1
=\infty.
\]
Thus a function satisfying the hypothesis may fail to lie in $L^2$, and therefore the minimum possible exponent at which failure can occur is
\[
\boxed{p=2}.
\]
:::

::: problem
Let
\[
f(x)=\sum_{n=1}^\infty \frac{x^{n-1}}{n^2(1+x^n)}.
\]

(a) Prove that $f(x)$ is continuous for $x\ge 0$.

(b) Evaluate $\int_0^1 f(x)\,dx$, justifying all steps of your work, and express your answer in terms of values of the function $\zeta(s)=\sum_{n=1}^\infty n^{-s}$.
:::

::: solution
<1>1. Prove uniform convergence and continuity.
::: proof
For every $x\ge0$ and every $n\ge1$,
\[
0\le \frac{x^{n-1}}{1+x^n}\le1.
\]
Indeed, if $0\le x\le1$, then $x^{n-1}\le1\le1+x^n$, while if $x\ge1$, then
\[
\frac{x^{n-1}}{1+x^n}\le \frac{x^{n-1}}{x^n}=\frac1x\le1.
\]
Hence
\[
\left|\frac{x^{n-1}}{n^2(1+x^n)}\right|\le\frac1{n^2}
\qquad(x\ge0).
\]
Since $\sum_{n=1}^\infty n^{-2}<\infty$, the Weierstrass $M$-test shows that the defining series for $f$ converges uniformly on $[0,\infty)$. Each summand is continuous there, so the uniform limit $f$ is continuous on $[0,\infty)$.
:::

<1>2. Interchange the sum and integral.
::: proof
On $[0,1]$ all summands are nonnegative, so Tonelli's theorem gives
\[
\int_0^1 f(x)\,dx
=\sum_{n=1}^\infty \frac1{n^2}
\int_0^1\frac{x^{n-1}}{1+x^n}\,dx.
\]
For each $n$, set $u=x^n$. Then $du=nx^{n-1}\,dx$, so
\[
\int_0^1\frac{x^{n-1}}{1+x^n}\,dx
=\frac1n\int_0^1\frac{du}{1+u}
=\frac{\log2}{n}.
\]
Therefore
\[
\int_0^1 f(x)\,dx
=\log2\sum_{n=1}^\infty\frac1{n^3}
=\boxed{\zeta(3)\log2}.
\]
:::

::: problem
Let $m_*$ be the exterior Lebesgue measure.
Prove that a set $E$ in $\mathbb{R}^d$ is Carathéodory measurable if and only if $E$ is Lebesgue measurable.

A set $E$ is Carathéodory measurable if $m_*(A)=m_*(A\cap E)+m_*(A\cap E^c)$ for any set $A\subset\mathbb{R}^d$.
A set $E$ is Lebesgue measurable if for any $\varepsilon>0$, there exists an open set $O$ with $E\subset O$ and $m_*(O\setminus E)\le\varepsilon$.
:::

::: solution
Recall first that Lebesgue outer measure is a metric outer measure, hence every Borel set—in particular every open set and every closed cube—is Carathéodory measurable.

<1>1. Lebesgue measurable implies Carathéodory measurable.
::: proof
Assume that $E$ is Lebesgue measurable in the stated open-approximation sense. Fix an arbitrary set $A\subset\mathbb R^d$ and $\varepsilon>0$. Choose an open set $O\supset E$ such that
\[
m_*(O\setminus E)\le\varepsilon.
\]
Since $O$ is Carathéodory measurable,
\[
m_*(A)=m_*(A\cap O)+m_*(A\cap O^c).
\]
Now
\[
A\cap E\subseteq A\cap O,
\]
and
\[
A\cap E^c
\subseteq (A\cap O^c)\cup(O\setminus E).
\]
Therefore, by monotonicity and subadditivity of outer measure,
\[
\begin{aligned}
m_*(A\cap E)+m_*(A\cap E^c)
&\le m_*(A\cap O)+m_*(A\cap O^c)+m_*(O\setminus E)\\
&\le m_*(A)+\varepsilon.
\end{aligned}
\]
Letting $\varepsilon\downarrow0$ gives
\[
m_*(A\cap E)+m_*(A\cap E^c)\le m_*(A).
\]
The reverse inequality follows from subadditivity because
\[
A=(A\cap E)\cup(A\cap E^c).
\]
Hence
\[
m_*(A)=m_*(A\cap E)+m_*(A\cap E^c)
\]
for every $A$, so $E$ is Carathéodory measurable.
:::

<1>2. Prove the converse when $m_*(E)<\infty$.
::: proof
Assume $E$ is Carathéodory measurable and $m_*(E)<\infty$. By the definition of Lebesgue outer measure, for every $\varepsilon>0$ there is an open set $O\supset E$ such that
\[
m(O)<m_*(E)+\varepsilon.
\]
Apply the Carathéodory identity to the set $A=O$:
\[
m(O)=m_*(O\cap E)+m_*(O\cap E^c)
=m_*(E)+m_*(O\setminus E).
\]
Consequently
\[
m_*(O\setminus E)<\varepsilon.
\]
Thus $E$ is Lebesgue measurable in the stated sense.
:::

<1>3. Remove the finite-measure assumption.
::: proof
Let
\[
Q_n=[-n,n]^d,
\qquad
E_n=E\cap Q_n.
\]
Since both $E$ and $Q_n$ are Carathéodory measurable, so is $E_n$, and
\[
m_*(E_n)\le m(Q_n)<\infty.
\]
By Step 2, for each $n$ there is an open set $O_n\supset E_n$ such that
\[
m_*(O_n\setminus E_n)<\varepsilon 2^{-n}.
\]
Set
\[
O=\bigcup_{n=1}^\infty O_n.
\]
Then $O$ is open and $E\subset O$. Moreover,
\[
O\setminus E
\subseteq\bigcup_{n=1}^\infty(O_n\setminus E_n),
\]
so
\[
m_*(O\setminus E)
\le\sum_{n=1}^\infty m_*(O_n\setminus E_n)
<\varepsilon.
\]
Hence $E$ is Lebesgue measurable.

Therefore the two notions of measurability are equivalent.
:::
:::

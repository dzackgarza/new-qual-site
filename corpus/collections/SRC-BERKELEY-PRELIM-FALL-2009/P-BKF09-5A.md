::: {.problem}
Is it possible to find two closed and connected subsets A and B in $\mathbb { R } ^ { 2 }$such that$$A + B = \{ ( x _ { 1 } + x _ { 2 } , y _ { 1 } + y _ { 2 } ) \in \mathbb { R } ^ { 2 } \mid ( x _ { 1 } , y _ { 1 } ) \in A , ( x _ { 2 } , y _ { 2 } ) \in B \}$$

is not closed?
:::

::: {.solution}
Yes; take A to be the x-axis and B to be one of the components of $x y = 1$, so that$A + B$is an open half-plane$( y > 0 \mathrm { ~ o r ~ } y < 0 )$
:::

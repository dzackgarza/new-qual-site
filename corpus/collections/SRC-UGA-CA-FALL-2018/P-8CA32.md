::: {.problem}
Let $f(z)$ be a nonconstant meromorphic function on $\CC$.
A number $\omega\in\CC$ is a period for $f(z)$ if $f(z+\omega)=f(z)$ for all $z$.
Show that any bounded set of periods of $f$ must be finite.
:::

::: {.solution}

The argument is the card's own, by the isolated-zeros argument for periods; no retained set solves this exercise, and the sets searched are recorded in the audit trail.

Let $f$ be a nonconstant meromorphic function on $\CC$, and let $P(f)=\{\omega\in\CC: f(z+\omega)=f(z)\ \text{for all } z\}$ be its set of periods. The set of poles of $f$ is discrete, and $\CC$ minus a discrete closed set is path connected.

::: pf

::: {.pf-step #reductio}
Assume that $f$ has an infinite bounded set of periods; then $f$ is constant.

::: pf-proof

::: {.pf-step #small-periods}
There are distinct periods $\omega_{n}$ of $f$ and nonzero periods $\tau_{n}$ with $\tau_{n}\to0$, where $\tau_{n}=\omega_{n+1}-\omega_{n}$ along a subsequence.

::: pf-proof
An infinite bounded subset of $\CC$ has an accumulation point (Bolzano--Weierstrass), so it contains a sequence of distinct points $\omega_{n}$ converging to some $\omega^{*}$. Passing to that subsequence, $\tau_{n}=\omega_{n+1}-\omega_{n}$ is a difference of two periods, hence a period, and is nonzero because the $\omega_{n}$ are distinct; and $\tau_{n}\to\omega^{*}-\omega^{*}=0$.
:::

:::

::: {.pf-step #derivative-zero}
$f'(z_{0})=0$ at every point $z_{0}$ at which $f$ is holomorphic.

::: pf-proof
Let $z_{0}$ not be a pole. Poles of a meromorphic function are isolated, so for all large $n$ the point $z_{0}+\tau_{n}$ is not a pole either, and periodicity gives $f(z_{0}+\tau_{n})=f(z_{0})$. Hence
$$
f'(z_{0})=\lim_{n\to\infty}\frac{f(z_{0}+\tau_{n})-f(z_{0})}{\tau_{n}}=\lim_{n\to\infty}\frac{0}{\tau_{n}}=0,
$$
the limit being legitimate because $\tau_{n}\to0$ with $\tau_{n}\ne0$.
:::

:::

::: {.pf-step #constant}
$f$ is constant.

::: pf-proof
By step [](#derivative-zero){.pf-ref} the derivative $f'$ vanishes on the open set $\Omega=\CC\setminus\{\text{poles of }f\}$. A holomorphic function with zero derivative on a domain is constant, and $\Omega$ is path connected, being $\CC$ minus a discrete closed set; so $f\equiv c$ on $\Omega$. Then $f-c$ is a meromorphic function vanishing on the nonempty open set $\Omega$, so $f-c\equiv0$ identically on $\CC$ by the identity theorem for meromorphic functions, poles of $f$ included. Hence $f$ is constant, contradicting the hypothesis.
:::

:::

:::

:::

::: {.pf-step #finite}
Every bounded set of periods of $f$ is finite.

::: pf-proof
Suppose $B$ is a bounded set of periods. If $B$ were infinite, step [](#reductio){.pf-ref} would make $f$ constant, contrary to the hypothesis; so $B$ is finite. Equivalently, the period group of a nonconstant meromorphic function has $0$ as an isolated point, and a bounded subset of a subset of $\CC$ accumulating only at infinity is finite.
:::

::: {.problem}
Prove or exhibit a counterexample: If $f(z)$ is an entire function that maps every unbounded sequence to an unbounded sequence, then it is a polynomial.
:::

::: {.solution}

The statement is true.

::: pf

::: {.pf-step #proper}

$\abs{f(z)}\to\infty$ as $\abs{z}\to\infty$.

::: pf-proof

Otherwise there are $M<\infty$ and a sequence $(z_n)$ with $\abs{z_n}\to\infty$ and $\abs{f(z_n)}\le M$ for all $n$. The sequence $(z_n)$ is unbounded and $(f(z_n))$ is bounded, contrary to the hypothesis.

:::

:::

::: {.pf-step #pole}

The function $g(w)=f(1/w)$, holomorphic on $0<\abs{w}<\infty$, has a pole at $w=0$.

::: pf-proof

By Step [](#proper){.pf-ref}, $\abs{g(w)}\to\infty$ as $w\to0$. So the singularity at $0$ is not removable, since $g$ is unbounded near $0$. It is not essential, since by the Casorati–Weierstrass theorem $g$ would then take values arbitrarily close to $0$ at points arbitrarily close to $0$. Hence it is a pole.

:::

:::

::: pf-qed

Write $f(z)=\sum_{n\ge0}c_nz^n$ on $\CC$. Then $g(w)=\sum_{n\ge0}c_nw^{-n}$ on $w\neq0$, and this is the Laurent expansion of $g$ at $0$. By Step [](#pole){.pf-ref} it has only finitely many negative powers, so $c_n=0$ for all large $n$, and $f$ is a polynomial.

:::

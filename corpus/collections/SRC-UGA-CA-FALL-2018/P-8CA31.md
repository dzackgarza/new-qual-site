::: {.problem}
Prove or exhibit a counterexample: If $f(z)$ is an entire function that maps every unbounded sequence to an unbounded sequence, then it is a polynomial.
:::

::: {.solution}

::: pf

::: pf-step

The statement is true: such an $f$ is a polynomial.

::: pf-proof

prove the claim.

:::

:::

::: pf-step

The hypothesis implies $|f(z)| \to \infty$ as $|z| \to \infty$.

::: pf-proof

::: {.pf-step #s2-1}

Suppose not; then there is $M < \infty$ and an unbounded sequence $z_n$ with $|f(z_n)| \le M$.

::: pf-proof

negating "$|f(z)| \to \infty$" gives a bounded subsequence of values along an unbounded sequence.

:::

:::

::: {.pf-step #s2-2}

This contradicts the hypothesis that $f$ maps every unbounded sequence to an unbounded sequence.

::: pf-proof

$\{z_n\}$ is unbounded but $\{f(z_n)\}$ is bounded.

:::

:::

::: pf-step

Hence $|f(z)| \to \infty$ as $|z| \to \infty$.

::: pf-proof

Steps [](#s2-1){.pf-ref} and [](#s2-2){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s3}

An entire function with $|f(z)| \to \infty$ as $|z| \to \infty$ is a polynomial.

::: pf-proof

::: pf-step

Consider $g(w) = f(1/w)$ on $\CC \setminus \{0\}$.

::: pf-proof

change of variable.

:::

:::

::: pf-step

$g$ has a pole (not an essential singularity) at $w = 0$.

::: pf-proof

$|f(z)| \to \infty$ as $|z| \to \infty$ means $|g(w)| \to \infty$ as $w \to 0$, so $g$ has a pole at $0$ (by Casorati–Weierstrass, an essential singularity would make $g$ unbounded in every neighborhood but not tending to $\infty$).

:::

:::

::: pf-step

Hence $g$ has a Laurent expansion $g(w) = \sum_{n=-N}^{\infty} a_n w^n$ with finitely many negative terms.

::: pf-proof

a pole has finite order.

:::

:::

::: pf-step

Therefore $f(z) = g(1/z) = \sum_{n=-N}^{\infty} a_n z^{-n}$ is a polynomial (a finite sum of nonnegative powers of $z$).

::: pf-proof

substitute $w = 1/z$.

:::

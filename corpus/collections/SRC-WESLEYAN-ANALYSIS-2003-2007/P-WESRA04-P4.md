::: {.problem}
Let $f:[0,1]\to[0,1]$ be Lebesgue measurable.
Prove that its graph
$$
\Gamma_f=\{(x,f(x)):x\in[0,1]\}
$$
has measure zero with respect to the completed product measure $m\times m$ on $[0,1]^2$.
:::

::: {.solution}

Let $f\colon[0,1]\to[0,1]$ be Lebesgue measurable,
$\Gamma_f=\{(x,f(x)):x\in[0,1]\}$, and $m\times m$ the completed product
measure on $[0,1]^2$.

::: pf

::: {.pf-step #borelrepresentative}

There is a Borel measurable $h\colon[0,1]\to[0,1]$ with $f=h$ almost
everywhere.

::: pf-proof

Lebesgue measure is the completion of Borel measure, so $f$, being Lebesgue
measurable, is equal almost everywhere to a Borel measurable function;
concretely, for each rational $q$ the set $\{f\le q\}$ is Lebesgue measurable,
hence differs from a Borel set by a null set, and the resulting Borel
$\sigma$-algebra generated by those approximations gives $h$. Then
$N=\{x:f(x)\ne h(x)\}$ is Lebesgue null.

:::

:::

::: {.pf-step #borelgraph}

$\Gamma_h$ is a Borel subset of $[0,1]^2$ and $(m\times m)(\Gamma_h)=0$.

::: pf-proof

The map $\Phi(x,y)=h(x)-y$ is Borel measurable, being a difference of the
Borel function $h\circ\pi_1$ and the continuous $\pi_2$, so
$\Gamma_h=\Phi^{-1}(\{0\})$ is Borel. Its vertical section over $x$ is the
singleton $\{h(x)\}$, of one-dimensional measure $0$, so by Tonelli, which
applies to the nonnegative indicator of the Borel set $\Gamma_h$, $(m\times
m)(\Gamma_h)=\int_0^1m((\Gamma_h)_x)\,dx=\int_0^10\,dx=0$.

:::

:::

::: {.pf-step #null}

$\Gamma_f$ is measurable for the completed product measure and has measure
$0$.

::: pf-proof

If $x\notin N$ then $f(x)=h(x)$ and $(x,f(x))\in\Gamma_h$; so
$\Gamma_f\setminus\Gamma_h\subseteq N\times[0,1]$ and
$\Gamma_h\setminus\Gamma_f\subseteq N\times[0,1]$, giving
$\Gamma_f\subseteq\Gamma_h\cup(N\times[0,1])$. The set $N\times[0,1]$ is a
Borel rectangle of product measure $m(N)\cdot m([0,1])=0$, and $\Gamma_h$ is
null by step [](#borelgraph){.pf-ref}; so $\Gamma_f$ is contained in a null
Borel set, hence has outer measure $0$ and is measurable with respect to the
completed product measure, with $(m\times m)(\Gamma_f)=0$.

:::

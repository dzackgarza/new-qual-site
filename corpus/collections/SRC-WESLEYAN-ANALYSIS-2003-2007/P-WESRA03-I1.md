::: {.problem}
Define the Borel sigma-algebra on $\RR$.
:::

::: {.solution}

The Borel $\sigma$-algebra on $\RR$ is the smallest $\sigma$-algebra
containing every open set:
$$
\boxed{\mathcal B(\RR)=\sigma(\{U\subseteq\RR:U\text{ open}\}).}
$$

::: pf

::: {.pf-step #generators}

$\mathcal B(\RR)$ equals the $\sigma$-algebra generated by the open intervals,
and also that generated by the half-lines $(-\infty,q]$ with $q$ rational.

::: pf-proof

Every open set is a countable union of open intervals with rational endpoints,
since each point of an open set lies in an interval with rational endpoints
inside the set and there are only countably many such intervals. So the
$\sigma$-algebra generated by those intervals contains every open set, and
conversely each such interval is open; hence the two $\sigma$-algebras
coincide with $\mathcal B(\RR)$. Similarly
$(-\infty,q]=\bigcap_{n}(-\infty,q+1/n)$ is a countable intersection of open
rays, so it is Borel, and $(a,b)=(-\infty,b)\cap(\overline{-\infty,a})$ can be
written using half-lines, giving the other generating family.

:::

:::

::: {.pf-step #examples}

Every open set, every closed set, every countable set and every $F_\sigma$ or
$G_\delta$ set is Borel; and $\mathcal B(\RR)$ is generated by countably many
sets.

::: pf-proof

Open sets generate it by definition; closed sets are complements of open sets;
a countable set is a countable union of singletons, each a closed set; and
$F_\sigma$ and $G_\delta$ sets are countable unions or intersections of closed
or open sets. The generating family of half-lines with rational endpoints is
countable, so $\mathcal B(\RR)$ is countably generated, which is why Borel
measures on $\RR$ can be handled by the monotone class theorem.

:::

::: problem
Prove that the essential-supremum norm makes $L^\infty(X)$ a Banach space.
Characterize norm convergence as uniform convergence off one null set.
Prove that simple functions are dense. If $m(X)>0$, prove that compactly supported continuous functions are not dense in $L^\infty(X)$.

The positive-measure qualification in the last assertion is necessary: if $m(X)=0$, then $L^\infty(X)$ is the zero space.
:::

::: {.solution}
<1>1. Completeness of $L^\infty(X)$ and uniform convergence off a null set: <2>1. Let $\{f_n\}$ be a Cauchy sequence in $L^\infty(X, \mu)$.
::: {.proof}
setup.
:::
<2>2. For each $n, m \ge 1$, there exists a null set $E_{n,m} \subset X$ such that $|f_n(x) - f_m(x)| \le \|f_n - f_m\|_{L^\infty}$ for all $x \in X \setminus E_{n,m}$.
::: {.proof}
definition of essential supremum.
:::
<2>3. For each $n \ge 1$, there exists a null set $N_n \subset X$ such that $|f_n(x)| \le \|f_n\|_{L^\infty}$ for all $x \in X \setminus N_n$.
::: {.proof}
definition of essential supremum.
:::
<2>4. The set $E = \left(\bigcup_{n,m=1}^\infty E_{n,m}\right) \cup \left(\bigcup_{n=1}^\infty N_n\right)$ is a countable union of null sets, so $\mu(E) = 0$.
::: {.proof}
countable subadditivity of measure.
:::
<2>5. On $X \setminus E$, for every $\varepsilon > 0$, choosing $N$ such that $\|f_n - f_m\|_{L^\infty} < \varepsilon$ for all $n, m \ge N$ yields:
\[
|f_n(x) - f_m(x)| \le \|f_n - f_m\|_{L^\infty} < \varepsilon \quad \text{for all } x \in X \setminus E.
\]
Thus $\{f_n\}$ is uniformly Cauchy on $X \setminus E$.
::: {.proof}
<2>2 and <2>4. <2>6. Since $\mathbb{C}$ is complete, $\{f_n\}$ converges uniformly on $X \setminus E$ to a function $f: X \to \mathbb{C}$ (defined by $f(x) = \lim f_n(x)$ on $X \setminus E$ and $f(x) = 0$ on $E$).
::: {.proof}
uniform Cauchy sequences of complex-valued functions converge uniformly.
:::
:::
<2>7. As the pointwise limit of measurable functions, $f$ is measurable.
Taking $m \to \infty$ in <2>5 shows $|f_n(x) - f(x)| \le \varepsilon$ on $X \setminus E$ for $n \ge N$, so:
\[
\|f_n - f\|_{L^\infty} \le \sup_{x \in X \setminus E} |f_n(x) - f(x)| \le \varepsilon.
\]
::: {.proof}
definition of $L^\infty$ norm.
:::
<2>8. Thus $f_n \to f$ in $L^\infty(X)$, establishing that $L^\infty(X)$ is a Banach space, and that $f_n \to f$ in $L^\infty$ if and only if $f_n \to f$ uniformly outside a single null set $E$.
::: {.proof}
<2>5 through <2>7.
:::

<1>2. Simple functions are dense in $L^\infty(X)$: <2>1. Let $f \in L^\infty(X)$ and let $\varepsilon > 0$.
::: {.proof}
setup.
:::
<2>2. Off a null set $E_0$, $|f(x)| \le M = \|f\|_{L^\infty}$.
The disk $D(0, M) \subset \mathbb{C}$ can be partitioned into finitely many disjoint Borel subsets $A_1, \dots, A_k$ of diameter less than $\varepsilon$.
::: {.proof}
compactness of the closed disk $\overline{D(0, M)}$.
:::
<2>3. For each $j \in \{1, \dots, k\}$, choose a point $c_j \in A_j$, and let $E_j = f^{-1}(A_j) \cap (X \setminus E_0)$.
::: {.proof}
preimage of measurable sets.
:::
<2>4. The simple function $\phi = \sum_{j=1}^k c_j \mathbf{1}_{E_j}$ satisfies:
\[
|f(x) - \phi(x)| = |f(x) - c_j| \le \operatorname{diam}(A_j) < \varepsilon \quad \text{for all } x \in E_j \subseteq X \setminus E_0.
\]
::: {.proof}
construction of $E_j$ and $A_j$.
:::
<2>5. Thus $\|f - \phi\|_{L^\infty} \le \sup_{x \in X \setminus E_0} |f(x) - \phi(x)| < \varepsilon$, proving that simple functions are dense in $L^\infty(X)$.
::: {.proof}
<2>4.
:::

<1>3. If $m(X)>0$, then $C_c(X)$ is not dense in $L^\infty(X)$.
::: {.proof}
Choose a Lebesgue density point $x_0\in X$. After a rigid motion, write $x=(x_1,\ldots,x_n)$ and define
\[
E:=X\cap\{x_1>x_{0,1}\}.
\]
Because $x_0$ is a density point of $X$, every sufficiently small ball centered at $x_0$ meets both $E$ and $X\setminus E$ in sets of positive measure: each of the two half-balls has half the volume of the full ball, while the portion missing from $X$ is $o(r^n)$.

Set $f=\mathbf 1_E\in L^\infty(X)$. Suppose that some continuous $g:X\to\mathbb C$ satisfied
\[
\|f-g\|_\infty<c<\frac12.
\]
Then outside a null set,
\[
x\in E\implies |g(x)|>1-c>\frac12,
\qquad
x\in X\setminus E\implies |g(x)|<c<\frac12.
\]
Since every neighborhood of $x_0$ contains positive-measure pieces of both $E$ and $X\setminus E$, we can choose sequences $x_k\in E$ and $y_k\in X\setminus E$, avoiding the exceptional null set, with
\[
x_k\to x_0,
\qquad
y_k\to x_0.
\]
Continuity of $g$ then gives simultaneously
\[
|g(x_0)|\ge 1-c>\frac12
\quad\text{and}\quad
|g(x_0)|\le c<\frac12,
\]
a contradiction. Thus no continuous function, and hence no compactly supported continuous function, can approximate $f$ within essential-supremum distance $<1/2$. Therefore $C_c(X)$ is not dense in $L^\infty(X)$ whenever $m(X)>0$.
:::

<1>4. Conclusion: $L^\infty(X)$ is a Banach space, norm convergence is uniform convergence off a null set, simple functions are dense, and for $m(X)>0$ the continuous compactly supported functions are not dense.
::: {.proof}
<1>1, <1>2, and <1>3.
:::
Q.E.D.
:::

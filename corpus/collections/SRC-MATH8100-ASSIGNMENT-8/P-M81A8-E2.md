::: {.problem}
Let $\|f_k\|_2\leq1$ on $[0,1]$.
Analyze almost-everywhere and $L^1$ convergence: prove the limit lies in the closed $L^2$ unit ball, decide whether either hypothesis gives $L^2$ convergence, and prove that almost-everywhere convergence gives $L^1$ convergence.
:::

::: {.solution}
**Goal:** Analyze convergence properties of sequences $(f_k)$ in $L^2([0, 1])$ with $\|f_k\|_{L^2} \le 1$.

::: pf

::: {.pf-step #limit-in-unit-ball-ae}
Limit in the closed $L^2$ unit ball under almost-everywhere convergence:

::: pf-proof
*Proof:*

::: pf-step
Assume $f_k(x) \to f(x)$ for almost every $x \in [0, 1]$.
:::

::: pf-step
The sequence of non-negative functions $|f_k(x)|^2$ converges almost everywhere to $|f(x)|^2$.
:::

::: pf-step
By Fatou's Lemma:
$$\int_0^1 |f(x)|^2\,dx = \int_0^1 \liminf_{k \to \infty} |f_k(x)|^2\,dx \le \liminf_{k \to \infty} \int_0^1 |f_k(x)|^2\,dx \le 1.$$
:::

::: pf-step
Thus $f \in L^2([0, 1])$ and $\|f\|_{L^2} \le 1$, meaning $f$ lies in the closed unit ball of $L^2([0, 1])$.
:::

:::

:::

::: pf-step
The same conclusion holds if $f_k\to f$ in $L^1$.

::: pf-proof
*Proof:*

::: pf-step
Choose a subsequence $(f_{k_j})$ such that
\[
\|f_{k_j}-f\|_1<2^{-j}.
\]
:::

::: pf-step
Tonelli gives
\[
\int_0^1\sum_{j=1}^\infty|f_{k_j}(x)-f(x)|\,dx
=\sum_{j=1}^\infty\|f_{k_j}-f\|_1<\infty.
\]
Hence the series inside the integral is finite for almost every $x$, so
\[
f_{k_j}(x)\to f(x)
\quad\text{for a.e. }x.
\]
:::

::: pf-step
Applying Fatou to this subsequence,
\[
\|f\|_2^2
\le\liminf_{j\to\infty}\|f_{k_j}\|_2^2
\le1.
\]
Thus $f\in L^2([0,1])$ and $\|f\|_2\le1$ also under the $L^1$-convergence hypothesis.
:::

:::

:::

::: pf-step
Neither almost-everywhere nor $L^1$ convergence implies $L^2$ convergence:

::: pf-proof
*Proof:*

::: pf-step
Define the sequence of functions $f_k(x) = \sqrt{k} \, \mathbf{1}_{(0, 1/k]}(x)$ on $[0, 1]$.
:::

::: pf-step
$L^2$ norm calculation:
$$\|f_k\|_{L^2}^2 = \int_0^{1/k} (\sqrt{k})^2\,dx = k \cdot \frac{1}{k} = 1 \implies \|f_k\|_{L^2} = 1 \le 1.$$
:::

::: pf-step
Almost-everywhere convergence: For any fixed $x \in (0, 1]$, choosing $K > 1/x$ ensures that for all $k \ge K$, $1/k < x$, so $f_k(x) = 0$. Thus $f_k(x) \to 0$ almost everywhere on $[0, 1]$.
:::

::: pf-step
$L^1$ convergence:
$$\|f_k - 0\|_{L^1} = \int_0^{1/k} \sqrt{k}\,dx = \sqrt{k} \cdot \frac{1}{k} = \frac{1}{\sqrt{k}} \to 0 \quad \text{as } k \to \infty.$$
:::

::: pf-step
Failure of $L^2$ convergence:
$$\|f_k - 0\|_{L^2} = \|f_k\|_{L^2} = 1 \not\to 0.$$
:::

::: pf-step
Therefore, neither $f_k \to 0$ almost everywhere nor $f_k \to 0$ in $L^1([0, 1])$ guarantees that $f_k \to 0$ in $L^2([0, 1])$.
:::

:::

:::

::: pf-step
Almost-everywhere convergence implies $L^1$ convergence under a uniform $L^2$ bound:

::: pf-proof
*Proof:*

::: pf-step
Assume $f_k \to f$ almost everywhere on $[0, 1]$ and $\|f_k\|_{L^2} \le 1$. By step [](#limit-in-unit-ball-ae){.pf-ref}, $\|f\|_{L^2} \le 1$.
:::

::: pf-step
Let $g_k = f_k - f$. Then $g_k \to 0$ almost everywhere on $[0, 1]$, and by Minkowski's inequality:
$$\|g_k\|_{L^2} \le \|f_k\|_{L^2} + \|f\|_{L^2} \le 1 + 1 = 2.$$
:::

::: pf-step
For any measurable set $E \subseteq [0, 1]$, applying the Cauchy–Schwarz inequality yields:
$$\int_E |g_k(x)|\,dx \le \left( \int_E 1^2\,dx \right)^{1/2} \left( \int_E |g_k(x)|^2\,dx \right)^{1/2} \le \sqrt{m(E)} \cdot \|g_k\|_{L^2} \le 2\sqrt{m(E)}.$$
:::

::: pf-step
Thus the family $\{g_k\}$ is uniformly integrable: for any $\varepsilon > 0$, choosing $\delta = (\varepsilon / 4)^2 > 0$ guarantees that $\int_E |g_k| < \varepsilon / 2$ whenever $m(E) < \delta$, uniformly for all $k$.
:::

::: pf-step
By Egorov's Theorem, there exists a measurable set $A \subset [0, 1]$ such that $m([0, 1] \setminus A) < \delta$ and $g_k \to 0$ uniformly on $A$.
:::

::: pf-step
Split the $L^1$ norm:
$$\int_0^1 |g_k(x)|\,dx = \int_A |g_k(x)|\,dx + \int_{[0, 1] \setminus A} |g_k(x)|\,dx \le \sup_{x \in A} |g_k(x)| \cdot m(A) + 2\sqrt{m([0, 1] \setminus A)}.$$
:::

::: pf-step
Since $g_k \to 0$ uniformly on $A$, there exists $K$ such that $\sup_{x \in A} |g_k(x)| < \varepsilon / 2$ for all $k \ge K$.
:::

::: pf-step
Thus for all $k \ge K$:
$$\|f_k - f\|_{L^1} = \int_0^1 |g_k(x)|\,dx < \frac{\varepsilon}{2} + 2\sqrt{\delta} = \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.$$
:::

::: pf-step
Therefore $\|f_k - f\|_{L^1} \to 0$ as $k \to \infty$.
:::

:::

:::

::: pf-qed
*Proof:*

The limit lies in the closed $L^2$ unit ball; neither a.e. nor $L^1$ convergence forces $L^2$ convergence; and a.e. convergence combined with the uniform $L^2$ bound implies $L^1$ convergence.
:::

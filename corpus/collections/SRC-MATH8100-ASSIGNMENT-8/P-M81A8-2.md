::: problem
For measurable $X$ with $0<m(X)<\infty$, prove the strict inclusions $L^\infty(X)\subset L^2(X)\subset L^1(X)$. For every measurable $X$ of finite measure, prove the associated norm inequalities.
Give counterexamples for infinite-measure spaces and prove that $L^2(X)\subseteq L^1(X)$ forces $m(X)<\infty$.
Also prove $L^1\cap L^\infty\subset L^2\subset L^1+L^\infty$ and the interpolation inequality.
:::

::: solution
<1>1. Finite-measure inclusions and norm bounds.
::: proof
Assume $m(X)<\infty$. By Cauchy--Schwarz,
\[
\|f\|_1
=\int_X|f|\cdot1
\le \|f\|_2\,m(X)^{1/2}.
\]
Also
\[
\|f\|_2^2
=\int_X|f|^2
\le \|f\|_\infty^2m(X),
\]
so
\[
\|f\|_2\le m(X)^{1/2}\|f\|_\infty.
\]
Combining these gives
\[
\boxed{
\|f\|_1\le m(X)^{1/2}\|f\|_2
\le m(X)\|f\|_\infty.}
\]
Thus
\[
L^\infty(X)\subseteq L^2(X)\subseteq L^1(X).
\]

To prove strictness for an arbitrary measurable $X\subset\mathbb R^n$ with $0<m(X)<\infty$, use non-atomicity of Lebesgue measure to choose pairwise disjoint measurable sets $E_k\subset X$ with
\[
m(E_k)=c4^{-k}
\]
for some $c>0$. Then
\[
u=\sum_{k\ge1}2^{k/2}\mathbf1_{E_k}
\]
satisfies
\[
\|u\|_2^2
=c\sum_{k\ge1}2^{-k}<\infty,
\]
but $u$ is unbounded, so $u\in L^2\setminus L^\infty$.

For the other strict inclusion, set
\[
w=\sum_{k\ge1}\frac{2^k}{\sqrt{k}}\mathbf1_{E_k}.
\]
Then
\[
\|w\|_1=c\sum_{k\ge1}\frac{2^{-k}}{\sqrt{k}}<\infty,
\qquad
\|w\|_2^2=c\sum_{k\ge1}\frac1k=\infty.
\]
Thus $w\in L^1\setminus L^2$, and both inclusions are strict.
:::

<1>2. No analogous inclusion chain holds on arbitrary infinite-measure sets.
::: proof
On $X=\mathbb R$,
\[
1\in L^\infty\setminus L^2,
\]
so $L^\infty\subseteq L^2$ fails. Also
\[
\frac1{1+|x|}\in L^2(\mathbb R)\setminus L^1(\mathbb R),
\]
so $L^2\subseteq L^1$ fails, while
\[
x^{-2/3}\mathbf1_{(0,1)}(x)
\in L^1(\mathbb R)\setminus L^2(\mathbb R),
\]
so the reverse inclusion $L^1\subseteq L^2$ also fails.
:::

<1>3. If $L^2(X)\subseteq L^1(X)$, then $m(X)<\infty$.
::: proof
Suppose instead that $m(X)=\infty$. Since Lebesgue measure is $\sigma$-finite and non-atomic, choose pairwise disjoint measurable sets $E_k\subset X$ such that
\[
0<m(E_k)<\infty
\]
and, after grouping if necessary,
\[
m(E_k)\ge1
\qquad(k\ge1).
\]
Define
\[
f=\sum_{k=1}^\infty \frac1{k\,m(E_k)^{1/2}}\mathbf1_{E_k}.
\]
Then
\[
\|f\|_2^2
=\sum_{k=1}^\infty\frac1{k^2}<\infty,
\]
whereas
\[
\|f\|_1
=\sum_{k=1}^\infty\frac{m(E_k)^{1/2}}k
\ge\sum_{k=1}^\infty\frac1k
=\infty.
\]
Thus $f\in L^2(X)\setminus L^1(X)$, a contradiction. Hence $m(X)<\infty$.
:::

<1>4. The interpolation inclusion $L^1\cap L^\infty\subseteq L^2$.
::: proof
If $f\in L^1(X)\cap L^\infty(X)$, then
\[
\|f\|_2^2
=\int_X|f|^2
\le \|f\|_\infty\int_X|f|
=\|f\|_\infty\|f\|_1.
\]
Therefore
\[
\boxed{
\|f\|_2\le\|f\|_1^{1/2}\|f\|_\infty^{1/2}}
\]
and in particular $f\in L^2(X)$.
:::

<1>5. Every $L^2$ function is a sum of an $L^1$ function and an $L^\infty$ function.
::: proof
For $f\in L^2(X)$, split
\[
f=f\mathbf1_{\{|f|>1\}}+f\mathbf1_{\{|f|\le1\}}.
\]
Set
\[
g=f\mathbf1_{\{|f|>1\}},
\qquad
h=f\mathbf1_{\{|f|\le1\}}.
\]
Then $h\in L^\infty$ with $\|h\|_\infty\le1$, while on $\{|f|>1\}$ one has $|f|\le|f|^2$, so
\[
\|g\|_1
\le\int_X|f|^2<\infty.
\]
Hence
\[
f=g+h\in L^1(X)+L^\infty(X).
\]
:::

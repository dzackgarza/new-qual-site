::: problem
Let $1\leq p\leq\infty$ and suppose $\sum_k\|f_k\|_p<\infty$.
Prove that $\sum_kf_k$ converges almost everywhere to an $L^p$ function and that $\|\sum_kf_k\|_p\leq\sum_k\|f_k\|_p$.
:::

::: solution
Set
\[
M=\sum_{k=1}^\infty\|f_k\|_p<\infty.
\]

<1>1. Suppose $1\le p<\infty$.
::: proof
For $N\ge1$, define
\[
G_N=\sum_{k=1}^N|f_k|.
\]
By Minkowski's inequality,
\[
\|G_N\|_p
\le\sum_{k=1}^N\|f_k\|_p
\le M.
\]
Since $G_N\uparrow G:=\sum_{k=1}^\infty|f_k|$ pointwise, monotone convergence applied to $G_N^p$ gives
\[
\|G\|_p^p
=\int G^p
=\lim_{N\to\infty}\int G_N^p
\le M^p.
\]
Thus $G\in L^p$, so
\[
G(x)<\infty
\]
for almost every $x$. At each such $x$ the numerical series
\[
\sum_{k=1}^\infty f_k(x)
\]
converges absolutely. Let its sum be $f(x)$ on this full-measure set, and define $f=0$ on the remaining null set. Then
\[
|f|\le G
\]
almost everywhere, hence $f\in L^p$ and
\[
\|f\|_p\le\|G\|_p\le M.
\]
Therefore
\[
\boxed{
\left\|\sum_{k=1}^\infty f_k\right\|_p
\le\sum_{k=1}^\infty\|f_k\|_p.}
\]
:::

<1>2. Suppose $p=\infty$.
::: proof
Choose representatives so that for each $k$,
\[
|f_k(x)|\le\|f_k\|_\infty
\]
outside a null set $N_k$. The union
\[
N=\bigcup_{k=1}^\infty N_k
\]
is null. For $x\notin N$,
\[
\sum_{k=1}^\infty|f_k(x)|
\le\sum_{k=1}^\infty\|f_k\|_\infty
=M.
\]
Hence the series converges absolutely for every $x\notin N$ to a function $f$, and
\[
|f(x)|\le M
\]
there. Thus $f\in L^\infty$ and
\[
\boxed{
\|f\|_\infty
\le\sum_{k=1}^\infty\|f_k\|_\infty.}
\]
:::
:::

::: problem
Show that if $\xi\in \RR$, then
\[
\int_{-\infty}^{\infty} \frac{e^{-2 \pi i x \xi}}{\left(1+x^{2}\right)^{2}} d x=\frac{\pi}{2}(1+2 \pi|\xi|) e^{-2 \pi|\xi|}
.\]
:::

::: {.solution}
<1>1. Symmetry reduction to $a = 2\pi |\xi| \ge 0$:
<2>1. Substituting $u = -x$ shows that $I(\xi) = \int_{-\infty}^\infty \frac{e^{-2\pi i x \xi}}{(1+x^2)^2}\,dx$ is an even function of $\xi$:
\[
I(-\xi) = \int_{-\infty}^\infty \frac{e^{2\pi i x \xi}}{(1+x^2)^2}\,dx = \int_{-\infty}^\infty \frac{e^{-2\pi i u \xi}}{(1+u^2)^2}\,du = I(\xi).
\]
::: {.proof}
substitution $u = -x$.
:::
<2>2. Therefore it suffices to evaluate $I(\xi)$ for $\xi \le 0$. Setting $a = -2\pi \xi = 2\pi |\xi| \ge 0$, the integral becomes:
\[
I(\xi) = \int_{-\infty}^\infty \frac{e^{i a x}}{(1+x^2)^2}\,dx.
\]
::: {.proof}
definition of $a$.
:::

<1>2. Setup the contour integration in the upper half-plane:
<2>1. Consider the meromorphic function $f(z) = \frac{e^{i a z}}{(z^2 + 1)^2} = \frac{e^{i a z}}{(z - i)^2 (z + i)^2}$.
::: {.proof}
factorization of $z^2 + 1$.
:::
<2>2. For $R > 1$, let $\Gamma_R = [-R, R] \cup C_R$, where $C_R = \{R e^{i\theta} : \theta \in [0, \pi]\}$ is the semicircular arc in the upper half-plane.
::: {.proof}
standard contour definition.
:::
<2>3. In the upper half-plane $\mathbb{H} = \{z \in \mathbb{C} : \operatorname{Im}(z) > 0\}$, $f(z)$ has a single isolated singularity at $z = i$, which is a pole of order 2.
::: {.proof}
roots of $z^2 + 1 = 0$ in $\mathbb{H}$.
:::

<1>3. Calculate the residue $\operatorname{Res}(f, i)$:
<2>1. For a pole of order 2:
\[
\operatorname{Res}(f, i) = \lim_{z \to i} \frac{d}{dz}\left[(z - i)^2 f(z)\right] = \lim_{z \to i} \frac{d}{dz}\left[\frac{e^{i a z}}{(z + i)^2}\right].
\]
::: {.proof}
residue formula for a second-order pole.
:::
<2>2. Compute the derivative:
\[
\frac{d}{dz}\left[\frac{e^{i a z}}{(z + i)^2}\right] = \frac{i a e^{i a z}(z + i)^2 - 2(z + i) e^{i a z}}{(z + i)^4} = \frac{i a (z + i) - 2}{(z + i)^3} e^{i a z}.
\]
::: {.proof}
quotient and chain rules.
:::
<2>3. Evaluate at $z = i$:
\[
z + i = 2i, \quad (z + i)^3 = -8i, \quad i a(2i) - 2 = -2a - 2 = -2(1 + a), \quad e^{i a (i)} = e^{-a}.
\]
::: {.proof}
arithmetic.
:::
<2>4. Thus:
\[
\operatorname{Res}(f, i) = \frac{-2(1 + a) e^{-a}}{-8i} = \frac{(1 + a) e^{-a}}{4i}.
\]
::: {.proof}
simplification of <2>3.
:::

<1>4. Apply the Residue Theorem and estimate along $C_R$:
<2>1. By the Cauchy Residue Theorem:
\[
\oint_{\Gamma_R} f(z)\,dz = 2\pi i \operatorname{Res}(f, i) = 2\pi i \cdot \frac{(1 + a) e^{-a}}{4i} = \frac{\pi}{2}(1 + a) e^{-a}.
\]
::: {.proof}
Residue Theorem.
:::
<2>2. For $z = x + i y \in C_R$, $y \ge 0$, so $|e^{i a z}| = e^{-a y} \le 1$ since $a \ge 0$.
::: {.proof}
$a \ge 0$ and $y \ge 0 \implies -ay \le 0$.
:::
<2>3. By the reverse triangle inequality, $|z^2 + 1| \ge |z|^2 - 1 = R^2 - 1 > 0$, so $|f(z)| \le \frac{1}{(R^2 - 1)^2}$.
::: {.proof}
triangle inequality.
:::
<2>4. By the $ML$-inequality:
\[
\left|\int_{C_R} f(z)\,dz\right| \le \frac{\pi R}{(R^2 - 1)^2} \xrightarrow[R \to \infty]{} 0.
\]
::: {.proof}
$ML$-inequality on semicircle of length $\pi R$.
:::

<1>5. Conclusion:
Taking $R \to \infty$:
\[
\int_{-\infty}^\infty \frac{e^{-2\pi i x \xi}}{(1+x^2)^2}\,dx = \lim_{R\to\infty} \int_{-R}^R f(x)\,dx = \frac{\pi}{2}(1 + a) e^{-a} = \frac{\pi}{2}(1 + 2\pi |\xi|) e^{-2\pi |\xi|}.
\]
Q.E.D.
::: {.proof}
<1>1, <1>4, and $a = 2\pi |\xi|$.
:::
:::

::: {.problem}
Suppose $f$ is entire and maps a circle $\abs{z-a}=r$ into $\RR$.
Prove that $f$ is constant.
:::

::: {.solution}

The argument is the card's own: no solution set for this examination is retained in `tmp/sources`, so nothing below is transcribed, and the card's existing solution is restructured into numbered steps. Here $f$ is entire and maps the circle $\abs{z-a}=r$ into $\RR$; the criteria used are the identity theorem on the connected open set $\CC\setminus\theset{a}$ and Liouville's theorem.

::: pf

::: {.pf-step #reflection}

For $\abs{z-a}=r$, $a+\frac{r^{2}}{\overline{z-a}}=z$.

::: pf-proof

Write $z-a=re^{i\theta}$; then $\overline{z-a}=re^{-i\theta}$ and $\frac{r^{2}}{\overline{z-a}}=re^{i\theta}=z-a$.

:::

:::

::: {.pf-step #hol}

$g(z)\coloneqq\overline{f\left(a+\frac{r^{2}}{\overline{z-a}}\right)}$ is holomorphic on $\CC\setminus\theset{a}$.

::: pf-proof

The map $z\mapsto a+\frac{r^{2}}{\overline{z-a}}$ is antiholomorphic on $\CC\setminus\theset{a}$, being a Möbius transformation in $\overline{z-a}$; composing it with the entire $f$ gives an antiholomorphic function, and conjugating values gives the holomorphic $g$.

:::

:::

::: {.pf-step #identity}

$f=g$ on $\CC\setminus\theset{a}$.

::: pf-proof

On the circle $\abs{z-a}=r$ step [](#reflection){.pf-ref} gives $g(z)=\overline{f(z)}$, and $f(z)\in\RR$ there by hypothesis, so $g(z)=f(z)$. The circle has an accumulation point in the connected open set $\CC\setminus\theset{a}$ and both functions are holomorphic there, so the identity theorem gives equality everywhere in that set.

:::

:::

::: {.pf-step #limit}

$f$ has a finite limit at infinity.

::: pf-proof

For $z\to\infty$ the argument $a+\frac{r^{2}}{\overline{z-a}}$ tends to $a$, so by step [](#identity){.pf-ref} $f(z)=g(z)=\overline{f\left(a+\frac{r^{2}}{\overline{z-a}}\right)}\to\overline{f(a)}$.

:::

:::

::: {.pf-step #done}

$f$ is constant.

::: pf-proof

By step [](#limit){.pf-ref} $f$ is bounded on the complement of a large disc and continuous hence bounded on the disc, so $f$ is bounded on $\CC$; Liouville's theorem makes it constant.

:::

::: {.problem}
Let $\overline{\FF}_p$ denote an algebraic closure of the finite field $\FF_p$.
Show that the absolute Galois group $G = \operatorname{Gal}(\overline{\FF}_p/\FF_p) \cong \widehat{\ZZ}$ has **no non-trivial finite subgroups** (i.e. is torsion-free).
:::

::: {.solution}
**Goal:** Prove that the profinite group $\operatorname{Gal}(\overline{\FF}_p/\FF_p) \cong \widehat{\ZZ}$ is torsion-free, so it has no non-trivial finite subgroups.

::: pf

::: pf-step
Structure of the Galois Group $\operatorname{Gal}(\overline{\FF}_p/\FF_p)$:

::: pf-proof

::: pf-step
The finite subfields of $\overline{\FF}_p$ are the unique fields $\FF_{p^n}$ of size $p^n$ for each integer $n \ge 1$.

:::

::: pf-step
The extension $\overline{\FF}_p/\FF_p$ is the direct limit (union) of the finite Galois extensions $\FF_{p^n}/\FF_p$:
$$\overline{\FF}_p = \bigcup_{n=1}^\infty \FF_{p^n}.$$

:::

::: pf-step
For each $n \ge 1$, the finite Galois group $\operatorname{Gal}(\FF_{p^n}/\FF_p) \cong \ZZ/n\ZZ$, generated by the Frobenius automorphism $\operatorname{Frob}_p(x) = x^p$.

:::

::: pf-step
By the **Fundamental Theorem of Infinite Galois Theory**, the absolute Galois group is the **inverse limit (profinite completion)**:
$$G = \operatorname{Gal}(\overline{\FF}_p/\FF_p) \cong \varprojlim_{n} \operatorname{Gal}(\FF_{p^n}/\FF_p) \cong \varprojlim_{n} \ZZ/n\ZZ = \widehat{\ZZ}.$$

:::

::: pf-step
By the **Chinese Remainder Theorem** for profinite rings:
$$\widehat{\ZZ} \cong \prod_{q \text{ prime}} \ZZ_q$$
where $\ZZ_q$ is the ring of **$q$-adic integers** (under addition, $\ZZ_q \cong \varprojlim_k \ZZ/q^k\ZZ$).

:::

:::

:::

::: pf-step
Torsion-Freeness of $\widehat{\ZZ}$:

::: pf-proof

::: pf-step
Let $\sigma = (\sigma_q)_{q} \in \prod_q \ZZ_q \cong \widehat{\ZZ}$ be an element of finite order $m \ge 1$.

:::

::: pf-step
Then $m \cdot \sigma = 0 \in \widehat{\ZZ}$, which means for every prime $q$:
$$m \cdot \sigma_q = 0 \in \ZZ_q.$$

:::

::: pf-step
The additive group of the $q$-adic integers $(\ZZ_q, +)$ is an **integral domain** (char 0), so it is a **torsion-free abelian group**:
$$\text{If } m \in \ZZ_{> 0} \text{ and } m \cdot x = 0 \text{ in } \ZZ_q, \text{ then } x = 0.$$

:::

::: pf-step
Therefore, $\sigma_q = 0$ for every prime $q$.

:::

::: pf-step
This implies $\sigma = 0 = \operatorname{id}$.

:::

::: pf-step
Thus the only element of finite order in $\operatorname{Gal}(\overline{\FF}_p/\FF_p)$ is the identity $\operatorname{id}$.

:::

:::

:::

::: pf-step
Absence of Non-Trivial Finite Subgroups:

::: pf-proof

::: pf-step
Let $H \le G$ be a finite subgroup of order $|H| = k \ge 1$.

:::

::: pf-step
By Lagrange's Theorem, every element $h \in H$ satisfies $h^k = 1$.

:::

::: pf-step
By Step 2, since $G$ is torsion-free, the only element satisfying $h^k = 1$ is $h = 1$.

:::

::: pf-step
Thus $H = \{1\}$.

:::

:::

:::

::: pf-step
Alternative Direct Field-Theoretic Proof:

::: pf-proof

::: pf-step
Suppose $H \le \operatorname{Gal}(\overline{\FF}_p/\FF_p)$ is a finite subgroup with $|H| = k > 1$.

:::

::: pf-step
Let $K = (\overline{\FF}_p)^H$ be the fixed field of $H$.

:::

::: pf-step
By **Artin's Theorem on Galois extensions**, $[\overline{\FF}_p : K] = |H| = k < \infty$.

:::

::: pf-step
Thus $\overline{\FF}_p$ would be a finite-degree extension of the field $K$.

:::

::: pf-step
Since $K$ is of characteristic $p$, $K$ cannot have an algebraically closed finite extension of degree $> 1$ other than the Artin-Schreier theorem case where the closure is algebraically closed (which requires char 0 and degree 2, $\RR \subset \CC$).

:::

::: pf-step
Specifically, by the **Artin-Schreier Theorem on formally real fields**, if an algebraically closed field is a finite non-trivial extension of a subfield $K$, then the characteristic must be 0 and the extension degree must be 2.

:::

::: pf-step
Since $\operatorname{char}(\overline{\FF}_p) = p > 0$, this is impossible.

:::

::: pf-step
Thus no such finite subgroup $H$ can exist.

:::

:::

:::

::: pf-step
Conclusion:
$\operatorname{Gal}(\overline{\FF}_p/\FF_p) \cong \prod_q \ZZ_q$ is torsion-free, hence has no non-trivial finite subgroups.
:::

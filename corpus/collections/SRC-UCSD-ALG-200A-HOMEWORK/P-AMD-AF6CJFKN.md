::: {.problem}
Let $G$ be a finite group and let $p$ be a prime dividing $|G|$.
Define
\[
X=\{(a_1,\ldots,a_p)\in G^p:a_1a_2\cdots a_p=e\}.
\]

Prove Cauchy's theorem by establishing the following.

1. If $a_1a_2\cdots a_p=e$, then $a_2a_3\cdots a_pa_1=e$.

2. The cyclic group $K=(\mathbb Z/p\mathbb Z,+)$ acts on $X$ so that its generator sends
   \[
   (a_1,a_2,\ldots,a_p)\longmapsto(a_2,a_3,\ldots,a_p,a_1).
   \]

3. The orbits of size $1$ are precisely the tuples
   \[
   (a,a,\ldots,a)
   \]
   with $a^p=e$.

4. We have $|X|=|G|^{p-1}$.

5. There is more than one orbit of size $1$.
   Deduce that $G$ has a nonidentity element of order $p$.
:::

::: {.solution}
<1>1. Cyclically rotating a tuple in $X$ again gives a tuple in $X$.
::: {.proof}
Suppose
\[
a_1a_2\cdots a_p=e.
\]
Then
\[
a_2a_3\cdots a_pa_1
=a_1^{-1}(a_1a_2\cdots a_p)a_1
=a_1^{-1}ea_1
=e.
\]
Thus the one-step cyclic rotation preserves $X$.
:::

<1>2. Cyclic rotation defines an action of $K=\mathbb Z/p\mathbb Z$ on $X$.
::: {.proof}
Let
\[
r(a_1,\ldots,a_p)=(a_2,\ldots,a_p,a_1).
\]
By <1>1, $r$ maps $X$ to itself.
Applying $r$ exactly $p$ times returns every coordinate to its original position, so
\[
r^p=\operatorname{id}_X.
\]
Hence the assignment
\[
\bar m\cdot x=r^m(x)
\]
depends only on $m\pmod p$ and defines an action of the cyclic group $K=\mathbb Z/p\mathbb Z$ on $X$.
:::

<1>3. An orbit has size $1$ if and only if its tuple is
\[
(a,a,\ldots,a)
\]
for some $a\in G$ satisfying $a^p=e$.
::: {.proof}
Because $K$ is generated by $\bar1$, a tuple has orbit of size $1$ exactly when it is fixed by the one-step rotation $r$.

If
\[
r(a_1,\ldots,a_p)=(a_1,\ldots,a_p),
\]
then comparison of coordinates gives
\[
a_1=a_2=\cdots=a_p=:a.
\]
Since the tuple lies in $X$,
\[
a^p=e.
\]

Conversely, if $a^p=e$, then $(a,\ldots,a)\in X$ and cyclic rotation fixes it.
Thus these and only these tuples have one-element orbits.
:::

<1>4. We have
\[
|X|=|G|^{p-1}.
\]
::: {.proof}
Choose $a_1,\ldots,a_{p-1}\in G$ arbitrarily.
There is then exactly one choice of the last coordinate for which the product is the identity, namely
\[
a_p=(a_1a_2\cdots a_{p-1})^{-1}.
\]
Thus the map sending the first $p-1$ coordinates to the completed tuple is a bijection
\[
G^{p-1}\longrightarrow X.
\]
Therefore $|X|=|G|^{p-1}$.
:::

<1>5. The number of size-one orbits is divisible by $p$.
::: {.proof}
By orbit-stabilizer, every orbit of the $p$-element group $K$ has cardinality dividing $p$.
Since $p$ is prime, every orbit therefore has size either $1$ or $p$.

Let $f$ be the number of size-one orbits.
Partitioning $X$ into its $K$-orbits gives
\[
|X|=f+pm
\]
for some integer $m\ge0$.
Hence
\[
f\equiv |X|\pmod p.
\]

Because $p\mid |G|$ and $p-1\ge1$, <1>4 gives
\[
p\mid |G|^{p-1}=|X|.
\]
Therefore
\[
f\equiv0\pmod p.
\]
:::

<1>6. There is a nonidentity element $a\in G$ satisfying $a^p=e$.
::: {.proof}
The tuple
\[
(e,e,\ldots,e)
\]
is fixed by the rotation, so $f\ge1$.
By <1>5, $f$ is a positive multiple of $p$, hence
\[
f\ge p\ge2.
\]
Thus there is another size-one orbit.
By <1>3, it is represented by a tuple
\[
(a,a,\ldots,a)
\]
with $a^p=e$.
Since the identity tuple already accounts for $a=e$, this second fixed tuple has $a\ne e$.
:::

<1>7. The element $a$ from <1>6 has order exactly $p$.
::: {.proof}
Since $a^p=e$, the order of $a$ divides $p$.
Because $p$ is prime, its only positive divisors are $1$ and $p$.
The element $a$ is nonidentity by <1>6, so its order is not $1$.
Hence
\[
\operatorname{ord}(a)=p.
\]
This proves Cauchy's theorem.
:::

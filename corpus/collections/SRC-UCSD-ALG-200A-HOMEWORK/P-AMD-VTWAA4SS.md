::: {.problem}
Let $G$ be a cyclic group of order $n$.
For each $a\in\mathbb Z$, define
\[
\sigma_a:G\longrightarrow G,
\qquad
\sigma_a(x)=x^a.
\]

Prove that:

1. each $\sigma_a$ is an endomorphism of $G$, and $\sigma_a$ is an automorphism if and only if $\gcd(a,n)=1$;

2. $\sigma_a=\sigma_b$ if and only if $a\equiv b\pmod n$;

3. every automorphism of $G$ is $\sigma_a$ for some $a\in\mathbb Z$;

4. $\sigma_a\circ\sigma_b=\sigma_{ab}$.

Deduce that
\[
\psi:(\mathbb Z/n\mathbb Z)^\times\longrightarrow\operatorname{Aut}(G),
\qquad
[a]\longmapsto\sigma_a,
\]
is an isomorphism of groups.
:::

::: {.solution}
Fix a generator $g$ of $G$.

::: pf

::: pf-step

For every $a\in\mathbb Z$, the map $\sigma_a$ is an endomorphism of $G$.

::: pf-proof

Since $G$ is cyclic, it is abelian.
Hence for all $x,y\in G$ and every integer $a$,
\[
\sigma_a(xy)=(xy)^a=x^ay^a=\sigma_a(x)\sigma_a(y).
\]
Thus $\sigma_a$ is a group homomorphism $G\to G$.

:::

:::

::: {.pf-step #s2}

The element $g^a$ has order
\[
\frac{n}{\gcd(a,n)}.
\]

::: pf-proof

Let $d=\gcd(a,n)$, and write
\[
a=da',
\qquad
n=dn',
\qquad
\gcd(a',n')=1.
\]
Then
\[
(g^a)^m=e
\iff g^{am}=e
\iff n\mid am
\iff dn'\mid da'm
\iff n'\mid a'm.
\]
Since $\gcd(a',n')=1$, the last condition is equivalent to $n'\mid m$.
Therefore the least positive such $m$ is $n'=n/d$.

:::

:::

::: {.pf-step #s3}

The endomorphism $\sigma_a$ is an automorphism if and only if $\gcd(a,n)=1$.

::: pf-proof

The image of $\sigma_a$ is generated by the image of the generator $g$:
\[
\operatorname{im}(\sigma_a)=\langle g^a\rangle.
\]
By step [](#s2){.pf-ref},
\[
|\operatorname{im}(\sigma_a)|=\frac{n}{\gcd(a,n)}.
\]
Thus $\sigma_a$ is surjective exactly when $\gcd(a,n)=1$.
Since $G$ is finite, surjectivity is equivalent to bijectivity, so this is exactly the condition for $\sigma_a$ to be an automorphism.

:::

:::

::: {.pf-step #s4}

We have $\sigma_a=\sigma_b$ if and only if $a\equiv b\pmod n$.

::: pf-proof

Two homomorphisms from the cyclic group $G=\langle g\rangle$ are equal if and only if they agree on $g$.
Hence
\[
\begin{aligned}
\sigma_a=\sigma_b
&\iff g^a=g^b\\
&\iff g^{a-b}=e\\
&\iff n\mid(a-b)\\
&\iff a\equiv b\pmod n.
\end{aligned}
\]

:::

:::

::: {.pf-step #s5}

Every automorphism of $G$ is $\sigma_a$ for some $a\in\mathbb Z$.

::: pf-proof

Let $\tau\in\operatorname{Aut}(G)$.
Since every element of $G$ is a power of $g$, there is some $a\in\mathbb Z$ such that
\[
\tau(g)=g^a.
\]
For every $r\in\mathbb Z$,
\[
\tau(g^r)=\tau(g)^r=(g^a)^r=g^{ar}=\sigma_a(g^r).
\]
Thus $\tau=\sigma_a$.
Moreover, because $\tau(g)$ is again a generator, step [](#s2){.pf-ref} implies $\gcd(a,n)=1$.

:::

:::

::: {.pf-step #s6}

For all $a,b\in\mathbb Z$,
\[
\sigma_a\circ\sigma_b=\sigma_{ab}.
\]

::: pf-proof

For every $x\in G$,
\[
(\sigma_a\circ\sigma_b)(x)
=\sigma_a(x^b)
=(x^b)^a
=x^{ab}
=\sigma_{ab}(x).
\]
Hence the two maps are equal.

:::

:::

::: pf-step

The map
\[
\psi:(\mathbb Z/n\mathbb Z)^\times\longrightarrow\operatorname{Aut}(G),
\qquad
[a]\longmapsto\sigma_a,
\]
is a well-defined group isomorphism.

::: pf-proof

If $[a]\in(\mathbb Z/n\mathbb Z)^\times$, then $\gcd(a,n)=1$, so step [](#s3){.pf-ref} shows $\sigma_a\in\operatorname{Aut}(G)$.
If $[a]=[b]$, then $a\equiv b\pmod n$, so step [](#s4){.pf-ref} gives $\sigma_a=\sigma_b$.
Thus $\psi$ is well-defined.

By step [](#s6){.pf-ref},
\[
\psi([a][b])=\sigma_{ab}=\sigma_a\circ\sigma_b
=\psi([a])\psi([b]),
\]
so $\psi$ is a homomorphism.
By step [](#s4){.pf-ref} it is injective, and by step [](#s5){.pf-ref} it is surjective.
Therefore $\psi$ is an isomorphism.

:::

::: {.problem}
Show: Every finite group is finitely generated.

- Show: $\ZZ$ is finitely generated.

- Show: If $H\leq(\QQ,+)$ is finitely generated, then $H$ is cyclic.

- Show: $\QQ$ is not finitely generated.
:::

::: {.solution}
<1>1. Every finite group is finitely generated.
::: {.proof}
Let $G$ be finite.
The set $G$ itself is a finite subset of $G$, and the subgroup generated by all elements of $G$ is plainly $G$:
\[
\langle G\rangle=G.
\]
Hence $G$ has a finite generating set.
:::

<1>2. The additive group $\mathbb Z$ is finitely generated.
::: {.proof}
Every integer is an integral multiple of $1$, so
\[
\mathbb Z=\langle1\rangle.
\]
Thus $\mathbb Z$ is cyclic, in particular finitely generated.
:::

<1>3. Every finitely generated subgroup of $(\mathbb Q,+)$ is cyclic.
::: {.proof}
Let
\[
H=\langle q_1,\ldots,q_r\rangle\le\mathbb Q,
\]
where
\[
q_i=\frac{a_i}{b_i},
\qquad
a_i\in\mathbb Z,
\quad b_i\in\mathbb Z_{>0}.
\]
Choose a common positive denominator, for example
\[
k=b_1b_2\cdots b_r.
\]
For each $i$, define
\[
n_i=a_i\frac{k}{b_i}\in\mathbb Z.
\]
Then
\[
q_i=\frac{n_i}{k}.
\]
Let
\[
d=\gcd(n_1,\ldots,n_r),
\]
with the convention $d=0$ if all $n_i$ vanish.
If $d=0$, then $H=\{0\}$, which is cyclic.
Assume $d>0$.

Every $n_i$ is divisible by $d$, so every integer linear combination of the $q_i$ is an integer multiple of $d/k$.
Hence
\[
H\subseteq\left\langle\frac dk\right\rangle.
\]
Conversely, Bézout's identity gives integers $c_1,\ldots,c_r$ such that
\[
d=c_1n_1+\cdots+c_rn_r.
\]
Dividing by $k$ yields
\[
\frac dk=c_1q_1+\cdots+c_rq_r\in H.
\]
Therefore
\[
\left\langle\frac dk\right\rangle\subseteq H.
\]
Thus
\[
H=\left\langle\frac dk\right\rangle,
\]
so $H$ is cyclic.
:::

<1>4. The additive group $\mathbb Q$ is not cyclic.
::: {.proof}
Suppose
\[
\mathbb Q=\langle q\rangle
\]
for some $q\in\mathbb Q$.
If $q=0$, then $\langle q\rangle=\{0\}\ne\mathbb Q$.
If $q\ne0$, then
\[
\frac q2\in\mathbb Q.
\]
Were $q/2\in\langle q\rangle$, there would be an integer $m$ such that
\[
\frac q2=mq.
\]
Cancelling the nonzero rational $q$ gives
\[
\frac12=m,
\]
which is impossible for $m\in\mathbb Z$.
Thus $\mathbb Q$ is not cyclic.
:::

<1>5. The additive group $\mathbb Q$ is not finitely generated.
::: {.proof}
If $\mathbb Q$ were finitely generated, then <1>3, applied to the subgroup
\[
\mathbb Q\le\mathbb Q,
\]
would imply that $\mathbb Q$ is cyclic.
This contradicts <1>4.
Hence $\mathbb Q$ is not finitely generated.
:::

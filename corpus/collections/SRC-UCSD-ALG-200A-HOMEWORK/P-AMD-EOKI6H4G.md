::: {.problem}
Let $H\le G$.
Show that the normal core $\operatorname{core}(H)$ has each of the following equivalent descriptions:

1. the largest normal subgroup of $G$ contained in $H$;

2. the subgroup generated by all normal subgroups of $G$ contained in $H$;

3. the intersection
   \[
   \bigcap_{g\in G}gHg^{-1};
   \]

4. the kernel of the action of $G$ on the set $G/H$ of left cosets by left multiplication.
:::

::: {.solution}
Set
\[
C=\bigcap_{g\in G}gHg^{-1}.
\]

<1>1. The subgroup $C$ is normal in $G$ and satisfies $C\le H$.
::: {.proof}
Because the term corresponding to $g=e$ is $H$ itself,
\[
C\le H.
\]

Let $x\in G$.
Then
\[
xCx^{-1}
=x\left(\bigcap_{g\in G}gHg^{-1}\right)x^{-1}
=\bigcap_{g\in G}(xg)H(xg)^{-1}.
\]
As $g$ ranges over $G$, so does $xg$.
Hence
\[
xCx^{-1}=\bigcap_{u\in G}uHu^{-1}=C.
\]
Thus $C\normal G$.
:::

<1>2. Every normal subgroup of $G$ contained in $H$ is contained in $C$.
::: {.proof}
Let $N\normal G$ with $N\le H$.
For every $g\in G$,
\[
N=gNg^{-1}\le gHg^{-1}.
\]
Thus $N$ is contained in every subgroup occurring in the intersection defining $C$, so
\[
N\le C.
\]
:::

<1>3. The subgroup $C$ is the largest normal subgroup of $G$ contained in $H$.
::: {.proof}
By <1>1, $C$ itself is normal in $G$ and contained in $H$.
By <1>2, every other normal subgroup of $G$ contained in $H$ lies in $C$.
This is exactly the stated maximality property.
:::

<1>4. The subgroup generated by all normal subgroups of $G$ contained in $H$ is $C$.
::: {.proof}
Let
\[
L=\left\langle N:N\normal G,\ N\le H\right\rangle.
\]
Every such $N$ lies in $C$ by <1>2, so
\[
L\le C.
\]
Conversely, <1>1 says that $C\normal G$ and $C\le H$.
Hence $C$ itself is one of the normal subgroups whose union generates $L$, so
\[
C\le L.
\]
Therefore $L=C$.
:::

<1>5. The kernel of the left action of $G$ on $G/H$ is $C$.
::: {.proof}
Let $x\in G$.
The element $x$ lies in the kernel exactly when it fixes every left coset $gH$, that is, exactly when
\[
xgH=gH
\qquad\text{for every }g\in G.
\]
For a fixed $g$, this equality is equivalent to
\[
g^{-1}xg\in H,
\]
or equivalently
\[
x\in gHg^{-1}.
\]
Hence $x$ is in the kernel exactly when
\[
x\in\bigcap_{g\in G}gHg^{-1}=C.
\]
Thus the kernel is $C$.
:::

<1>6. All four source descriptions define the same subgroup $\operatorname{core}(H)=C$.
::: {.proof}
Description (iii) is the definition of $C$.
Step <1>3 proves description (i), <1>4 proves description (ii), and <1>5 proves description (iv).
Therefore all four descriptions are equivalent.
:::

::: {.problem}
The parts of this question are unrelated.

(a) Suppose $A\subseteq\mathbb R^n$ is non-empty and there exists $a_0\in A$ such that for every $a\in A$ the line segment joining $a_0$ to $a$ lies in $A$.
Prove that $A$ is a contractible space.

(b) Suppose that $X$ is a topological space and for $i=0,1$, $f_i$ and $g_i$ are paths in $X$ such that the products $f_i*g_i$ are defined and $f_0*g_0$ and $f_1*g_1$ are path homotopic.
Prove that if $g_0$ and $g_1$ are path homotopic, then $f_0$ and $f_1$ are path homotopic.
You may use standard theorems of path homotopy, but if you do, you must state and prove at least one of the theorems you use by explicitly constructing a homotopy.
:::

::: {.solution}
<1>1. Define
$$
H:A\times I\to A,
\qquad
H(a,t)=(1-t)a+t a_0.
$$
::: {.proof}
For each $a\in A$, the point $H(a,t)$ lies on the line segment joining $a$ to $a_0$, which is contained in $A$ by hypothesis. The formula is continuous as the restriction of an affine map on $\mathbb R^n\times I$.
:::

<1>2. The homotopy $H$ contracts $A$ to the point $a_0$.
::: {.proof}
For every $a\in A$,
$$
H(a,0)=a,
\qquad
H(a,1)=a_0.
$$
Thus $H$ is a homotopy from $\operatorname{id}_A$ to the constant map at $a_0$, so $A$ is contractible.
:::

<1>3. For part (b), recall the standard path-homotopy facts that concatenation respects path homotopy and that concatenation is associative up to path homotopy rel endpoints.
::: {.proof}
These are the usual reparametrization theorems for path products: if $\alpha_0\simeq_p\alpha_1$ and $\beta_0\simeq_p\beta_1$ with compatible endpoints, then $\alpha_0*\beta_0\simeq_p\alpha_1*\beta_1$, and $(\alpha*\beta)*\gamma\simeq_p\alpha*(\beta*\gamma)$.
:::

<1>4. For every path $g:I\to X$, the path $g*\bar g$ is path homotopic rel endpoints to the constant path at $g(0)$, where $\bar g(t)=g(1-t)$.
::: {.proof}
Let
$$
\tau(t)=
\begin{cases}
2t,&0\le t\le\tfrac12,\\
2-2t,&\tfrac12\le t\le1.
\end{cases}
$$
Then $(g*\bar g)(t)=g(\tau(t))$. Define
$$
K:I\times I\to X,
\qquad
K(t,s)=g\bigl((1-s)\tau(t)\bigr).
$$
This is continuous. At $s=0$ it is $g*\bar g$, while at $s=1$ it is the constant path $g(0)$. Moreover
$$
K(0,s)=K(1,s)=g(0)
$$
for all $s$, so the homotopy fixes both endpoints.
:::

<1>5. If $g_0\simeq_p g_1$, then $\bar g_0\simeq_p\bar g_1$.
::: {.proof}
If $G(t,s)$ is a path homotopy from $g_0$ to $g_1$, then
$$
\overline G(t,s)=G(1-t,s)
$$
is a path homotopy from $\bar g_0$ to $\bar g_1$.
:::

<1>6. The hypotheses imply
$$
(f_0*g_0)*\bar g_0\simeq_p(f_1*g_1)*\bar g_1.
$$
::: {.proof}
By hypothesis, $f_0*g_0\simeq_p f_1*g_1$. By <1>5, $\bar g_0\simeq_p\bar g_1$. Apply the compatibility of concatenation with path homotopy stated in <1>3.
:::

<1>7. For $i=0,1$,
$$
(f_i*g_i)*\bar g_i\simeq_p f_i.
$$
::: {.proof}
By associativity up to path homotopy,
$$
(f_i*g_i)*\bar g_i\simeq_p f_i*(g_i*\bar g_i).
$$
By <1>4, $g_i*\bar g_i$ is path homotopic to the constant path at the endpoint of $f_i$. Concatenating $f_i$ with that constant path is path homotopic to $f_i$ by the standard reparametrization of the unit interval.
:::

<1>8. Therefore $f_0\simeq_p f_1$.
::: {.proof}
Combine <1>6 and <1>7 and use transitivity of path homotopy.
:::

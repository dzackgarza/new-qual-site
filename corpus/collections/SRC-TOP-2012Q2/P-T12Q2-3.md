::: {.problem}
The parts of this question are unrelated.

(a) Suppose $A\subseteq\RR^n$ is non-empty and there exists $a_0\in A$ such that for every $a\in A$ the line segment joining $a_0$ to $a$ lies in $A$.
Prove that $A$ is a contractible space.

(b) Suppose that $X$ is a topological space and for $i=0,1$, $f_i$ and $g_i$ are paths in $X$ such that the products $f_i*g_i$ are defined and $f_0*g_0$ and $f_1*g_1$ are path homotopic.
Prove that if $g_0$ and $g_1$ are path homotopic, then $f_0$ and $f_1$ are path homotopic.
You may use standard theorems of path homotopy, but if you do, you must state and prove at least one of the theorems you use by explicitly constructing a homotopy.
:::

::: {.solution}
Write $\simeq_p$ for path homotopy and $\bar g(t)=g(1-t)$ for the reverse of a path $g$.
Part (b) uses two standard facts about path products: if $\alpha_0\simeq_p\alpha_1$ and $\beta_0\simeq_p\beta_1$ with $\alpha_0(1)=\beta_0(0)$, then $\alpha_0*\beta_0\simeq_p\alpha_1*\beta_1$; and $(\alpha*\beta)*\gamma\simeq_p\alpha*(\beta*\gamma)$ whenever the products are defined.

::: pf

::: {.pf-step #part-a}
(a) $A$ is contractible.

::: pf-proof
Define $H\colon A\times I\to A$ by $H(a,t)=(1-t)a+ta_0$.
For each $a\in A$, $H(a,t)$ lies on the segment joining $a$ to $a_0$, which is contained in $A$ by hypothesis.
$H$ is continuous as the restriction of an affine map on $\RR^n\times I$, and $H(a,0)=a$, $H(a,1)=a_0$.
So $H$ is a homotopy from $\operatorname{id}_A$ to the constant map at $a_0$.
:::

:::

::: {.pf-step #path-times-reverse-null-homotopic}
For every path $g\colon I\to X$, $g*\bar g$ is path homotopic to the constant path at $g(0)$.

::: pf-proof
Let $\tau(t)=2t$ for $0\le t\le\tfrac12$ and $\tau(t)=2-2t$ for $\tfrac12\le t\le1$, so that $(g*\bar g)(t)=g(\tau(t))$.
Define $K\colon I\times I\to X$ by $K(t,s)=g\bigl((1-s)\tau(t)\bigr)$.
$K$ is continuous, $K(\cdot,0)=g*\bar g$, $K(\cdot,1)$ is the constant path at $g(0)$, and $K(0,s)=K(1,s)=g(0)$ for all $s$.
:::

:::

::: {.pf-step #reverse-preserves-homotopy}
If $g_0\simeq_p g_1$, then $\bar g_0\simeq_p\bar g_1$.

::: pf-proof
If $G(t,s)$ is a path homotopy from $g_0$ to $g_1$, then $(t,s)\mapsto G(1-t,s)$ is a path homotopy from $\bar g_0$ to $\bar g_1$.
:::

:::

::: {.pf-step #cancel-gi}
For $i=0,1$, $(f_i*g_i)*\bar g_i\simeq_p f_i$.

::: pf-proof
By associativity, $(f_i*g_i)*\bar g_i\simeq_p f_i*(g_i*\bar g_i)$.
By step [](#path-times-reverse-null-homotopic){.pf-ref}, $g_i*\bar g_i$ is path homotopic to the constant path $e$ at $g_i(0)=f_i(1)$, so $f_i*(g_i*\bar g_i)\simeq_p f_i*e$.
Finally $f_i*e\simeq_p f_i$ by reparametrizing the unit interval.
:::

:::

::: pf-qed
Step [](#part-a){.pf-ref} proves (a).
For (b), the hypothesis $f_0*g_0\simeq_p f_1*g_1$, step [](#reverse-preserves-homotopy){.pf-ref}, and compatibility of products with path homotopy give $(f_0*g_0)*\bar g_0\simeq_p(f_1*g_1)*\bar g_1$.
By step [](#cancel-gi){.pf-ref} and transitivity, $f_0\simeq_p f_1$.
:::

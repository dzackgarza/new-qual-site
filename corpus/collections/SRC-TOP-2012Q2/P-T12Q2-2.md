::: {.problem}
Suppose $X$ and $Y$ are topological spaces and $f:X\to Y$ is a continuous function.

(a) Prove there exists a topological space $Z$, a quotient map $q:X\to Z$ and a one-to-one continuous map $h:Z\to Y$ such that $f=h\circ q$.

(b) (This part is a continuation of part (a).) If $Z_1$ is a topological space, $q_1:X\to Z_1$ is a quotient map, $h_1:Z_1\to Y$ is one-to-one and continuous, and $f=h_1\circ q_1$, prove that $Z$ and $Z_1$ are homeomorphic.
:::

::: {.solution}
Define the equivalence relation $x\sim x'\iff f(x)=f(x')$ on $X$, let $Z=X/\!\sim$ with the quotient topology, and let $q\colon X\to Z$ be the quotient map.
Define $h\colon Z\to Y$ by $h([x])=f(x)$; this is well defined because $x\sim x'$ means $f(x)=f(x')$.

<1>1. (a) $h$ is one-to-one and continuous, and $f=h\circ q$.

::: {.proof}
For $x\in X$, $(h\circ q)(x)=h([x])=f(x)$.
If $h([x])=h([x'])$, then $f(x)=f(x')$, so $[x]=[x']$.
Since $h\circ q=f$ is continuous and $q$ is a quotient map, $h$ is continuous.
:::

<1>2. If $f=h_1\circ q_1$ with $q_1\colon X\to Z_1$ a quotient map and $h_1\colon Z_1\to Y$ one-to-one and continuous, then $q_1(x)=q_1(x')\iff f(x)=f(x')$.

::: {.proof}
If $q_1(x)=q_1(x')$, applying $h_1$ gives $f(x)=f(x')$.
Conversely, if $f(x)=f(x')$, then $h_1(q_1(x))=h_1(q_1(x'))$, and injectivity of $h_1$ gives $q_1(x)=q_1(x')$.
:::

<1>3. With $q_1$ as in step <1>2, $\varphi([x])=q_1(x)$ defines a bijection $\varphi\colon Z\to Z_1$ with $\varphi\circ q=q_1$.

::: {.proof}
By step <1>2, $q_1$ is constant exactly on the classes of $\sim$, so $\varphi$ is well defined and injective.
It is surjective because $q_1$ is surjective.
:::

<1>4. $\varphi$ and $\varphi^{-1}$ are continuous.

::: {.proof}
$\varphi\circ q=q_1$ is continuous and $q$ is a quotient map, so $\varphi$ is continuous.
From $\varphi\circ q=q_1$ we get $\varphi^{-1}\circ q_1=q$, which is continuous, and $q_1$ is a quotient map, so $\varphi^{-1}$ is continuous.
:::

<1>5. Q.E.D.

::: {.proof}
Step <1>1 proves (a).
For (b), steps <1>3 and <1>4 show that $\varphi\colon Z\to Z_1$ is a homeomorphism.
:::
:::

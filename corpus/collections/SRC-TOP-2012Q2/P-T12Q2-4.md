::: {.problem}
Give a complete and careful proof of the following well-known theorem: If $X$ is a compact Hausdorff space, then $X$ is normal.
:::

::: {.solution}
$X$ is Hausdorff, so points are closed.
Let $A,B\subseteq X$ be disjoint closed subsets; they are compact as closed subsets of the compact space $X$.
For every $(a,b)\in A\times B$ we have $a\neq b$, so we may choose disjoint open sets $U_{a,b}\ni a$ and $V_{a,b}\ni b$.

::: pf

::: {.pf-step #separate-a-from-b}
For each $a\in A$ there are disjoint open sets $U_a\ni a$ and $V_a\supseteq B$.

::: pf-proof
The family $\{V_{a,b}:b\in B\}$ is an open cover of the compact set $B$, so there are $b_1,\ldots,b_n\in B$ with $B\subseteq V_{a,b_1}\cup\cdots\cup V_{a,b_n}$.
Put $U_a=\bigcap_{i=1}^n U_{a,b_i}$ and $V_a=\bigcup_{i=1}^n V_{a,b_i}$; both are open, $a\in U_a$, and $B\subseteq V_a$.
If $x\in U_a\cap V_a$, then $x\in V_{a,b_i}\cap U_{a,b_i}$ for some $i$, which is empty.
:::

:::

::: {.pf-step #finite-cover-of-a}
There exist $a_1,\ldots,a_m\in A$ with $A\subseteq U_{a_1}\cup\cdots\cup U_{a_m}$.

::: pf-proof
By step [](#separate-a-from-b){.pf-ref}, $\{U_a:a\in A\}$ is an open cover of the compact set $A$.
:::

:::

::: pf-qed
Set $U=\bigcup_{j=1}^m U_{a_j}$ and $V=\bigcap_{j=1}^m V_{a_j}$, which are open.
By step [](#finite-cover-of-a){.pf-ref}, $A\subseteq U$; by step [](#separate-a-from-b){.pf-ref}, $B\subseteq V$.
If $x\in U\cap V$, then $x\in U_{a_j}\cap V_{a_j}$ for some $j$, contrary to step [](#separate-a-from-b){.pf-ref}.
So disjoint closed sets have disjoint open neighborhoods, and $X$ is normal.
:::

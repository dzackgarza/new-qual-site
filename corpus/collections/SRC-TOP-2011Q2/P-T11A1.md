::: {.problem}
Prove that if $f:X\to Y$ is continuous and $C$ is a compact subset of $X$, then $f(C)$ is a compact subset of $Y$.
:::

::: {.solution}
Let $\mathcal U$ be a cover of $f(C)$ by open subsets of $Y$.

::: pf

::: {.pf-step #preimages-cover-c}
$\{f^{-1}(U):U\in\mathcal U\}$ is an open cover of $C$.

::: pf-proof
Each $f^{-1}(U)$ is open in $X$ because $f$ is continuous.
If $x\in C$, then $f(x)\in f(C)$, so some $U\in\mathcal U$ contains $f(x)$; hence $x\in f^{-1}(U)$.
:::

:::

::: {.pf-step #finite-preimage-subcover}
There exist $U_1,\ldots,U_n\in\mathcal U$ such that $C\subseteq f^{-1}(U_1)\cup\cdots\cup f^{-1}(U_n)$.

::: pf-proof
This follows from step [](#preimages-cover-c){.pf-ref} and compactness of $C$.
:::

:::

::: {.pf-step #image-in-finite-union}
$f(C)\subseteq U_1\cup\cdots\cup U_n$.

::: pf-proof
If $y\in f(C)$, write $y=f(x)$ with $x\in C$.
By step [](#finite-preimage-subcover){.pf-ref}, $x\in f^{-1}(U_i)$ for some $i$, so $y\in U_i$.
:::

:::

::: pf-qed
By step [](#image-in-finite-union){.pf-ref}, every open cover $\mathcal U$ of $f(C)$ has a finite subcover, so $f(C)$ is compact.
:::

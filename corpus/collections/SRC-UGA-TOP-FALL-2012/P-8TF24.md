::: {.problem}
Let $X=\{(x,\sin(1/x))\mid x>0\}$ and let $Y=\{(0,y)\mid -1\leq y\leq 1\}$.
Show that $X\cup Y$ is not a path-connected subset of $\RR^2$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Suppose for contradiction there is a path $\gamma: [0,1] \to X \cup Y$ with $\gamma(0) \in Y$ and $\gamma(1) \in X$.

::: pf-proof

Both $X$ and $Y$ are nonempty, so if no path in $X\cup Y$ joins a point of $Y$ to a point of $X$, then $X\cup Y$ is not path-connected.

:::

:::

::: pf-step

Write $\gamma(t) = (x(t), y(t))$; then $x(t)$ is continuous, $x(0) = 0$, and $x(1) > 0$.

::: pf-proof

The first coordinate of the continuous map $\gamma$ is continuous, $\gamma(0)\in Y$ has first coordinate $0$, and $\gamma(1)\in X$ has positive first coordinate.

:::

:::

::: {.pf-step #s3}

Let
\[
t_0=\max\{t\in[0,1]:x(t)=0\}.
\]
Then $t_0<1$, and
\[
x(t)>0\qquad(t_0<t\le1).
\]

::: pf-proof

The set $x^{-1}(0)$ is nonempty because it contains $0$, and it is closed in the compact interval $[0,1]$ because $x$ is continuous.
Hence it has a maximum $t_0$.
Since $x(1)>0$, one has $t_0<1$.
Every point of $X\cup Y$ has nonnegative first coordinate, so if $t>t_0$ then $x(t)\ne0$ by maximality of $t_0$, and therefore $x(t)>0$.

:::

:::

::: {.pf-step #s4}

For every $t\in(t_0,1]$,
\[
\gamma(t)\in X
\qquad\text{and hence}\qquad
y(t)=\sin\frac1{x(t)}.
\]

::: pf-proof

By step [](#s3){.pf-ref}, $x(t)>0$ for $t>t_0$.
The only points of $X\cup Y$ with positive first coordinate are points of $X$, where the second coordinate is $\sin(1/x)$.

:::

:::

::: {.pf-step #s5}

There are sequences
\[
r_m,s_m\downarrow t_0
\]
such that
\[
y(r_m)=1,
\qquad
y(s_m)=-1.
\]

::: pf-proof

For every sufficiently large integer $m$, put
\[
u_m=t_0+\frac1m\le1.
\]
By step [](#s3){.pf-ref}, $x(u_m)>0$.

Choose positive numbers $a_m,b_m<x(u_m)$ with
\[
\sin\frac1{a_m}=1,
\qquad
\sin\frac1{b_m}=-1.
\]
Such choices can be made arbitrarily small by taking reciprocals of sufficiently large numbers of the forms
\[
\frac\pi2+2\pi k,
\qquad
\frac{3\pi}2+2\pi k.
\]

Since
\[
x(t_0)=0<a_m,b_m<x(u_m),
\]
the intermediate value theorem applied to $x$ on $[t_0,u_m]$ gives
\[
r_m,s_m\in(t_0,u_m)
\]
with
\[
x(r_m)=a_m,
\qquad
x(s_m)=b_m.
\]
By step [](#s4){.pf-ref},
\[
y(r_m)=\sin\frac1{a_m}=1,
\qquad
y(s_m)=\sin\frac1{b_m}=-1.
\]
Finally,
\[
t_0<r_m,s_m<t_0+\frac1m,
\]
so both sequences converge to $t_0$.

:::

:::

::: {.pf-step #s6}

The sequences in step [](#s5){.pf-ref} contradict continuity of $y$ at $t_0$.

::: pf-proof

Continuity would give
\[
y(r_m)\longrightarrow y(t_0)
\qquad\text{and}\qquad
y(s_m)\longrightarrow y(t_0).
\]
But the first sequence is constantly $1$ and the second is constantly $-1$.
They cannot have the same limit.

:::

:::

::: pf-step

Therefore no such path exists, so $X \cup Y$ is not path-connected.

::: pf-proof

The path assumed in step [](#s1){.pf-ref} leads to the contradiction in step [](#s6){.pf-ref}.

:::

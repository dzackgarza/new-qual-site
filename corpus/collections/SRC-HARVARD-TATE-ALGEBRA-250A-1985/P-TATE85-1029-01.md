::: {.problem}
(1) Let$f ( X ) \in \ZZ [ X ]$be an irreducible quintic. We have seen in class that its group,$G _ { f }$, has order 120, 60, 20, 10 or 5, being isomorphic to$S _ { 5 } , A _ { 5 } .$, or to the group of permutations of$\FF _ { 5 }$of the form$x \mapsto a x + b$for$b \in \FF _ { 5 }$and for$a \in \FF _ { 5 } ^ { \times }$, or$a = \pm 1$, or$a = 1$. For$i = { 0 , 1 , 2 , 3 , 5 }$, let$\mathcal { P } _ { i }$denote the set of prime numbers p such that the congruence$f ( X ) \equiv 0 { \bmod { p } }$has exactly i incongruent solutions mod p. Assuming the Tschebotaroff density theorem, make a table giving, for each of the five possible$\boldsymbol { G } _ { f } { } ^ { \prime } \mathrm { s }$, the density of$\mathcal { P } _ { i }$in that case. For example, the density of$\mathcal { P } _ { 5 } \mathrm { i s } \frac { 1 } { 1 2 0 } , \frac { 1 } { 6 0 } , \frac { 1 } { 2 0 } ,$${ \frac { 1 } { 1 0 } } \ \mathrm { { o r } } \ { \frac { 1 } { 5 } } ,$i.e., is$| G _ { f } | ^ { - 1 }$in each case.
:::

::: {.solution}

Let $L$ be the splitting field of $f$, let $G=G_f=\operatorname{Gal}(L/\QQ)$ in its natural action on the five roots, and write
\[
N_i(G)=\#\{\sigma\in G:\sigma\text{ has exactly }i\text{ fixed points}\}.
\]
For the three affine groups write
\[
F_{20}=\{x\mapsto ax+b:a\in\FF_5^\times,\ b\in\FF_5\},
\]
\[
D_{10}=\{x\mapsto ax+b:a\in\{\pm1\},\ b\in\FF_5\},
\qquad
C_5=\{x\mapsto x+b:b\in\FF_5\}.
\]

::: pf

::: {.pf-step #s1-1}

For every $i\in\{0,1,2,3,5\}$,
\[
\delta(\mathcal P_i)=\frac{N_i(G)}{|G|}.
\]


::: pf-proof

Exclude the finitely many primes at which the reduction of $f$ is not separable or does not retain degree $5$; removing finitely many primes does not affect a natural density. For every remaining prime $p$, the cycle lengths of a Frobenius element on the five roots are the degrees of the irreducible factors of $f$ modulo $p$. Hence the number of incongruent roots of $f$ modulo $p$ is exactly the number of fixed points of Frobenius.

The set of elements of $G$ having exactly $i$ fixed points is stable under conjugation. The Tschebotaroff density theorem therefore says that the primes whose Frobenius belongs to this set have density equal to the size of the set divided by $|G|$, which is the displayed formula.

:::

:::

::: {.pf-step #s1-2}

For $G=S_5$,
\[
(N_0,N_1,N_2,N_3,N_5)=(44,45,20,10,1).
\]


::: pf-proof

If exactly $i$ points are fixed, the remaining $5-i$ points must be deranged. Thus
\[
N_i(S_5)=\binom5i D_{5-i},
\]
where $D_m$ is the number of derangements of $m$ letters. The needed values are
\[
D_5=44,\qquad D_4=9,\qquad D_3=2,\qquad D_2=1,\qquad D_0=1.
\]
Therefore
\[
N_0=44,
\quad
N_1=5\cdot9=45,
\quad
N_2=10\cdot2=20,
\quad
N_3=10\cdot1=10,
\quad
N_5=1.
\]

:::

:::

::: {.pf-step #s1-3}

For $G=A_5$,
\[
(N_0,N_1,N_2,N_3,N_5)=(24,15,20,0,1).
\]


::: pf-proof

The elements of $A_5$ have cycle types
\[
1^5,\qquad 3\,1^2,\qquad 2^2 1,\qquad 5,
\]
with respective cardinalities
\[
1,\qquad 20,\qquad 15,\qquad 24.
\]
These cycle types have respectively $5,2,1,0$ fixed points. No element of $A_5$ has exactly three fixed points, since that would require a transposition, which is odd. The stated tuple follows.

:::

:::

::: {.pf-step #s1-4}

For $G=F_{20}$,
\[
(N_0,N_1,N_2,N_3,N_5)=(4,15,0,0,1).
\]


::: pf-proof

An element is $x\mapsto ax+b$. If $a=1$ and $b=0$, it is the identity and fixes all five points. If $a=1$ and $b\ne0$, it is a nontrivial translation and fixes no point; there are four such elements. If $a\ne1$, then a fixed point must satisfy
\[
(a-1)x=-b.
\]
Since $a-1\ne0$ in $\FF_5$, this equation has exactly one solution. There are $3\cdot5=15$ choices with $a\ne1$, giving the stated tuple.

:::

:::

::: {.pf-step #s1-5}

For $G=D_{10}$,
\[
(N_0,N_1,N_2,N_3,N_5)=(4,5,0,0,1).
\]


::: pf-proof

The identity fixes all five points. The four nontrivial translations $x\mapsto x+b$ fix no point. The remaining five elements have the form $x\mapsto -x+b$; each has exactly one fixed point because
\[
-x+b=x
\quad\Longleftrightarrow\quad
2x=b,
\]
and $2$ is invertible in $\FF_5$. This gives the stated tuple.

:::

:::

::: {.pf-step #s1-6}

For $G=C_5$,
\[
(N_0,N_1,N_2,N_3,N_5)=(4,0,0,0,1).
\]


::: pf-proof

The identity translation fixes all five points, whereas each of the four nontrivial translations $x\mapsto x+b$ has no fixed point. These are all elements of $C_5$.

:::

:::

::: {.pf-step #s1-7}

The density table is
\[
\boxed{
\begin{array}{c|ccccc}
G_f & \delta(\mathcal P_0) & \delta(\mathcal P_1) & \delta(\mathcal P_2) & \delta(\mathcal P_3) & \delta(\mathcal P_5)\\
\hline
S_5    & \frac{11}{30} & \frac38 & \frac16 & \frac1{12} & \frac1{120}\\
A_5    & \frac25 & \frac14 & \frac13 & 0 & \frac1{60}\\
F_{20} & \frac15 & \frac34 & 0 & 0 & \frac1{20}\\
D_{10} & \frac25 & \frac12 & 0 & 0 & \frac1{10}\\
C_5    & \frac45 & 0 & 0 & 0 & \frac15
\end{array}}
\]


::: pf-proof

Apply step [](#s1-1){.pf-ref} to the fixed-point counts in steps [](#s1-2){.pf-ref} through [](#s1-6){.pf-ref} and divide each row by the corresponding group order $120,60,20,10,5$.

:::

:::

::: pf-qed

Step [](#s1-7){.pf-ref} gives every density requested in the problem.

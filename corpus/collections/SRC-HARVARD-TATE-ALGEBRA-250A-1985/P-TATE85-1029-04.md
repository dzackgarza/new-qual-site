::: {.problem}
(4) To prove your guess for$G _ { A }$is not so easy without a clue. To show it by brute force, let α be a root of$A ( X )$and check that in$\ZZ [ \alpha ] [ X ]$, we have :

$$
A ( X ) = ( X - \alpha ) ( X ^ { 2 } - c _ { 1 } X + c _ { 2 } ) ( X ^ { 2 } - d _ { 1 } X + d _ { 2 } ) ,
$$

where

$$
\begin{array} { c } { { c _ { 1 } = 2 \alpha ^ { 4 } - \alpha ^ { 3 } - 2 \alpha ^ { 2 } - 3 \alpha - 2 , d _ { 1 } = - 2 \alpha ^ { 4 } + \alpha ^ { 3 } + 2 \alpha ^ { 2 } + 2 \alpha + 2 , } } \\ { { { } } } \\ { { c _ { 2 } = - \alpha ^ { 4 } + \alpha ^ { 3 } + \alpha ^ { 2 } + \alpha , d _ { 2 } = - \alpha ^ { 4 } + \alpha ^ { 3 } + 2 \alpha + 1 . } } \end{array}
$$

Please don’t hand in your verification of this. But answer the following : What is the quadratic field contained in the splitting field of$A ( X ) ?$
:::

::: {.solution}

Let
$$
A(X)=X^5-X^3-2X^2-2X-1,
$$
let $K=\QQ(\alpha)$, and let $L$ be the splitting field of $A$ over $\QQ$. By [[P-TATE85-1029-02|Problem 2]], $A$ is irreducible and
$$
G_A=\Gal(L/\QQ)\in\{A_5,D_{10}\}.
$$

::: pf

::: {.pf-step #s1-1}

$\boxed{G_A\cong D_{10}}$.


::: pf-proof

The displayed factorization in the problem lies in $K[X]$ and consists of the linear factor $X-\alpha$ and two quadratic factors. Thus $L/K$ is obtained by splitting two quadratics, so
$$
[L:K]\leq 4.
$$
Since $A$ is irreducible of degree $5$, $[K:\QQ]=5$, and therefore
$$
\cardinality{G_A}=[L:\QQ]=[L:K][K:\QQ]\leq 20.
$$
The alternative $A_5$ has order $60$, whereas $D_{10}$ has order $10$. The two possibilities from Problem 2 therefore leave only $G_A\cong D_{10}$.

:::

:::

::: {.pf-step #s1-2}

If $\delta=c_1^2-4c_2$ is the discriminant of the first quadratic factor, then there is an element $q\in K$ such that
$$
q^2=-47\delta.
$$


::: pf-proof

Put
$$
F(X)=3X^4-2X^3-5X^2-3X
$$
and
$$
Q(X)=4X^4-9X^3+2X^2+9X+2.
$$
For
$$
C_1(X)=2X^4-X^3-2X^2-3X-2,
\qquad
C_2(X)=-X^4+X^3+X^2+X,
$$
direct expansion gives the polynomial identity
$$
C_1(X)^2-4C_2(X)-F(X)
=(4X^3-4X^2-3X-4)A(X).
$$
Evaluating at $X=\alpha$ shows
$$
\delta=c_1^2-4c_2=F(\alpha).
$$
A second direct expansion gives
$$
Q(X)^2+47F(X)
=(16X^3-72X^2+113X-4)A(X).
$$
Hence, with $q=Q(\alpha)\in K$,
$$
q^2=-47F(\alpha)=-47\delta.
$$

:::

:::

::: {.pf-step #s1-3}

The field $L$ contains $\QQ(\sqrt{-47})$.


::: pf-proof

Let $\beta,\gamma\in L$ be the two roots of
$$
X^2-c_1X+c_2.
$$
Since $A$ is separable in characteristic zero, these roots are distinct. Therefore
$$
r\coloneqq\beta-\gamma\neq0,
\qquad
r^2=(\beta+\gamma)^2-4\beta\gamma=c_1^2-4c_2=\delta.
$$
By step [](#s1-2){.pf-ref},
$$
\left(\frac q r\right)^2=\frac{q^2}{\delta}=-47.
$$
Thus $q/r\in L$ is a square root of $-47$, so $\QQ(\sqrt{-47})\subseteq L$.

:::

:::

::: {.pf-step #s1-4}

The quadratic field contained in $L$ is
$$
\boxed{\QQ(\sqrt{-47})}.
$$


::: pf-proof

By step [](#s1-1){.pf-ref}, $\Gal(L/\QQ)\cong D_{10}$. A quadratic subfield of $L$ corresponds by Galois theory to a subgroup of $D_{10}$ of index $2$, hence of order $5$. The Sylow $5$-subgroup is unique because its number divides $2$ and is congruent to $1$ modulo $5$. Therefore $L$ has exactly one quadratic subfield. Step [](#s1-3){.pf-ref} exhibits $\QQ(\sqrt{-47})$ as such a subfield, so it is the unique one.

:::

:::

::: pf-qed

Step [](#s1-4){.pf-ref} identifies the requested quadratic field.

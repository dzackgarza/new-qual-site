(7) Let M be a maximal ideal in a ring B and let$A = B / M ^ { n }$for some integer$n > 0$Show that the only prime ideal of A is$M / M ^ { n }$

Examples:$A = \mathbb { Z } / 1 0 2 4 \mathbb { Z } , A = \mathbb { C } [ X ] / X ^ { n } \mathbb { C } [ X ]$

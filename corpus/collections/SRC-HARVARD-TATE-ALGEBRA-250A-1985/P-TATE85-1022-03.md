::: {.problem}
(3) Let$\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { n }$be “variables” and

$$
f ( X ) = \prod _ { i = 1 } ^ { n } ( X - \alpha _ { i } ) = X ^ { n } - a _ { 1 } X ^ { n - 1 } + \dots .
$$

Put :

$$
\beta = \sum _ { \pi \in { \mathcal A } _ { n } } \alpha _ { \pi ( 2 ) } \alpha _ { \pi ( 3 ) } ^ { 2 } \ldots \alpha _ { \pi ( n ) } ^ { n - 1 } , { \mathrm { ~ a n d ~ } } \gamma = \sum _ { \pi \in { \mathcal S } _ { n } \setminus { \mathcal A } _ { n } } \alpha _ { \pi ( 2 ) } \alpha _ { \pi ( 3 ) } ^ { 2 } \ldots \alpha _ { \pi ( n ) } ^ { n - 1 } .
$$

(a) Show that$( \beta - \gamma ) ^ { 2 } = d _ { f }$(the discriminant of$f )$

(b) Let$b = \beta + \gamma$and$c = \beta \gamma$. How do you know b and c are in$\ZZ [ a _ { 1 } , a _ { 2 } , \ldots ]$

(c) For$n \ = \ 2$and 3, give b and c explicitly as elements of$\ZZ [ a _ { 1 } , a _ { 2 } ]$, and of$\ZZ [ a _ { 1 } , a _ { 2 } , a _ { 3 } ]$(Recall :$\bar { f } ( X ) = X ^ { n } - a _ { 1 } X ^ { n - 1 } + a _ { 2 } X ^ { n - 2 } - \dots )$

(d) Now drop the assumption that the$\alpha _ { i }$are “variables”. Let F be a field,$a _ { i } \in$$F , \ 1 \leq \ i \ \leq \ n$, and suppose$d _ { f } \ne 0$. Let K be a splitting field for f over$F , { \mathrm { ~ i . e . , ~ } } K = F ( \alpha _ { 1 } , \ldots , \alpha _ { n } )$and$G = \operatorname { G a l } ( K / F )$Show that the fixed field of$G _ { f } \cap { \mathcal { A } } _ { n }$is the splitting field of the quadratic polynomial$X ^ { 2 } - b X + c .$regardless of the characteristic.

(e) Let$F = \mathbb { F } _ { 2 } ( t )$, t transcendental. Find$G _ { f }$in the following cases :

(i)$f ( X ) = X ^ { 3 } + t X + 1 ;$

(ii)$f ( X ) = X ^ { 3 } + t ^ { 3 } X + t ^ { 2 } ;$

(iii)$f ( X ) = X ^ { 3 } + t ^ { 2 } X + ( t + 1 )$;

(f) Show that if the$a _ { i } \in \ZZ$, then$d _ { f } \equiv 0$or 1 (mod 4) (just express$d _ { f }$in terms of b and c).
:::

::: {.solution}

For a permutation $\pi\in S_n$, write
\[
m_\pi=\alpha_{\pi(2)}\alpha_{\pi(3)}^2\cdots\alpha_{\pi(n)}^{n-1}.
\]
Also write $e_i$ for the $i$th elementary symmetric polynomial in the $\alpha_j$, so $e_i=a_i$.

::: pf

::: {.pf-step #s1}

For part (a),
\[
\boxed{(\beta-\gamma)^2=d_f}.
\]


::: pf-proof

By definition,
\[
\beta-\gamma
=\sum_{\pi\in S_n}\operatorname{sgn}(\pi)
  \prod_{j=1}^n\alpha_{\pi(j)}^{j-1}.
\]
This is the determinant of the Vandermonde matrix
\[
V=(\alpha_i^{j-1})_{1\le i,j\le n},
\]
because transposing the usual determinant expansion does not change the determinant. Hence
\[
\beta-\gamma
=\det V
=\prod_{1\le i<j\le n}(\alpha_j-\alpha_i).
\]
Squaring gives
\[
(\beta-\gamma)^2
=\prod_{i<j}(\alpha_i-\alpha_j)^2
=d_f.
\]

:::

:::

::: {.pf-step #s2}

For part (b),
\[
b=\beta+\gamma,
\qquad
c=\beta\gamma
\]
belong to $\ZZ[a_1,\ldots,a_n]$.


::: pf-proof

The polynomial $b$ is the sum of $m_\pi$ over all $\pi\in S_n$, so it is symmetric with integer coefficients. A permutation of the $\alpha_i$ either preserves the parity classes in $S_n$ and fixes both $\beta$ and $\gamma$, or interchanges the two parity classes and swaps $\beta$ with $\gamma$. Therefore $c=\beta\gamma$ is also symmetric with integer coefficients.

By the Fundamental Theorem of Symmetric Polynomials,
\[
b,c\in\ZZ[e_1,\ldots,e_n]
=\ZZ[a_1,\ldots,a_n].
\]

:::

:::

::: {.pf-step #s3}

For part (c), the explicit formulas are
\[
\boxed{n=2:\quad b=a_1,\qquad c=a_2,}
\]
and
\[
\boxed{n=3:\quad
b=a_1a_2-3a_3,
\qquad
c=a_2^3+a_1^3a_3-6a_1a_2a_3+9a_3^2.}
\]


::: pf-proof

For $n=2$,
\[
\beta=\alpha_2,
\qquad
\gamma=\alpha_1,
\]
so $b=e_1=a_1$ and $c=e_2=a_2$.

For $n=3$,
\[
\begin{aligned}
\beta
&=\alpha_2\alpha_3^2+\alpha_3\alpha_1^2+\alpha_1\alpha_2^2,\\
\gamma
&=\alpha_1\alpha_3^2+\alpha_2\alpha_1^2+\alpha_3\alpha_2^2.
\end{aligned}
\]
Adding and collecting elementary symmetric functions gives
\[
b=e_1e_2-3e_3.
\]
By step [](#s1){.pf-ref},
\[
d_f=b^2-4c.
\]
For a cubic, expanding the Vandermonde square gives
\[
d_f
=e_1^2e_2^2-4e_2^3-4e_1^3e_3-27e_3^2+18e_1e_2e_3.
\]
Therefore
\[
\begin{aligned}
4c
&=b^2-d_f\\
&=4\bigl(e_2^3+e_1^3e_3-6e_1e_2e_3+9e_3^2\bigr),
\end{aligned}
\]
and hence
\[
c=e_2^3+e_1^3e_3-6e_1e_2e_3+9e_3^2.
\]
Substituting $e_i=a_i$ yields the displayed formulas.

:::

:::

::: {.pf-step #s4}

For part (d), if
\[
H=G_f\cap A_n,
\]
then
\[
\boxed{K^H\text{ is the splitting field over }F\text{ of }X^2-bX+c.}
\]


::: pf-proof

Since $d_f\ne0$, the roots $\alpha_1,\ldots,\alpha_n$ are distinct, so $G=\operatorname{Gal}(K/F)$ acts faithfully on them and is identified with $G_f\subseteq S_n$. By step [](#s2){.pf-ref}, after specialization one has $b,c\in F$ and
\[
X^2-bX+c=(X-\beta)(X-\gamma).
\]

If $\sigma\in G_f$ is even, left multiplication by $\sigma$ preserves the two parity classes in $S_n$, so $\sigma$ fixes both $\beta$ and $\gamma$. If $\sigma$ is odd, it interchanges those parity classes, so it swaps $\beta$ and $\gamma$. Step [](#s1){.pf-ref} gives
\[
(\beta-\gamma)^2=d_f\ne0,
\]
hence $\beta\ne\gamma$ in every characteristic. Therefore the elements of $G$ fixing both roots of $X^2-bX+c$ are exactly the elements of $H$.

Let $E=F(\beta,\gamma)$, the splitting field of that quadratic inside $K$. Then
\[
\operatorname{Gal}(K/E)=H.
\]
The Galois correspondence gives $E=K^H$. No division by $2$ was used, so the argument also applies in characteristic $2$.

:::

:::

::: pf-step

For part (e), the three Galois groups are
\[
\boxed{\text{(i) }S_3,\qquad\text{(ii) }S_3,\qquad\text{(iii) }C_2.}
\]


::: pf-proof

::: {.pf-step #s5-1}

For a cubic
\[
g(X)=X^3+pX+q\in\mathbb F_2(t)[X],
\]
the quadratic from part (d) is
\[
R_{p,q}(Y)=Y^2+qY+(p^3+q^2).
\]


::: pf-proof

For such a cubic, $a_1=0$, $a_2=p$, and $a_3=q$. Reducing the formulas of step [](#s3){.pf-ref} modulo $2$ gives
\[
b=q,
\qquad
c=p^3+q^2,
\]
and in characteristic $2$ the polynomial $Y^2-bY+c$ is the displayed $R_{p,q}(Y)$.

For an irreducible cubic, the derivative $X^2+p$ is nonzero and has smaller degree, so it is relatively prime to the cubic. Thus the cubic is separable, $G_f$ is a transitive subgroup of $S_3$, and hence $G_f$ is either $A_3$ or $S_3$. By step [](#s4){.pf-ref}, the splitting field of $R_{p,q}$ is the fixed field of $G_f\cap A_3$. Thus an irreducible $R_{p,q}$ forces $[G_f:G_f\cap A_3]=2$, and therefore $G_f=S_3$.

:::

:::

::: {.pf-step #s5-2}

For $f(X)=X^3+tX+1$, one has $G_f=S_3$.


::: pf-proof

Because $f$ is monic over the integrally closed domain $\mathbb F_2[t]$, any root in $\mathbb F_2(t)$ would lie in $\mathbb F_2[t]$. If such a root $r$ has degree $d\ge1$, then
\[
\deg(r^3)=3d>d+1=\deg(tr),
\]
so the leading term cannot cancel. The constant possibilities $r=0,1$ are not roots. Hence $f$ is irreducible.

Here
\[
R_{t,1}(Y)=Y^2+Y+t^3+1.
\]
Any root in $\mathbb F_2(t)$ would again be a polynomial. If its degree is at least $2$, the $Y^2$ term has strictly largest degree; if its degree is at most $1$, the term $t^3$ has strictly largest degree. Thus the quadratic has no root and is irreducible. Step [](#s5-1){.pf-ref} gives $G_f=S_3$.

:::

:::

::: {.pf-step #s5-3}

For $f(X)=X^3+t^3X+t^2$, one has $G_f=S_3$.


::: pf-proof

As in step [](#s5-2){.pf-ref}, a rational root would be a polynomial $r\in\mathbb F_2[t]$. If $d=\deg r\ge2$, then $3d>d+3$, so $r^3$ has uniquely largest degree. If $d=1$, then $t^3r$ has degree $4$, larger than the other terms. The constant possibilities are not roots. Hence $f$ is irreducible.

Its quadratic is
\[
R_{t^3,t^2}(Y)=Y^2+t^2Y+t^9+t^4.
\]
If a polynomial root has degree $m\ge5$, its square has degree at least $10$ and dominates every other term. If $m\le4$, the term $t^9$ dominates every other term. Hence the quadratic is irreducible, and step [](#s5-1){.pf-ref} gives $G_f=S_3$.

:::

:::

::: {.pf-step #s5-4}

For $f(X)=X^3+t^2X+(t+1)$, one has $G_f\cong C_2$.


::: pf-proof

There is a factorization
\[
f(X)=(X+t+1)\bigl(X^2+(t+1)X+1\bigr).
\]
The quadratic factor has no root in $\mathbb F_2(t)$. Indeed a rational root would be a polynomial. A polynomial root of degree at least $2$ is impossible because its square has uniquely largest degree. For degree $1$, the only possibilities with leading coefficient $1$ are $t$ and $t+1$, and substitution gives respectively $t+1$ and $1$. The constants $0$ and $1$ are also not roots.

Thus the quadratic factor is irreducible. Its two roots generate a quadratic splitting field, while $t+1$ is already in $F$. Therefore the splitting field of $f$ has degree $2$ over $F$, and its Galois group is cyclic of order $2$, acting by the transposition of the two quadratic roots.

:::

::: pf-qed

Steps [](#s5-2){.pf-ref} and [](#s5-3){.pf-ref}, and [](#s5-4){.pf-ref} give the three groups requested in part (e).

::: {.pf-step #s6}

For part (f),
\[
\boxed{d_f\equiv0\text{ or }1\pmod4}.
\]


::: pf-proof

By the definitions of $b$ and $c$ and step [](#s1){.pf-ref},
\[
d_f
=(\beta-\gamma)^2
=(\beta+\gamma)^2-4\beta\gamma
=b^2-4c.
\]
If every $a_i\in\ZZ$, then step [](#s2){.pf-ref} gives $b,c\in\ZZ$. Hence
\[
d_f\equiv b^2\pmod4.
\]
Every integer square is congruent to $0$ or $1$ modulo $4$, proving the claim.

:::

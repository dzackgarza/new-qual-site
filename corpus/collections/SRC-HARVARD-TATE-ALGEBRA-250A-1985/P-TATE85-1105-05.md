::: {.problem}
Find three integers $a, b, c$ such that $\mathbb{Q}(e^{\frac{2\pi i}{4}}) = \mathbb{Q}(\sqrt{a}, \sqrt{b}, \sqrt{c})$.
:::

::: {.remark}
The source prints the exponent as $\frac{2\pi i}{4}$, so the left side is $\mathbb{Q}(i)$ and the problem is trivially solved by $a = b = c = -1$.
The phrase "three integers" suggests a field of degree $8$ such as $\mathbb{Q}(e^{\frac{2\pi i}{24}}) = \mathbb{Q}(\sqrt{-1}, \sqrt{2}, \sqrt{3})$; the source does not say so, and the statement above keeps its exponent.
:::

::: {.problem}
(1) Let$F \subset K$be finite fields. Prove that$N _ { K / F } : K ^ { \times } \to F ^ { \times }$is surjective.
:::

Write $q=|F|$ and $n=[K:F]$, so $|K|=q^n$, and set
\[
m=1+q+\cdots+q^{n-1}=\frac{q^n-1}{q-1}.
\]

::: pf

::: pf-step

For every $a\in K^\times$,
\[
N_{K/F}(a)=a^m.
\]


::: pf-proof

Every finite extension of finite fields is Galois, and its Galois group is generated by the Frobenius automorphism $\sigma(a)=a^q$. Since $[K:F]=n$, the conjugates of $a$ over $F$ are $a,a^q,\ldots,a^{q^{n-1}}$. Therefore
\[
N_{K/F}(a)=\prod_{j=0}^{n-1}a^{q^j}
=a^{1+q+\cdots+q^{n-1}}
=a^m.
\]

:::

:::

::: pf-step

If $g$ generates the cyclic group $K^\times$, then $N_{K/F}(g)$ has order $q-1$.


::: pf-proof

The group $K^\times$ is cyclic of order $q^n-1$. By step <1>1,
\[
N_{K/F}(g)=g^m.
\]
Hence
\[
\operatorname{ord}(N_{K/F}(g))
=\operatorname{ord}(g^m)
=\frac{q^n-1}{\gcd(q^n-1,m)}.
\]
Because $m=(q^n-1)/(q-1)$ divides $q^n-1$, the denominator is $m$, and therefore
\[
\operatorname{ord}(N_{K/F}(g))=\frac{q^n-1}{m}=q-1.
\]

:::

:::

::: pf-step

The norm map $N_{K/F}:K^\times\to F^\times$ is surjective.


::: pf-proof

By step <1>2, $N_{K/F}(g)$ is an element of $F^\times$ of order $q-1$. Since $|F^\times|=q-1$, it generates $F^\times$. Thus the image of the norm contains a generator of $F^\times$, so the norm map is surjective.

:::

:::

::: pf-qed

Step <1>3 proves the required surjectivity.

:::

:::

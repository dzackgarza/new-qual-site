::: {.problem}
Use de Moivre's theorem, i.e.
\[
(e^{i\theta})^n=\cos(n\theta)+i\sin(n\theta),
\qquad
(\cos\theta+i\sin\theta)^n=\cos(n\theta)+i\sin(n\theta),
\]
to find the sum
\[
\sin x+\sin 2x+\cdots+\sin nx.
\]
:::

::: {.solution}

Let
\[
S_n(x)
\coloneqq
\sum_{k=1}^n\sin(kx).
\]

::: pf

::: {.pf-step #s1-1}

If
\[
x\notin2\pi\ZZ,
\]
then
\[
\sum_{k=1}^n e^{ikx}
=
e^{ix}
\frac{1-e^{inx}}{1-e^{ix}}.
\]


::: pf-proof

Since
\[
e^{ix}\ne1,
\]
the finite geometric-series identity gives
\[
\sum_{k=1}^n(e^{ix})^k
=
e^{ix}
\frac{1-(e^{ix})^n}{1-e^{ix}}
=
e^{ix}
\frac{1-e^{inx}}{1-e^{ix}}.
\]

:::

:::

::: {.pf-step #s1-2}

The expression in step [](#s1-1){.pf-ref} can be rewritten as
\[
\sum_{k=1}^n e^{ikx}
=
e^{i(n+1)x/2}
\frac{\sin(nx/2)}{\sin(x/2)}.
\]


::: pf-proof

Use
\[
1-e^{i\alpha}
=
-2i
e^{i\alpha/2}
\sin(\alpha/2).
\]
Then
\[
1-e^{inx}
=
-2i
e^{inx/2}
\sin(nx/2),
\]
while
\[
1-e^{ix}
=
-2i
e^{ix/2}
\sin(x/2).
\]
Therefore
\[
\frac{1-e^{inx}}{1-e^{ix}}
=
e^{i(n-1)x/2}
\frac{\sin(nx/2)}{\sin(x/2)}.
\]
Multiplying by $e^{ix}$ yields
\[
e^{i(n+1)x/2}
\frac{\sin(nx/2)}{\sin(x/2)}.
\]

:::

:::

::: {.pf-step #s1-3}

If
\[
x\notin2\pi\ZZ,
\]
then
\[
\boxed{
S_n(x)
=
\frac{
\sin(nx/2)
\sin((n+1)x/2)
}{
\sin(x/2)
}.
}
\]


::: pf-proof

By de Moivre's theorem,
\[
\operatorname{Im}
\left(
\sum_{k=1}^n e^{ikx}
\right)
=
\sum_{k=1}^n\sin(kx)
=
S_n(x).
\]
In step [](#s1-2){.pf-ref}, the factor
\[
\frac{\sin(nx/2)}{\sin(x/2)}
\]
is real. Hence taking imaginary parts gives
\[
S_n(x)
=
\frac{\sin(nx/2)}{\sin(x/2)}
\operatorname{Im}
e^{i(n+1)x/2}.
\]
Using de Moivre again,
\[
\operatorname{Im}
e^{i(n+1)x/2}
=
\sin((n+1)x/2),
\]
which gives the displayed formula.

:::

:::

::: {.pf-step #s1-4}

If
\[
x\in2\pi\ZZ,
\]
then
\[
S_n(x)=0.
\]


::: pf-proof

Write
\[
x=2\pi m
\]
with $m\in\ZZ$. Then for every $1\le k\le n$,
\[
\sin(kx)
=
\sin(2\pi km)
=
0.
\]
Therefore their sum is zero.

:::

:::

::: {.pf-step #s1-5}

Thus the finite sine progression is
\[
\boxed{
\sum_{k=1}^n\sin(kx)
=
\begin{cases}
\displaystyle
\frac{
\sin(nx/2)
\sin((n+1)x/2)
}{
\sin(x/2)
},
&x\notin2\pi\ZZ,
\\[4mm]
0,
&x\in2\pi\ZZ.
\end{cases}
}
\]


::: pf-proof

Combine steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-5){.pf-ref} is the requested sum.

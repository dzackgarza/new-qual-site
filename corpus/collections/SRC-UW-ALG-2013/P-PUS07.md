::: {.problem}
Let $R=\CC[x_1,\ldots,x_n]$ be the polynomial ring over $\CC$ in $n$ indeterminates $x_1,\ldots,x_n$.
Let $S_n$ be the $n$-th symmetric group.
If $\sigma\in S_n$, then we can identify $\sigma$ with the automorphism of $R$ defined as follows: $\sigma(c)=c$ for all $c\in\CC$, and $\sigma(x_i)=x_{\sigma(i)}$ for all $i$, $1\leq i\leq n$.
Suppose that $G$ is any subgroup of $S_n$.
Let
$$
S=R^G=\{r\in R\mid \sigma(r)=r \text{ for all } \sigma\in G\}.
$$
Prove that $S$ is a finitely-generated $\CC$-algebra.
:::

::: {.solution}

Let $A=\CC[x_1,\dots,x_n]$ with $S_n$ acting by permuting the variables, and let $G\le S_n$ be a subgroup, acting by restriction.

::: pf

::: {.pf-step #s1}

The elementary symmetric functions $e_1,\dots,e_n$ lie in $A^G$, and $A$ is a finitely generated module over $R=\CC[e_1,\dots,e_n]$.

::: pf-proof

The $e_k$ are the coefficients, up to sign, of $\prod_{i=1}^n(t-x_i)=\sum_{k=0}^n(-1)^ke_kt^{n-k}$, and the left side is unchanged by permuting the $x_i$; so every $e_k$ is fixed by all of $S_n$, hence by $G$, and $\CC[e_1,\dots,e_n]\subseteq A^G$.

Since $\prod_i(t-x_i)=\sum_k(-1)^ke_kt^{n-k}$, each $x_i$ is a root of the monic polynomial $t^n-e_1t^{n-1}+\cdots+(-1)^ne_n$ with coefficients in $R$; so each $x_i$ is integral over $R$. The algebra $A=R[x_1,\dots,x_n]$ is therefore generated as an $R$-module by the finitely many monomials $x_1^{a_1}\cdots x_n^{a_n}$ with $0\le a_i\le n-1$, which span all monomials because each $x_i^n$ is an $R$-linear combination of lower powers of $x_i$.

Also $R$ is a polynomial ring over a field, hence Noetherian.

:::

:::

::: {.pf-step #s2}

$A^G$ is a finitely generated $R$-module, and hence a finitely generated $\CC$-algebra.

::: pf-proof

By step [](#s1){.pf-ref}, $A$ is a finitely generated $R$-module and $R$ is Noetherian, so $A$ is a Noetherian $R$-module and every $R$-submodule of $A$ is finitely generated. The fixed ring $A^G$ is an $R$-submodule of $A$ (it is an additive subgroup and closed under multiplication by $R\subseteq A^G$), so $A^G$ is a finitely generated $R$-module.

A finite generating set $f_1,\dots,f_m$ of $A^G$ over $R=\CC[e_1,\dots,e_n]$, together with $e_1,\dots,e_n$, generates $A^G$ as a $\CC$-algebra: any element of $A^G$ is $\sum_jc_jf_j$ with $c_j\in R$, and each $c_j$ is a polynomial in the $e_k$ with complex coefficients. Hence $A^G$ is a finitely generated $\CC$-algebra.

:::

:::

::: {.pf-step #s3}

No hypothesis beyond finiteness of $G$ is used, and in particular $G$ need not be generated by pseudo-reflections.

::: pf-proof

The argument above uses only that $G$ is a finite subgroup of $S_n$, so that $A^G\supseteq\CC[e_1,\dots,e_n]$ and $A$ is finite over $R$. The stronger conclusion that $A^G$ is itself a polynomial ring holds only when $G$ is generated by pseudo-reflections (Chevalley--Shephard--Todd), and that is not available here; finiteness of generation does not require it.

:::

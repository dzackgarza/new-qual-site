::: problem
Let $G$ be a group and let $H, K \le G$ be subgroups of finite index. Show that
$$
[G : H \cap K] \le [G : H] [G : K].
$$
:::

::: solution
**Goal:** Prove the index inequality $[G : H \cap K] \le [G : H] [G : K]$ for subgroups of finite index.

<1>1. Multiplicativity of indices in a subgroup tower:
    *Proof:*
    <2>1. The intersection $H \cap K$ is a subgroup of $H$, and $H$ is a subgroup of $G$, forming the chain $H \cap K \le H \le G$.
    <2>2. By the tower law for subgroup indices:
    $$[G : H \cap K] = [G : H] [H : H \cap K].$$

<1>2. Bounding the index $[H : H \cap K] \le [G : K]$ via an injective coset map:
    *Proof:*
    <2>1. Let $H / (H \cap K) = \{h(H \cap K) : h \in H\}$ be the set of left cosets of $H \cap K$ in $H$, and let $G/K = \{g K : g \in G\}$ be the set of left cosets of $K$ in $G$.
    <2>2. Define the map $\Phi: H / (H \cap K) \to G/K$ by
    $$\Phi(h(H \cap K)) = h K \quad \text{for all } h \in H.$$
    <2>3. Well-definedness: Suppose $h_1(H \cap K) = h_2(H \cap K)$ for $h_1, h_2 \in H$. Then $h_2^{-1} h_1 \in H \cap K \subseteq K$, which implies $h_1 K = h_2 K$. Thus $\Phi(h_1(H \cap K)) = \Phi(h_2(H \cap K))$.
    <2>4. Injectivity: Suppose $\Phi(h_1(H \cap K)) = \Phi(h_2(H \cap K))$. Then $h_1 K = h_2 K$, which implies $h_2^{-1} h_1 \in K$.
    <2>5. Since $h_1, h_2 \in H$ and $H$ is a subgroup, $h_2^{-1} h_1 \in H$.
    <2>6. Thus $h_2^{-1} h_1 \in H \cap K$, which proves $h_1(H \cap K) = h_2(H \cap K)$.
    <2>7. Since $\Phi$ is an injection from $H / (H \cap K)$ into $G/K$:
    $$[H : H \cap K] = |H / (H \cap K)| \le |G / K| = [G : K].$$

<1>3. Conclusion:
    *Proof:*
    Combining <1>1 and <1>2 gives
    $$[G : H \cap K] = [G : H] [H : H \cap K] \le [G : H] [G : K].$$
:::

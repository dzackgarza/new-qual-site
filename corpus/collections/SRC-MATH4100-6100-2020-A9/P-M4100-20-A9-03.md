::: {.problem}
Let

$$
f _ { n } ( x ) = { \frac { n x + x ^ { 2 } } { 2 n } } \qquad { \mathrm { a n d } } \qquad g _ { n } ( x ) = { \frac { n x ^ { 2 } + 1 } { 2 n + x } }
$$

for each $x \in \mathbb { R }$ and $f ( x ) : = \operatorname* { l i m } _ { n \to \infty } f _ { n } ( x )$ and $g ( x ) : = \operatorname* { l i m } _ { n \to \infty } g _ { n } ( x )$ . Show that f and g are both differentiable on R in two ways: (i) by computing $f$ and g, and (ii) using theorems on uniform convergence.
:::

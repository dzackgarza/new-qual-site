::: {.problem}
Let

$$
f _ { n } ( x ) = { \frac { n x + x ^ { 2 } } { 2 n } } \qquad { \mathrm { a n d } } \qquad g _ { n } ( x ) = { \frac { n x ^ { 2 } + 1 } { 2 n + x } }
$$

For $g_n$, omit the at most one index for which $2n+x=0$; for each fixed $x$ the resulting tail is defined. Set $f ( x ) : = \operatorname* { l i m } _ { n \to \infty } f _ { n } ( x )$ and $g ( x ) : = \operatorname* { l i m } _ { n \to \infty } g _ { n } ( x )$ . Show that f and g are both differentiable on R in two ways: (i) by computing $f$ and g, and (ii) using theorems on uniform convergence.
:::

::: {.remark}
The source says that every $g_n$ is defined for every real $x$, but $g_n$ has a pole at $x=-2n$. The tailwise formulation above preserves the intended pointwise limits. On every bounded interval, all sufficiently large $n$ have their poles outside the interval, so the uniform-convergence differentiation theorem applies to that common smooth tail.
:::

::: pf

::: pf-step

For every $x\in\RR$,
$$
f_n(x)
=
\frac x2
+
\frac{x^2}{2n}.
$$
Hence
$$
\boxed{f(x)=\frac x2}.
$$


::: pf-proof

The displayed identity is algebraic. Since $x$ is fixed,
$$
\frac{x^2}{2n}\longrightarrow0.
$$
Therefore $f_n(x)\to x/2$.

:::

:::

::: pf-step

The function $f$ is differentiable on $\RR$ and
$$
f'(x)=\frac12.
$$


::: pf-proof

This follows immediately from the explicit formula in step <1>1.

:::

:::

::: pf-step

For every fixed $x\in\RR$,
$$
g_n(x)
=
\frac{x^2+1/n}{2+x/n}
\longrightarrow
\frac{x^2}{2}.
$$
Thus
$$
\boxed{g(x)=\frac{x^2}{2}}.
$$


::: pf-proof

Divide numerator and denominator by $n$. For every fixed $x$, the denominator
$2+x/n$ tends to $2$ and is nonzero for all sufficiently large $n$. Hence the
quotient tends to $x^2/2$.

:::

:::

::: pf-step

The function $g$ is differentiable on $\RR$ and
$$
g'(x)=x.
$$


::: pf-proof

This follows immediately from the explicit formula in step <1>3.

:::

:::

::: pf-step

Steps <1>1--<1>4 prove differentiability by directly computing the
pointwise limits.


::: pf-proof

Step <1>2 handles $f$ and step <1>4 handles $g$.

:::

::: pf-step

Fix $M>0$. On $[-M,M]$,
$$
f_n'(x)
=
\frac12+\frac xn
\longrightarrow
\frac12
$$
uniformly.


::: pf-proof

For $|x|\leq M$,
$$
\left|
f_n'(x)-\frac12
\right|
=
\frac{|x|}{n}
\leq
\frac Mn.
$$
Therefore
$$
\sup_{|x|\leq M}
\left|
f_n'(x)-\frac12
\right|
\leq
\frac Mn
\longrightarrow0.
$$

:::

:::

::: pf-step

The sequence $(f_n)$ converges at the point $0$:
$$
f_n(0)=0
$$
for every $n$.


::: pf-proof

Direct substitution gives the identity.

:::

:::

::: pf-step

By the uniform-convergence differentiation theorem, the limit of
$(f_n)$ on $[-M,M]$ is differentiable and has derivative $1/2$.


::: pf-proof

Each $f_n$ is differentiable on $[-M,M]$. Step <1>6 gives uniform convergence
of the derivatives, and step <1>7 gives convergence at one point. The standard
differentiation theorem for uniformly convergent derivative sequences therefore
applies.

:::

:::

::: pf-step

For all sufficiently large $n$, the function $g_n$ is differentiable on
$[-M,M]$, and
$$
g_n'(x)
=
\frac{4n^2x+n x^2-1}{(2n+x)^2}.
$$


::: pf-proof

If $n>M$, then the pole $x=-2n$ lies outside $[-M,M]$. Thus $g_n$ is
differentiable throughout the interval. The derivative formula follows from
the quotient rule:
$$
\begin{aligned}
g_n'(x)
&=
\frac{2nx(2n+x)-(nx^2+1)}
{(2n+x)^2}\\
&=
\frac{4n^2x+n x^2-1}{(2n+x)^2}.
\end{aligned}
$$

:::

:::

::: pf-step

On $[-M,M]$,
$$
g_n'(x)\longrightarrow x
$$
uniformly.


::: pf-proof

For $n>M$ and $|x|\leq M$,
$$
\begin{aligned}
g_n'(x)-x
&=
\frac{4n^2x+n x^2-1-x(2n+x)^2}
{(2n+x)^2}\\
&=
-\frac{3n x^2+x^3+1}{(2n+x)^2}.
\end{aligned}
$$
Also,
$$
|2n+x|
\geq
2n-M
>
n.
$$
Therefore
$$
|g_n'(x)-x|
\leq
\frac{3nM^2+M^3+1}{n^2}
=
\frac{3M^2}{n}
+
\frac{M^3+1}{n^2}.
$$
The right-hand side is independent of $x$ and tends to $0$.

:::

:::

::: pf-step

The sequence $(g_n)$ converges at the point $0$:
$$
g_n(0)=\frac1{2n}\longrightarrow0.
$$


::: pf-proof

Direct substitution gives
$$
g_n(0)=\frac1{2n}.
$$

:::

:::

::: pf-step

By the uniform-convergence differentiation theorem, the limit of the
tail $(g_n)$ on $[-M,M]$ is differentiable and has derivative $x$.


::: pf-proof

Discard finitely many indices so that $n>M$. Then every remaining $g_n$ is
differentiable on $[-M,M]$ by step <1>9. Step <1>10 gives uniform convergence
of the derivatives to the function $x\mapsto x$, and step <1>11 gives
convergence at the point $0$. Hence the differentiation theorem applies.

:::

:::

::: pf-step

Since $M>0$ was arbitrary, both limiting functions are differentiable
on all of $\RR$ by the uniform-convergence theorem.


::: pf-proof

Every real point lies in some interval $[-M,M]$. Steps <1>8 and <1>12 prove
differentiability of the two limits on every such interval.

:::

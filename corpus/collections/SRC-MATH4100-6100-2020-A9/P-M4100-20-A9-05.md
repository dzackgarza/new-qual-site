::: {.problem}
Let

$$
f ( x ) = \sum _ { n = 1 } ^ { \infty } { \frac { 1 } { x ^ { 2 } + n ^ { 2 } } } .
$$

(a) Show that $f$ is a continuous function on R.

(b) Is $f$ differentiable?
If so, is the derivative function $f ^ { \prime }$ continuous?

::: {.problem}
(a) Show that $f ( x ) = \sum _ { n = 1 } ^ { \infty } { \frac { \cos ( 2 ^ { n } x ) } { 2 ^ { n } } }$ is continuous on all of R.

(b) Show that $g ( x ) = \sum _ { n = 1 } ^ { \infty } { \frac { x ^ { n } } { n ^ { 2 } } }$ is continuous on $[ - 1 , 1 ]$
:::

::: pf

::: pf-step

For every $x\in\RR$ and every $n\geq1$,
$$
\left|
\frac{\cos(2^n x)}{2^n}
\right|
\leq
\frac1{2^n}.
$$


::: pf-proof

The cosine function satisfies
$$
|\cos t|\leq1
$$
for every real $t$.

:::

:::

::: pf-step

The series
$$
\sum_{n=1}^{\infty}
\frac{\cos(2^n x)}{2^n}
$$
converges uniformly on $\RR$.


::: pf-proof

By step <1>1, the $n$th term is bounded uniformly in $x$ by $2^{-n}$.
The geometric series
$$
\sum_{n=1}^{\infty}2^{-n}
$$
converges. The Weierstrass $M$-test therefore gives uniform convergence on
$\RR$.

:::

:::

::: pf-step

The function
$$
f(x)=
\sum_{n=1}^{\infty}
\frac{\cos(2^n x)}{2^n}
$$
is continuous on $\RR$.


::: pf-proof

Each partial sum is a finite sum of continuous functions and is therefore
continuous. By step <1>2, the partial sums converge uniformly to $f$.
The uniform limit of continuous functions is continuous.

:::

:::

::: pf-step

Part (a) follows.


::: pf-proof

This is step <1>3.

:::

:::

::: pf-step

For every $x\in[-1,1]$ and every $n\geq1$,
$$
\left|
\frac{x^n}{n^2}
\right|
\leq
\frac1{n^2}.
$$


::: pf-proof

On $[-1,1]$,
$$
|x|\leq1,
$$
so
$$
|x|^n\leq1.
$$

:::

:::

::: pf-step

The series
$$
\sum_{n=1}^{\infty}
\frac{x^n}{n^2}
$$
converges uniformly on $[-1,1]$.


::: pf-proof

By step <1>5, the $n$th term is bounded uniformly by $1/n^2$.
The $p$-series
$$
\sum_{n=1}^{\infty}\frac1{n^2}
$$
converges. The Weierstrass $M$-test gives uniform convergence.

:::

:::

::: pf-step

The function
$$
g(x)=
\sum_{n=1}^{\infty}
\frac{x^n}{n^2}
$$
is continuous on $[-1,1]$.


::: pf-proof

Each partial sum is a polynomial, hence continuous. Step <1>6 gives uniform
convergence to $g$. Therefore $g$ is continuous as a uniform limit of
continuous functions.

:::

:::

::: pf-step

Part (b) follows.


::: pf-proof

This is step <1>7.

:::

:::

::: pf-qed

Steps <1>4 and <1>8 establish parts (a) and (b), respectively.

:::

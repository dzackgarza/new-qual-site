::: {.problem}
Let W be the subset of the space $C [ 0 , 1 ]$ of real-valued, continuous functions on [0, 1] satisfying the conditions:

$$
| f ( x ) - f ( y ) | < | x - y | \qquad \int _ { 0 } ^ { 1 } f ( x ) ^ { 2 } d x = 1
$$

(A) Prove that W is uniformly bounded, i.e., there exists $M > 0$ such that $| f ( x ) | \leq M$ for all $x \in [ 0 , 1 ]$ Hint: Show first that $| f ( 0 ) | \le 2$ for all $f \in W$

(B) Prove that W is a compact subset of $C [ 0 , 1 ]$ under the sup norm $\| f \| _ { \infty } = \operatorname* { s u p } _ { x \in [ 0 , 1 ] } | f ( x ) |$
:::

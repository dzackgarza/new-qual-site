::: {.problem}
(a) Define the compactly supported cohomology groups $H_c^i(X)$ of a space $X$.

(b) Show that $H_c^i$ is not a cohomology theory. More precisely, show that there is no cohomology theory $h^*$ such that $h^i(X)\cong H_c^i(X)$ for all spaces $X$ and integers $i$.
:::

We use singular cohomology with coefficients in $\mathbb Z$.

::: pf

::: pf-step

If $K\subseteq L\subseteq X$ are compact, then inclusion of pairs induces
\[
\boxed{H^i(X,X\setminus K)\longrightarrow H^i(X,X\setminus L)}.
\]


::: pf-proof

Since $K\subseteq L$, one has $X\setminus L\subseteq X\setminus K$, so there is an inclusion
\[
(X,X\setminus L)\hookrightarrow(X,X\setminus K).
\]
Relative cohomology is contravariant, which gives the displayed map.

:::

:::

::: pf-step

These groups form a directed system as $K$ ranges over the compact subsets of $X$.


::: pf-proof

Compact subsets are directed by inclusion because $K\cup L$ is compact. Functoriality of relative cohomology makes the maps from step <1>1 compatible under chains $K\subseteq L\subseteq M$.

:::

:::

::: pf-step

Define
\[
\boxed{
H_c^i(X)
\coloneqq
\varinjlim_{K\subseteq X\text{ compact}}H^i(X,X\setminus K)}.
\]


::: pf-proof

This is the compactly supported cohomology associated to the directed system in step <1>2.

:::

:::

::: pf-step

For the one-point space,
\[
\boxed{H_c^0(\{\ast\})\cong\mathbb Z}.
\]


::: pf-proof

The point is compact, and the terminal compact subset is $K=\{\ast\}$. Thus
\[
H_c^0(\{\ast\})
\cong
H^0(\{\ast\},\varnothing)
\cong
\mathbb Z.
\]

:::

:::

::: pf-step

For every compact $K\subset\mathbb R$,
\[
\boxed{H^0(\mathbb R,\mathbb R\setminus K)=0}.
\]


::: pf-proof

The long exact sequence of the pair begins
\[
0\to H^0(\mathbb R,\mathbb R\setminus K)\to H^0(\mathbb R)\xrightarrow{\rho}H^0(\mathbb R\setminus K).
\]
Because $K$ is compact, $\mathbb R\setminus K$ is nonempty. The generator $1\in H^0(\mathbb R)\cong\mathbb Z$ restricts to a nonzero class on $\mathbb R\setminus K$, so $\rho$ is injective. Exactness gives the claim.

:::

:::

::: pf-step

Therefore
\[
\boxed{H_c^0(\mathbb R)=0}.
\]


::: pf-proof

Every group in the directed system defining $H_c^0(\mathbb R)$ is zero by step <1>5, so the direct limit is zero.

:::

:::

::: pf-step

The spaces $\mathbb R$ and $\{\ast\}$ are homotopy equivalent.


::: pf-proof

The real line is contractible.

:::

:::

::: pf-step

No cohomology theory $h^*$ can satisfy $h^i(X)\cong H_c^i(X)$ for all spaces $X$ and all integers $i$.


::: pf-proof

Every cohomology theory is homotopy invariant, so step <1>7 would imply
\[
h^0(\mathbb R)\cong h^0(\{\ast\}).
\]
If $h^0$ agreed with compactly supported cohomology on every space, steps <1>4 and <1>6 would instead give
\[
h^0(\mathbb R)\cong0,
\qquad
h^0(\{\ast\})\cong\mathbb Z,
\]
a contradiction.

:::

:::

::: pf-qed

Step <1>3 answers part (a), and step <1>8 proves part (b).

:::

:::

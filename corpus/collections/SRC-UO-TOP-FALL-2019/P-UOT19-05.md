::: {.problem}
(a) Define the compactly supported cohomology groups $H_c^i(X)$ of a space $X$.

(b) Show that $H_c^i$ is not a cohomology theory. More precisely, show that there is no cohomology theory $h^*$ such that $h^i(X)\cong H_c^i(X)$ for all spaces $X$ and integers $i$.
:::

::: {.solution}

We use singular cohomology with coefficients in $\ZZ$.

::: pf

::: {.pf-step #s1-1}

If $K\subseteq L\subseteq X$ are compact, then inclusion of pairs induces
$$
\boxed{H^i(X,X\setminus K)\longrightarrow H^i(X,X\setminus L)}.
$$


::: pf-proof

Since $K\subseteq L$, one has $X\setminus L\subseteq X\setminus K$, so there is an inclusion
$$
(X,X\setminus L)\hookrightarrow(X,X\setminus K).
$$
Relative cohomology is contravariant, which gives the displayed map.

:::

:::

::: {.pf-step #s1-2}

These groups form a directed system as $K$ ranges over the compact subsets of $X$.


::: pf-proof

Compact subsets are directed by inclusion because $K\cup L$ is compact. Functoriality of relative cohomology makes the maps from step [](#s1-1){.pf-ref} compatible under chains $K\subseteq L\subseteq M$.

:::

:::

::: {.pf-step #s1-3}

Define
$$
\boxed{
H_c^i(X)
\coloneqq
\varinjlim_{K\subseteq X\text{ compact}}H^i(X,X\setminus K)}.
$$


::: pf-proof

This is the compactly supported cohomology associated to the directed system in step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-4}

For the one-point space,
$$
\boxed{H_c^0(\{\ast\})\cong\ZZ}.
$$


::: pf-proof

The point is compact, and the terminal compact subset is $K=\{\ast\}$. Thus
$$
H_c^0(\{\ast\})
\cong
H^0(\{\ast\},\varnothing)
\cong
\ZZ.
$$

:::

:::

::: {.pf-step #s1-5}

For every compact $K\subset\RR$,
$$
\boxed{H^0(\RR,\RR\setminus K)=0}.
$$


::: pf-proof

The long exact sequence of the pair begins
$$
0\to H^0(\RR,\RR\setminus K)\to H^0(\RR)\xrightarrow{\rho}H^0(\RR\setminus K).
$$
Because $K$ is compact, $\RR\setminus K$ is nonempty. The generator $1\in H^0(\RR)\cong\ZZ$ restricts to a nonzero class on $\RR\setminus K$, so $\rho$ is injective. Exactness gives the claim.

:::

:::

::: {.pf-step #s1-6}

Therefore
$$
\boxed{H_c^0(\RR)=0}.
$$


::: pf-proof

Every group in the directed system defining $H_c^0(\RR)$ is zero by step [](#s1-5){.pf-ref}, so the direct limit is zero.

:::

:::

::: {.pf-step #s1-7}

The spaces $\RR$ and $\{\ast\}$ are homotopy equivalent.


::: pf-proof

The real line is contractible.

:::

:::

::: {.pf-step #s1-8}

No cohomology theory $h^*$ can satisfy $h^i(X)\cong H_c^i(X)$ for all spaces $X$ and all integers $i$.


::: pf-proof

Every cohomology theory is homotopy invariant, so step [](#s1-7){.pf-ref} would imply
$$
h^0(\RR)\cong h^0(\{\ast\}).
$$
If $h^0$ agreed with compactly supported cohomology on every space, steps [](#s1-4){.pf-ref} and [](#s1-6){.pf-ref} would instead give
$$
h^0(\RR)\cong0,
\qquad
h^0(\{\ast\})\cong\ZZ,
$$
a contradiction.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} answers part (a), and step [](#s1-8){.pf-ref} proves part (b).

:::

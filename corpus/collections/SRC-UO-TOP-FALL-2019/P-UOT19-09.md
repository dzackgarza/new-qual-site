::: {.problem}
Recall that oriented $3$-dimensional vector bundles over $X$ are classified by
\[
[X,\operatorname{Gr}_3^+(\RR^\infty)],
\]
where
\[
\operatorname{Gr}_3^+(\RR^\infty)=V_3(\RR^\infty)/SO(3).
\]
Compute $\pi_i(\operatorname{Gr}_3^+(\RR^\infty))$ for $i\le 4$. (Hint: recall that $SO(3)\cong\mathbb{RP}^3$.)
:::

::: {.solution}

Write
\[
B=\operatorname{Gr}_3^+(\RR^\infty).
\]

::: pf

::: {.pf-step #s1-1}

There is a fibration
\[
\boxed{SO(3)\longrightarrow V_3(\RR^\infty)\longrightarrow B}.
\]


::: pf-proof

The group \(SO(3)\) acts freely on the infinite Stiefel manifold
\[
V_3(\RR^\infty)
\]
by changing an oriented orthonormal frame within a fixed oriented
\(3\)-plane. The orbit space is precisely
\[
V_3(\RR^\infty)/SO(3)=B.
\]

:::

:::

::: {.pf-step #s1-2}

The space \(V_3(\RR^\infty)\) is contractible.


::: pf-proof

The infinite Stiefel manifold is the universal free \(SO(3)\)-space
\[
ESO(3).
\]
Equivalently, the connectivity of \(V_3(\RR^N)\) tends to infinity
with \(N\), so the infinite-dimensional limit is contractible.

:::

:::

::: {.pf-step #s1-3}

For every \(i\ge2\),
\[
\boxed{\pi_i(B)\cong\pi_{i-1}(SO(3))}.
\]


::: pf-proof

The long exact sequence of the fibration from step [](#s1-1){.pf-ref} contains
\[
\pi_i(V_3(\RR^\infty))
\to
\pi_i(B)
\to
\pi_{i-1}(SO(3))
\to
\pi_{i-1}(V_3(\RR^\infty)).
\]
The outer groups vanish by step [](#s1-2){.pf-ref}, so the middle arrow is an
isomorphism.

:::

:::

::: {.pf-step #s1-4}

One has
\[
\boxed{\pi_1(B)=0}.
\]


::: pf-proof

The beginning of the same long exact sequence gives
\[
\pi_1(V_3(\RR^\infty))
\to
\pi_1(B)
\to
\pi_0(SO(3)).
\]
The first group is zero by step [](#s1-2){.pf-ref}, and the last is zero because \(SO(3)\)
is connected.

:::

:::

::: {.pf-step #s1-5}

One has
\[
\boxed{\pi_1(SO(3))\cong\ZZ/2}.
\]


::: pf-proof

Using
\[
SO(3)\cong\mathbb{RP}^3,
\]
the universal covering
\[
S^3\to\mathbb{RP}^3
\]
has deck group \(\ZZ/2\). Hence
\[
\pi_1(SO(3))\cong\ZZ/2.
\]

:::

:::

::: {.pf-step #s1-6}

For \(j>1\),
\[
\boxed{\pi_j(SO(3))\cong\pi_j(S^3)}.
\]


::: pf-proof

Covering maps induce isomorphisms on all homotopy groups in degrees greater
than \(1\). Apply this to the universal cover
\[
S^3\to\mathbb{RP}^3\cong SO(3).
\]

:::

:::

::: {.pf-step #s1-7}

One has
\[
\boxed{\pi_2(SO(3))=0}.
\]


::: pf-proof

By step [](#s1-6){.pf-ref},
\[
\pi_2(SO(3))
\cong
\pi_2(S^3)
=0.
\]

:::

:::

::: {.pf-step #s1-8}

One has
\[
\boxed{\pi_3(SO(3))\cong\ZZ}.
\]


::: pf-proof

Again by step [](#s1-6){.pf-ref},
\[
\pi_3(SO(3))
\cong
\pi_3(S^3).
\]
The Hurewicz theorem gives
\[
\pi_3(S^3)
\cong
H_3(S^3;\ZZ)
\cong
\ZZ.
\]

:::

:::

::: {.pf-step #s1-9}

Therefore
\[
\boxed{
\pi_i\!\left(\operatorname{Gr}_3^+(\RR^\infty)\right)
\cong
\begin{cases}
0,&i=1,\\
\ZZ/2,&i=2,\\
0,&i=3,\\
\ZZ,&i=4.
\end{cases}}
\]


::: pf-proof

Use step [](#s1-4){.pf-ref} for \(i=1\). For \(i=2,3,4\), combine the shift from
step [](#s1-3){.pf-ref} with steps [](#s1-5){.pf-ref} and [](#s1-7){.pf-ref}, and [](#s1-8){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-9){.pf-ref} is the requested computation.

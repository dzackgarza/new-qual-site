::: {.problem}
Let $(\mathbb{RP}^2)^{2019}$ be the product of 2019 copies of $\mathbb{RP}^2$. Suppose
\[
f:(\mathbb{RP}^2)^{2019}\to(\mathbb{RP}^2)^{2019}
\]
is continuous. Show that $f$ has a fixed point.
:::

::: {.solution}

Set
\[
X=(\mathbb{RP}^2)^{2019}.
\]

::: pf

::: {.pf-step #s1-1}

The integral homology of \(\mathbb{RP}^2\) is
\[
\boxed{
H_k(\mathbb{RP}^2;\ZZ)
\cong
\begin{cases}
\ZZ,&k=0,\\
\ZZ/2,&k=1,\\
0,&k\ge2.
\end{cases}}
\]


::: pf-proof

This is the standard cellular-homology computation for the CW structure on
\(\mathbb{RP}^2\) with one cell in each dimension \(0,1,2\). The cellular
boundary map
\[
C_2\to C_1
\]
is multiplication by \(2\), while
\[
C_1\to C_0
\]
is zero.

:::

:::

::: {.pf-step #s1-2}

With rational coefficients,
\[
\boxed{
H_k(\mathbb{RP}^2;\QQ)
\cong
\begin{cases}
\QQ,&k=0,\\
0,&k>0.
\end{cases}}
\]


::: pf-proof

Tensor the groups in step [](#s1-1){.pf-ref} with \(\QQ\). The torsion group
\[
\ZZ/2
\]
vanishes after tensoring with \(\QQ\), and there are no higher groups.
Equivalently, apply the universal coefficient theorem over the field
\(\QQ\).

:::

:::

::: {.pf-step #s1-3}

The rational homology of \(X\) is
\[
\boxed{
H_k(X;\QQ)
\cong
\begin{cases}
\QQ,&k=0,\\
0,&k>0.
\end{cases}}
\]


::: pf-proof

Apply the Künneth theorem over the field \(\QQ\). Each factor has
nonzero rational homology only in degree \(0\) by step [](#s1-2){.pf-ref}. Therefore the
tensor product contributing to the homology of the product is nonzero only
when every factor contributes degree \(0\), which gives total degree \(0\).

:::

:::

::: {.pf-step #s1-4}

The induced map
\[
f_*:
H_0(X;\QQ)\to H_0(X;\QQ)
\]
is the identity.


::: pf-proof

The space \(X\) is connected because each factor \(\mathbb{RP}^2\) is
connected. Thus
\[
H_0(X;\QQ)\cong\QQ
\]
is generated by the class of any point. Every continuous map of a connected
space to itself sends a point to a point in the same connected component, so
the induced map on \(H_0\) is the identity.

:::

:::

::: {.pf-step #s1-5}

The Lefschetz number of \(f\) is
\[
\boxed{L(f)=1}.
\]


::: pf-proof

By definition,
\[
L(f)
=
\sum_{k\ge0}
(-1)^k
\operatorname{tr}
\left(
f_*:H_k(X;\QQ)\to H_k(X;\QQ)
\right).
\]
By step [](#s1-3){.pf-ref}, all terms with \(k>0\) vanish. By step [](#s1-4){.pf-ref}, the degree-zero
trace is \(1\). Hence
\[
L(f)=1.
\]

:::

:::

::: {.pf-step #s1-6}

The space \(X\) is a compact finite CW complex.


::: pf-proof

The real projective plane is a finite CW complex. A finite product of finite
CW complexes is again a finite CW complex, and \(X\) is a finite product
with \(2019\) factors. It is compact because each factor is compact.

:::

:::

::: {.pf-step #s1-7}

The map \(f\) has a fixed point.


::: pf-proof

The Lefschetz fixed-point theorem applies to self-maps of finite CW
complexes: if the Lefschetz number is nonzero, then the map has a fixed
point. Steps [](#s1-5){.pf-ref} and [](#s1-6){.pf-ref} give
\[
L(f)=1\ne0.
\]
Therefore there exists
\[
x\in X
\]
such that
\[
f(x)=x.
\]

:::

:::

::: pf-qed

Step [](#s1-7){.pf-ref} is the required conclusion.

:::

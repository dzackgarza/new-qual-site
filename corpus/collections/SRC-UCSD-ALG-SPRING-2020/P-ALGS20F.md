::: problem
Let $F$ be a field with algebraic closure $\overline{F}$.
Let $F \subseteq K \subseteq \overline{F}$ and $F \subseteq L \subseteq \overline{F}$, where $K$ and $L$ are fields with $[K:F] < \infty$ and $[L:F] < \infty$.
Prove that the following conditions are equivalent:

(1) $K \otimes_F L$ is a field.

(2) Given any $F$-linearly independent elements $\alpha_1, \ldots, \alpha_m \in K$, then $\alpha_1, \ldots, \alpha_m$ are linearly independent over $L$.
:::

::: {.solution}
<1>1. $K \otimes_F L$ is a finite-dimensional $F$-algebra, and it is a field iff it is an integral domain.
::: {.proof}
a finite-dimensional integral domain over a field is a field (multiplication by a nonzero element is injective, hence surjective by finite dimension).
:::

<1>2. The multiplication map $\mu : K \otimes_F L \to KL$ (the compositum) is surjective.
::: {.proof}
$KL$ is generated by products $k\ell$, which are the images of $k \otimes \ell$.
:::

<1>3. $K \otimes_F L$ is a field iff $\mu$ is injective.
::: {.proof}
<1>1 and <1>2; $\mu$ is a ring homomorphism, so it is injective iff its kernel is zero, and $K \otimes_F L$ is a field iff it has no nonzero zero-divisors, which (for this surjection onto the field $KL$) is equivalent to injectivity.
:::

<1>4. $\ker \mu$ consists of all $\sum_i \alpha_i \otimes \ell_i$ with $\sum_i \alpha_i \ell_i = 0$ in $KL$.
::: {.proof}
definition of $\mu$.
:::

<1>5. $\mu$ is injective iff every $F$-linearly independent set $\{\alpha_1, \ldots, \alpha_m\} \subseteq K$ remains linearly independent over $L$.
::: {.proof}
a relation $\sum_i \alpha_i \ell_i = 0$ with $\ell_i \in L$ not all zero is exactly a nontrivial element of $\ker \mu$ (writing it as $\sum_i \alpha_i \otimes \ell_i$); conversely any element of $\ker \mu$ gives such a relation.
:::

<1>6. Hence (1) $\iff$ (2).
::: {.proof}
<1>3 and <1>5.
:::

<1>7. Q.E.D.
::: {.proof}
<1>6.
:::
:::

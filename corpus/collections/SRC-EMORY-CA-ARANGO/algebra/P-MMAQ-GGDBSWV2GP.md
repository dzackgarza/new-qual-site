::: problem
1. Let $G$ be a group of order $n$.
   Suppose that for every divisor $d$ of $n$, $G$ contains at most one subgroup of order $d$.
   Show that $G$ is clyclic.

2. Let $F$ be a field.
   Show that every finite subgroup of the group of units $F^\times$ is cyclic.
:::

::: {.solution}
**Part 1.**

<1>1. For each divisor $d$ of $n$, let $a_d$ be the number of elements of $G$ of order exactly $d$.
::: {.proof}
define the counting function.
:::

<1>2. If $G$ has an element of order $d$, then it has a cyclic subgroup of order $d$, which (by hypothesis) is the unique subgroup of order $d$.
::: {.proof}
the subgroup generated by an element of order $d$ has order $d$.
:::

<1>3. A cyclic group of order $d$ has exactly $\varphi(d)$ elements of order $d$.
::: {.proof}
standard fact about cyclic groups.
:::

<1>4. Hence $a_d \in \{0, \varphi(d)\}$ for each $d$.
::: {.proof}
if there is no element of order $d$, then $a_d = 0$; if there is one, then the unique subgroup of order $d$ is cyclic and contains all $\varphi(d)$ elements of order $d$, so $a_d = \varphi(d)$.
:::

<1>5. $n = \sum_{d \mid n} a_d \le \sum_{d \mid n} \varphi(d) = n$.
::: {.proof}
every element has some order dividing $n$; and $\sum_{d \mid n} \varphi(d) = n$.
:::

<1>6. Hence $a_d = \varphi(d)$ for every $d \mid n$.
::: {.proof}
<1>4 and <1>5 force equality term-by-term.
:::

<1>7. In particular, $a_n = \varphi(n) > 0$, so $G$ has an element of order $n$.
::: {.proof}
<1>6 with $d = n$.
:::

<1>8. Therefore $G$ is cyclic.
::: {.proof}
an element of order $n$ generates $G$.
:::

**Part 2.**

<1>1. Let $H \le F^\times$ be a finite subgroup of order $n$.
::: {.proof}
setup.
:::

<1>2. For each divisor $d$ of $n$, $H$ has at most one subgroup of order $d$.
::: {.proof}
the elements of $H$ of order dividing $d$ are roots of the polynomial $x^d - 1$ in the field $F$, and a polynomial of degree $d$ over a field has at most $d$ roots; hence there are at most $d$ such elements, so at most one subgroup of order $d$.
:::

<1>3. Hence $H$ is cyclic by part 1.
::: {.proof}
<1>2 and part 1.
:::

<1>4. Q.E.D.
::: {.proof}
<1>8 (part 1) and <1>3 (part 2).
:::
:::

::: {.problem}
Show that if $p\in \mathbb Z$ is prime, then $a^p = a$ for all $a\in \mathbb Z_p$, or equivalently $c^p \equiv c \mod p$ for all $c\in \mathbb Z$.
:::

::: solution
**Theorem.**  
For prime $p$ and any $a\in\mathbb Z_p$, one has $a^p=a$.

1. If $a=0$, then $a^p=0=a$.

2. If $a\neq0$ in $\mathbb Z_p$, then $a$ is a unit.
   The group $\mathbb Z_p^\times$ has order $p-1$.
   Lagrange gives $a^{p-1}=1$.
   Multiply both sides by $a$ and get $a^p=a$.

3. For any integer $c$, let $a=[c]_p\in\mathbb Z_p$ be its residue class.
   Since $c\equiv a\pmod p$, powers are congruent mod $p$:
   \[
   c^p\equiv a^p=a\equiv c\pmod p.
   \]

Hence $a^p=a$ in $\mathbb Z_p$, equivalently $c^p\equiv c\pmod p$ for every integer $c$.
:::

::: {.problem}
Show that if $p\in \ZZ$ is prime, then $a^p = a$ for all $a\in \ZZ_p$, or equivalently $c^p \equiv c \pmod p$ for all $c\in \ZZ$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For every $a\in\ZZ_p$, $a^p=a$.

::: pf-proof

If $a=0$, then $a^p=0=a$. If $a\neq0$, then $a$ is a unit of the field $\ZZ_p$, and the group $\ZZ_p^\times$ has order $p-1$. By Lagrange's theorem $a^{p-1}=1$, and multiplying by $a$ gives $a^p=a$.

:::

:::

::: {.pf-step #s2}

For every $c\in\ZZ$, $c^p\equiv c\pmod p$.

::: pf-proof

Let $a=[c]_p\in\ZZ_p$ be the residue class of $c$. Reduction modulo $p$ is a ring homomorphism $\ZZ\to\ZZ_p$, so $[c^p]_p=a^p=a=[c]_p$ by step [](#s1){.pf-ref}.

:::

:::

::: pf-qed

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} give both forms of the statement; they are equivalent because every element of $\ZZ_p$ is the class of an integer.

:::

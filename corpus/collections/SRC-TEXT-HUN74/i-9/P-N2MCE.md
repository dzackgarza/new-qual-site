::: {.problem}
Let $F$ be a free group and for a fixed integer $n$, let $H_n$ be the subgroup generated by the set $\{ x^n \mid x \in F \}$.
Show that $H_n \trianglelefteq F$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For all $g, x \in F$, $g x^n g^{-1} = (g x g^{-1})^n$.

::: pf-proof

Conjugation by $g$ is a homomorphism $F \to F$, so it sends $x^n$ to $(g x g^{-1})^n$.

:::

:::

::: {.pf-step #s2}

For all $g, x \in F$, $g x^n g^{-1} \in H_n$.

::: pf-proof

The element $g x g^{-1}$ lies in $F$, so its $n$th power $(g x g^{-1})^n$ is one of the generators of $H_n$. Step [](#s1){.pf-ref} identifies this power with $g x^n g^{-1}$.

:::

:::

::: {.pf-step #s3}

For every $g \in F$, $g H_n g^{-1} \subseteq H_n$.

::: pf-proof

Conjugation by $g$ is a homomorphism, so $g H_n g^{-1}$ is the subgroup generated by the conjugates $g x^n g^{-1}$ of the generators of $H_n$. By step [](#s2){.pf-ref} these conjugates lie in $H_n$, hence so does the subgroup they generate.

:::

:::

::: pf-qed

Step [](#s3){.pf-ref} is the definition of $H_n \trianglelefteq F$.

:::

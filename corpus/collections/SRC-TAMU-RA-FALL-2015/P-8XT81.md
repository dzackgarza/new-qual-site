::: {.problem}
Let $f:\mathbb{R}\to\mathbb{R}$ be a Borel measurable function.
For each $t\in\mathbb{R}$ define $$f_t(x)=f(t+x),\qquad x\in\mathbb{R}.$$ Prove that $f_t(x)$ is a Borel measurable function (in $x$) for each fixed $t\in\mathbb{R}$.
:::


::: {.solution}
Fix $t\in\mathbb R$ and define
\[
\tau_t:\mathbb R\to\mathbb R,
\qquad
\tau_t(x)=x+t.
\]

<1>1. $\tau_t$ is Borel measurable.
::: {.proof}
The map $\tau_t$ is continuous.
Every continuous map between topological spaces equipped with their Borel $\sigma$-algebras is Borel measurable.
Thus $\tau_t$ is Borel measurable.
:::

<1>2. $f_t=f\circ\tau_t$ is Borel measurable.
::: {.proof}
By definition,
\[
f_t(x)=f(t+x)=f(\tau_t(x)).
\]
The function $f$ is Borel measurable by hypothesis, and $\tau_t$ is Borel measurable by <1>1.
The composition of measurable maps is measurable.
Therefore
\[
f_t=f\circ\tau_t
\]
is Borel measurable.
:::
:::

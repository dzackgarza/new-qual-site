::: {.problem}
Let $Y$ be a closed subspace of a Banach space $X$, with norm $\|\cdot\|$.
Let $|||\cdot|||$ be a norm on $Y$ which is equivalent to $\|\cdot\|$, meaning that there is a $C\ge 1$ so that $$\frac1C\,|||y|||\le\|y\|\le C|||y|||\qquad\text{for all }y\in Y.$$ Let $S$ be the set of all linear functionals $\varphi:X\to\mathbb{R}$ so that $$|\varphi(y)|\le|||y|||\qquad\text{for all }y\in Y,$$ and $$|\varphi(x)|\le C\|x\|\qquad\text{for all }x\in X.$$ Prove the following statements:

(i) $||||x||||:=\sup_{\varphi\in S}|\varphi(x)|$, $x\in X$, defines a norm on $X$.

(ii) $||||y|||| = |||y|||$ for $y\in Y$.

(iii) The norms $||||\cdot||||$ and $\|\cdot\|$ are equivalent on $X$.
:::

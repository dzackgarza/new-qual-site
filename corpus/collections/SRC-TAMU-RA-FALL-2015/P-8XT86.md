::: {.problem}
Let $Y$ be a closed subspace of a Banach space $X$, with norm $\|\cdot\|$.
Let $|||\cdot|||$ be a norm on $Y$ which is equivalent to $\|\cdot\|$, meaning that there is a $C\ge 1$ so that $$\frac1C\,|||y|||\le\|y\|\le C|||y|||\qquad\text{for all }y\in Y.$$ Let $S$ be the set of all linear functionals $\varphi:X\to\mathbb{R}$ so that $$|\varphi(y)|\le|||y|||\qquad\text{for all }y\in Y,$$ and $$|\varphi(x)|\le C\|x\|\qquad\text{for all }x\in X.$$ Prove the following statements:

(i) $||||x||||:=\sup_{\varphi\in S}|\varphi(x)|$, $x\in X$, defines a norm on $X$.

(ii) $||||y|||| = |||y|||$ for $y\in Y$.

(iii) The norms $||||\cdot||||$ and $\|\cdot\|$ are equivalent on $X$.
:::


::: {.solution}
Write
\[
N(x):=\sup_{\varphi\in S}|\varphi(x)|,
\qquad x\in X.
\]

<1>1. For every $x\in X$,
\[
N(x)\le C\|x\|.
\]
::: {.proof}
Every $\varphi\in S$ satisfies
\[
|\varphi(x)|\le C\|x\|.
\]
Taking the supremum over $\varphi\in S$ gives the claim. In particular, $N(x)$ is finite.
:::

<1>2. For every $x\in X$,
\[
N(x)\ge \frac1C\|x\|.
\]
::: {.proof}
The case $x=0$ is immediate. Let $x\ne0$.
By Hahn--Banach for the original norm on $X$, there is a linear functional $\psi\in X^*$ such that
\[
\|\psi\|=1
\qquad\text{and}\qquad
\psi(x)=\|x\|.
\]
Set
\[
\varphi=\frac1C\psi.
\]
For every $u\in X$,
\[
|\varphi(u)|\le \frac1C\|u\|\le C\|u\|.
\]
For $y\in Y$, the assumed norm equivalence gives
\[
\|y\|\le C|||y|||,
\]
so
\[
|\varphi(y)|
\le \frac1C\|y\|
\le |||y|||.
\]
Hence $\varphi\in S$. Therefore
\[
N(x)\ge |\varphi(x)|
=\frac1C\|x\|.
\]
:::

<1>3. $N$ is a norm on $X$.
::: {.proof}
For every scalar $a$,
\[
N(ax)
=\sup_{\varphi\in S}|\varphi(ax)|
=|a|N(x).
\]
Also, for $x,z\in X$,
\[
\begin{aligned}
N(x+z)
&=\sup_{\varphi\in S}|\varphi(x)+\varphi(z)|\\
&\le
\sup_{\varphi\in S}\bigl(|\varphi(x)|+|\varphi(z)|\bigr)\\
&\le N(x)+N(z).
\end{aligned}
\]
Finally, if $N(x)=0$, then <1>2 gives
\[
\frac1C\|x\|\le0,
\]
so $x=0$.
Thus $N=||||\cdot||||$ is a norm.
:::

<1>4. For every $y\in Y$,
\[
N(y)\le |||y|||.
\]
::: {.proof}
This is immediate from the defining condition for $S$:
\[
|\varphi(y)|\le|||y|||
\qquad(\varphi\in S).
\]
Taking the supremum gives the inequality.
:::

<1>5. For every $y\in Y$,
\[
N(y)\ge |||y|||.
\]
::: {.proof}
Again the case $y=0$ is immediate. Fix $y\ne0$.
Apply Hahn--Banach in the normed space $(Y,|||\cdot|||)$ to the one-dimensional subspace $\mathbb R y$. There is a linear functional
\[
\ell:Y\to\mathbb R
\]
with
\[
|\ell(v)|\le|||v|||
\qquad(v\in Y)
\]
and
\[
\ell(y)=|||y|||.
\]
Because
\[
|||v|||\le C\|v\|
\]
by the other half of the assumed norm equivalence, we also have
\[
|\ell(v)|\le C\|v\|
\qquad(v\in Y).
\]
Hahn--Banach, now applied using the original norm on $X$, extends $\ell$ to a linear functional
\[
\varphi:X\to\mathbb R
\]
such that
\[
|\varphi(x)|\le C\|x\|
\qquad(x\in X).
\]
On $Y$, $\varphi=\ell$, hence
\[
|\varphi(v)|\le|||v|||
\qquad(v\in Y).
\]
Therefore $\varphi\in S$, and
\[
N(y)\ge|\varphi(y)|=|\ell(y)|=|||y|||.
\]
:::

<1>6. Consequently, the new norm restricts to $|||\cdot|||$ on $Y$.
::: {.proof}
Combining <1>4 and <1>5 yields
\[
||||y||||=N(y)=|||y|||
\qquad(y\in Y).
\]
:::

<1>7. The norms $||||\cdot||||$ and $\|\cdot\|$ are equivalent on $X$.
::: {.proof}
By <1>1 and <1>2,
\[
\frac1C\|x\|
\le
||||x||||
\le
C\|x\|
\qquad(x\in X).
\]
This is exactly equivalence of the two norms.
:::

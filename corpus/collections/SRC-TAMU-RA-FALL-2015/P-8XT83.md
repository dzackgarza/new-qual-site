::: {.problem}
Let $A$ be a Lebesgue null set in $\mathbb{R}$.
Prove that $$B:=\{e^x:x\in A\}$$ is also a null set.
:::


::: {.solution}
For each integer $n$, set
\[
A_n=A\cap[n,n+1].
\]
Then
\[
A=\bigcup_{n\in\mathbb Z}A_n
\qquad\text{and}\qquad
B=e^A=\bigcup_{n\in\mathbb Z}e^{A_n}.
\]

<1>1. The exponential map is Lipschitz on every interval $[n,n+1]$.
::: {.proof}
Fix $n\in\mathbb Z$.
For $x,y\in[n,n+1]$, the mean value theorem gives a point $\xi$ between $x$ and $y$ such that
\[
|e^x-e^y|=e^\xi|x-y|.
\]
Since $\xi\le n+1$,
\[
|e^x-e^y|\le e^{n+1}|x-y|.
\]
Thus $x\mapsto e^x$ is Lipschitz on $[n,n+1]$ with constant $e^{n+1}$.
:::

<1>2. Each set $e^{A_n}$ has Lebesgue measure zero.
::: {.proof}
Fix $n\in\mathbb Z$ and let $L=e^{n+1}$.
Since $A_n$ is null, for every $\varepsilon>0$ there is a countable collection of open intervals $I_k\subset\mathbb R$ such that
\[
A_n\subseteq\bigcup_{k=1}^\infty I_k
\qquad\text{and}\qquad
\sum_{k=1}^\infty |I_k|<\frac{\varepsilon}{L}.
\]
Replacing $I_k$ by $I_k\cap[n,n+1]$ does not increase the total length, so we may assume each interval lies in $[n,n+1]$.

Because the exponential map is increasing and $L$-Lipschitz on $[n,n+1]$, the image of each $I_k$ is an interval whose length is at most $L|I_k|$.
Hence
\[
e^{A_n}\subseteq\bigcup_{k=1}^\infty e^{I_k}
\]
and therefore the outer measure satisfies
\[
m^*(e^{A_n})
\le
\sum_{k=1}^\infty |e^{I_k}|
\le
L\sum_{k=1}^\infty |I_k|
<\varepsilon.
\]
Since $\varepsilon>0$ was arbitrary,
\[
m(e^{A_n})=0.
\]
:::

<1>3. Therefore $B$ is null.
::: {.proof}
By <1>2, every $e^{A_n}$ has measure zero.
Since
\[
B=\bigcup_{n\in\mathbb Z}e^{A_n}
\]
is a countable union of null sets,
\[
m(B)=0.
\]
:::
:::

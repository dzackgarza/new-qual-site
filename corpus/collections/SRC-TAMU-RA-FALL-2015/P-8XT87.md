::: {.problem}
Let $f$ be increasing on $[0,1]$ and let $$g(x)=\limsup_{h\to 0}\frac{f(x+h)-f(x-h)}{2h},\qquad\text{for }0<x<1.$$ Prove that if $A=\{x\in(0,1):g(x)>1\}$ then $$f(1)-f(0)\ge m^*(A).$$
:::

::: {.solution}
<1>1. For each $x \in A$, $g(x) > 1$, so there is a sequence $h_k \to 0$ with $\frac{f(x + h_k) - f(x - h_k)}{2h_k} > 1$.
::: {.proof}
definition of $\limsup$ (the limsup exceeds $1$ means there is a subsequence of difference quotients exceeding $1$).
:::

<1>2. Hence $f(x + h_k) - f(x - h_k) > 2h_k$ for these $h_k$.
::: {.proof}
<1>1.
:::

<1>3. The intervals $I_{x,k} = (x - h_k, x + h_k)$ form a Vitali cover of $A$.
::: {.proof}
<1>1 (for each $x \in A$ there are arbitrarily small intervals centered at $x$).
:::

<1>4. By the Vitali covering theorem, for any $\varepsilon > 0$ there are finitely many disjoint intervals $I_1, \ldots, I_N$ (of the form $(x_j - h_j, x_j + h_j)$ with $x_j \in A$) such that $m^*(A \setminus \bigcup_j I_j) < \varepsilon$.
::: {.proof}
Vitali covering theorem.
:::

<1>5. For each such interval $I_j = (x_j - h_j, x_j + h_j)$, $f(x_j + h_j) - f(x_j - h_j) > 2h_j = m(I_j)$.
::: {.proof}
<1>2.
:::

<1>6. Since $f$ is increasing and the intervals are disjoint, $\sum_j (f(x_j + h_j) - f(x_j - h_j)) \le f(1) - f(0)$.
::: {.proof}
the intervals $(x_j - h_j, x_j + h_j)$ are disjoint subintervals of $[0,1]$, and $f$ is increasing, so the total increase over disjoint intervals is at most the total increase $f(1) - f(0)$.
:::

<1>7. Hence $\sum_j m(I_j) < \sum_j (f(x_j + h_j) - f(x_j - h_j)) \le f(1) - f(0)$.
::: {.proof}
<1>5 and <1>6.
:::

<1>8. Therefore $m^*(A) \le \sum_j m(I_j) + \varepsilon \le f(1) - f(0) + \varepsilon$.
::: {.proof}
<1>4 and <1>7.
:::

<1>9. Since $\varepsilon > 0$ is arbitrary, $m^*(A) \le f(1) - f(0)$.
::: {.proof}
<1>8, letting $\varepsilon \to 0$.
:::

<1>10. Q.E.D.
::: {.proof}
<1>9.
:::
:::

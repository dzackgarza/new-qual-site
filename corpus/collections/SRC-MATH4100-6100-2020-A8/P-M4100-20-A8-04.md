::: {.problem}
Exactly one of the following requests is impossible.
Decide which it is, and provide examples for the other three.
In each case, lets assume that the functions are defined on all of R.

(a) Function $f$ and g not differentiable at $x _ { 0 } = 0$ , but where $f g$ is differentiable at $x _ { 0 } = 0$

(b) A function f not differentiable at $x _ { 0 } = 0$ and a function g differentiable at $x _ { 0 } = 0$ where $f g$ is differentiable at $x _ { 0 } = 0$

(c) A function f not differentiable at $x _ { 0 } = 0$ and a function $g$ differentiable at $x _ { 0 } = 0$ where $f + g$ is differentiable at $x _ { 0 } = 0$

(d) A function $f$ differentiable at $x _ { 0 } = 0$ , but not differentiable at any other point.
:::

::: pf

::: pf-step

For part (a), take
$$
f(x)=|x|,
\qquad
g(x)=|x|.
$$
Then neither $f$ nor $g$ is differentiable at $0$.


::: pf-proof

For $h>0$,
$$
\frac{|h|-|0|}{h}=1,
$$
while for $h<0$,
$$
\frac{|h|-|0|}{h}=-1.
$$
Thus the derivative at $0$ does not exist.

:::

:::

::: pf-step

For the functions in step <1>1,
$$
(fg)(x)=x^2,
$$
which is differentiable at $0$.


::: pf-proof

Since
$$
|x|^2=x^2,
$$
the product is the polynomial $x^2$, whose derivative at $0$ is $0$.

:::

:::

::: pf-step

Therefore request (a) is possible.


::: pf-proof

Steps <1>1--<1>2 give the required example.

:::

:::

::: pf-step

For part (b), take
$$
f(x)=|x|,
\qquad
g(x)=x.
$$
Then $f$ is not differentiable at $0$, while $g$ is differentiable at $0$.


::: pf-proof

Non-differentiability of $f$ is step <1>1. The function $g(x)=x$ is
differentiable everywhere, with derivative $1$.

:::

:::

::: pf-step

The product
$$
(fg)(x)=x|x|
$$
is differentiable at $0$.


::: pf-proof

Since $(fg)(0)=0$,
$$
\frac{(fg)(h)-(fg)(0)}h
=
\frac{h|h|}{h}
=
|h|
\longrightarrow0.
$$
Hence
$$
(fg)'(0)=0.
$$

:::

:::

::: pf-step

Therefore request (b) is possible.


::: pf-proof

Steps <1>4--<1>5 give the required example.

:::

:::

::: pf-step

Request (c) is impossible.


::: pf-proof

Suppose $g$ is differentiable at $0$ and $f+g$ is differentiable at $0$.
Then
$$
f=(f+g)-g.
$$
The difference of two functions differentiable at $0$ is differentiable at
$0$. Hence $f$ would be differentiable at $0$, contradicting the requirement
that it not be.

:::

:::

::: pf-step

For part (d), define
$$
f(x)=
\begin{cases}
x^2,&x\in\QQ,\\
0,&x\notin\QQ.
\end{cases}
$$
Then $f$ is differentiable at $0$.


::: pf-proof

For $h\neq0$,
$$
\left|
\frac{f(h)-f(0)}h
\right|
\leq
|h|.
$$
Hence by the squeeze theorem,
$$
f'(0)=0.
$$

:::

:::

::: pf-step

The function in step <1>8 is not differentiable at any $a\neq0$.


::: pf-proof

Fix $a\neq0$. By density of the rationals and irrationals, choose
$$
q_n\in\QQ,
\qquad
r_n\notin\QQ
$$
with
$$
q_n\to a,
\qquad
r_n\to a.
$$
Then
$$
f(q_n)=q_n^2\to a^2,
$$
while
$$
f(r_n)=0\to0.
$$
Since $a^2\neq0$, the function is discontinuous at $a$. Differentiability
would imply continuity, so $f$ cannot be differentiable at $a$.

:::

:::

::: pf-step

Therefore request (d) is possible.


::: pf-proof

Steps <1>8--<1>9 give a function differentiable exactly at $0$.

:::

:::

::: pf-step

Exactly one request is impossible:
$$
\boxed{\text{(c)}}.
$$


::: pf-proof

Steps <1>3, <1>6, and <1>10 construct examples for (a), (b), and (d),
respectively, while step <1>7 proves that (c) cannot occur.

:::

:::

::: pf-qed

Step <1>11 settles all four cases.

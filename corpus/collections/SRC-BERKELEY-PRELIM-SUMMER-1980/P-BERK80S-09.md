::: {.problem}
For each $( a , b , c ) \in \mathbb { R } ^ { 3 }$ , consider the series

$$
\sum _ { n = 3 } ^ { \infty } { \frac { a ^ { n } } { n ^ { b } ( \log n ) ^ { c } } } \cdotp
$$

Determine the values of $( a , b , c )$ for which the series

1. converges absolutely;

2. converges but not absolutely;

3. diverges.
:::

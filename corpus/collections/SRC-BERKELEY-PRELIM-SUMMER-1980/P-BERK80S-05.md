::: {.problem}
Consider the differential equations

$$
{ \frac { d x } { d t } } = - x + y , \quad { \frac { d y } { d t } } = \log ( 2 0 + x ) - y .
$$

Let $x ( t )$ and $y ( t )$ be a solution defined for all $t \geqslant 0$ with $x ( 0 ) > 0$ and $y ( 0 ) > 0$ . Prove that x(t) and $y ( t )$ are bounded.
:::

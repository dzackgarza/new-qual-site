::: {.problem}
Let C denote the positively oriented circle $| z | = 2 , z \in \mathbb { C }$ . Evaluate the integral

$$
\int _ { C } { \sqrt { z ^ { 2 } - 1 } } d z
$$

where the branch of the square root is chosen so that $\sqrt { 2 ^ { 2 } - 1 } > 0$
:::

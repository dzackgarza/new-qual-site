::: {.problem}
Let G be a finite group and $H \subset G$ a subgroup.

1. Show that the number of subgroups of G of the form $\mathrm { { c } } H \mathrm { { x } ^ { - 1 } }$ for some $x \in G$ is $\leqslant$ the index of H in G.

2. Prove that some element of G is not in any subgroup of the form x $; H x ^ { - 1 }$ $x \in G$
:::

::: {.problem}
Define paths $f,g:I\to S^2$ by
\[
f(s)=(\cos(2\pi s),\sin(2\pi s),0),
\qquad
g(s)=(1,0,0).
\]
Prove that $f$ is homotopic to $g$ relative to $\{0,1\}$; that is, prove that the two loops are path-homotopic.
:::

::: {.solution}

Let
\[
u(s)
\coloneqq
(\cos2\pi s,\sin2\pi s)
\in
\RR^2,
\]
and let
\[
p=(1,0).
\]

::: pf

::: {.pf-step #s1-1}

Define
\[
K:I\times I\to\RR^2
\]
by
\[
K(s,t)
=
(1-t)u(s)+tp.
\]
Then
\[
K(s,t)
\]
lies in the closed unit disk
\[
D^2.
\]


::: pf-proof

Both
\[
u(s)
\]
and
\[
p
\]
lie in the closed unit disk.
Because $D^2$ is convex, every convex combination
\[
(1-t)u(s)+tp
\]
also lies in $D^2$.

:::

:::

::: pf-step

Write
\[
K(s,t)
=
(X(s,t),Y(s,t)).
\]
Define
\[
H:I\times I\to S^2
\]
by
\[
\boxed{
H(s,t)
=
\left(
X(s,t),
Y(s,t),
\sqrt{
1-X(s,t)^2-Y(s,t)^2
}
\right).
}
\]


::: pf-proof

By step [](#s1-1){.pf-ref},
\[
X(s,t)^2+Y(s,t)^2
\le
1.
\]
Hence the square root is real and nonnegative.
Moreover,
\[
X^2+Y^2
+
\left(
\sqrt{1-X^2-Y^2}
\right)^2
=
1,
\]
so
\[
H(s,t)\in S^2.
\]

:::

:::

::: {.pf-step #s1-3}

The map $H$ is continuous.


::: pf-proof

The map $K$ is continuous because it is built from continuous trigonometric
functions and affine operations.
The function
\[
(x,y)
\longmapsto
\sqrt{1-x^2-y^2}
\]
is continuous on the closed unit disk.
Therefore the three coordinate functions of $H$ are continuous.

:::

:::

::: {.pf-step #s1-4}

At
\[
t=0,
\]
one has
\[
H(s,0)=f(s).
\]


::: pf-proof

When
\[
t=0,
\]
\[
K(s,0)
=
u(s)
=
(\cos2\pi s,\sin2\pi s).
\]
Since
\[
\cos^2(2\pi s)+\sin^2(2\pi s)=1,
\]
the third coordinate of $H$ is zero.
Thus
\[
H(s,0)
=
(\cos2\pi s,\sin2\pi s,0)
=
f(s).
\]

:::

:::

::: {.pf-step #s1-5}

At
\[
t=1,
\]
one has
\[
H(s,1)=g(s).
\]


::: pf-proof

When
\[
t=1,
\]
\[
K(s,1)
=
p
=
(1,0).
\]
Again the third coordinate is zero, so
\[
H(s,1)
=
(1,0,0)
=
g(s).
\]

:::

:::

::: {.pf-step #s1-6}

The endpoints are fixed throughout the homotopy:
\[
H(0,t)
=
H(1,t)
=
(1,0,0)
\qquad
(t\in I).
\]


::: pf-proof

Since
\[
u(0)
=
u(1)
=
(1,0)
=
p,
\]
one has
\[
K(0,t)
=
K(1,t)
=
p
\]
for every $t$.
Therefore the lifted points are always
\[
(1,0,0).
\]

:::

:::

::: {.pf-step #s1-7}

Hence $H$ is a path homotopy from $f$ to $g$ relative to
\[
\{0,1\}.
\]


::: pf-proof

Step [](#s1-3){.pf-ref} gives continuity.
Steps [](#s1-4){.pf-ref} through [](#s1-5){.pf-ref} give the initial and terminal paths.
Step [](#s1-6){.pf-ref} fixes both endpoints for every homotopy time.
These are exactly the conditions for a homotopy rel endpoints.

:::

:::

::: pf-step

Therefore
\[
\boxed{
[f]=[g]
}
\]
in
\[
\pi_1(S^2,(1,0,0)).
\]


::: pf-proof

Path-homotopic based loops represent the same fundamental-group element.

:::

:::

::: pf-qed

Step [](#s1-7){.pf-ref} proves the requested path homotopy.

:::

::: {.problem}
For a set $X$, define
\[
\mathcal B:=\{U\subseteq X:X\setminus U\text{ is infinite}\}\cup\{X\}.
\]

1. Show that $\mathcal B$ is a basis for a topology on $X$.

2. Identify the topology $\mathcal T(\mathcal B)$ for every set $X$, and prove your answer.
:::

::: pf

::: pf-step

The family $\mathcal B$ covers $X$.


::: pf-proof

By definition,
\[
X\in\mathcal B.
\]
Hence every point of $X$ belongs to at least one basis candidate.

:::

:::

::: pf-step

If
\[
U,V\in\mathcal B
\]
and
\[
x\in U\cap V,
\]
then there exists
\[
W\in\mathcal B
\]
such that
\[
x\in W\subseteq U\cap V.
\]


::: pf-proof

If
\[
U=V=X,
\]
take
\[
W=X.
\]

Otherwise at least one of $U,V$ is not $X$.
Suppose, without loss of generality,
\[
U\ne X.
\]
Then
\[
X\setminus U
\]
is infinite.
Now
\[
X\setminus(U\cap V)
=
(X\setminus U)\cup(X\setminus V),
\]
which contains the infinite set
\[
X\setminus U.
\]
Hence
\[
X\setminus(U\cap V)
\]
is infinite.
Therefore
\[
U\cap V\in\mathcal B.
\]
Take
\[
W=U\cap V.
\]

:::

:::

::: pf-step

Thus
\[
\boxed{
\mathcal B
\text{ is a basis for a topology on }X.
}
\]


::: pf-proof

The two basis axioms are exactly steps <1>1 and <1>2.

:::

:::

::: pf-step

Suppose $X$ is finite.
Then
\[
\mathcal B=\{X\}.
\]


::: pf-proof

If
\[
U\subseteq X,
\]
then
\[
X\setminus U
\]
is finite because $X$ is finite.
Thus no proper subset $U$ satisfies the condition that its complement be
infinite.
The only basis element supplied separately by the definition is $X$.

:::

:::

::: pf-step

If $X$ is finite, then
\[
\boxed{
\mathcal T(\mathcal B)
=
\{\varnothing,X\}.
}
\]


::: pf-proof

A topology generated by the one-element basis
\[
\{X\}
\]
consists of unions of basis elements.
The only such unions are
\[
\varnothing
\]
and
\[
X.
\]
Thus the topology is indiscrete.

:::

:::

::: pf-step

Suppose $X$ is infinite.
Then for every
\[
x\in X,
\]
the singleton
\[
\{x\}
\]
belongs to $\mathcal B$.


::: pf-proof

Since $X$ is infinite,
\[
X\setminus\{x\}
\]
is still infinite.
Therefore
\[
\{x\}\in\mathcal B.
\]

:::

:::

::: pf-step

If $X$ is infinite, then every subset
\[
A\subseteq X
\]
is open in
\[
\mathcal T(\mathcal B).
\]


::: pf-proof

By step <1>6,
\[
\{x\}\in\mathcal B
\]
for every
\[
x\in A.
\]
Hence
\[
A
=
\bigcup_{x\in A}\{x\}
\]
is a union of basis elements.
Therefore $A$ is open.

:::

:::

::: pf-step

Thus if $X$ is infinite,
\[
\boxed{
\mathcal T(\mathcal B)
=
\mathcal P(X),
}
\]
the discrete topology.


::: pf-proof

Step <1>7 shows every subset of $X$ is open.

:::

:::

::: pf-step

The complete answer is
\[
\boxed{
\mathcal T(\mathcal B)
=
\begin{cases}
\{\varnothing,X\},
&X\text{ finite},\\[1mm]
\mathcal P(X),
&X\text{ infinite}.
\end{cases}
}
\]


::: pf-proof

Combine steps <1>5 and <1>8.

:::

:::

::: pf-qed

Step <1>3 proves that $\mathcal B$ is a basis, and step <1>9 identifies
the generated topology in every case.

:::

:::

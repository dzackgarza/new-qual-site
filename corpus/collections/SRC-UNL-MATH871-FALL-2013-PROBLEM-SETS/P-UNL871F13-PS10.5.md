::: {.problem}
Let $X=\{a,b\}$ have the indiscrete topology.
Compute the fundamental group
\[
\pi_1(X,a),
\]
and prove your answer.
:::

::: {.solution}
<1>1. Every function from any topological space into $X$ is continuous.

::: {.proof}
The only open subsets of the indiscrete space $X$ are
\[
\varnothing
\qquad\text{and}\qquad
X.
\]
For any function
\[
f:Y\to X,
\]
\[
f^{-1}(\varnothing)
=
\varnothing
\]
and
\[
f^{-1}(X)
=
Y,
\]
both of which are open in $Y$.
Thus $f$ is continuous.
:::

<1>2. In particular, every function
\[
\gamma:[0,1]\to X
\]
with
\[
\gamma(0)=\gamma(1)=a
\]
is a based loop at $a$.

::: {.proof}
By step <1>1, every such set map is continuous.
The endpoint equalities make it a loop based at $a$.
:::

<1>3. Let
\[
\gamma_0,\gamma_1:[0,1]\to X
\]
be two based loops at $a$.
Define
\[
H:[0,1]\times[0,1]\to X
\]
by
\[
H(s,t)
=
\begin{cases}
\gamma_0(s),&t=0,\\
\gamma_1(s),&t=1,\\
a,&0<t<1.
\end{cases}
\]
Then $H$ is continuous.

::: {.proof}
The displayed rule defines a set map into $X$.
By step <1>1, every such map is continuous because the target is
indiscrete.
:::

<1>4. The homotopy $H$ is relative to the endpoints.

::: {.proof}
For
\[
t=0,
\]
\[
H(s,0)
=
\gamma_0(s).
\]
For
\[
t=1,
\]
\[
H(s,1)
=
\gamma_1(s).
\]

Also, because both loops are based at $a$,
\[
\gamma_0(0)
=
\gamma_0(1)
=
\gamma_1(0)
=
\gamma_1(1)
=
a.
\]
Hence for every
\[
t\in[0,1],
\]
\[
H(0,t)
=
H(1,t)
=
a.
\]
Thus the endpoints remain fixed throughout the homotopy.
:::

<1>5. Therefore every two based loops at $a$ are path-homotopic.

::: {.proof}
Steps <1>3--<1>4 construct a homotopy rel endpoints between arbitrary
based loops.
:::

<1>6. Hence there is exactly one element of
\[
\pi_1(X,a).
\]

::: {.proof}
The fundamental group consists of based loops modulo path homotopy.
By step <1>5, all based loops lie in the same homotopy class.
:::

<1>7. Consequently
\[
\boxed{
\pi_1(X,a)=0.
}
\]

::: {.proof}
A group with one element is the trivial group.
:::

<1>8. Q.E.D.

::: {.proof}
Step <1>7 is the required computation.
:::
:::

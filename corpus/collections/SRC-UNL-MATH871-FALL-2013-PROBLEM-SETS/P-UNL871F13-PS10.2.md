::: {.problem}
Let $X_f$ be the mapping cylinder of a continuous map $f:X\to Y$, and let
\[
j:Y\to X_f,\qquad j(y)=[y]
\]
denote the canonical inclusion.
Write $\overline Y=j(Y)$.

1. Define
   \[
   r:X_f\to\overline Y,
   \qquad
   r([(x,s)])=[f(x)],\quad r([y])=[y].
   \]
   Show that $r$ is a retraction.
   Show that
   \[
   F_t([(x,s)])=[(x,t+(1-t)s)],\qquad F_t([y])=[y]
   \]
   defines a deformation retraction of $X_f$ onto $\overline Y$.

2. Show that $j$ is an embedding and conclude that $X_f$ is homotopy equivalent to $Y$.
:::

Write
\[
q:
(X\times I)\sqcup Y
\longrightarrow
X_f
\]
for the quotient map, where
\[
(x,1)\sim f(x).
\]

::: pf

::: pf-step

Define
\[
p:X_f\to Y
\]
by
\[
p([(x,s)])=f(x),
\qquad
p([y])=y.
\]
Then $p$ is well defined and continuous.


::: pf-proof

On the disjoint union
\[
(X\times I)\sqcup Y,
\]
define
\[
\widetilde p(x,s)=f(x),
\qquad
\widetilde p(y)=y.
\]
This map is continuous on each summand, hence continuous on the disjoint
union.

The only identifications used to form $X_f$ are
\[
(x,1)\sim f(x),
\]
and
\[
\widetilde p(x,1)
=
f(x)
=
\widetilde p(f(x)).
\]
Thus $\widetilde p$ is constant on equivalence classes.
By the universal property of the quotient, it descends uniquely to a
continuous map
\[
p:X_f\to Y.
\]

:::

:::

::: pf-step

The canonical inclusion
\[
j:Y\to X_f,
\qquad
j(y)=[y],
\]
is injective and satisfies
\[
p\circ j
=
\operatorname{id}_Y.
\]


::: pf-proof

For
\[
y\in Y,
\]
\[
(p\circ j)(y)
=
p([y])
=
y.
\]
Hence
\[
p\circ j
=
\operatorname{id}_Y.
\]
A map with a left inverse is injective, so $j$ is injective.

:::

:::

::: pf-step

Define
\[
r:X_f\to\overline Y
\]
by
\[
r([(x,s)])=[f(x)],
\qquad
r([y])=[y].
\]
Then
\[
r=j\circ p.
\]


::: pf-proof

For a cylinder point,
\[
(j\circ p)([(x,s)])
=
j(f(x))
=
[f(x)].
\]
For a target point,
\[
(j\circ p)([y])
=
j(y)
=
[y].
\]
These are exactly the formulas defining $r$.

:::

:::

::: pf-step

The map $r$ is continuous.


::: pf-proof

The map
\[
p:X_f\to Y
\]
is continuous by step <1>1.
The canonical map
\[
j:Y\to X_f
\]
is continuous because it is the restriction of the quotient map $q$ to the
$Y$ summand, followed by corestriction to its image.
Therefore
\[
r=j\circ p
\]
is continuous.

:::

:::

::: pf-step

The map $r$ is a retraction onto
\[
\overline Y=j(Y).
\]


::: pf-proof

Let
\[
z\in\overline Y.
\]
Then
\[
z=[y]
\]
for some
\[
y\in Y.
\]
By definition,
\[
r(z)
=
r([y])
=
[y]
=
z.
\]
Hence
\[
r|_{\overline Y}
=
\operatorname{id}_{\overline Y}.
\]

:::

:::

::: pf-step

For
\[
t\in I,
\]
define
\[
F_t([(x,s)])
=
[(x,t+(1-t)s)],
\qquad
F_t([y])=[y].
\]
The formula is well defined.


::: pf-proof

The only issue is compatibility with the mapping-cylinder identification
\[
(x,1)\sim f(x).
\]
For such a point,
\[
t+(1-t)\cdot1
=
1,
\]
so
\[
F_t([(x,1)])
=
[(x,1)]
=
[f(x)].
\]
On the other representative,
\[
F_t([f(x)])
=
[f(x)].
\]
Thus equivalent representatives have the same image.

:::

:::

::: pf-step

The map
\[
F:X_f\times I\to X_f,
\qquad
F(z,t)=F_t(z),
\]
is continuous.


::: pf-proof

Define on
\[
((X\times I)\sqcup Y)\times I
\]
the map
\[
\widetilde F((x,s),t)
=
q(x,t+(1-t)s)
\]
and
\[
\widetilde F(y,t)
=
q(y).
\]
This map is continuous.

By step <1>6 it is constant on the equivalence classes induced by
\[
(x,1,t)\sim(f(x),t).
\]
The product
\[
q\times\operatorname{id}_I
:
((X\times I)\sqcup Y)\times I
\to
X_f\times I
\]
is a quotient map because $I$ is locally compact Hausdorff.
Hence the quotient universal property gives a unique continuous map
\[
F:X_f\times I\to X_f
\]
with the displayed formulas.

:::

:::

::: pf-step

One has
\[
F_0
=
\operatorname{id}_{X_f}.
\]


::: pf-proof

For a cylinder point,
\[
F_0([(x,s)])
=
[(x,0+(1-0)s)]
=
[(x,s)].
\]
For
\[
[y]\in\overline Y,
\]
the point is fixed by definition.

:::

:::

::: pf-step

One has
\[
F_1=r.
\]


::: pf-proof

For a cylinder point,
\[
F_1([(x,s)])
=
[(x,1)]
=
[f(x)]
=
r([(x,s)]).
\]
For
\[
[y],
\]
both maps fix the point.

:::

:::

::: pf-step

The homotopy fixes
\[
\overline Y
\]
pointwise:
\[
F_t(z)=z
\qquad
(z\in\overline Y, t\in I).
\]


::: pf-proof

This is part of the definition:
\[
F_t([y])=[y].
\]

:::

:::

::: pf-step

Therefore $F$ is a deformation retraction of $X_f$ onto
\[
\overline Y.
\]


::: pf-proof

Step <1>8 gives the identity at time $0$.
Step <1>9 gives the retraction at time $1$.
Step <1>10 fixes the retract throughout the homotopy.
These are precisely the defining conditions.

:::

:::

::: pf-step

The canonical map
\[
j:Y\to X_f
\]
is an embedding.


::: pf-proof

By step <1>2, $j$ is a continuous injection.
Its image is
\[
\overline Y.
\]
The inverse map
\[
j(Y)\to Y
\]
is the restriction
\[
p|_{\overline Y},
\]
because
\[
p([y])=y.
\]
This restriction is continuous since $p$ is continuous.
Thus
\[
j:Y\xrightarrow{\cong}\overline Y
\]
is a homeomorphism, so $j$ is an embedding.

:::

:::

::: pf-step

The maps
\[
j:Y\to X_f
\]
and
\[
p:X_f\to Y
\]
are homotopy inverses.


::: pf-proof

Step <1>2 gives
\[
p\circ j
=
\operatorname{id}_Y.
\]
By step <1>3,
\[
j\circ p
=
r.
\]
Step <1>11 gives
\[
r
\simeq
\operatorname{id}_{X_f}.
\]
Hence $j$ and $p$ are homotopy inverses.

:::

:::

::: pf-step

Consequently
\[
\boxed{
X_f\simeq Y.
}
\]


::: pf-proof

Step <1>13 is exactly the definition of a homotopy equivalence.

:::

:::

::: pf-qed

Steps <1>3--<1>11 prove part (1), and steps <1>12--<1>14 prove part (2).

:::

:::

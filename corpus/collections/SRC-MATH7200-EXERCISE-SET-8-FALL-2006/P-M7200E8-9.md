::: {.problem}
(a) Let $R$ be an integral domain, let $M$ be a torsion $R$-module, and let $N$ be a torsion-free $R$-module.
Show that $\operatorname{Hom}_R(M, N) = \langle 0 \rangle$.

(b) If $n = km$, then show that $\operatorname{Hom}_{\ZZ_n}(\ZZ_m, \ZZ_n) \cong \ZZ_m$.
:::

::: {.solution}
The collection records no provenance for this exercise set and holds no solution set, so no retained set covers it; the argument is the card's own. Write $\operatorname{Hom}_{\ZZ_{n}}$ for the module of $\ZZ_{n}$-linear maps and $\langle0\rangle$ for the zero submodule.

::: pf

::: {.pf-step #part-a}
If $R$ is an integral domain, $M$ a torsion $R$-module and $N$ a torsion-free $R$-module, then $\operatorname{Hom}_{R}(M,N)=\langle0\rangle$.

::: pf-proof
Let $f\in\operatorname{Hom}_{R}(M,N)$ and $m\in M$. Since $M$ is torsion, $rm=0$ for some nonzero $r\in R$. Then $r\,f(m)=f(rm)=f(0)=0$. In the torsion-free module $N$ an equality $rx=0$ with $r\ne0$ forces $x=0$, so $f(m)=0$. The element $m$ was arbitrary, so $f$ is the zero map and the Hom module has one element.
:::

:::

::: {.pf-step #part-b-module}
For $n=km$ the group $\ZZ_{m}$ is a $\ZZ_{n}$-module.

::: pf-proof
Since $m\mid n$, reduction modulo $m$ factors through reduction modulo $n$, so $s\cdot r=(sr\bmod m)$ is a well defined rule for $s\in\ZZ_{n}$, $r\in\ZZ_{m}$. The module axioms hold because the rule is induced by multiplication in $\ZZ_{n}$: distributivity in each variable, $(ss')\cdot r=s\cdot(s'\cdot r)$, and $1\cdot r=r$ all reduce to the corresponding identities for integers followed by reduction modulo $m$.
:::

:::

::: {.pf-step #part-b-injective}
$\varphi:\operatorname{Hom}_{\ZZ_{n}}(\ZZ_{m},\ZZ_{n})\to\ZZ_{n}$, $\varphi(f)=f(1)$, is an injective homomorphism of $\ZZ_{n}$-modules.

::: pf-proof
It is additive and $\ZZ_{n}$-linear because sums and scalar multiples of homomorphisms are computed pointwise: $\varphi(f+g)=(f+g)(1)=f(1)+g(1)$ and $\varphi(sf)=(sf)(1)=s\,f(1)$. For injectivity, a $\ZZ_{n}$-linear $f$ satisfies $f(r)=f(r\cdot1)=r\,f(1)$ for every $r\in\ZZ_{m}$, so $f$ is determined by $f(1)$; if $f(1)=0$ then $f(r)=0$ for all $r$ and $f=0$.
:::

:::

::: {.pf-step #image}
$\operatorname{im}\varphi=\theset{t\in\ZZ_{n}:mt=0}=\langle k\rangle$, a cyclic subgroup of order $m$.

::: pf-proof
If $t=f(1)$ then $mt=mf(1)=f(m\cdot1)=f(0)=0$, since $m=0$ in $\ZZ_{m}$; so the image lies in the stated set. Conversely, if $mt=0$ in $\ZZ_{n}$, then $r\mapsto rt$ is well defined on $\ZZ_{m}$ — from $r\equiv r'$ modulo $m$ we get $(r-r')t=0$ because $m\mid r-r'$ and $mt=0$ — and it is $\ZZ_{n}$-linear and sends $1$ to $t$; so $t$ lies in the image. Hence the image is exactly $\theset{t:mt=0}$. With $n=km$, the condition $n\mid mt$ is $km\mid mt$, that is $k\mid t$; the residues $t$ with $k\mid t$ are $0,k,2k,\dots,(m-1)k$, exactly $m$ of them, and they form the cyclic subgroup generated by $k$.
:::

:::

::: {.pf-step #part-b}
If $n=km$ then $\operatorname{Hom}_{\ZZ_{n}}(\ZZ_{m},\ZZ_{n})\cong\ZZ_{m}$.

::: pf-proof
By step [](#part-b-module){.pf-ref} the source is a $\ZZ_{n}$-module, and by step [](#part-b-injective){.pf-ref} $\varphi$ is injective, so it is an isomorphism onto its image; step [](#image){.pf-ref} identifies that image with $\langle k\rangle$, which is cyclic of order $m$, hence isomorphic to $\ZZ_{m}$ as an abelian group and as a $\ZZ_{n}$-module. Composing gives the required isomorphism.
:::

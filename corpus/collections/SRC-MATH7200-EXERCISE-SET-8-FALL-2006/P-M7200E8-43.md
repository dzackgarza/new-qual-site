::: {.problem}
Suppose $R$ is a PID and $M = R\langle x \rangle$ is a cyclic $R$-module with $\operatorname{Ann}(x) = \langle a \rangle \neq \langle 0 \rangle$.
Show that if $N$ is a submodule of $M$, then $N$ is cyclic with $\operatorname{Ann} N = \langle b \rangle$ where $b$ is a divisor of $a$.
Conversely, show that $M$ has a unique submodule $N$ with annihilator $\langle b \rangle$ for each divisor $b$ of $a$.
:::

::: {.solution}
This is Problem 43 of the retained Exercise Set 8 for MATH 7200, Fall 2006 (`assets/attachments/ExerciseSet8f06a.pdf`), whose printed solution the argument follows; the statement is the printed one word for word, including the misspelling "cylic" of the original. No other set covers it.

::: pf

::: {.pf-step #map}
The map $\varphi\colon R\to M$, $\varphi(r)=rx$, is a surjective $R$-module homomorphism with kernel $\ker\varphi=\operatorname{Ann}(x)=\langle a\rangle$.

::: pf-proof
$\varphi$ is $R$-linear because $\varphi(r+r')=(r+r')x=rx+r'x$ and $\varphi(rs)=(rs)x=r(sx)=s\,\varphi(r)$ up to the commutative convention. It is surjective since $M=R\langle x\rangle$ consists of the elements $rx$. And $\varphi(r)=0$ exactly when $rx=0$, that is when $r\in\operatorname{Ann}(x)=\langle a\rangle$.
:::
:::

::: {.pf-step #correspondence}
$N\mapsto\varphi^{-1}(N)$ is a bijection from the submodules of $M$ onto the submodules of $R$ containing $\langle a\rangle$, with inverse $I\mapsto\varphi(I)$.

::: pf-proof
This is the correspondence theorem for the quotient $R/\langle a\rangle\cong M$: submodules of the image correspond to submodules of $R$ containing the kernel. Explicitly, $\varphi^{-1}(N)$ is a submodule containing $\ker\varphi$ for every submodule $N$, and $\varphi(\varphi^{-1}(N))=N$ because $\varphi$ is onto, while $\varphi^{-1}(\varphi(I))=I$ whenever $I\supseteq\ker\varphi$.
:::
:::

::: {.pf-step #cyclic}
Every submodule $N$ of $M$ is cyclic, generated by $cx$ for some $c$ with $c\mid a$.

::: pf-proof
By step [](#correspondence){.pf-ref}, $\varphi^{-1}(N)=\langle c\rangle$ for some $c\in R$, since the ideals of the PID $R$ are principal, and $\langle c\rangle\supseteq\langle a\rangle$ means $c\mid a$. Then $N=\varphi(\langle c\rangle)=\theset{r(cx)\mid r\in R}=\langle cx\rangle$, a cyclic submodule.
:::
:::

::: {.pf-step #annihilator}
$\operatorname{Ann}(N)=\langle a/c\rangle$; so the annihilator of $N$ is generated by the divisor $b=a/c$ of $a$.

::: pf-proof
$\operatorname{Ann}(N)=\theset{r\in R\mid rcx=0}=\theset{r\in R\mid rc\in\langle a\rangle}=\theset{r\in R\mid a\mid rc}$. Since $c\mid a$ and $a\neq0$, write $a=cb$ with $b\neq0$; then $a\mid rc$ if and only if $cb\mid rc$, which in the domain $R$ is equivalent to $b\mid r$ (cancel $c$). So $\operatorname{Ann}(N)=\langle b\rangle=\langle a/c\rangle$, and $b\mid a$.
:::
:::

::: {.pf-step #converse}
Conversely, for each divisor $b$ of $a$ the submodule $N_{b}=\left\langle\frac{a}{b}x\right\rangle$ has annihilator $\langle b\rangle$.

::: pf-proof
Put $c=\frac{a}{b}$, which divides $a$. By step [](#annihilator){.pf-ref} applied to $N_{b}=\langle cx\rangle$, its annihilator is $\langle a/c\rangle=\langle b\rangle$.
:::
:::

::: {.pf-step #unique}
$N_{b}$ is the only submodule of $M$ with annihilator $\langle b\rangle$.

::: pf-proof
Let $N'$ be a submodule with $\operatorname{Ann}(N')=\langle b\rangle$ and write $\varphi^{-1}(N')=\langle c'\rangle$. Step [](#annihilator){.pf-ref} gives $\langle a/c'\rangle=\langle b\rangle$, so $a/c'$ and $b$ are associates; then $c'$ and $a/b$ are associates, since $R$ is a domain and $a\neq0$, hence $\varphi^{-1}(N')=\langle a/b\rangle$ and $N'=\varphi(\langle a/b\rangle)=N_{b}$.
:::

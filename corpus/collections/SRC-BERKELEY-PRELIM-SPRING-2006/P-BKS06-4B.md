::: {.problem}
Let n be a positive integer, and let ${ \mathrm { G L } } _ { n } ( \mathbb { R } )$ be the group of invertible $n \times n$ matrices.
Let S be the set of $A \in \operatorname { G L } _ { n } ( \mathbb { R } )$ such that $A - I$ has rank $\leq 2$ . Prove that S generates ${ \mathrm { G L } } _ { n } ( \mathbb { R } )$ as a group.
:::

::: {.solution}
By Gaussian elimination, ${ \mathrm { G L } } _ { n } ( \mathbb { R } )$ is generated by the elementary matrices obtained from the identity matrix by interchanging two rows, by multiplying one row by a nonzero scalar, or by adding a multiple of one row to a different row.
For each such matrix A, the matrix $A - I$ has at most two nonzero rows and hence has rank $\leq 2 .$
:::

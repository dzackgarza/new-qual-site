::: {.problem}
Let $A$ be the subring of $\RR[t]$ consisting of polynomials $f(t)$ such that $f'(0) = 0$. Is $A$ a principal ideal domain?
:::

::: {.solution}

No.

::: pf

::: {.pf-step #s1}

Let $I$ be the ideal of $A$ generated by $t^2$ and $t^3$. If $I=(p)$, then $p=ut^m$ with $u\in\RR^\times$ and $m\in\{0,1,2\}$.

::: pf-proof

Since $t^2\in I$, $t^2=qp$ for some $q\in A\subseteq\RR[t]$. So $p$ divides $t^2$ in the unique factorization domain $\RR[t]$, whose units are the nonzero constants.

:::

:::

::: {.pf-step #s2}

None of the three cases of step [](#s1){.pf-ref} occurs.

::: pf-proof

If $m=0$, then $I=A$, but every element of $I$ has constant term $0$. If $m=1$, then $p'(0)=u\ne0$, so $p\notin A$. If $m=2$, then $t^3=rp$ with $r\in A$ forces $r=u^{-1}t$, and $r'(0)=u^{-1}\ne0$, so $r\notin A$.

:::

:::

::: pf-qed

By steps [](#s1){.pf-ref} and [](#s2){.pf-ref}, the ideal $I$ is not principal, so $A$ is not a principal ideal domain.

:::

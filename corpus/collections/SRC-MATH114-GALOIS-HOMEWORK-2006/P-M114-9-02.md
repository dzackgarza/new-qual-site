::: {.problem}
Show that the Galois group of $x^{15}-1$ over Q is isomorphic to $\mathbb { Z } _ { 2 } \times \mathbb { Z } _ { 4 }$
:::

::: {.solution}

Let $\zeta=\zeta_{15}$ be a primitive fifteenth root of unity and let $K$ be the splitting field of $x^{15}-1$ over $\mathbb Q$.

::: pf

::: pf-step

One has
\[
K=\mathbb Q(\zeta).
\]


::: pf-proof

Every root of $x^{15}-1$ is a power of the primitive root $\zeta$, so $\mathbb Q(\zeta)$ contains every root. Conversely, any splitting field contains $\zeta$.

:::

:::

::: {.pf-step #s1-2}

The map
\[
\operatorname{Gal}(K/\mathbb Q)
\longrightarrow(\mathbb Z/15\mathbb Z)^\times,
\qquad
\sigma\longmapsto a_\sigma,
\]
defined by
\[
\sigma(\zeta)=\zeta^{a_\sigma},
\]
is an isomorphism.


::: pf-proof

Every automorphism sends $\zeta$ to another primitive fifteenth root, hence to $\zeta^a$ for a unique unit $a$ modulo $15$. Since $K=\mathbb Q(\zeta)$, this determines the automorphism, so the map is injective. Conversely, for every $a\in(\mathbb Z/15\mathbb Z)^\times$, the assignment $\zeta\mapsto\zeta^a$ preserves the cyclotomic polynomial $\Phi_{15}$ and defines a $\mathbb Q$-automorphism of $K$. Composition corresponds to multiplication of exponents, proving surjectivity and the homomorphism property.

:::

:::

::: {.pf-step #s1-3}

By the Chinese remainder theorem,
\[
(\mathbb Z/15\mathbb Z)^\times
\cong(\mathbb Z/3\mathbb Z)^\times
\times(\mathbb Z/5\mathbb Z)^\times.
\]


::: pf-proof

Since $15=3\cdot5$ and $3,5$ are coprime, the Chinese remainder theorem gives a ring isomorphism
\[
\mathbb Z/15\mathbb Z
\cong\mathbb Z/3\mathbb Z\times\mathbb Z/5\mathbb Z.
\]
An element is a unit exactly when each component is a unit, so restricting the isomorphism to unit groups gives the displayed product.

:::

:::

::: {.pf-step #s1-4}

The two factors are
\[
(\mathbb Z/3\mathbb Z)^\times\cong\mathbb Z_2,
\qquad
(\mathbb Z/5\mathbb Z)^\times\cong\mathbb Z_4.
\]


::: pf-proof

Modulo $3$, the units are $\{1,2\}$, a cyclic group of order $2$. Modulo $5$, the residue class of $2$ has powers
\[
2,4,3,1,
\]
so it generates all four units and the unit group is cyclic of order $4$.

:::

:::

::: {.pf-step #s1-5}

Therefore
\[
\boxed{
\operatorname{Gal}(x^{15}-1/\mathbb Q)
\cong\mathbb Z_2\times\mathbb Z_4.}
\]


::: pf-proof

Combine the isomorphism in step [](#s1-2){.pf-ref} with steps [](#s1-3){.pf-ref} through [](#s1-4){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-5){.pf-ref} is the required group identification.

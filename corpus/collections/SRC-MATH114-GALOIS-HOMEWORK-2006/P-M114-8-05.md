::: {.problem}
For a cubic polynomial $f \left( x \right) = x ^ { 3 } + a x + b$ the discriminant is given by the formula

$$
D = - 4 a ^ { 3 } -27b^2 .
$$

Assume that $a$ and b are real numbers. Prove that D is negative if and only if $f \left( x \right)$ has exactly one real root.
:::

Let the roots of $f$ in $\mathbb C$ be $r_1,r_2,r_3$. Since $f$ is monic, its discriminant is
\[
D=(r_1-r_2)^2(r_1-r_3)^2(r_2-r_3)^2.
\]

::: pf

::: pf-step

If $f$ has exactly one real root, then $D<0$.


::: pf-proof

Because the coefficients are real, the two nonreal roots are conjugate. Write the roots as
\[
r\in\mathbb R,
\qquad
z=u+iv,
\qquad
\bar z=u-iv,
\qquad v\ne0.
\]
Then
\[
D=(r-z)^2(r-\bar z)^2(z-\bar z)^2.
\]
The first two factors multiply to
\[
((r-z)(r-\bar z))^2=|r-z|^4>0,
\]
while
\[
(z-\bar z)^2=(2iv)^2=-4v^2<0.
\]
Hence $D<0$.

:::

:::

::: pf-step

If $D<0$, then $f$ has no repeated root.


::: pf-proof

The discriminant product preceding step <1>1 vanishes exactly when two roots coincide. Since $D<0$, it is nonzero.

:::

:::

::: pf-step

If all three roots are real and distinct, then $D>0$.


::: pf-proof

Every difference $r_i-r_j$ is then a nonzero real number, so each square $(r_i-r_j)^2$ is positive. Their product is positive.

:::

:::

::: pf-step

Every real cubic has at least one real root.


::: pf-proof

For the monic cubic $f(x)=x^3+ax+b$,
\[
\lim_{x\to-\infty}f(x)=-\infty,
\qquad
\lim_{x\to+\infty}f(x)=+\infty.
\]
Continuity and the intermediate value theorem therefore give a real zero.

:::

:::

::: pf-step

If $D<0$, then $f$ has exactly one real root.


::: pf-proof

By step <1>4, at least one root is real. Since the coefficients are real, nonreal roots occur in conjugate pairs, so a cubic has either one real root and one nonreal conjugate pair, or three real roots counted with multiplicity. Step <1>2 excludes repeated roots, and step <1>3 excludes three distinct real roots because $D<0$. Thus exactly one root is real.

:::

:::

::: pf-step

Therefore
\[
\boxed{D<0\iff f\text{ has exactly one real root}.}
\]


::: pf-proof

Step <1>1 proves the forward implication from the root configuration to the sign, and step <1>5 proves the converse.

:::

:::

::: pf-qed

Step <1>6 is the required equivalence.

:::

:::

::: {.problem}
Let $n = p ,$ or 2p where p is a prime number. Prove that the Galois group of the polynomial $x ^ { n } - 1$ over any field F is cyclic.
:::

Let $K$ be the splitting field of $x^n-1$ over $F$, and let $G=\operatorname{Gal}(K/F)$. If $\operatorname{char}F$ divides $n$, repeated roots may occur, but the splitting field is unchanged after removing the inseparable multiplicity; the argument below uses the actual roots in $K$.

::: pf

::: pf-step

If $n=p$ and $\operatorname{char}F\ne p$, then for a primitive $p$th root of unity $\zeta$ one has
\[
K=F(\zeta).
\]


::: pf-proof

The roots of $x^p-1$ are $1,\zeta,\ldots,\zeta^{p-1}$. Thus adjoining one primitive root adjoins every root.

:::

:::

::: pf-step

Every $\sigma\in G$ is determined by
\[
\sigma(\zeta)=\zeta^{a_\sigma}
\]
for a unique $a_\sigma\in(\mathbb Z/p\mathbb Z)^\times$, and
\[
\sigma\longmapsto a_\sigma
\]
embeds $G$ into $(\mathbb Z/p\mathbb Z)^\times$.


::: pf-proof

An $F$-automorphism permutes the roots of the minimal polynomial of $\zeta$, so it sends $\zeta$ to another primitive $p$th root, necessarily $\zeta^a$ with $a\not\equiv0\pmod p$. Since $K=F(\zeta)$, this image determines $\sigma$. Moreover,
\[
(\sigma\tau)(\zeta)
=\sigma(\zeta^{a_\tau})
=\zeta^{a_\sigma a_\tau},
\]
so the map is an injective homomorphism.

:::

:::

::: pf-step

Hence $G$ is cyclic when $n=p$ and $\operatorname{char}F\ne p$.


::: pf-proof

The multiplicative group $(\mathbb Z/p\mathbb Z)^\times$ is cyclic. Every subgroup of a cyclic group is cyclic, and step <1>2 realizes $G$ as such a subgroup.

:::

:::

::: pf-step

If $n=2p$ and $\operatorname{char}F\ne2,p$, then the splitting field of $x^{2p}-1$ is again generated by one primitive root, and $G$ embeds in
\[
(\mathbb Z/2p\mathbb Z)^\times.
\]


::: pf-proof

Let $\xi$ be a primitive $2p$th root of unity. Every $2p$th root is a power of $\xi$, so $K=F(\xi)$. As in step <1>2, every automorphism sends $\xi$ to $\xi^a$ for a unit $a$ modulo $2p$, producing the stated embedding.

:::

:::

::: pf-step

For odd prime $p$,
\[
(\mathbb Z/2p\mathbb Z)^\times\cong(\mathbb Z/p\mathbb Z)^\times,
\]
so it is cyclic; for $p=2$, $(\mathbb Z/4\mathbb Z)^\times$ is cyclic of order $2$.


::: pf-proof

When $p$ is odd, reduction modulo $p$ maps units modulo $2p$ bijectively to nonzero residue classes modulo $p$: each nonzero class modulo $p$ has exactly one odd representative modulo $2p$. This is a group isomorphism. The target is cyclic. For $p=2$, the units modulo $4$ are $\{1,3\}$.

:::

:::

::: pf-step

Hence $G$ is cyclic when $n=2p$ in the separable case.


::: pf-proof

By steps <1>4--<1>5, $G$ is a subgroup of a cyclic group.

:::

:::

::: pf-step

The remaining positive-characteristic cases reduce to the preceding cyclotomic cases or are trivial.


::: pf-proof

If $\operatorname{char}F=p$, then
\[
x^p-1=(x-1)^p,
\]
so for $n=p$ the splitting field is $F$ and $G$ is trivial. For $n=2p$ with $p$ odd,
\[
x^{2p}-1=(x^2-1)^p,
\]
whose roots $\pm1$ already lie in $F$, so again $G$ is trivial. If $p=2$ and $\operatorname{char}F=2$, then $x^4-1=(x-1)^4$, again giving the trivial group. If $n=2p$ and $\operatorname{char}F=2$ with $p$ odd, then
\[
x^{2p}-1=(x^p-1)^2,
\]
so its splitting field is that of $x^p-1$; since $p\ne\operatorname{char}F$, steps <1>1--<1>3 apply.

:::

:::

::: pf-step

Therefore, for $n=p$ or $n=2p$ and every field $F$,
\[
\boxed{\operatorname{Gal}(x^n-1/F)\text{ is cyclic}.}
\]


::: pf-proof

Steps <1>3 and <1>6 prove the separable cases, and step <1>7 covers every case in which the characteristic divides $n$.

:::

:::

::: pf-qed

Step <1>8 is the desired conclusion.

:::

:::

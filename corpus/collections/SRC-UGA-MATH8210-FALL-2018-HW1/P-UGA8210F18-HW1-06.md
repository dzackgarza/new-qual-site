::: {.problem}
Let X and Y be smooth manifolds.
Show that $X \times Y$ is a smooth manifold.
Suppose that f and $g$ are smooth functions with domains X and $Y$ , respectively.
Show that $( f \times g ) ( x , y ) = ( f ( x ) , g ( y ) )$ is a smooth function.\
Now suppose that $h : X \to Y$ . Show that the graph of $h ,$

$$
\mathrm { g r a p h } ( h ) = \{ ( x , h ( x ) ) : x \in X \}
$$

is a smooth manifold.
(Hint: define a map $X \to X \times Y$ which restricts to a diffeomorphism on the graph.)
:::

::: pf

::: {.pf-step #s1-1}

If $\dim X=m$ and $\dim Y=n$, then
\[
\boxed{X\times Y\text{ is a smooth }(m+n)\text{-manifold}}.
\]


::: pf-proof

Let
\[
(U,\phi),\qquad \phi:U\to\phi(U)\subseteq\mathbb R^m,
\]
be a smooth chart on $X$, and let
\[
(V,\psi),\qquad \psi:V\to\psi(V)\subseteq\mathbb R^n,
\]
be a smooth chart on $Y$. Define
\[
\phi\times\psi:
U\times V\longrightarrow
\phi(U)\times\psi(V)\subseteq\mathbb R^{m+n}
\]
by
\[
(\phi\times\psi)(x,y)=(\phi(x),\psi(y)).
\]
This is a homeomorphism onto an open subset of $\mathbb R^{m+n}$.

These product charts cover $X\times Y$. On an overlap,
\[
(\phi_2\times\psi_2)\circ(\phi_1\times\psi_1)^{-1}
\]
is
\[
(u,v)\longmapsto
\left(
\phi_2\circ\phi_1^{-1}(u),
\psi_2\circ\psi_1^{-1}(v)
\right),
\]
which is smooth because the transition maps on $X$ and $Y$ are smooth.
Thus the product charts define a smooth structure on $X\times Y$.

:::

:::

::: {.pf-step #s1-2}

If
\[
f:X\to\mathbb R
\qquad\text{and}\qquad
g:Y\to\mathbb R
\]
are smooth, then
\[
\boxed{
f\times g:X\times Y\to\mathbb R^2,
\qquad
(f\times g)(x,y)=(f(x),g(y))
}
\]
is smooth.


::: pf-proof

In a product chart $\phi\times\psi$, its coordinate expression is
\[
(u,v)
\longmapsto
\left(
f\circ\phi^{-1}(u),
g\circ\psi^{-1}(v)
\right).
\]
Each component is smooth, so the map to $\mathbb R^2$ is smooth.

:::

:::

::: {.pf-step #s1-3}

The final statement is false for an arbitrary map
\[
h:X\to Y.
\]


::: pf-proof

Take
\[
X=Y=\mathbb R
\]
and define
\[
h(x)=
\begin{cases}
1,&x=0,\\
0,&x\ne0.
\end{cases}
\]
Then
\[
\operatorname{graph}(h)
=
\{(0,1)\}
\cup
\{(x,0):x\ne0\}.
\]
The point $(0,1)$ is isolated in the graph, while every point $(x,0)$ with
$x\ne0$ is non-isolated. Therefore the graph cannot be an
$n$-manifold for any fixed $n$: if $n=0$, every point of a manifold is
isolated, while if $n\ge1$, no point of a manifold is isolated.

:::

:::

::: {.pf-step #s1-4}

Assume now that
\[
\boxed{h:X\to Y\text{ is smooth}}.
\]
Define
\[
F:X\longrightarrow X\times Y,
\qquad
F(x)=(x,h(x)).
\]
Then $F$ is smooth.


::: pf-proof

The identity map
\[
\operatorname{id}_X:X\to X
\]
and $h:X\to Y$ are smooth. In product coordinates, $F$ is the product map
\[
(\operatorname{id}_X,h),
\]
so the same coordinate argument as in step [](#s1-2){.pf-ref} shows that $F$ is smooth.

:::

:::

::: {.pf-step #s1-5}

The map $F$ is a bijection
\[
F:X\longrightarrow\operatorname{graph}(h).
\]


::: pf-proof

By definition,
\[
F(X)
=
\{(x,h(x)):x\in X\}
=
\operatorname{graph}(h).
\]
It is injective because the first coordinate of $F(x)$ is $x$.

:::

:::

::: {.pf-step #s1-6}

The inverse of $F$ is the restriction of the first projection:
\[
F^{-1}
=
\pi_X|_{\operatorname{graph}(h)}.
\]


::: pf-proof

For every $x\in X$,
\[
\pi_X(F(x))
=
\pi_X(x,h(x))
=x.
\]
Conversely, every point of the graph has the form $(x,h(x))$, so
\[
F(\pi_X(x,h(x)))
=
F(x)
=(x,h(x)).
\]

:::

:::

::: {.pf-step #s1-7}

With the smooth structure transported from $X$ through $F$,
\[
\boxed{\operatorname{graph}(h)\text{ is a smooth embedded submanifold and }
F:X\xrightarrow{\sim}\operatorname{graph}(h)\text{ is a diffeomorphism}}.
\]


::: pf-proof

Since $h$ is smooth, it is continuous, so
\[
F(x)=(x,h(x))
\]
is continuous as a map into $X\times Y$. By step [](#s1-6){.pf-ref}, its inverse on the
graph is the restriction of the continuous projection $\pi_X$. Thus
\[
F:X\longrightarrow\operatorname{graph}(h)
\]
is a homeomorphism when the graph has the subspace topology.

Use $F$ to transport every chart $(U,\phi)$ on $X$ to the chart
\[
\left(F(U),\,\phi\circ F^{-1}\right)
\]
on the graph. Since $F$ is a bijection by step [](#s1-5){.pf-ref}, these charts cover the
graph and have exactly the same transition maps as the original charts on
$X$. Thus they define a smooth manifold structure on the existing subspace
topology for which $F$ is a diffeomorphism. The inclusion of the graph into
$X\times Y$ composed with $F$ is the smooth map $x\mapsto(x,h(x))$, whose
differential has injective first component. Hence this smooth structure makes
the graph an embedded submanifold.

:::

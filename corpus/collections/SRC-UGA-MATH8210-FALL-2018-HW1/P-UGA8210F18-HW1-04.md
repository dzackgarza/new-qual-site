::: {.problem}
In this exercise you will show that $S ^ { n }$ is a manifold which can be covered by two charts.
Think of $S ^ { n } \subset \mathbb { R } ^ { n + 1 }$ as the set

$$
S ^ { n } = \{ x _ { 1 } ^ { 2 } + \cdot \cdot \cdot + x _ { n + 1 } ^ { 2 } = 1 : ( x _ { 1 } , \ldots , x _ { n + 1 } ) \in \mathbb { R } ^ { n + 1 } \}
$$

Write $N = ( 0 , \ldots , 0 , 1 )$ and ${ \cal S } = ( 0 , \ldots , 0 , - 1 )$ . (These are the north and south\
poles.)

• Define a map $p : S ^ { n } \setminus N \to \mathbb { R } ^ { n }$ as follows.
Let $x \in S ^ { n } \setminus N$ . There is a unique line $\ell _ { x }$ between N and X. This line intersects the plane $\{ x _ { n + 1 } = 0 \}$ in one point.
This point is $p ( x )$ . Identify $\mathbb { R } ^ { n }$ with the set

$$
\left\{ \left( x _ { 1 } , \ldots , x _ { n + 1 } \right) : x _ { n + 1 } = 0 \right\}
$$

so that $p$ really is a map to $\mathbb { R } ^ { n }$\
First, check that $p ( x )$ is well-defined: why does $\ell _ { x }$ intersect $\{ x _ { n + 1 } = 0 \}$ in\
exactly one point?

• Write down a nice expression for $p ( x )$ in terms of $\left( x _ { 1 } , \ldots , x _ { n + 1 } \right)$ . (Hint: your expression shouldn’t make sense if you try to set $x = N . )$

• Show that $p$ has an inverse and write down a nice expression for it.

$p ( \mathbb { R } ^ { n } )$ covers most of the sphere.
Find another good chart which covers the rest.

• Show that $S ^ { n }$ cannot be covered by a single chart.
:::

Write a point of $\mathbb R^{n+1}$ as
\[
(u,t),
\qquad
u\in\mathbb R^n,\quad t\in\mathbb R.
\]

::: pf

::: pf-step

For every $x=(u,t)\in S^n\setminus\{N\}$, the line through $N$ and
$x$ meets the hyperplane
\[
\mathbb R^n\times\{0\}
\]
in exactly one point.


::: pf-proof

The line through
\[
N=(0,1)
\]
and $x=(u,t)$ is
\[
\ell_x(s)
=
N+s(x-N)
=
(su,\ 1+s(t-1)).
\]
It meets the hyperplane $x_{n+1}=0$ exactly when
\[
1+s(t-1)=0.
\]
Since $x\ne N$, one has $t\ne1$, so this equation has the unique solution
\[
s=\frac1{1-t}.
\]
Thus the intersection exists and is unique.

:::

:::

::: pf-step

The stereographic projection from the north pole is
\[
\boxed{
p_N:S^n\setminus\{N\}\longrightarrow\mathbb R^n,
\qquad
p_N(u,t)=\frac{u}{1-t}}.
\]


::: pf-proof

Substitute the value
\[
s=\frac1{1-t}
\]
from step <1>1 into the first $n$ coordinates $su$ of the line.

:::

:::

::: pf-step

Define
\[
q_N:\mathbb R^n\longrightarrow S^n\setminus\{N\}
\]
by
\[
\boxed{
q_N(y)
=
\left(
\frac{2y}{1+\|y\|^2},
\frac{\|y\|^2-1}{1+\|y\|^2}
\right)}.
\]
Then $q_N$ is well-defined.


::: pf-proof

Let
\[
r^2=\|y\|^2.
\]
The squared Euclidean norm of the displayed vector is
\[
\frac{4r^2+(r^2-1)^2}{(1+r^2)^2}
=
\frac{r^4+2r^2+1}{(1+r^2)^2}
=1.
\]
Thus $q_N(y)\in S^n$.

Its last coordinate is
\[
\frac{r^2-1}{r^2+1}<1
\]
for every finite $r$, so $q_N(y)\ne N$.

:::

:::

::: pf-step

The maps $p_N$ and $q_N$ are mutual inverses.


::: pf-proof

For $y\in\mathbb R^n$, step <1>3 gives
\[
1-\frac{\|y\|^2-1}{1+\|y\|^2}
=
\frac{2}{1+\|y\|^2}.
\]
Hence
\[
p_N(q_N(y))
=
\frac{\frac{2y}{1+\|y\|^2}}
{\frac{2}{1+\|y\|^2}}
=y.
\]

Conversely, let $x=(u,t)\in S^n\setminus\{N\}$ and set
\[
y=p_N(x)=\frac{u}{1-t}.
\]
Since
\[
\|u\|^2+t^2=1,
\]
one has
\[
\|y\|^2
=
\frac{\|u\|^2}{(1-t)^2}
=
\frac{1-t^2}{(1-t)^2}
=
\frac{1+t}{1-t}.
\]
Therefore
\[
1+\|y\|^2
=
\frac{2}{1-t}.
\]
The first $n$ coordinates of $q_N(y)$ are then
\[
\frac{2y}{1+\|y\|^2}
=
\frac{2u/(1-t)}{2/(1-t)}
=u,
\]
and the final coordinate is
\[
\frac{\|y\|^2-1}{1+\|y\|^2}
=
\frac{\frac{1+t}{1-t}-1}{\frac{2}{1-t}}
=t.
\]
Thus $q_N(p_N(x))=x$.

:::

:::

::: pf-step

The second stereographic chart is projection from the south pole
\[
S=(0,-1):
\]
\[
\boxed{
p_S:S^n\setminus\{S\}\longrightarrow\mathbb R^n,
\qquad
p_S(u,t)=\frac{u}{1+t}}.
\]
Its inverse is
\[
\boxed{
q_S(y)
=
\left(
\frac{2y}{1+\|y\|^2},
\frac{1-\|y\|^2}{1+\|y\|^2}
\right)}.
\]


::: pf-proof

Repeat steps <1>1 through <1>4 with the line through
\[
S=(0,-1)
\]
and $(u,t)$. Its last coordinate is
\[
-1+s(t+1),
\]
which vanishes uniquely at
\[
s=\frac1{1+t}.
\]
This gives the formula for $p_S$.

The formula for $q_S$ is verified exactly as for $q_N$, with the sign of the
last coordinate reversed.

:::

:::

::: pf-step

The two chart domains cover the sphere:
\[
\boxed{
S^n
=
\bigl(S^n\setminus\{N\}\bigr)
\cup
\bigl(S^n\setminus\{S\}\bigr)}.
\]


::: pf-proof

The north and south poles are distinct, so every point of $S^n$ lies in at
least one of the two complements.

:::

:::

::: pf-step

If $n\ge1$, the sphere $S^n$ cannot be covered by a single chart.


::: pf-proof

Suppose a single chart covered all of $S^n$. Then there would be a
homeomorphism
\[
\phi:S^n\longrightarrow U
\]
onto an open subset $U\subseteq\mathbb R^n$.

The sphere $S^n$ is compact, so $U$ would be compact. But $U$ is nonempty
and open. If $U=\mathbb R^n$, then $U$ is unbounded and hence not compact.
If $U$ is a proper subset, then because $\mathbb R^n$ is connected for
$n\ge1$, the nonempty proper open set $U$ cannot also be closed. By the
Heine--Borel theorem, a compact subset of $\mathbb R^n$ must be closed and
bounded. Thus $U$ is not compact in either case, a contradiction.

:::

:::

::: pf-step

For $n=0$, the sphere $S^0$ also cannot be covered by a single
$0$-dimensional chart.


::: pf-proof

The space
\[
S^0=\{-1,1\}
\]
has two points, whereas
\[
\mathbb R^0
\]
has one point. The only nonempty open subset of $\mathbb R^0$ is
$\mathbb R^0$ itself, so no chart domain equal to all of $S^0$ can be
homeomorphic to an open subset of $\mathbb R^0$.

:::

::: pf-qed

Steps <1>1 through <1>4 construct the north stereographic chart, steps <1>5
and <1>6 give a second chart covering the remaining pole, and steps <1>7 and
<1>8 show that one global chart is impossible.

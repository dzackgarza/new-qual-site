::: {.problem}
Check the assertion from class that

$$
f ( x ) = { \left\{ \begin{array} { l l } { e ^ { - { \frac { 1 } { x } } } } & { x > 0 } \\ { 0 } & { x \leq 0 } \end{array} \right. }
$$

is a smooth function.
A more specific and helpful claim is that there is a sequence of polynomials $P _ { k } ( t )$ so that

$$
f ^ { ( k ) } ( x ) = { \left\{ \begin{array} { l l } { P _ { k } ( { \frac { 1 } { x } } ) e ^ { - { \frac { 1 } { x } } } } & { x > 0 } \\ { 0 } & { x \leq 0 } \end{array} \right. } .
$$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For every integer $m\ge0$,
$$
\lim_{t\to\infty}t^m e^{-t}=0.
$$


::: pf-proof

Using the exponential series,
$$
e^t
\ge
\frac{t^{m+1}}{(m+1)!}
\qquad(t>0).
$$
Hence
$$
0\le t^m e^{-t}
\le
\frac{(m+1)!}{t}
\longrightarrow0.
$$

:::

:::

::: {.pf-step #s1-2}

If $P$ is any polynomial, then
$$
\lim_{x\to0^+}P(1/x)e^{-1/x}=0.
$$


::: pf-proof

Put
$$
t=\frac1x.
$$
Then $x\to0^+$ is equivalent to $t\to\infty$. Each monomial of $P(t)$ has
the form $ct^m$, and step [](#s1-1){.pf-ref} shows that
$$
ct^m e^{-t}\to0.
$$
Summing finitely many terms gives the result.

:::

:::

::: {.pf-step #s1-3}

Define polynomials recursively by
$$
P_0(t)=1,
\qquad
\boxed{
P_{k+1}(t)
=
t^2\bigl(P_k(t)-P_k'(t)\bigr)}.
$$
For $x>0$,
$$
\frac{d}{dx}
\left(
P_k(1/x)e^{-1/x}
\right)
=
P_{k+1}(1/x)e^{-1/x}.
$$


::: pf-proof

Set $t=1/x$. Then
$$
\frac{dt}{dx}=-t^2
$$
and
$$
\frac{d}{dx}e^{-t}
=
t^2e^{-t}.
$$
Therefore
$$
\begin{aligned}
\frac{d}{dx}\bigl(P_k(t)e^{-t}\bigr)
&=
-t^2P_k'(t)e^{-t}
+t^2P_k(t)e^{-t}\\
&=
t^2\bigl(P_k(t)-P_k'(t)\bigr)e^{-t}.
\end{aligned}
$$
The factor multiplying $e^{-t}$ is a polynomial, namely $P_{k+1}$.

:::

:::

::: {.pf-step #s1-4}

For every $k\ge0$, the function
$$
F_k(x)
=
\begin{cases}
P_k(1/x)e^{-1/x},&x>0,\\
0,&x\le0
\end{cases}
$$
is continuous on $\RR$.


::: pf-proof

It is smooth away from $0$. At $0$, step [](#s1-2){.pf-ref} gives
$$
\lim_{x\to0^+}F_k(x)=0=F_k(0),
$$
while from the left $F_k$ is identically zero. Thus $F_k$ is continuous at
$0$ as well.

:::

:::

::: {.pf-step #s1-5}

For every $k\ge0$, the function $F_k$ is differentiable at $0$ and
$$
F_k'(0)=0.
$$


::: pf-proof

For $h<0$,
$$
\frac{F_k(h)-F_k(0)}h=0.
$$
For $h>0$,
$$
\frac{F_k(h)-F_k(0)}h
=
\frac1hP_k(1/h)e^{-1/h}.
$$
The function
$$
tP_k(t)
$$
is again a polynomial, so step [](#s1-2){.pf-ref} gives
$$
\frac1hP_k(1/h)e^{-1/h}\longrightarrow0
\qquad(h\to0^+).
$$
Hence the two-sided derivative exists and equals $0$.

:::

:::

::: {.pf-step #s1-6}

For every $k\ge0$,
$$
\boxed{
f^{(k)}(x)
=
\begin{cases}
P_k(1/x)e^{-1/x},&x>0,\\
0,&x\le0.
\end{cases}}
$$


::: pf-proof

Proceed by induction on $k$. For $k=0$, this is the definition of $f$ with
$P_0=1$. Assume the formula for $k$. On $x>0$, step [](#s1-3){.pf-ref} gives the formula
for the derivative with $P_{k+1}$. On $x<0$, the function is identically
zero. At $x=0$, step [](#s1-5){.pf-ref} gives derivative $0$. Thus the formula holds for
$k+1$.

:::

:::

::: {.pf-step #s1-7}

Therefore
$$
\boxed{f\in C^\infty(\RR)}.
$$


::: pf-proof

Step [](#s1-6){.pf-ref} supplies derivatives of every order, and step [](#s1-4){.pf-ref} shows each such
derivative is continuous.

:::

:::

::: pf-qed

Steps [](#s1-3){.pf-ref} and [](#s1-6){.pf-ref} establish the requested polynomial form, and step [](#s1-7){.pf-ref}
proves smoothness.

:::

::: {.problem}
Calculate the mod $2$ cohomology ring of the space $X(m, n) = \mathbb{CP}^m \times \mathbb{RP}^n$ where $m, n$ are positive integers.
Show that $X(m, n)$ is homotopy equivalent to $X(m', n')$ if and only if $(m, n) = (m', n')$.
:::

::: {.solution}
**Goal.** Compute $H^*(X(m,n);\ZZ_2)$ and show it determines $(m,n)$.

::: pf

::: pf-step
$H^*(\CP^m;\ZZ_2) = \ZZ_2[\alpha]/(\alpha^{m+1})$ with $|\alpha| = 2$, and $H^*(\RP^n;\ZZ_2) = \ZZ_2[\beta]/(\beta^{n+1})$ with $|\beta| = 1$.

::: pf-proof
standard mod-2 cohomology rings of projective spaces.
:::

:::

::: {.pf-step #s2}
By the Künneth theorem, $H^*(X(m,n);\ZZ_2) = \ZZ_2[\alpha, \beta]/(\alpha^{m+1}, \beta^{n+1})$.

::: pf-proof
the cohomology of a product is the tensor product of the cohomology rings (over a field, the Künneth theorem gives a ring isomorphism).
:::

:::

::: {.pf-step #s3}
The graded ring $H^*(X(m,n);\ZZ_2)$ determines $(m,n)$.

::: pf-proof

::: pf-step
Its degree-$1$ part is one-dimensional, generated by $\beta$.

::: pf-proof
Since $|\alpha|=2$ and $|\beta|=1$, the only degree-$1$ monomial is $\beta$; thus $H^1(X(m,n);\ZZ_2)=\ZZ_2\beta$.
:::

:::

::: {.pf-step #s3-2}
The nilpotence order of the unique nonzero degree-$1$ class is $n+1$: $\beta^n\ne0$ and $\beta^{n+1}=0$.

::: pf-proof
This follows directly from the presentation in step [](#s2){.pf-ref}. Therefore any graded ring isomorphism preserves this nilpotence order and hence determines $n$.
:::

:::

::: {.pf-step #s3-3}
The largest degree in which the ring is nonzero is $2m+n$, represented by $\alpha^m\beta^n$.

::: pf-proof
The monomials $\alpha^i\beta^j$ with $0\le i\le m$ and $0\le j\le n$ form a basis. Their degrees are $2i+j$, whose maximum is $2m+n$.
:::

:::

::: {.pf-step #s3-4}
Once $n$ is known, the top nonzero degree determines
$$
m=\frac{(2m+n)-n}{2}.
$$
Hence the graded cohomology ring determines $(m,n)$.

::: pf-proof
Combine step [](#s3-2){.pf-ref} and step [](#s3-3){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s4}
Hence $X(m,n) \simeq X(m',n')$ iff $(m,n) = (m',n')$.

::: pf-proof

::: pf-step
If $(m,n) = (m',n')$, then $X(m,n) = X(m',n')$, so they are homotopy equivalent.

::: pf-proof
equality.
:::

:::

::: pf-step
If $X(m,n) \simeq X(m',n')$, then $H^*(X(m,n);\ZZ_2) \cong H^*(X(m',n');\ZZ_2)$.

::: pf-proof
homotopy equivalence induces a cohomology ring isomorphism.
:::

:::

::: pf-step
Hence $(m,n) = (m',n')$.

::: pf-proof
by step [](#s3-4){.pf-ref}, the ring determines $(m,n)$.
:::

:::

:::

:::

::: pf-qed
step [](#s4){.pf-ref} is the claim.
:::

::: {.problem}
One of the foci of the hyperbola $y ^ { 2 } = \left( \frac { x } { a } \right) ^ { 2 } + 1$ is the point $( 0 , \sqrt { 2 } )$ . Find $a$ . (A) $\frac { 1 } { 2 \sqrt { 2 } }$ (B) $\frac { 1 } { \sqrt { 2 } }$ (C) $\frac { 1 } { 2 }$ (D) $1$ (E) $\sqrt { 3 }$
:::

::: {.problem}
Find the largest value of $b$ such that $1 + b i$ satisfies the equation $x ^ { 3 } - 3 x ^ { 2 } + 6 x - 4 = 0$ given that every root of this equation has the form $1 + b i$ (where $b$ is real).
(A) $1$ (B) $\sqrt { 2 }$ (C) $\sqrt { 3 }$ (D) $2$ (E) $3$
:::

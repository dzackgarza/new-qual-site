::: {.problem}
Let $f$ be a function such that $f ( n + 1 ) = 1 - [ f ( n ) ] ^ { 2 }$ for all nonnegative integers $n$ . Which of the following correctly expresses $f ( n + 2 )$ in terms of $f ( n )$ ? (A) $2 [ f ( n ) ] ^ { 2 }$ (B) $2 f ( n ) - 2 [ f ( n ) ] ^ { 2 }$ (C) $2 f ( n ) + 2 [ f ( n ) ] ^ { 2 }$ (D) $2 [ f ( n ) ] ^ { 2 } - [ f ( n ) ] ^ { 4 }$ (E) $2 [ f ( n ) ] ^ { 2 } + [ f ( n ) ] ^ { 4 }$
:::

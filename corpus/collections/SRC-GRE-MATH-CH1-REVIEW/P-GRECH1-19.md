::: {.problem}
The hyperbolic sine function, denoted $\sinh$ , is defined by the equation:

$$
\sinh x = \frac { e ^ { x } - e ^ { - x } } { 2 }
$$

Find a formula for $\sinh ^ { - 1 } x$ .

(A) $\log ( 1 - \sqrt { x ^ { 2 } + 1 } )$

(B) $\log ( 1 + \sqrt { x ^ { 2 } + 1 } )$

(C) $\log ( x - \sqrt { x ^ { 2 } + 1 } )$

(D) $\log ( x + \sqrt { x ^ { 2 } + 1 } )$

(E) $\log ( \sqrt { x ^ { 2 } + 1 } - x )$
:::

::: {.problem}
Determine the positive values that satisfy the following inequality: $\frac { 1 } { x } - \frac { 1 } { x - 1 } > \frac { 1 } { x - 2 }$ (A) $( 0 , 1 ) \cup ( \sqrt { 2 } , 2 )$ (B) $( 0 , \frac { 1 } { 2 } ) \cup ( 1 , 2 )$ (C) $\bigl ( \frac { 1 } { 2 } , 1 \bigr ) \cup \bigl ( \sqrt { 2 } , 2 \sqrt { 2 } \bigr )$ (D) $( 0 , \sqrt { 2 } ) \cup ( \frac { 3 } { 2 } , 2 )$ (E) $( 1 , \sqrt { 2 } ) \cup ( 2 , 2 \sqrt { 2 } )$
:::

::: {.problem}
Let $x$ be the real number such that $\sin ( \sin x ) = \frac { 1 } { 2 }$ and $2 < x < 3$ . What's the value of $\cos ( - \sin x ) ?$ (A) $- \sqrt { 1 - \left( \frac { \pi } { 6 } \right) ^ { 2 } }$ (B) $\sqrt { 1 - \left( \frac { \pi } { 3 } \right) ^ { 2 } }$ (C) $\sqrt { 1 - \left( \frac { \pi } { 6 } \right) ^ { 2 } }$ (D) $- \frac { \sqrt { 3 } } { 2 }$ (E) $\frac { \sqrt { 3 } } { 2 }$
:::

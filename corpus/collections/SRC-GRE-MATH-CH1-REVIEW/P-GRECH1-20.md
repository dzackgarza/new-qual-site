::: {.problem}
The hyperbolic cosine function, denoted $\cosh$ , is defined by the equation:

$$
\cosh x = \frac { e ^ { x } + e ^ { - x } } { 2 }
$$

If the hyperbolic tangent function, $\tanh$ , is defined by

find a formula for $\tanh ^ { - 1 } x$ .

$$
\tanh x = \frac { \sinh x } { \cosh x }
$$

(A) $\frac { 1 } { 2 } \log \frac { x - 1 } { x + 1 }$ (B) $\log \frac { \frac { x } { 2 } - 1 } { \frac { x } { 2 } + 1 }$ (C) $\log \frac { 1 + \frac { x } { 2 } } { 1 - \frac { x } { 2 } }$ (D) $\frac { 1 } { 2 } \log \frac { x + 1 } { x - 1 }$ (E) $\frac { 1 } { 2 } \log \frac { 1 + x } { 1 - x }$
:::

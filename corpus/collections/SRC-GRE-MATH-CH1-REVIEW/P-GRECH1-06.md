::: {.problem}
Let $f$ , $g$ , and $h$ be real-valued functions defined for all positive $x$ such that: $( f \circ g ) ( x ) = ( g \circ h ) ( x )$

If $f ( x ) = x + 1$ and $g ( x ) = \sqrt { x }$ , what is $h ( x )$ ? (A) $x ^ { 2 } - 1$ (B) $\sqrt { x - 1 }$ (C) $\sqrt { x } + 2$ (D) $x \sqrt { x } + 1$ (E) $1 + ( \sqrt { x } + 2 ) \sqrt { x }$
:::

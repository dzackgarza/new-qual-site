(A) $( \frac { 1 } { 2 } , 0 )$ (B) $( 1 , 0 )$ (C) $( \frac { 3 } { 2 } , 0 )$ (D) $( 2 , 0 )$ (E) $( \frac { 5 } { 2 } , 0 )$
:::

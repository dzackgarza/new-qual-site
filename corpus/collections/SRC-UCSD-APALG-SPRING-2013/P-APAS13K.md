::: {.problem}
Let $S$ be the parametric surface defined by
\begin{align*}
x&=u-2v,\\
y&=uv,\\
z&=v.
\end{align*}

(a) Compute a reduced Gröbner basis for the ideal generated by this set of equations relative to the lexicographic order where $u>v>x>y>z$.

(b) Find the equation of the smallest variety $V$ that contains $S$.

(c) Show that $S=V$.
:::

::: {.solution}

**(a).**

::: pf

::: pf-step
The ideal is $I = (x - u + 2v, y - uv, z - v) \subseteq \mathbb{C}[u, v, x, y, z]$.

::: pf-proof
the parametric equations give the generators $x - (u - 2v)$, $y - uv$, $z - v$.
:::

:::

::: {.pf-step #elimination-relation}
Eliminating $u$ and $v$ (using $v = z$ and $u = x + 2z$), we get $y = uv = (x + 2z)z = xz + 2z^2$.

::: pf-proof
substitute $v = z$ and $u = x + 2z$ into $y = uv$.
:::

:::

::: {.pf-step #grobner-basis-final}
Hence the reduced Gröbner basis (for lex order $u > v > x > y > z$) is
$$\{u - x - 2z,\ v - z,\ y - xz - 2z^2\}.$$

::: pf-proof
Step [](#elimination-relation){.pf-ref} (these are the elimination polynomials, and they form a reduced Gröbner basis).
:::

:::

:::

**(b).**

::: pf

::: {.pf-step #variety-relation-derivation}
The smallest variety containing $S$ is $V(y - xz - 2z^2)$.

::: pf-proof
the image of the parametrization satisfies $y = xz + 2z^2$, and this is the only relation (the parametrization is injective on a Zariski-open set).
:::

:::

::: {.pf-step #variety-v-definition}
Hence $V = V(y - xz - 2z^2) = \{(x, y, z) : y = xz + 2z^2\}$.

::: pf-proof
Step [](#variety-relation-derivation){.pf-ref}.
:::

:::

:::

**(c).**

::: pf

::: {.pf-step #s-subset-v}
Every point of $S$ satisfies $y = xz + 2z^2$, so $S \subseteq V$.

::: pf-proof
Step [](#variety-v-definition){.pf-ref} (b).
:::

:::

::: {.pf-step #solve-for-uv}
Conversely, given $(x, y, z) \in V$ (so $y = xz + 2z^2$), set $u = x + 2z$ and $v = z$; then $u - 2v = x$, $uv = (x + 2z)z = xz + 2z^2 = y$, and $v = z$.

::: pf-proof
solve for $u, v$ in terms of $x, y, z$.
:::

:::

::: {.pf-step #v-subset-s}
Hence $(x, y, z) \in S$, so $V \subseteq S$.

::: pf-proof
Step [](#solve-for-uv){.pf-ref}.
:::

:::

::: {.pf-step #s-equals-v}
Therefore $S = V$.

::: pf-proof
Steps [](#s-subset-v){.pf-ref} and [](#v-subset-s){.pf-ref}.
:::

:::

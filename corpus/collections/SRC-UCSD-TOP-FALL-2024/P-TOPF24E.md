::: problem
Let $\Sigma$ be a one-holed torus (delete an open disc from a standard torus) whose boundary is identified with the standard $S^1$.
Let $(X, x_0)$ be a based path-connected space, $\alpha$ a loop based at $x_0$, and $[\alpha]$ the corresponding class in $\pi_1(X, x_0)$.
Show that $[\alpha]$ may be expressed algebraically as a commutator $yzy^{-1}z^{-1}$ of two elements $y, z \in \pi_1(X, x_0)$ if and only if "$\alpha$ extends to a map of $\Sigma$", meaning that $\alpha$ may be expressed as $f|_{\partial\Sigma}$ for some map $f \colon \Sigma \to X$.
Is there an analogue of this result for one-holed higher-genus surfaces?
:::

::: {.solution}
<1>1. $\pi_1(\Sigma) \cong \langle a, b, c \mid [a, b] = c \rangle$, where $a, b$ are the two generators of the torus and $c$ is the boundary loop.
Proof: the one-holed torus has fundamental group the free group on $a, b$ with the boundary loop $c$ equal to the commutator $[a, b] = aba^{-1}b^{-1}$.

<1>2. ($\Rightarrow$) If $[\alpha] = [y, z] = yzy^{-1}z^{-1}$, define $f : \Sigma \to X$ by mapping the two generators $a \mapsto y$, $b \mapsto z$.
Proof: a map from $\Sigma$ is determined by the images of the generators $a, b$ (since $\pi_1(\Sigma)$ is generated by $a, b$).

<1>3. Then $f|_{\partial\Sigma}$ represents $[a, b] = [y, z] = [\alpha]$, so $\alpha$ extends to a map of $\Sigma$.
Proof: <1>1 and <1>2 (the boundary loop maps to the commutator $[y, z]$).

<1>4. ($\Leftarrow$) If $\alpha = f|_{\partial\Sigma}$ for some $f : \Sigma \to X$, then $[\alpha] = f_*([\partial\Sigma]) = f_*([a, b]) = [f_*(a), f_*(b)]$.
Proof: <1>1 (the boundary represents the commutator $[a, b]$), and $f_*$ is a homomorphism.

<1>5. Hence $[\alpha] = [y, z]$ with $y = f_*(a)$, $z = f_*(b)$.
Proof: <1>4.

<1>6. Therefore $[\alpha]$ is a commutator iff $\alpha$ extends to a map of $\Sigma$.
Proof: <1>3 and <1>5.

<1>7. For a one-holed genus-$g$ surface $\Sigma_g$, $\pi_1(\Sigma_g) = \langle a_1, b_1, \ldots, a_g, b_g, c \mid [a_1, b_1]\cdots[a_g, b_g] = c \rangle$.
Proof: the boundary loop is the product of $g$ commutators.

<1>8. Hence the analogue holds: $[\alpha]$ is a product of $g$ commutators iff $\alpha$ extends to a map of the one-holed genus-$g$ surface.
Proof: <1>7 and the same argument as <1>2–<1>5.

<1>9. Q.E.D.
Proof: <1>6 and <1>8.
:::

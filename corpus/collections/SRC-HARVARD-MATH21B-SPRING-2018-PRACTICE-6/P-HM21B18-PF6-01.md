::: {.problem}
Mark each statement true or false. No justifications are required.

1. If $A$ is a real $n\times n$ matrix, then $A+A^T$ is diagonalizable.
2. The equation $z^3=-1$ has three distinct complex solutions, and $z=-1$ is one of them.
3. There is a $2\times2$ projection matrix $A$ projecting onto a line and a $2\times2$ reflection matrix $B$ such that $AB$ is a rotation matrix.
4. The map $T(f)(x)=f(f(x))$ is linear on $C^\infty$.
5. If a continuous function on $[-\pi,\pi]$ is both even and odd, then it is constant.
6. If $A$ is a $2\times2$ matrix, then the characteristic polynomial of $AA^T$ is $\lambda^2+c\lambda$ for some real $c$.
7. The function $f(t)=e^t$ is an eigenfunction with eigenvalue $1$ of $T=D^2$, where $Df=f'$.
8. The initial-value problem $f''(x)+f(x)=\sin x$, $f''(0)=1$, $f'(0)=1$ has exactly one solution.
9. The map $L(A)=A+A^T$ is linear on $M_n$, and its only eigenvalues are $0$ and $2$.
10. The smooth functions $f(x,y,z)$ satisfying $f_{xx}+f_{yy}+f_{zz}=f$ form a vector space.
11. If a $5\times5$ matrix has rank $2$, then the eigenvalue $0$ has algebraic multiplicity $3$.
12. Every equilibrium point of a nonlinear system $\dot x=f(x,y)$, $\dot y=g(x,y)$ lies on at least one nullcline.
13. The map $T(A)=\operatorname{rank}(A)$ is linear from $M_2$ to $\mathbb R$.
14. If $A$ is an $n\times n$ reflection matrix, then $A=QR$ with $Q=A$ and $R=I_n$ is its QR decomposition.
15. If all eigenvalues of a $2\times2$ matrix $A$ are zero, then $A$ is the zero matrix.
16. The discrete dynamical system $x(t+1)=7x(t)+3x(t-1)$ has the property that $|x(t)|$ stays bounded for every initial condition $(x(0),x(1))$.
17. $\|6\sin x+8\cos(9x)\|=10$ for the norm induced by
   \[
   \langle f,g\rangle=\frac1\pi\int_{-\pi}^{\pi}f(x)g(x)\,dx.
   \]
18. Every reflection has real eigenvalues and an orthonormal eigenbasis.
19. Let $A$ be an $n\times m$ matrix with trivial kernel. If
   \[
   A(A^TA)^{-1}A^Tb=b
   \]
   for every $b$, then $n=m$.
20. If $A,B$ are $2\times2$ matrices, $Ax=0$ has infinitely many solutions, and $Bx=0$ has exactly one solution, then $ABx=0$ has infinitely many solutions.
:::

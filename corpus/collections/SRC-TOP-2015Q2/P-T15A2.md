::: {.problem}
If $X=\mathbb R^n$ with the usual Euclidean topology and $U\subseteq X$ is an open, connected subspace of $X$, show that $U$ is also path connected.
:::

::: {.solution}
<1>1. Fix $x_0\in U$ and let
$$
P=\{x\in U:\text{there is a path in }U\text{ from }x_0\text{ to }x\}.
$$
::: {.proof}
The set $U$ is nonempty unless the conclusion is vacuous. We show that $P$ is both open and closed in the connected space $U$.
:::

<1>2. The set $P$ is open in $U$.
::: {.proof}
Let $x\in P$. Since $U$ is open in $\mathbb R^n$, choose $r>0$ such that the Euclidean ball $B(x,r)\subseteq U$. The ball is convex, so every $y\in B(x,r)$ is joined to $x$ by the straight-line path $t\mapsto(1-t)x+ty$ contained in $B(x,r)$. Concatenating this path with a path from $x_0$ to $x$ shows $y\in P$. Hence $B(x,r)\subseteq P$.
:::

<1>3. The complement $U\setminus P$ is open in $U$.
::: {.proof}
Let $x\in U\setminus P$. Choose $r>0$ with $B(x,r)\subseteq U$. If some $y\in B(x,r)$ belonged to $P$, then a path from $x_0$ to $y$ followed by the straight-line path from $y$ to $x$ inside the convex ball would show $x\in P$, a contradiction. Thus $B(x,r)\subseteq U\setminus P$.
:::

<1>4. Since $U$ is connected and $P$ is nonempty, $P=U$.
::: {.proof}
The set $P$ contains $x_0$. By <1>2--<1>3, $P$ is both open and closed in $U$. Connectedness leaves only the nonempty clopen subset $U$ itself.
:::

<1>5. Hence $U$ is path-connected.
::: {.proof}
By <1>4, every point of $U$ can be joined by a path to $x_0$. Given $x,y\in U$, concatenate the reverse of a path from $x_0$ to $x$ with a path from $x_0$ to $y$.
:::
:::

::: {.problem}
Find the (simplicial) homology groups of the space $X$ obtained from the 3-simplex $\Delta^3=[v_0,v_1,v_2,v_3]$ by gluing the face $[v_0,v_1,v_2]$ to the face $[v_0,v_2,v_3]$ and the face $[v_0,v_1,v_3]$ to the face $[v_1,v_2,v_3]$ (respecting the ordering of vertices as written, i.e., the first gluing map sends $v_1$ to $v_2$, and so on).
:::

::: {.solution}
<1>1. All four vertices are identified to a single vertex.
<2>1. The first gluing $[v_0,v_1,v_2] \to [v_0,v_2,v_3]$ sends $v_0 \mapsto v_0$, $v_1 \mapsto v_2$, $v_2 \mapsto v_3$, so $v_1 \sim v_2 \sim v_3$.
::: {.proof}
the gluing map as stated.
:::
<2>2. The second gluing $[v_0,v_1,v_3] \to [v_1,v_2,v_3]$ sends $v_0 \mapsto v_1$, $v_1 \mapsto v_2$, $v_3 \mapsto v_3$, so $v_0 \sim v_1 \sim v_2$.
::: {.proof}
the gluing map as stated.
:::
<2>3. Hence $v_0 \sim v_1 \sim v_2 \sim v_3$.
::: {.proof}
combine <2>1 and <2>2.
:::

<1>2. All six edges are identified to a single edge.
<2>1. The first gluing identifies $[v_0,v_1] \sim [v_0,v_2]$, $[v_1,v_2] \sim [v_2,v_3]$, $[v_0,v_2] \sim [v_0,v_3]$.
::: {.proof}
the induced identifications on edges of the two faces.
:::
<2>2. The second gluing identifies $[v_0,v_1] \sim [v_1,v_2]$, $[v_1,v_3] \sim [v_2,v_3]$, $[v_0,v_3] \sim [v_1,v_3]$.
::: {.proof}
the induced identifications on edges.
:::
<2>3. Chaining these gives $[v_0,v_1] \sim [v_0,v_2] \sim [v_1,v_2] \sim [v_2,v_3] \sim [v_1,v_3] \sim [v_0,v_3]$.
::: {.proof}
<2>1 and <2>2.
:::

<1>3. The two face pairings identify the four faces into two face classes: $a = [v_0,v_1,v_2] = [v_0,v_2,v_3]$ and $b = [v_0,v_1,v_3] = [v_1,v_2,v_3]$.
::: {.proof}
the two gluing relations.
:::

<1>4. The cellular chain complex is $C_3 = \ZZ$, $C_2 = \ZZ^2$, $C_1 = \ZZ$, $C_0 = \ZZ$.
::: {.proof}
<1>1–<1>3 give one $0$-cell, one $1$-cell, two $2$-cells, and one $3$-cell.
:::

<1>5. The boundary maps are: $d_3(1) = 2b - 2a$, $d_2(a) = d_2(b) = e$, $d_1(e) = 0$.
<2>1. $\partial[v_0,v_1,v_2,v_3] = [v_1,v_2,v_3] - [v_0,v_2,v_3] + [v_0,v_1,v_3] - [v_0,v_1,v_2] = b - a + b - a = 2b - 2a$.
::: {.proof}
the simplicial boundary of the $3$-simplex, using <1>3.
:::
<2>2. $\partial[v_0,v_1,v_2] = [v_1,v_2] - [v_0,v_2] + [v_0,v_1] = e - e + e = e$, and similarly $\partial[v_0,v_1,v_3] = e$.
::: {.proof}
the simplicial boundary, using <1>2.
:::
<2>3. $\partial e = v - v = 0$.
::: {.proof}
<1>1.
:::

<1>6. $H_0(X) = \ZZ$.
::: {.proof}
$X$ is connected (a single $0$-cell with $d_1 = 0$).
:::

<1>7. $H_1(X) = 0$.
::: {.proof}
$\ker d_1 = \ZZ$ and $\operatorname{im} d_2 = \langle e \rangle = \ZZ$, so $H_1 = \ZZ/\ZZ = 0$.
:::

<1>8. $H_2(X) = \ZZ/2$.
<2>1. $\ker d_2 = \{ma + nb : m + n = 0\} = \langle a - b \rangle \cong \ZZ$.
::: {.proof}
$d_2(ma + nb) = (m+n)e = 0$ iff $m + n = 0$.
:::
<2>2. $\operatorname{im} d_3 = \langle 2b - 2a \rangle = \langle 2(a-b) \rangle = 2\ZZ$.
::: {.proof}
<1>5.
:::
<2>3. Hence $H_2 = \langle a-b \rangle / \langle 2(a-b) \rangle \cong \ZZ/2$.
::: {.proof}
<2>1 and <2>2.
:::

<1>9. $H_3(X) = 0$.
::: {.proof}
$d_3$ is injective ($2b - 2a \neq 0$), so $\ker d_3 = 0$.
:::

<1>10. Q.E.D.
::: {.proof}
$H_0 = \ZZ$, $H_1 = 0$, $H_2 = \ZZ/2$, $H_3 = 0$ (<1>6–<1>9).
:::
:::

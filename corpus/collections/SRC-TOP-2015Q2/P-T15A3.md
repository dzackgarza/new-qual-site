::: {.problem}
Let $f:(X,\mathcal T)\to(Y,\mathcal T')$ be a continuous map.
A *section* of $f$ is a continuous map $\sigma:(Y,\mathcal T')\to(X,\mathcal T)$ so that $f\circ\sigma=\operatorname{Id}_Y$.
Show that if $f$ has a section, then $f$ is a quotient map.
:::

::: {.solution}

::: pf

::: {.pf-step #f-surjective}
$f$ is surjective.

::: pf-proof
For every $y\in Y$, $f(\sigma(y))=y$.
:::

:::

::: {.pf-step #preimage-open-criterion}
If $V\subseteq Y$ and $f^{-1}(V)\in\mathcal T$, then $V\in\mathcal T'$.

::: pf-proof
For $y\in Y$, $y\in\sigma^{-1}(f^{-1}(V))\iff f(\sigma(y))\in V\iff y\in V$, because $f\circ\sigma=\operatorname{Id}_Y$.
So $V=\sigma^{-1}(f^{-1}(V))$, which is open because $\sigma$ is continuous.
:::

:::

::: pf-qed
$f$ is continuous by hypothesis, surjective by step [](#f-surjective){.pf-ref}, and by step [](#preimage-open-criterion){.pf-ref} a subset of $Y$ is open whenever its preimage is open; so $f$ is a quotient map.
:::

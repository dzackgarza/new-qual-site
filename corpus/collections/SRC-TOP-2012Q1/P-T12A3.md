::: {.problem}
Let $X=S^2$ (i.e., the subspace of $\mathbb R^3$ consisting of points $(x,y,z)$ such that $x^2+y^2+z^2=1$). Define an equivalence relation on $X$ by $(x,y,z)\sim(x',y',z')$ if and only if $z=z'$.
Let $Y=X/\sim$ equipped with the quotient topology.
Prove $Y$ is homeomorphic to the closed interval $[-1,1]$.
:::

::: {.remark}
The source names the space $S^3$; its own parenthetical defines the unit sphere in $\RR^3$, which is $S^2$, and the quotient by the height fibres is $[-1,1]$ only for that sphere.
The name is corrected to agree with the definition the problem gives.
:::

::: {.solution}
<1>1. Let $q:S^2\to Y=S^2/\!\sim$ be the quotient map, and let $h:S^2\to[-1,1]$ be the height map $h(x,y,z)=z$.
::: {.proof}
The map $h$ is continuous as the restriction of the third-coordinate projection $\mathbb R^3\to\mathbb R$.
:::

<1>2. The map $h$ is constant on every equivalence class of $\sim$.
::: {.proof}
By definition,
$$
(x,y,z)\sim(x',y',z')\iff z=z',
$$
so equivalent points have the same height.
:::

<1>3. Hence there is a unique continuous map $\bar h:Y\to[-1,1]$ such that
$$
h=\bar h\circ q.
$$
::: {.proof}
This is the universal property of the quotient topology: a map out of $Y$ is continuous exactly when its composite with the quotient map is continuous.
:::

<1>4. The map $\bar h$ is bijective.
::: {.proof}
It is injective because two quotient classes have the same image under $\bar h$ exactly when representatives have the same $z$-coordinate, which is precisely the equivalence relation. It is surjective because for each $t\in[-1,1]$, the point
$$
(\sqrt{1-t^2},0,t)\in S^2
$$
has height $t$.
:::

<1>5. The quotient space $Y$ is compact.
::: {.proof}
The sphere $S^2$ is compact and $q:S^2\to Y$ is continuous and surjective, so $Y=q(S^2)$ is compact.
:::

<1>6. Therefore $\bar h:Y\to[-1,1]$ is a homeomorphism.
::: {.proof}
By <1>3 and <1>4, $\bar h$ is a continuous bijection. By <1>5, its domain is compact, while $[-1,1]$ is Hausdorff as a subspace of $\mathbb R$. A continuous bijection from a compact space to a Hausdorff space is a homeomorphism.
:::
:::

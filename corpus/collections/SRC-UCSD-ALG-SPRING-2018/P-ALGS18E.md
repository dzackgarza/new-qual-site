::: {.problem}
Suppose $A$ is a unital commutative ring and $\langle f_1, \ldots, f_n \rangle = A$ where $\langle f_1, \ldots, f_n \rangle$ is the ideal generated by the $f_i$'s. Suppose $M \subseteq N$ are two $A$-modules, and, for any $i$, we have $S_{f_i}^{-1} M = S_{f_i}^{-1} N$ where $S_{f_i} = \{1, f_i, f_i^2, \ldots\}$.
Prove that $M = N$.

Hint: For $x \in N$, consider $\{a \in A \mid ax \in M\}$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
Colon ideal setup:

::: pf-proof

::: pf-step
Let $x \in N$ be an arbitrary element.
Define the colon ideal:
\[
I = (M :_A x) = \{a \in A \mid a x \in M\}.
\]
$I$ is an ideal of $A$, and $x \in M \iff 1 \in I \iff I = A$.

::: pf-proof
definition of annihilator ideal of the element $x + M \in N/M$.
:::

:::

:::

:::

::: {.pf-step #s2}
Powers of generators lie in $I$:

::: pf-proof

::: pf-step
Fix $i \in \{1, \dots, n\}$.
In the localized module $N_{f_i} = S_{f_i}^{-1} N$, consider the fraction $\frac{x}{1}$.
Since $S_{f_i}^{-1} M = S_{f_i}^{-1} N$, we have $\frac{x}{1} \in S_{f_i}^{-1} M$, so $\frac{x}{1} = \frac{m_i}{f_i^{k_i}}$ for some $m_i \in M$ and $k_i \ge 0$.

::: pf-proof
hypothesis $S_{f_i}^{-1} M = S_{f_i}^{-1} N$.
:::

:::

::: pf-step
By the definition of equality in localization of modules, there exists an integer $r_i \ge 0$ such that:
\[
f_i^{r_i} (f_i^{k_i} x - m_i) = 0 \in N.
\]
Thus:
\[
f_i^{k_i + r_i} x = f_i^{r_i} m_i \in M.
\]

::: pf-proof
definition of localization relation.
:::

:::

::: {.pf-step #s2-3}
Setting $N_i = k_i + r_i$, we have $f_i^{N_i} x \in M$, which means $f_i^{N_i} \in I$.

::: pf-proof
definition of the colon ideal $I$.
:::

:::

:::

:::

::: {.pf-step #s3}
Partition of unity in $A$:

::: pf-proof

::: pf-step
Since $\langle f_1, \dots, f_n \rangle = A$, no maximal ideal contains all $f_i$.
Thus no maximal ideal contains the set $\{f_1^{N_1}, \dots, f_n^{N_n}\}$.
Consequently, the ideal generated by these powers is the entire ring:
\[
\langle f_1^{N_1}, \ldots, f_n^{N_n} \rangle = A.
\]

::: pf-proof
radical of $\langle f_1^{N_1}, \dots, f_n^{N_n} \rangle$ contains $\langle f_1, \dots, f_n \rangle = A$.
:::

:::

::: {.pf-step #s3-2}
Since $1 \in A = \langle f_1^{N_1}, \dots, f_n^{N_n} \rangle$, there exist elements $g_1, \dots, g_n \in A$ such that:
\[
1 = \sum_{i=1}^n g_i f_i^{N_i}.
\]

::: pf-proof
definition of ideal generated by a set.
:::

:::

:::

:::

::: {.pf-step #s4}
Deduce $x \in M$ and $M = N$:

::: pf-proof

::: pf-step
Multiplying the identity in step [](#s3-2){.pf-ref} by $x$:
\[
x = 1 \cdot x = \left(\sum_{i=1}^n g_i f_i^{N_i}\right) x = \sum_{i=1}^n g_i \big(f_i^{N_i} x\big).
\]

::: pf-proof
$A$-module distributive law.
:::

:::

::: pf-step
For each $i$, $f_i^{N_i} x \in M$ by step [](#s2-3){.pf-ref}. Since $M$ is an $A$-submodule of $N$, the linear combination $\sum_{i=1}^n g_i (f_i^{N_i} x)$ belongs to $M$.
Thus $x \in M$.

::: pf-proof
$M$ is closed under $A$-linear combinations.
:::

:::

::: pf-step
Since $x \in M$ for every $x \in N$, $N \subseteq M$.
Combined with $M \subseteq N$, we conclude $M = N$.

::: pf-proof
subset inclusions in both directions.
:::

:::

:::

:::

::: pf-step
Conclusion: $M = N$.

::: pf-proof
step [](#s1){.pf-ref} through step [](#s4){.pf-ref}.
:::

::: {.problem}
Let $X$ be the standard middle-thirds Cantor set in $\mathbb R$, viewed as a subset of $\mathbb R^2$. Suppose $f:X\to\mathbb R$ has the following property: for every $x\in X$ there is an open neighborhood $U_x\subset\mathbb R^2$ of $x$ and a smooth function
\[
f_x:U_x\to\mathbb R
\]
such that
\[
f_x|_{U_x\cap X}=f|_{U_x\cap X}.
\]
Show that there is an open set $U\subset\mathbb R^2$ containing $X$ and a smooth function $g:U\to\mathbb R$ such that
\[
g|_X=f.
\]
:::

::: {.problem}
Suppose that f is a twice-differentiable real-valued function on the real line such that $| f ( x ) | \leq$ 1 and $| f ^ { \prime \prime } ( x ) | \le 1$ for all x. Find, with proof, a constant b such that $| f ^ { \prime } ( x ) | < b$ for all x.
:::

::: {.problem}
Using induction or otherwise, show that the polynomial $P _ { n } ( x ) = 1 + x ^ { 1 } / 1 ! + . . . + x ^ { n } / n !$ has exactly 1 real zero if n is odd and none if n is even.
:::

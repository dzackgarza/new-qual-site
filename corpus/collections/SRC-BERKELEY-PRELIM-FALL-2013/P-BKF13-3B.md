::: {.problem}
Suppose that $f : ( 0 , 1 ) \to \mathbf { R }$ is a continuous function with $\textstyle \int _ { 0 } ^ { 1 } | f ( t ) | \ d t < \infty$ . Define g : $( 0 , 1 )  \mathbf { R }$ by

$$
g ( x ) = \int _ { x } ^ { 1 } { \frac { f ( t ) } { t } } d t .
$$

Show that $\begin{array} { r } { \int _ { 0 } ^ { 1 } \left| g ( x ) \right| d x < \infty } \end{array}$
:::

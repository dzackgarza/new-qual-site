Define a set of positive real numbers as follows.
Let $x _ { 0 } > 0$ be any positive number, and let $x _ { n + 1 } = ( 1 + x _ { n } ) ^ { - 1 }$ for all $n \geq 0$ . Prove that this sequence converges, and find its limit.

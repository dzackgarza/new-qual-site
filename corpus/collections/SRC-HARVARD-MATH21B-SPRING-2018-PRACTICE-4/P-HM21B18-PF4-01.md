::: {.problem}
Mark each statement true or false. No justifications are required.

1. $\begin{pmatrix}0&1\\1&1\end{pmatrix}$ is invertible.
2. The difference of two eigenvectors of a matrix is always an eigenvector.
3. For any invertible $7\times7$ matrix, the column space is an eigenspace.
4. If a $2\times2$ matrix $A$ is diagonalizable, then $A^2$ is diagonalizable.
5. $f(x)=x\sin x$ has a cosine Fourier expansion.
6. The smooth solutions of $f(x)=f(1+f(x))$ form a vector space.
7. For a $5\times5$ matrix, the sum of geometric multiplicities is at most the sum of algebraic multiplicities.
8. The sum of a $2\times2$ rotation matrix and a $2\times2$ reflection matrix is orthogonal.
9. A discrete linear system with all eigenvalues negative is asymptotically stable.
10. There exists a matrix $A$ for which both $x'=Ax$ and $x(t+1)=Ax(t)$ are asymptotically stable.
11. An orthogonal rotation composed with an orthogonal projection in the plane is always an orthogonal projection.
12. $f(x,t)=e^{-t}\sin t-e^{-25t}\sin(5t)$ satisfies $f_t=f_{xx}$.
13. For a $20\times10$ matrix $A$, $Ax=b$ has either zero or infinitely many solutions.
14. At the equilibrium $(0,0)$ of $x'=x+y^2$, $y'=x-y^2$, the Jacobian matrix is invertible.
15. Some matrices are diagonalizable over $\CC$ but not over $\RR$.
16. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\|\sin(5x)-\sin(10x)\|=2$.
17. The sum of two eigenvalues of a noninvertible $3\times3$ matrix is an eigenvalue.
18. Every solution of $x''+x=\sin t$ is bounded.
19. If $A$ is similar to $B$, then $A^T$ is similar to $B^T$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}
Statement 1 is $\boxed{\mathrm T}$.

::: pf-proof
The determinant is $0\cdot1-1\cdot1=-1\ne0$.
:::

:::

::: {.pf-step #s1-2}
Statement 2 is $\boxed{\mathrm F}$.

::: pf-proof
For $A=\operatorname{diag}(1,2)$, the vectors $e_1,e_2$ are eigenvectors, but
$$
A(e_1-e_2)=e_1-2e_2
$$
is not a scalar multiple of $e_1-e_2$.
:::

:::

::: {.pf-step #s1-3}
Statement 3 is $\boxed{\mathrm F}$.

::: pf-proof
The column space of an invertible $7\times7$ matrix is $\RR^7$. An eigenspace equal to $\RR^7$ would force $A=\lambda I$. The invertible matrix $A=\operatorname{diag}(1,2,2,2,2,2,2)$ is not scalar, and its eigenspaces have dimensions $1$ and $6$, so neither is $\RR^7$.
:::

:::

::: {.pf-step #s1-4}
Statement 4 is $\boxed{\mathrm T}$.

::: pf-proof
If $A=PDP^{-1}$ with $D$ diagonal, then $A^2=PD^2P^{-1}$, and $D^2$ is diagonal.
:::

:::

::: {.pf-step #s1-5}
Statement 5 is $\boxed{\mathrm T}$.

::: pf-proof
The function $x\sin x$ is even, since $(-x)\sin(-x)=x\sin x$. Its Fourier series on $[-\pi,\pi]$ therefore has only cosine terms.
:::

:::

::: {.pf-step #s1-6}
Statement 6 is $\boxed{\mathrm F}$.

::: pf-proof
The constant function $f=1$ and the function $g(x)=x-1$ satisfy the equation, but their sum $h(x)=x$ does not:
$$
h(1+h(x))=1+x\ne x.
$$
:::

:::

::: {.pf-step #s1-7}
Statement 7 is $\boxed{\mathrm T}$.

::: pf-proof
For each eigenvalue, the geometric multiplicity is at most the algebraic multiplicity. Summing over the eigenvalues gives the claim.
:::

:::

::: {.pf-step #s1-8}
Statement 8 is $\boxed{\mathrm F}$.

::: pf-proof
The identity rotation plus the reflection $\operatorname{diag}(1,-1)$ is $\operatorname{diag}(2,0)$, which is not orthogonal.
:::

:::

::: {.pf-step #s1-9}
Statement 9 is $\boxed{\mathrm F}$.

::: pf-proof
For $A=-2I$, all eigenvalues are negative, but $A^n=(-2)^nI$ does not converge to $0$. The discrete system is therefore not asymptotically stable.
:::

:::

::: {.pf-step #s1-10}
Statement 10 is $\boxed{\mathrm T}$.

::: pf-proof
Take $A=-\frac12 I$. Its eigenvalue $-\frac12$ has negative real part and modulus less than $1$, so both the continuous and the discrete systems are asymptotically stable.
:::

:::

::: {.pf-step #s1-11}
Statement 11 is $\boxed{\mathrm F}$.

::: pf-proof
Let $P=\operatorname{diag}(1,0)$ and let $R$ be the $90^\circ$ rotation. Then
$$
PR=\begin{pmatrix}0&-1\\0&0\end{pmatrix},
$$
whose square is $0$, not $PR$. Hence $PR$ is not a projection.
:::

:::

::: {.pf-step #s1-12}
Statement 12 is $\boxed{\mathrm F}$.

::: pf-proof
The function $f$ does not depend on $x$, so $f_{xx}=0$. At $t=0$,
$$
f_t(0)=1-5=-4\ne0,
$$
so $f_t\ne f_{xx}$.
:::

:::

::: {.pf-step #s1-13}
Statement 13 is $\boxed{\mathrm F}$.

::: pf-proof
Take
$$
A=\begin{pmatrix}I_{10}\\0_{10\times10}\end{pmatrix},
\qquad
b=\binom{c}{0}
$$
with $c\in\RR^{10}$. Then $x=c$ is the unique solution of $Ax=b$.
:::

:::

::: {.pf-step #s1-14}
Statement 14 is $\boxed{\mathrm F}$.

::: pf-proof
The Jacobian is
$$
J=\begin{pmatrix}1&2y\\1&-2y\end{pmatrix},
$$
so
$$
J(0,0)=\begin{pmatrix}1&0\\1&0\end{pmatrix}
$$
has determinant $0$. It is not invertible.
:::

:::

::: {.pf-step #s1-15}
Statement 15 is $\boxed{\mathrm T}$.

::: pf-proof
The $90^\circ$ rotation
$$
\begin{pmatrix}0&-1\\1&0\end{pmatrix}
$$
has eigenvalues $\pm i$. It is diagonalizable over $\CC$ but not over $\RR$.
:::

:::

::: {.pf-step #s1-16}
Statement 16 is $\boxed{\mathrm F}$.

::: pf-proof
The squared norm is
$$
\pi^{-1}\int_{-\pi}^{\pi}\left(\sin^2(5x)+\sin^2(10x)-2\sin(5x)\sin(10x)\right)\,dx=1+1-0=2,
$$
so the norm is $\sqrt2$, not $2$.
:::

:::

::: {.pf-step #s1-17}
Statement 17 is $\boxed{\mathrm F}$.

::: pf-proof
For $A=\operatorname{diag}(0,1,2)$, the eigenvalues are $0,1,2$. The sum $1+2=3$ is not an eigenvalue.
:::

:::

::: {.pf-step #s1-18}
Statement 18 is $\boxed{\mathrm F}$.

::: pf-proof
The function $x_p(t)=-\frac12 t\cos t$ satisfies $x_p''+x_p=\sin t$ and is unbounded. Hence the general solution is unbounded.
:::

:::

::: {.pf-step #s1-19}
Statement 19 is $\boxed{\mathrm T}$.

::: pf-proof
If $B=S^{-1}AS$, then
$$
B^T=S^T A^T (S^{-1})^T=S^T A^T (S^T)^{-1},
$$
so $B^T$ is similar to $A^T$.
:::

::: {.problem}
Mark each statement true or false. No justifications are required.

1. $\begin{pmatrix}0&1\\1&1\end{pmatrix}$ is invertible.
2. The difference of two eigenvectors of a matrix is always an eigenvector.
3. For any invertible $7\times7$ matrix, the column space is an eigenspace.
4. If a $2\times2$ matrix $A$ is diagonalizable, then $A^2$ is diagonalizable.
5. $f(x)=x\sin x$ has a cosine Fourier expansion.
6. The smooth solutions of $f(x)=f(1+f(x))$ form a vector space.
7. For a $5\times5$ matrix, the sum of geometric multiplicities is at most the sum of algebraic multiplicities.
8. The sum of a $2\times2$ rotation matrix and a $2\times2$ reflection matrix is orthogonal.
9. A discrete linear system with all eigenvalues negative is asymptotically stable.
10. There exists a matrix $A$ for which both $x'=Ax$ and $x(t+1)=Ax(t)$ are asymptotically stable.
11. An orthogonal rotation composed with an orthogonal projection in the plane is always an orthogonal projection.
12. $f(x,t)=e^{-t}\sin t-e^{-25t}\sin(5t)$ satisfies $f_t=f_{xx}$.
13. For a $20\times10$ matrix $A$, $Ax=b$ has either zero or infinitely many solutions.
14. At the equilibrium $(0,0)$ of $x'=x+y^2$, $y'=x-y^2$, the Jacobian matrix is invertible.
15. Some matrices are diagonalizable over $\mathbb C$ but not over $\mathbb R$.
16. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\|\sin(5x)-\sin(10x)\|=2$.
17. The sum of two eigenvalues of a noninvertible $3\times3$ matrix is an eigenvalue.
18. Every solution of $x''+x=\sin t$ is bounded.
19. If $A$ is similar to $B$, then $A^T$ is similar to $B^T$.
20. A $3\times3$ matrix $A$ is invertible if and only if all its eigenvalues are positive.
:::

::: {.solution}
<1>1. Statement 1 is $\boxed{\mathrm{T}}$.

::: {.proof}
The determinant is
\[
\det\begin{pmatrix}0&1\\1&1\end{pmatrix}=-1\ne0,
\]
so the matrix is invertible.
:::

<1>2. Statement 2 is $\boxed{\mathrm{F}}$.

::: {.proof}
For $A=\operatorname{diag}(1,2)$, the vectors $e_1$ and $e_2$ are eigenvectors, but
\[
A(e_1-e_2)=e_1-2e_2
\]
is not a scalar multiple of $e_1-e_2$. Thus the difference need not be an eigenvector.
:::

<1>3. Statement 3 is $\boxed{\mathrm{F}}$.

::: {.proof}
Let $A=\operatorname{diag}(1,2,1,1,1,1,1)$. This matrix is invertible, so its column space is all of $\mathbb R^7$. But $e_1$ and $e_2$ have different eigenvalues, so $\mathbb R^7$ cannot be an eigenspace of $A$ for one eigenvalue.
:::

<1>4. Statement 4 is $\boxed{\mathrm{T}}$.

::: {.proof}
If $A=PDP^{-1}$ with $D$ diagonal, then
\[
A^2=PD^2P^{-1},
\]
and $D^2$ is diagonal. Hence $A^2$ is diagonalizable.
:::

<1>5. Statement 5 is $\boxed{\mathrm{T}}$.

::: {.proof}
Both $x$ and $\sin x$ are odd, so $x\sin x$ is even. Therefore all sine coefficients in its Fourier expansion on $[-\pi,\pi]$ vanish, leaving a cosine series.
:::

<1>6. Statement 6 is $\boxed{\mathrm{F}}$.

::: {.proof}
The functions $f(x)=1$ and $g(x)=x-1$ both satisfy $h(x)=h(1+h(x))$. Their sum is $h(x)=x$, but
\[
h(1+h(x))=1+x\ne x=h(x).
\]
Thus the solution set is not closed under addition.
:::

<1>7. Statement 7 is $\boxed{\mathrm{T}}$.

::: {.proof}
For every eigenvalue, its geometric multiplicity is at most its algebraic multiplicity. Summing these inequalities over the eigenvalues gives the asserted inequality.
:::

<1>8. Statement 8 is $\boxed{\mathrm{F}}$.

::: {.proof}
Take
\[
R=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
\qquad
F=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.
\]
Here $R$ is a rotation and $F$ is a reflection, but
\[
R+F=\begin{pmatrix}1&-1\\1&-1\end{pmatrix}
\]
does not have orthonormal columns, so it is not orthogonal.
:::

<1>9. Statement 9 is $\boxed{\mathrm{F}}$.

::: {.proof}
For $A=-2I_4$, every eigenvalue is negative, but a nonzero initial condition gives
\[
x_n=A^n x_0=(-2)^n x_0,
\]
which does not tend to $0$. Hence the discrete system is not asymptotically stable.
:::

<1>10. Statement 10 is $\boxed{\mathrm{T}}$.

::: {.proof}
Take $A=-\frac12 I$. For the continuous system,
\[
x(t)=e^{-t/2}x(0)\longrightarrow0.
\]
For the discrete system,
\[
x_n=\left(-\frac12\right)^n x_0\longrightarrow0.
\]
Thus both systems are asymptotically stable.
:::

<1>11. Statement 11 is $\boxed{\mathrm{F}}$.

::: {.proof}
Let
\[
R=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
\qquad
P=\begin{pmatrix}1&0\\0&0\end{pmatrix}.
\]
Then $R$ is an orthogonal rotation and $P$ an orthogonal projection, while
\[
PR=\begin{pmatrix}0&-1\\0&0\end{pmatrix}
\]
satisfies $(PR)^2=0\ne PR$. Since every projection is idempotent, $PR$ is not an orthogonal projection.
:::

<1>12. Statement 12 is $\boxed{\mathrm{F}}$.

::: {.proof}
The displayed function is independent of $x$, so $f_{xx}=0$. At $t=0$,
\[
f_t(x,0)=1-5=-4,
\]
and therefore $f_t(x,0)\ne f_{xx}(x,0)$.
:::

<1>13. Statement 13 is $\boxed{\mathrm{F}}$.

::: {.proof}
Let
\[
A=\begin{pmatrix}I_{10}\\0_{10\times10}\end{pmatrix},
\qquad b=0.
\]
Then $A$ has trivial kernel, so $Ax=0$ has the unique solution $x=0$. Thus a $20\times10$ system can have exactly one solution.
:::

<1>14. Statement 14 is $\boxed{\mathrm{F}}$.

::: {.proof}
The Jacobian of the vector field is
\[
J(x,y)=\begin{pmatrix}1&2y\\1&-2y\end{pmatrix}.
\]
Hence
\[
J(0,0)=\begin{pmatrix}1&0\\1&0\end{pmatrix},
\]
whose determinant is $0$. Therefore the Jacobian is not invertible.
:::

<1>15. Statement 15 is $\boxed{\mathrm{T}}$.

::: {.proof}
The real rotation
\[
R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}
\]
has distinct eigenvalues $i$ and $-i$ over $\mathbb C$, so it is diagonalizable over $\mathbb C$. It has no real eigenvalues, so it cannot be diagonalizable over $\mathbb R$.
:::

<1>16. Statement 16 is $\boxed{\mathrm{F}}$.

::: {.proof}
Orthogonality of distinct sine modes gives
\[
\frac1\pi\int_{-\pi}^{\pi}\sin(5x)\sin(10x)\,dx=0,
\]
while each of $\sin(5x)$ and $\sin(10x)$ has squared norm $1$. Consequently
\[
\|\sin(5x)-\sin(10x)\|^2=2,
\]
so the norm is $\sqrt2$, not $2$.
:::

<1>17. Statement 17 is $\boxed{\mathrm{F}}$.

::: {.proof}
The noninvertible matrix $A=\operatorname{diag}(0,1,2)$ has eigenvalues $0,1,2$, but $1+2=3$ is not an eigenvalue of $A$.
:::

<1>18. Statement 18 is $\boxed{\mathrm{F}}$.

::: {.proof}
The function
\[
x_p(t)=-\frac12 t\cos t
\]
satisfies $x_p''+x_p=\sin t$. It is unbounded, for example along $t=2\pi n$. Hence not every solution is bounded.
:::

<1>19. Statement 19 is $\boxed{\mathrm{T}}$.

::: {.proof}
If $B=S^{-1}AS$, then
\[
B^T=S^TA^T(S^T)^{-1}.
\]
Thus $B^T$ is similar to $A^T$, equivalently $A^T$ is similar to $B^T$.
:::

<1>20. Statement 20 is $\boxed{\mathrm{F}}$.

::: {.proof}
The matrix $A=-I_3$ is invertible, but all three of its eigenvalues are $-1$, which are negative. Thus invertibility does not imply that all eigenvalues are positive.
:::

<1>21. Q.E.D.

::: {.proof}
Steps <1>1--<1>20 determine the truth value of every statement.
:::

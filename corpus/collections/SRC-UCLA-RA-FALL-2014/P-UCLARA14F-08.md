::: {.problem}
Let $f : \mathbb{C} \to \mathbb{C}$ be an entire function. Show that
\[
|f(z)| \leq C e^{a|z|}, \quad z \in \mathbb{C},
\]
for some constants $C$ and $a$ if and only if we have
\[
|f^{(n)}(0)| \leq M^{n+1}, \quad n = 0, 1, \ldots,
\]
for some constant $M$.
:::

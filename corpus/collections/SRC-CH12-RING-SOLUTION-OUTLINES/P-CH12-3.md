::: {.problem}
Give an example of a subset of a ring that is a subgroup under addition but not a subring.
:::

::: {.solution}

No solution set for this chapter is retained in `tmp/sources`, so the two examples are the ones this collection's outline records and the verification below is the card's own. The statement was checked against Gallian, *Contemporary Abstract Algebra* (7th edition), Chapter 12, Exercises,

A subring of a ring $R$ is a subset that is itself a ring under the restrictions of the two operations of $R$; in particular it is closed under multiplication. Both examples use the following criterion: a nonempty subset $S$ of an additive abelian group is a subgroup exactly when $a-b\in S$ for all $a,b\in S$.

::: pf

::: {.pf-step #criterion}
If $S\subset\CC$ is nonempty and $a-b\in S$ whenever $a,b\in S$, then $S$ is a subgroup of $(\CC,+)$.

::: pf-proof
Pick $s\in S$; then $0=s-s\in S$, and for $a\in S$ we get $-a=0-a\in S$, and for $a,b\in S$ we get $a+b=a-(-b)\in S$. So $S$ contains $0$ and is closed under addition and negation, which is the subgroup criterion for the abelian group $(\CC,+)$.
:::

:::

::: {.pf-step #gaussian-subgroup}
$S\coloneqq\{bi\mid b\in\ZZ\}$ is a subgroup of $(\CC,+)$.

::: pf-proof
$S$ is nonempty, and for $b,b'\in\ZZ$ we have $bi-b'i=(b-b')i\in S$ because $b-b'\in\ZZ$; apply step [](#criterion){.pf-ref}.
:::

:::

::: {.pf-step #gaussian-not-closed}
$S$ is not closed under multiplication.

::: pf-proof
The element $i=1\cdot i$ lies in $S$, and $i\cdot i=-1$. If $-1=bi$ with $b\in\ZZ$, then comparing real parts in $\CC$ gives $-1=0$, a contradiction; so $-1\notin S$ and the product of two elements of $S$ escapes $S$.
:::

:::

::: {.pf-step #gaussian-result}
$S$ is a subgroup under addition but not a subring of $\CC$.

::: pf-proof
Step [](#gaussian-subgroup){.pf-ref} gives the subgroup, and a subring containing $i$ would have to contain $i\cdot i=-1$; by step [](#gaussian-not-closed){.pf-ref} it does not, so $S$ is not a subring.
:::

:::

::: {.pf-step #real-subgroup}
$T\coloneqq\{n\sqrt2\mid n\in\ZZ\}$ is a subgroup of $(\RR,+)$.

::: pf-proof
Nonempty, and $n\sqrt2-m\sqrt2=(n-m)\sqrt2\in T$ for $n,m\in\ZZ$; apply step [](#criterion){.pf-ref} with $\RR$ in place of $\CC$.
:::

:::

::: {.pf-step #real-not-closed}
$T$ is not closed under multiplication.

::: pf-proof
$\sqrt2=1\cdot\sqrt2\in T$ and $(\sqrt2)^{2}=2$. If $2=n\sqrt2$ with $n\in\ZZ$, then $n\neq0$ gives $\sqrt2=2/n\in\QQ$, contradicting the irrationality of $\sqrt2$, while $n=0$ gives $2=0$. Hence $2\notin T$.
:::

:::

::: {.pf-step}
The subsets $S\subset\CC$ and $T\subset\RR$ are each a subgroup under addition and not a subring, so each answers the exercise.

::: pf-proof
Steps [](#gaussian-result){.pf-ref} and [](#real-not-closed){.pf-ref} with [](#real-subgroup){.pf-ref}: the second example fails to be a subring for the same reason as the first, absence of closure under multiplication, which the definition of a subring requires.
:::

::: {.problem}
Give an example of a subset of a ring that is a subgroup under addition but not a subring.
:::

::: {.solution}
In $\CC$ , $\{ b i \st b \in \ZZ \}$ is a subgroup but not a subring since $i ^ { 2 } = - 1 \notin \{ b i \}$ . Similarly, in $\RR$ , $\{ n { \sqrt { 2 } } \st n \in \ZZ \}$ is a subgroup but not a subring.
:::

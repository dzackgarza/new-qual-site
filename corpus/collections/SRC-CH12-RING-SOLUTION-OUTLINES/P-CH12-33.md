::: {.problem}
Suppose that R is a ring such that $x ^ { 3 } = x$ for all x in R. Prove that $6 x = 0$ for all x in R.
:::

::: {.solution}
Let R be a ring such that $x ^ { 3 } = x$ for all $x \in R$ . Then, for any $x , ( 2 x ) ^ { 3 } = 2 x$ and $8 x ^ { 3 } = 8 x$ . Hence $2 x = 8 x$ , so $6 x = 0$ .
:::

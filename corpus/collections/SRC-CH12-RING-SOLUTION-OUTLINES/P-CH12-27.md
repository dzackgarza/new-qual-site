::: {.problem}
Show that a unit of a ring divides every element of the ring.
:::

::: {.solution}
Let a be a unit in a ring R. Let x be any element in R. Then $x = a a ^ { - 1 } x = a ( a ^ { - 1 } x )$ , and $a ^ { - 1 } x$ is also in R. Hence a divides x.
:::

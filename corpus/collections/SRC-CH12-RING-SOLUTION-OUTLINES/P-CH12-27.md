::: {.problem}
Show that a unit of a ring divides every element of the ring.
:::

::: {.solution}

The argument is that of the retained solution outline for Chapter 12, Exercise 27 (`assets/attachments/Ch12Sltns.pdf`), restructured into numbered steps. Here $R$ is a ring, $a\in R$ is a unit, so there is $a^{-1}\in R$ with $aa^{-1}=a^{-1}a=1$, and $a$ divides $x$ when $x=ar$ for some $r\in R$.

::: pf

::: {.pf-step #factor}

For every $x\in R$, $x=a(a^{-1}x)$.

::: pf-proof

$a(a^{-1}x)=(aa^{-1})x=1x=x$ by associativity and the defining property of $a^{-1}$.

:::

:::

::: {.pf-step #closed}

$a^{-1}x\in R$.

::: pf-proof

$R$ is closed under multiplication and $a^{-1},x\in R$.

:::

:::

::: {.pf-step #done}

$a$ divides every element of $R$.

::: pf-proof

Step [](#factor){.pf-ref} exhibits $x$ as $a$ times the element $a^{-1}x$ of step [](#closed){.pf-ref}, which is the definition of divisibility by $a$.

:::

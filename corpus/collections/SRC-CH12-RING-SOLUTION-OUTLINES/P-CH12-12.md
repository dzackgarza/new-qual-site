::: {.problem}
Let $a$, $b$, and $c$ be elements of a commutative ring, and suppose that $a$ is a unit.
Prove that $b$ divides $c$ if and only if $ab$ divides $c$.
:::

::: {.solution}

The argument is the card's own: the two divisibility statements differ by multiplication by the unit $a$.

::: pf

::: {.pf-step #forward}

If $b\mid c$ then $ab\mid c$.

::: pf-proof

$b\mid c$ means $c=bd$ for some $d$ in the ring. Since $a$ is a unit with inverse $a^{-1}$, also $c=ab(a^{-1}d)$, and $a^{-1}d$ lies in the ring; so $ab$ divides $c$.

:::

:::

::: {.pf-step #backward}

If $ab\mid c$ then $b\mid c$.

::: pf-proof

$ab\mid c$ means $c=abd$ for some $d$. Commutativity gives $c=b(ad)$ with $ad$ in the ring, so $b\mid c$. Commutativity is what allows the factor $a$ to be moved next to $d$, and it is where the hypothesis on the ring is used.

:::

:::

::: {.pf-step #conclusion}

$b\mid c$ if and only if $ab\mid c$.

::: pf-proof

Steps [](#forward){.pf-ref} and [](#backward){.pf-ref} give the two implications:
$$
\boxed{a\ \text{a unit}\implies\bigl(b\mid c\iff ab\mid c\bigr).}
$$

:::

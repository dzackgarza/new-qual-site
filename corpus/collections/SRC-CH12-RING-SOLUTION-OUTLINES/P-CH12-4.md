::: {.problem}
Show, by example, that for any fixed nonzero elements a and b in a ring, the equation $a x = b$ can have more than one solution.
How does this compare with groups?
:::

::: {.solution}
Consider the ring $\mathbb { Z } _ { 4 }$ , and let $a = b = 2$ . Then $2 ( 1 ) = 2$ and $2 ( 3 ) = 2$ , so $2 x = 2$ has two solutions.
This is in contrast to groups where there is only one solution, $x = a ^ { - 1 } b$ .
:::

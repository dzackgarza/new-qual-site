::: {.problem}
Show, by example, that for any fixed nonzero elements a and b in a ring, the equation $a x = b$ can have more than one solution.
How does this compare with groups?
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines.

::: pf

::: {.pf-step #example}
In $\ZZ_4$, with $a=b=2$, the equation $ax=b$ has the two distinct solutions $x=1$ and $x=3$.

::: pf-proof
$2\cdot1=2$ in $\ZZ_4$, and $2\cdot3=6$, which is congruent to $2$ modulo $4$, so both $1$ and $3$ satisfy $2x=2$; and $1\ne3$ in $\ZZ_4$. So the equation has more than one solution, with $a=b=2\ne0$ as required.
:::

:::

::: {.pf-step #groups}
In a group $G$, for fixed $a,b\in G$ the equation $ax=b$ has exactly one solution, namely $x=a^{-1}b$.

::: pf-proof
$a(a^{-1}b)=b$, so $a^{-1}b$ is a solution. If $ax=b$ then multiplying on the left by $a^{-1}$ gives $x=a^{-1}b$, so there is no other. The argument uses only that $a$ has an inverse, which holds because $G$ is a group; in a ring an element need not be invertible, and even when $a$ is, the failure above comes from $\ZZ_4$ not being a domain, so cancellation is unavailable.
:::

:::

::: {.pf-step}
A linear equation $ax=b$ over a ring can have several solutions, while over a group it has exactly one.

::: pf-proof
Step [](#example){.pf-ref} exhibits two solutions in the ring $\ZZ_4$, and step [](#groups){.pf-ref} shows uniqueness in any group. That is the comparison the problem asks for, and it shows that the uniqueness of solutions in the group case is a consequence of invertibility, not of the shape of the equation.
:::

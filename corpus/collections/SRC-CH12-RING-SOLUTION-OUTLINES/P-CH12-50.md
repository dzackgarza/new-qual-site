::: {.problem}
Suppose that $R$ is a ring and that $a^{2} = a$ for all $a$ in $R$. Show that $R$ is commutative.
(Note: Such a ring is called a Boolean ring.)
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $R$ be a ring in which $a^2=a$ for every $a\in R$.

::: pf

::: {.pf-step #expansion}
For all $a,b\in R$: $ab+ba=0$, hence $ab=-ba$.

::: pf-proof
Since $a+b$ is an element of $R$, $(a+b)^2=a+b$. Expanding and keeping the order of the factors, $(a+b)^2=a^2+ab+ba+b^2$, using distributivity; the two cross terms are not equal a priori because $R$ need not be commutative. With $a^2=a$ and $b^2=b$ this gives $a+b=a+b+ab+ba$, so $ab+ba=0$ after cancelling $a+b$, which is legitimate in the additive group. Hence $ab=-ba$.
:::

:::

::: {.pf-step #sign}
$-ba=ba$.

::: pf-proof
The element $-ba$ lies in $R$, so it is idempotent: $(-ba)^2=-ba$. On the other hand $(-ba)^2=(-1)^2(ba)(ba)=(ba)^2$, and $ba\in R$ is idempotent, so $(ba)^2=ba$. Hence $-ba=ba$.
:::

:::

::: {.pf-step #commutative}
$ab=ba$ for all $a,b$, so $R$ is commutative.

::: pf-proof
Combine: $ab=-ba$ by step [](#expansion){.pf-ref} and $-ba=ba$ by step [](#sign){.pf-ref}, so $ab=ba$. Since $a,b$ were arbitrary, the multiplication of $R$ is commutative. (The hypothesis $a^2=a$ for all $a$ is what makes both steps available; the argument needs no unity and no characteristic assumption.)
:::

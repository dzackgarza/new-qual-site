::: {.problem}
Describe the elements of $M _ { 2 } ( \mathbb { Z } )$ that have multiplicative inverses.
:::

::: {.solution}
Let $A = { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] }$ be an element of $M _ { 2 } ( \mathbb { Z } )$ . If $AB = I$ with $B \in M_2(\mathbb Z)$, then $\det(A)\det(B) = 1$ with $\det(A), \det(B) \in \mathbb Z$, so $\det(A) = \pm 1$. Conversely, if $\det(A) = \pm1$, then $A^{-1} = \pm\left[\begin{array}{rr} d & -b \\ -c & a \end{array}\right]$ has integer entries. Thus the elements with multiplicative inverse are $\left\{ { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } \ | a d - b c = \pm 1 \right\}$
:::

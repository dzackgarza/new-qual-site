::: {.problem}
Describe the elements of $M _ { 2 } ( \mathbb { Z } )$ that have multiplicative inverses.
:::

::: {.solution}
Let $A = { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] }$ be an element of $M _ { 2 } ( \mathbb { Z } )$ . Then A has a multiplicative inverse if and only if it has non-zero determinant so $a d - b c \neq 0$ . Moreover, the inverse is only in $M _ { 2 } ( \mathbb { Z } )$ if $\frac { 1 } { \operatorname { d e t } ( A ) } \in \mathbb { Z }$ (in order to ensure that the matrix entries are all integers).
Thus the determinant of A must be $\pm 1$ . Thus the elements with multiplicative inverse are $\left\{ { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } \ | a d - b c = \pm 1 \right\}$
:::

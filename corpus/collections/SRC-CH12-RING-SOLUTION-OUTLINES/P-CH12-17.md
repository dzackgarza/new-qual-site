::: {.problem}
Show that a ring that is cyclic under addition is commutative.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's `provenance` is the textbook's Google Books record and no solutions sheet is retained, so the argument below is the card's own, structured from the outline already on the card.

::: pf

::: {.pf-step #generated}
Every element of $R$ is $na$ for some integer $n$.

::: pf-proof
This is the hypothesis that $a$ generates the additive group.

:::

:::

::: {.pf-step #product}
For all integers $n, m$ one has $(na)(ma) = (nm)a^{2}$.

::: pf-proof
Distributivity gives $a(ma) = ma^{2}$ for $m \ge 0$, by induction on $m$: the case $m=0$ is $a\cdot0 = 0 = 0\cdot a^{2}$, and $a\bigl((m+1)a\bigr) = a(ma+a) = a(ma) + a^{2} = ma^{2} + a^{2} = (m+1)a^{2}$. For $m<0$, $a(ma) = a\bigl(-((-m)a)\bigr) = -a\bigl((-m)a\bigr) = -\bigl((-m)a^{2}\bigr) = ma^{2}$. Applying the same induction in $n$ to $(na)(ma) = n\bigl(a(ma)\bigr)$ gives $(na)(ma) = n(ma^{2}) = (nm)a^{2}$.

:::

:::

::: {.pf-step #commute}
Any two elements of $R$ commute.

::: pf-proof
By step [](#generated){.pf-ref} two elements are $na$ and $ma$, and by step [](#product){.pf-ref} $(na)(ma) = (nm)a^{2} = (mn)a^{2} = (ma)(na)$, since the integers $nm$ and $mn$ are equal.

:::

:::

::: pf-step
$R$ is commutative.

::: pf-proof
A ring is commutative when any two of its elements commute, which is step [](#commute){.pf-ref}.

:::

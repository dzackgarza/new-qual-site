::: {.problem}
Show that $2 \ZZ \cup 3 \ZZ$ is not a subring of Z.
:::

::: {.solution}
The elements 2 and 3 are both in $2 \ZZ \cup 3 \ZZ$ but $2 + 3 = 5 \not \in 2 \ZZ \cup 3 \ZZ$, so the set is not closed under addition and is not a subring.
:::

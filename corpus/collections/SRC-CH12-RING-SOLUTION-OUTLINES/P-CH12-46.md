::: {.problem}
Show that $2 \mathbb { Z } \cup 3 \mathbb { Z }$ is not a subring of Z.
:::

::: {.solution}
The elements 2 and 3 are both in $2 \mathbb { Z } \cup 3 \mathbb { Z }$ but $2 + 3 = 5 \not \in 2 \mathbb { Z } \cup 3 \mathbb { Z }$, so the set is not closed under addition and is not a subring.
:::

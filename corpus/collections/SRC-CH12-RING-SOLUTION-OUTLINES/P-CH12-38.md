::: {.problem}
Is $\mathbb { Z } _ { 6 }$ a subring of $\mathbb { Z } _ { 1 2 } ?$
:::

::: {.solution}
No. The set $\{0,1,\ldots,5\} \subseteq \mathbb { Z } _ { 1 2 }$ is not closed under the operations of $\mathbb { Z } _ { 1 2 }$: for example $3 + 3 = 6$ in $\mathbb { Z } _ { 1 2 }$, whereas $3 + 3 = 0$ in $\mathbb { Z } _ { 6 }$.
:::

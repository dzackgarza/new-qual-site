::: {.problem}
For each of the following subsets of $\RR$, decide whether it is open, closed, or neither. If it is not open, exhibit a point of the set with no $\varepsilon$-neighborhood contained in the set. If it is not closed, exhibit a limit point not contained in the set.

(a) $\QQ$;

(b) $\NN$;

(c) $(0,\infty)$;

(d) $(0,1]$;

(e)
$$
\left\{1+\frac14+\cdots+\frac1{n^2}:n\in\NN\right\}.
$$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The set $\QQ$ is neither open nor closed.


::: pf-proof

It is not open because $0\in\QQ$ and every neighborhood of $0$ contains an
irrational number. It is not closed because $\sqrt2\notin\QQ$, while every
neighborhood of $\sqrt2$ contains a rational number, so $\sqrt2$ is a limit
point of $\QQ$.

:::

:::

::: {.pf-step #s1-2}

The set $\NN$ is closed but not open.


::: pf-proof

It is not open because $1\in\NN$ and every neighborhood of $1$ contains
nonintegers.

To prove closedness, let $x\notin\NN$. If $x<1$, choose
$\varepsilon>0$ with $x+\varepsilon<1$. If $x>1$, let
$m=\lfloor x\rfloor$; since $x$ is not an integer,
$$
m<x<m+1.
$$
Choose
$$
0<\varepsilon<\min\{x-m,m+1-x\}.
$$
Then $(x-\varepsilon,x+\varepsilon)$ contains no natural number. Thus
$\RR\setminus\NN$ is open, so $\NN$ is closed.

:::

:::

::: {.pf-step #s1-3}

The set $(0,\infty)$ is open but not closed.


::: pf-proof

If $x>0$, then
$$
\left(x-\frac x2,x+\frac x2\right)\subseteq(0,\infty),
$$
so the set is open. It is not closed because
$$
\frac1n\longrightarrow0,
$$
with every $1/n\in(0,\infty)$ but $0\notin(0,\infty)$.

:::

:::

::: {.pf-step #s1-4}

The set $(0,1]$ is neither open nor closed.


::: pf-proof

It is not open because $1$ belongs to the set but every neighborhood of $1$
contains points greater than $1$. It is not closed because
$$
\frac1n\longrightarrow0,
$$
with every $1/n\in(0,1]$ but $0\notin(0,1]$.

:::

:::

::: {.pf-step #s1-5}

For part (e), set
$$
s_n=\sum_{k=1}^{n}\frac1{k^2}
$$
and
$$
E=\{s_n:n\in\NN\}.
$$
Then $E$ is not open.


::: pf-proof

Fix $s_n\in E$ and let $\varepsilon>0$. Since
$$
s_{n+1}-s_n=\frac1{(n+1)^2}>0,
$$
choose
$$
0<\delta<
\min\left\{
\varepsilon,
\frac1{(n+1)^2}
\right\}.
$$
Then
$$
s_n<s_n+\delta<s_{n+1},
$$
so $s_n+\delta\notin E$, while
$$
|s_n+\delta-s_n|<\varepsilon.
$$
Thus no neighborhood of $s_n$ is contained in $E$.

:::

:::

::: {.pf-step #s1-6}

The set $E$ is not closed.


::: pf-proof

The $p$-series
$$
\sum_{k=1}^{\infty}\frac1{k^2}
$$
converges; let its sum be $S$. Then
$$
s_n\longrightarrow S.
$$
Every omitted tail is positive, so
$$
s_n<S
$$
for every finite $n$. Hence $S\notin E$, while $S$ is a limit point of $E$.
Therefore $E$ is not closed.

:::

:::

::: {.pf-step #s1-7}

Therefore the set in part (e) is neither open nor closed.


::: pf-proof

Steps [](#s1-5){.pf-ref} and [](#s1-6){.pf-ref} prove both failures.

:::

::: {.problem}
Decide whether each statement is true or false. Give a counterexample for every false statement and a proof for every true statement.

(a) For every $E\subseteq\mathbb R$, the complement $(\overline E)^c$ is open.

(b) If a set has an isolated point, then it cannot be open.

(c) If $E\subseteq\mathbb R$ is nonempty and bounded, then $\sup E$ is a limit point of $E$.

(d) Every nonempty compact subset of $\mathbb R$ has a largest element.

(e) An open subset of $\mathbb R$ containing every rational number must equal $\mathbb R$.

(f) An arbitrary intersection of compact subsets of $\mathbb R$ is compact.

(g) If
\[
F_1\supseteq F_2\supseteq F_3\supseteq\cdots
\]
is a nested sequence of nonempty closed sets, then
\[
\bigcap_{n=1}^\infty F_n\ne\varnothing.
\]

(h) Every finite set is compact.

(i) Every countable set is compact.
:::

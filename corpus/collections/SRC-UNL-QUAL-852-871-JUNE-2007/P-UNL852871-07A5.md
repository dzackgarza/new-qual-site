::: {.problem}
Consider finite directed graphs with no loops and no multiple directed edges, but allowing both $\overrightarrow{xy}$ and $\overrightarrow{yx}$.

A *monotone tournament* is an orientation of a complete graph for which some ordering of the vertices directs every edge from the smaller vertex to the larger. A *complete digraph* has both directed edges between every two distinct vertices.

Given $m\ge1$, prove that for all sufficiently large $N$, every digraph on $N$ vertices has an $m$-vertex subset inducing either an empty digraph, a complete digraph, or a monotone tournament.
:::

::: pf

::: pf-step

Fix an arbitrary linear ordering
$$
v_1<\cdots<v_N
$$
of the vertices. Each unordered pair $\{v_i,v_j\}$ with $i<j$ has exactly one of four types:
$$
\begin{array}{ll}
0:&\text{neither directed edge is present},\\
2:&\text{both directed edges are present},\\
+:&\overrightarrow{v_iv_j}\text{ is present and }\overrightarrow{v_jv_i}\text{ is absent},\\
-:&\overrightarrow{v_jv_i}\text{ is present and }\overrightarrow{v_iv_j}\text{ is absent}.
\end{array}
$$


::: pf-proof

Because loops and repeated directed edges are excluded but the two opposite directed edges are allowed simultaneously, these four cases are mutually exclusive and exhaustive for every unordered pair of distinct vertices.

:::

:::

::: pf-step

For every $m\ge1$, if $N$ is sufficiently large, there is an $m$-vertex set on which all unordered pairs have the same type from step <1>1.


::: pf-proof

Apply the finite Ramsey theorem for $4$ colors to the coloring of the $2$-element subsets of the vertex set defined in step <1>1. Thus for
$$
N\ge R_4(m),
$$
where $R_4(m)$ is the $4$-color Ramsey number for $m$-element homogeneous sets, there is an $m$-element subset whose pairs are monochromatic.

:::

:::

::: pf-step

Every monochromatic $m$-vertex set from step <1>2 induces either an empty digraph, a complete digraph, or a monotone tournament.


::: pf-proof

If the common type is $0$, no directed edge occurs between any two vertices, so the induced digraph is empty. If the common type is $2$, both directed edges occur between every pair, so the induced digraph is complete.

If the common type is $+$, then with the inherited order every pair $v_i<v_j$ has exactly the directed edge $\overrightarrow{v_iv_j}$, so the induced digraph is a monotone tournament. If the common type is $-$, reverse the inherited order; then again every edge points from the smaller vertex to the larger, so the induced digraph is a monotone tournament.

:::

:::

::: pf-step

Therefore, for every $m\ge1$, every digraph on sufficiently many vertices contains an $m$-vertex subset of one of the three required types.


::: pf-proof

Take $N\ge R_4(m)$. Step <1>2 gives a monochromatic $m$-vertex subset, and step <1>3 identifies its induced digraph as empty, complete, or a monotone tournament.

:::

:::

::: pf-qed

Step <1>4 is the required Ramsey conclusion.

:::

:::

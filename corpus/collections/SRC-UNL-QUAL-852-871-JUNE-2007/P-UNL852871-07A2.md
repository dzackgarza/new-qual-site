::: {.problem}
Prove that a tree having $2k$ endvertices contains $k$ edge-disjoint paths that pair all of its endvertices.

Deduce that if $x$ is a vertex of a graph $G$ with degree $2k$ and $x$ is not a cutvertex of $G$, then $x$ lies on $k$ edge-disjoint cycles.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Let $T$ be a rooted tree. In every rooted subtree, all of its leaves can be paired by edge-disjoint leaf-to-leaf paths except possibly one leaf, and if one leaf remains then its path to the root of that subtree is edge-disjoint from all the paired paths.


::: pf-proof

Proceed upward from the leaves. A leaf contributes one unpaired leaf-path consisting initially of no edges. At an internal vertex $v$, each child subtree contributes either no unpaired leaf or one unpaired leaf together with its path to that child. Extend each contributed path across the corresponding child edge to $v$. Pair these extended paths arbitrarily in twos, joining each pair through $v$; if their number is odd, leave one extended path unpaired and pass it toward the parent of $v$.

Every child edge is used in at most one extended path, and paths produced in distinct child subtrees are edge-disjoint by induction. Hence all completed leaf-to-leaf paths are pairwise edge-disjoint, and any single path passed upward is edge-disjoint from them. This proves the assertion at each vertex, inductively from the leaves to the root.

:::

:::

::: {.pf-step #s1-2}

If a tree has $2k$ endvertices, then its endvertices can be paired by $k$ edge-disjoint paths.


::: pf-proof

If the tree consists of a single edge, the assertion is immediate. Otherwise choose a root of degree at least $2$, so the leaves of the rooted tree are exactly the endvertices of the original tree, and apply step [](#s1-1){.pf-ref} to the whole tree. Since the number of leaves is even, no unpaired leaf remains at the root. Thus all $2k$ leaves are partitioned into $k$ pairs, with one edge-disjoint path joining each pair.

:::

:::

::: {.pf-step #s1-3}

Let $x$ have degree $2k$ and suppose that $x$ is not a cutvertex. There is a tree $T'$ having exactly $2k$ leaves, one corresponding to each edge incident with $x$.


::: pf-proof

Work in the connected component of $G$ containing $x$. Since $x$ is not a cutvertex, deleting $x$ leaves the remaining vertices of this component connected. Let
$$
N(x)=\{v_1,\ldots,v_{2k}\}.
$$
Choose a tree $H\subseteq G-x$ that is minimal subject to containing all vertices of $N(x)$. Every leaf of $H$ lies in $N(x)$, since otherwise deleting that leaf and its incident edge would leave a smaller tree still containing all of $N(x)$.

For each $v_i$, adjoin a new vertex $u_i$ and the new pendant edge $u_iv_i$. Because every leaf of $H$ belongs to $N(x)$, adjoining these pendant edges makes each former leaf of $H$ non-leaf. Hence the resulting tree $T'$ has exactly the $2k$ vertices $u_1,\ldots,u_{2k}$ as its leaves.

:::

:::

::: {.pf-step #s1-4}

The vertex $x$ lies on $\boxed{k}$ pairwise edge-disjoint cycles in $G$.


::: pf-proof

Apply step [](#s1-2){.pf-ref} to the tree $T'$ from step [](#s1-3){.pf-ref}. This gives $k$ edge-disjoint paths pairing the leaves $u_1,\ldots,u_{2k}$. Remove the first and last pendant edge from each such path. The resulting paths lie in $H$ and pair the corresponding vertices $v_1,\ldots,v_{2k}$; they remain pairwise edge-disjoint.

For each paired pair $v_i,v_j$, join its path in $H$ to the two edges $xv_i$ and $xv_j$. This produces a cycle through $x$. Distinct cycles use disjoint paths in $H$ and distinct edges incident with $x$, because every $v_i$ is used in exactly one pair. Therefore the $k$ cycles are pairwise edge-disjoint.

:::

:::

::: pf-qed

Step [](#s1-2){.pf-ref} proves the tree assertion, and step [](#s1-4){.pf-ref} proves the graph-theoretic deduction.

:::

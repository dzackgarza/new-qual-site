::: {.problem}
Let $R$ denote a commutative ring and $I$ an ideal, $I \neq R$.
We say that $R$ has nilpotents if there exists $r \in R$, $r \neq 0$, with $r^n = 0$.

(a) Give an example where $R/I$ has nilpotents but $R$ doesn't.

(b) Give an example where $R$ has nilpotents but $R/I$ doesn't.
:::

::: {.solution}
**Part (a).**

::: pf

::: {.pf-step #z-no-nilpotents}
Take $R = \ZZ$ and $I = 4\ZZ$.

::: pf-proof
$\ZZ$ is a domain, so it has no nonzero nilpotents.
:::

:::

::: {.pf-step #z4-has-nilpotent}
$R/I = \ZZ/4\ZZ$ has a nilpotent.

::: pf-proof
the class $\overline{2}$ satisfies $\overline{2} \neq 0$ but $\overline{2}^2 = \overline{4} = \overline{0}$.
:::

:::

::: {.pf-step #quotient-has-nilpotents-base-does-not}
Hence $R/I$ has nilpotents while $R$ does not.

::: pf-proof
step [](#z-no-nilpotents){.pf-ref} and step [](#z4-has-nilpotent){.pf-ref}.
:::

:::

:::

**Part (b).**

::: pf

::: {.pf-step #r-has-nilpotent-b}
Take $R = \ZZ/4\ZZ$ and $I = 2\ZZ/4\ZZ$.

::: pf-proof
$R$ has the nilpotent $\overline{2}$.
:::

:::

::: pf-step
$R/I \cong \ZZ/2\ZZ$.

::: pf-proof
the quotient of $\ZZ/4\ZZ$ by the ideal generated by $\overline{2}$ is $\ZZ/2\ZZ$.
:::

:::

::: {.pf-step #quotient-no-nilpotents-b}
$\ZZ/2\ZZ$ has no nonzero nilpotents.

::: pf-proof
it is a field, hence a domain.
:::

:::

::: {.pf-step #base-has-nilpotents-quotient-does-not}
Hence $R$ has nilpotents while $R/I$ does not.

::: pf-proof
step [](#r-has-nilpotent-b){.pf-ref} and step [](#quotient-no-nilpotents-b){.pf-ref}.
:::

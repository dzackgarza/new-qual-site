::: {.problem}
Let $T$ be a linear transformation on $C_c(\RR)$ (continuous functions with compact support) that has the following two properties: $$\norm{Tf}_{L^\infty} \le \norm{f}_{L^\infty} \quad \text{and} \quad m\{x\in\RR: \abs{Tf(x)}>\lambda\} \le \frac{\norm{f}_{L^1}}{\lambda}$$ where $m$ denotes Lebesgue measure.
Prove that $$\int \abs{Tf(x)}^2\,dx \le C\int \abs{f(x)}^2\,dx$$ for all $f\in C_c(\RR)$ and some fixed number $C$.
:::

::: {.solution}
The argument follows the proof of the Marcinkiewicz interpolation theorem for the Hardy--Littlewood maximal function; since $T$ is defined only on $C_c(\RR)$, the truncations of $f$ are taken continuous.
We first prove the estimate for nonnegative real-valued $f$ and then pass to real-valued and complex-valued $f$.
We use the identity $$\int \abs{Tf}^2 = 2\int_0^\infty \lambda\cdot m\{x:\abs{Tf(x)}>\lambda\}\,d\lambda.$$ For each fixed $\lambda$, we have the decomposition $f=g+h$ where $h:=\min(f,\lambda/2)$ and $g:=f-h=0$ if $f<\lambda/2$ and $f-\lambda/2$ if $f>\lambda/2$.
Both $g$ and $h$ are continuous and non-negative with compact support.
Then we have $Tf=Tg+Th$, so $\abs{Tf}\le\abs{Tg}+\abs{Th}$, which implies that $$\{x:\abs{Tf(x)}>\lambda\} \subseteq \{x:\abs{Tg(x)}>\lambda/2\}\cup\{x:\abs{Th(x)}>\lambda/2\}.$$ But we have $\norm{Th}_{L^\infty} \le \norm{h}_{L^\infty} \le \lambda/2$ by construction, so the second set has measure zero and, up to a null set, $$\{x:\abs{Tf(x)}>\lambda\} \subseteq \{x:\abs{Tg(x)}>\lambda/2\}.$$ Thus we have $$\int\abs{Tf}^2 \le 2\int_0^\infty \lambda\cdot m\{x:\abs{Tg(x)}>\lambda/2\}\,d\lambda$$ $$\lesssim \int_0^\infty \lambda\frac{2\norm{g}_{L^1}}{\lambda}\,d\lambda \quad \text{by the weak-type hypothesis}$$ $$\lesssim \int_0^\infty \int_\RR \abs{g(x)}\,dx\,d\lambda = \int_0^\infty\int_{\{x:f(x)>\lambda/2\}} (f(x)-\lambda/2)\,dx\,d\lambda \le \int_0^\infty \int_{\{x:f(x)>\lambda/2\}} f(x)\,dx\,d\lambda$$ $$= \int_\RR \abs{f(x)} \int_0^{2\abs{f(x)}} d\lambda\,dx \quad \text{by Tonelli}$$ $$\lesssim \int_\RR \abs{f(x)}^2\,dx.$$ This establishes the result for positive real-valued $f$.
For general real-valued $f$, write $f=f_+-f_-$.
The functions $f_\pm$ are continuous, nonnegative, and compactly supported, and $\abs{a-b}^2\le2\abs{a}^2+2\abs{b}^2$ for complex numbers $a,b$, so $$\int \abs{Tf}^2 = \int \abs{Tf_+-Tf_-}^2 \le 2\int\abs{Tf_+}^2+2\int\abs{Tf_-}^2 \lesssim \norm{f_+}_{L^2}^2+\norm{f_-}_{L^2}^2 = \norm{f}_{L^2}^2,$$ where the last equality holds because $f_+(x)f_-(x)=0$ for all $x$.
This establishes the result for general real-valued $f$.
For complex-valued $f$, write $f=\text{Re}(f)+i\,\text{Im}(f)$; the functions $T\text{Re}(f)$ and $T\text{Im}(f)$ may be complex-valued, so again $$\int\abs{Tf}^2 = \int\abs{T\text{Re}(f)+iT\text{Im}(f)}^2 \le 2\int\abs{T\text{Re}(f)}^2+2\int\abs{T\text{Im}(f)}^2 \lesssim \int\abs{\text{Re}(f)}^2+\abs{\text{Im}(f)}^2 = \int\abs{f}^2.$$
$\square$
:::

::: {.problem}
Let $T$ be a linear transformation on $C_c(\mathbb{R})$ (continuous functions with compact support) that has the following two properties: $$||Tf||_{L^\infty} \le ||f||_{L^\infty} \quad \text{and} \quad m\{x\in\mathbb{R}: |Tf(x)|>\lambda\} \le \frac{||f||_{L^1}}{\lambda}$$ where $m$ denotes Lebesgue measure.
Prove that $$\int |Tf(x)|^2\,dx \le C\int |f(x)|^2\,dx$$ for all $f\in C_c(\mathbb{R})$ and some fixed number $C$.
:::

::: {.solution}
The argument follows the proof of the Marcinkiewicz interpolation theorem for the Hardy--Littlewood maximal function; since $T$ is defined only on $C_c(\mathbb R)$, the truncations of $f$ are taken continuous.
We first prove the estimate for nonnegative real-valued $f$ and then pass to real-valued and complex-valued $f$.
We use the identity $$\int |Tf|^2 = 2\int_0^\infty \lambda\cdot m\{x:|Tf(x)|>\lambda\}\,d\lambda.$$ For each fixed $\lambda$, we have the decomposition $f=g+h$ where $h:=\min(f,\lambda/2)$ and $g:=f-h=0$ if $f<\lambda/2$ and $f-\lambda/2$ if $f>\lambda/2$.
Both $g$ and $h$ are continuous and non-negative with compact support.
Then we have $Tf=Tg+Th$, so $|Tf|\le|Tg|+|Th|$, which implies that $$\{x:|Tf(x)|>\lambda\} \subseteq \{x:|Tg(x)|>\lambda/2\}\cup\{x:|Th(x)|>\lambda/2\}.$$ But we have $||Th||_{L^\infty} \le ||h||_{L^\infty} \le \lambda/2$ by construction, so the second set has measure zero and, up to a null set, $$\{x:|Tf(x)|>\lambda\} \subseteq \{x:|Tg(x)|>\lambda/2\}.$$ Thus we have $$\int|Tf|^2 \le 2\int_0^\infty \lambda\cdot m\{x:|Tg(x)|>\lambda/2\}\,d\lambda$$ $$\lesssim \int_0^\infty \lambda\frac{2||g||_{L^1}}{\lambda}\,d\lambda \quad \text{by the weak-type hypothesis}$$ $$\lesssim \int_0^\infty \int_\mathbb{R} |g(x)|\,dx\,d\lambda = \int_0^\infty\int_{\{x:f(x)>\lambda/2\}} (f(x)-\lambda/2)\,dx\,d\lambda \le \int_0^\infty \int_{\{x:f(x)>\lambda/2\}} f(x)\,dx\,d\lambda$$ $$= \int_\mathbb{R} |f(x)| \int_0^{2|f(x)|} d\lambda\,dx \quad \text{by Tonelli}$$ $$\lesssim \int_\mathbb{R} |f(x)|^2\,dx.$$ This establishes the result for positive real-valued $f$.
For general real-valued $f$, write $f=f_+-f_-$.
The functions $f_\pm$ are continuous, nonnegative, and compactly supported, and $|a-b|^2\le2|a|^2+2|b|^2$ for complex numbers $a,b$, so $$\int |Tf|^2 = \int |Tf_+-Tf_-|^2 \le 2\int|Tf_+|^2+2\int|Tf_-|^2 \lesssim ||f_+||_{L^2}^2+||f_-||_{L^2}^2 = ||f||_{L^2}^2,$$ where the last equality holds because $f_+(x)f_-(x)=0$ for all $x$.
This establishes the result for general real-valued $f$.
For complex-valued $f$, write $f=\text{Re}(f)+i\,\text{Im}(f)$; the functions $T\text{Re}(f)$ and $T\text{Im}(f)$ may be complex-valued, so again $$\int|Tf|^2 = \int|T\text{Re}(f)+iT\text{Im}(f)|^2 \le 2\int|T\text{Re}(f)|^2+2\int|T\text{Im}(f)|^2 \lesssim \int|\text{Re}(f)|^2+|\text{Im}(f)|^2 = \int|f|^2.$$
$\square$
:::

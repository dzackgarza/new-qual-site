::: {.problem}
Prove the following form of Jensen's inequality: If $f:[0,1]\to\mathbb{R}$ is continuous then $$\int_0^1 e^{f(x)}\,dx\ge\exp\left(\int_0^1 f(x)\,dx\right).$$ Moreover, if equality occurs then $f$ is a constant function.
:::

::: {.solution}
**Part 1: The Inequality.**

::: pf

::: pf-step
Let $\mu = \int_0^1 f(x)\,dx \in \mathbb{R}$.

::: pf-proof
$f$ is continuous on the compact interval $[0,1]$, hence integrable.
:::

:::

::: pf-step
The exponential function $\phi(t) = e^t$ is strictly convex on $\mathbb{R}$.

::: pf-proof
$\phi''(t) = e^t > 0$ for all $t \in \mathbb{R}$.
:::

:::

::: {.pf-step #s3}
For every $t \in \mathbb{R}$, $e^t \ge e^\mu + e^\mu(t - \mu)$, with equality if and only if $t = \mu$.

::: pf-proof
the tangent line to the strictly convex graph $y = e^t$ at $t = \mu$ is $y = e^\mu + e^\mu(t - \mu)$; by strict convexity, the graph lies strictly above its tangent line except at the point of tangency.
:::

:::

::: {.pf-step #s4}
Setting $t = f(x)$ gives $e^{f(x)} \ge e^\mu + e^\mu(f(x) - \mu)$ for all $x \in [0,1]$.

::: pf-proof
Step [](#s3){.pf-ref} evaluated at $t = f(x)$.
:::

:::

::: {.pf-step #s5}
Integrating over $[0,1]$ yields $\int_0^1 e^{f(x)}\,dx \ge \exp\left(\int_0^1 f(x)\,dx\right)$.

::: pf-proof

::: {.pf-step #s5-1}
Integrating both sides of step [](#s4){.pf-ref}:
\[
\int_0^1 e^{f(x)}\,dx \ge \int_0^1 \bigl(e^\mu + e^\mu(f(x) - \mu)\bigr)\,dx.
\]

::: pf-proof
monotonicity of the Riemann / Lebesgue integral.
:::

:::

::: {.pf-step #s5-2}
Compute the right-hand integral:
\[
\int_0^1 \bigl(e^\mu + e^\mu(f(x) - \mu)\bigr)\,dx = e^\mu \int_0^1 1\,dx + e^\mu \left(\int_0^1 f(x)\,dx - \mu\right) = e^\mu + e^\mu(\mu - \mu) = e^\mu.
\]

::: pf-proof
linearity of the integral and the definition $\mu = \int_0^1 f(x)\,dx$.
:::

:::

::: pf-step
Since $e^\mu = \exp\left(\int_0^1 f(x)\,dx\right)$, the inequality holds.

::: pf-proof
Step [](#s5-1){.pf-ref} and step [](#s5-2){.pf-ref}.
:::

:::

:::

:::

:::

**Part 2: The Equality Case.**

::: pf

::: {.pf-step #s6}
If $\int_0^1 e^{f(x)}\,dx = \exp\left(\int_0^1 f(x)\,dx\right)$, then $f$ is a constant function.

::: pf-proof

::: pf-step
Consider the difference function $g(x) = e^{f(x)} - \bigl(e^\mu + e^\mu(f(x) - \mu)\bigr)$ on $[0,1]$.

::: pf-proof
definition.
:::

:::

::: {.pf-step #s6-2}
$g(x)$ is continuous on $[0,1]$ and $g(x) \ge 0$ for all $x \in [0,1]$.

::: pf-proof
$f$ is continuous, $\exp$ and linear maps are continuous, and step [](#s4){.pf-ref} gives nonnegativity.
:::

:::

::: {.pf-step #s6-3}
$\int_0^1 g(x)\,dx = \int_0^1 e^{f(x)}\,dx - e^\mu = 0$.

::: pf-proof
The hypothesis of equality and step [](#s5-2){.pf-ref} of Part 1.
:::

:::

::: {.pf-step #s6-4}
$g(x) = 0$ for all $x \in [0,1]$.

::: pf-proof
By step [](#s6-2){.pf-ref} and step [](#s6-3){.pf-ref}, $g$ is continuous, nonnegative, and has zero integral. If $g(x_0) > 0$, by continuity $g(x) > g(x_0)/2$ on an interval $(\alpha,\beta) \subseteq [0,1]$, forcing $\int_0^1 g > 0$.
:::

:::

::: {.pf-step #s6-5}
By step [](#s3){.pf-ref}, $g(x) = 0$ implies $f(x) = \mu$.

::: pf-proof
the only solution to $e^t = e^\mu + e^\mu(t - \mu)$ is $t = \mu$.
:::

:::

::: pf-step
Thus $f(x) = \mu = \int_0^1 f(t)\,dt$ for all $x \in [0,1]$, so $f$ is constant.

::: pf-proof
Step [](#s6-4){.pf-ref} and step [](#s6-5){.pf-ref}.
:::

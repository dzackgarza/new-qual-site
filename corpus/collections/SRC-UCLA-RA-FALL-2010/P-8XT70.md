::: {.problem}
Let $\Omega\subset\mathbb{C}$ be a non-empty open connected set.
If $f:\Omega\to\mathbb{C}$ is harmonic and $f^2$ is also harmonic, show that either $f$ or $\overline{f}$ is holomorphic on $\Omega$.
:::

::: {.solution}
Write the Wirtinger operators as
\[
\partial_z=\frac12(\partial_x-i\partial_y),
\qquad
\partial_{\overline z}=\frac12(\partial_x+i\partial_y).
\]
Since $f$ is harmonic, it is smooth and
\[
\partial_z\partial_{\overline z}f
=\frac14\Delta f
=0.
\]

<1>1. The harmonicity of $f^2$ implies
\[
(\partial_z f)(\partial_{\overline z}f)=0
\qquad\text{on }\Omega.
\]
::: {.proof}
Using the product rule and the preceding identity,
\[
\begin{aligned}
0
&=\frac14\Delta(f^2)\\
&=\partial_z\partial_{\overline z}(f^2)\\
&=\partial_z\bigl(2f\,\partial_{\overline z}f\bigr)\\
&=2(\partial_z f)(\partial_{\overline z}f)
  +2f\,\partial_z\partial_{\overline z}f\\
&=2(\partial_z f)(\partial_{\overline z}f).
\end{aligned}
\]
Dividing by $2$ gives the claim.
:::

<1>2. The function $\partial_z f$ is holomorphic on $\Omega$, and
$\overline{\partial_{\overline z}f}$ is holomorphic on $\Omega$.
::: {.proof}
Because $f$ is harmonic,
\[
\partial_{\overline z}(\partial_z f)
=\partial_z\partial_{\overline z}f
=0,
\]
so $\partial_z f$ satisfies the Cauchy--Riemann equation and is holomorphic.
Also
\[
\partial_z(\partial_{\overline z}f)=0,
\]
so $\partial_{\overline z}f$ is antiholomorphic. Equivalently,
$\overline{\partial_{\overline z}f}$ is holomorphic.
:::

<1>3. Either $\partial_z f\equiv0$ on $\Omega$ or
$\partial_{\overline z}f\equiv0$ on $\Omega$.
::: {.proof}
If $\partial_z f\equiv0$, the first alternative holds.
Otherwise choose $z_0\in\Omega$ with
\[
\partial_z f(z_0)\ne0.
\]
By continuity, there is a nonempty open neighborhood $U\subseteq\Omega$ of $z_0$ on which
$\partial_z f$ is nowhere zero. By <1>1,
\[
\partial_{\overline z}f=0
\qquad\text{on }U.
\]
By <1>2, the holomorphic function
$\overline{\partial_{\overline z}f}$ therefore vanishes on the nonempty open set $U$.
Since $\Omega$ is connected, the identity theorem gives
\[
\overline{\partial_{\overline z}f}\equiv0
\qquad\text{on }\Omega,
\]
hence $\partial_{\overline z}f\equiv0$ on $\Omega$.
:::

<1>4. Either $f$ or $\overline f$ is holomorphic on $\Omega$.
::: {.proof}
If $\partial_{\overline z}f\equiv0$, then $f$ is holomorphic.
If instead $\partial_z f\equiv0$, then
\[
\partial_{\overline z}(\overline f)
=\overline{\partial_z f}
=0,
\]
so $\overline f$ is holomorphic.
These are exactly the two alternatives required.
:::

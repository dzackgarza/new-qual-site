::: {.problem}
Assume $A$ is a commutative ring with unity, and let $f_1, \ldots, f_n \in A$ generate the unit ideal $(1)$.
Assume that the rings of fractions $A_{f_1}, \ldots, A_{f_n}$ are Noetherian.
Prove that $A$ is Noetherian.
:::


::: {.solution}
Let $I\subseteq A$ be an arbitrary ideal.
We prove that $I$ is finitely generated.

<1>1. For each $i$, the localized ideal $I_{f_i}\subseteq A_{f_i}$ is finitely generated.
Choose finitely many elements
\[
a_{i1},\ldots,a_{ir_i}\in I
\]
whose images generate $I_{f_i}$.
::: {.proof}
Since $A_{f_i}$ is Noetherian, its ideal $I_{f_i}$ is finitely generated.
Every element of $I_{f_i}$ is represented by a fraction $a/f_i^N$ with $a\in I$.
Multiplying a chosen finite set of fractional generators by powers of the unit $f_i$ in $A_{f_i}$ replaces them by the images of finitely many numerators $a_{ij}\in I$ without changing the generated localized ideal.
:::

<1>2. Let $J\subseteq I$ be the ideal generated by all the finitely many $a_{ij}$.
Then
\[
J_{f_i}=I_{f_i}\qquad\text{for every }i.
\]
::: {.proof}
By construction the chosen $a_{ij}$ for the fixed index $i$ already generate $I_{f_i}$ after localization, while all generators of $J$ lie in $I$.
Thus
\[
I_{f_i}\subseteq J_{f_i}\subseteq I_{f_i}.
\]
:::

<1>3. The quotient module $M:=I/J$ has
\[
M_{f_i}=0\qquad\text{for every }i.
\]
::: {.proof}
Localization is exact, so
\[
M_{f_i}\cong I_{f_i}/J_{f_i}=0
\]
by <1>2.
:::

<1>4. If an $A$-module $M$ satisfies $M_{f_i}=0$ for every $i$ and $(f_1,\ldots,f_n)=A$, then $M=0$.
::: {.proof}
Fix $x\in M$.
Since $x/1=0$ in $M_{f_i}$, for every $i$ there is an integer $N_i\ge0$ such that
\[
f_i^{N_i}x=0.
\]
Let
\[
\mathfrak a=(f_1^{N_1},\ldots,f_n^{N_n}).
\]
Its radical contains every $f_i$, hence contains the ideal $(f_1,\ldots,f_n)=A$.
Therefore
\[
\sqrt{\mathfrak a}=A,
\]
which forces $\mathfrak a=A$.
Thus there exist $c_i\in A$ such that
\[
1=\sum_i c_i f_i^{N_i}.
\]
Multiplying by $x$ gives
\[
x=\sum_i c_i f_i^{N_i}x=0.
\]
Since $x$ was arbitrary, $M=0$.
:::

<1>5. Hence $I=J$, so $I$ is finitely generated.
Therefore $A$ is Noetherian.
::: {.proof}
Apply <1>4 to $M=I/J$ using <1>3. Then $I/J=0$, so $I=J$.
The ideal $J$ has finitely many generators by construction.
Since $I$ was arbitrary, every ideal of $A$ is finitely generated, which is equivalent to $A$ being Noetherian.
:::
:::

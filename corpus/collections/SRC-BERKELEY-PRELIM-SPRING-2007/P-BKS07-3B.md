::: {.problem}
Let $k$ and $l$ be positive integers.
Let
\[
\mathbb Q(x)\bigl(\sqrt[k]{1-x^l}\bigr)
\]
be any extension field of $\mathbb Q(x)$ generated by a $k$-th root of $1-x^l$.
Define
\[
\mathbb Q(x)\bigl(\sqrt[l]{1-x^k}\bigr)
\]
similarly.
Prove that these two fields are isomorphic.
:::

::: {.solution}
The polynomial $y ^ { k } + x ^ { l } - 1$ is irreducible, for any positive integers k, l. One way to prove this is to regard $y ^ { k } + x ^ { l } - 1$ as a polynomial in y over $\mathbb { Q } [ x ]$ and apply Eisenstein’s criterion, using the fact that $x - 1$ divides $x ^ { l } - 1$ but $( x - 1 ) ^ { 2 }$ does not.
It follows that the fields in question are the fraction fields of $\mathbb { Q } [ x , y ] / ( y ^ { k } + x ^ { l } - 1 )$ and $\mathbb { Q } [ x , y ] / ( y ^ { l } + x ^ { k } - 1 )$ , respectively, which are obviously isomorphic by the exchange of x and $y .$
:::

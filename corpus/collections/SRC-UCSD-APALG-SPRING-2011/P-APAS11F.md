::: {.problem}
Let $S_4$ denote the symmetric group on $4$ elements and $A_4$ denote the alternating group, i.e. $A_4=\{\sigma\in S_4:\operatorname{sign}(\sigma)=1\}$.

(a) Find the conjugacy classes of $A_4$.

(b) Let $D=\{\varepsilon,(1,2)(3,4),(1,3)(2,4),(1,4)(2,3)\}$.
Show that $D$ is a normal subgroup of $A_4$ and that $A_4/D$ is isomorphic to $\ZZ_3$.

(c) Give the character table for $\ZZ_3$.

(d) Find the lifting of the irreducible characters of $\ZZ_3$ to $A_4$.

(e) Use (d) to complete the character table of $A_4$.
:::

::: {.solution}

The argument is the card's own; no source text or solution set is retained for it.

Let $\omega=e^{2\pi i/3}$ and let $C_{1},C_{2},C_{3},C_{4}$ denote the classes displayed below.

::: pf

::: {.pf-step #classes}
The conjugacy classes of $A_{4}$ are $C_{1}=\{e\}$, $C_{2}=\{(12)(34),(13)(24),(14)(23)\}$, $C_{3}=\{(123),(142),(134),(243)\}$ and $C_{4}=C_{3}^{-1}$.

::: pf-proof
$A_{4}$ has $12$ elements: $1$ identity, $3$ double transpositions and $8$ three-cycles. The identity forms its own class and the double transpositions are all conjugate in $A_{4}$ (for instance $(12)(34)$ and $(13)(24)$ are conjugate by $(123)\in A_{4}$), giving $C_{2}$ of size $3$. For a three-cycle $g$ the class has size $\abs{A_{4}}/\abs{C_{A_{4}}(g)}$; the centralizer of $(123)$ in $A_{4}$ is $\langle(123)\rangle$, of order $3$, so the class has size $4$. There are $8$ three-cycles, so they form two classes of size $4$; a three-cycle and its inverse are not conjugate in $A_{4}$ (all elements conjugating $(123)$ to $(132)=(123)^{-1}$ in $S_{4}$ are odd), so $C_{3}$ and $C_{4}=C_{3}^{-1}$ are distinct and exhaust the three-cycles.
:::

:::

::: {.pf-step #subgroup}
$D=C_{1}\cup C_{2}$ is a subgroup of $A_{4}$ isomorphic to the Klein four group, and it is normal.

::: pf-proof
$D=\{e,(12)(34),(13)(24),(14)(23)\}$ is closed under multiplication: every nonidentity element is an involution and the product of two distinct ones is the third. So $D$ is a subgroup of order $4$, and every nonidentity element has order $2$, which makes it a Klein four group. It is a union of conjugacy classes of $A_{4}$, so it is normal: for $g\in A_{4}$ and $d\in D$, the element $gdg^{-1}$ lies in the class of $d$, which is contained in $D$.
:::

:::

::: {.pf-step #quotient}
$A_{4}/D\cong\ZZ_{3}$.

::: pf-proof
$\abs{A_{4}/D}=\abs{A_{4}}/\abs{D}=12/4=3$. A group of prime order is cyclic, generated by any nonidentity element, so $A_{4}/D\cong\ZZ_{3}$, generated by the coset of any three-cycle.
:::

:::

::: {.pf-step #z3table}
The character table of $\ZZ_{3}=\langle t\rangle$ is
$$
\begin{array}{c|ccc} &t^{0}&t&t^{2}\\ \hline \chi_{1}&1&1&1\\ \psi&1&\omega&\omega^{2}\\ \bar\psi&1&\omega^{2}&\omega \end{array}.
$$

::: pf-proof
$\ZZ_{3}$ is abelian, so every irreducible complex character is one-dimensional, and there are three of them, one for each cube root of unity $\zeta$: the character $t\mapsto\zeta$. With $\zeta=1,\omega,\omega^{2}$ this gives the displayed table.
:::

:::

::: {.pf-step #lifted}
Inflating along $q\colon A_{4}\to A_{4}/D\cong\ZZ_{3}$ gives three one-dimensional characters of $A_{4}$, with values $1$ on $C_{1}\cup C_{2}$ and $\omega$-powers on the three-cycles:
$$
\begin{array}{c|cccc} &C_{1}&C_{2}&C_{3}&C_{4}\\ \hline \chi_{1}&1&1&1&1\\ \chi_{2}&1&1&\omega&\omega^{2}\\ \chi_{3}&1&1&\omega^{2}&\omega \end{array}.
$$

::: pf-proof
$D$ is the kernel of $q$, so an inflated character $\chi\circ q$ takes the value $\chi(1)=1$ on every element of $D=C_{1}\cup C_{2}$. Choosing the isomorphism $A_{4}/D\cong\ZZ_{3}$ that sends the coset of a three-cycle in $C_{3}$ to $t$ and the coset of its inverse in $C_{4}$ to $t^{2}=t^{-1}$, the three characters of step [](#z3table){.pf-ref} pull back to the displayed table. Inflated characters are irreducible because the characters of the quotient are, and inflation is injective on characters.
:::

:::

::: {.pf-step #degree}
$A_{4}$ has exactly four irreducible characters, and the fourth has degree $3$.

::: pf-proof
The number of irreducible characters equals the number of conjugacy classes, which is $4$ by step [](#classes){.pf-ref}. Three of them are the one-dimensional characters of step [](#lifted){.pf-ref}, so exactly one further irreducible $\chi_{4}$ remains. The sum of squares of the degrees is $\abs{A_{4}}=12$, so $12=1+1+1+\chi_{4}(1)^{2}$ and $\chi_{4}(1)=3$.
:::

:::

::: {.pf-step #permutation}
The permutation character $\pi$ of $A_{4}$ on $\{1,2,3,4\}$, with $\pi(g)=\#\operatorname{Fix}(g)$, satisfies $\pi=1+\chi_{4}$, and $\chi_{4}$ is irreducible of degree $3$.

::: pf-proof
$\pi(g)$ counts the fixed points, so $\pi(1)=4$, $\pi(g)=0$ for a double transposition and $\pi(g)=1$ for a three-cycle; thus $\pi=1+\rho$ where $\rho(g)=\pi(g)-1$ takes values $3,-1,0,0$. The action is transitive, so $\langle\pi,\chi_{1}\rangle=1$, and it is $2$-transitive on $4$ points, so the number of orbits on ordered pairs is $2$ and $\langle\pi,\pi\rangle=2$. Hence
$$
\langle\rho,\rho\rangle=\langle\pi,\pi\rangle-2\langle\pi,\chi_{1}\rangle+1=2-2+1=1,
$$
so $\rho$ is irreducible, of degree $\rho(1)=3$. It is not one of the three linear characters, which take the value $1$ on $C_{2}$ while $\rho$ takes $-1$ there; so $\rho=\chi_{4}$.
:::

:::

::: {.pf-step #table}
The character table of $A_{4}$ is
$$
\begin{array}{c|cccc} &C_{1}&C_{2}&C_{3}&C_{4}\\ \hline \chi_{1}&1&1&1&1\\ \chi_{2}&1&1&\omega&\omega^{2}\\ \chi_{3}&1&1&\omega^{2}&\omega\\ \chi_{4}&3&-1&0&0 \end{array}.
$$

::: pf-proof
The first three rows are step [](#lifted){.pf-ref}; the fourth is step [](#permutation){.pf-ref}, with values $\chi_{4}(C_{1})=3$, $\chi_{4}(C_{2})=-1$, $\chi_{4}(C_{3})=\chi_{4}(C_{4})=0$. Column orthogonality checks it: in each column the sum of $\abs{\chi_{i}(g)}^{2}$ over $i$ equals $\abs{C_{A_{4}}(g)}$, namely $12,4,3,3$ for $C_{1},C_{2},C_{3},C_{4}$, which matches $1+1+1+9=12$, $1+1+1+1=4$ and $1+\omega\bar\omega+\bar\omega\omega+0=3$.
:::

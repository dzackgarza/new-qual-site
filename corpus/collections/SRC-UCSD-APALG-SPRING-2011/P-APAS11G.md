::: {.problem}
(a) Two ideals $I$ and $J$ in $\CC[x_1,\ldots,x_n]$ are co-maximal if and only if $I+J=\CC[x_1,\ldots,x_n]$.

(i) Prove that $I$ and $J$ are co-maximal if and only if $V(I)\cap V(J)=\emptyset$.

(ii) Show that if $I$ and $J$ are comaximal, then $IJ=I\cap J$.

(b) Suppose that $I$ and $J$ are ideals in $k[x_1,\ldots,x_n]$ where $k$ is field.
Show that if $I\subseteq\sqrt{J}$, then there is an $m\ge 1$ such that $I^m\subseteq J$.
(Hint: Use the Hilbert Basis Theorem.)
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.

Write $R=k[x_1,\dots,x_n]$, and $V(\mathfrak a)=\{p\in\AA^n:f(p)=0\ \text{for all}\ f\in\mathfrak a\}$ for an ideal $\mathfrak a\subseteq R$. Recall that $I$ and $J$ are comaximal when $I+J=R$.

::: pf

::: {.pf-step #intersection}
$V(I)\cap V(J)=V(I+J)$.

::: pf-proof
A point $p$ lies in $V(I)\cap V(J)$ exactly when every $f\in I$ and every $g\in J$ vanish at $p$; since $I+J$ consists of the sums $f+g$, and $f(p)+g(p)=0$ for all such $f,g$ precisely when both vanish at $p$, this is exactly the condition $p\in V(I+J)$.
:::

:::

::: {.pf-step #comaxempty}
If $I+J=R$ then $V(I)\cap V(J)=\varnothing$.

::: pf-proof
$1\in R=I+J$, so $1=f+g$ with $f\in I$, $g\in J$. A point $p\in V(I)\cap V(J)$ would give $1=f(p)+g(p)=0$, which is impossible; by step [](#intersection){.pf-ref} this says $V(I)\cap V(J)=\varnothing$.
:::

:::

::: {.pf-step #emptycomax}
If $V(I)\cap V(J)=\varnothing$ then $I+J=R$.

::: pf-proof
By step [](#intersection){.pf-ref}, $V(I+J)=\varnothing$. The Nullstellensatz applies because $k=\CC$ is algebraically closed: $\sqrt{I+J}=I\bigl(V(I+J)\bigr)=I(\varnothing)=R$, the ideal of every polynomial vanishing on the empty set being $R$ (vacuously). So $1\in\sqrt{I+J}$, i.e. $1^N\in I+J$ for some $N\ge1$, that is $1\in I+J$.
:::

:::

::: {.pf-step #partai}
$I$ and $J$ are comaximal if and only if $V(I)\cap V(J)=\varnothing$.

::: pf-proof
Steps [](#comaxempty){.pf-ref} and [](#emptycomax){.pf-ref} are the two implications, and comaximality is by definition $I+J=R$. This is (a)(i).
:::

:::

::: {.pf-step #ijin}
$IJ\subseteq I\cap J$ for any ideals $I,J$.

::: pf-proof
A general element of $IJ$ is a finite sum of products $fg$ with $f\in I$, $g\in J$; each such product lies in $I$ (as $I$ is an ideal and $f\in I$) and in $J$ (as $g\in J$), hence in $I\cap J$, and $I\cap J$ is closed under sums.
:::

:::

::: {.pf-step #ii}
If $I+J=R$ then $I\cap J=IJ$.

::: pf-proof
One inclusion is step [](#ijin){.pf-ref}. For the other, choose $a\in I$, $b\in J$ with $a+b=1$, and let $x\in I\cap J$. Then
$$
x=x\cdot1=x(a+b)=xa+xb,
$$
and $xa\in IJ$ because $x\in J$ and $a\in I$, while $xb\in IJ$ because $x\in I$ and $b\in J$. So $x\in IJ$. This is (a)(ii).
:::

:::

::: {.pf-step #noetherian}
$R=k[x_1,\dots,x_n]$ is Noetherian, so $I$ is generated by finitely many elements $f_1,\dots,f_r$.

::: pf-proof
Hilbert's basis theorem: a polynomial ring in finitely many variables over a field is Noetherian. In a Noetherian ring every ideal is finitely generated, and $I=(f_1,\dots,f_r)$ is what that means. (The case $I=0$ is $r=0$.)
:::

:::

::: {.pf-step #powers}
For $m\ge1$, $I^m$ is generated by the products $f_1^{a_1}\cdots f_r^{a_r}$ with $\sum_ia_i=m$.

::: pf-proof
$I^m$ is generated by all products of $m$ elements of $I$, and each element of $I$ is an $R$-linear combination of the $f_i$; expanding a product of $m$ such combinations expresses it as an $R$-linear combination of products of $m$ of the $f_i$, i.e. of the monomials $f_1^{a_1}\cdots f_r^{a_r}$ with $\sum_ia_i=m$.
:::

:::

::: {.pf-step #pigeonhole}
If $f_i^{n_i}\in J$ for each $i$ and $m=1+\sum_i(n_i-1)$, then every monomial $f_1^{a_1}\cdots f_r^{a_r}$ with $\sum_ia_i=m$ lies in $J$.

::: pf-proof
If $a_i\le n_i-1$ for every $i$ then $\sum_ia_i\le\sum_i(n_i-1)=m-1<m$, a contradiction; so some $a_i\ge n_i$. For that $i$, $f_1^{a_1}\cdots f_r^{a_r}=f_i^{n_i}\cdot f_i^{a_i-n_i}\prod_{j\ne i}f_j^{a_j}$ with $a_i-n_i\ge0$, a multiple of $f_i^{n_i}\in J$, hence an element of $J$.
:::

:::

::: {.pf-step #partb}
If $I\subseteq\sqrt J$ then $I^m\subseteq J$ for some $m\ge1$.

::: pf-proof
Let $I=(f_1,\dots,f_r)$ by step [](#noetherian){.pf-ref}. Each $f_i\in I\subseteq\sqrt J$, so there is $n_i\ge1$ with $f_i^{n_i}\in J$; put $m=1+\sum_i(n_i-1)$, which is at least $1$. By steps [](#powers){.pf-ref} and [](#pigeonhole){.pf-ref}, every generator of $I^m$ lies in $J$, hence $I^m\subseteq J$. Only the Hilbert basis theorem was used for the finiteness, and $k$ need not be algebraically closed; part (a) is where $\CC$ enters, through the Nullstellensatz.
:::

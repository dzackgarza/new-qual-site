::: {.problem}
(a) Two ideals $I$ and $J$ in $\mathbb{C}[x_1,\ldots,x_n]$ are co-maximal if and only if $I+J=\mathbb{C}[x_1,\ldots,x_n]$.

(i) Prove that $I$ and $J$ are co-maximal if and only if $V(I)\cap V(J)=\emptyset$.

(ii) Show that if $I$ and $J$ are comaximal, then $IJ=I\cap J$.

(b) Suppose that $I$ and $J$ are ideals in $k[x_1,\ldots,x_n]$ where $k$ is field.
Show that if $I\subseteq\sqrt{J}$, then there is an $m\ge 1$ such that $I^m\subseteq J$.
(Hint: Use the Hilbert Basis Theorem.)
:::

::: {.solution}
For (a)(i), note first that
\[
V(I)\cap V(J)=V(I+J).
\]
If $I+J=\mathbb C[x_1,\ldots,x_n]$, then $1\in I+J$, so clearly $V(I+J)=\varnothing$.

Conversely, suppose $V(I)\cap V(J)=\varnothing$. Then $V(I+J)=\varnothing$. By Hilbert's Nullstellensatz,
\[
\sqrt{I+J}=I(V(I+J))=I(\varnothing)=\mathbb C[x_1,\ldots,x_n].
\]
Thus $1\in\sqrt{I+J}$, so $1^N=1\in I+J$ for some $N$, and therefore $I+J$ is the whole ring. Hence $I$ and $J$ are comaximal.

For (a)(ii), the inclusion $IJ\subseteq I\cap J$ always holds. Conversely, if $I+J=R$, choose $a\in I$ and $b\in J$ with $a+b=1$. For $x\in I\cap J$,
\[
x=x(a+b)=xa+xb.
\]
Since $x\in J$ and $a\in I$, we have $xa\in IJ$; since $x\in I$ and $b\in J$, we have $xb\in IJ$. Thus $x\in IJ$, proving
\[
I\cap J=IJ.
\]

For (b), Hilbert's basis theorem implies that $k[x_1,\ldots,x_n]$ is Noetherian, so write
\[
I=(f_1,\ldots,f_r).
\]
Since each $f_i\in\sqrt J$, choose $n_i\ge1$ with
\[
f_i^{n_i}\in J.
\]
Set
\[
m=1+\sum_{i=1}^r(n_i-1).
\]
Every monomial of total degree $m$ in the generators $f_1,\ldots,f_r$ has the form
\[
f_1^{a_1}\cdots f_r^{a_r},\qquad \sum_i a_i=m.
\]
If every $a_i\le n_i-1$, then
\[
\sum_i a_i\le\sum_i(n_i-1)=m-1,
\]
a contradiction. Hence some $a_i\ge n_i$, and then that monomial lies in $J$ because it is divisible by $f_i^{n_i}\in J$.

Since $I^m$ is generated by these degree-$m$ monomials, every generator of $I^m$ belongs to $J$. Therefore
\[
I^m\subseteq J.
\]
:::

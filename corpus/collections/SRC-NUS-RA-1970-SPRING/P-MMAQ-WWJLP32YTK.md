::: {.problem}
Prove or disprove each of the following statements.

(a) If $f : [0, 1] \to \RR$ is a measurable function, then given any $\varepsilon > 0$, there exists a compact set $K \subset [0, 1]$ such that $f$ is continuous on $K$ relative to $K$.

(b) If f is Borel measurable on $\RR \times \RR$, then for any $x \in \RR$, the function $g(y) = f(x, y)$ is also Borel measurable on $\RR$.

(c) If $E \subset \RR$, then $E$ is measurable if and only if given any $\varepsilon > 0$, there exist a closed set $F$ and an open set $G$ such that $F \subset E \subset G$ and the measure of $G-F$ is less than $\varepsilon$.
:::

::: {.solution}

::: pf

::: pf-step
(a) is true.

::: pf-proof

::: {.pf-step #lusin-theorem-application}
For every $\varepsilon > 0$ there is a compact $K \subseteq [0,1]$ with $m([0,1] \setminus K) < \varepsilon$ and $f\restrict_K$ continuous relative to $K$.

::: pf-proof
This is Lusin's theorem for the real-valued measurable function $f$ on the set $[0,1]$ of finite measure.
:::

:::

::: pf-qed
Step [](#lusin-theorem-application){.pf-ref} is precisely the assertion of (a).
:::

:::

:::

::: pf-step
(b) is true.

::: pf-proof

::: {.pf-step #sections-of-borel-are-borel}
For every Borel set $B \subseteq \RR^2$ and every fixed $x$, the section $B_x := \theset{y : (x, y) \in B}$ is Borel in $\RR$.

::: pf-proof
Let $\mathcal{F}$ be the family of sets $B \subseteq \RR^2$ whose sections $B_x$ are Borel for every $x$.
$\mathcal{F}$ is a $\sigma$-algebra: sections of unions, intersections, and complements are the corresponding unions, intersections, and complements of sections.
Every open rectangle $U \times V$ lies in $\mathcal{F}$ (its section is $V$ or $\emptyset$). Hence $\mathcal{F}$ contains the $\sigma$-algebra generated by open rectangles, which is the Borel $\sigma$-algebra of $\RR^2$.
:::

:::

::: {.pf-step #ginv-U-is-section}
$g^{-1}(U) = \left(f^{-1}(U)\right)_x$ for every open $U \subseteq \RR$; since $f$ is Borel measurable, $f^{-1}(U)$ is Borel, so $g^{-1}(U)$ is Borel by step [](#sections-of-borel-are-borel){.pf-ref}.

::: pf-proof
$y \in g^{-1}(U) \iff f(x, y) \in U \iff (x, y) \in f^{-1}(U)$.
:::

:::

::: pf-qed
By step [](#ginv-U-is-section){.pf-ref} the preimage of every open set is Borel, so $g$ is Borel measurable.
:::

:::

::: pf-step
(c) is true.

::: pf-proof

::: {.pf-step #forward-direction}
($\Rightarrow$) If $E$ is measurable, then for every $\varepsilon > 0$ there exist closed $F$ and open $G$ with $F \subseteq E \subseteq G$ and $m(G \setminus F) < \varepsilon$.

::: pf-proof
Write $E = \bigcup_{n \in \ZZ} E_n$ with $E_n \coloneqq E \cap [n, n+1]$; each $E_n$ is a measurable subset of a bounded interval and so has finite measure. Regularity applies on each piece: choose open $G_n \supseteq E_n$ with $m(G_n \setminus E_n) < \varepsilon/2^{\abs{n}+3}$, and compact $F_n \subseteq E_n$ with $m(E_n \setminus F_n) < \varepsilon/2^{\abs{n}+3}$.
Put $G \coloneqq \bigcup_n G_n$ and $F \coloneqq \bigcup_n F_n$. Then $G$ is open and contains $E$, and $F \subseteq E$. $F$ is closed: a point $x \notin F$ lies in some $[m, m+1]$, at a positive distance from each of the finitely many compact $F_n$ meeting $[m-1, m+2]$, so a neighbourhood of $x$ misses $F$.
Finally $G \setminus F \subseteq \bigcup_n (G_n \setminus F_n)$, so
$$m(G \setminus F) \leq \sum_n m(G_n \setminus F_n) \leq \sum_n \big( m(G_n \setminus E_n) + m(E_n \setminus F_n) \big) \leq \sum_{n \in \ZZ} \frac{\varepsilon}{2^{\abs n + 2}} = \frac{3\varepsilon}{4} < \varepsilon,$$
using $\sum_{n \in \ZZ} 2^{-\abs n} = 3$.
:::

:::

::: {.pf-step #backward-direction}
($\Leftarrow$) If for every $\varepsilon > 0$ such $F, G$ exist, then $E$ is measurable.

::: pf-proof
For each $n \geq 1$ choose closed $F_n$ and open $G_n$ with $F_n \subseteq E \subseteq G_n$ and $m(G_n \setminus F_n) < 1/n$, and put $F = \bigcup_n F_n$, a measurable subset of $E$.
For every $n$, $E \setminus F \subseteq G_n \setminus F_n$, so $m^*(E \setminus F) < 1/n$. Hence $m^*(E \setminus F) = 0$; null sets are measurable, so $E = F \cup (E \setminus F)$ is measurable.
:::

:::

::: pf-qed
Steps [](#forward-direction){.pf-ref} and [](#backward-direction){.pf-ref} give both implications.
:::

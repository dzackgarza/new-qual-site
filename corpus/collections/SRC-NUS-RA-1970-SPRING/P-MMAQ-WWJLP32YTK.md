::: {.problem}
Prove or disprove each of the following statements.

(a) If $f : [0, 1] \to \mathbb{R}$ is a measurable function, then given any $\varepsilon > 0$, there exists a compact set $K \subset [0, 1]$ such that $f$ is continuous on $K$ relative to $K$.

(b) If f is Borel measurable on $\mathbb{R} \times \mathbb{R}$, then for any $x \in \mathbb{R}$, the function $g(y) = f(x, y)$ is also Borel measurable on $\mathbb{R}$.

(c) If $E \subset \mathbb{R}$, then $E$ is measurable if and only if given any $\varepsilon > 0$, there exist a closed set $F$ and an open set $G$ such that $F \subset E \subset G$ and the measure of $G-F$ is less than $\varepsilon$.
:::

::: {.solution}

::: pf

::: pf-step
(a) is true.

::: pf-proof

::: {.pf-step #lusin-theorem-application}
For every $\varepsilon > 0$ there is a compact $K \subseteq [0,1]$ with $m([0,1] \setminus K) < \varepsilon$ and $f|_K$ continuous relative to $K$.

::: pf-proof
This is Lusin's theorem for the real-valued measurable function $f$ on the set $[0,1]$ of finite measure.
:::

:::

::: pf-qed
Step [](#lusin-theorem-application){.pf-ref} is precisely the assertion of (a).
:::

:::

:::

::: pf-step
(b) is true.

::: pf-proof

::: {.pf-step #sections-of-borel-are-borel}
For every Borel set $B \subseteq \mathbb{R}^2$ and every fixed $x$, the section $B_x := \theset{y : (x, y) \in B}$ is Borel in $\mathbb{R}$.

::: pf-proof
Let $\mathcal{F}$ be the family of sets $B \subseteq \mathbb{R}^2$ whose sections $B_x$ are Borel for every $x$.
$\mathcal{F}$ is a $\sigma$-algebra: sections of unions, intersections, and complements are the corresponding unions, intersections, and complements of sections.
Every open rectangle $U \times V$ lies in $\mathcal{F}$ (its section is $V$ or $\emptyset$). Hence $\mathcal{F}$ contains the $\sigma$-algebra generated by open rectangles, which is the Borel $\sigma$-algebra of $\mathbb{R}^2$.
:::

:::

::: {.pf-step #ginv-U-is-section}
$g^{-1}(U) = \left(f^{-1}(U)\right)_x$ for every open $U \subseteq \mathbb{R}$; since $f$ is Borel measurable, $f^{-1}(U)$ is Borel, so $g^{-1}(U)$ is Borel by step [](#sections-of-borel-are-borel){.pf-ref}.

::: pf-proof
$y \in g^{-1}(U) \iff f(x, y) \in U \iff (x, y) \in f^{-1}(U)$.
:::

:::

::: pf-qed
By step [](#ginv-U-is-section){.pf-ref} the preimage of every open set is Borel, so $g$ is Borel measurable.
:::

:::

::: pf-step
(c) is true.

::: pf-proof

::: {.pf-step #forward-direction}
($\Rightarrow$) If $E$ is measurable, then for every $\varepsilon > 0$ there exist closed $F$ and open $G$ with $F \subseteq E \subseteq G$ and $m(G \setminus F) < \varepsilon$.

::: pf-proof
By outer regularity pick open $G \supseteq E$ with $m(G \setminus E) < \varepsilon/2$, and by inner regularity (approximation by closed sets for Lebesgue measure on $\mathbb{R}$) pick closed $F \subseteq E$ with $m(E \setminus F) < \varepsilon/2$.
Since $G \setminus F \subseteq (G \setminus E) \cup (E \setminus F)$, subadditivity gives $m(G \setminus F) < \varepsilon$.
:::

:::

::: {.pf-step #backward-direction}
($\Leftarrow$) If for every $\varepsilon > 0$ such $F, G$ exist, then $E$ is measurable.

::: pf-proof
For each $n \geq 1$ choose closed $F_n$ and open $G_n$ with $F_n \subseteq E \subseteq G_n$ and $m(G_n \setminus F_n) < 1/n$, and put $F = \bigcup_n F_n$, a measurable subset of $E$.
For every $n$, $E \setminus F \subseteq G_n \setminus F_n$, so $m^*(E \setminus F) < 1/n$. Hence $m^*(E \setminus F) = 0$; null sets are measurable, so $E = F \cup (E \setminus F)$ is measurable.
:::

:::

::: pf-qed
Steps [](#forward-direction){.pf-ref} and [](#backward-direction){.pf-ref} give both implications.
:::

::: {.problem}
Prove or disprove each of the following statements.

(d) If $\lim_{n\to\infty} \abs{a_{n+1}/a_n}$ exists, then $\lim_{n\to \infty} \abs{a_n}^{1/n}$ exists and the two limits are equal.

(e) If $\sum_{n=1}^\infty a_n x^n$ converges for all $x \in [0, 1]$, then $\lim_{x\to 1^-} \sum_{n=1}^\infty a_n x^n=\sum_{n=1}^\infty a_n$
:::

::: {.solution}
In (d), assume $a_n \neq 0$ for all large $n$.

::: pf

::: pf-step
(d) is true.

::: pf-proof

::: {.pf-step #sandwich-inequality}
If $a_n \neq 0$ for all large $n$, then $$\liminf_n \abs{\frac{a_{n+1}}{a_n}} \leq \liminf_n \abs{a_n}^{1/n} \leq \limsup_n \abs{a_n}^{1/n} \leq \limsup_n \abs{\frac{a_{n+1}}{a_n}}.$$

::: pf-proof
For the upper bound, let $L^+ := \limsup_n \abs{a_{n+1}/a_n}$; if $L^+ = +\infty$ there is nothing to prove.
Given $\varepsilon > 0$, $\abs{a_{n+1}/a_n} < L^+ + \varepsilon$ for all $n \geq N$; iterating, $\abs{a_n} \leq C\,(L^+ + \varepsilon)^{n}$ for some constant $C$, so $\abs{a_n}^{1/n} \leq C^{1/n}(L^+ + \varepsilon) \to L^+ + \varepsilon$; hence $\limsup \abs{a_n}^{1/n} \leq L^+$.
The lower bound is symmetric: if $L^- := \liminf_n \abs{a_{n+1}/a_n} > 0$, then $\abs{a_{n+1}/a_n} > L^- - \varepsilon$ eventually, giving $\abs{a_n} \geq c\,(L^- - \varepsilon)^n$, so $\liminf \abs{a_n}^{1/n} \geq L^- - \varepsilon$; and if $L^- = 0$ the inequality $\liminf \abs{a_n}^{1/n} \geq 0$ holds because $\abs{a_n}^{1/n} \geq 0$ for every $n$.
:::

:::

::: {.pf-step #ratio-limit-implies-root-limit}
If $L := \lim_n \abs{a_{n+1}/a_n}$ exists, then $\lim_n \abs{a_n}^{1/n}$ exists and equals $L$.

::: pf-proof
Existence of the limit means $\liminf_n \abs{a_{n+1}/a_n} = \limsup_n \abs{a_{n+1}/a_n} = L$; the sandwich in step [](#sandwich-inequality){.pf-ref} forces $\liminf \abs{a_n}^{1/n} = \limsup \abs{a_n}^{1/n} = L$.
:::

:::

::: pf-qed
Step [](#ratio-limit-implies-root-limit){.pf-ref} is the assertion of (d).
:::

:::

:::

::: pf-step
(e) is true.

::: pf-proof

::: {.pf-step #series-converges}
$\sum_{n=1}^\infty a_n$ converges.

::: pf-proof
The hypothesis gives convergence of $\sum a_n x^n$ at $x = 1$.
:::

:::

::: {.pf-step #abels-theorem-applied}
Abel's theorem: if $\sum a_n$ converges to $S$, then $\lim_{x \to 1^-} \sum_{n=1}^\infty a_n x^n = S$.

::: pf-proof
By partial summation, with $S_N := \sum_{n=1}^N a_n$ (and $S_0 = 0$), $\sum_{n=1}^N a_n x^n = (1-x)\sum_{n=1}^{N-1} S_n x^n + S_N x^N$; letting $N \to \infty$ (for $\abs{x} < 1$) gives $\sum_{n=1}^\infty a_n x^n = (1-x)\sum_{n=1}^\infty S_n x^n$.
Write $S_n = S + \rho_n$ with $\rho_n \to 0$: then $(1-x)\sum_n S_n x^n = S(1-x)\sum_n x^n + (1-x)\sum_n \rho_n x^n = Sx + (1-x)\sum_n \rho_n x^n$.
The last term tends to $0$: given $\varepsilon > 0$ choose $N_0$ with $\abs{\rho_n} < \varepsilon$ for $n > N_0$; then $(1-x)\abs{\sum_n \rho_n x^n} \leq (1-x)\sum_{n \leq N_0} \abs{\rho_n} x^n + \varepsilon(1-x)\sum_{n > N_0} x^n \leq (1-x)\sum_{n \leq N_0} \abs{\rho_n} + \varepsilon$, whose limit as $x \to 1^-$ is $\varepsilon$.
Since $\varepsilon > 0$ is arbitrary and $Sx \to S$, the limit is $S$.
:::

:::

::: pf-qed
Steps [](#series-converges){.pf-ref} and [](#abels-theorem-applied){.pf-ref} give the conclusion of (e).
:::

::: problem
Prove or disprove each of the following statements.

(d) If $\lim_{n\to\infty} |a_n+1/a_n|$ exists, then $\lim_{n\to \infty} |a_n|^{1/n}$ exists and the two limits are equal.

(e) If $\sum_{n=1}^\infty a_n x^n$ converges for all $x \in [0, 1]$, then $\lim_{x\to 1^-} \sum_{n=1}^\infty a_n x^n=\sum_{n=1}^\infty a_n$
:::

::: {.solution}
**Goal:** Decide (d) and (e): (d) existence of $\lim_n |a_{n+1}/a_n|$ forces existence of $\lim_n |a_n|^{1/n}$ with equality; (e) Abel's theorem for power series at $x = 1$.
Both are true.

<1>1. (d) is true.
<2>1. Assuming $a_n \neq 0$ eventually (so the ratios make sense), the general inequalities $$\liminf_n \left|\frac{a_{n+1}}{a_n}\right| \leq \liminf_n |a_n|^{1/n} \leq \limsup_n |a_n|^{1/n} \leq \limsup_n \left|\frac{a_{n+1}}{a_n}\right|$$ hold.
::: {.proof}
for the upper bound, let $L^+ := \limsup_n |a_{n+1}/a_n|$.
:::
Given $\varepsilon > 0$, $|a_{n+1}/a_n| < L^+ + \varepsilon$ for all $n \geq N$; iterating, $|a_n| \leq C\,(L^+ + \varepsilon)^{n}$ for some constant $C$, so $|a_n|^{1/n} \leq C^{1/n}(L^+ + \varepsilon) \to L^+ + \varepsilon$; hence $\limsup |a_n|^{1/n} \leq L^+$.
The lower bound is symmetric: if $L^- := \liminf_n |a_{n+1}/a_n| > 0$, then $|a_{n+1}/a_n| > L^- - \varepsilon$ eventually, giving $|a_n| \geq c\,(L^- - \varepsilon)^n$, so $\liminf |a_n|^{1/n} \geq L^- - \varepsilon$; and if $L^- = 0$ the inequality $\liminf |a_n|^{1/n} \geq 0$ holds because $|a_n|^{1/n} \geq 0$ for every $n$.
<2>2. If $L := \lim_n |a_{n+1}/a_n|$ exists, then $\lim_n |a_n|^{1/n}$ exists and equals $L$.
::: {.proof}
existence of the limit means $\liminf_n |a_{n+1}/a_n| = \limsup_n |a_{n+1}/a_n| = L$; the sandwich in <2>1 forces $\liminf |a_n|^{1/n} = \limsup |a_n|^{1/n} = L$.
:::
<2>3. Q.E.D.
::: {.proof}
<2>2 is the assertion of (d).
:::

<1>2. (e) is true.
<2>1. $\sum_{n=1}^\infty a_n$ converges.
::: {.proof}
the hypothesis gives convergence of $\sum a_n x^n$ at $x = 1$.
:::
<2>2. Abel's theorem: if $\sum a_n$ converges to $S$, then $\lim_{x \to 1^-} \sum_{n=1}^\infty a_n x^n = S$.
::: {.proof}
partial summation.
:::
With $S_N := \sum_{n=1}^N a_n$ (and $S_0 = 0$), $\sum_{n=1}^N a_n x^n = (1-x)\sum_{n=1}^{N-1} S_n x^n + S_N x^N$; letting $N \to \infty$ (for $|x| < 1$) gives $\sum_{n=1}^\infty a_n x^n = (1-x)\sum_{n=1}^\infty S_n x^n$.
Write $S_n = S + \rho_n$ with $\rho_n \to 0$: then $(1-x)\sum_n S_n x^n = S(1-x)\sum_n x^n + (1-x)\sum_n \rho_n x^n = Sx + (1-x)\sum_n \rho_n x^n$.
The last term tends to $0$: given $\varepsilon > 0$ choose $N_0$ with $|\rho_n| < \varepsilon$ for $n > N_0$; then $(1-x)\big|\sum_n \rho_n x^n\big| \leq (1-x)\sum_{n \leq N_0} |\rho_n| x^n + \varepsilon(1-x)\sum_{n > N_0} x^n \to \varepsilon$ as $x \to 1^-$.
Hence the limit is $S$.
<2>3. Q.E.D.
::: {.proof}
<2>1 and <2>2 give the conclusion of (e).
:::
:::

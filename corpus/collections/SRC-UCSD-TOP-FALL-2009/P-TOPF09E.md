::: {.problem}
Show that any homotopy equivalence from $\mathbb{CP}^{2n}$ to itself is orientation-preserving, that is has degree $+1$.
:::

::: {.solution}

::: pf

::: pf-step

$H^*(\mathbb{CP}^{2n}; \ZZ) = \ZZ[x]/(x^{2n+1})$ with $|x| = 2$, so $H^{4n}(\mathbb{CP}^{2n};\ZZ) = \ZZ$ generated by $x^{2n}$.

::: pf-proof

cohomology of complex projective space.

:::

:::

::: {.pf-step #s2}

Let $f : \mathbb{CP}^{2n} \to \mathbb{CP}^{2n}$ be a homotopy equivalence; then $f^*(x) = \pm x$ (since $f^*$ is a ring isomorphism, it sends the generator $x$ to $\pm x$).

::: pf-proof

$f^*$ is an isomorphism on $H^2 = \ZZ$, so $f^*(x) = \pm x$.

:::

:::

::: {.pf-step #s3}

The degree of $f$ is the integer $d$ with $f^*(x^{2n}) = d x^{2n}$.

::: pf-proof

definition of degree (the induced map on top cohomology).

:::

:::

::: {.pf-step #s4}

$f^*(x^{2n}) = f^*(x)^{2n} = (\pm x)^{2n} = x^{2n}$ (since $2n$ is even, $(\pm 1)^{2n} = 1$).

::: pf-proof

Step [](#s2){.pf-ref} and the ring homomorphism property.

:::

:::

::: {.pf-step #s5}

Hence $d = 1$, so $f$ has degree $+1$ and is orientation-preserving.

::: pf-proof

Steps [](#s3){.pf-ref} and [](#s4){.pf-ref}.

:::

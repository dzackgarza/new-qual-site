The number of nonsingular matrices is the number of bases which is $( p ^ { n } - 1 ) ( p ^ { n } - p ) . . . ( p ^ { n } -$ $p ^ { n - 1 } )$ (product of number of ways to choose first, second, ...n’th basis vectors). So $r =$ $0 + 1 + \ldots ( n - 1 ) = ( n - 1 ) n / 2$ and $s = ( p ^ { n } - 1 ) ( p ^ { n - 1 } - 1 ) . . . ( p - 1 )$ is congruent to $( - 1 ) ^ { n }$ (mod $p )$

For each of the following statements, either prove it or give a counterexample:

(a) If f (x) and $f _ { n } ( x )$ are continuous real-valued functions on the unit interval, and $\operatorname* { l i m } _ { n \to \infty } f _ { n } ( x ) = f ( x )$ for all x, then limn→∞ $\begin{array} { r } { \int _ { 0 } ^ { 1 } f _ { n } ( x ) d x = \int _ { 0 } ^ { 1 } f ( x ) d x } \end{array}$

(b) $\operatorname { I f } g ( m , n )$ is real for all integers $m , n$ , and $\scriptstyle \sum _ { m = 0 } ^ { \infty } ( \sum _ { n = 0 } ^ { \infty } g ( m , n ) )$ and $\scriptstyle \sum _ { n = 0 } ^ { \infty } ( \sum _ { m = 0 } ^ { \infty } g ( m , n ) )$ are both defined, then they are equal.

(c) If the functions $h _ { n } ( x )$ are continuous real-valued functions on the unit interval, and $\begin{array} { r } { \operatorname* { l i m } _ { n  \infty } h _ { n } ( x ) = h ( x ) } \end{array}$ for all x, then $h ( x )$ is a continuous function of x.

::: {.problem}
If N is the integer $2 ^ { 4 } \cdot 3 ^ { 3 } \cdot 5 ^ { 2 } \cdot 7$ find the smallest positive integer m such that $x ^ { m } \equiv 1$ mod N for all integers x coprime to N .
:::

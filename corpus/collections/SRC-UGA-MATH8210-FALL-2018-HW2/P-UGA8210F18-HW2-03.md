::: {.problem}
On the last homework, you showed that $M \times N$ gets a smooth structure from M and N. There are smooth ap $\pi _ { 1 } : M \times N \to M$ $\pi _ { 2 } : M \times N \to N$ by projecting onto the first or second coordiante.
(You do not have to check that they are smooth.)

Use these maps to cook up an isomorphism $T _ { ( } p , q ) ( M \times N ) \cong T _ { p } M \times T _ { q } N .$
:::

::: {.solution}

::: pf

::: pf-step

Define
\[
\Phi:
T_{(p,q)}(M\times N)
\longrightarrow
T_pM\times T_qN
\]
by
\[
\boxed{
\Phi(\xi)
=
\bigl(
d(\pi_1)_{(p,q)}(\xi),
d(\pi_2)_{(p,q)}(\xi)
\bigr)}.
\]


::: pf-proof

The projections
\[
\pi_1:M\times N\to M,
\qquad
\pi_2:M\times N\to N
\]
are smooth, so their differentials at $(p,q)$ are linear maps
\[
d(\pi_1)_{(p,q)}:
T_{(p,q)}(M\times N)\to T_pM
\]
and
\[
d(\pi_2)_{(p,q)}:
T_{(p,q)}(M\times N)\to T_qN.
\]
Taking them together gives the displayed linear map.

:::

:::

::: pf-step

Define the smooth inclusions
\[
i_q:M\to M\times N,
\qquad
i_q(x)=(x,q),
\]
and
\[
j_p:N\to M\times N,
\qquad
j_p(y)=(p,y).
\]


::: pf-proof

These are product maps of the identity with constant maps, hence are smooth.
They satisfy
\[
i_q(p)=(p,q)
\qquad\text{and}\qquad
j_p(q)=(p,q).
\]

:::

:::

::: pf-step

Define
\[
\Psi:
T_pM\times T_qN
\longrightarrow
T_{(p,q)}(M\times N)
\]
by
\[
\boxed{
\Psi(v,w)
=
d(i_q)_p(v)
+
d(j_p)_q(w)}.
\]


::: pf-proof

Both summands lie in
\[
T_{(p,q)}(M\times N),
\]
and the differential is linear in tangent vectors, so $\Psi$ is a well-defined
linear map.

:::

:::

::: {.pf-step #s1-4}

One has
\[
\Phi\circ\Psi
=
\operatorname{id}_{T_pM\times T_qN}.
\]


::: pf-proof

The compositions of the projection maps with the inclusions are
\[
\pi_1\circ i_q
=
\operatorname{id}_M,
\qquad
\pi_2\circ i_q
=
\operatorname{const}_q,
\]
and
\[
\pi_1\circ j_p
=
\operatorname{const}_p,
\qquad
\pi_2\circ j_p
=
\operatorname{id}_N.
\]
Differentiating gives
\[
d\pi_1\circ di_q
=
\operatorname{id}_{T_pM},
\qquad
d\pi_2\circ di_q
=0,
\]
and
\[
d\pi_1\circ dj_p
=0,
\qquad
d\pi_2\circ dj_p
=
\operatorname{id}_{T_qN}.
\]
Therefore
\[
\begin{aligned}
\Phi(\Psi(v,w))
&=
\Phi\bigl(di_q(v)+dj_p(w)\bigr)\\
&=
\bigl(v,w\bigr).
\end{aligned}
\]

:::

:::

::: {.pf-step #s1-5}

In product coordinates,
\[
\Phi
\]
is the identity map on
\[
\RR^{\dim M+\dim N}
\cong
\RR^{\dim M}\times\RR^{\dim N}.
\]


::: pf-proof

Choose charts
\[
\phi:U\to\RR^m
\]
around $p$ and
\[
\psi:V\to\RR^n
\]
around $q$. The product chart is
\[
\phi\times\psi:
U\times V
\to
\RR^m\times\RR^n.
\]
Under this chart, the maps $\pi_1$ and $\pi_2$ become the ordinary coordinate
projections
\[
(x,y)\mapsto x
\qquad\text{and}\qquad
(x,y)\mapsto y.
\]
Their differentials are the standard linear projections, so
\[
\Phi(a,b)=(a,b).
\]
Thus $\Phi$ is injective as well as surjective.

:::

:::

::: {.pf-step #s1-6}

Hence
\[
\boxed{
T_{(p,q)}(M\times N)
\cong
T_pM\times T_qN}.
\]


::: pf-proof

By step [](#s1-4){.pf-ref}, $\Phi$ has the right inverse $\Psi$, so it is surjective.
Step [](#s1-5){.pf-ref} shows that $\Phi$ is injective. Therefore $\Phi$ is a linear
isomorphism, with inverse $\Psi$.

:::

:::

::: pf-qed

Step [](#s1-6){.pf-ref} gives the requested canonical isomorphism.

:::

::: {.problem}
Show that $H _ { 0 , d R } ( M )$ is determined by the point-set topology of M rather than the smooth structure on M. (To do so, describe $H _ { 0 , d R } ( M )$ in terms of the point-set topology of M .)
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

In degree zero,
\[
H^0_{dR}(M)
=
\ker\!\left(
d:\Omega^0(M)\to\Omega^1(M)
\right).
\]


::: pf-proof

By definition,
\[
H^0_{dR}(M)
=
\frac{
\ker(d:\Omega^0(M)\to\Omega^1(M))
}{
\operatorname{im}(d:\Omega^{-1}(M)\to\Omega^0(M))
}.
\]
There are no differential forms of negative degree, so
\[
\Omega^{-1}(M)=0.
\]
Hence the denominator is zero.

:::

:::

::: {.pf-step #s1-2}

A smooth function
\[
f:M\to\RR
\]
satisfies
\[
df=0
\]
if and only if it is locally constant.


::: pf-proof

Suppose first that $df=0$. Fix $p\in M$ and choose a connected coordinate
neighborhood
\[
(U,\phi)
\]
of $p$, with $\phi(U)$ an open ball in $\RR^n$. The coordinate
representative
\[
\widetilde f=f\circ\phi^{-1}
\]
has derivative zero everywhere on $\phi(U)$ because $df=0$. The ordinary
multivariable theorem that a differentiable function with zero derivative on
a connected open set is constant shows that $\widetilde f$, and hence $f$,
is constant on $U$. Thus $f$ is locally constant.

Conversely, if $f$ is locally constant, then near every point it is constant,
so every directional derivative vanishes. Hence
\[
df=0.
\]

:::

:::

::: {.pf-step #s1-3}

A locally constant function on $M$ is exactly a function that is
constant on each connected component of $M$.


::: pf-proof

Every locally constant function is continuous. The image of a connected set
under a continuous map is connected, so the image of each connected
component of $M$ lies in a connected subset of $\RR$.

More directly, if $C$ is a connected component and $f$ is locally constant,
then for each $c\in\RR$ the subset
\[
C\cap f^{-1}(\{c\})
\]
is open in $C$. Its complement is also open because $f$ is locally constant.
Since $C$ is connected, only one such value can occur on $C$. Thus $f$ is
constant on $C$.

Conversely, smooth manifolds are locally connected, so their connected
components are open. A function that is constant on each connected
component is therefore locally constant.

:::

:::

::: {.pf-step #s1-4}

Consequently,
\[
\boxed{
H^0_{dR}(M)
\cong
\operatorname{Map}(\pi_0(M),\RR)
\cong
\prod_{C\in\pi_0(M)}\RR
}.
\]


::: pf-proof

By steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref}, degree-zero de Rham cohomology is the vector space of
locally constant real-valued functions on $M$. By step [](#s1-3){.pf-ref}, specifying such
a function is exactly specifying one real number for each connected
component
\[
C\in\pi_0(M).
\]
Addition and scalar multiplication are componentwise, yielding the displayed
vector-space isomorphism.

:::

:::

::: {.pf-step #s1-5}

Therefore $H^0_{dR}(M)$ depends only on the point-set topology of
$M$.


::: pf-proof

The set of connected components
\[
\pi_0(M)
\]
is determined entirely by the underlying topological space. Step [](#s1-4){.pf-ref}
describes $H^0_{dR}(M)$ solely in terms of this topological invariant, with no
reference to a smooth atlas. Hence changing the smooth structure without
changing the topology cannot change degree-zero de Rham cohomology.

:::

:::

::: pf-qed

Step [](#s1-5){.pf-ref} is the requested conclusion.

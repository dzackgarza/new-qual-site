::: {.problem}
Let $G$ be a finite group with $n$ distinct conjugacy classes, and let $g_1, g_2, \dots, g_n$ be a set of representatives for the conjugacy classes of $G$.

Prove that if $g_i g_j = g_j g_i$ for all $1 \le i, j \le n$, then $G$ is abelian.
:::

::: {.solution}
**Goal:** Prove that $G$ is abelian by considering the subgroup $H = \langle g_1, \dots, g_n \rangle$ and applying the conjugate cover theorem for finite groups.

::: pf

::: {.pf-step #s1}
Subgroup $H = \langle g_1, \dots, g_n \rangle$ generated by representatives:

::: pf-proof

::: pf-step
Define $H = \langle g_1, \dots, g_n \rangle \le G$ to be the subgroup of $G$ generated by the $n$ conjugacy class representatives.
:::

::: pf-step
By hypothesis, $g_i g_j = g_j g_i$ for all $1 \le i, j \le n$, so all generators of $H$ pairwise commute.
:::

::: pf-step
Since any group generated by pairwise commuting elements is abelian, $H$ is an abelian subgroup of $G$.
:::

:::

:::

::: {.pf-step #s2}
$G$ is the union of conjugates of $H$:

::: pf-proof

::: pf-step
Let $x \in G$ be an arbitrary element.
:::

::: pf-step
Since $g_1, \dots, g_n$ represent all conjugacy classes of $G$, the conjugacy classes partition $G$:
$$G = \bigsqcup_{i=1}^n \operatorname{Cl}(g_i).$$
:::

::: pf-step
Thus $x \in \operatorname{Cl}(g_k)$ for some $k \in \{1, \dots, n\}$.
:::

::: pf-step
By definition of conjugacy class, there exists an element $g \in G$ such that $x = g g_k g^{-1}$.
:::

::: pf-step
Since $g_k \in H$, $x = g g_k g^{-1} \in g H g^{-1}$.
:::

::: pf-step
Therefore:
$$G \subseteq \bigcup_{g \in G} g H g^{-1} \subseteq G \implies G = \bigcup_{g \in G} g H g^{-1}.$$
:::

:::

:::

::: {.pf-step #s3}
Lemma: No finite group is a union of conjugates of a proper subgroup.

::: pf-proof

::: pf-step
Let $K < G$ be a proper subgroup with $[G : K] = m > 1$.
:::

::: pf-step
The number of distinct conjugate subgroups of $K$ in $G$ is $[G : N_G(K)] \le [G : K] = m$.
:::

::: pf-step
Each conjugate $g K g^{-1}$ contains $|K|$ elements and shares the identity element $e$ with all other conjugates.
:::

::: pf-step
The union of all conjugates contains at most
$$\left| \bigcup_{g \in G} g K g^{-1} \right| \le 1 + [G : N_G(K)] (|K| - 1) \le 1 + [G : K] (|K| - 1) = 1 + |G| - [G : K].$$
:::

::: pf-step
Since $[G : K] \ge 2$, $1 + |G| - [G : K] \le |G| - 1 < |G|$.
:::

::: pf-step
Thus $\bigcup_{g \in G} g K g^{-1} \subsetneq G$.
:::

:::

:::

::: pf-step
$H = G$ and $G$ is abelian:

::: pf-proof

::: pf-step
From step [](#s2){.pf-ref}, $G = \bigcup_{g \in G} g H g^{-1}$.
:::

::: pf-step
By the contrapositive of step [](#s3){.pf-ref}, $H$ cannot be a proper subgroup of $G$.
:::

::: pf-step
Thus $H = G$.
:::

::: pf-step
From step [](#s1){.pf-ref}, $H$ is abelian, so $G$ is abelian.
:::

:::

:::

::: pf-step
Conclusion:

::: pf-proof
$G$ is abelian.
:::

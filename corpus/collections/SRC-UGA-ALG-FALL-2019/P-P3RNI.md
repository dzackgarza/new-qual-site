::: {.problem}
Let $G$ be a finite group with $n$ distinct conjugacy classes, and let $g_1, g_2, \dots, g_n$ be a set of representatives for the conjugacy classes of $G$.

Prove that if $g_i g_j = g_j g_i$ for all $1 \le i, j \le n$, then $G$ is abelian.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

The subgroup $H=\langle g_1,\ldots,g_n\rangle$ is abelian.

::: pf-proof

::: pf-step

Define $H = \langle g_1, \dots, g_n \rangle \le G$ to be the subgroup of $G$ generated by the $n$ conjugacy class representatives.


::: pf-proof
The chosen representatives are elements of $G$, so the subgroup they generate is a subgroup of $G$ by definition of the subgroup generated by a set.
:::

:::

::: pf-step

By hypothesis, $g_i g_j = g_j g_i$ for all $1 \le i, j \le n$, so all generators of $H$ pairwise commute.


::: pf-proof
The hypothesis is that any two of the chosen representatives commute, and pairwise commutation for the set of all $n$ generators says exactly that each of the $\binom{n}{2}$ pairs satisfies $g_ig_j = g_jg_i$, which is the displayed identity.
:::

:::

::: pf-step

Since any group generated by pairwise commuting elements is abelian, $H$ is an abelian subgroup of $G$.


::: pf-proof
Once the generators commute with one another, every word in them and their inverses can be rewritten as a monomial $g_1^{a_1}\cdots g_n^{a_n}$, and two such monomials multiply by adding exponents; so every pair of elements of $H$ commutes and $H$ is abelian.
:::

:::

:::

:::

::: {.pf-step #s2}

The group $G$ is the union of the conjugates of $H$.

::: pf-proof

::: pf-step

Let $x \in G$ be an arbitrary element.


::: pf-proof
Fix an arbitrary element of $G$; the argument that follows places it in the union, and since nothing was assumed about it the whole group is covered.
:::

:::

::: pf-step

Since $g_1, \dots, g_n$ represent all conjugacy classes of $G$, the conjugacy classes partition $G$:
    $$G = \bigsqcup_{i=1}^n \operatorname{Cl}(g_i).$$


::: pf-proof
Conjugacy is an equivalence relation, so its classes are disjoint and cover $G$; the elements $g_1,\dots,g_n$ are one representative from each class by hypothesis, so the displayed disjoint union is all of $G$.
:::

:::

::: pf-step

Thus $x \in \operatorname{Cl}(g_k)$ for some $k \in \{1, \dots, n\}$.


::: pf-proof
The classes partition $G$ and $x$ lies in $G$, so $x$ lies in exactly one class, and every class is $\operatorname{Cl}(g_k)$ for one of the chosen representatives.
:::

:::

::: pf-step

By definition of conjugacy class, there exists an element $g \in G$ such that $x = g g_k g^{-1}$.


::: pf-proof
The conjugacy class of $g_k$ is by definition the set of elements $gg_kg^{-1}$ with $g \in G$, so membership in it produces such an element $g$.
:::

:::

::: pf-step

Since $g_k \in H$, $x = g g_k g^{-1} \in g H g^{-1}$.


::: pf-proof
Conjugating every element of the subgroup $H$ by the fixed element $g$ gives the set $gHg^{-1}$, and $g_k$ lies in $H$ because $H$ is generated by the $g_i$; so the conjugate of $g_k$ lies in that set.
:::

:::

::: pf-step

Therefore $G = \bigcup_{g \in G} g H g^{-1}$.


::: pf-proof
Each $x \in G$ lies in some conjugate $gHg^{-1}$ by the step above, so $G$ is contained in the union; the reverse inclusion holds because every $gHg^{-1}$ is a subset of $G$. The two inclusions give equality.
:::

:::

$$G \subseteq \bigcup_{g \in G} g H g^{-1} \subseteq G \implies G = \bigcup_{g \in G} g H g^{-1}.$$

:::

:::

::: {.pf-step #s3}

No finite group is the union of the conjugates of a proper subgroup.

::: pf-proof

::: pf-step

Let $K < G$ be a proper subgroup with $[G : K] = m > 1$.


::: pf-proof
Since $K$ is a proper subgroup, $\cardinality{K} < \cardinality{G}$ and $\abs{G} = [G:K]\abs{K}$ by Lagrange, so the index is an integer greater than $1$.
:::

:::

::: pf-step

The number of distinct conjugate subgroups of $K$ in $G$ is $[G : N_G(K)] \le [G : K] = m$.


::: pf-proof
The conjugates of $K$ are the subgroups $gKg^{-1}$, and $gKg^{-1} = hKh^{-1}$ exactly when $h^{-1}g$ normalizes $K$, so the distinct conjugates correspond to the cosets of the normalizer and their number is $[G:N_G(K)]$. Since $K \subseteq N_G(K)$, that index is at most $[G:K]$.
:::

:::

::: pf-step

Each conjugate $g K g^{-1}$ contains $\cardinality{K}$ elements and shares the identity element $e$ with all other conjugates.


::: pf-proof
Conjugation by $g$ is a bijection of $G$ carrying $K$ onto $gKg^{-1}$, so each conjugate has $\abs{K}$ elements; and $geg^{-1} = e$ for every $g$, so the identity belongs to every conjugate.
:::

:::

::: pf-step

The union of all conjugates contains at most
    $$\cardinality{ \bigcup_{g \in G} g K g^{-1} } \le 1 + [G : N_G(K)] (\cardinality{K} - 1) \le 1 + [G : K] (\cardinality{K} - 1) = 1 + \cardinality{G} - [G : K].$$


::: pf-proof
The identity is common to all the conjugates and each of the $[G:N_G(K)]$ distinct ones contributes at most $\abs{K} - 1$ elements besides it, so the union has at most $1 + [G:N_G(K)](\abs{K}-1)$ elements; replacing the normalizer index by the larger $[G:K]$ and using $\abs{G} = [G:K]\abs{K}$ gives the last expression.
:::

:::

::: pf-step

Since $[G : K] \ge 2$, $1 + \cardinality{G} - [G : K] \le \cardinality{G} - 1 < \cardinality{G}$.


::: pf-proof
With $[G:K] \ge 2$ the expression $1 + \abs{G} - [G:K]$ is at most $1 + \abs{G} - 2 = \abs{G} - 1$, which is strictly less than $\abs{G}$.
:::

:::

::: pf-step

Thus $\bigcup_{g \in G} g K g^{-1} \subsetneq G$.


::: pf-proof
A subset with at most $\abs{G} - 1$ elements cannot equal the finite group of order $\abs{G}$, so the union of the conjugates is a proper subset.
:::

:::

:::

:::

::: {.pf-step #s4}

The group $G$ is abelian.

::: pf-proof

::: pf-step

From step [](#s2){.pf-ref}, $G = \bigcup_{g \in G} g H g^{-1}$.


::: pf-proof
This is the conclusion of step [](#s2){.pf-ref}, restated here so that the counting statement of step [](#s3){.pf-ref} can be applied to $H$.
:::

:::

::: pf-step

By the contrapositive of step [](#s3){.pf-ref}, $H$ cannot be a proper subgroup of $G$.


::: pf-proof
Step [](#s3){.pf-ref} says that the conjugates of a proper subgroup never cover the group; the conjugates of $H$ do cover $G$, so $H$ is not a proper subgroup.
:::

:::

::: pf-step

Thus $H = G$.


::: pf-proof
A subgroup is either a proper subgroup of $G$ or equal to $G$, and the previous step excludes the first alternative.
:::

:::

::: pf-step

From step [](#s1){.pf-ref}, $H$ is abelian, so $G$ is abelian.


::: pf-proof
Step [](#s1){.pf-ref} gives that $H$ is abelian, and $H = G$, so $G$ is abelian.
:::

::: {.problem}
Let $\zeta_n \in \CC$ denote a primitive $n$-th root of unity, and let $p_n(x) \in \QQ[x]$ be its minimal polynomial over $\QQ$. You may assume that the roots of $p_n(x)$ are precisely the primitive $n$-th roots of unity in $\CC$.

(a) Show that the field extension $\QQ(\zeta_n)/\QQ$ is Galois, and prove that its Galois group is isomorphic to $(\ZZ/n\ZZ)^\times$.

(b) How many subfields are there of $\QQ(\zeta_{20})$?
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

The extension $\QQ(\zeta_n)/\QQ$ is Galois.

::: pf-proof

::: pf-step

Splitting field: The polynomial $x^n - 1 \in \QQ[x]$ has roots $\{e^{2\pi i k / n} : 0 \le k < n\} = \{\zeta_n^k : 0 \le k < n\}$. All of these roots belong to $\QQ(\zeta_n)$.

:::

::: pf-step

Thus $\QQ(\zeta_n)$ is the splitting field of $x^n - 1$ over $\QQ$.

:::

::: pf-step

Since $\QQ$ has characteristic 0, every algebraic extension over $\QQ$ is separable.

:::

::: pf-step

Because $\QQ(\zeta_n)/\QQ$ is a splitting field of a separable polynomial, it is normal and separable, hence Galois.

:::

:::

:::

::: {.pf-step #s2}

Its Galois group is isomorphic to $(\ZZ/n\ZZ)^\times$.

::: pf-proof

::: pf-step

Field degree: By hypothesis, the roots of the minimal polynomial $p_n(x)$ of $\zeta_n$ over $\QQ$ are precisely the primitive $n$-th roots of unity. The number of primitive $n$-th roots of unity is $\varphi(n)$, so $[\QQ(\zeta_n) : \QQ] = \deg p_n(x) = \varphi(n)$.

:::

::: pf-step

Action on generators: Any automorphism $\sigma \in \operatorname{Gal}(\QQ(\zeta_n)/\QQ)$ is uniquely determined by its value $\sigma(\zeta_n)$, since $\QQ(\zeta_n) = \QQ[\zeta_n]$.

:::

::: pf-step

Roots of minimal polynomial: $\sigma(\zeta_n)$ must be a root of $p_n(x)$, which means $\sigma(\zeta_n) = \zeta_n^a$ for some integer $a$ with $1 \le a \le n$ and $\gcd(a, n) = 1$.

:::

::: pf-step

Group homomorphism: Define the map
    $$\Psi: \operatorname{Gal}(\QQ(\zeta_n)/\QQ) \to (\ZZ/n\ZZ)^\times, \quad \sigma \mapsto [a]_n \text{ where } \sigma(\zeta_n) = \zeta_n^a.$$
    For any $\sigma, \tau \in \operatorname{Gal}(\QQ(\zeta_n)/\QQ)$ with $\sigma(\zeta_n) = \zeta_n^a$ and $\tau(\zeta_n) = \zeta_n^b$:
    $$(\sigma \circ \tau)(\zeta_n) = \sigma(\zeta_n^b) = (\sigma(\zeta_n))^b = (\zeta_n^a)^b = \zeta_n^{ab}.$$
    Thus $\Psi(\sigma \circ \tau) = [ab]_n = [a]_n [b]_n = \Psi(\sigma) \Psi(\tau)$, so $\Psi$ is a group homomorphism.

:::

::: pf-step

Injectivity: If $\Psi(\sigma) = [1]_n$, then $\sigma(\zeta_n) = \zeta_n^1 = \zeta_n$. Since $\sigma$ fixes $\QQ$ and $\zeta_n$, $\sigma = \operatorname{id}$. Thus $\ker \Psi = \{\operatorname{id}\}$, so $\Psi$ is injective.

:::

::: pf-step

Isomorphism: Since $|\operatorname{Gal}(\QQ(\zeta_n)/\QQ)| = [\QQ(\zeta_n) : \QQ] = \varphi(n) = |(\ZZ/n\ZZ)^\times|$, the injective homomorphism $\Psi$ is a bijection, and hence an isomorphism:

:::

$$\operatorname{Gal}(\QQ(\zeta_n)/\QQ) \cong (\ZZ/n\ZZ)^\times.$$

:::

:::

::: {.pf-step #s3}

The field $\QQ(\zeta_{20})$ has exactly eight intermediate fields including itself and $\QQ$.

::: pf-proof

::: pf-step

Galois group structure:
        For $n = 20 = 2^2 \cdot 5$, by the Chinese Remainder Theorem:
        $$G = \operatorname{Gal}(\QQ(\zeta_{20})/\QQ) \cong (\ZZ/20\ZZ)^\times \cong (\ZZ/4\ZZ)^\times \times (\ZZ/5\ZZ)^\times \cong \ZZ/2\ZZ \times \ZZ/4\ZZ.$$

:::

::: pf-step

Galois Correspondence: By the Fundamental Theorem of Galois Theory, the subfields $E$ with $\QQ \subseteq E \subseteq \QQ(\zeta_{20})$ correspond bijectively to the subgroups of $G \cong \ZZ/2\ZZ \times \ZZ/4\ZZ$.

:::

::: pf-step

Classification of subgroups of $\ZZ/2\ZZ \times \ZZ/4\ZZ$:
        - Order 1 (index 8): Exactly 1 subgroup: $\{(0, 0)\}$, corresponding to $\QQ(\zeta_{20})$.
        - Order 2 (index 4): The elements of order 2 in $\ZZ/2\ZZ \times \ZZ/4\ZZ$ are $(1, 0)$, $(0, 2)$, and $(1, 2)$. Each generates a distinct cyclic subgroup of order 2:
        $$H_1 = \langle (1, 0) \rangle, \quad H_2 = \langle (0, 2) \rangle, \quad H_3 = \langle (1, 2) \rangle.$$
        There are exactly 3 subgroups of order 2.
        - Order 4 (index 2):
            - Cyclic subgroups of order 4: The elements of order 4 are $(0, 1)$, $(0, 3)$, $(1, 1)$, and $(1, 3)$. They generate 2 cyclic subgroups:
            $$K_1 = \langle (0, 1) \rangle = \langle (0, 3) \rangle, \quad K_2 = \langle (1, 1) \rangle = \langle (1, 3) \rangle.$$
            - Non-cyclic subgroup ($\cong \ZZ/2\ZZ \times \ZZ/2\ZZ$): Generated by the elements of order 2:
            $$K_3 = \{(0, 0), (1, 0), (0, 2), (1, 2)\}.$$
            There are exactly $2 + 1 = 3$ subgroups of order 4.
        - Order 8 (index 1): Exactly 1 subgroup: $G$ itself, corresponding to $\QQ$.

:::

::: pf-step

Total count:
        $$1 + 3 + 3 + 1 = 8 \text{ subgroups}.$$

:::

::: pf-step

Therefore $\QQ(\zeta_{20})$ has exactly 8 subfields.

:::

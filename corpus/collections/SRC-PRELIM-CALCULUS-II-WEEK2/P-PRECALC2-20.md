$$
{ \frac { 1 } { 3 } } + { \frac { 1 } { 3 { \sqrt { 3 } } } } + { \frac { 1 } { 3 { \sqrt { 3 } } { \sqrt { 3 } } } } + \cdots + { \frac { 1 } { 3 { \sqrt { 3 } } { \sqrt { 3 } } + \cdots + { \sqrt { 3 } } + \cdots } } .
$$

converge or diverge?

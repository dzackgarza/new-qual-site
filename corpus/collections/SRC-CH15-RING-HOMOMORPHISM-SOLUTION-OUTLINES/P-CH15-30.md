::: {.problem}
Prove that the sum of the squares of three consecutive integers can not be a square.
:::

::: {.solution}
Let n be an integer.
Then the sum of the squares of three consecutive integers can be represented as $n ^ { 2 } + ( n + 1 ) ^ { 2 } + ( n + 2 ) ^ { 2 }$ . Now consider this expression modulo 3. Then it is $n ^ { 2 } + n ^ { 2 } + 2 n + 1 + n ^ { 2 } + 4 n + 4 = 3 n ^ { 2 } + 6 n + 5 = 2$ . For this expression to be a square then there must exist an element, x, in $\mathbb { Z } _ { 3 }$ such that $x ^ { 2 } = 2$ . But $0 ^ { 2 } = 0 , 1 ^ { 2 } = 1$ and $2 ^ { 2 } = 1$ so there is no such solution.
:::

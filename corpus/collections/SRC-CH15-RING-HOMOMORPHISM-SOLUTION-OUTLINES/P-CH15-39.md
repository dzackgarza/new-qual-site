::: {.problem}
Suppose n is a positive integer written in the form $n = a _ { k } 3 ^ { k } + a _ { k - 1 } 3 ^ { k - 1 } +$ $\cdots + a _ { 1 } 3 + a _ { 0 }$ , where each of the $a _ { i }$ ’s is 0, 1, or 2. Show that n is even if and only if $a _ { k } + a _ { k - 1 } + \cdot \cdot \cdot + a _ { 1 } + a _ { 0 }$ is even.
:::

::: {.solution}
Consider $\phi _ { 2 }$ as defined in class.
Then $\phi _ { 2 } ( n ) = \phi _ { 2 } ( a _ { k } 3 ^ { k } + a _ { k - 1 } 3 ^ { k - 1 } + \cdot \cdot \cdot + a _ { 1 } 3 + a _ { 0 } ) =$ $\sum _ { i = 0 } ^ { k } \phi _ { 2 } ( a _ { i } ) \phi _ { 2 } ( 3 ) ^ { i } = \sum _ { i = 0 } ^ { k } \phi _ { 2 } ( a _ { i } ) \cdot 1 = \phi _ { 2 } ( a _ { 0 } + a _ { 1 } + a _ { 2 } + . . . + a _ { k } )$ . Hence, n is even iff the sum of its coefficients is even.
:::

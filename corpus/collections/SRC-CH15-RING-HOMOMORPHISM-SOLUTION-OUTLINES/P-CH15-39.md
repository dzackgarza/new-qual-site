::: {.problem}
Suppose $n$ is a positive integer written in the form $n = a_{k}3^{k} + a_{k-1}3^{k-1} + \cdots + a_{1}3 + a_{0}$, where each of the $a_{i}$'s is $0$, $1$, or $2$. Show that $n$ is even if and only if $a_{k} + a_{k-1} + \cdots + a_{1} + a_{0}$ is even.
:::

::: {.solution}
Reduce the identity $n=\sum_i a_i3^i$ modulo $2$: the reduction map $\ZZ\to\ZZ_2$ is a ring homomorphism, and $3\equiv1\pmod 2$ makes every power $3^i$ reduce to $1$, so $n\equiv\sum_i a_i\pmod2$. Hence $n$ is even exactly when the digit sum is. The argument is this card's own: no retained solution set in the checkout covers this chapter.

::: pf

::: {.pf-step #hom}
The reduction map $\varphi_2\colon\ZZ\to\ZZ_2$, $\varphi_2(m)=m\bmod2$, is a ring homomorphism.

::: pf-proof
For $m,n\in\ZZ$, $(m+n)\bmod2$ and $(mn)\bmod2$ depend only on $m\bmod2$ and $n\bmod2$, and addition and multiplication of residues satisfy $(m\bmod2)+(n\bmod2)\equiv m+n$ and $(m\bmod2)(n\bmod2)\equiv mn$ modulo $2$. So $\varphi_2(m+n)=\varphi_2(m)+\varphi_2(n)$ and $\varphi_2(mn)=\varphi_2(m)\varphi_2(n)$.
:::

:::


::: {.pf-step #powers}
$\varphi_2(3^i)=1$ for every $i\ge0$, and $\varphi_2(a_i)=a_i\bmod2$ for $a_i\in\{0,1,2\}$.

::: pf-proof
$\varphi_2(3)=1$, so $\varphi_2(3^i)=\varphi_2(3)^i=1$ by step [](#hom){.pf-ref}. The second claim is the definition of $\varphi_2$ restricted to the three digits: $0\mapsto0$, $1\mapsto1$, $2\mapsto0$.
:::

:::


::: {.pf-step #evaluate}
$\displaystyle\varphi_2(n)=\sum_{i=0}^k\varphi_2(a_i)$.

::: pf-proof
Apply $\varphi_2$ to $n=\sum_{i=0}^ka_i3^i$ and use that it is a ring homomorphism, so it respects sums and products: $\varphi_2(n)=\sum_i\varphi_2(a_i)\varphi_2(3^i)=\sum_i\varphi_2(a_i)$ by step [](#powers){.pf-ref}. In $\ZZ_2$ the last sum is the parity of the number of odd digits among $a_0,\dots,a_k$.
:::

:::


::: {.pf-step #conclusion}
$n$ is even if and only if $a_0+a_1+\cdots+a_k$ is even.

::: pf-proof
$n$ is even exactly when $\varphi_2(n)=0$ in $\ZZ_2$. By step [](#evaluate){.pf-ref} $\varphi_2(n)=0$ is the statement that $\sum_i\varphi_2(a_i)$ is even, and since $a_i\in\{0,1,2\}$ the sum $\sum_i\varphi_2(a_i)$ has the same parity as $\sum_ia_i$: each $a_i$ is replaced by its residue mod $2$, and adding a number of $2$'s does not change parity. So $n$ is even exactly when $a_0+\cdots+a_k$ is even.
:::

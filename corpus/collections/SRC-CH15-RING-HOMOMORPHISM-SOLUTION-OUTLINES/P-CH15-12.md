::: {.problem}
Let $\mathbb { Z } _ { 3 } [ i ] = \{ a + b i | a , b \in \mathbb { Z } _ { 3 } \}$ . Show that the field $\mathbb { Z } _ { 3 } [ i ]$ is ring-isomorphic to the field $\mathbb { Z } _ { 3 } [ x ] / < x ^ { 2 } + 1 >$
:::

::: {.solution}
Let $I = < x ^ { 2 } + 1 >$ and define $\phi ( a + b i ) = a + b x + I$. Then $\phi ( ( a + b i ) + ( c + d i ) ) = ( a + c ) + ( b + d ) x + I = \phi ( a + b i ) + \phi ( c + d i )$. Further, since $x^2 \equiv -1 \pmod I$,
$$\phi ( a + b i ) \phi ( c + d i ) = ac + (ad+bc)x + bd\,x^2 + I = ( a c - b d ) + ( a d + b c ) x + I = \phi ( ( a c - b d ) + ( a d + b c ) i ) = \phi ( ( a + b i ) ( c + d i ) ).$$
Hence, φ is a ring homomorphism. By the division algorithm, every coset of I has a unique representative $a + bx$ with $a, b \in \mathbb Z_3$, so φ is a bijection between the two sets of $9$ elements. Hence φ is a ring isomorphism.
:::

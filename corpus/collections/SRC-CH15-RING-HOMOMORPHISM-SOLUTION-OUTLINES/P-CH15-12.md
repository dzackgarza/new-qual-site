::: {.problem}
Let $\mathbb { Z } _ { 3 } [ i ] = \{ a + b i | a , b \in \mathbb { Z } _ { 3 } \}$ . Show that the field $\mathbb { Z } _ { 3 } [ i ]$ is ring-isomorphic to the field $\mathbb { Z } _ { 3 } [ x ] / < x ^ { 2 } + 1 >$
:::

::: {.solution}
Define $\phi ( a + b i ) = a + b i + < x ^ { 2 } + 1 >$ . Then $\phi ( ( a + b i ) + ( c + d i ) ) = \phi ( ( a + c ) + ( b + d ) i ) =$ $( a + c ) + ( b + d ) i + < x ^ { 2 } + 1 > = ( a + b i ) + ( c + d i ) + < x ^ { 2 } + 1 > = ( a + b i + < x ^ { 2 } + 1 > ) + ( c + d i + < x ^ { 2 } + 1 > ) = \phi ( a + b i ) + \phi ( c + d i )$ . Further, $\phi ( ( a + b i ) ( c + d i ) ) = \phi ( ( a c - b d ) + ( a d + b c ) i ) =$ $( a c - b d ) + ( a d + b c ) i + < x ^ { 2 } + 1 > = ( a + b i ) ( c + d i ) + < x ^ { 2 } + 1 > = ( ( a + b i ) + < x ^ { 2 } + 1 > ) ( ( c + d i ) + < x ^ { 2 } + 1 > ) = \phi ( a + b i ) \phi ( c + d i )$ . Hence, φ is a ring homomorphism.
:::

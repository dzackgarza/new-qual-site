::: {.problem}
Let $\ZZ_{3}[i] = \{ a + bi \st a, b \in \ZZ_{3} \}$. Show that the field $\ZZ_{3}[i]$ is ring-isomorphic to the field $\ZZ_{3}[x]/\langle x^{2} + 1 \rangle$.
:::

::: {.solution}

The argument is the card's own: the map $i\mapsto x$ induces a ring homomorphism with kernel $\langle x^{2}+1\rangle$, which is bijective because both sides have nine elements.

::: pf

::: {.pf-step #hom}

$\varphi(a+bi)=a+bx+I$, with $I=\langle x^{2}+1\rangle$, is a ring homomorphism $\ZZ_{3}[i]\to\ZZ_{3}[x]/I$.

::: pf-proof

Additivity is immediate. For multiplicativity, $(a+bi)(c+di)=(ac-bd)+(ad+bc)i$ in $\ZZ_{3}[i]$, where $i^{2}=-1$, and $x^{2}\equiv-1\pmod I$ gives
$$
(a+bx)(c+dx)+I=ac+(ad+bc)x+bd\,x^{2}+I=(ac-bd)+(ad+bc)x+I,
$$
which is the image of $(ac-bd)+(ad+bc)i$. Also $\varphi(1)=1+I$.

:::

:::

::: {.pf-step #injective}

$\varphi$ is injective.

::: pf-proof

If $\varphi(a+bi)=0$ then $a+bx\in I$, so $x^{2}+1$ divides $a+bx$ in $\ZZ_{3}[x]$. Since $\deg(a+bx)\le1<2=\deg(x^{2}+1)$, the only possibility is $a+bx=0$, i.e. $a=b=0$ and $a+bi=0$. So the kernel is trivial.

:::

:::

::: {.pf-step #bijective}

$\varphi$ is bijective.

::: pf-proof

$\ZZ_{3}[i]$ has $3\cdot3=9$ elements. Every class modulo $I$ has a representative of degree $<2$ by division with remainder, and that representative is unique since two of them differing by a multiple of $x^{2}+1$ would have degree $<2$ and be divisible by it, hence be $0$; so $\ZZ_{3}[x]/I$ also has exactly $9$ elements, namely $a+bx+I$ with $a,b\in\ZZ_{3}$. An injective map between finite sets of equal size is bijective.

:::

:::

::: {.pf-step #conclusion}

$\ZZ_{3}[i]\cong\ZZ_{3}[x]/\langle x^{2}+1\rangle$.

::: pf-proof

Steps [](#hom){.pf-ref}, [](#injective){.pf-ref} and [](#bijective){.pf-ref} show $\varphi$ is a bijective ring homomorphism, that is a ring isomorphism:
$$
\boxed{\ZZ_{3}[i]\cong\ZZ_{3}[x]/\langle x^{2}+1\rangle,\ \text{both of order } 9.}
$$

:::

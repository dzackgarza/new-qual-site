::: {.problem}
Recall that a ring element $a$ is called an idempotent if $a^{2} = a$. Prove that a ring homomorphism carries an idempotent to an idempotent.
:::

::: {.solution}

::: pf

::: {.pf-step #multiplicative}

For every $a\in R$, $\phi(a^{2})=\phi(a)^{2}$.

::: pf-proof

$\phi$ is a ring homomorphism, so it respects multiplication:
$\phi(xy)=\phi(x)\phi(y)$ for all $x,y$. Taking $x=y=a$ gives
$\phi(a^{2})=\phi(a)\phi(a)=\phi(a)^{2}$, where the last expression means the
product of $\phi(a)$ with itself in the target ring.

:::

:::

::: {.pf-step #idempotent}

If $a^{2}=a$ then $\phi(a)^{2}=\phi(a)$, so $\phi(a)$ is an idempotent.

::: pf-proof

Assume $a^{2}=a$. Then
$\phi(a)^{2}=\phi(a^{2})=\phi(a)$, using step [](#multiplicative){.pf-ref} for
the first equality and the hypothesis for the second. By the definition in the
statement, an element $b$ with $b^{2}=b$ is an idempotent, so $\phi(a)$ is an
idempotent of the target ring.

:::

:::

::: {.pf-step #hypotheses}

The argument uses only multiplicativity of $\phi$.

::: pf-proof

Neither additivity of $\phi$, nor the existence of a unity in either ring, nor
injectivity or surjectivity is invoked: only $\phi(xy)=\phi(x)\phi(y)$ at
$x=y=a$ and $a^{2}=a$. In particular the image of an idempotent under any
map preserving products is again an idempotent.

:::

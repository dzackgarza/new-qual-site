::: {.problem}
Show that no integer of the form $111{,}111{,}111{,}\ldots{,}111$ is prime.
:::

::: {.solution}

The argument is this collection's outline, written out. The statement is read as the source writes it: the numbers whose decimal digits are all $1$ and whose number of digits is a positive multiple of $3$.

Let $N_{k}=11\ldots1$ with $k$ digits $1$, that is $N_{k}=\sum_{i=0}^{k-1}10^{i}$.

::: pf

::: {.pf-step #digits}
$N_{k}=\sum_{i=0}^{k-1}10^{i}$ with $k$ a positive multiple of $3$, and $N_{k}>3$.

::: pf-proof
The decimal number with $k$ digits all equal to $1$ is $\sum_{i=0}^{k-1}10^{i}$ by the definition of decimal notation. Since $k\geq3$, $N_{k}\geq111>3$.
:::

:::

::: {.pf-step #mod3}
$N_{k}\equiv k \pmod{3}$.

::: pf-proof
Reduction modulo $3$ is a ring homomorphism $\ZZ\to\ZZ_{3}$, so it carries the sum to the sum of the reductions. Now $10\equiv1\pmod 3$, hence $10^{i}\equiv1^{i}=1$ and $N_{k}\equiv\sum_{i=0}^{k-1}1=k\pmod 3$.
:::

:::

::: {.pf-step #divisible}
$3$ divides $N_{k}$.

::: pf-proof
By hypothesis $k=3m$ for some $m\geq1$, so $k\equiv0\pmod 3$ and step [](#mod3){.pf-ref} gives $N_{k}\equiv0\pmod 3$, which is divisibility by $3$.
:::

:::

::: {.pf-step}
$N_{k}$ is not prime.

::: pf-proof
$3\mid N_{k}$ by step [](#divisible){.pf-ref} and $N_{k}>3$ by step [](#digits){.pf-ref}, so $N_{k}=3\cdot(N_{k}/3)$ with both factors greater than $1$; hence $N_{k}$ is composite. The remark on the card records why the hypothesis that the number of digits is a multiple of $3$ cannot be dropped: $11$ is prime.
:::

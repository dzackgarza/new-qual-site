::: {.problem}
Let $R = \left\{ \begin{bmatrix} a & b \\ b & a \end{bmatrix} \,\middle|\, a, b \in \mathbb{Z} \right\}$, and let $\phi$ be the mapping that takes $\begin{bmatrix} a & b \\ b & a \end{bmatrix}$ to $a - b$.

(a) Show that $\phi$ is a homomorphism.

(b) Determine the kernel of $\phi$.

(c) Show that $R / \operatorname{Ker} \phi$ is isomorphic to $\mathbb{Z}$.

(d) Is $\operatorname{Ker} \phi$ a prime ideal?

(e) Is $\operatorname{Ker} \phi$ a maximal ideal?
:::

::: {.solution}
(a) Addition is preserved since $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { b } & { a } \end{array} \right] } + { \left[ \begin{array} { l l } { c } & { d } \\ { d } & { c } \end{array} \right] } ) = \phi ( { \left[ \begin{array} { l l } { a + c } & { b + d } \\ { b + d } & { a + c } \end{array} \right] } ) = ( a + c ) - ( b + d ) = ( a - b ) + ( c - d ) = \phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { b } & { a } \end{array} \right] } ) + \phi ( { \left[ \begin{array} { l l } { c } & { d } \\ { d } & { c } \end{array} \right] } )$ . We can also see that multiplication is preserved since $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { b } & { a } \end{array} \right] } { \left[ \begin{array} { l l } { c } & { d } \\ { d } & { c } \end{array} \right] } ) = \phi ( { \left[ \begin{array} { l l } { a c + b d } & { a d + b c } \\ { b c + a d } & { b d + a c } \end{array} \right] } ) =$ $( a c + b d ) - ( a d + b c ) = a ( c - d ) + b ( d - c ) = a ( c - d ) - b ( c - d ) = ( a - b ) ( c - d ) = \phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { b } & { a } \end{array} \right] } ) \phi ( { \left[ \begin{array} { l l } { c } & { d } \\ { d } & { c } \end{array} \right] } )$

(b) The kernel is the set of matrices such that $a - b = 0$ , or $a = b$ . Hence it is the set of matrices of the form $\left[ \begin{array} { l l } { a } & { a } \\ { a } & { a } \end{array} \right]$ where $a \in \mathbb { Z }$

(c) The image of $\phi$ defined as above is $\mathbb { Z }$ . We know this since $\phi ( R ) \subseteq \mathbb { Z }$ , and the matrix with $b = 0$ maps to a for any $a \in \mathbb { Z }$ .

(d) Since Z is an integral domain, the kernel is a prime ideal.

(e) Since Z is not a field, the kernel is not maximal.
:::

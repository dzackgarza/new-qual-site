::: {.problem}
Let $R = \left\{ \begin{bmatrix} a & b \\ b & a \end{bmatrix} \,\st\, a, b \in \ZZ \right\}$, and let $\phi$ be the mapping that takes $\begin{bmatrix} a & b \\ b & a \end{bmatrix}$ to $a - b$.

(a) Show that $\phi$ is a homomorphism.

(b) Determine the kernel of $\phi$.

(c) Show that $R / \operatorname{Ker} \phi$ is isomorphic to $\ZZ$.

(d) Is $\operatorname{Ker} \phi$ a prime ideal?

(e) Is $\operatorname{Ker} \phi$ a maximal ideal?
:::

::: {.solution}

The argument is the card's own. Write $\begin{bmatrix}a&b\\b&a\end{bmatrix}=M(a,b)$; then $M(a,b)M(c,d)=M(ac+bd,\,ad+bc)$.

::: pf

::: {.pf-step #hom}

(a) $\phi(M(a,b))=a-b$ is a ring homomorphism $R\to\ZZ$.

::: pf-proof

$R$ is a subring of $M_{2}(\ZZ)$: $M(a,b)-M(c,d)=M(a-c,b-d)$ and $M(a,b)M(c,d)=M(ac+bd,ad+bc)$ both have the required shape, and $M(1,0)$ is the identity. Additivity: $\phi(M(a,b)+M(c,d))=(a+c)-(b+d)=(a-b)+(c-d)$. Multiplicativity: $\phi(M(a,b)M(c,d))=(ac+bd)-(ad+bc)=a(c-d)-b(c-d)=(a-b)(c-d)=\phi(M(a,b))\phi(M(c,d))$. Also $\phi(M(1,0))=1$.

:::

:::

::: {.pf-step #kernel}

(b) $\ker\phi=\{M(a,a):a\in\ZZ\}$.

::: pf-proof

$\phi(M(a,b))=0$ means $a-b=0$, that is $a=b$; so the kernel consists exactly of the matrices $\begin{bmatrix}a&a\\a&a\end{bmatrix}$.

:::

:::

::: {.pf-step #iso}

(c) $R/\ker\phi\cong\ZZ$.

::: pf-proof

$\phi$ is surjective: given $n\in\ZZ$, $M(0,-n)\in R$ has $\phi(M(0,-n))=0-(-n)=n$. By the first isomorphism theorem for rings, $R/\ker\phi\cong\operatorname{im}\phi=\ZZ$.

:::

:::

::: {.pf-step #prime}

(d) $\ker\phi$ is a prime ideal.

::: pf-proof

An ideal $I$ is prime exactly when $R/I$ is an integral domain. Here $R/\ker\phi\cong\ZZ$, which is a commutative ring without zero divisors, so $I$ is prime.

:::

:::

::: {.pf-step #maximal}

(e) $\ker\phi$ is not a maximal ideal.

::: pf-proof

An ideal $I$ is maximal exactly when $R/I$ is a field. But $R/\ker\phi\cong\ZZ$ is not a field: the class of $2$ is nonzero and has no inverse in $\ZZ$. Equivalently, $\ker\phi$ is properly contained in the ideal $\phi^{-1}(2\ZZ)$, which is proper. So
$$
\boxed{\ker\phi=\{M(a,a)\},\quad R/\ker\phi\cong\ZZ,\quad \ker\phi \text{ prime but not maximal}.}
$$

:::

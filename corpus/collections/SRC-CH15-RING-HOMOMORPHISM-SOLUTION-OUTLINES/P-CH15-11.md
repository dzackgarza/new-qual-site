::: {.problem}
Prove that the intersection of any collection of subfields of a field $F$ is a subfield of $F$.
:::

::: {.solution}
A subfield of $F$ is a subset containing $0$ and $1$ and closed under addition, additive inverses, multiplication and inversion of nonzero elements. Each of these properties is inherited by an intersection, because it is a condition that holds in every member of the family, so the intersection is again a subfield. The argument is this card's own: no retained solution set in the checkout covers this chapter.

::: pf

::: {.pf-step #nonempty}
For any family $\{F_i\}_{i\in I}$ of subfields of $F$, the intersection $\bigcap_{i\in I}F_i$ contains $0$ and $1$.

::: pf-proof
Each $F_i$ contains $0$ and $1$ by the definition of a subfield, so both elements lie in every $F_i$, hence in the intersection. In particular the intersection is nonempty, so it is a subset of $F$ that is a field under the inherited operations rather than a vacuous one; and if $I=\emptyset$ the intersection is all of $F$, which is a subfield of itself.
:::

:::


::: {.pf-step #ring}
$\bigcap_iF_i$ is closed under addition, under additive inverses and under multiplication.

::: pf-proof
Let $a,b\in\bigcap_iF_i$. Then $a,b\in F_i$ for every $i$, and $F_i$ is closed under addition, so $a+b\in F_i$ for every $i$, that is $a+b\in\bigcap_iF_i$; the same argument with $-a$ and with $ab$ in place of $a+b$ shows $-a\in\bigcap_iF_i$ and $ab\in\bigcap_iF_i$, using that each $F_i$ is closed under additive inverses and multiplication. Hence the intersection is a subring of $F$, and it contains $1$ by step [](#nonempty){.pf-ref}.
:::

:::


::: {.pf-step #inverse}
If $a\in\bigcap_iF_i$ and $a\ne0$, then $a^{-1}$ (taken in $F$) lies in $\bigcap_iF_i$.

::: pf-proof
For each $i$ one has $a\in F_i$ and $a\ne0$, and $F_i$ is a subfield of $F$, so the inverse of $a$ in $F_i$ exists and equals $a^{-1}$ computed in the field $F$: the inverse is unique in any field containing $a$. Hence $a^{-1}\in F_i$ for every $i$, which is the claim.
:::

:::


::: {.pf-step #conclusion}
$\bigcap_{i\in I}F_i$ is a subfield of $F$.

::: pf-proof
It is a nonempty subset of $F$ by step [](#nonempty){.pf-ref}, a subring containing $1$ by step [](#ring){.pf-ref}, and it contains the inverse of each of its nonzero elements by step [](#inverse){.pf-ref}. These are exactly the requirements for a subfield, so the intersection is one, for an arbitrary family $\{F_i\}$.
:::

::: {.problem}
Show that if m and n are distinct positive integers, then mZ is not ring isomorphic to $n \mathbb { Z } .$
:::

::: {.solution}
Let m and n be distinct positive integers.
Suppose $\phi : m\mathbb Z \to n\mathbb Z$ is a ring isomorphism. Because a ring isomorphism must take additive generators to additive generators, $\phi(m) = \varepsilon n$ with $\varepsilon = \pm1$. Then $\phi ( m m ) = \phi ( m + m + \cdot \cdot \cdot + m )$ with m copies of m. This is equal to $\phi ( m ) + \cdot \cdot \cdot + \phi ( m ) = m \varepsilon n$. But $\phi ( m m ) = \phi ( m ) \phi ( m ) = n^2$. Hence $n^2 = \varepsilon mn$, so $n = \varepsilon m$, and since both are positive, $n = m$, a contradiction. So there can not be any such isomorphism.
:::

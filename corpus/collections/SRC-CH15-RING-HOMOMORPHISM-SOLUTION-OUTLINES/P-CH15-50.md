::: {.problem}
Show that if m and n are distinct positive integers, then mZ is not ring isomorphic to $n \mathbb { Z } .$
:::

::: {.solution}
Let m and n be distinct positive integers.
Because a ring isomorphism must take generators to generators, m would have to map to ±n. Consider the case of $m \mapsto n$ . Then $\phi ( n n ) = \phi ( n + n + n + \cdot \cdot \cdot + n )$ with n copies of n. This is equal to $\phi ( n ) + \phi ( n ) + \cdot \cdot \cdot + \phi ( n ) =$ $m + m + \cdots + m = n m$ . But $\phi ( n n ) = \phi ( n ) \phi ( n ) = m m$ . Since n and m are distinct, $n m \neq m m$ so there can not be any such isomorphism.
:::

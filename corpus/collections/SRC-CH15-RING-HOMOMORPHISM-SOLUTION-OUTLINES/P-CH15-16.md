::: {.problem}
Let $R = \left\{ \begin{bmatrix} a & b \\ 0 & c \end{bmatrix} \,\st\, a, b, c \in \ZZ \right\}$. Prove or disprove that the mapping $\begin{bmatrix} a & b \\ 0 & c \end{bmatrix} \mapsto a$ is a ring homomorphism.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch15Sltns.pdf`, and entry "# 16" of that outline covers Gallian 7e Chapter 15 Exercise 16. The outline checks addition and multiplication for the diagonal-entry map. Both calculations are checked below, with every entry of the upper-triangular product displayed.

Define $\phi:R\to\ZZ$ by $\phi\!\left(\begin{bmatrix}a&b\\0&c\end{bmatrix}\right)=a$.

::: pf

::: {.pf-step #operations}
The map $\phi$ preserves addition and multiplication.

::: pf-proof

::: {.pf-step #addition}
For arbitrary $A,C\in R$, $\phi(A+C)=\phi(A)+\phi(C)$.

::: pf-proof
Write $A=\begin{bmatrix}a&b\\0&c\end{bmatrix}$ and $C=\begin{bmatrix}d&f\\0&g\end{bmatrix}$ with integer entries. Then
$$
A+C=\begin{bmatrix}a+d&b+f\\0&c+g\end{bmatrix},
$$
so $\phi(A+C)=a+d=\phi(A)+\phi(C)$.
:::

:::

::: {.pf-step #multiplication}
For arbitrary $A,C\in R$, $\phi(AC)=\phi(A)\phi(C)$.

::: pf-proof
With the notation of step [](#addition){.pf-ref},
$$
AC=\begin{bmatrix}ad&af+bg\\0&cg\end{bmatrix}.
$$
The lower-left entry is $0$, so no additional term enters the upper-left entry $ad$. Consequently $\phi(AC)=ad=\phi(A)\phi(C)$.
:::

:::

:::

:::

::: pf-step
$\boxed{\phi:R\to\ZZ\text{ is a ring homomorphism}}$.

::: pf-proof
The map takes values in $\ZZ$ by definition, and step [](#operations){.pf-ref} proves that it preserves both addition and multiplication for arbitrary elements of $R$. These are the defining properties of a ring homomorphism.
:::

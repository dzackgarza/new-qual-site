::: {.problem}
Let $R = \{ { [ \begin{array} { l l } { a } & { b } \\ { 0 } & { c } \end{array} ] } | a , b , c \in \mathbb { Z } \}$ . Prove or disprove that the mapping ${ \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { c } \end{array} \right] } \mapsto a$ is a ring homomorphism.
:::

::: {.solution}
This map is a ring homomorphism.
Addition is preserved because $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { c } \end{array} \right] } + { \left[ \begin{array} { l l } { d } & { f } \\ { 0 } & { g } \end{array} \right] } ) =$ $\phi ( { \left[ \begin{array} { l l } { a + d } & { b + f } \\ { 0 } & { c + g } \end{array} \right] } ) = a + d = \phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { c } \end{array} \right] } ) + \phi ( { \left[ \begin{array} { l l } { d } & { f } \\ { 0 } & { g } \end{array} \right] } )$ . Further, the multiplication is preserved since $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { d } \end{array} \right] } { \left[ \begin{array} { l l } { f } & { g } \\ { 0 } & { i } \end{array} \right] } ) = \phi ( { \left[ \begin{array} { l l } { a f } & { * } \\ { * } & { * } \end{array} \right] } ) = a f = \phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { 0 } & { d } \end{array} \right] } ) \phi ( { \left[ \begin{array} { l l } { f } & { g } \\ { 0 } & { i } \end{array} \right] } )$
:::

::: {.problem}
Determine all ring homomorphisms from $\ZZ_{6}$ to $\ZZ_{6}$. Determine all ring homomorphisms from $\ZZ_{20}$ to $\ZZ_{30}$.
:::

::: {.solution}
The book's own answer is **Gallian, *Contemporary Abstract Algebra* (7th ed.), *Selected Answers*, Chapter 15 Exercise 21, printed p. A22** (`tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`, PDF p. 611): for $\ZZ_{6}$ to $\ZZ_{6}$ the maps $1\mapsto0$, $1\mapsto1$, $1\mapsto3$, $1\mapsto4$; for $\ZZ_{20}$ to $\ZZ_{30}$ the maps $1\mapsto0$, $1\mapsto6$, $1\mapsto15$, $1\mapsto21$. The steps below derive both lists from one criterion. A ring homomorphism here need not carry $1$ to $1$, which is what makes the nonunital maps on the lists legitimate.

::: pf

::: {.pf-step #criterion}
Let $m,n$ be positive integers and $e\in\ZZ_{n}$. The map $\phi_{e}:\ZZ_{m}\to\ZZ_{n}$, $k\mapsto ke$, is a well defined ring homomorphism exactly when $me\equiv0$ and $e^{2}\equiv e$ in $\ZZ_{n}$.

::: pf-proof
Well definedness: $k$ is determined modulo $m$, so $\phi_{e}$ is a function on $\ZZ_{m}$ exactly when $m\equiv0$ implies $me\equiv0$, that is when $me\equiv0$; when this holds, $k\equiv k'$ gives $(k-k')e\equiv0$. Additivity is immediate, $(k+k')e=ke+k'e$. Multiplicativity: $\phi_{e}(kk')=(kk')e$ must equal $(ke)(k'e)=k^{2}e^{2}$ for all $k$, and both sides are functions of $e$ alone when $k=1$, so it holds for all $k$ exactly when $e^{2}\equiv e$. Every ring homomorphism $\ZZ_{m}\to\ZZ_{n}$ has this form with $e=\phi(1)$, because $\phi(k)=\phi(1+\cdots+1)=k\phi(1)$ by additivity.
:::

:::

::: {.pf-step #idempotents-six}
The idempotents of $\ZZ_{6}$ are $0,1,3,4$.

::: pf-proof
Check $e^{2}\equiv e\pmod 6$ for $e=0,\dots,5$: $0^{2}=0$, $1^{2}=1$, $2^{2}=4\ne2$, $3^{2}=9\equiv3$, $4^{2}=16\equiv4$, $5^{2}=25\equiv1\ne5$. So exactly $0,1,3,4$.
:::

:::

::: {.pf-step #six-to-six}
The ring homomorphisms $\ZZ_{6}\to\ZZ_{6}$ are the four maps $1\mapsto0$, $1\mapsto1$, $1\mapsto3$, $1\mapsto4$.

::: pf-proof
Here $m=n=6$, and $6e\equiv0\pmod 6$ holds for every $e$, so by step [](#criterion){.pf-ref} the homomorphisms are exactly the $\phi_{e}$ with $e$ idempotent, that is the four elements of step [](#idempotents-six){.pf-ref}. These are the maps the book's answer lists.
:::

:::

::: {.pf-step #idempotents-thirty}
The idempotents of $\ZZ_{30}$ are $0,1,6,10,15,16,21,25$.

::: pf-proof
Since $30=2\cdot3\cdot5$ with coprime factors, the residue map $e\mapsto(e\bmod2,e\bmod3,e\bmod5)$ is a ring isomorphism $\ZZ_{30}\to\ZZ_{2}\oplus\ZZ_{3}\oplus\ZZ_{5}$. In each of the fields $\ZZ_{2},\ZZ_{3},\ZZ_{5}$ the only idempotents are $0$ and $1$, since $x^{2}=x$ means $x(x-1)=0$ in a field; so $\ZZ_{30}$ has exactly $2^{3}=8$ idempotents, and the eight elements listed are distinct and idempotent: $6^{2}=36\equiv6$, $10^{2}=100\equiv10$, $15^{2}=225\equiv15$, $16^{2}=256\equiv16$, $21^{2}=441\equiv21$, $25^{2}=625\equiv25$, together with $0$ and $1$. Eight distinct idempotents exhaust them.
:::

:::

::: {.pf-step #twenty-to-thirty}
The ring homomorphisms $\ZZ_{20}\to\ZZ_{30}$ are the four maps $1\mapsto0$, $1\mapsto6$, $1\mapsto15$, $1\mapsto21$.

::: pf-proof
By step [](#criterion){.pf-ref} with $m=20$, $n=30$ we need $20e\equiv0\pmod{30}$, which says $30$ divides $20e$, equivalently $3$ divides $2e$, equivalently $3$ divides $e$; and $e$ idempotent. By step [](#idempotents-thirty){.pf-ref} the idempotents are $0,1,6,10,15,16,21,25$, and those divisible by $3$ are $0,6,15,21$. Hence exactly four homomorphisms, as the book's answer lists.
:::

:::

::: {.pf-step #answer}
The homomorphisms are those of steps [](#six-to-six){.pf-ref} and [](#twenty-to-thirty){.pf-ref}: four from $\ZZ_{6}$ to $\ZZ_{6}$ and four from $\ZZ_{20}$ to $\ZZ_{30}$.

::: pf-proof
Each list was obtained as the complete set of maps of the form $\phi_{e}$ satisfying the criterion, and step [](#criterion){.pf-ref} shows every ring homomorphism between cyclic rings arises that way, so no homomorphism is missing from either list. Both lists agree with the book's answers.
:::

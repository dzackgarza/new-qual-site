::: {.problem}
Consider the mapping from $M _ { 2 } ( \mathbb { Z } )$ into Z given by ${ \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } \mapsto a$ . Prove or disprove that this is a ring homomorphism.
:::

::: {.solution}
The map is not a ring homomorphism.
While addition is preserved, multiplication is not.
To see this observe: $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } { \left[ \begin{array} { l l } { f } & { g } \\ { h } & { i } \end{array} \right] } ) = \phi ( { \left[ \begin{array} { l l } { a f + b h } & { * } \\ { * } & { * } \end{array} \right] } ) = a f + b h \neq a f =$ $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } ) \phi ( { \left[ \begin{array} { l l } { f } & { g } \\ { h } & { i } \end{array} \right] } )$
:::

::: {.problem}
Consider the mapping from $M_{2}(\ZZ)$ into $\ZZ$ given by $\begin{bmatrix} a & b \\ c & d \end{bmatrix} \mapsto a$. Prove or disprove that this is a ring homomorphism.
:::

::: {.solution}
The map is not a ring homomorphism.
While addition is preserved, multiplication is not.
For matrices with $bh \neq 0$ (for instance $b = h = 1$): $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } { \left[ \begin{array} { l l } { f } & { g } \\ { h } & { i } \end{array} \right] } ) = \phi ( { \left[ \begin{array} { l l } { a f + b h } & { * } \\ { * } & { * } \end{array} \right] } ) = a f + b h \neq a f =$ $\phi ( { \left[ \begin{array} { l l } { a } & { b } \\ { c } & { d } \end{array} \right] } ) \phi ( { \left[ \begin{array} { l l } { f } & { g } \\ { h } & { i } \end{array} \right] } )$
:::

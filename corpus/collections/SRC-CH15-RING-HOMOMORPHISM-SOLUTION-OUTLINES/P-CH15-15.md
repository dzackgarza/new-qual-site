::: {.problem}
Consider the mapping from $M_{2}(\ZZ)$ into $\ZZ$ given by $\begin{bmatrix} a & b \\ c & d \end{bmatrix} \mapsto a$. Prove or disprove that this is a ring homomorphism.
:::

::: {.solution}
The book's own answer is **Gallian, *Contemporary Abstract Algebra* (7th ed.), *Selected Answers*, Chapter 15 Exercise 15, printed p. A22** (`tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`, PDF p. 611): "Multiplication is not preserved." The steps below prove that with a two-matrix witness and record that addition is preserved. Write $\phi\left(\begin{bmatrix}a&b\\c&d\end{bmatrix}\right)=a$ and $I_{2}$ for the $2\times2$ identity.

::: pf

::: {.pf-step #additive}
$\phi$ preserves addition.

::: pf-proof
For $A=\begin{bmatrix}a&b\\c&d\end{bmatrix}$ and $B=\begin{bmatrix}f&g\\h&i\end{bmatrix}$ the sum is $A+B=\begin{bmatrix}a+f&b+g\\c+h&d+i\end{bmatrix}$, whose displayed entry is $a+f$; so $\phi(A+B)=a+f=\phi(A)+\phi(B)$. Also $\phi$ sends the zero matrix to $0$.
:::

:::

::: {.pf-step #unity}
$\phi(I_{2})=1$.

::: pf-proof
The top-left entry of $\begin{bmatrix}1&0\\0&1\end{bmatrix}$ is $1$. So the failure below is not a failure to carry the identity to the identity.
:::

:::

::: {.pf-step #witness}
$\phi$ does not preserve multiplication.

::: pf-proof
Take $A=\begin{bmatrix}0&1\\0&0\end{bmatrix}$ and $C=\begin{bmatrix}0&0\\1&0\end{bmatrix}$. Then $AC=\begin{bmatrix}0\cdot0+1\cdot1&0\cdot0+1\cdot0\\0\cdot0+0\cdot1&0\cdot0+0\cdot0\end{bmatrix}=\begin{bmatrix}1&0\\0&0\end{bmatrix}$, so $\phi(AC)=1$. But $\phi(A)=0$ and $\phi(C)=0$, so $\phi(A)\phi(C)=0\ne1$.
:::

:::

::: {.pf-step #answer}
The map is not a ring homomorphism.

::: pf-proof
A ring homomorphism must preserve both operations. Step [](#witness){.pf-ref} exhibits matrices $A,C$ with $\phi(AC)\ne\phi(A)\phi(C)$, so multiplication is not preserved, and the map is therefore not a ring homomorphism; the statement is disproved rather than proved. Step [](#additive){.pf-ref} shows the map is nevertheless a homomorphism of the additive groups, and step [](#unity){.pf-ref} that it carries $I_{2}$ to $1$, so the obstruction is exactly multiplicative.
:::

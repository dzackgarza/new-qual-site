::: {.problem}
Is the mapping from $\ZZ_{5}$ to $\ZZ_{30}$ given by $x \mapsto 6x$ a ring homomorphism?
Note that the image of the unity is the unity of the image but not the unity of $\ZZ_{30}$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's `provenance` is the textbook's Google Books record and no solutions sheet is retained, so the argument below is the card's own, structured from the outline already on the card.

::: pf

::: {.pf-step #welldefined}
$\varphi$ is well defined.

::: pf-proof
If $x \equiv x' \pmod 5$ then $5$ divides $x - x'$, so $30 = 6\cdot 5$ divides $6(x-x') = 6x - 6x'$, that is $6x \equiv 6x' \pmod{30}$; the value does not depend on the representative.

:::

:::

::: {.pf-step #additive}
$\varphi(x+y) = \varphi(x) + \varphi(y)$ for all $x, y \in \ZZ_{5}$.

::: pf-proof
$6(x+y) = 6x + 6y$ as integers, so the two sides agree modulo $30$; the addition on the left is in $\ZZ_{5}$, and reduction modulo $5$ followed by the well-defined map of step [](#welldefined){.pf-ref} is the same as computing $6(x+y)$ modulo $30$.

:::

:::

::: {.pf-step #multiplicative}
$\varphi(xy) = \varphi(x)\varphi(y)$ for all $x, y \in \ZZ_{5}$.

::: pf-proof
$\varphi(x)\varphi(y) = (6x)(6y) = 36xy$, and $36xy - 6xy = 30xy$ is divisible by $30$, so $36xy \equiv 6xy = \varphi(xy) \pmod{30}$.

:::

:::

::: {.pf-step #unity}
$\varphi$ carries the unity $1$ of $\ZZ_{5}$ to $6$, which is the unity of the image $6\ZZ_{30} = \theset{0,6,12,18,24}$ but not the unity $1$ of $\ZZ_{30}$.

::: pf-proof
$\varphi(1) = 6$. Since $6\cdot 6 = 36 \equiv 6 \pmod{30}$, the element $6$ is idempotent, so it is the identity of the subring $6\ZZ_{30} = \theset{0,6,12,18,24}$, which is the image of $\varphi$ by step [](#generated){.pf-ref}; and $6 \ne 1$ in $\ZZ_{30}$. The image is a copy of $\ZZ_{5}$, an isomorphism being $6k \mapsto k$.

:::

:::

::: {.pf-step #generated}
The image of $\varphi$ is $\theset{0,6,12,18,24}$.

::: pf-proof
As $x$ runs over $0,1,2,3,4$ the values $6x$ are $0,6,12,18,24$ modulo $30$.

:::

:::

::: pf-step
Yes: $\varphi$ is a ring homomorphism, though not a homomorphism of rings with unity.

::: pf-proof
Steps [](#additive){.pf-ref} and [](#multiplicative){.pf-ref} are the two homomorphism laws, and step [](#welldefined){.pf-ref} makes $\varphi$ a map on $\ZZ_{5}$ at all. Step [](#unity){.pf-ref} is the sense in which the convention matters: under the convention that a ring homomorphism must send $1$ to $1$ the answer is no, and under the convention used here, which asks only for the two laws, it is yes. The exercise's own note is exactly this observation.

:::

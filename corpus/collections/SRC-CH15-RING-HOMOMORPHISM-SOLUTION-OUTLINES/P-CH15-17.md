::: {.problem}
Is the mapping from $\mathbb { Z } _ { 5 }$ to $\mathbb { Z } _ { 3 0 }$ given by $x \mapsto 6 x$ a ring homomorphism?
Note that the image of the unity is the unity of the image but not the unity of $\mathbb { Z } _ { 3 0 }$ .
:::

::: {.solution}
The mapping is a ring homomorphism.
Addition is straightforward to show since $\phi ( x + y ) =$ $6 ( x + y ) = 6 x + 6 y = \phi ( x ) + \phi ( y )$ . For multiplication, $\phi ( x y ) = 6 x y$ and $\phi ( x ) \phi ( y ) = 6 x \cdot 6 y = 36 x y = 6 x y$ . Thus multiplication is preserved.
:::

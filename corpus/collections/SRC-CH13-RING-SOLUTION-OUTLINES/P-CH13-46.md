::: {.problem}
Suppose that $a$ and $b$ belong to a commutative ring and $ab$ is a zero-divisor. Show that either $a$ or $b$ is a zero-divisor.
:::

::: {.solution}

The argument is the card's own: the annihilator of $ab$ is annihilated by $a$ times an annihilator of $b$, so one of the two factors must be a zero-divisor.

::: pf

::: {.pf-step #nonzero}

$ab\ne0$, hence $a\ne0$ and $b\ne0$.

::: pf-proof

A zero-divisor is by definition a nonzero element that annihilates some nonzero element, so the hypothesis that $ab$ is a zero-divisor includes $ab\ne0$. If $a=0$ or $b=0$ then $ab=0$, so both are nonzero.

:::

:::

::: {.pf-step #annihilator}

There is $c\ne0$ with $(ab)c=0$, and then $a(bc)=0$.

::: pf-proof

$ab$ being a zero-divisor means $abc=0$ for some nonzero $c$. Multiplication in the ring is commutative, so $abc=a(bc)$ as well.

:::

:::

::: {.pf-step #dichotomy}

Either $a$ is a zero-divisor, or $b$ is a zero-divisor.

::: pf-proof

If $a$ is a zero-divisor there is nothing to prove. Otherwise $a$ is not a zero-divisor, so $ax=0$ forces $x=0$ for every $x$; applying this to $x=bc$ in step [](#annihilator){.pf-ref} gives $bc=0$. Since $c\ne0$ and by step [](#nonzero){.pf-ref} $b\ne0$, this says exactly that $b$ is a zero-divisor:
$$
\boxed{ab\ \text{a zero-divisor}\implies a\ \text{or}\ b\ \text{is a zero-divisor}.}
$$

:::

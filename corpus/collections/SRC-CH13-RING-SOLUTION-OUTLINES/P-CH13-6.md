::: {.problem}
Find a nonzero element in a ring that is neither a zero-divisor nor a unit.
:::

::: {.solution}

The element is $x$ in $\ZZ[x]$.

::: pf

::: {.pf-step #nonzero}

$x$ is a nonzero element of the ring $\ZZ[x]$.

::: pf-proof

$\ZZ[x]$ is a ring under the usual addition and multiplication of polynomials,
and $x$ is the polynomial with $a_{1}=1$ and all other coefficients $0$, so it
is not the zero polynomial.

:::

:::

::: {.pf-step #not-zero-divisor}

$x$ is not a zero-divisor.

::: pf-proof

Since $\ZZ$ is an integral domain, $\ZZ[x]$ is an integral domain and
$\deg(fg)=\deg f+\deg g$ for nonzero $f,g$. If $xf=0$ with $f\neq 0$, then
$\deg(xf)=\deg x+\deg f=1+\deg f\ge 1$, so $xf$ is not the zero polynomial,
contradiction. The same holds for $fx=0$ since $\ZZ[x]$ is commutative. So $x$
times a nonzero polynomial is never zero.

:::

:::

::: {.pf-step #not-unit}

$x$ is not a unit.

::: pf-proof

If $xg=1$ for some $g\in \ZZ[x]$, then $g\neq 0$ and the degree rule gives
$1+\deg g=\deg(xg)=\deg 1=0$, which is impossible for $\deg g\ge 0$. So no such
$g$ exists and $x$ has no multiplicative inverse.

:::

:::

::: {.pf-step #conclusion}

$x\neq 0$ is neither a zero-divisor nor a unit, as required.

::: pf-proof

Steps [](#nonzero){.pf-ref}, [](#not-zero-divisor){.pf-ref} and
[](#not-unit){.pf-ref} establish the three properties. An integral domain has no
such element — there every nonzero element is a unit or a zero-divisor only
after adding finiteness — so an example needs an infinite ring, and $\ZZ[x]$
supplies one.

:::

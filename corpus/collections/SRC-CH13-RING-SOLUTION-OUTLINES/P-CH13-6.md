::: {.problem}
Find a nonzero element in a ring that is neither a zero-divisor nor a unit.
:::

::: {.solution}
Consider the polynomial ring $\mathbb { Z } [ x ]$ . Then $x \in \mathbb { Z } [ x ]$ but it is not a zero divisor and it is not a unit.
:::

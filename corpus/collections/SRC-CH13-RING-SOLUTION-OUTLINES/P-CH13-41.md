::: {.problem}
If a is an idempotent in a commutative ring, show that $1 - a$ is also an idempotent.
:::

::: {.solution}
Let a be an idempotent in a commutative ring.
Then $a ^ { 2 } = a$ . Hence, $( 1 - a ) ^ { 2 } =$ $1 - 2 a + a ^ { 2 } = 1 - 2 a + a = 1 - a$ . So $1 - a$ is also an idempotent.
:::

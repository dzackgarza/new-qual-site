::: {.problem}
If $a$ is an idempotent in a commutative ring, show that $1 - a$ is also an idempotent.
:::

::: {.solution}
The argument is the one carried by this collection's retained solution outline for the outline's Chapter 13 Exercise 41 (Gallian, *Contemporary Abstract Algebra*, student solutions manual). The seventh edition prints the same exercise as **Chapter 13 Exercise 37 on p. 257**, and the book is retained in this repository as `tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`, so the page is available and is named here; the outline's number and the book's name one exercise. It is re-derived here step by step and checked.

::: pf

::: {.pf-step #idempotent}
$a^2=a$.

::: pf-proof
That is the hypothesis: $a$ is idempotent.
:::

:::

::: {.pf-step #expansion}
$(1-a)^2=1-2a+a^2$.

::: pf-proof
Expanding in the ring, $(1-a)^2=1-a-a+a^2=1-(a+a)+a^2$, and $a+a$ is written $2a$; no commutativity is used, only distributivity and the meaning of subtraction.
:::

:::

::: {.pf-step}
$(1-a)^2=1-a$, so $1-a$ is idempotent.

::: pf-proof
Substituting step [](#idempotent){.pf-ref} into step [](#expansion){.pf-ref}, $(1-a)^2=1-2a+a=1-a-a+a=1-a$. That is the defining equation of an idempotent for the element $1-a$, so $1-a$ is idempotent.
:::

::: {.problem}
Describe all zero-divisors and units of $\ZZ \oplus \QQ \oplus \ZZ$.
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $R=\ZZ\oplus\QQ\oplus\ZZ$, a commutative ring with $1=(1,1,1)$ and coordinatewise operations.

::: pf

::: {.pf-step #zero_divisors}
An element $(a,b,c)\ne(0,0,0)$ is a zero divisor exactly when at least one of $a,b,c$ is $0$.

::: pf-proof
If, say, $a=0$ and $(a,b,c)\ne0$, then $x=(1,0,0)\ne0$ and $(a,b,c)x=(0,0,0)$, so the element is a zero divisor; the same witness pattern works for a zero in another coordinate, using $(0,1,0)$ or $(0,0,1)$. Conversely, suppose none of $a,b,c$ is zero and $(a,b,c)(x,y,z)=(0,0,0)$; then $ax=0$ in $\ZZ$, $by=0$ in $\QQ$ and $cz=0$ in $\ZZ$. Each of these rings is an integral domain and $a,b,c\ne0$, so $x=y=z=0$. Thus the only annihilating element is $0$ and $(a,b,c)$ is not a zero divisor.
:::

:::

::: {.pf-step #units}
$(a,b,c)$ is a unit of $R$ exactly when $a=\pm1$, $c=\pm1$ and $b\ne0$.

::: pf-proof
If $(a,b,c)(x,y,z)=(1,1,1)$ then $ax=1$ in $\ZZ$, so $a=\pm1$ with $x=a$; $by=1$ in $\QQ$, so $b\ne0$ with $y=1/b$; $cz=1$ in $\ZZ$, so $c=\pm1$. Conversely, if $a=\pm1$, $c=\pm1$ and $b\ne0$, then $(a,b,c)(a,1/b,c)=(1,1,1)$ because $a^2=1=c^2$, so the element has an inverse. Hence the units are exactly the triples $(\pm1,b,\pm1)$ with $b\in\QQ\setminus\{0\}$.
:::

:::

::: {.pf-step}
The zero divisors of $\ZZ\oplus\QQ\oplus\ZZ$ are the nonzero triples with a zero coordinate, and its units are the triples $(\pm1,b,\pm1)$ with $b\ne0$.

::: pf-proof
Steps [](#zero_divisors){.pf-ref} and [](#units){.pf-ref} give the two descriptions, which answer the question. Notice that the units form a proper subgroup of the elements with no zero coordinate: $(1,2,1)$ has none of its coordinates zero, yet it is not a unit because $2$ is not a unit of $\ZZ$.
:::

::: {.problem}
Let $G$ be a group.
An automorphism $\phi: G \rightarrow G$ is called *inner* if the automorphism is given by conjugation by a fixed group element $g$, i.e.,
\[
\phi=\phi_{g}: h \mapsto g h g^{-1} .
\]

a. Prove that the set of inner automorphisms forms a normal subgroup of the group of all automorphisms of $G$.

b. Give an example of a finite group with an automorphism which is not inner.

c. Denote by $S_{n}$ the group of permutations of the set $\{1, \ldots, n\}$.
Suppose that $g \in S_{n}$ sends $i$ to $g_{i}$ for $i=1, \ldots, n .$ Let $(a, b)$ denote as usual the cycle notation for the transposition which permutes $a$ and $b$.
For $i \in\{1, \ldots, n-1\}$, compute $\phi_{g}((i, i+1))$.

d. Suppose that an automorphism $\phi \in \operatorname{Aut}\left(S_{n}\right)$ preserves cycle type, i.e., that for every element $s$ of $S_{n}, s$ and $\phi(s)$ have the same cycle type.
Show that $\phi$ is inner.

> Hint: Consider the images of generators $\phi((1,2)), \phi((2,3)), \cdots, \phi((n-1, n))$.
:::

::: {.solution}
**Part (a).**

::: pf

::: {.pf-step #inn-hom-definition}
The set of inner automorphisms is $\operatorname{Inn}(G) = \{\phi_g : g \in G\}$, and the map $g \mapsto \phi_g$ is a homomorphism $G \to \operatorname{Aut}(G)$ with kernel $Z(G)$.

::: pf-proof
$\phi_g \circ \phi_h = \phi_{gh}$ and $\phi_g = \id$ iff $g \in Z(G)$.
:::

:::

::: pf-step
Hence $\operatorname{Inn}(G) \cong G/Z(G)$ is a subgroup of $\operatorname{Aut}(G)$.

::: pf-proof
Step [](#inn-hom-definition){.pf-ref} (image of a homomorphism).
:::

:::

::: {.pf-step #inn-normal-in-aut}
$\operatorname{Inn}(G)$ is normal in $\operatorname{Aut}(G)$.

::: pf-proof
for $\psi \in \operatorname{Aut}(G)$ and $\phi_g \in \operatorname{Inn}(G)$, $\psi \circ \phi_g \circ \psi^{-1} = \phi_{\psi(g)}$ (since $\psi(g h g^{-1}) = \psi(g)\psi(h)\psi(g)^{-1}$), which is inner.
:::

:::

:::

**Part (b).**

::: pf

::: pf-step
Take $G = \ZZ/3$ (cyclic of order $3$).

::: pf-proof
choose a finite group.
:::

:::

::: {.pf-step #z3-trivial-inner}
$\operatorname{Aut}(\ZZ/3) \cong \ZZ/2$ (generated by $x \mapsto x^{-1}$), but $\operatorname{Inn}(\ZZ/3) = 1$ (since $\ZZ/3$ is abelian, all inner automorphisms are trivial).

::: pf-proof
an abelian group has trivial inner automorphism group.
:::

:::

::: {.pf-step #nontrivial-auto-not-inner}
Hence the nontrivial automorphism $x \mapsto x^{-1}$ is not inner.

::: pf-proof
Step [](#z3-trivial-inner){.pf-ref}.
:::

:::

:::

**Part (c).**

::: pf

::: {.pf-step #phi-g-transposition-formula}
$\phi_g((i, i+1)) = (g_i, g_{i+1})$.

::: pf-proof
conjugation of a transposition: $g (i, i+1) g^{-1} = (g(i), g(i+1)) = (g_i, g_{i+1})$.
:::

:::

:::

**Part (d).**

::: pf

::: {.pf-step #phi-preserves-transpositions}
Since $\phi$ preserves cycle type, $\phi((i, i+1))$ is a transposition for each $i$.

::: pf-proof
$(i, i+1)$ is a transposition, and $\phi$ preserves cycle type.
:::

:::

::: pf-step
Write $\phi((1,2)) = (a_1, a_2)$.

::: pf-proof
Step [](#phi-preserves-transpositions){.pf-ref}.
:::

:::

::: {.pf-step #adjacent-transpositions-preserved}
Since $(1,2)$ and $(2,3)$ are adjacent transpositions (their product has order $3$), $\phi((1,2))$ and $\phi((2,3))$ are transpositions whose product has order $3$, so they are adjacent transpositions.

::: pf-proof
$\phi$ preserves the order of products (it is a homomorphism), and two transpositions have product of order $3$ iff they are adjacent (share exactly one point).
:::

:::

::: pf-step
Hence $\phi((2,3)) = (a_2, a_3)$ for some $a_3$ (sharing the point $a_2$ with $(a_1, a_2)$).

::: pf-proof
Step [](#adjacent-transpositions-preserved){.pf-ref}.
:::

:::

::: {.pf-step #inductive-chain-a-sequence}
Inductively, $\phi((i, i+1)) = (a_i, a_{i+1})$ for a sequence $a_1, \ldots, a_n$ of distinct points.

::: pf-proof
each consecutive pair of transpositions is adjacent, so they share exactly one point, giving a chain $a_1, a_2, \ldots, a_n$.
:::

:::

::: pf-step
The $a_1, \ldots, a_n$ are all distinct (they are the $n$ points of $\{1, \ldots, n\}$).

::: pf-proof
the transpositions $(a_i, a_{i+1})$ generate $S_n$, so the $a_i$ must be all $n$ points.
:::

:::

::: {.pf-step #define-g-from-sequence}
Let $g \in S_n$ be the permutation with $g(i) = a_i$.

::: pf-proof
define $g$.
:::

:::

::: {.pf-step #phi-equals-phi-g-on-generators}
Then $\phi((i, i+1)) = (a_i, a_{i+1}) = (g(i), g(i+1)) = \phi_g((i, i+1))$ for all $i$.

::: pf-proof
Step [](#inductive-chain-a-sequence){.pf-ref}, step [](#define-g-from-sequence){.pf-ref}, and step [](#phi-g-transposition-formula){.pf-ref} (part (c)).
:::

:::

::: {.pf-step #phi-is-inner}
Since the adjacent transpositions $(i, i+1)$ generate $S_n$, $\phi = \phi_g$ is inner.

::: pf-proof
Step [](#phi-equals-phi-g-on-generators){.pf-ref} and the fact that the adjacent transpositions generate $S_n$.
:::

:::

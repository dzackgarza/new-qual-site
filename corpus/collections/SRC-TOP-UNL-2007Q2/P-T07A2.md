::: {.problem}
A space $(X,\mathcal{T})$ is called *locally path-connected* if, for every $x \in X$, every neighborhood of $x$ contains a path-connected neighborhood of $x$.
Show that a connected, locally path-connected space is path-connected.
:::

::: {.solution}
<1>1. Definition of the path component $P$:
<2>1. If $X = \emptyset$, it is vacuously path-connected.
Otherwise, fix $x_0 \in X$ and let $P$ be the path component of $x_0$:
\[
P = \{x \in X \mid \exists \text{ a continuous path from } x_0 \text{ to } x \text{ in } X\}.
\]
Proof: definition of path component.
<2>2. $P$ is non-empty because the constant path at $x_0$ shows $x_0 \in P$.
Proof: constant path is continuous.

<1>2. Proof that every path component is open:
<2>1. Let $x \in P$.
Since $X$ is locally path-connected, there exists an open neighborhood $U$ of $x$ that is path-connected.
Proof: definition of local path-connectedness.
<2>2. For any $y \in U$, there is a continuous path $\gamma_1: [0, 1] \to U$ from $x$ to $y$.
Since $x \in P$, there is a continuous path $\gamma_0: [0, 1] \to X$ from $x_0$ to $x$.
Proof: path-connectedness of $U$ and $x \in P$.
<2>3. The concatenated path $\gamma_0 * \gamma_1: [0, 1] \to X$ is a continuous path from $x_0$ to $y$.
Thus $y \in P$, so $U \subseteq P$.
Therefore $P$ is an open subset of $X$.
Proof: concatenation of paths.

<1>3. Proof that $P$ is closed:
<2>1. The complement of $P$ in $X$ is the union of all other path components $\{P_\alpha\}_{\alpha \in A}$:
\[
X \setminus P = \bigcup_{\alpha \in A} P_\alpha.
\]
Proof: path components form a partition of $X$.
<2>2. By the same argument as in <1>2, every other path component $P_\alpha$ is an open subset of $X$.
Proof: <1>2 applied to each $P_\alpha$.
<2>3. Because the union of open sets is open, $X \setminus P$ is open, which implies $P$ is closed in $X$.
Proof: complement of an open set is closed.

<1>4. Connectedness and conclusion:
<2>1. $P$ is a non-empty, open, and closed (clopen) subset of $X$.
Since $X$ is connected, its only non-empty clopen subset is $X$ itself, so $P = X$.
Proof: definition of connectedness.
<2>2. Since $P = X$, every point in $X$ can be connected by a continuous path to $x_0$, so $X$ is path-connected.
Proof: definition of path-connectedness.

<1>5. Conclusion:
Every connected, locally path-connected topological space is path-connected. Q.E.D.
Proof: <1>1 through <1>4.
:::

::: {.problem}
Show that a linear functional $\varphi$ on a Banach space $X$ is continuous if and only if $\{x\in X:\varphi(2x)=3\}$ is norm closed.
:::

::: {.solution}
Set
\[
A=\{x\in X:\varphi(2x)=3\}
=\left\{x\in X:\varphi(x)=\frac32\right\}.
\]

<1>1. If $\varphi$ is continuous, then $A$ is closed.
::: {.proof}
The map
\[
x\longmapsto\varphi(2x)=2\varphi(x)
\]
is continuous.
Since $\{3\}$ is closed in the scalar field,
\[
A=(2\varphi)^{-1}(\{3\})
\]
is closed in $X$.
:::

<1>2. Suppose $A$ is closed.
If $\varphi=0$, then $\varphi$ is continuous.
::: {.proof}
The zero functional is bounded, hence continuous.
In this case $A=\varnothing$, which is indeed closed.
:::

<1>3. Suppose $A$ is closed and $\varphi\ne0$.
Then $\ker\varphi$ is closed.
::: {.proof}
Because $\varphi\ne0$, choose $u\in X$ with $\varphi(u)\ne0$ and set
\[
a=\frac{3}{2\varphi(u)}u.
\]
Then
\[
\varphi(a)=\frac32,
\]
so $a\in A$.

We claim
\[
A=a+\ker\varphi.
\]
Indeed, if $z\in\ker\varphi$, then
\[
\varphi(a+z)=\varphi(a)+\varphi(z)=\frac32,
\]
so $a+z\in A$.
Conversely, if $x\in A$, then
\[
\varphi(x-a)=\varphi(x)-\varphi(a)=0,
\]
so $x-a\in\ker\varphi$ and therefore $x\in a+\ker\varphi$.

Hence
\[
\ker\varphi=A-a.
\]
Translation by $-a$ is a homeomorphism of $X$, so the closedness of $A$ implies that $\ker\varphi$ is closed.
:::

<1>4. If $\ker\varphi$ is closed, then $\varphi$ is continuous.
::: {.proof}
For a linear functional on a normed space, continuity is equivalent to closedness of its kernel.
For completeness, because $\varphi\ne0$, the quotient
\[
X/\ker\varphi
\]
is one-dimensional.
Since $\ker\varphi$ is closed, the quotient carries its norm, and the quotient map
\[
\pi:X\to X/\ker\varphi
\]
is continuous.
The induced linear map
\[
\widetilde\varphi:X/\ker\varphi\to\mathbb F,
\qquad
\widetilde\varphi(x+\ker\varphi)=\varphi(x),
\]
is well defined.
Every linear map between finite-dimensional normed spaces is continuous, so $\widetilde\varphi$ is continuous.
Finally,
\[
\varphi=\widetilde\varphi\circ\pi,
\]
hence $\varphi$ is continuous.
:::

Combining <1>1--<1>4 proves the equivalence.
:::

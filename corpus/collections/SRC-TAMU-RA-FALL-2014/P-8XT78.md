::: {.problem}
(a) State the Riesz Representation Theorem for the dual $L_p^*(\mu)$ of $L_p(\mu)$, $1\le p<\infty$.

(b) Let $\mu$ be a finite measure on the measurable space $(\Omega,\Sigma)$.
Prove the following part of the proof of the above Theorem: If $F\in L_p^*(\mu)$, then there exists an $h\in L^1(\mu)$ so that $$F(\chi_A)=\int_A h\,d\mu\qquad\text{for all }A\in\Sigma.$$
:::

::: {.solution}
Let $q$ be the conjugate exponent to $p$, so
\[
\frac1p+\frac1q=1,
\]
with $q=\infty$ when $p=1$.

<1>1. On a finite measure space, the Riesz representation theorem identifies $(L^p(\mu))^*$ isometrically with $L^q(\mu)$.
::: {.proof}
For every $h\in L^q(\mu)$, define
\[
F_h(f)=\int_\Omega f h\,d\mu,
\qquad f\in L^p(\mu).
\]
Then $F_h\in(L^p(\mu))^*$, every bounded linear functional on $L^p(\mu)$ is of this form for a unique $h\in L^q(\mu)$ up to equality almost everywhere, and
\[
\|F_h\|=\|h\|_q.
\]
For the present problem only the existence step below is required.
:::

<1>2. Define a set function $\nu$ on $\Sigma$ by
\[
\nu(A)=F(\chi_A).
\]
Then $\nu$ is well defined and finitely additive.
::: {.proof}
Because $\mu(\Omega)<\infty$, every indicator $\chi_A$ belongs to $L^p(\mu)$ and
\[
\|\chi_A\|_p=\mu(A)^{1/p}.
\]
Thus $F(\chi_A)$ is defined for every $A\in\Sigma$.

Also
\[
\nu(\varnothing)=F(0)=0.
\]
If $A,B\in\Sigma$ are disjoint, then
\[
\chi_{A\cup B}=\chi_A+\chi_B,
\]
so linearity of $F$ gives
\[
\nu(A\cup B)=\nu(A)+\nu(B).
\]
:::

<1>3. $\nu$ is countably additive.
::: {.proof}
Let $E_1,E_2,\ldots$ be pairwise disjoint measurable sets and put
\[
E=\bigcup_{i=1}^\infty E_i.
\]
For each $n$,
\[
\chi_E-\sum_{i=1}^n\chi_{E_i}
=
\chi_{\bigcup_{i>n}E_i}.
\]
Hence
\[
\begin{aligned}
\left|\nu(E)-\sum_{i=1}^n\nu(E_i)\right|
&=
\left|F\left(\chi_E-\sum_{i=1}^n\chi_{E_i}\right)\right|\\
&\le
\|F\|\left\|\chi_{\bigcup_{i>n}E_i}\right\|_p\\
&=
\|F\|\,\mu\left(\bigcup_{i>n}E_i\right)^{1/p}.
\end{aligned}
\]
Because the $E_i$ are disjoint and $\mu(E)\le\mu(\Omega)<\infty$,
\[
\mu\left(\bigcup_{i>n}E_i\right)
=
\mu(E)-\sum_{i=1}^n\mu(E_i)
\longrightarrow0.
\]
Therefore
\[
\nu(E)=\sum_{i=1}^\infty\nu(E_i).
\]
Thus $\nu$ is a finite signed measure.
:::

<1>4. $\nu$ is absolutely continuous with respect to $\mu$.
::: {.proof}
If $\mu(A)=0$, then $\chi_A=0$ in $L^p(\mu)$, and equivalently
\[
\|\chi_A\|_p=\mu(A)^{1/p}=0.
\]
Hence
\[
|\nu(A)|
=|F(\chi_A)|
\le
\|F\|\,\|\chi_A\|_p
=0.
\]
Therefore $\nu(A)=0$, so
\[
\nu\ll\mu.
\]
:::

<1>5. Apply the Radon--Nikodym theorem.
::: {.proof}
Since $\nu$ is a finite signed measure and $\nu\ll\mu$, while $\mu$ is finite and therefore $\sigma$-finite, the Radon--Nikodym theorem yields an $h\in L^1(\mu)$ such that
\[
\nu(A)=\int_A h\,d\mu
\qquad\text{for every }A\in\Sigma.
\]
By the definition of $\nu$,
\[
F(\chi_A)
=\nu(A)
=\int_A h\,d\mu
\qquad\text{for every }A\in\Sigma,
\]
which is the required conclusion.
:::

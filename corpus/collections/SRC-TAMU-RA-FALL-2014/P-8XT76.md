::: {.problem}
Let $(f_n)$ be a sequence of continuous functions on $[0,1]$ such that for each $x\in[0,1]$ there is an $N=N_x$ so that $$f_n(x)\ge 0\quad\text{for all }n\ge N_x.$$ Show that there is an open nonempty set $U\subset[0,1]$ and an $N\in\mathbb{N}$ so that $f_n(x)\ge 0$ for all $n\ge N$ and all $x\in U$.
:::

::: {.solution}
For each $N\in\mathbb N$, define
\[
E_N
=
\bigcap_{n\ge N}\{x\in[0,1]: f_n(x)\ge0\}.
\]

<1>1. Each $E_N$ is closed in $[0,1]$.
::: {.proof}
For fixed $n$, continuity of $f_n$ gives
\[
\{x\in[0,1]:f_n(x)\ge0\}
=f_n^{-1}([0,\infty)),
\]
which is closed in $[0,1]$.
An arbitrary intersection of closed sets is closed, hence $E_N$ is closed.
:::

<1>2. The sets $E_N$ cover $[0,1]$.
::: {.proof}
Fix $x\in[0,1]$.
By hypothesis there is an integer $N_x$ such that
\[
f_n(x)\ge0
\qquad\text{for every }n\ge N_x.
\]
Therefore
\[
x\in E_{N_x}.
\]
Since $x$ was arbitrary,
\[
[0,1]=\bigcup_{N=1}^\infty E_N.
\]
:::

<1>3. Some $E_N$ has nonempty interior in $[0,1]$.
::: {.proof}
With the usual metric, $[0,1]$ is complete.
Hence it is a Baire space.
If every closed set $E_N$ had empty interior, then every $E_N$ would be nowhere dense, and <1>2 would express the nonempty Baire space $[0,1]$ as a countable union of nowhere-dense sets, a contradiction.

Thus there is some $N$ for which
\[
U:=\operatorname{int}_{[0,1]}(E_N)
\]
is nonempty.
:::

<1>4. This $U$ and $N$ have the required property.
::: {.proof}
Since $U\subseteq E_N$, every $x\in U$ belongs to
\[
\{x\in[0,1]:f_n(x)\ge0\}
\]
for every $n\ge N$.
Equivalently,
\[
f_n(x)\ge0
\qquad
(x\in U,\ n\ge N).
\]
By <1>3, $U$ is open in $[0,1]$ and nonempty, as required.
:::
:::

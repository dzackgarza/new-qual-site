::: {.problem}
Let $f$ be Lebesgue measurable on $[0,1]$ with $f(x)>0$ a.e. Suppose $(E_k)$ is a sequence of measurable sets in $[0,1]$ with the property that $\int_{E_k}f(x)\,dx\to 0$ as $k\to\infty$.
Prove that $m(E_k)\to 0$ as $k\to\infty$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Suppose $m(E_k) \not\to 0$; then for some $\varepsilon>0$ and subsequence, $m(E_k) \ge \varepsilon$.

::: pf-proof

negation.

:::

:::

::: {.pf-step #s2}

For $\delta>0$ let $F_\delta = \{x : f(x) > \delta\}$; since $f>0$ a.e., $\bigcup_{\delta>0}F_\delta$ has full measure, so choose $\delta$ with $m([0,1]\setminus F_\delta) < \varepsilon/2$.

::: pf-proof

$f>0$ a.e.

:::

:::

::: {.pf-step #s3}

Then $m(E_k) \le m(E_k\cap F_\delta) + \varepsilon/2$, so $m(E_k\cap F_\delta) \ge \varepsilon/2$.

::: pf-proof

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref}.

:::

:::

::: {.pf-step #s4}

On $F_\delta$, $f \ge \delta$, so $\int_{E_k} f \ge \int_{E_k\cap F_\delta} f \ge \delta\, m(E_k\cap F_\delta) \ge \delta\varepsilon/2 >0$.

::: pf-proof

Step [](#s3){.pf-ref}.

:::

:::

::: {.pf-step #s5}

This contradicts $\int_{E_k} f \to 0$.

::: pf-proof

Step [](#s4){.pf-ref}.

:::

:::

::: {.pf-step #s6}

Hence $m(E_k) \to 0$.

::: pf-proof

Step [](#s5){.pf-ref}.

:::

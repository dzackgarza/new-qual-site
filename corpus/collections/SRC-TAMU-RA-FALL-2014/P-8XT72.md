::: {.problem}
For $n\in\mathbb{N}$, let $f_n:[0,1]\to\mathbb{R}$ be continuous, and assume that for every $x\in[0,1]$ the sequence $(f_n(x))$ is decreasing.
Suppose that $f_n$ converges pointwise to a continuous function $f$.
Show that this convergence is uniform.
:::

::: {.solution}

::: pf

::: pf-step

Let $g_n = f_n - f$; then $g_n$ is continuous, $g_n \ge 0$, and $g_n \downarrow 0$ pointwise.

::: pf-proof

$f_n \downarrow f$ pointwise, so $g_n = f_n - f \ge 0$ and $g_n \downarrow 0$.

:::

:::

::: pf-step

It suffices to show $g_n \to 0$ uniformly.

::: pf-proof

uniform convergence of $f_n$ to $f$ is equivalent to uniform convergence of $g_n$ to $0$.

:::

:::

::: {.pf-step #s3}

Suppose for contradiction that $g_n$ does not converge uniformly to $0$.

::: pf-proof

assume the contrary.

:::

:::

::: {.pf-step #s4}

Then there is $\epsilon > 0$ and a sequence $x_{n_k}$ with $g_{n_k}(x_{n_k}) \ge \epsilon$.

::: pf-proof

negation of uniform convergence.

:::

:::

::: {.pf-step #s5}

Since $[0,1]$ is compact, $\{x_{n_k}\}$ has a convergent subsequence $x_{n_k} \to x_0 \in [0,1]$.

::: pf-proof

Bolzano–Weierstrass.

:::

:::

::: {.pf-step #s6}

For any fixed $m$, since $g_n \downarrow 0$ pointwise and $g_{n_k} \ge g_m$ for $n_k \ge m$ (monotone decreasing), we have $g_m(x_{n_k}) \ge g_{n_k}(x_{n_k}) \ge \epsilon$ for all $n_k \ge m$.

::: pf-proof

the sequence $g_n$ is decreasing pointwise, so $g_m \ge g_{n_k}$ when $m \le n_k$.

:::

:::

::: {.pf-step #s7}

Letting $k \to \infty$ and using continuity of $g_m$, we get $g_m(x_0) \ge \epsilon$ for all $m$.

::: pf-proof

Steps [](#s5){.pf-ref} and [](#s6){.pf-ref}.

:::

:::

::: {.pf-step #s8}

But $g_m(x_0) \to 0$ as $m \to \infty$ (pointwise convergence), contradicting $g_m(x_0) \ge \epsilon$ for all $m$.

::: pf-proof

Step [](#s7){.pf-ref} and pointwise convergence.

:::

:::

::: {.pf-step #s9}

Hence $g_n \to 0$ uniformly, so $f_n \to f$ uniformly.

::: pf-proof

:::

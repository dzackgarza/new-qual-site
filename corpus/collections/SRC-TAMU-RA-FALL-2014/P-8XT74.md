::: {.problem}
Let $f:\mathbb{R}\to\mathbb{R}$ be a Lebesgue integrable function such that $$\int_a^b f(x)\,dx=0$$ for every $a<b$.
Show that $f(x)=0$ for almost every $x\in\mathbb{R}$.
:::

::: {.solution}
Define
\[
F(x)=\int_0^x f(t)\,dt,
\qquad x\in\mathbb R,
\]
with the usual convention
\[
\int_0^x f(t)\,dt=-\int_x^0 f(t)\,dt
\qquad(x<0).
\]

<1>1. $F$ is constant on $\mathbb R$.
::: {.proof}
Let $x<y$.
By additivity of the Lebesgue integral,
\[
F(y)-F(x)=\int_x^y f(t)\,dt.
\]
The hypothesis says that the right-hand side is zero for every $x<y$.
Hence
\[
F(y)=F(x)
\]
for all $x<y$, so $F$ is constant.
Since $F(0)=0$, in fact
\[
F\equiv0.
\]
:::

<1>2. $F'(x)=f(x)$ for almost every $x\in\mathbb R$.
::: {.proof}
Because $f\in L^1(\mathbb R)$, its restriction to every bounded interval belongs to $L^1$ there.
For each integer $n\ge1$, the function
\[
x\longmapsto \int_0^x f(t)\,dt
\]
is absolutely continuous on $[-n,n]$ and satisfies
\[
F'(x)=f(x)
\]
for almost every $x\in[-n,n]$ by the fundamental theorem of calculus for Lebesgue integrals.

Let $N_n\subseteq[-n,n]$ be the null set on which this equality may fail.
Then
\[
N=\bigcup_{n=1}^\infty N_n
\]
has measure zero, and for every $x\notin N$ we have
\[
F'(x)=f(x).
\]
Thus the equality holds almost everywhere on $\mathbb R$.
:::

<1>3. Therefore $f=0$ almost everywhere.
::: {.proof}
By <1>1, $F$ is constant, hence
\[
F'(x)=0
\]
at every point where the derivative exists.
By <1>2,
\[
f(x)=F'(x)=0
\]
for almost every $x\in\mathbb R$.
:::
:::

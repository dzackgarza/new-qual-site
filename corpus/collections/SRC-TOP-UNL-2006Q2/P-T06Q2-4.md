::: {.problem}
A topological space $X$ is called locally connected if for every $x\in X$ and $O$ a neighborhood of $x$ there exists a connected open set $V$ with $x\in V\subseteq O$.
Prove that a compact, locally connected space has a finite number of components.
:::

::: {.solution}
<1>1. Every connected component $C$ of $X$ is open.

::: {.proof}
Let $x\in C$.
Local connectedness with $O=X$ gives a connected open set $V_x\ni x$.
$C\cup V_x$ is connected because the two sets meet at $x$, so $V_x\subseteq C$ by maximality of $C$.
Hence $C=\bigcup_{x\in C}V_x$ is open.
:::

<1>2. Q.E.D.

::: {.proof}
The components cover $X$ and are open by step <1>1, so by compactness finitely many of them, $C_1,\ldots,C_r$, cover $X$.
Distinct components are disjoint, so any other component would be a nonempty set disjoint from $C_1\cup\cdots\cup C_r=X$.
Hence $C_1,\ldots,C_r$ are all the components.
:::
:::

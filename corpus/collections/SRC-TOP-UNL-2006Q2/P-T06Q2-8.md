::: {.problem}
Use covering space theory to prove that every map $\mathbb{RP}^2\to S^1\times S^1$ is homotopic to a constant map.
:::

::: {.solution}
**Goal.** Show every map $\RP^2 \to S^1 \times S^1$ is null-homotopic.

<1>1. $f$ induces $f_*: \pi_1(\RP^2) = \ZZ/2 \to \pi_1(S^1 \times S^1) = \ZZ \oplus \ZZ$.
::: {.proof}
$\pi_1(\RP^2) = \ZZ/2$ and $\pi_1(S^1 \times S^1) = \ZZ^2$.
:::

<1>2. $f_* = 0$.
::: {.proof}
the only homomorphism $\ZZ/2 \to \ZZ \oplus \ZZ$ is the zero map (there is no element of order $2$ in $\ZZ \oplus \ZZ$).
:::

<1>3. Hence $f$ lifts to the universal cover $\RR^2 \to S^1 \times S^1$.
::: {.proof}
the lifting criterion: $f_*(\pi_1(\RP^2)) = 0 \subseteq \pi_1(\RR^2) = 0$, so $f$ lifts to $\tilde f: \RP^2 \to \RR^2$.
:::

<1>4. $\tilde f$ is null-homotopic (since $\RR^2$ is contractible).
::: {.proof}
$\RR^2$ is contractible.
:::

<1>5. Hence $f = p \circ \tilde f$ is null-homotopic.
::: {.proof}
composing a null-homotopy of $\tilde f$ with the covering map $p$ gives a null-homotopy of $f$.
:::

<1>6. Q.E.D.
::: {.proof}
<1>5 is the claim.
:::
:::

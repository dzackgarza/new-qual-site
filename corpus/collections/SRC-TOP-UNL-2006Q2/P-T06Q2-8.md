::: {.problem}
Use covering space theory to prove that every map $\mathbb{RP}^2\to S^1\times S^1$ is homotopic to a constant map.
:::

::: {.solution}
Let
\[
f:\mathbb{RP}^2\longrightarrow S^1\times S^1
\]
be continuous.
Choose a basepoint $x_0\in\mathbb{RP}^2$ and use $f(x_0)$ as the basepoint of the torus.

<1>1. The induced homomorphism
\[
f_*:\pi_1(\mathbb{RP}^2,x_0)\longrightarrow\pi_1(S^1\times S^1,f(x_0))
\]
is trivial.
::: {.proof}
The standard computations give
\[
\pi_1(\mathbb{RP}^2,x_0)\cong\mathbb Z/2
\qquad\text{and}\qquad
\pi_1(S^1\times S^1,f(x_0))\cong\mathbb Z^2.
\]
If $a$ is the nontrivial element of $\mathbb Z/2$, then
\[
2f_*(a)=f_*(2a)=0.
\]
Since $\mathbb Z^2$ is torsion-free, this forces
\[
f_*(a)=0.
\]
Thus $f_*=0$.
:::

<1>2. The map $f$ lifts through the universal covering
\[
p:\mathbb R^2\longrightarrow S^1\times S^1.
\]
::: {.proof}
Choose a point
\[
\widetilde y_0\in p^{-1}(f(x_0)).
\]
The space $\mathbb{RP}^2$ is path-connected and locally path-connected, so the covering-space lifting criterion applies.
Because $\mathbb R^2$ is simply connected,
\[
p_*\bigl(\pi_1(\mathbb R^2,\widetilde y_0)\bigr)=0.
\]
By <1>1,
\[
f_*\bigl(\pi_1(\mathbb{RP}^2,x_0)\bigr)=0
\subseteq
p_*\bigl(\pi_1(\mathbb R^2,\widetilde y_0)\bigr).
\]
Hence there is a continuous lift
\[
\widetilde f:\mathbb{RP}^2\longrightarrow\mathbb R^2
\]
with
\[
p\circ\widetilde f=f.
\]
:::

<1>3. The lift $\widetilde f$ is nullhomotopic.
::: {.proof}
The space $\mathbb R^2$ is contractible.
For example, if $c\in\mathbb R^2$ is fixed, then
\[
H(x,t)=(1-t)\widetilde f(x)+tc
\]
is a homotopy from $\widetilde f$ to the constant map with value $c$.
:::

<1>4. Therefore $f$ is homotopic to a constant map.
::: {.proof}
Let $H$ be the nullhomotopy from <1>3.
Then
\[
p\circ H:\mathbb{RP}^2\times I\longrightarrow S^1\times S^1
\]
is a homotopy from
\[
p\circ\widetilde f=f
\]
to the constant map with value $p(c)$.
:::
:::

::: {.problem}
Let $f:S^2\to S^2$ be such that $f(x)\ne f(-x)$ for all $x\in S^2$.
Prove that $f$ is surjective.
**Hint:** Degree theory will probably not be helpful.
:::

::: {.solution}
Suppose, toward a contradiction, that $f$ is not surjective.

<1>1. There is a continuous map
\[
g:S^2\longrightarrow\mathbb R^2
\]
such that
\[
g(x)\ne g(-x)
\qquad\text{for every }x\in S^2.
\]
::: {.proof}
Choose a point
\[
p\in S^2\setminus f(S^2).
\]
Stereographic projection from $p$ is a homeomorphism
\[
\sigma:S^2\setminus\{p\}\longrightarrow\mathbb R^2.
\]
Set
\[
g=\sigma\circ f.
\]
Since $f(x)\ne f(-x)$ by hypothesis and $\sigma$ is injective,
\[
g(x)\ne g(-x)
\]
for every $x$.
:::

<1>2. The formula
\[
h(x)=\frac{g(x)-g(-x)}{\|g(x)-g(-x)\|}
\]
defines a continuous odd map
\[
h:S^2\longrightarrow S^1,
\qquad
h(-x)=-h(x).
\]
::: {.proof}
By <1>1, the vector $g(x)-g(-x)$ is never zero, so the displayed normalization is defined and continuous.
Moreover,
\[
h(-x)
=
\frac{g(-x)-g(x)}{\|g(-x)-g(x)\|}
=-h(x).
\]
:::

Let
\[
E=\{(x_1,x_2,x_3)\in S^2:x_3=0\}\cong S^1
\]
be the equator, and write
\[
k=h|_E:E\longrightarrow S^1.
\]

<1>3. The map $k:S^1\to S^1$ has odd degree.
::: {.proof}
Identify both circles with
\[
S^1=\{e^{it}:t\in\mathbb R\}.
\]
Because $k$ is continuous, the path
\[
t\longmapsto k(e^{it})
\]
has a lift
\[
\phi:\mathbb R\longrightarrow\mathbb R
\]
through the covering map $u\mapsto e^{iu}$, so
\[
k(e^{it})=e^{i\phi(t)}.
\]

Oddness gives
\[
k(e^{i(t+\pi)})
=k(-e^{it})
=-k(e^{it}),
\]
hence
\[
e^{i\phi(t+\pi)}
=e^{i(\phi(t)+\pi)}.
\]
Therefore
\[
\phi(t+\pi)-\phi(t)-\pi\in 2\pi\mathbb Z.
\]
The left side is a continuous function of $t$ with values in the discrete set $2\pi\mathbb Z$, so it is constant.
Thus for some $m\in\mathbb Z$,
\[
\phi(t+\pi)=\phi(t)+(2m+1)\pi.
\]
Applying this twice gives
\[
\phi(t+2\pi)=\phi(t)+2\pi(2m+1).
\]
Hence
\[
\deg(k)=2m+1,
\]
which is odd.
:::

<1>4. The same map $k$ has degree zero.
::: {.proof}
Let
\[
D_+=\{(x_1,x_2,x_3)\in S^2:x_3\ge 0\}
\]
be the closed upper hemisphere.
It is homeomorphic to the disk $D^2$ and has boundary $E$.

The restriction
\[
h|_{D_+}:D_+\longrightarrow S^1
\]
extends $k$ over the disk.
Therefore $k$ is nullhomotopic: contract $D_+$ to a point and compose the contraction with $h|_{D_+}$.
Every nullhomotopic map $S^1\to S^1$ has degree zero, so
\[
\deg(k)=0.
\]
:::

<1>5. The assumption that $f$ is not surjective is impossible; therefore $f$ is surjective.
::: {.proof}
By <1>3, $\deg(k)$ is odd, while <1>4 gives
\[
\deg(k)=0.
\]
This contradiction arose from assuming that $f$ missed a point of $S^2$.
Hence no point is missed and $f$ is surjective.
:::

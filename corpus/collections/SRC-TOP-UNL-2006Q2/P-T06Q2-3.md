::: {.problem}
Given an integer $n$ we say that $2^i$ exactly divides $n$ if $2^i$ divides $n$ and $2^{i+1}$ does not.
In this case we write $2^i\parallel n$.
Define a metric on $\mathbb Z$ by $$d_2(n,m)=\begin{cases}0&\text{if }n=m,\\2^{-i}&\text{if }2^i\parallel(n-m).\end{cases}$$ Hereafter let $X$ be the metric space $(\mathbb Z,d_2)$.

(a) Prove that $d_2$ is a metric.

(b) Prove that $X$ is not discrete.

(c) Prove that $X$ is not connected.
:::

::: {.solution}
<1>1. The function $d_2$ is nonnegative, symmetric, and satisfies
\[
d_2(n,m)=0
\quad\Longleftrightarrow\quad
n=m.
\]
::: {.proof}
Nonnegativity is immediate from the definition.
If $n=m$, then $d_2(n,m)=0$ by definition.
If $n\ne m$, there is a unique $i\ge 0$ such that
\[
2^i\parallel(n-m),
\]
so
\[
d_2(n,m)=2^{-i}>0.
\]

Finally, $2^i$ exactly divides $n-m$ if and only if it exactly divides
\[
m-n=-(n-m),
\]
because multiplication by $-1$ changes no divisibility by powers of $2$.
Hence
\[
d_2(n,m)=d_2(m,n).
\]
:::

<1>2. The strong triangle inequality holds:
\[
d_2(n,\ell)
\le
\max\{d_2(n,m),d_2(m,\ell)\}
\]
for all $n,m,\ell\in\mathbb Z$.
::: {.proof}
If $n=m$ or $m=\ell$, the assertion is immediate.
Assume therefore that
\[
2^r\parallel(n-m)
\qquad\text{and}\qquad
2^s\parallel(m-\ell).
\]
Put
\[
t=\min\{r,s\}.
\]
Then $2^t$ divides both $n-m$ and $m-\ell$, hence it divides their sum
\[
n-\ell=(n-m)+(m-\ell).
\]

If $n=\ell$, then $d_2(n,\ell)=0$ and there is nothing more to prove.
Otherwise let
\[
2^u\parallel(n-\ell).
\]
Since $2^t\mid(n-\ell)$, we have $u\ge t$, and therefore
\[
d_2(n,\ell)
=2^{-u}
\le 2^{-t}
=\max\{2^{-r},2^{-s}\}
=\max\{d_2(n,m),d_2(m,\ell)\}.
\]
:::

<1>3. Hence $d_2$ is a metric on $\mathbb Z$.
::: {.proof}
By <1>1, $d_2$ has nonnegativity, definiteness, and symmetry.
By <1>2,
\[
d_2(n,\ell)
\le
\max\{d_2(n,m),d_2(m,\ell)\}
\le
d_2(n,m)+d_2(m,\ell),
\]
which is the ordinary triangle inequality.
Thus all metric axioms hold, proving part (a).
:::

<1>4. No point of $X$ is isolated.
::: {.proof}
Fix $n\in\mathbb Z$ and let $\varepsilon>0$.
Choose $k\ge 0$ so large that
\[
2^{-k}<\varepsilon.
\]
Set
\[
m=n+2^k.
\]
Then $m\ne n$, and
\[
n-m=-2^k,
\]
so $2^k\parallel(n-m)$.
Consequently
\[
d_2(n,m)=2^{-k}<\varepsilon.
\]
Thus every open ball about $n$ contains a point other than $n$.
In particular, no singleton is open, so $X$ is not discrete.
This proves part (b).
:::

<1>5. For $n,m\in\mathbb Z$,
\[
d_2(n,m)<1
\quad\Longleftrightarrow\quad
n\equiv m\pmod 2.
\]
::: {.proof}
If $n=m$, both sides hold.
Suppose $n\ne m$ and $2^i\parallel(n-m)$.
Then
\[
d_2(n,m)=2^{-i}<1
\]
if and only if $i\ge1$, which is equivalent to
\[
2\mid(n-m).
\]
The latter condition is exactly $n\equiv m\pmod2$.
:::

<1>6. The space $X$ is disconnected.
::: {.proof}
Let
\[
E=2\mathbb Z,
\qquad
O=2\mathbb Z+1.
\]
By <1>5,
\[
E=B_{d_2}(0,1)
\qquad\text{and}\qquad
O=B_{d_2}(1,1).
\]
Hence both $E$ and $O$ are open in $X$.
They are nonempty, disjoint, and
\[
X=E\cup O.
\]
Thus $X$ is the union of two disjoint nonempty open sets, so it is not connected.
This proves part (c).
:::

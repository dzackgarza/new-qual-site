::: {.problem}
Given an integer $n$ we say that $2^i$ exactly divides $n$ if $2^i$ divides $n$ and $2^{i+1}$ does not.
In this case we write $2^i\parallel n$.
Define a metric on $\ZZ$ by $$d_2(n,m)=\begin{cases}0&\text{if }n=m,\\2^{-i}&\text{if }2^i\parallel(n-m).\end{cases}$$ Hereafter let $X$ be the metric space $(\ZZ,d_2)$.

(a) Prove that $d_2$ is a metric.

(b) Prove that $X$ is not discrete.

(c) Prove that $X$ is not connected.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

(a) $d_2$ is a metric on $\ZZ$; it satisfies $d_2(n,\ell)\le\max\{d_2(n,m),d_2(m,\ell)\}$.

::: pf-proof

::: {.pf-step #s1-1}

$d_2(n,m)\ge0$, with equality exactly when $n=m$, and $d_2(n,m)=d_2(m,n)$.

::: pf-proof

If $n\neq m$, there is a unique $i\ge0$ with $2^i\parallel(n-m)$, so $d_2(n,m)=2^{-i}>0$.
$2^i\parallel(n-m)$ if and only if $2^i\parallel(m-n)$.

:::

:::

::: {.pf-step #s1-2}

$d_2(n,\ell)\le\max\{d_2(n,m),d_2(m,\ell)\}$.

::: pf-proof

This is clear if $n=m$, $m=\ell$, or $n=\ell$.
Otherwise let $2^r\parallel(n-m)$, $2^s\parallel(m-\ell)$, $2^u\parallel(n-\ell)$, and $t=\min\{r,s\}$.
$2^t$ divides $(n-m)+(m-\ell)=n-\ell$, so $u\ge t$ and $d_2(n,\ell)=2^{-u}\le2^{-t}=\max\{2^{-r},2^{-s}\}$.

:::

:::

::: pf-qed

Step [](#s1-1){.pf-ref} gives positivity and symmetry, and step [](#s1-2){.pf-ref} implies the triangle inequality since $\max\{a,b\}\le a+b$ for $a,b\ge0$.

:::

:::

:::

::: {.pf-step #s2}

(b) No point of $X$ is isolated, so $X$ is not discrete.

::: pf-proof

Given $n\in\ZZ$ and $\varepsilon>0$, choose $k\ge0$ with $2^{-k}<\varepsilon$.
Then $m=n+2^k\neq n$ and $2^k\parallel(n-m)$, so $d_2(n,m)=2^{-k}<\varepsilon$.
Hence no singleton is open.

:::

:::

::: {.pf-step #s3}

(c) $X$ is not connected.

::: pf-proof

For $n\neq m$ with $2^i\parallel(n-m)$, $d_2(n,m)<1$ exactly when $i\ge1$, that is, when $n\equiv m\pmod2$.
So $2\ZZ=B_{d_2}(0,1)$ and $2\ZZ+1=B_{d_2}(1,1)$ are disjoint nonempty open sets with union $X$.

:::

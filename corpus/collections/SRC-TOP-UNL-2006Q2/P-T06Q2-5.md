::: {.problem}
(a) Recall that a topological space is called *separable* if it contains a countable dense subset.
Prove that a countable product of separable spaces (with the product topology) is separable.

(b) Prove that the result in the first part is false if the product is given the box topology.
:::

::: {.solution}
Let
\[
X=\prod_{n=1}^{\infty}X_n,
\]
where each $X_n$ is separable.

<1>1. If every $X_n$ is nonempty, choose a countable dense subset $D_n\subseteq X_n$ and a point $a_n\in D_n$ for each $n$.
For $m\ge1$, define
\[
E_m
=
D_1\times\cdots\times D_m
\times
\prod_{n>m}\{a_n\},
\]
and set
\[
E=\bigcup_{m=1}^{\infty}E_m.
\]
Then $E$ is countable.
::: {.proof}
Each $D_n$ is countable, so the finite product
\[
D_1\times\cdots\times D_m
\]
is countable.
The remaining coordinates of a point of $E_m$ are forced to equal the fixed points $a_n$, so $E_m$ is countable.
Therefore the countable union
\[
E=\bigcup_{m=1}^{\infty}E_m
\]
is countable.

If some $X_n$ is empty, then $X$ itself is empty and is already separable, so the nonempty-factor assumption loses no case.
:::

<1>2. The set $E$ is dense in $X$ for the product topology.
::: {.proof}
It suffices to show that $E$ meets every nonempty basic open set.
Let
\[
B=\prod_{n=1}^{\infty}U_n
\]
be a nonempty basic open set in the product topology.
By definition of the product topology,
\[
U_n=X_n
\]
for all but finitely many $n$.
Choose $m$ so large that every coordinate on which $U_n\ne X_n$ has index at most $m$.

For each $1\le n\le m$, the set $U_n$ is a nonempty open subset of $X_n$.
Since $D_n$ is dense, choose
\[
d_n\in D_n\cap U_n.
\]
Define $x\in X$ by
\[
x_n=
\begin{cases}
d_n, & n\le m,\\
a_n, & n>m.
\end{cases}
\]
Then $x\in E_m\subseteq E$.
Also $x_n\in U_n$ for $n\le m$, while for $n>m$ we have $U_n=X_n$, so $x_n=a_n\in U_n$.
Hence
\[
x\in E\cap B.
\]
Thus every nonempty basic open set meets $E$, and $E$ is dense.
:::

<1>3. Therefore every countable product of separable spaces is separable in the product topology.
::: {.proof}
By <1>1, $E$ is countable, and by <1>2, $E$ is dense in $X$.
This proves part (a).
:::

<1>4. Let every factor be the discrete two-point space
\[
X_n=\{0,1\}.
\]
Then each $X_n$ is separable, but the box product
\[
\square_{n=1}^{\infty}X_n
\]
is discrete.
::: {.proof}
Each factor is finite, hence separable.

Let
\[
x=(x_1,x_2,\dots)\in\prod_{n=1}^{\infty}\{0,1\}.
\]
Since each factor has the discrete topology, every singleton $\{x_n\}$ is open in $X_n$.
The box topology therefore contains the basic open set
\[
\prod_{n=1}^{\infty}\{x_n\}=\{x\}.
\]
Thus every singleton is open, so the box product is discrete.
:::

<1>5. The box product in <1>4 is not separable.
::: {.proof}
The set
\[
\prod_{n=1}^{\infty}\{0,1\}
\]
is uncountable: the map
\[
(x_n)_{n\ge1}
\longmapsto
\{n\in\mathbb N:x_n=1\}
\]
is a bijection onto the power set of $\mathbb N$, which is uncountable by Cantor's theorem.

In a discrete space every subset is closed, so the closure of any subset $D$ is just $D$ itself.
Consequently a dense subset of a discrete space must be the whole space.
Since this box product is uncountable, it has no countable dense subset.
Hence it is not separable.

This supplies a countable family of separable spaces whose box product is not separable, proving part (b).
:::

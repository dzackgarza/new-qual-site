::: {.problem}
(a) Recall that a topological space is called *separable* if it contains a countable dense subset.
Prove that a countable product of separable spaces (with the product topology) is separable.

(b) Prove that the result in the first part is false if the product is given the box topology.
:::

::: {.solution}
Let $X=\prod_{n\ge1}X_n$ with each $X_n$ separable.
If some $X_n$ is empty, then $X=\varnothing$ is separable; assume every $X_n$ is nonempty, choose countable dense $D_n\subseteq X_n$ and $a_n\in D_n$, and put
$$E_m=D_1\times\cdots\times D_m\times\prod_{n>m}\{a_n\},\qquad E=\bigcup_{m\ge1}E_m.$$

<1>1. $E$ is countable.

::: {.proof}
Each $E_m$ is in bijection with the countable set $D_1\times\cdots\times D_m$, and $E$ is a countable union of the $E_m$.
:::

<1>2. $E$ is dense in $X$ with the product topology.

::: {.proof}
Let $B=\prod_nU_n$ be a nonempty basic open set, and choose $m$ with $U_n=X_n$ for all $n>m$.
For $n\le m$, choose $d_n\in D_n\cap U_n$, possible since $U_n$ is nonempty and open.
The point with coordinates $d_n$ for $n\le m$ and $a_n$ for $n>m$ lies in $E_m\cap B$.
:::

<1>3. With $X_n=\{0,1\}$ discrete for every $n$, each $X_n$ is separable but the box product $\Box_{n\ge1}X_n$ is not.

::: {.proof}
Each $X_n$ is finite, hence separable.
For $x=(x_n)$, the box-open set $\prod_n\{x_n\}$ equals $\{x\}$, so the box product is discrete, and the only dense subset of a discrete space is the whole space.
The map $(x_n)\mapsto\{n\in\NN:x_n=1\}$ is a bijection onto the power set of $\NN$, which is uncountable.
So the box product has no countable dense subset.
:::

<1>4. Q.E.D.

::: {.proof}
Steps <1>1 and <1>2 prove (a), and step <1>3 proves (b).
:::
:::

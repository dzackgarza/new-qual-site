::: {.problem}
Does there exists a homomorphism of commutative rings with unit from $\mathbb { Z } [ x ] / ( x ^ { 2 } + 3 )$ to $\mathbb { Z } [ x ] / ( x ^ { 2 } - x + 1 ) ?$ Either exhibit such a homomorphism, or prove that none exists.
:::

::: {.solution}
Set
$$
R\coloneqq\ZZ[t]/(t^2+3),
\qquad
S\coloneqq\ZZ[x]/(x^2-x+1),
$$
and let $\bar t\in R$ and $\bar x\in S$ denote the residue classes
of the variables.

<1>1. In $S$ one has
$$
\bar x^2=\bar x-1.
$$

::: {.proof}
The defining relation of $S$ is
$\bar x^2-\bar x+1=0$.
:::

<1>2. The element
$$
y\coloneqq 2\bar x-1\in S
$$
satisfies $y^2=-3$.

::: {.proof}
By step <1>1,
$$
\begin{aligned}
y^2
&=(2\bar x-1)^2\\
&=4\bar x^2-4\bar x+1\\
&=4(\bar x-1)-4\bar x+1\\
&=-3.
\end{aligned}
$$
:::

<1>3. Evaluation at $y$ defines a unital ring homomorphism
$$
F:\ZZ[t]\longrightarrow S
$$
such that $(t^2+3)\subseteq\ker F$.

::: {.proof}
There is a unique unital evaluation homomorphism with $F(t)=y$.
Step <1>2 gives
$$
F(t^2+3)=y^2+3=0,
$$
so the principal ideal generated by $t^2+3$ lies in the kernel.
:::

<1>4. The map $F$ descends to a unital ring homomorphism
$$
\boxed{
\varphi:R\longrightarrow S,
\qquad
\varphi(\bar t)=2\bar x-1
}.
$$

::: {.proof}
By step <1>3, the quotient universal property gives a unique unital
homomorphism
$$
\varphi:\ZZ[t]/(t^2+3)\longrightarrow S
$$
whose composite with the quotient map is $F$. Its value on $\bar t$
is therefore $F(t)=2\bar x-1$.
:::

<1>5. Q.E.D.

::: {.proof}
Step <1>4 explicitly exhibits the requested homomorphism.
:::
:::

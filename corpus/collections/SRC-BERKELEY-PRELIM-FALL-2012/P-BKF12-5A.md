::: {.problem}
(a) Show that if $| z | < 1$ then there is a holomorphic function defined on some neighborhood of the unit disk whose only zero is at z and that has absolute value 1 on the unit circle.

(b) Suppose that f is a holomorphic function on the complex plane and is not identically zero.
Show that there is a holomorphic function g defined in some open set containing the unit disk such that $| f ( z ) | = | g ( z ) |$ whenever $| z | = 1$ , and such that g has no zeros in the open unit disk.
:::

::: {.problem}
(a) Find the poles and residues of $1 / ( z ^ { 3 } \cos ( z ) )$

(b) Show that the integral of the function above over a square contour centered at the origin with side 2πN tends to zero as the integer N tends to infinity.

(c) Find the sum $1 / 1 ^ { 3 } - 1 / 3 ^ { 3 } + 1 / 5 ^ { 3 } - 1 / 7 ^ { 3 } + \cdot \cdot \cdot$

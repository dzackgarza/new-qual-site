::: {.problem}
Let $U$ be the upper half plane $\{z\in\CC\mid\operatorname{Im}(z)>0\}$ with the slit $\{iy\mid 0<y\le 1\}$ removed.
Find a conformal equivalence from $U$ to $\DD$.
:::

::: {.solution}
The map is built in three biholomorphic steps: $z\mapsto z^2$ carries the slit half-plane onto the plane cut along $[-1,\infty)$, adding $1$ moves the cut to $[0,\infty)$, the principal square root on that slit plane halves the argument and lands in the upper half-plane, and the Cayley map finishes into the disc. One point about the printed set is recorded first: as written, $U$ is not open, because the point $0$ lies in it and every neighbourhood of $0$ meets the slit. The argument is this card's own: no retained solution set covers this exam.

::: pf

::: {.pf-step #domain}
With $U=\{\Im z>0\}\setminus\{iy:0<y\le1\}$ as printed, $0\in U$ but $U$ contains no neighbourhood of $0$, so $U$ is not open; the open set intended by the problem is obtained by taking the slit to be $\{iy:0\le y\le1\}$ or $\{iy:0<y<1\}$, and both give the same image under $z\mapsto z^2$, so the conformal map below is the same either way.

::: pf-proof
$0=i\cdot0$ and $0\notin\{iy:0<y\le1\}$, so $0\in U$. For $\delta>0$ the point $i\delta/2$ lies in the slit and has modulus $\delta/2<\delta$, so every disc about $0$ leaves $U$; hence $U$ is not open, and conformality at $0$ — an open-set notion — is not defined for the printed set. Taking instead the closed slit $S=\{iy:0\le y\le1\}$ gives $U'=H\setminus S$, which is open since $S$ is closed in $\CC$, and the open slit gives an open set too. Since $z=iy$ maps to $z^2=-y^2$, the slit's image is $[-1,0]$ or $[-1,0)$ under the two readings, and the images $U'^2$ agree up to the point $-1$, which is not attained in either case (it would need $y=1$). So the computation below is unaffected by which open version is used.
:::

:::


::: {.pf-step #square}
$z\mapsto z^2$ is a biholomorphism of the open slit half-plane onto $\CC\setminus[-1,\infty)$, and $z\mapsto z^2+1$ onto $\CC\setminus[0,\infty)$.

::: pf-proof
On the upper half-plane $z\mapsto z^2$ is injective, since $z^2=w^2$ gives $z=\pm w$ and both are in the open upper half-plane only if $z=w$; and its image is $\CC\setminus[0,\infty)$, since every nonzero complex number has exactly two square roots, of which exactly one has positive imaginary part when the argument is taken in $(0,2\pi)$, and the non-negative reals have their square roots on the real axis or on the imaginary axis, the positive ones real and $0$ at the origin. Restricting to the complement of the slit removes exactly the points $-y^2$ with $0<y\le1$, that is the interval $[-1,0)$; adding the point $-1$ which is not attained, the image is $\CC\setminus[-1,\infty)$. Being the restriction of the holomorphic $z^2$ to an open set on which it is injective with open image, this is a biholomorphism. Composing with the translation $w\mapsto w+1$ shifts the cut to $[0,\infty)$.
:::

:::


::: {.pf-step #root}
The principal square root $S(w)$, defined on $\CC\setminus[0,\infty)$ by taking the argument of $w$ in $(0,2\pi)$ and halving it, is a biholomorphism onto the upper half-plane.

::: pf-proof
On $\CC$ minus the non-negative reals each $w$ has a unique representation $w=\abs w\,e^{i\theta}$ with $\theta\in(0,2\pi)$, and $\theta$ is a continuous function of $w$ there; so $S(w)=\sqrt{\abs w}\,e^{i\theta/2}$ is continuous, and it is holomorphic because on the complement of any ray it is a branch of the logarithm composed with the exponential form: locally $S(w)=\exp(\tfrac12\log w)$ for a holomorphic branch of $\log$. Since $0<\theta/2<\pi$, the values of $S$ have positive imaginary part. Conversely, given $\zeta$ in the upper half-plane, $w=\zeta^2$ has argument $2\arg\zeta\in(0,2\pi)$, so $S(\zeta^2)=\zeta$; and for $w$ in the slit plane $S(w)^2=w$. So $S$ is a bijection with two-sided inverse $\zeta\mapsto\zeta^2$ on the upper half-plane, and being holomorphic with holomorphic inverse it is a biholomorphism.
:::

:::


::: {.pf-step #cayley}
The Cayley map $C(\zeta)=\dfrac{\zeta-i}{\zeta+i}$ is a biholomorphism of the upper half-plane onto the unit disc.

::: pf-proof
For $\Im\zeta>0$ the denominator $\zeta+i$ does not vanish, since $-i$ is in the lower half-plane; and $\abs{\zeta-i}<\abs{\zeta+i}$ exactly when $\zeta$ is closer to $i$ than to $-i$, which is the condition $\Im\zeta>0$. So $C$ maps the upper half-plane into the disc. Its inverse is $w\mapsto i\dfrac{1+w}{1-w}$, defined for $\abs w<1$ because then $w\ne1$, and a direct substitution shows the two maps are mutually inverse; both are holomorphic where defined, so $C$ is a biholomorphism.
:::

:::


::: {.pf-step #conclusion}
$\Phi(z)=\dfrac{\sqrt{z^2+1}-i}{\sqrt{z^2+1}+i}$, with the square root the branch of step [](#root){.pf-ref}, is a conformal equivalence from the slit half-plane onto $\DD$.

::: pf-proof
$\Phi=C\circ S\circ(\cdot+1)\circ(\cdot)^2$ is a composite of biholomorphisms between open sets by steps [](#square){.pf-ref}, [](#root){.pf-ref} and [](#cayley){.pf-ref}, hence a biholomorphism of the slit half-plane onto the disc. Its derivative is nowhere zero because each factor's derivative is nowhere zero: $2z\ne0$ on the punctured slit domain, $S'(w)=1/(2S(w))\ne0$, and $C'(\zeta)=2i/(\zeta+i)^2\ne0$.
:::

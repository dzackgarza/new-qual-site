::: {.problem}
Let $f(x) = x^6 - 3$.
Let $K$ be the splitting field of $f(x)$ over $\mathbb{Q}$.
Show that $\mathrm{Gal}(K/\mathbb{Q})$ is isomorphic to a dihedral group.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
$f(x) = x^6 - 3$ is irreducible over $\QQ$.

::: pf-proof
Eisenstein's criterion at the prime $3$.
:::

:::

::: pf-step
The roots of $f$ are $\alpha \zeta_6^k$ for $k = 0, \ldots, 5$, where $\alpha = 3^{1/6}$ and $\zeta_6 = e^{2\pi i/6}$.

::: pf-proof
the sixth roots of $3$.
:::

:::

::: pf-step
$K = \QQ(\alpha, \zeta_6)$.

::: pf-proof
the splitting field is generated by one root $\alpha$ and the primitive sixth root of unity $\zeta_6$.
:::

:::

::: pf-step
$[\QQ(\alpha) : \QQ] = 6$ and $[\QQ(\zeta_6) : \QQ] = \varphi(6) = 2$.

::: pf-proof
step [](#s1){.pf-ref} gives the first; $\zeta_6$ has minimal polynomial $x^2 - x + 1$.
:::

:::

::: {.pf-step #s5}
$\zeta_6 \notin \QQ(\alpha)$, so $[K : \QQ] = 12$.

::: pf-proof
$\QQ(\alpha) \subseteq \RR$ (since $\alpha$ is real), but $\zeta_6 = \frac{1}{2} + \frac{\sqrt{3}}{2}i$ is not real.
:::

:::

::: pf-step
$\operatorname{Gal}(K/\QQ)$ has order $12$.

::: pf-proof
$K/\QQ$ is Galois (splitting field of a separable polynomial) and $[K:\QQ] = 12$ by step [](#s5){.pf-ref}.
:::

:::

::: {.pf-step #s7}
$\operatorname{Gal}(K/\QQ) \cong D_6$ (the dihedral group of order $12$).

::: pf-proof

::: pf-step
An automorphism is determined by $\alpha \mapsto \alpha \zeta_6^a$ and $\zeta_6 \mapsto \zeta_6^b$ with $a \in \{0,\ldots,5\}$ and $b \in \{1, 5\}$.

::: pf-proof
$\alpha$ must map to a root of $f$, and $\zeta_6$ to a primitive sixth root of unity.
:::

:::

::: pf-step
These $12$ choices form a group generated by $\sigma: \alpha \mapsto \alpha\zeta_6$, $\zeta_6 \mapsto \zeta_6$ (order $6$) and $\tau: \alpha \mapsto \alpha$, $\zeta_6 \mapsto \zeta_6^{-1}$ (order $2$), with $\tau\sigma\tau = \sigma^{-1}$.

::: pf-proof
direct check of the relations.
:::

:::

::: pf-step
This is the presentation of the dihedral group $D_6$.

::: pf-proof
$D_6 = \langle r, s \mid r^6 = s^2 = 1,\ srs = r^{-1}\rangle$.
:::

:::

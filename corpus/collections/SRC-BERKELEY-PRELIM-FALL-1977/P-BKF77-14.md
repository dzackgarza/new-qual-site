::: {.problem}
For nonzero complex $a$, define $a^b$ as the set of complex numbers $c$ for which $c=e^{b\alpha}$ for some logarithm $\alpha$ of $a$. Describe the set $a^b$ when $a=1$ and $b=1/3+i$.
:::

::: {.solution}
The argument is the card's own; the collection is a preliminary examination, so there is no printed solution set behind it and the statement is the source. It is checked against the definition of the multivalued power printed in the problem: $a^{b}=\{e^{b\alpha}:\alpha\text{ a logarithm of }a\}$.

::: pf

::: {.pf-step #logs}
The logarithms of $1$ are exactly $\alpha_{k}=2\pi ik$, $k\in\ZZ$.

::: pf-proof
$e^{\alpha}=1$ iff $\alpha=2\pi ik$ for some integer $k$, since $e^{\alpha}=e^{\operatorname{Re}\alpha}e^{i\operatorname{Im}\alpha}$ has modulus $1$ iff $\operatorname{Re}\alpha=0$ and equals $1$ iff additionally $\operatorname{Im}\alpha\in2\pi\ZZ$.
:::

:::

::: {.pf-step #values}
For $b=\tfrac13+i$ and $k\in\ZZ$, $e^{b\alpha_{k}}=e^{-2\pi k}e^{2\pi ik/3}$.

::: pf-proof
$\bigl(\tfrac13+i\bigr)2\pi ik=\tfrac{2\pi ik}{3}+2\pi i^{2}k=\tfrac{2\pi ik}{3}-2\pi k$, and $e^{-2\pi k+2\pi ik/3}=e^{-2\pi k}e^{2\pi ik/3}$.
:::

:::

::: {.pf-step #converse}
Every number $e^{-2\pi k}e^{2\pi ik/3}$ with $k\in\ZZ$ is a value of $1^{1/3+i}$.

::: pf-proof
For each $k$, $\alpha_{k}=2\pi ik$ is a logarithm of $1$ by step [](#logs){#logs}, so $e^{b\alpha_{k}}$ is a value by the definition of $a^{b}$; and step [](#values){.pf-ref} computes it.
:::

:::

::: {.pf-step #description}
The set is a geometric progression on three rays: $\cardinality{1^{1/3+i}}=\aleph_{0}$, the moduli are $e^{-2\pi k}$, and the arguments are $2\pi k/3$.

::: pf-proof
Each value has modulus $e^{-2\pi k}>0$ and argument $2\pi k/3$ modulo $2\pi$, so the values lie on the three rays of argument $0,2\pi/3,4\pi/3$ according as $k\equiv0,1,2\pmod 3$. Distinct integers give distinct moduli, hence distinct values, so the set is countably infinite and accumulates only at $0$ and $\infty$.
:::

:::

::: {.pf-step}
$1^{1/3+i}=\{e^{-2\pi k}e^{2\pi ik/3}:k\in\ZZ\}$.

::: pf-proof
Steps [](#values){.pf-ref}, [](#converse){.pf-ref} and [](#description){.pf-ref} give
$$
\boxed{1^{1/3+i}=\bigl\{e^{-2\pi k}e^{2\pi ik/3}:k\in\ZZ\bigr\}.}
$$
In particular the set is infinite, unlike the case of a rational exponent with denominator dividing the numerator of the imaginary part; the non-real exponent is what produces the geometric progression.
:::

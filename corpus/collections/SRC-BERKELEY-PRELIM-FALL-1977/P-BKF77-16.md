::: problem
Let $E,F$ be vector spaces and $S:E\to F$ linear.

(a) Prove $S(E)$ is a vector space.

(b) Show $\ker S=\{0\}$ if and only if $S$ is injective.

(c) If $S$ is injective, prove $S^{-1}:S(E)\to E$ is linear.
:::

::: problem
Extend the binary map on the Cantor set to the Cantor-Lebesgue function $F:[0,1]\to[0,1]$.

1. Prove that $F$ is continuous and nondecreasing.

2. Prove that $G(x)=F(x)+x$ is a bijection from $[0,1]$ to $[0,2]$.

3. Prove that $m(G(C))=1$, that $G(C)$ contains a nonmeasurable set $N'$, and that $G^{-1}(N')$ is measurable but not Borel.

4. Give a measurable $\varphi$ for which $\varphi\circ G^{-1}$ is not measurable.
:::

::: {.solution}
Let $T:C\to[0,1]$ be the binary digit map from the previous problem. If $(a,b)$ is one of the complementary intervals of the Cantor set, then its endpoints $a,b\in C$ have the same image under $T$. Define
\[
F(x)=
\begin{cases}
T(x),&x\in C,\\
T(a)=T(b),&x\in(a,b).
\end{cases}
\]

<1>1. The Cantor--Lebesgue function is nondecreasing and continuous.
::: {.proof}
The digit map $T$ is nondecreasing on $C$: if $x<y$ and the first differing ternary digit occurs at position $k$, then the corresponding first differing binary digits are $0$ and $1$, so $T(x)\le T(y)$. Equality occurs exactly at the two endpoints of a deleted interval. Since $F$ fills each such interval by this common endpoint value, $F$ is nondecreasing on all of $[0,1]$.

It remains to prove continuity. On the interior of each complementary interval, $F$ is constant. Let $x\in C$. Since $T$ is continuous on the compact set $C$, it is uniformly continuous there. Given $\varepsilon>0$, choose $\delta>0$ such that
\[
c,d\in C,\quad |c-d|<\delta
\quad\Longrightarrow\quad
|T(c)-T(d)|<\varepsilon.
\]
If $|y-x|<\delta/2$ and $y\notin C$, let $(a,b)$ be the deleted interval containing $y$. If this interval has an endpoint within $\delta$ of $x$, then
\[
F(y)=T(a)=T(b)
\]
is within $\varepsilon$ of $T(x)=F(x)$. If neither endpoint were within $\delta$ of $x$, then the whole interval would contain the segment from $y$ to one side of $x$ of length at least $\delta/2$, contradicting $|y-x|<\delta/2$ and $x\in C$. Thus in every case
\[
|F(y)-F(x)|<\varepsilon
\]
for $y$ sufficiently close to $x$. Hence $F$ is continuous at every point of $C$, and therefore on $[0,1]$.
:::

<1>2. The map $G(x)=F(x)+x$ is a bijection from $[0,1]$ to $[0,2]$.
::: {.proof}
Since $F$ is continuous, so is $G$. If $x<y$, then
\[
G(y)-G(x)
=\bigl(F(y)-F(x)\bigr)+(y-x)>0,
\]
because $F$ is nondecreasing. Thus $G$ is strictly increasing.

Also,
\[
G(0)=0,
\qquad
G(1)=F(1)+1=2.
\]
The intermediate value theorem therefore gives
\[
G([0,1])=[0,2],
\]
and strict monotonicity gives injectivity. Hence $G$ is a bijection, in fact a homeomorphism.
:::

<1>3. The image $G(C)$ has measure $1$ and yields a measurable non-Borel preimage.
::: {.proof}
Write the complement of the Cantor set as the disjoint union of its deleted open intervals:
\[
[0,1]\setminus C=\bigsqcup_{j=1}^\infty(a_j,b_j).
\]
On each closed gap $[a_j,b_j]$, the function $F$ is constant. Therefore
\[
G(b_j)-G(a_j)=b_j-a_j.
\]
Because $G$ is an increasing homeomorphism,
\[
[0,2]\setminus G(C)
=G([0,1]\setminus C)
=\bigsqcup_{j=1}^\infty(G(a_j),G(b_j)).
\]
Hence
\[
m([0,2]\setminus G(C))
=\sum_{j=1}^\infty\bigl(G(b_j)-G(a_j)\bigr)
=\sum_{j=1}^\infty(b_j-a_j)
=1,
\]
since the Cantor set has measure zero. Thus
\[
m(G(C))=2-1=1.
\]

Every set of positive outer measure contains a nonmeasurable subset, so choose
\[
N'\subseteq G(C)
\]
non-Lebesgue-measurable. Set
\[
E=G^{-1}(N').
\]
Since $E\subseteq C$ and $m(C)=0$, completeness of Lebesgue measure implies that $E$ is Lebesgue measurable.

However, $E$ is not Borel. If it were Borel, then because $G$ is a homeomorphism,
\[
N'=G(E)
\]
would be Borel in $[0,2]$, hence Lebesgue measurable, a contradiction.
:::

<1>4. A measurable function whose composition with $G^{-1}$ is not measurable.
::: {.proof}
Let
\[
\varphi=\mathbf 1_E,
\]
where $E=G^{-1}(N')$ is the measurable null set from <1>3. Then $\varphi$ is Lebesgue measurable on $[0,1]$. For $y\in[0,2]$,
\[
(\varphi\circ G^{-1})(y)
=\mathbf 1_E(G^{-1}(y))
=\mathbf 1_{G(E)}(y)
=\mathbf 1_{N'}(y).
\]
Since $N'$ is not Lebesgue measurable, its characteristic function is not measurable. Hence
\[
\varphi\circ G^{-1}
\]
is not measurable.
:::

::: problem
Extend the binary map on the Cantor set to the Cantor-Lebesgue function $F:[0,1]\to[0,1]$.

1. Prove that $F$ is continuous and nondecreasing.

2. Prove that $G(x)=F(x)+x$ is a bijection from $[0,1]$ to $[0,2]$.

3. Prove that $m(G(C))=1$, that $G(C)$ contains a nonmeasurable set $N'$, and that $G^{-1}(N')$ is measurable but not Borel.

4. Give a measurable $\varphi$ for which $\varphi\circ G^{-1}$ is not measurable.
:::

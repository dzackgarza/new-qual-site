::: problem
Prove that no continuous function on $\mathbb R$ equals $\chi_{[0,1]}$ almost everywhere.
:::

::: {.solution}
Suppose, toward a contradiction, that a continuous function $f:\mathbb R\to\mathbb R$ satisfies
\[
f=\chi_{[0,1]}
\quad\text{almost everywhere}.
\]

We first show that
\[
f(x)=0
\qquad(x<0).
\]
Indeed, if $f(x_0)\ne0$ for some $x_0<0$, continuity would give an open interval $I\subset(-\infty,0)$ around $x_0$ on which $|f|$ is bounded away from $0$. But $\chi_{[0,1]}=0$ everywhere on $I$, so $f\ne\chi_{[0,1]}$ on a set of positive measure, contradicting the assumed a.e. equality.

Similarly,
\[
f(x)=1
\qquad(0<x<1),
\]
because if $f(x_0)\ne1$ at some $x_0\in(0,1)$, continuity again produces an interval of positive measure on which $f\ne1=\chi_{[0,1]}$.

Therefore
\[
\lim_{x\to0^-}f(x)=0,
\qquad
\lim_{x\to0^+}f(x)=1,
\]
which is impossible for a continuous function at $0$.

Hence no continuous representative of $\chi_{[0,1]}$ exists.
:::

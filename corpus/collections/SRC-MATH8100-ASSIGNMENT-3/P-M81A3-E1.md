::: {.problem}
Prove that no continuous function on $\RR$ equals $\chi_{[0,1]}$ almost everywhere.
:::

::: {.solution}
The assignment sheet sets the problem and carries no solutions, so no retained solution set covers it; the argument is the card's own. Write $\lambda$ for Lebesgue measure and $\chi_{[0,1]}$ for the indicator of $[0,1]$, so that $\chi_{[0,1]}=0$ off $[0,1]$ and $=1$ on $(0,1)$.

::: pf

::: {.pf-step #left}
If $f:\RR\to\RR$ is continuous and $f=\chi_{[0,1]}$ almost everywhere, then $f(x)=0$ for every $x<0$.

::: pf-proof
Suppose $f(x_{0})\ne0$ for some $x_{0}<0$. By continuity at $x_{0}$ there is $\delta>0$ with $\abs{f(x)-f(x_{0})}<\abs{f(x_{0})}/2$ for $\abs{x-x_{0}}<\delta$, hence $\abs{f(x)}>\abs{f(x_{0})}/2>0$ on the interval $I=(x_{0}-\delta,x_{0}+\delta)$. Choosing $\delta$ smaller if necessary so that $I\subset(-\infty,0)$, we have $\chi_{[0,1]}=0$ on $I$; so $f\ne\chi_{[0,1]}$ at every point of $I$, and $\lambda(I)=2\delta>0$ contradicts equality almost everywhere.
:::

:::

::: {.pf-step #middle}
Under the same hypothesis $f(x)=1$ for every $x\in(0,1)$.

::: pf-proof
Suppose $f(x_{0})\ne1$ for some $x_{0}\in(0,1)$ and put $\varepsilon=\abs{f(x_{0})-1}>0$. By continuity at $x_{0}$ there is $\delta>0$ with $\abs{f(x)-f(x_{0})}<\varepsilon/2$ whenever $\abs{x-x_{0}}<\delta$; shrinking $\delta$ if necessary, take also $(x_{0}-\delta,x_{0}+\delta)\subset(0,1)$. For such $x$, $\abs{f(x)-1}\ge\varepsilon-\abs{f(x)-f(x_{0})}>\varepsilon/2>0$, so $f(x)\ne1=\chi_{[0,1]}(x)$. The interval $(x_{0}-\delta,x_{0}+\delta)$ then has positive length and consists of points where $f\ne\chi_{[0,1]}$, contradicting equality almost everywhere.
:::

:::

::: {.pf-step #limits}
Along $x\uparrow0$ the values $f(x)$ tend to $0$, and along $x\downarrow0$ they tend to $1$.

::: pf-proof
For $0<x<1$ step [](#middle){.pf-ref} gives $f(x)=1$, so the right-hand limit at $0$ is $1$. For $-\delta<x<0$ step [](#left){.pf-ref} gives $f(x)=0$, so the left-hand limit at $0$ is $0$.
:::

:::

::: {.pf-step #answer}
No continuous $f$ equals $\chi_{[0,1]}$ almost everywhere.

::: pf-proof
If such an $f$ existed, step [](#limits){.pf-ref} would give one-sided limits $0$ and $1$ at the point $0$. A function continuous at $0$ has equal one-sided limits there, both equal to $f(0)$; as $0\ne1$, no such $f$ is continuous at $0$, contradicting the hypothesis. So no continuous function equals $\chi_{[0,1]}$ almost everywhere.
:::

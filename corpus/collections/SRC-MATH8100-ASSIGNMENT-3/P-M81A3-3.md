::: {.problem}
Prove that every upper semicontinuous function $f:\RR^n\to\RR$ is Borel measurable.
:::

::: {.solution}

The argument is the card's own; the statement is Problem 3 of Math 8100 Assignment 3 as the card's source check records.

A function $f\colon\RR^{n}\to\RR$ is upper semicontinuous when $\limsup_{x\to x_{0}}f(x)\leq f(x_{0})$ for every $x_{0}$, and Borel measurable when $f^{-1}(B)$ is a Borel set for every Borel $B\subset\RR$.

::: pf

::: {.pf-step #sublevel}
For $a\in\RR$ the set $U_{a}=\{x\in\RR^{n}\mid f(x)<a\}$ is open.

::: pf-proof
Let $x_{0}\in U_{a}$, so $f(x_{0})<a$; the number $\eta=(a-f(x_{0}))/2$ is positive and $f(x_{0})+\eta<a$. Upper semicontinuity at $x_{0}$ says $\limsup_{x\to x_{0}}f(x)\leq f(x_{0})<f(x_{0})+\eta$, so there is $\delta>0$ with $f(x)<f(x_{0})+\eta$ whenever $\abs{x-x_{0}}<\delta$; for such $x$ then $f(x)<a$, that is $x\in U_{a}$. Hence $B_{\delta}(x_{0})\subset U_{a}$, and $x_{0}$ was an arbitrary point of $U_{a}$, so $U_{a}$ is open.
:::

:::

::: {.pf-step #generators}
The rays $(-\infty,a)$, $a\in\RR$, generate the Borel $\sigma$-algebra of $\RR$.

::: pf-proof
Every ray is open, so the $\sigma$-algebra generated by the rays is contained in the Borel $\sigma$-algebra. Conversely every open subset of $\RR$ is a countable union of bounded open intervals with rational endpoints, and $(c,d)=\RR\setminus\bigl((-\infty,c]\cup[d,\infty)\bigr)$ with $(-\infty,c]=\bigcap_{k}(-\infty,c+1/k)$ and $[d,\infty)=\RR\setminus(-\infty,d)$; so each open set lies in the $\sigma$-algebra generated by the rays, which therefore contains the Borel sets.
:::

:::

::: {.pf-step #sigma}
$\mathcal{A}=\{B\subset\RR\mid f^{-1}(B)\text{ is Borel}\}$ is a $\sigma$-algebra.

::: pf-proof
$f^{-1}(\RR)=\RR^{n}$ is Borel; $f^{-1}(\RR\setminus B)=\RR^{n}\setminus f^{-1}(B)$ is Borel when $f^{-1}(B)$ is; and $f^{-1}\bigl(\bigcup_{k}B_{k}\bigr)=\bigcup_{k}f^{-1}(B_{k})$ is Borel when each preimage is, being a countable union of Borel sets.
:::

:::

::: {.pf-step #measurable}
$f$ is Borel measurable.

::: pf-proof
Step [](#sublevel){.pf-ref} shows $f^{-1}\bigl((-\infty,a)\bigr)=U_{a}$ is open, hence Borel, for every $a$; so every ray lies in the $\sigma$-algebra $\mathcal{A}$ of step [](#sigma){.pf-ref}. By step [](#generators){.pf-ref} the rays generate the Borel sets, so $\mathcal{A}$ contains all Borel sets, which is the definition of Borel measurability.
:::

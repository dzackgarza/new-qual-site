::: problem
Map a Cantor-set point with ternary digits $a_k\in\{0,2\}$ to the number with binary digits $a_k/2$.

1. Prove that this map is well-defined and continuous, with values $0$ and $1$ at the endpoints.

2. Use it to construct a continuous function that maps a measurable set to a nonmeasurable set.
:::

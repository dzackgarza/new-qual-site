::: problem
Map a Cantor-set point with ternary digits $a_k\in\{0,2\}$ to the number with binary digits $a_k/2$.

1. Prove that this map is well-defined and continuous, with values $0$ and $1$ at the endpoints.

2. Use it to construct a continuous function that maps a measurable set to a nonmeasurable set.
:::

::: {.solution}
Let $C$ be the ternary Cantor set. Every $x\in C$ has a unique ternary expansion using only the digits $0$ and $2$:
\[
x=\sum_{k=1}^\infty a_k3^{-k},
\qquad a_k\in\{0,2\}.
\]
At endpoints there may be another ternary expansion, but that other expansion contains a digit $1$, so the expansion using only $0$ and $2$ is unique.

Define
\[
T(x)=\sum_{k=1}^\infty \frac{a_k}{2}\,2^{-k}.
\]

<1>1. The map is well-defined and continuous.
::: {.proof}
Well-definedness follows from uniqueness of the $\{0,2\}$ ternary expansion.

Suppose $x,y\in C$ and their first $k$ ternary digits agree. Then their first $k$ binary digits under $T$ also agree, so
\[
|T(x)-T(y)|
\le \sum_{j=k+1}^\infty 2^{-j}
=2^{-k}.
\]

Conversely, if the first differing ternary digit occurs at position $j\le k$, then, after possibly interchanging $x$ and $y$,
\[
a_j(x)=0,
\qquad
a_j(y)=2.
\]
The largest possible cancellation from later ternary digits is
\[
2\sum_{\ell>j}3^{-\ell}=3^{-j},
\]
while the difference contributed at position $j$ is $2\cdot3^{-j}$. Hence
\[
|x-y|\ge3^{-j}\ge3^{-k}.
\]
Therefore
\[
|x-y|<3^{-k}
\quad\Longrightarrow\quad
|T(x)-T(y)|\le2^{-k},
\]
which proves continuity.

For $x=0$, every ternary digit is $0$, so $T(0)=0$. For $x=1=0.222\ldots_3$, every binary digit is $1$, so
\[
T(1)=\sum_{k=1}^\infty2^{-k}=1.
\]
Moreover, every binary expansion determines a choice of ternary digits $a_k=2b_k$, so $T(C)=[0,1]$.
:::

<1>2. A continuous map can carry a measurable set to a nonmeasurable set.
::: {.proof}
Choose a non-Lebesgue-measurable set
\[
N\subseteq[0,1].
\]
Let
\[
E=T^{-1}(N)\subseteq C.
\]
The Cantor set has Lebesgue measure zero, and Lebesgue measure is complete, so every subset of $C$ is measurable. Hence $E$ is Lebesgue measurable.

Since $T(C)=[0,1]$,
\[
T(E)=T(T^{-1}(N))=N.
\]
Thus the continuous map
\[
T:C\to[0,1]
\]
maps the measurable set $E$ onto the nonmeasurable set $N$.
:::
:::

::: {.problem}
Let $(f_n)$ be measurable functions on $\RR^n$.
Prove that $\{x:\lim_{n\to\infty}f_n(x)\text{ exists}\}$ is measurable.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's provenance is the homework sheet alone, so the argument is the card's own. Let $(f_n)$ be a sequence of measurable functions $\RR^n\to\RR$ and let
$$
C=\{x\in\RR^n:\lim_{n\to\infty}f_n(x)\text{ exists in }\RR\}.
$$

::: pf

::: {.pf-step #cauchy}
$x\in C$ if and only if $x\in\bigcap_{k\ge1}\bigcup_{N\ge1}\bigcap_{m,n\ge N}\{y:\abs{f_m(y)-f_n(y)}<1/k\}$.

::: pf-proof
A sequence of real numbers converges if and only if it is Cauchy. Unwinding the two definitions: $(f_n(x))$ is Cauchy exactly when for every $k\ge1$ there is $N$ with $\abs{f_m(x)-f_n(x)}<1/k$ for all $m,n\ge N$. That is exactly the displayed set membership, the outer intersection ranging over $k$, the union over the modulus of convergence $N$, and the inner intersection over the pairs $m,n\ge N$.
:::

:::

::: {.pf-step #measurable_sets}
For every $k,m,n$ the set $\{y:\abs{f_m(y)-f_n(y)}<1/k\}$ is measurable.

::: pf-proof
Differences and absolute values of measurable real-valued functions are measurable: $f_m-f_n$ is measurable, and $\abs{\cdot}$ is continuous, so the composite is measurable. The set in question is the preimage of the open interval $(-1/k,1/k)$ under that measurable function, and preimages of open sets under measurable functions are measurable.
:::

:::

::: {.pf-step #closure}
$C$ is measurable.

::: pf-proof
Countable intersections and countable unions of measurable sets are measurable, and complements of measurable sets are measurable. The set in step [](#cauchy){.pf-ref} is built from the measurable sets of step [](#measurable_sets){.pf-ref} by a countable intersection, a countable union and a countable intersection, so it is measurable. Since it equals $C$ by step [](#cauchy){.pf-ref}, the convergence set is measurable, which is the assertion.
:::

::: problem
Let $(f_n)$ be measurable functions on $\mathbb R^n$.
Prove that $\{x:\lim_{n\to\infty}f_n(x)\text{ exists}\}$ is measurable.
:::

::: {.solution}
For a fixed point $x$, the real sequence $(f_n(x))$ converges if and only if it is Cauchy. Therefore the convergence set is
\[
C=
\bigcap_{k=1}^\infty
\bigcup_{N=1}^\infty
\bigcap_{m,n\ge N}
\left\{x:|f_m(x)-f_n(x)|<\frac1k\right\}.
\]

For every $m,n,k$, the function
\[
x\longmapsto |f_m(x)-f_n(x)|
\]
is measurable, so the set
\[
\left\{x:|f_m(x)-f_n(x)|<\frac1k\right\}
\]
is measurable. Countable unions and intersections of measurable sets are measurable, hence $C$ is measurable.

Thus
\[
\boxed{\{x:\lim_{n\to\infty}f_n(x)\text{ exists}\}\text{ is measurable}.}
\]
:::

::: problem
1. For every $E\subseteq\mathbb R^n$, prove that some Borel set $B\supseteq E$ satisfies $m(B)=m^*(E)$.

2. For every measurable $E\subseteq\mathbb R^n$, prove that some Borel set $B\subseteq E$ satisfies $m(B)=m(E)$.

3. If also $m(E)<\infty$, prove that for every $\varepsilon>0$ there is a finite union of closed cubes $A$ with $m(E\mathbin\triangle A)<\varepsilon$.
:::

::: {.solution}
<1>1. Every set has a Borel hull of the same outer measure.
::: {.proof}
If $m^*(E)=\infty$, take $B=\mathbb R^n$. Assume $m^*(E)<\infty$.

By the definition of Lebesgue outer measure, for each $k\ge1$ there is an open set $G_k\supseteq E$ such that
\[
m(G_k)<m^*(E)+2^{-k}.
\]
Set
\[
B=\bigcap_{k=1}^\infty G_k.
\]
Then $B$ is Borel and contains $E$. By monotonicity of outer measure,
\[
m^*(E)\le m(B),
\]
while for every $k$,
\[
m(B)\le m(G_k)<m^*(E)+2^{-k}.
\]
Letting $k\to\infty$ gives
\[
m(B)=m^*(E).
\]
:::

<1>2. Every measurable set has a Borel kernel of the same measure.
::: {.proof}
For each $N\ge1$, let
\[
E_N=E\cap[-N,N]^n.
\]
Then $E_N$ is measurable and has finite measure. By inner regularity of Lebesgue measure, for every $j\ge1$ there exists a compact set
\[
K_{N,j}\subseteq E_N
\]
such that
\[
m(E_N\setminus K_{N,j})<2^{-j}.
\]
Define
\[
B_N=\bigcup_{j=1}^\infty K_{N,j}.
\]
Then $B_N$ is Borel, $B_N\subseteq E_N$, and
\[
m(E_N\setminus B_N)=0.
\]

Now set
\[
B=\bigcup_{N=1}^\infty B_N.
\]
Then $B$ is Borel and $B\subseteq E$. Moreover,
\[
E\setminus B
\subseteq
\bigcup_{N=1}^\infty(E_N\setminus B_N),
\]
so $m(E\setminus B)=0$. Therefore
\[
m(B)=m(E),
\]
with the equality valid also when $m(E)=\infty$.
:::

<1>3. Approximate a finite-measure measurable set by finitely many closed cubes.
::: {.proof}
Fix $\varepsilon>0$. By inner regularity choose a compact set
\[
K\subseteq E
\]
such that
\[
m(E\setminus K)<\frac\varepsilon2.
\]
By outer regularity choose an open set
\[
G\supseteq E
\]
such that
\[
m(G\setminus E)<\frac\varepsilon2.
\]

For each $x\in K$, since $G$ is open there is a closed cube $Q_x$ containing $x$ in its interior and satisfying
\[
Q_x\subseteq G.
\]
The interiors of these cubes cover the compact set $K$, so finitely many suffice:
\[
K\subseteq Q_1\cup\cdots\cup Q_M\subseteq G.
\]
Set
\[
A=Q_1\cup\cdots\cup Q_M.
\]
Then $A$ is a finite union of closed cubes and
\[
E\triangle A
\subseteq
(E\setminus K)\cup(G\setminus E).
\]
Hence
\[
m(E\triangle A)
\le m(E\setminus K)+m(G\setminus E)
<\varepsilon.
\]
:::

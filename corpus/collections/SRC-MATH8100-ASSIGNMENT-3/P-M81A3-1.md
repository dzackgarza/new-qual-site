::: problem
1. For every $E\subseteq\mathbb R^n$, prove that some Borel set $B\supseteq E$ satisfies $m(B)=m^*(E)$.
2. For every measurable $E\subseteq\mathbb R^n$, prove that some Borel set $B\subseteq E$ satisfies $m(B)=m(E)$.
3. If also $m(E)<\infty$, prove that for every $\varepsilon>0$ there is a finite union of closed cubes $A$ with $m(E\mathbin\triangle A)<\varepsilon$.
:::

::: {.problem}
Let $f$ be measurable and finite almost everywhere on $[0,1]$.
Prove that continuous functions $g_n$ exist with $g_n\to f$ almost everywhere.
:::

::: {.solution}
The collection's `provenance` is the assignment sheet `assets/attachments/Analysis HW3.pdf`, and no solutions sheet accompanies it, so the argument below is the card's own. Throughout $m$ is Lebesgue measure on $[0,1]$, and $f$ is measurable and finite almost everywhere.

::: pf

::: {.pf-step #reduce}
One may assume $f(x) \in \RR$ for every $x \in [0,1]$.

::: pf-proof
Changing $f$ on a null set changes neither measurability nor any almost-everywhere statement, and if the modified $f$ is a limit almost everywhere of continuous functions, then so is the original: the two differ only on a null set. So redefine $f$ to be $0$ on the null set where it is not finite.

:::

:::

::: {.pf-step #lusin}
For each $n \ge 1$ there is a compact $K_{n} \subseteq [0,1]$ with $m\bigl([0,1]\setminus K_{n}\bigr) < 2^{-n}$ on which the restriction of $f$ is continuous.

::: pf-proof
This is Lusin's theorem, applicable to the measurable, finite-valued $f$ of step [](#reduce){.pf-ref} on the finite measure space $[0,1]$, with $\varepsilon = 2^{-n}$.

:::

:::

::: {.pf-step #tietze}
For each $n$ there is a continuous $g_{n}\colon[0,1]\to\RR$ with $g_{n} = f$ on $K_{n}$.

::: pf-proof
$K_{n}$ is compact, hence closed in the metric space $[0,1]$, and $[0,1]$ is normal; the restriction $\restrictionof{f}{K_{n}}$ is continuous and real-valued on the closed set $K_{n}$, so the Tietze extension theorem extends it to a continuous real-valued function on $[0,1]$, which is $g_{n}$.

:::

:::

::: {.pf-step #bc}
For almost every $x \in [0,1]$ there is $N(x)$ with $x \in K_{n}$ for all $n \ge N(x)$.

::: pf-proof
$\sum_{n} m\bigl([0,1]\setminus K_{n}\bigr) < \sum_{n}2^{-n} = 1 < \infty$, so by the Borel--Cantelli lemma the set of $x$ lying in infinitely many of the sets $[0,1]\setminus K_{n}$ is null. Its complement is the set of $x$ that lie in $[0,1]\setminus K_{n}$ for only finitely many $n$, that is, in $K_{n}$ for all sufficiently large $n$.

:::

:::

::: {.pf-step #converges}
$g_{n}(x) \to f(x)$ for almost every $x \in [0,1]$.

::: pf-proof
For $x$ as in step [](#bc){.pf-ref} and every $n \ge N(x)$ one has $x \in K_{n}$, hence $g_{n}(x) = f(x)$ by step [](#tietze){.pf-ref}; a sequence that is eventually constant with value $f(x)$ converges to $f(x)$.

:::

:::

::: pf-step
There are continuous $g_{n}$ on $[0,1]$ with $g_{n} \to f$ almost everywhere.

::: pf-proof
Step [](#tietze){.pf-ref} supplies the continuous $g_{n}$ and step [](#converges){.pf-ref} the almost-everywhere convergence; step [](#reduce){.pf-ref} covers the value taken on the null set where $f$ is infinite.

:::

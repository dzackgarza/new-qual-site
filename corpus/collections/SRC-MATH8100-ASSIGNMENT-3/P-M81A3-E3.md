::: problem
Let $f$ be measurable and finite almost everywhere on $[0,1]$.
Prove that continuous functions $g_n$ exist with $g_n\to f$ almost everywhere.
:::

::: {.solution}
Changing $f$ on a null set does not affect the desired conclusion, so redefine $f$ on the set where it is not finite and assume from now on that
\[
f(x)\in\mathbb R
\qquad\text{for every }x\in[0,1].
\]

For each $n\ge1$, Lusin's theorem gives a compact set
\[
K_n\subseteq[0,1]
\]
such that
\[
m([0,1]\setminus K_n)<2^{-n}
\]
and such that the restriction
\[
f|_{K_n}:K_n\to\mathbb R
\]
is continuous.

Because $K_n$ is closed in the normal space $[0,1]$, the Tietze extension theorem gives a continuous function
\[
g_n:[0,1]\to\mathbb R
\]
such that
\[
g_n=f
\qquad\text{on }K_n.
\]

Now
\[
\sum_{n=1}^\infty m([0,1]\setminus K_n)
\le\sum_{n=1}^\infty2^{-n}<\infty.
\]
By the Borel--Cantelli lemma, almost every $x\in[0,1]$ belongs to only finitely many of the complements $[0,1]\setminus K_n$. Equivalently, for almost every $x$ there exists $N(x)$ such that
\[
x\in K_n
\qquad\text{for all }n\ge N(x).
\]
For such $x$,
\[
g_n(x)=f(x)
\qquad\text{for all }n\ge N(x).
\]
Hence
\[
g_n(x)\longrightarrow f(x)
\]
for almost every $x\in[0,1]$.
:::

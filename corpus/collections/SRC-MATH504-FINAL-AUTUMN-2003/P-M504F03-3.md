::: {.problem}
Assume that $G$ is a group of order $231 = 3 \times 7 \times 11$. Show that $G$ contains a normal Sylow 7-subgroup and a central Sylow 11-subgroup.
:::

::: {.solution}

The argument is the card's own; the card is an examination problem and no published solution is retained for it.

Let $G$ be a group of order $231=3\cdot7\cdot11$, and let $n_{p}$ denote the number of Sylow $p$-subgroups of $G$.

::: pf

::: {.pf-step #n3}
$n_{3}\in\{1,7\}$.

::: pf-proof
The Sylow theorems give $n_{3}\equiv1\pmod 3$ and $n_{3}\mid 231/3=77$. The divisors of $77$ are $1,7,11,77$, with residues $1,1,2,2$ modulo $3$; so $n_{3}\in\{1,7\}$.
:::

:::

::: {.pf-step #n7}
$n_{7}=1$.

::: pf-proof
$n_{7}\equiv1\pmod 7$ and $n_{7}\mid 231/7=33$. The divisors of $33$ are $1,3,11,33$, with residues $1,3,4,5$ modulo $7$, so only $n_{7}=1$ is possible.
:::

:::

::: {.pf-step #n11}
$n_{11}=1$.

::: pf-proof
$n_{11}\equiv1\pmod{11}$ and $n_{11}\mid 231/11=21$. The divisors of $21$ are $1,3,7,21$, with residues $1,3,7,10$ modulo $11$, so $n_{11}=1$.
:::

:::

::: {.pf-step #normal}
$G$ has a normal Sylow $7$-subgroup and a normal Sylow $11$-subgroup.

::: pf-proof
A Sylow $p$-subgroup is normal exactly when $n_{p}=1$, since the conjugates of a Sylow $p$-subgroup are all the Sylow $p$-subgroups and a subgroup with no distinct conjugate is normal. Steps [](#n7){.pf-ref} and [](#n11){.pf-ref} give $n_{7}=n_{11}=1$.
:::

:::

::: {.pf-step #cyclic}
Let $P$ be the normal Sylow $11$-subgroup. Then $P\cong C_{11}$ is cyclic, generated by some $x$, and $P$ is abelian.

::: pf-proof
$P$ has order $11$, a prime, so it is cyclic: pick $x\in P$ with $x\neq e$, whose order is a divisor of $11$ greater than $1$, hence $11$; then $P=\langle x\rangle\cong C_{11}$.
:::

:::

::: {.pf-step #conjugation}
Conjugation gives a homomorphism $\theta\colon G\to\operatorname{Aut}(P)\cong C_{10}$.

::: pf-proof
For $g\in G$ the map $c_{g}(y)=gyg^{-1}$ is an automorphism of $G$; since $P$ is normal, $c_{g}(P)=P$, so $c_{g}$ restricts to an automorphism of $P$. The assignment $g\mapsto \restrictionof{c_{g}}{P}$ is a homomorphism because $c_{g}c_{h}=c_{gh}$, and $\operatorname{Aut}(C_{11})$ has order $\varphi(11)=10$.
:::

:::

::: {.pf-step #trivial}
$\theta$ is trivial.

::: pf-proof
By the first isomorphism theorem the order of the image of $\theta$ divides $\abs{G}=231$ and also divides $\abs{\operatorname{Aut}(P)}=10$; since $\gcd(231,10)=1$ (as $231=3\cdot7\cdot11$ and $10=2\cdot5$), the image has order $1$.
:::

:::

::: {.pf-step #central}
$P$ is central in $G$.

::: pf-proof
$\theta$ trivial means $gxg^{-1}=x$ for every $g\in G$, so $x$ is central. Every element of $P$ is a power of $x$, and a power of a central element is central, so $P\subset Z(G)$: the Sylow $11$-subgroup is central.
:::

:::

::: {.pf-step}
$G$ contains a normal Sylow $7$-subgroup and a central Sylow $11$-subgroup.

::: pf-proof
Step [](#normal){.pf-ref} gives the normal Sylow $7$-subgroup and step [](#central){.pf-ref} the centrality of the Sylow $11$-subgroup.
:::

::: {.problem}
Show that any finite abelian group is isomorphic to the direct product of its Sylow subgroups (without using the fundamental theorem of finitely generated abelian groups).
:::

::: {.solution}
No retained solution set covers this problem, so the argument is the card's own; it is the induction on the number of distinct primes, using only the Sylow theorems, Cauchy's theorem and the recognition theorem for direct products.

::: pf

::: {.pf-step #base}
If $\abs G$ is a power of a single prime then $G$ equals its Sylow subgroup for that prime.

::: pf-proof
A group of order $p^n$ has a Sylow $p$-subgroup of order $p^n$, namely $G$ itself, so the product of the Sylow subgroups is $G$.
:::

:::

::: {.pf-step #induction}
Assume the result for groups whose order has fewer than $m$ distinct prime factors, and let $\abs G=p_1^{i_1}\cdots p_m^{i_m}$ with the $p_j$ distinct primes and $m\ge2$. Let $P_j$ be the Sylow $p_j$-subgroup and $H=\langle P_1,\dots,P_{m-1}\rangle$. Then $\abs H=p_1^{i_1}\cdots p_{m-1}^{i_{m-1}}$ and $H\cong P_1\times\cdots\times P_{m-1}$.

::: pf-proof
Every element of $H$ is a product of commuting elements of orders dividing $p_j^{i_j}$ with $j\le m-1$, since $G$ is abelian and each $P_j$ is a $p_j$-group; a product of commuting elements of pairwise coprime orders has order the product of the orders, so every element of $H$ has order dividing $N=p_1^{i_1}\cdots p_{m-1}^{i_{m-1}}$. Hence $p_m\nmid\abs H$, since otherwise Cauchy's theorem would give an element of order $p_m$ in $H$. On the other hand $H$ contains $P_j$ for $j\le m-1$, so $N=\abs{P_1}\cdots\abs{P_{m-1}}$ divides $\abs H$; and $\abs H$ divides $\abs G$ by Lagrange. A divisor of $\abs G$ that is a multiple of $N$ and not divisible by $p_m$ is $N$ itself, so $\abs H=N$. The order of $H$ has $m-1$ distinct prime factors, and $H$ is abelian as a subgroup of $G$, so the induction hypothesis gives $H\cong P_1\times\cdots\times P_{m-1}$.
:::

:::

::: {.pf-step #coprime}
$H\cap P_m=\{1\}$ and $HP_m=G$.

::: pf-proof
Both $H$ and $P_m$ are normal in the abelian group $G$. An element of $H$ has order dividing $N$, which is prime to $p_m$, while an element of $P_m$ has order a power of $p_m$, so a common element has order $1$ and $H\cap P_m=\{1\}$. Then $\abs{HP_m}=\abs H\abs{P_m}/\abs{H\cap P_m}=N\,p_m^{i_m}=\abs G$, and $HP_m\subseteq G$ gives $HP_m=G$.
:::

:::

::: {.pf-step}
$\boxed{G\cong P_1\times\cdots\times P_m}$.

::: pf-proof
$H$ and $P_m$ are normal subgroups of $G$ with trivial intersection and product $G$, so the recognition theorem for direct products gives $G\cong H\times P_m$. Composing with the isomorphism $H\cong P_1\times\cdots\times P_{m-1}$ of step [](#induction){.pf-ref} gives $G\cong P_1\times\cdots\times P_m$, the direct product of the Sylow subgroups. The base case is step [](#base){.pf-ref}, and the induction terminates after $m$ steps, so every finite abelian group is such a product.
:::

::: {.remark title="Alternative proof"}
Let $G$ be a finite abelian group of order $\abs{G} = p_1^{a_1} \cdots p_k^{a_k}$, where $p_1, \ldots, p_k$ are distinct primes and $a_i \ge 1$. For each $i$ define
$$P_i = \left\{ x \in G : x^{p_i^{a_i}} = e \right\}.$$

::: pf

::: pf-step

Each $P_i$ is the unique Sylow $p_i$-subgroup of $G$.

::: pf-proof

Because $G$ is abelian, $(xy)^{p_i^{a_i}} = x^{p_i^{a_i}} y^{p_i^{a_i}} = e$ for $x, y \in P_i$, and $(x^{-1})^{p_i^{a_i}} = e$, so $P_i$ is a subgroup. The order of every element of $P_i$ is a power of $p_i$, so by Cauchy's theorem $P_i$ is a $p_i$-group, and $\abs{P_i}\le p_i^{a_i}$ by Lagrange's theorem. Every Sylow $p_i$-subgroup has exponent dividing $p_i^{a_i}$, so it lies in $P_i$; hence $\abs{P_i} = p_i^{a_i}$ and $P_i$ is the only Sylow $p_i$-subgroup.

:::

:::

::: {.pf-step #s2}

For each $j$, let $Q_j = \prod_{i \ne j} P_i$. Then $P_j \cap Q_j = \{e\}$.

::: pf-proof

Every element of $Q_j$ has order dividing $\prod_{i \neq j} p_i^{a_i} = \abs{G} / p_j^{a_j}$, and every element of $P_j$ has order dividing $p_j^{a_j}$. An element $z \in P_j \cap Q_j$ therefore has order dividing $\gcd(p_j^{a_j}, \abs{G}/p_j^{a_j}) = 1$, so $z = e$.

:::

:::

::: {.pf-step #s3}

$G = P_1 P_2 \cdots P_k$.

::: pf-proof

Let $m_i = \abs{G} / p_i^{a_i}$. Since the $p_i$ are distinct primes, $\gcd(m_1, \ldots, m_k) = 1$, and Bézout's identity gives integers $u_i$ with $\sum_{i=1}^k u_i m_i = 1$. For $g \in G$,
$$g = g^{\sum_{i} u_i m_i} = \prod_{i=1}^k g^{u_i m_i},$$
and $g_i = g^{u_i m_i}$ satisfies $g_i^{p_i^{a_i}} = (g^{\abs{G}})^{u_i} = e$, so $g_i \in P_i$.

:::

:::

::: pf-step

The map $\Phi: P_1 \times \cdots \times P_k \to G$, $\Phi(g_1, \ldots, g_k) = g_1 \cdots g_k$, is an isomorphism.

::: pf-proof

Since $G$ is abelian, $\Phi$ is a homomorphism, and it is surjective by step [](#s3){.pf-ref}. If $\Phi(g_1, \ldots, g_k) = e$, then for each $j$, $g_j^{-1} = \prod_{i \neq j} g_i \in P_j \cap Q_j$, so $g_j = e$ by step [](#s2){.pf-ref}. Hence $\Phi$ is injective.

:::

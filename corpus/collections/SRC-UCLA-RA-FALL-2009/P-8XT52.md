::: {.problem}
Let $f:[0,1]\to\mathbb{R}$ be continuous with $$\min_{0\le x\le 1}f(x)=0.$$ Assume that for all $0\le a<b\le 1$ we have $$\int_a^b\Bigl(f(x)-\min_{a\le y\le b}f(y)\Bigr)\,dx\le\frac12|b-a|.$$

(a) Prove that for all $\lambda\ge 0$: $$\bigl|\{x:f(x)>\lambda+1\}\bigr|\le\frac12\bigl|\{x:f(x)>\lambda\}\bigr|,$$ where $|S|$ denotes Lebesgue measure of the set $S$.

(b) Prove that for all $1\le c<2$, $$\int_0^1 c^{f(x)}\,dx\le\frac{100}{2-c}.$$ (The constant $100$ is not optimal, but is certainly large enough.)
:::

::: {.solution}
Since
\[
\min_{[0,1]}f=0,
\]
we have
\[
f\ge0
\]
on $[0,1]$.
For $\lambda\ge0$, write
\[
E_\lambda=\{x\in[0,1]:f(x)>\lambda\}.
\]

<1>1. Let $I$ be a connected component of $E_\lambda$, and let
\[
J=\overline I=[a,b]
\]
be its closure in $[0,1]$.
Then
\[
\min_J f=\lambda.
\]
::: {.proof}
The set $E_\lambda$ is relatively open in $[0,1]$ because $f$ is continuous, so its connected components are intervals.
Also $E_\lambda\ne[0,1]$: for $\lambda\ge0$, a point where $f=0$ does not belong to $E_\lambda$.

On $I$ one has $f>\lambda$.
By continuity, every point of $J=\overline I$ satisfies
\[
f\ge\lambda.
\]
At least one endpoint of $J$ is a boundary point of $I$ lying in $[0,1]\setminus E_\lambda$; at such a point continuity from inside $I$ gives
\[
f=\lambda.
\]
Thus the minimum of $f$ on $J$ is exactly $\lambda$.
:::

<1>2. For every connected component $I$ of $E_\lambda$,
\[
|I\cap E_{\lambda+1}|
\le\frac12|I|.
\]
::: {.proof}
Let $J=[a,b]=\overline I$.
By <1>1 and the hypothesis of the problem,
\[
\int_a^b(f(x)-\lambda)\,dx
\le\frac12(b-a)
=\frac12|I|,
\]
since adjoining the endpoints does not change the length.

On
\[
I\cap E_{\lambda+1}
\]
we have
\[
f(x)-\lambda>1.
\]
Therefore
\[
|I\cap E_{\lambda+1}|
\le
\int_{I\cap E_{\lambda+1}}(f(x)-\lambda)\,dx
\le
\int_a^b(f(x)-\lambda)\,dx
\le\frac12|I|.
\]
:::

<1>3. For every $\lambda\ge0$,
\[
\boxed{|E_{\lambda+1}|\le\frac12|E_\lambda|.}
\]
::: {.proof}
The relatively open set $E_\lambda$ is a countable disjoint union of its interval components $(I_j)_j$.
Since
\[
E_{\lambda+1}\subseteq E_\lambda,
\]
we have the disjoint decomposition
\[
E_{\lambda+1}
=\bigsqcup_j(E_{\lambda+1}\cap I_j).
\]
Using countable additivity of Lebesgue measure and <1>2,
\[
|E_{\lambda+1}|
=\sum_j|E_{\lambda+1}\cap I_j|
\le\frac12\sum_j|I_j|
=\frac12|E_\lambda|.
\]
This proves part (a).
:::

<1>4. For every integer $k\ge0$,
\[
|E_k|\le2^{-k}.
\]
::: {.proof}
Since $E_0\subseteq[0,1]$,
\[
|E_0|\le1.
\]
Applying <1>3 successively with
\[
\lambda=0,1,\ldots,k-1
\]
gives
\[
|E_k|
\le2^{-k}|E_0|
\le2^{-k}.
\]
:::

<1>5. If $1<c<2$, then
\[
\int_0^1c^{f(x)}\,dx
=1+(\log c)\int_0^\infty c^t|E_t|\,dt.
\]
::: {.proof}
For every $s\ge0$,
\[
c^s
=1+(\log c)\int_0^s c^t\,dt.
\]
Taking $s=f(x)$ and writing the integral with an indicator gives
\[
c^{f(x)}
=1+(\log c)\int_0^\infty c^t\mathbf1_{\{f(x)>t\}}\,dt.
\]
The integrand is nonnegative, so Tonelli's theorem allows the order of integration to be reversed:
\[
\begin{aligned}
\int_0^1c^{f(x)}\,dx
&=1+(\log c)\int_0^\infty c^t
\left(\int_0^1\mathbf1_{E_t}(x)\,dx\right)dt\\
&=1+(\log c)\int_0^\infty c^t|E_t|\,dt.
\end{aligned}
\]
:::

<1>6. For $1<c<2$,
\[
\int_0^1c^{f(x)}\,dx
\le\frac{c}{2-c}.
\]
::: {.proof}
If $k\le t<k+1$, then
\[
E_t\subseteq E_k,
\]
so <1>4 gives
\[
|E_t|\le2^{-k}.
\]
Using <1>5 and splitting the integral into unit intervals,
\[
\begin{aligned}
\int_0^1c^{f(x)}\,dx
&\le
1+(\log c)\sum_{k=0}^\infty2^{-k}
\int_k^{k+1}c^t\,dt\\
&=1+\sum_{k=0}^\infty2^{-k}(c^{k+1}-c^k)\\
&=1+(c-1)\sum_{k=0}^\infty\left(\frac c2\right)^k\\
&=1+\frac{c-1}{1-c/2}\\
&=\frac{c}{2-c}.
\end{aligned}
\]
The geometric series converges because $c<2$.
:::

<1>7. For every $1\le c<2$,
\[
\boxed{
\int_0^1c^{f(x)}\,dx
\le\frac{100}{2-c}.}
\]
::: {.proof}
If $c=1$, the integral equals $1$, while
\[
\frac{100}{2-c}=100.
\]
If $1<c<2$, <1>6 gives
\[
\int_0^1c^{f(x)}\,dx
\le\frac{c}{2-c}
\le\frac2{2-c}
\le\frac{100}{2-c}.
\]
This proves part (b).
:::
:::

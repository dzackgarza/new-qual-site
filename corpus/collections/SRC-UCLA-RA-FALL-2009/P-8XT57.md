::: {.problem}
Let $f$ be a non-constant meromorphic function in the complex plane.
Assume that if $f$ has a pole at the point $z\in\mathbb{C}$, then $z$ is of the form $n\pi$ with an integer $n\in\mathbb{Z}$.
Assume that for all non-real $z$ we have the estimate $$|f(z)|\le\bigl(1+|\operatorname{Im}(z)|^{-1}\bigr)e^{-|\operatorname{Im}(z)|}.$$ Prove that for every integer $n\in\mathbb{Z}$, $f$ has a pole at the point $\pi n$.
:::

::: {.solution}
<1>1. Every pole of $f$ is simple.
::: {.proof}
Fix $n\in\mathbb Z$ and suppose that $f$ has a pole of order $m$ at $n\pi$.
Then for some $c\ne0$,
\[
f(n\pi+w)=c w^{-m}+O(|w|^{1-m})
\qquad(w\to0).
\]
Putting $w=iy$ with real $y\to0$ gives
\[
|f(n\pi+iy)|\asymp |y|^{-m}.
\]
On the other hand, the assumed estimate gives
\[
|f(n\pi+iy)|
\le (1+|y|^{-1})e^{-|y|}
=O(|y|^{-1}).
\]
Hence $m\le1$, so $m=1$.
:::

<1>2. The function
\[
h(z)=f(z)\sin z
\]
extends to an entire function on $\mathbb C$.
::: {.proof}
Away from $\pi\mathbb Z$, the function $f$ is holomorphic, hence so is $h$.
At $n\pi$, either $f$ is holomorphic or, by <1>1, it has a simple pole.
Since $\sin z$ has a simple zero at every $n\pi$, the product $f(z)\sin z$ has a removable singularity there in either case.
Removing all of these singularities gives an entire function $h$.
:::

<1>3. For every non-real $z=x+iy$,
\[
|h(z)|\le 1+\frac1{|y|}.
\]
::: {.proof}
The identity
\[
|\sin(x+iy)|^2=\sin^2x+\sinh^2y
\]
implies
\[
|\sin(x+iy)|\le \cosh |y|.
\]
Therefore
\[
\begin{aligned}
|h(z)|
&\le \left(1+\frac1{|y|}\right)e^{-|y|}\cosh|y|\\
&=\left(1+\frac1{|y|}\right)\frac{1+e^{-2|y|}}2\\
&\le 1+\frac1{|y|}.
\end{aligned}
\]
:::

<1>4. There is a constant $C$ such that, for every $a\in[-1/2,1/2]$,
\[
\int_0^{2\pi}|\sin t+a|^{-1/2}\,dt\le C.
\]
::: {.proof}
Splitting the circle into the two monotonic halves of the sine function and substituting $u=\sin t$ gives
\[
\int_0^{2\pi}|\sin t+a|^{-1/2}\,dt
=2\int_{-1}^{1}
\frac{|u+a|^{-1/2}}{\sqrt{1-u^2}}\,du.
\]
On $[-3/4,3/4]$, the factor $(1-u^2)^{-1/2}$ is uniformly bounded, while
\[
\sup_{|a|\le1/2}\int_{-3/4}^{3/4}|u+a|^{-1/2}\,du<\infty
\]
because the singularity has exponent $1/2<1$.

On $[3/4,1]$, one has $|u+a|\ge1/4$, so the remaining integrand is bounded by a constant multiple of $(1-u^2)^{-1/2}$, which is integrable there.
The same argument applies on $[-1,-3/4]$.
Thus the displayed integrals are bounded uniformly in $a$.
:::

<1>5. The entire function $h$ satisfies $|h(w)|\le1$ for every $w\in\mathbb C$.
::: {.proof}
Fix $w=x_0+iy_0$.
If $h(w)=0$ there is nothing to prove, so suppose $h(w)\ne0$.
The function
\[
u(z)=\log|h(z)|
\]
is subharmonic, hence for every $R>0$,
\[
\log|h(w)|
\le \frac1{2\pi}\int_0^{2\pi}
\log|h(w+Re^{it})|\,dt.
\]
Take $R>2|y_0|$ and put $a=y_0/R$, so $|a|<1/2$.
For all but finitely many $t$, the point $w+Re^{it}$ is non-real, and <1>3 gives
\[
\log|h(w+Re^{it})|
\le
\log\left(1+\frac1{R|\sin t+a|}\right).
\]
The exceptional $t$ have measure zero and do not affect the integral.

For $s>0$,
\[
\log(1+s)\le2\sqrt{s}.
\]
Indeed,
\[
\log(1+s)=\int_0^s\frac{dt}{1+t}
\le\int_0^s t^{-1/2}\,dt=2\sqrt s.
\]
Consequently <1>4 yields
\[
\begin{aligned}
\log|h(w)|
&\le \frac1{2\pi}\int_0^{2\pi}
\log\left(1+\frac1{R|\sin t+a|}\right)dt\\
&\le \frac{1}{\pi\sqrt R}
\int_0^{2\pi}|\sin t+a|^{-1/2}\,dt\\
&\le \frac{C}{\pi\sqrt R}.
\end{aligned}
\]
Letting $R\to\infty$ gives $\log|h(w)|\le0$, hence $|h(w)|\le1$.
:::

<1>6. The function $h$ is a nonzero constant.
::: {.proof}
By <1>2 and <1>5, $h$ is bounded and entire.
Liouville's theorem therefore gives
\[
h\equiv c
\]
for some constant $c$.
If $c=0$, then
\[
f(z)=0
\qquad(z\notin\pi\mathbb Z),
\]
because $\sin z\ne0$ there.
Thus $f$ vanishes on a nonempty open set and hence, as a meromorphic function, is identically zero, contradicting the hypothesis that it is nonconstant.
Therefore $c\ne0$.
:::

<1>7. The function $f$ has a pole at every $n\pi$.
::: {.proof}
Fix $n\in\mathbb Z$.
If $f$ were holomorphic at $n\pi$, then the entire extension of $h=f\sin z$ would satisfy
\[
h(n\pi)=f(n\pi)\sin(n\pi)=0.
\]
But <1>6 gives $h\equiv c$ with $c\ne0$, a contradiction.
Thus $f$ is not holomorphic at $n\pi$.
By the hypotheses its only possible singularity there is a pole, and <1>1 shows that pole is simple.
Since $n$ was arbitrary, every $n\pi$ is a pole of $f$.
:::

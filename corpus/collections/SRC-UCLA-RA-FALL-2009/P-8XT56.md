::: {.problem}
Let $f$ be an analytic function in the open unit disc $D=\{z:|z|<1\}$ that obeys $|f(z)|\le 1$ for all $z\in D$.
Let $g$ be the restriction of $f$ to the real interval $(0,1)$ and assume $$\lim_{r\to 1}g(r)=1\qquad\text{and}\qquad\lim_{r\to 1}g'(r)=0.$$ Prove that $f$ is constant.
:::

::: {.solution}
<1>1. As $r\to1^-$,
\[
1-g(r)=o(1-r).
\]
::: {.proof}
Let $\varepsilon>0$.
Since $g'(r)\to0$, there is $r_0<1$ such that
\[
|g'(t)|<\varepsilon
\qquad(r_0<t<1).
\]
If $r_0<r<s<1$, then
\[
|g(s)-g(r)|
=\left|\int_r^s g'(t)\,dt\right|
\le \varepsilon(s-r).
\]
Letting $s\to1^-$ and using $g(s)\to1$ gives
\[
|1-g(r)|\le\varepsilon(1-r).
\]
Since $\varepsilon$ is arbitrary,
\[
\frac{|1-g(r)|}{1-r}\longrightarrow0.
\]
:::

<1>2. If $f$ is nonconstant and $a=f(0)$, then $|a|<1$ and
\[
h(z)=\frac{f(z)-a}{1-\overline a\,f(z)}
\]
is a holomorphic self-map of $D$ satisfying $h(0)=0$.
::: {.proof}
If $|f(z_0)|=1$ at some interior point, the maximum modulus principle would make $f$ constant.
Thus nonconstancy implies
\[
|f(z)|<1
\qquad(z\in D),
\]
in particular $|a|<1$.

The Möbius map
\[
\varphi_a(w)=\frac{w-a}{1-\overline a\,w}
\]
is an automorphism of $D$ carrying $a$ to $0$.
Therefore $h=\varphi_a\circ f$ is a holomorphic self-map of $D$ and $h(0)=0$.
:::

<1>3. Under the nonconstancy assumption,
\[
1-|h(r)|=o(1-r)
\qquad(r\to1^-).
\]
::: {.proof}
Set
\[
\xi=\varphi_a(1)=\frac{1-a}{1-\overline a}.
\]
Since
\[
|1-a|=|1-\overline a|,
\]
one has $|\xi|=1$.

For any $w$ for which the denominators are nonzero,
\[
\varphi_a(w)-\varphi_a(1)
=
\frac{(1-|a|^2)(w-1)}
{(1-\overline a\,w)(1-\overline a)}.
\]
As $r\to1^-$, one has $f(r)=g(r)\to1$, so
\[
1-\overline a\,f(r)\longrightarrow1-\overline a\ne0.
\]
Hence the displayed identity and <1>1 imply
\[
h(r)-\xi=o(1-r).
\]
Because $|h(r)|\le1$ and $|\xi|=1$,
\[
0\le1-|h(r)|
\le |\xi-h(r)|
=o(1-r).
\]
:::

<1>4. The function $f$ is constant.
::: {.proof}
Suppose otherwise.
By <1>2, the normalized map $h$ satisfies $h(0)=0$ and maps $D$ into itself.
Schwarz's lemma therefore gives
\[
|h(r)|\le r
\qquad(0<r<1),
\]
so
\[
1-|h(r)|\ge1-r.
\]
This contradicts <1>3, which says
\[
\frac{1-|h(r)|}{1-r}\longrightarrow0.
\]
Thus $f$ is constant.
Since $g(r)\to1$, the constant is in fact $1$.
:::

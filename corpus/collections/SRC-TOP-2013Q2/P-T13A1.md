::: {.problem}
Let $X_\alpha$ be non-empty topological spaces and suppose that $X=\prod_\alpha X_\alpha$ is endowed with the product topology.

(a) Prove that each projection map $\pi_\alpha$ is continuous and open.

(b) Prove that $X$ is Hausdorff if and only if each space $X_\alpha$ is Hausdorff.
:::

::: {.solution}
Fix an index $\alpha$ and let $\pi_\alpha\colon X\to X_\alpha$ be the projection.

::: pf

::: {.pf-step #pi-alpha-continuous}
$\pi_\alpha$ is continuous.

::: pf-proof
For every open $U\subseteq X_\alpha$, the set $\pi_\alpha^{-1}(U)$ belongs to the standard subbasis of the product topology, so it is open.
:::

:::

::: {.pf-step #pi-alpha-open}
$\pi_\alpha$ is open.

::: pf-proof
Every open set is a union of basic open sets, and images preserve unions, so it suffices to treat a basic open set $B=\prod_\beta U_\beta$, with each $U_\beta$ open and $U_\beta=X_\beta$ for all but finitely many $\beta$.
If some $U_\beta$ is empty, then $\pi_\alpha(B)=\varnothing$.
Otherwise $\pi_\alpha(B)=U_\alpha$: for $x_\alpha\in U_\alpha$, choose a point of $U_\beta$ in each coordinate $\beta\neq\alpha$, which is possible because every $U_\beta$ is nonempty.
In both cases $\pi_\alpha(B)$ is open.
:::

:::

::: {.pf-step #product-hausdorff-forward}
If every $X_\alpha$ is Hausdorff, then $X$ is Hausdorff.

::: pf-proof
Let $x=(x_\beta)$ and $y=(y_\beta)$ be distinct points of $X$, so $x_\gamma\neq y_\gamma$ for some $\gamma$.
Choose disjoint open sets $U\ni x_\gamma$ and $V\ni y_\gamma$ in $X_\gamma$.
Then $\pi_\gamma^{-1}(U)$ and $\pi_\gamma^{-1}(V)$ are disjoint open neighborhoods of $x$ and $y$.
:::

:::

::: {.pf-step #product-hausdorff-backward}
If $X$ is Hausdorff, then $X_\alpha$ is Hausdorff.

::: pf-proof
For each $\beta\neq\alpha$ choose $c_\beta\in X_\beta$, possible because the factors are nonempty.
Define $s_\alpha\colon X_\alpha\to X$ by $s_\alpha(t)_\alpha=t$ and $s_\alpha(t)_\beta=c_\beta$ for $\beta\neq\alpha$.
Each coordinate $\pi_\beta\circ s_\alpha$ is the identity or a constant map, so $s_\alpha$ is continuous by the universal property of the product.
Since $\pi_\alpha\circ s_\alpha=\id_{X_\alpha}$, the map $s_\alpha$ is a homeomorphism onto its image, with inverse $\pi_\alpha|_{s_\alpha(X_\alpha)}$.
A subspace of a Hausdorff space is Hausdorff, so $X_\alpha$ is Hausdorff.
:::

:::

:::

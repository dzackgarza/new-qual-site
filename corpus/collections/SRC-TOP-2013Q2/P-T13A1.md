::: {.problem}
Let $X_\alpha$ be non-empty topological spaces and suppose that $X=\prod_\alpha X_\alpha$ is endowed with the product topology.

(a) Prove that each projection map $\pi_\alpha$ is continuous and open.

(b) Prove that $X$ is Hausdorff if and only if each space $X_\alpha$ is Hausdorff.
:::

::: {.solution}
<1>1. Fix an index $\alpha$.
::: {.proof}
We prove the two assertions about the projection $\pi_\alpha:X\to X_\alpha$ first.
:::

<1>2. The projection $\pi_\alpha$ is continuous.
::: {.proof}
A subbasis for the product topology on $X$ consists of sets of the form $\pi_\beta^{-1}(U)$ with $U\subseteq X_\beta$ open. For every open $U\subseteq X_\alpha$, the inverse image $\pi_\alpha^{-1}(U)$ is therefore open. Hence $\pi_\alpha$ is continuous.
:::

<1>3. The projection $\pi_\alpha$ is open.
::: {.proof}
It suffices to check basic open sets. Let
$$
B=\prod_\beta U_\beta
$$
be basic open, where each $U_\beta$ is open and $U_\beta=X_\beta$ for all but finitely many $\beta$. Because every factor $X_\beta$ is nonempty, $\pi_\alpha(B)=U_\alpha$: for any $x_\alpha\in U_\alpha$, choose one point in each $U_\beta$ for the finitely many constrained coordinates and arbitrary points in the remaining nonempty factors. Thus $\pi_\alpha(B)$ is open. An arbitrary open set is a union of basic opens, and projections preserve unions, so its image is open.
:::

<1>4. If every $X_\alpha$ is Hausdorff, then $X$ is Hausdorff.
::: {.proof}
Let $x=(x_\alpha)$ and $y=(y_\alpha)$ be distinct points of $X$. Then $x_\alpha\neq y_\alpha$ for some $\alpha$. Since $X_\alpha$ is Hausdorff, choose disjoint open neighborhoods $U,V\subseteq X_\alpha$ of $x_\alpha,y_\alpha$. Then $\pi_\alpha^{-1}(U)$ and $\pi_\alpha^{-1}(V)$ are disjoint open neighborhoods of $x$ and $y$ in $X$.
:::

<1>5. Suppose $X$ is Hausdorff. Then every factor $X_\alpha$ is Hausdorff.
::: {.proof}
Fix $\alpha$. For each $\beta\neq\alpha$, choose a point $c_\beta\in X_\beta$, possible because the factors are nonempty. Define
$$
s_\alpha:X_\alpha\longrightarrow X,
\qquad
s_\alpha(t)_\beta=
\begin{cases}
t,&\beta=\alpha,\\
c_\beta,&\beta\neq\alpha.
\end{cases}
$$
This map is continuous by the universal property of the product topology: each coordinate $\pi_\beta\circ s_\alpha$ is either the identity or a constant map. Moreover $\pi_\alpha\circ s_\alpha=\mathrm{id}_{X_\alpha}$, so $s_\alpha$ is a homeomorphism from $X_\alpha$ onto the subspace $s_\alpha(X_\alpha)\subseteq X$. Every subspace of a Hausdorff space is Hausdorff, hence $X_\alpha$ is Hausdorff.
:::

<1>6. Therefore each projection is continuous and open, and $X$ is Hausdorff if and only if every factor $X_\alpha$ is Hausdorff.
::: {.proof}
Combine <1>2--<1>5.
:::
:::

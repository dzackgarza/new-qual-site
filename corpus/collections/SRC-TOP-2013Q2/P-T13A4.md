::: {.problem}
A space is locally connected if for each point $x\in X$ and every neighborhood $U$ of $x$, there is a connected neighborhood $V$ of $x$ contained in $U$.

(a) Prove that $X$ is locally connected if and only if for every open set $U$ of $X$, each connected component of $U$ is open in $X$.

(b) Prove that if $p:X\to Y$ is a quotient map and $X$ is locally connected, then $Y$ is locally connected.
:::

::: {.solution}

::: pf

::: {.pf-step #components-open-forward}
If $X$ is locally connected, then every connected component $C$ of every open set $U\subseteq X$ is open in $X$.

::: pf-proof
Let $x\in C$.
By local connectedness there is a connected neighborhood $N_x$ of $x$ with $N_x\subseteq U$.
$N_x$ is connected, lies in $U$, and meets $C$ at $x$, so $C\cup N_x$ is connected and maximality of $C$ gives $N_x\subseteq C$.
$N_x$ contains an open set $O_x$ with $x\in O_x\subseteq C$, so $C$ is open.
:::

:::

::: {.pf-step #components-open-backward}
If every connected component of every open subset of $X$ is open, then $X$ is locally connected.

::: pf-proof
Let $x\in X$ and let $U$ be a neighborhood of $x$, containing an open set $O\ni x$.
The component $C$ of $O$ containing $x$ is open by hypothesis, connected, and satisfies $x\in C\subseteq O\subseteq U$.
:::

:::

::: {.pf-step #quotient-preserves}
If $p\colon X\to Y$ is a quotient map and $X$ is locally connected, then every connected component $C$ of every open set $U\subseteq Y$ is open in $Y$.

::: pf-proof
$p^{-1}(U)$ is open, so by step [](#components-open-forward){.pf-ref} its components are open in $X$.
Let $W$ be the union of the components $D$ of $p^{-1}(U)$ with $p(D)\subseteq C$; it is open.
If $x'\in p^{-1}(C)$, let $D'$ be the component of $p^{-1}(U)$ containing $x'$.
Then $p(D')$ is a connected subset of $U$ containing $p(x')\in C$, so $p(D')\subseteq C$ and $x'\in W$.
Hence $p^{-1}(C)=W$, which is open, and $C$ is open because $p$ is a quotient map.
:::

:::

::: pf-qed
Steps [](#components-open-forward){.pf-ref} and [](#components-open-backward){.pf-ref} prove (a).
For (b), step [](#quotient-preserves){.pf-ref} and the converse direction of (a), step [](#components-open-backward){.pf-ref} applied to $Y$, show that $Y$ is locally connected.
:::

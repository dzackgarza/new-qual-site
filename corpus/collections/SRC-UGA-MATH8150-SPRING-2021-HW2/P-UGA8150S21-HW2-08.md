::: {.problem}
It was defined that $e ^ { z } : = \sum _ { n = 0 } ^ { \infty } \frac { z ^ { n } } { n ! } .$ . Show that $e ^ { z } = \operatorname* { l i m } _ { n \to \infty } \left( 1 + { \frac { z } { n } } \right) ^ { n }$
:::

Fix $z\in\CC$. For integers $n,k\ge0$, define
$$
a_{n,k}
\coloneqq
\begin{cases}
\displaystyle
\frac1{k!}
\prod_{j=0}^{k-1}\left(1-\frac jn\right),
&0\le k\le n,\\[1ex]
0,&k>n.
\end{cases}
$$

::: pf

::: pf-step

The binomial theorem gives
$$
\left(1+\frac zn\right)^n
=
\sum_{k=0}^\infty a_{n,k}z^k.
$$


::: pf-proof

For $0\le k\le n$,
$$
\binom nk\frac1{n^k}
=
\frac{n(n-1)\cdots(n-k+1)}{k!n^k}
=
\frac1{k!}
\prod_{j=0}^{k-1}\left(1-\frac jn\right)
=
a_{n,k}.
$$
The terms with $k>n$ vanish by definition, so the ordinary finite binomial expansion is exactly the displayed infinite sum.

:::

:::

::: pf-step

For every fixed $k$,
$$
a_{n,k}\longrightarrow\frac1{k!}
$$
as $n\to\infty$, and for all $n,k$,
$$
\abs{a_{n,k}}\le\frac1{k!}.
$$


::: pf-proof

For fixed $k$, once $n\ge k$,
$$
a_{n,k}
=
\frac1{k!}
\prod_{j=0}^{k-1}\left(1-\frac jn\right),
$$
and every factor tends to $1$. Thus $a_{n,k}\to1/k!$.

If $k\le n$, every factor in the product lies in $[0,1]$, so
$$
0\le a_{n,k}\le\frac1{k!}.
$$
If $k>n$, then $a_{n,k}=0$, giving the same bound.

:::

:::

::: pf-step

One may pass the limit through the series:
$$
\lim_{n\to\infty}
\sum_{k=0}^\infty a_{n,k}z^k
=
\sum_{k=0}^\infty\frac{z^k}{k!}.
$$


::: pf-proof

By step <1>2,
$$
\abs{a_{n,k}z^k}
\le
\frac{\abs z^k}{k!}.
$$
The majorant series
$$
\sum_{k=0}^\infty\frac{\abs z^k}{k!}
=
e^{\abs z}
$$
converges. Dominated convergence for series, together with the pointwise coefficient limit from step <1>2, therefore yields the displayed equality.

:::

:::

::: pf-step

Therefore
$$
\boxed{
e^z
=
\lim_{n\to\infty}
\left(1+\frac zn\right)^n}.
$$


::: pf-proof

By step <1>1 and step <1>3,
$$
\lim_{n\to\infty}
\left(1+\frac zn\right)^n
=
\sum_{k=0}^\infty\frac{z^k}{k!},
$$
and the series on the right is the given definition of $e^z$.

:::

:::

::: pf-qed

Step <1>4 is the required identity.

:::

:::

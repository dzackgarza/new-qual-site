::: {.problem}
Show that the series

$$
\sum _ { n = 1 } ^ { \infty } { \frac { 1 } { n ^ { z } } }
$$

defines a continuous function for $\mathrm { R e } ( z ) > 1$ . (This is the Riemann ζ function and you will see later that it is analytic in the above region-not just being continuous thereand it can be extended to the complex plane with only 1 removed.
You do not need to prove the latter assertions.)
[Hint: Show that the series converges uniformly for $\mathrm { R e } ( z ) \geq 1 + \delta$ , where $\delta > 0$ is any positive number.]
:::

For $n\ge1$, interpret
$$
n^{-z}=e^{-z\log n}.
$$

::: pf

::: pf-step

For every $\delta>0$, the series
$$
\sum_{n=1}^\infty n^{-z}
$$
converges uniformly on
$$
H_\delta\coloneqq\{z\in\CC:\operatorname{Re}z\ge1+\delta\}.
$$


::: pf-proof

If $z\in H_\delta$, then
$$
\abs{n^{-z}}
=
e^{-(\operatorname{Re}z)\log n}
=
n^{-\operatorname{Re}z}
\le
n^{-(1+\delta)}.
$$
The numerical series
$$
\sum_{n=1}^\infty n^{-(1+\delta)}
$$
converges. The Weierstrass $M$-test therefore gives uniform convergence on $H_\delta$.

:::

:::

::: pf-step

The sum
$$
\zeta(z)\coloneqq\sum_{n=1}^\infty n^{-z}
$$
is continuous on every $H_\delta$.


::: pf-proof

Each function
$$
z\longmapsto n^{-z}=e^{-z\log n}
$$
is entire, hence continuous. By step <1>1, their series converges uniformly on $H_\delta$. A uniform limit of continuous functions is continuous.

:::

:::

::: pf-step

The function $\zeta$ is continuous on the half-plane
$$
\boxed{\{z\in\CC:\operatorname{Re}z>1\}}.
$$


::: pf-proof

Fix $z_0$ with $\operatorname{Re}z_0>1$, and set
$$
\delta\coloneqq\frac{\operatorname{Re}z_0-1}{2}>0.
$$
Then $z_0\in H_\delta$, and step <1>2 shows that $\zeta$ is continuous at $z_0$. Since $z_0$ was arbitrary, $\zeta$ is continuous throughout the open half-plane.

:::

:::

::: pf-qed

Step <1>3 is the required conclusion.

:::

:::

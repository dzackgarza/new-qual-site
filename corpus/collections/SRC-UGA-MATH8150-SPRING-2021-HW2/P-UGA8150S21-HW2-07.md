$$
\sum _ { n = 1 } ^ { \infty } { \frac { ( - 1 ) ^ { n } } { n } } z ^ { n ( n + 1 ) }
$$

has radius of convergence 1. Examine convergence at $z = 1 , - 1$ and i.

::: {.problem}
Suppose $U ( z )$ has continuous second order partial derivatives and $z = f ( \zeta ) , \zeta = \xi + i \eta$ is a holomorphic function.
Show that

$$
\frac { \partial ^ { 2 } U } { \partial \xi ^ { 2 } } + \frac { \partial ^ { 2 } U } { \partial \eta ^ { 2 } } = \abs{ f ^ { \prime } ( \zeta ) } ^ { 2 } \left[ \frac { \partial ^ { 2 } U } { \partial x ^ { 2 } } + \frac { \partial ^ { 2 } U } { \partial y ^ { 2 } } \right] .
$$
:::

::: {.solution}

Write
$$
f(\zeta)=x(\xi,\eta)+iy(\xi,\eta),
$$
and interpret the left-hand side as the Laplacian of
$$
\widetilde U(\xi,\eta)
\coloneqq
U(x(\xi,\eta),y(\xi,\eta)).
$$

::: pf

::: {.pf-step #s1-1}

The chain rule gives
$$
\begin{aligned}
\widetilde U_{\xi\xi}+\widetilde U_{\eta\eta}
&=
U_{xx}(x_\xi^2+x_\eta^2)
+2U_{xy}(x_\xi y_\xi+x_\eta y_\eta)\\
&\quad
+U_{yy}(y_\xi^2+y_\eta^2)
+U_x(x_{\xi\xi}+x_{\eta\eta})
+U_y(y_{\xi\xi}+y_{\eta\eta}).
\end{aligned}
$$


::: pf-proof

Differentiating once gives
$$
\widetilde U_\xi
=
U_xx_\xi+U_yy_\xi,
\qquad
\widetilde U_\eta
=
U_xx_\eta+U_yy_\eta.
$$
Differentiating each expression once more and adding yields the displayed identity.

:::

:::

::: {.pf-step #s1-2}

Holomorphicity of $f$ implies
$$
x_\xi=y_\eta,
\qquad
x_\eta=-y_\xi,
$$
and both $x$ and $y$ are harmonic.


::: pf-proof

The first two identities are the Cauchy--Riemann equations. Differentiating them and using equality of mixed partials gives
$$
x_{\xi\xi}+x_{\eta\eta}=0,
\qquad
y_{\xi\xi}+y_{\eta\eta}=0.
$$

:::

:::

::: {.pf-step #s1-3}

The mixed coefficient vanishes, and the two quadratic coefficients both equal $\abs{f'(\zeta)}^2$:
$$
x_\xi y_\xi+x_\eta y_\eta=0,
$$
$$
x_\xi^2+x_\eta^2
=
y_\xi^2+y_\eta^2
=
\abs{f'(\zeta)}^2.
$$


::: pf-proof

By the Cauchy--Riemann equations,
$$
x_\xi y_\xi+x_\eta y_\eta
=
x_\xi(-x_\eta)+x_\eta x_\xi
=0.
$$
Also
$$
y_\xi^2+y_\eta^2
=
x_\eta^2+x_\xi^2.
$$
Finally,
$$
f'(\zeta)=x_\xi+iy_\xi=x_\xi-ix_\eta,
$$
so
$$
\abs{f'(\zeta)}^2=x_\xi^2+x_\eta^2.
$$

:::

:::

::: {.pf-step #s1-4}

Therefore
$$
\boxed{
\widetilde U_{\xi\xi}+\widetilde U_{\eta\eta}
=
\abs{f'(\zeta)}^2
\left(U_{xx}+U_{yy}\right)}.
$$


::: pf-proof

Substitute the identities from steps [](#s1-2){.pf-ref} through [](#s1-3){.pf-ref} into the chain-rule formula of step [](#s1-1){.pf-ref}. The mixed term and the first-derivative terms vanish, while both remaining quadratic coefficients equal $\abs{f'(\zeta)}^2$.

:::

:::

::: pf-qed

Step [](#s1-4){.pf-ref} is the required transformation law for the Laplacian under the holomorphic change of variables.

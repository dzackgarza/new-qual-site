::: problem
Give examples of:

a. A connected space which is not path-connected.

b. A path-connected space which is not locally connected.
:::

::: {.solution}
<1>1. For part (a), let
\[
G=\left\{\left(x,\sin\frac1x\right):0<x\le1\right\}
\subset\mathbb R^2
\]
and set
\[
X_a=G\cup\{(0,0)\}.
\]
Then \(X_a\) is connected.
::: {.proof}
The map
\[
(0,1]\longrightarrow\mathbb R^2,
\qquad
x\longmapsto\left(x,\sin\frac1x\right)
\]
is continuous, so its image \(G\) is connected because \((0,1]\) is connected.
Moreover
\[
\left(\frac1{m\pi},0\right)\in G
\qquad(m\ge1)
\]
and these points converge to \((0,0)\). Hence \((0,0)\in\overline G\). A connected set together with a point of its closure is connected, so \(X_a\) is connected.
:::

<1>2. The space \(X_a\) is not path-connected.
::: {.proof}
Suppose, for contradiction, that there is a path
\[
\gamma:[0,1]\to X_a
\]
from \((0,0)\) to a point of \(G\). Write
\[
\gamma(t)=(x(t),y(t)).
\]
Choose \(t_1\) with \(x(t_1)>0\). The set
\[
Z=\{t\in[0,t_1]:x(t)=0\}
\]
is nonempty and closed, hence compact.
Let
\[
t_0=\max Z.
\]
Then
\[
x(t_0)=0,
\qquad
x(t)>0\quad(t_0<t\le t_1).
\]
Because \((0,0)\) is the only point of \(X_a\) with first coordinate zero,
\[
\gamma(t_0)=(0,0).
\]

For \(m\ge1\), define
\[
u_m=\frac1{\pi/2+2\pi m},
\qquad
v_m=\frac1{3\pi/2+2\pi m}.
\]
Then
\[
u_m\to0,
\qquad
v_m\to0,
\qquad
\sin(1/u_m)=1,
\qquad
\sin(1/v_m)=-1.
\]
For all sufficiently large \(m\), both \(u_m\) and \(v_m\) lie strictly between \(0\) and \(x(t_1)\). By the intermediate value theorem there are
\[
r_m,s_m\in(t_0,t_1]
\]
with
\[
x(r_m)=u_m,
\qquad
x(s_m)=v_m.
\]
We claim that
\[
r_m\to t_0,
\qquad
s_m\to t_0.
\]
Indeed, for any \(\delta>0\) with \(t_0+\delta\le t_1\), the continuous positive function \(x\) has a positive minimum on the compact interval \([t_0+\delta,t_1]\). Since \(u_m,v_m\to0\), for all large \(m\) neither value can be attained on that interval.
Hence eventually
\[
t_0<r_m,s_m<t_0+\delta.
\]

But every point of \(X_a\) with positive first coordinate lies in \(G\), so
\[
y(r_m)=\sin(1/u_m)=1,
\qquad
 y(s_m)=\sin(1/v_m)=-1.
\]
Continuity of \(\gamma\) at \(t_0\) would force both sequences to converge to
\[
y(t_0)=0,
\]
a contradiction.
Thus no path joins \((0,0)\) to \(G\), and \(X_a\) is not path-connected.
:::

<1>3. For part (b), let the comb space be
\[
X_b
=
([0,1]\times\{0\})
\cup
(\{0\}\times[0,1])
\cup
\bigcup_{n\ge1}\left(\left\{\frac1n\right\}\times[0,1]\right)
\subset\mathbb R^2.
\]
Then \(X_b\) is path-connected.
::: {.proof}
Let \((x,y)\in X_b\). If \(y>0\), then by the definition of \(X_b\) one has either \(x=0\) or \(x=1/n\) for some \(n\). In either case the vertical segment from \((x,y)\) to \((x,0)\) lies in \(X_b\). The horizontal segment from \((x,0)\) to \((0,0)\) lies in \([0,1]\times\{0\}\subset X_b\). If \(y=0\), only the horizontal segment is needed.
Thus every point is joined by a path to \((0,0)\), so \(X_b\) is path-connected.
:::

<1>4. The comb space \(X_b\) is not locally connected at
\[
p=\left(0,\frac12\right).
\]
::: {.proof}
Consider the open neighborhood
\[
U=X_b\cap B\left(p,\frac14\right)
\]
of \(p\) in the subspace \(X_b\). Suppose there were a connected open set \(V\subseteq X_b\) satisfying
\[
p\in V\subseteq U.
\]
Since \(V\) is open in \(X_b\), there is \(\varepsilon>0\) such that
\[
X_b\cap B(p,\varepsilon)\subseteq V.
\]
Choose \(n\) so large that \(1/n<\varepsilon\). Then
\[
q=\left(\frac1n,\frac12\right)
\in X_b\cap B(p,\varepsilon)
\subseteq V.
\]

Because \(V\subseteq U\), every point of \(V\) has positive second coordinate.
Therefore the first-coordinate projection satisfies
\[
\operatorname{pr}_1(V)
\subseteq
\left\{0\right\}
\cup
\left\{\frac1m:m\ge1\right\}.
\]
It contains both \(0\) and \(1/n\), because \(p,q\in V\). If \(V\) were connected, its continuous image \(\operatorname{pr}_1(V)\subset\mathbb R\) would be connected, hence would contain the whole interval \([0,1/n]\). This is impossible because
\[
\left\{0\right\}
\cup
\left\{\frac1m:m\ge1\right\}
\]
contains no nontrivial interval.
Thus no connected open neighborhood of \(p\) is contained in \(U\). Hence \(X_b\) is not locally connected at \(p\).
:::

<1>5. Therefore the required examples are
\[
\boxed{X_a=\left\{\left(x,\sin\frac1x\right):0<x\le1\right\}\cup\{(0,0)\}}
\]
for part (a), and the comb space \(X_b\) from <1>3 for part (b).
::: {.proof}
By <1>1--<1>2, \(X_a\) is connected but not path-connected.
By <1>3--<1>4, \(X_b\) is path-connected but not locally connected.
:::
:::

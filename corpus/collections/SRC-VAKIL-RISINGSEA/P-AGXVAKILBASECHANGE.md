::: {.problem}
**Part a**: for $M$ an $A\dash$module and $\phi: A\to B$ a morphism of rings, give $B\tensor_A M$ the structure of a $B\dash$module and show that it describes a functor $\mods{A}\to \mods{B}$.

**Part b**: if $\psi: A\to C$ is another ring morphism, show that $B\tensor_A C$ has a ring structure.
:::

::: {.solution}
All rings are commutative with $1$.
Make $B$ an $A$-module by $a\cdot b=\phi(a)b$ and $C$ an $A$-module by $a\cdot c=\psi(a)c$.
The abelian group $B\tensor_A M$ is generated by the elementary tensors $b\tensor m$, so two additive maps out of it agree when they agree on elementary tensors.
An additive map out of $B\tensor_A M$ is the same as a biadditive map $\beta$ on $B\times M$ with $\beta(\phi(a)b,m)=\beta(b,am)$ for all $a\in A$.

::: pf

::: {.pf-step #module}
For an $A$-module $M$, the rule $b_0\cdot(b\tensor m)=b_0b\tensor m$ defines a $B$-module structure on $B\tensor_A M$.

::: pf-proof
Fix $b_0\in B$.
The map $(b,m)\mapsto b_0b\tensor m$ is biadditive, and $b_0\phi(a)b\tensor m=b_0b\tensor am$, so it induces an additive endomorphism $\mu_{b_0}$ of $B\tensor_A M$ with $\mu_{b_0}(b\tensor m)=b_0b\tensor m$.
On elementary tensors, $\mu_{b_0+b_1}=\mu_{b_0}+\mu_{b_1}$, $\mu_{b_0b_1}=\mu_{b_0}\circ\mu_{b_1}$ and $\mu_1=\id$.
All these maps are additive, so these identities hold on all of $B\tensor_A M$.
Thus $b_0\mapsto\mu_{b_0}$ is a ring map $B\to\operatorname{End}_{\ZZ}(B\tensor_A M)$, which is a $B$-module structure.
:::

:::

::: {.pf-step #functor}
The assignment $M\mapsto B\tensor_A M$, $f\mapsto\id_B\tensor f$ is a functor $\mods{A}\to\mods{B}$.

::: pf-proof
For an $A$-linear $f:M\to N$, the map $(b,m)\mapsto b\tensor f(m)$ is biadditive, and $\phi(a)b\tensor f(m)=b\tensor af(m)=b\tensor f(am)$.
So it induces an additive map $\id_B\tensor f$ with $b\tensor m\mapsto b\tensor f(m)$.
This map is $B$-linear: $(\id_B\tensor f)\circ\mu_{b_0}$ and $\mu_{b_0}\circ(\id_B\tensor f)$, with $\mu_{b_0}$ as in step [](#module){.pf-ref}, both send $b\tensor m$ to $b_0b\tensor f(m)$.
The maps $\id_B\tensor\id_M$ and $\id_{B\tensor_A M}$ agree on each $b\tensor m$, so they are equal.
For $f:M\to N$ and $g:N\to P$, the maps $\id_B\tensor(g\circ f)$ and $(\id_B\tensor g)\circ(\id_B\tensor f)$ both send $b\tensor m$ to $b\tensor g(f(m))$, so they are equal.
:::

:::

::: {.pf-step #multiplication}
There is a biadditive multiplication on $B\tensor_A C$ with $(b\tensor c)(b'\tensor c')=bb'\tensor cc'$.

::: pf-proof
Fix $(b',c')\in B\times C$.
The map $(b,c)\mapsto bb'\tensor cc'$ is biadditive, and
$$
\phi(a)bb'\tensor cc'=bb'\tensor\psi(a)cc',
$$
so it induces an additive endomorphism $R_{b',c'}$ of $B\tensor_A C$.
The map $(b',c')\mapsto R_{b',c'}$ into $\operatorname{End}_{\ZZ}(B\tensor_A C)$ is biadditive, and $R_{\phi(a)b',c'}=R_{b',\psi(a)c'}$ because both send $b\tensor c$ to $\phi(a)bb'\tensor cc'=bb'\tensor\psi(a)cc'$.
So it induces an additive map $y\mapsto R_y$ on $B\tensor_A C$.
Define $xy\coloneqq R_y(x)$.
This is additive in $x$ because each $R_y$ is additive, and additive in $y$ because $y\mapsto R_y$ is additive.
On elementary tensors it is the displayed formula.
:::

:::

::: pf-step
With its tensor-product addition and the multiplication of step [](#multiplication){.pf-ref}, $B\tensor_A C$ is a commutative ring with unit $1\tensor1$.

::: pf-proof
The addition is the abelian group structure that $B\tensor_A C$ has as a module.
Distributivity on both sides is the biadditivity of the multiplication.
The expressions $(xy)z$ and $x(yz)$ are additive in each of $x,y,z$, and on elementary tensors both equal $bb'b''\tensor cc'c''$, so the multiplication is associative.
The expressions $xy$ and $yx$ agree on elementary tensors because $B$ and $C$ are commutative, and $(1\tensor1)x$ and $x$ agree on elementary tensors.
Both comparisons are between additive maps, so the multiplication is commutative with unit $1\tensor1$.
:::

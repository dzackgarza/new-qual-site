::: problem
Find the splitting fields and Galois groups of the following polynomials over $\mathbb{Q}$.
You should state clearly results that you use.

(a) $(x^2 + 3)(x^3 - 5)$

(b) $(x^2 - 3)(x^3 - 7)$

(c) $x^{15} - 2$

(d) $x^3 + 2x^2 + 1$
:::

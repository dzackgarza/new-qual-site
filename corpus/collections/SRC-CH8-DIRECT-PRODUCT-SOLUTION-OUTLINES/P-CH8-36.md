::: {.problem}
Find a subgroup of $\ZZ_{12} \oplus \ZZ_{4} \oplus \ZZ_{15}$ that has order $9$.
:::

::: {.solution}
$$
< 4 > \oplus \{ 0 \} \oplus < 5 > = \{ ( 0 , 0 , 0 ) , ( 4 , 0 , 0 ) , ( 8 , 0 , 0 ) , ( 0 , 0 , 5 ) , ( 0 , 0 , 1 0 ) , ( 4 , 0 , 5 ) , ( 4 , 0 , 1 0 ) , ( 8 , 0 , 5 ) , ( 8 , 0 , 1 0 ) \}
$$

Note: This is not the same as $< ( 4 , 0 , 5 ) > = \{ ( 4 , 0 , 5 ) , ( 8 , 0 , 1 0 ) , ( 0 , 0 , 0 ) \}$ .
:::

::: {.remark}
Certificate. `proofs/cards/CH8DirectProduct.g` (`P-CH8-36`) checks that the
$3$-part of $\ZZ_{12}\oplus\ZZ_{4}\oplus\ZZ_{15}$ has order $9$, and that the
subgroup $\langle 4\rangle\oplus\langle 5\rangle$ of
$\ZZ_{12}\oplus\ZZ_{15}$, the order-$3$ subgroup in each factor, realises it.
:::

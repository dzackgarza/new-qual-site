::: {.problem}
Is $\ZZ_{10} \oplus \ZZ_{12} \oplus \ZZ_{6} \approx \ZZ_{60} \oplus \ZZ_{6} \oplus \ZZ_{2}$?
:::

::: {.solution}
$$
\text { Yes! } Z _ { 1 0 } \oplus \ZZ _ { 1 2 } \oplus \ZZ _ { 6 } \approx \ZZ _ { 5 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 3 } \approx \left( \ZZ _ { 5 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 3 } \right) \oplus \left( \ZZ _ { 3 } \oplus \ZZ _ { 2 } \right) \oplus \ZZ _ { 2 } \approx \ZZ _ { 6 0 } \oplus \ZZ _ { 6 } \oplus \ZZ _ { 2 } .
$$
:::

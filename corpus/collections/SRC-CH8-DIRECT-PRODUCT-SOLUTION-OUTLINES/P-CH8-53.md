::: {.problem}
Is $\mathbb { Z } _ { 1 0 } \oplus \mathbb { Z } _ { 1 2 } \oplus \mathbb { Z } _ { 6 } \approx \mathbb { Z } _ { 1 5 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 1 2 } ?$
:::

::: {.solution}
No! $\mathbb { Z } _ { 1 0 } \oplus \mathbb { Z } _ { 1 2 } \oplus \mathbb { Z } _ { 6 } \approx \mathbb { Z } _ { 5 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ but $\mathbb { Z } _ { 1 5 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 1 2 } \approx \mathbb { Z } _ { 5 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 }$ .

Alternately, $\mathbb { Z } _ { 1 0 } \oplus \mathbb { Z } _ { 1 2 } \oplus \mathbb { Z } _ { 6 }$ has more than three elements of order 2 [(5,6,3), (0,6,3), (5,6,0), (5,0,3)] while $\mathbb { Z } _ { 1 5 } \oplus \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 1 2 }$ only has three such elements [(0,0,6), (0,2,0), (0,2,6)].
:::

::: {.problem}
Is $\ZZ_{10} \oplus \ZZ_{12} \oplus \ZZ_{6} \approx \ZZ_{15} \oplus \ZZ_{4} \oplus \ZZ_{12}$?
:::

::: {.solution}
No! $\ZZ _ { 1 0 } \oplus \ZZ _ { 1 2 } \oplus \ZZ _ { 6 } \approx \ZZ _ { 5 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 2 }$ but $\ZZ _ { 1 5 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 1 2 } \approx \ZZ _ { 5 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 }$ .

Alternately, $\ZZ _ { 1 0 } \oplus \ZZ _ { 1 2 } \oplus \ZZ _ { 6 }$ has more than three elements of order 2 [(5,6,3), (0,6,3), (5,6,0), (5,0,3)] while $\ZZ _ { 1 5 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 1 2 }$ only has three such elements [(0,0,6), (0,2,0), (0,2,6)].
:::

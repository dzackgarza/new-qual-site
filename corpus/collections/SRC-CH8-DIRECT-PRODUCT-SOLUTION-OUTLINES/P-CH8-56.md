::: {.problem}
Suppose that $\phi$ is an isomorphism from $\ZZ_{3} \oplus \ZZ_{5}$ to $\ZZ_{15}$ and $\phi(2, 3) = 2$. Find the element in $\ZZ_{3} \oplus \ZZ_{5}$ that maps to $1$.
:::

::: {.solution}
In the seventh edition this is Chapter 8 Exercise 48, where the printed
words are the statement below.

::: pf

::: {.pf-step #multiple}

$8\cdot 2\equiv 1 \pmod{15}$, so $1=8\,\phi(2,3)=\phi\bigl(8\cdot(2,3)\bigr)$.

::: pf-proof

$8\cdot 2=16=15+1\equiv1$ in $\ZZ_{15}$. Since $\phi$ is a homomorphism of additive groups,
$\phi(n\cdot x)=n\cdot\phi(x)$ for every integer $n$ and every $x\in\ZZ_3\oplus\ZZ_5$.

:::

:::

::: {.pf-step #element}

$8\cdot(2,3)=(16,24)\equiv(1,4)$ in $\ZZ_3\oplus\ZZ_5$.

::: pf-proof

$16=5\cdot 3+1\equiv1\pmod 3$ and $24=4\cdot 5+4\equiv4\pmod 5$.

:::

:::

::: {.pf-step #answer}

$\phi(1,4)=1$, so $(1,4)$ is the element that maps to $1$.

::: pf-proof

By steps [](#multiple){.pf-ref} and [](#element){.pf-ref},
$\phi(1,4)=\phi\bigl(8\cdot(2,3)\bigr)=8\,\phi(2,3)=8\cdot2=16\equiv1$ in $\ZZ_{15}$.

:::

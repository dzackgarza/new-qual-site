::: {.problem}
Suppose that $\phi$ is an isomorphism from $\ZZ_{3} \oplus \ZZ_{5}$ to $\ZZ_{15}$ and $\phi(2, 3) = 2$. Find the element in $\ZZ_{3} \oplus \ZZ_{5}$ that maps to $1$.
:::

::: {.solution}
Let $\phi : \ZZ _ { 3 } \oplus \ZZ _ { 5 } \to \ZZ _ { 1 5 }$ be defined by $\phi ( ( 2 , 3 ) ) = 2$ . Then $1 \equiv 8 \cdot 2 = 8 \cdot \phi ( ( 2 , 3 ) ) = \phi ( 8 \cdot ( 2 , 3 ) )$ . This last step is the additive version of $\phi ( a ) ^ { n } = \phi ( a ^ { n } )$ . Now, $\phi ( 8 \cdot ( 2 , 3 ) ) = \phi ( ( 1 6 , 2 4 ) ) = \phi ( ( 1 , 4 ) )$ . Thus, (1, 4) maps to 1.
:::

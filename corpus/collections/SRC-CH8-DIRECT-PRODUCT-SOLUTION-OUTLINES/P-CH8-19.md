::: {.problem}
If r is a divisor of m and s is a divisor of $n$ , find a subgroup of $\ZZ _ { m } \oplus \ZZ _ { n }$ that is isomorphic to $\ZZ _ { r } \oplus \ZZ _ { s }$ .
:::

::: {.solution}
$$
\begin{array} { r } { < \frac { m } { r } > \oplus < \frac { n } { s } > } \end{array}
$$
:::

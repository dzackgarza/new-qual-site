::: {.problem}
If $r$ is a divisor of $m$ and $s$ is a divisor of $n$, find a subgroup of $\ZZ_{m} \oplus \ZZ_{n}$ that is isomorphic to $\ZZ_{r} \oplus \ZZ_{s}$.
:::

::: {.solution}
$$
\begin{array} { r } { < \frac { m } { r } > \oplus < \frac { n } { s } > } \end{array}
$$
:::

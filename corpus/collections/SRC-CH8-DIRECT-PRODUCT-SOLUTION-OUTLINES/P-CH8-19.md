::: {.problem}
If r is a divisor of m and s is a divisor of $n$ , find a subgroup of $\mathbb { Z } _ { m } \oplus \mathbb { Z } _ { n }$ that is isomorphic to $\mathbb { Z } _ { r } \oplus \mathbb { Z } _ { s }$ .
:::

::: {.solution}
$$
\begin{array} { r } { < \frac { m } { r } > \oplus < \frac { n } { s } > } \end{array}
$$
:::

::: {.problem}
If $r$ is a divisor of $m$ and $s$ is a divisor of $n$, find a subgroup of $\ZZ_{m} \oplus \ZZ_{n}$ that is isomorphic to $\ZZ_{r} \oplus \ZZ_{s}$.
:::

::: {.solution}

The subgroup is $\left\langle \frac{m}{r}\right\rangle \oplus
\left\langle \frac{n}{s}\right\rangle$ inside $\ZZ_{m}\oplus\ZZ_{n}$.

::: pf

::: {.pf-step #order-in-zm}

In $\ZZ_{m}$ the element $m/r$ generates a subgroup of order $r$, and in
$\ZZ_{n}$ the element $n/s$ generates a subgroup of order $s$.

::: pf-proof

In $\ZZ_{m}$ the order of an element $a$ is $m/\gcd(m,a)$. With $a=m/r$, where
$r\mid m$, we get $\gcd(m,m/r)=m/r$, so the order is $m/(m/r)=r$. The same
computation in $\ZZ_{n}$ with $s\mid n$ gives order $n/(n/s)=s$.

:::

:::

::: {.pf-step #the-subgroup}

$K=\langle (m/r,0)\rangle\cdot\langle (0,n/s)\rangle$ is a subgroup of
$\ZZ_{m}\oplus\ZZ_{n}$ isomorphic to $\ZZ_{r}\oplus\ZZ_{s}$.

::: pf-proof

Each of the two cyclic subgroups lies in $\ZZ_{m}\oplus\ZZ_{n}$, and they
commute, so the set of products $K$ is a subgroup. Intersecting them is trivial:
$(a m/r,0)=(0,b n/s)$ forces both coordinates to be $0$. So $K$ is the internal
direct product $\langle m/r\rangle\times\langle 0,n/s\rangle$, of order $r\cdot
s$. Since a finite Abelian group of order $rs$ that is a product of a cyclic
group of order $r$ and one of order $s$ is $\ZZ_{r}\oplus\ZZ_{s}$, this is a
copy of $\ZZ_{r}\oplus\ZZ_{s}$.

:::

:::

::: {.pf-step #explicit-iso}

Explicitly, $(a\cdot\frac{m}{r},\, b\cdot\frac{n}{s})\mapsto (a\bmod r, b\bmod
s)$ is an isomorphism $K\to\ZZ_{r}\oplus\ZZ_{s}$.

::: pf-proof

The map is well defined and onto, since $a$ runs over $\ZZ$ and the multiple
$a\cdot m/r$ runs over all of $\langle m/r\rangle$. It is a homomorphism because
addition in $K$ is componentwise, and its kernel is the set of pairs with
$a\equiv 0\pmod r$ and $b\equiv 0\pmod s$, which is exactly the identity of
$K$. Hence $K\cong \ZZ_{r}\oplus\ZZ_{s}$, as required.

:::

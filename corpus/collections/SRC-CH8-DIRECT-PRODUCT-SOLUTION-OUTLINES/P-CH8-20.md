::: {.problem}
Find a subgroup of $\mathbb { Z } _ { 1 2 } \oplus \mathbb { Z } _ { 1 8 }$ that is isomorphic to $\mathbb { Z } _ { 9 } \oplus \mathbb { Z } _ { 4 }$
:::

::: {.solution}
First notice that $\mathbb { Z } _ { 9 } \oplus \mathbb { Z } _ { 4 }$ is isomorphic to $\mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 9 }$ . This second presentation is, by the previous problem, isomorphic to $< 3 > \oplus < 2 >$ .
:::

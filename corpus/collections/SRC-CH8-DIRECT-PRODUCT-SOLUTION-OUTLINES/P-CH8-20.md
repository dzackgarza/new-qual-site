::: {.problem}
Find a subgroup of $\ZZ_{12} \oplus \ZZ_{18}$ that is isomorphic to $\ZZ_{9} \oplus \ZZ_{4}$.
:::

::: {.solution}

The exercise is Gallian, *Contemporary Abstract Algebra* (7th ed.), Chapter 8 exercise 18, and is item 20 of the retained Chapter 8 solution outline
(`assets/attachments/Ch8Sltns.pdf`, PDF p. 3). The subgroup is the outline's
$\langle3\rangle\oplus\langle2\rangle$; the steps below prove its order, write it out, and
exhibit the isomorphism the outline attributes to the previous exercise.

Throughout, $\ZZ_{12}\oplus\ZZ_{18}$ carries the componentwise operation
$(a,b)+(a',b')=(a+a',b+b')$.

::: pf

::: {.pf-step #orders}

In $\ZZ_{12}$ the element $3$ has order $4$, and in $\ZZ_{18}$ the element $2$ has order
$9$; hence $\langle3\rangle=\theset{0,3,6,9}$ and $\langle2\rangle=\theset{0,2,4,\dots,16}$.

::: pf-proof

The multiples of $3$ modulo $12$ are $3,6,9,0$ and then repeat, so the order is $4$; the
four are distinct since $0<3<6<9<12$. The multiples of $2$ modulo $18$ are
$2,4,\dots,16,0$: the partial sums $2j$ for $1\le j\le8$ satisfy $0<2j\le16<18$, so none is
$0$, and $2\cdot9=18\equiv0$. Hence the order is $9$ and the subgroup has the nine listed
elements.

:::

:::

::: {.pf-step #subgroup}

$H=\theset{(3i,2j) : 0\le i\le3,\ 0\le j\le8}$ is a subgroup of $\ZZ_{12}\oplus\ZZ_{18}$ with
$4\cdot9=36$ elements.

::: pf-proof

$H$ is the set of all sums $m(3,0)+n(0,2)$ for integers $m,n$, that is the subgroup
generated by $(3,0)$ and $(0,2)$: such a sum is $(3m,2n)$ and depends only on $m$ modulo
$4$ and $n$ modulo $9$ by step [](#orders){.pf-ref}. A subgroup generated by a subset is a
subgroup. The $36$ pairs $(3i,2j)$ with $0\le i\le3$ and $0\le j\le8$ are distinct, because
$3i\equiv3i'$ modulo $12$ forces $i\equiv i'$ modulo $4$ (as $3$ has order $4$) and
$2j\equiv2j'$ modulo $18$ forces $j\equiv j'$ modulo $9$.

:::

:::

::: {.pf-step #isomorphic}

$H\cong\ZZ_{4}\oplus\ZZ_{9}$.

::: pf-proof

Define $\psi:\ZZ_{4}\oplus\ZZ_{9}\to H$ by $\psi(i,j)=(3i,2j)$. It is well defined and a
homomorphism because $(3(i+i'),2(j+j'))=(3i,2j)+(3i',2j')$; it is injective because
$(3i,2j)=(0,0)$ forces $4\mid i$ and $9\mid j$ by step [](#orders){.pf-ref}; and it is
surjective by the description of $H$ in step [](#subgroup){.pf-ref}. A bijective homomorphism
is an isomorphism.

:::

:::

::: {.pf-step #answer}

$H=\theset{(3i,2j)}$ is a subgroup of $\ZZ_{12}\oplus\ZZ_{18}$ isomorphic to
$\ZZ_{9}\oplus\ZZ_{4}$.

::: pf-proof

By steps [](#subgroup){.pf-ref} and [](#isomorphic){.pf-ref} together with the isomorphism
$\ZZ_{4}\oplus\ZZ_{9}\to\ZZ_{9}\oplus\ZZ_{4}$, $(i,j)\mapsto(j,i)$, which is a homomorphism
and its own inverse. As $\gcd(4,9)=1$, Theorem 8.2  further identifies this
group with $\ZZ_{36}$, so $H$ is cyclic of order $36$.

:::

::: {.problem}
Let $H = \left\{ \begin{bmatrix} 1 & a & b \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} \,\middle|\, a, b \in \mathbb{Z}_3 \right\}$.
Show that $H$ is an Abelian group of order 9.
Is $H$ isomorphic to $\mathbb{Z}_9$ or to $\mathbb{Z}_3 \oplus \mathbb{Z}_3$?
:::

::: {.solution}
First we show that H is an abelian group.
Since ${ \left[ \begin{array} { l l l } { 1 } & { a } & { b } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } { \left[ \begin{array} { l l l } { 1 } & { c } & { d } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } = { \left[ \begin{array} { l l l } { 1 } & { a + c } & { b + d } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } ,$ which is of the desired form, we know that H is closed.
Associativity is known for matrix

multiplication and we know that I is the standard identity matrix.
Now, $A ^ { - 1 } = { \left[ \begin{array} { l l l } { 1 } & { - a } & { - b } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] }$ by the previous calculation.
Finally we observe that ${ \left[ \begin{array} { l l l } { 1 } & { c } & { d } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } { \left[ \begin{array} { l l l } { 1 } & { a } & { b } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } = { \left[ \begin{array} { l l l } { 1 } & { a + c } & { b + d } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] }$ so H is Abelian since addition in $\mathbb { Z } _ { 3 }$ is Abelian.

Now, we know that H has order 9 because there are three options for a and three for b or $3 * 3 = 9$ total possible matrices.

We know H can not be isomorphic to $\mathbb { Z } _ { 9 }$ since it is not cyclic.
But we can clearly see that $H \approx \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 }$ using the map ${ \left[ \begin{array} { l l l } { 1 } & { a } & { b } \\ { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 1 } \end{array} \right] } \mapsto ( a , b ) .$
:::

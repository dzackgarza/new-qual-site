::: {.problem}
The group $S _ { 3 } \oplus \mathbb { Z } _ { 2 }$ is isomorphic to one of the following groups: $\mathbb { Z } _ { 1 2 } , \mathbb { Z } _ { 6 } \oplus \mathbb { Z } _ { 2 } , A _ { 4 } , D _ { 6 }$ . Determine which one by elimination.
:::

::: {.solution}
Since $S _ { 3 } \oplus \mathbb { Z } _ { 2 }$ is not Abelian (since $S _ { 3 }$ is not), $S _ { 3 } \oplus \mathbb { Z } _ { 2 }$ is not isomorphic to $\mathbb { Z } _ { 1 2 }$ or $\mathbb { Z } _ { 6 } \oplus \mathbb { Z } _ { 2 }$ Now, $A _ { 4 }$ is the set of even permutations of $S _ { 4 }$ and contains elements of order 1, 2, and $3$ , as seen on page 111 of the text.
But $S _ { 3 } \oplus \mathbb { Z } _ { 2 }$ contains the element ((123), 1) which has order $\operatorname { l c m } ( 3 , 2 ) = 6$ . Thus the group is not $A _ { 4 }$ , and $S _ { 3 } \oplus \mathbb { Z } _ { 2 }$ is actually isomorphic to $D _ { 6 }$ .
:::

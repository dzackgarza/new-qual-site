::: {.problem}
Express $\Aut(U(25))$ in the form $\ZZ_{m} \oplus \ZZ_{n}$.
:::

::: {.solution}
The book's own answer is **Gallian, *Contemporary Abstract Algebra* (7th ed.), *Selected Answers*, Chapter 8 Exercise 41, printed p. A11** (`tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`, PDF p. 600): $\operatorname{Aut}(U(25))\cong\operatorname{Aut}(\ZZ_{20})\cong U(20)\cong U(4)\oplus U(5)\cong\ZZ_{2}\oplus\ZZ_{4}$. The steps below prove each link of that chain, which the answer states without reasons.

::: pf

::: {.pf-step #cyclic-20}
$U(25)=\langle 2\rangle$ is cyclic of order $20$, so $U(25)\cong\ZZ_{20}$.

::: pf-proof
$U(25)$ consists of the residues $1\le k\le24$ coprime to $25$, that is all of them except the four multiples $5,10,15,20$ of $5$, so $\cardinality{U(25)}=24-4=20$. Compute $2^{10}=1024=40\cdot25+24\equiv-1\pmod{25}$, so $2^{10}\ne1$ and the order of $2$ divides $20$ but not $10$; also $2^{4}=16\ne1$. The divisors of $20$ are $1,2,4,5,10,20$ and those not dividing $10$ are $4$ and $20$, so the order of $2$ is $20$. A group element of order equal to the group's order generates the group; so $U(25)=\langle2\rangle\cong\ZZ_{20}$.
:::

:::

::: {.pf-step #aut}
$\operatorname{Aut}(U(25))\cong\operatorname{Aut}(\ZZ_{20})$ and $\operatorname{Aut}(\ZZ_{20})\cong U(20)$.

::: pf-proof
An isomorphism $\psi:U(25)\to\ZZ_{20}$ conjugates automorphisms, $\sigma\mapsto\psi\sigma\psi^{-1}$, giving an isomorphism of the automorphism groups, which is the first assertion. The second is Gallian's Theorem 6.5 (printed p. 132): for every positive integer $n$, $\operatorname{Aut}(\ZZ_{n})\cong U(n)$, the isomorphism sending an automorphism to its value at $1$.
:::

:::

::: {.pf-step #split}
$U(20)\cong U(4)\oplus U(5)$.

::: pf-proof
Define $\theta(k)=(k\bmod 4,\ k\bmod 5)$. If $k$ is a unit modulo $20$ then $k$ is coprime to $20$, hence coprime to $4$ and to $5$, so its residues lie in $U(4)$ and $U(5)$; conversely if $k$ is coprime to $4$ and to $5$ it is coprime to $20$. So $\theta$ maps $U(20)$ into $U(4)\oplus U(5)$, and it preserves multiplication because reduction modulo $4$ and modulo $5$ does. It is injective: $k\equiv k'$ modulo $4$ and modulo $5$ forces $k\equiv k'$ modulo $20$, as $4$ and $5$ are coprime. Both sides have $2\cdot4=8$ elements, so $\theta$ is a bijective homomorphism.
:::

:::

::: {.pf-step #small-units}
$U(4)\cong\ZZ_{2}$ and $U(5)\cong\ZZ_{4}$.

::: pf-proof
$U(4)=\{1,3\}$ with $3^{2}=9\equiv1$, a group of two elements, hence $\ZZ_{2}$. $U(5)=\{1,2,3,4\}$ and $2^{1}=2$, $2^{2}=4$, $2^{3}=8\equiv3$, $2^{4}=16\equiv1$, so $2$ has order $4$ and $U(5)=\langle2\rangle\cong\ZZ_{4}$.
:::

:::

::: {.pf-step #answer}
$\boxed{\operatorname{Aut}(U(25))\cong\ZZ_{2}\oplus\ZZ_{4}}$.

::: pf-proof
Chaining steps [](#aut){.pf-ref}, [](#split){.pf-ref} and [](#small-units){.pf-ref} gives $\operatorname{Aut}(U(25))\cong U(20)\cong U(4)\oplus U(5)\cong\ZZ_{2}\oplus\ZZ_{4}$, which is the book's chain with $\ZZ_{4}\oplus\ZZ_{2}$ written in the order $\ZZ_{2}\oplus\ZZ_{4}$; the direct sum is commutative, so the two orders name the same group. This is the form $\ZZ_{m}\oplus\ZZ_{n}$ the exercise asks for, with $m=2$ and $n=4$.
:::

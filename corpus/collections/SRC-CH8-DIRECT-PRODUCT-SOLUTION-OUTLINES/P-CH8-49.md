::: {.problem}
Express Aut(U(25)) in the form $\mathbb { Z } _ { m } \oplus \mathbb { Z } _ { n }$
:::

::: {.solution}
First, notice that U (25) has $\phi ( 2 5 ) = 5 ^ { 2 } - 5 = 2 0$ elements and is cyclic (one generator is 2) so $U ( 2 5 ) \approx \mathbb { Z } _ { 2 0 }$ . Thus $\operatorname { A u t } ( U ( 2 5 ) ) \approx \operatorname { A u t } ( \mathbb { Z } _ { 2 0 } )$ .

Now, $\operatorname { A u t } ( \mathbb { Z } _ { 2 0 } ) \approx U ( 2 0 )$ from our previous work and $U ( 2 0 ) \approx U ( 4 ) \oplus U ( 5 )$ . But $U ( 4 )$ and U(5) are both cyclic and of orders 2 and 4 respectively.
Thus, $U ( 4 ) \oplus U ( 5 ) \approx \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 4 }$ .
:::

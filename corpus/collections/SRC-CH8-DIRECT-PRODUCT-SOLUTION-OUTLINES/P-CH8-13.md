::: {.problem}
For each integer $n > 1$, give two examples of two non isomorphic groups of order $n^{2}$.
:::

::: {.solution}

The two groups are $\ZZ_{n^{2}}$ and $\ZZ_{n}\oplus\ZZ_{n}$, both of order
$n^{2}$, and they are not isomorphic.

::: pf

::: {.pf-step #orders}

Both groups have order $n^{2}$.

::: pf-proof

$|\ZZ_{n^{2}}|=n^{2}$ and $|\ZZ_{n}\oplus\ZZ_{n}|=n\cdot n=n^{2}$ by the
definition of the external direct product.

:::

:::

::: {.pf-step #element-orders}

$\ZZ_{n^{2}}$ has an element of order $n^{2}$; every element of
$\ZZ_{n}\oplus\ZZ_{n}$ has order dividing $n$.

::: pf-proof

In $\ZZ_{n^{2}}$ the class of $1$ has order $n^{2}$. In $\ZZ_{n}\oplus\ZZ_{n}$,
take $(a,b)$; then $n(a,b)=(na,nb)=(0,0)$, so the order of $(a,b)$ divides $n$
by the definition of order. Since $n>1$ we have $n<n^{2}$, so no element of
$\ZZ_{n}\oplus\ZZ_{n}$ has order $n^{2}$.

:::

:::

::: {.pf-step #not-isomorphic}

No isomorphism $f\colon\ZZ_{n^{2}}\to\ZZ_{n}\oplus\ZZ_{n}$ exists.

::: pf-proof

An isomorphism preserves the order of every element: if $f(a)=b$ then
$a^{k}=0$ exactly when $b^{k}=0$. The element $1\in\ZZ_{n^{2}}$ has order
$n^{2}$, so $f(1)$ would have order $n^{2}$, contradicting step
[](#element-orders){.pf-ref}. Hence the two groups of order $n^{2}$ are not
isomorphic. The same conclusion follows from the criterion that
$\ZZ_{m}\oplus\ZZ_{k}\cong\ZZ_{mk}$ requires $\gcd(m,k)=1$, which fails here
with $m=k=n>1$.

:::

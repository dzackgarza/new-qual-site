::: {.problem}
For each integer $n > 1$ , give two examples of two non isomorphic groups of order $n ^ { 2 }$
:::

::: {.solution}
$\mathbb { Z } _ { n ^ { 2 } }$ and $\mathbb { Z } _ { n } \oplus \mathbb { Z } _ { n }$ (Note: we know these are different since n is not relatively prime to $n$ ) .
:::

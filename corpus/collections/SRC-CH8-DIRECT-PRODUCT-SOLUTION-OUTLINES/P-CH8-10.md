::: {.problem}
How many elements of order $9$ does $\ZZ_{3} \oplus \ZZ_{9}$ have?
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $G=\ZZ_3\oplus\ZZ_9$.

::: pf

::: {.pf-step #order}
For $a\in\ZZ_3$ and $b\in\ZZ_9$, the order of $(a,b)$ is $\operatorname{lcm}(\operatorname{ord}a,\operatorname{ord}b)$.

::: pf-proof
$(a,b)^m=(ma,mb)$, so $(a,b)^m=0$ exactly when $ma=0$ and $mb=0$, that is when $m$ is a multiple of both orders. The least such $m$ is the least common multiple, and that is the order of the element in a finite abelian group written additively.
:::

:::

::: {.pf-step #condition}
$\operatorname{ord}(a,b)=9$ if and only if $\operatorname{ord}b=9$ and $\operatorname{ord}a\in\{1,3\}$.

::: pf-proof
Since $a\in\ZZ_3$, its order divides $3$, so it is $1$ or $3$; and $\operatorname{ord}b$ divides $9$, so it is $1,3$ or $9$. The lcm of the two orders equals $9$ exactly when the second is $9$ and the first divides $3$; if $\operatorname{ord}b\ne9$ then both orders divide $3$ and the lcm divides $3$. So the condition is as stated, and it is automatically satisfied by every $a\in\ZZ_3$.
:::

:::

::: {.pf-step #count}
$G$ has $3\cdot\varphi(9)=18$ elements of order $9$.

::: pf-proof
By step [](#condition){.pf-ref} such an element is determined by an arbitrary $a\in\ZZ_3$, three choices, and by $b\in\ZZ_9$ of order exactly $9$. In $\ZZ_9$ the elements of order $9$ are the generators, of which there are $\varphi(9)=6$ — explicitly $1,2,4,5,7,8$. The choices are independent, so the number is $3\cdot6=18$, which is the answer. The GAP certificate recorded in the card's remark enumerates the same $18$ pairs.
:::

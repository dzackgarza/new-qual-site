::: {.problem}
How many elements of order 9 does $\mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 9 }$ have?
:::

::: {.solution}
We know that $( a , b )$ has order 9 if $\operatorname { l c m } ( | a | , | b | ) = 9$ . Thus $b$ must have order 9 and $| a |$ can be 1 or 3. Everything in $\mathbb { Z } _ { 3 }$ has order 1 or 3, so a can be any element in $\mathbb { Z } _ { 3 }$ . In $\mathbb { Z } _ { 9 }$ , there are $\phi ( 9 ) = 3 ^ { 2 } - 3 = 6$ elements of order 9. Thus there are $3 \cdot 6 = 1 8$ elements of order 9 in $\mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 9 }$ .
:::

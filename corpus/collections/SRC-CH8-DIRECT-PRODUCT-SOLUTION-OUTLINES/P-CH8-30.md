::: {.problem}
Find all subgroups of order 4 in $\mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 4 }$
:::

::: {.solution}
Recall that there are two groups of order $4$ , $\mathbb { Z } _ { 4 }$ and $\mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ . The subgroups isomorphic to $\mathbb { Z } _ { 4 }$ are the cyclic ones generated by $( a , b )$ where $\operatorname { l c m } ( | a | , | b | ) = 4$ . These are: $< ( 1 , 0 ) > = < ( 3 , 0 ) > , < ( 1 , 1 ) > = < ( 3 , 3 ) > , < ( 1 , 2 ) > = < ( 3 , 2 ) > , < ( 1 , 3 ) > = < ( 3 , 1 ) > , < ( 0 , 1 ) > = < ( 0 , 3 ) > , < ( 2 , 1 ) > = < ( 2 , 3 ) >$ . The other subgroups are isomorphic to $\mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ and are, by our previous theorem, $< 2 > \oplus < 2 > = \{ ( 0 , 0 ) , ( 0 , 2 ) , ( 2 , 0 ) , ( 2 , 2 ) \}$ .
:::

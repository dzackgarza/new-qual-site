::: {.problem}
Prove that the group of complex numbers under addition is isomorphic to $\RR \oplus \RR$.
:::

::: {.solution}
Proof.
Define $\phi : ( \CC , + ) \to \RR \oplus \RR$ by $a + b i \mapsto ( a , b )$ . The calculation $\phi ( ( a + b i ) + ( c + d i ) ) = \phi ( ( a + c ) + ( b + d ) i ) = ( a + c , b + d ) = ( a , b ) + ( c , d ) = \phi ( a + b i ) + \phi ( c + d i )$ shows that $\phi$ is indeed a homomorphism.
Suppose that $\phi ( a + b i ) = \phi ( c + d i )$ . Then $( a , b ) = ( c , d )$ so $a = c$ and $b = d$ . Hence, $a + b i = c + d i$ , showing one-to-one.
For onto, let $( a , b )$ be any element of $\RR \oplus \RR$ . Then it is clear that $a + b i \in \CC$ and $\phi ( a + b i ) = ( a , b )$ as desired.
□
:::

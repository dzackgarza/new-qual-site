::: {.problem}
Prove that the group of complex numbers under addition is isomorphic to $\RR \oplus \RR$.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own. Write $(\CC,+)$ and $(\RR\oplus\RR,+)$ for the two groups under addition, and define $\phi(a+bi)=(a,b)$ for real $a,b$.

::: pf

::: {.pf-step #well-defined}
$\phi$ is a well defined map from $\CC$ to $\RR\oplus\RR$.

::: pf-proof
Every complex number has exactly one expression $a+bi$ with $a,b\in\RR$, namely $a=\Re z$ and $b=\Im z$, so the rule assigns to each $z$ a single pair; and every pair $(a,b)$ of reals arises from the complex number $a+bi$.
:::

:::

::: {.pf-step #homomorphism}
$\phi(z+w)=\phi(z)+\phi(w)$ for all $z,w\in\CC$.

::: pf-proof
Write $z=a+bi$ and $w=c+di$; then $z+w=(a+c)+(b+d)i$, so $\phi(z+w)=(a+c,b+d)=(a,b)+(c,d)=\phi(z)+\phi(w)$, the middle equality being the definition of addition in $\RR\oplus\RR$.
:::

:::

::: {.pf-step #injective}
$\phi$ is one-to-one.

::: pf-proof
If $\phi(a+bi)=\phi(c+di)$ then $(a,b)=(c,d)$ as pairs of reals, so $a=c$ and $b=d$ and therefore $a+bi=c+di$.
:::

:::

::: {.pf-step #surjective}
$\phi$ is onto.

::: pf-proof
Given $(a,b)\in\RR\oplus\RR$, the complex number $a+bi$ satisfies $\phi(a+bi)=(a,b)$ by the definition of $\phi$.
:::

:::

::: {.pf-step #answer}
$(\CC,+)\cong\RR\oplus\RR$.

::: pf-proof
Steps [](#homomorphism){.pf-ref}, [](#injective){.pf-ref} and [](#surjective){.pf-ref} make $\phi$ a bijective homomorphism of additive groups, that is an isomorphism. Its inverse $(a,b)\mapsto a+bi$ also preserves addition, since $(a,b)+(c,d)\mapsto(a+c)+(b+d)i=(a+bi)+(c+di)$; and because $\phi(\lambda z)=\lambda\phi(z)$ for real $\lambda$, the isomorphism is one of real vector spaces.
:::

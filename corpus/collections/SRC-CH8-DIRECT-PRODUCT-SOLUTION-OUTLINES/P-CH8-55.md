::: {.problem}
How many isomorphisms are there from $\ZZ_{12}$ to $\ZZ_{4} \oplus \ZZ_{3}$?
:::

::: {.solution}
The book prints a selected answer to this exercise — **Gallian, *Contemporary Abstract Algebra* (7th ed.), *Selected Answers*, printed p. A11** (`tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`, PDF p. 600): "Using the fact that an isomorphism from $\ZZ_{12}$ is determined by the image of $1$ and the fact that a generator must map to a generator, we determine that there are $4$ isomorphisms." The steps below are that argument with the count of generators computed. Write the source additively as $\ZZ_{12}$ and the target as $\ZZ_{4}\oplus\ZZ_{3}$.

::: pf

::: {.pf-step #determined}
Every group homomorphism $\phi:\ZZ_{12}\to\ZZ_{4}\oplus\ZZ_{3}$ is determined by $\phi(1)$, and it is an isomorphism exactly when $\phi(1)$ has order $12$.

::: pf-proof
By additivity $\phi(k)=\phi(1+\cdots+1)=k\phi(1)$ for $k\ge0$ and $\phi(-k)=-k\phi(1)$, so the values on all of $\ZZ_{12}$ follow from $\phi(1)$. An isomorphism carries an element of order $12$ to an element of order $12$, since it preserves orders; conversely, if $\phi(1)$ has order $12$, the image has $12$ elements, because the $k\phi(1)$ for $k=0,\dots,11$ are distinct, and $\ZZ_{4}\oplus\ZZ_{3}$ has order $12$, so $\phi$ is onto and hence bijective as a map between sets of $12$ elements.
:::

:::

::: {.pf-step #order-formula}
For $a\in\ZZ_{4}$ and $b\in\ZZ_{3}$ the order of $(a,b)$ is $\operatorname{lcm}(\cardinality{a},\cardinality{b})$.

::: pf-proof
$k(a,b)=(ka,kb)$ vanishes exactly when $ka=0$ and $kb=0$, that is when $k$ is a multiple of both $\cardinality{a}$ and $\cardinality{b}$; the least such positive $k$ is their least common multiple.
:::

:::

::: {.pf-step #generators}
The elements of $\ZZ_{4}\oplus\ZZ_{3}$ of order $12$ are $(1,1)$, $(3,1)$, $(1,2)$ and $(3,2)$.

::: pf-proof
By step [](#order-formula){.pf-ref} the order of $(a,b)$ is $12$ exactly when $\cardinality{a}=4$ and $\cardinality{b}=3$, because the coordinates have orders dividing $4$ and $3$ and the only way their least common multiple is $12$ is that the two orders are $4$ and $3$. In $\ZZ_{4}$ the elements of order $4$ are $1$ and $3$ (the units, since $2$ has order $2$ and $0$ order $1$), and in $\ZZ_{3}$ the elements of order $3$ are $1$ and $2$. So there are $2\cdot2=4$ such pairs, namely those listed; for instance $(1,1)$ does have order $12$, which also shows $\ZZ_{4}\oplus\ZZ_{3}$ is cyclic.
:::

:::

::: {.pf-step #answer}
There are $\boxed{4}$ isomorphisms from $\ZZ_{12}$ to $\ZZ_{4}\oplus\ZZ_{3}$.

::: pf-proof
By step [](#determined){.pf-ref} the isomorphisms correspond bijectively to the elements $\phi(1)$ of order $12$, and by step [](#generators){.pf-ref} there are exactly four of those; each choice gives one isomorphism, the maps $k\mapsto k(1,1)$, $k\mapsto k(3,1)$, $k\mapsto k(1,2)$ and $k\mapsto k(3,2)$.
:::

:::

::: {.problem}
What is the order of any nonidentity element of $\ZZ_{3} \oplus \ZZ_{3} \oplus \ZZ_{3}$? Generalize.
:::

::: {.solution}
Let $e \neq ( a , b , c ) \in \ZZ _ { 3 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 }$ . Since $( a , b , c )$ is not the identity, at least one of $a , b ,$ or c is not the identity.
Every non-identity element in $\ZZ _ { 3 }$ has order 3 and so each of these non-identity elements has order 3. Hence lcm $( \elementorder{ a } , \elementorder{ b } , \elementorder{ c } ) = 3$ and the order of the element is 3.

In general, the order of any element in $\ZZ _ { p } \oplus \ZZ _ { p } \oplus \cdots \oplus \ZZ _ { p }$ , where $p$ is prime, is $p .$
:::

::: {.remark}
Certificate. `proofs/cards/CH8DirectProduct.g` (`P-CH8-23`) checks that all $26$
nonidentity elements of $\ZZ_{3}\oplus\ZZ_{3}\oplus\ZZ_{3}$ have order $3$, and
that $\ZZ_{3}^{n}$ has exactly $3^{n}-1$ elements of order $3$ for $n=1,\dots,4$,
which is the generalisation the exercise asks for.
:::

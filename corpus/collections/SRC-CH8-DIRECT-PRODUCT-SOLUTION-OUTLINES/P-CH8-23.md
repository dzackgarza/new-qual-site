::: {.problem}
What is the order of any nonidentity element of $\ZZ_{3} \oplus \ZZ_{3} \oplus \ZZ_{3}$? Generalize.
:::

::: {.solution}
In the seventh edition this is Chapter 8 Exercise 21, printed p. 168, where the printed
words are the statement below.

No retained solution set covers this exercise: the collection's `provenance` is the textbook's Google Books record and no solutions sheet is retained, so the argument below is the card's own, structured from the outline already on the card.

::: pf

::: {.pf-step #coords}
$(a,b,c) \ne (0,0,0)$ exactly when at least one of $a,b,c$ is nonzero, and in $\ZZ_{3}$ the nonzero elements $1,2$ have additive order $3$.

::: pf-proof
A triple is the identity exactly when all three coordinates vanish, which is the negation of having a nonzero coordinate. In $\ZZ_{3}$ one has $1+1+1=3\equiv0$ and $2+2+2=6\equiv0$, while neither $1$ nor $2$ is $0$, so both have additive order $3$.

:::

:::

::: {.pf-step #kills}
$3\cdot(a,b,c) = (0,0,0)$ for every $(a,b,c) \in \ZZ_{3}\oplus\ZZ_{3}\oplus\ZZ_{3}$.

::: pf-proof
Each coordinate of $3\cdot(a,b,c)$ is $3a$, $3b$ or $3c$, and $3k\equiv0 \pmod 3$ for every integer $k$.

:::

:::

::: {.pf-step #order-three}
If $(a,b,c) \ne (0,0,0)$ then the additive order of $(a,b,c)$ is $3$.

::: pf-proof
By step [](#kills){.pf-ref} the order divides $3$. It is not $1$, since step [](#coords){.pf-ref} gives a nonzero coordinate $a$, and $a \ne 0$ means the first coordinate of $1\cdot(a,b,c)$ is nonzero, so $(a,b,c) \ne (0,0,0)$. As $3$ is prime its divisors are $1$ and $3$.

:::

:::

::: {.pf-step #lcm}
Equivalently the order is $\lcm\bigl(\elementorder{a},\elementorder{b},\elementorder{c}\bigr) = 3$.

::: pf-proof
The order of a triple in a direct product is the least common multiple of the orders of its coordinates, since $k\cdot(a,b,c)=(0,0,0)$ exactly when $ka=kb=kc=0$ in $\ZZ_{3}$. Each coordinate has order $1$ (if it is $0$) or $3$ (by step [](#coords){.pf-ref}), and at least one coordinate has order $3$ by step [](#coords){.pf-ref}, so the least common multiple is $3$.

:::

:::

::: {.pf-step #general}
Generalisation: for a prime $p$ and $n \ge 1$, every nonidentity element of $\ZZ_{p}^{n}$ has order $p$, and $\ZZ_{p}^{n}$ has exactly $p^{n}-1$ such elements.

::: pf-proof
The same two computations with $3$ replaced by $p$: $p\cdot x = 0$ for all $x \in \ZZ_{p}^{n}$, so every order divides the prime $p$, and a nonidentity element has order $\ne1$, hence order $p$. The count is the number of nonzero vectors, $p^{n}-1$. For $n \ge 2$ this shows $\ZZ_{p}^{n}$ has no element of order $p^{2}$, so it is not cyclic, and its exponent is $p$ while its order is $p^{n}$.

:::

:::

::: pf-step
Every nonidentity element of $\ZZ_{3}\oplus\ZZ_{3}\oplus\ZZ_{3}$ has order $\boxed{3}$, and in $\ZZ_{p}^{n}$ every nonidentity element has order $p$.

::: pf-proof
The first assertion is step [](#order-three){.pf-ref}, with the mixed-radix description of the same computation in step [](#lcm){.pf-ref}; the generalisation is step [](#general){.pf-ref}.

:::

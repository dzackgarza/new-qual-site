::: {.problem}
What is the order of any nonidentity element of $\mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 } ?$ Generalize.
:::

::: {.solution}
Let $e \neq ( a , b , c ) \in \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 } \oplus \mathbb { Z } _ { 3 }$ . Since $( a , b , c )$ is not the identity, at least one of $a , b ,$ or c is not the identity.
Every non-identity element in $\mathbb { Z } _ { 3 }$ has order 3 and so each of these non-identity elements has order 3. Hence lcm $( | a | , | b | , | c | ) = 3$ and the order of the element is 3.

In general, the order of any element in $\mathbb { Z } _ { p } \oplus \mathbb { Z } _ { p } \oplus \cdots \oplus \mathbb { Z } _ { p }$ , where $p$ is prime, is $p .$
:::

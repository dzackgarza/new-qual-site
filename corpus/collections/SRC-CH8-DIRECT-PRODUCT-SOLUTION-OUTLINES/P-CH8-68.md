::: {.problem}
Without doing any calculations in $\Aut(\ZZ_{20})$, determine how many elements of $\Aut(\ZZ_{20})$ have order $4$. How many have order $2$?
:::

::: {.solution}
First we notice that $\operatorname { A u t } ( \ZZ _ { 2 0 } ) \approx U ( 2 0 ) \approx U ( 4 ) \oplus U ( 5 )$ . Further, both $U ( 4 )$ and $U ( 5 )$ are cyclic with orders 2 and 4 respectively.
So, $\operatorname { A u t } ( \ZZ _ { 2 0 } ) \approx \ZZ _ { 2 } \oplus \ZZ _ { 4 }$ . Now, for an element here to have order 4, the second coordinate must be 1 or 3, and the first can be either 0 or 1. Thus there are four elements of order 4.
For an element $(a, b)$ to have order 2, it must be a nonidentity element with $2a = 0$ and $2b = 0$, so $a \in \{0, 1\}$ and $b \in \{0, 2\}$ with $(a, b) \neq (0, 0)$. Thus there are three elements of order 2, namely $(1, 0)$, $(0, 2)$ and $(1, 2)$.
:::

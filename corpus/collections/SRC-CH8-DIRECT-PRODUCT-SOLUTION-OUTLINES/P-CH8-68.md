::: {.problem}
Without doing any calculations in $\operatorname { A u t } ( \mathbb { Z } _ { 2 0 } )$ , determine how many elements of $\operatorname { A u t } ( \mathbb { Z } _ { 2 0 } )$ have order 4. How many have order 2?
:::

::: {.solution}
First we notice that $\operatorname { A u t } ( \mathbb { Z } _ { 2 0 } ) \approx U ( 2 0 ) \approx U ( 4 ) \oplus U ( 5 )$ . Further, both $U ( 4 )$ and $U ( 5 )$ are cyclic with orders 2 and 4 respectively.
So, $\operatorname { A u t } ( \mathbb { Z } _ { 2 0 } ) \approx \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 4 }$ . Now, for an element here to have order 4, the second coordinate must be 1 or 3, and the first can be either 0 or 1. Thus there are four elements of order 4.
:::

::: {.problem}
Prove, by comparing orders of elements, that $\mathbb { Z } _ { 8 } \oplus \mathbb { Z } _ { 2 }$ is not isomorphic to $\mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 4 }$ .
:::

::: {.solution}
Notice that $\mathbb { Z } _ { 8 } \oplus \mathbb { Z } _ { 2 }$ has an element of order 8, namely (1, 1), but $\mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 4 }$ can not have an element of order 8 since the orders in $\mathbb { Z } _ { 4 }$ are 1, 2, and 4. (There is no way to get a least common multiple of 8 from 1, 2, and 4.)
:::

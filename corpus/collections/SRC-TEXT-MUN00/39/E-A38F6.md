::: {.exercise}

Show that if $X$ has a countable basis, a collection $\mathcal{A}$ of subsets of $X$ is countably locally finite if and only if it is countable.
:::

::: {.solution}

::: pf

::: {.pf-step #countable-implies-clf}
Backward direction ($\impliedby$): Countable implies countably locally finite.

::: pf-proof

::: pf-step
Suppose $\mathcal{A}$ is countable, so $\mathcal{A} = \{A_k\}_{k=1}^\infty$ (or finite).
:::

::: pf-step
Decompose $\mathcal{A} = \bigcup_{k=1}^\infty \mathcal{A}_k$ where each $\mathcal{A}_k = \{A_k\}$.
:::

::: pf-step
A collection consisting of a single set $\{A_k\}$ is locally finite in any space: each point $x \in X$ has the open neighborhood $X$ itself, which meets only the one member $A_k$.
:::

::: pf-step
Thus $\mathcal{A}$ is a countable union of locally finite collections, hence countably locally finite.
:::

:::

:::

::: {.pf-step #locally-finite-is-countable-lemma}
Lemma: In a second-countable space, any locally finite collection is countable.

::: pf-proof

::: pf-step
Let $\mathcal{B}$ be a locally finite collection of non-empty subsets of $X$.
:::

::: pf-step
By local finiteness, for each $x \in X$, there exists an open neighborhood $U_x$ of $x$ that intersects only finitely many elements of $\mathcal{B}$.
:::

::: pf-step
The family $\mathcal{U} = \{U_x\}_{x \in X}$ forms an open covering of $X$.
:::

::: pf-step
Since $X$ is second-countable, $X$ is Lindelöf, so there exists a countable subcover $\{U_{x_k}\}_{k=1}^\infty$ of $X$.
:::

::: pf-step
For each $k \ge 1$, the collection $\mathcal{B}_k = \{B \in \mathcal{B} \mid B \cap U_{x_k} \neq \varnothing\}$ is finite.
:::

::: pf-step
Because $\bigcup_{k=1}^\infty U_{x_k} = X$, every non-empty set $B \in \mathcal{B}$ intersects some $U_{x_k}$, which means $\mathcal{B} = \bigcup_{k=1}^\infty \mathcal{B}_k$.
:::

::: pf-step
As a countable union of finite sets, $\mathcal{B}$ is at most countable. An arbitrary collection may also contain $\varnothing$, but this adds at most one member.
:::

:::

:::

::: {.pf-step #clf-implies-countable}
Forward direction ($\implies$): Countably locally finite implies countable.

::: pf-proof

::: pf-step
By definition, $\mathcal{A} = \bigcup_{n=1}^\infty \mathcal{A}_n$ where each $\mathcal{A}_n$ is a locally finite collection.
:::

::: pf-step
By step [](#locally-finite-is-countable-lemma){.pf-ref}, each subcollection $\mathcal{A}_n$ is at most countable.
:::

::: pf-step
As a countable union of countable collections, $\mathcal{A}$ is countable.
:::

:::

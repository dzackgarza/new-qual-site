::: {.exercise}

Consider the seventeen properties listed in Exercise 1 of the Supplementary Exercises (Review of the Basics): connected, path connected, locally connected, locally path connected, compact, limit point compact, locally compact Hausdorff, Hausdorff, regular, completely regular, normal, first-countable, second-countable, Lindelöf, separable, locally metrizable, metrizable.

Which of these properties does a metric space necessarily have?
:::

::: {.solution}
::: pf

::: pf-step
Properties that EVERY metric space necessarily satisfies: A metric space $(X, d)$ necessarily has the following **7 properties**: 1. **Hausdorff ($T_2$):** For distinct $x \neq y$, let $r = \frac{1}{2}d(x, y) > 0$.
The open balls $B(x, r)$ and $B(y, r)$ are disjoint open neighborhoods.
2. **Regular ($T_3$):** Singletons are closed. The empty closed set is separated from any point by $\varnothing$ and $X$. For a nonempty closed set $C$ with $x \notin C$, $r = d(x, C) = \inf_{c \in C} d(x, c) > 0$, since $C$ is closed.
The open sets $U = B(x, r/2)$ and $V = \{y \in X \mid d(y, C) < r/2\}$ are disjoint open sets separating $x$ and $C$.
3. **Completely regular ($T_{3\frac{1}{2}}$):** If $C=\varnothing$, the constant zero function separates $x$ from $C$. Otherwise, for a closed set $C$ and $x \notin C$, the function $f(y) = \frac{d(y, x)}{d(y, x) + d(y, C)}$ is continuous with $f(x) = 0$ and $f(c)=1$ for every $c\in C$.
4. **Normal ($T_4$):** This is Theorem 32.2. The card's own certificate is the function of Exercise 33.3: if either of two disjoint closed sets $A,B$ is empty, $X$ and $\varnothing$ separate them; otherwise $f(y) = \frac{d(y, A)}{d(y, A) + d(y, B)}$ is continuous and separates $A$ from $B$.
5. **First-countable:** For every $x \in X$, the countable family $\{B(x, 1/n) \mid n \in \ZZ_+\}$ forms a countable local neighborhood basis at $x$.
6. **Locally metrizable:** Every point has an open neighborhood (e.g. $X$ itself) that is metrizable.
7. **Metrizable:** Holds tautologically since $X$ is equipped with a compatible metric $d$, which is the topology the other entries use.
:::

::: pf-step
Properties that a metric space does NOT necessarily satisfy (with counterexamples):

::: pf-proof

::: pf-step
**Connected / Path connected:** The discrete two-point metric space $X = \{0, 1\}$ with $d(0, 1) = 1$ is neither connected nor path-connected, its two points being disjoint open sets and a path connected space being connected.
:::

::: pf-step
**Locally connected / Locally path connected:** The subspace $X = \{0\} \cup \{1/n \mid n \in \ZZ_+\} \subset \RR$ with the Euclidean metric is not locally connected at $0$, and a locally path connected space is locally connected, so it is not locally path connected either. For a small $\epsilon$, the components of the open set $X \cap (-\epsilon, \epsilon)$ are its points, as a connected subset of $X$ meeting two of them would meet $\{0\}$ and some $1/n$ and would have to contain the points in between, which are not in $X$; so Theorem 25.3 forbids local connectedness at $0$.
:::

::: pf-step
**Compact / Limit point compact:** The Euclidean line $\RR$ is not compact, the covering by the intervals $(-n, n)$ having no finite subcover, and $\ZZ \subset \RR$ is infinite, closed and discrete, so it has no limit point and $\RR$ is not limit point compact.
:::

::: pf-step
**Locally compact Hausdorff:** The rational numbers $\QQ \subset \RR$ with the induced Euclidean metric (or the Hilbert space $\ell^2$) is not locally compact at any point.
:::

::: pf-step
**Second-countable / Lindelöf / Separable:** An uncountable set $X$ equipped with the discrete metric $d(x, y) = 1$ ($x \neq y$) is a metric space that is not second-countable: in a space with a countable basis every discrete subspace is countable, by the injection of Example 2 of Section 30. It is then neither Lindelöf nor separable, by Theorem 30.3, and the three properties are equivalent in a metric space, Exercise 30.5.
:::

:::

:::

::: pf-step
Conclusion: The properties possessed by every metric space are precisely: **Hausdorff, regular, completely regular, normal, first-countable, locally metrizable, and metrizable**.

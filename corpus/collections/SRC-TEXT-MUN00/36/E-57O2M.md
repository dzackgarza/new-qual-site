::: {.exercise}

Consider the seventeen properties listed in Exercise 1 of the Supplementary Exercises (Review of the Basics).

Which of these properties are preserved under finite products?
Countable products?
Arbitrary products?
:::

::: {.solution}
The columns use the seventeen properties in Supplementary Exercise 1. “Yes” means that every product of spaces with that property has it, with the specified number of factors.

| Number | Property | Finite | Countable | Arbitrary |
| --- | --- | :---: | :---: | :---: |
| 1 | Connected | Yes | Yes | Yes |
| 2 | Path connected | Yes | Yes | No |
| 3 | Locally connected | Yes | No | No |
| 4 | Locally path connected | Yes | No | No |
| 5 | Compact | Yes | Yes | Yes |
| 6 | Limit point compact | No | No | No |
| 7 | Locally compact Hausdorff | Yes | No | No |
| 8 | Hausdorff | Yes | Yes | Yes |
| 9 | Regular | Yes | Yes | Yes |
| 10 | Completely regular | Yes | Yes | Yes |
| 11 | Normal | No | No | No |
| 12 | First countable | Yes | Yes | No |
| 13 | Second countable | Yes | Yes | No |
| 14 | Lindelöf | No | No | No |
| 15 | Countable dense subset | Yes | Yes | No |
| 16 | Locally metrizable | Yes | No | No |
| 17 | Metrizable | Yes | Yes | No |

Products preserve connectedness in every case: the points differing from a fixed base point in finitely many coordinates form a connected set, since each finite-coordinate piece is a finite product of connected spaces meeting the base point, and that set is dense. Path connectedness is preserved for finitely many factors, and for countably many by changing the coordinates one at a time along a path that rests on coordinate $n$ during the $n$-th of a shrinking sequence of intervals, so that every basic neighbourhood, which restricts finitely many coordinates, is entered in finite time. It is NOT preserved for arbitrary products: for uncountable $J$ the cube $\{0,1\}^J$ is connected because each of its factors is, while every path into it is constant, since each coordinate of a path is a continuous map into the discrete two-point space and $[0,1]$ is connected. Tychonoff's theorem gives compactness. The product topology preserves Hausdorffness, regularity, and complete regularity. Countable products preserve the two countability axioms and metrizability; choosing a countable dense set in each factor and varying only finitely many coordinates at a time gives a countable dense subset.

The Cantor cube $\{0,1\}^{\omega}$ is a countable product of locally connected, locally path connected discrete spaces, but is neither locally connected nor locally path connected. The product $\RR^\omega$ is not locally compact. A countable product of long rays is not locally metrizable: each long ray is locally metrizable but not metrizable, and every basic neighborhood in the product leaves some factor unrestricted, so it contains a nonmetrizable long-ray slice.

The Sorgenfrey plane is a product of two normal Lindelöf spaces but is neither normal nor Lindelöf. The failure of finite-product preservation for limit point compactness is noted in §28; it persists for countable and arbitrary products by adjoining singleton factors.

An uncountable product of nontrivial spaces can fail first countability, as $\{0,1\}^J$ does for uncountable $J$. It then fails second countability and metrizability. If $\cardinality{J}>\cardinality{\mathcal P(\ZZ_+)}$, the product $\RR^J$ has no countable dense subset by §30.

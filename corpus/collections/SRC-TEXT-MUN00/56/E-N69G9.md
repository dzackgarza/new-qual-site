::: {.exercise}

Find a circle about the origin containing all the roots of the polynomial equation $x^7 + x^2 + 1 = 0$.
:::

::: {.solution}
The exercise is solved in the retained set **dbFin, "Section 56: Problem 2 Solution"** (`tmp/sources/dbfin/section-56-the-fundamental-theorem-of-algebra/problem-2-solution.txt`), which rescales the polynomial and obtains the sharper radius $1.124$; the argument below is the card's own and answers the exercise as printed with the larger radius $2$. The statement is on the card.

::: pf

::: {.pf-step #root-estimate}
If $z$ is a root of $p(z)=z^{7}+z^{2}+1$, then $\abs{z}^{7}=\abs{z^{2}+1}\le\abs{z}^{2}+1$.

::: pf-proof
From $p(z)=0$ comes $z^{7}=-(z^{2}+1)$. Taking absolute values gives $\abs{z}^{7}=\abs{z^{2}+1}$, and the triangle inequality gives $\abs{z^{2}+1}\le\abs{z^{2}}+1=\abs{z}^{2}+1$.
:::

:::

::: {.pf-step #growth-comparison}
For every real $r\ge2$, $r^{7}>r^{2}+1$.

::: pf-proof
Since $r\ge2$ we have $r^{5}\ge2^{5}=32$, so $r^{7}=r^{5}r^{2}\ge32r^{2}$. Also $r\ge2$ gives $1\le r^{2}/4$, hence $r^{2}+1\le\tfrac54r^{2}$. Combining the two, $r^{7}\ge32r^{2}>\tfrac54r^{2}\ge r^{2}+1$.
:::

:::

::: {.pf-step #no-large-root}
Every root of $p$ satisfies $\abs{z}<2$.

::: pf-proof
Suppose $\abs{z}\ge2$. Step [](#root-estimate){.pf-ref} gives $\abs{z}^{7}\le\abs{z}^{2}+1$, while step [](#growth-comparison){.pf-ref} applied to $r=\abs{z}$ gives $\abs{z}^{7}>\abs{z}^{2}+1$; the two are incompatible, so no root has $\abs{z}\ge2$.
:::

:::

::: {.pf-step #answer}
The circle $\boxed{\abs{z}=2}$ about the origin contains every root of $x^{7}+x^{2}+1$ in its interior.

::: pf-proof
Step [](#no-large-root){.pf-ref} puts every root in the open disc $\abs{z}<2$, which is the interior of the circle of radius $2$ about the origin, so that circle contains all the roots, as the exercise asks. A smaller radius is available: dbFin's rescaling shows that every root lies in $\abs{z}\le c$ as soon as $c^{7}-c^{2}-1>0$, and $c=1.124$ satisfies it; no optimality is requested, and the card claims none.
:::

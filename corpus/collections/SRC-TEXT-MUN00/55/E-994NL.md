::: {.exercise}

Suppose that you are given the fact that for each $n$, there is no retraction $r: B^{n+1} \to S^n$.
(This result can be proved using more advanced techniques of algebraic topology.)
Prove the following:

(a) The identity map $i: S^n \to S^n$ is not nulhomotopic.

(b) The inclusion map $j: S^n \to \RR^{n+1} - 0$ is not nulhomotopic.

(c) Every nonvanishing vector field on $B^{n+1}$ points directly outward at some point of $S^n$, and directly inward at some point of $S^n$.

(d) Every continuous map $f: B^{n+1} \to B^{n+1}$ has a fixed point.

(e) Every $n+1$ by $n+1$ matrix with positive real entries has a positive eigenvalue.

(f) If $h: S^n \to S^n$ is nulhomotopic, then $h$ has a fixed point and $h$ maps some point $x$ to its antipode $-x$.
:::

::: {.solution}

::: pf

::: pf-step

Part (a): $\operatorname{id}_{S^n}$ is not nullhomotopic.
    *Proof:*

::: pf-proof

::: pf-step

Suppose for contradiction that $\operatorname{id}_{S^n}$ is nullhomotopic, so there is a homotopy $H: S^n \times I \to S^n$ with $H(x, 0) = x$ and $H(x, 1) = p_0$ for some $p_0 \in S^n$.

:::

::: pf-step

Define $r: B^{n+1} \to S^n$ in spherical coordinates by:
        $$r(t x) = H(x, 1 - t) \quad \text{for } x \in S^n, \, t \in [0, 1].$$

:::

::: pf-step

Because $r(0) = H(x, 1) = p_0$ is independent of $x$, $r$ is continuous on all of $B^{n+1}$.

:::

::: pf-step

For $x \in S^n$ ($t = 1$), $r(x) = H(x, 0) = x$.

:::

::: pf-step

Thus $r$ is a retraction $B^{n+1} \to S^n$, contradicting the no-retraction theorem.

:::

:::

:::

::: pf-step

Part (b): The inclusion $j: S^n \hookrightarrow \RR^{n+1} \setminus \{0\}$ is not nullhomotopic.
    *Proof:*

::: pf-proof

::: pf-step

The radial projection $\rho: \RR^{n+1} \setminus \{0\} \to S^n$ given by $\rho(y) = y / \norm{y}$ is continuous and satisfies $\rho \circ j = \operatorname{id}_{S^n}$.

:::

::: pf-step

If $j$ were nullhomotopic, the composition $\rho \circ j = \operatorname{id}_{S^n}$ would be nullhomotopic, contradicting Part (a).

:::

:::

:::

::: pf-step

Part (c): Nonvanishing vector fields point directly inward and outward.
    *Proof:*

::: pf-proof

::: pf-step

Let $v: B^{n+1} \to \RR^{n+1} \setminus \{0\}$ be a continuous non-vanishing vector field.

:::

::: pf-step

Suppose $v(x)$ never points directly outward on $S^n$, meaning there is no $x \in S^n$ and $\lambda > 0$ such that $v(x) = \lambda x$.

:::

::: pf-step

For each $x \in B^{n+1}$, the ray starting at $x$ in direction $-v(x)$ intersects the boundary $S^n$ at a unique point $r(x) = x - t v(x)$ with $t \ge 0$.

:::

::: pf-step

Since $v(x)$ never points outward on $S^n$, $r(x) = x$ for $x \in S^n$, making $r: B^{n+1} \to S^n$ a continuous retraction, contradiction.

:::

::: pf-step

Replacing $v$ with $-v$ proves that $v$ must also point directly inward at some point of $S^n$.

:::

:::

:::

::: pf-step

Part (d): Brouwer Fixed Point Theorem.
    *Proof:*

::: pf-proof

::: pf-step

Suppose $f: B^{n+1} \to B^{n+1}$ has no fixed points ($f(x) \neq x$ for all $x$).

:::

::: pf-step

For each $x \in B^{n+1}$, the ray from $f(x)$ through $x$ intersects $S^n$ at a unique point $r(x) = x + t(x)(x - f(x))$ where $t(x) \ge 0$.

:::

::: pf-step

By the quadratic formula, $t(x)$ is continuous, and for $x \in S^n$, $r(x) = x$.

:::

::: pf-step

Thus $r: B^{n+1} \to S^n$ is a continuous retraction, contradiction.

:::

:::

:::

::: pf-step

Part (e): Perron-Frobenius positive eigenvalue.
    *Proof:*

::: pf-proof

::: pf-step

Let $A$ be an $(n+1) \times (n+1)$ matrix with strictly positive entries $a_{ij} > 0$.

:::

::: pf-step

Let $\Delta^n = \{x \in \RR^{n+1} \mid x_i \ge 0, \, \sum_{i=1}^{n+1} x_i = 1\}$, which is homeomorphic to $B^n$.

:::

::: pf-step

For $x \in \Delta^n$, $x \neq 0$, so $(Ax)_i = \sum_j a_{ij} x_j > 0$ for all $i$.

:::

::: pf-step

Define $g: \Delta^n \to \Delta^n$ by $g(x) = \frac{Ax}{\norm{Ax}_1}$.

:::

::: pf-step

By Brouwer's Fixed Point Theorem on $\Delta^n \cong B^n$, $g$ has a fixed point $x_0 \in \Delta^n$.

:::

::: pf-step

Then $Ax_0 = \lambda x_0$ where $\lambda = \norm{Ax_0}_1 > 0$, so $\lambda$ is a positive eigenvalue.

:::

:::

:::

::: pf-step

Part (f): Fixed points and antipodal points of nullhomotopic maps on $S^n$.
    *Proof:*

::: pf-proof

::: pf-step

If $h(x) \neq -x$ for all $x \in S^n$, then the straight-line homotopy $H_1(x, t) = \frac{(1-t)h(x) + t x}{\norm{(1-t)h(x) + tx}}$ is well-defined, showing $h \simeq \operatorname{id}_{S^n}$. Since $h$ is nullhomotopic, this would force $\operatorname{id}_{S^n}$ to be nullhomotopic, contradicting (a). Thus $h(x) = -x$ for some $x$.

:::

::: pf-step

If $h(x) \neq x$ for all $x \in S^n$, then $H_2(x, t) = \frac{(1-t)h(x) - tx}{\norm{(1-t)h(x) - tx}}$ shows $h \simeq a$, where $a(x) = -x$ is the antipodal map.

:::

::: pf-step

Then $\operatorname{id}_{S^n} = a \circ a \simeq a \circ h \simeq a \circ c_{p_0} = c_{-p_0}$, making $\operatorname{id}_{S^n}$ nullhomotopic, contradiction. Thus $h(x) = x$ for some $x$. Q.E.D.

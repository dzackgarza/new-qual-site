::: {.exercise}

Let $p: X \to Y$ be a closed continuous surjective map.
Show that if $X$ is normal, then so is $Y$.
[Hint: If $U$ is an open set containing $p^{-1}(\ts{y})$, show there is a neighborhood $W$ of $y$ such that $p^{-1}(W) \subset U$.]
:::

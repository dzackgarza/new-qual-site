::: {.exercise}

Let $f: X \to Y$ be a continuous open map.
Show that if $X$ satisfies the first or the second countability axiom, then $f(X)$ satisfies the same axiom.
:::

::: {.solution}
The published solution is **"Doug's World", *Munkres - Topology - Chapter 4 Solutions* (30 August 2017; the file names no author), Problem 30.12, printed p. 3** (`tmp/sources/munkres-solutions-dougsworld-ch4.pdf`); both countability arguments are its.

Replace $Y$ by $f(X)$, so that $f$ is a continuous open surjection.

::: pf

::: {.pf-step #first}
If $X$ is first countable, then so is $Y$.

::: pf-proof
Let $y\in Y$ and choose $x\in f^{-1}(\{y\})$. Let $B_{1},B_{2},\dots$ be a countable basis for the neighbourhoods of $x$ in $X$. Each $f(B_{n})$ is open in $Y$ because $f$ is open, and contains $y$ because $x\in B_{n}$. If $V$ is a neighbourhood of $y$, then $f^{-1}(V)$ is a neighbourhood of $x$ because $f$ is continuous, so $B_{n}\subset f^{-1}(V)$ for some $n$, whence $f(B_{n})\subset V$. So $\{f(B_{n})\}$ is a countable basis at $y$.
:::

:::

::: {.pf-step #second}
If $X$ is second countable, then so is $Y$.

::: pf-proof
Let $\mathcal{B}=\{B_{n}\mid n\ge1\}$ be a countable basis for $X$. The collection $\{f(B_{n})\mid n\ge1\}$ is a countable collection of open sets of $Y$, since $f$ is open. If $y\in V$ with $V$ open in $Y$, choose $x\in f^{-1}(\{y\})$; then $f^{-1}(V)$ is open in $X$ and contains $x$, so $x\in B_{n}\subset f^{-1}(V)$ for some $n$, whence $y\in f(B_{n})\subset V$. So the collection is a basis for $Y$.
:::

:::

::: {.pf-step}
$f(X)$ satisfies the same countability axiom.

::: pf-proof
Steps [](#first){.pf-ref} and [](#second){.pf-ref} prove each implication for the surjection $f:X\to f(X)$, which has the same property as $f$.
:::

::: {.exercise}

Let $A$ be a closed subspace of $X$.
Show that if $X$ is Lindelöf, then $A$ is Lindelöf.
Show by example that if $X$ has a countable dense subset, $A$ need not have a countable dense subset.
:::

::: {.solution}

::: pf

::: pf-step
Closed subspaces of Lindelöf spaces are Lindelöf:
Let $X$ be Lindelöf and $A \subseteq X$ be a closed subspace. Then $A$ is Lindelöf.

::: pf-proof

::: pf-step
Let $\mathcal{U} = \{U_\alpha\}_{\alpha \in J}$ be an open cover of the subspace $A$.
:::

::: pf-step
By definition of the subspace topology, for each $\alpha \in J$ there exists an open set $V_\alpha \subseteq X$ such that $U_\alpha = V_\alpha \cap A$.
:::

::: pf-step
Since $A \subseteq \bigcup_{\alpha \in J} V_\alpha$ and $A$ is closed in $X$, the complement $X \setminus A$ is open in $X$.
:::

::: pf-step
The family $\mathcal{V} = \{V_\alpha\}_{\alpha \in J} \cup \{X \setminus A\}$ is an open cover of the entire space $X$.
:::

::: pf-step
Because $X$ is Lindelöf, there exists a countable subcover of $X$:
$$\mathcal{V}' = \{V_{\alpha_n}\}_{n=1}^\infty \cup \{X \setminus A\}.$$
:::

::: pf-step
Intersecting with $A$, since $(X \setminus A) \cap A = \varnothing$:
$$A = A \cap \left[ (X \setminus A) \cup \bigcup_{n=1}^\infty V_{\alpha_n} \right] = \bigcup_{n=1}^\infty (V_{\alpha_n} \cap A) = \bigcup_{n=1}^\infty U_{\alpha_n}.$$
:::

::: pf-step
Thus $\{U_{\alpha_n}\}_{n=1}^\infty$ is a countable subcover of $A$, proving $A$ is Lindelöf.
:::

:::

:::

::: pf-step
Counterexample: Separability is not hereditary to closed subspaces.

::: pf-proof

::: pf-step
Consider the Sorgenfrey plane $X = \RR_l \times \RR_l$, where $\RR_l$ is the lower limit topology (Sorgenfrey line).
:::

::: pf-step
The countable subset $D = \QQ \times \QQ$ is dense in $X$ because every basic open rectangle $[a, b) \times [c, d)$ contains points of $\QQ \times \QQ$. Thus $X$ is separable.
:::

::: pf-step
Consider the "anti-diagonal" line $L = \{(x, -x) \mid x \in \RR\} \subset X$.
:::

::: pf-step
The subspace $L$ is closed in $X$. If $x+y>0$, every point of $[x,x+1)\times[y,y+1)$ has positive coordinate sum. If $x+y<0$, choose $0<\varepsilon<-(x+y)/2$; every point of $[x,x+\varepsilon)\times[y,y+\varepsilon)$ has negative coordinate sum. Thus every point outside $L$ has a basic neighborhood disjoint from $L$.
:::

::: pf-step
The subspace topology induced on $L$ is discrete: for any $p = (x, -x) \in L$, the basic open set $U = [x, x+1) \times [-x, -x+1)$ in $X$ satisfies $U \cap L = \{(x, -x)\} = \{p\}$.
:::

::: pf-step
In an uncountable discrete space, the only dense subset is the entire space itself, which is uncountable.
:::

::: pf-step
Therefore, the closed subspace $L$ is not separable. Q.E.D.
:::

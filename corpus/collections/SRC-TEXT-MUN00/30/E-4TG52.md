::: {.exercise}

Show that every compact metrizable space $X$ has a countable basis.
[Hint: Let $\mathcal{A}_n$ be a finite covering of $X$ by $1/n$-balls.]
:::

::: {.solution}

::: pf

::: pf-step
Construction of candidate basis $\mathcal{B}$:

::: pf-proof

::: pf-step
Let $d$ be a compatible metric on $X$.

::: pf-proof
Such a metric exists because $X$ is metrizable.
:::

:::

::: pf-step
For each positive integer $n \in \ZZ_+$, the family of open balls $\{B_d(x, 1/n)\}_{x \in X}$ is an open cover of $X$.

::: pf-proof
Every point lies in the ball of radius $1/n$ about itself.
:::

:::

::: pf-step
Because $X$ is compact, there exists a finite subcover:
$$\mathcal{A}_n = \left\{ B_d\left(x_{n, 1}, \frac{1}{n}\right), \dots, B_d\left(x_{n, k_n}, \frac{1}{n}\right) \right\}.$$

::: pf-proof
Compactness applied to the open cover by balls of radius $1/n$.
:::

:::

::: pf-step
Define $\mathcal{B} = \bigcup_{n=1}^\infty \mathcal{A}_n$.

::: pf-proof
This is a definition: the union of the finitely many chosen coverings.
:::

:::

::: pf-step
As a countable union of finite sets, $\mathcal{B}$ is a countable collection of open subsets of $X$.

::: pf-proof
Each $\mathcal{A}_n$ is finite, a countable union of finite sets is countable, and every member of it is an open ball.
:::

:::

:::

:::

::: pf-step
Verification that $\mathcal{B}$ is a basis for the topology of $X$:

::: pf-proof

::: pf-step
Let $U \subseteq X$ be an open set and let $x \in U$.

::: pf-proof
This is arbitrary data for the basis condition: an open set and a point of it.
:::

:::

::: pf-step
Since $U$ is metric-open, there exists $\varepsilon > 0$ such that the metric ball $B_d(x, \varepsilon) \subseteq U$.

::: pf-proof
The metric $d$ induces the topology, so an open set containing $x$ contains a metric ball about $x$.
:::

:::

::: pf-step
Choose an integer $n \in \ZZ_+$ sufficiently large such that $\frac{1}{n} < \frac{\varepsilon}{2}$.

::: pf-proof
The sequence $1/n$ tends to $0$, so some $n$ satisfies the inequality.
:::

:::

::: pf-step
Because $\mathcal{A}_n$ covers $X$, there exists an index $i \in \{1, \dots, k_n\}$ such that $x \in B_d(x_{n, i}, \frac{1}{n})$.

::: pf-proof
The family $\mathcal{A}_n$ covers $X$.
:::

:::

::: pf-step
We claim that $B_d(x_{n, i}, \frac{1}{n}) \subseteq B_d(x, \varepsilon)$:
- For any $y \in B_d(x_{n, i}, \frac{1}{n})$, the triangle inequality gives:
  $$d(y, x) \le d(y, x_{n, i}) + d(x_{n, i}, x) < \frac{1}{n} + \frac{1}{n} = \frac{2}{n} < \varepsilon.$$
- Thus $y \in B_d(x, \varepsilon) \subseteq U$.

::: pf-proof
If $y$ is within $1/n$ of $x_{n,i}$, then $d(y,x)\le d(y,x_{n,i})+d(x_{n,i},x)<1/n+1/n<\varepsilon$.
:::

:::

::: pf-step
Hence $x \in B_d(x_{n, i}, \frac{1}{n}) \subseteq U$, with $B_d(x_{n, i}, \frac{1}{n}) \in \mathcal{B}$.

::: pf-proof
The ball about $x_{n,i}$ contains $x$ and lies inside $B(x,\varepsilon)$, which lies in $U$.
:::

:::

:::

:::

::: pf-step
Conclusion:
$\mathcal{B}$ is a countable basis for $X$, so $X$ is second-countable. Q.E.D.

::: pf-proof
The basis condition was verified at an arbitrary point of an arbitrary open set, and countability was shown above.
:::

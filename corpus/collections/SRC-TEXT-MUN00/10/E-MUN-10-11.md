The retained text argued: "If there is an injection A -> B, then there is no injection B -> A: two injections would give equal cardinality by Cantor-Schroeder-Bernstein, and we are in the case where the cardinalities differ." That is circular -- the trichotomy is what is being proved, so nothing may assume which case holds -- and the sentence is also false as a statement, since two injections can perfectly well coexist (A = B = Z+). ::: {.exercise}

Let $A$ and $B$ be two sets.
Using the well-ordering theorem, prove that either they have the same cardinality, or one has cardinality greater than the other.
[Hint: If there is no surjection $f: A \to B$, apply the preceding exercise.]

:::

::: {.solution}
The complete published solution is **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 10.11, printed pp. 118--119** (`tmp/sources/munkres-solutions-whitman.pdf`); the lemma comparing injections with surjections and the appeal to Exercise 10.10 are his. The case analysis has been rearranged: see the last audit note.

Throughout, two sets have the same cardinality when there is a bijection between them (Exercise 7.6, printed p. 51), and a nonempty set $A$ has greater cardinality than a nonempty set $B$ when there is an injection $B\to A$ but no injection $A\to B$ (Exercise 9.6, printed p. 62). Cantor--Schroeder--Bernstein is Exercise 7.6(b), printed p. 52; the well-ordering theorem is on printed p. 65; the transfinite recursion of Exercise 10.10 is stated on printed pp. 67--68, and the exercise itself is on printed p. 68.

::: pf

::: {.pf-step #lemma}
Let $A$ and $B$ be nonempty well-ordered sets. Then there is an injection $A\to B$ if and only if there is a surjection $B\to A$.

::: pf-proof

::: {.pf-step #injection-to-surjection}
An injection $f:A\to B$ gives a surjection $B\to A$.

::: pf-proof
Fix $a\in A$, possible as $A\neq\varnothing$, and define $g:B\to A$ by $g(y)=x$ when $y=f(x)$ and $g(y)=a$ when $y\notin f(A)$. This is well defined: at most one $x$ satisfies $f(x)=y$ because $f$ is injective, and the two cases are exhaustive. For $x\in A$ we have $g(f(x))=x$, so $g$ is surjective.

:::

:::

::: {.pf-step #surjection-to-injection}
A surjection $g:B\to A$ gives an injection $A\to B$.

::: pf-proof
For $x\in A$ the set $B_x=\{y\in B: g(y)=x\}$ is nonempty because $g$ is surjective, and $B$ is well ordered, so $B_x$ has a smallest element; define $f(x)$ to be it. Then $f(x)\in B_x$, that is $g(f(x))=x$. If $x\neq x'$ then $B_x\cap B_{x'}=\varnothing$, since no $y$ has $g(y)=x$ and $g(y)=x'$; so $f(x)\neq f(x')$ and $f$ is injective.

:::

:::

:::

:::

::: {.pf-step #wellorder}
Both sets may be assumed well ordered.

::: pf-proof
By the well-ordering theorem each of $A$ and $B$ carries an order relation making it well ordered; fix one such order on each. This is the only use of the well-ordering theorem.

:::

:::

::: {.pf-step #empty}
If one of the sets is empty, the conclusion holds.

::: pf-proof
Suppose $A=\varnothing$. If $B=\varnothing$ the empty function is a bijection, so the two have the same cardinality. If $B\neq\varnothing$ there is no bijection $A\to B$, while the empty function is an injection $A\to B$ with no inverse, so $A$ has strictly smaller cardinality than $B$; this is the degenerate case of the notion of greater cardinality, which Exercise 9.6 states for nonempty sets. The case $B=\varnothing$ is the same with the roles exchanged.

:::

:::

::: {.pf-step #case-injection}
If there is an injection $A\to B$, then either the two sets have the same cardinality or $B$ has greater cardinality than $A$.

::: pf-proof

::: {.pf-step #both}
If there is also an injection $B\to A$, the two sets have the same cardinality.

::: pf-proof
Cantor--Schroeder--Bernstein, Exercise 7.6(b), turns the two injections into a bijection $A\to B$.

:::

:::

::: {.pf-step #only}
If there is no injection $B\to A$, then $B$ has greater cardinality than $A$.

::: pf-proof
By assumption $A$ and $B$ are nonempty and there is an injection $A\to B$; by the subcase hypothesis there is none $B\to A$. That is exactly the definition of $B$ having greater cardinality than $A$ (Exercise 9.6, with the roles of the two sets exchanged).

:::

:::

:::

:::

::: {.pf-step #case-no-injection}
If there is no injection $A\to B$, then $A$ has greater cardinality than $B$.

::: pf-proof

::: {.pf-step #no-surjection}
No section of $B$ maps onto $A$, and in particular there is no surjection $B\to A$.

::: pf-proof
By the lemma of step [](#lemma){.pf-ref}, applied to the nonempty well-ordered sets $A$ and $B$, the absence of an injection $A\to B$ means there is no surjection $B\to A$. If a section $S$ of $B$ admitted a surjection $q:S\to A$, then extending $q$ to $B$ by sending the elements of $B-S$ to a fixed element $a\in A$ — possible because $A\neq\varnothing$ — would give a surjection $B\to A$, which does not exist. Note $B$ itself is not a section of $B$, so the two statements are separate.

:::

:::

::: {.pf-step #recursion}
Exercise 10.10 applies with $J=B$ and $C=A$ and yields $h:B\to A$ with $h(x)=\text{smallest}[A-h(S_x)]$ for every $x\in B$.

::: pf-proof
$B$ and $A$ are well-ordered sets, and by step [](#no-surjection){.pf-ref} no surjective function maps a section of $B$ onto $A$; these are exactly the hypotheses of the theorem stated in Exercise 10.10 (printed pp. 67--68). The conclusion is the unique $h:B\to A$ satisfying that recursion.

:::

:::

::: {.pf-step #injective}
$h$ is injective.

::: pf-proof
If $y<y'$ in $B$ then $y\in S_{y'}$, the section of $B$ by $y'$, so $h(y)\in h(S_{y'})$; while $h(y')$, being the smallest element of $A-h(S_{y'})$, does not lie in $h(S_{y'})$. Hence $h(y)\neq h(y')$. So distinct comparable elements have distinct images, and any two distinct elements of the well-ordered set $B$ are comparable.

:::

:::

::: {.pf-step #greater}
$A$ has greater cardinality than $B$.

::: pf-proof
There is an injection $B\to A$, namely $h$, by step [](#injective){.pf-ref}; and there is no injection $A\to B$ by the hypothesis of this case. Both sets are nonempty, so this is the definition of $A$ having greater cardinality than $B$.

:::

:::

:::

:::

::: {.pf-step #trichotomy}
For any two sets $A$ and $B$, either they have the same cardinality or one of them has greater cardinality than the other.

::: pf-proof
Steps [](#empty){.pf-ref} disposes of the case that one set is empty; otherwise steps [](#wellorder){.pf-ref} and [](#case-injection){.pf-ref}, [](#case-no-injection){.pf-ref} cover the two exhaustive possibilities, that there is an injection $A\to B$ or that there is none. In the first there is a bijection or $B$ is greater than $A$, in the second $A$ is greater than $B$.

:::

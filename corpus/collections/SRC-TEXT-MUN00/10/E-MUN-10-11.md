::: {.exercise}

Let $A$ and $B$ be two sets.
Using the well-ordering theorem, prove that either they have the same cardinality, or one has cardinality greater than the other.
[Hint: If there is no surjection $f: A \to B$, apply the preceding exercise.]
:::

::: {.solution}
The complete published solution is **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 10.11, printed pp. 118--119** (`tmp/sources/munkres-solutions-whitman.pdf`); the lemma and the appeal to Exercise 10.10 are his.

**Lemma.** For well-ordered sets $A\ne\varnothing$ and $B$, there is an injection $A\to B$ if and only if there is a surjection $B\to A$.

*Proof.* If $f:A\to B$ is injective and $a\in A$, define $g:B\to A$ by $g(y)=x$ when $y=f(x)$ — the $x$ is unique because $f$ is injective — and $g(y)=a$ when $y\notin f(A)$. Then $g$ is a function $B\to A$ and $g(f(x))=x$ for every $x\in A$, so $g$ is surjective.

Conversely, let $g:B\to A$ be surjective. For $x\in A$ the set $B_{x}=\{y\in B\mid g(y)=x\}$ is nonempty, and $B$ is well ordered, so $B_{x}$ has a smallest element; define $f(x)$ to be that element. Then $f:A\to B$ and $f(x)\in B_{x}$, i.e. $g(f(x))=x$, for every $x$. If $x\ne x'$ then $B_{x}\cap B_{x'}=\varnothing$ (no $y$ can have $g(y)=x$ and $g(y)=x'$), so $f(x)\ne f(x')$: the map $f$ is injective.

Now let $A$ and $B$ be sets. By the well-ordering theorem each carries a well-ordering, and we fix such orders; so $A$ and $B$ are well-ordered sets.

If $A=\varnothing$: then $\cardinality{A}=0$ and, if $B\ne\varnothing$, $B$ has greater cardinality than $A$; while if $B=\varnothing$ the two sets have the same cardinality, the empty function being a bijection. So assume $A\ne\varnothing$ and $B\ne\varnothing$.

If there is an injection $A\to B$, then there is no injection $B\to A$: two injections would give $\cardinality{A}=\cardinality{B}$ by the Cantor--Schroeder--Bernstein theorem (Exercise 7.6(b)), and we are in the case where the cardinalities differ. By definition this means that $B$ has greater cardinality than $A$.

If there is no injection $A\to B$, then by the lemma there is no surjection $B\to A$. Hence no section of $B$ maps onto $A$: such a surjection $S\to A$, $S$ a section of $B$, would extend to a surjection $B\to A$ by assigning to the elements of $B-S$ any fixed element of $A$, which is possible since $A\ne\varnothing$. So Exercise 10.10 applies with $J=B$ and $C=A$ and gives a function $h:B\to A$ satisfying
$$
h(x)=\text{smallest}[A-h(S_{x})]
$$
for every $x\in B$, where $S_{x}$ is the section of $B$ by $x$.

The map $h$ is injective. If $y<y'$ in $B$, then $y\in S_{y'}$, so $h(y)\in h(S_{y'})$, while $h(y')$, being the smallest element of $A-h(S_{y'})$, does not lie in $h(S_{y'})$; hence $h(y)\ne h(y')$. Thus there is an injection $B\to A$ and none $A\to B$, so $A$ has greater cardinality than $B$ by definition.

The two cases are exhaustive, so either the sets have the same cardinality or one of them has greater cardinality than the other.

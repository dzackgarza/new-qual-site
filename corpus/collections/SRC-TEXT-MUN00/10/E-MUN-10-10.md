::: {.exercise}

Theorem.
Let $J$ and $C$ be well-ordered sets; assume that there is no surjective function mapping a section of $J$ onto $C$. Then there exists a unique function $h \colon J \to C$ satisfying the equation

(\*)
$$
h(x) = \text{smallest}\,[C - h(S_{x})]
$$
for each $x \in J$, where $S_{x}$ is the section of $J$ by $x$.

(a) If $h$ and $k$ map sections of $J$, or all of $J$, into $C$ and satisfy (\*) for all $x$ in their respective domains, show that $h(x) = k(x)$ for all $x$ in both domains.

(b) If there exists a function $h \colon S_{\alpha} \to C$ satisfying (\*), show that there exists a function $k \colon S_{\alpha} \cup \{\alpha\} \to C$ satisfying (\*).

(c) If $K \subset J$ and for all $\alpha \in K$ there exists a function $h_{\alpha} \colon S_{\alpha} \to C$ satisfying (\*), show that there exists a function
$$
k \colon \bigcup_{\alpha \in K} S_{\alpha} \longrightarrow C
$$
satisfying (\*).

(d) Show by transfinite induction that for every $\beta \in J$, there exists a function $h_{\beta} \colon S_{\beta} \to C$ satisfying (\*). [Hint: If $\beta$ has an immediate predecessor $\alpha$, then $S_{\beta} = S_{\alpha} \cup \{\alpha\}$. If not, $S_{\beta}$ is the union of all $S_{\alpha}$ with $\alpha < \beta$.]

(e) Prove the theorem.
:::

::: {.solution}
The published solution is **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 10.10, printed pp. 115--117** (`tmp/sources/munkres-solutions-whitman.pdf`); all five parts are his, together with the reduction of proof by transfinite induction to Exercise 10.7. The statement is Munkres, *Topology*, 2nd ed. (2000), §10 Exercise 10. Throughout, $J$ and $C$ are well ordered, $S_x=\{y\in J\mid y<x\}$ is the section of $J$ by $x$, and the standing hypothesis is that no surjective function maps a section of $J$ onto $C$; consequently $C-h(S_x)\ne\varnothing$ for every partial $h$ into $C$ satisfying $(\ast)$, so the smallest element in $(\ast)$ exists.

::: pf

::: {.pf-step #transfinite-induction}
If $P$ is a proposition about elements of $J$ and $P(\alpha)$ holds whenever $P(x)$ holds for all $x\in S_\alpha$, then $P(\beta)$ holds for every $\beta\in J$.

::: pf-proof
Let $J_0=\{x\in J\mid P(x)\}$. If $S_\alpha\subset J_0$ then $P(x)$ holds for every $x\in S_\alpha$, hence $P(\alpha)$ holds and $\alpha\in J_0$; so $J_0$ is inductive in the sense of the section, and $J_0=J$ by Exercise 10.7.
:::

:::

::: {.pf-step #part-a}
(a) If $h$ and $k$ map sections of $J$, or all of $J$, into $C$ and satisfy $(\ast)$ on their respective domains, then $h(x)=k(x)$ for every $x$ in both domains.

::: pf-proof
Let the domains be $H$ and $K$; sections of a well-ordered set are nested, and $J$ contains every section, so after relabelling $H\subset K$. If $h$ and $k$ differed on $H$, there would be a smallest $x\in H$ with $h(x)\ne k(x)$, because $H\subset J$ is well ordered. For $y\in S_x\subset H$ minimality gives $h(y)=k(y)$, so $h(S_x)=k(S_x)$; and both functions satisfy $(\ast)$ at $x$, whence
$$
h(x)=\text{smallest}\,[C-h(S_x)]=\text{smallest}\,[C-k(S_x)]=k(x),
$$
a contradiction.
:::

:::

::: {.pf-step #part-b}
(b) If $h:S_\alpha\to C$ satisfies $(\ast)$, then some $k:S_\alpha\cup\{\alpha\}\to C$ satisfies $(\ast)$.

::: pf-proof
Define $k$ by $k(x)=h(x)$ for $x\in S_\alpha$ and $k(\alpha)=\text{smallest}\,[C-h(S_\alpha)]$; this is well defined because $S_\alpha\cap\{\alpha\}=\varnothing$ and $C-h(S_\alpha)\ne\varnothing$ by the standing hypothesis. For $x\in S_\alpha$ we have $S_x\subset S_\alpha$, so $k(S_x)=h(S_x)$ and $k(x)=h(x)=\text{smallest}\,[C-h(S_x)]=\text{smallest}\,[C-k(S_x)]$; for $x=\alpha$ the same identity holds because $k$ and $h$ agree on $S_\alpha$. So $k$ satisfies $(\ast)$.
:::

:::

::: {.pf-step #part-c}
(c) If $K\subset J$ and for every $\alpha\in K$ there is $h_\alpha:S_\alpha\to C$ satisfying $(\ast)$, then $k=\bigcup_{\alpha\in K}h_\alpha$ is a function on $\bigcup_{\alpha\in K}S_\alpha$ into $C$ satisfying $(\ast)$.

::: pf-proof
$k$ is a function: if $(x,a),(x,b)\in k$ then $x\in S_\alpha\cap S_\beta$ for some $\alpha,\beta\in K$, and step [](#part-a){.pf-ref} gives $a=h_\alpha(x)=h_\beta(x)=b$. Its domain is $\bigcup_{\alpha\in K}S_\alpha$ and its values lie in $C$. If $x\in S_\alpha$ with $\alpha\in K$, then $S_x\subset S_\alpha$, so $k(S_x)=h_\alpha(S_x)$ and $k(x)=h_\alpha(x)=\text{smallest}\,[C-h_\alpha(S_x)]=\text{smallest}\,[C-k(S_x)]$, which is $(\ast)$ at $x$.
:::

:::

::: {.pf-step #part-d}
(d) For every $\beta\in J$ there is $h_\beta:S_\beta\to C$ satisfying $(\ast)$.

::: pf-proof

::: {.pf-step #successor-case}
If $\beta$ has an immediate predecessor $\alpha$, then $h_\beta$ exists.

::: pf-proof
Here $S_\beta=S_\alpha\cup\{\alpha\}$: an $x<\beta$ satisfies $x\le\alpha$ because $\alpha$ is immediate predecessor, and conversely $x<\alpha$ or $x=\alpha$ gives $x<\beta$. Since $\alpha\in S_\beta$, the induction hypothesis supplies $h_\alpha:S_\alpha\to C$ satisfying $(\ast)$, and step [](#part-b){.pf-ref} extends it to $S_\alpha\cup\{\alpha\}=S_\beta$.
:::

:::

::: {.pf-step #limit-case}
If $\beta$ has no immediate predecessor, then $h_\beta$ exists.

::: pf-proof
Here $S_\beta=\bigcup_{\gamma<\beta}S_\gamma$: one inclusion is immediate, and if $x<\beta$ then $x$ is not an immediate predecessor of $\beta$, so some $\gamma$ satisfies $x<\gamma<\beta$ and $x\in S_\gamma$. By the induction hypothesis each $\gamma<\beta$ carries $h_\gamma$ satisfying $(\ast)$ on $S_\gamma$, so step [](#part-c){.pf-ref} applied to $K=S_\beta$ produces a function on $\bigcup_{\gamma\in S_\beta}S_\gamma=S_\beta$ satisfying $(\ast)$.
:::

:::

Steps [](#successor-case){.pf-ref} and [](#limit-case){.pf-ref} are the two cases of the induction, so step [](#transfinite-induction){.pf-ref} gives the assertion for every $\beta\in J$.
:::

:::

::: {.pf-step #part-e}
(e) There is a function $h:J\to C$ satisfying $(\ast)$, and it is unique.

::: pf-proof
If $J=\varnothing$ the empty function satisfies $(\ast)$ vacuously. If $J$ has no largest element then $J=\bigcup_{\alpha\in J}S_\alpha$: every $x$ satisfies $x<y$ for some $y\in J$, so $x\in S_y$. Part [](#part-d){.pf-ref} supplies $h_\alpha$ on each $S_\alpha$, and step [](#part-c){.pf-ref} with $K=J$ produces $h:J\to C$ satisfying $(\ast)$. If $J$ has a largest element $\beta$ then $J=S_\beta\cup\{\beta\}$, part [](#part-d){.pf-ref} supplies $h_\beta$, and step [](#part-b){.pf-ref} extends it to $J$. In every case a function satisfying $(\ast)$ exists, and uniqueness is step [](#part-a){.pf-ref}. This proves the theorem.
:::

::: {.exercise}

In the finite complement topology on $\RR$, to what point or points does the sequence $x_n = 1/n$ converge?
:::

::: {.solution}
The complete published solution is **"positron0802", *Solutions to Topology, Chapter 2* (1 January 2021), Exercise 17.14, PDF p. 8** (`tmp/sources/munkres-solutions-positron-ch2.pdf`); the argument is theirs. Whitman, printed p. 166, argues by contradiction from the definition of convergence.

In the finite complement topology on $\RR$, a nonempty open set is one whose complement is finite.

::: pf

::: pf-step

The sequence $x_{n}=1/n$ converges to every point of $\RR$.

::: pf-proof

Let $a\in\RR$ and let $U$ be a neighbourhood of $a$; replacing $U$ by an open subset of it containing $a$, assume $U$ is open. Then $\RR-U$ is finite, since $U$ is nonempty and open. The terms $x_{n}$ are pairwise distinct, so only finitely many indices $n$ satisfy $x_{n}\in\RR-U$; hence there is $N\in\ZZ_{+}$ with $x_{n}\in U$ for every $n\ge N$. As $U$ was an arbitrary neighbourhood of $a$, the sequence converges to $a$, and $a$ was arbitrary.

:::

:::

:::
:::

::: {.remark}
The same argument applies to any sequence in this topology whose set of values is infinite, so limits are not unique there; dually, the finite complement topology on an infinite set is not Hausdorff (Theorem 17.10, printed p. 99).
:::

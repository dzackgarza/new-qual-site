::: {.exercise}

Consider the five topologies on $\RR$ given in Exercise 7 of §13.

(a) Determine the closure of the set $K = \theset{1/n \mid n \in \ZZ_+}$ under each of these topologies.

(b) Which of these topologies satisfy the Hausdorff axiom?
the $T_1$ axiom?
:::

::: {.solution}
The complete published solution is **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 17.16** (`tmp/sources/munkres-solutions-whitman.pdf`); the five closures of (a) and the separation arguments of (b) are his, with "positron0802", *Solutions to Topology, Chapter 2*, Exercise 17.16, agreeing on all ten answers.

Let $K=\theset{1/n\mid n\in\ZZ_{+}}$, and let $\mathcal{T}_{1}$ be the standard topology on $\RR$, $\mathcal{T}_{2}$ the topology of $\RR_{K}$, $\mathcal{T}_{3}$ the finite complement topology, $\mathcal{T}_{4}$ the upper limit topology with basis the sets $(a,b]$, and $\mathcal{T}_{5}$ the topology generated by the rays $(-\infty,a)$; these are the five topologies of Exercise 13.7.

::: pf

::: {.pf-step #refinement}

If $\mathcal{T}\subset\mathcal{T}'$ are topologies on $X$ and $\mathcal{T}$ is $T_{1}$, respectively Hausdorff, then so is $\mathcal{T}'$.

::: pf-proof

A finite set closed in $\mathcal{T}$ has complement open in $\mathcal{T}$, hence open in $\mathcal{T}'$ and so closed there, which gives the $T_{1}$ assertion; and disjoint $\mathcal{T}$-neighbourhoods of two points are open in $\mathcal{T}'$ and remain disjoint, which gives the Hausdorff assertion.

:::

:::

::: pf-step

In the standard topology, $\overline{K}=K\cup\{0\}$.

::: pf-proof

The point $0$ is a limit point of $K$: a basis element $(a,b)$ with $0\in(a,b)$ has $b>0$, so $1/n\in(a,b)$ for all $n>1/b$. Every $x\notin K\cup\{0\}$ has a neighbourhood meeting $K$ in nothing: if $x<0$ then $(x-1,0)$ contains no element of $K$; if $x>1$ then $(1,x+1)$ contains none; and if $0<x\notin K$ then, choosing $n$ with $n<1/x<n+1$ (Exercise 4.9(b)), we get $1/(n+1)<x<1/n$ and the interval $(1/(n+1),1/n)$ contains $x$ and no element of $K$. So the only limit point of $K$ is $0$.

:::

:::

::: pf-step

In $\RR_{K}$, $\overline{K}=K$.

::: pf-proof

The complement is open in $\RR_{K}$, since
$$
\RR-K=(-\infty,0)\cup\bigcup_{n\in\ZZ_{+}}\Big(\tfrac1{n+1},\tfrac1n\Big)\cup(1,\infty)
$$
is a union of basis elements. So $K$ is closed and equals its closure. Pointwise, for $x\notin K$ the basis element $(x-1,x+1)-K$ contains $x$ and misses $K$.

:::

:::

::: pf-step

In the finite complement topology, $\overline{K}=\RR$.

::: pf-proof

A nonempty open set $U$ has finite complement, so $U\cap K$ is infinite, in particular it contains points other than any prescribed $x\in\RR$. Hence every point of $\RR$ is a limit point of $K$.

:::

:::

::: pf-step

In the upper limit topology, $\overline{K}=K$.

::: pf-proof

Every $x\notin K$ has a basis element $(a,b]$ containing $x$ and meeting $K$ in nothing: if $x\le0$ take $(x-1,x]$; if $x>1$ take $(1,x]$; and if $0<x\notin K$ choose $n$ with $1/(n+1)<x<1/n$ and take $(1/(n+1),x]$, whose points $y$ satisfy $1/(n+1)<y\le x<1/n$ and so lie in no $\{1/m\}$. Hence no point outside $K$ is a limit point of $K$.

:::

:::

::: pf-step

In the topology generated by the rays $(-\infty,a)$, $\overline{K}=[0,\infty)$.

::: pf-proof

If $x\ge0$ and $(-\infty,a)$ is a basis element containing $x$, then $a>x\ge0$ and $1/n\in(-\infty,a)$ for $n>1/a$, so $x$ is a limit point of $K$; the point $0$ is included here. If $x<0$ then $(-\infty,0)$ is a neighbourhood of $x$ meeting $K$ in nothing. Hence the closure is $[0,\infty)$.

:::

:::

::: pf-step

$\mathcal{T}_{1}$, $\mathcal{T}_{2}$ and $\mathcal{T}_{4}$ satisfy the Hausdorff axiom and the $T_{1}$ axiom.

::: pf-proof

$\mathcal{T}_{1}$ is induced by the metric of $\RR$, hence Hausdorff, hence $T_{1}$. By Exercise 13.7, $\mathcal{T}_{1}\subset\mathcal{T}_{2}\subset\mathcal{T}_{4}$, so step [](#refinement){.pf-ref} applies twice.

:::

:::

::: pf-step

$\mathcal{T}_{3}$ satisfies the $T_{1}$ axiom but not the Hausdorff axiom.

::: pf-proof

A finite set $F$ has complement $\RR-F$, which is open in $\mathcal{T}_{3}$ because its own complement is $F$, finite; so every finite set, and in particular every one-point set, is closed. It is not Hausdorff: if $U\ni0$ and $V\ni1$ are open, then $\RR-U$ and $\RR-V$ are finite, since $U$ and $V$ are nonempty and not all of $\RR$, so $\RR-(U\cap V)=(\RR-U)\cup(\RR-V)$ is finite and $U\cap V\ne\varnothing$.

:::

:::

::: pf-step

$\mathcal{T}_{5}$ satisfies neither the $T_{1}$ axiom nor the Hausdorff axiom.

::: pf-proof

For $x<y$ every basis element $(-\infty,a)$ containing $y$ has $a>y>x$, so it contains $x$; hence $y$ has no neighbourhood omitting $x$, and the $T_{1}$ axiom fails by Exercise 17.15. A Hausdorff space is $T_{1}$ (Theorem 17.8), so $\mathcal{T}_{5}$ is not Hausdorff either.

:::

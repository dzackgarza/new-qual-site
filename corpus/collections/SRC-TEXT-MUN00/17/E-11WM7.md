::: {.exercise}

Let $A$, $B$, and $A_\alpha$ denote subsets of a space $X$.
Determine whether the following equations hold; if an equality fails, determine whether one of the inclusions $\supset$ or $\subset$ holds.

(a) $\overline{A \cap B} = \overline{A} \cap \overline{B}$.

(b) $\overline{\bigcap A_\alpha} = \bigcap \overline{A}_\alpha$.

(c) $\overline{A - B} = \overline{A} - \overline{B}$.
:::

::: solution
**Goal:** Determine the validity of set relations involving closures of intersections and set differences.

<1>1. Part (a): $\overline{A \cap B} \subseteq \overline{A} \cap \overline{B}$; equality fails in general.
    *Proof:*
    <2>1. Inclusion ($\subseteq$): Since $A \cap B \subseteq A$, monotonicity of closure gives $\overline{A \cap B} \subseteq \overline{A}$. Similarly $A \cap B \subseteq B \implies \overline{A \cap B} \subseteq \overline{B}$. Therefore $\overline{A \cap B} \subseteq \overline{A} \cap \overline{B}$.
    <2>2. Counterexample to reverse inclusion: In $\mathbb{R}$ with the standard topology, let $A = (0, 1)$ and $B = (1, 2)$. Then $A \cap B = \emptyset$, so $\overline{A \cap B} = \emptyset$. However $\overline{A} = [0, 1]$ and $\overline{B} = [1, 2]$, so $\overline{A} \cap \overline{B} = \{1\} \neq \emptyset$. Thus $\overline{A} \cap \overline{B} \not\subseteq \overline{A \cap B}$.

<1>2. Part (b): $\overline{\bigcap A_\alpha} \subseteq \bigcap \overline{A_\alpha}$; equality fails in general.
    *Proof:*
    <2>1. Inclusion ($\subseteq$): For each index $\beta$, $\bigcap A_\alpha \subseteq A_\beta$, so $\overline{\bigcap A_\alpha} \subseteq \overline{A_\beta}$. Since this holds for every $\beta$, $\overline{\bigcap A_\alpha} \subseteq \bigcap \overline{A_\alpha}$.
    <2>2. Counterexample to reverse inclusion: In $\mathbb{R}$, for each $n \in \mathbb{Z}_+$ let $A_n = (0, \frac{1}{n})$. Then $\bigcap_{n=1}^\infty A_n = \emptyset \implies \overline{\bigcap A_n} = \emptyset$. But $\overline{A_n} = [0, \frac{1}{n}]$, so $\bigcap_{n=1}^\infty \overline{A_n} = \{0\} \neq \emptyset$.

<1>3. Part (c): $\overline{A} \setminus \overline{B} \subseteq \overline{A \setminus B}$; equality fails in general.
    *Proof:*
    <2>1. Inclusion ($\subseteq$): Let $x \in \overline{A} \setminus \overline{B}$.
        - Since $x \notin \overline{B}$, there exists an open neighborhood $U$ of $x$ such that $U \cap B = \emptyset$.
        - Let $V$ be any open neighborhood of $x$. Then $U \cap V$ is an open neighborhood of $x$.
        - Since $x \in \overline{A}$, the neighborhood $U \cap V$ intersects $A$: there exists $y \in (U \cap V) \cap A$.
        - Since $y \in U$ and $U \cap B = \emptyset$, $y \notin B$. Thus $y \in A \setminus B$.
        - Since $y \in V$, $V \cap (A \setminus B) \neq \emptyset$.
        - Since every open neighborhood $V$ of $x$ intersects $A \setminus B$, $x \in \overline{A \setminus B}$.
    <2>2. Counterexample to reverse inclusion: In $\mathbb{R}$, let $A = [0, 1]$ and $B = (0, 1)$. Then $A \setminus B = \{0, 1\}$, so $\overline{A \setminus B} = \{0, 1\}$. But $\overline{A} = [0, 1]$ and $\overline{B} = [0, 1]$, so $\overline{A} \setminus \overline{B} = \emptyset$. Thus $\overline{A \setminus B} \not\subseteq \overline{A} \setminus \overline{B}$. Q.E.D.

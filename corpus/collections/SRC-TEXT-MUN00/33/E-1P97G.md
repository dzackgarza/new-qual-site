::: {.exercise}

A space $X$ is said to be perfectly normal if $X$ is normal and if every closed set in $X$ is a $G_\delta$ set in $X$.

(a) Show that every metrizable space is perfectly normal.

(b) Show that a perfectly normal space is completely normal.
For this reason the condition of perfect normality is sometimes called the "$T_6$ axiom."
[Hint: Let $A$ and $B$ be separated sets in $X$. Choose continuous functions $f, g: X \to [0, 1]$ that vanish precisely on $\overline{A}$ and $\overline{B}$, respectively.
Consider the function $f - g$.]

(c) There is a familiar space that is completely normal but not perfectly normal.
What is it?
:::

::: {.solution}
**Goal:** Characterize perfectly normal spaces ($T_6$), prove that metrizability implies perfect normality, perfect normality implies complete normality ($T_5$), and identify the ordinal space $[0, \Omega]$ as a completely normal non-perfectly normal space.

::: pf

::: pf-step
Part (a): Every metrizable space is perfectly normal.

::: pf-proof

::: pf-step
Every metric space $(X, d)$ is $T_4$ (normal).
:::

::: pf-step
Let $A \subseteq X$ be an arbitrary closed set.
:::

::: pf-step
For each $n \in \mathbb{Z}_+$, define $U_n = \{x \in X : d(x, A) < \frac{1}{n}\}$.
:::

::: pf-step
The distance function $x \mapsto d(x, A)$ is continuous, so each $U_n$ is open in $X$.
:::

::: pf-step
Since $A$ is closed, $x \in A \iff d(x, A) = 0 \iff \forall n \ge 1, d(x, A) < \frac{1}{n} \iff x \in \bigcap_{n=1}^\infty U_n$.
:::

::: pf-step
Thus $A = \bigcap_{n=1}^\infty U_n$ is a countable intersection of open sets ($G_\delta$).
:::

::: pf-step
Hence $X$ is perfectly normal.
:::

:::

:::

::: pf-step
Part (b): Perfectly normal spaces are completely normal ($T_5$).

::: pf-proof

::: pf-step
Let $A, B \subseteq X$ be separated sets, so $\overline{A} \cap B = \emptyset$ and $A \cap \overline{B} = \emptyset$.
:::

::: pf-step
Since $X$ is perfectly normal, the closed sets $\overline{A}$ and $\overline{B}$ are closed $G_\delta$ sets in $X$.
:::

::: pf-step
By Urysohn's theorem for $G_\delta$ zero sets, there exist continuous functions $f, g: X \to [0, 1]$ vanishing precisely on $\overline{A}$ and $\overline{B}$:
$$f^{-1}(\{0\}) = \overline{A}, \qquad g^{-1}(\{0\}) = \overline{B}.$$
:::

::: pf-step
Define $h: X \to \mathbb{R}$ by $h(x) = f(x) - g(x)$. Since $f$ and $g$ are continuous, $h$ is continuous.
:::

::: pf-step
Define $U = h^{-1}((-\infty, 0)) = \{x \in X : f(x) < g(x)\}$ and $V = h^{-1}((0, \infty)) = \{x \in X : f(x) > g(x)\}$.
:::

::: pf-step
Since $(-\infty, 0)$ and $(0, \infty)$ are disjoint open intervals in $\mathbb{R}$, $U$ and $V$ are disjoint open subsets of $X$.
:::

::: pf-step
For any $a \in A \subseteq \overline{A}$, $f(a) = 0$. Since $a \notin \overline{B}$, $g(a) > 0$, so $f(a) < g(a) \implies a \in U$. Thus $A \subseteq U$.
:::

::: pf-step
For any $b \in B \subseteq \overline{B}$, $g(b) = 0$. Since $b \notin \overline{A}$, $f(b) > 0$, so $f(b) > g(b) \implies b \in V$. Thus $B \subseteq V$.
:::

::: pf-step
Therefore separated sets are separated by disjoint open sets, so $X$ is completely normal.
:::

:::

:::

::: pf-step
Part (c): The space $\overline{S}_\Omega = [0, \Omega]$ is completely normal but not perfectly normal.

::: pf-proof

::: pf-step
Every well-ordered set in the order topology is completely normal (Munkres Theorem 32.4).
:::

::: pf-step
The singleton $\{\Omega\}$ is closed in $\overline{S}_\Omega$.
:::

::: pf-step
Suppose $\{\Omega\} = \bigcap_{n=1}^\infty U_n$ for some collection of open sets $U_n \subseteq \overline{S}_\Omega$.
:::

::: pf-step
For each $n$, $\Omega \in U_n$, so there exists $\alpha_n < \Omega$ such that $(\alpha_n, \Omega] \subseteq U_n$.
:::

::: pf-step
The countable set $\{\alpha_n : n \in \mathbb{Z}_+\} \subset S_\Omega$ has an upper bound $\alpha = \sup_{n} \alpha_n < \Omega$ in $S_\Omega$.
:::

::: pf-step
Then the uncountably infinite set $(\alpha, \Omega) \subset \bigcap_{n=1}^\infty (\alpha_n, \Omega] \subseteq \bigcap_{n=1}^\infty U_n = \{\Omega\}$, a contradiction.
:::

::: pf-step
Thus $\{\Omega\}$ is not a $G_\delta$ set, so $\overline{S}_\Omega$ is not perfectly normal. Q.E.D.
:::

::: {.exercise}

If $X$ and $Y$ are spaces, define

$$
e: X \times \mathcal{C}(X, Y) \to Y
$$

by the equation $e(x, f) = f(x)$; the map $e$ is called the evaluation map.
Show that if $d$ is a metric for $Y$ and $\mathcal{C}(X, Y)$ has the corresponding uniform topology, then $e$ is continuous.
We shall generalize this result in §46.
:::

::: {.solution}
The uniform topology on $\mathcal{C}(X, Y)$ is induced by the uniform metric $\bar{\rho}(f, g) = \sup_{x \in X} \bar{d}(f(x), g(x))$, where $\bar{d} = \min(d, 1)$.

::: pf

::: {.pf-step #s1}
Reduction:
Let $(x_0, f_0) \in X \times \mathcal{C}(X, Y)$ and let $\varepsilon > 0$. We may assume without loss of generality that $\varepsilon < 1$.
It suffices to find an open neighborhood $U \subseteq X$ of $x_0$ and an open neighborhood $V \subseteq \mathcal{C}(X, Y)$ of $f_0$ such that $e(U \times V) \subseteq B_d(f_0(x_0), \varepsilon)$.
:::

::: pf-step
Construction of neighborhoods:

::: pf-proof

::: pf-step
Since $f_0: X \to Y$ is continuous at $x_0$, there exists an open neighborhood $U \subseteq X$ of $x_0$ such that:
$$d(f_0(x), f_0(x_0)) < \frac{\varepsilon}{2} \quad \text{for all } x \in U.$$
:::

::: pf-step
In the uniform metric space $\mathcal{C}(X, Y)$, define the open ball $V = B_{\bar{\rho}}(f_0, \frac{\varepsilon}{2})$.
:::

::: pf-step
For any $f \in V$, the uniform bound holds:
$$\bar{\rho}(f, f_0) = \sup_{x \in X} \bar{d}(f(x), f_0(x)) < \frac{\varepsilon}{2}.$$
:::

::: pf-step
Since $\frac{\varepsilon}{2} < 1$, $\bar{d}(f(x), f_0(x)) = d(f(x), f_0(x))$, which implies:
$$d(f(x), f_0(x)) < \frac{\varepsilon}{2} \quad \text{for all } x \in X.$$
:::

:::

:::

::: {.pf-step #s3}
Verification of continuity:

::: pf-proof

::: pf-step
Let $(x, f) \in U \times V$.
:::

::: pf-step
By the triangle inequality in the metric space $(Y, d)$:
$$d(e(x, f), e(x_0, f_0)) = d(f(x), f_0(x_0)) \le d(f(x), f_0(x)) + d(f_0(x), f_0(x_0)).$$
:::

::: pf-step
Since $f \in V$, $d(f(x), f_0(x)) < \frac{\varepsilon}{2}$.
:::

::: pf-step
Since $x \in U$, $d(f_0(x), f_0(x_0)) < \frac{\varepsilon}{2}$.
:::

::: pf-step
Summing these bounds gives:
$$d(e(x, f), e(x_0, f_0)) < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon.$$
:::

::: pf-step
Thus $e(U \times V) \subseteq B_d(f_0(x_0), \varepsilon)$.
:::

:::

:::

::: pf-qed
By steps [](#s1){.pf-ref} and [](#s3){.pf-ref}, $e$ is continuous at every point $(x_0, f_0) \in X \times \mathcal{C}(X, Y)$.
:::

:::

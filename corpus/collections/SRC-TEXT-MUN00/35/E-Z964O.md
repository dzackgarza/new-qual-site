::: {.exercise}

Prove the following.

Theorem.
Let $Y$ be a normal space.
Then $Y$ is an absolute retract if and only if $Y$ has the universal extension property.

[Hint: If $X$ and $Y$ are disjoint normal spaces, $A$ is closed in $X$, and $f: A \to Y$ is a continuous map, define the adjunction space $Z_f$ to be the quotient space obtained from $X \cup Y$ by identifying each point $a$ of $A$ with the point $f(a)$ and with all the points of $f^{-1}(\theset{f(a)})$. Using the Tietze theorem, show that $Z_f$ is normal. If $p: X \cup Y \to Z_f$ is the quotient map, show that $p \mid Y$ is a homeomorphism of $Y$ with a closed subspace of $Z_f$.]
:::

::: {.solution}
The argument is the card's own, following the book's hint; no retained solution set covers this exercise. Throughout, $Y$ is a normal space, and $Y$ is an absolute retract when for every pair $(Y_{0},Z)$ with $Z$ normal and $Y_{0}$ a closed subspace of $Z$ homeomorphic to $Y$, the set $Y_{0}$ is a retract of $Z$ (§35 Exercise 8).

::: pf

::: {.pf-step #uep-to-ar}
If $Y$ has the universal extension property, then $Y$ is an absolute retract.

::: pf-proof
Let $Z$ be normal, let $Y_{0}\subset Z$ be closed, and let $h:Y_{0}\to Y$ be a homeomorphism. By the universal extension property the continuous map $h$ on the closed subset $Y_{0}$ of the normal space $Z$ extends to a continuous $H:Z\to Y$, and $r=h^{-1}\circ H:Z\to Y_{0}$ is continuous with $r\restrict_{Y_{0}}=\mathsf{l}_{Y_{0}}$; so $Y_{0}$ is a retract of $Z$.
:::

:::

::: {.pf-step #adjunction}
Assume $Y$ is an absolute retract, let $X$ be normal, $A\subset X$ closed, $f:A\to Y$ continuous, and let $Z_{f}=(X\sqcup Y)/\!\sim$ be the adjunction space, with $p:X\sqcup Y\to Z_{f}$ the quotient map.

::: pf-proof
Take $X$ and $Y$ disjoint, form the disjoint union, and let $\sim$ be the least equivalence relation identifying each $a\in A$ with $f(a)$ and with every point of $f^{-1}\big(\{f(a)\}\big)$; $Z_{f}$ is the quotient of $X\sqcup Y$ by $\sim$ with the quotient topology, and $p$ the quotient map, which is continuous and onto.
:::

:::

::: {.pf-step #t1}
$Z_{f}$ satisfies the $T_{1}$ axiom.

::: pf-proof
Let $c\in Z_{f}$. If $c=p(x)$ with $x\in X-A$, then $p^{-1}(c)=\{x\}$, closed in $X\sqcup Y$. If $c=p(y)$ with $y\in Y$, then $p^{-1}(c)=f^{-1}(\{y\})\sqcup\{y\}$: the set $f^{-1}(\{y\})$ is closed in $A$ because $f$ is continuous, hence closed in $X$ because $A$ is closed, and $\{y\}$ is closed because $Y$ is normal, hence $T_{1}$. In both cases the preimage of the singleton is closed in $X\sqcup Y$, so the singleton is closed in $Z_{f}$ by the quotient criterion.
:::

:::

::: {.pf-step #normal}
$Z_{f}$ is normal.

:::: pf-proof

::: {.pf-step #pulled-back}
For disjoint closed $C,D\subset Z_{f}$, the sets $C_{X}=p^{-1}(C)\cap X$, $C_{Y}=p^{-1}(C)\cap Y$ and $D_{X}$, $D_{Y}$ defined in the same way are closed, are disjoint in each factor, and satisfy $f(A\cap C_{X})\subset C_{Y}$, $f(A\cap D_{X})\subset D_{Y}$.

::: pf-proof
$p$ is continuous, so $p^{-1}(C)$ and $p^{-1}(D)$ are closed, and their intersections with $X$ and with $Y$ are closed. They are disjoint because $C\cap D=\varnothing$. If $a\in A\cap C_{X}$ then $a\in p^{-1}(C)$ and $p(a)=p(f(a))$, so $f(a)\in p^{-1}(C)\cap Y=C_{Y}$; likewise for $D$.
:::

:::

::: {.pf-step #functions}
There are continuous $g:Y\to[0,1]$ with $g(C_{Y})=0$, $g(D_{Y})=1$, and $h:X\to[0,1]$ with $h=g\circ f$ on $A$, $h=0$ on $C_{X}$ and $h=1$ on $D_{X}$.

::: pf-proof
$Y$ is normal and $C_{Y}$, $D_{Y}$ are disjoint closed sets, so Urysohn's lemma gives $g$. On the closed subset $A\cup C_{X}\cup D_{X}$ of $X$ define $h_{0}$ by those three prescriptions; they agree on overlaps, since $A\cap C_{X}$ maps into $C_{Y}$ by step [](#pulled-back){.pf-ref}, so $g\circ f=0$ there, and similarly $g\circ f=1$ on $A\cap D_{X}$, while $C_{X}\cap D_{X}=\varnothing$. The family $\{A,C_{X},D_{X}\}$ is finite and closed, so the pasting lemma gives a continuous $h_{0}$; the Tietze theorem extends it to a continuous $h:X\to[0,1]$.
:::

:::

::: {.pf-step #descends}
The function equal to $h$ on $X$ and to $g$ on $Y$ is constant on the classes of $\sim$, so it induces a continuous $H:Z_{f}\to[0,1]$ with $H(C)=0$ and $H(D)=1$.

::: pf-proof
The two prescriptions agree on the only points where classes meet different factors: if $a\in A$ then $h(a)=g\big(f(a)\big)$, which is the value of $g$ at the point of $Y$ identified with $a$. So the function on $X\sqcup Y$ is constant on classes and factors through a function $H$ with $H\circ p$ continuous; since $p$ is a quotient map, $H$ is continuous. For $c\in C$ take any $\xi\in p^{-1}(c)$: if $\xi\in X$ then $\xi\in C_{X}$ and $H(c)=h(\xi)=0$, and if $\xi\in Y$ then $\xi\in C_{Y}$ and $H(c)=g(\xi)=0$; so $H(C)=0$, and likewise $H(D)=1$.
:::

:::

::: {.pf-step}
$Z_{f}$ is normal.

::: pf-proof
The sets $H^{-1}\big([0,\tfrac13)\big)$ and $H^{-1}\big((\tfrac23,1]\big)$ are open in $Z_{f}$ because $H$ is continuous, they are disjoint, and they contain $C$ and $D$ respectively by step [](#descends){.pf-ref}; so any two disjoint closed sets are separated by disjoint open sets.
:::

:::

:::

:::

::: {.pf-step #copy-closed}
$p\restrict_{Y}:Y\to p(Y)$ is a homeomorphism onto a closed subspace of $Z_{f}$.

::: pf-proof
It is injective, because two distinct points of $Y$ are never equivalent under $\sim$, and onto $p(Y)$ by definition. The set $p(Y)$ is closed: $p^{-1}\big(p(Y)\big)=A\sqcup Y$, closed in $X\sqcup Y$ because $A$ is closed in $X$. For closed $F\subset Y$ one has $p^{-1}\big(p(F)\big)=f^{-1}(F)\sqcup F$, closed because $f$ is continuous and $F$ is closed, so $p(F)$ is closed in $Z_{f}$. Hence $p\restrict_{Y}$ is a closed continuous bijection onto $p(Y)$, that is a homeomorphism.
:::

:::

::: {.pf-step #ar-to-uep}
If $Y$ is an absolute retract, then every continuous map $f:A\to Y$ on a closed subset $A$ of a normal space $X$ extends to $X$.

::: pf-proof
With $Z_{f}$ and $p$ as above, $Z_{f}$ is normal by step [](#normal){.pf-ref}, and $p(Y)$ is a closed subspace of it homeomorphic to $Y$ by step [](#copy-closed){.pf-ref}. Since $Y$ is an absolute retract, there is a retraction $r:Z_{f}\to p(Y)$. The composite
$$
X\xrightarrow{\ p\ }Z_{f}\xrightarrow{\ r\ }p(Y)\xrightarrow{\ (p\restrict_{Y})^{-1}\ }Y
$$
is continuous, and for $a\in A$ one has $p(a)=p\big(f(a)\big)\in p(Y)$, which $r$ fixes, so the composite sends $a$ to $(p\restrict_{Y})^{-1}\big(p(f(a))\big)=f(a)$. Hence it extends $f$.
:::

:::

::: {.pf-step}
$Y$ is an absolute retract if and only if $Y$ has the universal extension property.

::: pf-proof
Step [](#uep-to-ar){.pf-ref} is one implication and step [](#ar-to-uep){.pf-ref} the other.
:::

::: {.exercise}

Let $X$ and $X'$ denote a single set in the two topologies $\mathcal{T}$ and $\mathcal{T}'$, respectively.
Let $i: X' \to X$ be the identity function.

(a) Show that $i$ is continuous if and only if $\mathcal{T}'$ is finer than $\mathcal{T}$.

(b) Show that $i$ is a homeomorphism if and only if $\mathcal{T}' = \mathcal{T}$.
:::

::: {.solution}
The published solution is **"positron0802", *Solutions to Topology, Chapter 2* (1 January 2021), Exercise 18.3, PDF p. 11** (`tmp/sources/munkres-solutions-positron-ch2.pdf`); both parts below are theirs, and Whitman, printed p. 180, gives the same.

Here $X$ and $X'$ are one set carrying the topologies $\mathcal{T}$ and $\mathcal{T}'$, and $i:X'\to X$ is the identity.

::: pf

::: {.pf-step #identity}
$i$ is a bijection and $i^{-1}(V)=V$ for every subset $V$ of $X$.

::: pf-proof
The map $i$ sends each point to itself, so it is both injective and surjective, and for $V\subset X$ the preimage $\{x\in X'\mid i(x)\in V\}$ is $V$ itself.
:::

:::

::: {.pf-step #part-a}
(a) $i$ is continuous if and only if $\mathcal{T}'\supset\mathcal{T}$, that is, if and only if $\mathcal{T}'$ is finer than $\mathcal{T}$.

::: pf-proof
A map into $X$ is continuous if and only if the preimage of every open set of $X$ is open in the domain (Theorem 18.1). By step [](#identity){.pf-ref}, $i^{-1}(V)=V$, so the condition reads: $V\in\mathcal{T}$ implies $V\in\mathcal{T}'$, for every $V$. That is exactly $\mathcal{T}\subset\mathcal{T}'$, which says $\mathcal{T}'$ is finer than $\mathcal{T}$.
:::

:::

::: {.pf-step #part-b}
(b) $i$ is a homeomorphism if and only if $\mathcal{T}'=\mathcal{T}$.

::: pf-proof
$i$ is a homeomorphism exactly when $i$ is a bijection and both $i$ and $i^{-1}$ are continuous; the bijection is step [](#identity){.pf-ref}. The inverse $i^{-1}:X\to X'$ is again the identity map of the same underlying set, now from the space with topology $\mathcal{T}$ to the space with topology $\mathcal{T}'$, so step [](#part-a){.pf-ref} applied to it says that $i^{-1}$ is continuous exactly when $\mathcal{T}\subset\mathcal{T}'$ with the two topologies interchanged, that is exactly when $\mathcal{T}'\subset\mathcal{T}$. Together with step [](#part-a){.pf-ref}, both maps are continuous exactly when $\mathcal{T}\subset\mathcal{T}'$ and $\mathcal{T}'\subset\mathcal{T}$, that is exactly when the two topologies are equal.
:::

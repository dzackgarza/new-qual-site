::: {.exercise}

Suppose you are given the fact that for each $n$, no continuous antipode-preserving map $h: S^n \to S^n$ is nulhomotopic.
(This result can be proved using more advanced techniques of algebraic topology.)
Prove the following:

(a) There is no retraction $r: B^{n+1} \to S^n$.

(b) There is no continuous antipode-preserving map $g: S^{n+1} \to S^n$.

(c) (Borsuk-Ulam theorem) Given a continuous map $f: S^{n+1} \to \RR^{n+1}$, there is a point $x$ of $S^{n+1}$ such that $f(x) = f(-x)$.

(d) If $A_1, \ldots, A_{n+1}$ are bounded measurable sets in $\RR^{n+1}$, there exists an $n$-plane in $\RR^{n+1}$ that bisects each of them.
:::

::: {.solution}
The four parts are proved from the hypothesis by the book's own route, and the exercise is Munkres, *Topology* (2000), Section 57, Exercise 4, printed p. 359. Throughout, $a_n\colon S^n\to S^n$ is the antipodal map $a_n(x)=-x$, and a map is antipode-preserving when it commutes with $a_n$.

::: pf

::: {.pf-step #part-a}
There is no retraction $r\colon B^{n+1}\to S^n$.

::: pf-proof

::: pf-step

Suppose $r: B^{n+1} \to S^n$ is a continuous retraction, so $r(x) = x$ for all $x \in \partial B^{n+1} = S^n$.


::: pf-proof
This is the hypothesis of the part, with the retraction condition stated in full.
:::

:::

::: pf-step

Since $B^{n+1}$ is contractible, the inclusion map $i: S^n \hookrightarrow B^{n+1}$ is nullhomotopic.


::: pf-proof
The ball $B^{n+1}$ is convex, hence contractible, and a map into a contractible space is nullhomotopic.
:::

:::

::: pf-step

Therefore the composition $r \circ i = \operatorname{id}_{S^n}: S^n \to S^n$ is nullhomotopic.


::: pf-proof
A composition of a nullhomotopic map with a continuous map is nullhomotopic, and $r\circ i$ is the identity by the retraction condition.
:::

:::

::: pf-step

The identity map $\operatorname{id}_{S^n}$ satisfies $\operatorname{id}_{S^n}(-x) = -x = -\operatorname{id}_{S^n}(x)$, so it is an antipode-preserving map.


::: pf-proof
$\operatorname{id}_{S^n}(-x)=-x=-\operatorname{id}_{S^n}(x)$, so it commutes with the antipodal map.
:::

:::

::: pf-step

This contradicts the given fact that no continuous antipode-preserving map $S^n \to S^n$ is nullhomotopic.


::: pf-proof
The identity of $S^n$ is a continuous antipode-preserving self-map and has just been shown nullhomotopic, which the hypothesis forbids.
:::

:::

::: pf-step

Thus no retraction $r: B^{n+1} \to S^n$ exists.


::: pf-proof
The supposition has led to a contradiction, so no such retraction exists.
:::

:::

:::

:::

::: {.pf-step #part-b}
There is no continuous antipode-preserving map $g\colon S^{n+1}\to S^n$.

::: pf-proof

::: pf-step

Suppose $g: S^{n+1} \to S^n$ is continuous and satisfies $g(-x) = -g(x)$ for all $x \in S^{n+1}$.


::: pf-proof
This is the negation of the assertion of the part.
:::

:::

::: pf-step

Embed $S^n$ as the equator of $S^{n+1}$: $S^n = \{(x, 0) \in S^{n+1} : x \in S^n\}$.


::: pf-proof
The map $x\mapsto(x,0)$ is a homeomorphism of $S^n$ onto the equator of $S^{n+1}$.
:::

:::

::: pf-step

The restriction $h = g\restrict_{S^n}: S^n \to S^n$ is continuous and antipode-preserving on $S^n$.


::: pf-proof
A restriction of a continuous map is continuous, and for $x\in S^n$ the antipode of $(x,0)$ is $(-x,0)$, so $h(-x)=-h(x)$.
:::

:::

::: pf-step

Let $E_+^{n+1} = \{(x, z) \in S^{n+1} : z \ge 0\}$ be the upper hemisphere. $E_+^{n+1}$ is homeomorphic to $B^{n+1}$, with boundary $\partial E_+^{n+1} = S^n$.


::: pf-proof
Orthogonal projection $(x,z)\mapsto x$ carries the closed upper hemisphere homeomorphically onto the closed unit ball, with inverse $x\mapsto(x,\sqrt{1-\norm{x}^2})$, and it carries the equator onto the boundary sphere.
:::

:::

::: pf-step

The map $g\restrict_{E_+^{n+1}}: E_+^{n+1} \to S^n$ is a continuous extension of $h$ to the disk $B^{n+1}$.


::: pf-proof
It is continuous as a restriction, and on the equator it agrees with $h$ by the definition of $h$.
:::

:::

::: pf-step

A continuous map from $S^n$ to $S^n$ extends to $B^{n+1}$ if and only if it is nullhomotopic, so $h$ is nullhomotopic.


::: pf-proof
A map $S^n\to S^n$ extends over the ball exactly when it is nullhomotopic: an extension can be coned to a point, and a nullhomotopy can be used to define the map on each slice of the ball.
:::

:::

::: pf-step

This contradicts the given fact that $h$ cannot be nullhomotopic. Hence no such $g$ exists.


::: pf-proof
The hypothesis forbids a continuous antipode-preserving self-map of $S^n$ that is nullhomotopic, and $h$ is one.
:::

:::

:::

::: {.pf-step #part-c}
Every continuous $f\colon S^{n+1}\to\RR^{n+1}$ has a point $x\in S^{n+1}$ with $f(x)=f(-x)$.

::: pf-proof

::: pf-step

Suppose for contradiction that $f(x) \neq f(-x)$ for all $x \in S^{n+1}$.


::: pf-proof
This is the negation of the assertion of the part.
:::

:::

::: pf-step

Define $v: S^{n+1} \to \RR^{n+1} \setminus \{0\}$ by $v(x) = f(x) - f(-x)$.


::: pf-proof
This is a definition; the values lie in $\RR^{n+1}\setminus\{0\}$ because $f(x)\neq f(-x)$ under the supposition.
:::

:::

::: pf-step

Define $g: S^{n+1} \to S^n$ by $g(x) = \frac{v(x)}{\norm{v(x)}}$.


::: pf-proof
The denominator never vanishes, so the formula defines a continuous map into the unit sphere.
:::

:::

::: pf-step

$g$ is continuous, and $v(-x) = f(-x) - f(x) = -v(x)$ implies:
        $$g(-x) = \frac{-v(x)}{\norm{-v(x)}} = -\frac{v(x)}{\norm{v(x)}} = -g(x).$$


::: pf-proof
It is a composition of continuous maps, and $v(-x)=f(-x)-f(x)=-v(x)$ gives the displayed computation.
:::

:::

::: pf-step

Thus $g: S^{n+1} \to S^n$ is a continuous antipode-preserving map, contradicting step [](#part-b){.pf-ref}.


::: pf-proof
Part [](#part-b){.pf-ref} says that no such map exists.
:::

:::

::: pf-step

Therefore, there exists $x \in S^{n+1}$ such that $f(x) = f(-x)$.


::: pf-proof
The supposition is therefore false, which is the assertion.
:::

:::

:::

:::

::: {.pf-step #part-d}
For bounded measurable $A_1,\ldots,A_{n+1}\subset\RR^{n+1}$ there is an $n$-plane that bisects each of them.

::: pf-proof

::: pf-step

Embed $\RR^{n+1}$ into $\RR^{n+2}$ via $y \mapsto (y, 1)$. For each $i \in \{1, \dots, n+1\}$, let $A_i' = \{(y, 1) : y \in A_i\}$.


::: pf-proof
This embeds $\RR^{n+1}$ as the affine hyperplane at height $1$ in $\RR^{n+2}$, and $A_i'$ is the copy of $A_i$ in it.
:::

:::

::: pf-step

For each unit vector $u = (u_1, \dots, u_{n+2}) \in S^{n+1} \subset \RR^{n+2}$, define the open half-space $H_u^+ = \{z \in \RR^{n+2} : \langle z, u \rangle > 0\}$.


::: pf-proof
This is the open half-space on the positive side of the hyperplane through the origin orthogonal to $u$.
:::

:::

::: pf-step

Let $\mu$ be Lebesgue measure on the original $\RR^{n+1}$. Define $f: S^{n+1} \to \RR^{n+1}$ by $f(u) = (f_1(u), \dots, f_{n+1}(u))$, where
$$
f_i(u)=\mu\bigl(\{y\in A_i:\langle(y,1),u\rangle>0\}\bigr).
$$


::: pf-proof
This is a definition: the measure of the part of $A_i$ lying on the positive side of that hyperplane.
:::

:::

::: pf-step

For fixed $u$, the set $\{y:\langle(y,1),u\rangle=0\}$ is a hyperplane of measure zero when $(u_1,\ldots,u_{n+1})\ne0$, and is empty when that vector is zero. The defining indicators therefore converge almost everywhere as $u$ varies continuously. Since each $A_i$ is bounded and measurable, dominated convergence makes each $f_i$ continuous.


::: pf-proof
The indicator of the set where $\langle(y,1),u\rangle>0$ converges pointwise, off the null boundary, as $u$ varies; the indicators are dominated by the indicator of the bounded set $A_i$, so dominated convergence gives continuity in $u$.
:::

:::

::: pf-step

By step [](#part-c){.pf-ref} (Borsuk-Ulam), there exists $u \in S^{n+1}$ such that $f(u) = f(-u)$.


::: pf-proof
This is part [](#part-c){.pf-ref} applied to the continuous map $f:S^{n+1}\to\RR^{n+1}$.
:::

:::

::: pf-step

The boundary set $\{y:\langle(y,1),u\rangle=0\}$ has $\mu$-measure zero, so $\mu(A_i) = f_i(u) + f_i(-u) = 2f_i(u)$. Thus $f_i(u) = \frac{1}{2}\mu(A_i)$ for all $i$.


::: pf-proof
The two open half-spaces cut $A_i$ into the parts where the linear form is positive and where it is negative, of measures $f_i(u)$ and $f_i(-u)$, and what remains is the null boundary; hence $\mu(A_i)=2f_i(u)$.
:::

:::

::: pf-step

If $u' = (u_1, \dots, u_{n+1}) \neq 0$, the equation $\langle y, u' \rangle + u_{n+2} = 0$ defines an affine hyperplane ($n$-plane) in $\RR^{n+1}$ bisecting every $A_i$. If $u' = 0$, then $u_{n+2} = \pm 1$, giving $f_i(u) \in \{0, \mu(A_i)\}$, so $\mu(A_i) = 0$ for all $i$; in this case every $A_i$ has measure zero, so any $n$-plane bisects each $A_i$ (both halves have measure $0 = \frac{1}{2}\mu(A_i)$).


::: pf-proof
For $u'\neq0$ the equation $\langle y,u'\rangle=-u_{n+2}$ is an affine hyperplane of $\RR^{n+1}$, and its two sides are the two halves computed above; for $u'=0$ one has $f_i(u)\in\{0,\mu(A_i)\}$, so $2f_i(u)=\mu(A_i)$ forces $\mu(A_i)=0$ and any hyperplane bisects a null set.
:::

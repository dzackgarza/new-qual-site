::: {.exercise}

Let $X$ be a space.
Let us define $x \sim y$ if there is no separation $X = A \cup B$ of $X$ into disjoint open sets such that $x \in A$ and $y \in B$.

(a) Show this relation is an equivalence relation.
The equivalence classes are called the quasicomponents of $X$.

(b) Show that each component of $X$ lies in a quasicomponent of $X$, and that the components and quasicomponents of $X$ are the same if $X$ is locally connected.

(c) Let $K$ denote the set $\ts{1/n \mid n \in \mathbb{Z}_+}$ and let $-K$ denote the set $\ts{-1/n \mid n \in \mathbb{Z}_+}$.
Determine the components, path components, and quasicomponents of the following subspaces of $\mathbb{R}^2$:

$$
A = (K \times [0, 1]) \cup \ts{0 \times 0} \cup \ts{0 \times 1},
$$

$$
B = A \cup ([0, 1] \times \ts{0}),
$$

$$
C = (K \times [0, 1]) \cup (-K \times [-1, 0]) \cup ([0, 1] \times -K) \cup ([-1, 0] \times K).
$$
:::

::: solution
**Goal:** Prove the foundational theory of quasicomponents (equivalence relation, component inclusion, and equivalence under local connectedness) and determine the components, path components, and quasicomponents of spaces $A, B, C \subset \mathbb{R}^2$.

<1>1. Part (a): $\sim$ is an equivalence relation.
    *Proof:*
    <2>1. Reflexivity: For any $x \in X$, if $X = U \cup V$ is a separation with $x \in U$, then $x \notin V$ since $U \cap V = \emptyset$. Thus $x \sim x$.
    <2>2. Symmetry: If $x \sim y$, then any separation placing $y \in U$ and $x \in V$ is equivalent to a separation placing $x \in V$ and $y \in U$, so $y \sim x$.
    <2>3. Transitivity: Suppose $x \sim y$ and $y \sim z$. If $x \not\sim z$, there exists a clopen partition $X = U \cup V$ with $x \in U$ and $z \in V$. Since $U \cup V = X$, either $y \in U$ or $y \in V$. If $y \in V$, then $x \in U, y \in V$, contradicting $x \sim y$. If $y \in U$, then $y \in U, z \in V$, contradicting $y \sim z$. Thus $x \sim z$.

<1>2. Part (b): Component inclusion and agreement in locally connected spaces.
    *Proof:*
    <2>1. Let $C(x)$ and $Q(x)$ denote the connected component and quasicomponent of $x$.
    <2>2. For every clopen set $U \subseteq X$ with $x \in U$, the connected set $C(x)$ cannot be partitioned into non-empty disjoint open sets $C(x) \cap U$ and $C(x) \cap (X \setminus U)$. Since $x \in C(x) \cap U$, $C(x) \cap (X \setminus U) = \emptyset$, so $C(x) \subseteq U$.
    <2>3. Since $Q(x) = \bigcap \{U \subseteq X : U \text{ is clopen and } x \in U\}$, $C(x) \subseteq Q(x)$.
    <2>4. If $X$ is locally connected, each connected component $C(x)$ is open in $X$. Since the complement $X \setminus C(x) = \bigcup_{y \notin C(x)} C(y)$ is a union of open sets, $C(x)$ is closed, hence clopen.
    <2>5. Thus $Q(x) \subseteq C(x)$, which gives $C(x) = Q(x)$ for all $x \in X$.

<1>3. Part (c): Analysis of subspaces $A, B, C$.
    *Proof:*
    <2>1. Space $A = (K \times [0, 1]) \cup \{(0, 0)\} \cup \{(0, 1)\}$:
        - Components & Path components: The vertical segments $\{\frac{1}{n}\} \times [0, 1]$ for each $n \in \mathbb{Z}_+$, together with the singletons $\{(0, 0)\}$ and $\{(0, 1)\}$.
        - Quasicomponents: The vertical segments $\{\frac{1}{n}\} \times [0, 1]$ for each $n \in \mathbb{Z}_+$, and the two-point set $\{(0, 0), (0, 1)\}$ (since any clopen set containing $(0, 0)$ must contain the segments for all large $n$, hence must contain the limit $(0, 1)$).
    <2>2. Space $B = A \cup ([0, 1] \times \{0\})$:
        - Components & Path components: The comb space $(K \times [0, 1]) \cup ([0, 1] \times \{0\})$, and the singleton point $\{(0, 1)\}$.
        - Quasicomponents: The single set $B$ (since any clopen set containing the connected comb must contain the limit point $(0, 1)$, so no separation of $B$ exists).
    <2>3. Space $C = (K \times [0, 1]) \cup (-K \times [-1, 0]) \cup ([0, 1] \times -K) \cup ([-1, 0] \times K)$:
        - Components & Path components: Each individual vertical and horizontal line segment $\{\frac{1}{n}\} \times [0, 1]$, $\{-\frac{1}{n}\} \times [-1, 0]$, $[0, 1] \times \{-\frac{1}{n}\}$, and $[-1, 0] \times \{\frac{1}{n}\}$ for $n \in \mathbb{Z}_+$.
        - Quasicomponents: The entire space $C$ constitutes a single quasicomponent. Q.E.D.
:::

::: {.exercise}

Prove the following.

Theorem (Arzela's theorem).
Let $X$ be compact; let $f_n \in \mathcal{C}(X, \mathbb{R}^k)$.
If the collection $\ts{f_n}$ is pointwise bounded and equicontinuous, then the sequence $f_n$ has a uniformly convergent subsequence.
:::

::: {.solution}
::: pf

::: pf-step
Uniform boundedness from equicontinuity and compactness:
The sequence $(f_n)$ is uniformly bounded on $X$: $\sup_{n \in \mathbb{Z}_+} \sup_{x \in X} \|f_n(x)\| \le M < \infty$.

::: pf-proof

::: pf-step
By equicontinuity at $\varepsilon = 1$, for each $x \in X$ there is an open neighborhood $U_x \subseteq X$ such that $\|f_n(y) - f_n(x)\| < 1$ for all $y \in U_x$ and all $n \in \mathbb{Z}_+$.
:::

::: pf-step
Since $X$ is compact, the open cover $\{U_x\}_{x \in X}$ has a finite subcover $\{U_{x_1}, \dots, U_{x_m}\}$.
:::

::: pf-step
By pointwise boundedness, for each $j \in \{1, \dots, m\}$, there exists $M_j < \infty$ such that $\|f_n(x_j)\| \le M_j$ for all $n$.
:::

::: pf-step
Setting $M = \max_{1 \le j \le m} M_j + 1$, for every $y \in X$, choosing $x_j$ with $y \in U_{x_j}$ gives:
$$\|f_n(y)\| \le \|f_n(x_j)\| + \|f_n(y) - f_n(x_j)\| < M_j + 1 \le M.$$
:::

:::

:::

::: pf-step
Extraction of a subsequence converging on a countable dense net:

::: pf-proof

::: pf-step
For each integer $m \ge 1$, equicontinuity with $\varepsilon = 1/m$ yields a finite open cover $\{U_{m, 1}, \dots, U_{m, p_m}\}$ centered at points $\{x_{m, 1}, \dots, x_{m, p_m}\}$.
:::

::: pf-step
The union $D = \bigcup_{m=1}^\infty \{x_{m, 1}, \dots, x_{m, p_m}\} = \{d_1, d_2, d_3, \dots\}$ is a countable subset of $X$.
:::

::: pf-step
Since $(f_n(d_1))$ is bounded in $\mathbb{R}^k$, by the Bolzano-Weierstrass theorem there exists a subsequence $(f_{1, n})$ converging at $d_1$.
:::

::: pf-step
Inductively, for each $j \ge 2$, choose $(f_{j, n})$ as a subsequence of $(f_{j-1, n})$ converging at $d_j$.
:::

::: pf-step
The diagonal sequence $g_n = f_{n, n}$ is a subsequence of $(f_n)$ that converges pointwise at every point of $D$.
:::

:::

:::

::: pf-step
Uniform convergence of the diagonal subsequence $g_n$:

::: pf-proof

::: pf-step
Let $\varepsilon > 0$.
:::

::: pf-step
By equicontinuity, choose an integer $m > \frac{3}{\varepsilon}$ such that for every $x \in X$, there exists $d_j \in D \cap \{x_{m, 1}, \dots, x_{m, p_m}\}$ with:
$$\|g_n(x) - g_n(d_j)\| < \frac{\varepsilon}{3} \quad \text{for all } n \in \mathbb{Z}_+.$$
:::

::: pf-step
Since $g_n$ converges at each of the finitely many points $d_j \in \{x_{m, 1}, \dots, x_{m, p_m}\}$, there exists an index $N$ such that for all $p, q \ge N$ and all $j \in \{1, \dots, p_m\}$:
$$\|g_p(d_j) - g_q(d_j)\| < \frac{\varepsilon}{3}.$$
:::

::: pf-step
For an arbitrary point $x \in X$, select $d_j$ with $\|g_n(x) - g_n(d_j)\| < \varepsilon/3$. Then for all $p, q \ge N$:
$$\|g_p(x) - g_q(x)\| \le \|g_p(x) - g_p(d_j)\| + \|g_p(d_j) - g_q(d_j)\| + \|g_q(d_j) - g_q(x)\| < \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \varepsilon.$$
:::

::: pf-step
Thus $(g_n)$ is uniformly Cauchy on $X$.
:::

::: pf-step
Since $\mathbb{R}^k$ is complete, $(g_n)$ converges uniformly to a continuous function $g: X \to \mathbb{R}^k$.
:::

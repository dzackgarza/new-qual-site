::: {.exercise}

Consider the sequence of continuous functions $f_n: \RR \to \RR$ defined by

$$
f_n(x) = x/n.
$$

In which of the three topologies of Theorem 46.7 does this sequence converge?
Answer the same question for the sequence given in [[E-BTI7W]].
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on it. The comparison is Theorem 46.7, by which the topology of pointwise convergence is contained in the topology of compact convergence, which is contained in the uniform topology, all on $\RR^{\RR}$; the second sequence is that of [[E-BTI7W]], where its pointwise limit is already computed.

::: pf

::: {.pf-step #nesting}
Each of the three topologies is finer than the topology of pointwise convergence, and each is Hausdorff, so a sequence convergent in any of them converges pointwise, to the pointwise limit, and that limit is unique.

::: pf-proof
The inclusions of the topologies are Theorem 46.7. A sequence converging in a topology also converges in every coarser topology, to the same limit, so convergence in the compact or uniform topology gives pointwise convergence to the same function; and the topologies are Hausdorff, the pointwise one because $\RR$ is Hausdorff, the uniform one because it is induced by the metric $\bar\rho$, so limits are unique.
:::

:::

::: {.pf-step #pointwise-first}
$f_{n}(x)=x/n$ converges pointwise to the zero function.

::: pf-proof
For each fixed $x\in\RR$ the real sequence $x/n$ tends to $0$.
:::

:::

::: {.pf-step #compact-first}
$f_{n}$ converges to the zero function in the topology of compact convergence.

::: pf-proof
Let $C\subset\RR$ be compact and put $M=\sup_{x\in C}\abs{x}$, finite because $x\mapsto\abs{x}$ is continuous on the compact set $C$. Then $\sup_{x\in C}\abs{f_{n}(x)}=M/n\to0$, so $f_{n}$ converges to $0$ uniformly on $C$; as $C$ was an arbitrary compact set, the convergence is compact.
:::

:::

::: {.pf-step #not-uniform-first}
$f_{n}$ does not converge in the uniform topology.

::: pf-proof
By step [](#nesting){.pf-ref} a limit in the uniform topology would be the pointwise limit, the zero function. But $\bar\rho(f_{n},0)=\sup_{x}\min\{\abs{x/n},1\}=1$ for every $n$, because the supremum of $\abs{x/n}$ over $\RR$ is infinite; so $\bar\rho(f_{n},0)$ does not tend to $0$ and $f_{n}$ does not converge to $0$ in the uniform metric.
:::

:::

::: {.pf-step #compact-second}
The sequence of [[E-BTI7W]] does not converge in the compact-convergence topology, hence not in the uniform topology either.

::: pf-proof
For $g_{n}(x)=1/\big(n^{3}(x-1/n)^{2}+1\big)$ one has $0<g_{n}\le1$, and $g_{n}(1/n)=1$. The compact set $[0,1]$ contains $1/n$ for every $n\ge1$, so $\sup_{[0,1]}g_{n}=1$ for every $n$, which does not tend to $0$. By step [](#nesting){.pf-ref} a limit in the compact topology would be the pointwise limit, which is $0$ by [[E-BTI7W]], and convergence to it would require the suprema over the fixed compact set $[0,1]$ to tend to $0$. So there is no such limit, and the finer uniform topology gives none either.
:::

:::

::: {.pf-step}
$x/n$ converges pointwise and compact-uniformly but not uniformly; the sequence of [[E-BTI7W]] converges only pointwise.

::: pf-proof
Steps [](#pointwise-first){.pf-ref}, [](#compact-first){.pf-ref} and [](#not-uniform-first){.pf-ref} settle the first sequence, and steps [](#pointwise-first){.pf-ref} with [[E-BTI7W]] and [](#compact-second){.pf-ref} settle the second.
:::

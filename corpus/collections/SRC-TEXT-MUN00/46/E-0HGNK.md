::: {.exercise}

Let $\mathcal{C}'(X, Y)$ denote the set $\mathcal{C}(X, Y)$ in some topology $\mathcal{T}$.
Show that if the evaluation map

$$
e: X \times \mathcal{C}'(X, Y) \to Y
$$

is continuous, then $\mathcal{T}$ contains the compact-open topology.
[Hint: The induced map $E: \mathcal{C}'(X, Y) \to \mathcal{C}(X, Y)$ is continuous.]
:::

::: {.solution}
The exercise is Munkres, *Topology* (2000), Section 46, Exercise 8, printed p. 289. The argument is the card's own — no complete published solution of this exercise was located, as the audit of 2026-11-15 records — and it uses the Tube Lemma, Lemma 26.8.

::: pf

::: {.pf-step #subbasis}
The compact-open topology is generated by the subbasis of the sets $S(C,U)=\{f\in\mathcal C(X,Y):f(C)\subseteq U\}$ with $C\subseteq X$ compact and $U\subseteq Y$ open, so it suffices to show that each $S(C,U)$ is open in the topology $\mathcal T$ of $\mathcal C'(X,Y)$.

::: pf-proof
A topology that contains a subbasis contains the topology the subbasis generates, so it is enough to test the subbasis elements $S(C,U)$.
:::

:::

::: {.pf-step #preimage}
For compact $C\subseteq X$, open $U\subseteq Y$ and $f_0\in S(C,U)$, the set $e^{-1}(U)$ is open in $X\times\mathcal C'(X,Y)$ and contains the slice $C\times\{f_0\}$.

::: pf-proof
$e$ is continuous by hypothesis, so $e^{-1}(U)$ is open. For $x\in C$ one has $e(x,f_0)=f_0(x)\in f_0(C)\subseteq U$, because $f_0\in S(C,U)$; hence $C\times\{f_0\}\subseteq e^{-1}(U)$.
:::

:::

::: {.pf-step #tube}
There is an open set $W\in\mathcal T$ with $f_0\in W$ and $C\times W\subseteq e^{-1}(U)$.

::: pf-proof

::: pf-step
$C$ is compact in $X$.
:::

::: pf-step
$e^{-1}(U)$ is an open subset of the product space $X\times\mathcal C'(X,Y)$ containing the slice $C\times\{f_0\}$.
:::

::: pf-step
By the Tube Lemma (Lemma 26.8), applied with the compact set $C$ in the role of the compact factor and $f_0$ in the role of the point, there is an open $W\subseteq\mathcal C'(X,Y)$ with $W\in\mathcal T$ such that $f_0\in W$ and $C\times W\subseteq e^{-1}(U)$.
:::

:::

:::

::: {.pf-step #inclusion}
$W\subseteq S(C,U)$, so $f_0$ has a neighbourhood in $\mathcal T$ inside $S(C,U)$.

::: pf-proof

::: pf-step
Let $f\in W$. For every $x\in C$ the pair $(x,f)$ lies in $C\times W\subseteq e^{-1}(U)$.
:::

::: pf-step
Hence $e(x,f)=f(x)\in U$ for every $x\in C$, that is, $f(C)\subseteq U$.
:::

::: pf-step
By the definition of $S(C,U)$ this says $f\in S(C,U)$, and $f_0\in W$ gives $f_0\in W\subseteq S(C,U)$.
:::

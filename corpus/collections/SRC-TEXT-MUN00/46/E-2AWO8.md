::: {.exercise}

Prove Theorem 46.7. Let $X$ be a space; let $(Y, d)$ be a metric space.
For the function space $Y^X$, one has the following inclusions of topologies:

$$
(\text{uniform}) \supset (\text{compact convergence}) \supset (\text{pointwise convergence}).
$$

If $X$ is compact, the first two coincide, and if $X$ is discrete, the second two coincide.
:::

::: solution
**Goal:** Prove the inclusions among the uniform, compact convergence, and pointwise convergence topologies on $Y^X$, and establish their equivalence under compactness and discreteness hypotheses.

<1>1. Basis definitions for the three topologies: Let $f \in Y^X$ and $\varepsilon \in (0, 1]$.
1. Pointwise convergence: Generated by subbasis elements $B_{\{x\}}(f, \varepsilon) = \{g \in Y^X : d(f(x), g(x)) < \varepsilon\}$ for single points $x \in X$.
2. Compact convergence: Generated by basic sets $B_C(f, \varepsilon) = \{g \in Y^X : \sup_{x \in C} d(f(x), g(x)) < \varepsilon\}$ for compact sets $C \subseteq X$.
3. Uniform topology: Generated by basic metric balls $B(f, \varepsilon) = \{g \in Y^X : \sup_{x \in X} \bar{d}(f(x), g(x)) < \varepsilon\}$.

<1>2. Inclusion: (pointwise) $\subseteq$ (compact convergence).
::: {.proof}
<2>1. For every point $x \in X$, the singleton $C = \{x\}$ is compact.
<2>2. The pointwise subbasis element $B_{\{x\}}(f, \varepsilon)$ is precisely the compact convergence basic set with $C = \{x\}$.
<2>3. Thus every pointwise-open set is open in the compact convergence topology.

<1>3. Inclusion: (compact convergence) $\subseteq$ (uniform).
::: {.proof}
<2>1. Let $C \subseteq X$ be compact and $\varepsilon \in (0, 1]$.
<2>2. For any $g \in B(f, \varepsilon)$, $\sup_{x \in C} d(f(x), g(x)) \le \sup_{x \in X} \bar{d}(f(x), g(x)) < \varepsilon$.
<2>3. Thus $B(f, \varepsilon) \subseteq B_C(f, \varepsilon)$.
<2>4. Hence every compact convergence basic open set contains a uniform ball, so the uniform topology contains the compact convergence topology.

<1>4. Coincidence when $X$ is compact: *Proof:* <2>1. If $X$ is compact, taking $C = X$ in the compact convergence topology yields the basic set $B_X(f, \varepsilon) = \{g \in Y^X : \sup_{x \in X} d(f(x), g(x)) < \varepsilon\}$.
<2>2. For $\varepsilon \le 1$, $B_X(f, \varepsilon) = B(f, \varepsilon)$, which is the basic open set for the uniform topology.
<2>3. Thus (uniform) $\subseteq$ (compact convergence), so the uniform and compact convergence topologies coincide.

<1>5. Coincidence when $X$ is discrete: *Proof:* <2>1. In a discrete space $X$, a subset $C \subseteq X$ is compact if and only if $C$ is finite.
<2>2. Let $C = \{x_1, \dots, x_k\}$ be a finite subset of $X$.
<2>3. The compact convergence basic set is: $$B_C(f, \varepsilon) = \{g \in Y^X : \max_{1 \le i \le k} d(f(x_i), g(x_i)) < \varepsilon\} = \bigcap_{i=1}^k B_{\{x_i\}}(f, \varepsilon).$$ <2>4. This is a finite intersection of open sets in the pointwise convergence topology, hence pointwise-open.
<2>5. Thus (compact convergence) $\subseteq$ (pointwise), so the compact convergence and pointwise convergence topologies coincide.
Q.E.D.
:::

::: {.exercise}

Let $A$ be a subspace of $\RR^n$; let $h: (A, a_0) \to (Y, y_0)$.
Show that if $h$ is extendable to a continuous map of $\RR^n$ into $Y$, then $h_*$ is the trivial homomorphism (the homomorphism that maps everything to the identity element).
:::

::: {.solution}
Let $H: \RR^n \to Y$ be a continuous extension of $h$.

::: pf

::: pf-step
Factorization through the ambient space $\RR^n$:

::: pf-proof

::: pf-step
Let $i: (A, a_0) \hookrightarrow (\RR^n, a_0)$ denote the canonical inclusion map.

::: pf-proof
This names the inclusion of the subspace, with the basepoint carried along.
:::

:::

::: pf-step
Since $H: (\RR^n, a_0) \to (Y, y_0)$ is a continuous extension of $h$, the composition satisfies:
$$h = H \circ i: (A, a_0) \to (Y, y_0).$$

::: pf-proof
On points of $A$ the map $H$ agrees with $h$, which is what it means for $H$ to extend $h$.
:::

:::

::: pf-step
By functoriality of the fundamental group operator $\pi_1$:
$$h_* = (H \circ i)_* = H_* \circ i_*,$$
where $i_*: \pi_1(A, a_0) \to \pi_1(\RR^n, a_0)$ and $H_*: \pi_1(\RR^n, a_0) \to \pi_1(Y, y_0)$.

::: pf-proof
A functor respects composition, so the induced map of the composite is the composite of the induced maps.
:::

:::

:::

:::

::: pf-step
Simple connectivity of $\RR^n$:

::: pf-proof

::: pf-step
The Euclidean space $\RR^n$ is convex, and the straight-line homotopy $K(x, t) = (1 - t)x + t a_0$ exhibits $\RR^n$ as contractible to $a_0$.

::: pf-proof
The straight-line homotopy $F(x,t)=(1-t)x+ta_0$ stays in $\RR^n$ by convexity and joins the identity to the constant map at $a_0$.
:::

:::

::: pf-step
In particular, $\RR^n$ is simply connected, so its fundamental group is trivial:
$$\pi_1(\RR^n, a_0) = \{1\}.$$

::: pf-proof
A contractible space has trivial fundamental group.
:::

:::

:::

:::

::: {.pf-step #s3}
Triviality of the homomorphism $h_*$:

::: pf-proof

::: pf-step
Let $[\gamma] \in \pi_1(A, a_0)$ be an arbitrary element.

::: pf-proof
This is an arbitrary element, which is what the triviality statement quantifies over.
:::

:::

::: pf-step
Since $\pi_1(\RR^n, a_0) = \{1\}$, the image $i_*([\gamma])$ must be the identity element $1 \in \pi_1(\RR^n, a_0)$.

::: pf-proof
The target group $\pi_1(\RR^n,a_0)$ has a single element.
:::

:::

::: pf-step
Because group homomorphisms preserve the identity element:
$$h_*([\gamma]) = (H_* \circ i_*)([\gamma]) = H_*(1) = 1 \in \pi_1(Y, y_0).$$

::: pf-proof
A group homomorphism carries the identity to the identity, and $h_*=H_*\circ i_*$ by the preceding step.
:::

:::

::: pf-step
Thus $h_*([\gamma]) = 1$ for all $[\gamma] \in \pi_1(A, a_0)$.

::: pf-proof
Since the class was arbitrary, $h_*$ is the trivial homomorphism.
:::

:::

:::

:::

::: pf-qed
Step [](#s3){.pf-ref} shows that $h_*$ is trivial.
:::

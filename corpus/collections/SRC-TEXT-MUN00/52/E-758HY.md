::: {.exercise}

Let $A$ be a subspace of $\mathbb{R}^n$; let $h: (A, a_0) \to (Y, y_0)$.
Show that if $h$ is extendable to a continuous map of $\mathbb{R}^n$ into $Y$, then $h_*$ is the trivial homomorphism (the homomorphism that maps everything to the identity element).
:::

::: {.solution}
Let $H: \mathbb{R}^n \to Y$ be a continuous extension of $h$.

::: pf

::: pf-step
Factorization through the ambient space $\mathbb{R}^n$:

::: pf-proof

::: pf-step
Let $i: (A, a_0) \hookrightarrow (\mathbb{R}^n, a_0)$ denote the canonical inclusion map.
:::

::: pf-step
Since $H: (\mathbb{R}^n, a_0) \to (Y, y_0)$ is a continuous extension of $h$, the composition satisfies:
$$h = H \circ i: (A, a_0) \to (Y, y_0).$$
:::

::: pf-step
By functoriality of the fundamental group operator $\pi_1$:
$$h_* = (H \circ i)_* = H_* \circ i_*,$$
where $i_*: \pi_1(A, a_0) \to \pi_1(\mathbb{R}^n, a_0)$ and $H_*: \pi_1(\mathbb{R}^n, a_0) \to \pi_1(Y, y_0)$.
:::

:::

:::

::: pf-step
Simple connectivity of $\mathbb{R}^n$:

::: pf-proof

::: pf-step
The Euclidean space $\mathbb{R}^n$ is convex, and the straight-line homotopy $K(x, t) = (1 - t)x + t a_0$ exhibits $\mathbb{R}^n$ as contractible to $a_0$.
:::

::: pf-step
In particular, $\mathbb{R}^n$ is simply connected, so its fundamental group is trivial:
$$\pi_1(\mathbb{R}^n, a_0) = \{1\}.$$
:::

:::

:::

::: {.pf-step #s3}
Triviality of the homomorphism $h_*$:

::: pf-proof

::: pf-step
Let $[\gamma] \in \pi_1(A, a_0)$ be an arbitrary element.
:::

::: pf-step
Since $\pi_1(\mathbb{R}^n, a_0) = \{1\}$, the image $i_*([\gamma])$ must be the identity element $1 \in \pi_1(\mathbb{R}^n, a_0)$.
:::

::: pf-step
Because group homomorphisms preserve the identity element:
$$h_*([\gamma]) = (H_* \circ i_*)([\gamma]) = H_*(1) = 1 \in \pi_1(Y, y_0).$$
:::

::: pf-step
Thus $h_*([\gamma]) = 1$ for all $[\gamma] \in \pi_1(A, a_0)$.
:::

:::

:::

::: pf-qed
Step [](#s3){.pf-ref} shows that $h_*$ is trivial.
:::

:::

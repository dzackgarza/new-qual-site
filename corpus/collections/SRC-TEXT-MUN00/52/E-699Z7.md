::: {.exercise}

Let $A \subset X$; suppose $r: X \to A$ is a continuous map such that $r(a) = a$ for each $a \in A$.
(The map $r$ is called a retraction of $X$ onto $A$.)
If $a_0 \in A$, show that

$$
r_*: \pi_1(X, a_0) \to \pi_1(A, a_0)
$$

is surjective.
:::

::: {.solution}
::: pf

::: pf-step
The inclusion $i: A \hookrightarrow X$ satisfies $r \circ i = \operatorname{id}_A$:

::: pf-proof
The subclaims record the inclusion, the retraction identity, and the basepoint condition.

::: pf-step
Let $i: (A, a_0) \hookrightarrow (X, a_0)$ denote the canonical inclusion map.

::: pf-proof
This names the inclusion of the subspace $A$ into $X$; it carries $a_0$ to $a_0$.
:::

:::

::: pf-step
By definition of a retraction, $r(a) = a$ for all $a \in A$, which means that the composition satisfies:
$$r \circ i = \operatorname{id}_A: A \to A.$$

::: pf-proof
For $a\in A$ one has $(r\circ i)(a)=r(i(a))=r(a)=a=\operatorname{id}_A(a)$, and $a$ was arbitrary.
:::

:::

::: pf-step
Since $r(a_0) = a_0$ and $i(a_0) = a_0$, both $i$ and $r$ are basepoint-preserving continuous maps.

::: pf-proof
$r(a_0)=a_0$ is the retraction hypothesis at the point $a_0$, and $i(a_0)=a_0$ holds by the definition of the inclusion; continuity is part of the hypotheses on $r$ and of the inclusion.
:::

:::

:::

:::

::: {.pf-step #s2}
Functoriality of the fundamental group:

::: pf-proof
The subclaims recall that $\pi_1$ is a functor and apply it to the retraction identity.

::: pf-step
The fundamental group operator $\pi_1$ is a functor from pointed topological spaces to groups.

::: pf-proof
It assigns to a pointed space its fundamental group and to a basepoint-preserving continuous map the induced homomorphism, carrying identities to identity homomorphisms and respecting composition.
:::

:::

::: pf-step
Applying functoriality to the identity $r \circ i = \operatorname{id}_A$ yields:
$$r_* \circ i_* = (r \circ i)_* = (\operatorname{id}_A)_* = \operatorname{id}_{\pi_1(A, a_0)},$$
where $i_*: \pi_1(A, a_0) \to \pi_1(X, a_0)$ and $r_*: \pi_1(X, a_0) \to \pi_1(A, a_0)$.

::: pf-proof
A functor carries the identity map to the identity homomorphism and respects composition, so $(r\circ i)_*=r_*\circ i_*$ and $(\operatorname{id}_A)_*$ is the identity of $\pi_1(A,a_0)$.
:::

:::

:::

:::

::: {.pf-step #s3}
Surjectivity of $r_*$:

::: pf-proof
The subclaims lift an arbitrary class from $A$ to $X$ and check that $r_*$ returns it.

::: pf-step
Let $\gamma \in \pi_1(A, a_0)$ be an arbitrary element.

::: pf-proof
Nothing is assumed about $\gamma$ beyond membership in the group, so what follows applies to every element.
:::

:::

::: pf-step
Define $\beta = i_*(\gamma) \in \pi_1(X, a_0)$.

::: pf-proof
This is a definition; $\beta$ lies in $\pi_1(X,a_0)$ because $i_*$ maps that group's source into it.
:::

:::

::: pf-step
Applying $r_*$ to $\beta$:
$$r_*(\beta) = r_*(i_*(\gamma)) = (r_* \circ i_*)(\gamma) = \operatorname{id}_{\pi_1(A, a_0)}(\gamma) = \gamma.$$

::: pf-proof
The first equality substitutes the definition of $\beta$, the second is the definition of composition, and the third the identity $r_*\circ i_*=\operatorname{id}$ established in the preceding container.
:::

:::

::: pf-step
Thus, every element of $\pi_1(A, a_0)$ is in the image of $r_*$.

::: pf-proof
For the arbitrary $\gamma$ a preimage $\beta$ has been exhibited, which is exactly surjectivity; the same identity also forces $i_*$ to be injective, though only surjectivity of $r_*$ is asked.
:::

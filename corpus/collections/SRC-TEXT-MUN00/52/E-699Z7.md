::: {.exercise}

Let $A \subset X$; suppose $r: X \to A$ is a continuous map such that $r(a) = a$ for each $a \in A$.
(The map $r$ is called a retraction of $X$ onto $A$.)
If $a_0 \in A$, show that

$$
r_*: \pi_1(X, a_0) \to \pi_1(A, a_0)
$$

is surjective.
:::

::: {.solution}
::: pf

::: pf-step
The inclusion $i: A \hookrightarrow X$ satisfies $r \circ i = \operatorname{id}_A$:

::: pf-proof

::: pf-step
Let $i: (A, a_0) \hookrightarrow (X, a_0)$ denote the canonical inclusion map.
:::

::: pf-step
By definition of a retraction, $r(a) = a$ for all $a \in A$, which means that the composition satisfies:
$$r \circ i = \operatorname{id}_A: A \to A.$$
:::

::: pf-step
Since $r(a_0) = a_0$ and $i(a_0) = a_0$, both $i$ and $r$ are basepoint-preserving continuous maps.
:::

:::

:::

::: {.pf-step #s2}
Functoriality of the fundamental group:

::: pf-proof

::: pf-step
The fundamental group operator $\pi_1$ is a functor from pointed topological spaces to groups.
:::

::: pf-step
Applying functoriality to the identity $r \circ i = \operatorname{id}_A$ yields:
$$r_* \circ i_* = (r \circ i)_* = (\operatorname{id}_A)_* = \operatorname{id}_{\pi_1(A, a_0)},$$
where $i_*: \pi_1(A, a_0) \to \pi_1(X, a_0)$ and $r_*: \pi_1(X, a_0) \to \pi_1(A, a_0)$.
:::

:::

:::

::: {.pf-step #s3}
Surjectivity of $r_*$:

::: pf-proof

::: pf-step
Let $\gamma \in \pi_1(A, a_0)$ be an arbitrary element.
:::

::: pf-step
Define $\beta = i_*(\gamma) \in \pi_1(X, a_0)$.
:::

::: pf-step
Applying $r_*$ to $\beta$:
$$r_*(\beta) = r_*(i_*(\gamma)) = (r_* \circ i_*)(\gamma) = \operatorname{id}_{\pi_1(A, a_0)}(\gamma) = \gamma.$$
:::

::: pf-step
Thus, every element of $\pi_1(A, a_0)$ is in the image of $r_*$.
:::

:::

:::

::: pf-qed
Step [](#s3){.pf-ref} shows that $r_*$ is surjective. Step [](#s2){.pf-ref} also shows that $i_*$ is injective.
:::

::: {.exercise}

Prove the following.

Theorem.
Let $X$ be a space that is path connected, locally path connected, and semilocally simply connected.
If $X$ is compact Hausdorff, then $\pi_1(X, x_0)$ is finitely generated, and hence countable.

Proof.
Repeat the proof outlined in Exercise 2 of this set, whose statement is [[E-QVJ8J]], choosing $\mathcal{B}$ to be finite.
One has the equation

$$
[f] = [g_1] * \dots * [g_n],
$$

as before.
Choose, for each $x \in X$, a path $\beta_x$ from $x_0$ to $x$; let $\beta_{x_0}$ be the constant path.
If $g = g(B, B')$, define

$$
L(g) = \beta_x * (g * \overline{\beta}_y),
$$

where $x = p(B)$ and $y = p(B')$ name the chosen points of $B$ and $B'$.
Show that

$$
[f] = [L(g_1)] * \dots * [L(g_n)].
$$

:::

::: {.solution}

::: pf

::: {.pf-step #cover}

There is a finite cover $\mathcal{B}=\{B_0,\dots,B_{m-1}\}$ of $X$ by path-connected open sets with the pairwise-union property with respect to the cover $\mathcal{A}$ of all path-connected open sets whose inclusion kills $\pi_1$, and with $x_0\in B_0$.

::: pf-proof

::: {.pf-step}

The family $\mathcal{A}$ of all path-connected open sets $A$ with $\pi_1(A,a)\to\pi_1(X,a)$ trivial for every $a\in A$ is an open cover of $X$.

::: {.pf-proof}

Each $x\in X$ has a neighbourhood $U$ with $\pi_1(U,x)\to\pi_1(X,x)$ trivial, by semilocal simple connectedness (Definition, printed p. 494), and a path-connected neighbourhood inside it, by local path connectedness; that smaller set lies in $\mathcal{A}$, since for $a$ in it the map $\pi_1(A,a)\to\pi_1(X,a)$ factors through the trivial map of $\pi_1(U,x)$ up to the change of base point.

:::

:::

::: {.pf-step}

There is a finite open cover $\mathcal{B}$ of $X$ by path-connected sets such that $B\cup B'$ lies in an element of $\mathcal{A}$ whenever $B\cap B'\ne\varnothing$.

::: {.pf-proof}

$X$ is compact Hausdorff, so [[E-8Q9TN]] (b) (printed p. 499) gives an open refinement $\mathcal{A}'$ of $\mathcal{A}$ with the pairwise-union property. The path components of the members of $\mathcal{A}'$ are open, path connected, refine $\mathcal{A}$ and inherit that property; being an open cover of the compact space $X$, they contain a finite subcover, which is $\mathcal{B}$ (definition of compactness, printed p. 164). Relabel it so that $B_0$ contains $x_0$.

:::

:::

:::

:::

::: {.pf-step #generators}

The set
$$
\mathcal{S}=\{[L(g(B,B'))]\mid B,B'\in\mathcal{B},\ B\cap B'\ne\varnothing\}
$$
is a finite subset of $\pi_1(X,x_0)$ and generates it.

::: pf-proof

::: {.pf-step}

$\mathcal{S}$ is finite.

::: {.pf-proof}

Choose a point $p(B)\in B$ for each $B$, and for each intersecting pair $B,B'$ a path $g(B,B')$ in $B\cup B'$ from $p(B)$ to $p(B')$, which exists because $B\cup B'$ is path connected. With a path $\beta_x$ from $x_0$ to each $x$ and $\beta_{x_0}$ constant, $L(g(B,B'))=\beta_{p(B)}*(g*\overline{\beta}_{p(B')})$ is a loop at $x_0$. There are at most $m^2$ ordered pairs $(B,B')$, so $\mathcal{S}$ is finite.

:::

:::

::: {.pf-step}

Every class $[f]$ in $\pi_1(X,x_0)$ is a product of elements of $\mathcal{S}$.

::: {.pf-proof}

Let $f$ be a loop at $x_0$. By parts (a) and (c) of [[E-QVJ8J]] applied to the finite cover $\mathcal{B}$ there are $B_1,\dots,B_{n-1}\in\mathcal{B}$ with $B_n=B_0$ and select paths $g_i=g(B_{i-1},B_i)$ such that
$$
[f]=[g_1]*\cdots*[g_n],
$$
and consecutive sets intersect, so each $g_i$ is one of the chosen paths. The product of the based loops $L(g_i)$ telescopes, using that multiplication of path-homotopy classes is associative and that a class times the class of its reverse is the class of the constant loop (Theorem 51.2, printed p. 326):
$$
\begin{aligned}
[L(g_1)]\cdots[L(g_n)]
&=[\beta_{B_0}*g_1*\overline{\beta}_{B_1}*\beta_{B_1}*\cdots*g_n*\overline{\beta}_{B_n}]\\
&=[g_1*\cdots*g_n]=[f],
\end{aligned}
$$
because $B_n=B_0$, so $\beta_{B_n}=\beta_{B_0}$ is the constant path and drops out.

:::

:::

:::

:::

::: {.pf-step}

$\pi_1(X,x_0)$ is finitely generated, and hence countable.

::: pf-proof

By step [](#generators){.pf-ref} every element of $\pi_1(X,x_0)$ is a product of elements of a finite set $\mathcal{S}$, so $\pi_1(X,x_0)$ is generated by $\mathcal{S}$. The set of words in a finite alphabet is countable, so the subgroup generated by $\mathcal{S}$ is countable.

:::

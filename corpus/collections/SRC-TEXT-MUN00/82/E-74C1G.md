::: {.exercise}

Prove the following.

Theorem.
Let $X$ be a space that is path connected, locally path connected, and semilocally simply connected.
If $X$ is compact Hausdorff, then $\pi_1(X, x_0)$ is finitely generated, and hence countable.

Proof.
Repeat the proof outlined in [[E-QVJ8J]], choosing $\mathcal{B}$ to be finite.
One has the equation

$$
[f] = [g_1] * \dots * [g_n],
$$

as before.
Choose, for each $x \in X$, a path $\beta_x$ from $x_0$ to $x$; let $\beta_{x_0}$ be the constant path.
If $g = g(B, B')$, define

$$
L(g) = \beta_x * (g * \overline{\beta}_y),
$$

where $x = p(B)$ and $y = p(B')$.
Show that

$$
[f] = [L(g_1)] * \dots * [L(g_n)].
$$
:::

::: {.solution}

::: pf

::: pf-step
Finite cover by canonical open sets:

::: pf-proof

::: pf-step
By local path-connectedness and semilocal simple-connectedness, each $x \in X$ has an open path-connected neighborhood $U_x$ such that the inclusion homomorphism $\pi_1(U_x, x) \to \pi_1(X, x)$ is trivial.
:::

::: pf-step
The collection $\mathcal A=\{U_x\}_{x \in X}$ forms an open cover of $X$.
:::

::: pf-step
By [[E-8Q9TN]], compact Hausdorffness gives an open cover refining $\mathcal A$ such that any two intersecting members have their union inside one member of $\mathcal A$. Take the path components of its members; these are open by local path connectedness and retain the pairwise-union property. Compactness gives a finite subcover $\mathcal B=\{B_0,\ldots,B_{m-1}\}$ of these path-connected sets. Choose $B_0$ to contain $x_0$.
:::

::: pf-step
For each $B \in \mathcal B$, choose $p(B)\in B$ and a path $\beta_B$ from $x_0$ to $p(B)$. Take $p(B_0)=x_0$ and $\beta_{B_0}$ constant.
:::

:::

:::

::: pf-step
Finite generating family of loops:

::: pf-proof

::: pf-step
For any pair $(B, B') \in \mathcal{B} \times \mathcal{B}$ with $B \cap B' \neq \varnothing$, choose a point $q \in B \cap B'$.
:::

::: pf-step
Choose a path $\alpha$ in $B$ from $p(B)$ to $q$, and a path $\alpha'$ in $B'$ from $p(B')$ to $q$.
:::

::: pf-step
Define $g(B, B') = \alpha * \overline{\alpha'}$, which is a path in $B \cup B'$ from $p(B)$ to $p(B')$.
:::

::: pf-step
Define the based loop:
$$L(g(B, B')) = \beta_B * g(B, B') * \overline{\beta}_{B'}.$$
:::

::: pf-step
Because $\mathcal{B}$ is a finite set of $m$ open sets, the set of non-empty pairs is finite (at most $m^2$).
:::

::: pf-step
Hence $\mathcal{S} = \{ [L(g(B, B'))] \mid B, B' \in \mathcal{B}, B \cap B' \neq \varnothing \}$ is a finite subset of $\pi_1(X, x_0)$.
:::

:::

:::

::: pf-step
Decomposition and factorization of an arbitrary loop $f$:

::: pf-proof

::: pf-step
Let $f:[0,1]\to X$ be a loop based at $x_0$. Apply [[E-QVJ8J]] to the finite cover $\mathcal B$. There are $B_1,\ldots,B_{n-1}\in\mathcal B$, with $B_n=B_0$, and selected paths $g_i=g(B_{i-1},B_i)$ such that
$$
[f]=[g_1*\cdots*g_n].
$$
:::

::: pf-step
The product of the based loops $L(g_i)$ telescopes:
$$
\begin{aligned}
[L(g_1)]\cdots[L(g_n)]
&=[\beta_{B_0}*g_1*\overline{\beta}_{B_1}*
\beta_{B_1}*\cdots*g_n*\overline{\beta}_{B_n}]\\
&=[g_1*\cdots*g_n]=[f],
\end{aligned}
$$
because $B_n=B_0$ and $\beta_{B_0}$ is constant.
:::

:::

:::

::: pf-step
Conclusion:
Every $[f] \in \pi_1(X, x_0)$ is a product of elements from the finite set $\mathcal{S}$.
Thus $\pi_1(X, x_0)$ is finitely generated, and hence countable.
:::

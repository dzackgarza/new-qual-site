::: {.exercise}

Show that the map of Example 3 of §53 is a covering map.
Generalize to the map $p(z) = z^n$.
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
Setup and angular coordinates:

::: pf-proof

::: pf-step
Represent $S^1 \subset \mathbb{C}$ as $\{e^{i\theta} \mid \theta \in \mathbb{R}\}$.
:::

::: pf-step
The map $p: S^1 \to S^1$ given by $p(z) = z^n$ sends $e^{i\theta} \mapsto e^{in\theta}$.
:::

::: pf-step
Since complex multiplication is continuous, $p$ is continuous. Without loss of generality, assume $n \ge 1$ (for $n < 0$, $p$ is the composition of $z \mapsto z^{|n|}$ with the reflection homeomorphism $z \mapsto \bar{z} = z^{-1}$).
:::

:::

:::

::: {.pf-step #s2}
Construction of evenly covered neighborhoods:

::: pf-proof

::: pf-step
Let $w_0 = e^{i\theta_0} \in S^1$ be an arbitrary base point.
:::

::: pf-step
Choose $\varepsilon$ such that $0 < \varepsilon < \pi$.
:::

::: pf-step
Define the open arc neighborhood $U \subset S^1$ centered at $w_0$:
$$U = \{ e^{i\theta} \mid \theta_0 - \varepsilon < \theta < \theta_0 + \varepsilon \}.$$
:::

:::

:::

::: pf-step
Preimage decomposition into disjoint slices:

::: pf-proof

::: pf-step
A point $z = e^{i\phi} \in S^1$ satisfies $p(z) \in U$ if and only if $n\phi \in (\theta_0 - \varepsilon + 2\pi k, \theta_0 + \varepsilon + 2\pi k)$ for some $k \in \mathbb{Z}$.
:::

::: pf-step
For each $k \in \{0, 1, \dots, n-1\}$, define the open arc:
$$V_k = \left\{ e^{i\phi} \;\middle|\; \frac{\theta_0 - \varepsilon + 2\pi k}{n} < \phi < \frac{\theta_0 + \varepsilon + 2\pi k}{n} \right\}.$$
:::

::: pf-step
Each $V_k$ has angular width $\frac{2\varepsilon}{n} < \frac{2\pi}{n}$.
:::

::: pf-step
The centers of the arcs $V_k$ are spaced by $\frac{2\pi}{n}$, so the sets $V_0, V_1, \dots, V_{n-1}$ are pairwise disjoint open sets in $S^1$.
:::

::: pf-step
Their union is the entire preimage: $p^{-1}(U) = \bigsqcup_{k=0}^{n-1} V_k$.
:::

:::

:::

::: {.pf-step #s4}
Homeomorphism of each sheet onto $U$:

::: pf-proof

::: pf-step
For each $k \in \{0, 1, \dots, n-1\}$, the restricted map $p|_{V_k}: V_k \to U$ is a continuous bijection.
:::

::: pf-step
The inverse map $q_k: U \to V_k$ given by $q_k(e^{i\theta}) = e^{i(\theta + 2\pi k)/n}$ (for $\theta \in (\theta_0 - \varepsilon, \theta_0 + \varepsilon)$) is continuous.
:::

::: pf-step
Thus $p|_{V_k}: V_k \to U$ is a homeomorphism.
:::

:::

:::

::: pf-qed
By steps [](#s2){.pf-ref} through [](#s4){.pf-ref}, every point of $S^1$ has an evenly covered open neighborhood $U$ with $n$ slices, so $p(z) = z^n$ is an $n$-fold covering map; for $n < 0$ it is an $|n|$-fold covering by step [](#s1){.pf-ref}.
:::

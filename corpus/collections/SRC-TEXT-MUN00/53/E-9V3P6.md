::: {.exercise}

Show that the map of Example 3 of §53 is a covering map.
Generalize to the map $p(z) = z^n$ for nonzero integers $n$.
:::

::: {.solution}
The argument is Solution 5 of dbFin, "Section 53: Problem 5 Solution": the preimage of a short arc is cut into $n$ congruent arcs, and $z\mapsto z^n$ carries each of them homeomorphically onto the arc. The exercise is Munkres, *Topology* (2000), Section 53, Exercise 5, printed p. 341, with Example 3 of that section; a covering map is defined on printed p. 336.

::: pf

::: {.pf-step #s1}
The power map $p(z)=z^n$ is a continuous map of $S^1$ to itself, and for $n<0$ it is a covering map as soon as $z\mapsto z^{\abs{n}}$ is one.

::: pf-proof

::: pf-step
Represent $S^1\subset\CC$ as $\{e^{i\theta}\mid\theta\in\RR\}$; then $p(e^{i\theta})=e^{in\theta}$.
:::

::: pf-step
Since complex multiplication is continuous, $p$ is continuous.
:::

::: pf-step
For $n<0$, $p$ is the composition of $z\mapsto z^{\abs{n}}$ with the reflection homeomorphism $z\mapsto\bar z=z^{-1}$ of $S^1$, so it suffices to treat $n\ge1$.
:::

:::

:::

::: {.pf-step #s2}
Every point of $S^1$ has an open arc neighbourhood $U$ of angular radius $\varepsilon<\pi$.

::: pf-proof

::: pf-step
Let $w_0=e^{i\theta_0}\in S^1$ be arbitrary and choose $\varepsilon$ with $0<\varepsilon<\pi$.
:::

::: pf-step
Then $U=\{e^{i\theta}\mid\theta_0-\varepsilon<\theta<\theta_0+\varepsilon\}$ is an open arc about $w_0$.
:::

:::

:::

::: {.pf-step #preimage}
$p^{-1}(U)=\bigsqcup_{k=0}^{n-1}V_k$, where
$$
V_k=\left\{e^{i\phi}\mid\frac{\theta_0-\varepsilon+2\pi k}{n}<\phi<\frac{\theta_0+\varepsilon+2\pi k}{n}\right\},
$$
and the $V_k$ are pairwise disjoint open arcs.

::: pf-proof

::: pf-step
A point $z=e^{i\phi}$ satisfies $p(z)\in U$ if and only if $n\phi\in(\theta_0-\varepsilon+2\pi k,\theta_0+\varepsilon+2\pi k)$ for some $k\in\ZZ$.
:::

::: pf-step
Each $V_k$ has angular width $\frac{2\varepsilon}{n}<\frac{2\pi}{n}$, and the centres of the arcs are spaced by $\frac{2\pi}{n}$, so the $V_0,\ldots,V_{n-1}$ are pairwise disjoint open subsets of $S^1$ whose union is $p^{-1}(U)$.
:::

:::

:::

::: {.pf-step #s4}
Each restriction $p\restriction_{V_k}:V_k\to U$ is a homeomorphism.

::: pf-proof

::: pf-step
It is the restriction of the continuous map $p$, and it is a bijection because $e^{i\phi}\mapsto e^{in\phi}$ carries the interval of $\phi$ defining $V_k$ onto the interval of $\theta$ defining $U$.
:::

::: pf-step
Its inverse, $q_k(e^{i\theta})=e^{i(\theta+2\pi k)/n}$ for $\theta_0-\varepsilon<\theta<\theta_0+\varepsilon$, is continuous, since it is the restriction of a continuous map of the real line composed with the quotient $\RR\to S^1$.
:::

:::

:::

::: pf-qed
By steps [](#s2){.pf-ref}, [](#preimage){.pf-ref} and [](#s4){.pf-ref}, every point of $S^1$ has an evenly covered neighbourhood with exactly $n$ slices, so $p(z)=z^n$ is an $n$-fold covering map for $n\ge1$; step [](#s1){.pf-ref} gives an $\abs{n}$-fold covering map for $n<0$.
:::

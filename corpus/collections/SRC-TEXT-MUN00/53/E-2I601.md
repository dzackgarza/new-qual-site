::: {.exercise}

Let $p: E \to B$ be a covering map; let $B$ be connected.
Show that if $p^{-1}(b_0)$ has $k$ elements for some $b_0 \in B$, then $p^{-1}(b)$ has $k$ elements for every $b \in B$.
In such a case, $E$ is called a $k$-fold covering of $B$.
:::

::: {.solution}
The argument is Solution 3 of dbFin, "Section 53: Problem 3 Solution": the sets of points whose fibres have a given cardinality are open, and a connected base has only one of them. The exercise is Munkres, *Topology* (2000), Section 53, Exercise 3; a covering map and an evenly covered set are defined on printed p. 336, and a connected space has no non-empty proper subset that is both open and closed by printed p. 148.

::: pf

::: {.pf-step #evenly}
Every $b\in B$ has an evenly covered open neighbourhood $U$, over which $p^{-1}(U)$ is a disjoint union of open slices $V_\alpha$ each carried homeomorphically onto $U$ by $p$.

::: pf-proof
This is the definition of a covering map, Munkres, printed p. 336: $p$ is continuous and surjective and each point of $B$ has an open neighbourhood $U$ whose preimage is a union of disjoint open sets $V_\alpha$ such that $p\restriction_{V_\alpha}$ is a homeomorphism of $V_\alpha$ onto $U$.
:::

:::

::: {.pf-step #fiber-cardinality}
If $U$ is an evenly covered neighbourhood of $b$ with slices $\{V_\alpha\}_{\alpha\in J}$, then $\cardinality{p^{-1}(y)}=\cardinality{J}$ for every $y\in U$.

::: pf-proof
Fix $y\in U$. For each $\alpha$ the restriction $p\restriction_{V_\alpha}$ is a bijection onto $U$, which contains $y$, so $p^{-1}(y)\cap V_\alpha$ consists of exactly one point. The slices are pairwise disjoint and cover $p^{-1}(U)$, so $p^{-1}(y)=\bigsqcup_{\alpha\in J}\big(p^{-1}(y)\cap V_\alpha\big)$ and $\cardinality{p^{-1}(y)}=\cardinality{J}$.
:::

:::

::: {.pf-step #fiber-sets-open}
For every cardinal $j$ the set $B_j=\{b\in B:\cardinality{p^{-1}(b)}=j\}$ is open in $B$.

::: pf-proof
Let $b\in B_j$ and let $U$ be an evenly covered neighbourhood of $b$ with set of slices $J$. By step [](#fiber-cardinality){.pf-ref} every $y\in U$ has $\cardinality{p^{-1}(y)}=\cardinality{J}$, and $\cardinality{J}=\cardinality{p^{-1}(b)}=j$ by the same step applied at $b$; so $U\subseteq B_j$, and $B_j$ contains a neighbourhood of each of its points.
:::

:::

::: {.pf-step #fiber-sets-closed}
The sets $B_j$ are pairwise disjoint with union $B$, and each is closed as well as open.

::: pf-proof
A point $b\in B$ has exactly one fibre cardinality $\cardinality{p^{-1}(b)}$, so the $B_j$ are pairwise disjoint and their union is $B$. The complement of $B_j$ is the union of the other $B_{j'}$, which is open by step [](#fiber-sets-open){.pf-ref}; so $B_j$ is closed in $B$.
:::

:::

::: {.pf-step #constant-cardinality}
If $B$ is connected and $\cardinality{p^{-1}(b_0)}=k$, then $\cardinality{p^{-1}(b)}=k$ for every $b\in B$.

::: pf-proof
By steps [](#fiber-sets-open){.pf-ref} and [](#fiber-sets-closed){.pf-ref} the sets $B_j$ are open and closed, pairwise disjoint, and cover $B$, so each is a non-empty proper open and closed subset of $B$ unless it is $B$ itself. A connected space has no non-empty proper subset that is both open and closed (Munkres, printed p. 148), so exactly one $B_j$ is non-empty. Since $b_0\in B_k$, that one is $B_k$, and every point of $B$ lies in it.
:::

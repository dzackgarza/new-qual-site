::: {.exercise}

Theorem.
Let $U$ be a simply connected open set in $\mathbb{R}^2$.
If $C$ is a simple closed curve lying in $U$, then each bounded component of $\mathbb{R}^2 - C$ also lies in $U$.

(This condition actually characterizes the simply connected open sets of $\mathbb{R}^2$.
See [RW]. The space $\mathbb{R}^2 - C$ has, of course, only one bounded component, as we shall prove in the next section.)
:::

::: {.solution}
**Goal:** Prove that if $U \subseteq \mathbb{R}^2$ is a simply connected open set and $C \subseteq U$ is a simple closed curve, then every bounded component of $\mathbb{R}^2 \setminus C$ is contained in $U$.

::: pf

::: pf-step
Setting up proof by contradiction:

::: pf-proof

::: pf-step
Let $B$ be a bounded component of $\mathbb{R}^2 \setminus C$.
:::

::: pf-step
Suppose for contradiction that $B \not\subseteq U$.
:::

::: pf-step
Then there exists a point $p \in B$ such that $p \notin U$.
:::

:::

:::

::: {.pf-step #s2}
Fundamental group of the punctured plane and winding number:

::: pf-proof

::: pf-step
Parameterize the simple closed curve $C$ as a continuous loop $\gamma: S^1 \to C \subseteq U$ based at some point $x_0 \in C$.
:::

::: pf-step
Since $p \in B$ lies in a bounded component of $\mathbb{R}^2 \setminus C$, the Jordan curve theorem / winding number theorem (Theorem 61.1) implies that the loop $\gamma$ generates a non-trivial homology/homotopy class in the punctured plane $\mathbb{R}^2 \setminus \{p\}$:
$$[\gamma] \neq 1 \in \pi_1(\mathbb{R}^2 \setminus \{p\}, x_0) \cong \mathbb{Z}.$$
:::

:::

:::

::: {.pf-step #s3}
Nullhomotopy in $U$ and induced homomorphism:

::: pf-proof

::: pf-step
Since $p \notin U$, we have the topological inclusion $i: U \hookrightarrow \mathbb{R}^2 \setminus \{p\}$.
:::

::: pf-step
The loop $\gamma$ lies entirely inside the simply connected open set $U$.
:::

::: pf-step
Because $\pi_1(U, x_0) = \{1\}$, the loop $\gamma$ is nullhomotopic in $U$: $[\gamma]_U = 1 \in \pi_1(U, x_0)$.
:::

::: pf-step
The continuous inclusion map $i: U \to \mathbb{R}^2 \setminus \{p\}$ induces a group homomorphism:
$$i_*: \pi_1(U, x_0) \to \pi_1(\mathbb{R}^2 \setminus \{p\}, x_0).$$
:::

::: pf-step
Applying $i_*$ gives:
$$[\gamma]_{\mathbb{R}^2 \setminus \{p\}} = i_*([\gamma]_U) = i_*(1) = 1 \in \pi_1(\mathbb{R}^2 \setminus \{p\}, x_0).$$
:::

:::

:::

::: pf-step
Contradiction and conclusion:

::: pf-proof

::: pf-step
Step [](#s3){.pf-ref} proves $[\gamma] = 1$ in $\pi_1(\mathbb{R}^2 \setminus \{p\}, x_0)$, directly contradicting step [](#s2){.pf-ref} which established $[\gamma] \neq 1$.
:::

::: pf-step
Hence no such point $p \in B \setminus U$ exists, which forces $B \subseteq U$.
:::

::: {.pf-step #example-1}
Example 1. In a first countable Hausdorff space every open set and every singleton is a $G_{\delta}$, and in $\overline{S}_{\Omega}=[0,\Omega]$ the top point $\Omega$ is not a $G_{\delta}$.

::: pf-proof

::: {.pf-step #open-gdelta}
Every open set $U\subset X$ is a $G_{\delta}$.

::: pf-proof
$U=\bigcap_{n=1}^{\infty}U$, an intersection of countably many open sets, all equal to $U$; so $U$ is a countable intersection of open sets, which is what $G_{\delta}$ means (§40).
:::

:::

::: {.pf-step #singleton-gdelta}
If $X$ is first countable and Hausdorff, then every singleton $\{x\}$ is a $G_{\delta}$.

::: pf-proof
Let $B_{1},B_{2},\ldots$ be a countable local base at $x$ all of whose members are open, which first countability supplies: a countable local base is turned into one of open sets by replacing a member $N$ with an open $W$ satisfying $x\in W\subset N$, and every neighbourhood of $x$ contains one of the original members, hence its replacement. Put $C_{n}=B_{1}\cap\cdots\cap B_{n}$; then $C_{n+1}\subset C_{n}$ and each $C_{n}$, a finite intersection of open sets containing $x$, is an open neighbourhood of $x$. So $x\in\bigcap_{n}C_{n}$. If $y\ne x$, Hausdorffness gives disjoint open sets $U\ni x$ and $V\ni y$. The sets $B_{1},B_{2},\ldots$ form a local base at $x$, so some $B_{n}$ lies in the neighbourhood $U$ of $x$, that is $x\in B_{n}\subset U$; then $C_{n}=B_{1}\cap\cdots\cap B_{n}\subset B_{n}\subset U$, and $y\notin U$ gives $y\notin C_{n}$, hence $y\notin\bigcap_{n}C_{n}$. Therefore $\{x\}=\bigcap_{n}C_{n}$ is a $G_{\delta}$.
:::

:::

::: {.pf-step #omega-not-gdelta}
$\{\Omega\}$ is not a $G_{\delta}$ in $\overline{S}_{\Omega}=[0,\Omega]$.

::: pf-proof
Suppose $\{\Omega\}=\bigcap_{n}U_{n}$ with each $U_{n}$ open and containing $\Omega$. For each $n$ there is $\alpha_{n}<\Omega$ with $(\alpha_{n},\Omega]\subset U_{n}$, since the intervals $(\alpha,\Omega]$ form a neighbourhood basis at the top point of a well-ordered set (§14). A countable supremum of countable ordinals is a countable ordinal (§10), so $\alpha=\sup_{n}\alpha_{n}<\Omega$. Then $\beta=\alpha+1<\Omega$, because $\Omega$ is a limit ordinal and $\alpha<\Omega$; and $\beta\in U_{n}$ for every $n$, since $\alpha_{n}<\alpha<\beta$ and $(\alpha_{n},\Omega]\subset U_{n}$. Yet $\beta\ne\Omega$, which contradicts the intersection being $\{\Omega\}$.
:::

::: {.pf-step #example-2}
Example 2. In a metric space every closed set is a $G_{\delta}$.

::: pf-proof
The empty set is open, hence a $G_{\delta}$. Let $A\ne\varnothing$ be closed in the metric space $(X,d)$ and put $U(A,\varepsilon)=\{x:d(x,A)<\varepsilon\}$ for $\varepsilon>0$. Each $U(A,1/n)$ is open, being the union of the balls $B_{d}(a,1/n)$ over $a\in A$, and it contains $A$. If $x\notin A$, then $d(x,A)>0$, since $d(x,A)=0$ would put $x$ in $\overline{A}=A$; choose $n$ with $1/n<d(x,A)$, so $x\notin U(A,1/n)$. Hence $A=\bigcap_{n}U(A,1/n)$ is a countable intersection of open sets, so a $G_{\delta}$.
:::

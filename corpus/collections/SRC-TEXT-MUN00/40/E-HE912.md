::: {.pf-step #example-1}
Example 1. In a first countable Hausdorff space every open set and every singleton is a $G_{\delta}$, and in $\overline{S}_{\Omega}=[0,\Omega]$ the top point $\Omega$ is not a $G_{\delta}$.

::: pf-proof

::: {.pf-step #open-gdelta}
Every open set $U\subset X$ is a $G_{\delta}$.

::: pf-proof
$U=\bigcap_{n=1}^{\infty}U$, an intersection of countably many open sets, all equal to $U$; so $U$ is a countable intersection of open sets, which is what $G_{\delta}$ means (§40).
:::

:::

::: {.pf-step #singleton-gdelta}
If $X$ is first countable and Hausdorff, then every singleton $\{x\}$ is a $G_{\delta}$.

::: pf-proof
Let $B_{1},B_{2},\ldots$ be a countable basis of neighbourhoods of $x$, which exists by first countability, and put $C_{n}=B_{1}\cap\cdots\cap B_{n}$; then $C_{n+1}\subset C_{n}$ and each $C_{n}$ is an open neighbourhood of $x$. So $x\in\bigcap_{n}C_{n}$. If $y\ne x$, Hausdorffness gives disjoint open sets $U\ni x$ and $V\ni y$; since $C_{n}$ is a basis element at $x$ inside the neighbourhood $U$ for some $n$, one has $y\notin C_{n}$, hence $y\notin\bigcap_{n}C_{n}$. Therefore $\{x\}=\bigcap_{n}C_{n}$ is a $G_{\delta}$.
:::

:::

::: {.pf-step #omega-not-gdelta}
$\{\Omega\}$ is not a $G_{\delta}$ in $\overline{S}_{\Omega}=[0,\Omega]$.

::: pf-proof
Suppose $\{\Omega\}=\bigcap_{n}U_{n}$ with each $U_{n}$ open and containing $\Omega$. For each $n$ there is $\alpha_{n}<\Omega$ with $(\alpha_{n},\Omega]\subset U_{n}$, since the intervals $(\alpha,\Omega]$ form a neighbourhood basis at the top point of a well-ordered set (§14). A countable supremum of countable ordinals is a countable ordinal (§10), so $\alpha=\sup_{n}\alpha_{n}<\Omega$, and any $\beta$ with $\alpha<\beta<\Omega$ lies in every $U_{n}$ although $\beta\ne\Omega$; that contradicts the intersection being $\{\Omega\}$.
:::

::: {.pf-step #example-2}
Example 2. In a metric space every closed set is a $G_{\delta}$.

::: pf-proof
The empty set is open, hence a $G_{\delta}$. Let $A\ne\varnothing$ be closed in the metric space $(X,d)$ and put $U(A,\varepsilon)=\{x:d(x,A)<\varepsilon\}$ for $\varepsilon>0$. Each $U(A,1/n)$ is open, being the union of the balls $B_{d}(a,1/n)$ over $a\in A$, and it contains $A$. If $x\notin A$, then $d(x,A)>0$, since $d(x,A)=0$ would put $x$ in $\overline{A}=A$; choose $n$ with $1/n<d(x,A)$, so $x\notin U(A,1/n)$. Hence $A=\bigcap_{n}U(A,1/n)$ is a countable intersection of open sets, so a $G_{\delta}$.
:::

::: {.exercise}

Give an example showing that a Hausdorff space with a countable basis need not be metrizable.
:::

::: {.solution}

::: pf

::: pf-step
Definition of the space $\RR_K$ (the $K$-topology on $\RR$):
Let $K = \{\frac{1}{n} : n \in \ZZ_+\} = \{1, \frac{1}{2}, \frac{1}{3}, \dots\} \subset \RR$. The space $\RR_K$ is $\RR$ equipped with the topology generated by the basis:
$$\mathcal{B} = \{(a, b) : a < b\} \cup \{(a, b) \setminus K : a < b\}.$$
:::

::: pf-step
$\RR_K$ is Hausdorff:

::: pf-proof
The $K$-topology is strictly finer than the standard Euclidean topology on $\RR$. Since $\RR$ with the standard topology is Hausdorff, any finer topology is also Hausdorff.
:::

:::

::: pf-step
$\RR_K$ has a countable basis (second-countable):

::: pf-proof

::: pf-step
Define $\mathcal{B}_\QQ = \{(p, q) : p, q \in \QQ, p < q\} \cup \{(p, q) \setminus K : p, q \in \QQ, p < q\}$.
:::

::: pf-step
Since $\QQ \times \QQ$ is countable, $\mathcal{B}_\QQ$ is a countable collection of open sets.
:::

::: pf-step
For any $x \in (a, b)$, choose rationals $p, q \in \QQ$ with $a < p < x < q < b$; then $x \in (p, q) \subseteq (a, b)$.
:::

::: pf-step
Similarly, for any $x \in (a, b) \setminus K$, choose rationals $p, q$ with $a < p < x < q < b$; then $x \in (p, q) \setminus K \subseteq (a, b) \setminus K$.
:::

::: pf-step
Thus $\mathcal{B}_\QQ$ is a countable basis for the topology of $\RR_K$.
:::

:::

:::

::: {.pf-step #rk-not-regular}
$\RR_K$ is not regular:

::: pf-proof

::: pf-step
The set $K$ is closed in $\RR_K$ because $\RR\setminus K=\bigcup_{m\ge1}((-m,m)\setminus K)$ is open in the $K$-topology.
:::

::: pf-step
The point $0$ does not belong to $K$ ($0 \notin K$).
:::

::: pf-step
Suppose there exist disjoint open sets $U, V \subseteq \RR_K$ such that $0 \in U$ and $K \subseteq V$.
:::

::: pf-step
Since $0 \in U$ and $0 \notin K$, there exists a basic open neighborhood $(-\varepsilon, \varepsilon) \setminus K \subseteq U$ for some $\varepsilon > 0$.
:::

::: pf-step
Since $K \subseteq V$, for every $n \in \ZZ_+$, $\frac{1}{n} \in V$, so there exists an open interval $(a_n, b_n) \subseteq V$ containing $\frac{1}{n}$.
:::

::: pf-step
Choose $N \in \ZZ_+$ such that $\frac{1}{N} < \varepsilon$.
:::

::: pf-step
The interval $(a_N, b_N)$ contains points of $(-\varepsilon, \varepsilon)$ not in $K$ (since $K$ is discrete in $(0, \infty)$).
:::

::: pf-step
Thus $((-\varepsilon, \varepsilon) \setminus K) \cap (a_N, b_N) \neq \emptyset$, which implies $U \cap V \neq \emptyset$, contradicting disjointness.
:::

::: pf-step
Hence the closed set $K$ and the point $0$ cannot be separated by disjoint open sets, so $\RR_K$ is not regular.
:::

:::

:::

::: pf-step
Conclusion: $\RR_K$ is not metrizable.

::: pf-proof
Every metrizable space is regular ($T_3$). Since $\RR_K$ is not regular by step [](#rk-not-regular){.pf-ref}, it cannot be metrizable. Q.E.D.
:::

::: {.exercise}

Let $X$ be a locally compact Hausdorff space.
Is it true that if $X$ has a countable basis, then $X$ is metrizable?
Is it true that if $X$ is metrizable, then $X$ has a countable basis?
:::

::: {.solution}
::: pf

::: {.pf-step #s1}
Answer to Question 1: **Yes**, second countable implies metrizable:

::: pf-proof

::: {.pf-step #s1-1}
A locally compact Hausdorff space is regular ($T_3$): for any point $x \in X$ and any closed set $C \subset X$ not containing $x$, local compactness and the Hausdorff property imply that $x$ and $C$ can be separated by disjoint open sets.

::: pf-proof
Munkres Theorem 32.2 (locally compact Hausdorff spaces are completely regular).
:::

:::

::: {.pf-step #s1-2}
By Urysohn’s Metrization Theorem, every regular space with a countable basis (second-countable) is metrizable.

::: pf-proof
Urysohn's Metrization Theorem.
:::

:::

::: pf-step
Thus, if $X$ is a locally compact Hausdorff space with a countable basis, $X$ is metrizable.

::: pf-proof
steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s2}
Answer to Question 2: **No**, metrizability does not imply second countability:

::: pf-proof

::: pf-step
Let $X$ be any uncountable set (such as $\mathbb{R}$) equipped with the discrete metric $d(x, y) = 1$ for $x \neq y$ and $d(x, x) = 0$.

::: pf-proof
definition of the discrete metric space.
:::

:::

::: pf-step
$X$ is a metric space, hence metrizable and Hausdorff.

::: pf-proof
metric spaces are metrizable and Hausdorff.
:::

:::

::: pf-step
$X$ is locally compact: for each $x \in X$, the singleton $\{x\} = B(x, 1/2)$ is an open neighborhood of $x$ which is finite, hence compact.

::: pf-proof
finite subsets of a topological space are compact.
:::

:::

::: pf-step
In the discrete topology, every singleton $\{x\}$ is an open set.
Any topological basis $\mathcal{B}$ for $X$ must contain a subset of $\{x\}$ around $x$, which forces $\{x\} \in \mathcal{B}$ for every $x \in X$.

::: pf-proof
definition of a topological basis.
:::

:::

::: pf-step
Since $X$ is uncountable, the cardinality of any basis is $|\mathcal{B}| \ge |X| > \aleph_0$.
Thus $X$ does not have a countable basis.

::: pf-proof
uncountability of $X$.
:::

:::

:::

:::

::: pf-step
Conclusion:

1. Yes: every second-countable locally compact Hausdorff space is metrizable.

2. No: an uncountable discrete space is a metrizable, locally compact Hausdorff space without a countable basis.

::: pf-proof
step [](#s1){.pf-ref} and step [](#s2){.pf-ref}.
:::

::: {.exercise}

Let $F$ be a free group on two free generators $\alpha$ and $\beta$.
Let $H$ be the subgroup generated by $\alpha$.
Show that $H$ has infinite index in $F$.

:::

::: {.solution}
The published sentence this card cites is **David Yang, *MATH104: Topology, Fall 2023*, Homework 12**, `HW/hw12.tex` lines 102--116 of `dyang5/MATH104-Topology` at commit `12686a815d58f29aeaadb90a30449ae85c0a613f` (2024-05-04): the index count reproduced in step [](#yang){.pf-ref} is his, with Corollary 69.5 named to close it. The proof displayed below is the card's own, by the right cosets $H\beta^{n}$ and uniqueness of reduced words; it is not Yang's and not either answer to Math Stack Exchange question 1277144.

::: pf

::: {.pf-step #setup}
$H=\{\alpha^{k}\mid k\in\ZZ\}$, and $H$ has infinite index in $F$ exactly when $F$ has infinitely many right cosets modulo $H$.

::: pf-proof
$H$ is the subgroup generated by the single element $\alpha$, so it consists of the powers $\alpha^{k}$ for $k\in\ZZ$. The index of a subgroup is the cardinality of the set of right cosets when that set is finite (Munkres, printed p. 514), and the index is infinite exactly when the set of right cosets is infinite.
:::

:::

::: {.pf-step #coset-criterion}
For $m,n\in\ZZ$ one has $H\beta^{m}=H\beta^{n}$ if and only if $\beta^{m-n}\in H$.

::: pf-proof
Right cosets are equal exactly when $xy^{-1}\in H$ for $x=\beta^{m}$ and $y=\beta^{n}$, and $\beta^{m}\beta^{-n}=\beta^{m-n}$.
:::

:::

::: {.pf-step #distinct}
$\beta^{m-n}=\alpha^{k}$ forces $m=n$ and $k=0$.

::: pf-proof
If $m-n\ne0$ then $\beta^{m-n}$ is a reduced word whose first letter is $\beta^{\pm1}$, while for $k\ne0$ the element $\alpha^{k}$ is a reduced word whose first letter is $\alpha^{\pm1}$, and for $k=0$ it is the empty word. Reduced words are unique, so the two sides can be equal only if both are empty: $m-n=0$ and $k=0$.
:::

:::

::: {.pf-step #index}
$H$ has infinite index in $F$.

::: pf-proof
If $H\beta^{m}=H\beta^{n}$ then $\beta^{m-n}\in H$ by step [](#coset-criterion){.pf-ref}, so $\beta^{m-n}=\alpha^{k}$ for some $k$, and step [](#distinct){.pf-ref} gives $m=n$. So the cosets $H\beta^{n}$, indexed by $\ZZ$, are pairwise distinct, and there are infinitely many of them; by step [](#setup){.pf-ref} the index is infinite.
:::

:::

::: {.pf-step #yang}
If $H$ had finite index $k$, then $k+1=1$.

::: pf-proof
$F$ is free on the two generators $\alpha,\beta$. If $[F:H]=k$ were finite, Theorem 85.3 (printed p. 515) with $n+1=2$ free generators for $F$ would give $H$ a system of $k+1$ free generators; but $H=\langle\alpha\rangle\cong\ZZ$ has a system of one free generator. The number of elements in a system of free generators of a free group is the same for every such system (Corollary 69.5, printed p. 423), so $k+1=1$. This is the index count of the cited source, which states the comparison without naming Corollary 69.5.
:::

:::

::: {.pf-step}
$[F:H]=\infty$.

::: pf-proof
Step [](#index){.pf-ref} proves it directly, and step [](#yang){.pf-ref} excludes every finite index, since no positive integer $k$ satisfies $k+1=1$.
:::

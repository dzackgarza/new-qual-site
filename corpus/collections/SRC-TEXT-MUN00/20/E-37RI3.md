::: {.exercise}

(a) In $\mathbb{R}^n$, define

$$
d'(\mathbf{x}, \mathbf{y}) = \abs{x_1 - y_1} + \dots + \abs{x_n - y_n}.
$$

Show that $d'$ is a metric that induces the usual topology of $\mathbb{R}^n$.
Sketch the basis elements under $d'$ when $n = 2$.

(b) More generally, given $p \geq 1$, define

$$
d'(\mathbf{x}, \mathbf{y}) = \left[ \sum_{i=1}^{n} \abs{x_i - y_i}^p \right]^{1/p}
$$

for $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$.
Assume that $d'$ is a metric.
Show that it induces the usual topology on $\mathbb{R}^n$.
:::

::: solution
**Goal:** Prove that the $\ell_1$ and general $\ell_p$ metrics on $\mathbb{R}^n$ are topologically equivalent to the standard Euclidean product metric, and describe the geometry of $\ell_1$ balls in $\mathbb{R}^2$.

<1>1. Part (a): $\ell_1$ metric axioms and topological equivalence.
    *Proof:*
    <2>1. **Metric axioms:**
        - Positivity & Non-degeneracy: $d'(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^n |x_i - y_i| \ge 0$, with equality if and only if $|x_i - y_i| = 0$ for all $i$, i.e., $\mathbf{x} = \mathbf{y}$.
        - Symmetry: $d'(\mathbf{x}, \mathbf{y}) = \sum |x_i - y_i| = \sum |y_i - x_i| = d'(\mathbf{y}, \mathbf{x})$.
        - Triangle inequality: $|x_i - z_i| \le |x_i - y_i| + |y_i - z_i|$ for each $i$. Summing over $i=1,\dots,n$ gives $d'(\mathbf{x}, \mathbf{z}) \le d'(\mathbf{x}, \mathbf{y}) + d'(\mathbf{y}, \mathbf{z})$.
    <2>2. **Topological equivalence:**
        - Let $\rho(\mathbf{x}, \mathbf{y}) = \max_{1 \le i \le n} |x_i - y_i|$ be the standard square metric inducing the product topology on $\mathbb{R}^n$.
        - For every $\mathbf{x}, \mathbf{y} \in \mathbb{R}^n$:
          $$\rho(\mathbf{x}, \mathbf{y}) \le d'(\mathbf{x}, \mathbf{y}) = \sum_{i=1}^n |x_i - y_i| \le n \max_{1 \le i \le n} |x_i - y_i| = n \rho(\mathbf{x}, \mathbf{y}).$$
        - Hence $B_\rho(\mathbf{x}, \frac{\varepsilon}{n}) \subseteq B_{d'}(\mathbf{x}, \varepsilon) \subseteq B_\rho(\mathbf{x}, \varepsilon)$.
        - This sandwiching of open balls proves that $d'$ and $\rho$ generate the exact same topology.
    <2>3. **Geometry for $n=2$:** The open ball $B_{d'}((x_0, y_0), r) = \{(x, y) \in \mathbb{R}^2 : |x - x_0| + |y - y_0| < r\}$ is an open square (diamond) centered at $(x_0, y_0)$ with vertices $(x_0 \pm r, y_0)$ and $(x_0, y_0 \pm r)$, rotated by $45^\circ$ relative to the coordinate axes.

<1>2. Part (b): Equivalence of the $\ell_p$ metric for $p \ge 1$.
    *Proof:*
    <2>1. Let $d_p(\mathbf{x}, \mathbf{y}) = \left(\sum_{i=1}^n |x_i - y_i|^p\right)^{1/p}$.
    <2>2. For any $j \in \{1, \dots, n\}$, $|x_j - y_j| = (|x_j - y_j|^p)^{1/p} \le d_p(\mathbf{x}, \mathbf{y})$, which gives:
        $$\rho(\mathbf{x}, \mathbf{y}) = \max_{1 \le i \le n} |x_i - y_i| \le d_p(\mathbf{x}, \mathbf{y}).$$
    <2>3. Conversely:
        $$d_p(\mathbf{x}, \mathbf{y}) = \left(\sum_{i=1}^n |x_i - y_i|^p\right)^{1/p} \le \left(\sum_{i=1}^n \rho(\mathbf{x}, \mathbf{y})^p\right)^{1/p} = \left(n \rho(\mathbf{x}, \mathbf{y})^p\right)^{1/p} = n^{1/p} \rho(\mathbf{x}, \mathbf{y}).$$
    <2>4. Combining the bounds gives the uniform norm comparison:
        $$\rho(\mathbf{x}, \mathbf{y}) \le d_p(\mathbf{x}, \mathbf{y}) \le n^{1/p} \rho(\mathbf{x}, \mathbf{y}).$$
    <2>5. Therefore, for every $\mathbf{x} \in \mathbb{R}^n$ and $\varepsilon > 0$:
        $$B_\rho\left(\mathbf{x}, \frac{\varepsilon}{n^{1/p}}\right) \subseteq B_{d_p}(\mathbf{x}, \varepsilon) \subseteq B_\rho(\mathbf{x}, \varepsilon).$$
    <2>6. Thus every $d_p$-open set is $\rho$-open and vice versa, so $d_p$ induces the standard topology on $\mathbb{R}^n$. Q.E.D.
:::

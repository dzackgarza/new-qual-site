::: {.exercise}

Let $X$ be an ordered set.
If $Y$ is a proper subset of $X$ that is convex in $X$, does it follow that $Y$ is an interval or a ray in $X$?
:::

::: {.solution}
The complete published solution is **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 16.7, printed pp. 153--154** (`tmp/sources/munkres-solutions-whitman.pdf`); the counterexample and its convexity are his, and the elimination of the seven interval and ray forms at the end replaces his "similar arguments show" for the remaining three.

**No.** Take $X=\QQ$ with the usual order and
$$
Y=\{x\in\QQ\mid x^{2}<2\},
$$
which is a proper subset of $X$: the element $2\in X$ satisfies $2^{2}=4>2$, so $2\notin Y$.

*$Y$ is convex in $X$.* Let $a<b$ in $Y$ and let $x\in\QQ$ with $a<x<b$. If $x\ge0$ then $0\le x<b$ so $x^{2}<b^{2}<2$. If $x<0$ then $a<x<0$ so $x^{2}<a^{2}<2$. In either case $x^{2}<2$, so $x\in Y$; hence $(a,b)\subset Y$.

*$Y$ has no least upper bound in $X=\QQ$.* Every element of $Y$ is positive-rational or... precisely, $Y$ is nonempty ($0\in Y$) and bounded above in $\QQ$ (by $2$, since $2^{2}=4>2$). Suppose $q\in\QQ$ were a least upper bound of $Y$ in $\QQ$. Since $\sqrt2$ is irrational, $q^{2}\ne2$. If $q^{2}>2$ then $q>0$ and, the rationals being order dense in $\RR$, there is $q'\in\QQ$ with $\sqrt2<q'<q$; then $q'^{2}>2$, so $q'$ is an upper bound of $Y$ (if $y\in Y$ then $y<\sqrt2<q'$), contradicting the minimality of $q$. If $q^{2}<2$ then $q<\sqrt2$ and there is $q'\in\QQ$ with $q<q'<\sqrt2$; then $q'^{2}<2$, so $q'\in Y$ and $q$ is not an upper bound of $Y$. Both cases are impossible.

*$Y$ is not an interval and not a ray in $X$.* Every interval or ray in $\QQ$ other than $\QQ$ itself has one of the forms $(-\infty,b)$, $(-\infty,b]$, $(a,+\infty)$, $[a,+\infty)$, $(a,b)$, $(a,b]$, $[a,b)$, $[a,b]$ with $a<b$ in $\QQ$. The rays $(a,+\infty)$ and $[a,+\infty)$ contain elements larger than every element of $Y$, and $(-\infty,b)$, $(-\infty,b]$, $(a,b)$, $(a,b]$, $[a,b)$, $[a,b]$ each have $b$ as their least upper bound in $\QQ$: no element of the set exceeds $b$, every element is below $b$, and if $q\in\QQ$ with $q<b$ there is an element of the set above $q$ (if $q\le a$ any element will do, and otherwise $(q+b)/2$ lies strictly between $q$ and $b$). By the previous paragraph $Y$ has no least upper bound in $\QQ$, so $Y$ is none of these sets, and $Y\ne\QQ$; hence $Y$ is neither an interval nor a ray in $X$.

So a proper convex subset of an ordered set need not be an interval or a ray.

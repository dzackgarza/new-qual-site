::: {.exercise}

A space $X$ is said to be contractible if the identity map $i_X: X \to X$ is nulhomotopic.

(a) Show that $I$ and $\RR$ are contractible.

(b) Show that a contractible space is path connected.

(c) Show that if $Y$ is contractible, then for any $X$, the set $[X, Y]$ has a single element.

(d) Show that if $X$ is contractible and $Y$ is path connected, then $[X, Y]$ has a single element.
:::

::: {.solution}

::: pf

::: pf-step

Part (a): $I = [0, 1]$ and $\RR$ are contractible.
    *Proof:*

::: pf-proof

::: pf-step

For $I = [0, 1]$, define $H: I \times I \to I$ by $H(x, t) = (1 - t)x$. Then $H$ is continuous, $H(x, 0) = x = \operatorname{id}_I(x)$, and $H(x, 1) = 0$. Thus $\operatorname{id}_I \simeq c_0$.

:::

::: pf-step

For $\RR$, define $H: \RR \times I \to \RR$ by $H(x, t) = (1 - t)x$. Then $H$ is continuous, $H(x, 0) = x = \operatorname{id}_{\RR}(x)$, and $H(x, 1) = 0$. Thus $\operatorname{id}_{\RR} \simeq c_0$.

:::

:::

:::

::: pf-step

Part (b): Contractible spaces are path-connected.
    *Proof:*

::: pf-proof

::: pf-step

Let $X$ be contractible, so there exists a null-homotopy $H: X \times I \to X$ with $H(x, 0) = x$ and $H(x, 1) = x_0$ for some fixed $x_0 \in X$.

:::

::: pf-step

For any point $x \in X$, the curve $\gamma_x: I \to X$ given by $\gamma_x(t) = H(x, t)$ is a continuous path in $X$ from $\gamma_x(0) = x$ to $\gamma_x(1) = x_0$.

:::

::: pf-step

For any two points $a, b \in X$, the path product $\gamma_a * \overline{\gamma_b}$ is a continuous path in $X$ from $a$ to $b$.

:::

::: pf-step

Thus $X$ is path-connected.

:::

:::

:::

::: pf-step

Part (c): If $Y$ is contractible, then $[X, Y]$ is a singleton for any space $X$.
    *Proof:*

::: pf-proof

::: pf-step

Let $H: Y \times I \to Y$ be a homotopy with $H(y, 0) = y$ and $H(y, 1) = y_0$.

:::

::: pf-step

For any continuous map $f: X \to Y$, define $G: X \times I \to Y$ by $G(x, t) = H(f(x), t)$.

:::

::: pf-step

As a composition of continuous maps, $G$ is continuous; moreover $G(x, 0) = H(f(x), 0) = f(x)$ and $G(x, 1) = H(f(x), 1) = y_0$.

:::

::: pf-step

Thus every map $f: X \to Y$ is homotopic to the constant map $c_{y_0}: X \to Y$.

:::

::: pf-step

Therefore, all maps in $\mathcal{C}(X, Y)$ lie in the single homotopy class $[c_{y_0}]$, so $\cardinality{[X, Y]} = 1$.

:::

:::

:::

::: pf-step

Part (d): If $X$ is contractible and $Y$ is path-connected, then $[X, Y]$ is a singleton.
    *Proof:*

::: pf-proof

::: pf-step

Let $H: X \times I \to X$ be a null-homotopy with $H(x, 0) = x$ and $H(x, 1) = x_0$.

:::

::: pf-step

For any map $f: X \to Y$, the homotopy $F(x, t) = f(H(x, t))$ shows $f \simeq c_{f(x_0)}$.

:::

::: pf-step

Since $Y$ is path-connected, for any $y_1, y_2 \in Y$ there exists a path $\alpha: I \to Y$ with $\alpha(0) = y_1$ and $\alpha(1) = y_2$.

:::

::: pf-step

The homotopy $K(x, t) = \alpha(t)$ establishes that $c_{y_1} \simeq c_{y_2}$.

:::

::: pf-step

Consequently, for any two maps $f, g: X \to Y$, $f \simeq c_{f(x_0)} \simeq c_{g(x_0)} \simeq g$.

:::

::: pf-step

Thus all maps from $X$ to $Y$ are homotopic, so $\cardinality{[X, Y]} = 1$. Q.E.D.

Two remarks on the printed hypotheses. Part (d) is printed without a nonemptiness hypothesis on $Y$, and parts (c) and (d) both need one: under Munkres's definition a space is path connected when every pair of its points can be joined, which the empty space satisfies vacuously, and it is contractible, its identity map being the empty map; but for $Y=\varnothing$ and $X\neq\varnothing$ the set $[X,Y]$ is empty, since there is no map of a nonempty space into the empty one. So the two parts assert a singleton set exactly when $Y\neq\varnothing$, and the arguments above use a point of $Y$ in each case. Part (b) is unaffected: the empty space is path connected.

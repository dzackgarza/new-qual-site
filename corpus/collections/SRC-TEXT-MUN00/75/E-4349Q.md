::: {.exercise}

Let $X$ be the quotient space obtained from an 8-sided polygonal region $P$ by pasting its edges together according to the labelling scheme $acadbcb^{-1}d$.

(a) Check that all vertices of $P$ are mapped to the same point of the quotient space $X$ by the pasting map.

(b) Calculate $H_1(X)$.

(c) Assuming $X$ is homeomorphic to one of the surfaces given in Theorem 75.5 (which it is), which surface is it?
:::

::: {.solution}

::: pf

::: pf-step
Part (a): All 8 vertices of $P$ are identified to a single point.

::: pf-proof

::: pf-step
Label the vertices of the 8-gon in counterclockwise order as $v_0, v_1, v_2, v_3, v_4, v_5, v_6, v_7$, so the oriented boundary edges are:
$$a: v_0 \to v_1, \quad c: v_1 \to v_2, \quad a: v_2 \to v_3, \quad d: v_3 \to v_4,$$
$$b: v_4 \to v_5, \quad c: v_5 \to v_6, \quad b^{-1}: v_6 \to v_7, \quad d: v_7 \to v_0.$$

::: pf-proof
The boundary of an $8$-gon consists of eight edges in cyclic order, and reading the labelling scheme $acadbcb^{-1}d$ in that order gives the eight directed edges listed, each running from one vertex to the next.
:::

:::

::: pf-step
The identifications from identical directed edges yield:
- $e_1(a)$ and $e_3(a) \implies v_0 \sim v_2$ and $v_1 \sim v_3$.
- $e_2(c)$ and $e_6(c) \implies v_1 \sim v_5$ and $v_2 \sim v_6$.
- $e_4(d)$ and $e_8(d) \implies v_3 \sim v_7$ and $v_4 \sim v_0$.
- $e_5(b)$ and $e_7(b^{-1}) \implies b: v_7 \to v_6$, so $v_4 \sim v_7$ and $v_5 \sim v_6$.

::: pf-proof
Edges with the same label and the same orientation are pasted direction-preservingly, so their initial vertices are identified and their terminal vertices are identified; the pair $b$ and $b^{-1}$ is pasted with the orientations reversed, so the initial vertex of $b$ is identified with the terminal vertex of $b^{-1}$ and conversely.
:::

:::

::: pf-step
Combining these equivalences:
$$v_0 \sim v_2 \sim v_6 \sim v_5 \sim v_1 \sim v_3 \sim v_7 \sim v_4 \sim v_0.$$

::: pf-proof
The relation $\sim$ generated by the pastings contains $v_0 \sim v_2$, $v_2 \sim v_6$, $v_6 \sim v_5$, $v_5 \sim v_1$, $v_1 \sim v_3$, $v_3 \sim v_7$, $v_7 \sim v_4$ and $v_4 \sim v_0$; a relation generated by these is transitive, so all eight vertices lie in one class.
:::

:::

::: pf-step
Hence all 8 vertices lie in a single equivalence class, so $V = 1$.

::: pf-proof
The eight vertices form a single equivalence class under the pasting, and the quotient space has one point for that class, so $V = 1$.
:::

:::

:::

:::

::: pf-step
Part (b): Calculation of $H_1(X)$.
$$H_1(X) \cong \ZZ^3 \oplus \ZZ/2\ZZ.$$

::: pf-proof

::: pf-step
$X$ has a standard CW complex structure with one 0-cell $v$, four 1-cells $\{a, b, c, d\}$, and one 2-cell $e^2$ attached along the loop $w = a c a d b c b^{-1} d$.

::: pf-proof
The quotient of the polygon by the pastings is a CW complex whose $0$-skeleton is the single vertex class, whose $1$-cells are the four edge classes $a, b, c, d$ attached to it, and whose $2$-cell is the image of the interior, attached along the loop that reads the labelling scheme with a negative exponent read as the reverse direction.
:::

:::

::: pf-step
The 1-chains group is $C_1(X) = \ZZ a \oplus \ZZ b \oplus \ZZ c \oplus \ZZ d$, and the boundary map $\partial_1: C_1 \to C_0$ is zero because all 1-cells are closed loops at $v$.

::: pf-proof
The $1$-chains are the free abelian group on the four $1$-cells, and $\partial_1$ of a $1$-cell is its terminal vertex minus its initial vertex; both are the single vertex $v$, so every $\partial_1$ vanishes.
:::

:::

::: pf-step
The cellular boundary of the 2-cell is:
$$\partial_2(e^2) = a + c + a + d + b + c - b + d = 2a + 2c + 2d + 0b = 2(a + c + d).$$

::: pf-proof
The attaching loop read as a cellular $1$-chain contributes each letter with the sign of its exponent, giving $a + c + a + d + b + c - b + d$; the two $b$ terms cancel and the sum is $2a + 2c + 2d$.
:::

:::

::: pf-step
Thus $H_1(X) = C_1 / \operatorname{Im}(\partial_2) \cong \langle a, b, c, d \mid 2(a + c + d) = 0 \rangle$.

::: pf-proof
With one vertex $\partial_1 = 0$, so $H_1 = C_1/\operatorname{im}\partial_2$, and $\operatorname{im}\partial_2$ is the cyclic subgroup generated by $2(a+c+d)$; the quotient of the free group on four generators by one relation is presented by that relation alone.
:::

:::

::: pf-step
Making the change of basis $u = a + c + d, c' = c, d' = d, b' = b$ for $\ZZ^4$ presents the group as:
$$\langle u, b', c', d' \mid 2u = 0 \rangle \cong (\ZZ/2\ZZ) \oplus \ZZ \oplus \ZZ \oplus \ZZ = \ZZ^3 \oplus \ZZ/2\ZZ.$$

::: pf-proof
The substitution $u = a+c+d$, $b' = b$, $c' = c$, $d' = d$ has a matrix that becomes triangular with ones on the diagonal once the generators are ordered $u, b', c', d'$, so it is an automorphism of $\ZZ^4$; in the new basis the relation is $2u = 0$ and the other three generators are free, which is $\ZZ/2\ZZ \oplus \ZZ^3$.
:::

:::

:::

:::

::: pf-step
Part (c): Topological classification of $X$.
$X$ is homeomorphic to the connected sum of 4 real projective planes:
$$X \cong \#^4 \RP^2 \cong P^2 \# P^2 \# P^2 \# P^2.$$

::: pf-proof

::: pf-step
**Euler characteristic:** $\chi(X) = V - E + F = 1 - 4 + 1 = -2$.

::: pf-proof
For a finite CW complex the Euler characteristic is the alternating count of cells, here $1 - 4 + 1 = -2$.
:::

:::

::: pf-step
**Orientability:** by part (b), $H_1(X)\cong\ZZ^3\oplus\ZZ_2$ has an element of order $2$, while every orientable closed connected surface has $H_1=\ZZ^{2g}$ by Theorem 75.5, which is torsion-free. So $X$ is non-orientable.

::: pf-proof
Part (b) produced an element of order $2$ in $H_1(X)$. A closed orientable surface has $H_1 \cong \ZZ^{2g}$ by Theorem 75.5, which is torsion-free, so $X$ cannot be orientable.
:::

:::

::: pf-step
**Classification:** Any closed, connected non-orientable 2-manifold is classified by its Euler characteristic $\chi(N_k) = 2 - k$.

::: pf-proof
Theorem 75.5 classifies closed connected surfaces up to homeomorphism by orientability together with the Euler characteristic, the non-orientable surface with $k$ crosscaps having $\chi(N_k) = 2 - k$.
:::

:::

::: pf-step
Setting $2 - k = -2$ gives $k = 4$.

::: pf-proof
Solving $\chi(N_k) = 2 - k = -2$ gives $k = 4$.
:::

:::

::: pf-step
Therefore $X \cong N_4 = \#^4 \RP^2$.

::: pf-proof
The surface is closed, connected and non-orientable with $\chi = -2$, so by the classification it is the non-orientable surface with $k = 4$, the connected sum of four projective planes.
:::

::: {.exercise}
Let $P$ be the group of bijections of the set $\{0, 1, 2\}$ with itself.
For $i = 1, 2$, let $\pi_i \in P$ be the bijection with $\pi_i(i) = i - 1$, $\pi_i(i-1) = i$, and $\pi_i(j) = j$ otherwise, and let $G_i$ be the subgroup generated by $\pi_i$.
Check that each $G_i$ has order $2$, that $G_1$ and $G_2$ generate $P$, and that $P$ is not the free product of $G_1$ and $G_2$: for instance, the reduced words $(\pi_1, \pi_2, \pi_1)$ and $(\pi_2, \pi_1, \pi_2)$ represent the same element of $P$.
:::

::: {.solution}
Products are composites of bijections, applied right to left.

::: pf

::: pf-step
Each $G_i$ has order $2$.

::: pf-proof
$\pi_i$ swaps $i-1$ and $i$ and fixes the third point, so $\pi_i \ne 1$ and $\pi_i^2 = 1$; hence $G_i = \{1, \pi_i\}$.
:::

:::

::: pf-step
$G_1$ and $G_2$ generate $P$.

::: pf-proof
$\pi_1\pi_2$ sends $0 \mapsto 1$, $1 \mapsto 2$, $2 \mapsto 0$, so it has order $3$.
The subgroup generated by $\pi_1$ and $\pi_2$ therefore has order divisible by $2$ and by $3$, hence by $6 = |P|$, so it is $P$.
:::

:::

::: {.pf-step #same-element}
$\pi_1\pi_2\pi_1 = \pi_2\pi_1\pi_2$.

::: pf-proof
Both composites send $0 \mapsto 2$, $1 \mapsto 1$, $2 \mapsto 0$: for instance $\pi_1\pi_2\pi_1(0) = \pi_1\pi_2(1) = \pi_1(2) = 2$ and $\pi_2\pi_1\pi_2(0) = \pi_2\pi_1(0) = \pi_2(1) = 2$, and the other values are computed the same way.
:::

:::

::: pf-step
$P$ is not the free product of $G_1$ and $G_2$.

::: pf-proof
The words $(\pi_1, \pi_2, \pi_1)$ and $(\pi_2, \pi_1, \pi_2)$ are reduced, since adjacent letters lie in different subgroups, and they are distinct words.
In a free product each element is represented by exactly one reduced word, but by step [](#same-element){.pf-ref} these two represent the same element of $P$.
:::

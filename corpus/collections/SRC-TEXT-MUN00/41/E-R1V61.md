::: {.exercise}

Is every locally compact Hausdorff space paracompact?
:::

::: {.solution}
No retained published solution covers this exercise; the argument is the card's own. Write $S_\Omega=[0,\Omega)$ for the set of countable ordinals with the order topology and $\overline S_\Omega=S_\Omega\cup\{\Omega\}$ for its one-point completion, which is well-ordered and has the least upper bound property.

::: pf

::: {.pf-step #locally-compact-hausdorff}
$S_\Omega$ is Hausdorff and locally compact.

::: pf-proof
Hausdorff: the open rays $\theset{\gamma:\gamma<\delta}$ and $\theset{\gamma:\gamma>\delta}$ are open in the order topology, so for $\alpha<\beta$ the sets $U=\theset{\gamma:\gamma<\alpha+1}$ and $V=\theset{\gamma:\gamma>\alpha}$ are open, contain $\alpha$ and $\beta$ respectively, and are disjoint because no $\gamma$ satisfies $\alpha<\gamma<\alpha+1$. Local compactness: for $\alpha<\Omega$ the set $C_\alpha=[0,\alpha+1]$ is compact, being a closed interval in the well-ordered set $\overline S_\Omega$, which has the least upper bound property (Theorem 27.1); compactness of a subspace is intrinsic, so $C_\alpha$ is compact as a subspace of $S_\Omega$. It is also a neighbourhood of $\alpha$: for any $\beta<\alpha$ the basic open set $(\beta,\alpha+2)$ of the order topology contains $\alpha$ and lies in $[0,\alpha+1]$, since every ordinal below $\alpha+2$ is at most $\alpha+1$. Hence each $\alpha<\Omega$ has a compact neighbourhood, which is local compactness (§29).
:::

:::

::: {.pf-step #not-paracompact}
$S_\Omega$ is not paracompact.

::: pf-proof
This is part (b) of Exercise 41.2, proved on the card of [[E-94C75]]: $S_\Omega\times\overline S_\Omega$ is a non-normal product of a paracompact space with a compact one, which contradicts part (a) of the same exercise and so forces $S_\Omega$ not to be paracompact.
:::

:::

::: {.pf-step #answer}
Not every locally compact Hausdorff space is paracompact.

::: pf-proof
Step [](#locally-compact-hausdorff){.pf-ref} gives a space that is locally compact and Hausdorff, and step [](#not-paracompact){.pf-ref} shows that this same space is not paracompact, so the implication fails and the answer to the exercise is no. The question as printed asks only for the implication, so no separation axiom beyond Hausdorffness is claimed for a counterexample.
:::

::: {.exercise}

Consider the following topologies on $\RR$:

$\mathcal{T}_1$ = the standard topology,

$\mathcal{T}_2$ = the topology of $\RR_K$,

$\mathcal{T}_3$ = the finite complement topology,

$\mathcal{T}_4$ = the upper limit topology, having all sets $(a, b]$ as basis,

$\mathcal{T}_5$ = the topology having all sets $(-\infty, a) = \theset{x \mid x < a}$ as basis.

Determine, for each of these topologies, which of the others it contains.
:::

::: {.solution}

The answer and every comparison are those of **Dan Whitman, *Topology, Second Edition by James Munkres: Solutions Manual* (30 November 2019), Exercise 13.7** (`tmp/sources/munkres-solutions-whitman.pdf`); the inclusion $\mathcal{T}_{1}\subsetneq\mathcal{T}_{2}$ is Munkres's Lemma 13.4 , quoted.

Write $\mathcal{B}_{1}=\{(a,b)\}$, $\mathcal{B}_{2}=\{(a,b)\}\cup\{(a,b)-K\}$ with $K=\{1/n\mid n\in\ZZ_{+}\}$, $\mathcal{B}_{4}=\{(a,b]\}$, $\mathcal{B}_{5}=\{(-\infty,a)\}$, which are bases for $\mathcal{T}_{1},\mathcal{T}_{2},\mathcal{T}_{4},\mathcal{T}_{5}$, and let $\mathcal{B}_{3}=\mathcal{T}_{3}$ be the cofinite topology regarded as a basis for itself.

::: pf

::: {.pf-step #lemma}
If for every $x$ and every basis element $B$ of $\mathcal{B}$ containing $x$ there is $B'\in\mathcal{B}'$ with $x\in B'\subset B$, then $\mathcal{T}(\mathcal{B})\subset\mathcal{T}(\mathcal{B}')$.

::: pf-proof
This is Lemma 13.3 : a topology is generated by its basis, so every $B\in\mathcal{B}$ is open in $\mathcal{T}(\mathcal{B}')$ under the stated condition, and every set of $\mathcal{T}(\mathcal{B})$, being a union of members of $\mathcal{B}$, is then open in $\mathcal{T}(\mathcal{B}')$.
:::

:::

::: {.pf-step #t3-in-t1}
$\mathcal{T}_{3}\subsetneq\mathcal{T}_{1}$.

::: pf-proof
Let $U\in\mathcal{T}_{3}$, so $\RR-U$ is finite or $\RR$. If $\RR-U=\RR$ then $U=\varnothing\in\mathcal{T}_{1}$. Otherwise list $\RR-U=\{x_{1}<\dots<x_{n}\}$; then $U=(-\infty,x_{1})\cup\bigcup_{k=1}^{n-1}(x_{k},x_{k+1})\cup(x_{n},\infty)$, and $(-\infty,x_{1})=\bigcup_{k\geq1}(x_{1}-k-1,x_{1}-k+1)$ is a union of members of $\mathcal{B}_{1}$, likewise $(x_{n},\infty)$, so $U$ is open in $\mathcal{T}_{1}$. The inclusion is proper: $(-1,1)\in\mathcal{T}_{1}$ has complement $(-\infty,-1]\cup[1,\infty)$, neither finite nor all of $\RR$, so $(-1,1)\notin\mathcal{T}_{3}$.
:::

:::

::: {.pf-step #t5-in-t1}
$\mathcal{T}_{5}\subsetneq\mathcal{T}_{1}$.

::: pf-proof
If $x\in(-\infty,a)\in\mathcal{B}_{5}$ then $x\in(x-1,a)\in\mathcal{B}_{1}$ and $(x-1,a)\subset(-\infty,a)$, so step [](#lemma){.pf-ref} gives the inclusion. It is proper: $-1\in(-2,0)\in\mathcal{B}_{1}$, while every member $(-\infty,a)$ of $\mathcal{B}_{5}$ containing $-1$ has $a>-1$ and hence contains $-3\notin(-2,0)$; so no $\mathcal{B}_{5}$-element at $-1$ lies in $(-2,0)$ and $(-2,0)\notin\mathcal{T}_{5}$.
:::

:::

::: {.pf-step #incomparable}
$\mathcal{T}_{3}$ and $\mathcal{T}_{5}$ are incomparable.

::: pf-proof
$\RR-\{0\}\in\mathcal{T}_{3}$ because its complement is finite. It is not in $\mathcal{T}_{5}$: a member $(-\infty,a)$ containing $1$ and lying in $\RR-\{0\}$ would contain $0<1$. So $\mathcal{T}_{3}\not\subset\mathcal{T}_{5}$. Conversely $(-\infty,0)\in\mathcal{T}_{5}$ has complement $[0,\infty)$, neither finite nor all of $\RR$, so it is not in $\mathcal{T}_{3}$ and $\mathcal{T}_{5}\not\subset\mathcal{T}_{3}$.
:::

:::

::: {.pf-step #t1-in-t2}
$\mathcal{T}_{1}\subsetneq\mathcal{T}_{2}$.

::: pf-proof
This is Lemma 13.4 : the $K$-topology contains the standard topology, because every basis element $(a,b)$ of $\mathcal{B}_{1}$ belongs to $\mathcal{B}_{2}$, and the inclusion is proper since $(-1,1)-K$ is open in $\mathcal{T}_{2}$ but not in $\mathcal{T}_{1}$.
:::

:::

::: {.pf-step #t2-in-t4}
$\mathcal{T}_{2}\subsetneq\mathcal{T}_{4}$.

::: pf-proof
Let $x\in B\in\mathcal{B}_{2}$. If $B=(a,b)$ then $x\in(a,x]\in\mathcal{B}_{4}$ and $(a,x]\subset(a,b)$. If $B=(a,b)-K$ then $a<x<b$ and $x\notin K$. For $x\leq0$ every $y\in(a,x]$ has $y\leq0$, so $y\notin K$ and $(a,x]\subset B$. For $x>0$ let $n$ be the least positive integer with $n>1/x$ and put $a_{0}=\max(a,1/n)<x$; then $x\in(a_{0},x]\subset(a,b)$, and a point $y\in(a_{0},x]$ cannot lie in $K$: if $y=1/m$ then $1/n\leq a_{0}<1/m$ gives $m<n$, while $m\leq1/x$ gives $1/m\geq x\geq y=1/m$, forcing $y=x\notin K$. So $(a_{0},x]\subset B$, and step [](#lemma){.pf-ref} gives the inclusion. It is proper: $-1\in(-2,-1]\in\mathcal{B}_{4}$, while a member $B=(a,b)$ or $(a,b)-K$ of $\mathcal{B}_{2}$ containing $-1$ has $a<-1<b$; if $b>0$ then $0\in B$ as $0\notin K$, and $0\notin(-2,-1]$; if $b\leq0$ then $y=(-1+b)/2$ satisfies $a<-1<y<b\leq0$, so $y\notin K$, $y\in B$ and $y\notin(-2,-1]$.
:::

:::

::: {.pf-step #t3-t5-in-t4}
$\mathcal{T}_{3}\subsetneq\mathcal{T}_{4}$ and $\mathcal{T}_{5}\subsetneq\mathcal{T}_{4}$.

::: pf-proof
Transitivity of inclusion applied to steps [](#t3-in-t1){.pf-ref}, [](#t5-in-t1){.pf-ref} and [](#t1-in-t2){.pf-ref}, [](#t2-in-t4){.pf-ref}: $\mathcal{T}_{3}\subset\mathcal{T}_{1}\subset\mathcal{T}_{2}\subset\mathcal{T}_{4}$ and $\mathcal{T}_{5}\subset\mathcal{T}_{1}\subset\mathcal{T}_{2}\subset\mathcal{T}_{4}$. Properness follows since each of the intermediate inclusions is proper.
:::

:::

::: {.pf-step}
The containments among the five topologies are exactly $\mathcal{T}_{3}\subsetneq\mathcal{T}_{1}\subsetneq\mathcal{T}_{2}\subsetneq\mathcal{T}_{4}$ and $\mathcal{T}_{5}\subsetneq\mathcal{T}_{1}$, with $\mathcal{T}_{3}$ and $\mathcal{T}_{5}$ incomparable.

::: pf-proof
Steps [](#t3-in-t1){.pf-ref}, [](#t5-in-t1){.pf-ref}, [](#t1-in-t2){.pf-ref}, [](#t2-in-t4){.pf-ref} give the chain and [](#incomparable){.pf-ref} the incomparability. Every listed inclusion is proper, so no two of the five coincide; by transitivity the containments recorded are all that hold, and the per-topology summary of the card follows: $\mathcal{T}_{1}$ contains $\mathcal{T}_{3}$ and $\mathcal{T}_{5}$ and no other, $\mathcal{T}_{2}$ contains $\mathcal{T}_{1},\mathcal{T}_{3},\mathcal{T}_{5}$, $\mathcal{T}_{4}$ contains all four others, and $\mathcal{T}_{3}$, $\mathcal{T}_{5}$ contain none of the others.
:::

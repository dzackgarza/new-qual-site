::: {.exercise}

Suppose that $i_2$ is surjective.

(a) Show that $j_1$ induces an epimorphism

$$
h: \pi_1(U, x_0)/M \to \pi_1(X, x_0),
$$

where $M$ is the least normal subgroup of $\pi_1(U, x_0)$ containing $i_1(\ker i_2)$.

(b) Show that $h$ is an isomorphism.
[Hint: Let $H = \pi_1(U, x_0)/M$. Let $\phi_1: \pi_1(U, x_0) \to H$ be the projection. Use the fact that $\pi_1(U \cap V, x_0)/\ker i_2$ is isomorphic to $\pi_1(V, x_0)$ to define a homomorphism $\phi_2: \pi_1(V, x_0) \to H$. Use Theorem 70.1 to define a left inverse for $h$.]
:::

::: {.solution}

Notation as in Theorem 70.1 (printed p. 426): $i_1,i_2,j_1,j_2$ induced by inclusions, $i=j_1i_1=j_2i_2$, and $i_2$ is onto. Put $H=\pi_1(U,x_0)/M$ and let $\phi_1=q:\pi_1(U,x_0)\to H$ be the quotient map.

::: pf

::: pf-step

$j_1$ is onto.

::: pf-proof

By §59, $\pi_1(X,x_0)$ is generated by the images of $j_1$ and $j_2$. For $v\in\pi_1(V,x_0)$, surjectivity of $i_2$ gives $u\in\pi_1(U\cap V)$ with $i_2(u)=v$, so $j_2(v)=j_2i_2(u)=j_1i_1(u)$ lies in the image of $j_1$. Hence the images of $j_2$ and $j_1$ agree as subgroups and generate $\pi_1(X)$, so $j_1$ is onto.

:::

:::

::: pf-step

$M\subseteq\ker j_1$, so $j_1$ induces $h:H\to\pi_1(X,x_0)$.

::: pf-proof

If $u\in\ker i_2$ then $j_1i_1(u)=j_2i_2(u)=j_2(1)=1$, so $i_1(\ker i_2)\subseteq\ker j_1$; since $\ker j_1$ is normal, it contains the least normal subgroup $M$ generated by that image. Hence $j_1$ factors through $q$, giving $h$ with $h\circ q=j_1$, and $h$ is onto because $j_1$ is.

:::

:::

::: pf-step

There is a homomorphism $\phi_2:\pi_1(V,x_0)\to H$ with $\phi_2\circ i_2=q\circ i_1$.

::: pf-proof

$i_2$ induces an isomorphism $\bar i_2:\pi_1(U\cap V,x_0)/\ker i_2\to\pi_1(V,x_0)$ whose inverse is $v\mapsto u\ker i_2$ for any $u$ with $i_2(u)=v$. Define $\phi_2(v)=q(i_1(u))$. It is well defined: if $i_2(u)=i_2(u')$ then $u'u^{-1}\in\ker i_2$, so $i_1(u'u^{-1})\in M$ and $q(i_1(u'))=q(i_1(u))$. It is a homomorphism as a composite of homomorphisms, and $\phi_2i_2(u)=q i_1(u)$ by construction.

:::

:::

::: pf-step

Theorem 70.1 gives $\Phi:\pi_1(X,x_0)\to H$ with $\Phi j_1=q$ and $\Phi j_2=\phi_2$.

::: pf-proof

The hypothesis of Theorem 70.1 is $\phi_1i_1=\phi_2i_2$, which is step 3 with $\phi_1=q$; so $\Phi$ exists.

:::

:::

::: pf-step

$\Phi\circ h=\mathrm{id}_H$.

::: pf-proof

Since $h q=j_1$, $\Phi h q=\Phi j_1=q=\mathrm{id}_H\circ q$, and $q$ is onto; hence $\Phi h=\mathrm{id}_H$.

:::

:::

::: pf-qed

$h$ is onto by step 2 and injective because it has a left inverse by step 5; so $h$ is an isomorphism.

:::

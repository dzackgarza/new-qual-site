::: {.exercise}

(a) Show that if $G_1$ and $G_2$ have finite presentations, so does $G_1 * G_2$.

(b) Show that if $\pi_1(U \cap V, x_0)$ is finitely generated and $\pi_1(U, x_0)$ and $\pi_1(V, x_0)$ have finite presentations, then $\pi_1(X, x_0)$ has a finite presentation.
[Hint: If $N'$ is a normal subgroup of $\pi_1(U, x_0) * \pi_1(V, x_0)$ that contains the elements $i_1(g_i)^{-1} i_2(g_i)$ where $g_i$ runs over a set of generators for $\pi_1(U \cap V, x_0)$, then $N'$ contains $i_1(g)^{-1} i_2(g)$ for arbitrary $g$.]
:::

::: {.solution}

::: pf

::: pf-step

(a) A finite presentation of $G_1$ and one of $G_2$ give a finite presentation of $G_1*G_2$.

::: pf-proof

Let $G_i=\langle X_i\mid R_i\rangle$ with $X_i,R_i$ finite; the meaning is that $G_i\cong F(X_i)/N_i$ where $N_i$ is the least normal subgroup of the free group $F(X_i)$ containing $R_i$. The free group on the disjoint union $X_1\sqcup X_2$ maps onto $G_1*G_2$. By Theorem 68.7 (printed p. 419) applied to $N_i\triangleleft G_i$ — and here $G_i=F(X_i)$ and $G_i/N_i$ — the kernel is the least normal subgroup generated by $R_1\cup R_2$. So $G_1*G_2\cong\langle X_1\sqcup X_2\mid R_1\sqcup R_2\rangle$, a finite presentation.

:::

:::

::: pf-step

(b) The hint's claim: if $N'$ contains $i_1(g_t)^{-1}i_2(g_t)$ for a generating set $\theset{g_t}$ of $\pi_1(U\cap V,x_0)$, then it contains $i_1(g)^{-1}i_2(g)$ for every $g$.

::: pf-proof

Let $\Gamma=\pi_1(U,x_0)*\pi_1(V,x_0)$ and let $\rho:\Gamma\to\Gamma/N'$ be the quotient map. By hypothesis $\rho i_1(g_t)=\rho i_2(g_t)$ for all $t$. Any $g$ is a word $g_t^{\pm1}\cdots$, and since $\rho i_1$ and $\rho i_2$ are homomorphisms agreeing on each $g_t^{\pm1}$, they agree on $g$: $\rho i_1(g)=\rho i_2(g)$, that is $i_1(g)^{-1}i_2(g)\in N'$.

:::

:::

::: pf-step

(b) $\pi_1(X,x_0)$ has a finite presentation.

::: pf-proof

By Theorem 70.2 (printed p. 431), $\pi_1(X,x_0)\cong\Gamma/N$ where $N$ is the least normal subgroup of $\Gamma$ containing all $i_1(g)^{-1}i_2(g)$, $g\in\pi_1(U\cap V,x_0)$. Let $N_0$ be the least normal subgroup containing the finitely many elements $i_1(g_t)^{-1}i_2(g_t)$ for a finite generating set $\theset{g_t}$, which exists by hypothesis. By step 2 applied to $N'=N_0$, $N_0$ contains every $i_1(g)^{-1}i_2(g)$, so $N\subseteq N_0$; and $N_0\subseteq N$ since $N$ contains the generators of $N_0$. So $N=N_0$ is normally generated by finitely many elements. By (a) the group $\Gamma$ has a finite presentation $\langle X\mid R\rangle$; adjoining the finitely many words representing the $i_1(g_t)^{-1}i_2(g_t)$ to $R$ presents $\Gamma/N$. Hence $\pi_1(X,x_0)$ is finitely presented.

:::

:::

::: pf-qed

Parts (a) and (b) are steps 1 and 3.

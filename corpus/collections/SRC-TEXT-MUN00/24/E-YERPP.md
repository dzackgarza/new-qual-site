::: {.exercise}

(a) Let $X$ and $Y$ be ordered sets in the order topology.
Show that if $f: X \to Y$ is order preserving and surjective, then $f$ is a homeomorphism.

(b) Let $X = Y = \RR_+$.
Given a positive integer $n$, show that the function $f(x) = x^n$ is order preserving and surjective.
Conclude that its inverse, the $n$th root function, is continuous.

(c) Let $X$ be the subspace $(-\infty, -1) \cup [0, \infty)$ of $\RR$.
Show that the function $f: X \to \RR$ defined by setting $f(x) = x + 1$ if $x < -1$, and $f(x) = x$ if $x \geq 0$, is order preserving and surjective.
Is $f$ a homeomorphism?
Compare with (a).

:::

::: {.solution}
The complete published solution is **"positron0802", *Solutions to Topology, Chapter 3* (1 January 2021), Exercise 24.7** (`tmp/sources/munkres-solutions-positron-ch3.pdf`); all three parts are theirs. What is supplied below is the reason the retained text leaves implicit, that an order-preserving map is injective because the definition is strict.

Throughout, an order-preserving map $f:X\to Y$ of ordered sets satisfies $x<x'\Rightarrow f(x)<f(x')$ (definition of a map preserving order, printed p. 25), so it is strictly increasing; the order topology on a set with more than one element is generated by the basis of open intervals, together with the half-open intervals at a smallest and at a largest element, if these exist (printed p. 84); and a bijection is a homeomorphism exactly when it and its inverse are continuous (printed p. 105). The exercise is on printed p. 158.

::: pf

::: {.pf-step #a}
(a) An order-preserving surjection $f:X\to Y$ of ordered sets in the order topology is a homeomorphism.

::: pf-proof

::: {.pf-step #bijection}
$f$ is a bijection, and $x<x'$ if and only if $f(x)<f(x')$.

::: pf-proof
If $x\neq x'$ then $x<x'$ or $x'<x$ by comparability, so $f(x)<f(x')$ or $f(x')<f(x)$; either way $f(x)\neq f(x')$, and $f$ is injective. Being surjective by hypothesis, $f$ is a bijection. For the equivalence, $x<x'$ gives $f(x)<f(x')$ by order preservation, and if $f(x)<f(x')$ then $x\neq x'$ and $x'<x$ would give $f(x')<f(x)$, so $x<x'$.

:::

:::

::: {.pf-step #basis}
For each basis element $B$ of the order topology on $X$, the set $f(B)$ is a basis element of the order topology on $Y$, and for each basis element $C$ of $Y$ the set $f^{-1}(C)$ is a basis element of $X$.

::: pf-proof
Three types, using step [](#bijection){.pf-ref}. An open interval: $f\big((a,b)\big)=(f(a),f(b))$, since $a<x<b$ is equivalent to $f(a)<f(x)<f(b)$ and $f$ is onto. A half-open interval at the smallest element $a_0$ of $X$, when it exists: $f(a_0)$ is the smallest element of $Y$, because every $y=f(x)$ with $x\neq a_0$ satisfies $a_0<x$ and hence $f(a_0)<y$; and $f\big([a_0,b)\big)=[f(a_0),f(b))$ by the equivalence again. A half-open interval at the largest element is the same with the order reversed. The preimage statement is the same computation read backwards, $f^{-1}\big((f(a),f(b))\big)=(a,b)$ and $f^{-1}\big([f(a_0),f(b))\big)=[a_0,b)$, because $f$ is a bijection preserving order both ways.

:::

:::

::: {.pf-step #continuous-open}
$f$ and $f^{-1}$ are continuous.

::: pf-proof
A map is continuous when the preimage of every basis element is open, since an open set is a union of basis elements (§18). By step [](#basis){.pf-ref}, $f^{-1}$ of each basis element of $Y$ is a basis element of $X$, hence open, so $f$ is continuous; and $f$ of each basis element of $X$ is a basis element of $Y$, so $f^{-1}$ is continuous. Since $f$ is a bijection, this says $f$ is a homeomorphism.

:::

:::

:::

:::

::: {.pf-step #b-order}
(b) On $X=Y=\RR_+$ the map $f(x)=x^{n}$ is order preserving.

::: pf-proof
Let $0<x<x'$. Then $x^{2}<xx'<(x')^{2}$, and inductively if $x^{k}<(x')^{k}$ then $x^{k+1}=x^{k}x<x^{k}x'<(x')^{k}x'=(x')^{k+1}$, the middle inequality using $x<x'$ and $x^{k}>0$. So $x^{n}<(x')^{n}$ for every positive integer $n$.

:::

:::

::: {.pf-step #b-surjective}
(b) $f(x)=x^{n}$ is surjective onto $\RR_+$.

::: pf-proof
$f(0)=0$, so let $y>0$ and put $S=\{t\ge0:t^{n}<y\}$. Then $0\in S$, and $S$ is bounded above by $\max\{1,y\}$, since $t>1$ and $t\ge y$ give $t^{n}\ge t>y$. So $s=\sup S$ exists. If $s^{n}<y$, then $(s+\varepsilon)^{n}<y$ for all small $\varepsilon>0$, because $(s+\varepsilon)^{n}\to s^{n}$ as $\varepsilon\to0$ by the binomial expansion and $s^{n}<y$; this puts $s+\varepsilon$ in $S$, contradicting that $s$ is an upper bound. If $s^{n}>y$, then $(s-\varepsilon)^{n}>y$ for small $\varepsilon>0$ with $s-\varepsilon\ge0$, so $s-\varepsilon$ is an upper bound on $S$, contradicting minimality. Hence $s^{n}=y$ and $f(s)=y$.

:::

:::

::: {.pf-step #b-conclusion}
(b) The $n$-th root function is continuous.

::: pf-proof
By steps [](#b-order){.pf-ref} and [](#b-surjective){.pf-ref} the map $x\mapsto x^{n}$ is an order-preserving surjection of $\RR_+$, an ordered set in the order topology, onto itself; by step [](#a){.pf-ref} it is a homeomorphism, so its inverse $y\mapsto y^{1/n}$ is continuous.

:::

:::

::: {.pf-step #c}
(c) On $X=(-\infty,-1)\cup[0,\infty)$ with the subspace topology, the map $f(x)=x+1$ for $x<-1$ and $f(x)=x$ for $x\ge0$ is an order-preserving surjection onto $\RR$ that is not a homeomorphism.

::: pf-proof

::: {.pf-step #c-order}
$f$ is order preserving and surjective.

::: pf-proof
On each piece $f$ is strictly increasing, so for $x<x'$ within one piece $f(x)<f(x')$. If $x<-1\le x'$, then $f(x)=x+1<0\le x'=f(x')$, so again $f(x)<f(x')$. Hence $f$ is order preserving. For $y<0$ we have $y-1<-1$ and $f(y-1)=y$; for $y\ge0$ we have $f(y)=y$. So $f$ is surjective.

:::

:::

::: {.pf-step #c-not-homeo}
$f$ is not a homeomorphism.

::: pf-proof
The set $[0,1)$ is open in $X$, since $[0,1)=(-1,1)\cap X$. Its image $f\big([0,1)\big)=[0,1)$ is not open in $\RR$, because $0$ is a boundary point of it in the usual topology. Since $f$ is a bijection (it is injective on each piece and the two images $(-\infty,0)$ and $[0,\infty)$ are disjoint), a homeomorphism would carry the open set $[0,1)$ to an open set; it does not, so $f^{-1}$ is not continuous and $f$ is not a homeomorphism.

:::

:::

::: {.pf-step #c-compare}
The comparison with (a) is that $X$ does not carry the order topology of its own order.

::: pf-proof
In the order topology of the ordered set $X$, the basis consists of intervals with endpoints in $X$; since $0$ is neither the smallest element of $X$ nor isolated from below in the order, a basis element containing $0$ is an interval $(a,b)$ with $a\in(-\infty,-1)$, and such an interval meets $(-\infty,-1)$. So $[0,1)$ is not open in the order topology of $X$, although it is open in the subspace topology. Hence the hypothesis of (a) fails for this $f$: $X$ is an ordered set whose topology here is not the order topology, which is exactly the point of the exercise.

:::

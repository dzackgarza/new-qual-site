::: {.exercise}

Show that if $U$ is an open connected subspace of $\RR^2$, then $U$ is path connected.
[Hint: Show that given $x_0 \in U$, the set of points that can be joined to $x_0$ by a path in $U$ is both open and closed in $U$.]
:::

::: {.solution}

The argument is **"positron0802"**, *Solutions to Topology, Chapter 3* (1 January 2021), Exercise 24.10 (`tmp/sources/munkres-solutions-positron-ch3.pdf`); it carries out the book's hint, and the statement was checked against Munkres, *Topology* (2000), §24 Exercise 10, with the definitions of path and of path connectedness on printed p. 155, the path connectedness of balls on printed p. 156, and the pasting lemma, Theorem 18.3. The concatenation of paths used below is the standard one: the path $f$ from $x$ to $y$ on $[0,1]$ followed by the path $g$ from $y$ to $z$ on $[0,1]$ is continuous on $[0,2]$ by the pasting lemma and is a path from $x$ to $z$.

::: pf

::: {.pf-step #component}
Fix $x\in U$ and let $C_{x}\coloneqq\theset{y\in U\mid\text{there is a path in }U\text{ from }x\text{ to }y}$. Then $x\in C_{x}$.

::: pf-proof
The constant path $t\mapsto x$ on $[0,1]$ is continuous and joins $x$ to itself.
:::

:::

::: {.pf-step #open}
$C_{x}$ is open in $U$.

:::: pf-proof

::: {.pf-step #ball}
For $y\in C_{x}$ there is $\varepsilon>0$ with the open ball $B(y,\varepsilon)$ contained in $U$, and $B(y,\varepsilon)$ is path connected.

::: pf-proof
$U$ is open in $\RR^{2}$, so it contains a ball about each of its points. An open ball is path connected by the straight-line path $t\mapsto(1-t)u+tv$: for $u,v\in B(y,\varepsilon)$ and $t\in[0,1]$ one has $\norm{(1-t)u+tv-y}\leq(1-t)\norm{u-y}+t\norm{v-y}<\varepsilon$ (printed p. 156).
:::

:::

::: {.pf-step #ball-in-component}
$B(y,\varepsilon)\subset C_{x}$, so $C_{x}$ contains a neighbourhood in $U$ of each of its points.

::: pf-proof
Let $z\in B(y,\varepsilon)$. The hypothesis $y\in C_{x}$ gives a path in $U$ from $x$ to $y$; the segment from $y$ to $z$ stays in $B(y,\varepsilon)\subset U$ by step [](#ball){.pf-ref}; concatenating the two gives a path in $U$ from $x$ to $z$, so $z\in C_{x}$.
:::

:::

::::

:::

::: {.pf-step #closed}
$U-C_{x}$ is open in $U$.

::: pf-proof
Let $z\in U-C_{x}$ and choose $\varepsilon>0$ with $B(z,\varepsilon)\subset U$. If some $w\in B(z,\varepsilon)$ lay in $C_{x}$, the segment from $w$ to $z$ would be a path in $B(z,\varepsilon)\subset U$, and concatenating a path from $x$ to $w$ with it would give a path in $U$ from $x$ to $z$, contradicting $z\notin C_{x}$. Hence $B(z,\varepsilon)\subset U-C_{x}$, so $U-C_{x}$ is open in $U$.
:::

:::

::: {.pf-step #equals-U}
$C_{x}=U$.

::: pf-proof
$C_{x}$ is a nonempty subset of $U$ that is both open and closed in $U$ (steps [](#open){.pf-ref}, [](#closed){.pf-ref}, [](#component){.pf-ref}). If $C_{x}$ were a proper nonempty subset, then $C_{x}$ and $U-C_{x}$ would be disjoint nonempty open sets with union $U$, a separation of $U$; since $U$ is connected, no such pair exists, so $C_{x}=U$.
:::

:::

::: pf-step
Therefore $U$ is path connected.

::: pf-proof
With $x\in U$ arbitrary, step [](#equals-U){.pf-ref} says every point of $U$ can be joined to $x$ by a path in $U$; since $x$ was arbitrary, every pair of points of $U$ can be so joined, which is path connectedness.
:::

::: {.exercise}

Show that if $U$ is an open connected subspace of $\mathbb{R}^2$, then $U$ is path connected.
[Hint: Show that given $x_0 \in U$, the set of points that can be joined to $x_0$ by a path in $U$ is both open and closed in $U$.]
:::

::: solution
**Goal:** Prove that every open connected subspace $U \subseteq \mathbb{R}^2$ is path-connected.

<1>1. Setting and path-component definition:
    If $U = \varnothing$, it is vacuously path-connected.
    Assume $U \neq \varnothing$, and fix an arbitrary basepoint $x_0 \in U$.
    Define the path-component of $x_0$ in $U$:
    $$C = \{x \in U \mid \text{there exists a continuous path in } U \text{ from } x_0 \text{ to } x\}.$$
    We show that $C$ is a non-empty clopen subset of $U$.

<1>2. $C$ is open in $U$:
    *Proof:*
    <2>1. Let $x \in C$. Since $U$ is open in $\mathbb{R}^2$, there exists $\varepsilon > 0$ such that the Euclidean open ball $B(x, \varepsilon) \subseteq U$.
    <2>2. The open ball $B(x, \varepsilon)$ is convex, so for any $y \in B(x, \varepsilon)$, the straight-line segment $[x, y]$ is a continuous path in $B(x, \varepsilon) \subseteq U$.
    <2>3. Since $x \in C$, there is a continuous path $\gamma: [0, 1] \to U$ from $x_0$ to $x$.
    <2>4. The concatenation $\gamma * [x, y]$ is a continuous path in $U$ from $x_0$ to $y$, so $y \in C$.
    <2>5. Thus $B(x, \varepsilon) \subseteq C$, proving $C$ is open in $U$.

<1>3. $C$ is closed in $U$ ($U \setminus C$ is open in $U$):
    *Proof:*
    <2>1. Let $z \in U \setminus C$.
    <2>2. Since $U$ is open, choose $\delta > 0$ such that $B(z, \delta) \subseteq U$.
    <2>3. Suppose for contradiction that there exists a point $w \in B(z, \delta) \cap C$.
    <2>4. Since $w \in C$, there is a path in $U$ from $x_0$ to $w$.
    <2>5. Concatenating this path with the straight line segment $[w, z] \subset B(z, \delta) \subseteq U$ produces a continuous path in $U$ from $x_0$ to $z$.
    <2>6. This would imply $z \in C$, contradicting $z \in U \setminus C$.
    <2>7. Thus $B(z, \delta) \cap C = \varnothing$, so $B(z, \delta) \subseteq U \setminus C$, proving $U \setminus C$ is open in $U$.

<1>4. Connectedness argument and conclusion:
    *Proof:*
    <2>1. The constant path at $x_0$ proves $x_0 \in C$, so $C \neq \varnothing$.
    <2>2. By <1>2 and <1>3, $C$ is both open and closed in the subspace topology of $U$.
    <2>3. Since $U$ is connected, the only non-empty clopen subset of $U$ is $U$ itself.
    <2>4. Therefore $C = U$, so every point of $U$ can be joined to $x_0$ by a path in $U$.
    <2>5. Hence $U$ is path-connected. Q.E.D.
:::

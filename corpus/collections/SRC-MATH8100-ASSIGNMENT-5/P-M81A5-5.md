::: {.problem}
For $f,g\in L^1([0,1])$, set $F(x)=\int_0^xf$ and $G(x)=\int_0^xg$.
Prove that
$$
\int_0^1F(x)g(x)\,dx=F(1)G(1)-\int_0^1f(x)G(x)\,dx.
$$
:::

::: {.solution}

::: pf

::: pf-step
Absolute integrability on the product space:

::: pf-proof

::: pf-step
Define the integrand $h(t, x) = f(t) g(x) \mathbf{1}_{\{0 \le t \le x \le 1\}}$ on $[0, 1] \times [0, 1]$.
$h$ is Lebesgue measurable on $[0, 1]^2$.

::: pf-proof
product of measurable functions and indicator of measurable triangle.
:::

:::

::: pf-step
Check absolute integrability using Tonelli’s Theorem:
\[
\int_0^1 \left( \int_0^1 |h(t, x)| \, dt \right) dx = \int_0^1 |g(x)| \left( \int_0^x |f(t)| \, dt \right) dx
\le \int_0^1 |g(x)| \|f\|_{L^1} \, dx = \|f\|_{L^1} \|g\|_{L^1} < \infty.
\]
Thus $h \in L^1([0, 1] \times [0, 1])$.

::: pf-proof
Tonelli's Theorem and $f, g \in L^1([0, 1])$.
:::

:::

:::

:::

::: {.pf-step #evaluate-via-fubini}
Evaluate the double integral via iterated integrals (Fubini’s Theorem):

::: pf-proof

::: pf-step
By Fubini’s Theorem, the double integral $I = \iint_{\{0 \le t \le x \le 1\}} f(t) g(x) \, dt \, dx$ can be evaluated in either order.

::: pf-proof
Fubini's Theorem for $L^1$ functions.
:::

:::

::: pf-step
Integrating with respect to $t$ first:
\[
I = \int_0^1 g(x) \left( \int_0^x f(t) \, dt \right) dx = \int_0^1 F(x) g(x) \, dx.
\]

::: pf-proof
definition $F(x) = \int_0^x f(t) \, dt$.
:::

:::

::: {.pf-step #fubini-other-order}
Integrating with respect to $x$ first (where the region is $\{(t, x) \mid 0 \le t \le 1, \, t \le x \le 1\}$):
\[
I = \int_0^1 f(t) \left( \int_t^1 g(x) \, dx \right) dt.
\]

::: pf-proof
changing order of integration over the triangle.
:::

:::

:::

:::

::: {.pf-step #relate-to-F1-G1}
Relate the second iterated integral to $F(1), G(1)$ and $G(t)$:

::: pf-proof

::: pf-step
For each $t \in [0, 1]$:
\[
\int_t^1 g(x) \, dx = \int_0^1 g(x) \, dx - \int_0^t g(x) \, dx = G(1) - G(t).
\]

::: pf-proof
additivity of Lebesgue integrals.
:::

:::

::: pf-step
Substituting this into the formula from step [](#fubini-other-order){.pf-ref}:
\[
I = \int_0^1 f(t) \big( G(1) - G(t) \big) \, dt = G(1) \int_0^1 f(t) \, dt - \int_0^1 f(t) G(t) \, dt = F(1) G(1) - \int_0^1 f(x) G(x) \, dx.
\]

::: pf-proof
linearity of integration and renaming dummy variable $t$ to $x$.
:::

:::

:::

:::

::: pf-qed
Conclusion:
Equating the expressions for $I$ in step [](#evaluate-via-fubini){.pf-ref} and step [](#relate-to-F1-G1){.pf-ref} yields:
\[
\int_0^1 F(x) g(x) \, dx = F(1) G(1) - \int_0^1 f(x) G(x) \, dx.
\]
:::

::: problem
For $f,g\in L^1([0,1])$, set $F(x)=\int_0^xf$ and $G(x)=\int_0^xg$.
Prove that
$$
\int_0^1F(x)g(x)\,dx=F(1)G(1)-\int_0^1f(x)G(x)\,dx.
$$
:::

::: {.solution}
<1>1. Absolute integrability on the product space:
<2>1. Define the integrand $h(t, x) = f(t) g(x) \mathbf{1}_{\{0 \le t \le x \le 1\}}$ on $[0, 1] \times [0, 1]$.
$h$ is Lebesgue measurable on $[0, 1]^2$.
::: {.proof}
product of measurable functions and indicator of measurable triangle.
:::
<2>2. Check absolute integrability using Tonelli’s Theorem:
\[
\int_0^1 \left( \int_0^1 |h(t, x)| \, dt \right) dx = \int_0^1 |g(x)| \left( \int_0^x |f(t)| \, dt \right) dx
\le \int_0^1 |g(x)| \|f\|_{L^1} \, dx = \|f\|_{L^1} \|g\|_{L^1} < \infty.
\]
Thus $h \in L^1([0, 1] \times [0, 1])$.
::: {.proof}
Tonelli's Theorem and $f, g \in L^1([0, 1])$.
:::

<1>2. Evaluate the double integral via iterated integrals (Fubini’s Theorem):
<2>1. By Fubini’s Theorem, the double integral $I = \iint_{\{0 \le t \le x \le 1\}} f(t) g(x) \, dt \, dx$ can be evaluated in either order.
::: {.proof}
Fubini's Theorem for $L^1$ functions.
:::
<2>2. Integrating with respect to $t$ first:
\[
I = \int_0^1 g(x) \left( \int_0^x f(t) \, dt \right) dx = \int_0^1 F(x) g(x) \, dx.
\]
::: {.proof}
definition $F(x) = \int_0^x f(t) \, dt$.
:::
<2>3. Integrating with respect to $x$ first (where the region is $\{(t, x) \mid 0 \le t \le 1, \, t \le x \le 1\}$):
\[
I = \int_0^1 f(t) \left( \int_t^1 g(x) \, dx \right) dt.
\]
::: {.proof}
changing order of integration over the triangle.
:::

<1>3. Relate the second iterated integral to $F(1), G(1)$ and $G(t)$:
<2>1. For each $t \in [0, 1]$:
\[
\int_t^1 g(x) \, dx = \int_0^1 g(x) \, dx - \int_0^t g(x) \, dx = G(1) - G(t).
\]
::: {.proof}
additivity of Lebesgue integrals.
:::
<2>2. Substituting this into the formula from <2>3:
\[
I = \int_0^1 f(t) \big( G(1) - G(t) \big) \, dt = G(1) \int_0^1 f(t) \, dt - \int_0^1 f(t) G(t) \, dt = F(1) G(1) - \int_0^1 f(x) G(x) \, dx.
\]
::: {.proof}
linearity of integration and renaming dummy variable $t$ to $x$.
:::

<1>4. Conclusion:
Equating the expressions for $I$ in <1>2 and <1>3 yields:
\[
\int_0^1 F(x) g(x) \, dx = F(1) G(1) - \int_0^1 f(x) G(x) \, dx.
\]
Q.E.D.
::: {.proof}
<1>2 and <1>3.
:::
:::

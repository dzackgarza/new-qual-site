::: {.problem}
For $f\in L^1(\mathbb R)$ and $h>0$, set $A_hf(x)=(2h)^{-1}\int_{x-h}^{x+h}f(y)\,dy$.

1. Prove that $\|A_hf\|_1\leq\|f\|_1$.

2. Prove that $A_hf\to f$ in $L^1$ as $h\to0^+$.
:::

::: {.solution}
**Part 1.**

::: pf

::: {.pf-step #Ahf-norm-bound-setup}
$\|A_h f\|_1 = \int_{\RR} \left| \frac{1}{2h}\int_{x-h}^{x+h} f(y)\, dy \right| dx \le \frac{1}{2h}\int_{\RR}\int_{x-h}^{x+h} |f(y)|\, dy\, dx$.

::: pf-proof
triangle inequality and Fubini–Tonelli (nonnegative integrand).
:::

:::

::: {.pf-step #interchange-order-equals-norm}
$\frac{1}{2h}\int_{\RR}\int_{x-h}^{x+h} |f(y)|\, dy\, dx = \frac{1}{2h}\int_{\RR} |f(y)| \int_{y-h}^{y+h} dx\, dy = \frac{1}{2h}\int_{\RR} |f(y)| \cdot 2h\, dy = \|f\|_1$.

::: pf-proof
interchange the order of integration; the inner integral over $x$ has length $2h$.
:::

:::

::: {.pf-step #Ahf-le-f-norm}
Hence $\|A_h f\|_1 \le \|f\|_1$.

::: pf-proof
step [](#Ahf-norm-bound-setup){.pf-ref} and step [](#interchange-order-equals-norm){.pf-ref}.
:::

:::

:::

**Part 2.**

::: pf

::: {.pf-step #suffices-dense-subset}
It suffices to show $A_h f \to f$ in $L^1$ for $f$ in a dense subset, since the $A_h$ are uniformly bounded (by part 1).

::: pf-proof
the operators $A_h$ have operator norm $\le 1$ (part 1), so convergence on a dense set extends to all of $L^1$.
:::

:::

::: {.pf-step #Cc-uniform-convergence}
For $f \in C_c(\RR)$ (continuous with compact support), $A_h f \to f$ uniformly, hence in $L^1$.

::: pf-proof
Since $f$ is uniformly continuous,
\[
|A_hf(x)-f(x)|
\le \frac1{2h}\int_{x-h}^{x+h}|f(y)-f(x)|\,dy
\le \sup_{|y-x|\le h}|f(y)-f(x)|,
\]
and the last quantity tends to $0$ uniformly in $x$ as $h\to0$.

If $\operatorname{supp}f\subset[-R,R]$, then for every $0<h\le1$,
\[
\operatorname{supp}(A_hf)\subset[-R-1,R+1].
\]
Hence for such $h$,
\[
\|A_hf-f\|_1
\le (2R+2)\|A_hf-f\|_\infty\longrightarrow0.
\]
:::

:::

::: {.pf-step #Cc-dense-in-L1}
$C_c(\RR)$ is dense in $L^1(\RR)$.

::: pf-proof
standard density result.
:::

:::

::: {.pf-step #Ahf-to-f-all-f}
Hence $A_h f \to f$ in $L^1$ for all $f \in L^1$.

::: pf-proof
steps [](#suffices-dense-subset){.pf-ref}, [](#Cc-uniform-convergence){.pf-ref}, and [](#Cc-dense-in-L1){.pf-ref}.
:::

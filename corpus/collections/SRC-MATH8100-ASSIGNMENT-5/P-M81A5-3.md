::: problem
Prove that the function equal to $x^{1/3}(1+xy)^{-3/2}$ when $0\leq x\leq y$, and zero otherwise, belongs to $L^1(\mathbb R^2)$.
:::

::: {.solution}
<1>1. Let $f(x, y) = x^{1/3}(1+xy)^{-3/2}$ on the region $0 \le x \le y$, and $0$ elsewhere.
::: {.proof}
setup.
:::

<1>2. $f \ge 0$, so it suffices to show $\iint f < \infty$.
::: {.proof}
nonnegativity.
:::

<1>3. $\iint_{\RR^2} f\, dx\, dy = \int_0^\infty \int_0^y x^{1/3}(1+xy)^{-3/2}\, dx\, dy$.
::: {.proof}
the region $0 \le x \le y$ (with $y \ge 0$).
:::

<1>4. For fixed $y$, substitute $u = xy$ (so $x = u/y$, $dx = du/y$):
$$\int_0^y x^{1/3}(1+xy)^{-3/2}\, dx = \int_0^{y^2} \left(\frac{u}{y}\right)^{1/3}(1+u)^{-3/2}\frac{du}{y} = y^{-4/3}\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du.$$
::: {.proof}
change of variables.
:::

<1>5. $\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du \le \int_0^\infty u^{1/3}(1+u)^{-3/2}\, du < \infty$.
::: {.proof}
the integral $\int_0^\infty u^{1/3}(1+u)^{-3/2}\, du$ converges (near $0$ it behaves like $u^{1/3}$, and near $\infty$ like $u^{1/3 - 3/2} = u^{-7/6}$, both integrable).
:::

<1>6. Hence $\iint f = \int_0^\infty y^{-4/3}\left(\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du\right) dy$.
::: {.proof}
<1>3 and <1>4.
:::

<1>7. This integral converges: near $y = 0$, the inner integral is $O(y^{2 \cdot 4/3}) = O(y^{8/3})$ (since $\int_0^{y^2} u^{1/3}\, du = \frac{3}{4}y^{8/3}$), so the integrand is $O(y^{-4/3} \cdot y^{8/3}) = O(y^{4/3})$, integrable near $0$; near $y = \infty$, the inner integral is bounded (by <1>5), so the integrand is $O(y^{-4/3})$, integrable near $\infty$.
::: {.proof}
asymptotic analysis.
:::

<1>8. Hence $f \in L^1(\RR^2)$.
::: {.proof}
<1>7.
:::

<1>9. Q.E.D.
::: {.proof}
<1>8.
:::
:::

::: {.problem}
Prove that the function equal to $x^{1/3}(1+xy)^{-3/2}$ when $0\leq x\leq y$, and zero otherwise, belongs to $L^1(\mathbb R^2)$.
:::

::: {.solution}

::: pf

::: pf-step
Let $f(x, y) = x^{1/3}(1+xy)^{-3/2}$ on the region $0 \le x \le y$, and $0$ elsewhere.

::: pf-proof
setup.
:::

:::

::: pf-step
$f \ge 0$, so it suffices to show $\iint f < \infty$.

::: pf-proof
nonnegativity.
:::

:::

::: {.pf-step #iterated-integral-form}
$\iint_{\RR^2} f\, dx\, dy = \int_0^\infty \int_0^y x^{1/3}(1+xy)^{-3/2}\, dx\, dy$.

::: pf-proof
the region $0 \le x \le y$ (with $y \ge 0$).
:::

:::

::: {.pf-step #change-of-variables}
For fixed $y$, substitute $u = xy$ (so $x = u/y$, $dx = du/y$):
$$\int_0^y x^{1/3}(1+xy)^{-3/2}\, dx = \int_0^{y^2} \left(\frac{u}{y}\right)^{1/3}(1+u)^{-3/2}\frac{du}{y} = y^{-4/3}\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du.$$

::: pf-proof
change of variables.
:::

:::

::: {.pf-step #inner-integral-converges}
$\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du \le \int_0^\infty u^{1/3}(1+u)^{-3/2}\, du < \infty$.

::: pf-proof
the integral $\int_0^\infty u^{1/3}(1+u)^{-3/2}\, du$ converges (near $0$ it behaves like $u^{1/3}$, and near $\infty$ like $u^{1/3 - 3/2} = u^{-7/6}$, both integrable).
:::

:::

::: pf-step
Hence $\iint f = \int_0^\infty y^{-4/3}\left(\int_0^{y^2} u^{1/3}(1+u)^{-3/2}\, du\right) dy$.

::: pf-proof
step [](#iterated-integral-form){.pf-ref} and step [](#change-of-variables){.pf-ref}.
:::

:::

::: {.pf-step #outer-integral-converges}
This integral converges: near $y = 0$, the inner integral is $O(y^{2 \cdot 4/3}) = O(y^{8/3})$ (since $\int_0^{y^2} u^{1/3}\, du = \frac{3}{4}y^{8/3}$), so the integrand is $O(y^{-4/3} \cdot y^{8/3}) = O(y^{4/3})$, integrable near $0$; near $y = \infty$, the inner integral is bounded (by step [](#inner-integral-converges){.pf-ref}), so the integrand is $O(y^{-4/3})$, integrable near $\infty$.

::: pf-proof
asymptotic analysis.
:::

:::

::: {.pf-step #f-in-L1}
Hence $f \in L^1(\RR^2)$.

::: pf-proof
step [](#outer-integral-converges){.pf-ref}.
:::

:::

Step [](#f-in-L1){.pf-ref}.
:::

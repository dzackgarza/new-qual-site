::: {.problem}
Let $\mathbb { F } _ { p }$ be the field of p elements.
Let $\operatorname { S L } _ { 2 } ( \mathbb { F } _ { p } )$ be the group of $2 \times 2$ matrices over $\mathbb { F } _ { p }$ of determinant 1. Let G be a normal subgroup of $\operatorname { S L } _ { 2 } ( \mathbb { F } _ { p } )$ . Suppose G contains a non-identity element $\gamma$ that fixes a nonzero vector v. Show that any $\gamma ^ { \prime } \in \mathrm { S L } _ { 2 } ( \mathbb { F } _ { p } )$ that fixes a nonzero vector $v ^ { \prime }$ belongs to $G .$
:::

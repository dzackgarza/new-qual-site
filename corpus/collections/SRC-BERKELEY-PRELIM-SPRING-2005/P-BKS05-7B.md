::: {.problem}
Let $\mathbb { F } _ { p }$ be the field of p elements.
Let $\operatorname { S L } _ { 2 } ( \mathbb { F } _ { p } )$ be the group of $2 \times 2$ matrices over $\mathbb { F } _ { p }$ of determinant 1. Let G be a normal subgroup of $\operatorname { S L } _ { 2 } ( \mathbb { F } _ { p } )$ . Suppose G contains a non-identity element $\gamma$ that fixes a nonzero vector v. Show that any $\gamma ^ { \prime } \in \mathrm { S L } _ { 2 } ( \mathbb { F } _ { p } )$ that fixes a nonzero vector $v ^ { \prime }$ belongs to $G .$
:::

::: {.solution}
For each nonzero vector $u\in\FF_p^2$, set
$$
S_u\coloneqq
\{\sigma\in\SL_2(\FF_p):\sigma u=u\}.
$$

::: pf

::: {.pf-step #stabilizer-v-in-g}
The stabilizer $S_v$ is contained in $G$.

::: pf-proof
Choose $w\in\FF_p^2$ such that $(v,w)$ is a basis. Since $\gamma v=v$
and $\det\gamma=1$, the matrix of $\gamma$ in this basis has the form
$$
\begin{pmatrix}
1&c\\
0&1
\end{pmatrix}
$$
for some $c\in\FF_p$. Because $\gamma$ is not the identity, $c\neq0$.

Every $\sigma\in S_v$ likewise has matrix
$$
\begin{pmatrix}
1&t\\
0&1
\end{pmatrix}
$$
for some $t\in\FF_p$: fixing $v$ determines the first column, and
$\det\sigma=1$ forces the lower-right entry to be $1$. Since $c\neq0$,
there is an integer $k$ such that $t=kc$ in $\FF_p$. Therefore
$$
\sigma
=
\begin{pmatrix}
1&kc\\
0&1
\end{pmatrix}
=
\gamma^k.
$$
Thus every element of $S_v$ belongs to the subgroup generated by $\gamma$,
which is contained in $G$.
:::

:::

::: {.pf-step #stabilizer-u-in-g}
For every nonzero $u\in\FF_p^2$, one has $S_u\subseteq G$.

::: pf-proof
Choose $w$ as in step [](#stabilizer-v-in-g){.pf-ref}. Choose any $u_0$ such that $(u,u_0)$ is a
basis, and rescale $u_0$ to a vector $w'$ satisfying
$$
\det(u,w')=\det(v,w).
$$
Let $\rho$ be the unique linear map with
$$
\rho(v)=u,
\qquad
\rho(w)=w'.
$$
Then
$$
\det\rho
=
\frac{\det(u,w')}{\det(v,w)}
=
1,
$$
so $\rho\in\SL_2(\FF_p)$.

Conjugation by $\rho$ carries the stabilizer of $v$ to the stabilizer of
$u$:
$$
S_u=\rho S_v\rho^{-1}.
$$
Indeed, an element fixes $v$ exactly when its conjugate by $\rho$ fixes
$\rho(v)=u$. By step [](#stabilizer-v-in-g){.pf-ref}, $S_v\subseteq G$, and normality of $G$ gives
$$
S_u
=
\rho S_v\rho^{-1}
\subseteq
\rho G\rho^{-1}
=
G.
$$
:::

:::

::: {.pf-step #gammaprime-in-g}
The element $\gamma'$ belongs to $G$.

::: pf-proof
By hypothesis, $\gamma'$ fixes the nonzero vector $v'$, so
$$
\gamma'\in S_{v'}.
$$
Applying step [](#stabilizer-u-in-g){.pf-ref} with $u=v'$ gives $S_{v'}\subseteq G$, hence
$\gamma'\in G$.
:::

:::

::: pf-qed
Step [](#gammaprime-in-g){.pf-ref} is the required conclusion.
:::

::: {.problem}
(a) Let $( a _ { n } ) _ { 1 } ^ { \infty }$ be a sequence in R such that

$$
\sum _ { n = 1 } ^ { \infty } \left| a _ { n + 1 } - a _ { n } \right| < \infty .
$$

Prove that $( a _ { n } ) _ { 1 } ^ { \infty }$ is a Cauchy sequence.

(b) Is the converse true? Give a proof or a counterexample.
:::

::: {.problem}
For every positive integer n, define $[ n ] _ { q } = q ^ { n - 1 } { + } q ^ { n - 2 } { + } \cdot \cdot \cdot { + } q { + } 1$ . Prove that $[ 1 ] _ { q } [ 2 ] _ { q } \cdot \cdot \cdot [ r ] _ { q }$ divides $[ k + \bar { 1 } ] _ { q } [ k + 2 ] _ { q } \cdot \cdot \cdot [ k + r ] _ { q }$ in the polynomial ring $\mathbb { Z } [ q ]$ , for all positive integers k and r.
:::

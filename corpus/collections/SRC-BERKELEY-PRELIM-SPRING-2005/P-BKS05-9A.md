::: {.problem}
Let $f \colon  { \mathbb { R } } ^ { 2 } \to$ R be an infinitely differentiable function that is zero outside some bounded subset of $\mathbb { R } ^ { 2 }$ . Prove that

$$
\operatorname* { l i m } _ { \epsilon \to 0 } \int \int _ { x ^ { 2 } + y ^ { 2 } \geq \epsilon ^ { 2 } } { \frac { f ( x , y ) } { ( x + i y ) ^ { 3 } } } d x d y
$$

exists.
:::

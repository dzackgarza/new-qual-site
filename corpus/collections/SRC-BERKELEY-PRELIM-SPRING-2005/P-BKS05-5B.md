::: {.problem}
Let $\mathbb { Q } ( x )$ be the field of rational functions in one variable over $\mathbb { Q }$ . Let i : $\mathbb { Q } ( x ) \to \mathbb { Q } ( x )$ be the unique field automorphism such that $i ( x ) = x ^ { - 1 }$ Prove that the fixed subfield $\{ r \in \mathbb { Q } ( x ) : i ( r ) = r \}$ is equal to $\mathbb { Q } ( x + x ^ { - 1 } )$ .
:::

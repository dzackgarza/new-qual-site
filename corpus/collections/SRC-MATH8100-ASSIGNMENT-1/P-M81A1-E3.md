::: problem
Let $f:[a,b]\to\mathbb R$ be bounded.
Prove that $f$ is Riemann integrable if and only if its discontinuity set has measure zero.
:::

::: {.solution}
Let
\[
\omega_f(x)
=\lim_{r\downarrow0}
\sup\{|f(y)-f(z)|:y,z\in(x-r,x+r)\cap[a,b]\}
\]
be the oscillation of $f$ at $x$, and for $\alpha>0$ set
\[
A_\alpha=\{x\in[a,b]:\omega_f(x)\ge\alpha\}.
\]
The oscillation sets $A_\alpha$ are closed, and
\[
D_f=\{x:f\text{ is discontinuous at }x\}
=\bigcup_{n=1}^{\infty}A_{1/n}.
\]

<1>1. If $m(D_f)=0$, then $f$ is Riemann integrable.
::: {.proof}
Let $|f|\le M$. If $M=0$, the conclusion is immediate, so assume $M>0$. Fix $\varepsilon>0$. Choose $\alpha>0$ so small that
\[
\alpha(b-a)<\frac\varepsilon2.
\]
Since $A_\alpha\subset D_f$ and $A_\alpha$ is compact of measure zero, choose a finite union $O$ of open intervals such that
\[
A_\alpha\subset O,
\qquad
m(O)<\frac{\varepsilon}{4M}.
\]

Set
\[
K=[a,b]\setminus O.
\]
For every $x\in K$, one has $\omega_f(x)<\alpha$, so there exists an open interval $J_x$ about $x$ such that
\[
\sup_{y,z\in J_x\cap[a,b]}|f(y)-f(z)|<\alpha.
\]
The compact set $K$ is covered by finitely many such $J_x$. Let $\lambda>0$ be a Lebesgue number for this finite cover.

Choose a partition $P$ which contains all endpoints of the finitely many component intervals of $O$ and whose mesh is less than $\lambda$. For each subinterval $I$ of $P$, write
\[
\operatorname{osc}_I f=\sup_I f-\inf_I f.
\]

If the interior of $I$ meets $A_\alpha$, then $I\subset O$ because the endpoints of $O$ belong to the partition. The total length of all such intervals is at most $m(O)$. On them,
\[
\operatorname{osc}_I f\le2M.
\]

Every remaining partition interval lies in the complement of $A_\alpha$ and, by the mesh condition, is contained in one of the chosen $J_x$ whenever it meets $K$. Thus on every such interval,
\[
\operatorname{osc}_I f<\alpha.
\]
Consequently,
\[
\begin{aligned}
U(f,P)-L(f,P)
&=\sum_{I\in P}(\operatorname{osc}_I f)|I|\\
&\le 2M\,m(O)+\alpha(b-a)\\
&<\frac\varepsilon2+\frac\varepsilon2
=\varepsilon.
\end{aligned}
\]
By the Darboux criterion, $f$ is Riemann integrable.
:::

<1>2. If $f$ is Riemann integrable, then $m(D_f)=0$.
::: {.proof}
It suffices to prove
\[
m(A_{1/n})=0
\qquad(n\ge1),
\]
because
\[
D_f=\bigcup_{n=1}^{\infty}A_{1/n}.
\]

Fix $n\ge1$ and $\varepsilon>0$. Since $f$ is Riemann integrable, choose a partition $P$ such that
\[
U(f,P)-L(f,P)<\frac\varepsilon n.
\]
Call a partition interval $I$ bad if its interior meets $A_{1/n}$. If $x\in\operatorname{int}(I)\cap A_{1/n}$, then $I$ contains a neighborhood of $x$, so
\[
\operatorname{osc}_I f\ge\omega_f(x)\ge\frac1n.
\]
Therefore
\[
\frac1n\sum_{I\text{ bad}}|I|
\le
\sum_{I\text{ bad}}(\operatorname{osc}_I f)|I|
\le U(f,P)-L(f,P)
<\frac\varepsilon n.
\]
Hence
\[
\sum_{I\text{ bad}}|I|<\varepsilon.
\]

The set $A_{1/n}$ is contained in the union of the bad intervals together with the finitely many partition points. The latter set has measure zero, so
\[
m(A_{1/n})\le\varepsilon.
\]
Since $\varepsilon>0$ was arbitrary,
\[
m(A_{1/n})=0.
\]
Taking the countable union over $n$ gives
\[
m(D_f)=0.
\]
:::

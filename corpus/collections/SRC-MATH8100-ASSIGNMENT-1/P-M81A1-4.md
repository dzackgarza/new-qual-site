::: problem
Let $(x_n)$ enumerate a countable set $X\subseteq\mathbb R$.
Set $f_n(x)=1$ for $x>x_n$ and $f_n(x)=0$ for $x\leq x_n$.
Prove that
$$
f(x)=\sum_{n=1}^{\infty}\frac{f_n(x)}{n^2}
$$
is increasing on $\mathbb R$ and continuous on $\mathbb R\setminus X$.
:::

::: {.solution}
Each $f_n$ is nondecreasing, and every coefficient $1/n^2$ is positive. Hence if $x<y$, then
\[
f_n(x)\le f_n(y)
\qquad\text{for every }n,
\]
so termwise comparison gives
\[
f(x)=\sum_{n=1}^\infty\frac{f_n(x)}{n^2}
\le
\sum_{n=1}^\infty\frac{f_n(y)}{n^2}
=f(y).
\]
Thus $f$ is increasing.

Now fix $x\in\mathbb R\setminus X$ and $\varepsilon>0$. Choose $N$ so large that
\[
2\sum_{n>N}\frac1{n^2}<\varepsilon.
\]
Since $x\ne x_n$ for $1\le n\le N$, the finite set
\[
\{|x-x_n|:1\le n\le N\}
\]
has a positive minimum. Choose
\[
0<\delta<\min_{1\le n\le N}|x-x_n|.
\]
If $|y-x|<\delta$, then $x$ and $y$ lie on the same side of every $x_n$ with $n\le N$, hence
\[
f_n(y)=f_n(x)
\qquad(1\le n\le N).
\]
Therefore
\[
\begin{aligned}
|f(y)-f(x)|
&\le
\sum_{n>N}\frac{|f_n(y)-f_n(x)|}{n^2}\\
&\le
\sum_{n>N}\frac1{n^2}
<\varepsilon.
\end{aligned}
\]
Thus $f$ is continuous at every $x\notin X$.
:::

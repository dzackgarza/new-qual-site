::: problem
Let $(r_n)$ enumerate $\mathbb Q\cap[0,1]$. Define $f(r_n)=1/n$ and set $f(x)=0$ for irrational $x\in[0,1]$.

1. Prove that $\lim_{x\to c}f(x)=0$ for every $c\in[0,1]$. Determine the discontinuity set of $f$.
2. For a bounded function $g:\mathbb R\to\mathbb R$, define
   $$
   \omega_g(x)=\lim_{\delta\to0^+}\sup_{y,z\in B_\delta(x)}|g(y)-g(z)|.
   $$
   Prove that this is well-defined and that $g$ is continuous at $x$ if and only if $\omega_g(x)=0$.
3. Prove that $\{x:\omega_g(x)\geq\varepsilon\}$ is closed for every $\varepsilon>0$. Deduce that every discontinuity set is $F_\sigma$.
:::

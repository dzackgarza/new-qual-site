::: {.problem}
Let $(r_n)$ enumerate $\mathbb Q\cap[0,1]$.
Define $f(r_n)=1/n$ and set $f(x)=0$ for irrational $x\in[0,1]$.

1. Prove that $\lim_{x\to c}f(x)=0$ for every $c\in[0,1]$.
   Determine the discontinuity set of $f$.

2. For a bounded function $g:\mathbb R\to\mathbb R$, define
   $$
   \omega_g(x)=\lim_{\delta\to0^+}\sup_{y,z\in B_\delta(x)}|g(y)-g(z)|.
   $$
   Prove that this is well-defined and that $g$ is continuous at $x$ if and only if $\omega_g(x)=0$.

3. Prove that $\{x:\omega_g(x)\geq\varepsilon\}$ is closed for every $\varepsilon>0$.
   Deduce that every discontinuity set is $F_\sigma$.
:::

::: {.solution}
**Part 1.**

::: pf

::: {.pf-step #s1}

For every $c \in [0, 1]$, $\lim_{x \to c} f(x) = 0$.

::: pf-proof

::: {.pf-step #s1-1}

Let $\varepsilon > 0$.
Choose $N \in \mathbb{N}$ such that $\frac{1}{N} < \varepsilon$.

::: pf-proof

Archimedean property of the real numbers.

:::

:::

::: pf-step

The set $S_N = \{r_1, r_2, \dots, r_N\}$ is finite.

::: pf-proof

finite subset of $\mathbb{Q} \cap [0, 1]$.

:::

:::

::: pf-step

Define $\delta = \min\bigl(\{ |r_n - c| : 1 \le n \le N,\ r_n \neq c\} \cup \{1\}\bigr) > 0$.

::: pf-proof

minimum of a non-empty finite set of positive numbers is strictly positive.

:::

:::

::: {.pf-step #s1-4}

For all $x \in [0, 1]$ satisfying $0 < |x - c| < \delta$, $x \notin \{r_1, \dots, r_N\}$.

::: pf-proof

choice of $\delta$.

:::

:::

::: {.pf-step #s1-5}

If $x \notin \mathbb{Q}$, then $f(x) = 0$, so $|f(x) - 0| = 0 < \varepsilon$.

::: pf-proof

definition of $f$ on irrationals.

:::

:::

::: {.pf-step #s1-6}

If $x \in \mathbb{Q} \cap [0, 1]$, then $x = r_k$ with $k > N$, so $|f(x) - 0| = f(r_k) = \frac{1}{k} < \frac{1}{N} < \varepsilon$.

::: pf-proof

Steps [](#s1-4){.pf-ref} and [](#s1-1){.pf-ref}.

:::

:::

::: pf-step

Thus $|f(x) - 0| < \varepsilon$ for all $x \in [0,1]$ with $0 < |x - c| < \delta$, which proves $\lim_{x \to c} f(x) = 0$.

::: pf-proof

Steps [](#s1-5){.pf-ref} and [](#s1-6){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s2}

The discontinuity set of $f$ is $\mathbb{Q} \cap [0, 1]$.

::: pf-proof

::: pf-step

A function is continuous at $c$ if and only if $\lim_{x \to c} f(x) = f(c)$.

::: pf-proof

definition of continuity.

:::

:::

::: {.pf-step #s2-2}

For $c \in (\mathbb{R} \setminus \mathbb{Q}) \cap [0, 1]$, $f(c) = 0 = \lim_{x \to c} f(x)$, so $f$ is continuous at every irrational point.

::: pf-proof

definition of $f$ on irrationals and step [](#s1){.pf-ref}.

:::

:::

::: {.pf-step #s2-3}

For $c = r_n \in \mathbb{Q} \cap [0, 1]$, $f(c) = \frac{1}{n} \neq 0 = \lim_{x \to c} f(x)$, so $f$ is discontinuous at every rational point.

::: pf-proof

$\frac{1}{n} > 0$ and step [](#s1){.pf-ref}.

:::

:::

::: pf-step

Hence the discontinuity set of $f$ is precisely $\mathbb{Q} \cap [0, 1]$.

::: pf-proof

Steps [](#s2-2){.pf-ref} and [](#s2-3){.pf-ref}.

:::

**Part 2.**

::: pf

::: {.pf-step #s3}

$\omega_g(x)$ is well-defined.

::: pf-proof

::: pf-step

For $\delta > 0$, let $\Omega_g(x, \delta) = \sup_{y,z \in B_\delta(x)} |g(y) - g(z)|$.

::: pf-proof

definition of oscillation on a ball.

:::

:::

::: pf-step

Since $g$ is bounded, $|g(y)| \le M$ for all $y \in \mathbb{R}$, so $|g(y) - g(z)| \le 2M$ and $\Omega_g(x, \delta) \in [0, 2M]$.

::: pf-proof

triangle inequality.

:::

:::

::: pf-step

If $0 < \delta_1 \le \delta_2$, then $B_{\delta_1}(x) \subseteq B_{\delta_2}(x)$, so $\Omega_g(x, \delta_1) \le \Omega_g(x, \delta_2)$.

::: pf-proof

supremum over a smaller set is less than or equal to supremum over a larger set.

:::

:::

::: pf-step

As $\delta \to 0^+$, $\Omega_g(x, \delta)$ is non-negative and monotonically non-increasing, so $\lim_{\delta \to 0^+} \Omega_g(x, \delta) = \inf_{\delta > 0} \Omega_g(x, \delta)$ exists in $[0, 2M]$.

::: pf-proof

monotone convergence of bounded monotonic functions.

:::

:::

:::

:::

::: {.pf-step #s4}

$g$ is continuous at $x$ if and only if $\omega_g(x) = 0$.

::: pf-proof

::: {.pf-step #s4-1}

($\Leftarrow$) Assume $\omega_g(x) = 0$.
For any $\varepsilon > 0$, since $\lim_{\delta \to 0^+} \Omega_g(x,\delta) = 0$, there exists $\delta > 0$ such that $\Omega_g(x,\delta) < \varepsilon$.

::: pf-proof

definition of limit.

:::

:::

::: pf-step

Since $x \in B_\delta(x)$, for all $y \in B_\delta(x)$ we have $|g(y) - g(x)| \le \Omega_g(x,\delta) < \varepsilon$, so $g$ is continuous at $x$.

::: pf-proof

Step [](#s4-1){.pf-ref} and definition of continuity.

:::

:::

::: pf-step

($\Rightarrow$) Assume $g$ is continuous at $x$.
For any $\varepsilon > 0$, there exists $\delta > 0$ such that $|y - x| < \delta \implies |g(y) - g(x)| < \varepsilon/2$.

::: pf-proof

$\varepsilon$-$\delta$ definition of continuity.

:::

:::

::: {.pf-step #s4-4}

For all $y, z \in B_\delta(x)$, $|g(y) - g(z)| \le |g(y) - g(x)| + |g(x) - g(z)| < \varepsilon/2 + \varepsilon/2 = \varepsilon$.

::: pf-proof

triangle inequality.

:::

:::

::: pf-step

Thus $\Omega_g(x,\delta) \le \varepsilon$, which implies $\omega_g(x) \le \Omega_g(x,\delta) \le \varepsilon$.
Since $\varepsilon > 0$ was arbitrary, $\omega_g(x) = 0$.

::: pf-proof

Steps [](#s4-4){.pf-ref} and [](#s3){.pf-ref}.

:::

**Part 3.**

::: pf

::: {.pf-step #s5}

For every $\varepsilon > 0$, the set $E_\varepsilon = \{x \in \mathbb{R} : \omega_g(x) \ge \varepsilon\}$ is closed.

::: pf-proof

::: pf-step

It suffices to show that $E_\varepsilon^c = \{x \in \mathbb{R} : \omega_g(x) < \varepsilon\}$ is open.

::: pf-proof

a set is closed iff its complement is open.

:::

:::

::: pf-step

Let $x_0 \in E_\varepsilon^c$, so $\omega_g(x_0) < \varepsilon$.

::: pf-proof

setup.

:::

:::

::: {.pf-step #s5-3}

There exists $\delta > 0$ such that $\sup_{y,z \in B_\delta(x_0)} |g(y) - g(z)| < \varepsilon$.

::: pf-proof

$\omega_g(x_0) = \inf_{\delta > 0} \Omega_g(x_0, \delta) < \varepsilon$.

:::

:::

::: pf-step

For any $x \in B_{\delta/2}(x_0)$, let $r = \delta/2 > 0$.
The ball $B_r(x)$ satisfies $B_r(x) \subseteq B_\delta(x_0)$.

::: pf-proof

if $|y - x| < \delta/2$, then $|y - x_0| \le |y - x| + |x - x_0| < \delta/2 + \delta/2 = \delta$.

:::

:::

::: {.pf-step #s5-5}

Therefore $\omega_g(x) \le \Omega_g(x, r) \le \Omega_g(x_0, \delta) < \varepsilon$, so $x \in E_\varepsilon^c$.

::: pf-proof

$B_r(x) \subseteq B_\delta(x_0)$ and step [](#s5-3){.pf-ref}.

:::

:::

::: pf-step

Thus $B_{\delta/2}(x_0) \subseteq E_\varepsilon^c$, showing $E_\varepsilon^c$ is open, so $E_\varepsilon$ is closed.

::: pf-proof

Step [](#s5-5){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s6}

The discontinuity set $D_g$ of $g$ is an $F_\sigma$ set.

::: pf-proof

::: pf-step

By step [](#s4){.pf-ref}, $x \in D_g \iff \omega_g(x) > 0$.

::: pf-proof

Step [](#s4){.pf-ref}.

:::

:::

::: {.pf-step #s6-2}

$\omega_g(x) > 0 \iff \exists n \in \mathbb{N} \text{ such that } \omega_g(x) \ge \frac{1}{n}$.

::: pf-proof

Archimedean property.

:::

:::

::: pf-step

Therefore $D_g = \bigcup_{n=1}^\infty \{x \in \mathbb{R} : \omega_g(x) \ge \frac{1}{n}\} = \bigcup_{n=1}^\infty E_{1/n}$.

::: pf-proof

Step [](#s6-2){.pf-ref}.

:::

:::

::: pf-step

Each $E_{1/n}$ is closed by step [](#s5){.pf-ref}, so $D_g$ is a countable union of closed sets, which by definition is an $F_\sigma$ set.

::: pf-proof

Step [](#s5){.pf-ref} and definition of $F_\sigma$.

:::

::: problem
Given an arbitrary $F_\sigma$ set $V\subseteq\mathbb R$, construct a function whose discontinuity set is exactly $V$.
:::

::: {.solution}
Write
\[
V=\bigcup_{n=1}^{\infty}F_n
\]
with each $F_n$ closed. Since every closed subset of $\mathbb R$ is separable, choose a countable dense subset
\[
D_n\subset F_n
\]
for each $n$; if $F_n=\varnothing$, take $D_n=\varnothing$.

Define
\[
f(x)=\sum_{n=1}^{\infty}3^{-n}\mathbf1_{D_n}(x).
\]
The series converges uniformly because
\[
0\le 3^{-n}\mathbf1_{D_n}(x)\le 3^{-n}
\]
and $\sum 3^{-n}<\infty$.

<1>1. $f$ is continuous at every point of $\mathbb R\setminus V$.
::: {.proof}
Fix $x\notin V$ and $\varepsilon>0$. Choose $N$ so large that
\[
\sum_{n>N}3^{-n}<\frac\varepsilon2.
\]
For $1\le n\le N$, one has $x\notin F_n$. Since each $F_n$ is closed, there exists a neighborhood $U$ of $x$ disjoint from
\[
F_1\cup\cdots\cup F_N.
\]
Hence for $y\in U$,
\[
\mathbf1_{D_n}(y)=\mathbf1_{D_n}(x)=0
\qquad(1\le n\le N).
\]
Therefore
\[
|f(y)-f(x)|
\le
2\sum_{n>N}3^{-n}
<\varepsilon.
\]
So $f$ is continuous at $x$.
:::

<1>2. $f$ is discontinuous at every point of $V$.
::: {.proof}
Fix $x\in V$, and let $N$ be the least index such that $x\in F_N$. Since $D_N$ is dense in $F_N$, there exists a sequence
\[
y_k\in D_N,
\qquad y_k\to x.
\]
For every $k$,
\[
f(y_k)\ge 3^{-N}.
\]

On the other hand,
\[
D:=\bigcup_{n=1}^{\infty}D_n
\]
is countable, so its complement is dense in $\mathbb R$. Choose
\[
z_k\notin D,
\qquad z_k\to x.
\]
Then
\[
f(z_k)=0
\qquad\text{for every }k.
\]
Thus arbitrarily near $x$ the function takes the value $0$ and also values at least $3^{-N}$. Hence $f$ cannot be continuous at $x$.
:::

Combining the two parts, the discontinuity set of $f$ is exactly
\[
V.
\]
:::

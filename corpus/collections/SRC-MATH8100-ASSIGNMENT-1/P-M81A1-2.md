::: problem
1. Prove that a set is $G_\delta$ if and only if its complement is $F_\sigma$.

2. Prove that every closed subset of $\mathbb R^n$ is $G_\delta$, and every open subset is $F_\sigma$.

3. Give an $F_\sigma$ set that is not $G_\delta$.
   Give a set that is neither $F_\sigma$ nor $G_\delta$.
:::

::: {.solution}
<1>1. Complements exchange $F_\sigma$ and $G_\delta$.
::: {.proof}
Suppose
\[
A=\bigcap_{n=1}^\infty U_n
\]
with each $U_n$ open. By De Morgan's law,
\[
A^c
=\bigcup_{n=1}^\infty U_n^c,
\]
and each $U_n^c$ is closed. Thus $A^c$ is $F_\sigma$.

Conversely, if
\[
A^c=\bigcup_{n=1}^\infty F_n
\]
with each $F_n$ closed, then
\[
A=\bigcap_{n=1}^\infty F_n^c,
\]
an intersection of open sets. Hence $A$ is $G_\delta$.
:::

<1>2. Closed sets are $G_\delta$ and open sets are $F_\sigma$.
::: {.proof}
Let $F\subset\mathbb R^n$ be closed. For $k\ge1$, set
\[
U_k=\{x:\operatorname{dist}(x,F)<1/k\}.
\]
Each $U_k$ is open, and since $F$ is closed,
\[
F=\bigcap_{k=1}^\infty U_k.
\]
Thus $F$ is $G_\delta$.

Now let $U\subset\mathbb R^n$ be open. If $U=\mathbb R^n$, it is already closed and hence certainly $F_\sigma$. Otherwise define
\[
F_k=\{x\in U:\operatorname{dist}(x,U^c)\ge1/k\}.
\]
Each $F_k$ is closed, and every $x\in U$ has positive distance from $U^c$ because $U$ is open. Hence $x\in F_k$ for some $k$, so
\[
U=\bigcup_{k=1}^\infty F_k.
\]
Therefore $U$ is $F_\sigma$.
:::

<1>3. Examples.
::: {.proof}
The rational numbers satisfy
\[
\mathbb Q=\bigcup_{q\in\mathbb Q}\{q\},
\]
so $\mathbb Q$ is $F_\sigma$.

We claim that $\mathbb Q$ is not $G_\delta$. Suppose instead that
\[
\mathbb Q=\bigcap_{n=1}^\infty U_n
\]
with each $U_n$ open. Since $\mathbb Q$ is dense, every $U_n$ is dense. Enumerate
\[
\mathbb Q=\{q_1,q_2,\ldots\}.
\]
Then each set
\[
V_n=U_n\setminus\{q_n\}
\]
is open and dense in $\mathbb R$. By the Baire category theorem,
\[
\bigcap_{n=1}^\infty V_n
\]
is dense, in particular nonempty. But
\[
\bigcap_{n=1}^\infty V_n
\subset
\left(\bigcap_{n=1}^\infty U_n\right)
\setminus\{q_1,q_2,\ldots\}
=\mathbb Q\setminus\mathbb Q
=\varnothing,
\]
a contradiction. Thus $\mathbb Q$ is $F_\sigma$ but not $G_\delta$.

For the second example, note that every $F_\sigma$ and every $G_\delta$ set is Borel. There are only continuum-many Borel subsets of $\mathbb R$: the topology has cardinality continuum, and closing under countably many unions and complements still yields at most continuum many sets. But
\[
|\mathcal P(\mathbb R)|=2^{\mathfrak c}>\mathfrak c.
\]
Hence there exists a non-Borel subset $A\subset\mathbb R$. Such an $A$ can be neither $F_\sigma$ nor $G_\delta$.
:::

::: {.problem}
Suppose that $X$ is a set of size $mn$ and $(A_i)_{i=1}^m$, $(B_i)_{i=1}^m$ are partitions of $X$ into $m$ sets of size $n$.
Prove that the sets $B_i$ can be renumbered so that
\[
A_i\cap B_i\ne\varnothing
\]
for $i=1,2,\ldots,m$.
:::

Construct a bipartite graph \(\Gamma\) with left vertex set
\[
\{A_1,\dots,A_m\}
\]
and right vertex set
\[
\{B_1,\dots,B_m\},
\]
where
\[
\boxed{
A_i\sim B_j
\iff
A_i\cap B_j\ne\varnothing}.
\]

::: pf

::: pf-step

It suffices to prove that \(\Gamma\) has a matching saturating all
vertices \(A_1,\dots,A_m\).


::: pf-proof

Such a matching pairs each \(A_i\) with a distinct \(B_j\) having nonempty
intersection. Since there are \(m\) vertices on each side, a matching
saturating the left side is a perfect matching. Renumber the matched
\(B_j\)'s as \(B_i\).

:::

:::

::: pf-step

Let
\[
\mathcal S
\subseteq
\{A_1,\dots,A_m\}
\]
be any subset of \(k\) left vertices.


::: pf-proof

To apply Hall's theorem, we verify the neighborhood condition for an
arbitrary subset of the left side.

:::

:::

::: pf-step

Since the \(A_i\)'s form a partition and each has size \(n\),
\[
\boxed{
\left|
\bigcup_{A_i\in\mathcal S}A_i
\right|
=
kn}.
\]


::: pf-proof

The sets in \(\mathcal S\) are pairwise disjoint and there are \(k\) of
them, each containing \(n\) elements.

:::

:::

::: pf-step

Let
\[
N(\mathcal S)
\]
denote the set of right-side neighbors of \(\mathcal S\).


::: pf-proof

By definition,
\[
B_j\in N(\mathcal S)
\]
exactly when
\[
B_j\cap A_i\ne\varnothing
\]
for at least one \(A_i\in\mathcal S\).

:::

:::

::: pf-step

Every element of
\[
\bigcup_{A_i\in\mathcal S}A_i
\]
belongs to some \(B_j\in N(\mathcal S)\).


::: pf-proof

The \(B_j\)'s partition \(X\), so every element \(x\in X\) lies in a unique
\(B_j\). If
\[
x\in A_i
\]
for some \(A_i\in\mathcal S\), then
\[
x\in A_i\cap B_j,
\]
so this intersection is nonempty and hence
\[
B_j\in N(\mathcal S).
\]

:::

:::

::: pf-step

Therefore
\[
\boxed{
\bigcup_{A_i\in\mathcal S}A_i
\subseteq
\bigcup_{B_j\in N(\mathcal S)}B_j}.
\]


::: pf-proof

This is the set-theoretic content of step <1>5.

:::

:::

::: pf-step

If
\[
|N(\mathcal S)|=r,
\]
then
\[
\left|
\bigcup_{B_j\in N(\mathcal S)}B_j
\right|
=
rn.
\]


::: pf-proof

The \(B_j\)'s are pairwise disjoint, each has \(n\) elements, and there are
\(r\) of them.

:::

:::

::: pf-step

Comparing cardinalities in step <1>6 gives
\[
kn\le rn.
\]


::: pf-proof

Use step <1>3 for the left union and step <1>7 for the right union.

:::

:::

::: pf-step

Since \(n>0\),
\[
\boxed{r\ge k}.
\]


::: pf-proof

Divide step <1>8 by \(n\).

:::

:::

::: pf-step

Hence every subset \(\mathcal S\) of the left side satisfies
\[
\boxed{
|N(\mathcal S)|
\ge
|\mathcal S|}.
\]


::: pf-proof

The subset \(\mathcal S\) was arbitrary, and step <1>9 gives precisely
Hall's neighborhood inequality.

:::

:::

::: pf-step

By Hall's marriage theorem, \(\Gamma\) has a matching saturating all
left vertices.


::: pf-proof

Step <1>10 verifies Hall's condition.

:::

:::

::: pf-step

Since both sides of \(\Gamma\) have \(m\) vertices, this matching is
perfect.


::: pf-proof

A matching saturating all \(m\) left vertices uses \(m\) distinct right
vertices. There are only \(m\) right vertices total, so it uses all of them.

:::

:::

::: pf-step

Renumber the \(B_j\)'s according to this perfect matching.


::: pf-proof

For each \(i\), let the matched right vertex of \(A_i\) be called \(B_i\).
Since the matching is perfect, this is merely a permutation of the original
labels.

:::

:::

::: pf-step

Then
\[
\boxed{
A_i\cap B_i\ne\varnothing
\qquad
(1\le i\le m)}.
\]


::: pf-proof

Matched vertices are adjacent by definition of a matching, and adjacency in
\(\Gamma\) means nonempty intersection.

:::

:::

::: pf-qed

Step <1>14 is the required renumbering.

:::

:::

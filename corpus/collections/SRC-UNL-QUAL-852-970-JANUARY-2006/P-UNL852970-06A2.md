::: {.problem}
Prove that if $G$ is a $k$-connected graph and $S,T\subset V(G)$ are disjoint subsets of vertices, each of size $k$, then there are $k$ pairwise disjoint paths $P_1,\ldots,P_k$ and labelings
\[
S=\{s_1,\ldots,s_k\},\qquad T=\{t_1,\ldots,t_k\}
\]
such that $P_i$ is a path from $s_i$ to $t_i$ for each $i$.
:::

::: {.solution}
We use the vertex form of Menger's theorem for two vertex sets:

> The maximum number of pairwise vertex-disjoint \(S\)-\(T\) paths equals
> the minimum cardinality of a vertex set meeting every \(S\)-\(T\) path.

Moreover, the paths may be chosen to have one endpoint in \(S\), one
endpoint in \(T\), and no other vertices in \(S\cup T\).

<1>1. Let
\[
R\subseteq V(G)
\]
meet every path from \(S\) to \(T\).

::: {.proof}
Such an \(R\) is an \(S\)-\(T\) vertex separator in the set form of
Menger's theorem.
:::

<1>2. Suppose, toward a contradiction, that
\[
|R|<k.
\]

::: {.proof}
We will show that no separator this small can meet every \(S\)-\(T\) path.
:::

<1>3. Since
\[
|S|=k>|R|,
\]
there exists
\[
\boxed{s\in S-R}.
\]

::: {.proof}
A set of fewer than \(k\) vertices cannot contain all \(k\) vertices of
\(S\).
:::

<1>4. Likewise, there exists
\[
\boxed{t\in T-R}.
\]

::: {.proof}
The same counting argument applies to \(T\).
:::

<1>5. Since \(G\) is \(k\)-connected and
\[
|R|<k,
\]
the graph
\[
G-R
\]
is connected.

::: {.proof}
By definition, deleting fewer than \(k\) vertices from a \(k\)-connected
graph leaves a connected graph.
:::

<1>6. Therefore there is a path in \(G-R\) from \(s\) to \(t\).

::: {.proof}
The vertices \(s,t\) both lie in \(G-R\) by steps <1>3--<1>4, and that
graph is connected by step <1>5.
:::

<1>7. The path in step <1>6 is an \(S\)-\(T\) path that avoids \(R\).

::: {.proof}
Its initial vertex \(s\) lies in \(S\), its terminal vertex \(t\) lies in
\(T\), and all its vertices lie in \(G-R\).
:::

<1>8. This contradicts the assumption that \(R\) meets every \(S\)-\(T\)
path.

::: {.proof}
Step <1>7 produces an \(S\)-\(T\) path disjoint from \(R\).
:::

<1>9. Hence every \(S\)-\(T\) separator has size at least
\[
\boxed{k}.
\]

::: {.proof}
Steps <1>2--<1>8 rule out separators of cardinality \(<k\).
:::

<1>10. The set \(S\) itself meets every \(S\)-\(T\) path.

::: {.proof}
Every \(S\)-\(T\) path has its initial endpoint in \(S\), so it meets \(S\).
:::

<1>11. Therefore the minimum size of an \(S\)-\(T\) separator is exactly
\[
\boxed{k}.
\]

::: {.proof}
Step <1>9 gives the lower bound \(k\), while step <1>10 gives a separator of
size
\[
|S|=k.
\]
:::

<1>12. By Menger's theorem, there exist
\[
\boxed{k}
\]
pairwise vertex-disjoint \(S\)-\(T\) paths.

::: {.proof}
The maximum number of pairwise vertex-disjoint \(S\)-\(T\) paths equals the
minimum separator size, which is \(k\) by step <1>11.
:::

<1>13. Let these paths be
\[
P_1,\dots,P_k.
\]
Their endpoints in \(S\) are pairwise distinct.

::: {.proof}
If two paths shared an endpoint in \(S\), they would share a vertex,
contradicting pairwise vertex-disjointness.
:::

<1>14. Their endpoints in \(T\) are pairwise distinct.

::: {.proof}
The same argument applies to the terminal endpoints in \(T\).
:::

<1>15. Since there are \(k\) paths and \(|S|=k\), the \(S\)-endpoints of the
paths exhaust \(S\).

::: {.proof}
There are \(k\) pairwise distinct endpoints in a set of cardinality \(k\).
:::

<1>16. Likewise, the \(T\)-endpoints exhaust \(T\).

::: {.proof}
Use step <1>14 and \(|T|=k\).
:::

<1>17. Label the endpoint of \(P_i\) in \(S\) by \(s_i\), and its endpoint
in \(T\) by \(t_i\).

::: {.proof}
Each \(P_i\) has one endpoint in \(S\) and one in \(T\), by the set form of
Menger's theorem.
:::

<1>18. Then
\[
\boxed{
S=\{s_1,\dots,s_k\},
\qquad
T=\{t_1,\dots,t_k\}}
\]
and \(P_i\) joins \(s_i\) to \(t_i\).

::: {.proof}
Exhaustion is steps <1>15--<1>16, and the endpoint assignment is step
<1>17.
:::

<1>19. Q.E.D.

::: {.proof}
Step <1>12 gives the \(k\) disjoint paths, and step <1>18 supplies the
required labelings of \(S\) and \(T\).
:::
:::

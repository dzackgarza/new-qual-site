::: {.problem}
Prove that if $G$ is a $k$-connected graph and $S,T\subset V(G)$ are disjoint subsets of vertices, each of size $k$, then there are $k$ pairwise disjoint paths $P_1,\ldots,P_k$ and labelings
$$
S=\{s_1,\ldots,s_k\},\qquad T=\{t_1,\ldots,t_k\}
$$
such that $P_i$ is a path from $s_i$ to $t_i$ for each $i$.
:::

::: {.solution}

We use the vertex form of Menger's theorem for two vertex sets:

> The maximum number of pairwise vertex-disjoint $S$-$T$ paths equals
> the minimum cardinality of a vertex set meeting every $S$-$T$ path.

Moreover, the paths may be chosen to have one endpoint in $S$, one
endpoint in $T$, and no other vertices in $S\cup T$.

::: pf

::: pf-step

Let
$$
R\subseteq V(G)
$$
meet every path from $S$ to $T$.


::: pf-proof

Such an $R$ is an $S$-$T$ vertex separator in the set form of
Menger's theorem.

:::

:::

::: {.pf-step #s1-2}

Suppose, toward a contradiction, that
$$
\cardinality{R}<k.
$$


::: pf-proof

We will show that no separator this small can meet every $S$-$T$ path.

:::

:::

::: {.pf-step #s1-3}

Since
$$
\cardinality{S}=k>\cardinality{R},
$$
there exists
$$
\boxed{s\in S-R}.
$$


::: pf-proof

A set of fewer than $k$ vertices cannot contain all $k$ vertices of
$S$.

:::

:::

::: {.pf-step #s1-4}

Likewise, there exists
$$
\boxed{t\in T-R}.
$$


::: pf-proof

The same counting argument applies to $T$.

:::

:::

::: {.pf-step #s1-5}

Since $G$ is $k$-connected and
$$
\cardinality{R}<k,
$$
the graph
$$
G-R
$$
is connected.


::: pf-proof

By definition, deleting fewer than $k$ vertices from a $k$-connected
graph leaves a connected graph.

:::

:::

::: {.pf-step #s1-6}

Therefore there is a path in $G-R$ from $s$ to $t$.


::: pf-proof

The vertices $s,t$ both lie in $G-R$ by steps [](#s1-3){.pf-ref} through [](#s1-4){.pf-ref}, and that
graph is connected by step [](#s1-5){.pf-ref}.

:::

:::

::: {.pf-step #s1-7}

The path in step [](#s1-6){.pf-ref} is an $S$-$T$ path that avoids $R$.


::: pf-proof

Its initial vertex $s$ lies in $S$, its terminal vertex $t$ lies in
$T$, and all its vertices lie in $G-R$.

:::

:::

::: {.pf-step #s1-8}

This contradicts the assumption that $R$ meets every $S$-$T$
path.


::: pf-proof

Step [](#s1-7){.pf-ref} produces an $S$-$T$ path disjoint from $R$.

:::

:::

::: {.pf-step #s1-9}

Hence every $S$-$T$ separator has size at least
$$
\boxed{k}.
$$


::: pf-proof

Steps [](#s1-2){.pf-ref} through [](#s1-8){.pf-ref} rule out separators of cardinality $<k$.

:::

:::

::: {.pf-step #s1-10}

The set $S$ itself meets every $S$-$T$ path.


::: pf-proof

Every $S$-$T$ path has its initial endpoint in $S$, so it meets $S$.

:::

:::

::: {.pf-step #s1-11}

Therefore the minimum size of an $S$-$T$ separator is exactly
$$
\boxed{k}.
$$


::: pf-proof

Step [](#s1-9){.pf-ref} gives the lower bound $k$, while step [](#s1-10){.pf-ref} gives a separator of
size
$$
\cardinality{S}=k.
$$

:::

:::

::: {.pf-step #s1-12}

By Menger's theorem, there exist
$$
\boxed{k}
$$
pairwise vertex-disjoint $S$-$T$ paths.


::: pf-proof

The maximum number of pairwise vertex-disjoint $S$-$T$ paths equals the
minimum separator size, which is $k$ by step [](#s1-11){.pf-ref}.

:::

:::

::: pf-step

Let these paths be
$$
P_1,\dots,P_k.
$$
Their endpoints in $S$ are pairwise distinct.


::: pf-proof

If two paths shared an endpoint in $S$, they would share a vertex,
contradicting pairwise vertex-disjointness.

:::

:::

::: {.pf-step #s1-14}

Their endpoints in $T$ are pairwise distinct.


::: pf-proof

The same argument applies to the terminal endpoints in $T$.

:::

:::

::: {.pf-step #s1-15}

Since there are $k$ paths and $\cardinality{S}=k$, the $S$-endpoints of the
paths exhaust $S$.


::: pf-proof

There are $k$ pairwise distinct endpoints in a set of cardinality $k$.

:::

:::

::: {.pf-step #s1-16}

Likewise, the $T$-endpoints exhaust $T$.


::: pf-proof

Use step [](#s1-14){.pf-ref} and $\cardinality{T}=k$.

:::

:::

::: {.pf-step #s1-17}

Label the endpoint of $P_i$ in $S$ by $s_i$, and its endpoint
in $T$ by $t_i$.


::: pf-proof

Each $P_i$ has one endpoint in $S$ and one in $T$, by the set form of
Menger's theorem.

:::

:::

::: {.pf-step #s1-18}

Then
$$
\boxed{
S=\{s_1,\dots,s_k\},
\qquad
T=\{t_1,\dots,t_k\}}
$$
and $P_i$ joins $s_i$ to $t_i$.


::: pf-proof

Exhaustion is steps [](#s1-15){.pf-ref} through [](#s1-16){.pf-ref}, and the endpoint assignment is step
[](#s1-17){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-12){.pf-ref} gives the $k$ disjoint paths, and step [](#s1-18){.pf-ref} supplies the
required labelings of $S$ and $T$.

:::

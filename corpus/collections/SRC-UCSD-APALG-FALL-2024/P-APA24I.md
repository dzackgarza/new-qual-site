::: {.problem}
Let $k$ be a field and let $I \subseteq k[x_1, \ldots, x_n]$ be an ideal.
Fix a monomial order $<$ and let $G = \{g_1, \ldots, g_r\}$ be a Gröbner basis of $I$ with respect to $<$.
Consider the set of monomials
\[
\mathcal{M} := \{ \text{monomials } m = x_1^{a_1} \cdots x_n^{a_n} : \operatorname{LT}(g_i) \nmid m \text{ for } 1 \leq i \leq r \}.
\]
Here $\operatorname{LT}(g_i)$ is the leading term of $g_i$ with respect to the monomial order $<$.

(a) Prove that $\mathcal{M}$ descends to a spanning set of the $k$-vector space $k[x_1, \ldots, x_n]/I$.

(b) If $G$ is a basis of $I$ which is not necessarily Gröbner, does the set $\mathcal{M}$ necessarily span $k[x_1, \ldots, x_n]/I$?
Prove or give a counterexample.
:::

::: {.solution}
<1>1. Every polynomial \(f\in k[x_1,\ldots,x_n]\) can be written
\[
f=q_1g_1+\cdots+q_rg_r+r
\]
where no monomial occurring in \(r\) is divisible by any \(\operatorname{LT}(g_i)\).
::: {.proof}
This is exactly the conclusion of the multivariate division algorithm with divisors \(g_1,\ldots,g_r\). At each step one cancels the current leading term if it is divisible by some \(\operatorname{LT}(g_i)\); otherwise that leading term is moved to the remainder. Since the monomial order is a well-order and strictly decreases during cancellation, the process terminates. By construction, no monomial left in \(r\) is divisible by any \(\operatorname{LT}(g_i)\).
:::

<1>2. The images of the monomials in \(\mathcal M\) span \(k[x_1,\ldots,x_n]/I\).
::: {.proof}
Let \(f\in k[x_1,\ldots,x_n]\). By <1>1,
\[
f=q_1g_1+\cdots+q_rg_r+r.
\]
Because each \(g_i\in I\), the difference \(f-r\) lies in \(I\), so
\[
f+I=r+I.
\]
Every monomial appearing in \(r\) lies in \(\mathcal M\). Thus \(r+I\), and therefore \(f+I\), is a \(k\)-linear combination of the images of monomials in \(\mathcal M\). This proves part (a).
:::

<1>3. The conclusion of part (a) remains true even if \(G\) is merely a finite generating set of \(I\) and is not a Gröbner basis.
::: {.proof}
The proof of <1>1 uses only the multivariate division algorithm, not the Gröbner-basis property. Therefore, for every polynomial \(f\), division by any finite generating set \(G=\{g_1,\ldots,g_r\}\) still produces
\[
f=\sum_i q_i g_i+r
\]
with every monomial of \(r\) outside the divisibility ideals generated by the listed leading terms. Since the \(g_i\) generate \(I\), one again has \(f+I=r+I\), so the corresponding set \(\mathcal M\) spans the quotient.

What can fail without the Gröbner hypothesis is **linear independence** (and uniqueness of the remainder), because the ideal may contain a polynomial whose leading term is not divisible by any \(\operatorname{LT}(g_i)\). But spanning itself does not fail.
:::

<1>4. Hence the answer to part (b) is yes: Gröbnerness is not required for the spanning assertion.
::: {.proof}
This is precisely <1>3.
:::
:::

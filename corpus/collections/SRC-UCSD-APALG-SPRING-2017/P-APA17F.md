::: problem
Give examples of each of the following objects.

(a) A finite group $G$, an irreducible $G$-module $V$ defined over the real numbers $\mathbb{R}$, and a $G$-module homomorphism $\varphi \colon V \to V$ which is not multiplication by a scalar.

(b) An infinite group $G$ and a $G$-module $V$ defined over the complex numbers $\mathbb{C}$ which is indecomposable but not irreducible.
:::

::: solution
For (a), take \(G=C_4=\langle g:g^4=1
angle\) and let \(V=\mathbb R^2\) with
\[
g\longmapsto J=
\begin{pmatrix}
0&-1\\
1&0
\end{pmatrix}.
\]
This is an irreducible real representation. Indeed, any nonzero proper real subspace of \(\mathbb R^2\) is a line, and a \(G\)-stable line would be spanned by a real eigenvector of \(J\). But the characteristic polynomial of \(J\) is \(t^2+1\), which has no real root. Thus no nonzero proper \(G\)-stable subspace exists.

Now define
\[
\varphi=J:V\to V.
\]
Since \(G\) is generated by \(J\), the map \(\varphi\) commutes with the action of every element of \(G\), so it is a \(G\)-module endomorphism. It is plainly not a real scalar multiple of the identity. This shows why the usual scalar conclusion in Schur's lemma requires an algebraically closed ground field.

For (b), take \(G=\mathbb Z=\langle t\rangle\) and let \(V=\mathbb C^2\) with
\[
t\longmapsto U=
\begin{pmatrix}
1&1\\
0&1
\end{pmatrix}.
\]
The line \(L=\mathbb C e_1\) is \(G\)-stable, so \(V\) is not irreducible.

We claim that \(V\) is nevertheless indecomposable. If
\[
V=V_1\oplus V_2
\]
were a decomposition into two nonzero \(G\)-submodules, then each \(V_i\) would be one-dimensional, hence spanned by an eigenvector of \(U\). Therefore \(U\) would admit a basis of eigenvectors and so would be diagonalizable. But \(U\ne I\) has characteristic polynomial \((t-1)^2\) and only the one-dimensional eigenspace \(\mathbb C e_1\); hence \(U\) is not diagonalizable. Thus no such decomposition exists, and \(V\) is indecomposable but reducible.
:::

::: {.problem}
Let
\[
A = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix} \in \mathrm{GL}_2(\mathbb{C})
\]
and let $G$ be the cyclic subgroup of $\mathrm{GL}_2(\mathbb{C})$ of order $4$ generated by $A$.

(a) Calculate the Hilbert series of the invariant ring $\mathbb{C}[x, y]^G$.

(b) Describe a finite set of polynomials which generates $\mathbb{C}[x, y]^G$ as a $\mathbb{C}$-algebra (you need not compute this set explicitly).
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
Calculate the Hilbert series of $\mathbb{C}[x, y]^G$ using Molien’s Theorem:

::: pf-proof

::: pf-step
The group $G = \langle A \rangle = \{I, A, A^2, A^3\} \cong \mathbb{Z}_4$ has order $|G| = 4$.

::: pf-proof
definition of cyclic group generated by $A$.
:::

:::

::: pf-step
Determine the eigenvalues and characteristic polynomials $\det(I - tg)$ for each $g \in G$:

- For $g = I$: eigenvalues are $1, 1 \implies \det(I - tI) = (1 - t)^2$.

- For $g = A = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$: eigenvalues are $i, -i \implies \det(I - tA) = (1 - it)(1 + it) = 1 + t^2$.

- For $g = A^2 = -I$: eigenvalues are $-1, -1 \implies \det(I + tI) = (1 + t)^2$.

- For $g = A^3 = -A$: eigenvalues are $-i, i \implies \det(I + tA) = 1 + t^2$.

::: pf-proof
characteristic polynomials of $2 \times 2$ matrices.
:::

:::

::: pf-step
By Molien’s Formula:
\[
\operatorname{Hilb}(\mathbb{C}[x, y]^G, t) = \frac{1}{|G|} \sum_{g \in G} \frac{1}{\det(I - tg)} = \frac{1}{4} \left( \frac{1}{(1-t)^2} + \frac{1}{(1+t)^2} + \frac{2}{1+t^2} \right).
\]

::: pf-proof
Molien's Theorem for invariant rings of finite groups in characteristic 0.
:::

:::

::: pf-step
Simplify the rational expression:
\[
\frac{1}{(1-t)^2} + \frac{1}{(1+t)^2} = \frac{(1+t)^2 + (1-t)^2}{(1-t^2)^2} = \frac{2(1+t^2)}{(1-t^2)^2}.
\]
\[
\operatorname{Hilb}(\mathbb{C}[x, y]^G, t) = \frac{1}{4} \left( \frac{2(1+t^2)}{(1-t^2)^2} + \frac{2}{1+t^2} \right) = \frac{1}{2} \left( \frac{(1+t^2)^2 + (1-t^2)^2}{(1-t^2)^2 (1+t^2)} \right) = \frac{1 + t^4}{(1 - t^2)(1 - t^4)}.
\]

::: pf-proof
algebraic simplification.
:::

:::

:::

:::

::: {.pf-step #s2}
Describe a finite set of algebra generators for $\mathbb{C}[x, y]^G$:

::: pf-proof

::: {.pf-step #s2-1}
By Noether’s Degree Bound, the invariant ring of a finite group $G$ acting linearly on a polynomial ring over $\mathbb{C}$ is generated as a $\mathbb{C}$-algebra by invariants of degree at most $|G| = 4$.

::: pf-proof
Noether's Theorem on polynomial invariants of finite groups.
:::

:::

::: pf-step
The group action on the variables is given by $A \cdot x = -y$ and $A \cdot y = x$.

::: pf-proof
dual representation $(A \cdot f)(v) = f(A^{-1} v)$.
:::

:::

::: {.pf-step #s2-3}
Applying the Reynolds operator $\mathcal{R}(f) = \frac{1}{4} \sum_{g \in G} g \cdot f$ to monomials of degree $\le 4$ produces explicit generators:

- Degree 2: $f_1 = x^2 + y^2$.

- Degree 4: $f_2 = x^2 y^2$ (or $x^4 + y^4$), and $f_3 = x y (x^2 - y^2) = x^3 y - x y^3$.

::: pf-proof
checking $A \cdot f_1 = (-y)^2 + x^2 = f_1$, $A \cdot f_2 = (-y)^2 x^2 = f_2$, and $A \cdot f_3 = (-y) x ((-y)^2 - x^2) = -xy(y^2 - x^2) = f_3$.
:::

:::

::: pf-step
Thus the finite set $\{x^2 + y^2, \; x^2 y^2, \; xy(x^2 - y^2)\}$ generates $\mathbb{C}[x, y]^G$ as a $\mathbb{C}$-algebra.

::: pf-proof
step [](#s2-1){.pf-ref} and step [](#s2-3){.pf-ref}.
:::

:::

:::

:::

::: pf-step
Conclusion: The Hilbert series is $\frac{1 + t^4}{(1 - t^2)(1 - t^4)}$, and $\mathbb{C}[x, y]^G = \mathbb{C}[x^2 + y^2, x^2 y^2, xy(x^2 - y^2)]$.

::: pf-proof
step [](#s1){.pf-ref} and step [](#s2){.pf-ref}.
:::

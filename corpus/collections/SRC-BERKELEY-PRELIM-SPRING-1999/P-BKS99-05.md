::: {.problem}
1. Let $f$ be holomorphic on the unit disk $\mathbb D$ and suppose $f(z)\ne0$ for every $z\in\mathbb D$. Prove that there is a holomorphic function $g$ on $\mathbb D$ such that
\[
f(z)=e^{g(z)}
\qquad(z\in\mathbb D).
\]
2. Does the conclusion remain true if $\mathbb D$ is replaced by an arbitrary connected open subset of $\mathbb C$? Prove your answer.
:::

::: {.solution}
<1>1. On $\mathbb D$, the function $f'/f$ has a holomorphic primitive.

::: {.proof}
Because $f$ has no zeros, $f'/f$ is holomorphic on $\mathbb D$. The unit disk is simply connected, so every holomorphic function on $\mathbb D$ has a holomorphic primitive. Thus there is a holomorphic function $H$ on $\mathbb D$ such that
\[
H'(z)=\frac{f'(z)}{f(z)}.
\]
:::

<1>2. There is a holomorphic function $g$ on $\mathbb D$ with $e^g=f$.

::: {.proof}
By step <1>1,
\[
\frac{d}{dz}\bigl(f(z)e^{-H(z)}\bigr)
=e^{-H(z)}\bigl(f'(z)-f(z)H'(z)\bigr)=0.
\]
Hence $f e^{-H}$ is constant on the connected set $\mathbb D$. Write
\[
f(z)e^{-H(z)}=C,
\]
where $C\neq0$. Choose any complex number $w$ with $e^w=C$ and set
\[
g(z):=H(z)+w.
\]
Then $g$ is holomorphic and
\[
e^{g(z)}=e^{H(z)}C=f(z).
\]
:::

<1>3. The conclusion fails for arbitrary connected open subsets of $\mathbb C$.

::: {.proof}
Take
\[
G:=\mathbb C\setminus\{0\},
\qquad
f(z):=z.
\]
Then $G$ is connected and open, and $f$ is holomorphic and nowhere zero on $G$. Suppose that $f=e^g$ for some holomorphic $g$ on $G$. Differentiating gives
\[
1=e^{g(z)}g'(z)=zg'(z),
\]
so $g'(z)=1/z$. Let $\gamma(t)=e^{it}$ for $0\leq t\leq2\pi$. Since $g'$ is a derivative,
\[
\int_\gamma g'(z)\,dz=0,
\]
whereas
\[
\int_\gamma\frac{dz}{z}=2\pi i,
\]
a contradiction. Thus no such holomorphic logarithm exists on $G$.
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>2 proves part 1, and step <1>3 gives a counterexample for part 2.
:::
:::

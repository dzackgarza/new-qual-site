::: {.problem}
Let $n$ be a positive integer, let $\alpha\in\RR$, and let $\varepsilon>0$.
Prove that there exists a real $C^\infty$ function $f$ such that

1. for every $x\in\RR$ and every $k=0,1,\ldots,n-1$,
   \[
   |f^{(k)}(x)|\le\varepsilon;
   \]
2. for $k=0,1,\ldots,n-1$,
   \[
   f^{(k)}(0)=0;
   \]
3. \[
   f^{(n)}(0)=\alpha.
   \]
:::

::: {.solution}

Let $\chi\in C^\infty(\RR)$ be a smooth cutoff satisfying
\[
\chi(x)=1\quad(|x|\leq1),
\qquad
\chi(x)=0\quad(|x|\geq2),
\]
and define
\[
\phi(x):=\frac{x^n}{n!}\chi(x).
\]

::: pf

::: {.pf-step #s1-1}

The function $\phi$ has bounded derivatives of every order and satisfies
\[
\phi^{(k)}(0)=0\quad(0\leq k<n),
\qquad
\phi^{(n)}(0)=1.
\]


::: pf-proof

A smooth cutoff as above exists; for example, with
\[
\theta(s):=
\begin{cases}
e^{-1/s},&s>0,\\
0,&s\leq0,
\end{cases}
\]
one may take
\[
\chi(x):=
\frac{\theta(4-x^2)}
{\theta(4-x^2)+\theta(x^2-1)}.
\]
The denominator never vanishes, so $\chi$ is smooth; the displayed support and plateau properties follow directly. Hence $\phi$ is smooth and compactly supported, so every derivative of $\phi$ is bounded. Near $0$ one has $\chi=1$, hence
\[
\phi(x)=\frac{x^n}{n!},
\]
which gives the stated derivatives at $0$.

:::

:::

::: {.pf-step #s1-2}

If $\alpha\neq0$, there is $h>0$ such that for every $k=0,\ldots,n-1$,
\[
|\alpha|h^{\,n-k}\|\phi^{(k)}\|_\infty\leq\varepsilon.
\]


::: pf-proof

For each $k<n$, the exponent $n-k$ is positive and
\[
C_k:=\|\phi^{(k)}\|_\infty<\infty
\]
by step [](#s1-1){.pf-ref}. For those $k$ with $C_k>0$, require
\[
h\leq
\left(\frac{\varepsilon}{|\alpha|C_k}\right)^{1/(n-k)}.
\]
There are only finitely many such conditions, so a positive $h$ satisfying all of them exists.

:::

:::

::: {.pf-step #s1-3}

If $\alpha\neq0$, the function
\[
f(x):=\alpha h^n\phi(x/h),
\]
with $h$ chosen in step [](#s1-2){.pf-ref}, satisfies all three required conditions.


::: pf-proof

For every $k\geq0$,
\[
f^{(k)}(x)
=\alpha h^{\,n-k}\phi^{(k)}(x/h).
\]
Thus step [](#s1-2){.pf-ref} gives
\[
|f^{(k)}(x)|
\leq |\alpha|h^{\,n-k}\|\phi^{(k)}\|_\infty
\leq\varepsilon
\]
for every $x\in\RR$ and every $k<n$. By step [](#s1-1){.pf-ref},
\[
f^{(k)}(0)
=\alpha h^{\,n-k}\phi^{(k)}(0)
=0
\]
for $k<n$, while
\[
f^{(n)}(0)
=\alpha\phi^{(n)}(0)
=\alpha.
\]

:::

:::

::: {.pf-step #s1-4}

If $\alpha=0$, the function $f\equiv0$ satisfies all three required conditions.


::: pf-proof

All derivatives of the zero function vanish identically.

:::

::: pf-qed

Steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref} cover the cases $\alpha\neq0$ and $\alpha=0$, respectively.

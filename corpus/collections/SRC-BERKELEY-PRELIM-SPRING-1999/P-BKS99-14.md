::: {.problem}
Let $A=(a_{ij})$ be an $n\times n$ complex matrix such that
\[
a_{ij}\ne0\quad\text{if }i=j+1,
\]
while
\[
a_{ij}=0\quad\text{if }i\ge j+2.
\]
Prove that $A$ cannot have more than one Jordan block for any eigenvalue.
:::

::: {.solution}
Fix $\lambda\in\mathbb C$.

<1>1. Any vector
\[
x=(x_1,\ldots,x_n)^T\in\ker(A-\lambda I)
\]
is uniquely determined by its last coordinate $x_n$.

::: {.proof}
The last row of $(A-\lambda I)x=0$ is
\[
a_{n,n-1}x_{n-1}+(a_{nn}-\lambda)x_n=0,
\]
because the hypothesis gives $a_{nj}=0$ for $j\leq n-2$. Since $a_{n,n-1}\neq0$, this determines $x_{n-1}$ uniquely from $x_n$.

Proceed upward. For $2\leq i\leq n$, the $i$th row has the form
\[
a_{i,i-1}x_{i-1}
+(a_{ii}-\lambda)x_i
+\sum_{j=i+1}^n a_{ij}x_j
=0,
\]
because all entries in columns $j\leq i-2$ vanish. Since $a_{i,i-1}\neq0$, once $x_i,\ldots,x_n$ are known, this equation uniquely determines $x_{i-1}$. Descending induction therefore determines every coordinate from $x_n$.
:::

<1>2. For every $\lambda\in\mathbb C$,
\[
\dim\ker(A-\lambda I)\leq1.
\]

::: {.proof}
By step <1>1, the linear map
\[
\ker(A-\lambda I)\longrightarrow\mathbb C,
\qquad
x\longmapsto x_n,
\]
is injective: if $x_n=0$, the downward recurrence forces every coordinate of $x$ to be zero. Hence the kernel has dimension at most $1$.
:::

<1>3. For each eigenvalue $\lambda$ of $A$, there is exactly one Jordan block belonging to $\lambda$.

::: {.proof}
In Jordan normal form, each Jordan block with eigenvalue $\lambda$ contributes exactly one basis vector to
\[
\ker(A-\lambda I),
\]
and blocks with other eigenvalues contribute none. Thus the number of Jordan blocks for $\lambda$ equals the geometric multiplicity
\[
\dim\ker(A-\lambda I).
\]
If $\lambda$ is an eigenvalue this dimension is at least $1$, while step <1>2 shows that it is at most $1$. Hence it equals $1$.
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>3 proves that no eigenvalue can have more than one Jordan block.
:::

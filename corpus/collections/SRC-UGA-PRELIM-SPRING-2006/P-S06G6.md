::: {.problem}
Let $f$ be a Riemann integrable function on a closed interval $[a, b]$.
For $x \in [a, b]$, let $g(x) = \int_a^x f(t)\,dt$.
Prove that $g$ is continuous.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Since $f$ is Riemann integrable on $[a,b]$, it is bounded: there is $M$ with $\abs{f(t)} \le M$ for all $t \in [a,b]$.

::: pf-proof

Riemann integrable functions are bounded.

:::

:::

::: {.pf-step #s2}

For $x, y \in [a,b]$,
$$\abs{g(x) - g(y)} = \abs{ \int_a^x f - \int_a^y f } = \abs{ \int_y^x f(t)\,dt } \le M \abs{x - y}.$$

::: pf-proof

Step [](#s1){.pf-ref} and the triangle inequality for integrals.

:::

:::

::: {.pf-step #s3}

Hence $g$ is Lipschitz continuous (with constant $M$).

::: pf-proof

Step [](#s2){.pf-ref} gives $\abs{g(x)-g(y)}\le M\abs{x-y}$ for all $x,y\in[a,b]$, which is the Lipschitz condition with constant $M$ (the case $x<y$ is the same estimate read with the oriented integral, since $\int_y^x f=-\int_x^y f$).

:::

:::

::: {.pf-step #s4}

Therefore $g$ is continuous.

::: pf-proof

Let $x\in[a,b]$ and $\varepsilon>0$. With $\delta=\varepsilon/(M+1)$ one has $\delta>0$, and for $y\in[a,b]$ with $\abs{x-y}<\delta$ step [](#s3){.pf-ref} gives $\abs{g(x)-g(y)}\le M\abs{x-y}<M\delta<\varepsilon$. So $g$ is continuous at every point of $[a,b]$.

:::

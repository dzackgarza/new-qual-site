::: {.problem}
Let $\Omega\subset\mathbb{C}$ be a connected open set, let $z_0\in\Omega$, and let $\mathcal{U}$ be the set of positive harmonic functions $U$ on $\Omega$ such that $U(z_0)=1$.
Prove that for every compact set $K\subset\Omega$ there is a finite constant $M$ (depending on $\Omega$, $z_0$ and $K$) such that $$\sup_{U\in\mathcal{U}}\sup_{z\in K}U(z)\le M.$$ You may use Harnack's inequality for the disk without proving it, provided you state it correctly.
:::

::: {.solution}
We use the following disk form of Harnack's inequality.
If $u$ is positive and harmonic on the disk $D(a,R)$, then for every $z\in D(a,R)$,
\[
\frac{R-|z-a|}{R+|z-a|}\,u(a)
\le u(z)
\le
\frac{R+|z-a|}{R-|z-a|}\,u(a).
\]
In particular, if $|z-a|\le R/2$, then
\[
\frac13u(a)\le u(z)\le3u(a).
\]

Let $G\subseteq\Omega$ be the set of points $a$ for which there exist an open neighborhood $V_a\subseteq\Omega$ and a constant $C_a<\infty$ such that
\[
U(w)\le C_a
\qquad
\text{for every }w\in V_a\text{ and every }U\in\mathcal U.
\]

<1>1. The set $G$ is nonempty.
::: {.proof}
Choose $R>0$ such that
\[
\overline{D(z_0,R)}\subseteq\Omega.
\]
For every $U\in\mathcal U$ and every $w\in D(z_0,R/2)$, Harnack's inequality gives
\[
U(w)\le3U(z_0)=3.
\]
Thus $z_0\in G$, with
\[
V_{z_0}=D(z_0,R/2)
\qquad\text{and}\qquad
C_{z_0}=3.
\]
:::

<1>2. The set $G$ is open in $\Omega$.
::: {.proof}
Let $a\in G$ and choose $V_a,C_a$ as in the definition of $G$.
Every point $b\in V_a$ has the same open neighborhood $V_a$ on which
\[
U(w)\le C_a
\]
for all $U\in\mathcal U$.
Hence $V_a\subseteq G$.
Therefore $G$ is open.
:::

<1>3. The set $G$ is closed relative to $\Omega$.
::: {.proof}
Suppose $a_j\in G$ and
\[
a_j\longrightarrow a\in\Omega.
\]
Choose $R>0$ such that
\[
\overline{D(a,R)}\subseteq\Omega.
\]
For all sufficiently large $j$,
\[
|a_j-a|<\frac R4.
\]
Fix one such index $j$.
Since $a_j\in G$, there is a finite constant $C_j$ such that, in particular,
\[
U(a_j)\le C_j
\qquad(U\in\mathcal U).
\]

Apply the lower Harnack inequality in the disk $D(a,R)$ at the point $a_j$.
Writing $\rho=|a_j-a|<R/4$, we obtain
\[
U(a_j)
\ge
\frac{R-\rho}{R+\rho}U(a),
\]
so
\[
U(a)
\le
\frac{R+\rho}{R-\rho}U(a_j)
\le
\frac53C_j
\qquad(U\in\mathcal U).
\]
Now if $w\in D(a,R/2)$, the upper Harnack inequality gives
\[
U(w)\le3U(a)\le5C_j
\qquad(U\in\mathcal U).
\]
Thus the whole neighborhood $D(a,R/2)$ has a uniform bound over $\mathcal U$, so $a\in G$.
Therefore $G$ is relatively closed in $\Omega$.
:::

<1>4. One has $G=\Omega$.
::: {.proof}
By <1>1, $G$ is nonempty.
By <1>2 and <1>3, it is both open and closed relative to the connected space $\Omega$.
Hence
\[
G=\Omega.
\]
:::

<1>5. The family $\mathcal U$ is uniformly bounded on every compact set $K\subseteq\Omega$.
::: {.proof}
By <1>4, for every $a\in K$ choose an open neighborhood $V_a$ and a finite constant $C_a$ such that
\[
U(w)\le C_a
\qquad
(w\in V_a,\ U\in\mathcal U).
\]
The sets $V_a$, $a\in K$, form an open cover of the compact set $K$.
Choose a finite subcover
\[
K\subseteq V_{a_1}\cup\cdots\cup V_{a_N}.
\]
Set
\[
M=\max_{1\le j\le N}C_{a_j}.
\]
If $z\in K$ and $U\in\mathcal U$, then $z\in V_{a_j}$ for some $j$, and hence
\[
U(z)\le C_{a_j}\le M.
\]
Therefore
\[
\sup_{U\in\mathcal U}\sup_{z\in K}U(z)\le M<\infty.
\]
:::

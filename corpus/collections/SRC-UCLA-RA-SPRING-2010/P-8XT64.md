::: {.problem}
Let $1\le p<\infty$.

(a) Show that if a sequence of real-valued functions $\{f_n\}_{n\ge 1}$ converges in $L^p(\mathbb{R})$, then it contains a subsequence that converges almost everywhere.

(b) Give an example of a sequence of functions converging to zero in $L^2(\mathbb{R})$ that does not converge almost everywhere.
:::

::: {.solution}
Suppose first that
\[
f_n\longrightarrow f
\qquad\text{in }L^p(\mathbb R).
\]

<1>1. There is a subsequence $\{f_{n_k}\}$ such that
\[
\sum_{k=1}^{\infty}\|f_{n_k}-f\|_p^p<\infty.
\]
::: {.proof}
Since $\|f_n-f\|_p\to0$, for each $k\ge1$ one can choose
\[
n_k>n_{k-1}
\]
so large that
\[
\|f_{n_k}-f\|_p^p<2^{-k}.
\]
Therefore
\[
\sum_{k=1}^{\infty}\|f_{n_k}-f\|_p^p
\le\sum_{k=1}^{\infty}2^{-k}<\infty.
\]
:::

<1>2. The subsequence $f_{n_k}$ converges to $f$ almost everywhere.
::: {.proof}
By Tonelli's theorem and <1>1,
\[
\begin{aligned}
\int_{\mathbb R}
\sum_{k=1}^{\infty}|f_{n_k}(x)-f(x)|^p\,dx
&=
\sum_{k=1}^{\infty}
\int_{\mathbb R}|f_{n_k}(x)-f(x)|^p\,dx\\
&=
\sum_{k=1}^{\infty}\|f_{n_k}-f\|_p^p\\
&<\infty.
\end{aligned}
\]
Hence
\[
\sum_{k=1}^{\infty}|f_{n_k}(x)-f(x)|^p<\infty
\]
for almost every $x$.
At each such $x$, the terms of this convergent nonnegative series tend to zero, so
\[
|f_{n_k}(x)-f(x)|^p\longrightarrow0.
\]
Thus
\[
f_{n_k}(x)\longrightarrow f(x)
\]
for almost every $x$.
This proves part (a).
:::

For part (b), define a sequence by traversing all dyadic subintervals of $[0,1)$ one level at a time.
For each $n\ge1$, write uniquely
\[
n=2^k+j,
\qquad
k\ge0,
\qquad
0\le j<2^k,
\]
and set
\[
g_n=\chi_{[j2^{-k},(j+1)2^{-k})}.
\]

<1>3. One has
\[
g_n\longrightarrow0
\qquad\text{in }L^2(\mathbb R).
\]
::: {.proof}
If $n=2^k+j$ as above, then
\[
\|g_n\|_2^2
=
\left|[j2^{-k},(j+1)2^{-k})\right|
=2^{-k}.
\]
As $n\to\infty$, necessarily $k\to\infty$ because
\[
2^k\le n<2^{k+1}.
\]
Therefore
\[
\|g_n\|_2^2=2^{-k}\longrightarrow0,
\]
and hence $\|g_n\|_2\to0$.
:::

<1>4. The sequence $g_n(x)$ does not converge for any $x\in[0,1)$.
::: {.proof}
Fix $x\in[0,1)$.
For each level $k$, the half-open dyadic intervals
\[
[j2^{-k},(j+1)2^{-k}),
\qquad 0\le j<2^k,
\]
form a partition of $[0,1)$.
Thus exactly one index $j_k$ satisfies
\[
x\in[j_k2^{-k},(j_k+1)2^{-k}),
\]
so
\[
g_{2^k+j_k}(x)=1.
\]
Hence the sequence takes the value $1$ infinitely often.

For every $k\ge1$, there is also some $j\ne j_k$ with $0\le j<2^k$.
For that index,
\[
g_{2^k+j}(x)=0.
\]
Thus the sequence also takes the value $0$ infinitely often.
Consequently $g_n(x)$ cannot converge.
:::

<1>5. The sequence $g_n$ is therefore the required counterexample.
::: {.proof}
By <1>3, $g_n\to0$ in $L^2(\mathbb R)$.
By <1>4, pointwise convergence fails at every point of $[0,1)$, a set of Lebesgue measure $1$.
Hence $g_n$ does not converge almost everywhere.
:::

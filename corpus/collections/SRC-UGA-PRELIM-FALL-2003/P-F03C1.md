::: {.problem}
a) Let $f$ be a function defined on an interval $(a,b)$ and let $c \in (a,b)$.
Define what it means to say that $f$ is continuous at $c$.

b) Use this definition to show that $f(x) = 1/x$ is continuous at $x = 1$.
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.

::: pf

::: {.pf-step #definition}
(a) A function $f$ on an interval $(a,b)$ is continuous at $c\in(a,b)$ if for every $\varepsilon>0$ there is $\delta>0$ such that every $x\in(a,b)$ with $\abs{x-c}<\delta$ satisfies $\abs{f(x)-f(c)}<\varepsilon$.

::: pf-proof
This is the $\varepsilon$-$\delta$ definition of continuity at a point of the domain; $c$ is an interior point of the interval, so points of the domain on either side of $c$ are available.
:::

:::

::: {.pf-step #delta}
For every $\varepsilon>0$ the number $\delta\coloneqq\min\left\{\frac12,\frac{\varepsilon}{2}\right\}$ is positive, and $2\delta\le\varepsilon$.

::: pf-proof
Both entries of the minimum are positive, so $\delta>0$; and $\delta\le\frac{\varepsilon}{2}$ gives $2\delta\le\varepsilon$.
:::

:::

::: {.pf-step #window}
If $\abs{x-1}<\delta$ for the $\delta$ of step [](#delta){.pf-ref}, then $x>\frac12$, so $x\ne0$ and $\abs{x}>\frac12$.

::: pf-proof
$\delta\le\frac12$ by step [](#delta){.pf-ref}, so $x\in\left(\frac12,\frac32\right)$, and on that interval $x>\frac12>0$, whence $\abs{x}=x>\frac12$.
:::

:::

::: {.pf-step #estimate}
If $\varepsilon>0$ and $0<\abs{x-1}<\delta$ for the $\delta$ of step [](#delta){.pf-ref}, then $\abs{\frac1x-1}<\varepsilon$.

::: pf-proof
By step [](#window){.pf-ref} the quotient is defined, and
$$
\abs{\frac1x-1}=\frac{\abs{1-x}}{\abs{x}}=\frac{\abs{x-1}}{\abs{x}}<2\abs{x-1}<2\delta\le\varepsilon,
$$
the first inequality using $\abs{x}>\frac12$, the second $\abs{x-1}<\delta$, the third step [](#delta){.pf-ref}.
:::

:::

::: {.pf-step}
(b) $f(x)=\frac1x$ is continuous at $x=1$.

::: pf-proof
Take the interval $(0,2)$, on which $f$ is defined and whose interior contains $1$. Steps [](#delta){.pf-ref} and [](#estimate){.pf-ref} produce, for every $\varepsilon>0$, a $\delta>0$ such that every $x$ with $\abs{x-1}<\delta$ satisfies $\abs{f(x)-f(1)}<\varepsilon$, which is continuity at $1$ by step [](#definition){.pf-ref}.
:::

::: {.problem}
Let $a _ { 1 } , a _ { 2 } , \ldots , a _ { n }$ be complex numbers. Prove that there is a point x in [0, 1] such that

$$
\left| 1 - \sum _ { k = 1 } ^ { n } a _ { k } e ^ { 2 \pi i k x } \right| \geqslant 1 .
$$

::: {.problem}
Let F be a finite field with q elements. Say that a function $f : \mathbf { F }  \mathbf { F }$ is a polynomial function if there are elements $a _ { 0 } , a _ { 1 } , \ldots , a _ { n }$ of F such that $f ( x ) = a _ { 0 } + a _ { 1 } x + \cdot \cdot \cdot + a _ { n } x ^ { n }$ for all $x \in \mathbf { F }$ . How many polynomial functions are there?
:::

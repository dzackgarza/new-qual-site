::: {.problem}
Let $\mathbf{F}$ be a finite field with $q$ elements. Say that a function $f : \mathbf{F} \to \mathbf{F}$ is a polynomial function if there are elements $a_0, a_1, \ldots, a_n$ of $\mathbf{F}$ such that $f(x) = a_0 + a_1 x + \cdots + a_n x^n$ for all $x \in \mathbf{F}$. How many polynomial functions are there?
:::

::: {.solution}
<1>1. Every function
$$
f:\mathbf F\longrightarrow\mathbf F
$$
is a polynomial function.

::: {.proof}
List the elements of the field as
$$
\mathbf F=\{\alpha_1,\ldots,\alpha_q\}.
$$
For each $i$, define the Lagrange polynomial
$$
L_i(x)
\coloneqq
\prod_{j\neq i}
\frac{x-\alpha_j}{\alpha_i-\alpha_j}.
$$
All denominators are nonzero because the $\alpha_i$ are distinct. These
polynomials satisfy
$$
L_i(\alpha_j)
=
\begin{cases}
1,&i=j,\\
0,&i\neq j.
\end{cases}
$$

Given any function $f:\mathbf F\to\mathbf F$, set
$$
p(x)
\coloneqq
\sum_{i=1}^q f(\alpha_i)L_i(x).
$$
Then
$$
p(\alpha_j)=f(\alpha_j)
$$
for every $j$. Thus $p$ represents $f$ as a polynomial function.
:::

<1>2. The number of functions from $\mathbf F$ to itself is
$$
q^q.
$$

::: {.proof}
There are $q$ independent choices for the value of a function at each of
the $q$ elements of its domain.
:::

<1>3. The number of polynomial functions is
$$
\boxed{q^q}.
$$

::: {.proof}
By step <1>1, every set-theoretic function $\mathbf F\to\mathbf F$ is a
polynomial function. Step <1>2 counts all such functions.
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>3 gives the requested number.
:::
:::

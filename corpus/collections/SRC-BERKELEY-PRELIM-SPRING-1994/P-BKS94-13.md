::: {.problem}
Let $\mathbf{F}$ be a finite field with $q$ elements. Say that a function $f : \mathbf{F} \to \mathbf{F}$ is a polynomial function if there are elements $a_0, a_1, \ldots, a_n$ of $\mathbf{F}$ such that $f(x) = a_0 + a_1 x + \cdots + a_n x^n$ for all $x \in \mathbf{F}$. How many polynomial functions are there?
:::

::: {.problem}
Let W be a real $\mathcal { B } { \times } \mathcal { B }$ antisymmetric matrix, i.e., $W ^ { t } = - W$ Let the function

$$
X ( t ) = { \binom { x _ { 1 } ( t ) } { x _ { 2 } ( t ) } }
$$

be a real solution of the vector differential equation ${ \frac { d X } { d t } } = W X$

1. Prove that $\| X ( t ) \|$ , the Euclidean norm of $X ( t )$ , is independent $o f t$

2. Prove that if v is a vector in the null space of $W$ , then $X ( t ) \cdot v$ is independent of t.

3. Prove that the values $X ( t )$ all lie on a fixed circle in $\mathbb { R } ^ { 3 }$

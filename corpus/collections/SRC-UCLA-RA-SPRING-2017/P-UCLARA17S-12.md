::: {.problem}
Problem 12. Let 0 < α < 1 and let f (z) be an analytic function on the unit disc
D. Prove that if

                           |f (z) − f (w)| ≤ C|z − w|α
for all z, w ∈ D and some constant C ∈ R, then there is constant A = A(C) < ∞
such that

                              |f 0 (z)| ≤ A(1 − |z|)α−1 .
:::

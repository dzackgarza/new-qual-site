::: {.problem}
Let $\Lambda\subset\RR^n$ be a discrete subgroup.
Prove that
\[
\Lambda\cong\ZZ^a
\]
for some $a\le n$, and that $a=n$ if and only if $\RR^n/\Lambda$ is compact.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Let
\[
V=\operatorname{span}_{\RR}(\Lambda),
\qquad
a=\dim_{\RR}V\le n.
\]
Choose $v_1,\ldots,v_a\in\Lambda$ which form a real basis of $V$, and set
\[
L=\mathbb Zv_1+\cdots+\mathbb Zv_a\subseteq\Lambda.
\]
Then $L\cong\ZZ^a$.

::: pf-proof

Because the $v_i$ are linearly independent over $\RR$, they are also linearly independent over $\ZZ$. Hence the homomorphism
\[
\ZZ^a\longrightarrow L,
\qquad
(m_1,\ldots,m_a)\longmapsto\sum_i m_iv_i
\]
is an isomorphism.

:::

:::

::: {.pf-step #s2}

The subgroup $L$ has finite index in $\Lambda$.

::: pf-proof

Consider the compact parallelepiped
\[
P=\left\{\sum_{i=1}^a t_iv_i:0\le t_i\le1\right\}\subset V.
\]
Every $\lambda\in\Lambda$ can be written $\lambda=\sum_i x_iv_i$. Subtracting
\[
\sum_i\lfloor x_i\rfloor v_i\in L
\]
produces a representative of the coset $\lambda+L$ lying in $P\cap\Lambda$.

The set $P\cap\Lambda$ is finite. Indeed, if it were infinite, compactness of $P$ would give distinct $\lambda_j\in P\cap\Lambda$ with a convergent subsequence. Then
\[
\lambda_j-\lambda_k\longrightarrow0.
\]
Since $\Lambda$ is discrete, some neighborhood of $0$ contains no nonzero element of $\Lambda$, so for sufficiently large $j,k$ one would have $\lambda_j-\lambda_k=0$, a contradiction. Thus only finitely many cosets of $L$ occur in $\Lambda$, i.e.
\[
[\Lambda:L]<\infty.
\]

:::

:::

::: pf-step

One has
\[
\Lambda\cong\ZZ^a.
\]

::: pf-proof

By step [](#s2){.pf-ref}, $\Lambda$ is finitely generated: adjoining finitely many representatives for $\Lambda/L$ to the basis $v_1,\ldots,v_a$ generates it. It is torsion-free because it is a subgroup of the additive group $\RR^n$. Hence the structure theorem for finitely generated abelian groups gives
\[
\Lambda\cong\ZZ^r
\]
for some $r$.

Since $L\subseteq\Lambda$ has finite index, tensoring the inclusion with $\QQ$ gives an isomorphism
\[
L\otimes_{\ZZ}\QQ
\cong
\Lambda\otimes_{\ZZ}\QQ.
\]
The left side has dimension $a$ over $\QQ$, while the right side has dimension $r$. Therefore $r=a$.

:::

:::

::: pf-step

If $a=n$, then $\RR^n/\Lambda$ is compact.

::: pf-proof

When $a=n$, the subgroup $L$ from step [](#s1){.pf-ref} is a full-rank lattice in $\RR^n$. Its compact parallelepiped $P$ maps surjectively onto $\RR^n/L$, so $\RR^n/L$ is compact. Since $L\subseteq\Lambda$, the natural map
\[
\RR^n/L\longrightarrow\RR^n/\Lambda
\]
is continuous and surjective. Therefore $\RR^n/\Lambda$ is compact.

:::

:::

::: pf-step

If $\RR^n/\Lambda$ is compact, then $a=n$.

::: pf-proof

Because $\Lambda\subseteq V$, there is a well-defined continuous surjection
\[
\RR^n/\Lambda\longrightarrow\RR^n/V,
\qquad
x+\Lambda\longmapsto x+V.
\]
If $a<n$, then
\[
\RR^n/V\cong\RR^{n-a}
\]
is noncompact. It cannot be the continuous image of the compact space $\RR^n/\Lambda$. Hence $a=n$.

:::

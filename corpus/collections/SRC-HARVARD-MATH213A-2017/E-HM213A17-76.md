::: {.problem}
Let
\[
I=(f_1,f_2,\ldots)\subset\mathcal O(\mathbb C),
\qquad
f_n(z)=\frac{\sin(z/n)}{z}.
\]

(a) Prove that $I\ne\mathcal O(\mathbb C)$.

(b) Prove that $I$ is not contained in any proper principal ideal.

(c) Conclude that $\mathcal O(\mathbb C)$ is not a PID and that it has maximal ideals which are not of the form $(z-a)$.
:::

::: {.solution}
Each $f_n$ extends holomorphically across $0$, with $f_n(0)=1/n$, and its
nonzero zeros are
\[
Z(f_n)=\{\pi nk:k\in\mathbb Z\setminus\{0\}\}.
\]

<1>1. Any finite collection $f_{n_1},\ldots,f_{n_m}$ has a common nonzero
zero.
::: {.proof}
Let
\[
L=\operatorname{lcm}(n_1,\ldots,n_m).
\]
Then $L/n_j$ is a positive integer for every $j$, so
\[
f_{n_j}(\pi L)
=\frac{\sin(\pi L/n_j)}{\pi L}
=0.
\]
Thus $\pi L$ is a common zero.
:::

<1>2. The ideal $I$ is proper.
::: {.proof}
Every element of $I$ is a finite sum
\[
h_1f_{n_1}+\cdots+h_mf_{n_m},
\qquad h_j\in\mathcal O(\mathbb C).
\]
By <1>1, this function vanishes at $\pi L$ for
$L=\operatorname{lcm}(n_1,\ldots,n_m)$. Hence no element of $I$ can be the
constant function $1$. Therefore
\[
I\neq\mathcal O(\mathbb C).
\]
:::

<1>3. The family $(f_n)_{n\ge1}$ has no common zero.
::: {.proof}
The point $0$ is not a zero of any $f_n$, since $f_n(0)=1/n$. If
$z\neq0$ were a common zero, then for every $n$ one would have
\[
z=\pi nk_n
\]
for some nonzero integer $k_n$. In particular $z/\pi$ would be an integer
divisible by every positive integer $n$, which is impossible for a fixed
nonzero integer. Thus there is no common zero.
:::

<1>4. The ideal $I$ is not contained in any proper principal ideal.
::: {.proof}
Suppose
\[
I\subset(g)
\]
for some entire function $g$. Then $g$ divides every $f_n$. Consequently
every zero of $g$ would be a zero of every $f_n$. By <1>3, $g$ has no zeros.
Therefore $1/g$ is entire, so $g$ is a unit and
\[
(g)=\mathcal O(\mathbb C).
\]
Thus no proper principal ideal can contain $I$.
:::

<1>5. The ring $\mathcal O(\mathbb C)$ is not a PID.
::: {.proof}
By <1>2, $I$ is proper. If it were principal, say $I=(g)$, then it would be
contained in the proper principal ideal $(g)$, contradicting <1>4. Hence the
ring has a nonprincipal ideal and is not a PID.
:::

<1>6. There is a maximal ideal containing $I$ which is not of the form
$(z-a)$.
::: {.proof}
Since $I$ is proper, Zorn's lemma gives a maximal ideal
\[
I\subset M\subsetneq\mathcal O(\mathbb C).
\]
If $M=(z-a)$ for some $a\in\mathbb C$, then every $f_n\in I\subset M$
would satisfy $f_n(a)=0$. This would make $a$ a common zero of all the
$f_n$, contradicting <1>3. Hence this maximal ideal is not an evaluation
ideal $(z-a)$.
:::

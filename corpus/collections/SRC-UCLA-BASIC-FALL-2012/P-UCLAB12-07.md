::: {.problem}
Let A be an invertible n by n matrix with entries in $\mathbb { C }$.
Suppose that the set of powers $A ^ { n }$ of A, for $n \in \mathbb { Z } ,$ is bounded.
Show that A is diagonalizable.
:::

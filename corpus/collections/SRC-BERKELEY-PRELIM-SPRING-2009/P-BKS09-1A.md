::: {.problem}
Suppose that f is a continuous real function on [0, 1]. Prove that

$$
\operatorname* { l i m } _ { \alpha \to 0 ^ { + } } \alpha \int _ { 0 } ^ { 1 } x ^ { \alpha - 1 } f ( x ) d x = f ( 0 ) .
$$
:::

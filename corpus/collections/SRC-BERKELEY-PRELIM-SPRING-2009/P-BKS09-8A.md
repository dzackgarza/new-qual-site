::: {.problem}
Let $\mathbb { Q } ( x )$ be the field of rational functions of one variable over $\mathbb { Q } .$ Let $i \colon \mathbb { Q } ( x )  \mathbb { Q } ( x )$ be the unique field automorphism such that $i ( x ) = x ^ { - 1 }$ . Prove that the subfield of elements fixed by i is equal to $\mathbb { Q } ( x + x ^ { - 1 } )$ .
:::

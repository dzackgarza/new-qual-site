::: {.problem}
Show that if $f : \mathbb { C } \to \hat { \mathbb { C } }$ is a meromorphic function in the plane, such that there exists $R , C > 0$ so that for $| z | > R , | f ( z ) | \leq C | z | ^ { n }$ , then f is a rational function.
:::

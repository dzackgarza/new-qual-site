::: {.problem}
Mark each statement true or false. No justifications are required.

1. If $Ax=0$ has at least one solution, then $Ax=b$ has at least one solution for every $b$.
2. If $A$ is orthogonal, then every entry satisfies $|A_{ij}|\le1$.
3. $T(f)(x)=f(x^2)-23f(x)$ is linear on the vector space of polynomials.
4. If a smooth function on $[-\pi,\pi]$ has a sine Fourier expansion, then its integral over $[-\pi,\pi]$ is zero.
5. Characteristic polynomials satisfy $f_A(\lambda)+f_B(\lambda)=f_{A+B}(\lambda)$.
6. $23e^{10t}$ is an eigenfunction of $D$ with eigenvalue $23$.
7. $(A^{23})(A^{23})^T$ is diagonalizable for every real square matrix $A$.
8. The problem $f''+23f'+10f=x+e^x$, $f'''(0)=0$, has exactly one solution.
9. $T(f)(x)=\sin(x)f(\sin x)$ is linear on $C^\infty(\RR)$.
10. The smooth solutions of $f_{ttt}-f_{xxx}=f_x$ form a vector space.
11. If $A$ is a $23\times23$ matrix of rank $23$, then $0$ is an eigenvalue.
12. Relative to the basis $((1,2)^T,(0,2)^T)$, the vector $(1,0)^T$ has coordinates $(1,-1)^T$.
13. If every geometric multiplicity equals the corresponding algebraic multiplicity, then the matrix is diagonalizable.
14. Every equilibrium point of $\dot x=f(x,y)$, $\dot y=g(x,y)$ lies at an intersection of two nullclines.
15. If $z=2i$, then its square roots are $1+i$ and $1-i$.
16. Every $2\times2$ matrix satisfies $\operatorname{tr}A\le\det A$.
17. If $A$ is upper triangular with positive diagonal entries, then $A=IR$ with $R=A$ is its QR decomposition.
18. If both trace and determinant of a $2\times2$ matrix vanish, then the matrix is zero.
19. Every nonzero solution of $x(t+1)=x(t)+23x(t-1)$ has $|x(t)|\to\infty$.
20. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\|\sin x+\cos(23x)\|=\sqrt2$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Statement 1 is $\boxed{\mathrm{F}}$.


::: pf-proof

The equation $Ax=0$ always has the solution $x=0$, but this does not make $A$ surjective. For example, if $A=0$ and $b\ne0$, then $Ax=b$ has no solution.

:::

:::

::: {.pf-step #s1-2}

Statement 2 is $\boxed{\mathrm{T}}$.


::: pf-proof

Every row of an orthogonal matrix has Euclidean norm $1$. Hence
\[
\sum_j A_{ij}^2=1,
\]
so each summand satisfies $A_{ij}^2\le1$ and therefore $|A_{ij}|\le1$.

:::

:::

::: {.pf-step #s1-3}

Statement 3 is $\boxed{\mathrm{T}}$.


::: pf-proof

For polynomials $f,g$ and scalars $a,b$,
\[
T(af+bg)(x)
=a f(x^2)+b g(x^2)-23a f(x)-23b g(x)
=aT(f)(x)+bT(g)(x).
\]
Thus $T$ is linear.

:::

:::

::: {.pf-step #s1-4}

Statement 4 is $\boxed{\mathrm{T}}$.


::: pf-proof

A sine Fourier expansion lies in the span of the functions $\sin(nx)$, each of which is orthogonal to the constant function $1$ on $[-\pi,\pi]$. Hence
\[
0=\langle f,1\rangle
=\frac1\pi\int_{-\pi}^{\pi}f(x)\,dx,
\]
which gives the asserted integral.

:::

:::

::: {.pf-step #s1-5}

Statement 5 is $\boxed{\mathrm{F}}$.


::: pf-proof

Already in dimension one, take $A=B=(0)$. Then
\[
f_A(\lambda)+f_B(\lambda)=2\lambda,
\qquad
f_{A+B}(\lambda)=\lambda,
\]
under the convention $f_A(\lambda)=\det(\lambda I-A)$. Thus characteristic polynomials are not additive.

:::

:::

::: {.pf-step #s1-6}

Statement 6 is $\boxed{\mathrm{F}}$.


::: pf-proof

Differentiation gives
\[
D(23e^{10t})=230e^{10t}=10(23e^{10t}),
\]
so the eigenvalue is $10$, not $23$.

:::

:::

::: {.pf-step #s1-7}

Statement 7 is $\boxed{\mathrm{T}}$.


::: pf-proof

Let $C=A^{23}$. Then
\[
(A^{23})(A^{23})^T=CC^T,
\]
which is real symmetric. The spectral theorem therefore makes it orthogonally diagonalizable.

:::

:::

::: {.pf-step #s1-8}

Statement 8 is $\boxed{\mathrm{F}}$.


::: pf-proof

The differential equation is second order, so its full solution set is an affine space modeled on the two-dimensional solution space of
\[
h''+23h'+10h=0.
\]
Its characteristic roots are nonzero. Hence for either exponential solution $h(t)=e^{rt}$ one has $h'''(0)=r^3\ne0$, so the linear functional $h\mapsto h'''(0)$ on the two-dimensional homogeneous solution space is nonzero and therefore surjective onto $\RR$. Starting from any particular solution, one can therefore impose $f'''(0)=0$, and the set of homogeneous corrections satisfying that condition is an affine line. Thus there are infinitely many solutions rather than exactly one.

:::

:::

::: {.pf-step #s1-9}

Statement 9 is $\boxed{\mathrm{T}}$.


::: pf-proof

For scalars $a,b$ and smooth functions $f,g$,
\[
T(af+bg)(x)
=\sin x\bigl(a f(\sin x)+b g(\sin x)\bigr)
=aT(f)(x)+bT(g)(x).
\]
Composition with $\sin x$ and multiplication by $\sin x$ also preserve smoothness, so $T$ is a linear endomorphism of $C^\infty(\RR)$.

:::

:::

::: {.pf-step #s1-10}

Statement 10 is $\boxed{\mathrm{T}}$.


::: pf-proof

The displayed equation is
\[
L(f):=f_{ttt}-f_{xxx}-f_x=0,
\]
where $L$ is linear. Its solution set is therefore the kernel of a linear map and hence a vector space.

:::

:::

::: {.pf-step #s1-11}

Statement 11 is $\boxed{\mathrm{F}}$.


::: pf-proof

A $23\times23$ matrix of rank $23$ is invertible, so its kernel is trivial. Thus $Ax=0$ has no nonzero solution, equivalently $0$ is not an eigenvalue.

:::

:::

::: {.pf-step #s1-12}

Statement 12 is $\boxed{\mathrm{T}}$.


::: pf-proof

Indeed,
\[
1\binom12-1\binom02=\binom10,
\]
so the coordinates of $(1,0)^T$ in the stated basis are $(1,-1)^T$.

:::

:::

::: {.pf-step #s1-13}

Statement 13 is $\boxed{\mathrm{T}}$.


::: pf-proof

Over a splitting field, the algebraic multiplicities of the eigenvalues sum to the dimension of the matrix. If each geometric multiplicity equals the corresponding algebraic multiplicity, then the direct sum of all eigenspaces has that full dimension. Hence there is a basis of eigenvectors, so the matrix is diagonalizable.

:::

:::

::: {.pf-step #s1-14}

Statement 14 is $\boxed{\mathrm{T}}$.


::: pf-proof

At an equilibrium $(x_0,y_0)$ one has
\[
f(x_0,y_0)=0,
\qquad
g(x_0,y_0)=0.
\]
Thus the point lies on both the $x$-nullcline and the $y$-nullcline, hence at their intersection.

:::

:::

::: {.pf-step #s1-15}

Statement 15 is $\boxed{\mathrm{F}}$.


::: pf-proof

One has
\[
(1+i)^2=2i,
\qquad
(1-i)^2=-2i.
\]
Therefore the two square roots of $2i$ are $1+i$ and $-(1+i)=-1-i$, not $1+i$ and $1-i$.

:::

:::

::: {.pf-step #s1-16}

Statement 16 is $\boxed{\mathrm{F}}$.


::: pf-proof

For $A=I_2$,
\[
\operatorname{tr}(A)=2>1=\det(A).
\]
Thus the proposed inequality does not hold for every $2\times2$ matrix.

:::

:::

::: {.pf-step #s1-17}

Statement 17 is $\boxed{\mathrm{T}}$.


::: pf-proof

The identity matrix $Q=I_n$ is orthogonal, and $R=A$ is upper triangular with positive diagonal entries. Hence
\[
A=I_nA=QR
\]
is a QR decomposition with the usual positive-diagonal convention for $R$.

:::

:::

::: {.pf-step #s1-18}

Statement 18 is $\boxed{\mathrm{F}}$.


::: pf-proof

The nonzero matrix
\[
A=\begin{pmatrix}1&1\\-1&-1\end{pmatrix}
\]
has trace $0$ and determinant $0$.

:::

:::

::: {.pf-step #s1-19}

Statement 19 is $\boxed{\mathrm{T}}$.


::: pf-proof

The characteristic equation of the recurrence is
\[
r^2-r-23=0,
\]
with roots
\[
r_+=\frac{1+\sqrt{93}}2,
\qquad
r_- =\frac{1-\sqrt{93}}2.
\]
They satisfy $r_+>|r_-|>1$. Every solution has the form
\[
x(t)=c_+r_+^t+c_-r_-^t.
\]
If $c_+\ne0$, then
\[
\frac{x(t)}{r_+^t}=c_++c_-\left(\frac{r_-}{r_+}\right)^t\longrightarrow c_+,
\]
so $|x(t)|\to\infty$. If $c_+=0$, then a nonzero solution has $c_-\ne0$ and $|x(t)|=|c_-||r_-|^t\to\infty$.

:::

:::

::: {.pf-step #s1-20}

Statement 20 is $\boxed{\mathrm{T}}$.


::: pf-proof

The Fourier modes $\sin x$ and $\cos(23x)$ are orthogonal for the stated inner product, and each has squared norm $1$. Therefore
\[
\|\sin x+\cos(23x)\|^2=1+1=2,
\]
so the norm is $\sqrt2$.

:::

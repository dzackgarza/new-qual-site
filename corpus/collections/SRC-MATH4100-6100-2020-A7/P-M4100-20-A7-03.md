::: {.problem}
(a) Let $f : [ 0 , 1 ] \to [ 0 , 1 ]$ be continuous.
Prove that f must have a fixed point; that is, show that there must exist $x \in [ 0 , 1 ]$ with the property that $f ( x ) = x$

(b) Let $f : [ 0 , 1 ] \to \mathbb { R }$ be continuous with $f ( 0 ) = f ( 1 )$

Show that there must exist $x \in [ 0 , 1 / 2 ]$ with the property that $f ( x ) = f ( x + 1 / 2 )$

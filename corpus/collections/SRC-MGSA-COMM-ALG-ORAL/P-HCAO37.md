::: {.problem}
Can a surjective homomorphism of rings fail to be finite?
:::

::: {.solution}

::: pf

::: {.pf-step #surjection-is-finite}
A surjective ring homomorphism $\phi: R \to S$ is always finite.

::: pf-proof

::: pf-step
$S$ is generated as an $R$-module by the single element $1_S$.

::: pf-proof
for any $s \in S$, surjectivity gives $r \in R$ with $\phi(r) = s$, so $s = \phi(r) = \phi(r \cdot 1_R) = r \cdot \phi(1_R) = r \cdot 1_S$.
:::

:::

::: pf-step
Hence $S$ is a finitely generated $R$-module.

::: pf-proof
it is generated by one element.
:::

:::

::: pf-step
Hence $\phi$ is finite.

::: pf-proof
a ring homomorphism is finite iff the target is a finitely generated module over the source.
:::

:::

:::

:::

::: pf-qed
By step [](#surjection-is-finite){.pf-ref} every surjective ring homomorphism is finite, so no surjective ring homomorphism fails to be finite.
:::

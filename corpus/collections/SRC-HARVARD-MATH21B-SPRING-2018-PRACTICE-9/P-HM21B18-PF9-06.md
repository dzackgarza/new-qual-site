::: {.problem}
(a) Find the $3\times3$ matrix for reflection in the plane $x=z$ in $\RR^3$.

(b) Find the $3\times3$ matrix for rotation by $180^\circ$ around the line perpendicular to the plane $x=z$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The reflection in the plane $x=z$ has matrix
\[
\boxed{
R=
\begin{pmatrix}
0&0&1\\
0&1&0\\
1&0&0
\end{pmatrix}.}
\]


::: pf-proof

Reflection in the plane $x=z$ interchanges the two coordinates perpendicular to that plane while fixing points of the plane. Explicitly,
\[
(x,y,z)\longmapsto(z,y,x).
\]
Hence
\[
e_1\mapsto e_3,
\qquad
e_2\mapsto e_2,
\qquad
e_3\mapsto e_1,
\]
and these image vectors are exactly the columns of the displayed matrix.

:::

:::

::: {.pf-step #s1-2}

The $180^\circ$ rotation about the line perpendicular to $x=z$ has matrix
\[
\boxed{
H=
\begin{pmatrix}
0&0&-1\\
0&-1&0\\
-1&0&0
\end{pmatrix}.}
\]


::: pf-proof

A normal vector to the plane $x=z$ is
\[
n=(1,0,-1)^T,
\]
so a unit vector along the rotation axis is $u=n/\sqrt2$. A half-turn fixes the component parallel to $u$ and negates the perpendicular component. Therefore its matrix is
\[
2uu^T-I_3
=
\begin{pmatrix}
1&0&-1\\
0&0&0\\
-1&0&1
\end{pmatrix}
-I_3
=
\begin{pmatrix}
0&0&-1\\
0&-1&0\\
-1&0&0
\end{pmatrix},
\]
as claimed.

:::

::: {.problem}
Find the determinant of the $36\times36$ matrix and document the determinant facts used.
:::

::: {.remark}
The $36\times36$ matrix is printed in the source exam.
:::

::: {.solution}
Let $M$ denote the $36\times36$ matrix in the source display and set
\[
C=\begin{pmatrix}2&1\\5&2\end{pmatrix}.
\]

<1>1. In $18\times18$ block form, the source matrix has the shape
\[
M=\begin{pmatrix}A&U\\0&B\end{pmatrix},
\]
where
\[
A=B=\operatorname{diag}(C,C,\ldots,C)
\]
with nine copies of $C$.

::: {.proof}
Reading the displayed source matrix by its first and last $18$ rows and columns, the lower-left $18\times18$ block consists entirely of zeros. In each diagonal $18\times18$ block, the only nonzero entries occur in nine successive $2\times2$ diagonal blocks, and each such block is
\[
\begin{pmatrix}2&1\\5&2\end{pmatrix}.
\]
The upper-right block $U$ does not affect the block-triangular determinant calculation.
:::

<1>2. The determinant of each diagonal $18\times18$ block is $-1$.

::: {.proof}
First,
\[
\det C=2\cdot2-5\cdot1=-1.
\]
Since $A$ and $B$ are block diagonal with nine copies of $C$,
\[
\det A=\det B=(\det C)^9=(-1)^9=-1.
\]
:::

<1>3. The determinant of the $36\times36$ matrix is
\[
\boxed{\det M=1.}
\]

::: {.proof}
The determinant of a block upper-triangular matrix with square diagonal blocks is the product of the determinants of those diagonal blocks. Hence, by steps <1>1 and <1>2,
\[
\det M=\det A\,\det B=(-1)(-1)=1.
\]
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>3 gives the required determinant from the recovered source matrix structure.
:::

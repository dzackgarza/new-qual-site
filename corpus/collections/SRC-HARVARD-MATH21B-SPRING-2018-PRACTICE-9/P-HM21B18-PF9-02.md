::: {.problem}
No justifications are required.

(a) Match the graphs A--C to
\[
f''+\frac15f'+f=0,\quad f(0)=1,\ f'(0)=0,
\]
\[
f''+f'+f=5\sin(4x),\quad f(0)=1,\ f'(0)=0,
\]
\[
f''+f=0,\quad f(0)=1,\ f'(0)=0.
\]

(b) Match phase portraits D--F to the continuous systems
\[
\dot x=\begin{pmatrix}-2&0\\-2&-2\end{pmatrix}x,
\qquad
\dot x=\begin{pmatrix}-1&0\\1&1\end{pmatrix}x,
\qquad
\dot x=\begin{pmatrix}2&0\\2&2\end{pmatrix}x.
\]
:::

::: {.remark}
The graphs A--C and the phase portraits D--F are printed in the source exam.
:::

::: pf

::: pf-step

The graph matching in part (a), in the order the equations are listed, is
\[
\boxed{C,\ B,\ A.}
\]


::: pf-proof

::: pf-step

The first equation matches graph $C$.


::: pf-proof

Its characteristic polynomial is
\[
r^2+\frac15r+1,
\]
whose roots have real part $-1/10$ and nonzero imaginary part. Hence its nonzero solutions oscillate with exponentially decaying amplitude. Among graphs $A$--$C$, graph $C$ is the decaying oscillation.

:::

:::

::: pf-step

The second equation matches graph $B$.


::: pf-proof

The homogeneous equation has characteristic roots
\[
-\frac12\pm\frac{\sqrt3}{2}i,
\]
so its transient part decays. The forcing $5\sin(4x)$ produces a nonzero persistent particular solution of frequency $4$. Thus the long-time behavior is a small, rapid periodic oscillation after a decaying transient, which is graph $B$.

:::

:::

::: pf-step

The third equation matches graph $A$.


::: pf-proof

The initial-value problem
\[
f''+f=0,
\qquad
f(0)=1,
\qquad
f'(0)=0
\]
has solution $f(x)=\cos x$. Its amplitude is constant, which is graph $A$.

:::

Steps <2>1--<2>3 identify all three graphs and establish the order stated in step <1>1.

:::

::: pf-step

The phase-portrait matching in part (b), in the order the matrices are listed, is
\[
\boxed{F,\ D,\ E.}
\]


::: pf-proof

::: pf-step

The first matrix matches portrait $F$.


::: pf-proof

For
\[
A_1=\begin{pmatrix}-2&0\\-2&-2\end{pmatrix},
\]
the only eigenvalue is $-2$, so every solution tends to the origin. The eigendirection is the $y$-axis. Portrait $F$ is the stable improper node whose arrows point toward the origin and whose distinguished straight trajectory is the vertical axis.

:::

:::

::: pf-step

The second matrix matches portrait $D$.


::: pf-proof

For
\[
A_2=\begin{pmatrix}-1&0\\1&1\end{pmatrix},
\]
the eigenvalues are $-1$ and $1$. Hence the origin is a saddle, with one stable and one unstable eigendirection. Portrait $D$ is the saddle portrait.

:::

:::

::: pf-step

The third matrix matches portrait $E$.


::: pf-proof

For
\[
A_3=\begin{pmatrix}2&0\\2&2\end{pmatrix},
\]
the only eigenvalue is $2$, so every nonzero solution moves away from the origin in forward time. The eigendirection is again the $y$-axis. Portrait $E$ is the unstable improper node whose arrows point away from the origin.

:::

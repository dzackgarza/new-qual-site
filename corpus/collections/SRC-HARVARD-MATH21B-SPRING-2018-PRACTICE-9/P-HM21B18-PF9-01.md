::: {.problem}
Mark each statement true or false. No justifications are required.

1. Every homogeneous linear system $Ax=0$ is consistent.
2. If $P$ is the matrix of orthogonal projection onto a line, then every entry satisfies $|P_{ij}|\le1$.
3. The map $A\mapsto AA^T-I$ is linear on the vector space of real $2\times2$ matrices.
4. If a smooth $2\pi$-periodic function has a sine Fourier expansion, then its derivative has a cosine expansion.
5. Characteristic polynomials satisfy $f_A(\lambda)f_B(\lambda)=f_{AB}(\lambda)$ for square matrices $A,B$.
6. The function $\cos(10t)$ is an eigenfunction of $D^4$.
7. For every real square matrix $A$, the matrix $A^2+(A^2)^T$ is diagonalizable over $\mathbb R$.
8. The initial-value problem $f''+f'+f=\cos x$, $f(0)=0$, has exactly one solution.
9. The map $T(f)(x)=f(\sin x)$ is linear on $C^\infty(\mathbb R)$.
10. The smooth solutions of $f_{tt}-f_{xx}=f$ form a vector space.
11. If a $6\times6$ matrix has rank $5$, then $0$ is an eigenvalue.
12. Relative to the basis $\bigl((1,2)^T,(0,2)^T\bigr)$, the vector $(1,1)^T$ has coordinates $(1,-1)^T$.
13. If every geometric multiplicity of a matrix equals the corresponding algebraic multiplicity, then the matrix is symmetric.
14. Every point on a nullcline of $\dot x=f(x,y)$, $\dot y=g(x,y)$ is an equilibrium point.
15. For nonzero $z=a+ib$, one has $z^{-1}=(a-ib)/(a^2+b^2)$.
16. For every real $2\times2$ matrix $A$, $\operatorname{tr}(A^2)=\operatorname{tr}(A)^2$.
17. If $A$ is orthogonal, then $A=QR$ is a QR decomposition with $Q=A$ and $R=I$.
18. Given arbitrary real numbers $a,b$, there exists a real $2\times2$ matrix with trace $a$ and determinant $b$.
19. Every solution of
\[
x(t+1)=\frac12x(t)+\frac13x(t-1)
\]
tends to $0$ for arbitrary initial data $(x(0),x(1))$.
20. For a real symmetric matrix $A$, $\ker A$ is perpendicular to $\operatorname{im}A$.

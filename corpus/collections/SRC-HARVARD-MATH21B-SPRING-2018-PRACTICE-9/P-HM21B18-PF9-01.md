::: {.problem}
Mark each statement true or false. No justifications are required.

1. Every homogeneous linear system $Ax=0$ is consistent.
2. If $P$ is the matrix of orthogonal projection onto a line, then every entry satisfies $|P_{ij}|\le1$.
3. The map $A\mapsto AA^T-I$ is linear on the vector space of real $2\times2$ matrices.
4. If a smooth $2\pi$-periodic function has a sine Fourier expansion, then its derivative has a cosine expansion.
5. Characteristic polynomials satisfy $f_A(\lambda)f_B(\lambda)=f_{AB}(\lambda)$ for square matrices $A,B$.
6. The function $\cos(10t)$ is an eigenfunction of $D^4$.
7. For every real square matrix $A$, the matrix $A^2+(A^2)^T$ is diagonalizable over $\RR$.
8. The initial-value problem $f''+f'+f=\cos x$, $f(0)=0$, has exactly one solution.
9. The map $T(f)(x)=f(\sin x)$ is linear on $C^\infty(\RR)$.
10. The smooth solutions of $f_{tt}-f_{xx}=f$ form a vector space.
11. If a $6\times6$ matrix has rank $5$, then $0$ is an eigenvalue.
12. Relative to the basis $\bigl((1,2)^T,(0,2)^T\bigr)$, the vector $(1,1)^T$ has coordinates $(1,-1)^T$.
13. If every geometric multiplicity of a matrix equals the corresponding algebraic multiplicity, then the matrix is symmetric.
14. Every point on a nullcline of $\dot x=f(x,y)$, $\dot y=g(x,y)$ is an equilibrium point.
15. For nonzero $z=a+ib$, one has $z^{-1}=(a-ib)/(a^2+b^2)$.
16. For every real $2\times2$ matrix $A$, $\operatorname{tr}(A^2)=\operatorname{tr}(A)^2$.
17. If $A$ is orthogonal, then $A=QR$ is a QR decomposition with $Q=A$ and $R=I$.
18. Given arbitrary real numbers $a,b$, there exists a real $2\times2$ matrix with trace $a$ and determinant $b$.
19. Every solution of
\[
x(t+1)=\frac12x(t)+\frac13x(t-1)
\]
tends to $0$ for arbitrary initial data $(x(0),x(1))$.
20. For a real symmetric matrix $A$, $\ker A$ is perpendicular to $\operatorname{im}A$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Statement 1 is $\boxed{\mathrm T}$.


::: pf-proof

The vector $x=0$ satisfies $A0=0$ for every matrix $A$, so every homogeneous system has at least one solution.

:::

:::

::: {.pf-step #s1-2}

Statement 2 is $\boxed{\mathrm T}$.


::: pf-proof

If $u$ is a unit vector spanning the line, the orthogonal projection matrix is $P=uu^T$. Hence $P_{ij}=u_i u_j$, and $|u_i|,|u_j|\le1$ because $\|u\|=1$. Therefore $|P_{ij}|\le1$.

:::

:::

::: {.pf-step #s1-3}

Statement 3 is $\boxed{\mathrm F}$.


::: pf-proof

For the zero matrix,
\[
T(0)=00^T-I=-I\ne0.
\]
A linear map must send $0$ to $0$.

:::

:::

::: {.pf-step #s1-4}

Statement 4 is $\boxed{\mathrm T}$.


::: pf-proof

If
\[
f(x)=\sum_{n\ge1}b_n\sin(nx),
\]
then smoothness makes the Fourier coefficients rapidly decreasing, so the series may be differentiated term by term. Thus
\[
f'(x)=\sum_{n\ge1}n b_n\cos(nx),
\]
which is a cosine Fourier expansion.

:::

:::

::: {.pf-step #s1-5}

Statement 5 is $\boxed{\mathrm F}$.


::: pf-proof

Already for $1\times1$ matrices $A=B=(1)$, one has
\[
f_A(\lambda)f_B(\lambda)=(\lambda-1)^2,
\qquad
f_{AB}(\lambda)=\lambda-1,
\]
using the convention $f_A(\lambda)=\det(\lambda I-A)$. These polynomials are unequal.

:::

:::

::: {.pf-step #s1-6}

Statement 6 is $\boxed{\mathrm T}$.


::: pf-proof

Four differentiations give
\[
D^4\cos(10t)=10^4\cos(10t).
\]
Thus $\cos(10t)$ is an eigenfunction of $D^4$ with eigenvalue $10^4$.

:::

:::

::: {.pf-step #s1-7}

Statement 7 is $\boxed{\mathrm T}$.


::: pf-proof

The matrix
\[
A^2+(A^2)^T
\]
is real symmetric, because its transpose equals itself. Every real symmetric matrix is orthogonally diagonalizable over $\RR$.

:::

:::

::: {.pf-step #s1-8}

Statement 8 is $\boxed{\mathrm F}$.


::: pf-proof

For every prescribed value $c\in\RR$, the second-order initial-value problem
\[
f''+f'+f=\cos x,
\qquad
f(0)=0,
\qquad
f'(0)=c
\]
has a unique solution. Taking two distinct values of $c$ gives two distinct solutions satisfying the single condition stated in the problem, so that condition does not determine exactly one solution.

:::

:::

::: {.pf-step #s1-9}

Statement 9 is $\boxed{\mathrm T}$.


::: pf-proof

For scalars $a,b$ and smooth functions $f,g$,
\[
T(af+bg)(x)
=(af+bg)(\sin x)
=aT(f)(x)+bT(g)(x).
\]
Composition with the smooth function $\sin x$ also preserves smoothness, so $T$ is a linear endomorphism of $C^\infty(\RR)$.

:::

:::

::: {.pf-step #s1-10}

Statement 10 is $\boxed{\mathrm T}$.


::: pf-proof

Define
\[
L(f)=f_{tt}-f_{xx}-f.
\]
This is a linear differential operator, and the stated solution set is $\ker L$. A kernel of a linear map is a vector space.

:::

:::

::: {.pf-step #s1-11}

Statement 11 is $\boxed{\mathrm T}$.


::: pf-proof

Rank--nullity gives
\[
\dim\ker A=6-5=1.
\]
Thus there is a nonzero vector $v$ with $Av=0$, so $v$ is an eigenvector with eigenvalue $0$.

:::

:::

::: {.pf-step #s1-12}

Statement 12 is $\boxed{\mathrm F}$.


::: pf-proof

Writing
\[
\begin{pmatrix}1\\1\end{pmatrix}
=c_1\begin{pmatrix}1\\2\end{pmatrix}
+c_2\begin{pmatrix}0\\2\end{pmatrix}
\]
gives $c_1=1$ and $2+2c_2=1$, hence $c_2=-1/2$. The coordinate column is therefore
\[
\begin{pmatrix}1\\-1/2\end{pmatrix},
\]
not $(1,-1)^T$.

:::

:::

::: {.pf-step #s1-13}

Statement 13 is $\boxed{\mathrm F}$.


::: pf-proof

Consider
\[
A=\begin{pmatrix}1&1\\0&2\end{pmatrix}.
\]
Its eigenvalues $1$ and $2$ are distinct, so for each eigenvalue the geometric multiplicity equals the algebraic multiplicity. Nevertheless $A\ne A^T$, so $A$ is not symmetric.

:::

:::

::: {.pf-step #s1-14}

Statement 14 is $\boxed{\mathrm F}$.


::: pf-proof

An $x$-nullcline consists of points where $f(x,y)=0$, while a $y$-nullcline consists of points where $g(x,y)=0$. An equilibrium requires both equations simultaneously. A point lying on only one nullcline need not be an equilibrium.

:::

:::

::: {.pf-step #s1-15}

Statement 15 is $\boxed{\mathrm T}$.


::: pf-proof

For $z=a+ib\ne0$,
\[
(a+ib)(a-ib)=a^2+b^2\ne0.
\]
Therefore
\[
z^{-1}=\frac{a-ib}{a^2+b^2}.
\]

:::

:::

::: {.pf-step #s1-16}

Statement 16 is $\boxed{\mathrm F}$.


::: pf-proof

Take $A=I_2$. Then
\[
\operatorname{tr}(A^2)=2,
\qquad
\operatorname{tr}(A)^2=2^2=4.
\]

:::

:::

::: {.pf-step #s1-17}

Statement 17 is $\boxed{\mathrm T}$.


::: pf-proof

If $A$ is orthogonal, then $Q=A$ is orthogonal and $R=I$ is upper triangular. Hence
\[
A=AI=QR
\]
is a QR decomposition.

:::

:::

::: {.pf-step #s1-18}

Statement 18 is $\boxed{\mathrm T}$.


::: pf-proof

For arbitrary $a,b\in\RR$, the matrix
\[
A=\begin{pmatrix}a&-1\\b&0\end{pmatrix}
\]
has
\[
\operatorname{tr}A=a,
\qquad
\det A=b.
\]

:::

:::

::: {.pf-step #s1-19}

Statement 19 is $\boxed{\mathrm T}$.


::: pf-proof

The recurrence has characteristic equation
\[
r^2-\frac12r-\frac13=0,
\]
whose distinct roots are
\[
r_\pm=\frac{3\pm\sqrt{57}}{12}.
\]
Since $\sqrt{57}<9$, one has $0<r_+<1$, and since $\sqrt{57}<15$, one has $|r_-|=(\sqrt{57}-3)/12<1$. Every solution is therefore of the form
\[
x_n=C_+r_+^n+C_-r_-^n
\]
for constants determined by the initial data, and both terms tend to $0$.

:::

:::

::: {.pf-step #s1-20}

Statement 20 is $\boxed{\mathrm T}$.


::: pf-proof

Let $z\in\ker A$ and $y\in\operatorname{im}A$. Write $y=Ax$. Since $A=A^T$,
\[
z\cdot y
=z^TAx
=(A^Tz)^Tx
=(Az)^Tx
=0.
\]
Thus every vector in $\ker A$ is perpendicular to every vector in $\operatorname{im}A$.

:::

::: {.problem}
Let $f ( x _ { 1 } , \ldots , x _ { n } ) = \sum _ { 1 \leq i < j \leq n } x _ { i } x _ { j }$ . Find $\frac { \partial f } { \partial x _ { n } }$
:::

::: {.solution}
The only time that the index n appears is when $j = n$ . Thus taking the derivative, we find $\begin{array} { r } { \frac { \partial f } { \partial x _ { n } } ( x _ { 1 } , \dots , x _ { n } ) = \sum _ { i = 1 } ^ { n - 1 } x _ { i } } \end{array}$
:::

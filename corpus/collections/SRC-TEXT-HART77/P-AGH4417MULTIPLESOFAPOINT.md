::: problem
Let $X$ be the curve $y^2+y=x^3-x$ of (4.23.8).

a. If $Q=(a, b)$ is a point on the curve, compute the coordinates of the point $P+Q$, where $P=(0,0)$, as a function of $a, b$. Use this formula to find the coordinates of $nP$, $n=1,2, \ldots, 10$. Check: $6P = (6,14)$.

b. This equation defines a nonsingular curve over $\FF_p$ for all $p \neq 37$.
:::

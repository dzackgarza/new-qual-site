::: {.problem}
Let $k$ be algebraically closed and let $S\coloneqq k[x_0,\ldots,x_n]$.
Prove the **homogeneous Nullstellensatz**: if $\mfa \subseteq S$ is a homogeneous ideal and $f \in S$ is a homogeneous polynomial with $\deg f > 0$ such that $f(P) = 0$ for all $P \in Z(\mfa)$ in $\PP^n$, then $f^q \in \mfa$ for some $q > 0$.

[Hint: interpret the problem in terms of the affine $(n+1)$-space whose affine coordinate ring is $S$, and use the usual Nullstellensatz (1.3A).]
:::

::: {.hint}
Interpret the problem in the affine $(n+1)$-space whose affine coordinate ring is $S$, and apply the usual Nullstellensatz.
:::

::: {.solution}
Write $V_a(\mfa)\subseteq\AA_k^{n+1}$ for the affine common zero set and $Z(\mfa)\subseteq\PP_k^n$ for the projective common zero set.
The notation $f(P)=0$ for a homogeneous polynomial means vanishing at any nonzero homogeneous-coordinate representative of $P$.
It is independent of that choice, since scaling by $\lambda\in k^\times$ multiplies the value by $\lambda^{\deg f}$.

::: pf

::: {.pf-step #affine-point-gives-projective-point}
Every nonzero point $v\in V_a(\mfa)$ determines a point $[v]\in Z(\mfa)$.

::: pf-proof
The ideal $\mfa$ is generated by homogeneous polynomials.
For each such generator $g$, the equation $g(v)=0$ holds by the definition of the affine zero set.
These are exactly the equations defining membership of $[v]$ in the projective zero set.
Conversely, every nonzero representative of a point of $Z(\mfa)$ satisfies the generators and therefore every element of $\mfa$, so lies in $V_a(\mfa)$.
The zero vector is not used as a projective point.
:::

:::

::: {.pf-step #f-vanishes-on-affine-zero-set}
The polynomial $f$ vanishes on all of $V_a(\mfa)$.

::: pf-proof
At a nonzero point, step [](#affine-point-gives-projective-point){.pf-ref} and the assumed projective vanishing give $f(v)=0$.
At the zero vector, if it belongs to $V_a(\mfa)$, the same equality follows because $f$ is homogeneous of positive degree.
These two cases exhaust the affine zero set.
They also cover the case where the projective zero set is empty.
If $\mfa=S$, the affine zero set is empty as well and this vanishing is vacuous.
:::

:::

::: pf-qed
By step [](#f-vanishes-on-affine-zero-set){.pf-ref} and the [[T-JRTS2|affine Nullstellensatz]],
$$
f\in I(V_a(\mfa))=\sqrt{\mfa}
$$
[@Har77, Theorem I.1.3A].
By the definition of the radical, there is an integer $q\ge1$ for which $f^q\in\mfa$, as required.
:::

:::

:::

::: {.remark title="The positive-degree hypothesis"}
For $\mfa=(x_0,\ldots,x_n)$, the projective zero set is empty, so the constant polynomial $1$ vanishes there vacuously.
No power of $1$ belongs to this proper ideal.
Thus the positive-degree hypothesis cannot be dropped; in the affine argument it supplies vanishing at the cone vertex.
:::

::: {.remark title="Published solution"}
Richard E. Borcherds, *Hartshorne, Chapter 1: Answers to exercises* (1994), Exercise 2.1, PDF p. 2, and William Troiani, *Hartshorne Exercise Solutions* (October 2020), Exercise 2.1, PDF p. 3: both read the projective statement in the affine cone, note that a positive-degree homogeneous $f$ vanishes at the cone vertex as well, and apply the affine Nullstellensatz to the affine zero set.
The proof above separates the two cases of the affine zero set — a nonzero point and the vertex — as a step, which is the step both published arguments take in one sentence, and it records that the vertex case is vacuous when the projective zero set is empty.
Agree.
:::

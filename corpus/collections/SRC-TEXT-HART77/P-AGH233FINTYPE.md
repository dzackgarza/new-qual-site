::: {.problem}
a. Show that a morphism $f: X \to Y$ is of finite type if and only if it is locally of finite type and quasi-compact.

b. Conclude that $f$ is of finite type if and only if for every open affine subset $V = \Spec B$ of $Y$, the preimage $\inverseof{f}(V)$ can be covered by a finite number of open affines $U_j = \Spec A_j$ where each $A_j$ is a finitely generated $B$-algebra.

c. Show also that if $f$ is of finite type, then for every open affine subset $V = \Spec B \subseteq Y$ and every open affine subset $U = \Spec A \subseteq \inverseof{f}(V)$, the ring $A$ is a finitely generated $B$-algebra.
:::

::: {.solution}

::: pf

::: {.pf-step #finite-type-implies-loc-ft-qc}
If $f$ is of finite type, then it is locally of finite type and quasi-compact.

::: pf-proof
By definition, there is an affine cover
\[
Y=\bigcup_iV_i,
\qquad
V_i=\Spec B_i,
\]
such that every $f^{-1}(V_i)$ is covered by finitely many affine opens
\[
U_{ij}=\Spec A_{ij}
\]
with $A_{ij}$ finitely generated over $B_i$.

Ignoring the word ``finitely'' gives exactly the definition of locally finite type.
Moreover each $f^{-1}(V_i)$ is a finite union of affine, hence quasi-compact, opens, so it is quasi-compact.
Hartshorne II.3.2 therefore shows that $f$ is quasi-compact.
:::

:::

::: {.pf-step #loc-ft-qc-implies-finite-type}
If $f$ is locally of finite type and quasi-compact, then it is of finite type.

::: pf-proof
Choose an affine cover $Y=\bigcup_iV_i$ witnessing local finite type.
For each $i$, the inverse image $f^{-1}(V_i)$ has an affine cover
\[
f^{-1}(V_i)=\bigcup_jU_{ij},
\qquad
U_{ij}=\Spec A_{ij},
\]
with each $A_{ij}$ finitely generated over $B_i=\Gamma(V_i,\mathcal O_Y)$.

Since $f$ is quasi-compact, II.3.2 implies that every $f^{-1}(V_i)$ is quasi-compact.  Hence finitely many of the $U_{ij}$ cover it.  Thus the defining finite affine-cover condition for a finite type morphism holds.
:::

:::

::: {.pf-step #finite-type-iff-loc-ft-qc}
Consequently
\[
\boxed{
f\text{ is of finite type}
\iff
f\text{ is locally of finite type and quasi-compact}.}
\]

::: pf-proof
Combine steps [](#finite-type-implies-loc-ft-qc){.pf-ref} and [](#loc-ft-qc-implies-finite-type){.pf-ref}.
:::

:::

::: {.pf-step #finite-cover-for-affine-v}
If $f$ is of finite type and $V=\Spec B\subseteq Y$ is affine, then $f^{-1}(V)$ has a finite affine cover
\[
U_j=\Spec A_j
\]
with every $A_j$ finitely generated over $B$.

::: pf-proof
By step [](#finite-type-iff-loc-ft-qc){.pf-ref}, $f$ is locally of finite type and quasi-compact.  Hartshorne II.3.1 gives an affine cover of $f^{-1}(V)$ by spectra of finitely generated $B$-algebras.  Hartshorne II.3.2 says that $f^{-1}(V)$ is quasi-compact.  A finite subcover gives the assertion.
:::

:::

::: {.pf-step #converse-finite-cover-implies-ft}
Conversely, if the finite-cover condition of part (b) holds for every affine open $V\subseteq Y$, then $f$ is of finite type.

::: pf-proof
Choose any affine open cover of $Y$.  The hypothesis supplies, over each member of that cover, a finite affine cover by spectra of finitely generated algebras.  This is precisely the definition of a finite type morphism.
:::

:::

::: {.pf-step #part-b-proof}
This proves part (b).

::: pf-proof
Steps [](#finite-cover-for-affine-v){.pf-ref} and [](#converse-finite-cover-implies-ft){.pf-ref} prove the two implications.
:::

:::

::: {.pf-step #algebra-lemma-glue-fg}
We use the following algebra lemma.
Let $B\to A$ be a ring map and let
\[
g_1,\ldots,g_n\in A
\]
generate the unit ideal.
If every $A_{g_i}$ is a finitely generated $B$-algebra, then $A$ is a finitely generated $B$-algebra.

::: pf-proof
For each $i$, choose finitely many elements of $A_{g_i}$ which generate it over $B$, and write them with denominators powers of $g_i$.
Let $C\subseteq A$ be the $B$-subalgebra generated by

- the finitely many numerators of all these generators,

- the elements $g_i$, and

- finitely many coefficients $c_i\in A$ satisfying
  \[
  \sum_i c_ig_i=1.
  \]

Then $C$ is a finitely generated $B$-algebra and the $g_i$ generate the unit ideal already in $C$.
By construction,
\[
C_{g_i}=A_{g_i}
\]
for every $i$.

Let $a\in A$.  Since $a/1$ lies in $C_{g_i}=A_{g_i}$, for every $i$ there is an integer $N_i$ such that
\[
g_i^{N_i}a\in C.
\]
Take one $N$ at least all the $N_i$.  Then
\[
g_i^Na\in C
\]
for all $i$.  Because the $g_i$ generate $(1)$ in $C$, so do the powers $g_i^N$: the ideal $(g_1^N,\ldots,g_n^N)$ has radical $(1)$ and therefore equals $(1)$.  Hence there are $d_i\in C$ with
\[
\sum_i d_ig_i^N=1.
\]
Multiplying by $a$ gives
\[
a=\sum_i d_i(g_i^Na)\in C.
\]
Thus $A=C$, so $A$ is finitely generated over $B$.
:::

:::

::: {.pf-step #common-distinguished-cover}
Let $V=\Spec B\subseteq Y$ and let
\[
U=\Spec A\subseteq f^{-1}(V)
\]
be affine.
There is a finite cover
\[
U=D(g_1)\cup\cdots\cup D(g_n)
\]
such that every $D(g_i)$ is also a distinguished open subset of some affine chart
\[
W_i=\Spec C_i\subseteq f^{-1}(V)
\]
with $C_i$ finitely generated over $B$.

::: pf-proof
By step [](#finite-cover-for-affine-v){.pf-ref}, choose a finite affine cover $\{W_j\}$ of $f^{-1}(V)$ with each coordinate ring finitely generated over $B$.

Fix $x\in U$.
Choose $W_j$ containing $x$.
The intersection $U\cap W_j$ is an open neighborhood of $x$ in both affine schemes.
First choose a distinguished open
\[
x\in D_U(a)\subseteq U\cap W_j.
\]
Inside the affine $W_j$, choose a distinguished open
\[
x\in D_{W_j}(b)\subseteq D_U(a).
\]
Write the regular function $b|_{D_U(a)}$ as $c/a^m$ with $c\in A$.
Then
\[
D_{W_j}(b)=D_U(a)\cap D_U(c)=D_U(ac),
\]
so this neighborhood is distinguished in both $U$ and $W_j$.

Such common distinguished neighborhoods cover $U$.  Since $U$ is affine, it is quasi-compact, so finitely many suffice.  Rename them $D(g_1),\ldots,D(g_n)$ and their corresponding finite-type affine charts $W_i$.
:::

:::

::: {.pf-step #agi-fg-and-unit-ideal}
For the cover in step [](#common-distinguished-cover){.pf-ref}, every localization $A_{g_i}$ is a finitely generated $B$-algebra, and the $g_i$ generate the unit ideal of $A$.

::: pf-proof
Because $D(g_i)$ is distinguished inside $W_i=\Spec C_i$, its coordinate ring is a localization
\[
(C_i)_{h_i}
\]
for some $h_i\in C_i$.
Since $C_i$ is finitely generated over $B$, so is $(C_i)_{h_i}$; adjoining one inverse preserves finite generation.
But $D(g_i)$ is also distinguished in $U=\Spec A$, so
\[
A_{g_i}\cong(C_i)_{h_i}
\]
is finitely generated over $B$.

The opens $D(g_i)$ cover $\Spec A$, hence
\[
V(g_1,\ldots,g_n)=\varnothing.
\]
Thus $(g_1,\ldots,g_n)=A$.
:::

:::

::: {.pf-step #a-is-fg-over-b}
The ring $A$ is a finitely generated $B$-algebra.

::: pf-proof
Apply the algebra lemma step [](#algebra-lemma-glue-fg){.pf-ref} to the elements $g_i$ from step [](#agi-fg-and-unit-ideal){.pf-ref}.
:::

:::

::: {.pf-step #part-c-proof}
Hence part (c) holds.

::: pf-proof
The affine opens $V=\Spec B$ and $U=\Spec A\subseteq f^{-1}(V)$ were arbitrary, and step [](#a-is-fg-over-b){.pf-ref} proves that $A$ is finitely generated over $B$.
:::

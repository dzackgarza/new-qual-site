::: {.problem}
Show that a $k$-algebra $B$ is isomorphic to the affine coordinate ring of some algebraic set in $\AA^n$, for some $n$, if and only if $B$ is a finitely generated $k$-algebra with no nilpotent elements.
:::

::: {.solution}
This is Hartshorne Exercise I.5. The published solutions are recorded above: Borcherds proves the forward direction and leaves the converse unstated, while Troiani and Park prove both, Park in the form used below. The proof here isolates the same two facts; what it adds is that the chapter's standing hypothesis is named, because the Nullstellensatz step needs it.

::: pf

::: {.pf-step #facts}
Two facts are used: an ideal $I\subset k[x_{1},\dots,x_{n}]$ is radical exactly when $k[x_{1},\dots,x_{n}]/I$ is reduced, and a $k$-algebra is finitely generated exactly when it is isomorphic to some $k[x_{1},\dots,x_{n}]/I$.

::: pf-proof
The first is the dictionary between radicality and nilpotents: $k[x_{1},\dots,x_{n}]/I$ is reduced precisely when every class $f+I$ with $f^{m}\in I$ for some $m\geq1$ already satisfies $f\in I$, which is the definition of $I=\sqrt{I}$. The second is the definition of finite generation: a surjection $k[x_{1},\dots,x_{n}]\to B$ from a polynomial ring in finitely many variables has kernel $I$ and induces $B\cong k[x_{1},\dots,x_{n}]/I$, and conversely such a presentation exhibits $B$ as generated by the classes of $x_{1},\dots,x_{n}$.
:::
:::

::: {.pf-step #forward}
If $B$ is a finitely generated $k$-algebra with no nilpotent elements, then $B\cong A(Y)$ for some algebraic set $Y\subset\AA^{n}$.

::: pf-proof
Present $B\cong k[x_{1},\dots,x_{n}]/I_{B}$ using the second fact of step [](#facts){.pf-ref}, and let $Y=V(I_{B})$. Since $B$ is reduced, $I_{B}$ is radical by the first fact. In this chapter $k$ is algebraically closed, so the Nullstellensatz applies and gives $I(Y)=I(V(I_{B}))=\sqrt{I_{B}}=I_{B}$; hence $A(Y)=k[x_{1},\dots,x_{n}]/I(Y)\cong k[x_{1},\dots,x_{n}]/I_{B}\cong B$.
:::
:::

::: {.pf-step #backward}
If $B\cong A(Y)=k[x_{1},\dots,x_{n}]/I(Y)$ for an algebraic set $Y\subset\AA^{n}$, then $B$ is finitely generated and has no nilpotent elements.

::: pf-proof
The presentation exhibits $B$ as generated by the $n$ classes of the variables, so $B$ is finitely generated. And $I(Y)$ is radical for every subset $Y$: if $f^{m}$ vanishes on $Y$ then so does $f$, since $k$ is a field and $f(y)^{m}=0$ implies $f(y)=0$. So $B$ is reduced by the first fact of step [](#facts){.pf-ref}.
:::
:::

::: {.pf-step #convention}
The two directions together prove the equivalence, under the chapter's standing convention that $k$ is algebraically closed.

::: pf-proof
Both directions are steps [](#forward){.pf-ref} and [](#backward){.pf-ref}. The convention is not decoration: the Nullstellensatz in step [](#forward){.pf-ref} is false over a field that is not algebraically closed, and with it the statement, since over $\RR$ the algebra $\RR[x]/(x^{2}+1)$ is finitely generated and reduced while $\RR[x]/(x^{2}+1)$ is not the coordinate ring of any algebraic set, the only algebraic set cut out by $(x^{2}+1)$ being empty and its coordinate ring being the zero ring.
:::

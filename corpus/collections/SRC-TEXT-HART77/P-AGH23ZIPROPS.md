::: problem
Let $S \da k[x_0,\ldots,x_n]$ and let $S^h$ denote its set of homogeneous elements.

1. If $T_1 \subseteq T_2$ are subsets of $S^h$, then $Z(T_1) \supseteq Z(T_2)$.
2. If $Y_1 \subseteq Y_2$ are subsets of $\PP^n$, then $I(Y_1) \supseteq I(Y_2)$.
3. For any two subsets $Y_1, Y_2 \subseteq \PP^n$, $I(Y_1 \union Y_2) = I(Y_1) \intersect I(Y_2)$.
4. If $\mfa \subseteq S$ is a homogeneous ideal with $Z(\mfa) \neq \emptyset$, then $I(Z(\mfa)) = \sqrt{\mfa}$.
5. For any subset $Y \subseteq \PP^n$, $Z(I(Y)) = \bar{Y}$.
:::

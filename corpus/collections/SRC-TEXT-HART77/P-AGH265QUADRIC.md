::: problem
Let $\characteristic k \neq 2$, and let $X$ be the affine quadric hypersurface
\[
\Spec k[x_0, \ldots, x_n]/(x_0^2 + x_1^2 + \cdots + x_r^2)
.\]

a. Show that $X$ is normal if $r \geq 2$.

b. Show by a suitable linear change of coordinates that the equation of $X$ can be written $x_0 x_1 = x_2^2 + \cdots + x_r^2$.
   Now show that

    1. if $r = 2$, then $\Cl X \cong \ZZ/2\ZZ$;
    2. if $r = 3$, then $\Cl X \cong \ZZ$;
    3. if $r \geq 4$, then $\Cl X = 0$.

c. Now let $Q$ be the projective quadric hypersurface in $\PP^n$ defined by the same equation.
   Show that

    1. if $r = 2$, then $\Cl Q \cong \ZZ$, and the class of a hyperplane section $Q . H$ is twice the generator;
    2. if $r = 3$, then $\Cl Q \cong \ZZ \oplus \ZZ$;
    3. if $r \geq 4$, then $\Cl Q \cong \ZZ$, generated by $Q . H$.

d. Prove Klein's theorem: if $r \geq 4$ and $Y$ is an irreducible subvariety of codimension $1$ on $Q$, then there is an irreducible hypersurface $V \subseteq \PP^n$ such that $V \intersect Q = Y$ with multiplicity one.
   In other words, $Y$ is a complete intersection.
   *Hint:* first show that for $r \geq 4$ the homogeneous coordinate ring $S(Q) = k[x_0, \ldots, x_n]/(x_0^2 + \cdots + x_r^2)$ is a UFD.
:::

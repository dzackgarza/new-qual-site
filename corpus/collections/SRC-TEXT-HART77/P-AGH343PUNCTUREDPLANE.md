::: problem
Let $X=\AA_k^2=\Spec k[x, y]$, and let $U=X-\ts{(0,0)}$. Using a suitable cover of $U$ by open affine subsets, show that $H^1(U, \mco_U)$ is isomorphic to the $k$-vector space spanned by $\ts{x^i y^j \st i, j<0}$. In particular, it is infinite-dimensional.

Using (3.5), this provides another proof that $U$ is not affine — cf. (I, Ex. 3.6).
:::

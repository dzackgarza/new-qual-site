::: problem
If $X$ is an elliptic curve, show that there is an exact sequence
$$
0 \to p_1^* \Pic X \oplus p_2^* \Pic X \to \Pic(X \times X) \to R \to 0,
$$
where $R=\operatorname{End}(X, P_0)$. In particular, we see that $\Pic(X \times X)$ is bigger than the sum of the Picard groups of the factors. Cf. (III, Ex. 12.6), (V, Ex. 1.6).
:::

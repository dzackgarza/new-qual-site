::: problem
Assume $\operatorname{char} k \neq 2$. Locate the singular points of the following curves in $\AA^2$ and sketch each curve.

1. $x^2 = x^4 + y^4$
2. $xy = x^6 + y^6$
3. $x^3 = y^2 + x^4 + y^4$
4. $x^2 y + x y^2 = x^4 + y^4$
:::

::: problem
Let $f: X \to Y$ be a morphism of finite type of noetherian schemes.
Show that
\[
\ts{ x \in X \st f \text{ is flat at } x }
\]
is an open subset of $X$, possibly empty.

See Grothendieck, EGA $\mathrm{IV}_3$, 11.1.1.
:::

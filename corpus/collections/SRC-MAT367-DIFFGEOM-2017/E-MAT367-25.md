::: {.problem}
Let $S\subseteq\mathbb R^3$ be a smooth surface.
Show that $p\in S$ is a critical point of the height function $f(x,y,z)=z$ if and only if $T_pS$ is the $xy$-plane.
:::

::: {.solution}
Let
\[
h:\mathbb R^3\longrightarrow\mathbb R,
\qquad
h(x,y,z)=z,
\]
so that $f=h|_S$.

::: pf

::: {.pf-step #critical-iff-kernel-contains-tangent}
A point $p\in S$ is critical for $f$ if and only if
\[
T_pS\subseteq\ker D_ph.
\]

::: pf-proof
If $i:S\hookrightarrow\mathbb R^3$ is the inclusion, then $f=h\circ i$.  Hence the chain rule gives
\[
T_pf=D_ph\circ T_pi.
\]
The image of $T_pi$ is the tangent plane $T_pS$.  Therefore $T_pf=0$ exactly when $D_ph$ vanishes on $T_pS$.
:::

:::

::: {.pf-step #derivative-and-kernel-of-height}
For every $p\in\mathbb R^3$,
\[
D_ph(a,b,c)=c,
\qquad
\ker D_ph=\mathbb R^2\times\{0\},
\]
the $xy$-plane.

::: pf-proof
The function $h(x,y,z)=z$ is linear, so its derivative is the linear functional extracting the third coordinate.  Its kernel consists exactly of vectors whose third coordinate is zero.
:::

:::

::: {.pf-step #condition-equals-xy-plane}
The condition in step [](#critical-iff-kernel-contains-tangent){.pf-ref} is equivalent to
\[
T_pS=\mathbb R^2\times\{0\}.
\]

::: pf-proof
Since $S$ is a surface, $T_pS$ has dimension two.  By step [](#derivative-and-kernel-of-height){.pf-ref}, $\ker D_ph$ also has dimension two.  Thus
\[
T_pS\subseteq\ker D_ph
\]
holds if and only if the two two-dimensional subspaces are equal.
:::

:::

::: {.pf-step #boxed-equivalence}
Hence
\[
\boxed{
p\text{ is a critical point of }f
\iff
T_pS\text{ is the }xy\text{-plane}.
}
\]

::: pf-proof
Combine steps [](#critical-iff-kernel-contains-tangent){.pf-ref}, [](#derivative-and-kernel-of-height){.pf-ref}, and [](#condition-equals-xy-plane){.pf-ref}.
:::

:::

::: pf-qed
Step [](#boxed-equivalence){.pf-ref} is the claimed equivalence.
:::

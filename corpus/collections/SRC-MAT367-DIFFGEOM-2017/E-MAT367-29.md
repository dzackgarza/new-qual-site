::: {.problem}
Express the coordinate vector fields $\partial/\partial x$ and $\partial/\partial y$ in polar coordinates
\[
x=r\cos\theta,\qquad y=r\sin\theta,
\]
for $r>0$ and $-\pi<\theta<\pi$.
:::

::: {.solution}
<1>1. The polar coordinate vector fields satisfy
\[
\frac{\partial}{\partial r}
=\cos\theta\frac{\partial}{\partial x}
+\sin\theta\frac{\partial}{\partial y},
\]
and
\[
\frac{\partial}{\partial\theta}
=-r\sin\theta\frac{\partial}{\partial x}
+r\cos\theta\frac{\partial}{\partial y}.
\]
::: {.proof}
Apply the coordinate-change rule to
\[
x=r\cos\theta,
\qquad
y=r\sin\theta.
\]
Since
\[
\frac{\partial x}{\partial r}=\cos\theta,
\quad
\frac{\partial y}{\partial r}=\sin\theta,
\quad
\frac{\partial x}{\partial\theta}=-r\sin\theta,
\quad
\frac{\partial y}{\partial\theta}=r\cos\theta,
\]
the displayed identities follow.
:::

<1>2. In matrix form,
\[
\begin{pmatrix}
\partial_r\\[2mm]
\partial_\theta
\end{pmatrix}
=
\begin{pmatrix}
\cos\theta&\sin\theta\\
-r\sin\theta&r\cos\theta
\end{pmatrix}
\begin{pmatrix}
\partial_x\\[2mm]
\partial_y
\end{pmatrix}.
\]
The coefficient matrix has inverse
\[
\frac1r
\begin{pmatrix}
r\cos\theta&-\sin\theta\\
r\sin\theta&\cos\theta
\end{pmatrix}.
\]
::: {.proof}
The determinant of the coefficient matrix is
\[
r\cos^2\theta+r\sin^2\theta=r,
\]
which is nonzero because $r>0$.  The displayed inverse is the ordinary inverse of this $2\times2$ matrix.
:::

<1>3. Therefore
\[
\boxed{
\frac{\partial}{\partial x}
=\cos\theta\frac{\partial}{\partial r}
-\frac{\sin\theta}{r}\frac{\partial}{\partial\theta}
}
\]
and
\[
\boxed{
\frac{\partial}{\partial y}
=\sin\theta\frac{\partial}{\partial r}
+\frac{\cos\theta}{r}\frac{\partial}{\partial\theta}.
}
\]
::: {.proof}
Multiply the matrix identity in <1>2 by the inverse coefficient matrix.
:::

<1>4. Q.E.D.
::: {.proof}
Step <1>3 gives the requested expressions of the Cartesian coordinate vector fields in polar coordinates.
:::
:::

::: {.problem}
Suppose $F\in C^\infty(M,N)$ is constant, with $F(M)=\{q\}$.
Show that $T_pF=0$ for every $p\in M$.
:::

::: {.solution}

::: pf

::: {.pf-step #tangent-vectors-annihilate-constants}
Every tangent vector annihilates constant functions.

::: pf-proof
Let $v\in T_pM$.  By the product rule,
\[
v(1)=v(1\cdot1)=1\,v(1)+v(1)\,1=2v(1),
\]
so $v(1)=0$.  By linearity, for every constant $c\in\mathbb R$,
\[
v(c)=v(c\cdot1)=c\,v(1)=0.
\]
:::

:::

::: {.pf-step #pullback-of-constant-map}
If $F(M)=\{q\}$, then for every $g\in C^\infty(N)$ the pullback $g\circ F$ is constant with value $g(q)$.

::: pf-proof
For every $x\in M$,
\[
(g\circ F)(x)=g(F(x))=g(q).
\]
:::

:::

::: {.pf-step #tangent-map-kills-v}
For every $p\in M$ and $v\in T_pM$,
\[
T_pF(v)=0\in T_qN.
\]

::: pf-proof
For every $g\in C^\infty(N)$, the definition of the tangent map and step [](#pullback-of-constant-map){.pf-ref} give
\[
\bigl(T_pF(v)\bigr)(g)=v(g\circ F).
\]
The function $g\circ F$ is constant, so step [](#tangent-vectors-annihilate-constants){.pf-ref} gives
\[
\bigl(T_pF(v)\bigr)(g)=0.
\]
Thus $T_pF(v)$ is the zero tangent vector.
:::

:::

::: {.pf-step #tangent-map-is-zero}
Hence
\[
\boxed{T_pF=0\quad\text{for every }p\in M.}
\]

::: pf-proof
Step [](#tangent-map-kills-v){.pf-ref} holds for every $v\in T_pM$, so the linear map $T_pF$ is the zero map.
:::

:::

::: pf-qed
Step [](#tangent-map-is-zero){.pf-ref} is the required conclusion.
:::

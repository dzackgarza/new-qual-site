::: {.problem}
Suppose $F\in C^\infty(M,N)$ is constant, with $F(M)=\{q\}$.
Show that $T_pF=0$ for every $p\in M$.
:::

::: {.solution}
<1>1. Every tangent vector annihilates constant functions.
::: {.proof}
Let $v\in T_pM$.  By the product rule,
\[
v(1)=v(1\cdot1)=1\,v(1)+v(1)\,1=2v(1),
\]
so $v(1)=0$.  By linearity, for every constant $c\in\mathbb R$,
\[
v(c)=v(c\cdot1)=c\,v(1)=0.
\]
:::

<1>2. If $F(M)=\{q\}$, then for every $g\in C^\infty(N)$ the pullback $g\circ F$ is constant with value $g(q)$.
::: {.proof}
For every $x\in M$,
\[
(g\circ F)(x)=g(F(x))=g(q).
\]
:::

<1>3. For every $p\in M$ and $v\in T_pM$,
\[
T_pF(v)=0\in T_qN.
\]
::: {.proof}
For every $g\in C^\infty(N)$, the definition of the tangent map and <1>2 give
\[
\bigl(T_pF(v)\bigr)(g)=v(g\circ F).
\]
The function $g\circ F$ is constant, so <1>1 gives
\[
\bigl(T_pF(v)\bigr)(g)=0.
\]
Thus $T_pF(v)$ is the zero tangent vector.
:::

<1>4. Hence
\[
\boxed{T_pF=0\quad\text{for every }p\in M.}
\]
::: {.proof}
Step <1>3 holds for every $v\in T_pM$, so the linear map $T_pF$ is the zero map.
:::

<1>5. Q.E.D.
::: {.proof}
Step <1>4 is the required conclusion.
:::
:::

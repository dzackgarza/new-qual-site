::: {.problem}
In the notation of Section 5.4 of the source, explore the consequences of Proposition 5.3 for the other examples of related vector fields given immediately before this exercise.
:::

::: {.solution}
Proposition 5.3 says that for a smooth map $F:M\to N$ and vector fields $X\in\mathfrak X(M)$, $Y\in\mathfrak X(N)$,
\[
X\sim_FY
\quad\Longleftrightarrow\quad
X(g\circ F)=Y(g)\circ F
\quad\text{for every }g\in C^\infty(N).
\]

::: pf

::: {.pf-step #diffeomorphism-conjugation}
If $F:M\to N$ is a diffeomorphism and $Y=F_*X$, then
\[
\boxed{X\circ F^*=F^*\circ Y}
\]
as operators $C^\infty(N)\to C^\infty(M)$.

::: pf-proof
Example 5.7 says that $Y=F_*X$ is equivalent to $X\sim_FY$.  Proposition 5.3 rewrites this as
\[
X(F^*g)=F^*(Yg)
\]
for every $g\in C^\infty(N)$, which is exactly the displayed operator identity.
:::

:::

::: {.pf-step #invariance-criterion}
In particular, if $F:M\to M$ is a diffeomorphism, then $X$ is $F$-invariant if and only if
\[
\boxed{X\circ F^*=F^*\circ X.}
\]

::: pf-proof
The field is $F$-invariant exactly when $X\sim_FX$.  Apply step [](#diffeomorphism-conjugation){.pf-ref} with $Y=X$.
:::

:::

::: {.pf-step #restriction-criterion}
Let $i:S\hookrightarrow M$ be an embedded submanifold, let $X\in\mathfrak X(S)$, and let $Y\in\mathfrak X(M)$.  Then $X$ is the restriction of the tangent field $Y$ to $S$ if and only if
\[
\boxed{X(g|_S)=(Yg)|_S\quad\text{for every }g\in C^\infty(M).}
\]

::: pf-proof
Example 5.8 identifies restriction with the relation $X\sim_iY$.  Since
\[
i^*g=g\circ i=g|_S,
\]
Proposition 5.3 gives precisely
\[
X(i^*g)=i^*(Yg).
\]
:::

:::

::: {.pf-step #vanishing-along-submanifold}
A vector field $Y\in\mathfrak X(M)$ vanishes along $S$ if and only if
\[
\boxed{(Yg)|_S=0\quad\text{for every }g\in C^\infty(M).}
\]

::: pf-proof
Example 5.8 says that $Y$ vanishes along $S$ exactly when
\[
0\sim_iY.
\]
Apply step [](#restriction-criterion){.pf-ref} with the zero vector field on $S$.
:::

:::

::: {.pf-step #tangent-to-fibers}
If $F:M\to N$ is a submersion, then a vector field $X\in\mathfrak X(M)$ is tangent to the fibers of $F$ if and only if
\[
\boxed{X(g\circ F)=0\quad\text{for every }g\in C^\infty(N).}
\]

::: pf-proof
Example 5.9 says that $X$ is tangent to the fibers exactly when
\[
X\sim_F0.
\]
Proposition 5.3 then gives
\[
X(g\circ F)=0(g)\circ F=0
\]
for every smooth function $g$ on $N$.
:::

:::

::: {.pf-step #descends-to-quotient}
Let $\pi:S^n\to\mathbb{RP}^n$ be the antipodal quotient.  If $X\in\mathfrak X(S^n)$ descends to $Y\in\mathfrak X(\mathbb{RP}^n)$, then for every $g\in C^\infty(\mathbb{RP}^n)$,
\[
\boxed{X(g\circ\pi)=Y(g)\circ\pi.}
\]
In particular, $X$ sends smooth antipodally invariant functions to smooth antipodally invariant functions.

::: pf-proof
Descending to $Y$ means $X\sim_\pi Y$ by Example 5.10, so the displayed identity is Proposition 5.3.

Every pullback $g\circ\pi$ is antipodally invariant because $\pi(x)=\pi(-x)$.  The right-hand side $Y(g)\circ\pi$ is again a pullback from $\mathbb{RP}^n$, hence is also antipodally invariant.  Thus $X$ preserves this class of functions.
:::

:::

::: {.pf-step #uniqueness-of-descended-field}
Conversely, for an antipodally invariant vector field $X$ as in Example 5.10, the descended field $Y$ is characterized uniquely by
\[
\boxed{Y(g)\circ\pi=X(g\circ\pi).}
\]

::: pf-proof
Example 5.10 gives the descended field $Y$ with $X\sim_\pi Y$.  Proposition 5.3 gives the displayed formula.  Since $\pi$ is surjective, a function on $\mathbb{RP}^n$ is uniquely determined by its pullback along $\pi$, so this identity uniquely determines $Y(g)$ for every $g$ and hence determines $Y$.
:::

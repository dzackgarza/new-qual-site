::: {.problem}
Let $M$ be a manifold and $f:M\to\mathbb R$.
Show that $f$ is continuous if and only if for every coordinate chart $(U,\phi)$ the function $f\circ\phi^{-1}$ is continuous on $\phi(U)$.
:::

::: {.solution}
<1>1. If $f:M\to\mathbb R$ is continuous, then for every coordinate chart $(U,\phi)$ the function
\[
f\circ\phi^{-1}:\phi(U)\longrightarrow\mathbb R
\]
is continuous.
::: {.proof}
For a coordinate chart $(U,\phi)$, the map
\[
\phi^{-1}:\phi(U)\longrightarrow U\subseteq M
\]
is continuous because $\phi$ is a homeomorphism.  Hence $f\circ\phi^{-1}$ is a composition of continuous maps and is therefore continuous.
:::

<1>2. Conversely, suppose that $f\circ\phi^{-1}$ is continuous for every coordinate chart $(U,\phi)$.  For every open set $J\subseteq\mathbb R$ and every coordinate chart $(U,\phi)$, the set
\[
U\cap f^{-1}(J)
\]
is open in $M$.
::: {.proof}
Since $f\circ\phi^{-1}$ is continuous,
\[
(f\circ\phi^{-1})^{-1}(J)
\]
is open in the open set $\phi(U)\subseteq\mathbb R^n$.  Because $\phi:U\to\phi(U)$ is a homeomorphism,
\[
\phi^{-1}\bigl((f\circ\phi^{-1})^{-1}(J)\bigr)
=U\cap f^{-1}(J)
\]
is open in $U$.  The chart domain $U$ is open in $M$, so $U\cap f^{-1}(J)$ is open in $M$.
:::

<1>3. Under the hypothesis of <1>2, the preimage $f^{-1}(J)$ is open in $M$ for every open set $J\subseteq\mathbb R$.
::: {.proof}
The coordinate domains cover $M$.  Therefore
\[
f^{-1}(J)
=\bigcup_{(U,\phi)}\bigl(U\cap f^{-1}(J)\bigr),
\]
where the union ranges over the coordinate charts of $M$.  Every set in this union is open by <1>2, so the union is open.
:::

<1>4. Hence
\[
\boxed{
f\text{ is continuous}
\iff
f\circ\phi^{-1}\text{ is continuous for every coordinate chart }(U,\phi).
}
\]
::: {.proof}
Step <1>1 proves the forward implication.  Steps <1>2 and <1>3 show that the inverse image of every open subset of $\mathbb R$ is open, which is the reverse implication.
:::

<1>5. Q.E.D.
::: {.proof}
Step <1>4 is the required equivalence.
:::

::: {.problem}
Let $M$ be a manifold and $f:M\to\mathbb R$.
Show that $f$ is continuous if and only if for every coordinate chart $(U,\phi)$ the function $f\circ\phi^{-1}$ is continuous on $\phi(U)$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

If $f:M\to\mathbb R$ is continuous, then for every coordinate chart $(U,\phi)$ the function
\[
f\circ\phi^{-1}:\phi(U)\longrightarrow\mathbb R
\]
is continuous.

::: pf-proof

For a coordinate chart $(U,\phi)$, the map
\[
\phi^{-1}:\phi(U)\longrightarrow U\subseteq M
\]
is continuous because $\phi$ is a homeomorphism.  Hence $f\circ\phi^{-1}$ is a composition of continuous maps and is therefore continuous.

:::

:::

::: {.pf-step #s2}

Conversely, suppose that $f\circ\phi^{-1}$ is continuous for every coordinate chart $(U,\phi)$.  For every open set $J\subseteq\mathbb R$ and every coordinate chart $(U,\phi)$, the set
\[
U\cap f^{-1}(J)
\]
is open in $M$.

::: pf-proof

Since $f\circ\phi^{-1}$ is continuous,
\[
(f\circ\phi^{-1})^{-1}(J)
\]
is open in the open set $\phi(U)\subseteq\mathbb R^n$.  Because $\phi:U\to\phi(U)$ is a homeomorphism,
\[
\phi^{-1}\bigl((f\circ\phi^{-1})^{-1}(J)\bigr)
=U\cap f^{-1}(J)
\]
is open in $U$.  The chart domain $U$ is open in $M$, so $U\cap f^{-1}(J)$ is open in $M$.

:::

:::

::: {.pf-step #s3}

Under the hypothesis of step [](#s2){.pf-ref}, the preimage $f^{-1}(J)$ is open in $M$ for every open set $J\subseteq\mathbb R$.

::: pf-proof

The coordinate domains cover $M$.  Therefore
\[
f^{-1}(J)
=\bigcup_{(U,\phi)}\bigl(U\cap f^{-1}(J)\bigr),
\]
where the union ranges over the coordinate charts of $M$.  Every set in this union is open by step [](#s2){.pf-ref}, so the union is open.

:::

:::

::: {.pf-step #s4}

Hence
\[
\boxed{
f\text{ is continuous}
\iff
f\circ\phi^{-1}\text{ is continuous for every coordinate chart }(U,\phi).
}
\]

::: pf-proof

Step [](#s1){.pf-ref} proves the forward implication.  Steps [](#s2){.pf-ref} and [](#s3){.pf-ref} show that the inverse image of every open subset of $\mathbb R$ is open, which is the reverse implication.

:::

:::

::: pf-qed

Step [](#s4){.pf-ref} is the required equivalence.

:::

::: {.problem}
In the proof preceding this exercise, one needs the following fact.
For a coordinate chart $(U,\phi)$ about $p$ and a coordinate function $u_j$ on $\phi(U)$, construct $f\in C^\infty(M)$ such that $f\circ\phi^{-1}$ agrees with $u_j$ near $\phi(p)$.
Write out the construction using a bump function.
:::

::: {.problem}
In the proof preceding this exercise, one needs the following fact.
For a coordinate chart $(U,\phi)$ about $p$ and a coordinate function $u_j$ on $\phi(U)$, construct $f\in C^\infty(M)$ such that $f\circ\phi^{-1}$ agrees with $u_j$ near $\phi(p)$.
Write out the construction using a bump function.
:::

::: {.solution}
Put
\[
a=\phi(p)\in\phi(U)\subseteq\mathbb R^m.
\]

::: pf

::: {.pf-step #bump-function-choice}
Choose radii $0<r<R$ such that
\[
\overline{B_R(a)}\subseteq\phi(U),
\]
and choose a smooth function
\[
\chi:\mathbb R^m\longrightarrow[0,1]
\]
with
\[
\chi=1\text{ on }B_r(a),
\qquad
\operatorname{supp}(\chi)\subseteq B_R(a).
\]

::: pf-proof
The set $\phi(U)$ is open and contains $a$, so such radii exist.  The bump-function lemma from the source supplies $\chi$ with the stated properties after translation to the center $a$.
:::

:::

::: {.pf-step #f-is-smooth}
Define $f:M\to\mathbb R$ by
\[
\boxed{
f(x)=
\begin{cases}
\chi(\phi(x))\,u_j(\phi(x)),&x\in U,\\
0,&x\notin U.
\end{cases}
}
\]
Then $f$ is smooth on $M$.

::: pf-proof
On $U$, the function is a product of smooth functions and is therefore smooth.  Its possible nonzero set inside $U$ is contained in
\[
K=\phi^{-1}(\operatorname{supp}\chi)
\subseteq
\phi^{-1}(B_R(a)).
\]
Since $\operatorname{supp}\chi$ is compact and contained in the chart image, $K$ is compact in $M$, hence closed.  Moreover $K\subseteq U$.

If $x\notin K$, then some neighborhood of $x$ is disjoint from $K$, and $f$ is identically zero on that neighborhood.  Thus the zero extension is smooth at every point outside $K$, including points of $M\setminus U$.  Together with smoothness on $U$, this proves $f\in C^\infty(M)$.
:::

:::

::: {.pf-step #f-agrees-with-uj-near-a}
The local coordinate expression $f\circ\phi^{-1}$ agrees with $u_j$ on a neighborhood of $a=\phi(p)$.

::: pf-proof
For $u\in B_r(a)$, step [](#bump-function-choice){.pf-ref} gives $\chi(u)=1$.  Hence
\[
(f\circ\phi^{-1})(u)
=\chi(u)u_j(u)
=u_j(u).
\]
Thus the two functions agree on the open neighborhood $B_r(a)$ of $\phi(p)$.
:::

:::

::: pf-qed
Steps [](#f-is-smooth){.pf-ref} and [](#f-agrees-with-uj-near-a){.pf-ref} give the requested global smooth function with the prescribed coordinate germ.
:::

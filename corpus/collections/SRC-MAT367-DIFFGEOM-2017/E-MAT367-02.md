::: {.problem}
Let $f:X\to Y$ be an injective map and let $A,B\subseteq X$.
Show that
\[
f(A\cap B)=f(A)\cap f(B).
\]
Show by example that this equality need not hold when $f$ is not injective.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For every map $f:X\to Y$,
\[
f(A\cap B)\subseteq f(A)\cap f(B).
\]

::: pf-proof

Let $y\in f(A\cap B)$.  Then there is some $x\in A\cap B$ such that $f(x)=y$.
Since $x\in A$ and $x\in B$, we have $y\in f(A)$ and $y\in f(B)$.  Hence
\[
y\in f(A)\cap f(B).
\]

:::

:::

::: {.pf-step #s2}

If $f$ is injective, then
\[
f(A)\cap f(B)\subseteq f(A\cap B).
\]

::: pf-proof

Let $y\in f(A)\cap f(B)$.  There are $a\in A$ and $b\in B$ such that
\[
f(a)=y=f(b).
\]
Injectivity of $f$ gives $a=b$.  Thus this common element lies in $A\cap B$, and therefore
\[
y=f(a)\in f(A\cap B).
\]

:::

:::

::: {.pf-step #s3}

Without injectivity the reverse inclusion can fail.

::: pf-proof

Take
\[
X=\{0,1\},
\qquad
Y=\{*\},
\]
let $f:X\to Y$ be the constant map, and set
\[
A=\{0\},
\qquad
B=\{1\}.
\]
Then $A\cap B=\varnothing$, so
\[
f(A\cap B)=\varnothing.
\]
On the other hand,
\[
f(A)=f(B)=\{*\},
\]
and hence
\[
f(A)\cap f(B)=\{*\}.
\]
Thus equality fails for this noninjective map.

:::

:::

::: pf-qed

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} prove the equality for injective maps, and step [](#s3){.pf-ref} gives the required counterexample when injectivity is dropped.

:::

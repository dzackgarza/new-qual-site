::: {.problem}
Compute $A ^ { 1 0 }$ for the matrix

$$
A = \left( \begin{array} { r r r } { { 3 } } & { { 1 } } & { { 1 } } \\ { { 2 } } & { { 4 } } & { { 2 } } \\ { { - 1 } } & { { - 1 } } & { { 1 } } \end{array} \right) .
$$
:::

::: {.solution}
::: pf

::: {.pf-step #annihilating-polynomial}
The matrix $A$ satisfies
$$
(A-2I)(A-4I)=0.
$$

::: pf-proof
Direct multiplication gives
$$
A^2=
\begin{pmatrix}
10&6&6\\
12&16&12\\
-6&-6&-2
\end{pmatrix}
=6A-8I.
$$
Therefore $A^2-6A+8I=0$, which is exactly $(A-2I)(A-4I)=0$.
:::

:::

::: {.pf-step #linear-formula}
One has
$$
A^{10}=523776A-1046528I.
$$

::: pf-proof
Let
$$
r(x):=2^{10}\frac{4-x}{2}+4^{10}\frac{x-2}{2}.
$$
Then $r(2)=2^{10}$ and $r(4)=4^{10}$, so the polynomial $x^{10}-r(x)$ is divisible by $(x-2)(x-4)$. By [](#annihilating-polynomial){.pf-ref},
$$
A^{10}=r(A).
$$
Since $2^{10}=1024$ and $4^{10}=1048576$,
$$
r(A)
=512(4I-A)+524288(A-2I)
=523776A-1046528I.
$$
:::

:::

::: pf-step
Therefore
$$
A^{10}=\boxed{
\begin{pmatrix}
524800&523776&523776\\
1047552&1048576&1047552\\
-523776&-523776&-522752
\end{pmatrix}}.
$$

::: pf-proof
Substitute the given matrix $A$ into the formula in [](#linear-formula){.pf-ref} and compute each entry.
:::

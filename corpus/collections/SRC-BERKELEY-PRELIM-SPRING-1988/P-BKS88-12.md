::: {.problem}
For each real value of the parameter $t$, determine the number of real roots, counting multiplicities, of the cubic polynomial
$$
p_t(x)=(1+t^2)x^3-3t^3x+t^4.
$$
:::

::: {.solution}
::: pf

::: {.pf-step #negative-parameter}
If $t<0$, then $p_t$ has exactly one real root.

::: pf-proof
One has
$$
p_t'(x)=3(1+t^2)x^2-3t^3.
$$
If $t<0$, then $-t^3>0$, so $p_t'(x)>0$ for every real $x$. Thus $p_t$ is strictly increasing. Since its leading coefficient is positive,
$$
\lim_{x\to-\infty}p_t(x)=-\infty,
\qquad
\lim_{x\to\infty}p_t(x)=\infty,
$$
so it crosses the real axis exactly once.
:::

:::

::: {.pf-step #zero-parameter}
If $t=0$, then $p_t$ has three real roots counting multiplicity.

::: pf-proof
For $t=0$,
$$
p_0(x)=x^3,
$$
so $x=0$ is a real root of multiplicity $3$.
:::

:::

::: {.pf-step #critical-points}
Suppose $t>0$ and set
$$
\alpha:=\sqrt{\frac{t^3}{1+t^2}}.
$$
Then $-\alpha$ is the local maximum point, $\alpha$ is the local minimum point, and
$$
p_t(-\alpha)=t^3(t+2\alpha)>0,
\qquad
p_t(\alpha)=t^3(t-2\alpha).
$$

::: pf-proof
For $t>0$, the critical-point equation $p_t'(x)=0$ is
$$
(1+t^2)x^2=t^3,
$$
whose solutions are $x=\pm\alpha$. The derivative is positive for $|x|>\alpha$ and negative for $|x|<\alpha$, so $-\alpha$ is a local maximum and $\alpha$ a local minimum. Since $(1+t^2)\alpha^2=t^3$,
$$
(1+t^2)\alpha^3=t^3\alpha.
$$
Substitution gives
$$
p_t(\alpha)=t^3\alpha-3t^3\alpha+t^4=t^3(t-2\alpha)
$$
and
$$
p_t(-\alpha)=-t^3\alpha+3t^3\alpha+t^4=t^3(t+2\alpha)>0.
$$
:::

:::

::: {.pf-step #minimum-sign}
For $t>0$, one has $p_t(\alpha)\leq 0$ exactly when
$$
2-\sqrt3\leq t\leq 2+\sqrt3.
$$

::: pf-proof
By [](#critical-points){.pf-ref}, $p_t(\alpha)\leq0$ is equivalent to $t\leq2\alpha$. Because $t>0$, dividing by $t$ and squaring preserves the inequality:
$$
1\leq \frac{4t}{1+t^2}
\quad\Longleftrightarrow\quad
t^2-4t+1\leq0.
$$
The quadratic on the right has roots $2\pm\sqrt3$, so the inequality holds exactly on the stated interval.
:::

:::

::: {.pf-step #positive-parameter}
If $t>0$, then $p_t$ has three real roots counting multiplicity exactly for $2-\sqrt3\leq t\leq2+\sqrt3$, and otherwise it has exactly one real root.

::: pf-proof
By [](#critical-points){.pf-ref}, the local maximum value is always positive. If the local minimum value is negative, then the cubic crosses the axis once in each of the three monotonicity intervals, giving three distinct real roots. If the local minimum value is zero, then $x=\alpha$ is a double real root and there is one further real root to the left of $-\alpha$, giving three real roots counting multiplicity. If the local minimum value is positive, the graph crosses the axis only once, before the local maximum. [](#minimum-sign){.pf-ref} gives exactly the parameter interval for the first two cases.
:::

:::

::: pf-step
Therefore the number of real roots of $p_t$, counting multiplicities, is
$$
\boxed{
\begin{cases}
3,&t=0\text{ or }2-\sqrt3\leq t\leq2+\sqrt3,\\
1,&\text{otherwise}.
\end{cases}}
$$

::: pf-proof
Combine [](#negative-parameter){.pf-ref}, [](#zero-parameter){.pf-ref}, and [](#positive-parameter){.pf-ref}.
:::

$$
\int _ { 0 } ^ { 1 } x f ( x ) d x = 1 \quad a n d \quad \int _ { 0 } ^ { 1 } x ^ { n } f ( x ) d x = 0
$$

for $n = 0 , 2 , 3 , 4 , \dots \colon$ Give an example or a proof that no such f exists.

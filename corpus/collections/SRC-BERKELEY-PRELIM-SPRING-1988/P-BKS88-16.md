::: problem
Let X be a set and V a real vector space of real valued functions on X of dimension n, $0 < n < \infty$ . Prove that there are n points $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$ in X such that the map $f \mapsto ( f ( x _ { 1 } ) , \dots , f ( x _ { n } ) )$ of V to $\mathbb { R } ^ { n }$ is an isomorphism.
:::

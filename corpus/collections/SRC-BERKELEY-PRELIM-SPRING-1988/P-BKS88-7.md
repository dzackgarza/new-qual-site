::: {.problem}
Let R be a commutative ring with identity element and $a \in R$ Let n and m be positive integers, and write $d = \operatorname* { g c d } \{ n , m \}$ . Prove that the ideal of R generated by $a ^ { n } - 1$ and $a ^ { m } - 1$ is the same as the ideal generated by $a ^ { d } - 1$
:::

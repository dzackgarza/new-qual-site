::: problem
Let $R$ be an integral domain and let $M$ be a nonzero torsion $R\dash$module.

a. Prove that if $M$ is finitely generated then the annihilator in $R$ of $M$ is nonzero.

b. Give an example of a non-finitely generated torsion $R\dash$module whose annihilator is $(0)$, and justify your answer.
:::

::: {.solution}
**(a).**

<1>1. Let $M$ be generated by $m_1, \ldots, m_n$.
::: {.proof}
$M$ is finitely generated.
:::

<1>2. Since $M$ is torsion, for each $m_i$ there is a nonzero $r_i \in R$ with $r_i m_i = 0$.
::: {.proof}
definition of torsion.
:::

<1>3. Let $r = r_1 r_2 \cdots r_n$.
::: {.proof}
define the product.
:::

<1>4. $r \neq 0$ (since $R$ is an integral domain and each $r_i \neq 0$).
::: {.proof}
<1>3 and the domain property.
:::

<1>5. For any $m \in M$, write $m = \sum_i s_i m_i$; then $r m = \sum_i s_i r m_i = \sum_i s_i (r/r_i) r_i m_i = 0$.
::: {.proof}
<1>1 and <1>2 (each $r m_i = 0$ since $r_i \mid r$).
:::

<1>6. Hence $r \in \operatorname{Ann}(M)$, so $\operatorname{Ann}(M) \neq 0$.
::: {.proof}
<1>4 and <1>5.
:::

**(b).**

<1>1. Take $R = \mathbb{Z}$ and $M = \bigoplus_{p \text{ prime}} \mathbb{Z}/p\mathbb{Z}$ (the direct sum over all primes).
::: {.proof}
candidate example.
:::

<1>2. $M$ is torsion (every element is annihilated by its prime).
::: {.proof}
each $\mathbb{Z}/p\mathbb{Z}$ is torsion.
:::

<1>3. $M$ is not finitely generated.
::: {.proof}
it is an infinite direct sum of nonzero groups.
:::

<1>4. $\operatorname{Ann}(M) = (0)$.
::: {.proof}
if $n \in \operatorname{Ann}(M)$, then $n$ annihilates $\mathbb{Z}/p\mathbb{Z}$ for every prime $p$, so $p \mid n$ for every prime $p$, forcing $n = 0$.
:::

<1>5. Q.E.D.
::: {.proof}
<1>6 (a) and <1>4 (b).
:::
:::

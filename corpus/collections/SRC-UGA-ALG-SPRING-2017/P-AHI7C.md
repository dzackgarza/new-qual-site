::: {.problem}
Let $R$ be an integral domain and let $M$ be a nonzero torsion $R\dash$module.

a. Prove that if $M$ is finitely generated then the annihilator in $R$ of $M$ is nonzero.

b. Give an example of a non-finitely generated torsion $R\dash$module whose annihilator is $(0)$, and justify your answer.
:::

::: {.solution}
**(a).**

::: pf

::: {.pf-step #m-generated-by-mi}
Let $M$ be generated by $m_1, \ldots, m_n$.

::: pf-proof
$M$ is finitely generated.
:::

:::

::: {.pf-step #ri-annihilates-mi}
Since $M$ is torsion, for each $m_i$ there is a nonzero $r_i \in R$ with $r_i m_i = 0$.

::: pf-proof
definition of torsion.
:::

:::

::: {.pf-step #r-product-def}
Let $r = r_1 r_2 \cdots r_n$.

::: pf-proof
define the product.
:::

:::

::: {.pf-step #r-nonzero}
$r \neq 0$ (since $R$ is an integral domain and each $r_i \neq 0$).

::: pf-proof
Step [](#r-product-def){.pf-ref} and the domain property.
:::

:::

::: {.pf-step #r-annihilates-m}
For any $m \in M$, write $m = \sum_i s_i m_i$; then $r m = \sum_i s_i r m_i = \sum_i s_i (r/r_i) r_i m_i = 0$.

::: pf-proof
Step [](#m-generated-by-mi){.pf-ref} and step [](#ri-annihilates-mi){.pf-ref} (each $r m_i = 0$ since $r_i \mid r$).
:::

:::

::: {.pf-step #ann-m-nonzero}
Hence $r \in \operatorname{Ann}(M)$, so $\operatorname{Ann}(M) \neq 0$.

::: pf-proof
Step [](#r-nonzero){.pf-ref} and step [](#r-annihilates-m){.pf-ref}.
:::

:::

:::

**(b).**

::: pf

::: pf-step
Take $R = \mathbb{Z}$ and $M = \bigoplus_{p \text{ prime}} \mathbb{Z}/p\mathbb{Z}$ (the direct sum over all primes).

::: pf-proof
candidate example.
:::

:::

::: pf-step
$M$ is torsion (every element is annihilated by its prime).

::: pf-proof
each $\mathbb{Z}/p\mathbb{Z}$ is torsion.
:::

:::

::: pf-step
$M$ is not finitely generated.

::: pf-proof
it is an infinite direct sum of nonzero groups.
:::

:::

::: {.pf-step #ann-m-is-zero}
$\operatorname{Ann}(M) = (0)$.

::: pf-proof
if $n \in \operatorname{Ann}(M)$, then $n$ annihilates $\mathbb{Z}/p\mathbb{Z}$ for every prime $p$, so $p \mid n$ for every prime $p$, forcing $n = 0$.
:::

:::

::: pf-qed
Step [](#ann-m-nonzero){.pf-ref} (a) and step [](#ann-m-is-zero){.pf-ref} (b).
:::

:::

:::

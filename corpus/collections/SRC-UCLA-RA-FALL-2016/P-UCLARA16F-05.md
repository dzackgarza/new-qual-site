::: {.problem}
Let $X=C([0,1])$ be the Banach space of real-valued continuous functions on $[0,1]$ equipped with the norm
\[
\lVert f\rVert=\max_{x\in[0,1]}|f(x)|.
\]
Let $\mathcal A$ be the Borel $\sigma$-algebra on $X$.
Show that $\mathcal A$ is the smallest $\sigma$-algebra on $X$ that contains all sets of the form
\[
S(t,B)=\{f\in X:f(t)\in B\},
\]
where $t\in[0,1]$ and $B\subset\mathbb R$ is a Borel set in $\mathbb R$.
:::

Let
\[
\Sigma
=
\sigma\bigl(
S(t,B):
t\in[0,1],\ B\in\mathcal B(\mathbb R)
\bigr).
\]
We prove
\[
\boxed{\Sigma=\mathcal A}.
\]

## First inclusion

For each \(t\in[0,1]\), define the evaluation map
\[
e_t:X\to\mathbb R,
\qquad
e_t(f)=f(t).
\]

::: pf

::: pf-step

The map \(e_t\) is continuous.


::: pf-proof

For \(f,g\in X\),
\[
|e_t(f)-e_t(g)|
=
|f(t)-g(t)|
\le
\|f-g\|_\infty.
\]
Thus \(e_t\) is \(1\)-Lipschitz.

:::

:::

::: pf-step

For every Borel set \(B\subseteq\mathbb R\),
\[
\boxed{
S(t,B)=e_t^{-1}(B)\in\mathcal A}.
\]


::: pf-proof

Continuous maps are Borel measurable, so inverse images of Borel sets are Borel.

:::

:::

::: pf-step

Therefore
\[
\boxed{\Sigma\subseteq\mathcal A}.
\]


::: pf-proof

The Borel \(\sigma\)-algebra \(\mathcal A\) contains every generator \(S(t,B)\), so it contains the \(\sigma\)-algebra generated by them.

:::

:::

::: pf-step

For every \(h\in C([0,1])\),
\[
\boxed{
\|h\|_\infty
=
\sup_{q\in Q}|h(q)|}.
\]


::: pf-proof

The inequality
\[
\sup_{q\in Q}|h(q)|
\le
\|h\|_\infty
\]
is immediate.

Conversely, since \(|h|\) is continuous on the compact interval \([0,1]\), it attains its maximum at some \(x_0\). Choose rationals \(q_n\in Q\) with
\[
q_n\to x_0.
\]
Continuity gives
\[
|h(q_n)|
\to
|h(x_0)|
=
\|h\|_\infty.
\]
Hence the rational supremum is at least \(\|h\|_\infty\).

:::

:::

::: pf-step

The closed ball
\[
\overline B(g,r)
=
\{f\in X:\|f-g\|_\infty\le r\}
\]
can be written as
\[
\boxed{
\overline B(g,r)
=
\bigcap_{q\in Q}
\left\{
f\in X:
|f(q)-g(q)|\le r
\right\}}.
\]


::: pf-proof

Apply step <1>4 to the continuous function
\[
h=f-g.
\]
The condition
\[
\|f-g\|_\infty\le r
\]
is equivalent to
\[
|f(q)-g(q)|\le r
\]
for every rational \(q\in Q\).

:::

:::

::: pf-step

For fixed \(q\in Q\), the set
\[
\left\{
f:
|f(q)-g(q)|\le r
\right\}
\]
belongs to \(\Sigma\).


::: pf-proof

It is
\[
S\bigl(q,[g(q)-r,g(q)+r]\bigr),
\]
and the interval is Borel in \(\mathbb R\).

:::

:::

::: pf-step

Therefore every closed ball in \(X\) belongs to \(\Sigma\).


::: pf-proof

The set \(Q\) is countable, so step <1>5 is a countable intersection of sets in \(\Sigma\) by step <1>6.

:::

:::

::: pf-step

Every open ball in \(X\) belongs to \(\Sigma\).


::: pf-proof

For \(r>0\),
\[
B(g,r)
=
\bigcup_{\substack{m\ge1\\1/m<r}}
\overline B\left(g,r-\frac1m\right).
\]
Indeed, if \(\|f-g\|_\infty<r\), choose \(m\) so large that
\[
\|f-g\|_\infty
\le
r-\frac1m.
\]
The reverse inclusion is immediate. By step <1>7, every closed ball in the union lies in \(\Sigma\), and the union is countable.

:::

:::

::: pf-step

The Banach space \(C([0,1])\) is separable.


::: pf-proof

By the Weierstrass approximation theorem, polynomials are dense in \(C([0,1])\) under the sup norm.

Polynomials with rational coefficients form a countable set. Given a real-coefficient polynomial
\[
p(x)=\sum_{j=0}^N a_jx^j
\]
and \(\varepsilon>0\), choose rational numbers \(r_j\) so close to \(a_j\) that
\[
\sum_{j=0}^N|a_j-r_j|<\varepsilon.
\]
Then on \([0,1]\),
\[
\left|
p(x)-\sum_{j=0}^Nr_jx^j
\right|
\le
\sum_{j=0}^N|a_j-r_j|
<
\varepsilon.
\]
Thus rational-coefficient polynomials are countable and dense.

:::

:::

::: pf-step

Hence \(X\) has a countable base consisting of open balls.


::: pf-proof

Let \(D\subset X\) be a countable dense subset from step <1>9. The family
\[
\mathcal B
=
\{B(g,r):g\in D,\ r\in\mathbb Q_{>0}\}
\]
is countable.

If \(U\subseteq X\) is open and \(f\in U\), choose \(\varepsilon>0\) with
\[
B(f,\varepsilon)\subseteq U.
\]
Choose \(g\in D\) with
\[
\|f-g\|_\infty<\varepsilon/3,
\]
and choose rational \(r\) with
\[
\|f-g\|_\infty<r<2\varepsilon/3.
\]
Then
\[
f\in B(g,r)\subseteq B(f,\varepsilon)\subseteq U.
\]
Thus \(\mathcal B\) is a countable base.

:::

:::

::: pf-step

Every open subset \(U\subseteq X\) is a countable union of open balls from the base \(\mathcal B\).


::: pf-proof

One has
\[
U
=
\bigcup
\{B\in\mathcal B:B\subseteq U\}.
\]
Since \(\mathcal B\) is countable, this union is countable.

:::

:::

::: pf-step

Therefore every open subset of \(X\) belongs to \(\Sigma\).


::: pf-proof

Every basis ball belongs to \(\Sigma\) by step <1>8, and every open set is a countable union of such balls by step <1>11.

:::

:::

::: pf-step

Hence
\[
\boxed{\mathcal A\subseteq\Sigma}.
\]


::: pf-proof

The Borel \(\sigma\)-algebra \(\mathcal A\) is generated by the open subsets of \(X\), all of which lie in \(\Sigma\) by step <1>12.

:::

:::

::: pf-step

Combining the two inclusions,
\[
\boxed{
\mathcal A
=
\sigma\bigl(
S(t,B):
t\in[0,1],\ B\in\mathcal B(\mathbb R)
\bigr)}.
\]


::: pf-proof

Use steps <1>3 and <1>13.

:::

:::

::: pf-qed

Step <1>14 is the required minimality statement.

:::

:::

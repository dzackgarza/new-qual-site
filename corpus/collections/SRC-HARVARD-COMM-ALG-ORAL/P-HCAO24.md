::: {.problem}
Define the Hilbert function of a graded ring.
:::

::: {.solution}
Let $S=\bigoplus_{d\ge0}S_d$ be a graded commutative ring such that $S_0$ is
Artinian and $S$ is generated as an $S_0$-algebra by finitely many elements
$x_1,\ldots,x_n\in S_1$.

<1>1. Each $S_d$ is an $S_0$-module of finite length.

::: {.proof}
The $S_0$-module $S_d$ is generated by the $\binom{d+n-1}{n-1}$ monomials of
degree $d$ in $x_1,\ldots,x_n$. A finitely generated module over an Artinian
ring has finite length.
:::

<1>2. The \dfn{Hilbert function} of $S$ is
$$
\operatorname{HF}_S\colon\ZZ_{\ge0}\to\ZZ_{\ge0},\qquad
d\longmapsto\ell_{S_0}(S_d).
$$
When $S_0=k$ is a field, $\operatorname{HF}_S(d)=\dim_kS_d$. For a finitely
generated graded $S$-module $M=\bigoplus_{d\in\ZZ}M_d$, the Hilbert function
of $M$ is $\operatorname{HF}_M(d)=\ell_{S_0}(M_d)$.

::: {.proof}
By step <1>1 the value $\ell_{S_0}(S_d)$ is a nonnegative integer. If $M$ is
generated by homogeneous elements $m_1,\ldots,m_t$ of degrees
$e_1,\ldots,e_t$, then $M_d=\sum_iS_{d-e_i}m_i$ is a finitely generated
$S_0$-module, so it has finite length.
:::
:::

::: {.remark}
By the Hilbert--Serre theorem, the Hilbert series
$\sum_{d\ge0}\operatorname{HF}_S(d)\,t^d$ equals $P(t)/(1-t)^n$ for some
$P(t)\in\ZZ[t]$. Consequently there is a polynomial
$\operatorname{HP}_S\in\QQ[d]$, the Hilbert polynomial of $S$, with
$\operatorname{HF}_S(d)=\operatorname{HP}_S(d)$ for all $d\gg0$, and
$\deg\operatorname{HP}_S=\dim S-1$, where the zero polynomial has degree $-1$.
:::

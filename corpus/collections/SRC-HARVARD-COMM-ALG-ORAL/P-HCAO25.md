::: problem
Let $S=\bigoplus_{d=0}^{\infty} S_d$ be a graded ring.
State conditions on $S$ which ensure that its Hilbert function agrees with a polynomial for all sufficiently large $d$.
:::

::: solution
**Goal:** Give hypotheses that force the Hilbert function of $S$ to be eventually polynomial.

<1> Assume $S$ is a **standard graded Noetherian $k$-algebra**: *Proof:* <2>1. $S_0=k$ is a field.
<2>2. Each homogeneous piece $S_d$ is finite-dimensional over $k$.
<2>3. $S$ is generated as a $k$-algebra by finitely many elements of degree $1$.
<2>4. Equivalently, $S\cong k[x_1,\dots,x_r]/I$ with the standard grading and homogeneous ideal $I$.

<1> Apply the Hilbert--Serre theorem.
*Proof:* <2>1. For such $S$, the Hilbert series is $$H_S(t)=\sum_{d\ge0}\dim_k S_d\, t^d=\frac{P(t)}{(1-t)^m}$$ with $P(t)\in\ZZ[t]$ and $P(1)\ne0$.
<2>2. Expanding this rational function gives $$\dim_k S_d = \text{(polynomial in $d$)} \quad \text{for all } d\gg0.$$ <2>3. Therefore the Hilbert function agrees with a polynomial eventually.

<1> So the condition set is: $S_0$ is a field and $S$ is Noetherian, finitely generated by degree-$1$ elements as a graded $S_0$-algebra.

:::

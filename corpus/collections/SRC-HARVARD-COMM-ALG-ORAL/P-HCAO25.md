::: problem
Let $S=\bigoplus_{d=0}^{\infty} S_d$ be a graded ring.
State conditions on $S$ which ensure that its Hilbert function agrees with a polynomial for all sufficiently large $d$.
:::

::: solution
**Goal:** State the precise conditions on a graded ring $S$ ensuring its Hilbert function is eventually polynomial (the Hilbert polynomial) and prove this via the Hilbert–Serre Theorem.

<1>1. Necessary and sufficient conditions on $S$:
    *Proof:*
    <2>1. Base ring condition: $S_0 = k$ is a field (or more generally, an Artinian ring, so that finite-length $S_0$-modules have well-defined finite length).
    <2>2. Generation condition: $S$ is finitely generated as an $S_0$-algebra by elements of degree 1:
    $$S = S_0[x_1, x_2, \dots, x_r], \qquad \deg(x_i) = 1 \text{ for } i = 1, \dots, r.$$
    (Such a graded algebra is called a *standard graded* $k$-algebra).
    <2>3. Under these conditions, each homogeneous graded piece $S_d$ is a finite-dimensional $k$-vector space, so the Hilbert function $H(S, d) = \dim_k S_d$ is well-defined.

<1>2. The Hilbert–Serre Theorem on Hilbert series:
    *Proof:*
    <2>1. Define the Hilbert–Poincaré series of $S$ as the formal power series
    $$P(S, t) = \sum_{d=0}^\infty (\dim_k S_d) t^d \in \mathbb{Z}[[t]].$$
    <2>2. By the Hilbert–Serre Theorem, for any standard graded $k$-algebra $S$ generated by $r$ elements of degree 1, there exists a polynomial $Q(t) \in \mathbb{Z}[t]$ such that
    $$P(S, t) = \frac{Q(t)}{(1 - t)^r}.$$

<1>3. Extraction of the Hilbert polynomial for large $d$:
    *Proof:*
    <2>1. Write $Q(t) = \sum_{j=0}^m a_j t^j \in \mathbb{Z}[t]$.
    <2>2. Using the negative binomial expansion:
    $$\frac{1}{(1 - t)^r} = \sum_{k=0}^\infty \binom{k + r - 1}{r - 1} t^k.$$
    <2>3. Multiplying by $Q(t)$ gives the coefficient of $t^d$ for any $d \ge m$:
    $$\dim_k S_d = \sum_{j=0}^m a_j \binom{d - j + r - 1}{r - 1}.$$
    <2>4. For each fixed $j$, the binomial coefficient $\binom{d - j + r - 1}{r - 1} = \frac{(d - j + r - 1)(d - j + r - 2)\cdots(d - j + 1)}{(r - 1)!}$ is a polynomial in $d$ with rational coefficients of degree $r - 1$.
    <2>5. Therefore, for all $d \ge m = \deg Q$, $\dim_k S_d$ agrees identically with a single polynomial $P_S(d) \in \mathbb{Q}[d]$ (the Hilbert polynomial of $S$).

<1>4. Conclusion:
    *Proof:*
    The Hilbert function of $S$ agrees with a polynomial for all sufficiently large $d$ whenever $S_0$ is a field (or Artinian ring) and $S$ is finitely generated over $S_0$ by elements of degree 1.
:::

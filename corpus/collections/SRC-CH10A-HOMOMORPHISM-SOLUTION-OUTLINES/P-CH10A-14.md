::: {.problem}
Explain why the correspondence $x \mapsto 3 x$ from $\ZZ_{12}$ to $\ZZ_{10}$ is not a homomorphism.
:::

::: {.solution}
If the correspondence is a homomorphism, then it should preserve the operation.
Let’s show this is not true via a counter example.
Take $6, 7 \in \ZZ_{12}$. Then $\phi(6 + 7) = \phi(1) = 3$. But $\phi(6) + \phi(7) = 18 + 21 = 8 + 1 = 9$. Since $3 \neq 9$ in $\ZZ_{10}$, the operation is not preserved.
:::

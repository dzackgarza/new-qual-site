::: {.problem}
Explain why the correspondence $x \mapsto 3 x$ from $\ZZ_{12}$ to $\ZZ_{10}$ is not a homomorphism.
:::

::: {.solution}

The exercise is Gallian, *Contemporary Abstract Algebra* (7th ed.), Chapter 10 exercise 14, and is item 14 of the retained Chapter 10 Part A solution outline
(`assets/attachments/Ch10PtASltns.pdf`). The outline's computation appears as step
[](#outline){.pf-ref}; the diagnosis it draws from that computation is corrected below,
since the two numbers it compares are values of the rule at two representatives of a single
class of $\ZZ_{12}$.

Write $[r]_{m}$ for the class of $r$ in $\ZZ_{m}$, and let $\phi$ be the correspondence
$[r]_{12}\mapsto[3r]_{10}$.

::: pf

::: {.pf-step #wellposed}

$\phi$ is not well defined: $\theset{0}_{12}=\theset{12}_{12}$, but $\phi$ sends them to
$\theset{0}_{10}$ and $\theset{36}_{10}=\theset{6}_{10}$, and $\theset{0}_{10}\ne\theset{6}_{10}$.

::: pf-proof

$12\equiv0\pmod{12}$ by definition of the residue classes modulo $12$. In $\ZZ_{10}$,
$3\cdot0=0$ and $3\cdot12=36\equiv6\pmod{10}$, since $36-6=30$ is a multiple of $10$. As
$10$ does not divide $6$, the classes $\theset{0}_{10}$ and $\theset{6}_{10}$ are distinct.

:::

:::

::: {.pf-step #notfunction}

A correspondence from $\ZZ_{12}$ to $\ZZ_{10}$ that assigns two different values to one
element is not a function, and a homomorphism of groups is in particular a function.

::: pf-proof

By the definition of a function, each element of the domain has exactly one image. The
correspondence $\phi$ assigns to $\theset{0}_{12}$ both $\theset{0}_{10}$ and $\theset{6}_{10}$ by step
[](#wellposed){.pf-ref}, so it is not a function on $\ZZ_{12}$. A group homomorphism
$\ZZ_{12}\to\ZZ_{10}$ is a map that satisfies $\phi(x+y)=\phi(x)+\phi(y)$ for all $x,y$ in
$\ZZ_{12}$ (Definition, Chapter 10), and a map is a function; hence $\phi$ is not a
homomorphism.

:::

:::

::: {.pf-step #outline}

The outline's computation, read correctly, is the same failure: it compares
$\phi(\theset{6}_{12}+\theset{7}_{12})=\phi(\theset{1}_{12})=\theset{3}_{10}$ with
$\phi(\theset{6}_{12})+\phi(\theset{7}_{12})=\theset{18}_{10}+\theset{21}_{10}=\theset{8}_{10}+\theset{1}_{10}
=\theset{9}_{10}$, and $\theset{3}_{10}\ne\theset{9}_{10}$.

::: pf-proof

The sum $\theset{6}_{12}+\theset{7}_{12}=\theset{13}_{12}=\theset{1}_{12}$, so the left-hand side evaluates
the rule at the class of $1$. The right-hand side evaluates it at the representatives $6$
and $7$: $3\cdot6=18\equiv8$ and $3\cdot7=21\equiv1$ modulo $10$, and $8+1=9$. The same
class $\theset{13}_{12}=\theset{1}_{12}$ therefore receives $\theset{39}_{10}=\theset{9}_{10}$ from the
representative $13$ and $\theset{3}_{10}$ from the representative $1$, which is the failure
proved in step [](#wellposed){.pf-ref}. So the outline's two sides differ because the rule
is not well defined, not because it is well defined and fails to be additive.

:::

:::

::: {.pf-step #classification}

The homomorphisms $\ZZ_{12}\to\ZZ_{10}$ are exactly $x\mapsto\theset{5x}_{10}$ and
$x\mapsto\theset{0}_{10}$; the correspondence $x\mapsto\theset{3x}_{10}$ is neither.

::: pf-proof

Let $\psi:\ZZ_{12}\to\ZZ_{10}$ be a homomorphism and put $e=\psi(\theset{1}_{12})$. Additivity
gives $\psi(\theset{n}_{12})=\theset{ne}_{10}$ for every integer $n$, so $\psi$ is determined by $e$
and has the form $x\mapsto\theset{xe}_{10}$. Such a rule is well defined exactly when
$\theset{12}_{12}=\theset{0}_{12}$ forces $\theset{12e}_{10}=\theset{0}_{10}$, that is when
$12e\equiv0\pmod{10}$; since $12\equiv2$ modulo $10$, this is $2e\equiv0\pmod{10}$, which
holds exactly when $5$ divides $e$, that is for $e=\theset{0}_{10}$ and $e=\theset{5}_{10}$. Both
give homomorphisms by direct check: $12\cdot5=60\equiv0$ and $12\cdot0=0$ modulo $10$, and
$\theset{(n+m)e}_{10}=\theset{ne}_{10}+\theset{me}_{10}$. The correspondence with $e=\theset{3}_{10}$ fails
the well-definedness condition $12\cdot3=36\not\equiv0\pmod{10}$, which is step
[](#wellposed){.pf-ref}.

:::

:::

::: {.pf-step #answer}

The correspondence $x\mapsto3x$ from $\ZZ_{12}$ to $\ZZ_{10}$ is not a homomorphism, because
it is not even well defined.

::: pf-proof

This is step [](#notfunction){.pf-ref}, with the arithmetic of the failure identified in step
[](#wellposed){.pf-ref} and the contrast supplied by step [](#classification){.pf-ref}: of
the rules $x\mapsto xe$ with $e$ in $\ZZ_{10}$, only $e=0$ and $e=5$ respect the class of
$x$ modulo $12$, and $e=3$ is not among them.

:::

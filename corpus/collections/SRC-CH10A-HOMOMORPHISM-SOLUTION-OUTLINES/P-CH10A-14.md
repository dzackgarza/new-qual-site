::: {.problem}
Explain why the correspondence $x \mapsto 3 x$ from $\mathbb { Z } _ { 1 2 }$ to $\mathbb { Z } _ { 1 0 }$ is not a homomorphism.
:::

::: {.solution}
If the correspondence is a homomorphism, then it should preserve the operation.
Let’s show this is not true via a counter example.
Take $6 , 7 \in \mathbb { Z } _ { 1 2 }$ Then $\phi ( 6 + 7 ) = \phi ( 1 ) = 3$ . But $\phi ( 6 ) + \phi ( 7 ) = 1 8 + 2 1 = 8 + 1 = 9$ . Since $3 \neq 9$ in $\mathbb { Z } _ { 1 0 }$ the operation is not preserved.
:::

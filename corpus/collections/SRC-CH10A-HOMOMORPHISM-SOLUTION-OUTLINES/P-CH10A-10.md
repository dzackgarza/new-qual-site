::: {.problem}
Let $G$ be a subgroup of some dihedral group.
For each $x$ in $G$, define $\phi(x)$ to be $+1$ if $x$ is a rotation and $-1$ if $x$ is a reflection.
Prove that $\phi$ is a homomorphism from $G$ to the multiplicative group $\{+1,-1\}$.
What is the kernel?
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Let $D_n=\langle r,f\mid r^n=f^2=1,\ fr=r^{-1}f\rangle$ and let $G\le D_n$. Every element of $D_n$ is $r^i$ (a rotation) or $r^if$ (a reflection).

::: pf

::: {.pf-step #multiplicative}
The assignment $\varphi(G\cap\langle r\rangle)=1$ and $\varphi(G\setminus\langle r\rangle)=-1$ is multiplicative.

::: pf-proof
Check the four kinds of product, using $f^2=1$ and $fr=r^{-1}f$. Rotation times rotation: $r^ir^j=r^{i+j}$ is a rotation, and $1\cdot1=1$. Reflection times reflection: $(r^if)(r^jf)=r^ifr^jf=r^ir^{-j}f^2=r^{i-j}$, a rotation, and $(-1)(-1)=1$. Rotation times reflection: $r^i\cdot r^jf=r^{i+j}f$, a reflection, and $1\cdot(-1)=-1$. Reflection times rotation: $(r^if)r^j=r^ifr^j=r^ir^{-j}f$, a reflection, and $(-1)\cdot1=-1$. In each case $\varphi(xy)=\varphi(x)\varphi(y)$, and $\varphi(1)=1$ since $1$ is a rotation.
:::

:::

::: {.pf-step #kernel}
$\ker\varphi=G\cap\langle r\rangle$, the subgroup of rotations in $G$.

::: pf-proof
$\varphi(x)=1$ exactly when $x$ is a rotation, by the definition of $\varphi$; so the kernel is the set of rotations lying in $G$, which is $G\cap\langle r\rangle$. It is normal in $G$ because it is a kernel, and it has index $1$ or $2$ according as $G$ contains no reflection or at least one, since $\{\pm1\}$ has order $2$ and $\varphi$ is onto in the second case.
:::

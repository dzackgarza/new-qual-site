::: {.problem}
Let $G$ be a subgroup of some dihedral group.
For each $x$ in $G$, define $\phi(x)$ to be $+1$ if $x$ is a rotation and $-1$ if $x$ is a reflection.
Prove that $\phi$ is a homomorphism from $G$ to the multiplicative group $\{+1,-1\}$.
What is the kernel?
:::

::: {.solution}
Let $D_n$ be the dihedral group containing $G$, with rotation $r$ of order $n$ and a reflection $f$.
Every element of $G$ is a rotation $r ^ { i }$ or a reflection $r ^ { i } f$. Since $D_n$ is not Abelian, there are four cases for a product: two rotations, two reflections, a rotation times a reflection, and a reflection times a rotation. In each case $\phi$ is multiplicative:

$$
\bullet \ \phi ( r ^ { i } \circ r ^ { j } ) = \phi ( r ^ { i + j } ) = 1 = 1 \cdot 1 = \phi ( r ^ { i } ) \cdot \phi ( r ^ { j } )
$$

$$
\phi ( r ^ { i } f \circ r ^ { j } f ) = \phi ( r ^ { i } r ^ { n - j } f f ) = \phi ( r ^ { i + n - j } ) = 1 = - 1 \cdot - 1 = \phi ( r ^ { i } f ) \cdot \phi ( r ^ { j } f )
$$

• $\phi ( r ^ { i } \circ r ^ { j } f ) = \phi ( r ^ { i + j } f ) = - 1 = 1 \cdot - 1 = \phi ( r ^ { i } ) \cdot \phi ( r ^ { j } f )$

$$
\bullet \ \phi ( r ^ { i } f \circ r ^ { j } ) = \phi ( r ^ { i } r ^ { n - j } f ) = \phi ( r ^ { i + n - j } f ) = - 1 = - 1 \cdot 1 = \phi ( r ^ { i } f ) \cdot \phi ( r ^ { j } )
$$

$K e r \phi = \{ g \mid \phi ( g ) = 1 \} = \{ \text { rotations in } G \} = G \cap \langle r \rangle$
:::

::: {.problem}
Prove that the mapping given in Example 3 is a homomorphism.
:::

::: {.solution}
Let $\phi : \mathbb { R } ^ { * } \to \mathbb { R } ^ { * }$ be defined by $x \mapsto | x |$ . Then $\phi ( x y ) = | x y | = | x | | y | = \phi ( x ) \phi ( y )$ so $\phi$ is a homomorphism.
:::

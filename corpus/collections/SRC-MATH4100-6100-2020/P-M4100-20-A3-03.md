::: {.problem}
A real number is called algebraic if it is a root of a nonzero polynomial with integer coefficients.

(a) Show that
$$
\sqrt2,
\qquad
\sqrt[3]{2},
\qquad
\sqrt2+\sqrt3
$$
are algebraic.

(b) Prove that the set of all algebraic real numbers is countable. What does this imply about the set of transcendental real numbers?

Hint: first show that, for each fixed degree $n$, the set of integer-coefficient polynomials of degree $n$ is countable.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The number $\sqrt2$ is algebraic.


::: pf-proof

It is a root of the nonzero polynomial
$$
x^2-2\in\ZZ[x].
$$

:::

:::

::: {.pf-step #s1-2}

The number $\sqrt[3]{2}$ is algebraic.


::: pf-proof

It is a root of
$$
x^3-2\in\ZZ[x].
$$

:::

:::

::: {.pf-step #s1-3}

The number $\sqrt2+\sqrt3$ is algebraic.


::: pf-proof

Set
$$
\alpha=\sqrt2+\sqrt3.
$$
Then
$$
\alpha^2
=
5+2\sqrt6,
$$
so
$$
\alpha^2-5=2\sqrt6.
$$
Squaring gives
$$
(\alpha^2-5)^2=24.
$$
Therefore
$$
\alpha^4-10\alpha^2+1=0,
$$
so $\alpha$ is a root of the nonzero polynomial
$$
x^4-10x^2+1\in\ZZ[x].
$$

:::

:::

::: {.pf-step #s1-4}

Part (a) follows.


::: pf-proof

Steps [](#s1-1){.pf-ref} through [](#s1-3){.pf-ref} give an integer-coefficient polynomial annihilating each of
the three numbers.

:::

:::

::: {.pf-step #s1-5}

For every fixed $n\geq0$, the set of integer-coefficient polynomials of
degree at most $n$ is countable.


::: pf-proof

Every such polynomial is determined by its coefficient tuple
$$
(a_0,a_1,\ldots,a_n)\in\ZZ^{n+1}.
$$
The set $\ZZ$ is countable, so its finite Cartesian power
$$
\ZZ^{n+1}
$$
is countable. Hence the set of such polynomials is countable.

:::

:::

::: {.pf-step #s1-6}

The set of all integer-coefficient polynomials is countable.


::: pf-proof

Let $P_n$ be the set of integer-coefficient polynomials of degree at most
$n$. By step [](#s1-5){.pf-ref}, each $P_n$ is countable, and
$$
\ZZ[x]
=
\bigcup_{n=0}^{\infty}P_n.
$$
A countable union of countable sets is countable.

:::

:::

::: {.pf-step #s1-7}

Every nonzero polynomial has only finitely many real roots.


::: pf-proof

A nonzero polynomial of degree $d$ over a field has at most $d$ roots.
Therefore its set of real roots is finite.

:::

:::

::: {.pf-step #s1-8}

The set $\mathcal A$ of algebraic real numbers is countable.


::: pf-proof

For each nonzero polynomial $p\in\ZZ[x]$, let
$$
Z(p)=\{x\in\RR:p(x)=0\}.
$$
By step [](#s1-7){.pf-ref}, each $Z(p)$ is finite. By step [](#s1-6){.pf-ref}, there are only countably many
nonzero polynomials in $\ZZ[x]$. Since
$$
\mathcal A
=
\bigcup_{0\neq p\in\ZZ[x]} Z(p),
$$
the set $\mathcal A$ is a countable union of finite sets, hence countable.

:::

:::

::: {.pf-step #s1-9}

The set of transcendental real numbers is uncountable.


::: pf-proof

The real numbers are uncountable, while the algebraic reals are countable by
step [](#s1-8){.pf-ref}. If the transcendental reals
$$
\RR\setminus\mathcal A
$$
were countable, then
$$
\RR
=
\mathcal A\cup(\RR\setminus\mathcal A)
$$
would be a union of two countable sets and therefore countable, a
contradiction.

:::

:::

::: {.pf-step #s1-10}

Part (b) follows.


::: pf-proof

Step [](#s1-8){.pf-ref} proves countability of the algebraic reals, and step [](#s1-9){.pf-ref} gives the
stated consequence for transcendental reals.

:::

:::

::: pf-qed

Steps [](#s1-4){.pf-ref} and [](#s1-10){.pf-ref} establish parts (a) and (b), respectively.

:::

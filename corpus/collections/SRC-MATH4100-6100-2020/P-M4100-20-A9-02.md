::: {.problem}
(a) Consider the sequence of functions

$$
F _ { n } ( x ) = { \frac { x } { 1 + n x ^ { 2 } } } .
$$

Find the points on R where each $F _ { n } ( x )$ attains it maximum and minimum value.
Use this to prove that $\{ F _ { n } \}$ converges uniformly on R.

(b) Prove that $G _ { n } ( x ) = x ^ { n } ( 1 - x )$ converges uniformly to 0 on [0, 1].
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For
$$
F_n(x)=\frac{x}{1+nx^2},
$$
one has
$$
F_n'(x)=\frac{1-nx^2}{(1+nx^2)^2}.
$$


::: pf-proof

Differentiate using the quotient rule.

:::

:::

::: pf-step

The only critical points of $F_n$ are
$$
x=\pm\frac1{\sqrt n}.
$$


::: pf-proof

The denominator in step [](#s1-1){.pf-ref} is always positive, so
$$
F_n'(x)=0
\iff
1-nx^2=0.
$$

:::

:::

::: {.pf-step #s1-3}

The function $F_n$ attains its maximum at
$$
x=\frac1{\sqrt n}
$$
and its minimum at
$$
x=-\frac1{\sqrt n},
$$
with values
$$
\pm\frac1{2\sqrt n}.
$$


::: pf-proof

By step [](#s1-1){.pf-ref}, the derivative is positive when
$$
|x|<\frac1{\sqrt n}
$$
and negative when
$$
|x|>\frac1{\sqrt n}.
$$
Thus the positive critical point is a global maximum and the negative one is
a global minimum. Direct substitution gives
$$
F_n\left(\frac1{\sqrt n}\right)
=
\frac{1/\sqrt n}{2}
=
\frac1{2\sqrt n},
$$
and oddness gives the minimum value.

:::

:::

::: {.pf-step #s1-4}

The sequence $(F_n)$ converges uniformly to $0$ on $\RR$.


::: pf-proof

Step [](#s1-3){.pf-ref} gives
$$
\sup_{x\in\RR}|F_n(x)|
=
\frac1{2\sqrt n}
\longrightarrow0.
$$
This is precisely uniform convergence to $0$.

:::

:::

::: {.pf-step #s1-5}

Part (a) follows.


::: pf-proof

Steps [](#s1-3){.pf-ref} and [](#s1-4){.pf-ref} give the extrema and the uniform convergence.

:::

:::

::: {.pf-step #s1-6}

For
$$
G_n(x)=x^n(1-x),
\qquad
x\in[0,1],
$$
one has
$$
G_n'(x)
=
x^{n-1}\bigl(n-(n+1)x\bigr).
$$


::: pf-proof

Differentiate by the product rule.

:::

:::

::: {.pf-step #s1-7}

The maximum of $G_n$ on $[0,1]$ occurs at
$$
x_n=\frac{n}{n+1}.
$$


::: pf-proof

The function is nonnegative on $[0,1]$ and vanishes at both endpoints. By
step [](#s1-6){.pf-ref}, the derivative is positive for
$$
0<x<\frac{n}{n+1}
$$
and negative for
$$
\frac{n}{n+1}<x<1.
$$
Hence the unique interior critical point is the global maximum.

:::

:::

::: {.pf-step #s1-8}

One has
$$
0\leq G_n(x)
\leq
\frac1{n+1}
$$
for every $x\in[0,1]$.


::: pf-proof

At the maximizer from step [](#s1-7){.pf-ref},
$$
G_n(x_n)
=
\left(\frac{n}{n+1}\right)^n
\frac1{n+1}
\leq
\frac1{n+1}.
$$
Since $G_n$ is nonnegative, the stated bound follows.

:::

:::

::: {.pf-step #s1-9}

The sequence $(G_n)$ converges uniformly to $0$ on $[0,1]$.


::: pf-proof

Step [](#s1-8){.pf-ref} gives
$$
\sup_{0\leq x\leq1}|G_n(x)|
\leq
\frac1{n+1}
\longrightarrow0.
$$

:::

:::

::: {.pf-step #s1-10}

Part (b) follows.


::: pf-proof

This is step [](#s1-9){.pf-ref}.

:::

:::

::: pf-qed

Steps [](#s1-5){.pf-ref} and [](#s1-10){.pf-ref} establish parts (a) and (b), respectively.

:::

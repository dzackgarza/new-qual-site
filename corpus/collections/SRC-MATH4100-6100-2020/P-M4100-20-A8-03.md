::: {.problem}
(a) Let

$$
f _ { a } ( x ) = { \left\{ \begin{array} { l l } { x ^ { a } } & { { \mathrm { i f ~ } } x > 0 } \\ { 0 } & { { \mathrm { i f ~ } } x \leq 0 } \end{array} \right. }
$$

i. For which values of a is $f _ { a }$ continuous at $0 ?$

ii.
For which values of a is $f _ { a }$ differentiable at 0? In this case is the derivative function continuous?

iii.
For which values of a is $f _ { a }$ twice-differentiable?

(b) Let

$$
g _ { a } ( x ) = { \left\{ \begin{array} { l l } { x ^ { a } \sin ( 1 / x ) } & { { \mathrm { i f ~ } } x \neq 0 } \\ { 0 } & { { \mathrm { i f ~ } } x = 0 } \end{array} \right. }
$$

Find particular non-negative (and potentially non-integral) values of a for which:

i. $g _ { a }$ is differentiable on $\RR ,$ but $g _ { a } ^ { \prime }$ is unbounded on [0, 1].

ii.
$g _ { a }$ is differentiable on R with $g _ { a } ^ { \prime }$ continuous but not differentiable at 0.

iii.
$g _ { a }$ and $g _ { a } ^ { \prime }$ are differentiable on R, but $g _ { a } ^ { \prime \prime }$ is not continuous at 0.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The function $f_a$ is continuous at $0$ exactly when
$$
\boxed{a>0}.
$$


::: pf-proof

Since $f_a(0)=0$, continuity at $0$ requires
$$
\lim_{x\to0}f_a(x)=0.
$$
From the left, $f_a(x)=0$, so the left-hand limit is always $0$.

From the right,
$$
f_a(x)=x^a.
$$
If $a>0$, then $x^a\to0$ as $x\to0^+$. If $a=0$, then $x^a=1$ for
$x>0$, so the right-hand limit is $1$. If $a<0$, then $x^a\to+\infty$.
Hence continuity occurs exactly for $a>0$.

:::

:::

::: {.pf-step #s1-2}

The function $f_a$ is differentiable at $0$ exactly when
$$
\boxed{a>1},
$$
and then
$$
f_a'(0)=0.
$$


::: pf-proof

For $h<0$,
$$
\frac{f_a(h)-f_a(0)}h=0.
$$
For $h>0$,
$$
\frac{f_a(h)-f_a(0)}h
=
h^{a-1}.
$$
The right-hand limit equals $0$ exactly when $a>1$. For $a=1$ it equals $1$,
and for $a<1$ it does not tend to $0$. Thus the two-sided derivative exists
exactly when $a>1$, and its value is $0$.

:::

:::

::: {.pf-step #s1-3}

If $a>1$, then
$$
f_a'(x)
=
\begin{cases}
a x^{a-1},&x>0,\\
0,&x\leq0,
\end{cases}
$$
and $f_a'$ is continuous on $\RR$.


::: pf-proof

Away from $0$, differentiation is immediate. Step [](#s1-2){.pf-ref} gives $f_a'(0)=0$.
As $x\to0^+$,
$$
a x^{a-1}\longrightarrow0
$$
because $a-1>0$, while from the left the derivative is identically $0$.
Hence $f_a'$ is continuous at $0$, and it is plainly continuous elsewhere.

:::

:::

::: {.pf-step #s1-4}

The function $f_a$ is twice differentiable on $\RR$ exactly when
$$
\boxed{a>2}.
$$


::: pf-proof

A necessary condition is $a>1$ by step [](#s1-2){.pf-ref}. For such $a$, step [](#s1-3){.pf-ref} gives
$f_a'(0)=0$. Thus
$$
\frac{f_a'(h)-f_a'(0)}h
=
\begin{cases}
a h^{a-2},&h>0,\\
0,&h<0.
\end{cases}
$$
The right-hand limit is $0$ exactly when $a>2$. For $a=2$ it equals $2$,
while the left-hand limit is $0$; for $1<a<2$ it does not have a finite
right-hand limit. Therefore the second derivative exists at $0$ exactly when
$a>2$. Away from $0$, $f_a$ is smooth on each side.

:::

:::

::: {.pf-step #s1-5}

Part (a) follows.


::: pf-proof

Steps [](#s1-1){.pf-ref} through [](#s1-4){.pf-ref} answer parts (i)--(iii), including continuity of the
derivative in the differentiable cases.

:::

::: {.pf-step #s1-6}

For any exponent for which $x^a$ is real and differentiable on
$\RR\setminus\{0\}$,
$$
g_a'(x)
=
a x^{a-1}\sin(1/x)
-
x^{a-2}\cos(1/x),
\qquad x\neq0.
$$


::: pf-proof

Differentiate
$$
x^a\sin(1/x)
$$
by the product and chain rules:
$$
\begin{aligned}
g_a'(x)
&=
a x^{a-1}\sin(1/x)
+
x^a\cos(1/x)\left(-\frac1{x^2}\right)\\
&=
a x^{a-1}\sin(1/x)
-
x^{a-2}\cos(1/x).
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-7}

If $a>1$, then $g_a$ is differentiable at $0$ and
$$
g_a'(0)=0.
$$


::: pf-proof

Since $g_a(0)=0$,
$$
\left|
\frac{g_a(h)-g_a(0)}h
\right|
=
|h|^{a-1}|\sin(1/h)|
\leq
|h|^{a-1}.
$$
If $a>1$, the right-hand side tends to $0$. The squeeze theorem gives the
derivative value $0$.

:::

:::

::: {.pf-step #s1-8}

Take
$$
a=\frac53.
$$
Then $g_a$ is differentiable on $\RR$, but $g_a'$ is unbounded on $[0,1]$.


::: pf-proof

The exponent $5/3>1$, so step [](#s1-7){.pf-ref} gives differentiability at $0$; away from
$0$, the function is differentiable by the ordinary power and chain rules.

For $x\neq0$, step [](#s1-6){.pf-ref} gives
$$
g_{5/3}'(x)
=
\frac53x^{2/3}\sin(1/x)
-
x^{-1/3}\cos(1/x).
$$
Let
$$
x_k=\frac1{2\pi k}.
$$
Then $x_k\in(0,1]$ for large $k$,
$$
\sin(1/x_k)=0,
\qquad
\cos(1/x_k)=1,
$$
and therefore
$$
g_{5/3}'(x_k)
=
-x_k^{-1/3}
=
-(2\pi k)^{1/3}
\longrightarrow-\infty.
$$
Hence $g_{5/3}'$ is unbounded on $[0,1]$.

:::

:::

::: {.pf-step #s1-9}

Part (b)(i) follows.


::: pf-proof

Step [](#s1-8){.pf-ref} gives the required exponent.

:::

::: {.pf-step #s1-10}

Take $a=3$. Then $g_3$ is differentiable on $\RR$ and $g_3'$ is
continuous on $\RR$.


::: pf-proof

Step [](#s1-7){.pf-ref} gives
$$
g_3'(0)=0.
$$
For $x\neq0$, step [](#s1-6){.pf-ref} gives
$$
g_3'(x)
=
3x^2\sin(1/x)
-
x\cos(1/x).
$$
As $x\to0$,
$$
|3x^2\sin(1/x)-x\cos(1/x)|
\leq
3x^2+|x|
\longrightarrow0.
$$
Thus $g_3'$ is continuous at $0$, and it is continuous away from $0$ by its
formula.

:::

:::

::: {.pf-step #s1-11}

The derivative $g_3'$ is not differentiable at $0$.


::: pf-proof

Since $g_3'(0)=0$,
$$
\frac{g_3'(h)-g_3'(0)}h
=
3h\sin(1/h)-\cos(1/h).
$$
Along
$$
h_k=\frac1{2\pi k},
$$
this expression equals $-1$. Along
$$
\ell_k=\frac1{(2k+1)\pi},
$$
it equals $1$. Hence the limit as $h\to0$ does not exist.

:::

:::

::: {.pf-step #s1-12}

Part (b)(ii) follows.


::: pf-proof

Steps [](#s1-10){.pf-ref} through [](#s1-11){.pf-ref} show that $a=3$ has exactly the required properties.

:::

:::

::: {.pf-step #s1-13}

Take $a=4$. Then both $g_4$ and $g_4'$ are differentiable on $\RR$,
and
$$
g_4''(0)=0.
$$


::: pf-proof

Since $4>1$, step [](#s1-7){.pf-ref} gives differentiability of $g_4$ at $0$. For
$x\neq0$,
$$
g_4'(x)
=
4x^3\sin(1/x)
-
x^2\cos(1/x),
$$
while $g_4'(0)=0$.

Therefore
$$
\frac{g_4'(h)-g_4'(0)}h
=
4h^2\sin(1/h)-h\cos(1/h).
$$
Its absolute value is at most
$$
4h^2+|h|,
$$
which tends to $0$. Hence $g_4'$ is differentiable at $0$ and
$$
g_4''(0)=0.
$$
Away from $0$, both differentiabilities follow from the ordinary product and
chain rules.

:::

:::

::: {.pf-step #s1-14}

For $x\neq0$,
$$
g_4''(x)
=
12x^2\sin(1/x)
-
6x\cos(1/x)
-
\sin(1/x).
$$


::: pf-proof

Differentiate
$$
g_4'(x)
=
4x^3\sin(1/x)-x^2\cos(1/x).
$$
The derivative of the first term is
$$
12x^2\sin(1/x)-4x\cos(1/x),
$$
and the derivative of the second is
$$
-2x\cos(1/x)-\sin(1/x).
$$
Adding gives the displayed formula.

:::

:::

::: {.pf-step #s1-15}

The second derivative $g_4''$ is not continuous at $0$.


::: pf-proof

Let
$$
x_k=\frac1{\pi/2+2\pi k}.
$$
Then
$$
\sin(1/x_k)=1,
\qquad
\cos(1/x_k)=0,
$$
so by step [](#s1-14){.pf-ref},
$$
g_4''(x_k)
=
12x_k^2-1
\longrightarrow-1.
$$
But step [](#s1-13){.pf-ref} gives
$$
g_4''(0)=0.
$$
Therefore $g_4''(x)$ does not tend to $g_4''(0)$ as $x\to0$.

:::

:::

::: {.pf-step #s1-16}

Part (b)(iii) follows.


::: pf-proof

Steps [](#s1-13){.pf-ref} through [](#s1-15){.pf-ref} show that $a=4$ has exactly the required properties.

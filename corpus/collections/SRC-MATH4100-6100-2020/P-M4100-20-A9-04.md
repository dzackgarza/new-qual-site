::: {.problem}
(a) Show that $f ( x ) = \sum _ { n = 1 } ^ { \infty } { \frac { \cos ( 2 ^ { n } x ) } { 2 ^ { n } } }$ is continuous on all of R.

(b) Show that $g ( x ) = \sum _ { n = 1 } ^ { \infty } { \frac { x ^ { n } } { n ^ { 2 } } }$ is continuous on $[ - 1 , 1 ]$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For every $x\in\RR$ and every $n\geq1$,
$$
\abs{
\frac{\cos(2^n x)}{2^n}
}
\leq
\frac1{2^n}.
$$


::: pf-proof

The cosine function satisfies
$$
\abs{\cos t}\leq1
$$
for every real $t$.

:::

:::

::: {.pf-step #s1-2}

The series
$$
\sum_{n=1}^{\infty}
\frac{\cos(2^n x)}{2^n}
$$
converges uniformly on $\RR$.


::: pf-proof

By step [](#s1-1){.pf-ref}, the $n$th term is bounded uniformly in $x$ by $2^{-n}$.
The geometric series
$$
\sum_{n=1}^{\infty}2^{-n}
$$
converges. The Weierstrass $M$-test therefore gives uniform convergence on
$\RR$.

:::

:::

::: {.pf-step #s1-3}

The function
$$
f(x)=
\sum_{n=1}^{\infty}
\frac{\cos(2^n x)}{2^n}
$$
is continuous on $\RR$.


::: pf-proof

Each partial sum is a finite sum of continuous functions and is therefore
continuous. By step [](#s1-2){.pf-ref}, the partial sums converge uniformly to $f$.
The uniform limit of continuous functions is continuous.

:::

:::

::: {.pf-step #s1-4}

Part (a) follows.


::: pf-proof

This is step [](#s1-3){.pf-ref}.

:::

:::

::: {.pf-step #s1-5}

For every $x\in[-1,1]$ and every $n\geq1$,
$$
\abs{
\frac{x^n}{n^2}
}
\leq
\frac1{n^2}.
$$


::: pf-proof

On $[-1,1]$,
$$
\abs{x}\leq1,
$$
so
$$
\abs{x}^n\leq1.
$$

:::

:::

::: {.pf-step #s1-6}

The series
$$
\sum_{n=1}^{\infty}
\frac{x^n}{n^2}
$$
converges uniformly on $[-1,1]$.


::: pf-proof

By step [](#s1-5){.pf-ref}, the $n$th term is bounded uniformly by $1/n^2$.
The $p$-series
$$
\sum_{n=1}^{\infty}\frac1{n^2}
$$
converges. The Weierstrass $M$-test gives uniform convergence.

:::

:::

::: {.pf-step #s1-7}

The function
$$
g(x)=
\sum_{n=1}^{\infty}
\frac{x^n}{n^2}
$$
is continuous on $[-1,1]$.


::: pf-proof

Each partial sum is a polynomial, hence continuous. Step [](#s1-6){.pf-ref} gives uniform
convergence to $g$. Therefore $g$ is continuous as a uniform limit of
continuous functions.

:::

:::

::: {.pf-step #s1-8}

Part (b) follows.


::: pf-proof

This is step [](#s1-7){.pf-ref}.

:::

:::

::: pf-qed

Steps [](#s1-4){.pf-ref} and [](#s1-8){.pf-ref} establish parts (a) and (b), respectively.

:::

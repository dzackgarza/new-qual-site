::: {.problem}
(a) If A is a non-empty subset of R, we define the distance from $x \in \RR$ to A by

$$
\rho _ { A } ( x ) = \operatorname* { i n f } _ { y \in A } \abs{ x - y } .
$$

i. Prove that $\rho _ { A } ( x ) = 0$ if and only if $x \in { \overline { { A } } }$

ii.
Prove that $\rho _ { A }$ is uniformly continuous on R, by showing that

$$
\abs{ \rho _ { A } ( x ) - \rho _ { A } ( y ) } \leq \abs{ x - y }
$$

for all $x , y \in \RR .$

(b) Let A and B be disjoint non-empty closed subsets of R, and define

$$
f ( x ) : = \frac { \rho _ { A } ( x ) } { \rho _ { A } ( x ) + \rho _ { B } ( x ) }
$$

for each $x \in \RR$ . Show that f is a continuous function from R into [0, 1] such that $f ( x ) = 0$ for all $x \in A$, and $f ( x ) = 1$ for all $x \in B$

Note that this in particular establishes a converse to Q1b: Every closed set in R is $Z ( f )$ for some continuous function $f : \RR \to \RR$ . It also gives a proof (but bot the easiest one) that R cannot be written as a disjoint union of two non-empty closed subsets.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

If $x\in\overline A$, then
$$
\rho_A(x)=0.
$$


::: pf-proof

Let $\varepsilon>0$. Since $x\in\overline A$, every neighborhood of $x$
meets $A$. Hence there exists $y\in A$ such that
$$
\abs{x-y}<\varepsilon.
$$
By definition of infimum,
$$
0\leq\rho_A(x)\leq\abs{x-y}<\varepsilon.
$$
Since this holds for every $\varepsilon>0$, one has $\rho_A(x)=0$.

:::

:::

::: {.pf-step #s1-2}

If
$$
\rho_A(x)=0,
$$
then $x\in\overline A$.


::: pf-proof

Let $\varepsilon>0$. Since
$$
\inf_{y\in A}\abs{x-y}=0,
$$
there exists $y\in A$ such that
$$
\abs{x-y}<\varepsilon.
$$
Thus every open interval centered at $x$ meets $A$, which means
$$
x\in\overline A.
$$

:::

:::

::: {.pf-step #s1-3}

Therefore
$$
\boxed{
\rho_A(x)=0
\iff
x\in\overline A.
}
$$


::: pf-proof

Steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref} prove the two implications.

:::

:::

::: {.pf-step #s1-4}

For every $x,y\in\RR$,
$$
\rho_A(x)
\leq
\abs{x-y}+\rho_A(y).
$$


::: pf-proof

For every $z\in A$, the triangle inequality gives
$$
\abs{x-z}
\leq
\abs{x-y}+\abs{y-z}.
$$
Taking the infimum over $z\in A$ yields
$$
\inf_{z\in A}\abs{x-z}
\leq
\abs{x-y}
+
\inf_{z\in A}\abs{y-z},
$$
which is the claimed inequality.

:::

:::

::: {.pf-step #s1-5}

For every $x,y\in\RR$,
$$
\boxed{
\abs{\rho_A(x)-\rho_A(y)}
\leq
\abs{x-y}.
}
$$


::: pf-proof

Step [](#s1-4){.pf-ref} gives
$$
\rho_A(x)-\rho_A(y)
\leq
\abs{x-y}.
$$
Interchanging $x$ and $y$ gives
$$
\rho_A(y)-\rho_A(x)
\leq
\abs{x-y}.
$$
Together these are equivalent to the absolute-value inequality.

:::

:::

::: {.pf-step #s1-6}

The function $\rho_A$ is uniformly continuous on $\RR$.


::: pf-proof

Let $\varepsilon>0$ and choose
$$
\delta=\varepsilon.
$$
Then step [](#s1-5){.pf-ref} gives
$$
\abs{x-y}<\delta
\implies
\abs{\rho_A(x)-\rho_A(y)}
\leq
\abs{x-y}
<
\varepsilon.
$$
The same $\delta$ works for all $x,y$.

:::

:::

::: {.pf-step #s1-7}

Part (a) follows.


::: pf-proof

Step [](#s1-3){.pf-ref} proves part (a)(i), and steps [](#s1-5){.pf-ref} through [](#s1-6){.pf-ref} prove part (a)(ii).

:::

:::

::: {.pf-step #s1-8}

Suppose $A$ and $B$ are disjoint nonempty closed subsets of $\RR$.
Then for every $x\in\RR$,
$$
\rho_A(x)+\rho_B(x)>0.
$$


::: pf-proof

Since $A$ and $B$ are closed,
$$
\overline A=A,
\qquad
\overline B=B.
$$
If
$$
\rho_A(x)+\rho_B(x)=0,
$$
then both nonnegative terms must vanish. By step [](#s1-3){.pf-ref},
$$
x\in A
\qquad\text{and}\qquad
x\in B,
$$
contradicting $A\cap B=\varnothing$.

:::

:::

::: {.pf-step #s1-9}

The function
$$
f(x)
=
\frac{\rho_A(x)}
{\rho_A(x)+\rho_B(x)}
$$
is continuous on $\RR$.


::: pf-proof

By step [](#s1-6){.pf-ref}, both $\rho_A$ and $\rho_B$ are continuous. Their sum is
continuous and never zero by step [](#s1-8){.pf-ref}. Therefore the quotient is continuous.

:::

:::

::: {.pf-step #s1-10}

For every $x\in\RR$,
$$
0\leq f(x)\leq1.
$$


::: pf-proof

Both distance functions are nonnegative, and the denominator is positive by
step [](#s1-8){.pf-ref}. Hence
$$
0
\leq
\rho_A(x)
\leq
\rho_A(x)+\rho_B(x).
$$
Dividing by the positive denominator gives the claim.

:::

:::

::: {.pf-step #s1-11}

If $x\in A$, then
$$
f(x)=0.
$$


::: pf-proof

Since $A$ is closed and $x\in A$, step [](#s1-3){.pf-ref} gives
$$
\rho_A(x)=0.
$$
Because $A$ and $B$ are disjoint,
$$
x\notin B,
$$
so step [](#s1-3){.pf-ref} gives
$$
\rho_B(x)>0.
$$
Therefore
$$
f(x)=0.
$$

:::

:::

::: {.pf-step #s1-12}

If $x\in B$, then
$$
f(x)=1.
$$


::: pf-proof

Now
$$
\rho_B(x)=0
$$
and, because $x\notin A$,
$$
\rho_A(x)>0.
$$
Hence
$$
f(x)
=
\frac{\rho_A(x)}{\rho_A(x)}
=1.
$$

:::

:::

::: {.pf-step #s1-13}

Thus
$$
\boxed{
f:\RR\to[0,1]
}
$$
is continuous, equals $0$ on $A$, and equals $1$ on $B$.


::: pf-proof

Step [](#s1-9){.pf-ref} gives continuity, step [](#s1-10){.pf-ref} gives the stated codomain, and
steps [](#s1-11){.pf-ref} through [](#s1-12){.pf-ref} give the prescribed values.

:::

:::

::: {.pf-step #s1-14}

Part (b) follows.


::: pf-proof

This is step [](#s1-13){.pf-ref}.

:::

::: {.problem}
Construct a compact set of real numbers whose set of limit points is countable.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Define
$$
K=
\{0\}
\cup
\left\{\frac1n:n\in\NN\right\}
\cup
\left\{
\frac1n+\frac{1}{n^2m}:n,m\in\NN
\right\}.
$$
Then $K$ is bounded.


::: pf-proof

Every element of $K$ is nonnegative. Moreover,
$$
\frac1n+\frac{1}{n^2m}
\leq
1+1=2,
$$
so
$$
K\subseteq[0,2].
$$

:::

:::

::: {.pf-step #s1-2}

For every fixed $n\in\NN$, the point $1/n$ is a limit point of $K$.


::: pf-proof

For fixed $n$, the points
$$
x_m=
\frac1n+\frac{1}{n^2m}
$$
belong to $K$, are distinct from $1/n$, and satisfy
$$
x_m\longrightarrow\frac1n.
$$
Hence $1/n$ is a limit point.

:::

:::

::: {.pf-step #s1-3}

The point $0$ is a limit point of $K$.


::: pf-proof

The points $1/n$ belong to $K$ and satisfy
$$
\frac1n\longrightarrow0.
$$

:::

:::

::: {.pf-step #s1-4}

Every convergent sequence of distinct points of $K$ has limit in
$$
L=
\{0\}
\cup
\left\{\frac1n:n\in\NN\right\}.
$$


::: pf-proof

Let $(y_j)$ be a convergent sequence of distinct points of $K$.
Each nonzero $y_j$ is either $1/n_j$ or has the form
$$
y_j=
\frac1{n_j}+\frac{1}{n_j^2m_j}
$$
for positive integers $n_j,m_j$.

If the integers $n_j$ are unbounded, pass to a subsequence with
$n_j\to\infty$. Along that subsequence,
$$
0<y_j
\leq
\frac1{n_j}+\frac1{n_j^2}
\longrightarrow0,
$$
so the limit is $0$.

If the integers $n_j$ are bounded, pass to a subsequence for which
$$
n_j=n
$$
is constant. Since the points $y_j$ are distinct, only one of them can equal
$1/n$, so after discarding at most one term they have the form
$$
y_j=
\frac1n+\frac{1}{n^2m_j}
$$
with distinct $m_j$. Hence $m_j\to\infty$ along a further subsequence, and
therefore
$$
y_j\longrightarrow\frac1n.
$$
Thus every possible limit lies in $L$.

:::

:::

::: {.pf-step #s1-5}

The set of limit points of $K$ is exactly
$$
\boxed{
K'
=
\{0\}
\cup
\left\{\frac1n:n\in\NN\right\}.
}
$$


::: pf-proof

Steps [](#s1-2){.pf-ref} and [](#s1-3){.pf-ref} show that every point of the displayed set is a limit
point. Step [](#s1-4){.pf-ref} excludes all other limit points.

:::

:::

::: {.pf-step #s1-6}

The set $K$ is closed.


::: pf-proof

Every limit point of $K$ belongs to $K$ by step [](#s1-5){.pf-ref}. Hence $K$ contains all
of its limit points and is closed.

:::

:::

::: {.pf-step #s1-7}

The set $K$ is compact.


::: pf-proof

By steps [](#s1-1){.pf-ref} and [](#s1-6){.pf-ref}, $K$ is bounded and closed. The Heine--Borel theorem
therefore implies that $K$ is compact.

:::

:::

::: {.pf-step #s1-8}

The set of limit points of $K$ is countable.


::: pf-proof

By step [](#s1-5){.pf-ref}, it is
$$
\{0\}\cup\{1/n:n\in\NN\},
$$
which is countable.

:::

:::

::: pf-qed

Steps [](#s1-7){.pf-ref} and [](#s1-8){.pf-ref} show that the constructed set is compact and has a
countable set of limit points.

:::

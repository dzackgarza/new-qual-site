::: {.problem}
Compute
\[
\int_0^{2\pi}\frac{\sin^2\theta}{a+b\cos\theta}\,d\theta,
\qquad a,b\in\RR,\quad |a|>|b|>0.
\]
:::

::: {.solution}

Set
\[
\Delta=\sqrt{a^2-b^2}>0.
\]

::: pf

::: {.pf-step #s1-1}

One has the algebraic identity
\[
\boxed{
\frac{\sin^2\theta}{a+b\cos\theta}
=
-\frac{\cos\theta}{b}
+
\frac{a}{b^2}
+
\frac{b^2-a^2}{b^2}
\frac1{a+b\cos\theta}}.
\]


::: pf-proof

Let
\[
x=\cos\theta.
\]
Then
\[
\sin^2\theta=1-x^2.
\]
Direct expansion gives
\[
\left(
-\frac{x}{b}
+
\frac{a}{b^2}
\right)(a+bx)
+
\frac{b^2-a^2}{b^2}
=
1-x^2.
\]
Divide by $a+bx$, which never vanishes because $|a|>|b|$.

:::

:::

::: pf-step

Define
\[
J(a,b)
=
\int_0^{2\pi}
\frac{d\theta}{a+b\cos\theta}.
\]
Under
\[
z=e^{i\theta},
\]
one has
\[
\boxed{
J(a,b)
=
\frac2i
\oint_{|z|=1}
\frac{dz}{bz^2+2az+b}}.
\]


::: pf-proof

Use
\[
\cos\theta
=
\frac12\left(z+\frac1z\right),
\qquad
d\theta
=
\frac{dz}{iz}.
\]
Then
\[
a+b\cos\theta
=
\frac{bz^2+2az+b}{2z},
\]
which yields the displayed contour integral.

:::

:::

::: pf-step

The roots of
\[
bz^2+2az+b
\]
are
\[
z_\pm
=
\frac{-a\pm\Delta}{b},
\]
and
\[
z_+z_-=1.
\]
Exactly one root lies inside the unit circle.


::: pf-proof

The quadratic formula gives the roots, and their product is the constant
term divided by the leading coefficient:
\[
z_+z_-=1.
\]
No root lies on $|z|=1$: if $z=e^{i\theta}$ were a root, then
\[
0
=
bz^2+2az+b
=
2z(a+b\cos\theta),
\]
contradicting $|a|>|b|$. Since their product has modulus $1$, precisely one
root has modulus less than $1$.

:::

:::

::: {.pf-step #s1-4}

The root inside $|z|<1$ is
\[
z_{\mathrm{in}}
=
\frac{-a+\operatorname{sgn}(a)\Delta}{b}.
\]


::: pf-proof

If $a>0$, then
\[
|-a+\Delta|
=
a-\Delta
=
\frac{b^2}{a+\Delta}
<
|b|,
\]
because $a+\Delta>|b|$. Thus
\[
\left|\frac{-a+\Delta}{b}\right|<1.
\]

If $a<0$, write $A=-a>0$. Then
\[
|-a-\Delta|
=
A-\Delta
=
\frac{b^2}{A+\Delta}
<
|b|,
\]
so the inside root is
\[
\frac{-a-\Delta}{b}.
\]
These two cases are exactly the displayed formula.

:::

:::

::: {.pf-step #s1-5}

The residue of
\[
\frac1{bz^2+2az+b}
\]
at $z_{\mathrm{in}}$ is
\[
\frac1{2\operatorname{sgn}(a)\Delta}.
\]


::: pf-proof

For a simple root $z_{\mathrm{in}}$, the residue is
\[
\frac1{2bz_{\mathrm{in}}+2a}.
\]
By step [](#s1-4){.pf-ref},
\[
bz_{\mathrm{in}}+a
=
\operatorname{sgn}(a)\Delta.
\]
Hence the denominator is
\[
2\operatorname{sgn}(a)\Delta.
\]

:::

:::

::: {.pf-step #s1-6}

Therefore
\[
\boxed{
J(a,b)
=
\frac{2\pi\,\operatorname{sgn}(a)}{\sqrt{a^2-b^2}}}.
\]


::: pf-proof

By the residue theorem and step [](#s1-5){.pf-ref},
\[
\begin{aligned}
J(a,b)
&=
\frac2i
\left(
2\pi i
\frac1{2\operatorname{sgn}(a)\Delta}
\right)\\
&=
\frac{2\pi}{\operatorname{sgn}(a)\Delta}\\
&=
\frac{2\pi\,\operatorname{sgn}(a)}{\Delta},
\end{aligned}
\]
since
\[
\operatorname{sgn}(a)^{-1}
=
\operatorname{sgn}(a).
\]

:::

:::

::: {.pf-step #s1-7}

The required integral is
\[
\boxed{
\int_0^{2\pi}
\frac{\sin^2\theta}{a+b\cos\theta}\,d\theta
=
\frac{2\pi}{b^2}
\left(
a-\operatorname{sgn}(a)\sqrt{a^2-b^2}
\right)}.
\]


::: pf-proof

Integrate the identity in step [](#s1-1){.pf-ref}. Since
\[
\int_0^{2\pi}\cos\theta\,d\theta=0,
\]
steps [](#s1-1){.pf-ref} and [](#s1-6){.pf-ref} give
\[
\begin{aligned}
I
&=
\frac{2\pi a}{b^2}
+
\frac{b^2-a^2}{b^2}
\frac{2\pi\operatorname{sgn}(a)}{\Delta}\\
&=
\frac{2\pi}{b^2}
\left(
a
-
\operatorname{sgn}(a)\Delta
\right),
\end{aligned}
\]
because
\[
b^2-a^2=-\Delta^2.
\]

:::

:::

::: pf-qed

Step [](#s1-7){.pf-ref} is the requested value.

:::

::: {.problem}
Assume that $f(z)$ is an entire function that is $2\pi$-periodic in the sense that $f(z + 2\pi) = f(z)$, and
\[
|f(x+iy)| \leq C e^{\alpha|y|},
\]
for some $C > 0$, where $0 < \alpha < 1$. Prove that $f$ is constant.
:::

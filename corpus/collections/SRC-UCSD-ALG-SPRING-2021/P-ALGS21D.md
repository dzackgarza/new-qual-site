::: problem
Let $K$ be a field with $|K| = 64$.
Let $\mathbb{F}_2$ be the prime subfield of $K$.
Let $G = \operatorname{Gal}(K/\mathbb{F}_2)$ act in the natural way on $K$, where for $\sigma \in G$ and $a \in K$ we have $\sigma \cdot a = \sigma(a)$.

(a) Describe the orbits of this action and calculate how many distinct orbits there are of each size.

(b) Calculate the number of $\alpha \in K$ such that $K = \mathbb{F}_2(\alpha)$.

(c) Calculate the number of $\beta \in K$ such that $\beta$ generates the group $K^\times$.
:::


::: {.solution}
<1>1. The field \(K\) is \(\mathbb F_{2^6}\), and
\[
G=\operatorname{Gal}(K/\mathbb F_2)=\langle\sigma\rangle\cong C_6,
\qquad \sigma(x)=x^2.
\]
::: {.proof}
A finite field of order \(64=2^6\) is unique up to isomorphism. Its Galois group over \(\mathbb F_2\) is cyclic of order \(6\), generated by Frobenius.
:::

<1>2. The possible orbit sizes are \(1,2,3,6\). The elements whose orbit size divides \(d\mid6\) are exactly the elements of \(\mathbb F_{2^d}\).
::: {.proof}
The orbit size of \(a\) is the least positive \(d\) with \(\sigma^d(a)=a\), equivalently \(a^{2^d}=a\). Inside \(\mathbb F_{2^6}\), the solutions are exactly the subfield \(\mathbb F_{2^d}\) when \(d\mid6\).
:::

<1>3. There are \(2\) elements of orbit size \(1\), \(2\) of orbit size \(2\), \(6\) of orbit size \(3\), and \(54\) of orbit size \(6\).
::: {.proof}
Orbit size \(1\): \(|\mathbb F_2|=2\).

Orbit size exactly \(2\): \(|\mathbb F_4|-|\mathbb F_2|=4-2=2\).

Orbit size exactly \(3\): \(|\mathbb F_8|-|\mathbb F_2|=8-2=6\), since the only proper subfield of \(\mathbb F_8\) is \(\mathbb F_2\).

The remaining
\[
64-2-2-6=54
\]
elements have orbit size \(6\).
:::

<1>4. Thus there are exactly \(2\) orbits of size \(1\), \(1\) orbit of size \(2\), \(2\) orbits of size \(3\), and \(9\) orbits of size \(6\).
::: {.proof}
Divide each exact element count in <1>3 by the corresponding orbit size.
:::

<1>5. Exactly \(54\) elements \(\alpha\in K\) satisfy \(K=\mathbb F_2(\alpha)\).
::: {.proof}
The degree \([\mathbb F_2(\alpha):\mathbb F_2]\) equals the Frobenius orbit size of \(\alpha\). Thus \(\alpha\) generates \(K\) exactly when its orbit has size \(6\). By <1>3 there are \(54\) such elements.
:::

<1>6. Exactly \(36\) elements generate \(K^\times\).
::: {.proof}
The multiplicative group of a finite field is cyclic, so \(K^\times\cong C_{63}\). A cyclic group of order \(63\) has \(\varphi(63)\) generators, and
\[
\varphi(63)=63\left(1-\frac13\right)\left(1-\frac17\right)=36.
\]
Hence there are \(36\) multiplicative generators.
:::
:::

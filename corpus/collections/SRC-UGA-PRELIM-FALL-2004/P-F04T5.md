::: {.problem}
Let $T: V \to W$ be an injective linear transformation and suppose $v_1, \dots, v_n$ are linearly independent vectors in $V$.
Prove that the vectors $T(v_1), \dots, T(v_n)$ are linearly independent in $W$.
:::

::: {.solution}
The collection's provenance is the examination paper alone, so no retained solution set covers this exercise; the argument is the card's own.

::: pf

::: {.pf-step}
Every choice of scalars $a_1,\ldots,a_n$ with $a_1T(v_1)+\cdots+a_nT(v_n)=0$ has $a_1=\cdots=a_n=0$.

::: pf-proof

::: {.pf-step #linearity}
$a_1T(v_1)+\cdots+a_nT(v_n)=T(a_1v_1+\cdots+a_nv_n)$.

::: pf-proof
$T$ is linear, so it carries a linear combination of the $v_i$ to the same linear combination of the $T(v_i)$.
:::

:::

::: {.pf-step #kernel}
If $T(a_1v_1+\cdots+a_nv_n)=0$ then $a_1v_1+\cdots+a_nv_n=0$.

::: pf-proof
An injective linear map has trivial kernel: $T(0)=0$ by linearity, so injectivity gives $Tu=0\Rightarrow u=0$; apply this to $u=a_1v_1+\cdots+a_nv_n$.
:::

:::

::: {.pf-step #independent}
$a_1=\cdots=a_n=0$.

::: pf-proof
By steps [](#linearity){.pf-ref} and [](#kernel){.pf-ref} the vanishing combination of the $T(v_i)$ forces $a_1v_1+\cdots+a_nv_n=0$, and the $v_i$ are linearly independent, which is exactly the assertion that this last equation has only the trivial solution.
:::

:::

:::

:::

::: {.pf-step}
$T(v_1),\ldots,T(v_n)$ are linearly independent in $W$.

::: pf-proof
That is the statement of the preceding step, read through the definition of linear independence: the only combination of the $T(v_i)$ that vanishes is the trivial one.
:::

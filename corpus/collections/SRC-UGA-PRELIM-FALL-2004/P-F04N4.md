::: {.problem}
Prove that there is no $n \in \NN$ so that $(21n - 3)/4$ and $(15n + 2)/4$ are both integers.
:::

::: {.solution}
The argument is the card's own; the collection is a preliminary examination, so the problem statement is the source.

::: pf

::: {.pf-step #first}
If $\dfrac{21n-3}{4}$ is an integer then $n\equiv3\pmod 4$.

::: pf-proof
$4\mid21n-3$, and $21\equiv1\pmod4$, so $21n-3\equiv n-3\pmod4$; hence $n\equiv3\pmod4$.
:::

:::

::: {.pf-step #second}
If $\dfrac{15n+2}{4}$ is an integer then $n\equiv2\pmod 4$.

::: pf-proof
$4\mid15n+2$, and $15\equiv-1\pmod4$, so $15n+2\equiv-n+2\pmod4$; hence $n\equiv2\pmod4$.
:::

:::

::: {.pf-step #contradiction}
No integer satisfies both congruences.

::: pf-proof
$n\equiv3$ and $n\equiv2$ modulo $4$ are incompatible: congruence modulo $4$ is an equivalence relation, so two integers congruent to $n$ are congruent to each other, and $3\not\equiv2\pmod4$.
:::

:::

::: {.pf-step}
There is no $n\in\NN$ making both numbers integers.

::: pf-proof
Steps [](#first){.pf-ref}, [](#second){.pf-ref} and [](#contradiction){.pf-ref} give
$$
\boxed{\nexists\,n\in\NN:\ 4\mid(21n-3)\text{ and }4\mid(15n+2).}
$$
:::

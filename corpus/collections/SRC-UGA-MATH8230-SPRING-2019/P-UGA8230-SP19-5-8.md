::: {.problem}
Let
\[
D^*=\{z\in\mathbb C:0<|z|<1\}
\]
with the standard symplectic structure $dp\wedge dq$, where $z=p+iq$. Using
\[
dp\wedge dq=d\!\left(\frac12 r^2\right)\wedge d\theta,
\]
give an explicit symplectomorphism $\phi:D^*\to D^*$ that turns $D^*$ inside out: if $z_n\to0$ in $D^*$, then $|\phi(z_n)|\to1$.
:::

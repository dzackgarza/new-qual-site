::: {.problem}
Let $R$ be a commutative algebra over $\CC$.
A derivation of $R$ is a $\CC$-linear map $D:R\rightarrow R$ such that (i) $D(1)=0$ and (ii) $D(ab)=D(a)b+aD(b)$ for all $a,b\in R$.

(a) Describe all derivations of the polynomial ring $\CC[x]$.

(b) Let $A$ be the subring (or $\CC$-subalgebra) of $\operatorname{End}_{\CC}(\CC[x])$ generated by all derivations of $\CC[x]$ and the left multiplications by $x$.
Prove that $\CC[x]$ is a simple left $A$-module.
Note that the inclusion $A\rightarrow\operatorname{End}_{\CC}(\CC[x])$ defines a natural left $A$-module structure on $\CC[x]$.
:::

::: {.solution}
**Goal.** Describe all derivations of $\CC[x]$, and show $\CC[x]$ is a simple left $A$-module.

::: pf

::: {.pf-step #s1}
All derivations of $\CC[x]$.

::: pf-proof

::: {.pf-step #s1-1}
A derivation $D$ is determined by $D(x)$.

::: pf-proof
$D(1) = 0$ and the Leibniz rule give $D(x^n) = n x^{n-1} D(x)$ by induction, so $D$ is determined by its value on the generator $x$.
:::

:::

::: {.pf-step #s1-2}
Conversely, for any $p(x) \in \CC[x]$, the map $D_p(f) = p(x) f'(x)$ is a derivation.

::: pf-proof
$D_p(1) = 0$ and $D_p(fg) = p(f'g + fg') = D_p(f)g + fD_p(g)$.
:::

:::

::: pf-step
Hence the derivations of $\CC[x]$ are exactly $\theset{p(x)\frac{d}{dx} : p \in \CC[x]}$.

::: pf-proof
step [](#s1-1){.pf-ref} and step [](#s1-2){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s2}
$\CC[x]$ is a simple left $A$-module.

::: pf-proof

::: pf-step
$A$ contains the derivation $\frac{d}{dx}$ and the multiplication operator $x$.

::: pf-proof
$\frac{d}{dx}$ is a derivation (with $p = 1$), and $x$ is a left multiplication.
:::

:::

::: pf-step
The operators $x$ and $\frac{d}{dx}$ satisfy $[\frac{d}{dx}, x] = 1$.

::: pf-proof
$\frac{d}{dx}(x f) - x \frac{d}{dx}(f) = f + x f' - x f' = f$, so $[\frac{d}{dx}, x] = \operatorname{id}$.
:::

:::

::: {.pf-step #s2-3}
Every nonzero $A$-submodule $N\subseteq\CC[x]$ contains $1$.

::: pf-proof
Pick $0\ne f\in N$ of degree $n$ with leading coefficient $c\ne0$. Since $\frac{d}{dx}\in A$, the element $\left(\frac{d}{dx}\right)^n f=n!\,c$ lies in $N$ and is a nonzero constant, so $1\in N$.
:::

:::

::: {.pf-step #s2-4}
Every $A$-submodule containing $1$ is all of $\CC[x]$.

::: pf-proof
Left multiplication by $x$ lies in $A$, so $x^k=x^k\cdot1\in N$ for every $k\ge0$; these span $\CC[x]$ over $\CC$.
:::

:::

::: pf-step
Hence $\CC[x]$ is a simple left $A$-module.

::: pf-proof
step [](#s2-3){.pf-ref} and step [](#s2-4){.pf-ref}.
:::

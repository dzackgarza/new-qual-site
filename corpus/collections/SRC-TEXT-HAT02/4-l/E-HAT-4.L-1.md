::: {.problem}
Determine all cohomology operations $H^1(X; \ZZ) \to H^n(X; \ZZ)$, $H^2(X; \ZZ) \to H^n(X; \ZZ)$, and $H^1(X; \ZZ_p) \to H^n(X; \ZZ_p)$ for $p$ prime.
:::

::: {.solution}
No retained solution set covers this exercise, so the argument is the card's own; it applies the representation theorem for cohomology operations to the three Eilenberg--MacLane spaces involved.

::: pf

::: {.pf-step #representable}
Cohomology operations $H^m(-;G)\to H^n(-;H)$ correspond to classes in $H^n(K(G,m);H)$, the operation being evaluation of the class on the fundamental class.

::: pf-proof
This is Hatcher's Proposition 4L.1 (p. 488): a natural transformation between the represented functors $[-,K(G,m)]$ and $[-,K(H,n)]$ is induced by a map $K(G,m)\to K(H,n)$, and such maps correspond to classes in $H^n(K(G,m);H)$ by the universal property of Eilenberg--MacLane spaces. The induced map on cohomology is a homomorphism, so an operation is determined by the image of the fundamental class.
:::

:::

::: {.pf-step #h1z}
Every operation $H^1(-;\ZZ)\to H^n(-;\ZZ)$ is $u\mapsto au$ for $n=1$ and $a\in\ZZ$, is constant for $n=0$, and is zero for $n>1$.

::: pf-proof
$K(\ZZ,1)=S^1$, so the representing group is $H^n(S^1;\ZZ)$, which is $\ZZ$ for $n=0$ and $n=1$ and $0$ for $n>1$. A class in $H^1(S^1;\ZZ)$ is $a$ times the generator, whose evaluation on $u$ is $au$; for $n=0$ the class is constant, and for $n>1$ there is no class.
:::

:::

::: {.pf-step #h2z}
Every operation $H^2(-;\ZZ)\to H^{2j}(-;\ZZ)$ is $u\mapsto au^j$ for $a\in\ZZ$, and there are no nonzero operations into odd degree.

::: pf-proof
$K(\ZZ,2)=\CP^\infty$ with $H^*(\CP^\infty;\ZZ)=\ZZ[x]$, $\abs x=2$, by Example 3.12 (p. 213); so $H^n$ is $\ZZ x^j$ for $n=2j$ and $0$ for $n$ odd. A class $ax^j$ evaluated on the fundamental class $u$ of $\CP^\infty$ gives $au^j$, and there is no class in odd degree.
:::

:::

::: {.pf-step #h1zp-two}
For $p=2$, every operation $H^1(-;\ZZ_2)\to H^n(-;\ZZ_2)$ is $u\mapsto au^n$ with $a\in\ZZ_2$.

::: pf-proof
$K(\ZZ_2,1)$ has $H^*(K(\ZZ_2,1);\ZZ_2)=\ZZ_2[x]$ with $\abs x=1$, the polynomial algebra on the class $x$ in degree one; so $H^n$ is one-dimensional for every $n\ge0$, generated by $x^n$, and evaluation on $u$ gives $au^n$. This is the ring computed from the infinite lens space with $\ZZ_2$ coefficients, where the Bockstein sequence degenerates and $x^2\ne0$.
:::

:::

::: {.pf-step}
For odd $p$, the operations $H^1(-;\ZZ_p)\to H^n(-;\ZZ_p)$ are the scalar multiples of $u\mapsto(\beta u)^j$ in degree $2j$ and of $u\mapsto u(\beta u)^j$ in degree $2j+1$.

::: pf-proof
For odd $p$, $H^*(K(\ZZ_p,1);\ZZ_p)=\Lambda(x)\otimes\ZZ_p[y]$ with $\abs x=1$, $\abs y=2$ and $y=\beta x$ the mod-$p$ Bockstein: additively this is the cohomology of the infinite lens space (Example 2.43, p. 144) and multiplicatively the Bockstein of §3.E (p. 303) gives $y=\beta x$. So $H^{2j}$ is spanned by $y^j$ and $H^{2j+1}$ by $xy^j$, each one-dimensional; evaluating on the fundamental class $u$ gives the two displayed families, and every operation is a $\ZZ_p$-multiple of one of them.
:::

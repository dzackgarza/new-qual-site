::: {.problem}
Show that a direct limit $\varinjlim G_\alpha$ of torsionfree abelian groups $G_\alpha$ is torsionfree.
More generally, show that any finitely generated subgroup of $\varinjlim G_\alpha$ is realized as a subgroup of some $G_\alpha$.
:::

::: {.solution}
The published solution is **Guanyu Li, *Hatcher.pdf*, §3.3 Exercise 8 (Hatcher §3.3 Exercise 18), PDF p. 58** (`tmp/sources/hatcher-solutions-guanyu-li.pdf`), which uses the same passage to a later stage for the generators and for the relations. The statement is Hatcher, *Algebraic Topology* (2002), §3.3 Exercise 18. The relation lattice argument below is the card's own addition, and makes explicit why a finitely generated subgroup is isomorphic to a subgroup of one stage rather than merely checking that one generator keeps its order.

Let $G=\varinjlim G_\alpha$ over the directed index set, and for $\alpha\le\beta$ let $\iota_{\alpha\beta}:G_\alpha\to G_\beta$ and $\iota_\alpha:G_\alpha\to G$ be the structure maps; an element of $G$ is represented by $g_\alpha\in G_\alpha$, and $x=0$ in $G$ exactly when $\iota_{\alpha\beta}(g_\alpha)=0$ for some $\beta\ge\alpha$.

::: pf

::: {.pf-step #torsionfree}
If $x\in G$ and $mx=0$ for a nonzero integer $m$, then $x=0$.

::: pf-proof
Represent $x$ by $g_\alpha\in G_\alpha$. Since $\iota_\alpha(mg_\alpha)=mx=0$, there is $\beta\ge\alpha$ with $\iota_{\alpha\beta}(mg_\alpha)=0$, that is $m\,\iota_{\alpha\beta}(g_\alpha)=0$ in $G_\beta$. The group $G_\beta$ is torsionfree, so $\iota_{\alpha\beta}(g_\alpha)=0$, hence $x=\iota_\beta\bigl(\iota_{\alpha\beta}(g_\alpha)\bigr)=0$.
:::

:::

::: {.pf-step #representation}
Let $H\le G$ be generated by $x_1,\dots,x_r$. There are an index $\alpha$ and $g_1,\dots,g_r\in G_\alpha$ with $\iota_\alpha(g_i)=x_i$, and the homomorphism $\phi:\ZZ^r\to H$, $e_i\mapsto x_i$, has a kernel $K$ that is finitely generated.

::: pf-proof
Finitely many elements are each represented at some stage, and a directed index set has an upper bound for finitely many indices, so one $\alpha$ works for all of them. The map $\phi$ is surjective by the choice of the $x_i$. Its kernel is a subgroup of the finitely generated free abelian group $\ZZ^r$, and every subgroup of a finitely generated free abelian group is free of finite rank, so $K$ has a finite generating set $k_1,\dots,k_s$.
:::

:::

::: {.pf-step #one-stage}
There is an index $\beta\ge\alpha$ at which all the relations $k_1,\dots,k_s$ vanish, and the subgroup $H_\beta\le G_\beta$ generated by the images of $g_1,\dots,g_r$ has relation lattice exactly $K$.

::: pf-proof
For each $j$ the element $\phi(k_j)=0$ of $G$ is represented by $k_j$ read in $G_\alpha$, so there is $\beta_j\ge\alpha$ with $\iota_{\alpha\beta_j}(k_j)=0$ in $G_{\beta_j}$; directedness gives one $\beta$ above all the $\beta_j$, and then all $k_j$ vanish in $G_\beta$. Let $\psi:\ZZ^r\to H_\beta$, $e_i\mapsto\iota_{\alpha\beta}(g_i)$, and let $K_\beta=\ker\psi$. Every relation at stage $\beta$ is a relation in $G$, because $\iota_\beta\circ\iota_{\alpha\beta}=\iota_\alpha$: so $K_\beta\subseteq K$. Conversely each generator $k_j$ of $K$ lies in $K_\beta$ by the choice of $\beta$, so $K\subseteq K_\beta$. Hence $K_\beta=K$.
:::

:::

::: {.pf-step #realized}
$H_\beta\cong H$, so every finitely generated subgroup of $G$ is realized as a subgroup of some $G_\alpha$.

::: pf-proof
$\psi$ is surjective onto $H_\beta$ by definition, so $H_\beta\cong\ZZ^r/K_\beta=\ZZ^r/K\cong H$ by step [](#one-stage){.pf-ref} and step [](#representation){.pf-ref}. Thus the finitely generated subgroup $H$ of the direct limit is isomorphic to the subgroup $H_\beta$ of the single group $G_\beta$, which is the general assertion of the exercise; the torsion statement is step [](#torsionfree){.pf-ref}.
:::

::: {.problem}
Give an example of a weak homotopy equivalence $X \to Y$ for which there does not exist a weak homotopy equivalence $Y \to X$.
:::

::: {.solution}
Let $P = \{a, b, c, d\}$ be the pseudocircle, with open sets generated by $\{a\}$, $\{b\}$, $\{a, b, c\}$ and $\{a, b, d\}$.

::: pf

::: {.pf-step #s1}

There is a weak homotopy equivalence $f: S^1 \to P$.

::: pf-proof

::: pf-step

The order complex of $P$ (with $a, b < c, d$) is a square, so its realization is $S^1$.

::: pf-proof

Its simplices are the chains of $P$: four vertices and the four edges $ac$, $ad$, $bc$, $bd$, which form one cycle.

:::

:::

::: pf-step

McCord's map from the realization of the order complex to $P$ is a weak homotopy equivalence.

::: pf-proof

This is McCord's theorem (1966): for a finite $T_0$ space, this map is a weak homotopy equivalence.

:::

:::

:::

:::

::: {.pf-step #s2}

There is no weak homotopy equivalence $P \to S^1$.

::: pf-proof

::: pf-step

Every continuous map $g: P \to S^1$ is null-homotopic.

::: pf-proof

The image $g(P)$ is a finite subspace of the Hausdorff space $S^1$, so it is discrete. $P$ is path-connected (it is weakly equivalent to $S^1$), so $g(P)$ is connected, hence one point. So $g$ is constant.

:::

:::

::: pf-step

Hence $g$ cannot induce an isomorphism on $\pi_1$.

::: pf-proof

$g_*: \pi_1(P) \cong \ZZ \to \pi_1(S^1) \cong \ZZ$ is the zero map (a null-homotopic map induces the trivial map on homotopy groups), not an isomorphism.

:::

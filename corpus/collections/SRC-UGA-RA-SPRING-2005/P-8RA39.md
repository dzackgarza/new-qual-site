::: problem
If $0 < p \leq 1$, prove that $\frac{\sin x}{x^{p}}$ is not integrable on $(0,\infty)$, but
\[
\int_{0}^{\infty}\frac{\sin x}{x^{p}}\, dx = \lim_{r \rightarrow \infty}\int_{0}^{r}\frac{\sin x}{x^{p}}\, dx
\]
exists.
:::

::: {.solution}
<1>1. Show that $\frac{\sin x}{x^p} \notin L^1(0, \infty)$ for $0 < p \le 1$:
<2>1. Partition $(0, \infty)$ into intervals $[k\pi, (k+1)\pi]$ for $k \ge 1$.
::: {.proof}
partition of the real line.
:::
<2>2. On $[k\pi, (k+1)\pi]$, $|\sin x| = \sin(x - k\pi)$ and $x \le (k+1)\pi$. Thus:
\[
\int_{k\pi}^{(k+1)\pi} \frac{|\sin x|}{x^p}\,dx \ge \frac{1}{((k+1)\pi)^p} \int_{k\pi}^{(k+1)\pi} |\sin x|\,dx = \frac{1}{\pi^p (k+1)^p} \int_0^\pi \sin t\,dt = \frac{2}{\pi^p (k+1)^p}.
\]
::: {.proof}
substitution $t = x - k\pi$ and monotonicity of $x \mapsto x^{-p}$.
:::
<2>3. Summing over $k=1, \dots, N$:
\[
\int_\pi^{(N+1)\pi} \frac{|\sin x|}{x^p}\,dx = \sum_{k=1}^N \int_{k\pi}^{(k+1)\pi} \frac{|\sin x|}{x^p}\,dx \ge \frac{2}{\pi^p} \sum_{k=1}^N \frac{1}{(k+1)^p}.
\]
::: {.proof}
additivity of integration on disjoint intervals.
:::
<2>4. Since $0 < p \le 1$, the $p$-series $\sum_{k=1}^\infty \frac{1}{(k+1)^p}$ diverges by comparison with the harmonic series $\sum \frac{1}{k}$.
::: {.proof}
divergence of $p$-series for $p \le 1$.
:::
<2>5. Thus $\int_0^\infty \frac{|\sin x|}{x^p}\,dx = \infty$, so $\frac{\sin x}{x^p}$ is not Lebesgue integrable on $(0, \infty)$.
::: {.proof}
monotone convergence theorem / limit as $N \to \infty$.
:::

<1>2. Existence of the improper Riemann integral:
<2>1. Split the integral at $x = 1$: $\int_0^r \frac{\sin x}{x^p}\,dx = \int_0^1 \frac{\sin x}{x^p}\,dx + \int_1^r \frac{\sin x}{x^p}\,dx$.
::: {.proof}
additivity of integral.
:::
<2>2. Near $x = 0$: using $|\sin x| \le x$, we have $\left|\frac{\sin x}{x^p}\right| \le x^{1-p}$ on $(0, 1]$.
Since $p \le 1$, $1 - p \ge 0$, so $x^{1-p}$ is bounded and continuous on $[0, 1]$.
Thus $\int_0^1 \frac{\sin x}{x^p}\,dx$ converges absolutely.
::: {.proof}
$|\sin x| \le x$ for $x \ge 0$.
:::
<2>3. For $r > 1$, apply integration by parts to $\int_1^r \frac{\sin x}{x^p}\,dx$ with $u = x^{-p}$ and $dv = \sin x\,dx$ (so $du = -p x^{-p-1}\,dx$ and $v = -\cos x$):
\[
\int_1^r \frac{\sin x}{x^p}\,dx = \left[ -\frac{\cos x}{x^p} \right]_1^r - p \int_1^r \frac{\cos x}{x^{p+1}}\,dx = \cos 1 - \frac{\cos r}{r^p} - p \int_1^r \frac{\cos x}{x^{p+1}}\,dx.
\]
::: {.proof}
integration by parts formula.
:::
<2>4. Since $|\cos r| \le 1$ and $p > 0$, $\lim_{r \to \infty} \frac{\cos r}{r^p} = 0$.
::: {.proof}
squeeze theorem.
:::
<2>5. For the integral term, $\left|\frac{\cos x}{x^{p+1}}\right| \le \frac{1}{x^{p+1}}$.
Since $p > 0$, the exponent $p + 1 > 1$, so $\int_1^\infty \frac{1}{x^{p+1}}\,dx = \frac{1}{p} < \infty$.
By the Weierstrass $M$-test / comparison test, $\int_1^\infty \frac{\cos x}{x^{p+1}}\,dx$ converges absolutely.
::: {.proof}
convergence of $p$-integrals for exponent $> 1$.
:::
<2>6. Therefore:
\[
\lim_{r \to \infty} \int_1^r \frac{\sin x}{x^p}\,dx = \cos 1 - p \int_1^\infty \frac{\cos x}{x^{p+1}}\,dx \in \mathbb{R}.
\]
::: {.proof}
sum of limits of convergent terms.
:::
<2>7. Combining with <2>2, $\lim_{r \to \infty} \int_0^r \frac{\sin x}{x^p}\,dx$ exists.
::: {.proof}
<2>2 and <2>6.
:::

<1>3. Conclusion:
$\frac{\sin x}{x^p} \notin L^1(0, \infty)$ but the improper Riemann integral $\int_0^\infty \frac{\sin x}{x^p}\,dx$ converges for all $0 < p \le 1$. Q.E.D.
::: {.proof}
<1>1 and <1>2.
:::

::: problem
The source asks for the following assertion. Suppose $\{f_n:n\ge0\}$ is a sequence of continuous functions on $\mathbb R^m$ such that for every $x\in\mathbb R^m$,
\[
\sum_{n = 1}^{\infty}\left| f_{n}(x) - f_{n - 1}(x) \right| \leq \frac{1}{1 + |x|^{2}}.
\]
Must $f_n$ converge to a continuous function? Justify the answer.
:::

::: solution
The assertion is false.

Define, for $n\ge0$,
\[
f_n(x):=\frac{e^{-n|x|^2}}{1+|x|^2},
\qquad x\in\mathbb R^m.
\]
Each $f_n$ is continuous. For every fixed $x$, the sequence $(f_n(x))_n$ is nonincreasing and nonnegative. Hence
\[
\sum_{n=1}^\infty|f_n(x)-f_{n-1}(x)|
=f_0(x)-\lim_{n\to\infty}f_n(x).
\]

If $x\ne0$, then
\[
f_n(x)\longrightarrow0,
\]
so
\[
\sum_{n=1}^\infty|f_n(x)-f_{n-1}(x)|
=\frac1{1+|x|^2}.
\]
If $x=0$, then $f_n(0)=1$ for every $n$, so the sum is $0$. Therefore the stated bound holds at every point.

However,
\[
f_n(x)\longrightarrow
f(x):=
\begin{cases}
1,&x=0,\\
0,&x\ne0.
\end{cases}
\]
The limit $f$ is discontinuous at the origin.

Thus the telescoping bound guarantees pointwise convergence, because
\[
\sum_n|f_n(x)-f_{n-1}(x)|<\infty
\]
for each fixed $x$, but it does not imply locally uniform convergence or continuity of the pointwise limit. Hence
\[
\boxed{\text{the source assertion is false}.}
\]
:::

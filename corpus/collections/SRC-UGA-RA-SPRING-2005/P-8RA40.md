::: {.problem}
The source asks for the following assertion. Suppose $\{f_n:n\ge0\}$ is a sequence of continuous functions on $\RR^m$ such that for every $x\in\RR^m$,
$$
\sum_{n = 1}^{\infty}\abs{ f_{n}(x) - f_{n - 1}(x) } \leq \frac{1}{1 + \norm{x}^{2}}.
$$
Must $f_n$ converge to a continuous function? Justify the answer.
:::

::: {.solution}
The argument is the card's own; no retained solution set is cited on it, and the counterexample below answers the source's question in the negative.

Define $f_{n}(x)=\dfrac{e^{-n\norm{x}^{2}}}{1+\norm{x}^{2}}$ for $x\in\RR^{m}$ and $n\ge0$, and put $c(x)=1/(1+\norm{x}^{2})$.

::: pf

::: {.pf-step #continuous}
Each $f_{n}$ is continuous on $\RR^{m}$, and for each fixed $x$ the sequence $\big(f_{n}(x)\big)_{n}$ is nonnegative and nonincreasing.

::: pf-proof
$f_{n}$ is a quotient of the continuous functions $e^{-n\norm{x}^{2}}$ and $1+\norm{x}^{2}$, the denominator being positive. For fixed $x$ one has $f_{n}(x)=c(x)\,e^{-n\norm{x}^{2}}$ with $c(x)>0$, and $e^{-n\norm{x}^{2}}$ decreases with $n$, so $f_{n}(x)$ is nonnegative and nonincreasing.
:::

:::

::: {.pf-step #sum}
For each $x$, $\displaystyle\sum_{n=1}^{\infty}\abs{f_{n}(x)-f_{n-1}(x)}=c(x)-\lim_{n\to\infty}f_{n}(x)$.

::: pf-proof
Because the sequence is nonincreasing, $\abs{f_{n}(x)-f_{n-1}(x)}=f_{n-1}(x)-f_{n}(x)$, and the partial sums telescope to $f_{0}(x)-f_{N}(x)$; letting $N\to\infty$ gives the displayed identity, the limit existing since a nonincreasing nonnegative sequence converges.
:::

:::

::: {.pf-step #hypothesis}
The hypothesis of the source's assertion holds for this sequence.

::: pf-proof
If $x\ne0$ then $\norm{x}^{2}>0$, so $e^{-n\norm{x}^{2}}\to0$ and $\lim_{n}f_{n}(x)=0$; by step [](#sum){.pf-ref} the series equals $c(x)=1/(1+\norm{x}^{2})$, which is the bound. If $x=0$ then $f_{n}(0)=1$ for every $n$, so every difference is $0$ and the series is $0\le1$. So the inequality holds at every point of $\RR^{m}$.
:::

:::

::: {.pf-step #limit}
$f_{n}\to f$ pointwise, where $f(0)=1$ and $f(x)=0$ for $x\ne0$.

::: pf-proof
At $x=0$ the value is $f_{n}(0)=1$ for all $n$; at $x\ne0$ one has $f_{n}(x)=c(x)e^{-n\norm{x}^{2}}\to0$.
:::

:::

::: {.pf-step #discontinuous}
$f$ is discontinuous at the origin.

::: pf-proof
$f(0)=1$, while $f(x)=0$ for every $x\ne0$; so in every neighbourhood of $0$ there are points at which $f$ differs from $f(0)$ by $1$. Since $\{1\}$ is not a neighbourhood of $1$ in $\RR$, continuity at $0$ fails.
:::

:::

::: {.pf-step}
The source's assertion is false.

::: pf-proof
Steps [](#continuous){.pf-ref}, [](#hypothesis){.pf-ref} and [](#limit){.pf-ref} exhibit a sequence of continuous functions satisfying the stated bound whose pointwise limit exists and is discontinuous, by step [](#discontinuous){.pf-ref}. What the bound gives at each fixed $x$ is absolute summability of the differences, hence pointwise convergence; it gives neither locally uniform convergence nor continuity of the limit.
:::

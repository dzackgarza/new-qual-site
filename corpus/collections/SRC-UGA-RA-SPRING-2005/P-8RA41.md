::: problem
If $\mu$ is Lebesgue measure on $\mathbb{R}$ and $f \in L(\mathbb{R},d\mu)$, prove that $F$ is absolutely continuous where
\[
F(x) = \int_{(-\infty,x]} f\, d\mu.
\]
:::

::: solution
Let $\varepsilon>0$. Since $f\in L^1(\mathbb R)$, the Lebesgue integral is absolutely continuous: there exists $\delta>0$ such that for every measurable set $E$ with
\[
m(E)<\delta,
\]
we have
\[
\int_E|f|\,dm<\varepsilon.
\]

Now let
\[
(a_1,b_1),\ldots,(a_N,b_N)
\]
be pairwise disjoint intervals satisfying
\[
\sum_{j=1}^N(b_j-a_j)<\delta.
\]
For each $j$,
\[
F(b_j)-F(a_j)=\int_{(a_j,b_j]}f\,dm.
\]
Therefore
\[
\begin{aligned}
\sum_{j=1}^N|F(b_j)-F(a_j)|
&\le\sum_{j=1}^N\int_{(a_j,b_j]}|f|\,dm\\
&=\int_{\bigcup_j(a_j,b_j]}|f|\,dm\\
&<\varepsilon,
\end{aligned}
\]
because the union has measure less than $\delta$.

This is precisely the definition of absolute continuity. Hence
\[
\boxed{F\text{ is absolutely continuous on }\mathbb R.}
\]
:::

::: {.problem}
Let $X$ be the result, shown below, of "sandwiching" a standard 2-torus between two infinite horizontal planes in $\mathbb{R}^3$, so that each plane is tangent to the torus along a circle.
Compute the integer homology groups $H_*(X; \mathbb{Z})$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Each plane is contractible, and it is attached to the torus along a circle; attaching a plane along a circle is homotopy equivalent to attaching a $2$-cell (disk) along that circle.

::: pf-proof

a plane $\RR^2$ is contractible; the circle along which it is attached bounds a disk in the plane, and the complement of that disk in the plane is homotopy equivalent to the circle itself, so it contributes nothing to the homotopy type.

:::

:::

::: pf-step

Hence $X \simeq T^2$ with two $2$-cells attached along the two tangent circles.

::: pf-proof

Step [](#s1){.pf-ref} applied to both planes.

:::

:::

::: pf-step

The two tangent circles are parallel "longitude" circles on the torus, and they are homologous.

::: pf-proof

on a torus of revolution, the top and bottom tangent circles are both longitude circles (the $u$-circles), and the outer annulus between them is a cylinder whose boundary is their difference, so they are homologous.

:::

:::

::: pf-step

The cellular chain complex of $X$ is $C_2 = \ZZ^3$, $C_1 = \ZZ^2$, $C_0 = \ZZ$, with boundary maps: the torus $2$-cell maps to $0$, and each of the two cap $2$-cells maps to the longitude generator $a$.

::: pf-proof

the torus has one $0$-cell, two $1$-cells (longitude $a$ and meridian $b$), and one $2$-cell (with boundary $aba^{-1}b^{-1} = 0$); the two caps add two $2$-cells each with boundary $a$.

:::

:::

::: {.pf-step #s5}

$H_0(X) = \ZZ$.

::: pf-proof

$X$ is connected.

:::

:::

::: {.pf-step #s6}

$H_1(X) = \ZZ$.

::: pf-proof

$\ker d_1 = \ZZ^2$ and $\operatorname{im} d_2 = \langle a \rangle \cong \ZZ$, so $H_1 = \ZZ^2/\langle a \rangle \cong \ZZ$ (generated by the meridian $b$).

:::

:::

::: {.pf-step #s7}

$H_2(X) = \ZZ^2$.

::: pf-proof

::: {.pf-step #s7-1}

$\ker d_2$ is generated by the torus $2$-cell (boundary $0$) and the difference of the two cap cells (boundary $a - a = 0$).

::: pf-proof

a combination $m(\text{torus}) + n_1(\text{cap}_1) + n_2(\text{cap}_2)$ has boundary $(n_1 + n_2)a$, which is $0$ iff $n_1 + n_2 = 0$.

:::

:::

::: {.pf-step #s7-2}

$\operatorname{im} d_3 = 0$ (no $3$-cells).

::: pf-proof

$X$ is $2$-dimensional.

:::

:::

::: pf-step

Hence $H_2 = \ker d_2 \cong \ZZ^2$.

::: pf-proof

Steps [](#s7-1){.pf-ref} and [](#s7-2){.pf-ref}.

:::

:::

:::

:::

::: {.pf-step #s8}

$H_n(X) = 0$ for $n \ge 3$.

::: pf-proof

$X$ is $2$-dimensional.

:::

:::

::: pf-qed

$H_0 = \ZZ$, $H_1 = \ZZ$, $H_2 = \ZZ^2$, $H_n = 0$ for $n \ge 3$ (steps [](#s5){.pf-ref}, [](#s6){.pf-ref}, [](#s7){.pf-ref} and [](#s8){.pf-ref}).

:::

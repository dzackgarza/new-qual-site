::: {.problem}
If $X_i$, $i\in\mathbb N$, are topological spaces and $x_i\in X_i$, let $$Z=\{(y_i)_{i\in\mathbb N}:\text{for some }N\in\mathbb N\text{ we have }y_i=x_i\text{ for all }i\ge N\}.$$ Show that, in the product topology, $Z$ is dense in $\prod_{i\in\mathbb N}X_i$.
:::
::: {.solution}
<1>1. Let $B=\prod_{i\in\mathbb N}U_i$ be a nonempty basic open subset of $\prod_iX_i$, where each $U_i$ is open in $X_i$ and $U_i=X_i$ for all but finitely many $i$.
::: {.proof}
These sets form a basis for the product topology.
:::

<1>2. The set $B$ meets $Z$.
::: {.proof}
Let $F=\{i:U_i\ne X_i\}$, which is finite, and choose $N$ larger than every element of $F$. Since $B$ is nonempty, choose $y_i\in U_i$ for $i<N$. For $i\ge N$, put $y_i=x_i$. Then $U_i=X_i$ for every $i\ge N$, so $y_i\in U_i$ for all $i$. Hence $y=(y_i)\in B$, and by construction $y_i=x_i$ for all $i\ge N$, so $y\in Z$.
:::

<1>3. Therefore $Z$ is dense in $\prod_iX_i$.
::: {.proof}
Every nonempty basic open set meets $Z$ by <1>2, hence every nonempty open set meets $Z$.
:::
:::

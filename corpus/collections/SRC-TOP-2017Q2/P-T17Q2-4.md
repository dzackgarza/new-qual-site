::: {.problem}
If $X_i$, $i\in\NN$, are topological spaces and $x_i\in X_i$, let $$Z=\{(y_i)_{i\in\NN}:\text{for some }N\in\NN\text{ we have }y_i=x_i\text{ for all }i\ge N\}.$$ Show that, in the product topology, $Z$ is dense in $\prod_{i\in\NN}X_i$.
:::

::: {.solution}
<1>1. $Z$ meets every nonempty basic open set $B=\prod_{i\in\NN}U_i$, where each $U_i$ is open in $X_i$ and $U_i=X_i$ for all but finitely many $i$.

::: {.proof}
The set $F=\{i:U_i\neq X_i\}$ is finite; choose $N$ larger than every element of $F$.
Since $B$ is nonempty, choose $y_i\in U_i$ for $i<N$, and put $y_i=x_i\in X_i=U_i$ for $i\ge N$.
Then $y=(y_i)\in B\cap Z$.
:::

<1>2. Q.E.D.

::: {.proof}
Every nonempty open set contains a nonempty basic open set, which meets $Z$ by step <1>1, so $Z$ is dense.
:::
:::

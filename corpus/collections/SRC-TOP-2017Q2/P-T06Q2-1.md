::: {.problem}
Prove that if $f:X\to Y$ is continuous and surjective, $X$ is compact, and $Y$ is Hausdorff, then $f$ is a quotient map.
:::

::: {.solution}
<1>1. $f$ is a closed map.

::: {.proof}
Let $F\subseteq X$ be closed.
Since $X$ is compact, $F$ is compact, so $f(F)$ is compact in $Y$.
Because $Y$ is Hausdorff, $f(F)$ is closed.
:::

<1>2. For every $A\subseteq Y$, $A$ is closed in $Y$ if and only if $f^{-1}(A)$ is closed in $X$.

::: {.proof}
If $A$ is closed, $f^{-1}(A)$ is closed by continuity.
Conversely, if $f^{-1}(A)$ is closed, then $f(f^{-1}(A))$ is closed by step <1>1, and $f(f^{-1}(A))=A$ because $f$ is surjective.
:::

<1>3. Q.E.D.

::: {.proof}
Taking complements in step <1>2, $U\subseteq Y$ is open if and only if $f^{-1}(U)$ is open.
Since $f$ is surjective, $f$ is a quotient map.
:::
:::

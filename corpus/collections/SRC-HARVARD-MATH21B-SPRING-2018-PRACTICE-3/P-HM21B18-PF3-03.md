::: {.problem}
(a) On $C^\infty(\RR)$, decide which maps are linear:
$$
Tf(x)=3f(5x^2),\quad Tf(x)=f(4-x),\quad Tf(x)=\sin(x)f'(x),
$$
$$
Tf(x)=f(5)f(x),\quad Tf(x)=f(5)x^2,\quad Tf(x)=1+f(5f(x)).
$$

(b) Match, in the displayed order, the four systems $x'=A_jx$ with
$$
A_1=\begin{pmatrix}-1&0\\1&-1\end{pmatrix},\qquad
A_2=\begin{pmatrix}-1&1\\0&1\end{pmatrix},\qquad
A_3=\begin{pmatrix}0&0\\1&0\end{pmatrix},\qquad
A_4=\begin{pmatrix}1&1\\0&1\end{pmatrix}
$$
to source phase portraits a--d. In the source, portrait a is an unstable
improper node, portrait b is a saddle, portrait c is a stable improper node,
and portrait d consists of vertical trajectories directed downward for
$x_1<0$ and upward for $x_1>0$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The map
$$
T_1f(x)=3f(5x^2)
$$
is linear.


::: pf-proof

For scalars $a,b$ and functions $f,g$,
$$
\begin{aligned}
T_1(af+bg)(x)
&=3(af+bg)(5x^2)\\
&=aT_1f(x)+bT_1g(x).
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-2}

The map
$$
T_2f(x)=f(4-x)
$$
is linear.


::: pf-proof

For scalars $a,b$ and functions $f,g$,
$$
T_2(af+bg)(x)
=(af+bg)(4-x)
=aT_2f(x)+bT_2g(x).
$$

:::

:::

::: {.pf-step #s1-3}

The map
$$
T_3f(x)=\sin(x)f'(x)
$$
is linear.


::: pf-proof

Differentiation is linear, and multiplication by the fixed function
$\sin x$ is linear. Explicitly,
$$
\begin{aligned}
T_3(af+bg)(x)
&=\sin(x)(af+bg)'(x)\\
&=aT_3f(x)+bT_3g(x).
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-4}

The map
$$
T_4f(x)=f(5)f(x)
$$
is not linear.


::: pf-proof

Let $f\equiv1$. Then $T_4f\equiv1$, whereas
$$
T_4(2f)(x)=(2f)(5)(2f)(x)=4
$$
but $2T_4f(x)=2$. Thus homogeneity fails.

:::

:::

::: {.pf-step #s1-5}

The map
$$
T_5f(x)=f(5)x^2
$$
is linear.


::: pf-proof

Evaluation at $5$ is a linear functional. Hence
$$
\begin{aligned}
T_5(af+bg)(x)
&=(af+bg)(5)x^2\\
&=aT_5f(x)+bT_5g(x).
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-6}

The map
$$
T_6f(x)=1+f(5f(x))
$$
is not linear.


::: pf-proof

For the zero function,
$$
T_6(0)(x)=1.
$$
A linear map must send the zero vector to the zero vector.

:::

:::

::: {.pf-step #s1-7}

The system with matrix $A_1$ matches portrait c.


::: pf-proof

Write
$$
A_1=-I+N,
\qquad
N=\begin{pmatrix}0&0\\1&0\end{pmatrix},
\qquad
N^2=0.
$$
Therefore
$$
e^{tA_1}=e^{-t}(I+tN).
$$
Every solution tends to the origin as $t\to\infty$, while $A_1$ has only
one eigendirection. Thus the phase portrait is the stable improper node c.

:::

:::

::: {.pf-step #s1-8}

The system with matrix $A_2$ matches portrait b.


::: pf-proof

The triangular matrix $A_2$ has eigenvalues $-1$ and $1$. Hence one
eigendirection is exponentially contracting and the other is exponentially
expanding. Its phase portrait is therefore the saddle b.

:::

:::

::: {.pf-step #s1-9}

The system with matrix $A_3$ matches portrait d.


::: pf-proof

Writing the state as $(x_1,x_2)^T$, the system is
$$
x_1'=0,
\qquad
x_2'=x_1.
$$
Thus $x_1$ is constant and every nonstationary trajectory is a vertical
line. It is directed upward when $x_1>0$ and downward when $x_1<0$, exactly
as in portrait d.

:::

:::

::: {.pf-step #s1-10}

The system with matrix $A_4$ matches portrait a.


::: pf-proof

Write
$$
A_4=I+N,
\qquad
N=\begin{pmatrix}0&1\\0&0\end{pmatrix},
\qquad
N^2=0.
$$
Then
$$
e^{tA_4}=e^t(I+tN).
$$
The repeated eigenvalue is $1>0$ and there is only one eigendirection, so
the origin is an unstable improper node. This is portrait a.

:::

:::

::: {.pf-step #s1-11}

The complete answers are
$$
\boxed{
\begin{gathered}
\text{(a) }T_1,T_2,T_3,T_5\text{ are linear, while }T_4,T_6\text{ are not;}\\
\text{(b) }c,\ b,\ d,\ a.
\end{gathered}}
$$


::: pf-proof

Steps [](#s1-1){.pf-ref} through [](#s1-6){.pf-ref} establish part (a), and steps [](#s1-7){.pf-ref} through [](#s1-10){.pf-ref} establish part
(b).

:::

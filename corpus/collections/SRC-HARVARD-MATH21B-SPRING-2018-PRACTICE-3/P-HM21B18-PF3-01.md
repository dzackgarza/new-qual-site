::: {.problem}
Mark each statement true or false. No justifications are required.

1. $\begin{pmatrix}2&1\\1&4\end{pmatrix}$ is symmetric.
2. The zero vector is always in the kernel of a matrix.
3. For every $2\times2$ matrix $A$, $\ker A\subseteq\operatorname{im}A$.
4. If a $2\times2$ matrix $A$ is diagonalizable, then $A^T$ is diagonalizable.
5. The Fourier series of $\sin^2x$ contains only cosine terms and a constant term.
6. The smooth solutions of $f(x)=f(-x)^2$ form a vector space.
7. The algebraic multiplicity of the eigenvalue $0$ equals the nullity.
8. If two real matrices both have eigenvalues $i,-i$, then their sum has eigenvalues $i,-i$.
9. A discrete planar linear system is asymptotically stable whenever $\det A<0$.
10. If both $x'=Ax$ and $x(t+1)=Ax(t)$ are asymptotically stable, then every real eigenvalue satisfies $-1<\lambda<0$.
11. The sum of two orthogonal projections is an orthogonal projection.
12. $f(x,t)=e^{-6t}\sin(3x)$ solves $f_t=2f_{xx}$.
13. If $Ax=c$ for a $2\times2$ matrix has infinitely many solutions, then there exists $b$ for which $Ax=b$ has no solution.
14. The equilibrium $(0,0)$ of $x'=x^2$, $y'=y^2$ is asymptotically stable.
15. Every real symmetric matrix is diagonalizable over $\RR$.
16. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\norm{3\sin(5x)-7\sin(10x)}=\sqrt{5^2+10^2}$.
17. The sum of the eigenvalues of every symmetric $2\times2$ matrix is $0$.
18. The differential equation $x''+9x=\sin(3t)$ with $x(0)=2$, $x'(0)=2$ has a solution for which $\abs{x(t)}$ becomes arbitrarily large.
19. For every invertible matrix $A$, $A^{-1}$ is similar to $A$.
20. If the sum of all entries of an $n\times n$ matrix is zero, then the matrix is not invertible.
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

Statement 1 is true.


::: pf-proof

The matrix equals its transpose:
$$
\begin{pmatrix}2&1\\1&4\end{pmatrix}^T
=
\begin{pmatrix}2&1\\1&4\end{pmatrix}.
$$

:::

:::

::: pf-step

Statement 2 is true.


::: pf-proof

For every matrix $A$,
$$
A0=0.
$$
Hence the zero vector belongs to $\ker A$.

:::

:::

::: pf-step

Statement 3 is false.


::: pf-proof

For the zero $2\times2$ matrix,
$$
\ker A=\RR^2,
\qquad
\operatorname{im}A=\{0\}.
$$
Thus $\ker A\nsubseteq\operatorname{im}A$.

:::

:::

::: pf-step

Statement 4 is true.


::: pf-proof

If $A=SDS^{-1}$ with $D$ diagonal, then
$$
A^T=(S^{-1})^TDS^T=(S^T)^{-1}DS^T.
$$
Thus $A^T$ is similar to the diagonal matrix $D$.

:::

:::

::: pf-step

Statement 5 is true.


::: pf-proof

The identity
$$
\sin^2x=\frac{1-\cos(2x)}2
$$
expresses the function using only a constant term and a cosine term.

:::

:::

::: pf-step

Statement 6 is false.


::: pf-proof

The constant function $f\equiv1$ satisfies
$$
f(x)=1=f(-x)^2.
$$
If the solution set were a vector space, then $2f\equiv2$ would also be a
solution, but
$$
2\ne 2^2.
$$
Hence the solution set is not closed under scalar multiplication.

:::

:::

::: pf-step

Statement 7 is false.


::: pf-proof

Take
$$
A=\begin{pmatrix}0&1\\0&0\end{pmatrix}.
$$
Its characteristic polynomial is $\lambda^2$, so the algebraic
multiplicity of $0$ is $2$. On the other hand,
$$
\ker A
=
\left\{
\begin{pmatrix}x\\0\end{pmatrix}:x\in\RR
\right\},
$$
so the nullity is $1$.

:::

:::

::: pf-step

Statement 8 is false.


::: pf-proof

Let
$$
A=\begin{pmatrix}0&-1\\1&0\end{pmatrix},
\qquad
B=-A.
$$
Both $A$ and $B$ have eigenvalues $i,-i$, whereas $A+B=0$ has only the
eigenvalue $0$.

:::

:::

::: pf-step

Statement 9 is false.


::: pf-proof

For
$$
A=\begin{pmatrix}2&0\\0&-1/2\end{pmatrix}
$$
one has $\det A=-1<0$. The solution of the discrete system with initial
vector $e_1$ is
$$
x(n)=A^ne_1=2^ne_1,
$$
which does not tend to zero. Thus the system is not asymptotically stable.

:::

:::

::: pf-step

Statement 10 is true.


::: pf-proof

Let $\lambda\in\RR$ be an eigenvalue with eigenvector $v$. For the
continuous system, the corresponding solution is
$$
x(t)=e^{\lambda t}v.
$$
Asymptotic stability therefore forces $\lambda<0$. For the discrete system,
$$
x(n)=\lambda^nv,
$$
so asymptotic stability forces $\abs{\lambda}<1$. Combining the two inequalities
gives
$$
-1<\lambda<0.
$$

:::

:::

::: pf-step

Statement 11 is false.


::: pf-proof

Take the orthogonal projection $P=I$. Then $P+P=2I$, but
$$
(2I)^2=4I\ne2I.
$$
Hence $2I$ is not a projection.

:::

:::

::: pf-step

Statement 12 is false.


::: pf-proof

For
$$
f(x,t)=e^{-6t}\sin(3x),
$$
one has
$$
f_t=-6e^{-6t}\sin(3x)
$$
and
$$
2f_{xx}=-18e^{-6t}\sin(3x).
$$
These functions are not equal, so $f$ does not solve the stated heat
equation.

:::

:::

::: pf-step

Statement 13 is true.


::: pf-proof

If $Ax=c$ has infinitely many solutions, then $\ker A$ is nontrivial.
Rank-nullity for a $2\times2$ matrix gives
$$
\operatorname{rank}A<2.
$$
Thus $\operatorname{im}A$ is a proper subspace of $\RR^2$. Choose
$b\notin\operatorname{im}A$. Then $Ax=b$ has no solution.

:::

:::

::: pf-step

Statement 14 is false.


::: pf-proof

Fix any $\delta>0$ and choose
$$
0<x_0<\min\{\delta,1\},
\qquad
y_0=0.
$$
The solution with this initial condition is
$$
x(t)=\frac{x_0}{1-x_0t},
\qquad
y(t)=0
$$
as long as $t<1/x_0$. At
$$
t=\frac1{x_0}-1>0
$$
one has $x(t)=1$. Hence arbitrarily small initial data leave a fixed
neighborhood of the origin, so $(0,0)$ is not stable and therefore not
asymptotically stable.

:::

:::

::: pf-step

Statement 15 is true.


::: pf-proof

By the real spectral theorem, every real symmetric matrix is orthogonally
diagonalizable over $\RR$.

:::

:::

::: pf-step

Statement 16 is false.


::: pf-proof

Distinct sine modes are orthogonal for the given inner product, and
$$
\norm{\sin(nx)}^2
=
\frac1\pi\int_{-\pi}^{\pi}\sin^2(nx)\,dx
=1.
$$
Therefore
$$
\norm{3\sin(5x)-7\sin(10x)}^2
=3^2+7^2
=58.
$$
Thus the norm is $\sqrt{58}$, not $\sqrt{5^2+10^2}=\sqrt{125}$.

:::

:::

::: pf-step

Statement 17 is false.


::: pf-proof

The symmetric matrix
$$
A=\begin{pmatrix}1&0\\0&0\end{pmatrix}
$$
has eigenvalues $1$ and $0$, whose sum is $1$.

:::

:::

::: pf-step

Statement 18 is true.


::: pf-proof

The resonant equation
$$
x''+9x=\sin(3t)
$$
has general solution
$$
x(t)=C_1\cos(3t)+C_2\sin(3t)-\frac t6\cos(3t).
$$
The initial conditions give
$$
C_1=2,
\qquad
3C_2-\frac16=2,
$$
so $C_2=13/18$. Hence
$$
x(t)
=
2\cos(3t)+\frac{13}{18}\sin(3t)-\frac t6\cos(3t).
$$
Along $t_k=2\pi k/3$, this becomes
$$
x(t_k)=2-\frac{t_k}{6},
$$
whose absolute value tends to infinity.

:::

:::

::: pf-step

Statement 19 is false.


::: pf-proof

Take $A=2I_2$. Then $A^{-1}=\tfrac12 I_2$. A scalar matrix is fixed by
similarity, since
$$
S(cI_2)S^{-1}=cI_2
$$
for every invertible $S$. Thus $2I_2$ is not similar to
$\tfrac12 I_2$.

:::

:::

::: {.pf-step #s1-20}

Statement 20 is false.


::: pf-proof

The matrix
$$
A=\begin{pmatrix}1&0\\0&-1\end{pmatrix}
$$
has sum of entries equal to $0$, but
$$
\det A=-1\ne0.
$$
Hence $A$ is invertible.

:::

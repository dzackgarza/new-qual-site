::: {.problem}
Mark each statement true or false. No justifications are required.

1. $\begin{pmatrix}2&1\\1&4\end{pmatrix}$ is symmetric.
2. The zero vector is always in the kernel of a matrix.
3. For every $2\times2$ matrix $A$, $\ker A\subseteq\operatorname{im}A$.
4. If a $2\times2$ matrix $A$ is diagonalizable, then $A^T$ is diagonalizable.
5. The Fourier series of $\sin^2x$ contains only cosine terms and a constant term.
6. The smooth solutions of $f(x)=f(-x)^2$ form a vector space.
7. The algebraic multiplicity of the eigenvalue $0$ equals the nullity.
8. If two real matrices both have eigenvalues $i,-i$, then their sum has eigenvalues $i,-i$.
9. A discrete planar linear system is asymptotically stable whenever $\det A<0$.
10. If both $x'=Ax$ and $x(t+1)=Ax(t)$ are asymptotically stable, then every real eigenvalue satisfies $-1<\lambda<0$.
11. The sum of two orthogonal projections is an orthogonal projection.
12. $f(x,t)=e^{-6t}\sin(3x)$ solves $f_t=2f_{xx}$.
13. If $Ax=c$ for a $2\times2$ matrix has infinitely many solutions, then there exists $b$ for which $Ax=b$ has no solution.
14. The equilibrium $(0,0)$ of $x'=x^2$, $y'=y^2$ is asymptotically stable.
15. Every real symmetric matrix is diagonalizable over $\mathbb R$.
16. With $\langle f,g\rangle=\pi^{-1}\int_{-\pi}^{\pi}fg$, one has $\|3\sin(5x)-7\sin(10x)\|=\sqrt{5^2+10^2}$.
17. The sum of the eigenvalues of every symmetric $2\times2$ matrix is $0$.
18. Every solution of $x''+9x=\sin(3t)$ with $x(0)=2$, $x'(0)=2$ is bounded.
19. For every invertible matrix $A$, $A^{-1}$ is similar to $A$.
20. If the sum of all entries of an $n\times n$ matrix is zero, then the matrix is not invertible.

::: {.problem}
If $\sin^{-1} x = \frac{\pi}{6}$, then the acute angle value of $\cos^{-1} x$ is

(A) $\frac{5\pi}{6}$
(B) $\frac{\pi}{3}$
(C) $\sqrt{1 - \frac{\pi^2}{6^2}}$
(D) $1 - \frac{\pi}{6}$
(E) $0$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The hypothesis gives
$$
x=\sin\frac{\pi}{6}=\frac12.
$$


::: pf-proof

Apply the sine function to both sides of
$\sin^{-1}x=\pi/6$.

:::

:::

::: {.pf-step #s1-2}

The acute value of $\cos^{-1}x$ is
$$
\boxed{\frac{\pi}{3}},
$$
so the answer is (B).


::: pf-proof

By step [](#s1-1){.pf-ref}, $x=1/2$. Since
$$
\cos\frac{\pi}{3}=\frac12
$$
and $\pi/3\in[0,\pi]$, the principal inverse cosine gives
$\cos^{-1}(1/2)=\pi/3$.

:::

:::

::: pf-qed

Step [](#s1-2){.pf-ref} identifies the requested angle and choice.

:::

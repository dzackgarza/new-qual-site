::: {.problem}
Suppose $f$ is a real function such that $f'(x_0)$ exists. Which of the following is the value of $\lim_{h \to 0} \frac{f(x_0 + h) - f(x_0 - h)}{h}$?

(A) $0$
(B) $2f'(x_0)$
(C) $f'(-x_0)$
(D) $-f'(x_0)$
(E) $-2f'(x_0)$
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For $h\neq0$,
$$
\frac{f(x_0+h)-f(x_0-h)}{h}
=
\frac{f(x_0+h)-f(x_0)}{h}
+
\frac{f(x_0)-f(x_0-h)}{h}.
$$


::: pf-proof

Add and subtract $f(x_0)$ in the numerator and split the quotient.

:::

:::

::: {.pf-step #s1-2}

Each quotient on the right-hand side of step [](#s1-1){.pf-ref} tends to
$f'(x_0)$ as $h\to0$.


::: pf-proof

The first quotient is the defining difference quotient for $f'(x_0)$. For the
second, put $k=-h$. Then
$$
\frac{f(x_0)-f(x_0-h)}{h}
=
\frac{f(x_0+k)-f(x_0)}{k},
$$
which also tends to $f'(x_0)$ as $k\to0$.

:::

:::

::: {.pf-step #s1-3}

Therefore
$$
\boxed{\lim_{h\to0}\frac{f(x_0+h)-f(x_0-h)}{h}=2f'(x_0)},
$$
so the answer is (B).


::: pf-proof

Take limits in step [](#s1-1){.pf-ref} and apply step [](#s1-2){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} gives the requested limit and choice.

:::

:::

:::

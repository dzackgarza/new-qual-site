::: {.problem}
Suppose that $f(1 + x) = f(x)$ for all real $x$. If $f$ is a polynomial and $f(5) = 11$, then $f\left(\frac{15}{2}\right)$ is

(A) $-11$
(B) $0$
(C) $11$
(D) $\frac{33}{2}$
(E) not uniquely determined by the information given
:::

::: pf

::: pf-step

The polynomial $f$ is bounded on $\RR$.


::: pf-proof

Since $f$ is continuous, it is bounded on the compact interval $[0,1]$; choose
$M>0$ with $\abs{f(t)}\leq M$ there. For any $x\in\RR$, choose an integer $n$
such that $x-n\in[0,1)$. Repeatedly using $f(y+1)=f(y)$ gives
$$
f(x)=f(x-n),
$$
so $\abs{f(x)}\leq M$.

:::

:::

::: pf-step

The polynomial $f$ is constant.


::: pf-proof

Every nonconstant real polynomial is unbounded in absolute value as
$\abs{x}\to\infty$, contradicting step <1>1. Hence $f$ has degree $0$.

:::

:::

::: pf-step

One has
$$
\boxed{f\left(\frac{15}{2}\right)=11},
$$
so the answer is (C).


::: pf-proof

By step <1>2, $f$ is constant, and the given value $f(5)=11$ forces
$f(x)=11$ for every real $x$.

:::

:::

::: pf-qed

Step <1>3 gives the requested value and choice.

:::

:::

::: {.problem}
In the $xy$-plane, the graph of $x^{\log y} = y^{\log x}$ is

(A) empty
(B) a single point
(C) a ray in the open first quadrant
(D) a closed curve
(E) the open first quadrant
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

The equation is defined exactly when $x>0$ and $y>0$.


::: pf-proof

Both $\log x$ and $\log y$ occur, so real-valued logarithms require
$x,y>0$. For positive bases, the real powers in the equation are then defined.

:::

:::

::: {.pf-step #s1-2}

Every pair $(x,y)$ with $x>0$ and $y>0$ satisfies the equation.


::: pf-proof

Using $a^t=e^{t\log a}$ for $a>0$,
$$
x^{\log y}
=e^{(\log y)(\log x)}
=e^{(\log x)(\log y)}
=y^{\log x}.
$$

:::

:::

::: {.pf-step #s1-3}

The graph is
$$
\boxed{\{(x,y)\in\RR^2:x>0,\ y>0\}},
$$
the open first quadrant, so the answer is (E).


::: pf-proof

Step [](#s1-1){.pf-ref} gives the full domain and step [](#s1-2){.pf-ref} shows that every point of that
domain satisfies the equation.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} identifies the requested graph and choice.

:::

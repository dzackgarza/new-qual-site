::: {.problem}
If

$$f(x) = \begin{cases} \frac{\abs{x}}{x}, & \text{for } x \neq 0 \\ 0, & \text{for } x = 0, \end{cases}$$

then $\int_{-1}^1 f(x) \, dx$ is

(A) $-2$
(B) $0$
(C) $2$
(D) not defined
(E) none of the above
:::

::: {.problem}
If

$$f(x) = \begin{cases} \frac{\abs{x}}{x}, & \text{for } x \neq 0 \\ 0, & \text{for } x = 0, \end{cases}$$

then $\int_{-1}^1 f(x) \, dx$ is

(A) $-2$
(B) $0$
(C) $2$
(D) not defined
(E) none of the above
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

One has
$$
f(x)=
\begin{cases}
-1,&-1\leq x<0,\\
0,&x=0,\\
1,&0<x\leq1.
\end{cases}
$$


::: pf-proof

For $x<0$, $\abs{x}=-x$, so $\abs{x}/x=-1$. For $x>0$,
$\abs{x}=x$, so $\abs{x}/x=1$. The value at $0$ is given in the definition.

:::

:::

::: {.pf-step #s1-2}

The integral equals
$$
\boxed{0},
$$
so the answer is (B).


::: pf-proof

The value at the single point $0$ does not affect the Riemann integral, and by
step [](#s1-1){.pf-ref},
$$
\int_{-1}^1 f(x)\,dx
=\int_{-1}^0(-1)\,dx+\int_0^1 1\,dx
=-1+1
=0.
$$

:::

:::

::: pf-qed

Step [](#s1-2){.pf-ref} gives the requested integral and choice.

:::

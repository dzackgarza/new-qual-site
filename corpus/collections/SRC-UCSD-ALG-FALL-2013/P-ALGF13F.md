::: problem
Let $p$ be an odd prime.
Let $E$ be a splitting field of $x^p - x + 1$ over $\mathbb{F}_p$.

(a) Prove that, if $\alpha \in E$ is a root of $x^p - x + 1$, then for any $0 \leq i \leq p$ we have $\alpha^{p^i} = \alpha - i$.

(b) Explain why if $K$ is any finite field, then $|K| = \min\{n \mid x^n = x \text{ for all } x \in K\}$.
Then prove that $x^p - x + 1$ is irreducible over $\mathbb{F}_p$ and find $|E|$.
:::

::: {.solution}
**Part (a).**

<1>1. $\alpha^p = \alpha - 1$.
Proof: $\alpha$ is a root of $x^p - x + 1$, so $\alpha^p - \alpha + 1 = 0$, i.e. $\alpha^p = \alpha - 1$.

<1>2. $\alpha^{p^i} = \alpha - i$ for all $0 \le i \le p$.
<2>1. Base case $i = 0$: $\alpha^{p^0} = \alpha = \alpha - 0$.
Proof: trivial.
<2>2. Inductive step: $\alpha^{p^{i+1}} = (\alpha^{p^i})^p = (\alpha - i)^p = \alpha^p - i = (\alpha - 1) - i = \alpha - (i+1)$.
Proof: the Frobenius map $x \mapsto x^p$ is additive in characteristic $p$ (so $(\alpha - i)^p = \alpha^p - i^p = \alpha^p - i$), and $i^p = i$ since $i \in \FF_p$.
<2>3. Hence the claim holds by induction.
Proof: <2>1 and <2>2.

**Part (b).**

<1>1. For a finite field $K$ with $|K| = q$, the multiplicative group $K^\times$ has order $q - 1$, so $x^{q-1} = 1$ for all $x \in K^\times$, hence $x^q = x$ for all $x \in K$.
Proof: Lagrange's theorem applied to $K^\times$, and $0^q = 0$.

<1>2. No smaller positive $n$ satisfies $x^n = x$ for all $x \in K$.
Proof: if $x^n = x$ for all $x \in K$, then $x^{n-1} = 1$ for all $x \in K^\times$, so $q - 1 \mid n - 1$ (the multiplicative group is cyclic of order $q-1$), forcing $n \ge q$.

<1>3. Hence $|K| = \min\{n : x^n = x \text{ for all } x \in K\}$.
Proof: <1>1 and <1>2.

<1>4. $x^p - x + 1$ is irreducible over $\FF_p$.
<2>1. Let $\alpha$ be a root in $E$; by part (a), $\alpha^{p^p} = \alpha - p = \alpha$.
Proof: <1>2 of part (a) with $i = p$, and $p = 0$ in $\FF_p$.
<2>2. Hence $\alpha \in \FF_{p^p}$ (the field of $p^p$ elements), and $\alpha$ is not in any proper subfield.
Proof: $\alpha^{p^p} = \alpha$ means $\alpha \in \FF_{p^p}$; and $\alpha^{p^i} = \alpha - i \neq \alpha$ for $0 < i < p$ (since $i \neq 0$ in $\FF_p$), so $\alpha \notin \FF_{p^i}$ for $i < p$.
<2>3. Hence the minimal polynomial of $\alpha$ over $\FF_p$ has degree $p$.
Proof: $\alpha$ lies in $\FF_{p^p}$ but in no proper subfield, so $[\FF_p(\alpha) : \FF_p] = p$.
<2>4. Since $x^p - x + 1$ has degree $p$ and $\alpha$ is a root, it is the minimal polynomial of $\alpha$, hence irreducible.
Proof: <2>3.

<1>5. $|E| = p^p$.
Proof: $E = \FF_p(\alpha) = \FF_{p^p}$ (the splitting field is generated by one root, since the other roots are $\alpha - i$ for $i = 0, \ldots, p-1$ by part (a)), so $|E| = p^p$.

<1>6. Q.E.D.
Proof: <1>2 (a), <1>3, <1>4, <1>5 (b).

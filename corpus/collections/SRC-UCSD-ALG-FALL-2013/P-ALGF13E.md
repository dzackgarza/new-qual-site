::: problem
Let $A \in M_n(F)$, where $F$ is any field.
Let $V = F^n$ and let $\phi \colon V \to V$ be the linear transformation given by the matrix $A$.
Show that the following are equivalent:

(i) $\mathrm{charpoly}(A) = \mathrm{minpoly}(A)$.

(ii) The rational canonical form of $A$ is a companion matrix of a polynomial $f \in F[x]$.

(iii) There exists $v \in V$ such that the elements $\{v, \phi(v), \phi^2(v), \ldots, \phi^{n-1}(v)\}$ span $V$ over $F$.
:::

::: {.solution}
<1>1. (i) $\Rightarrow$ (ii).
<2>1. The rational canonical form of $A$ is a block-diagonal matrix of companion matrices of the invariant factors $d_1 \mid d_2 \mid \cdots \mid d_k$.
::: {.proof}
the rational canonical form.
:::
<2>2. The minimal polynomial is $d_k$ and the characteristic polynomial is $d_1 d_2 \cdots d_k$.
::: {.proof}
standard facts.
:::
<2>3. If $\operatorname{charpoly} = \operatorname{minpoly}$, then $d_1 \cdots d_k = d_k$, so $k = 1$ (there is a single invariant factor).
::: {.proof}
the degrees force $d_1 = \cdots = d_{k-1} = 1$.
:::
<2>4. Hence the rational canonical form is a single companion matrix (of $d_k$).
::: {.proof}
<2>3.
:::

<1>2. (ii) $\Rightarrow$ (iii).
<2>1. If the rational canonical form is the companion matrix of $f$, then $V$ is a cyclic $F[x]$-module generated by a single vector $v$.
::: {.proof}
a companion matrix corresponds to a cyclic module $F[x]/(f)$.
:::
<2>2. The cyclic module $F[x]/(f)$ is spanned by $1, x, x^2, \ldots, x^{n-1}$ (where $n = \deg f$).
::: {.proof}
$F[x]/(f)$ has basis $\{1, x, \ldots, x^{n-1}\}$.
:::
<2>3. Hence $\{v, \phi(v), \ldots, \phi^{n-1}(v)\}$ spans $V$.
::: {.proof}
<2>1 and <2>2 (the action of $x$ is $\phi$).
:::

<1>3. (iii) $\Rightarrow$ (i).
<2>1. If $\{v, \phi(v), \ldots, \phi^{n-1}(v)\}$ spans $V$, then $V$ is a cyclic $F[x]$-module generated by $v$.
::: {.proof}
the spanning set is exactly the orbit of $v$ under powers of $\phi$.
:::
<2>2. Hence $V \cong F[x]/(f)$ for some monic $f$ of degree $n$.
::: {.proof}
a cyclic module is a quotient $F[x]/(f)$, and $\dim V = n = \deg f$.
:::
<2>3. For $V = F[x]/(f)$, the minimal polynomial and characteristic polynomial of multiplication by $x$ are both $f$.
::: {.proof}
the minimal polynomial of multiplication by $x$ on $F[x]/(f)$ is $f$, and the characteristic polynomial is also $f$ (degree $n$).
:::
<2>4. Hence $\operatorname{charpoly}(A) = \operatorname{minpoly}(A) = f$.
::: {.proof}
<2>3.
:::

<1>4. Q.E.D.
::: {.proof}
<1>1, <1>2, and <1>3.
:::

::: {.problem}
Let $A \in M_n(F)$, where $F$ is any field.
Let $V = F^n$ and let $\phi \colon V \to V$ be the linear transformation given by the matrix $A$.
Show that the following are equivalent:

(i) $\mathrm{charpoly}(A) = \mathrm{minpoly}(A)$.

(ii) The rational canonical form of $A$ is a companion matrix of a polynomial $f \in F[x]$.

(iii) There exists $v \in V$ such that the elements $\{v, \phi(v), \phi^2(v), \ldots, \phi^{n-1}(v)\}$ span $V$ over $F$.
:::

::: {.solution}

::: pf

::: {.pf-step #i-implies-ii}
(i) $\Rightarrow$ (ii).

::: pf-proof

::: pf-step
The rational canonical form of $A$ is a block-diagonal matrix of companion matrices of the invariant factors $d_1 \mid d_2 \mid \cdots \mid d_k$.

::: pf-proof
the rational canonical form.
:::

:::

::: pf-step
The minimal polynomial is $d_k$ and the characteristic polynomial is $d_1 d_2 \cdots d_k$.

::: pf-proof
standard facts.
:::

:::

::: {.pf-step #single-invariant-factor}
If $\operatorname{charpoly} = \operatorname{minpoly}$, then $d_1 \cdots d_k = d_k$, so $k = 1$ (there is a single invariant factor).

::: pf-proof
the degrees force $d_1 = \cdots = d_{k-1} = 1$.
:::

:::

::: pf-step
Hence the rational canonical form is a single companion matrix (of $d_k$).

::: pf-proof
step [](#single-invariant-factor){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #ii-implies-iii}
(ii) $\Rightarrow$ (iii).

::: pf-proof

::: {.pf-step #cyclic-module-generator}
If the rational canonical form is the companion matrix of $f$, then $V$ is a cyclic $F[x]$-module generated by a single vector $v$.

::: pf-proof
a companion matrix corresponds to a cyclic module $F[x]/(f)$.
:::

:::

::: {.pf-step #cyclic-module-basis}
The cyclic module $F[x]/(f)$ is spanned by $1, x, x^2, \ldots, x^{n-1}$ (where $n = \deg f$).

::: pf-proof
$F[x]/(f)$ has basis $\{1, x, \ldots, x^{n-1}\}$.
:::

:::

::: pf-step
Hence $\{v, \phi(v), \ldots, \phi^{n-1}(v)\}$ spans $V$.

::: pf-proof
step [](#cyclic-module-generator){.pf-ref} and step [](#cyclic-module-basis){.pf-ref} (the action of $x$ is $\phi$).
:::

:::

:::

:::

::: {.pf-step #iii-implies-i}
(iii) $\Rightarrow$ (i).

::: pf-proof

::: pf-step
If $\{v, \phi(v), \ldots, \phi^{n-1}(v)\}$ spans $V$, then $V$ is a cyclic $F[x]$-module generated by $v$.

::: pf-proof
the spanning set is exactly the orbit of $v$ under powers of $\phi$.
:::

:::

::: pf-step
Hence $V \cong F[x]/(f)$ for some monic $f$ of degree $n$.

::: pf-proof
a cyclic module is a quotient $F[x]/(f)$, and $\dim V = n = \deg f$.
:::

:::

::: {.pf-step #minpoly-charpoly-both-f}
For $V = F[x]/(f)$, the minimal polynomial and characteristic polynomial of multiplication by $x$ are both $f$.

::: pf-proof
the minimal polynomial of multiplication by $x$ on $F[x]/(f)$ is $f$, and the characteristic polynomial is also $f$ (degree $n$).
:::

:::

::: pf-step
Hence $\operatorname{charpoly}(A) = \operatorname{minpoly}(A) = f$.

::: pf-proof
step [](#minpoly-charpoly-both-f){.pf-ref}.
:::

::: {.problem}
Let $f$ and $g$ be real-valued integrable functions on a measure space $(X,\mathcal{B},\mu)$, and define $$F_t=\{x\in X:f(x)>t\},\qquad G_t=\{x\in X:g(x)>t\}.$$ Prove $$\int|f-g|\,d\mu=\int_{-\infty}^\infty\mu\bigl((F_t\setminus G_t)\cup(G_t\setminus F_t)\bigr)\,dt.$$
:::

::: {.solution}
Set
\[
Y=\{x\in X:f(x)\ne g(x)\}.
\]
Since $f-g\in L^1(\mu)$,
\[
Y=\bigcup_{n=1}^{\infty}
\left\{x:|f(x)-g(x)|>\frac1n\right\},
\]
and for every $n$,
\[
\mu\left(\left\{|f-g|>\frac1n\right\}\right)
\le n\int_X|f-g|\,d\mu<\infty.
\]
Thus the restricted measure space $(Y,\mathcal B|_Y,\nu)$, where
$\nu=\mu|_Y$, is $\sigma$-finite.

<1>1. For every $t\in\mathbb R$,
\[
(F_t\setminus G_t)\cup(G_t\setminus F_t)\subseteq Y.
\]
::: {.proof}
If $x\notin Y$, then $f(x)=g(x)$, so
\[
f(x)>t\iff g(x)>t.
\]
Hence $x$ belongs to neither difference.
:::

<1>2. For every $x\in Y$,
\[
\mathbf 1_{(F_t\setminus G_t)\cup(G_t\setminus F_t)}(x)
=
\mathbf 1_{[\min(f(x),g(x)),\,\max(f(x),g(x)))}(t).
\]
::: {.proof}
If $f(x)>g(x)$, membership differs precisely when
\[
g(x)\le t<f(x).
\]
If $g(x)>f(x)$, it differs precisely when
\[
f(x)\le t<g(x).
\]
These are exactly the two cases described by the interval on the right.
:::

<1>3. The required identity holds.
::: {.proof}
By <1>1, the symmetric difference is contained in $Y$, so its $\mu$-measure equals its $\nu$-measure.
Since both $(Y,\nu)$ and $(\mathbb R,dt)$ are $\sigma$-finite, Tonelli's theorem applies to the nonnegative measurable indicator in <1>2. Therefore
\[
\begin{aligned}
&\int_{-\infty}^{\infty}
\mu\bigl((F_t\setminus G_t)\cup(G_t\setminus F_t)\bigr)\,dt\\
&\quad=
\int_{-\infty}^{\infty}
\int_Y
\mathbf 1_{(F_t\setminus G_t)\cup(G_t\setminus F_t)}(x)
\,d\nu(x)\,dt\\
&\quad=
\int_Y\int_{-\infty}^{\infty}
\mathbf 1_{[\min(f(x),g(x)),\,\max(f(x),g(x)))}(t)
\,dt\,d\nu(x)\\
&\quad=
\int_Y|f(x)-g(x)|\,d\nu(x).
\end{aligned}
\]
Because $f=g$ on $X\setminus Y$, the last expression is
\[
\int_X|f-g|\,d\mu.
\]
This is the desired formula.
:::

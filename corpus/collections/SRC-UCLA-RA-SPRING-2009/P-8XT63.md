::: {.problem}
Suppose that $f:\DD\to\CC$ is holomorphic and injective in some annulus $\{z:r<\abs{z}<1\}$, where $\DD$ is the open unit disc.
Show that $f$ is injective in $\DD$.
:::

::: {.solution}
Throughout $\DD = \theset{z \mid \abs{z} < 1}$, the hypothesis is that there is $r \in (0,1)$ such that $f$ is injective on the annulus $A \coloneqq \theset{z \mid r < \abs{z} < 1}$, and for $\rho \in (r,1)$ the curve $\gamma_{\rho}(t) \coloneqq f(\rho e^{it})$, $0 \le t \le 2\pi$, is the image of the circle of radius $\rho$ under $f$. The collection's `provenance` names the Spring 2009 examination paper, and no solutions sheet accompanies it, so the argument below is the card's own.

::: pf

::: {.pf-step #simple}
For every $\rho \in (r,1)$ the curve $\gamma_{\rho}$ is a simple closed curve.

::: pf-proof
The circle $C_{\rho} = \theset{z \mid \abs{z} = \rho}$ is contained in $A$, since $r < \rho < 1$. The map $t \mapsto \rho e^{it}$ is a continuous bijection of $[0,2\pi)$ onto $C_{\rho}$ with $\rho e^{i0} = \rho e^{i2\pi}$, and $f$ is injective on $A$, so $f$ restricted to $C_{\rho}$ is injective; hence $\gamma_{\rho}$ is a closed curve without self-intersections.

:::

:::

::: {.pf-step #winding}
For every $\rho \in (r,1)$ and every $w \notin \gamma_{\rho}$ the winding number $\operatorname{ind}(\gamma_{\rho}, w)$ is $0$ or $\pm 1$.

::: pf-proof
The winding number of a closed curve is constant on each connected component of the complement of its image, and a simple closed curve has exactly two such components, an inside on which the winding number is $\pm1$ and an unbounded outside on which it is $0$ (the Jordan curve theorem, with the argument giving the sign from the orientation).

:::

:::

::: {.pf-step #count}
For every $\rho \in (r,1)$ and every $w \notin \gamma_{\rho}$, the number of solutions of $f(z) = w$ in $\abs{z} < \rho$, counted with multiplicity, equals $\operatorname{ind}(\gamma_{\rho}, w)$, and is therefore at most $1$.

::: pf-proof
The argument principle applied to the holomorphic function $f - w$ on the disc $\abs{z} < \rho$, whose boundary circle carries no zero of $f - w$ because $w \notin \gamma_{\rho}$, gives that this number is $\frac{1}{2\pi i}\oint_{\abs{z}=\rho}\frac{f'(z)}{f(z)-w}dz$, that is the winding number of $f \circ \gamma_{\rho} = \gamma_{\rho}$ about $w$. Step [](#winding){.pf-ref} bounds it by $1$.

:::

:::

::: {.pf-step #choose}
For $z_{1} \ne z_{2}$ in $\DD$ with $f(z_{1}) = f(z_{2}) = w$ there is $\rho \in (r,1)$ such that $\rho > \max(\abs{z_{1}},\abs{z_{2}})$ and $w \notin \gamma_{\rho}$.

::: pf-proof
The set of $\rho \in (r,1)$ with $w \in \gamma_{\rho}$ is the set of moduli of the preimages of $w$ in $A$, of which there is at most one, because $f$ is injective on $A$; so all but at most one $\rho$ in $(r,1)$ avoid it, and one may choose $\rho$ larger than $\max(\abs{z_{1}},\abs{z_{2}})$ and still avoiding that single value.

:::

:::

::: {.pf-step #contradiction}
No such pair $z_{1} \ne z_{2}$ exists.

::: pf-proof
With $\rho$ as in step [](#choose){.pf-ref}, both $z_{1}$ and $z_{2}$ lie in $\abs{z} < \rho$ and both solve $f(z) = w$, so the count of step [](#count){.pf-ref} is at least $2$, contradicting its bound of $1$.

:::

:::

::: pf-step
$f$ is injective on $\DD$.

::: pf-proof
Step [](#contradiction){.pf-ref} shows that distinct points of $\DD$ have distinct images, which is injectivity.

:::

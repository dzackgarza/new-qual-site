::: {.problem}
Let F be a field, and let a and b belong to F with $a \neq 0$ . If c belongs to some extension of F , prove that $F ( c ) = F ( a c + b )$ . (F “absorbs” its own elements.)
:::

::: {.solution}
This is akin to exercise 6. First, it is clear that $a c + b \in F ( c )$ so $F ( a c + b ) \subseteq F ( c )$ . Now, $c = a ^ { - 1 } ( a c + b ) - a ^ { - 1 } b$ so $F ( c ) \subseteq F ( a c + b )$ and we are done.
:::

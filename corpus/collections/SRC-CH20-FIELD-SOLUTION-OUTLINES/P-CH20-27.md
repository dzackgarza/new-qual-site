::: {.problem}
Prove or disprove that $\QQ(\sqrt{3})$ and $\QQ(\sqrt{-3})$ are ring isomorphic.
:::

::: {.solution}
Suppose that there is some map $\phi$ that is a ring isomorphism from $\QQ ( { \sqrt { - 3 } } )$ to $\QQ ( { \sqrt { 3 } } )$ . Then $\phi ( 1 ) = 1$, so $\phi ( - 3 ) = - 3$ by additivity.
So $-3 = \phi ( - 3 ) = \phi ( \sqrt { - 3 } \sqrt { - 3 } ) = ( \phi ( { \sqrt { - 3 } } ) ) ^ { 2 }$ . But this is a contradiction since $\phi ( { \sqrt { - 3 } } )$ is a real number.
Hence, no such isomorphism exists.
:::

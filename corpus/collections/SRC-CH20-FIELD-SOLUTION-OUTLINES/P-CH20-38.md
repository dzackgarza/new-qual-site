::: {.problem}
Show that $\QQ(\sqrt{7}, i)$ is the splitting field for $x^{4} - 6x^{2} - 7$ (over $\QQ$).
:::

::: {.solution}
First we need to factor $x ^ { 4 } - 6 x ^ { 2 } - 7$ . We see that it factors to $( x ^ { 2 } - 7 ) ( x ^ { 2 } + 1 )$ . Hence the roots are $\pm \sqrt { 7 }$ and $\pm i$ . Notice that adjoining $\sqrt { 7 }$ gives us $- { \sqrt { 7 } }$ for free.
Similarly, adjoining $i$ also gives us $-i$ . So the splitting field is $\QQ ( { \sqrt { 7 } } , i )$ .
:::

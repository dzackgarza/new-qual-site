::: {.problem}
Find the splitting field of $x ^ { 3 } - 1$ over Q. Express your answer in the form Q(a).
:::

::: {.solution}
First, notice that $x ^ { 3 } - 1 = ( x - 1 ) ( x ^ { 2 } + x + 1 )$ (see cyclotomic polynomials from class).
So the roots of $x ^ { 3 } - 1$ are 1 and $( - 1 \pm { \sqrt { - 3 } } ) / 2$ . Notice that 1 is already in Q. By arguments like those in class, we see that we get $- ( 1 \pm { \sqrt { - 3 } } ) / 2$ by simply adjoining $\sqrt { - 3 }$ . So $\mathbb { Q } ( { \sqrt { - 3 } } )$ is the splitting field.
:::

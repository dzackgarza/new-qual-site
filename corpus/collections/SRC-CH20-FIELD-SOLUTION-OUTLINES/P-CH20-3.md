::: {.problem}
Find the splitting field of $x ^ { 3 } - 1$ over Q. Express your answer in the form Q(a).
:::

::: {.solution}
Factor $x ^ { 3 } - 1 = ( x - 1 ) ( x ^ { 2 } + x + 1 )$.
So the roots of $x ^ { 3 } - 1$ are 1 and $( - 1 \pm { \sqrt { - 3 } } ) / 2$ . The root 1 is already in Q. The field $\mathbb { Q } ( { \sqrt { - 3 } } )$ contains $( - 1 \pm { \sqrt { - 3 } } ) / 2$, and conversely any field containing $\omega = ( - 1 + { \sqrt { - 3 } } ) / 2$ contains $\sqrt{-3} = 2\omega + 1$. So $\mathbb { Q } ( { \sqrt { - 3 } } )$ is the splitting field.
:::

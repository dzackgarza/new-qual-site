::: {.problem}
Describe the elements of $\mathbb { Q } ( { \sqrt [ 3 ] { 5 } } )$ .
:::

::: {.solution}
$$
\mathbb { Q } ( 5 ^ { \frac { 1 } { 3 } } ) = \{ a + b 5 ^ { \frac { 1 } { 3 } } + c 5 ^ { \frac { 2 } { 3 } } | a , b , c \in \mathbb { Q } \}
$$
:::

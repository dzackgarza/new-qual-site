::: {.problem}
Describe the elements of $\QQ(\sqrt[3]{5})$.
:::

::: {.solution}
$$
\QQ ( 5 ^ { \frac { 1 } { 3 } } ) = \{ a + b 5 ^ { \frac { 1 } { 3 } } + c 5 ^ { \frac { 2 } { 3 } } \st a , b , c \in \QQ \}
$$
:::

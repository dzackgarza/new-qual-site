::: {.problem}
Let $a, b \in \RR$ with $b \neq 0$. Show that $\RR(a + bi) = \CC$.
:::

::: {.solution}
Since $a + bi \in \CC$, $\RR ( a + b i ) \subseteq \CC$ . For the reverse inclusion $\CC \subseteq \RR ( a + b i )$ , it suffices to show that $i \in \RR ( a + b i )$, since $\RR \subseteq \RR(a+bi)$ and $\CC = \{x + yi : x, y \in \RR\}$. We see that $i = b ^ { - 1 } ( a + b i ) - b ^ { - 1 } a$ which is a real number times $( a + b i )$ plus a real number and so it is an element of $\RR ( a + b i )$ . Thus we have equality.
:::

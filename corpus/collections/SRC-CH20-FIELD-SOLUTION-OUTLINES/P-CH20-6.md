::: {.problem}
Let $a, b \in \RR$ with $b \neq 0$. Show that $\RR(a + bi) = \CC$.
:::

::: {.solution}

The argument is the card's own: the one inclusion is automatic, and $i$ is a real combination of $a+bi$ and $1$.

::: pf

::: {.pf-step #subset}

$\RR(a+bi)\subseteq\CC$.

::: pf-proof

$\CC$ is a field containing $\RR$ and $a+bi$, and $\RR(a+bi)$ is by definition the smallest subfield of $\CC$ containing both; hence it lies inside $\CC$.

:::

:::

::: {.pf-step #i}

$i=b^{-1}(a+bi)-b^{-1}a$, so $i\in\RR(a+bi)$.

::: pf-proof

$b\ne0$ is real, so $b^{-1}\in\RR$; expanding, $b^{-1}(a+bi)-b^{-1}a=b^{-1}a+i-b^{-1}a=i$. The right-hand side is a sum of a real multiple of the element $a+bi$ and a real number, both of which lie in the subfield $\RR(a+bi)$, which is closed under addition.

:::

:::

::: {.pf-step #conclusion}

$\RR(a+bi)=\CC$.

::: pf-proof

$\RR\subseteq\RR(a+bi)$ by definition and $i\in\RR(a+bi)$ by step [](#i){.pf-ref}, so every $x+yi$ with $x,y\in\RR$ lies in $\RR(a+bi)$; that is $\CC\subseteq\RR(a+bi)$. With step [](#subset){.pf-ref},
$$
\boxed{\RR(a+bi)=\CC\qquad(a,b\in\RR,\ b\ne0).}
$$

:::

::: {.problem}
Let $a , b \in \mathbb { R }$ with $b \neq 0$ . Show that $\mathbb { R } ( a + b i ) = \mathbb { C }$ .
:::

::: {.solution}
Since $a + bi \in \mathbb C$, $\mathbb { R } ( a + b i ) \subseteq \mathbb { C }$ . For the reverse inclusion $\mathbb { C } \subseteq \mathbb { R } ( a + b i )$ , it suffices to show that $i \in \mathbb { R } ( a + b i )$, since $\mathbb R \subseteq \mathbb R(a+bi)$ and $\mathbb C = \{x + yi : x, y \in \mathbb R\}$. We see that $i = b ^ { - 1 } ( a + b i ) - b ^ { - 1 } a$ which is a real number times $( a + b i )$ plus a real number and so it is an element of $\mathbb { R } ( a + b i )$ . Thus we have equality.
:::

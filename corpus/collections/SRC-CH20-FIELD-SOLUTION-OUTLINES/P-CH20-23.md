::: {.problem}
Determine all of the subfields of $\mathbb { Q } ( { \sqrt { 2 } } )$ .
:::

::: {.solution}
First notice that $\mathbb { Q }$ and $\mathbb { Q } ( { \sqrt { 2 } } )$ are subfields.
Now suppose we have another subfield, K. K must contain Q and some element $a + b { \sqrt { 2 } }$ where $b \neq 0$ . Now, K must contain $\mathbb { Q } ( a + b { \sqrt { 2 } } )$ , but by exercise 20 this is just $\mathbb { Q } ( { \sqrt { 2 } } )$ . So those are the only two subfields.
:::

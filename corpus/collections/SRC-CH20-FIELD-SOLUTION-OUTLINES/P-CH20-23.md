::: {.problem}
Determine all of the subfields of $\QQ(\sqrt{2})$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's `provenance` is the textbook's Google Books record and no solutions sheet is retained, so the argument below is the card's own, structured from the outline already on the card.

::: pf

::: {.pf-step #two-subfields}
$\QQ$ and $K$ are subfields of $K$, and $\QQ \ne K$.

::: pf-proof
A subfield is a subfield of itself, and $\QQ \subseteq K$ by the definition of $K$. Moreover $\sqrt2 \in K \setminus \QQ$ by the stated irrationality of $\sqrt2$, so the inclusion is strict.

:::

:::

::: {.pf-step #outside}
If $L$ is a subfield of $K$ with $L \ne \QQ$ then $L$ contains $x = a + b\sqrt2$ with $b \ne 0$.

::: pf-proof
Since $L \ne \QQ$ and $\QQ \subseteq L$, some $x \in L$ lies outside $\QQ$; writing $x = a + b\sqrt2$ with $a,b \in \QQ$, the characterisation of $\QQ$ inside $K$ given above forces $b \ne 0$.

:::

:::

::: {.pf-step #generates}
If $x = a + b\sqrt2 \in L$ with $a, b \in \QQ$ and $b \ne 0$, then $\sqrt2 \in L$.

::: pf-proof
The field $L$ contains $x - a = b\sqrt2$ and is closed under division by the nonzero rational $b$, so it contains $\sqrt2$.

:::

:::

::: {.pf-step #top}
If $L \subseteq K$ is a subfield containing $\sqrt2$ and $\QQ$ then $L = K$.

::: pf-proof
$L$ is closed under addition and multiplication, so it contains $a + b\sqrt2$ for all $a,b \in \QQ$, which is all of $K$; the reverse inclusion is the hypothesis $\QQ \subseteq L$ together with $\sqrt2 \in L$ giving $K \subseteq L$.

:::

:::

::: pf-step
The subfields of $\QQ(\sqrt2)$ are exactly $\boxed{\QQ \text{ and } \QQ(\sqrt2)}$.

::: pf-proof
Step [](#two-subfields){.pf-ref} exhibits both. Conversely a subfield $L \subseteq K$ is either $\QQ$, or by step [](#outside){.pf-ref} contains $x = a+b\sqrt2$ with $b \ne 0$, whence $\sqrt2 \in L$ by step [](#generates){.pf-ref} and $L = K$ by step [](#top){.pf-ref}.

:::

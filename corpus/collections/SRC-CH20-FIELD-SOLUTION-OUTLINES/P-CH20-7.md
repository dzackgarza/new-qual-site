::: {.problem}
Find a polynomial $p ( x )$ in $\mathbb { Q } [ x ]$ such that $\mathbb { Q } ( { \sqrt { 1 + { \sqrt { 5 } } } } )$ is ring isomorphic to $\mathbb { Q } [ x ] / < p ( x ) >$ .
:::

::: {.solution}
If $p(x) \in \mathbb Q[x]$ is irreducible over Q and has the root $\alpha = \sqrt { 1 + { \sqrt { 5 } } }$, then $\mathbb Q(\alpha) \approx \mathbb Q[x]/<p(x)>$ (Theorem 20.3).
From $\alpha ^ { 2 } = 1 + { \sqrt { 5 } }$ we get $\alpha ^ { 2 } - 1 = { \sqrt { 5 } }$, so $\alpha ^ { 4 } - 2 \alpha ^ { 2 } + 1 = 5$, that is, $\alpha$ is a root of $p ( x ) = x ^ { 4 } - 2 x ^ { 2 } - 4$.

The monic polynomial $p$ is irreducible over Q because its reduction $\bar p = x^4 + x^2 + 2$ is irreducible over $\mathbb Z_3$. Indeed, $\bar p(0) = 2$ and $\bar p(1) = \bar p(2) = 1$, so $\bar p$ has no linear factor. A factorization into monic quadratics $(x^2 + ax + b)(x^2 - ax + c)$ would require $a(c - b) = 0$ and $bc = 2$: if $a = 0$, then $b + c = 1$ and $bc = 2$, so $b$ is a root of $t^2 - t + 2$, which has no root in $\mathbb Z_3$; if $a \neq 0$, then $b = c$ and $b^2 = 2$, which has no solution in $\mathbb Z_3$.
:::

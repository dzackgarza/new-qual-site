::: {.problem}
Let C be the portion of the astroid $x ^ { 2 / 3 } + y ^ { 2 / 3 } = 1$ from (1, 0) to (0, 1), which can be parameterized by the equations

$$
x = \cos ^ { 3 } t , \quad y = \sin ^ { 3 } t
$$

as t increases from 0 to $\frac { \pi } { 2 }$ . Evaluate the integral: $\int _ { C } ( y \cos x y - 1 ) d x + ( 1 + x \cos x y ) d y$ (A) $-2$ (B) $-1$ (C) $1$ (D) $\frac { 1 } { 2 } \pi - 1$ (E) $2$
:::

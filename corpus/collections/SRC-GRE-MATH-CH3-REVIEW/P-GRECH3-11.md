::: {.problem}
Consider the following three functions, each of which is defined for all (x, y) in the plane:

$$
f _ { 1 } ( x , y ) = \left\{ \begin{array} { l l } { \displaystyle \frac { x - y } { x + y } } & { \mathrm { i f } \ x + y \neq 0 } \\ { 1 } & { \mathrm { i f } \ x + y = 0 } \end{array} \right.
$$

$$
f _ { 2 } ( x , y ) = \left\{ \begin{array} { l l } { \displaystyle \frac { x y } { x ^ { 2 } + y ^ { 2 } } } & { \mathrm { i f } \ ( x , y ) \neq ( 0 , 0 ) } \\ { 0 } & { \mathrm { i f } \ ( x , y ) = ( 0 , 0 ) } \end{array} \right.
$$

$$
f _ { 3 } ( x , y ) = \left\{ \begin{array} { l l } { \displaystyle \frac { x ^ { 3 } - y ^ { 3 } } { x ^ { 2 } + y ^ { 2 } } } & { \mathrm { i f } \ ( x , y ) \neq ( 0 , 0 ) } \\ { 0 } & { \mathrm { i f } \ ( x , y ) = ( 0 , 0 ) } \end{array} \right.
$$

Which of these functions is/are continuous at the origin? (A) None (B) $f _ { 1 }$ only (C) $f _ { 2 }$ only (D) $f _ { 3 }$ only (E) All three
:::

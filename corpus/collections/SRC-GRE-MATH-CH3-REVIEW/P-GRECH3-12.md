::: {.problem}
The plane $y = 1$ slices the surface

$$
z = \arctan \frac { x + y } { 1 - x y }
$$

in a curve, C. Find the slope of the tangent line to C at the point where $x = 2$ . (A) $-3$ (B) $-1$ (C) $\frac { 1 } { 5 }$ (D) $\frac { 1 } { 3 }$ (E) $\frac { 1 } { 2 }$
:::

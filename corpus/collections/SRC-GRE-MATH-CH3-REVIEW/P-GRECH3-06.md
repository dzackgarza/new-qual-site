::: {.problem}
Let $P = ( 1 , - 1 , 1 )$ and $Q = ( - 3 , 3 , 3 )$ . Find the point R on the line containing P and Q whose distance from P is 3 times its distance from Q, given that R is not between P and Q. (A) $( - 4 , 4 , \frac { 7 } { 2 } )$ (B) $( - 5 , 5 , 4 )$ (C) $( - \frac { 1 3 } { 3 } , \frac { 1 3 } { 3 } , \frac { 1 1 } { 3 } )$ (D) $( - \frac { 1 5 } { 2 } , \frac { 1 5 } { 2 } , \frac { 1 1 } { 2 } )$ (E) $( - 9 , 9 , 6 )$
:::

::: {.problem}
A right circular cylinder has base radius $r = 1 0 0$ cm and height h = 100 cm. Which of the following best describes how the volume of the cylinder will change if r increases to 101 cm and h decreases to 99 cm?

(A) Volume will decrease by approximately $3 \pi ( 1 0 0 ) ^ { 2 }$ cubic cm

(B) Volume will decrease by approximately $\pi ( 1 0 0 ) ^ { 2 }$ cubic cm

(C) Volume will increase by approximately $\pi ( 1 0 0 ) ^ { 2 }$ cubic cm

(D) Volume will increase by approximately $2 \pi ( 1 0 0 ) ^ { 2 }$ cubic cm

(E) Volume will increase by approximately $3 \pi ( 1 0 0 )$ cubic cm
:::

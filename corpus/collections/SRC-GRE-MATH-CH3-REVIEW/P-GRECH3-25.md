::: {.problem}
If $\mathbf { F } = ( 3 y - 2 x ) \hat { \mathbf { i } } + ( x ^ { 2 } + y ) \hat { \mathbf { j } }$ , find the value of $\int _ { C } \mathbf { F } \cdot d \mathbf { r }$ , where C is the portion of the parabola $y = x ^ { 2 }$ , directed from (1, 1) to the origin. (A) $-1$ (B) $0$ (C) $1$ (D) $2$ (E) $3$
:::

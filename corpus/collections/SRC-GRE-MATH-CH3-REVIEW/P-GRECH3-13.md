::: {.problem}
If the variables $P$ , $V$ , and $T$ are related by the equation $P V = n R T$ , where $n$ and $R$ are constants, simplify the expression $\frac { \partial V } { \partial T } \frac { \partial T } { \partial p } \frac { \partial p } { \partial V }$ . (A) $- 1$ (B) $1$ (C) $- n R$ (D) $n R$ (E) $\frac { 1 } { n R }$
:::

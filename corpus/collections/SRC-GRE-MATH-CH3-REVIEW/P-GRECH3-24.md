::: {.problem}
A vertical fence is constructed whose base is the curve $y = x \sqrt { x }$ , from (0, 0) to (1, 1), and whose height above each point (x, y) along the curve is $x ^ { 3 } - y ^ { 2 } + 2 7$ . Find the area of this fence. (A) $\frac { 1 } { 9 } ( 5 \sqrt { 5 } - 2 )$ (B) $5 \sqrt { 1 3 } - 6$ (C) $9 \sqrt { 3 }$ (D) $1 3 \sqrt { 1 3 } - 8$ (E) $27$
:::

::: {.problem}
Evaluate the integral:

$$
\int _ { 0 } ^ { 2 a } \int _ { - \sqrt { 2 a y - y ^ { 2 } } } ^ { 0 } \sqrt { x ^ { 2 } + y ^ { 2 } } d x d y
$$

(A) $a ^ { 3 }$ (B) $\frac { 3 2 } { 9 } a ^ { 3 }$ (C) $\frac { \pi } { 2 } a ^ { 2 }$ (D) $\frac { 8 \pi } { 3 } a ^ { 2 }$ (E) $2 a ^ { 4 }$
:::

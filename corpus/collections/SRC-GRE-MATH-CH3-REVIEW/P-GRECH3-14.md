::: {.problem}
Let f be the function defined for all (x, y) as follows:

$$
f ( x , y ) = \left\{ \begin{array} { l l } { x y \frac { x ^ { 2 } - y ^ { 2 } } { x ^ { 2 } + y ^ { 2 } } } & { \mathrm { i f } \ ( x , y ) \neq ( 0 , 0 ) } \\ { 0 } & { \mathrm { i f } \ ( x , y ) = ( 0 , 0 ) } \end{array} \right.
$$

What is the value of $f _ { x y }$ at the point $( 0 , 0 )$ ? (A) $-1$ (B) $0$ (C) $\frac { 1 } { 2 }$ (D) $1$ (E) Undefined
:::

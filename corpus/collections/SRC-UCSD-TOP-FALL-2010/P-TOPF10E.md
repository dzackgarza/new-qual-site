::: {.problem}
Show that there does not exist a map of degree $1$ from $S^2 \times S^2$ to $\mathbb{CP}^2$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

$H^2(S^2 \times S^2; \ZZ) \cong \ZZ \oplus \ZZ$, generated by $\alpha = [S^2 \times \text{pt}]^*$ and $\beta = [\text{pt} \times S^2]^*$.

::: pf-proof

Künneth theorem.

:::

:::

::: {.pf-step #s2}

$H^2(\mathbb{CP}^2; \ZZ) \cong \ZZ$, generated by $x$ (the hyperplane class), with $x^2$ a generator of $H^4(\mathbb{CP}^2) \cong \ZZ$.

::: pf-proof

cohomology of $\mathbb{CP}^2$.

:::

:::

::: pf-step

Suppose $f : S^2 \times S^2 \to \mathbb{CP}^2$ has degree $1$.

::: pf-proof

assume such a map exists.

:::

:::

::: {.pf-step #s4}

Then $f^* : H^4(\mathbb{CP}^2) \to H^4(S^2 \times S^2)$ is an isomorphism (multiplication by $\deg f = 1$).

::: pf-proof

degree $1$ means $f^*$ sends the fundamental class to the fundamental class.

:::

:::

::: pf-step

Write $f^*(x) = a\alpha + b\beta$ for integers $a, b$.

::: pf-proof

Step [](#s1){.pf-ref}.

:::

:::

::: {.pf-step #s6}

Then $f^*(x^2) = f^*(x)^2 = (a\alpha + b\beta)^2 = 2ab\,(\alpha \smile \beta)$.

::: pf-proof

$\alpha^2 = \beta^2 = 0$ (each is a class of a $2$-sphere, and $H^4(S^2 \times S^2) \cong \ZZ$ is generated by $\alpha \smile \beta$).

:::

:::

::: {.pf-step #s7}

But $f^*(x^2)$ must be a generator of $H^4(S^2 \times S^2) \cong \ZZ$, i.e. $\pm(\alpha \smile \beta)$.

::: pf-proof

Steps [](#s4){.pf-ref} and [](#s2){.pf-ref}.

:::

:::

::: {.pf-step #s8}

Hence $2ab = \pm 1$, which is impossible for integers $a, b$.

::: pf-proof

Steps [](#s6){.pf-ref} and [](#s7){.pf-ref}; $2ab$ is even, $\pm 1$ is odd.

:::

:::

::: {.pf-step #s9}

Contradiction, so no degree-$1$ map exists.

::: pf-proof

Step [](#s8){.pf-ref}.

:::

:::

::: pf-qed

Step [](#s9){.pf-ref}.

:::

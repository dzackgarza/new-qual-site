::: {.problem}
Show that $\mathbb{CP}^2$ has no orientation reversing self-homeomorphism.
:::

::: {.solution}

::: pf

::: pf-step
$H^*(\mathbb{CP}^2; \ZZ) = \ZZ[x]/(x^3)$ with $|x| = 2$, so $H^4(\mathbb{CP}^2) = \ZZ$ generated by $x^2$.

::: pf-proof
cohomology of $\mathbb{CP}^2$.
:::

:::

::: {.pf-step #fstar-x-is-pm-x}
Let $f : \mathbb{CP}^2 \to \mathbb{CP}^2$ be a homeomorphism; then $f^*(x) = \pm x$.

::: pf-proof
$f^*$ is an isomorphism on $H^2 = \ZZ$.
:::

:::

::: {.pf-step #degree-def}
The degree of $f$ is $d$ where $f^*(x^2) = d x^2$.

::: pf-proof
definition of degree.
:::

:::

::: {.pf-step #fstar-x2-eq-x2}
$f^*(x^2) = f^*(x)^2 = (\pm x)^2 = x^2$.

::: pf-proof
Step [](#fstar-x-is-pm-x){.pf-ref} (squaring kills the sign).
:::

:::

::: {.pf-step #degree-equals-one}
Hence $d = 1$, so $f$ is orientation-preserving.

::: pf-proof
Step [](#degree-def){.pf-ref} and step [](#fstar-x2-eq-x2){.pf-ref}.
:::

:::

::: {.pf-step #no-orientation-reversing}
Therefore $\mathbb{CP}^2$ has no orientation-reversing self-homeomorphism.

::: pf-proof
Step [](#degree-equals-one){.pf-ref}.
:::

:::

::: pf-qed
Step [](#no-orientation-reversing){.pf-ref}.
:::

::: problem
Show that $\mathbb{CP}^2$ has no orientation reversing self-homeomorphism.
:::

::: {.solution}
<1>1. $H^*(\mathbb{CP}^2; \ZZ) = \ZZ[x]/(x^3)$ with $|x| = 2$, so $H^4(\mathbb{CP}^2) = \ZZ$ generated by $x^2$.
Proof: cohomology of $\mathbb{CP}^2$.

<1>2. Let $f : \mathbb{CP}^2 \to \mathbb{CP}^2$ be a homeomorphism; then $f^*(x) = \pm x$.
Proof: $f^*$ is an isomorphism on $H^2 = \ZZ$.

<1>3. The degree of $f$ is $d$ where $f^*(x^2) = d x^2$.
Proof: definition of degree.

<1>4. $f^*(x^2) = f^*(x)^2 = (\pm x)^2 = x^2$.
Proof: <1>2 (squaring kills the sign).

<1>5. Hence $d = 1$, so $f$ is orientation-preserving.
Proof: <1>3 and <1>4.

<1>6. Therefore $\mathbb{CP}^2$ has no orientation-reversing self-homeomorphism.
Proof: <1>5.

<1>7. Q.E.D. Proof: <1>6.
:::

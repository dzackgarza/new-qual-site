::: {.problem}
Show that the following improper Riemann integrals exist and are equal:

$$
\int _ { - \infty } ^ { \infty } { \frac { \sin ( x ) } { x } } d x = \int _ { - \infty } ^ { \infty } { \frac { \sin ^ { 2 } ( x ) } { x ^ { 2 } } } d x
$$
:::

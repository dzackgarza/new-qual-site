::: {.problem}
Find all differentiable functions$f : \mathbb { R } \to \mathbb { R }$with the property that

$$
f ^ { \prime } ( x ) = { \frac { f ( x + h ) - f ( x - h ) } { 2 h } }
$$

for all$x \in \mathbb { R }$and all$h \neq 0$. (Hint: multiply both sides by 2h.)
:::

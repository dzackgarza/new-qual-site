::: {.problem}
Given n distinct points$z _ { j } \in \mathbb { C }$and n values$f _ { j } \in \mathbb { C }$, show that there is a unique polynomial P of degree at most$n - 1$such that

$$
P ( z _ { j } ) = f _ { j }
$$

for$1 \leq j \leq n .$
:::

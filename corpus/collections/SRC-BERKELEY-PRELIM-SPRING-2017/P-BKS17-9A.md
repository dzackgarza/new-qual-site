::: {.problem}
The Bell number$P _ { n }$is the number of partitions of a set of n elements into disjoint nonempty subsets, so for example$\{ 1 , 2 , 3 \} = \{ 1 \} \cup \{ 2 \} \cup \{ 3 \} = \{ 1 , 2 \} \cup \{ 3 \} = \{ 2 , 3 \} \cup \{ 1 \} = \{ 1 , 3 \} \cup \{ 2 \}$and$P _ { 3 } = 5$. Show that

$$
{ \frac { P _ { n } } { n ! } }  0
$$

as$n \to \infty$
:::

::: problem
Let $R = \mathbb{Z}[\sqrt{-6}] = \{a + b\sqrt{-6} \mid a,b \in \mathbb{Z}\}$.
Let $I = (2, \sqrt{-6})$ be the ideal of $R$ generated by $2$ and $\sqrt{-6}$.

(a) Show that $I$ is not a free $R$-module.

(b) Show that $I$ is a flat $R$-module.
:::

::: {.solution}
<1>1. As an additive subgroup of \(R=\mathbb Z\oplus \mathbb Z\sqrt{-6}\),
\[
I=(2,\sqrt{-6})=2\mathbb Z\oplus \mathbb Z\sqrt{-6},
\]
so \([R:I]=2\).
::: {.proof}
Every element of \(I\) has the form \(2r+\sqrt{-6}\,s\) with \(r,s\in R\), hence its integer coefficient is even; conversely \(2\) and \(\sqrt{-6}\) generate every element \(2a+b\sqrt{-6}\). Thus \(R/I\cong \mathbb Z/2\mathbb Z\).
:::

<1>2. If \(I\) were free as an \(R\)-module, then it would be free of rank \(1\), hence principal.
::: {.proof}
Let \(K=\operatorname{Frac}(R)\). Since \(I eq0\) is an ideal in the domain \(R\), \(K\otimes_R I\cong K\), so the rank of \(I\) is \(1\). A finite-rank free module of rank \(1\) is generated by one element.
:::

<1>3. If \(I=(\alpha)\) with \(\alpha=a+b\sqrt{-6}\), then \([R:I]=|N(\alpha)|=a^2+6b^2\).
::: {.proof}
Multiplication by \(\alpha\) on the \(\mathbb Z\)-basis \(1,\sqrt{-6}\) has matrix
\[
\begin{pmatrix}a&-6b\\ b&a\end{pmatrix},
\]
whose determinant is \(a^2+6b^2\). Its image is the principal ideal \((\alpha)\), so its absolute determinant is the additive index.
:::

<1>4. The equation \(a^2+6b^2=2\) has no integer solution, so \(I\) is not principal and therefore is not free.
::: {.proof}
If \(b=0\), then \(a^2=2\), impossible.
If \(b\neq0\), then \(a^2+6b^2\ge6>2\). Combine with <1>1--<1>3.
:::

<1>5. One has \(I^2=(2)\).
::: {.proof}
Since \(I=(2,\sqrt{-6})\),
\[
I^2=(4,\,2\sqrt{-6},\,-6)=2(2,\sqrt{-6},-3).
\]
But \(1=2\cdot2+(-3)\cdot1\) belongs to \((2,\sqrt{-6},-3)\), so that ideal is all of \(R\). Hence \(I^2=(2)\).
:::

<1>6. Thus \(I\) is an invertible fractional ideal, with inverse \( rac12 I\).
::: {.proof}
From <1>5,
\[
I\left(\frac12 I\right)=\frac12 I^2=R.
\]
:::

<1>7. Every invertible ideal is projective, hence flat; therefore \(I\) is flat.
::: {.proof}
Write \(1=\sum_j a_jb_j\) with \(a_j\in I\) and \(b_j\in I^{-1}\). The maps
\[
I\longrightarrow R^n,\qquad x\longmapsto (b_1x,\dots,b_nx),
\]
and
\[
R^n\longrightarrow I,\qquad (r_j)\longmapsto\sum_j r_ja_j
\]
compose to the identity on \(I\). Hence \(I\) is a direct summand of a finite free module, so it is projective.
Projective modules are flat.
:::
:::

::: {.problem}
Suppose $f\in L^1(\RR^n)$ and $f>0$ almost everywhere. Prove that
$$
\abs{\widehat f(y)}<\widehat f(0)
\qquad(y\ne0).
$$
:::

::: {.solution}

The argument is the card's own: the triangle inequality gives $\le$, and equality would force a non-discrete condition that fails on a set of measure zero.

::: pf

::: {.pf-step #bound}

$\abs{\widehat f(y)}\le\widehat f(0)$ for every $y$.

::: pf-proof

$\widehat f(y)=\int f(x)e^{-2\pi ix\cdot y}\,dx$ and $\abs{e^{-2\pi ix\cdot y}}=1$, so $\abs{\widehat f(y)}\le\int\abs{f(x)}\,dx=\int f(x)\,dx=\widehat f(0)$, using $f\ge0$.

:::

:::

::: {.pf-step #equality}

If $\abs{\widehat f(y)}=\widehat f(0)$ then $e^{-2\pi ix\cdot y}=\eta$ for $f\,dx$-almost every $x$, for a single $\eta$ with $\abs{\eta}=1$.

::: pf-proof

Write $\widehat f(y)=\int f(x)e^{-2\pi ix\cdot y}dx$ with $f\ge0$ and $\widehat f(0)=\int f$. Equality in the triangle inequality for a nonnegative measure means the integrand $e^{-2\pi ix\cdot y}$ is $f\,dx$-almost everywhere equal to a constant of modulus $1$: putting $g(x)=e^{-2\pi ix\cdot y}$ and $d\mu=f\,dx$, $\abs{\int g\,d\mu}=\int\abs{g}d\mu$ forces $\int\abs{g-\eta}d\mu=0$ for any $\eta$ of modulus $1$ chosen so that $\eta\int g\,d\mu$ is real and nonnegative, since $\int\abs{g-\eta}^{2}d\mu=2\int d\mu-2\operatorname{Re}\bigl(\bar\eta\int g\,d\mu\bigr)=0$.

:::

:::

::: {.pf-step #nonull}

For $y\ne0$ and any $\eta$ of modulus $1$, $\{x:e^{-2\pi i x\cdot y}=\eta\}$ has Lebesgue measure zero.

::: pf-proof

Choose a vector $u$ with $u\cdot y=1$ and an orthonormal basis with $y/\abs{y}$ as first element. In the corresponding coordinates $x\cdot y=\abs{y}x_{1}$, so the set is $\{x:\abs{y}x_{1}\equiv c\pmod1\}$ for a constant $c$ determined by $\eta$, that is a countable union of hyperplanes $x_{1}=\frac{k+c}{\abs{y}}$, $k\in\ZZ$. Each hyperplane has $(n-1)$-dimensional measure zero in $\RR^{n}$, hence $n$-dimensional measure zero, and a countable union of null sets is null.

:::

:::

::: {.pf-step #strict}

$\abs{\widehat f(y)}<\widehat f(0)$ for $y\ne0$.

::: pf-proof

Suppose equality held for some $y\ne0$. By step [](#equality){.pf-ref} the set $E=\{x:e^{-2\pi ix\cdot y}=\eta\}$ carries the whole measure $f\,dx$, so $\int_{\RR^{n}\setminus E}f=0$; since $f>0$ almost everywhere, $\RR^{n}\setminus E$ has Lebesgue measure zero, so $E$ has full measure. But step [](#nonull){.pf-ref} says $E$ has measure zero. Hence equality cannot hold:
$$
\boxed{\abs{\widehat f(y)}<\widehat f(0)\qquad(y\ne0).}
$$

:::

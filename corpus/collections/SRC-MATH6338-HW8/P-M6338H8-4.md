::: problem
For the Fourier transform on $\mathcal S(\mathbb R)$ with convention
\[
\widehat f(\xi)=\int_{\mathbb R}f(x)e^{-2\pi i x\xi}\,dx,
\]
find all eigenvalues $\lambda$ for which there is a nonzero $f\in\mathcal S(\mathbb R)$ satisfying $\widehat f=\lambda f$.
:::

::: solution
For every Schwartz function,
\[
\widehat{\widehat f}(x)=f(-x),
\]
so applying the Fourier transform four times gives $\mathcal F^4f=f$. If $\widehat f=\lambda f$ with $f\ne0$, then
\[
\lambda^4f=f,
\]
hence $\lambda^4=1$. Thus
\[
\lambda\in\{1,-1,i,-i\}.
\]

All four values occur. The normalized Hermite functions $h_m$ satisfy
\[
\widehat h_m=(-i)^m h_m,
\]
so choosing $m\equiv0,1,2,3\pmod4$ realizes respectively $1,-i,-1,i$.
Therefore the set of eigenvalues is exactly
\[
\boxed{\{1,-1,i,-i\}}.
\]
:::

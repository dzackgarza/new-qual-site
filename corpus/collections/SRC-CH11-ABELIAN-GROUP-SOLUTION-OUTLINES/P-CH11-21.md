::: {.problem}
The set $\{1, 9, 16, 22, 29, 53, 74, 79, 81\}$ is a group under multiplication modulo 91. Determine the isomorphism class of this group.
:::

::: {.solution}
No retained solution set covers this exercise; the argument is the card's own, on the outline's plan. Write $G=\theset{1,9,16,22,29,53,74,79,81}$ with multiplication modulo $91$.

::: pf

::: {.pf-step #abelian}
$G$ is an abelian group of order $9$.

::: pf-proof
The exercise states that $G$ is a group under multiplication modulo $91$; multiplication of residue classes modulo $91$ is commutative, so $G$ is abelian, and the displayed set has nine elements.
:::

:::

::: {.pf-step #dichotomy}
$G\cong\ZZ_{9}$ or $G\cong\ZZ_{3}\oplus\ZZ_{3}$.

::: pf-proof
By the fundamental theorem of finite abelian groups, an abelian group of order $9=3^{2}$ is a direct product of cyclic groups of prime-power order, so it is of the form $\ZZ_{3^{a}}\oplus\ZZ_{3^{b}}$ with $a+b=2$: either $(a,b)=(2,0)$, giving $\ZZ_{9}$, or $(a,b)=(1,1)$, giving $\ZZ_{3}\oplus\ZZ_{3}$.
:::

:::

::: {.pf-step #three-elements}
$G$ has at least three elements of order $3$, namely $9$, $16$ and $22$.

::: pf-proof
Compute modulo $91=7\cdot13$: $9^{2}=81\ne1$ and $9^{3}=729=8\cdot91+1\equiv1$; $16^{2}=256=2\cdot91+74\ne1$ and $16^{3}=1184=13\cdot91+1\equiv1$; $22^{2}=484=5\cdot91+29\ne1$ and $22^{3}=638=7\cdot91+1\equiv1$. In each case the order divides $3$ and is not $1$, so it is $3$.
:::

:::

::: {.pf-step #z9-count}
$\ZZ_{9}$ has exactly two elements of order $3$.

::: pf-proof
An element $x$ of $\ZZ_{9}$ has order dividing $3$ exactly when $3x\equiv0\pmod 9$, that is when $x$ is one of $0,3,6$. Of these, $0$ has order $1$ and $3$ and $6$ have order $3$ since $2\cdot3=6\ne0$ and $3\cdot3=0$ modulo $9$. So there are two.
:::

:::

::: {.pf-step #answer}
$\boxed{G\cong\ZZ_{3}\oplus\ZZ_{3}}$.

::: pf-proof
By step [](#three-elements){.pf-ref} the group $G$ has at least three elements of order $3$, whereas step [](#z9-count){.pf-ref} leaves $\ZZ_{9}$ with only two, so $G\not\cong\ZZ_{9}$; step [](#dichotomy){.pf-ref} then forces $G\cong\ZZ_{3}\oplus\ZZ_{3}$. This is the isomorphism class the exercise asks for.
:::

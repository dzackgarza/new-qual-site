::: {.problem}
Find all the Abelian groups (up to isomorphism) of order 360.
:::

::: {.solution}
The prime factorization is $360 = 2 ^ { 3 } 3 ^ { 2 } 5$. Hence the groups, up to isomorphism, are: $\begin{array} { r } { \ZZ _ { 2 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 5 } , \ \ZZ _ { 2 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 2 } \oplus \ZZ _ { 9 } \oplus \ZZ _ { 5 } , \ \ZZ _ { 2 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 5 } , \ \ZZ _ { 2 } \oplus \ZZ _ { 4 } \oplus \ZZ _ { 9 } \oplus \ZZ _ { 5 } . } \end{array}$ $\ZZ _ { 8 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 3 } \oplus \ZZ _ { 5 } , \ZZ _ { 8 } \oplus \ZZ _ { 9 } \oplus \ZZ _ { 5 }$
:::

::: {.problem}
Let $G = \{ 1 , 7 , 1 7 , 2 3 , 4 9 , 5 5 , 6 5 , 7 1 \}$ under multiplication modulo 96. Express G as an external and an internal direct product of cyclic groups.
:::

::: {.solution}
G has 8 elements, so it is isomorphic to one of $\mathbb { Z } _ { 8 } , \ \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 2 }$ or $\mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ The order of 1 is 1, and there are four elements of order 4 (namely: 7, 23, 55, 71). The remaining three elements (17, 49, 65) have order 2. Since no elements have order 8, and there are elements of order 4, $G \approx \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 2 }$ as an external direct product.
As an internal direct product, G can be expressed as $< 7 > \times < 1 7 >$, since $\langle 7\rangle = \{1,7,49,55\}$ and $\langle 17\rangle = \{1,17\}$ meet trivially and $4 \cdot 2 = 8$. Every element of order 4 squares to $49$, so the order-2 factor must be $\langle 17\rangle$ or $\langle 65\rangle$, not $\langle 49\rangle$.
:::

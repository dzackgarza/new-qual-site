::: {.problem}
Prove that any Abelian group of order 45 has an element of order 15. Does every Abelian group of order 45 have an element of order 9?
:::

::: {.solution}
$45=3^2\cdot5$, so by the fundamental theorem of finite abelian groups there are exactly two abelian groups of order $45$ up to isomorphism, and each is examined separately: the cyclic one has an element of order $15$ and one of order $9$, and the other has an element of order $15$ but none of order $9$. The answer to the second question is therefore no. The collection retains its solution outline as `assets/attachments/Ch11Sltns.pdf`, whose entry "# 5" on PDF p. 1 is this exercise: it names $\ZZ_{45}$ and $\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$ as the abelian groups of order $45$, gives $3$ and $(1,1,1)$ as elements of order $15$, and notes that $5$ has order $9$ in $\ZZ_{45}$ while the second group has no element of order $9$. The card proves the classification from the fundamental theorem and verifies the two order claims; the wording is its own.

::: pf

::: {.pf-step #classify}
Every abelian group of order $45$ is isomorphic to $\ZZ_{45}$ or to $\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$, and these two are not isomorphic.

::: pf-proof
By the fundamental theorem of finite abelian groups an abelian group of order $45=3^2\cdot 5$ is the direct sum of its Sylow $3$-subgroup, of order $9$, and its Sylow $5$-subgroup, of order $5$. A group of order $9=3^2$ is $\ZZ_9$ or $\ZZ_3\oplus\ZZ_3$, and a group of order $5$ is $\ZZ_5$; so the possibilities are $\ZZ_9\oplus\ZZ_5$ and $\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$. Since $\ZZ_9\oplus\ZZ_5\cong\ZZ_{45}$ by the Chinese remainder theorem, as $\gcd(9,5)=1$, the two displayed groups are the complete list. They are not isomorphic, because $\ZZ_{45}$ is cyclic and $\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$ is not: its subgroup of elements of order dividing $3$ is $\ZZ_3\oplus\ZZ_3$, of order $9$, whereas in a cyclic group of order $45$ the elements of order dividing $3$ form the unique subgroup of order $3$.
:::

:::


::: {.pf-step #cyclic}
$\ZZ_{45}$ has an element of order $15$ and an element of order $9$.

::: pf-proof
In $\ZZ_{45}$ the element $\bar3$ has order $45/\gcd(45,3)=15$, and the element $\bar5$ has order $45/\gcd(45,5)=9$.
:::

:::


::: {.pf-step #noncyclic}
$\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$ has an element of order $15$ and no element of order $9$.

::: pf-proof
The element $(1,1,1)$ has order $\operatorname{lcm}(3,3,5)=15$. An element $(x,y,z)$ has order $\operatorname{lcm}(\abs x,\abs y,\abs z)$ with $\abs x,\abs y\in\{1,3\}$ and $\abs z\in\{1,5\}$, so its order divides $\operatorname{lcm}(3,5)=15$ and is therefore never $9$.
:::

:::


::: {.pf-step #conclusion}
Every abelian group of order $45$ has an element of order $15$, and not every one has an element of order $9$.

::: pf-proof
By step [](#classify){.pf-ref} the two groups listed exhaust the abelian groups of order $45$ up to isomorphism, and steps [](#cyclic){.pf-ref} and [](#noncyclic){.pf-ref} give an element of order $15$ in each. The second question is answered negatively by the second group, which has no element of order $9$: an element of order $9$ in $\ZZ_3\oplus\ZZ_3\oplus\ZZ_5$ would generate a cyclic subgroup of order $9$, hence an element of order $9$ in the $3$-part $\ZZ_3\oplus\ZZ_3$, where every nonzero element has order $3$.
:::

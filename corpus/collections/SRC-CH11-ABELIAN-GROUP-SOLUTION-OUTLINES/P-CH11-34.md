::: {.problem}
Let $G$ be the group of all $n\times n$ diagonal matrices with $\pm1$ diagonal entries. What is the isomorphism class of $G$?
:::

::: {.solution}
$\mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 } \oplus . . . \mathbb { Z } _ { 2 }$ , n terms
:::

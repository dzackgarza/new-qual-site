::: {.problem}
Let $G$ be the group of all $n\times n$ diagonal matrices with $\pm1$ diagonal entries.
What is the isomorphism class of $G$?
:::

::: {.solution}

Let $G$ be the group of all $n\times n$ diagonal matrices with diagonal
entries in $\{\pm1\}$, under matrix multiplication. Since a diagonal matrix
has zero entries off the diagonal and the product of diagonal matrices is
diagonal with entrywise products, $G$ is the direct product of $n$ copies of
the two-element group $\{\pm1\}$ under multiplication, which is isomorphic to
$\ZZ_2$.

::: pf

::: {.pf-step #order}

$\abs G=2^n$, and every nonidentity element of $G$ has order $2$.

::: pf-proof

A diagonal matrix with entries in $\{\pm1\}$ is determined by the $n$-tuple of
its diagonal entries, so $\abs G=2^n$. If $D$ has diagonal entries
$d_i\in\{\pm1\}$ then $D^2$ has diagonal entries $d_i^2=1$, so $D^2=I$; hence
the order of $D$ is $1$ if $D=I$ and $2$ otherwise.

:::

:::

::: {.pf-step #isomorphism}

$G\cong\ZZ_2\oplus\cdots\oplus\ZZ_2$ with $n$ summands.

::: pf-proof

The map $\ZZ_2^n\to G$ sending $(a_1,\dots,a_n)$ to the diagonal matrix with
entries $(-1)^{a_i}$ is well defined because $a_i$ is taken mod $2$ and
$(-1)^{a_i}$ depends only on $a_i$ mod $2$; it is a homomorphism because the
diagonal entries multiply and exponents add; it is injective because the sign
vector determines the matrix; and it is surjective because every diagonal sign
matrix arises this way. So $G$ is the external direct product of $n$ copies of
$\ZZ_2$. The same conclusion follows from the classification of finite abelian
groups: an abelian group of order $2^n$ all of whose nonidentity elements have
order $2$ is elementary abelian and hence is $\ZZ_2^n$, which is the chapter's
Theorem 11.1 read for this group.

:::

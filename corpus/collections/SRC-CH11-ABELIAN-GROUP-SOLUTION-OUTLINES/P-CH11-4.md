::: {.problem}
Calculate the number of elements of order 2 in each of $\ZZ_{16}$, $\ZZ_{8} \oplus \ZZ_{2}$, $\ZZ_{4} \oplus \ZZ_{4}$ and $\ZZ_{4} \oplus \ZZ_{2} \oplus \ZZ_{2}$. Do the same for the elements of order 4.
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines and no retained solution set accompanies the printed exercise. For a finite abelian group $G$ write
$$
G[d]=\{x\in G:dx=0\},
$$
the subgroup of elements killed by $d$.

::: pf

::: {.pf-step #principle}
The elements of order exactly $2$ are $G[2]\setminus\{0\}$, and if $G$ has exponent dividing $4$ the elements of order exactly $4$ are $G[4]\setminus G[2]$.

::: pf-proof
An element has order dividing $d$ exactly when $dx=0$, so the elements of order exactly $2$ are those killed by $2$ and not the identity. If the exponent divides $4$, every element has order $1,2$ or $4$; those of order $1$ or $2$ are precisely the elements killed by $2$, and removing them from $G[4]$ leaves the elements of order exactly $4$. The sets $G[d]$ are subgroups because $G$ is abelian: $d(x+y)=dx+dy$ and $d(-x)=-dx$.
:::

:::

::: {.pf-step #counts}
In the four groups,
$$
\#G[2]=2,\,4,\,4,\,8\quad\text{and}\quad\#G[4]=4,\,8,\,16,\,16
$$
for $\ZZ_{16}$, $\ZZ_8\oplus\ZZ_2$, $\ZZ_4\oplus\ZZ_4$, $\ZZ_4\oplus\ZZ_2\oplus\ZZ_2$ respectively.

::: pf-proof
Count coordinate by coordinate, using that $dx=0$ in $\ZZ_m$ has exactly $\gcd(d,m)$ solutions. $\ZZ_{16}$: $\#G[2]=\gcd(2,16)=2$ and $\#G[4]=\gcd(4,16)=4$. $\ZZ_8\oplus\ZZ_2$: $\#G[2]=2\cdot2=4$ and $\#G[4]=4\cdot2=8$. $\ZZ_4\oplus\ZZ_4$: $\#G[2]=2\cdot2=4$ and $\#G[4]=4\cdot4=16$. $\ZZ_4\oplus\ZZ_2\oplus\ZZ_2$: $\#G[2]=2\cdot2\cdot2=8$ and $\#G[4]=4\cdot2\cdot2=16$.
:::

:::

::: {.pf-step #table}
The numbers of elements of order $2$ and of order $4$ are
$$
1,2;\qquad 3,4;\qquad 3,12;\qquad 7,8
$$
in the same order.

::: pf-proof
Apply step [](#principle){.pf-ref} to the counts of step [](#counts){.pf-ref}. $\ZZ_{16}$: order $2$ gives $2-1=1$, order $4$ gives $4-2=2$. $\ZZ_8\oplus\ZZ_2$: $4-1=3$ and $8-4=4$. $\ZZ_4\oplus\ZZ_4$: $4-1=3$ and $16-4=12$. $\ZZ_4\oplus\ZZ_2\oplus\ZZ_2$: $8-1=7$ and $16-8=8$. These reproduce the four rows of the card's table.
:::

:::

::: {.pf-step #cyclic}
For the cyclic group the entries are $\varphi(2)=1$ and $\varphi(4)=2$.

::: pf-proof
In $\ZZ_{16}$ the elements of order exactly $d$ are those $a$ with $\gcd(a,16)=16/d$, of which there are $\varphi(d)$: for $d=2$, $\varphi(2)=1$; for $d=4$, $\varphi(4)=2$. This agrees with step [](#table){.pf-ref}, which is a check on the counting rather than a new fact.
:::

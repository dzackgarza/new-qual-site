::: {.problem}
Calculate the number of elements of order 2 in each of $\mathbb { Z } _ { 1 6 } , \ \mathbb { Z } _ { 8 } \oplus \mathbb { Z } _ { 2 } , \ \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 4 }$ and $\mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ . Do the same for the elements of order 4.
:::

:::

::: {.problem}
Calculate the number of elements of order 2 in each of $\ZZ_{16}$, $\ZZ_{8} \oplus \ZZ_{2}$, $\ZZ_{4} \oplus \ZZ_{4}$ and $\ZZ_{4} \oplus \ZZ_{2} \oplus \ZZ_{2}$. Do the same for the elements of order 4.
:::

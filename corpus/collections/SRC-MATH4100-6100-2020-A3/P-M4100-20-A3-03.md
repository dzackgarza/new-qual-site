::: {.problem}
A real number is called algebraic if it is a root of a nonzero polynomial with integer coefficients.

(a) Show that
\[
\sqrt2,
\qquad
\sqrt[3]{2},
\qquad
\sqrt2+\sqrt3
\]
are algebraic.

(b) Prove that the set of all algebraic real numbers is countable. What does this imply about the set of transcendental real numbers?

Hint: first show that, for each fixed degree $n$, the set of integer-coefficient polynomials of degree $n$ is countable.
:::

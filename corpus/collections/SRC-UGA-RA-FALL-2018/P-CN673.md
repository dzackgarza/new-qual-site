::: {.problem}
Let $f \in L^1([0, 1])$. Prove that
$$
\lim_{n \to \infty} \int_0^1 f(x) \abs{\sin(nx)} \, dx = \frac{2}{\pi} \int_0^1 f(x) \, dx.
$$
Hint: begin with the case in which $f$ is the characteristic function of an interval.
:::

::: {.solution}
**Goal:** Prove the generalized Riemann–Lebesgue lemma for $\abs{\sin(nx)}$ by establishing the result for interval indicator functions and extending to $L^1([0, 1])$ by density.

::: pf

::: pf-step
Step 1: Characteristic functions of intervals $f = \chi_{[a, b]}$ with $0 \le a \le b \le 1$.

::: pf-proof

::: pf-step
Substitute $u = n x$ ($d x = \frac{1}{n} d u$):
$$\int_0^1 \chi_{[a, b]}(x) \abs{\sin(nx)} \, dx = \int_a^b \abs{\sin(nx)} \, dx = \frac{1}{n} \int_{na}^{nb} \abs{\sin u} \, du.$$

:::

::: pf-step
The function $\abs{\sin u}$ is periodic with period $\pi$, and its integral over one period is
$$\int_0^\pi \abs{\sin u} \, du = \int_0^\pi \sin u \, du = [-\cos u]_0^\pi = 2.$$

:::

::: pf-step
Let $K = \left\lfloor \frac{n(b - a)}{\pi} \right\rfloor \in \NN$ be the number of full periods contained in $[na, nb]$.

:::

::: pf-step
The interval $[na, nb]$ decomposes as $K$ full periods of length $\pi$ plus a remainder interval $J_n$ of length $m(J_n) = n(b - a) - K \pi \in [0, \pi)$:
$$\int_{na}^{nb} \abs{\sin u} \, du = \sum_{j=1}^K \int_{(j-1)\pi}^{j\pi} \abs{\sin u} \, du + \int_{J_n} \abs{\sin u} \, du = 2 K + R_n,$$
where $0 \le R_n = \int_{J_n} \abs{\sin u} \, du \le m(J_n) \cdot 1 < \pi$.

:::

::: pf-step
Divide by $n$:
$$\int_a^b \abs{\sin(nx)} \, dx = \frac{2 K}{n} + \frac{R_n}{n}.$$

:::

::: pf-step
Since $\frac{n(b - a)}{\pi} - 1 < K \le \frac{n(b - a)}{\pi}$, multiplying by $\frac{2}{n}$ gives
$$\frac{2(b - a)}{\pi} - \frac{2}{n} < \frac{2 K}{n} \le \frac{2(b - a)}{\pi}.$$

:::

::: pf-step
Taking $n \to \infty$, $\lim_{n \to \infty} \frac{2 K}{n} = \frac{2(b - a)}{\pi}$.

:::

::: pf-step
Since $0 \le \frac{R_n}{n} < \frac{\pi}{n} \to 0$, we obtain
$$\lim_{n \to \infty} \int_0^1 \chi_{[a, b]}(x) \abs{\sin(nx)} \, dx = \frac{2(b - a)}{\pi} = \frac{2}{\pi} \int_0^1 \chi_{[a, b]}(x) \, dx.$$

:::

:::

:::

::: {.pf-step #s2}
Step 2: Step functions (linear combinations of interval indicators).

::: pf-proof

::: pf-step
Let $\psi = \sum_{j=1}^m c_j \chi_{[a_j, b_j]}$ be a step function on $[0, 1]$, where $c_j \in \RR$ and $[a_j, b_j] \subseteq [0, 1]$.

:::

::: pf-step
By the linearity of integration and limits:
$$\lim_{n \to \infty} \int_0^1 \psi(x) \abs{\sin(nx)} \, dx = \sum_{j=1}^m c_j \lim_{n \to \infty} \int_0^1 \chi_{[a_j, b_j]}(x) \abs{\sin(nx)} \, dx = \sum_{j=1}^m c_j \frac{2}{\pi} \int_0^1 \chi_{[a_j, b_j]}(x) \, dx = \frac{2}{\pi} \int_0^1 \psi(x) \, dx.$$

:::

:::

:::

::: pf-step
Step 3: Arbitrary $f \in L^1([0, 1])$ by density.

::: pf-proof

::: pf-step
Let $\varepsilon > 0$.

:::

::: pf-step
Since the set of step functions is dense in $L^1([0, 1])$, choose a step function $\psi$ such that
$$\norm{f - \psi}_{L^1} < \frac{\varepsilon}{3}.$$

:::

::: pf-step
For any $n \in \NN$, bound the difference using $\abs{\sin(nx)} \le 1$:
$$\abs{ \int_0^1 f(x) \abs{\sin(nx)} \, dx - \int_0^1 \psi(x) \abs{\sin(nx)} \, dx } \le \int_0^1 \abs{f(x) - \psi(x)} \abs{\sin(nx)} \, dx \le \norm{f - \psi}_{L^1} < \frac{\varepsilon}{3}.$$

:::

::: pf-step
Bound the difference between the limits:
$$\abs{ \frac{2}{\pi} \int_0^1 \psi(x) \, dx - \frac{2}{\pi} \int_0^1 f(x) \, dx } \le \frac{2}{\pi} \norm{f - \psi}_{L^1} < \frac{2}{3\pi} \varepsilon < \frac{\varepsilon}{3}.$$

:::

::: pf-step
By Step 2 (step [](#s2){.pf-ref}), choose $N \in \NN$ such that for all $n \ge N$:
$$\abs{ \int_0^1 \psi(x) \abs{\sin(nx)} \, dx - \frac{2}{\pi} \int_0^1 \psi(x) \, dx } < \frac{\varepsilon}{3}.$$

:::

::: pf-step
For all $n \ge N$, by the triangle inequality:
$$\begin{aligned}
\abs{ \int_0^1 f(x) \abs{\sin(nx)} \, dx - \frac{2}{\pi} \int_0^1 f(x) \, dx } &\le \abs{ \int_0^1 (f - \psi) \abs{\sin(nx)} \, dx } \\
&\quad + \abs{ \int_0^1 \psi \abs{\sin(nx)} \, dx - \frac{2}{\pi} \int_0^1 \psi \, dx } \\
&\quad + \abs{ \frac{2}{\pi} \int_0^1 (\psi - f) \, dx } \\
&< \frac{\varepsilon}{3} + \frac{\varepsilon}{3} + \frac{\varepsilon}{3} = \varepsilon.
\end{aligned}$$

:::

::: pf-step
Since $\varepsilon > 0$ was arbitrary:
$$\lim_{n \to \infty} \int_0^1 f(x) \abs{\sin(nx)} \, dx = \frac{2}{\pi} \int_0^1 f(x) \, dx.$$

:::

:::

:::

::: pf-step
Conclusion:

::: pf-proof
The limit holds for all $f \in L^1([0, 1])$.
:::

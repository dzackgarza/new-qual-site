::: {.problem}
1. Let $G$ be a group of order $n$.
   Suppose that for every divisor $d$ of $n$, $G$ contains at most one subgroup of order $d$.
   Show that $G$ is cyclic.

2. Let $F$ be a field.
   Show that every finite subgroup of the group of units $F^\times$ is cyclic.
:::

::: {.solution}
**Part 1.**

::: pf

::: pf-step
For each divisor $d$ of $n$, let $a_d$ be the number of elements of $G$ of order exactly $d$.

::: pf-proof
This is a definition.
:::

:::

::: pf-step
If $G$ has an element of order $d$, then it has a cyclic subgroup of order $d$, which (by hypothesis) is the unique subgroup of order $d$.

::: pf-proof
The subgroup generated by an element of order $d$ has order $d$.
:::

:::

::: pf-step
A cyclic group of order $d$ has exactly $\varphi(d)$ elements of order $d$.

::: pf-proof
If $g$ generates a cyclic group of order $d$, then $g^k$ has order $d/\gcd(k,d)$, which equals $d$ exactly when $\gcd(k,d)=1$. There are $\varphi(d)$ such $k$ with $0\le k<d$.
:::

:::

::: {.pf-step #a-d-in-0-or-phi-d}
Hence $a_d \in \{0, \varphi(d)\}$ for each $d$.

::: pf-proof
If there is no element of order $d$, then $a_d = 0$; if there is one, then the unique subgroup of order $d$ is cyclic and contains all $\varphi(d)$ elements of order $d$, so $a_d = \varphi(d)$.
:::

:::

::: {.pf-step #n-equals-sum-a-d}
$n = \sum_{d \mid n} a_d \le \sum_{d \mid n} \varphi(d) = n$.

::: pf-proof
By Lagrange's theorem every element has order dividing $n$; and $\sum_{d \mid n} \varphi(d) = n$.
:::

:::

::: {.pf-step #a-d-equals-phi-d}
Hence $a_d = \varphi(d)$ for every $d \mid n$.

::: pf-proof
Steps [](#a-d-in-0-or-phi-d){.pf-ref} and [](#n-equals-sum-a-d){.pf-ref} force equality term-by-term.
:::

:::

::: pf-step
In particular, $a_n = \varphi(n) > 0$, so $G$ has an element of order $n$.

::: pf-proof
Step [](#a-d-equals-phi-d){.pf-ref} with $d = n$.
:::

:::

::: {.pf-step #g-is-cyclic-part1}
Therefore $G$ is cyclic.

::: pf-proof
An element of order $n$ generates a subgroup of order $n=|G|$, which is $G$.
:::

:::

:::

**Part 2.**

::: pf

::: pf-step
Let $H \le F^\times$ be a finite subgroup of order $n$.

::: pf-proof
This introduces notation.
:::

:::

::: {.pf-step #at-most-one-subgroup-per-order-in-h}
For each divisor $d$ of $n$, $H$ has at most one subgroup of order $d$.

::: pf-proof
The elements of $H$ of order dividing $d$ are roots of the polynomial $x^d - 1$ in the field $F$, and a polynomial of degree $d$ over a field has at most $d$ roots; hence there are at most $d$ such elements, so at most one subgroup of order $d$.
:::

:::

::: {.pf-step #h-is-cyclic}
Hence $H$ is cyclic by part 1.

::: pf-proof
Step [](#at-most-one-subgroup-per-order-in-h){.pf-ref} and part 1.
:::

:::

:::

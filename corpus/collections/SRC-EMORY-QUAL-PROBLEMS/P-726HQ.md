::: {.problem}
State the Riemann mapping theorem and prove the uniqueness part.
:::

::: {.solution}
### Statement of the Riemann Mapping Theorem

**Theorem (Riemann Mapping Theorem):** Let $\Omega \subsetneq \mathbb{C}$ be a non-empty simply connected domain (open connected subset), and let $z_0 \in \Omega$ be an arbitrary fixed point.
Then there exists a unique biholomorphic (conformal bijection) mapping $f: \Omega \to \mathbb{D}$ (where $\mathbb{D} = \{z \in \mathbb{C} : |z| < 1\}$ is the open unit disk) such that: $$f(z_0) = 0 \quad \text{and} \quad f'(z_0) > 0.$$

* * *

### Proof of the Uniqueness Part

::: pf

::: pf-step

**Set up the comparison between two such Riemann mappings.**

::: pf-proof

::: pf-step

Suppose $f_1, f_2: \Omega \to \mathbb{D}$ are two biholomorphic mappings satisfying the normalization conditions: $$f_1(z_0) = 0, \quad f_1'(z_0) > 0, \qquad f_2(z_0) = 0, \quad f_2'(z_0) > 0.$$

::: pf-proof

This is the hypothesis of the uniqueness assertion.

:::

:::

::: pf-step

Define $g: \mathbb{D} \to \mathbb{D}$ by $g = f_1 \circ f_2^{-1}$.

::: pf-proof

Well-defined because $f_2: \Omega \to \mathbb{D}$ is biholomorphic, so its inverse $f_2^{-1}: \mathbb{D} \to \Omega$ exists and is biholomorphic.

:::

:::

:::

:::

::: pf-step

**$g$ is an automorphism of the unit disk fixing the origin.**

::: pf-proof

::: pf-step

$g$ is a composition of two biholomorphisms ($f_1$ and $f_2^{-1}$), hence $g \in \text{Aut}(\mathbb{D})$.

::: pf-proof

The set of biholomorphic self-maps $\text{Aut}(\mathbb{D})$ is a group under composition.

:::

:::

::: pf-step

$g(0) = f_1(f_2^{-1}(0)) = f_1(z_0) = 0$.

::: pf-proof

$f_2(z_0) = 0 \implies f_2^{-1}(0) = z_0$, and $f_1(z_0) = 0$.

:::

:::

:::

:::

::: pf-step

**By the Schwarz Lemma, $g$ is a pure rotation.**

::: pf-proof

::: {.pf-step #s3-1}

Any holomorphic map $g: \mathbb{D} \to \mathbb{D}$ with $g(0) = 0$ that is bijective (an automorphism) is of the form $g(w) = e^{i\theta} w$ for some constant $\theta \in \mathbb{R}$.

::: pf-proof

By the Schwarz Lemma, $|g'(0)| \leq 1$ and $|(g^{-1})'(0)| \leq 1$.
By the chain rule, $g'(0) \cdot (g^{-1})'(0) = 1$, so $|g'(0)| = 1$.
The equality case of the Schwarz Lemma implies $g(w) = e^{i\theta} w$.

:::

:::

::: pf-step

Therefore, $g(w) = e^{i\theta} w$ for all $w \in \mathbb{D}$.

::: pf-proof

Follows from step [](#s3-1){.pf-ref}.

:::

:::

:::

:::

::: pf-step

**Determine the angle $\theta$ using the derivative normalization.**

::: pf-proof

::: {.pf-step #s4-1}

Differentiating $g(w) = e^{i\theta} w$ gives $g'(0) = e^{i\theta}$.

::: pf-proof

Derivative of linear function.

:::

:::

::: {.pf-step #s4-2}

By the chain rule on $g(w) = f_1(f_2^{-1}(w))$ at $w=0$: $$g'(0) = f_1'(f_2^{-1}(0)) \cdot (f_2^{-1})'(0) = f_1'(z_0) \cdot \frac{1}{f_2'(z_0)} = \frac{f_1'(z_0)}{f_2'(z_0)}.$$

::: pf-proof

Inverse function theorem derivative rule $(f_2^{-1})'(0) = \frac{1}{f_2'(z_0)}$.

:::

:::

::: pf-step

Since $f_1'(z_0) > 0$ and $f_2'(z_0) > 0$, the ratio $\frac{f_1'(z_0)}{f_2'(z_0)}$ is a strictly positive real number: $$\frac{f_1'(z_0)}{f_2'(z_0)} > 0.$$

::: pf-proof

Quotient of two positive real numbers.

:::

:::

::: pf-step

From steps [](#s4-1){.pf-ref} and [](#s4-2){.pf-ref}, $e^{i\theta} = \frac{f_1'(z_0)}{f_2'(z_0)} \in (0, \infty)$.
Since $|e^{i\theta}| = 1$, we must have $e^{i\theta} = 1$.

::: pf-proof

The only positive real number on the unit circle is $1$.

:::

:::

:::

:::

::: pf-step

**Conclusion: $f_1 = f_2$.**

::: pf-proof

::: pf-step

Since $e^{i\theta} = 1$, $g(w) = w$ for all $w \in \mathbb{D}$, which means $g = \text{id}_{\mathbb{D}}$.

::: pf-proof

Substitution of $e^{i\theta} = 1$ into $g(w) = e^{i\theta} w$.

:::

:::

::: pf-step

$f_1 \circ f_2^{-1} = \text{id}_{\mathbb{D}} \implies f_1(z) = f_2(z)$ for all $z \in \Omega$.

::: pf-proof

Composing both sides with $f_2$ on the right.

:::

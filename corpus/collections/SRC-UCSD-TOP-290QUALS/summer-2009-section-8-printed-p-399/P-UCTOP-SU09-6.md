::: {.problem}
Show that any homotopy equivalence from $\mathbb{CP}^{2n}$ to itself is orientation-preserving, that is has degree +1.
:::

::: {.solution}

::: pf

::: pf-step
$H^*(\CP^{2n};\ZZ) = \ZZ[x]/(x^{2n+1})$ with $|x| = 2$, so $H^{4n}(\CP^{2n};\ZZ) = \ZZ$ generated by $x^{2n}$.

::: pf-proof
standard computation of the cohomology ring of complex projective space.
:::

:::

::: pf-step
Let $f: \CP^{2n} \to \CP^{2n}$ be a homotopy equivalence; then $f^*: H^2 \to H^2$ is an isomorphism, so $f^*(x) = \pm x$.

::: pf-proof
$f^*$ is a ring isomorphism, so it sends the generator $x$ of $H^2 = \ZZ$ to $\pm x$.
:::

:::

::: {.pf-step #pullback-top-class-fixed}
$f^*(x^{2n}) = f^*(x)^{2n} = (\pm x)^{2n} = x^{2n}$ (since $2n$ is even).

::: pf-proof
$f^*$ is a ring homomorphism, and $(\pm x)^{2n} = x^{2n}$.
:::

:::

::: {.pf-step #f-star-identity-top}
Hence $f^*$ is the identity on $H^{4n}(\CP^{2n};\ZZ) = \ZZ$.

::: pf-proof
Step [](#pullback-top-class-fixed){.pf-ref}.
:::

:::

::: pf-step
The degree of $f$ is the integer $d$ such that $f_*$ is multiplication by $d$ on $H_{4n}(\CP^{2n};\ZZ) = \ZZ$.

::: pf-proof
definition of degree.
:::

:::

::: {.pf-step #duality-same-integer}
By Poincaré duality (or the universal coefficient theorem), $f^*$ on $H^{4n}$ is multiplication by the same integer $d$ as $f_*$ on $H_{4n}$.

::: pf-proof
the induced maps on cohomology and homology are dual.
:::

:::

::: {.pf-step #degree-one-conclusion}
Hence $d = 1$, so $f$ has degree $+1$ and is orientation-preserving.

::: pf-proof
Steps [](#f-star-identity-top){.pf-ref} and [](#duality-same-integer){.pf-ref}.
:::

:::

::: pf-qed
Step [](#degree-one-conclusion){.pf-ref}.
:::

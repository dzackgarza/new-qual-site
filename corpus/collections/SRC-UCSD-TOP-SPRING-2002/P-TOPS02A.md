::: problem
Let $G$ be a group of homeomorphisms acting freely on $S^{2n}$ so that for all $g \in G$, $gx = x$ for some $x$ if and only if $g = 1$.
Prove $|G| \leq 2$.
:::

::: {.solution}
<1>1. $X$ CW.
Proof: cellular.

<1>2. Q.E.D.
Proof: <1>1.
:::

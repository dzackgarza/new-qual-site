::: {.problem}
Let $i:S^n\to S^n$ be the antipodal map.
Call a differential form $\omega$ invariant if $i^*\omega=\omega$, and let $H^*(S^n)^I$ denote the cohomology of the invariant subcomplex.

1. Show that
   \[
   H^*(\RP^n)\cong H^*(S^n)^I.
   \]

2. You may assume that the natural map $H^*(S^n)^I\to H^*(S^n)$ is injective.

3. Show that the antipodal map is orientation-preserving if and only if $n$ is odd.
   Deduce that if $[\sigma]$ generates $H^n(S^n)$, then $[\sigma]$ is invariant if and only if $n$ is odd.

4. Compute the de Rham cohomology of $\RP^n$, showing that
   \[
   H^q(\RP^n)\cong
   \begin{cases}
   \RR,&q=0,\\
   \RR,&q=n\text{ and }n\text{ is odd},\\
   0,&\text{otherwise}.
   \end{cases}
   \]
:::

::: {.solution}

Let
\[
p:S^n\to\RP^n
\]
be the quotient map.
Its deck group is
\[
\{\operatorname{id},i\}.
\]

::: pf

::: {.pf-step #s1-1}

For every differential form
\[
\alpha\in\Omega^q(\RP^n),
\]
the pullback
\[
p^*\alpha
\]
is antipodal-invariant.


::: pf-proof

Because
\[
p\circ i
=
p,
\]
one has
\[
i^*(p^*\alpha)
=
(p\circ i)^*\alpha
=
p^*\alpha.
\]
Thus
\[
p^*\alpha
\in
\Omega^q(S^n)^I.
\]

:::

:::

::: {.pf-step #s1-2}

The pullback map
\[
p^*:
\Omega^q(\RP^n)
\to
\Omega^q(S^n)^I
\]
is injective.


::: pf-proof

The covering map $p$ is a local diffeomorphism and is surjective.
Suppose
\[
p^*\alpha=0.
\]
Fix
\[
x\in\RP^n.
\]
Choose
\[
\widetilde x\in S^n
\]
with
\[
p(\widetilde x)=x.
\]
There are neighborhoods
\[
\widetilde U\ni\widetilde x,
\qquad
U\ni x
\]
such that
\[
p|_{\widetilde U}:
\widetilde U\xrightarrow{\cong}U
\]
is a diffeomorphism.
On $U$,
\[
\alpha
=
\bigl(
(p|_{\widetilde U})^{-1}
\bigr)^*
(p^*\alpha|_{\widetilde U})
=
0.
\]
Since $x$ was arbitrary,
\[
\alpha=0.
\]

:::

:::

::: {.pf-step #s1-3}

Every invariant form
\[
\omega\in\Omega^q(S^n)^I
\]
descends uniquely to a form
\[
\alpha\in\Omega^q(\RP^n)
\]
such that
\[
p^*\alpha=\omega.
\]


::: pf-proof

Let
\[
x\in\RP^n.
\]
Choose an evenly covered neighborhood
\[
U
\]
of $x$ and one sheet
\[
\widetilde U
\subseteq
p^{-1}(U).
\]
Define on $U$
\[
\alpha_U
\coloneqq
\bigl(
(p|_{\widetilde U})^{-1}
\bigr)^*
(\omega|_{\widetilde U}).
\]

If the other sheet
\[
i(\widetilde U)
\]
is chosen instead, then invariance
\[
i^*\omega=\omega
\]
shows that the resulting form on $U$ is identical.
Hence the local descended form does not depend on the sheet.

On overlaps of evenly covered neighborhoods, both local definitions pull
back to the same form
\[
\omega
\]
upstairs.
Injectivity of pullback on each local diffeomorphism therefore makes them
agree.
Thus the local forms glue to a global form
\[
\alpha
\]
with
\[
p^*\alpha=\omega.
\]

Uniqueness follows from step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-4}

Therefore
\[
\boxed{
p^*:
\Omega^*(\RP^n)
\xrightarrow{\cong}
\Omega^*(S^n)^I
}
\]
is an isomorphism of cochain complexes.


::: pf-proof

Steps [](#s1-1){.pf-ref} through [](#s1-3){.pf-ref} give bijectivity.
Pullback commutes with exterior differentiation:
\[
d(p^*\alpha)
=
p^*(d\alpha).
\]
Thus the isomorphism respects the differentials.

:::

:::

::: {.pf-step #s1-5}

Passing to cohomology gives
\[
\boxed{
H^*(\RP^n)
\cong
H^*(S^n)^I.
}
\]


::: pf-proof

Isomorphic cochain complexes have isomorphic cohomology.
Apply step [](#s1-4){.pf-ref}.

:::

:::

::: {.pf-step #s1-6}

The antipodal map
\[
i:S^n\to S^n,
\qquad
i(x)=-x,
\]
has degree
\[
\boxed{
\deg i
=
(-1)^{n+1}.
}
\]


::: pf-proof

The antipodal map is the restriction to $S^n$ of the linear map
\[
-I:
\RR^{n+1}
\to
\RR^{n+1}.
\]
Its determinant is
\[
\det(-I)
=
(-1)^{n+1}.
\]
For the induced map on the boundary sphere, this sign is the degree of the
antipodal map.
Equivalently, one may use the standard formula
\[
\deg(-\operatorname{id}_{S^n})
=
(-1)^{n+1}.
\]

:::

:::

::: {.pf-step #s1-7}

Hence the antipodal map is orientation-preserving if and only if
\[
n
\]
is odd.


::: pf-proof

A self-map of the oriented sphere preserves orientation exactly when its
degree is
\[
+1.
\]
By step [](#s1-6){.pf-ref},
\[
(-1)^{n+1}=1
\]
exactly when
\[
n+1
\]
is even, i.e. when
\[
n
\]
is odd.

:::

:::

::: {.pf-step #s1-8}

Let
\[
[\sigma]
\]
generate
\[
H^n(S^n;\RR)
\cong
\RR.
\]
Then
\[
i^*[\sigma]
=
(-1)^{n+1}[\sigma].
\]


::: pf-proof

On top cohomology, a self-map acts by multiplication by its degree.
Apply step [](#s1-6){.pf-ref}.

:::

:::

::: {.pf-step #s1-9}

Therefore
\[
[\sigma]
\]
is invariant if and only if
\[
n
\]
is odd.


::: pf-proof

Invariance means
\[
i^*[\sigma]
=
[\sigma].
\]
By step [](#s1-8){.pf-ref}, this is equivalent to
\[
(-1)^{n+1}=1,
\]
which by step [](#s1-7){.pf-ref} is equivalent to odd $n$.

:::

:::

::: {.pf-step #s1-10}

By the assumed injectivity
\[
H^q(S^n)^I
\hookrightarrow
H^q(S^n),
\]
the invariant cohomology can be nonzero only in degrees
\[
q=0
\quad\text{and}\quad
q=n.
\]


::: pf-proof

The de Rham cohomology of the sphere is
\[
H^q(S^n;\RR)
\cong
\begin{cases}
\RR,&q=0,n,\\
0,&\text{otherwise}.
\end{cases}
\]
If the natural map from invariant cohomology is injective, then an
invariant cohomology group in a degree where the sphere cohomology vanishes
must itself vanish.

:::

:::

::: {.pf-step #s1-11}

In degree
\[
0,
\]
\[
H^0(S^n)^I
\cong
\RR.
\]


::: pf-proof

Degree-zero cohomology of the connected sphere consists of constant
functions.
Constants are antipodal-invariant.

:::

:::

::: {.pf-step #s1-12}

In degree
\[
n,
\]
\[
H^n(S^n)^I
\cong
\begin{cases}
\RR,&n\text{ odd},\\
0,&n\text{ even}.
\end{cases}
\]


::: pf-proof

The ambient group
\[
H^n(S^n)
\]
is one-dimensional, generated by
\[
[\sigma].
\]
By step [](#s1-9){.pf-ref}, the generator is invariant exactly for odd $n$.
For even $n$, $i^*$ acts by
\[
-1,
\]
so the only invariant vector in this one-dimensional real vector space is
zero.

:::

:::

::: {.pf-step #s1-13}

Combining with step [](#s1-5){.pf-ref},
\[
\boxed{
H^q(\RP^n;\RR)
\cong
\begin{cases}
\RR,
&q=0,\\
\RR,
&q=n\text{ and }n\text{ odd},\\
0,
&\text{otherwise}.
\end{cases}
}
\]


::: pf-proof

Step [](#s1-5){.pf-ref} identifies the de Rham cohomology of
\[
\RP^n
\]
with invariant cohomology upstairs.
Steps [](#s1-10){.pf-ref} through [](#s1-12){.pf-ref} compute those invariant groups.

:::

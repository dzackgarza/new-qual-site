::: {.problem}
Suppose a continuous multiplication on $\mathbb R^n$ makes it a real division algebra.
Write $e_i$ for the $i$th standard basis vector.

1. For $p\in S^{n-1}\subset\mathbb R^n$, show that there is a unique $a\in\mathbb R^n$ such that
   \[
   p=ae_1.
   \]

2. If $b\in\mathbb R^n$ is nonzero, show that
   \[
   be_1,\ldots,be_n
   \]
   are linearly independent.

3. For $p=ae_1$ as above, orthogonally project $ae_2,\ldots,ae_n$ to $T_pS^{n-1}$.
   Describe these projections and show that they remain linearly independent.

4. Deduce that $TS^{n-1}$ is trivial.
   Conclude that $\mathbb R^3$ cannot admit a real division-algebra structure.
:::

Let
\[
A=\mathbb R^n
\]
with the assumed real division-algebra structure.
Thus multiplication is bilinear, and multiplication by any nonzero element
on either side is an invertible linear map.

::: pf

::: pf-step

Right multiplication by
\[
e_1
\]
defines a linear map
\[
R_{e_1}:A\to A,
\qquad
R_{e_1}(a)=ae_1.
\]


::: pf-proof

Because
\[
e_1\ne0
\]
and $A$ is a division algebra, the equation
\[
ae_1=0
\]
forces
\[
a=0.
\]
Thus
\[
R_{e_1}
\]
is injective.
Since $A$ is finite-dimensional, an injective linear endomorphism is
surjective.
Hence $R_{e_1}$ is a linear isomorphism.

:::

:::

::: pf-step

Therefore, for every
\[
p\in S^{n-1},
\]
there exists a unique
\[
a\in A
\]
such that
\[
\boxed{
p=ae_1.
}
\]


::: pf-proof

Existence and uniqueness are exactly bijectivity of
\[
R_{e_1}.
\]
Explicitly,
\[
a=R_{e_1}^{-1}(p).
\]

:::

:::

::: pf-step

Let
\[
b\in A
\]
be nonzero.
Left multiplication
\[
L_b:A\to A,
\qquad
L_b(x)=bx,
\]
is a linear isomorphism.


::: pf-proof

If
\[
bx=0,
\]
then, because $b\ne0$ and $A$ has no zero divisors,
\[
x=0.
\]
Thus $L_b$ is injective.
Finite-dimensionality again implies surjectivity.

:::

:::

::: pf-step

Hence
\[
\boxed{
be_1,\dots,be_n
}
\]
are linearly independent.


::: pf-proof

Suppose
\[
c_1be_1+cdots+c_nbe_n=0.
\]
By bilinearity,
\[
b(c_1e_1+cdots+c_ne_n)=0.
\]
Injectivity of $L_b$ gives
\[
c_1e_1+cdots+c_ne_n=0.
\]
Since
\[
e_1,dots,e_n
\]
is a basis,
\[
c_1=cdots=c_n=0.
\]

:::

:::

::: pf-step

Fix
\[
p\in S^{n-1}
\]
and write
\[
p=ae_1
\]
as in step <1>2.
Then
\[
a\ne0.
\]


::: pf-proof

If
\[
a=0,
\]
then
\[
p=ae_1=0,
\]
contradicting
\[
p\in S^{n-1}.
\]

:::

:::

::: pf-step

The tangent space of the sphere at $p$ is
\[
T_pS^{n-1}
=
p^\perp
=
\{
v\in\mathbb R^n:
\langle v,p\rangle=0
\}.
\]


::: pf-proof

The sphere is the level set
\[
\|x\|^2=1.
\]
Differentiating gives
\[
2\langle v,p\rangle=0
\]
for tangent vectors $v$.

:::

:::

::: pf-step

For
\[
j=2,\dots,n,
\]
define the orthogonal projection of $ae_j$ to
\[
T_pS^{n-1}
\]
by
\[
\boxed{
v_j(p)
=
ae_j
-
\langle ae_j,p\rangle p.
}
\]


::: pf-proof

Since
\[
\|p\|=1,
\]
the orthogonal projection of a vector $w$ onto
\[
p^\perp
\]
is
\[
w-\langle w,p\rangle p.
\]
Apply this to
\[
w=ae_j.
\]
Indeed,
\[
\begin{aligned}
\langle v_j(p),p\rangle
&=
\langle ae_j,p\rangle
-
\langle ae_j,p\rangle
\langle p,p\rangle\\
&=
0.
\end{aligned}
\]

:::

:::

::: pf-step

The vectors
\[
v_2(p),\dots,v_n(p)
\]
are linearly independent in
\[
T_pS^{n-1}.
\]


::: pf-proof

Suppose
\[
\sum_{j=2}^n c_jv_j(p)=0.
\]
Substitute step <1>7:
\[
\sum_{j=2}^n c_jae_j
-
\left(
\sum_{j=2}^n
c_j
\langle ae_j,p\rangle
\right)p
=
0.
\]
Set
\[
\lambda
\coloneqq
\sum_{j=2}^n
c_j
\langle ae_j,p\rangle.
\]
Since
\[
p=ae_1,
\]
the relation becomes
\[
a
\left(
\sum_{j=2}^n c_je_j
-
\lambda e_1
\right)
=
0.
\]

By step <1>5,
\[
a\ne0,
\]
so left multiplication by $a$ is injective.
Therefore
\[
\sum_{j=2}^n c_je_j
-
\lambda e_1
=
0.
\]
Linear independence of
\[
e_1,dots,e_n
\]
gives
\[
c_2=cdots=c_n=0
\]
and
\[
\lambda=0.
\]
Thus the projected vectors are independent.

:::

:::

::: pf-step

The vectors
\[
v_2(p),\dots,v_n(p)
\]
form a basis of
\[
T_pS^{n-1}.
\]


::: pf-proof

The tangent space has dimension
\[
n-1.
\]
Step <1>8 gives exactly
\[
n-1
\]
linearly independent tangent vectors.

:::

:::

::: pf-step

For each
\[
j=2,\dots,n,
\]
the assignment
\[
p\longmapsto v_j(p)
\]
is a continuous global tangent vector field on
\[
S^{n-1}.
\]


::: pf-proof

The element
\[
a
=
R_{e_1}^{-1}(p)
\]
depends linearly, hence continuously, on $p$.

Multiplication
\[
(a,e_j)\mapsto ae_j
\]
is continuous by hypothesis.
The Euclidean inner product and the projection formula in step <1>7 are
continuous.
Hence
\[
v_j
\]
is a continuous tangent section.

:::

:::

::: pf-step

Define
\[
\Theta:
S^{n-1}\times\mathbb R^{n-1}
\to
TS^{n-1}
\]
by
\[
\Theta
\left(
p,
(c_2,\dots,c_n)
\right)
=
\left(
p,
\sum_{j=2}^n c_jv_j(p)
\right).
\]
Then $\Theta$ is a vector-bundle isomorphism.


::: pf-proof

The map is continuous and fiberwise linear by step <1>10.

For each fixed $p$, step <1>9 says
\[
v_2(p),\dots,v_n(p)
\]
is a basis of
\[
T_pS^{n-1}.
\]
Thus the fiber map
\[
\mathbb R^{n-1}
\to
T_pS^{n-1}
\]
is a linear isomorphism.

The inverse coefficients depend continuously on $p$ because the matrix
whose columns are the $v_j(p)$ has continuously varying full rank.
Hence $\Theta$ is a bundle isomorphism.

:::

:::

::: pf-step

Therefore
\[
\boxed{
TS^{n-1}
\cong
S^{n-1}\times\mathbb R^{n-1}.
}
\]
Thus
\[
S^{n-1}
\]
is parallelizable.


::: pf-proof

This is exactly the conclusion of step <1>11.

:::

:::

::: pf-step

If
\[
\mathbb R^3
\]
admitted a real division-algebra structure, then
\[
S^2
\]
would be parallelizable.


::: pf-proof

Apply step <1>12 with
\[
n=3.
\]

:::

:::

::: pf-step

But
\[
S^2
\]
is not parallelizable.


::: pf-proof

A trivial tangent bundle would admit a nowhere-zero tangent vector field.
The Hairy Ball Theorem says that every continuous tangent vector field on
\[
S^2
\]
vanishes somewhere.
Therefore
\[
TS^2
\]
cannot be trivial.

Equivalently, its Euler class is nonzero:
\[
\langle e(TS^2),[S^2]\rangle
=
\chi(S^2)
=
2.
\]

:::

:::

::: pf-step

Hence
\[
\boxed{
\mathbb R^3
\text{ admits no real division-algebra structure}.
}
\]


::: pf-proof

Steps <1>13--<1>14 give a contradiction to the existence of such a
structure.

:::

::: {.problem}
Let $\pi:E\to M$ be a rank-two vector bundle, and let $\Phi$ be its Thom class.
Wedge product with $\Phi$ gives an isomorphism
\[
H^*(M)\longrightarrow H_{cv}^{*+2}(E).
\]
Thus every class $\omega\in H_{cv}^{*+2}(E)$ can be written as
\[
\omega=\Phi\wedge\pi^*u
\]
for some $u\in H^*(M)$.

Give a natural description of the class $u$ for which
\[
\Phi\wedge\pi^*u=\Phi\wedge\Phi.
\]
:::

::: {.solution}
Assume the bundle is oriented over the coefficient ring being used, so that
the Thom class exists.
Let
\[
s:M\to E
\]
be the zero section.

<1>1. The natural class is the Euler class
\[
\boxed{
u=e(E)
\coloneqq
s^*\Phi
\in
H^2(M).
}
\]

::: {.proof}
For an oriented rank-two bundle, the Euler class is defined as the pullback
of the Thom class along the zero section:
\[
e(E)=s^*\Phi.
\]
The remaining steps verify that this class satisfies the required identity.
:::

<1>2. Under the Thom isomorphism, the Gysin map of the zero section is
\[
s_!:
H^*(M)
\longrightarrow
H_{cv}^{*+2}(E),
\qquad
s_!(a)
=
\Phi\wedge\pi^*a.
\]

::: {.proof}
The normal bundle of the zero section
\[
s(M)\subset E
\]
is canonically the original vector bundle
\[
E\to M.
\]
Therefore the Gysin map for the zero section is precisely the Thom
isomorphism.
:::

<1>3. In particular,
\[
\Phi
=
s_!(1).
\]

::: {.proof}
Apply step <1>2 to the unit class
\[
1\in H^0(M):
\]
\[
s_!(1)
=
\Phi\wedge\pi^*(1)
=
\Phi.
\]
:::

<1>4. The Gysin map satisfies the projection formula
\[
s_!(a)\wedge\eta
=
s_!
\bigl(
a\wedge s^*\eta
\bigr)
\]
for
\[
a\in H^*(M),
\qquad
\eta\in H^*(E)
\]
whenever the products are defined.

::: {.proof}
This is the standard projection formula for the Gysin map.
For the zero-section Thom model it follows directly from
\[
s_!(a)
=
\Phi\wedge\pi^*a
\]
and
\[
\pi\circ s
=
\operatorname{id}_M.
\]
:::

<1>5. Apply the projection formula with
\[
a=1
\qquad\text{and}\qquad
\eta=\Phi.
\]
Then
\[
\Phi\wedge\Phi
=
s_!(s^*\Phi).
\]

::: {.proof}
By step <1>3,
\[
\Phi=s_!(1).
\]
Hence
\[
\begin{aligned}
\Phi\wedge\Phi
&=
s_!(1)\wedge\Phi\\
&=
s_!
\bigl(
1\wedge s^*\Phi
\bigr)\\
&=
s_!(s^*\Phi).
\end{aligned}
\]
:::

<1>6. Since
\[
s^*\Phi=e(E),
\]
step <1>5 becomes
\[
\Phi\wedge\Phi
=
s_!(e(E)).
\]

::: {.proof}
Substitute the definition of the Euler class from step <1>1.
:::

<1>7. Using the Thom formula for $s_!$,
\[
s_!(e(E))
=
\Phi\wedge\pi^*e(E).
\]

::: {.proof}
Apply step <1>2 with
\[
a=e(E).
\]
:::

<1>8. Therefore
\[
\boxed{
\Phi\wedge\Phi
=
\Phi\wedge\pi^*e(E).
}
\]

::: {.proof}
Combine steps <1>6--<1>7.
:::

<1>9. By uniqueness in the Thom isomorphism, the class $u$ satisfying
\[
\Phi\wedge\pi^*u
=
\Phi\wedge\Phi
\]
is exactly
\[
\boxed{
u=e(E)=s^*\Phi.
}
\]

::: {.proof}
The map
\[
H^*(M)
\xrightarrow{\cong}
H_{cv}^{*+2}(E),
\qquad
u\mapsto
\Phi\wedge\pi^*u
\]
is an isomorphism by hypothesis.
Step <1>8 shows that
\[
e(E)
\]
maps to
\[
\Phi\wedge\Phi.
\]
Hence it is the unique preimage.
:::

<1>10. Equivalently,
\[
u
=
\pi_*
\bigl(
\Phi\wedge\Phi
\bigr),
\]
where
\[
\pi_*
\]
is fiber integration.

::: {.proof}
Fiber integration is the inverse of the Thom isomorphism in this
normalization:
\[
\pi_*
\bigl(
\Phi\wedge\pi^*a
\bigr)
=
a.
\]
Apply it to the identity in step <1>8.
:::

<1>11. Q.E.D.

::: {.proof}
Step <1>9 gives the requested natural description of $u$.
:::
:::

::: {.problem}
An element is called a square if it can be expressed in the form $b^{2}$ for some $b$. Suppose that $G$ is an Abelian group and $H$ is a subgroup of $G$. If every element of $H$ is a square and every element of $G / H$ is a square, prove that every element of $G$ is a square.
Does your proof remain valid when “square” is replaced by “$n$th power” where $n$ is any integer?
:::

::: {.solution}

::: pf

::: {.pf-step #s1-1}

For every $g\in G$, there is an $a\in G$ such that
$$
gH=a^2H.
$$


::: pf-proof

Because $G$ is Abelian, every subgroup is normal, so $G/H$ is a group.
By hypothesis every element of $G/H$ is a square. Applying this to the
coset $gH$ gives some $aH\in G/H$ with
$$
gH=(aH)^2=a^2H.
$$

:::

:::

::: {.pf-step #s1-2}

For the element $a$ from step [](#s1-1){.pf-ref}, there is a $b\in H$ such that
$$
a^{-2}g=b^2.
$$


::: pf-proof

The equality $gH=a^2H$ from step [](#s1-1){.pf-ref} is equivalent to
$$
a^{-2}g\in H.
$$
Every element of $H$ is a square by hypothesis, so there is a $b\in H$
with $a^{-2}g=b^2$.

:::

:::

::: {.pf-step #s1-3}

Every element of $G$ is a square.


::: pf-proof

Let $g\in G$ be arbitrary and choose $a$ and $b$ as in steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref}. Then
$$
g=a^2b^2=(ab)^2,
$$
where the last equality uses that $G$ is Abelian. Thus the arbitrary
element $g$ is a square.

:::

:::

::: {.pf-step #s1-4}

The same argument remains valid for every integer $n$; the answer to the second question is
$$
\boxed{\text{yes}}.
$$


::: pf-proof

Assume instead that every element of $H$ and every element of $G/H$ is
an $n$th power, where $n\in\ZZ$. Given $g\in G$, choose $a\in G$
such that
$$
gH=(aH)^n=a^nH.
$$
Then $a^{-n}g\in H$, so there is a $b\in H$ with
$$
a^{-n}g=b^n.
$$
Hence
$$
g=a^nb^n=(ab)^n,
$$
again because $G$ is Abelian. This computation is valid for every
integer $n$, including $n=0$ and negative $n$.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} proves the square case, and step [](#s1-4){.pf-ref} proves the stated
generalization to arbitrary integer powers.

:::

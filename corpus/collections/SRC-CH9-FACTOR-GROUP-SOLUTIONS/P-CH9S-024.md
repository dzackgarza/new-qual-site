::: {.problem}
The group $\left( \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 1 2 } \right) / \textrm { < } ( 2 , 2 ) \textrm { > }$ is isomorphic to one of $\mathbb { Z } _ { 8 } , \ \mathbb { Z } _ { 4 } \oplus \mathbb { Z } _ { 2 }$ , or $\mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 } \oplus \mathbb { Z } _ { 2 }$ . Determine which one by elimination.
:::

Let
$$
A=\mathbb Z_4\oplus\mathbb Z_{12},
\qquad
H=\langle(2,2)\rangle,
\qquad
Q=A/H.
$$

::: pf

::: pf-step

The quotient $Q$ has order $8$.


::: pf-proof

The element $2\in\mathbb Z_4$ has order $2$, while
$2\in\mathbb Z_{12}$ has order $6$. Hence
$$
\operatorname{ord}(2,2)=\operatorname{lcm}(2,6)=6,
$$
so $|H|=6$. Since
$$
|A|=4\cdot12=48,
$$
Lagrange's theorem gives
$$
|Q|=\frac{48}{6}=8.
$$

:::

:::

::: pf-step

The group $Q$ has no element of order $8$.


::: pf-proof

Every $x\in A$ satisfies
$$
12x=0,
$$
because the exponent of
$\mathbb Z_4\oplus\mathbb Z_{12}$ divides $12$. Hence every coset
$x+H\in Q$ satisfies
$$
12(x+H)=H,
$$
so its order divides $12$. By step <1>1 and Lagrange's theorem, its
order also divides $8$. Therefore every element order in $Q$ divides
$$
\gcd(12,8)=4.
$$
In particular, $Q$ has no element of order $8$.

:::

:::

::: pf-step

The group $Q$ has an element of order $4$.


::: pf-proof

Consider
$$
x=(0,1)+H.
$$
Since
$$
4(0,1)=(0,4)=2(2,2)\in H,
$$
one has $4x=H$. On the other hand,
$$
2(0,1)=(0,2)\notin H.
$$
Indeed, if $(0,2)=k(2,2)$, then
$$
2k\equiv0\pmod4
\qquad\text{and}\qquad
2k\equiv2\pmod{12}.
$$
The first congruence forces $k$ even, whereas the second forces
$k\equiv1\pmod6$, hence $k$ odd, a contradiction. Thus $2x\neq H$,
so $x$ has order $4$.

:::

:::

::: pf-step

Among the three listed possibilities,
$$
\boxed{
Q\cong\mathbb Z_4\oplus\mathbb Z_2}.
$$


::: pf-proof

The group $\mathbb Z_8$ contains an element of order $8$, while step
<1>2 shows that $Q$ does not. Thus $Q\not\cong\mathbb Z_8$.

Every nonidentity element of
$\mathbb Z_2\oplus\mathbb Z_2\oplus\mathbb Z_2$ has order $2$, whereas
step <1>3 gives an element of order $4$ in $Q$. Thus $Q$ is not
isomorphic to that group either. The only remaining listed possibility
is $\mathbb Z_4\oplus\mathbb Z_2$.

:::

:::

::: pf-qed

Steps <1>1--<1>4 determine the quotient by the requested elimination.

:::

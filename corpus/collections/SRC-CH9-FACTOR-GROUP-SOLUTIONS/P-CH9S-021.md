::: {.problem}
Prove that an Abelian group of order 33 is cyclic.
:::

::: {.solution}

Let $G$ be an abelian group with $\cardinality{G}=33=3\cdot11$.

::: pf

::: {.pf-step #s1-1}

There exist elements $a,b\in G$ with
$$
\operatorname{ord}(a)=3
\qquad\text{and}\qquad
\operatorname{ord}(b)=11.
$$


::: pf-proof

Both primes $3$ and $11$ divide $\cardinality{G}$. By Cauchy's theorem, $G$
contains an element of order $3$ and an element of order $11$.

:::

:::

::: {.pf-step #s1-2}

The element $ab$ has order $33$.


::: pf-proof

Since $G$ is abelian,
$$
(ab)^{33}=a^{33}b^{33}=e,
$$
so $\operatorname{ord}(ab)$ divides $33$. The possible orders are
therefore
$$
1,\ 3,\ 11,\ 33.
$$
However,
$$
(ab)^3=a^3b^3=b^3\neq e,
$$
because $b$ has order $11$. Thus $\operatorname{ord}(ab)$ is neither
$1$ nor $3$. Likewise,
$$
(ab)^{11}=a^{11}b^{11}=a^2\neq e,
$$
because $a$ has order $3$. Thus $\operatorname{ord}(ab)$ is neither
$1$ nor $11$. The only remaining possibility is
$$
\operatorname{ord}(ab)=33.
$$

:::

:::

::: {.pf-step #s1-3}

The group $G$ is cyclic:
$$
\boxed{G=\langle ab\rangle\cong\ZZ_{33}}.
$$


::: pf-proof

By step [](#s1-2){.pf-ref}, the subgroup $\langle ab\rangle$ contains $33$ elements.
Since $G$ itself has $33$ elements,
$$
\langle ab\rangle=G.
$$

:::

:::

::: pf-qed

Steps [](#s1-1){.pf-ref} through [](#s1-3){.pf-ref} construct an element that generates $G$.

:::

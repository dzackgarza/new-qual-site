::: {.problem}
Show that $D_{13}$ is isomorphic to $\operatorname{Inn}(D_{13})$.
:::

::: {.solution}

Write
$$
D_{13}=\langle r,s\mid r^{13}=e,\ s^2=e,\ srs=r^{-1}\rangle.
$$

::: pf

::: {.pf-step #s1-1}

The center of $D_{13}$ is trivial:
$$
Z(D_{13})=\{e\}.
$$


::: pf-proof

Every element of $D_{13}$ is either $r^k$ or $sr^k$ for some
$k\in\{0,1,\dots,12\}$. If $r^k$ is central, then it commutes with $s$,
so
$$
r^k=sr^ks=r^{-k}.
$$
Hence $r^{2k}=e$. Since $r$ has order $13$ and $13$ is odd, this forces
$13\mid k$, so $r^k=e$.

On the other hand, no element $sr^k$ is central. Indeed, using
$rs=sr^{-1}$,
$$
r(sr^k)=sr^{k-1},
\qquad
(sr^k)r=sr^{k+1}.
$$
If these were equal, then $r^{k-1}=r^{k+1}$, hence $r^2=e$, contrary
to the fact that $r$ has order $13$. Thus the only central element is
$e$.

:::

:::

::: {.pf-step #s1-2}

The conjugation map
$$
c:D_{13}\longrightarrow\operatorname{Inn}(D_{13}),
\qquad
c(g)(x)=gxg^{-1},
$$
is a surjective homomorphism with kernel $Z(D_{13})$.


::: pf-proof

For $g,h,x\in D_{13}$,
$$
c(gh)(x)=ghx(gh)^{-1}=g(hxh^{-1})g^{-1},
$$
so $c(gh)=c(g)\circ c(h)$. By definition every inner automorphism is
conjugation by some element of $D_{13}$, so $c$ is onto. Finally,
$c(g)$ is the identity automorphism exactly when $gxg^{-1}=x$ for
every $x\in D_{13}$, equivalently exactly when $g\in Z(D_{13})$.

:::

:::

::: {.pf-step #s1-3}

The map $c$ is an isomorphism
$$
D_{13}\cong\operatorname{Inn}(D_{13}).
$$


::: pf-proof

By step [](#s1-1){.pf-ref} and step [](#s1-2){.pf-ref},
$$
\ker c=Z(D_{13})=\{e\}.
$$
Thus $c$ is injective, and step [](#s1-2){.pf-ref} shows that it is surjective.
Therefore $c$ is an isomorphism.

:::

:::

::: pf-qed

Step [](#s1-3){.pf-ref} is the required isomorphism.

:::

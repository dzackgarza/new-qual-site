It is known that the series $\sum _ { n = 1 } ^ { \infty } { \frac { 1 } { n } }$ diverges while the series $\sum _ { n = 1 } ^ { \infty } { \frac { ( - 1 ) ^ { n } } { n } }$ converges.
One may ask about the convergence or divergence of the series $\sum _ { n = 1 } ^ { \infty } { \frac { \xi _ { n } } { n } }$ 2 where $\xi _ { n }$ =1are independent random variables taking the values +1 or 1 with the probabilities p and $q = 1 - p$ correspondingly.

(a) Show that if $p = q = \frac { 1 } { 2 }$ , the series converges with the unit probability.

(b) Show that otherwise the series diverges with the unit probability.

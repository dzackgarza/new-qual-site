$$
P _ { i j } ( t = 1 ) = c _ { i } e ^ { - \alpha | i - j | } ,\tag{54}
$$

where $\alpha > 0$ and $c _ { i }$ are some constants.

(a) $P _ { i j } ( t = 2 )$

(b) $c _ { i } .$

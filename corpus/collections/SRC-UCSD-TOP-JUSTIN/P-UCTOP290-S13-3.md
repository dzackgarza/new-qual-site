::: {.problem}
Show that a compact manifold cannot retract to its boundary.
:::

::: {.solution}

Let $M$ be a nonempty compact $n$-manifold, $n\ge1$, with nonempty boundary
$\partial M$, and let $i\colon\partial M\to M$ be the inclusion. Work with
$\ZZ/2$ coefficients, so that no orientability is needed and the relative
fundamental class exists.

::: pf

::: {.pf-step #class}

$H_n(M,\partial M;\ZZ/2)\cong\ZZ/2$, generated by a class $[M,\partial M]$,
and $\partial[M,\partial M]=[\partial M]$, the sum of the fundamental classes
of the boundary components.

::: pf-proof

This is Poincaré-Lefschetz duality for a compact manifold with boundary over
$\ZZ/2$: $H_n(M,\partial M;\ZZ/2)\cong H^0(M;\ZZ/2)=\ZZ/2$, and the dual of
the constant function $1$ is the relative fundamental class. The connecting
map of the pair sends it to the fundamental class of the boundary, which is
the standard computation on a collar $\partial M\times[0,1)$: the boundary of
the relative chain is the boundary of the collar end, carrying the fundamental
class of $\partial M$.

:::

:::

::: {.pf-step #zero}

$i_*[\partial M]=0$ in $H_{n-1}(M;\ZZ/2)$.

::: pf-proof

The long exact sequence of the pair reads $H_n(M,\partial
M)\xrightarrow{\partial}H_{n-1}(\partial M)\xrightarrow{i_*}H_{n-1}(M)$, so
$\ker i_*=\operatorname{im}\partial$; step [](#class){.pf-ref} exhibits
$[\partial M]=\partial[M,\partial M]$ in that image. For a disconnected $M$
the same applies component by component, the fundamental class of each
boundary component being a boundary, and the sum of classes in the image is in
the image.

:::

:::

::: {.pf-step #retraction}

No continuous map $r\colon M\to\partial M$ satisfies $r\circ
i=\mathrm{id}_{\partial M}$.

::: pf-proof

If such an $r$ existed, then $r_*i_*=\mathrm{id}$ on $H_{n-1}(\partial
M;\ZZ/2)$, so $i_*$ would be injective with a left inverse $r_*$. But
$H_{n-1}(\partial M;\ZZ/2)\ne0$: a compact $(n-1)$-manifold without boundary
has a nonzero top class, each of its components contributing $\ZZ/2$. So there
is a nonzero class, $[\partial M]$, that $i_*$ kills by step
[](#zero){.pf-ref}, contradicting injectivity. Hence no retraction exists, and
$M$ does not retract to its boundary.

:::

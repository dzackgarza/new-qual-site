::: {.problem}
Identify the following groups up to isomorphism

1. $\ZZ_m \tensor \ZZ_n$

2. $\ZZ_{60}^4 \tensor (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120})$

3. $\ZZ_n \tensor \QQ$

4. $(\ZZ \oplus \ZZ_n) \tensor (\QQ/\ZZ)$
:::

::: {.solution}
**Goal:** Compute the following tensor products of abelian groups ($\ZZ$-modules) up to group isomorphism:

1. $\ZZ_m \otimes_\ZZ \ZZ_n$,

2. $\ZZ_{60}^4 \otimes_\ZZ (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120})$,

3. $\ZZ_n \otimes_\ZZ \QQ$,

4. $(\ZZ \oplus \ZZ_n) \otimes_\ZZ (\QQ/\ZZ)$.

::: pf

::: {.pf-step #s1}
Compute Part 1: $\ZZ_m \otimes_\ZZ \ZZ_n \cong \ZZ_{\gcd(m, n)}$.

::: pf-proof

::: pf-step
By the standard presentation of cyclic modules, $\ZZ_m \cong \ZZ / m\ZZ$.
:::

::: pf-step
For any abelian group $A$, $(\ZZ/m\ZZ) \otimes_\ZZ A \cong A / mA$.
:::

::: pf-step
Applying this to $A = \ZZ/n\ZZ$ gives: $$\ZZ_m \otimes_\ZZ \ZZ_n \cong (\ZZ/n\ZZ) / m(\ZZ/n\ZZ) \cong \ZZ / (n\ZZ + m\ZZ) = \ZZ / \gcd(m, n)\ZZ \cong \ZZ_{\gcd(m, n)}.$$
:::

::: pf-qed
Standard right-exactness of tensor products with cyclic modules.
:::

:::

:::

::: pf-step
Compute Part 2: $\ZZ_{60}^4 \otimes_\ZZ (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120})$.

::: pf-proof

::: pf-step
Tensor product distributes over direct sums: $$(A^{\oplus 4}) \otimes (B_1^{\oplus 3} \oplus B_2^{\oplus 4} \oplus B_3) \cong (A \otimes B_1)^{\oplus 12} \oplus (A \otimes B_2)^{\oplus 16} \oplus (A \otimes B_3)^{\oplus 4}.$$
:::

::: pf-step
Compute each component using step [](#s1){.pf-ref}:

- $\ZZ_{60} \otimes \ZZ_{24} \cong \ZZ_{\gcd(60, 24)} = \ZZ_{12}$.

- $\ZZ_{60} \otimes \ZZ_8 \cong \ZZ_{\gcd(60, 8)} = \ZZ_4$.

- $\ZZ_{60} \otimes \ZZ_{120} \cong \ZZ_{\gcd(60, 120)} = \ZZ_{60}$.
:::

::: pf-step
Summing all components: $$\ZZ_{60}^4 \otimes (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120}) \cong \ZZ_{12}^{12} \oplus \ZZ_4^{16} \oplus \ZZ_{60}^4.$$
:::

::: pf-qed
Tensor product distributes over direct sums, so the tensor product of $\ZZ_{60}^4$ with the direct sum is the direct sum of the pairwise tensor products; each pairwise product is computed by step [](#s1){.pf-ref}, and the multiplicities come from the exponents.
:::

:::

:::

::: pf-step
Compute Part 3: $\ZZ_n \otimes_\ZZ \QQ \cong 0$ (for $n \ge 1$).

::: pf-proof

::: pf-step
In $\ZZ_n \otimes_\ZZ \QQ$, for any $a \in \ZZ_n$ and $q \in \QQ$: $$a \otimes q = a \otimes \left( n \cdot \frac{q}{n} \right) = (n \cdot a) \otimes \frac{q}{n} = 0 \otimes \frac{q}{n} = 0.$$
:::

::: pf-step
Since the tensor product is generated by simple tensors, $\ZZ_n \otimes_\ZZ \QQ = 0$.
:::

::: pf-qed
Every simple tensor $a \otimes q$ vanishes because $a$ is $n$-torsion and $q$ is $n$-divisible; since simple tensors generate the tensor product, the whole group is $0$.
:::

:::

:::

::: {.pf-step #s4}
Compute Part 4: $(\ZZ \oplus \ZZ_n) \otimes_\ZZ (\QQ/\ZZ) \cong \QQ/\ZZ$.

::: pf-proof

::: pf-step
By distributivity: $$(\ZZ \oplus \ZZ_n) \otimes (\QQ/\ZZ) \cong (\ZZ \otimes (\QQ/\ZZ)) \oplus (\ZZ_n \otimes (\QQ/\ZZ)).$$
:::

::: pf-step
For the first term: $\ZZ \otimes_\ZZ A \cong A$ for any abelian group $A$, so $\ZZ \otimes (\QQ/\ZZ) \cong \QQ/\ZZ$.
:::

::: pf-step
For the second term: $\ZZ_n \otimes (\QQ/\ZZ) \cong (\QQ/\ZZ) / n(\QQ/\ZZ)$.
Since $\QQ/\ZZ$ is divisible, for any $x \in \QQ/\ZZ$ there exists $y \in \QQ/\ZZ$ such that $n y = x$, so $n(\QQ/\ZZ) = \QQ/\ZZ$.
Thus $(\QQ/\ZZ) / n(\QQ/\ZZ) = 0$.
:::

::: pf-step
Therefore: $$(\ZZ \oplus \ZZ_n) \otimes (\QQ/\ZZ) \cong (\QQ/\ZZ) \oplus 0 \cong \QQ/\ZZ.$$
:::

::: pf-qed
Distributivity splits the tensor product into two summands; the first is $\QQ/\ZZ$ because $\ZZ \otimes A \cong A$, and the second vanishes because $\QQ/\ZZ$ is divisible, so $n(\QQ/\ZZ) = \QQ/\ZZ$.
:::

:::

:::

::: pf-qed
Steps [](#s1){.pf-ref} through [](#s4){.pf-ref} determine all four tensor product groups.
:::

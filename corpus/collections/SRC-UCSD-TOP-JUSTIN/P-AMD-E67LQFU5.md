::: {.problem}
Identify the following groups up to isomorphism

1. $\ZZ_m \tensor \ZZ_n$

2. $\ZZ_{60}^4 \tensor (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120})$

3. $\ZZ_n \tensor \QQ$

4. $(\ZZ \oplus \ZZ_n) \tensor (\QQ/\ZZ)$
:::

::: {.solution}
All tensor products are tensor products of abelian groups, over $\ZZ$.

::: pf

::: {.pf-step #s1}
$\ZZ_m \otimes_\ZZ \ZZ_n \cong \ZZ_{\gcd(m, n)}$.

::: pf-proof
The cyclic group is the quotient $\ZZ_m \cong \ZZ/m\ZZ$. For any abelian group $A$ the tensor product $(\ZZ/m\ZZ)\otimes_\ZZ A$ is $A/mA$: the map $(k + m\ZZ, a) \mapsto ka + mA$ is $\ZZ$-bilinear and balanced, hence induces a homomorphism $A/mA \to (\ZZ/m\ZZ)\otimes A$ inverse to the one sending $(k + m\ZZ)\otimes a$ to $ka + mA$, which is well defined because replacing $k$ by $k + mt$ changes $ka$ by an element of $mA$. Taking $A = \ZZ/n\ZZ$ and using $mA = m(\ZZ/n\ZZ) = (n\ZZ + m\ZZ)/n\ZZ$, the quotient is $\ZZ/(n\ZZ + m\ZZ) = \ZZ/\gcd(m,n)\ZZ$, since $n\ZZ + m\ZZ = \gcd(m,n)\ZZ$ in $\ZZ$.
:::

:::

::: {.pf-step #s2}
$\ZZ_{60}^4 \otimes_\ZZ (\ZZ_{24}^3 \oplus \ZZ_8^4 \oplus \ZZ_{120}) \cong \ZZ_{12}^{12} \oplus \ZZ_4^{16} \oplus \ZZ_{60}^4$.

::: pf-proof
Tensoring commutes with finite direct sums in each variable, so the product is the direct sum of the pairwise products $\ZZ_{60}\otimes\ZZ_{24}$, $\ZZ_{60}\otimes\ZZ_8$ and $\ZZ_{60}\otimes\ZZ_{120}$, with multiplicities $4\cdot 3 = 12$, $4\cdot 4 = 16$ and $4\cdot 1 = 4$. By step [](#s1){.pf-ref} each pairwise product is cyclic of order the gcd: $\gcd(60,24) = 12$, $\gcd(60,8) = 4$ and $\gcd(60,120) = 60$. Substituting gives the displayed direct sum.
:::

:::

::: {.pf-step #s3}
$\ZZ_n \otimes_\ZZ \QQ = 0$ for every $n \ge 1$.

::: pf-proof
The tensor product of abelian groups is generated by the simple tensors $a \otimes q$. For $a \in \ZZ_n$ and $q \in \QQ$, write $q = n \cdot (q/n)$ with $q/n \in \QQ$, and move the integer across the tensor:
$$a \otimes q = a \otimes \left(n \cdot \frac{q}{n}\right) = (n \cdot a) \otimes \frac{q}{n} = 0 \otimes \frac{q}{n} = 0,$$
where $n \cdot a = 0$ because $a$ is an element of $\ZZ_n$ and $\QQ$ is torsion-free so that $n(q/n) = q$ exactly. Every generator vanishes, hence the group is $0$.
:::

:::

::: {.pf-step #s4}
$(\ZZ \oplus \ZZ_n) \otimes_\ZZ (\QQ/\ZZ) \cong \QQ/\ZZ$.

::: pf-proof
Tensoring commutes with finite direct sums, so the product splits as $(\ZZ \otimes (\QQ/\ZZ)) \oplus (\ZZ_n \otimes (\QQ/\ZZ))$. The first summand is $\QQ/\ZZ$, because $\ZZ \otimes_\ZZ A \cong A$ for every abelian group $A$ via $k \otimes a \mapsto ka$. The second is $(\QQ/\ZZ)/n(\QQ/\ZZ)$ by the identification of step [](#s1){.pf-ref} with $m = n$, and $n(\QQ/\ZZ) = \QQ/\ZZ$ because $\QQ/\ZZ$ is divisible: given $x = r + \ZZ$ take $y = r/n + \ZZ$, which satisfies $ny = x$. So the second summand is $0$ and the product is $\QQ/\ZZ \oplus 0 \cong \QQ/\ZZ$.
:::

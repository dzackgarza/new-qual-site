::: {.problem}
Suppose $\ell$ is a line and $C$ is a circle in the plane.
Under what conditions is there a Möbius map which simultaneously sends $\ell\cup\{\infty\}$ and $C$ to concentric circles?
Justify your conclusions.
:::

::: {.solution}

::: pf

::: pf-step

A Möbius map sends generalized circles (circles or lines) to generalized circles.

::: pf-proof

Möbius transformations are conformal and preserve the class of generalized circles.

:::

:::

::: {.pf-step #s2}

Two generalized circles can be sent to concentric circles iff they are disjoint (do not intersect).

::: pf-proof

::: pf-step

Concentric circles are disjoint.

::: pf-proof

two distinct concentric circles have no common point.

:::

:::

::: pf-step

Conversely, two disjoint generalized circles can be mapped to concentric circles.

::: pf-proof

a Möbius map sending a point of one circle to $\infty$ turns it into a line; then a further map can be arranged so the two images are concentric circles (this is the standard fact that disjoint circles are "separated" and can be normalized to concentric circles).

:::

:::

:::

:::

::: {.pf-step #s3}

Hence the condition is that $\ell \cup \{\infty\}$ and $C$ are disjoint.

::: pf-proof

::: pf-step

$\ell \cup \{\infty\}$ is a generalized circle (a line together with the point at infinity).

::: pf-proof

a line is a circle through $\infty$.

:::

:::

::: pf-step

The condition is that $\ell$ does not meet $C$ (in the finite plane).

::: pf-proof

$\ell \cup \{\infty\}$ meets $C$ iff $\ell$ meets $C$ (since $\infty \notin C$ for a finite circle).

:::

:::

:::

:::

::: {.pf-step #s4}

Therefore a Möbius map sending $\ell \cup \{\infty\}$ and $C$ to concentric circles exists iff the line $\ell$ and the circle $C$ are disjoint.

::: pf-proof

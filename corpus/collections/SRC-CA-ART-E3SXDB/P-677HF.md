::: {.problem}
Can every continuous function on $\bar \DD$ be uniformly approximated by polynomials in the variable $z$?

> Hint: compare to Weierstrass for the real interval.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

If a sequence of polynomials $p_n$ converges uniformly on $\overline\DD$ to a function $g$, then $g$ is holomorphic on $\DD$.

::: pf-proof

Each $p_n$ is holomorphic on $\DD$, and a locally uniform limit of holomorphic functions on an open set is holomorphic there.

:::

:::

::: {.pf-step #s2}

The function $f(z)\definedas\bar z$ is continuous on $\overline\DD$ and not holomorphic on $\DD$.

::: pf-proof

Continuity is clear. Writing $f=u+iv$ with $u(x,y)=x$ and $v(x,y)=-y$ gives $u_x=1\neq-1=v_y$, so the Cauchy--Riemann equations fail at every point.

:::

:::

::: pf-qed

By steps [](#s1){.pf-ref} and [](#s2){.pf-ref}, no sequence of polynomials in $z$ converges uniformly to $\bar z$ on $\overline\DD$. The answer is $\boxed{\text{no}}$.

:::

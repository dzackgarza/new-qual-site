::: {.problem}
Assume that $A$ is a commutative Noetherian ring, and let $a_n \in A$ for $n \geq 0$.
Prove that the power series
\[
f = \sum_{n=0}^\infty a_n x^n
\]
is nilpotent if and only if each $a_n \in A$ is nilpotent.
:::


::: {.solution}
<1>1. If \(f\) is nilpotent, then every coefficient \(a_n\) is nilpotent.
::: {.proof}
Suppose
\[
f^m=0
\]
for some \(m\ge1\).
We prove by induction on \(n\) that \(a_n\) is nilpotent.

For \(n=0\), the constant coefficient of \(f^m\) is
\[
a_0^m,
\]
so \(a_0^m=0\).

Now assume \(a_0,\ldots,a_{n-1}\) are nilpotent, and set
\[
I:=(a_0,\ldots,a_{n-1}).
\]
Because \(I\) is generated by finitely many nilpotent elements in a commutative ring, \(I\) is nilpotent.
Indeed, if \(a_j^{e_j}=0\), then every product of
\[
1+\sum_{j=0}^{n-1}(e_j-1)
\]
generators contains some \(a_j^{e_j}\) as a factor.

Pass to \((A/I)[[x]]\).
The image \(\bar f\) has no terms of degree below \(n\):
\[
\bar f=\bar a_nx^n+\bar a_{n+1}x^{n+1}+\cdots.
\]
The coefficient of \(x^{mn}\) in \(\bar f^{\,m}\) is therefore exactly
\[
\bar a_n^{\,m},
\]
because a sum of \(m\) indices, each at least \(n\), equals \(mn\) only when all of them equal \(n\).
Since \(\bar f^{\,m}=0\),
\[
\bar a_n^{\,m}=0,
\]
so \(a_n^m\in I\).
If \(I^N=0\), then
\[
a_n^{mN}=0.
\]
Thus \(a_n\) is nilpotent, completing the induction.
:::

<1>2. In a commutative Noetherian ring, the nilradical is a nilpotent ideal.
::: {.proof}
Let
\[
\mathcal N:=\{a\in A:a\text{ is nilpotent}\}.
\]
For a commutative ring, \(\mathcal N\) is an ideal.
Since \(A\) is Noetherian, it is finitely generated:
\[
\mathcal N=(b_1,\ldots,b_r).
\]
Choose \(e_i\ge1\) with
\[
b_i^{e_i}=0.
\]
Set
\[
N:=1+\sum_{i=1}^r(e_i-1).
\]
Every product of \(N\) generators \(b_i\) contains some \(b_i\) at least \(e_i\) times, so every such product is zero.
Hence
\[
\mathcal N^N=0.
\]
:::

<1>3. If every coefficient \(a_n\) is nilpotent, then \(f\) is nilpotent.
::: {.proof}
If every \(a_n\) is nilpotent, then every coefficient lies in the nilradical \(\mathcal N\).
By <1>2, choose \(N\) such that
\[
\mathcal N^N=0.
\]
Every coefficient of \(f^N\) is a finite sum of products of \(N\) coefficients of \(f\), hence lies in
\[
\mathcal N^N=0.
\]
Therefore every coefficient of \(f^N\) is zero, so
\[
f^N=0.
\]
Thus \(f\) is nilpotent.
:::

<1>4. Therefore \(f\) is nilpotent if and only if every \(a_n\) is nilpotent.
::: {.proof}
Necessity is <1>1, and sufficiency is <1>3.

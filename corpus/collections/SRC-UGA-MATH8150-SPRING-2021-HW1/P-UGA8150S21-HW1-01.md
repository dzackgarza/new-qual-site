::: {.problem}
Describe geometrically the sets of points z in the complex plane defined by the following relations: (a) $| z - 1 | = 1 .$ (b) $| z - 1 | = 2 | z - 2 |$ (c) $1 / z = { \bar { z } } .$ (d) $\mathrm { R e } ( z ) = 3$ (e) $\operatorname { I m } ( z ) = a$ with $a \in \RR .$ (f) $\operatorname { R e } ( z ) > a$ with $a \in \RR$

(g) $| z - 1 | < 2 | z - 2 |$
:::

::: {.solution}

Write
\[
z=x+iy,
\qquad
x,y\in\RR.
\]

## Part (a)

::: pf

::: {.pf-step #s1-1}

The relation
\[
|z-1|=1
\]
becomes
\[
\boxed{
(x-1)^2+y^2=1}.
\]


::: pf-proof

Since
\[
z-1=(x-1)+iy,
\]
one has
\[
|z-1|^2=(x-1)^2+y^2.
\]
Square the equation.

:::

:::

::: {.pf-step #s1-2}

Therefore the locus is the circle of radius \(1\) centered at
\[
\boxed{(1,0)}.
\]


::: pf-proof

Step [](#s1-1){.pf-ref} is the standard circle equation.

:::

:::

::: pf-step

Squaring
\[
|z-1|=2|z-2|
\]
gives
\[
(x-1)^2+y^2
=
4\bigl((x-2)^2+y^2\bigr).
\]


::: pf-proof

Both sides are nonnegative, so squaring is equivalent.

:::

:::

::: {.pf-step #s1-4}

Expanding,
\[
3x^2-14x+15+3y^2=0.
\]


::: pf-proof

\[
x^2-2x+1+y^2
=
4x^2-16x+16+4y^2.
\]
Move all terms to one side.

:::

:::

::: {.pf-step #s1-5}

Completing the square,
\[
\boxed{
\left(x-\frac73\right)^2+y^2
=
\frac49}.
\]


::: pf-proof

Divide step [](#s1-4){.pf-ref} by \(3\):
\[
x^2-\frac{14}{3}x+5+y^2=0.
\]
Since
\[
x^2-\frac{14}{3}x
=
\left(x-\frac73\right)^2-\frac{49}{9},
\]
one obtains
\[
\left(x-\frac73\right)^2+y^2
=
\frac{49}{9}-5
=
\frac49.
\]

:::

:::

::: {.pf-step #s1-6}

Therefore the locus is the circle centered at
\[
\boxed{\left(\frac73,0\right)}
\]
with radius
\[
\boxed{\frac23}.
\]


::: pf-proof

Read the center and radius from step [](#s1-5){.pf-ref}.

:::

:::

::: {.pf-step #s1-7}

The relation
\[
\frac1z=\overline z
\]
implies
\[
\boxed{|z|^2=1}.
\]


::: pf-proof

The equation already requires \(z\ne0\). Multiply both sides by \(z\):
\[
1=z\overline z=|z|^2.
\]

:::

:::

::: {.pf-step #s1-8}

Conversely, if
\[
|z|=1,
\]
then
\[
\frac1z=\overline z.
\]


::: pf-proof

From
\[
z\overline z=1,
\]
divide by \(z\ne0\).

:::

:::

::: {.pf-step #s1-9}

Thus the locus is the unit circle
\[
\boxed{|z|=1}.
\]


::: pf-proof

Combine steps [](#s1-7){.pf-ref} through [](#s1-8){.pf-ref}.

:::

:::

::: {.pf-step #s1-10}

The equation
\[
\operatorname{Re}z=3
\]
is
\[
\boxed{x=3}.
\]


::: pf-proof

For \(z=x+iy\),
\[
\operatorname{Re}z=x.
\]

:::

:::

::: {.pf-step #s1-11}

Hence the locus is the vertical line through
\[
\boxed{x=3}.
\]


::: pf-proof

This is the geometric meaning of step [](#s1-10){.pf-ref}.

:::

:::

::: {.pf-step #s1-12}

The equation
\[
\operatorname{Im}z=a
\]
is
\[
\boxed{y=a}.
\]


::: pf-proof

For \(z=x+iy\),
\[
\operatorname{Im}z=y.
\]

:::

:::

::: {.pf-step #s1-13}

Hence the locus is the horizontal line
\[
\boxed{y=a}.
\]


::: pf-proof

This is the geometric meaning of step [](#s1-12){.pf-ref}.

:::

:::

::: pf-step

The inequality
\[
\operatorname{Re}z>a
\]
is
\[
\boxed{x>a}.
\]


::: pf-proof

Again,
\[
\operatorname{Re}z=x.
\]

:::

:::

::: {.pf-step #s1-15}

Hence the locus is the open right half-plane bounded by the vertical
line
\[
\boxed{x=a}.
\]


::: pf-proof

The strict inequality excludes the boundary line.

:::

:::

::: pf-step

Squaring
\[
|z-1|<2|z-2|
\]
gives
\[
(x-1)^2+y^2
<
4\bigl((x-2)^2+y^2\bigr).
\]


::: pf-proof

Both sides are nonnegative, so the strict inequality is preserved by
squaring.

:::

:::

::: {.pf-step #s1-17}

Rearranging as in part (b),
\[
\boxed{
\left(x-\frac73\right)^2+y^2
<
\frac49}.
\]


::: pf-proof

The algebra in steps [](#s1-4){.pf-ref} through [](#s1-5){.pf-ref} is unchanged, with equality replaced by a
strict inequality.

:::

:::

::: {.pf-step #s1-18}

Therefore the locus is the open disk centered at
\[
\boxed{\left(\frac73,0\right)}
\]
with radius
\[
\boxed{\frac23}.
\]


::: pf-proof

Step [](#s1-17){.pf-ref} is the standard equation of the interior of that circle.

:::

:::

requested geometric descriptions.

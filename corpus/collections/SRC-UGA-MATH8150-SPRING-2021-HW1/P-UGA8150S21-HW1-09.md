::: {.problem}
Let f(z) be analytic.
Show that $\overline { { f ( \bar { z } ) } }$ is also analytic.
:::

::: {.solution}
Suppose \(f\) is analytic on a domain \(D\). Define the reflected domain
\[
\overline D
=
\{z\in\mathbb C:\overline z\in D\},
\]
and define
\[
g(z)
=
\overline{f(\overline z)}
\qquad
(z\in\overline D).
\]

<1>1. The set \(\overline D\) is a domain.

::: {.proof}
Complex conjugation
\[
z\longmapsto\overline z
\]
is a homeomorphism of \(\mathbb C\). Hence it sends the open connected set
\(D\) to the open connected reflected set \(\overline D\).
:::

<1>2. Fix
\[
z_0\in\overline D
\]
and set
\[
w_0=\overline{z_0}\in D.
\]

::: {.proof}
This is exactly the defining property of \(\overline D\).
:::

<1>3. For sufficiently small \(h\ne0\),
\[
\frac{g(z_0+h)-g(z_0)}{h}
=
\frac{
\overline{
f(w_0+\overline h)-f(w_0)
}
}{h}.
\]

::: {.proof}
Since
\[
\overline{z_0+h}
=
\overline{z_0}+\overline h
=
w_0+\overline h,
\]
substitute the definition of \(g\).
:::

<1>4. The quotient in step <1>3 can be rewritten as
\[
\boxed{
\frac{g(z_0+h)-g(z_0)}{h}
=
\overline{
\frac{
f(w_0+\overline h)-f(w_0)
}{
\overline h
}
}}.
\]

::: {.proof}
For \(h\ne0\),
\[
\overline{
\frac{A}{\overline h}
}
=
\frac{\overline A}{h},
\]
because
\[
\overline{\overline h}=h.
\]
Apply this with
\[
A=f(w_0+\overline h)-f(w_0).
\]
:::

<1>5. As
\[
h\to0,
\]
one also has
\[
\overline h\to0.
\]

::: {.proof}
Complex conjugation preserves modulus:
\[
|\overline h|=|h|.
\]
:::

<1>6. Since \(f\) is analytic at \(w_0\),
\[
\lim_{h\to0}
\frac{
f(w_0+\overline h)-f(w_0)
}{
\overline h
}
=
f'(w_0).
\]

::: {.proof}
By step <1>5, the increment \(\overline h\) approaches \(0\). The defining
difference quotient for \(f'(w_0)\) therefore applies.
:::

<1>7. Taking conjugates in step <1>6,
\[
\lim_{h\to0}
\overline{
\frac{
f(w_0+\overline h)-f(w_0)
}{
\overline h
}
}
=
\overline{f'(w_0)}.
\]

::: {.proof}
Complex conjugation is continuous.
:::

<1>8. Combining steps <1>4 and <1>7,
\[
\boxed{
g'(z_0)
=
\overline{f'(\overline{z_0})}}.
\]

::: {.proof}
The left-hand side is the limit of the difference quotient for \(g\) at
\(z_0\), and
\[
w_0=\overline{z_0}.
\]
:::

<1>9. Since \(z_0\in\overline D\) was arbitrary,
\[
\boxed{
g(z)
=
\overline{f(\overline z)}
\text{ is analytic on }\overline D}.
\]

::: {.proof}
Step <1>8 proves the existence of the complex derivative at every point of
\(\overline D\).
:::

<1>10. In particular, if \(f\) is entire, then
\[
\boxed{
\overline{f(\overline z)}
}
\]
is entire.

::: {.proof}
For \(D=\mathbb C\),
\[
\overline D=\mathbb C.
\]
Apply step <1>9.
:::

<1>11. Q.E.D.

::: {.proof}
Step <1>9 proves the required analyticity.
:::

::: {.problem}
(a) Show that in polar coordinates, the Cauchy-Riemann equations take the form

$$
{ \frac { \partial u } { \partial r } } = { \frac { 1 } { r } } { \frac { \partial v } { \partial \theta } } \quad { \mathrm { a n d } } \quad { \frac { \partial v } { \partial r } } = - { \frac { 1 } { r } } { \frac { \partial u } { \partial \theta } }
$$

(b) Use these equations to show that the logarithm function defined by

$$
\log z : = \log r + i \theta \mathrm { w h e r e } z = r e ^ { i \theta } \mathrm { w i t h } - \pi < \theta < \pi
$$

is a holomorphic function in the region $r > 0 , - \pi < \theta < \pi$ . Also show that log z defined above is not continuous in $r > 0$
:::

::: {.solution}

Write
$$
z=x+iy=re^{i\theta},
\qquad
x=r\cos\theta,
\qquad
y=r\sin\theta.
$$
Let
$$
f=u+iv.
$$

## Part (a)

::: pf

::: {.pf-step #s1-1}

By the chain rule,
$$
\boxed{
u_r
=
u_x\cos\theta+u_y\sin\theta}.
$$


::: pf-proof

Differentiate
$$
u(x(r,\theta),y(r,\theta))
$$
with respect to $r$:
$$
u_r
=
u_xx_r+u_yy_r.
$$
Since
$$
x_r=\cos\theta,
\qquad
y_r=\sin\theta,
$$
the formula follows.

:::

:::

::: {.pf-step #s1-2}

Likewise,
$$
\boxed{
v_\theta
=
-rv_x\sin\theta
+
rv_y\cos\theta}.
$$


::: pf-proof

Differentiate $v(x(r,\theta),y(r,\theta))$ with respect to $\theta$:
$$
v_\theta
=
v_xx_\theta+v_yy_\theta.
$$
Now
$$
x_\theta=-r\sin\theta,
\qquad
y_\theta=r\cos\theta.
$$

:::

:::

::: {.pf-step #s1-3}

If the Cartesian Cauchy--Riemann equations
$$
u_x=v_y,
\qquad
u_y=-v_x
$$
hold, then
$$
u_r
=
v_y\cos\theta-v_x\sin\theta.
$$


::: pf-proof

Substitute
$$
u_x=v_y
$$
and
$$
u_y=-v_x
$$
into step [](#s1-1){.pf-ref}.

:::

:::

::: {.pf-step #s1-4}

Comparing steps [](#s1-2){.pf-ref} through [](#s1-3){.pf-ref} gives
$$
\boxed{
u_r
=
\frac1r\,v_\theta}.
$$


::: pf-proof

Step [](#s1-2){.pf-ref} says
$$
\frac1r\,v_\theta
=
-v_x\sin\theta+v_y\cos\theta,
$$
which is the right-hand side of step [](#s1-3){.pf-ref}.

:::

:::

::: {.pf-step #s1-5}

By the chain rule,
$$
\boxed{
v_r
=
v_x\cos\theta+v_y\sin\theta}.
$$


::: pf-proof

This is the analogue of step [](#s1-1){.pf-ref} for $v$.

:::

:::

::: {.pf-step #s1-6}

Also,
$$
\boxed{
u_\theta
=
-ru_x\sin\theta
+
ru_y\cos\theta}.
$$


::: pf-proof

Apply the chain rule in the $\theta$-direction as in step [](#s1-2){.pf-ref}.

:::

:::

::: {.pf-step #s1-7}

Using the Cartesian Cauchy--Riemann equations,
$$
u_\theta
=
-rv_y\sin\theta-rv_x\cos\theta.
$$


::: pf-proof

Substitute
$$
u_x=v_y,
\qquad
u_y=-v_x
$$
into step [](#s1-6){.pf-ref}.

:::

:::

::: {.pf-step #s1-8}

Therefore
$$
\boxed{
v_r
=
-\frac1r\,u_\theta}.
$$


::: pf-proof

By step [](#s1-5){.pf-ref},
$$
v_r
=
v_x\cos\theta+v_y\sin\theta.
$$
Step [](#s1-7){.pf-ref} gives
$$
-\frac1r\,u_\theta
=
v_x\cos\theta+v_y\sin\theta.
$$

:::

:::

::: {.pf-step #s1-9}

Thus the Cauchy--Riemann equations in polar coordinates are
$$
\boxed{
u_r
=
\frac1r\,v_\theta,
\qquad
v_r
=
-\frac1r\,u_\theta}.
$$


::: pf-proof

Combine steps [](#s1-4){.pf-ref} and [](#s1-8){.pf-ref}.

:::

:::

::: {.pf-step #s1-10}

Conversely, for $r>0$, the polar equations in step [](#s1-9){.pf-ref} imply the
Cartesian Cauchy--Riemann equations.


::: pf-proof

The change-of-variables matrix
$$
\begin{pmatrix}
x_r&y_r\\
x_\theta/r&y_\theta/r
\end{pmatrix}
=
\begin{pmatrix}
\cos\theta&\sin\theta\\
-\sin\theta&\cos\theta
\end{pmatrix}
$$
is invertible. Reversing the calculations in steps [](#s1-1){.pf-ref} through [](#s1-8){.pf-ref} therefore
recovers
$$
u_x=v_y,
\qquad
u_y=-v_x.
$$

:::

:::

::: {.pf-step #s1-11}

The polar derivatives are
$$
\boxed{
u_r=\frac1r,
\qquad
u_\theta=0}.
$$


::: pf-proof

Differentiate $u=\log r$.

:::

:::

::: {.pf-step #s1-12}

Also,
$$
\boxed{
v_r=0,
\qquad
v_\theta=1}.
$$


::: pf-proof

Differentiate $v=\theta$.

:::

:::

::: {.pf-step #s1-13}

The first polar Cauchy--Riemann equation holds:
$$
u_r
=
\frac1r\,v_\theta.
$$


::: pf-proof

By steps [](#s1-11){.pf-ref} through [](#s1-12){.pf-ref},
$$
u_r=\frac1r
$$
and
$$
\frac1r\,v_\theta
=
\frac1r.
$$

:::

:::

::: {.pf-step #s1-14}

The second polar Cauchy--Riemann equation holds:
$$
v_r
=
-\frac1r\,u_\theta.
$$


::: pf-proof

Both sides are zero by steps [](#s1-11){.pf-ref} through [](#s1-12){.pf-ref}.

:::

:::

::: {.pf-step #s1-15}

Therefore
$$
\boxed{
\log z
\text{ is holomorphic on }
\Omega}.
$$


::: pf-proof

The functions $u,v$ have continuous first partial derivatives on
$$
r>0,\qquad -\pi<\theta<\pi,
$$
and satisfy the polar Cauchy--Riemann equations by steps [](#s1-13){.pf-ref} through [](#s1-14){.pf-ref}.
By step [](#s1-10){.pf-ref}, the Cartesian Cauchy--Riemann equations hold, so the function
is holomorphic.

:::

:::

::: pf-step

Its derivative is
$$
\boxed{
(\log z)'=\frac1z}.
$$


::: pf-proof

Using
$$
f'(z)
=
e^{-i\theta}
\left(
u_r+iv_r
\right)
$$
for a holomorphic function in polar coordinates,
$$
f'(z)
=
e^{-i\theta}\frac1r
=
\frac1{re^{i\theta}}
=
\frac1z.
$$

:::

:::

::: {.pf-step #s1-17}

Define
$$
z_n=e^{i(\pi-1/n)}
$$
and
$$
w_n=e^{-i(\pi-1/n)}.
$$
Then
$$
\boxed{
z_n\to-1
\qquad\text{and}\qquad
w_n\to-1}.
$$


::: pf-proof

Their arguments tend to $\pi$ and $-\pi$, respectively, and both
corresponding points on the unit circle tend to $-1$.

:::

:::

::: {.pf-step #s1-18}

For the principal argument,
$$
\log z_n
=
i\left(\pi-\frac1n\right).
$$


::: pf-proof

Both sequences have modulus $1$, so $\log r=0$. The argument of $z_n$
lies in $(-\pi,\pi)$ and equals $\pi-1/n$.

:::

:::

::: {.pf-step #s1-19}

Therefore
$$
\boxed{
\log z_n\to i\pi}.
$$


::: pf-proof

Take $n\to\infty$ in step [](#s1-18){.pf-ref}.

:::

:::

::: {.pf-step #s1-20}

Similarly,
$$
\log w_n
=
-i\left(\pi-\frac1n\right),
$$
so
$$
\boxed{
\log w_n\to-i\pi}.
$$


::: pf-proof

The principal argument of $w_n$ is
$$
-\pi+\frac1n.
$$
Again the modulus is $1$.

:::

:::

::: {.pf-step #s1-21}

Since the two sequences approach the same point $-1$ but their
logarithms have different limits, the principal logarithm cannot be
continuous on the whole punctured plane
$$
\boxed{\{z:|z|>0\}}.
$$


::: pf-proof

Continuity at $-1$ would force every sequence converging to $-1$ to have
image converging to the same value. Steps [](#s1-17){.pf-ref} through [](#s1-20){.pf-ref} violate this.

:::

:::

::: pf-step

The obstruction is exactly the jump of the principal argument across
the negative real axis.


::: pf-proof

Approaching that axis from above gives argument near $+\pi$, while
approaching from below gives argument near $-\pi$, a jump of $2\pi$.

:::

:::

::: pf-qed

Step [](#s1-9){.pf-ref} proves the polar Cauchy--Riemann equations, step [](#s1-15){.pf-ref} proves
holomorphy of the principal logarithm on the slit plane, and step [](#s1-21){.pf-ref}
proves failure of continuity on the whole punctured plane.

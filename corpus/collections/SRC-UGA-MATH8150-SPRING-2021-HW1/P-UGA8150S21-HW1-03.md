::: {.problem}
Prove that the equation $z^3 + 2z + 4 = 0$ has its roots outside the unit circle.
[Hint: what is the maximum value of the modulus of the first two terms if $\abs{z} \le 1$?]
:::

Suppose, toward a contradiction, that
\[
z^3+2z+4=0
\]
for some \(z\) with
\[
|z|\le1.
\]

::: pf

::: pf-step

Rearranging the equation,
\[
\boxed{
z^3+2z=-4}.
\]


::: pf-proof

Subtract \(4\) from both sides.

:::

:::

::: pf-step

Therefore
\[
\boxed{
|z^3+2z|=4}.
\]


::: pf-proof

Take absolute values in step <1>1:
\[
|-4|=4.
\]

:::

:::

::: pf-step

By the triangle inequality,
\[
|z^3+2z|
\le
|z|^3+2|z|.
\]


::: pf-proof

Apply
\[
|a+b|\le|a|+|b|
\]
with
\[
a=z^3,
\qquad
b=2z.
\]

:::

:::

::: pf-step

Since \(|z|\le1\),
\[
|z|^3\le1
\]
and
\[
2|z|\le2.
\]


::: pf-proof

For \(0\le r\le1\),
\[
r^3\le1
\]
and
\[
2r\le2.
\]
Set \(r=|z|\).

:::

:::

::: pf-step

Hence
\[
\boxed{
|z^3+2z|
\le3}.
\]


::: pf-proof

Combine steps <1>3--<1>4:
\[
|z^3+2z|
\le
1+2
=
3.
\]

:::

:::

::: pf-step

Steps <1>2 and <1>5 contradict one another.


::: pf-proof

Step <1>2 gives
\[
|z^3+2z|=4,
\]
while step <1>5 gives
\[
|z^3+2z|\le3.
\]

:::

:::

::: pf-step

Therefore no root of
\[
z^3+2z+4
\]
lies in the closed unit disk.


::: pf-proof

The assumption \(|z|\le1\) led to the contradiction in step <1>6.

:::

:::

::: pf-step

Hence every root satisfies
\[
\boxed{|z|>1}.
\]


::: pf-proof

The complement of the closed unit disk is precisely the set
\[
\{z:|z|>1\}.
\]

:::

:::

::: pf-qed

Step <1>8 is the required conclusion.

:::

:::

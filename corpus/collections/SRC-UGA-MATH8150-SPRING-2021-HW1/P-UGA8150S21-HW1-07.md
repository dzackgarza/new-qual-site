::: {.problem}
Prove that $f ( z ) = | z | ^ { 2 }$ has a derivative only at $z = 0$ , but nowhere else.
:::

Let
\[
f(z)=|z|^2=z\overline z.
\]

## Differentiability at \(0\)

::: pf

::: pf-step

For \(h\ne0\),
\[
\frac{f(h)-f(0)}{h}
=
\frac{|h|^2}{h}.
\]


::: pf-proof

Since
\[
f(0)=0,
\]
the difference quotient is exactly the displayed expression.

:::

:::

::: pf-step

One has
\[
\boxed{
\frac{|h|^2}{h}
=
\overline h}.
\]


::: pf-proof

Because
\[
|h|^2=h\overline h,
\]
division by \(h\ne0\) gives the identity.

:::

:::

::: pf-step

Therefore
\[
\lim_{h\to0}
\frac{f(h)-f(0)}{h}
=
0.
\]


::: pf-proof

By step <1>2, the quotient is \(\overline h\), which tends to \(0\) as
\(h\to0\).

:::

:::

::: pf-step

Hence
\[
\boxed{
f'(0)=0}.
\]


::: pf-proof

Step <1>3 is precisely the definition of the complex derivative at \(0\).

:::

:::

::: pf-step

For \(h\ne0\),
\[
\boxed{
\frac{f(z_0+h)-f(z_0)}{h}
=
\overline{z_0}
+
\overline h
+
z_0\frac{\overline h}{h}}.
\]


::: pf-proof

Expand:
\[
\begin{aligned}
|z_0+h|^2-|z_0|^2
&=
(z_0+h)(\overline{z_0}+\overline h)
-
z_0\overline{z_0}\\
&=
z_0\overline h
+
h\overline{z_0}
+
h\overline h.
\end{aligned}
\]
Divide by \(h\).

:::

:::

::: pf-step

Along real increments
\[
h=t\in\mathbb R,
\qquad
t\to0,
\]
one has
\[
\boxed{
\frac{\overline h}{h}=1}.
\]


::: pf-proof

For real \(t\),
\[
\overline t=t.
\]

:::

:::

::: pf-step

Therefore along real increments, the difference quotient tends to
\[
\boxed{
\overline{z_0}+z_0}.
\]


::: pf-proof

Use step <1>5. Along \(h=t\to0\),
\[
\overline h\to0
\]
and step <1>6 gives
\[
z_0\frac{\overline h}{h}=z_0.
\]

:::

:::

::: pf-step

Along purely imaginary increments
\[
h=it,
\qquad
t\in\mathbb R,
\qquad
t\to0,
\]
one has
\[
\boxed{
\frac{\overline h}{h}=-1}.
\]


::: pf-proof

If \(h=it\), then
\[
\overline h=-it,
\]
so
\[
\frac{\overline h}{h}
=
\frac{-it}{it}
=
-1.
\]

:::

:::

::: pf-step

Therefore along purely imaginary increments, the difference quotient
tends to
\[
\boxed{
\overline{z_0}-z_0}.
\]


::: pf-proof

Use step <1>5. Along \(h=it\to0\),
\[
\overline h\to0
\]
and step <1>8 gives
\[
z_0\frac{\overline h}{h}=-z_0.
\]

:::

:::

::: pf-step

If the complex derivative \(f'(z_0)\) existed, the two limits in
steps <1>7 and <1>9 would have to agree.


::: pf-proof

A complex limit is independent of the path along which the increment tends
to \(0\).

:::

:::

::: pf-step

Equality of the two candidate limits would imply
\[
\overline{z_0}+z_0
=
\overline{z_0}-z_0.
\]


::: pf-proof

Set the limits from steps <1>7 and <1>9 equal.

:::

:::

::: pf-step

Hence
\[
2z_0=0,
\]
so
\[
z_0=0.
\]


::: pf-proof

Subtract
\[
\overline{z_0}
\]
from both sides of step <1>11.

:::

:::

::: pf-step

This contradicts the assumption
\[
z_0\ne0.
\]


::: pf-proof

The point \(z_0\) was fixed as nonzero before step <1>5.

:::

:::

::: pf-step

Therefore \(f\) is not complex differentiable at any
\[
z_0\ne0.
\]


::: pf-proof

If it were differentiable at such a point, steps <1>10--<1>13 would give a
contradiction.

:::

:::

::: pf-step

Consequently,
\[
\boxed{
f(z)=|z|^2
\text{ is complex differentiable exactly at }z=0}.
\]


::: pf-proof

Differentiability at \(0\) is step <1>4, and non-differentiability elsewhere
is step <1>14.

:::

:::

::: pf-qed

Step <1>15 is the required conclusion.

:::

:::

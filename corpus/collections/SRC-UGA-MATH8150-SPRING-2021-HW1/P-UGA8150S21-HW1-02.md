::: {.problem}
Prove that $| z _ { 1 } + z _ { 2 } | \geq | | z _ { 1 } | - | z _ { 2 } | |$ and explain when equality holds.
:::

::: pf

::: pf-step

By the triangle inequality,
\[
|z_1|
=
|(z_1+z_2)-z_2|
\le
|z_1+z_2|+|z_2|.
\]


::: pf-proof

Apply the triangle inequality to the two complex numbers
\[
z_1+z_2
\qquad\text{and}\qquad
-z_2.
\]

:::

:::

::: pf-step

Therefore
\[
|z_1|-|z_2|
\le
|z_1+z_2|.
\]


::: pf-proof

Subtract \(|z_2|\) from both sides of step <1>1.

:::

:::

::: pf-step

Interchanging \(z_1\) and \(z_2\) gives
\[
|z_2|-|z_1|
\le
|z_1+z_2|.
\]


::: pf-proof

Apply step <1>2 with the two variables reversed.

:::

:::

::: pf-step

Combining steps <1>2--<1>3,
\[
\boxed{
|z_1+z_2|
\ge
\bigl||z_1|-|z_2|\bigr|}.
\]


::: pf-proof

The two inequalities say that
\[
|z_1+z_2|
\]
is at least both
\[
|z_1|-|z_2|
\]
and
\[
|z_2|-|z_1|.
\]
The maximum of these two numbers is
\[
\bigl||z_1|-|z_2|\bigr|.
\]

:::

:::

::: pf-step

Equality in step <1>4 is equivalent to
\[
\boxed{
|z_1+z_2|^2
=
\bigl(|z_1|-|z_2|\bigr)^2}.
\]


::: pf-proof

Both sides of step <1>4 are nonnegative, so equality is preserved by
squaring.

:::

:::

::: pf-step

One has
\[
|z_1+z_2|^2
=
|z_1|^2+|z_2|^2
+
2\operatorname{Re}(z_1\overline{z_2}).
\]


::: pf-proof

Expand
\[
(z_1+z_2)(\overline{z_1}+\overline{z_2}).
\]

:::

:::

::: pf-step

Also,
\[
\bigl(|z_1|-|z_2|\bigr)^2
=
|z_1|^2+|z_2|^2
-
2|z_1||z_2|.
\]


::: pf-proof

Expand the square.

:::

:::

::: pf-step

Therefore equality holds if and only if
\[
\boxed{
\operatorname{Re}(z_1\overline{z_2})
=
-|z_1||z_2|}.
\]


::: pf-proof

Compare the right-hand sides of steps <1>6--<1>7 and cancel the common
terms.

:::

:::

::: pf-step

If both \(z_1,z_2\ne0\), the condition in step <1>8 holds if and only
if \(z_1\) and \(z_2\) point in opposite directions.


::: pf-proof

Write
\[
z_1\overline{z_2}
=
|z_1||z_2|e^{i\theta},
\]
where \(\theta\) is the oriented angle from \(z_2\) to \(z_1\). Then
\[
\operatorname{Re}(z_1\overline{z_2})
=
|z_1||z_2|\cos\theta.
\]
Step <1>8 is therefore equivalent to
\[
\cos\theta=-1,
\]
hence
\[
\theta\equiv\pi\pmod{2\pi}.
\]

:::

:::

::: pf-step

Equivalently, when both numbers are nonzero, equality holds exactly
when
\[
\boxed{
z_1=-t z_2
\quad\text{for some }t>0}.
\]


::: pf-proof

Two nonzero complex numbers point in opposite directions exactly when their
ratio is a negative real number.

:::

:::

::: pf-step

If either \(z_1=0\) or \(z_2=0\), equality also holds.


::: pf-proof

If \(z_2=0\), for example,
\[
|z_1+z_2|
=
|z_1|
=
\bigl||z_1|-0\bigr|.
\]
The case \(z_1=0\) is symmetric.

:::

:::

::: pf-step

Hence equality holds exactly when the two complex numbers are
collinear with opposite directions, allowing either one to be zero.


::: pf-proof

Combine steps <1>9--<1>11.

:::

:::

::: pf-qed

Step <1>4 proves the inequality and step <1>12 gives the equality
criterion.

:::

:::

::: {.problem}
(a) Let z, w be complex numbers, such that $\bar { z } w \ne 1$ . Prove that

$$
\left| { \frac { w - z } { 1 - { \bar { w } } z } } \right| < 1 \ \mathrm { ~ i f ~ } | z | < 1 \ \mathrm { a n d ~ } | w | < 1 ,
$$

and also that

$$
\left| { \frac { w - z } { 1 - { \bar { w } } z } } \right| = 1 \ \mathrm { ~ i f ~ } | z | = 1 \ \mathrm { { o r } } \ | w | = 1 .
$$

(b) Prove that for fixed w in the unit disk ${ \DD } : = \{ z : | z | < 1 \}$ , the mapping

$$
{ \cal F } : z \mapsto \frac { w - z } { 1 - \bar { w } z }
$$

satisfies the following conditions:

(i) F maps D to itself and is holomorphic.

(ii) F interchanges 0 and w, namely, $F ( 0 ) = w$ and $F ( w ) = 0$

(iii) $| F ( z ) | = 1 { \mathrm { ~ i f ~ } } | z | = 1$

(iv) $F : \DD \mapsto \DD$ is bijective.
[Hint: Calculate $F \circ F . ]$
:::

::: {.solution}

## Part (a)

Let
$$
N=|1-\overline wz|^2-|w-z|^2.
$$

::: pf

::: {.pf-step #s1-1}

Expanding the first modulus,
$$
|1-\overline wz|^2
=
1
-\overline wz
-w\overline z
+
|w|^2|z|^2.
$$


::: pf-proof

Multiply by the complex conjugate:
$$
(1-\overline wz)(1-w\overline z).
$$

:::

:::

::: {.pf-step #s1-2}

Expanding the second modulus,
$$
|w-z|^2
=
|w|^2+|z|^2-w\overline z-\overline wz.
$$


::: pf-proof

Multiply
$$
(w-z)(\overline w-\overline z).
$$

:::

:::

::: {.pf-step #s1-3}

Subtracting,
$$
\boxed{
N
=
(1-|w|^2)(1-|z|^2)}.
$$


::: pf-proof

Using steps [](#s1-1){.pf-ref} through [](#s1-2){.pf-ref},
$$
\begin{aligned}
N
&=
1-|w|^2-|z|^2+|w|^2|z|^2\\
&=
(1-|w|^2)(1-|z|^2).
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-4}

If
$$
|w|<1
\qquad\text{and}\qquad
|z|<1,
$$
then
$$
\boxed{
|1-\overline wz|^2>|w-z|^2}.
$$


::: pf-proof

Both factors on the right-hand side of step [](#s1-3){.pf-ref} are positive, so
$$
N>0.
$$

:::

:::

::: {.pf-step #s1-5}

Hence
$$
\boxed{
\left|
\frac{w-z}{1-\overline wz}
\right|
<1}
$$
when $|w|<1$ and $|z|<1$.


::: pf-proof

The denominator is nonzero because
$$
|\overline wz|
=
|w||z|
<1.
$$
Step [](#s1-4){.pf-ref} gives
$$
|w-z|<|1-\overline wz|.
$$
Divide by the positive denominator modulus.

:::

:::

::: {.pf-step #s1-6}

If
$$
|w|=1
\qquad\text{or}\qquad
|z|=1,
$$
then
$$
\boxed{
|1-\overline wz|^2
=
|w-z|^2}.
$$


::: pf-proof

At least one factor on the right-hand side of step [](#s1-3){.pf-ref} is zero, so
$$
N=0.
$$

:::

:::

::: {.pf-step #s1-7}

Under the standing assumption
$$
\overline zw\ne1,
$$
the denominator
$$
1-\overline wz
$$
is nonzero.


::: pf-proof

If
$$
1-\overline wz=0,
$$
then
$$
\overline wz=1.
$$
Taking complex conjugates gives
$$
w\overline z=1,
$$
which is exactly
$$
\overline zw=1,
$$
contrary to the hypothesis.

:::

:::

::: {.pf-step #s1-8}

Therefore, if $|w|=1$ or $|z|=1$,
$$
\boxed{
\left|
\frac{w-z}{1-\overline wz}
\right|
=1}.
$$


::: pf-proof

Use steps [](#s1-6){.pf-ref} through [](#s1-7){.pf-ref} and take nonnegative square roots.

:::

:::

::: {.pf-step #s1-9}

For every $z\in\DD$,
$$
1-\overline wz\ne0.
$$


::: pf-proof

Since
$$
|w|<1
\qquad\text{and}\qquad
|z|<1,
$$
one has
$$
|\overline wz|
=
|w||z|
<1.
$$
Thus $\overline wz\ne1$.

:::

:::

::: {.pf-step #s1-10}

Hence $F$ is holomorphic on $\DD$.


::: pf-proof

The numerator and denominator are affine holomorphic functions of $z$, and
the denominator has no zeros on $\DD$ by step [](#s1-9){.pf-ref}.

:::

:::

::: {.pf-step #s1-11}

For every $z\in\DD$,
$$
\boxed{|F(z)|<1}.
$$


::: pf-proof

Apply step [](#s1-5){.pf-ref} with the fixed $w\in\DD$.

:::

:::

::: {.pf-step #s1-12}

Therefore
$$
\boxed{
F(\DD)\subseteq\DD}.
$$


::: pf-proof

This is the content of step [](#s1-11){.pf-ref}.

:::

:::

::: {.pf-step #s1-13}

One has
$$
\boxed{F(0)=w}.
$$


::: pf-proof

$$
F(0)
=
\frac{w}{1}
=
w.
$$

:::

:::

::: {.pf-step #s1-14}

One has
$$
\boxed{F(w)=0}.
$$


::: pf-proof

$$
F(w)
=
\frac{w-w}{1-|w|^2}
=
0.
$$
The denominator is nonzero because $|w|<1$.

:::

:::

::: {.pf-step #s1-15}

If
$$
|z|=1,
$$
then
$$
\boxed{|F(z)|=1}.
$$


::: pf-proof

Apply step [](#s1-8){.pf-ref}. Since $|w|<1$, the denominator cannot vanish on the unit
circle.

:::

:::

::: {.pf-step #s1-16}

Conversely, if
$$
|F(z)|=1
$$
and the expression is defined, then
$$
\boxed{|z|=1}.
$$


::: pf-proof

By step [](#s1-3){.pf-ref},
$$
|1-\overline wz|^2-|w-z|^2
=
(1-|w|^2)(1-|z|^2).
$$
The hypothesis
$$
|F(z)|=1
$$
means the two moduli on the left are equal, so the left side is zero.
Because
$$
1-|w|^2>0,
$$
one must have
$$
1-|z|^2=0.
$$
Thus $|z|=1$.

:::

:::

::: {.pf-step #s1-17}

Therefore
$$
\boxed{
|F(z)|=1
\iff
|z|=1}.
$$


::: pf-proof

The forward implication is step [](#s1-16){.pf-ref}, and the reverse implication is step
[](#s1-15){.pf-ref}.

:::

:::

::: {.pf-step #s1-18}

The numerator of $F(F(z))$ is
$$
w-F(z)
=
\frac{(1-|w|^2)z}{1-\overline wz}.
$$


::: pf-proof

Compute
$$
\begin{aligned}
w-F(z)
&=
w-\frac{w-z}{1-\overline wz}\\
&=
\frac{w(1-\overline wz)-(w-z)}
{1-\overline wz}\\
&=
\frac{z-|w|^2z}
{1-\overline wz}.
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-19}

The denominator of $F(F(z))$ is
$$
1-\overline wF(z)
=
\frac{1-|w|^2}{1-\overline wz}.
$$


::: pf-proof

$$
\begin{aligned}
1-\overline wF(z)
&=
1-\overline w
\frac{w-z}{1-\overline wz}\\
&=
\frac{
1-\overline wz-|w|^2+\overline wz
}{
1-\overline wz
}\\
&=
\frac{1-|w|^2}{1-\overline wz}.
\end{aligned}
$$

:::

:::

::: {.pf-step #s1-20}

Therefore
$$
\boxed{F(F(z))=z}
$$
for every $z\in\DD$.


::: pf-proof

Divide the expressions from steps [](#s1-18){.pf-ref} through [](#s1-19){.pf-ref}:
$$
F(F(z))
=
\frac{(1-|w|^2)z}
{1-|w|^2}
=
z.
$$
The scalar $1-|w|^2$ is nonzero.

:::

:::

::: {.pf-step #s1-21}

Hence $F:\DD\to\DD$ is injective.


::: pf-proof

If
$$
F(z_1)=F(z_2),
$$
apply $F$ to both sides:
$$
F(F(z_1))
=
F(F(z_2)).
$$
By step [](#s1-20){.pf-ref},
$$
z_1=z_2.
$$

:::

:::

::: {.pf-step #s1-22}

The map $F:\DD\to\DD$ is surjective.


::: pf-proof

Given $y\in\DD$, set
$$
z=F(y).
$$
By step [](#s1-12){.pf-ref},
$$
z\in\DD.
$$
Then step [](#s1-20){.pf-ref} gives
$$
F(z)
=
F(F(y))
=
y.
$$

:::

:::

::: {.pf-step #s1-23}

Thus
$$
\boxed{
F:\DD\to\DD
\text{ is a biholomorphic involution}}.
$$


::: pf-proof

Holomorphicity is step [](#s1-10){.pf-ref}, mapping into the disk is step [](#s1-12){.pf-ref},
bijectivity is steps [](#s1-21){.pf-ref} through [](#s1-22){.pf-ref}, and involutivity is step [](#s1-20){.pf-ref}.

:::

:::

claims in part (b).

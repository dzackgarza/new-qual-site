::: {.problem}
(a) Let z, w be complex numbers, such that $\bar { z } w \ne 1$ . Prove that

$$
\left| { \frac { w - z } { 1 - { \bar { w } } z } } \right| < 1 \ \mathrm { ~ i f ~ } | z | < 1 \ \mathrm { a n d ~ } | w | < 1 ,
$$

and also that

$$
\left| { \frac { w - z } { 1 - { \bar { w } } z } } \right| = 1 \ \mathrm { ~ i f ~ } | z | = 1 \ \mathrm { { o r } } \ | w | = 1 .
$$

(b) Prove that for fixed w in the unit disk ${ \mathbb D } : = \{ z : | z | < 1 \}$ , the mapping

$$
{ \cal F } : z \mapsto \frac { w - z } { 1 - \bar { w } z }
$$

satisfies the following conditions:

(i) F maps D to itself and is holomorphic.

(ii) F interchanges 0 and w, namely, $F ( 0 ) = w$ and $F ( w ) = 0$

(iii) $| F ( z ) | = 1 { \mathrm { ~ i f ~ } } | z | = 1$

(iv) $F : \mathbb { D } \mapsto \mathbb { D }$ is bijective.
[Hint: Calculate $F \circ F . ]$
:::

## Part (a)

Let
\[
N=|1-\overline wz|^2-|w-z|^2.
\]

::: pf

::: pf-step

Expanding the first modulus,
\[
|1-\overline wz|^2
=
1
-\overline wz
-w\overline z
+
|w|^2|z|^2.
\]


::: pf-proof

Multiply by the complex conjugate:
\[
(1-\overline wz)(1-w\overline z).
\]

:::

:::

::: pf-step

Expanding the second modulus,
\[
|w-z|^2
=
|w|^2+|z|^2-w\overline z-\overline wz.
\]


::: pf-proof

Multiply
\[
(w-z)(\overline w-\overline z).
\]

:::

:::

::: pf-step

Subtracting,
\[
\boxed{
N
=
(1-|w|^2)(1-|z|^2)}.
\]


::: pf-proof

Using steps <1>1--<1>2,
\[
\begin{aligned}
N
&=
1-|w|^2-|z|^2+|w|^2|z|^2\\
&=
(1-|w|^2)(1-|z|^2).
\end{aligned}
\]

:::

:::

::: pf-step

If
\[
|w|<1
\qquad\text{and}\qquad
|z|<1,
\]
then
\[
\boxed{
|1-\overline wz|^2>|w-z|^2}.
\]


::: pf-proof

Both factors on the right-hand side of step <1>3 are positive, so
\[
N>0.
\]

:::

:::

::: pf-step

Hence
\[
\boxed{
\left|
\frac{w-z}{1-\overline wz}
\right|
<1}
\]
when \(|w|<1\) and \(|z|<1\).


::: pf-proof

The denominator is nonzero because
\[
|\overline wz|
=
|w||z|
<1.
\]
Step <1>4 gives
\[
|w-z|<|1-\overline wz|.
\]
Divide by the positive denominator modulus.

:::

:::

::: pf-step

If
\[
|w|=1
\qquad\text{or}\qquad
|z|=1,
\]
then
\[
\boxed{
|1-\overline wz|^2
=
|w-z|^2}.
\]


::: pf-proof

At least one factor on the right-hand side of step <1>3 is zero, so
\[
N=0.
\]

:::

:::

::: pf-step

Under the standing assumption
\[
\overline zw\ne1,
\]
the denominator
\[
1-\overline wz
\]
is nonzero.


::: pf-proof

If
\[
1-\overline wz=0,
\]
then
\[
\overline wz=1.
\]
Taking complex conjugates gives
\[
w\overline z=1,
\]
which is exactly
\[
\overline zw=1,
\]
contrary to the hypothesis.

:::

:::

::: pf-step

Therefore, if \(|w|=1\) or \(|z|=1\),
\[
\boxed{
\left|
\frac{w-z}{1-\overline wz}
\right|
=1}.
\]


::: pf-proof

Use steps <1>6--<1>7 and take nonnegative square roots.

:::

:::

::: pf-step

For every \(z\in\mathbb D\),
\[
1-\overline wz\ne0.
\]


::: pf-proof

Since
\[
|w|<1
\qquad\text{and}\qquad
|z|<1,
\]
one has
\[
|\overline wz|
=
|w||z|
<1.
\]
Thus \(\overline wz\ne1\).

:::

:::

::: pf-step

Hence \(F\) is holomorphic on \(\mathbb D\).


::: pf-proof

The numerator and denominator are affine holomorphic functions of \(z\), and
the denominator has no zeros on \(\mathbb D\) by step <1>9.

:::

:::

::: pf-step

For every \(z\in\mathbb D\),
\[
\boxed{|F(z)|<1}.
\]


::: pf-proof

Apply step <1>5 with the fixed \(w\in\mathbb D\).

:::

:::

::: pf-step

Therefore
\[
\boxed{
F(\mathbb D)\subseteq\mathbb D}.
\]


::: pf-proof

This is the content of step <1>11.

:::

:::

::: pf-step

One has
\[
\boxed{F(0)=w}.
\]


::: pf-proof

\[
F(0)
=
\frac{w}{1}
=
w.
\]

:::

:::

::: pf-step

One has
\[
\boxed{F(w)=0}.
\]


::: pf-proof

\[
F(w)
=
\frac{w-w}{1-|w|^2}
=
0.
\]
The denominator is nonzero because \(|w|<1\).

:::

:::

::: pf-step

If
\[
|z|=1,
\]
then
\[
\boxed{|F(z)|=1}.
\]


::: pf-proof

Apply step <1>8. Since \(|w|<1\), the denominator cannot vanish on the unit
circle.

:::

:::

::: pf-step

Conversely, if
\[
|F(z)|=1
\]
and the expression is defined, then
\[
\boxed{|z|=1}.
\]


::: pf-proof

By step <1>3,
\[
|1-\overline wz|^2-|w-z|^2
=
(1-|w|^2)(1-|z|^2).
\]
The hypothesis
\[
|F(z)|=1
\]
means the two moduli on the left are equal, so the left side is zero.
Because
\[
1-|w|^2>0,
\]
one must have
\[
1-|z|^2=0.
\]
Thus \(|z|=1\).

:::

:::

::: pf-step

Therefore
\[
\boxed{
|F(z)|=1
\iff
|z|=1}.
\]


::: pf-proof

The forward implication is step <1>16, and the reverse implication is step
<1>15.

:::

:::

::: pf-step

The numerator of \(F(F(z))\) is
\[
w-F(z)
=
\frac{(1-|w|^2)z}{1-\overline wz}.
\]


::: pf-proof

Compute
\[
\begin{aligned}
w-F(z)
&=
w-\frac{w-z}{1-\overline wz}\\
&=
\frac{w(1-\overline wz)-(w-z)}
{1-\overline wz}\\
&=
\frac{z-|w|^2z}
{1-\overline wz}.
\end{aligned}
\]

:::

:::

::: pf-step

The denominator of \(F(F(z))\) is
\[
1-\overline wF(z)
=
\frac{1-|w|^2}{1-\overline wz}.
\]


::: pf-proof

\[
\begin{aligned}
1-\overline wF(z)
&=
1-\overline w
\frac{w-z}{1-\overline wz}\\
&=
\frac{
1-\overline wz-|w|^2+\overline wz
}{
1-\overline wz
}\\
&=
\frac{1-|w|^2}{1-\overline wz}.
\end{aligned}
\]

:::

:::

::: pf-step

Therefore
\[
\boxed{F(F(z))=z}
\]
for every \(z\in\mathbb D\).


::: pf-proof

Divide the expressions from steps <1>18--<1>19:
\[
F(F(z))
=
\frac{(1-|w|^2)z}
{1-|w|^2}
=
z.
\]
The scalar \(1-|w|^2\) is nonzero.

:::

:::

::: pf-step

Hence \(F:\mathbb D\to\mathbb D\) is injective.


::: pf-proof

If
\[
F(z_1)=F(z_2),
\]
apply \(F\) to both sides:
\[
F(F(z_1))
=
F(F(z_2)).
\]
By step <1>20,
\[
z_1=z_2.
\]

:::

:::

::: pf-step

The map \(F:\mathbb D\to\mathbb D\) is surjective.


::: pf-proof

Given \(y\in\mathbb D\), set
\[
z=F(y).
\]
By step <1>12,
\[
z\in\mathbb D.
\]
Then step <1>20 gives
\[
F(z)
=
F(F(y))
=
y.
\]

:::

:::

::: pf-step

Thus
\[
\boxed{
F:\mathbb D\to\mathbb D
\text{ is a biholomorphic involution}}.
\]


::: pf-proof

Holomorphicity is step <1>10, mapping into the disk is step <1>12,
bijectivity is steps <1>21--<1>22, and involutivity is step <1>20.

:::

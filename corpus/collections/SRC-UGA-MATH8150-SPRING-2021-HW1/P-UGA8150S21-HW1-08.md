::: {.problem}
Let $f(z)$ be analytic in a domain. Prove that $f(z)$ is a constant if it satisfies any of the following conditions:

(a) $\abs{f(z)}$ is constant;

(b) $\operatorname{Re}(f(z))$ is constant;

(c) $\arg(f(z))$ is constant;

(d) $\overline{f(z)}$ is analytic;

How do you generalize (a) and (b)?
:::

::: {.solution}
Let
\[
f=u+iv
\]
with real-valued functions \(u,v\). Since \(f\) is analytic, the
Cauchy--Riemann equations hold:
\[
\boxed{
u_x=v_y,
\qquad
u_y=-v_x}.
\]

## Part (a)

Assume
\[
|f(z)|=c
\]
for all \(z\) in the domain.

<1>1. If
\[
c=0,
\]
then
\[
\boxed{f\equiv0}.
\]

::: {.proof}
A complex number has modulus zero exactly when it is zero.
:::

<1>2. Suppose
\[
c>0.
\]
Then
\[
|f|
\]
attains its maximum value \(c\) at every point of the domain.

::: {.proof}
The modulus is identically equal to \(c\).
:::

<1>3. By the maximum modulus principle,
\[
\boxed{f\text{ is constant}}.
\]

::: {.proof}
A nonconstant analytic function cannot attain a local maximum of its modulus
at an interior point. Step <1>2 says every point would be such a maximum.
:::

## Part (b)

Assume
\[
\operatorname{Re}f=u
\]
is constant.

<1>4. Then
\[
\boxed{
u_x=u_y=0}.
\]

::: {.proof}
All partial derivatives of a constant function vanish.
:::

<1>5. By the Cauchy--Riemann equations,
\[
\boxed{
v_x=v_y=0}.
\]

::: {.proof}
From
\[
u_x=v_y
\]
and
\[
u_y=-v_x,
\]
use step <1>4.
:::

<1>6. Hence \(v\) is constant on the domain.

::: {.proof}
A \(C^1\) function with zero gradient is constant on each connected
component. A domain is connected.
:::

<1>7. Therefore
\[
\boxed{f=u+iv\text{ is constant}}.
\]

::: {.proof}
Both \(u\) and \(v\) are constant by the hypothesis and step <1>6.
:::

## Part (c)

Assume
\[
\arg f(z)=\theta_0
\]
is constant.

<1>8. The function \(f\) has no zeros.

::: {.proof}
The argument of \(0\) is undefined. Thus the hypothesis that \(\arg f(z)\)
is defined and constant on the domain excludes zeros.
:::

<1>9. Define
\[
g(z)=e^{-i\theta_0}f(z).
\]
Then
\[
\boxed{
g(z)\in(0,\infty)}
\]
for every \(z\).

::: {.proof}
Multiplication by \(e^{-i\theta_0}\) rotates every value of \(f\) by
\(-\theta_0\), so the constant argument becomes \(0\). By step <1>8 the
values are nonzero.
:::

<1>10. The function \(g\) is analytic.

::: {.proof}
It is a constant multiple of the analytic function \(f\).
:::

<1>11. The function
\[
-ig
\]
has constant real part \(0\).

::: {.proof}
Since \(g\) is real-valued,
\[
-ig
\]
is purely imaginary.
:::

<1>12. Therefore \(g\), and hence \(f\), is constant.

::: {.proof}
Apply part (b), step <1>7, to the analytic function \(-ig\). Then \(-ig\)
is constant, so \(g\) and \(f=e^{i\theta_0}g\) are constant.
:::

## Part (d)

Assume
\[
\overline{f}
\]
is also analytic.

<1>13. The function
\[
h=f+\overline f
\]
is analytic.

::: {.proof}
It is the sum of two analytic functions.
:::

<1>14. One has
\[
\boxed{
h=2\operatorname{Re}f=2u},
\]
so \(h\) is real-valued.

::: {.proof}
\[
f+\overline f
=
(u+iv)+(u-iv)
=
2u.
\]
:::

<1>15. Therefore \(h\) is constant.

::: {.proof}
The analytic function
\[
-ih
\]
has real part \(0\), so part (b) implies \(-ih\), hence \(h\), is constant.
:::

<1>16. Hence
\[
\operatorname{Re}f
\]
is constant.

::: {.proof}
By step <1>14,
\[
\operatorname{Re}f=\frac h2.
\]
Use step <1>15.
:::

<1>17. Therefore
\[
\boxed{f\text{ is constant}}.
\]

::: {.proof}
Apply part (b), step <1>7, to \(f\).
:::

## Generalizations of (a) and (b)

<1>18. Suppose the image of \(f\) lies in a circle
\[
\boxed{|w-a|=R}
\]
for fixed \(a\in\mathbb C\) and \(R\ge0\). Then \(f\) is constant.

::: {.proof}
The analytic function
\[
g=f-a
\]
has constant modulus
\[
|g|=R.
\]
Apply part (a).
:::

<1>19. Suppose the image of \(f\) lies in a straight line in \(\mathbb C\).
Then \(f\) is constant.

::: {.proof}
Every straight line can be written in the form
\[
\operatorname{Re}\!\left(
e^{-i\theta}(w-a)
\right)=c
\]
for suitable constants \(a\in\mathbb C\), \(\theta\in\mathbb R\), and
\(c\in\mathbb R\).

Thus
\[
g(z)
=
e^{-i\theta}(f(z)-a)
\]
is analytic and has constant real part. Apply part (b).
:::

<1>20. Hence the general rigidity statement is
\[
\boxed{
\text{an analytic map whose image is contained in a circle or a line is
constant}.}
\]

::: {.proof}
The circle case is step <1>18 and the line case is step <1>19.
:::

<1>21. Q.E.D.

::: {.proof}
Steps <1>3, <1>7, <1>12, and <1>17 prove parts (a)--(d), and step <1>20
gives the requested generalization.
:::
:::

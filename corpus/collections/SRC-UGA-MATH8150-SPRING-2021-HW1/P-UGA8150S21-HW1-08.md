::: {.problem}
Let $f(z)$ be analytic in a domain. Prove that $f(z)$ is a constant if it satisfies any of the following conditions:

(a) $\abs{f(z)}$ is constant;

(b) $\operatorname{Re}(f(z))$ is constant;

(c) $\arg(f(z))$ is constant;

(d) $\overline{f(z)}$ is analytic;

How do you generalize (a) and (b)?
:::

::: {.solution}

Let
\[
f=u+iv
\]
with real-valued functions \(u,v\). Since \(f\) is analytic, the
Cauchy--Riemann equations hold:
\[
\boxed{
u_x=v_y,
\qquad
u_y=-v_x}.
\]

## Part (a)

Assume
\[
|f(z)|=c
\]
for all \(z\) in the domain.

::: pf

::: pf-step

If
\[
c=0,
\]
then
\[
\boxed{f\equiv0}.
\]


::: pf-proof

A complex number has modulus zero exactly when it is zero.

:::

:::

::: {.pf-step #s1-2}

Suppose
\[
c>0.
\]
Then
\[
|f|
\]
attains its maximum value \(c\) at every point of the domain.


::: pf-proof

The modulus is identically equal to \(c\).

:::

:::

::: {.pf-step #s1-3}

By the maximum modulus principle,
\[
\boxed{f\text{ is constant}}.
\]


::: pf-proof

A nonconstant analytic function cannot attain a local maximum of its modulus
at an interior point. Step [](#s1-2){.pf-ref} says every point would be such a maximum.

:::

:::

::: {.pf-step #s1-4}

Then
\[
\boxed{
u_x=u_y=0}.
\]


::: pf-proof

All partial derivatives of a constant function vanish.

:::

:::

::: pf-step

By the Cauchy--Riemann equations,
\[
\boxed{
v_x=v_y=0}.
\]


::: pf-proof

From
\[
u_x=v_y
\]
and
\[
u_y=-v_x,
\]
use step [](#s1-4){.pf-ref}.

:::

:::

::: {.pf-step #s1-6}

Hence \(v\) is constant on the domain.


::: pf-proof

A \(C^1\) function with zero gradient is constant on each connected
component. A domain is connected.

:::

:::

::: {.pf-step #s1-7}

Therefore
\[
\boxed{f=u+iv\text{ is constant}}.
\]


::: pf-proof

Both \(u\) and \(v\) are constant by the hypothesis and step [](#s1-6){.pf-ref}.

:::

:::

::: {.pf-step #s1-8}

The function \(f\) has no zeros.


::: pf-proof

The argument of \(0\) is undefined. Thus the hypothesis that \(\arg f(z)\)
is defined and constant on the domain excludes zeros.

:::

:::

::: pf-step

Define
\[
g(z)=e^{-i\theta_0}f(z).
\]
Then
\[
\boxed{
g(z)\in(0,\infty)}
\]
for every \(z\).


::: pf-proof

Multiplication by \(e^{-i\theta_0}\) rotates every value of \(f\) by
\(-\theta_0\), so the constant argument becomes \(0\). By step [](#s1-8){.pf-ref} the
values are nonzero.

:::

:::

::: pf-step

The function \(g\) is analytic.


::: pf-proof

It is a constant multiple of the analytic function \(f\).

:::

:::

::: pf-step

The function
\[
-ig
\]
has constant real part \(0\).


::: pf-proof

Since \(g\) is real-valued,
\[
-ig
\]
is purely imaginary.

:::

:::

::: {.pf-step #s1-12}

Therefore \(g\), and hence \(f\), is constant.


::: pf-proof

Apply part (b), step [](#s1-7){.pf-ref}, to the analytic function \(-ig\). Then \(-ig\)
is constant, so \(g\) and \(f=e^{i\theta_0}g\) are constant.

:::

:::

::: pf-step

The function
\[
h=f+\overline f
\]
is analytic.


::: pf-proof

It is the sum of two analytic functions.

:::

:::

::: {.pf-step #s1-14}

One has
\[
\boxed{
h=2\operatorname{Re}f=2u},
\]
so \(h\) is real-valued.


::: pf-proof

\[
f+\overline f
=
(u+iv)+(u-iv)
=
2u.
\]

:::

:::

::: {.pf-step #s1-15}

Therefore \(h\) is constant.


::: pf-proof

The analytic function
\[
-ih
\]
has real part \(0\), so part (b) implies \(-ih\), hence \(h\), is constant.

:::

:::

::: pf-step

Hence
\[
\operatorname{Re}f
\]
is constant.


::: pf-proof

By step [](#s1-14){.pf-ref},
\[
\operatorname{Re}f=\frac h2.
\]
Use step [](#s1-15){.pf-ref}.

:::

:::

::: {.pf-step #s1-17}

Therefore
\[
\boxed{f\text{ is constant}}.
\]


::: pf-proof

Apply part (b), step [](#s1-7){.pf-ref}, to \(f\).

:::

:::

::: {.pf-step #s1-18}

Suppose the image of \(f\) lies in a circle
\[
\boxed{|w-a|=R}
\]
for fixed \(a\in\CC\) and \(R\ge0\). Then \(f\) is constant.


::: pf-proof

The analytic function
\[
g=f-a
\]
has constant modulus
\[
|g|=R.
\]
Apply part (a).

:::

:::

::: {.pf-step #s1-19}

Suppose the image of \(f\) lies in a straight line in \(\CC\).
Then \(f\) is constant.


::: pf-proof

Every straight line can be written in the form
\[
\operatorname{Re}\!\left(
e^{-i\theta}(w-a)
\right)=c
\]
for suitable constants \(a\in\CC\), \(\theta\in\RR\), and
\(c\in\RR\).

Thus
\[
g(z)
=
e^{-i\theta}(f(z)-a)
\]
is analytic and has constant real part. Apply part (b).

:::

:::

::: {.pf-step #s1-20}

Hence the general rigidity statement is
\[
\boxed{
\text{an analytic map whose image is contained in a circle or a line is
constant}.}
\]


::: pf-proof

The circle case is step [](#s1-18){.pf-ref} and the line case is step [](#s1-19){.pf-ref}.

:::

:::

::: pf-qed

Steps [](#s1-3){.pf-ref}, [](#s1-7){.pf-ref}, and [](#s1-12){.pf-ref}, and [](#s1-17){.pf-ref} prove parts (a)--(d), and step [](#s1-20){.pf-ref}
gives the requested generalization.

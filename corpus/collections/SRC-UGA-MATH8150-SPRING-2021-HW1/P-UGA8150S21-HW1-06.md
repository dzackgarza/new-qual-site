::: {.problem}
Use n-th roots of unity (i.e. solutions of $z ^ { n } - 1 = 0 )$ to show that

$$
2 ^ { n - 1 } \sin { \frac { \pi } { n } } \sin { \frac { 2 \pi } { n } } \cdot \cdot \cdot \sin { \frac { ( n - 1 ) \pi } { n } } = n .
$$

[Hint: $1 - \cos 2 \theta = 2 \sin ^ { 2 } \theta .$ , sin $2 \theta = 2 \sin \theta \cos \theta .$
:::

::: {.solution}
Let
\[
\zeta=e^{2\pi i/n}.
\]

<1>1. The \(n\)th roots of unity are
\[
\boxed{
1,\zeta,\zeta^2,\dots,\zeta^{n-1}}.
\]

::: {.proof}
The solutions of
\[
z^n=1
\]
are
\[
e^{2\pi ik/n},
\qquad
0\le k\le n-1.
\]
:::

<1>2. Therefore
\[
\boxed{
z^n-1
=
(z-1)\prod_{k=1}^{n-1}(z-\zeta^k)}.
\]

::: {.proof}
The polynomial \(z^n-1\) is monic of degree \(n\) and has exactly the roots
listed in step <1>1.
:::

<1>3. For \(z\ne1\),
\[
\frac{z^n-1}{z-1}
=
\prod_{k=1}^{n-1}(z-\zeta^k).
\]

::: {.proof}
Divide the factorization in step <1>2 by \(z-1\).
:::

<1>4. Taking the limit as \(z\to1\),
\[
\boxed{
n
=
\prod_{k=1}^{n-1}(1-\zeta^k)}.
\]

::: {.proof}
The left-hand side satisfies
\[
\lim_{z\to1}\frac{z^n-1}{z-1}
=
\left.\frac{d}{dz}z^n\right|_{z=1}
=
n.
\]
The right-hand side is continuous at \(z=1\), so its limit is the displayed
product.
:::

<1>5. Taking absolute values,
\[
\boxed{
n
=
\prod_{k=1}^{n-1}|1-\zeta^k|}.
\]

::: {.proof}
Since \(n>0\),
\[
|n|=n.
\]
Apply multiplicativity of the complex modulus to step <1>4.
:::

<1>6. For every real \(\theta\),
\[
\boxed{
|1-e^{i\theta}|
=
2\left|\sin\frac{\theta}{2}\right|}.
\]

::: {.proof}
Square the modulus:
\[
\begin{aligned}
|1-e^{i\theta}|^2
&=
(1-e^{i\theta})(1-e^{-i\theta})\\
&=
2-2\cos\theta\\
&=
4\sin^2\frac{\theta}{2}.
\end{aligned}
\]
Take nonnegative square roots.
:::

<1>7. Hence
\[
\boxed{
|1-\zeta^k|
=
2\sin\frac{k\pi}{n}}
\]
for
\[
1\le k\le n-1.
\]

::: {.proof}
Take
\[
\theta=\frac{2\pi k}{n}
\]
in step <1>6. Then
\[
0<\frac{k\pi}{n}<\pi,
\]
so the sine is positive and the absolute value may be removed.
:::

<1>8. Substituting step <1>7 into step <1>5,
\[
n
=
\prod_{k=1}^{n-1}
2\sin\frac{k\pi}{n}.
\]

::: {.proof}
Replace every factor in the product from step <1>5.
:::

<1>9. Pulling out the \(n-1\) factors of \(2\),
\[
\boxed{
2^{n-1}
\prod_{k=1}^{n-1}
\sin\frac{k\pi}{n}
=
n}.
\]

::: {.proof}
There are exactly \(n-1\) factors in the product.
:::

<1>10. Equivalently,
\[
\boxed{
\prod_{k=1}^{n-1}
\sin\frac{k\pi}{n}
=
\frac{n}{2^{n-1}}}.
\]

::: {.proof}
Divide step <1>9 by \(2^{n-1}\).
:::

<1>11. Q.E.D.

::: {.proof}
Step <1>9 is the identity requested in the problem.
:::
:::

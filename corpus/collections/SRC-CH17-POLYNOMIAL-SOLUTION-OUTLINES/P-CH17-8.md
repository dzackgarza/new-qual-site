::: {.problem}
Suppose that $f ( x ) \in \mathbb { Z } _ { p } [ x ]$ and $f ( x )$ is irreducible over $\mathbb { Z } _ { p }$ where $p$ is a prime.
If $\operatorname { d e g } ( f ( x ) ) = n$ , prove that $\mathbb { Z } _ { p } [ x ] / < f ( x ) >$ is a field with $p ^ { n }$ elements.
:::

::: {.solution}
Put $k=\mathbb F_p$ and $K=k[x]/(f)$, and write $\pi:k[x]\to K$ for the quotient morphism.

<1>1. The ring $K$ is a field.

::: {.proof}
Let $\pi(g)$ be a nonzero element of $K$. Then $f$ does not divide $g$. Since $f$ is irreducible in the Euclidean domain $k[x]$, $\gcd(f,g)=1$. Bézout's identity supplies $a,b\in k[x]$ with $af+bg=1$. Applying $\pi$ yields $\pi(b)\pi(g)=1$, so every nonzero element of $K$ is invertible.
:::

<1>2. Every element of $K$ has a unique representative of degree strictly less than $n$.

::: {.proof}
Polynomial division by the nonzero polynomial $f$ gives, for every $g\in k[x]$, polynomials $q,r\in k[x]$ with $g=qf+r$ and either $r=0$ or $\deg r<n$. Hence $\pi(g)=\pi(r)$. If $r,r'$ are two such representatives of the same class, then $f$ divides $r-r'$. But $r-r'$ is zero or has degree less than $n=\deg f$, so divisibility forces $r-r'=0$. Thus the representative is unique.
:::

<1>3. The field $K$ has
\[
\boxed{|K|=p^n}
\]
elements.

::: {.proof}
By step <1>2, each class is represented uniquely by $\sum_{j=0}^{n-1}a_jx^j$ with $a_j\in k$. There are exactly $p$ independent choices for each of the $n$ coefficients, giving $p^n$ distinct classes.
:::

<1>4. Q.E.D.

::: {.proof}
Step <1>1 proves that the quotient is a field, and step <1>3 establishes its cardinality.
:::
:::

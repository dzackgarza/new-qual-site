::: {.problem}
Suppose that $f(x) \in \ZZ_{p}[x]$ and $f(x)$ is irreducible over $\ZZ_{p}$, where $p$ is a prime.
If $\deg(f(x)) = n$, prove that $\ZZ_{p}[x]/\langle f(x) \rangle$ is a field with $p^{n}$ elements.
:::

::: {.solution}
Since $f ( x )$ is irreducible, $< f ( x ) >$ is maximal and $\ZZ _ { p } [ x ] / < f ( x ) >$ is a field.
Now since the degree of $f ( x )$ is n, every element in $\ZZ _ { p } [ x ] / < f ( x ) >$ can be written as $a _ { n - 1 } x ^ { n - 1 } +$ $a _ { n - 2 } x ^ { n - 2 } + \cdot \cdot \cdot + a _ { 1 } x + a _ { 0 } + < f ( x ) >$ . Indeed, by the division algorithm any $g ( x ) \in \ZZ _ { p } [ x ]$ has the form $g ( x ) = f ( x ) q ( x ) + r ( x )$ with $r ( x ) = 0$ or $\deg r < \deg f$, so $g ( x ) + < f ( x ) > = r ( x ) + < f ( x ) >$. Since each $a _ { i }$ is in $\ZZ _ { p }$ , there are p options for each coefficient in the coset representative.
So there are $p \times p \times \cdot \cdot \cdot \times p = p ^ { n }$ possible standard representatives.
Moreover, distinct representatives give distinct cosets: the difference of two of them is a nonzero polynomial of degree less than $n$, which $f(x)$ cannot divide.
:::

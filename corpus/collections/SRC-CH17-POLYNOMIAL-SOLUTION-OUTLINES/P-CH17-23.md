::: {.problem}
Find all monic irreducible polynomials of degree 2 over $\mathbb { Z } _ { 3 }$ .
:::

::: {.solution}
So this means that the polynomial must look like $x ^ { 2 } + a x + b$ where $b \neq 0$ . Suppose $b = 1$ . Then $x ^ { 2 } + a x + 1 = f ( x )$ . Then $f ( 0 ) = 1 , f ( 1 ) = a + 2$ , and $f ( 2 ) = 2 + 2 a$ . So $a \neq 1 , 2$ . Thus $x ^ { 2 } + 1$ is irreducible.
Now suppose $b = 2$ . Then $f ( x ) = x ^ { 2 } + a x + 2$ . So $f ( 0 ) = 2$ , $f ( 1 ) = a$ , and $f ( 2 ) = 2 a$ . Thus $a \neq 0$ . So $x ^ { 2 } + x + 2$ and $x ^ { 2 } + 2 x + 2$ are irreducible.
Final answer: $x ^ { 2 } + 1 , x ^ { 2 } + x + 2 , x ^ { 2 } + 2 x + 2$ .
:::

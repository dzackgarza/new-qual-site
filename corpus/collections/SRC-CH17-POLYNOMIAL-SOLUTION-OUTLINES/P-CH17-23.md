::: {.problem}
Find all monic irreducible polynomials of degree 2 over $\ZZ_{3}$.
:::

::: {.solution}
No retained solution set covers this exercise: the collection's `provenance` is the textbook's Google Books record and no solutions sheet is retained, so the argument below is the card's own, structured from the outline already on the card.

::: pf

::: {.pf-step #criterion}
A monic quadratic over a field is irreducible exactly when it has no zero in that field.

::: pf-proof
If $f(r) = 0$ then $x - r$ divides $f$ by the factor theorem, so $f$ is reducible. Conversely if $f = gh$ with both factors of positive degree, then, the leading coefficient of $f$ being $1$, both factors may be taken monic of degree $1$, say $g = x - r$, and then $f(r) = 0$.

:::

:::

::: {.pf-step #no-zero-constant}
For $f(x) = x^{2} + ax + b$: $f(0) = b$, so $b = 0$ forces the zero $0$ and makes $f$ reducible.

::: pf-proof
$f(0) = b$, and $b = 0$ gives $f(x) = x(x+a)$, a product of two monic linears over $\ZZ_{3}$.

:::

:::

::: {.pf-step #b-one}
For $b = 1$: $f(x) = x^{2} + 1$ is irreducible, while $x^{2} + x + 1$ and $x^{2} + 2x + 1$ are reducible.

::: pf-proof
Here $f(0) = 1$, $f(1) = 1 + a + 1 = a + 2$ and $f(2) = 4 + 2a + 1 = 2 + 2a$ in $\ZZ_{3}$. For $a = 0$ these are $1, 2, 2$, none zero, so step [](#criterion){.pf-ref} gives irreducibility of $x^{2}+1$. For $a = 1$, $f(1) = 3 = 0$, and for $a = 2$, $f(2) = 2 + 4 = 6 = 0$; in those cases $f$ has a zero. Explicitly $x^{2}+x+1 = (x+2)^{2}$ and $x^{2}+2x+1 = (x+1)^{2}$ in $\ZZ_{3}[x]$.

:::

:::

::: {.pf-step #b-two}
For $b = 2$: $x^{2} + x + 2$ and $x^{2} + 2x + 2$ are irreducible, while $x^{2} + 2$ is reducible.

::: pf-proof
Here $f(0) = 2$, $f(1) = 1 + a + 2 = a$ and $f(2) = 4 + 2a + 2 = 2a$ in $\ZZ_{3}$. For $a = 0$ one gets $f(1) = 0$, so $x^{2} + 2 = (x+1)(x+2)$ is reducible. For $a = 1$ the values are $2, 1, 2$, none zero, so $x^{2}+x+2$ is irreducible. For $a = 2$ the values are $2, 2, 4 = 1$, none zero, so $x^{2}+2x+2$ is irreducible.

:::

:::

::: pf-step
The monic irreducible quadratics over $\ZZ_{3}$ are $\boxed{x^{2}+1,\ x^{2}+x+2,\ x^{2}+2x+2}$.

::: pf-proof
The nine monic quadratics are grouped by $b$ in steps [](#no-zero-constant){.pf-ref}, [](#b-one){.pf-ref} and [](#b-two){.pf-ref}: those with $b = 0$ are reducible, and in each of $b = 1, 2$ exactly one value of $a$ gives a zero-free quadratic and the other two give a zero, so exactly three of the nine are irreducible, and they are the three listed.

:::

::: {.problem}
Prove that, for every positive integer n, there are infinitely many polynomials of degree n in $\mathbb { Z } [ x ]$ that are irreducible over Q.
:::

::: {.solution}
Fix n. Consider the infinite class of polynomials of the form $x ^ { n } + p$ where p is a prime.
Then, by Eisenstein’s, $x ^ { n } + p$ is irreducible over Q.
:::

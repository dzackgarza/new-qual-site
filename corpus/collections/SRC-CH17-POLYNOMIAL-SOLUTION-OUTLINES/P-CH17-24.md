::: {.problem}
Given that π is not the zero of a nonzero polynomial with rational coefficients, prove that $\pi ^ { 2 }$ cannot be written in the form $a \pi + b ,$ where a and b are rational.
:::

::: {.solution}
Suppose that $\pi ^ { 2 }$ can be written as $a \pi + b$ . Then set $g ( x ) = x ^ { 2 } - a x - b$ . So $g ( \pi ) =$ $\pi ^ { 2 } - a \pi - b = a \pi + b - a \pi - b = 0$ , so $\pi$ is a zero of a nonzero polynomial with rational coefficients, which is a contradiction.
:::

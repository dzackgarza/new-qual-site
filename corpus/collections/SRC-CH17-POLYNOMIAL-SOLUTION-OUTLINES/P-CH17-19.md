::: {.problem}
Show that for every prime $p$ there exists a field of order $p^{2}$.
:::

::: {.solution}
By exercise 18, there is a degree 2 polynomial $f ( x ) \in \ZZ _ { p } [ x ]$ that is irreducible over $\ZZ _ { p }$ . Thus $\ZZ _ { p } [ x ] / < f ( x ) >$ is a field. By the division algorithm, each of its elements is a coset $a x + b + < f ( x ) >$ with $a, b \in \ZZ_p$.
Now $a x + b + < f ( x ) > = c x + d + < f ( x ) >$ implies that $( a - c ) x + ( b - d )$ is divisible by $f ( x )$ . This means that $a = c$ and $b = d$ . Thus the order is precisely $p ^ { 2 }$ .
:::

::: {.problem}
Let F be a field and let $p ( x )$ be irreducible over F . If E is a field that contains F and there is an element a in E such that $p ( a ) = 0$ , show that the mapping $\phi : F [ x ] \to E$ given by $f ( x ) \mapsto f ( a )$ is a ring homomorphism with kernel $< p ( x ) >$ .
:::

::: {.solution}
Let $\phi , F , p ( x )$ , E and a be defined as above.
Then $\phi ( f ( x ) + g ( x ) ) = f ( a ) + g ( a ) =$ $\phi ( f ( x ) ) + \phi ( g ( x ) )$ and $\phi ( f ( x ) g ( x ) ) = f ( a ) g ( a ) = \phi ( f ( x ) ) \phi ( g ( x ) )$ . Since $p(a) = 0$, the kernel of $\phi$ contains $< p ( x ) >$. Since $p ( x )$ is irreducible, $< p ( x ) >$ is a maximal ideal. The kernel is a proper ideal, because $\phi(1) = 1 \neq 0$. So the kernel of $\phi$ is precisely $< p ( x ) >$ .
:::

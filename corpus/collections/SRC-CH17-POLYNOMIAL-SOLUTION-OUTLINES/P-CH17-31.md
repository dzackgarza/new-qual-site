::: {.problem}
Let $F$ be a field and let $p(x)$ be irreducible over $F$. If $E$ is a field that contains $F$ and there is an element $a$ in $E$ such that $p(a) = 0$, show that the mapping $\phi : F[x] \to E$ given by $f(x) \mapsto f(a)$ is a ring homomorphism with kernel $\langle p(x) \rangle$.
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **item 31, PDF p. 3** (`assets/attachments/Ch17Sltns.pdf`), restructured into steps.

Throughout, $F$ is a field, $p(x)\in F[x]$ is irreducible over $F$, $E$ is a field containing $F$ as a subfield, $a\in E$ satisfies $p(a)=0$, and $\phi(f(x))=f(a)$.

::: pf

::: {.pf-step #hom}
$\phi:F[x]\to E$ is a ring homomorphism, and $\phi(1)=1$.

::: pf-proof
Evaluation at $a$ respects the operations: for $f,g\in F[x]$, $(f+g)(a)=f(a)+g(a)$ and $(fg)(a)=f(a)g(a)$, because both sides are computed by adding and multiplying the finitely many coefficients in the field $E$ and distributing. The constant polynomial $1$ evaluates to $1\in E$. So $\phi$ preserves sums, products and unity.
:::

:::

::: {.pf-step #contains}
$\langle p(x)\rangle\subseteq\ker\phi$.

::: pf-proof
An element of $\langle p(x)\rangle$ is $p(x)h(x)$ for some $h\in F[x]$. Then $\phi\big(p(x)h(x)\big)=p(a)h(a)=0\cdot h(a)=0$, using $p(a)=0$ and the homomorphism property of step [](#hom){.pf-ref}, so this element lies in the kernel. In particular $p(x)$ itself lies in $\ker\phi$.
:::

:::

::: {.pf-step #maximal}
$\langle p(x)\rangle$ is a maximal ideal of $F[x]$.

::: pf-proof
$F$ is a field, so $F[x]$ is a principal ideal domain, and in a principal ideal domain an ideal generated by an irreducible element is maximal; this is one direction of Theorem 17.5 (printed p. 311), which states that $\langle p(x)\rangle$ is maximal if and only if $p(x)$ is irreducible over $F$. The ideal is proper because $p$ is a nonconstant polynomial, so $1\notin\langle p(x)\rangle$.
:::

:::

::: {.pf-step #proper}
$\ker\phi\neq F[x]$.

::: pf-proof
$\phi(1)=1$ by step [](#hom){.pf-ref}, and $1\neq0$ in the field $E$. So the constant polynomial $1$ is not in the kernel, and the kernel is a proper ideal of $F[x]$.
:::

:::

::: {.pf-step #kernel}
$\ker\phi=\langle p(x)\rangle$.

::: pf-proof
By step [](#contains){.pf-ref} the kernel contains the ideal $\langle p(x)\rangle$, and by step [](#maximal){.pf-ref} that ideal is maximal. A maximal ideal has no proper ideal strictly containing it, so any ideal containing it is either itself or the whole ring; by step [](#proper){.pf-ref} the kernel is not the whole ring, so $\ker\phi=\langle p(x)\rangle$. Together with step [](#hom){.pf-ref} this proves both assertions of the exercise.
:::

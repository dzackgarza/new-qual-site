::: {.problem}
Determine which of the polynomials below is (are) irreducible over $\mathbb{Q}$.

(a) $x^5 + 9x^4 + 12x^2 + 6$

(b) $x^4 + x + 1$

(c) $x^4 + 3x^2 + 3$

(d) $x^5 + 5x^2 + 1$

(e) $\left(\frac{5}{2}\right)x^5 + \left(\frac{9}{2}\right)x^4 + 15x^3 + \left(\frac{3}{7}\right)x^2 + 6x + \frac{3}{14}$
:::

::: {.solution}
(a) Irreducible, by Eisenstein's criterion with $p = 3$.

(b) Irreducible.
The polynomial is monic, so its reduction $\bar f(x) = x^4 + x + 1 \in \mathbb{F}_2[x]$ has the same degree, and irreducibility of $\bar f$ over $\mathbb{F}_2$ implies irreducibility of $f$ over $\mathbb{Q}$ (mod $p$ irreducibility test).
Since $\bar f(0) = \bar f(1) = 1$, $\bar f$ has no linear factor.
A quartic without roots is reducible only as a product of two irreducible quadratics, and the only irreducible quadratic over $\mathbb{F}_2$ is $x^2 + x + 1$, whose square is $x^4 + x^2 + 1 \neq \bar f$.
So $\bar f$ is irreducible.

(c) Irreducible, by Eisenstein's criterion with $p = 3$.

(d) Irreducible.
As in (b), it suffices that $\bar f(x) = x^5 + x^2 + 1$ is irreducible over $\mathbb{F}_2$.
Since $\bar f(0) = \bar f(1) = 1$, $\bar f$ has no linear factor, so a factorization would have an irreducible quadratic factor, necessarily $x^2 + x + 1$.
Modulo $x^2 + x + 1$ we have $x^3 \equiv 1$, so $\bar f \equiv x^2 + x^2 + 1 = 1 \not\equiv 0$.
So $\bar f$ is irreducible.

(e) Irreducible.
Call the polynomial $f(x)$.
Then $14 f(x) = 35x^5 + 63x^4 + 210x^3 + 6x^2 + 84x + 3$, which is irreducible over $\mathbb{Q}$ by Eisenstein's criterion with $p = 3$.
Hence $f(x)$ is irreducible.
:::

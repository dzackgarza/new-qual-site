::: {.problem}
Construct a field of order 25.
:::

::: {.solution}
Since $2 5 = 5 ^ { 2 }$ , start with $\mathbb { Z } _ { 5 } [ x ]$ . Now, we must find a degree 2 polynomial, $p ( x )$ , that is irreducible over $\mathbb { Z } _ { 5 }$ . Then $\mathbb { Z } _ { 5 } [ x ] / < p ( x ) >$ is a field of order $5 \cdot 5 = 2 5$ . Now, lets start with $p ( x ) = x ^ { 2 } + x + a$ . Then $p ( 0 ) = a , p ( 1 ) = a + 2 , p ( 2 ) = a + 1 , p ( 3 ) = 2 + a$ , and $p ( 4 ) = a$ . So $a \neq 0 , 3 , 4$ . Choose $a = 1$ . Then $p ( x ) = x ^ { 2 } + x + 1$ is irreducible over $\mathbb { Z } _ { 5 }$ and works to give us the field we want.
:::

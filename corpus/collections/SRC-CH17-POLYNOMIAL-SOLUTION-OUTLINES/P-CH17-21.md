::: {.problem}
Show that the field given in Example 11 in this chapter, $\mathbb{Z}_3[x]/\langle x^2 + 1 \rangle$, is isomorphic to the field given in Example 9 in Chapter 13, $\mathbb{Z}_3[i]$.
:::

::: {.solution}
The example 11 field is: $\mathbb { Z } _ { 3 } [ x ] / < x ^ { 2 } + 1 >$ . The example 9 field is: $\mathbb { Z } _ { 3 } [ i ]$ . Define $\phi : \mathbb { Z } _ { 3 } [ x ] / < x ^ { 2 } + 1 > \to \mathbb { Z } _ { 3 } [ i ]$ by $\phi ( f ( x ) + < x ^ { 2 } + 1 > ) = f ( i )$ . Then $\phi ( f ( x ) + < x ^ { 2 } + 1 > + g ( x ) + < x ^ { 2 } + 1 > ) = \phi ( f ( x ) + g ( x ) + < x ^ { 2 } + 1 > ) = f ( i ) + g ( i ) = \phi ( f ( x ) + < x ^ { 2 } + 1 > ) + \phi ( g ( x ) + < x ^ { 2 } + 1 > )$ and $\phi ( ( f ( x ) + < x ^ { 2 } + 1 > ) ( g ( x ) + < x ^ { 2 } + 1 > ) ) = \phi ( f ( x ) g ( x ) + < x ^ { 2 } + 1 > ) = f ( i ) g ( i ) = \phi ( f ( x ) + < x ^ { 2 } + 1 > ) \phi ( g ( x ) + < x ^ { 2 } + 1 > )$ . Thus φ is a homomorphism.
Now, $\operatorname { k e r } \phi =$ $\{ f ( x ) + < x ^ { 2 } + 1 > | f ( i ) = 0 \} = \{ a x + b + < x ^ { 2 } + 1 > | a i + b = 0$ where $a , b \in \mathbb { Z } _ { 3 } \} = < x ^ { 2 } + 1 >$ , so φ is 1-1. Now let $a + b i \in \mathbb { Z } _ { 3 } [ i ]$ . Then $a + b x + < x ^ { 2 } + 1 >$ maps to $a + b i$ , so φ is onto.
Thus, these fields are isomorphic.
:::

::: {.problem}
Show that the field given in Example 11 in this chapter, $\ZZ_3[x]/\langle x^2 + 1 \rangle$, is isomorphic to the field given in Example 9 in Chapter 13, $\ZZ_3[i]$.
:::

::: {.solution}
The book's own answer is **Gallian, *Contemporary Abstract Algebra* (7th ed.), *Selected Answers*, Chapter 17 Exercise 19, printed p. A24** (`tmp/sources/Gallian-Contemporary-Abstract-Algebra-7e.pdf`): "Map $\ZZ_{3}[x]$ onto $\ZZ_{3}[i]$ by $f(x)\mapsto f(i)$. This is a ring homomorphism with kernel $\langle x^{2}+1\rangle$." The steps below prove each claim of that answer. Write $\operatorname{ev}_{i}(f)=f(i)$ and recall $\ZZ_{3}[i]=\theset{a+bi\mid a,b\in\ZZ_{3}}$ with $i^{2}=-1=2$.

::: pf

::: {.pf-step #homomorphism}
$\operatorname{ev}_{i}:\ZZ_{3}[x]\to\ZZ_{3}[i]$, $f\mapsto f(i)$, is a well defined ring homomorphism.

::: pf-proof
For a polynomial $f=\sum c_{k}x^{k}$ with $c_{k}\in\ZZ_{3}$, the element $f(i)=\sum c_{k}i^{k}$ is defined by the ring operations of $\ZZ_{3}[i]$ and lies there, so $\operatorname{ev}_{i}$ is a well defined map. It preserves addition and multiplication because evaluation does in any commutative ring: $\operatorname{ev}_{i}(f+g)=f(i)+g(i)$ and $\operatorname{ev}_{i}(fg)=f(i)g(i)$; and $\operatorname{ev}_{i}(1)=1$.
:::

:::

::: {.pf-step #kernel}
$\ker\operatorname{ev}_{i}=\langle x^{2}+1\rangle$.

::: pf-proof
Clearly $x^{2}+1\in\ker\operatorname{ev}_{i}$, since $i^{2}+1=2+1=0$ in $\ZZ_{3}$, so $\langle x^{2}+1\rangle\subset\ker\operatorname{ev}_{i}$. Conversely let $f\in\ker\operatorname{ev}_{i}$. Since $x^{2}+1$ is monic, division gives $f=q(x)(x^{2}+1)+(ax+b)$ with $q\in\ZZ_{3}[x]$ and $a,b\in\ZZ_{3}$. Evaluating at $i$ gives $0=f(i)=q(i)\cdot0+(ai+b)=ai+b$, so $ai=-b$. If $a\ne0$ then $i=-b/a\in\ZZ_{3}$, which is false because $i\notin\ZZ_{3}$ — indeed $i$ is not a residue class, and the elements $1,i$ are linearly independent over $\ZZ_{3}$ since $bi=-a$ with $b\ne0$ would again put $i$ in $\ZZ_{3}$. Hence $a=0$ and then $b=0$, so $f=q(x)(x^{2}+1)\in\langle x^{2}+1\rangle$.
:::

:::

::: {.pf-step #onto}
$\operatorname{ev}_{i}$ is onto $\ZZ_{3}[i]$.

::: pf-proof
Given $a+bi$ with $a,b\in\ZZ_{3}$, the linear polynomial $a+bx$ satisfies $\operatorname{ev}_{i}(a+bx)=a+bi$.
:::

:::

::: {.pf-step #quotient-field}
$x^{2}+1$ is irreducible over $\ZZ_{3}$, so $\ZZ_{3}[x]/\langle x^{2}+1\rangle$ is a field.

::: pf-proof
A quadratic over a field is irreducible exactly when it has no zero there. At the three residues, $(x^{2}+1)(0)=1$, $(x^{2}+1)(1)=2$ and $(x^{2}+1)(2)=4+1=5\equiv2$, none zero. So $x^{2}+1$ is irreducible and the quotient by the ideal it generates is a field, which is the reason given in Example 11 of this chapter.
:::

:::

::: {.pf-step #answer}
$\ZZ_{3}[x]/\langle x^{2}+1\rangle\cong\ZZ_{3}[i]$.

::: pf-proof
Steps [](#homomorphism){.pf-ref}, [](#kernel){.pf-ref} and [](#onto){.pf-ref} make $\operatorname{ev}_{i}$ a surjective ring homomorphism with kernel $\langle x^{2}+1\rangle$, so the first isomorphism theorem for rings gives $\ZZ_{3}[x]/\langle x^{2}+1\rangle\cong\ZZ_{3}[i]$. By step [](#quotient-field){.pf-ref} the left side is a field, and it is the field of Example 11 while the right side is the field of Example 9 of Chapter 13; both have nine elements, as the isomorphism requires.
:::

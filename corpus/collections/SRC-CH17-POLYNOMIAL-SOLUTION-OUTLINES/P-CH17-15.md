::: {.problem}
Let $f ( x ) = x ^ { 3 } + 6 \in \mathbb { Z } _ { 7 } [ x ]$ . Write $f ( x )$ as a product of irreducible polynomials over $\mathbb { Z } _ { 7 }$ .
:::

::: {.solution}
Since the degree of $f ( x )$ is 3, any factor must correspond to a zero.
So $f ( 0 ) = 6 , f ( 1 ) = 0$ , $f ( 2 ) = 0 , f ( 3 ) = 5 , f ( 4 ) = 0 , f ( 5 ) = 5 , f ( 6 ) = 5$ . So $f ( x ) = ( x - 1 ) ( x - 2 ) ( x - 4 ) = ( x + 6 ) ( x + 5 ) ( x + 3 )$ . (Notice that each root occurs with multiplicity 1 because of the degree.)
:::

::: {.problem}
For which even dimensions 2n is it true that the Euler characteristic of a compact, connected, orientable 2n-manifold is necessarily even?
:::

::: {.solution}
Here a manifold has no boundary.
Let $M$ be a compact connected orientable $2n$-manifold, and let $b_i = \dim_\QQ H^i(M; \QQ)$.

::: pf

::: {.pf-step #mod2}
$\chi(M) \equiv b_n \pmod 2$.

::: pf-proof
Poincaré duality and the universal coefficient theorem over $\QQ$ give $b_i = b_{2n-i}$.
So the terms with $i \neq n$ cancel in pairs modulo $2$: $(-1)^i b_i + (-1)^{2n-i} b_{2n-i} = 2(-1)^i b_i$.
:::

:::

::: {.pf-step #odd-n}
If $n$ is odd, $\chi(M)$ is even.

::: pf-proof
The cup product pairing $H^n(M; \QQ) \times H^n(M; \QQ) \to \QQ$, $(x, y) \mapsto \langle x \smile y, [M] \rangle$, is nondegenerate by Poincaré duality.
It is skew-symmetric, because $y \smile x = (-1)^{n^2} x \smile y = -x \smile y$ for odd $n$.
A nondegenerate skew-symmetric form exists only on an even-dimensional space, so $b_n$ is even.
By step [](#mod2){.pf-ref}, $\chi(M)$ is even.
:::

:::

::: {.pf-step #even-n}
If $n$ is even, some such $M$ has odd Euler characteristic.

::: pf-proof
$M = \CP^n$ is compact, connected, orientable and of real dimension $2n$, with one cell in each even dimension up to $2n$.
So $\chi(\CP^n) = n + 1$, which is odd for even $n$.
:::

:::

::: pf-step
The Euler characteristic is necessarily even exactly in the dimensions $\boxed{2n \equiv 2 \pmod 4}$.

::: pf-proof
This combines steps [](#odd-n){.pf-ref} and [](#even-n){.pf-ref}.
:::

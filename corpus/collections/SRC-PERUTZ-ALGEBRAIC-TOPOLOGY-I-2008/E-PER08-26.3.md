::: {.problem}
For which even dimensions 2n is it true that the Euler characteristic of a compact, connected, orientable 2n-manifold is necessarily even?
:::

::: {.solution}
For a compact connected orientable manifold of dimension $2n$,
\[
\chi(M)\equiv b_n(M)\pmod2,
\]
because Poincaré duality pairs $b_i=b_{2n-i}$ for $i\ne n$.

The middle-dimensional intersection form on $H^n(M;\mathbb Q)$ is $(-1)^n$-symmetric.
If $n$ is odd, it is nondegenerate skew-symmetric, so its dimension $b_n$ is even.
Hence $\chi(M)$ is necessarily even when
\[
2n\equiv2\pmod4.
\]

If $n$ is even, there is no such parity constraint.
Indeed
\[
M=\mathbb{CP}^{\,n}
\]
has real dimension $2n$ and
\[
\chi(\mathbb{CP}^{\,n})=n+1,
\]
which is odd when $n$ is even.
Therefore the precise answer is
\[
\boxed{\text{exactly the dimensions }2n\equiv2\pmod4.}
\]
:::

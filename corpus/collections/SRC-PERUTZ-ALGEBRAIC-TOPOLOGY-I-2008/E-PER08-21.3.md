::: {.problem}
Work over $\ZZ$ and fix distinct primes $p$ and $q$.
Compute (i) $\operatorname{Ext}(\ZZ,\ZZ/p^n)$; (ii) $\operatorname{Ext}(\ZZ/p^n,\ZZ)$; (iii) $\operatorname{Ext}(\ZZ/p^n,\ZZ/q^m)$; (iv) $\operatorname{Ext}(\ZZ/p^n,\ZZ/p^m)$.
:::

::: {.solution}
Write $\operatorname{Ext}$ for $\operatorname{Ext}^1_{\ZZ}$.

::: pf

::: {.pf-step #ext-cyclic}
For $r \geq 1$ and an abelian group $B$, $\operatorname{Ext}(\ZZ/r, B) \cong B/rB$.

::: pf-proof
The sequence $0 \to \ZZ \xrightarrow{\times r} \ZZ \to \ZZ/r \to 0$ is a free resolution of $\ZZ/r$.
Applying $\Hom({-}, B)$ gives the complex $B \xrightarrow{\times r} B$, whose cokernel is $\operatorname{Ext}(\ZZ/r, B)$.
:::

:::

::: pf-step
(i) $\operatorname{Ext}(\ZZ, \ZZ/p^n) = \boxed{0}$.

::: pf-proof
$\ZZ$ is free, hence projective, so $\operatorname{Ext}(\ZZ, {-}) = 0$.
:::

:::

::: pf-step
(ii) $\operatorname{Ext}(\ZZ/p^n, \ZZ) \cong \boxed{\ZZ/p^n}$.

::: pf-proof
By step [](#ext-cyclic){.pf-ref}, it is $\ZZ/p^n\ZZ$.
:::

:::

::: pf-step
(iii) $\operatorname{Ext}(\ZZ/p^n, \ZZ/q^m) = \boxed{0}$.

::: pf-proof
Since $p \neq q$, the integer $p^n$ is a unit modulo $q^m$, so multiplication by $p^n$ is surjective on $\ZZ/q^m$.
By step [](#ext-cyclic){.pf-ref}, the Ext group is $(\ZZ/q^m)/p^n(\ZZ/q^m) = 0$.
:::

:::

::: pf-step
(iv) $\operatorname{Ext}(\ZZ/p^n, \ZZ/p^m) \cong \boxed{\ZZ/p^{\min(n,m)}}$.

::: pf-proof
By step [](#ext-cyclic){.pf-ref}, the Ext group is $(\ZZ/p^m)/p^n(\ZZ/p^m)$.
The subgroup $p^n(\ZZ/p^m)$ is generated by $p^{\min(n,m)}$, so the quotient is $\ZZ/p^{\min(n,m)}$.
:::

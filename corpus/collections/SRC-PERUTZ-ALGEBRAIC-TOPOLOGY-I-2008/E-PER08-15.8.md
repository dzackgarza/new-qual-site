::: {.problem}
Suppose M is a compact, connected n-manifold with non-empty boundary ∂M. It is a fact (see Hatcher) that there is a neighbourhood U of ∂M and a homeomorphism U → ∂M × [0, 1) sending any x ∈ ∂M to (x, 0). (a) Show that Hp(M) = 0 for p ≥ n and Hp(M, ∂M) = 0 for p > n. (b) Show that if M ∖ ∂M is orientable then Hn(M, ∂M) ∼= Z. (c) Let X be a space.
Suppose h ∈ Hn−1(X) is a homology class that is representable by a manifold, in that there is a compact oriented n − 1-manifold N with fundamental class zN and a map f : N → X with f∗zN = h. Show that h = 0 if N = ∂M for a compact oriented n-manifold with ∂M = N such that f extends to F : M → X.
:::

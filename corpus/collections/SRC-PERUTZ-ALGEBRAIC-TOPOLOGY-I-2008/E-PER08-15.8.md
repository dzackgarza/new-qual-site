::: {.problem}
Suppose \(M\) is a compact, connected \(n\)-manifold with nonempty boundary \(\partial M\). Assume the collar-neighbourhood theorem: there is a neighbourhood \(U\) of \(\partial M\) and a homeomorphism
\[
U\cong\partial M\times[0,1)
\]
sending each \(x\in\partial M\) to \((x,0)\).

(a) Show that
\[
H_p(M)=0\quad(p\ge n),
\qquad
H_p(M,\partial M)=0\quad(p>n).
\]

(b) Show that if the interior \(M\setminus\partial M\) is orientable, then
\[
H_n(M,\partial M)\cong\mathbb Z.
\]

(c) Let \(X\) be a space. Suppose \(h\in H_{n-1}(X)\) is represented by a compact oriented \((n-1)\)-manifold \(N\): there are a fundamental class \(z_N\in H_{n-1}(N)\) and a map \(f:N\to X\) with
\[
f_*z_N=h.
\]
Show that \(h=0\) if \(N=\partial M\) for a compact oriented \(n\)-manifold \(M\), with the induced boundary orientation on \(N\), and \(f\) extends to a map \(F:M\to X\).
:::

::: {.solution}
Write \(M^\circ=M\setminus\partial M\).

<1>1. The inclusion \(M^\circ\hookrightarrow M\) is a homotopy equivalence.
::: {.proof}
Choose a collar
\[
c:\partial M\times[0,1)\longrightarrow U\subset M.
\]
Choose a continuous increasing map \(r:[0,1)\to(0,1)\) such that \(r(t)=t\) for all \(t\ge1/2\).  On the collar define
\[
R(c(x,t))=c(x,r(t)),
\]
and define \(R\) to be the identity outside the part of the collar where \(r\ne t\).  Then \(R(M)\subset M^\circ\).

The straight-line homotopy between \(t\) and \(r(t)\) in the collar gives a homotopy from \(\operatorname{id}_M\) to the composite
\[
M\xrightarrow{R}M^\circ\hookrightarrow M.
\]
Restricted to \(M^\circ\), this homotopy stays in \(M^\circ\), so \(R|_{M^\circ}\) is also homotopic to \(\operatorname{id}_{M^\circ}\).  Thus the inclusion is a homotopy equivalence.
:::

<1>2. For \(p\ge n\), one has \(H_p(M)=0\).
::: {.proof}
The interior \(M^\circ\) is a noncompact \(n\)-manifold.  The noncompact-manifold vanishing theorem proved earlier in the notes gives
\[
H_p(M^\circ)=0
\qquad(p\ge n).
\]
By <1>1,
\[
H_p(M)\cong H_p(M^\circ)=0
\qquad(p\ge n).
\]
:::

<1>3. For \(p>n\), one has \(H_p(M,\partial M)=0\).
::: {.proof}
By Exercise 15.7, \(\partial M\) is an \((n-1)\)-manifold, so
\[
H_{p-1}(\partial M)=0
\qquad(p-1>n-1).
\]
For \(p>n\), the relevant part of the long exact sequence of the pair is
\[
H_p(M)\longrightarrow H_p(M,\partial M)
\longrightarrow H_{p-1}(\partial M).
\]
Both outer groups vanish by <1>2 and the dimension bound above.  Hence
\[
H_p(M,\partial M)=0.
\]
This proves part (a).
:::

<1>4. If \(M^\circ\) is orientable, then \(H_n(M,\partial M)\cong\mathbb Z\).
::: {.proof}
Choose \(0<\varepsilon<1/2\) in the collar and put
\[
C=c(\partial M\times[0,\varepsilon)),
\qquad
K=M\setminus C.
\]
Then \(K\) is a compact connected subset of \(M^\circ\); it is obtained from \(M\) by deleting a thin open boundary collar and is a deformation retract of \(M\).

The inclusion \(\partial M\hookrightarrow C\) is a homotopy equivalence, so the long exact sequences of pairs give
\[
H_n(M,\partial M)\cong H_n(M,C).
\]
Since \(\partial M\subset C\) and \(C\) is an open neighbourhood of \(\partial M\), excision gives
\[
H_n(M,C)
\cong
H_n(M^\circ,C\setminus\partial M).
\]
But
\[
C\setminus\partial M=M^\circ\setminus K,
\]
so
\[
H_n(M,\partial M)
\cong
H_n(M^\circ,M^\circ\setminus K).
\]

Now use the oriented local-fundamental-class theorem proved immediately before these exercises.  For a connected oriented \(n\)-manifold and a compact connected subset \(K\), the restriction to local homology identifies
\[
H_n(M^\circ,M^\circ\setminus K)
\]
with the rank-one module of coherent local orientations along \(K\).  Equivalently, the orientation determines a unique relative fundamental class \([M]_K\), and every relative top-dimensional class is an integer multiple of it.  Therefore
\[
H_n(M^\circ,M^\circ\setminus K)\cong\mathbb Z,
\]
and hence
\[
H_n(M,\partial M)\cong\mathbb Z.
\]
This proves part (b).
:::

<1>5. If \(f:N=\partial M\to X\) extends over an oriented \(M\), then \(f_*z_N=0\).
::: {.proof}
Let
\[
[M,\partial M]\in H_n(M,\partial M)
\]
be the relative fundamental class from <1>4.  Choose a relative fundamental cycle represented by an \(n\)-chain \(c\in C_n(M)\).  Its boundary lies in \(C_{n-1}(\partial M)\), and with the induced boundary orientation it represents the fundamental class \(z_N\):
\[
[\partial c]=z_N.
\]

Let \(F:M\to X\) extend \(f\).  Then \(F_\#c\) is an \(n\)-chain in \(X\), and
\[
\partial(F_\#c)
=F_\#(\partial c)
=f_\#(\partial c).
\]
Thus the cycle representing
\[
h=f_*z_N
\]
is the boundary of the chain \(F_\#c\). Therefore
\[
h=0\in H_{n-1}(X).
\]
This proves part (c).
:::

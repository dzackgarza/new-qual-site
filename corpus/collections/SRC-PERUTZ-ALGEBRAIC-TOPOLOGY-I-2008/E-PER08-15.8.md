::: {.problem}
Suppose M is a compact, connected n-manifold with non-empty boundary $\\partial$M. It is a fact (see Hatcher) that there is a neighbourhood U of $\\partial$M and a homeomorphism U $\\to$ $\\partial$M $\\times$ [0, 1) sending any x $\\in$ $\\partial$M to (x, 0). (a) Show that Hp(M) = 0 for p $\\ge$ n and Hp(M, $\\partial$M) = 0 for p > n. (b) Show that if M $\\setminus$ $\\partial$M is orientable then Hn(M, $\\partial$M) $\\cong$ Z. (c) Let X be a space.
Suppose h $\\in$ Hn$^{-1}$(X) is a homology class that is representable by a manifold, in that there is a compact oriented n $-$ 1-manifold N with fundamental class zN and a map f : N $\\to$ X with f$\\ast$zN = h. Show that h = 0 if N = $\\partial$M for a compact oriented n-manifold with $\\partial$M = N such that f extends to F : M $\\to$ X.
:::

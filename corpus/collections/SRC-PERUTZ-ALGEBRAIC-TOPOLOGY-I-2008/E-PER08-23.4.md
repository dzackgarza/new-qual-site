::: {.problem}
A special case of the Lefschetz fixed point theorem states that if $X$ is a finite CW complex, and $g\colon X\to X$ a map without fixed points, then
$$
\sum_{p\ge0}(-1)^p\operatorname{tr}H^p(g)=0.
$$
Here $H^p(g)$ is the induced map on $H^p(X;\QQ)$.
What restrictions does this entail for groups acting freely on $\CP^n$?
:::

::: {.solution}
Let a group $G$ act freely on $\CP^n$ by homeomorphisms, and let $u$ generate $H^2(\CP^n; \ZZ)$, so that $H^*(\CP^n; \ZZ) = \ZZ[u]/(u^{n+1})$.

::: pf

::: {.pf-step #sign}
For each $g \in G$, there is $\varepsilon_g \in \theset{\pm 1}$ with $g^* u = \varepsilon_g u$, and $g^*$ acts on $H^{2k}(\CP^n; \QQ)$ as multiplication by $\varepsilon_g^k$.

::: pf-proof
The map $g^*$ is a ring automorphism of $H^*(\CP^n; \ZZ)$, so it sends the generator $u$ of $H^2 \cong \ZZ$ to $\pm u$.
Then $g^*(u^k) = (g^* u)^k = \varepsilon_g^k u^k$, and $u^k$ spans $H^{2k}(\CP^n; \QQ)$ for $k \leq n$.
The odd-degree groups vanish.
:::

:::

::: {.pf-step #minus-one}
Every $g \neq 1$ in $G$ has $\varepsilon_g = -1$, and $n$ is odd if $G \neq 1$.

::: pf-proof
A nonidentity $g$ has no fixed points, because the action is free.
By the Lefschetz theorem and step [](#sign){.pf-ref}, $0 = \sum_{k=0}^n \varepsilon_g^k$.
If $\varepsilon_g = 1$, the sum is $n + 1 \neq 0$, so $\varepsilon_g = -1$.
Then the sum is $1 - 1 + \cdots + (-1)^n$, which is $0$ only when $n$ is odd.
:::

:::

::: pf-step
$G = 1$ if $n$ is even, and $\abs{G} \leq 2$ if $n$ is odd: $\boxed{G = 1 \text{ for } n \text{ even}, \quad \abs{G} \leq 2 \text{ for } n \text{ odd}}$.

::: pf-proof
The map $g \mapsto \varepsilon_g$ is a homomorphism $G \to \theset{\pm 1}$, because $(gh)^* = h^* g^*$ and the signs commute.
By step [](#minus-one){.pf-ref}, its kernel is trivial, so $\abs{G} \leq 2$.
The same step gives $G = 1$ for even $n$.
The bound is attained for odd $n = 2m + 1$: the involution of $\CP^{2m+1} = \PP(\HH^{m+1})$ induced by right multiplication by $j$ on $\HH^{m+1} = \CC^{2m+2}$ is free.
:::

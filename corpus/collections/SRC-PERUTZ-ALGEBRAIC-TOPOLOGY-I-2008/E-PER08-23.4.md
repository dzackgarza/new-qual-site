::: {.problem}
A special case of the Lefschetz fixed point theorem states that if X is a finite CW complex, and g: X $\\to$ X a map without fixed points, then $\\sum$ p$\\ge$0 ($^{-1}$)p tr Hp(g) = 0. Here Hp(g) is the induced map on H$\\ast$(X; Q). What restrictions does this entail for groups acting freely on CP n?
:::

::: {.solution}
Let a finite group $G$ act freely on $\mathbb{CP}^n$.
For $g\in G$, write
\[
g^*u=\varepsilon_g u,
\qquad \varepsilon_g\in\{\pm1\},
\]
for a generator $u\in H^2(\mathbb{CP}^n;\mathbb Z)$.
Then on $H^{2k}(\mathbb{CP}^n;\mathbb Q)$, $g^*$ acts by multiplication by $\varepsilon_g^k$.

For nonidentity $g$, freeness implies that $g$ has no fixed points, so its Lefschetz number must vanish:
\[
0=L(g)=\sum_{k=0}^n\varepsilon_g^k.
\]
If $\varepsilon_g=1$, this sum is $n+1\ne0$.
Therefore every nonidentity element must satisfy $\varepsilon_g=-1$.
Then
\[
L(g)=1-1+1-\cdots+(-1)^n,
\]
which is zero exactly when $n$ is odd.
Hence:

- if $n$ is even, no nontrivial finite group can act freely on $\mathbb{CP}^n$;

- if $n$ is odd, every nonidentity element must act by $-1$ on $H^2$.

Finally, $g\mapsto\varepsilon_g$ is a homomorphism $G\to\{\pm1\}$.
If two distinct nonidentity elements existed, their product would have sign $+1$; unless their product were the identity this contradicts the preceding paragraph, and if their product is the identity then they are equal inverses in a group where every nonidentity has order $2$.
Thus $|G|\le2$.

So the Lefschetz constraint is
\[
\boxed{G=1\text{ if }n\text{ is even},\qquad |G|\le2\text{ if }n\text{ is odd}.}
\]
(The bound is sharp in odd complex dimension: the standard quaternionic involution on $\mathbb{CP}^{2m+1}$ is free.)
:::

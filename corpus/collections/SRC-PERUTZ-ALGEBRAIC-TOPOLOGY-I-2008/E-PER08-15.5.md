::: {.problem}
Let \(M\) be an \(n\)-manifold and let \(p\) be an odd prime. Show that \(M\) is \(\ZZ/p\)-orientable if and only if it is \(\ZZ\)-orientable.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

Every integral orientation induces a \(\ZZ/p\)-orientation.

::: pf-proof

For every \(x\in M\), local homology is free of rank one:
\[
H_n(M,M\setminus\{x\};\ZZ)\cong\ZZ.
\]
Changing coefficients gives
\[
H_n(M,M\setminus\{x\};\ZZ/p)
\cong
H_n(M,M\setminus\{x\};\ZZ)\otimes\ZZ/p
\cong\ZZ/p.
\]
A coherent integral choice of generator therefore reduces to a coherent nonzero generator modulo \(p\), hence to a \(\ZZ/p\)-orientation.

:::

:::

::: {.pf-step #s2}

Every \(\ZZ/p\)-orientable manifold is integrally orientable.

::: pf-proof

It suffices to work on each connected component.
Fix a basepoint \(x\).  Parallel transport in the integral local-homology system
\[
H_n(M,M\setminus\{x\};\ZZ)\cong\ZZ
\]
gives the orientation character
\[
w_1:\pi_1(M,x)\longrightarrow\{\pm1\}.
\]
After reducing coefficients modulo \(p\), the same loop acts on the one-dimensional \(\FF_p\)-local homology by multiplication by the image of \(w_1(\gamma)\), namely \(+1\) or \(-1\) in \(\FF_p\).

Assume a \(\ZZ/p\)-orientation exists.
Its value at \(x\) selects a nonzero element
\[
v\in H_n(M,M\setminus\{x\};\FF_p),
\]
and because the orientation is a global section, every loop must fix \(v\).  If some loop had \(w_1(\gamma)=-1\), then transport would give
\[
v=-v.
\]
Since \(p\) is odd, \(2\neq0\) in \(\FF_p\), so the only vector satisfying \(v=-v\) is \(v=0\), contradicting the choice of a generator.
Therefore \(w_1\) is trivial.

Triviality of the orientation character is equivalent to triviality of the integral orientation double cover, hence to integral orientability.

:::

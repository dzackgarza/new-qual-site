::: {.problem}
(May 2013) Let $Y$ be the standard $3$-simplex $\Delta^3$ with a total ordering on its four vertices.
Let $X$ be the $\Delta$-complex obtained from $Y$ by identifying, for each $k\leq 3$, all of its $k$-dimensional faces such that the identifications respect the vertex ordering.
Thus $X$ has a single $k$-simplex for each $k\leq 3$.
Compute the simplicial homology groups of the $\Delta$-complex $X$.
:::

::: {.solution}
<1>1. Setup the simplicial chain complex $\Delta_*(X)$: <2>1. The $\Delta$-complex $X$ has exactly one $k$-simplex for each $k \in \{0, 1, 2, 3\}$, which we denote by $e_0, e_1, e_2, e_3$.
::: {.proof}
problem hypothesis that all $k$-faces are identified order-preservingly.
:::
<2>2. The simplicial chain groups are:
\[
\Delta_k(X) \cong \begin{cases} \mathbb{Z} \cdot e_k & k = 0, 1, 2, 3 \\ 0 & k \ge 4. \end{cases}
\]
::: {.proof}
free abelian groups generated by the simplices in each dimension.
:::

<1>2. Compute the boundary homomorphisms $\partial_k$: <2>1. **$\partial_1: \Delta_1(X) \to \Delta_0(X)$:** Any 1-simplex $[v_i, v_j]$ with $i < j$ is mapped to $e_1$.
Its boundary is $[v_j] - [v_i] = e_0 - e_0 = 0$.
Thus $\partial_1(e_1) = 0$, so $\partial_1 = 0$.
::: {.proof}
simplicial boundary formula $\partial_1([v_i, v_j]) = [v_j] - [v_i]$.
:::
<2>2. **$\partial_2: \Delta_2(X) \to \Delta_1(X)$:** Any 2-simplex $[v_i, v_j, v_k]$ with $i < j < k$ is mapped to $e_2$.
Its boundary is:
\[
\partial_2(e_2) = [v_j, v_k] - [v_i, v_k] + [v_i, v_j] = e_1 - e_1 + e_1 = e_1.
\]
Thus $\partial_2: \mathbb{Z} \to \mathbb{Z}$ is multiplication by $1$ (an isomorphism).
::: {.proof}
simplicial boundary formula with face identification.
:::
<2>3. **$\partial_3: \Delta_3(X) \to \Delta_2(X)$:** The 3-simplex $[v_0, v_1, v_2, v_3] = e_3$ has boundary:
\[
\partial_3(e_3) = [v_1, v_2, v_3] - [v_0, v_2, v_3] + [v_0, v_1, v_3] - [v_0, v_1, v_2] = e_2 - e_2 + e_2 - e_2 = 0.
\]
Thus $\partial_3 = 0$.
::: {.proof}
alternating sum of the four 2-faces identified to $e_2$.
:::

<1>3. Compute the homology groups $H_k(X) = \ker\partial_k / \operatorname{im}\partial_{k+1}$: <2>1. $H_0(X) = \ker\partial_0 / \operatorname{im}\partial_1 = \mathbb{Z} / \{0\} \cong \mathbb{Z}$.
::: {.proof}
$\Delta_0(X) = \mathbb{Z}$ and $\partial_1 = 0$.
:::
<2>2. $H_1(X) = \ker\partial_1 / \operatorname{im}\partial_2 = \mathbb{Z} / \mathbb{Z} = 0$.
::: {.proof}
$\ker\partial_1 = \mathbb{Z}$ and $\operatorname{im}\partial_2 = \mathbb{Z}$.
:::
<2>3. $H_2(X) = \ker\partial_2 / \operatorname{im}\partial_3 = \{0\} / \{0\} = 0$.
::: {.proof}
$\partial_2$ is injective, so $\ker\partial_2 = \{0\}$.
:::
<2>4. $H_3(X) = \ker\partial_3 / \operatorname{im}\partial_4 = \mathbb{Z} / \{0\} \cong \mathbb{Z}$.
::: {.proof}
$\ker\partial_3 = \mathbb{Z}$ and $\Delta_4(X) = 0$.
:::
<2>5. $H_k(X) = 0$ for all $k \ge 4$.
::: {.proof}
$\Delta_k(X) = 0$ for $k \ge 4$.
:::

<1>4. Conclusion: The simplicial homology groups of $X$ are:
\[
H_k(X) \cong \begin{cases} \mathbb{Z} & k = 0, 3 \\ 0 & k = 1, 2 \text{ or } k \ge 4. \end{cases}
\]
::: {.proof}
<1>3.
:::
Q.E.D.

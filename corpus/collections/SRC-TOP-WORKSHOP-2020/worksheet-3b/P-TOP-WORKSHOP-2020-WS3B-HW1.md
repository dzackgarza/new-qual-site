::: {.problem}
Find the universal covers of these spaces:

(a) $X=S^1$.

(b) $Y=S^1\vee S^1$ (two circles glued together along a point).
:::

::: {.solution}
No retained solution set covers this item, the collection's provenance being the worksheet, so the argument is the card's own.

::: pf

::: {.pf-step #circle}
(a) $p\colon\RR\to S^1$, $p(t)=e^{2\pi it}$, is a covering map and $\RR$ is simply connected, so $\RR$ is the universal cover of $S^1$.

::: pf-proof
$\RR$ is convex, hence contractible, hence simply connected. For each point $z\in S^1$ the open arc $S^1\setminus\{-z\}$ has inverse image $\bigcup_{n\in\ZZ}(t_n-\tfrac12,t_n+\tfrac12)$ where $z=e^{2\pi it_n}$, a disjoint union of open intervals each mapped homeomorphically onto the arc by $p$; so $p$ is a covering map. A covering map with simply connected total space is the universal cover.
:::

:::

::: {.pf-step #tree}
(b) The graph $T$ with vertex set $F(a,b)$ and, for each $g\in F(a,b)$, an edge from $g$ to $ga$ and an edge from $g$ to $gb$, is a tree.

::: pf-proof
Every vertex has degree $4$, the four incident edges being those of $a,b,a^{-1},b^{-1}$, and each edge joins two distinct vertices, so $T$ has no loop. It is connected because $F(a,b)$ is generated by $a,b$, so any $g$ is joined to the identity by the word expressing it. It contains no cycle: a cycle would be a word in $a^{\pm1},b^{\pm1}$ that returns to its starting point without immediate backtracking, and such a word is a nontrivial reduced word, hence a nontrivial element of the free group, contradiction. A connected graph without cycles is a tree, and a tree is contractible, in particular simply connected.
:::

:::

::: {.pf-step #covering}
(b) There is a covering map $T\to S^1\vee S^1$ whose deck transformations are the left translations of $F(a,b)$.

::: pf-proof
Map every $a$-edge homeomorphically onto the first circle and every $b$-edge onto the second, in the orientation prescribed by the edge labels; this is well defined because each edge carries exactly one label, and continuous because a neighbourhood of a vertex meets only the finitely many edges at it. Each open edge covers the circle minus a point, and a small arc in either circle avoiding the wedge point lifts to one edge at each vertex, so the map is a covering map. A left translation $g\mapsto hg$ permutes the edges and commutes with the map, so $F(a,b)$ acts by deck transformations; the action is free and transitive on the fibre over the wedge point, which is the vertex set, so the quotient of $T$ by the action is $S^1\vee S^1$.
:::

:::

::: {.pf-step}
$\boxed{\text{The universal cover of }S^1\text{ is }\RR\text{, and of }S^1\vee S^1\text{ is the Cayley graph of }F(a,b)}$

::: pf-proof
Part (a) is step [](#circle){.pf-ref}. For part (b), step [](#tree){.pf-ref} shows the Cayley graph is simply connected and step [](#covering){.pf-ref} shows it covers $S^1\vee S^1$ with deck group $\pi_1(S^1\vee S^1)=F(a,b)$, which is the definition of the universal cover; so the universal cover of $S^1\vee S^1$ is that $4$-regular tree.
:::

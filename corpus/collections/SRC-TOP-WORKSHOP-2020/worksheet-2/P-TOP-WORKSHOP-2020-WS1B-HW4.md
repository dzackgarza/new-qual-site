::: {.problem}
Give 4--6 different topologies on $\mathbb R$.
:::

::: solution
**Goal:** Define six distinct topologies on $\mathbb{R}$ and prove that they are pairwise distinct.

<1>1. Definition of six topologies on $\mathbb{R}$: *Proof:* <2>1. Trivial (indiscrete) topology: $\mathcal{T}_1 = \{\emptyset, \mathbb{R}\}$.
<2>2. Standard Euclidean topology: $\mathcal{T}_2$, generated by the basis of open intervals $\{(a, b) : a < b\}$.
<2>3. Lower limit (Sorgenfrey) topology: $\mathcal{T}_3$, generated by the basis of half-open intervals $\{[a, b) : a < b\}$.
<2>4. Cofinite (finite complement) topology: $\mathcal{T}_4 = \{U \subseteq \mathbb{R} : \mathbb{R} \setminus U \text{ is finite}\} \cup \{\emptyset\}$.
<2>5. Cocountable (countable complement) topology: $\mathcal{T}_5 = \{U \subseteq \mathbb{R} : \mathbb{R} \setminus U \text{ is countable}\} \cup \{\emptyset\}$.
<2>6. Discrete topology: $\mathcal{T}_6 = \mathcal{P}(\mathbb{R})$ (the power set of $\mathbb{R}$).

<1>2. Proof that all six topologies are pairwise distinct: *Proof:* <2>1. $\mathcal{T}_1 \neq \mathcal{T}_k$ for all $k > 1$: The open interval $(0, 1)$ belongs to $\mathcal{T}_2, \mathcal{T}_3, \mathcal{T}_6$ and $\mathbb{R} \setminus \{0\} \in \mathcal{T}_4, \mathcal{T}_5$, but neither set is in $\mathcal{T}_1$.
<2>2. $\mathcal{T}_2 \neq \mathcal{T}_3$: The interval $[0, 1)$ is basic open in $\mathcal{T}_3$, but is not open in $\mathcal{T}_2$ because it contains its left endpoint 0 without any Euclidean open interval $(-\varepsilon, \varepsilon) \subseteq [0, 1)$.
<2>3. $\mathcal{T}_2 \neq \mathcal{T}_4$: The Euclidean open interval $(0, 1) \in \mathcal{T}_2$ has complement $(-\infty, 0] \cup [1, \infty)$, which is infinite, so $(0, 1) \notin \mathcal{T}_4$.
<2>4. $\mathcal{T}_2 \neq \mathcal{T}_5$: The Euclidean open interval $(0, 1) \in \mathcal{T}_2$ has uncountable complement, so $(0, 1) \notin \mathcal{T}_5$.
<2>5. $\mathcal{T}_3 \neq \mathcal{T}_4$ and $\mathcal{T}_3 \neq \mathcal{T}_5$: The interval $[0, 1) \in \mathcal{T}_3$ has uncountable complement, so $[0, 1) \notin \mathcal{T}_4$ and $[0, 1) \notin \mathcal{T}_5$.
<2>6. $\mathcal{T}_4 \subsetneq \mathcal{T}_5$: Every finite set is countable, so $\mathcal{T}_4 \subseteq \mathcal{T}_5$.
The set $U = \mathbb{R} \setminus \mathbb{N}$ has countably infinite complement $\mathbb{N}$, so $U \in \mathcal{T}_5$, but $U \notin \mathcal{T}_4$ because $\mathbb{N}$ is not finite.
<2>7. $\mathcal{T}_6 \neq \mathcal{T}_k$ for all $k \le 5$: The singleton $\{0\} \in \mathcal{T}_6$, but $\{0\}$ is not open in $\mathcal{T}_1, \mathcal{T}_2, \mathcal{T}_3, \mathcal{T}_4, \mathcal{T}_5$ because its complement $\mathbb{R} \setminus \{0\}$ is uncountable and contains no interval around 0.

<1>3. Conclusion: *Proof:* The six collections $\mathcal{T}_1, \dots, \mathcal{T}_6$ are valid, pairwise distinct topologies on $\mathbb{R}$.
:::

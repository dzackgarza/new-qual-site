::: {.problem}
Use Corollary 2 of Lagrange’s Theorem to prove that the order of $U(n)$ is even when $n > 2$.
:::

::: {.solution}
Proof.
Notice that $n - 1 \in U ( n )$ for all n. Further, $( n - 1 ) ^ { 2 } = n ^ { 2 } - 2 n + 1 = 1$ so the order of $n - 1$ is 2. Thus we know that $2 \mid | U ( n ) |$ , so its order must be even.
:::

::: {.remark}
The source does not state Corollary 2 of Lagrange’s Theorem; its solution uses it in the form that the order of an element of a finite group divides the order of the group.
:::

::: {.problem}
Suppose that a has order 15. Find all of the left cosets of $< a ^ { 5 } >$ in $< a >$ .
:::

::: {.solution}
Notice that ${ \frac { 1 5 } { 3 } } = 5$ , so we will have five left cosets.
They are: $< a ^ { 5 } > = \{ a ^ { 5 } , a ^ { 1 0 } , e \} , a < a ^ { 5 } > = \{ a ^ { 6 } , a ^ { 1 1 } , a \} , a ^ { 2 } < a ^ { 5 } > = \{ a ^ { 7 } , a ^ { 1 2 } , a ^ { 2 } \} , a ^ { 3 } < a ^ { 5 } > = \{ a ^ { 8 } , a ^ { 1 3 } , a ^ { 3 } \} ,$ and $a ^ { 4 } < a ^ { 5 } > = \{ a ^ { 9 } , a ^ { 1 4 } , a ^ { 4 } \} .$
:::

::: {.problem}
Let $\cardinality{G} = 15$. If $G$ has only one subgroup of order $3$ and only one of order $5$, prove that $G$ is cyclic. Generalize to $\cardinality{G} = pq$, where $p$ and $q$ are prime.
:::

::: {.solution}

The argument is that of the retained solution outline for Chapter 7, Exercise 27, PDF p. 3 of `assets/attachments/Ch7Sltns.pdf`, restructured into numbered steps. Here $G$ is a finite group of order $15$ with exactly one subgroup of order $3$ and exactly one of order $5$, and the generalization concerns a group of order $pq$ with $p\neq q$ primes and one subgroup of each order.

::: pf

::: {.pf-step #cyclic}

The unique subgroups of orders $3$ and $5$ are cyclic; write them $\langle a\rangle$ and $\langle b\rangle$.

::: pf-proof

A group of prime order is cyclic, generated by any nonidentity element, so each of the two subgroups is generated by a choice of nonidentity element.

:::

:::

::: {.pf-step #union}

$\langle a\rangle\cap\langle b\rangle=\set{e}$ and $\cardinality{\langle a\rangle\cup\langle b\rangle}=3+5-1=7$.

::: pf-proof

The intersection is a subgroup of both, so its order divides $3$ and $5$, which are distinct primes; hence the order is $1$ and the intersection is $\set{e}$. The union has $3+5-1$ elements by inclusion-exclusion.

:::

:::

::: {.pf-step #choose}

There is $d\in G$ with $d\notin\langle a\rangle\cup\langle b\rangle$.

::: pf-proof

$7<15=\cardinality{G}$ by step [](#union){.pf-ref}.

:::

:::

::: {.pf-step #order}

The order of $d$ is $15$.

::: pf-proof

By Lagrange's theorem the order of $d$ divides $15$, so it is $1$, $3$, $5$ or $15$. It is not $1$, since $d\neq e$ (as $e$ lies in both subgroups). It is not $3$: then $\langle d\rangle$ is a subgroup of order $3$ different from $\langle a\rangle$, because $d\notin\langle a\rangle$, contradicting uniqueness. It is not $5$, for the same reason with $\langle b\rangle$. Hence it is $15$.

:::

:::

::: {.pf-step #cyclic2}

$G=\langle d\rangle$ is cyclic.

::: pf-proof

A subgroup of order equal to $\cardinality{G}$ is $G$ itself, so the cyclic subgroup generated by $d$ is $G$.

:::

:::

::: {.pf-step #general}

Generalization: if $p\neq q$ are primes, $\cardinality{G}=pq$, and $G$ has a unique subgroup $H$ of order $p$ and a unique subgroup $K$ of order $q$, then $G$ is cyclic.

::: pf-proof

The same argument with $3,5$ replaced by $p,q$: $\cardinality{H\cup K}=p+q-1<pq$ because $pq-p-q+1=(p-1)(q-1)>0$, so some $d$ lies outside $H\cup K$; its order divides $pq$ and is not $1$, $p$ or $q$ — the last two because $\langle d\rangle$ would be a second subgroup of that order — hence its order is $pq$ and $G=\langle d\rangle$.

:::

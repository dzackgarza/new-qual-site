::: {.problem}
Prove that every subgroup of $D_{n}$ of odd order is cyclic.
:::

::: {.solution}
The argument is the card's own: the collection's provenance is a set of solution outlines. Write
$$
D_n=\langle r,s\mid r^n=s^2=1,\ srs=r^{-1}\rangle,
$$
so that every element is $r^k$ or $sr^k$ with $0\le k<n$, and let $G\le D_n$ have odd order.

::: pf

::: {.pf-step #reflections}
Every element of $D_n$ outside $\langle r\rangle$ is an involution.

::: pf-proof
Such an element is $sr^k$ (equivalently $r^ks$). Now $(sr^k)^2=sr^ksr^k$, and $r^ks=sr^{-k}$ by the relation $srs=r^{-1}$, so $(sr^k)^2=s\cdot sr^{-k}\cdot r^k=s^2=1$. Hence $sr^k$ has order $2$ (it is not the identity, since $s\ne1$ and $r^k$ would otherwise make $s\in\langle r\rangle$, which it is not).
:::

:::

::: {.pf-step #odd}
$G$ contains no element of order $2$.

::: pf-proof
By Lagrange's theorem the order of any element of $G$ divides $\abs{G}$, which is odd; $2$ does not divide an odd number, so no element of $G$ has order $2$. (The identity has order $1$, and orders of other elements are at least $3$.)
:::

:::

::: {.pf-step #cyclic}
$G\subseteq\langle r\rangle$ and $G$ is cyclic.

::: pf-proof
If $G$ had an element outside $\langle r\rangle$, that element would be an involution by step [](#reflections){.pf-ref}, contradicting step [](#odd){.pf-ref}. So $G$ lies in the cyclic group $\langle r\rangle\cong C_n$. Subgroups of a cyclic group are cyclic: if $\langle r\rangle$ has order $n$ and $H\le\langle r\rangle$ is nontrivial, the least positive $m$ with $r^m\in H$ generates $H$, using division with remainder by $m$ to see that every power of $r$ in $H$ is a multiple of $r^m$. Hence $G$ is cyclic.
:::

::: {.problem}
Let $| G | = 8$ . Show that G must have an element of order 2.
:::

::: {.solution}
Let $| G | = 8$ . Let g be any non-identity element of G. Its order is 2, 4 or 8 (consequence of Lagrange’s theorem).
If $g$ has order 2, we are done.
Assume g has order 4. Then $( g ^ { 2 } ) ^ { 2 } = e$ and $g ^ { 2 } \neq e$ . So $g ^ { 2 }$ is an element of order 2. Now, assume g has order 8, making G cyclic.
Then $( g ^ { 4 } ) ^ { 2 } = e$ so the element $g ^ { 4 }$ has order 2.
:::

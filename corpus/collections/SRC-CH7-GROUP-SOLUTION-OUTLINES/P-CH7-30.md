::: {.problem}
Let $\cardinality{G} = 8$. Show that $G$ must have an element of order $2$.
:::

::: {.solution}
The collection retains its solution outline as `assets/attachments/Ch7Sltns.pdf`, and entry "# 30" of that outline covers Gallian 7e Chapter 7 Exercise 28. The outline chooses a nonidentity element $g$, divides according as its order is $2,4,8$, and uses $g,g^{2},g^{4}$ respectively. The three cases and the orders of those powers are checked below.

Choose $g\in G\setminus\theset{e}$, which is possible because $\cardinality{G}=8>1$.

::: pf

::: {.pf-step #order-cases}
The order of $g$ is $2,4$, or $8$.

::: pf-proof
The cyclic subgroup generated by $g$ has order equal to the order of $g$, so Lagrange's theorem implies that the order of $g$ divides $\cardinality{G}=8$. Its positive divisors are $1,2,4,8$. Since $g\ne e$, its order is not $1$, leaving exactly the three stated possibilities.
:::

:::

::: {.pf-step #involution}
In each case, a suitable power of $g$ has order $2$, so $G$ contains an element of order $2$.

::: pf-proof

::: pf-step
If the order of $g$ is $2$, then $g$ itself is the required element.

::: pf-proof
The element $g$ has order $2$ by hypothesis in this case.
:::

:::

::: pf-step
If the order of $g$ is $4$, then $g^{2}$ has order $2$.

::: pf-proof
Since $g^{4}=e$, we have $(g^{2})^{2}=e$. Moreover $g^{2}\ne e$, because the order of $g$ is $4$ rather than a divisor of $2$. Hence the order of $g^{2}$ is greater than $1$ and divides $2$; it is therefore exactly $2$.
:::

:::

::: pf-step
If the order of $g$ is $8$, then $g^{4}$ has order $2$.

::: pf-proof
Since $g^{8}=e$, we have $(g^{4})^{2}=e$. Moreover $g^{4}\ne e$, because the order of $g$ is $8$ rather than a divisor of $4$. Hence the order of $g^{4}$ is greater than $1$ and divides $2$; it is therefore exactly $2$.
:::

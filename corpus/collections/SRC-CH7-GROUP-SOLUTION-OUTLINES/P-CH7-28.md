::: {.problem}
Let $G$ be a group of order $25$. Prove that $G$ is cyclic or $g^{5} = e$ for all $g$ in $G$. Generalize to any group of order $p^{2}$ where $p$ is prime. Does your proof work for this generalization?
:::

::: {.solution}
The argument is the retained solution outline for this chapter, **Gallian, *Contemporary Abstract Algebra*, seventh edition, Chapter 7 solution outlines, exercise 28, PDF p. 2** (`assets/attachments/Ch7Sltns.pdf`), restructured into steps. One sentence of the outline is corrected: it concludes that "the order of $g$ must be $5$ for all elements", which fails at the identity, whose order is $1$; the conclusion $g^{5}=e$ is unaffected.

::: pf

::: {.pf-step #divides}
Every element of $G$ has order dividing $25$.

::: pf-proof
By Lagrange's theorem the order of an element divides the order of the group, and $\cardinality{G}=25$.
:::

:::

::: {.pf-step #orders}
If $G$ is not cyclic then every element has order $1$ or $5$.

::: pf-proof
The divisors of $25$ are $1,5,25$. An element of order $25$ generates a cyclic subgroup of order $25$, which is $G$ itself since $\cardinality{G}=25$, so $G$ would be cyclic; by hypothesis that does not occur. Hence the order of every element is $1$ or $5$ by step [](#divides){.pf-ref}.
:::

:::

::: {.pf-step #power}
$g^{5}=e$ for every $g\in G$.

::: pf-proof
If the order of $g$ is $1$ then $g=e$ and $g^{5}=e$; if it is $5$ then $g^{5}=e$ by definition of the order as the least positive power equal to the identity. Step [](#orders){.pf-ref} covers exactly these two cases.
:::

:::

::: {.pf-step #general}
For a group of order $p^{2}$ with $p$ prime: either $G$ is cyclic or $g^{p}=e$ for all $g\in G$.

::: pf-proof
The same argument with $25$ replaced by $p^{2}$: the order of an element divides $p^{2}$, hence is $1$, $p$ or $p^{2}$; an element of order $p^{2}$ makes $G$ cyclic; and otherwise every element has order $1$ or $p$, so $g^{p}=e$. The proof does depend on $p$ being prime only through the shape of the divisors of $p^{2}$, so it transfers verbatim.
:::

:::

::: {.pf-step}
The dichotomy holds, and the proof generalises.

::: pf-proof
Steps [](#orders){.pf-ref}, [](#power){.pf-ref} and [](#general){.pf-ref} give
$$
\boxed{\cardinality{G}=25:\quad G\text{ cyclic, or }g^{5}=e\text{ for all }g;\qquad \cardinality{G}=p^{2}:\quad G\text{ cyclic, or }g^{p}=e\text{ for all }g.}
$$
Note that when $G$ is cyclic of order $p^{2}$ the conclusion also holds for every element of order $p$, but fails for a generator; the two cases of the dichotomy are genuinely different.
:::

::: {.problem}
Suppose G is a finite group of order n, and $m$ is relatively prime to n. If $g \in G$ and $g ^ { m } = e ,$ , prove that $g = e$ .
:::

::: {.solution}
The order of an element divides the order of the group, so $g ^ { n } = e$. Since also $g^m = e$, the order of g divides both m and n. However, $\operatorname { g c d } ( m , n ) = 1$ so the order of g is 1. Hence, $g = e$ .
:::

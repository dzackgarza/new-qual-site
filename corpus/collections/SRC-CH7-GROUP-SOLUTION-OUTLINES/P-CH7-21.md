::: {.problem}
Suppose G is a finite group of order n, and $m$ is relatively prime to n. If $g \in G$ and $g ^ { m } = e ,$ , prove that $g = e$ .
:::

::: {.solution}
Proof.
Notice that the order of an element has to divide the order of the group, so the order of g can not be m. We also know that $g ^ { | G | } = g ^ { n } = e \qquad$ . So the order of g divides both m and n. However, $\operatorname { g c d } ( m , n ) = 1$ so the order of g is actually 1. Hence, $g = e$ . □
:::

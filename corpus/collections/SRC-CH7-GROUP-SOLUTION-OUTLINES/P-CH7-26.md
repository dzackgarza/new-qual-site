::: {.problem}
Suppose that $G$ is a group with more than one element and $G$ has no proper, nontrivial subgroups. Prove that $\cardinality{G}$ is prime.
:::

::: {.solution}

The argument is the card's own: a non-identity element generates a nontrivial subgroup, which must be the whole group, and then the order is forced to be prime.

::: pf

::: {.pf-step #generated}

For $x\ne e$ in $G$, the cyclic subgroup $\langle x\rangle$ is nontrivial, so $\langle x\rangle=G$.

::: pf-proof

$\langle x\rangle$ contains $x\ne e$, so it has more than one element and is nontrivial. It is a subgroup of $G$, and $G$ has no proper nontrivial subgroups, so the only possibility is $\langle x\rangle=G$. In particular $G$ is cyclic, generated by any non-identity element.

:::

:::

::: {.pf-step #finite}

$G$ is finite.

::: pf-proof

By step [](#generated){.pf-ref} $G=\langle x\rangle$ for any $x\ne e$. If $x$ had infinite order then $\langle x\rangle\cong\ZZ$, a group with the proper nontrivial subgroup $\langle x^{2}\rangle\cong2\ZZ$, and $\langle x^{2}\rangle$ would be a proper nontrivial subgroup of $G$, contrary to hypothesis. So $x$ has finite order $n$, and $G=\langle x\rangle$ has $n$ elements.

:::

:::

::: {.pf-step #prime}

$\cardinality{G}$ is prime.

::: pf-proof

Let $n=\cardinality{G}=o(x)>1$ and suppose $n=ab$ with $1<a,b<n$. Then $x^{a}\ne e$ (as $a<n=o(x)$), and $\langle x^{a}\rangle$ is a nontrivial subgroup; its order is $n/\gcd(n,a)=b<n$, so it is proper. That contradicts the hypothesis. Hence $n$ has no factorisation with both factors between $1$ and $n$, so $n$ is prime:
$$
\boxed{\cardinality{G}\ \text{is prime}.}
$$

:::

::: {.problem}
Let $H$ and $K$ be subgroups of a finite group $G$ with $H \subseteq K \subseteq G$. Prove that $\subgroupindex{G : H} = \subgroupindex{G : K} \subgroupindex{K : H}$.
:::

::: {.solution}
Viewing K as a subgroup of $G ,$ we see ${ \frac { \cardinality{ G } } { \cardinality{ K } } } = \subgroupindex{ G : K }$ . Next, we can view H as a subgroup of K so ${ \frac { \cardinality{ K } } { \cardinality{ H } } } = \subgroupindex{ K : H }$ . Finally, we can view H as a subgroup of G so $\subgroupindex{ G : H } = { \frac { \cardinality{ G } } { \cardinality{ H } } } = { \frac { \cardinality{ G } } { \cardinality{ K } } } { \frac { \cardinality{ K } } { \cardinality{ H } } } = \subgroupindex{ G : K } \subgroupindex{ K : H } .$
:::

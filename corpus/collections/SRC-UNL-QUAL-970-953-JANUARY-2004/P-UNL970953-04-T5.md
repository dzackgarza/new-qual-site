::: {.problem}
Show that if
$$
f:(X,\mathcal T)\longrightarrow(Y,\mathcal T')
$$
is a homotopy equivalence, then $f$ induces a bijective correspondence between the path components of $X$ and the path components of $Y$.
:::

::: {.solution}

Let
$$
\pi_0^{\mathrm{path}}(X)
$$
denote the set of path components of $X$.

::: pf

::: pf-step

The map $f$ induces a well-defined map
$$
f_\#:
\pi_0^{\mathrm{path}}(X)
\longrightarrow
\pi_0^{\mathrm{path}}(Y),
\qquad
[x]\longmapsto[f(x)].
$$


::: pf-proof

Suppose $x_0,x_1\in X$ lie in the same path component. Then there is a
continuous path
$$
\gamma:[0,1]\to X
$$
with
$$
\gamma(0)=x_0,
\qquad
\gamma(1)=x_1.
$$
The composite
$$
f\circ\gamma:[0,1]\to Y
$$
is a path from $f(x_0)$ to $f(x_1)$. Thus $f(x_0)$ and $f(x_1)$ lie in the
same path component of $Y$, so the assignment depends only on the path
component of $x$.

:::

:::

::: pf-step

Choose a homotopy inverse
$$
g:Y\to X
$$
with homotopies
$$
G:g\circ f\simeq\operatorname{id}_X
$$
and
$$
H:f\circ g\simeq\operatorname{id}_Y.
$$


::: pf-proof

This is the definition of $f$ being a homotopy equivalence.

:::

:::

::: {.pf-step #s1-3}

For every $y\in Y$, the points
$$
f(g(y))
\qquad\text{and}\qquad
y
$$
lie in the same path component of $Y$.


::: pf-proof

Fix $y\in Y$. The map
$$
t\longmapsto H(y,t)
$$
is a path in $Y$. Its endpoints are
$$
H(y,0)=f(g(y))
$$
and
$$
H(y,1)=y
$$
after choosing the homotopy orientation accordingly. Hence the two points
are path-connected.

:::

:::

::: {.pf-step #s1-4}

The induced map
$$
f_\#
:
\pi_0^{\mathrm{path}}(X)
\to
\pi_0^{\mathrm{path}}(Y)
$$
is surjective.


::: pf-proof

Let
$$
[y]\in\pi_0^{\mathrm{path}}(Y).
$$
By step [](#s1-3){.pf-ref},
$$
[y]
=
[f(g(y))]
=
f_\#([g(y)]).
$$
Thus every path component of $Y$ lies in the image of $f_\#$.

:::

:::

::: {.pf-step #s1-5}

For every $x\in X$, the points
$$
g(f(x))
\qquad\text{and}\qquad
x
$$
lie in the same path component of $X$.


::: pf-proof

Fix $x\in X$. The map
$$
t\longmapsto G(x,t)
$$
is a path in $X$ joining
$$
g(f(x))
$$
to
$$
x.
$$

:::

:::

::: {.pf-step #s1-6}

Suppose
$$
f_\#([x_0])
=
f_\#([x_1]).
$$
Then $x_0$ and $x_1$ lie in the same path component of $X$.


::: pf-proof

The equality means that $f(x_0)$ and $f(x_1)$ are path-connected in $Y$.
Choose a path
$$
\gamma:[0,1]\to Y
$$
from $f(x_0)$ to $f(x_1)$.

Then
$$
g\circ\gamma:[0,1]\to X
$$
is a path from
$$
g(f(x_0))
$$
to
$$
g(f(x_1)).
$$

By step [](#s1-5){.pf-ref}, there is also a path from $x_0$ to $g(f(x_0))$ and a path
from $g(f(x_1))$ to $x_1$. Concatenating these three paths gives a path
from $x_0$ to $x_1$.

:::

:::

::: {.pf-step #s1-7}

The induced map $f_\#$ is injective.


::: pf-proof

If
$$
f_\#([x_0])
=
f_\#([x_1]),
$$
step [](#s1-6){.pf-ref} gives
$$
[x_0]=[x_1].
$$
This is injectivity.

:::

:::

::: {.pf-step #s1-8}

Therefore
$$
\boxed{
f_\#:
\pi_0^{\mathrm{path}}(X)
\xrightarrow{\cong}
\pi_0^{\mathrm{path}}(Y)
}
$$
is a bijection.


::: pf-proof

Step [](#s1-4){.pf-ref} proves surjectivity and step [](#s1-7){.pf-ref} proves injectivity.

:::

:::

::: pf-qed

Step [](#s1-8){.pf-ref} is exactly the required bijective correspondence between path
components.

:::

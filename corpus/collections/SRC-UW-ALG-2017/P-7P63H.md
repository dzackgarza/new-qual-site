::: {.problem}
Find all ring homomorphisms $\QQ[x]/(x^{100}+2)\to\QQ[x]/(x^{1001}+2)$.
:::

::: {.solution}

Write $f=x^{100}+2$, $g=x^{1001}+2$, $A=\QQ[x]/(f)$ and $B=\QQ[x]/(g)$, and let $\alpha,\beta$ be the classes of $x$ in $A$ and $B$.

::: pf

::: {.pf-step #s1}

$f$ and $g$ are irreducible over $\QQ$, so $A=\QQ(\alpha)$ and $B=\QQ(\beta)$ are fields with $[A:\QQ]=100$ and $[B:\QQ]=1001$.

::: pf-proof

Eisenstein's criterion at the prime $2$: in both $x^{100}+2$ and $x^{1001}+2$ the leading coefficient is $1$, all intermediate coefficients are $0$ and hence divisible by $2$, and the constant term $2$ is divisible by $2$ but not by $4$. So both polynomials are irreducible over $\QQ$, and in particular the quotients are fields, of dimensions $100$ and $1001$ over $\QQ$.

:::

:::

::: {.pf-step #s2}

A unital ring homomorphism $\varphi:A\to B$ is injective and is determined by $y=\varphi(\alpha)$, an element of $B$ with $y^{100}=-2$.

::: pf-proof

Since $A$ is a field, $\ker\varphi$ is an ideal of $A$, so it is $0$ or $A$; $\varphi(1)=1\ne0$ excludes $\ker\varphi=A$. Hence $\varphi$ is injective, and $\QQ\subseteq A$ is fixed by $\varphi$ because $\varphi(1)=1$.

Every element of $A$ is $p(\alpha)$ for a polynomial $p$ of degree $<100$, so $\varphi$ is determined by $y=\varphi(\alpha)$. From $\alpha^{100}=-2$ we get $y^{100}=\varphi(\alpha)^{100}=\varphi(\alpha^{100})=\varphi(-2)=-2$.

:::

:::

::: {.pf-step #s3}

No element $y\in B$ satisfies $y^{100}=-2$.

::: pf-proof

Suppose $y\in B$ with $y^{100}+2=0$. Then $y$ is a root of the irreducible polynomial $f$ (step [](#s1){.pf-ref}), so $f$ is the minimal polynomial of $y$ over $\QQ$ and $[\QQ(y):\QQ]=\deg f=100$.

Since $y\in B$ and $B$ is a field containing $\QQ$, the field $\QQ(y)$ is a subfield of $B$. By the tower law,
$$
[B:\QQ]=[B:\QQ(y)]\cdot[\QQ(y):\QQ]=[B:\QQ(y)]\cdot100 .
$$
So $100$ divides $[B:\QQ]=1001$, which is false ($1001=7\cdot11\cdot13$). Hence no such $y$ exists.

:::

:::

::: {.pf-step #s4}

There are no unital ring homomorphisms $A\to B$; if the zero map is admitted, it is the only one.

::: pf-proof

By steps [](#s2){.pf-ref} and [](#s3){.pf-ref} there is no element of $B$ to serve as $\varphi(\alpha)$, so no unital homomorphism exists.

For an arbitrary ring homomorphism $\varphi:A\to B$: the element $e=\varphi(1)$ satisfies $e^2=e$, and in the field $B$ the only idempotents are $0$ and $1$. If $e=0$ then $\varphi\equiv0$. If $e=1$ then $\varphi$ is unital, which is impossible. Hence there are no ring homomorphisms, except the zero map if it is counted as one.

:::

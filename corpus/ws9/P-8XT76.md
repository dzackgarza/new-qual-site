::: {.problem title="?"}
Let $(f_n)$ be a sequence of continuous functions on $[0,1]$ such that for each $x\in[0,1]$ there is an $N=N_x$ so that $$f_n(x)\ge 0\quad\text{for all }n\ge N_x.$$ Show that there is an open nonempty set $U\subset[0,1]$ and an $N\in\mathbb{N}$ so that $f_n(x)\ge 0$ for all $n\ge N$ and all $x\in U$.
:::

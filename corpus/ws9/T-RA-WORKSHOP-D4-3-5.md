:::{.theorem title="Theorem 3.5"}
If $f:(a,b)\to\mathbb R$ is monotonic then $f$ is discontinuous on a set $E\subset(a,b)$ which is at
most countable. Further, each point where $f$ is discontinuous is a jump discontinuity in that the limits
$f(x_i-)$ and $f(x_i+)$ both exist for each $x_i\in E$.
:::

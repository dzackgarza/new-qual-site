:::{.problem title="?"}
a. For $f\in L^2(\mathbb{R})$ and a sequence $\{x_n\}\subseteq\mathbb{R}$ which converges to zero, define $f_n(x):=f(x+x_n)$. Show that $\{f_n\}$ converges to $f$ in $L^2$.

b. Let $W\subseteq\mathbb{R}$ be a Lebesgue measurable set of positive Lebesgue measure. Show that the set of differences $W-W = \{x-y: x,y\in W\}$ contains an open neighborhood of the origin.
:::

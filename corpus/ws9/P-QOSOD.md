:::{.problem title="?"}
Let $D = \{z \in \mathbb{C} : |z| < 1\}$ denote the unit disk. What is the maximum possible value of $|f'(\frac{1}{2})|$ for a holomorphic function $f : D \to D$ with $f(\frac{1}{2}) = \frac{3}{4}$? Find all such functions $f$ that attain this maximum value.
:::

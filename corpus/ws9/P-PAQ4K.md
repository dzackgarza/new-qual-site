:::{.problem title="?"}
Assume that $f_1, f_2, \ldots$ is a sequence of positive continuous functions defined on $[0,1]$ with
$$f(x) = \lim_{n\to\infty} f_n(x) \text{ for every } x \in [0,1]$$
and
$$\int_0^1 f_n(x)dx = 1.$$

a. Is it always true that $\int_0^1 f(x)dx \le 1$? Provide a proof if it is true or provide a counter example if it is false.
b. Is it always true that $\int_0^1 f(x)dx \ge 1$? Provide a proof if it is true or provide a counter example if it is false.
:::

:::{.problem title="?"}
Let $Y$ be a closed subspace of a Banach space $X$, with norm $\|\cdot\|$. Let $|||\cdot|||$ be a norm on $Y$ which is equivalent to $\|\cdot\|$, meaning that there is a $C\ge 1$ so that for all $y\in Y$:
$$\frac{1}{C}|||y|||\le\|y\|\le C|||y|||.$$
Let $S$ be the set of all linear functionals $\psi:X\to\mathbb{R}$, so that
$|\psi(y)|\le |||y|||$ for all $y\in Y$ and
$|\psi(x)|\le \|x\|$ for all $x\in X$.
Prove the following statements:

(1) $|||x|||:=\sup_{\psi\in S}|\psi(x)|$ defines a norm on $X$.

(2) $|||y|||=\|y\|$ for $y\in Y$.

(3) The norm $|||\cdot|||$ and $\|\cdot\|$ are equivalent on $X$.
:::

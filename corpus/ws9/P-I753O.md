::: {.problem title="?"}
Let $T$ be a linear transformation on $C_0(\mathbb{R})$, the space of continuous functions of compact support, that has the following two properties: $$\|Tf\|_{L^\infty} \le \|f\|_{L^\infty}, \text{ and } \left|\{x \in \mathbb{R} : |Tf(x)| > \lambda\}\right| \le \frac{\|f\|_{L^1}}{\lambda}.$$ (Here $|A|$ denotes the Lebesgue measure of the set $A$.)
Prove that $$\int_{-\infty}^{+\infty} |Tf(x)|^2 dx \le C\int_{-\infty}^{+\infty} |f(x)|^2 dx$$ for all $f \in C_0(\mathbb{R})$ and some fixed number $C$.
:::

:::: {.solution}
> **AI-Generated Solution**

<1>1. Reduce to a pointwise split of $f$ at height $\lambda/2$.
    Proof: fix $f \in C_0(\mathbb{R})$ and $\lambda > 0$, and write $f = g_\lambda + h_\lambda$ with $g_\lambda = f\,\mathbf 1_{\{|f| > \lambda/2\}}$ and $h_\lambda = f\,\mathbf 1_{\{|f| \le \lambda/2\}}$. Then $\|h_\lambda\|_{L^\infty} \le \lambda/2$ and $\|g_\lambda\|_{L^1} \le \|f\|_{L^1}$.
<1>2. Bound the distribution function of $Tf$.
    Proof: $\{|Tf| > \lambda\} \subseteq \{|Tg_\lambda| > \lambda/2\} \cup \{|Th_\lambda| > \lambda/2\}$. The second set is empty, since the strong bound gives $\|Th_\lambda\|_{L^\infty} \le \|h_\lambda\|_{L^\infty} \le \lambda/2$, so $|Th_\lambda(x)| \le \lambda/2$ everywhere. The first set is controlled by the weak $(1,1)$ bound:
    \[\left|\{|Tg_\lambda| > \lambda/2\}\right| \le \frac{\|g_\lambda\|_{L^1}}{\lambda/2} = \frac{2\|g_\lambda\|_{L^1}}{\lambda}.\]
    Hence $\left|\{|Tf| > \lambda\}\right| \le 2\|g_\lambda\|_{L^1}/\lambda$ with $g_\lambda = f\mathbf 1_{\{|f| > \lambda/2\}}$.
<1>3. Apply the layer-cake formula for the $L^2$ norm.
    Proof: for any measurable $u$, $\|u\|_{L^2}^2 = \int_0^\infty 2\lambda\,|\{|u| > \lambda\}|\,d\lambda$ (Tonelli: $\int_0^\infty 2\lambda\mathbf 1_{\{|u|>\lambda\}}d\lambda = |u|^2$). Applying it to $Tf$ and using <1>2,
    \[\|Tf\|_{L^2}^2 \le \int_0^\infty 2\lambda\cdot\frac{2}{\lambda}\int_{\{|f| > \lambda/2\}}|f(x)|\,dx\,d\lambda = 4\int_{\mathbb{R}}|f(x)|\left(\int_0^{2|f(x)|}d\lambda\right)dx = 4\int_{\mathbb{R}}|f(x)|\cdot 2|f(x)|\,dx = 8\|f\|_{L^2}^2,\]
    where the interchange is justified by Tonelli (all integrands are non-negative).
<1>4. Conclude.
    Proof: $\|Tf\|_{L^2} \le \sqrt{8}\,\|f\|_{L^2}$ for all $f \in C_0(\mathbb{R})$, so the claimed inequality holds with $C = 8$ (equivalently $\sqrt{8}$ under the square root).
<1>5. Q.E.D.

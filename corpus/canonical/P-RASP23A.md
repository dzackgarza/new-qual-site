::: problem
TRUE or FALSE: If true, prove it. If false, disprove it.

(a) If $f$ is a linear functional of a normed vector space $X$, $f^{-1}(0)$ is closed.

(b) In a Hilbert space, if $\{x_n\}$ converges to $x$ weakly and $\|x_n\| \to \|x\|$, then $\{x_n\}$ converges to $x$ strongly, namely $\|x_n - x\| \to 0$.

(c) Let $E \subset \mathbb{R}$ be a Lebesgue measurable set and assume that there exists $0 < \alpha < 1$ such that $m(E \cap I) \leq \alpha \, m(I)$ for all open intervals $I$. Then $m(E) = 0$.
:::

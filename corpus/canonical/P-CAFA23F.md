::: problem
For each $N \in \mathbb{N}$, let $P_N(z) = \sum_{n=0}^{N} \frac{z^n}{n!}$.

(a) Show that the set $\{z \in \mathbb{C} : P_N(z) = 0 \text{ for some } N \in \mathbb{N}\}$ is discrete.

(b) Find a constant $c > 0$ such that $P_N(z)$ has no zeros in $\{z \in \mathbb{C} : |z| < cN\}$.
You may use the inequality $n! > e^{-n} n^n$ if you wish.
:::

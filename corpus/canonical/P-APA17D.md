::: problem
Let $Q_8$ denote the quaternion group $Q_8 = \{\pm 1, \pm i, \pm j, \pm k\}$ with the usual multiplication
\[
(-1)^2 = 1,\quad
(-1)i = -i = i(-1),\quad
(-1)j = -j = j(-1),\quad
(-1)k = -k = k(-1),
\]
\[
i^2 = j^2 = k^2 = -1,\quad
ij = k = -ji,\quad
ki = j = -ik,\quad
jk = i = -kj.
\]
Calculate the character table of $Q_8$.
:::

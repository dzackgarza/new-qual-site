4. Let f be a holomorphic function which maps the unit disk into the unit disc.
   Show that

$$
| f ( z ) + f ( - z ) | \leq 2 | z | ^ { 2 }
$$

for all z in the unit disc, and if the equality holds for some z, then,

$$
f \left( z \right) = e ^ { i \theta } z ^ { 2 }
$$

for some real ^.

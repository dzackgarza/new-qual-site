$$
g _ { n } ( t ) = \operatorname* { m a x } \{ f _ { 1 } ( t ) , \ldots , f _ { n } ( t ) \}
$$

for $n = 1 , 2 , \dots$ . Prove that the sequence $\left\{ g _ { n } \right\}$ converges uniformly on [0, 1].

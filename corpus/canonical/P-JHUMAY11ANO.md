7. Determine all entire functions $f \ ( \mathrm { i . e . } , \ f ( z )$ is holomorphic and is defined for all $z \in \mathbb { C } )$ that satisfy the inequality:

$$
| f ( z ) | \leq | \mathrm { R e } z | ^ { 2 } + | z | ^ { \frac { 3 } { 2 } } \quad \mathrm { w h e n e v e r ~ } | z | > 1 .
$$

::: problem
(a) Let $A\in M_n$.
Show that if $z^HAz=0$ for all $z\in\mathbb{C}^n$ then $A=0$.

(b) Give a $2\times 2$ example of $A\in M_2(\mathbb{R})$, where $A\neq 0$, but $x^TAx=0$ for all $x\in\mathbb{R}^2$.

(c) Show that $A\in M_n$ is normal iff $\|Ax\|_2=\|A^Hx\|_2$ for all $x\in\mathbb{C}^n$.

(d) Show that $A\in M_n$ is normal iff $(Ax,Ay)=(A^Hx,A^Hy)$ for all $x,y\in\mathbb{C}^n$.

(Notation: $M_n$ denotes the set of $n\times n$ complex matrices; $M_2(\mathbb{R})$ denotes the set of $2\times 2$ real matrices.)
:::

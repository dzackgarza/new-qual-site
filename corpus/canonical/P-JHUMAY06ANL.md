12. Let $f _ { j }$ be an orthonormal sequence in $L ^ { 2 } ( [ 0 , 1 ] )$ . Prove that

$$
S _ { n } = \frac { 1 } { n } \sum _ { j = 1 } ^ { n } f _ { j }
$$

converges to zero a.e.

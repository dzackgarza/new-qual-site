::: problem
Assume that $f: \mathbb{D} \to \mathbb{D}$ is an analytic function such that $f(0) = 0$.
Show that $g(z) = \sum_{n=0}^{\infty} f(z^n)$ converges to an analytic function on $\mathbb{D}$.
:::

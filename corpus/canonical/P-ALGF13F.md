::: problem
Let $p$ be an odd prime. Let $E$ be a splitting field of $x^p - x + 1$ over $\mathbb{F}_p$.

(a) Prove that, if $\alpha \in E$ is a root of $x^p - x + 1$, then for any $0 \leq i \leq p$ we have $\alpha^{p^i} = \alpha - i$.

(b) Explain why if $K$ is any finite field, then $|K| = \min\{n \mid x^n = x \text{ for all } x \in K\}$. Then prove that $x^p - x + 1$ is irreducible over $\mathbb{F}_p$ and find $|E|$.
:::

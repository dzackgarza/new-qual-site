::: {.problem}
Let $f: \RR^n\to \RR$ be a Lebesgue measurable function.

a. Prove that for all \( \alpha> 0 \) ,
\[
A_ \alpha  \definedas \theset{x\in \RR^n \st \abs{ f(x) } > \alpha} \implies m(A_ \alpha) \leq {1\over \alpha} \int \abs{f (x)} \dx
.\]

b. Prove that 
\[
\int \abs{ f(x) } \dx = 0 \iff f = 0 \text{ almost everywhere}
.\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For $\alpha > 0$, $m(A_\alpha) \le \frac{1}{\alpha}\int|f|$.

::: pf-proof

Since $|f| > \alpha$ on $A_\alpha$ and $|f| \geq 0$ everywhere, $\int_{\RR^n}|f| \ge \int_{A_\alpha}|f| \ge \int_{A_\alpha}\alpha = \alpha\, m(A_\alpha)$.

:::

:::

::: {.pf-step #s2}

$\int |f| = 0$ if and only if $f = 0$ a.e.

::: pf-proof

::: {.pf-step #s2-1}

If $f = 0$ a.e., then $\int|f| = 0$.

::: pf-proof

$|f|$ agrees a.e. with the zero function, and functions equal a.e. have equal integrals.

:::

:::

::: {.pf-step #s2-2}

If $\int|f| = 0$, then $f = 0$ a.e.

::: pf-proof

$\theset{|f| > 0} = \bigcup_{k \geq 1} A_{1/k}$, and step [](#s1){.pf-ref} gives $m(A_{1/k}) \le k\int|f| = 0$ for each $k$. A countable union of null sets is null.

:::

:::

:::

:::

:::

::: pf-qed

Step [](#s1){.pf-ref} is part (a) and step [](#s2){.pf-ref} is part (b).

::: {.problem}
Let $f: \RR^n\to \RR$ be a Lebesgue measurable function.

(a) Prove that for all $\alpha> 0$, the set $A_ \alpha  \coloneqq \theset{x\in \RR^n \st \abs{ f(x) } > \alpha}$ satisfies
$$
m(A_ \alpha) \leq {1\over \alpha} \int \abs{f (x)} \dx.
$$

(b) Prove that
$$
\int \abs{ f(x) } \dx = 0 \iff f = 0 \text{ almost everywhere}.
$$
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

For $\alpha > 0$, $m(A_\alpha) \le \frac{1}{\alpha}\int\abs{f}$.

::: pf-proof

Since $\abs{f} > \alpha$ on $A_\alpha$ and $\abs{f} \geq 0$ everywhere, $\int_{\RR^n}\abs{f} \ge \int_{A_\alpha}\abs{f} \ge \int_{A_\alpha}\alpha = \alpha\, m(A_\alpha)$.

:::

:::

::: {.pf-step #s2}

$\int \abs{f} = 0$ if and only if $f = 0$ a.e.

::: pf-proof

::: {.pf-step #s2-1}

If $f = 0$ a.e., then $\int\abs{f} = 0$.

::: pf-proof

$\abs{f}$ agrees a.e. with the zero function, and functions equal a.e. have equal integrals.

:::

:::

::: {.pf-step #s2-2}

If $\int\abs{f} = 0$, then $f = 0$ a.e.

::: pf-proof

$\theset{\abs{f} > 0} = \bigcup_{k \geq 1} A_{1/k}$, and step [](#s1){.pf-ref} gives $m(A_{1/k}) \le k\int\abs{f} = 0$ for each $k$. A countable union of null sets is null.

:::

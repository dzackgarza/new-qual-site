::: {.exercise}
(a) Show that if $f\in L^1(\RR)$ and $\hat f = 0$, then $f = 0$ almost everywhere.

(b) Show that Fourier inversion formula $f(x) = \int_\RR \hat f(\xi) e^{2\pi i x \xi}\, d\xi$ does not necessarily hold pointwise for arbitrary $f \in L^1(\RR)$ (since $\hat f$ need not be in $L^1(\RR)$).
:::

::: {.solution}
Use $\hat f(\xi)=\int_\RR f(x)e^{-2\pi i\xi x}\,dx$, and for $\varepsilon>0$ the Gaussian
$$
\Phi_\varepsilon(x) = \frac{1}{\varepsilon} e^{-\pi (x/\varepsilon)^2}, \qquad \widehat{\Phi_\varepsilon}(\xi) = e^{-\pi \varepsilon^2 \xi^2}.
$$

::: pf

::: {.pf-step #conv}
For $f\in L^1(\RR)$, $(f*\Phi_\varepsilon)(x)=\int_\RR\hat f(\xi)e^{2\pi ix\xi}\widehat{\Phi_\varepsilon}(\xi)\,d\xi$ for all $x$.

::: pf-proof
Fourier inversion holds for the Gaussian: $\Phi_\varepsilon(x-y)=\int_\RR\widehat{\Phi_\varepsilon}(\xi)e^{2\pi i(x-y)\xi}\,d\xi$. Substitute this into $(f*\Phi_\varepsilon)(x)=\int_\RR f(y)\Phi_\varepsilon(x-y)\,dy$ and apply Fubini's theorem, which holds because $\abs{f(y)}\widehat{\Phi_\varepsilon}(\xi)$ is integrable on $\RR^2$.
:::

:::

::: pf-step
(a) If $\hat f=0$, then $f=0$ almost everywhere.

::: pf-proof
By step [](#conv){.pf-ref}, $f*\Phi_\varepsilon=0$ for every $\varepsilon>0$. Since $(\Phi_\varepsilon)$ is an approximate identity, $\norm{f*\Phi_\varepsilon-f}_{L^1}\to0$ as $\varepsilon\to0^+$, so $\norm{f}_{L^1}=0$.
:::

:::

::: {.pf-step #indicator}
For $f=\mathbf{1}_{[-1,1]}$, $\hat f(\xi)=\dfrac{\sin(2\pi\xi)}{\pi\xi}$ and $\hat f\notin L^1(\RR)$.

::: pf-proof
$\hat f(\xi)=\int_{-1}^1e^{-2\pi ix\xi}\,dx=\frac{e^{2\pi i\xi}-e^{-2\pi i\xi}}{2\pi i\xi}=\frac{\sin(2\pi\xi)}{\pi\xi}$.
For $k\ge1$ and $\xi\in[k/2+1/8,k/2+3/8]$, $\abs{\sin(2\pi\xi)}\ge1/\sqrt2$, so $\abs{\hat f(\xi)}\ge\frac{1}{\sqrt2\,\pi(k/2+1)}$. Each such interval has length $1/4$, and comparison with the harmonic series gives $\int_\RR\abs{\hat f}=\infty$.
:::

:::

::: pf-step
(b) The inversion formula does not hold pointwise for every $f\in L^1(\RR)$.

::: pf-proof
For $f=\mathbf{1}_{[-1,1]}$, step [](#indicator){.pf-ref} shows that the integral $\int_\RR\hat f(\xi)e^{2\pi ix\xi}\,d\xi$ does not exist as a Lebesgue integral at any $x$. Even the symmetric limit $\lim_{R\to\infty}\int_{-R}^R\hat f(\xi)e^{2\pi ix\xi}\,d\xi$ equals $1/2\ne1=f(\pm1)$ at $x=\pm1$.
:::

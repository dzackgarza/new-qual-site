::: {.exercise}
- $\star$: Show that for $E\subseteq \RR^n$, TFAE:

  1. $E$ is measurable

  2. $E = H\union Z$ here $H$ is $F_\sigma$ and $Z$ is null

  3. $E = V\setminus Z'$ where $V\in G_\delta$ and $Z'$ is null.
:::

::: {.solution}
Let $m$ denote Lebesgue measure on $\RR^n$.

::: pf

::: {.pf-step #s1}

(1) $\Rightarrow$ (2).

::: pf-proof

::: {.pf-step #s1-1}

For each $k \geq 1$ there is a closed $F_k \subseteq E$ with $m(E \setminus F_k) < 1/k$.

::: pf-proof

This is inner regularity of Lebesgue measure by closed sets, which holds for every measurable $E \subseteq \RR^n$: apply outer regularity to $E^c$ to get an open $G \supseteq E^c$ with $m(G \setminus E^c) < 1/k$, and put $F_k = G^c$.

:::

:::

::: pf-qed

Put $H \coloneqq \bigcup_k F_k$ and $Z \coloneqq E \setminus H$.
$H$ is a countable union of closed sets, hence $F_\sigma$, and $E = H \cup Z$.
Since $Z \subseteq E \setminus F_k$ for every $k$, step [](#s1-1){.pf-ref} gives $m(Z) < 1/k$ for all $k$, so $m(Z) = 0$.

:::

:::

:::

::: {.pf-step #s2}

(1) $\Rightarrow$ (3).

::: pf-proof

::: {.pf-step #s2-1}

For each $k \geq 1$ there is an open $G_k \supseteq E$ with $m(G_k \setminus E) < 1/k$.

::: pf-proof

This is outer regularity of Lebesgue measure.

:::

:::

::: pf-qed

Put $V \coloneqq \bigcap_k G_k$ and $Z' \coloneqq V \setminus E$.
$V$ is a countable intersection of open sets, hence $G_\delta$.
Since $Z' \subseteq G_k \setminus E$ for every $k$, step [](#s2-1){.pf-ref} gives $m(Z') < 1/k$ for all $k$, so $m(Z') = 0$.
Since $E \subseteq V$, $V \setminus Z' = V \setminus (V \setminus E) = E$.

:::

:::

:::

::: {.pf-step #s3}

(2) $\Rightarrow$ (1).

::: pf-proof

$H$ is a countable union of closed, hence measurable, sets, so $H$ is measurable. $Z$ is null, hence measurable because Lebesgue measure is complete. So $E = H \cup Z$ is measurable.

:::

:::

::: {.pf-step #s4}

(3) $\Rightarrow$ (1).

::: pf-proof

$V$ is a countable intersection of open, hence measurable, sets, so $V$ is measurable. $Z'$ is null, hence measurable. So $E = V \cap (Z')^c$ is measurable.

:::

:::

::: pf-qed

Steps [](#s1){.pf-ref} and [](#s2){.pf-ref} give (1) $\Rightarrow$ (2) and (1) $\Rightarrow$ (3), and steps [](#s3){.pf-ref} and [](#s4){.pf-ref} give the converses.

:::

::: {.exercise}
- $\star$: Show that cylinder functions are measurable, i.e. if $f$ is measurable on $\RR^s$, then $F(x, y) \definedas f(x)$ is measurable on $\RR^s\cross \RR^t$ for any $t$.
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

The claim holds when $f = \chi_E$ is the indicator of a measurable set $E \subseteq \RR^s$.

::: pf-proof

::: {.pf-step #s1-1}

$F = \chi_{E \cross \RR^t}$.

::: pf-proof

$F(x,y) = 1$ if and only if $x \in E$, that is, if and only if $(x,y) \in E \cross \RR^t$.

:::

:::

::: {.pf-step #s1-2}

$E \cross \RR^t$ is measurable.

::: pf-proof

Write $E = V \setminus Z$ with $V$ a $G_\delta$ set and $Z$ a Lebesgue null set. Then $E \cross \RR^t = (V \cross \RR^t) \setminus (Z \cross \RR^t)$. The set $V \cross \RR^t = \pi_s^{-1}(V)$ is Borel, because the projection $\pi_s: \RR^s \cross \RR^t \to \RR^s$ is continuous. The set $Z \cross \RR^t$ is null: $Z \cross [-k,k]^t$ is covered by products of cubes of total measure at most $(2k)^t\eps$ for every $\eps > 0$, and $Z \cross \RR^t$ is the countable union over $k$ of these sets. So $E \cross \RR^t$ is Lebesgue measurable.

:::

:::

::: pf-qed

Steps [](#s1-1){.pf-ref} and [](#s1-2){.pf-ref} show that $F$ is the indicator of a measurable set.

:::

:::

:::

::: {.pf-step #s2}

The claim holds for simple functions $f = \sum_{i=1}^k c_i \chi_{E_i}$.

::: pf-proof

$F(x,y) = \sum_i c_i \chi_{E_i}(x)$ is a finite linear combination of functions that are measurable by step [](#s1){.pf-ref}.

:::

:::

::: {.pf-step #s3}

The claim holds for measurable $f \geq 0$.

::: pf-proof

There are simple functions $0 \leq s_n \nearrow f$ pointwise. By step [](#s2){.pf-ref}, $F_n(x,y) \coloneqq s_n(x)$ is measurable, and $F_n(x,y) \nearrow f(x) = F(x,y)$ for each $(x,y)$. A pointwise limit of measurable functions is measurable.

:::

:::

::: pf-qed

For general measurable $f$, write $f = f^+ - f^-$ and apply step [](#s3){.pf-ref} to $f^+$ and $f^-$.

:::

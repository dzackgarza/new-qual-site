::: {.exercise}

What is a **nowhere dense** subspace?

:::

::: {.solution}

A subset $A$ of a topological space $X$ is nowhere dense in $X$ if $\operatorname{int}_X(\overline A)=\varnothing$.

::: pf

::: {.pf-step #complement-dense}

$A$ is nowhere dense iff $X\setminus\overline A$ is dense in $X$.

::: pf-proof

Taking complements, $\overline{X\setminus\overline A} = X\setminus\operatorname{int}(\overline A)$, and this equals $X$ iff $\operatorname{int}(\overline A)=\varnothing$.

:::

:::

::: pf-step

$A$ is nowhere dense iff every nonempty open set $U\subseteq X$ contains a nonempty open set $V\subseteq U$ with $V\cap A=\varnothing$.

::: pf-proof

If $A$ is nowhere dense, take $V=U\cap(X\setminus\overline A)$, which is open, and nonempty because $X\setminus\overline A$ is dense by step [](#complement-dense){.pf-ref}.
Conversely, if every nonempty open $U$ contains such a $V$, then $V$ is open and disjoint from $A$, hence from $\overline A$, so no nonempty open set is contained in $\overline A$; hence $\operatorname{int}(\overline A)=\varnothing$.

:::

:::

::: pf-step

Finite subsets of $\RR$, the set $\ZZ$, and the Cantor set are nowhere dense in $\RR$; $\QQ$ is not.

::: pf-proof

Each of the first three sets is closed and contains no open interval, so its closure has empty interior. On the other hand $\overline{\QQ}=\RR$, whose interior is $\RR$.

:::

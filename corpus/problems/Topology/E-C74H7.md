::: {.exercise}
Use the fact that intervals are connected to prove the intermediate value theorem.
:::

::: {.solution}
Let $f: [a,b] \to \RR$ be continuous, and let $c$ lie between $f(a)$ and $f(b)$. We show that $f(x)=c$ for some $x\in[a,b]$.

::: pf

::: {.pf-step #image-interval}

$f([a,b])$ is an interval.

::: pf-proof

The interval $[a,b]$ is connected, the continuous image of a connected space is connected, and the connected subsets of $\RR$ are exactly the intervals.

:::

:::

::: pf-qed

The interval $f([a,b])$ of step [](#image-interval){.pf-ref} contains $f(a)$ and $f(b)$, hence every point between them, in particular $c$. So $c=f(x)$ for some $x\in[a,b]$.

:::

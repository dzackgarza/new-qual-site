::: {.exercise}
Use the fact that intervals are connected to prove the intermediate value theorem.
:::

::: {.solution}
**Goal.** Prove the intermediate value theorem using connectedness of intervals.

::: pf

::: pf-step

Let $f: [a,b] \to \RR$ be continuous, and suppose $f(a) < c < f(b)$ (the other case is symmetric).

::: pf-proof

setup.

:::

:::

::: pf-step

$[a,b]$ is connected.

::: pf-proof

intervals are connected.

:::

:::

::: pf-step

$f([a,b])$ is connected.

::: pf-proof

the continuous image of a connected space is connected.

:::

:::

::: pf-step

$f([a,b])$ is a connected subset of $\RR$, hence an interval.

::: pf-proof

the connected subsets of $\RR$ are exactly the intervals.

:::

:::

::: pf-step

$f(a), f(b) \in f([a,b])$, so the interval $f([a,b])$ contains $[f(a), f(b)]$.

::: pf-proof

an interval containing $f(a)$ and $f(b)$ contains everything between them.

:::

:::

::: {.pf-step #s6}

Hence $c \in [f(a), f(b)] \subseteq f([a,b])$, so there is $x \in [a,b]$ with $f(x) = c$.

::: pf-proof

$c$ is between $f(a)$ and $f(b)$.

:::

:::

::: pf-qed

Step [](#s6){.pf-ref} is the intermediate value theorem.

:::

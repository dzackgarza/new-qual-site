::: {.problem}
Prove that for every $n\in \ZZ^{\geq 0}$ the following polynomial has no roots in the open unit disc:
$$
f_n(z) \definedas \sum_{k=0}^n {z^k \over k!}
.$$
:::

::: {.hint}
Check $n=1,2$ directly.
:::

::: {.solution}

::: pf

::: pf-step

For $n\le1$, $f_n$ has no zeros in $\DD$.

::: pf-proof

$f_0\equiv1$, and the only zero of $f_1(z)=1+z$ is $-1\notin\DD$.

:::

:::

::: {.pf-step #tail}

For $n\ge2$ and $\abs z=1$, $\abs{e^z-f_n(z)}\le\frac14$.

::: pf-proof

For $k\ge3$ we have $k!\ge2\cdot3^{k-2}$, so on $\abs z=1$
$$
\abs{e^z-f_n(z)}\le\sum_{k=n+1}^\infty\frac1{k!}\le\sum_{k=3}^\infty\frac1{k!}\le\frac12\sum_{j=1}^\infty\frac1{3^j}=\frac14.
$$

:::

:::

::: pf-step

For $n\ge2$, $f_n$ has no zeros in $\DD$.

::: pf-proof

On $\abs z=1$, $\abs{e^z}=e^{\Re z}\ge e^{-1}>\frac13$, so step [](#tail){.pf-ref} gives $\abs{e^z-f_n(z)}<\abs{e^z}$ there. By Rouché's theorem, $f_n$ and $e^z$ have the same number of zeros in $\DD$, and $e^z$ has none.

:::

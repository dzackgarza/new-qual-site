::: {.problem}
Find a conformal map

(a) from $\{ z: \abs{z - 1/2} > 1/2, \Re(z)>0 \}$ to $\HH$

(b) from $\{ z: \abs{z - 1/2} > 1/2, \abs{z} <1 \}$ to $\DD$

(c) from the intersection of the disk $\abs{z + i} < \sqrt{2}$ with $\HH$ to $\DD$.

(d) from $\DD \setminus [a, 1)$ to $\DD \setminus [0, 1)$ ($0<a<1$).

(e) from $\{ z: \abs{z} < 1, \Re(z) > 0 \} \setminus (0, 1/2]$ to $\HH$.
:::

::: {.hint}
(d) A Blaschke factor gives a short solution.
:::

::: {.solution}
Throughout, $C(w) = \frac{w-i}{w+i}$ is the Cayley transform, a biholomorphism $\HH \to \DD$, and $\exp$ maps the strip $\{0 < \Im w < \pi\}$ biholomorphically onto $\HH$.

(a) Let $\Omega_1$ be the domain.

::: pf

::: {.pf-step #a-strip}
$z \mapsto 1/z$ maps $\Omega_1$ biholomorphically onto the strip $\{0 < \Re w < 1\}$.

::: pf-proof
For $z = x+iy \neq 0$, $\Re(1/z) = \frac{x}{x^2+y^2}$.
So $\Re(1/z) > 0$ if and only if $x > 0$, and $\Re(1/z) < 1$ if and only if $x^2 + y^2 > x$, that is, $\abs{z - 1/2} > 1/2$.
The map is its own inverse.
:::

:::

::: pf-step
$\boxed{f_1(z) = \exp\left(\frac{i\pi}{z}\right)}$ maps $\Omega_1$ conformally onto $\HH$.

::: pf-proof
Multiplication by $i\pi$ maps the strip of step [](#a-strip){.pf-ref} onto $\{0 < \Im w < \pi\}$, which $\exp$ maps onto $\HH$.
:::

:::

:::

(b) Let $\Omega_2$ be the domain.

::: pf

::: {.pf-step #b-strip}
$z \mapsto \frac{1}{z-1}$ maps $\Omega_2$ biholomorphically onto the strip $\{-1 < \Re w < -1/2\}$.

::: pf-proof
For $z = x + iy \neq 1$, $\Re\frac{1}{z-1} = \frac{x-1}{\abs{z-1}^2}$.
Now $\abs{z} < 1$ if and only if $\abs{z-1}^2 < 2(1-x)$, that is, $\Re\frac{1}{z-1} < -\frac12$; and $\abs{z - 1/2} > 1/2$ if and only if $\abs{z-1}^2 > 1 - x$, that is, $\Re\frac{1}{z-1} > -1$.
The map $w \mapsto 1 + 1/w$ is its inverse.
:::

:::

::: pf-step
$$
\boxed{f_2(z) = C\left(\exp\frac{2\pi i z}{z-1}\right) = \frac{\exp\left(\frac{2\pi i z}{z-1}\right) - i}{\exp\left(\frac{2\pi i z}{z-1}\right) + i}}
$$
maps $\Omega_2$ conformally onto $\DD$.

::: pf-proof
The map $w \mapsto 2\pi i(w+1)$ sends the strip of step [](#b-strip){.pf-ref} onto $\{0 < \Im w < \pi\}$, and $2\pi i\left(\frac{1}{z-1} + 1\right) = \frac{2\pi i z}{z-1}$.
Then $\exp$ maps onto $\HH$ and $C$ onto $\DD$.
:::

:::

:::

(c) Let $\Omega_3 = \{z \in \HH : \abs{z+i} < \sqrt2\}$, a lune with vertices $\pm 1$ bounded by $(-1,1)$ and an arc of the circle $\abs{z+i} = \sqrt2$, and let $M(z) = \frac{z+1}{z-1}$.

::: pf

::: {.pf-step #c-sector}
$M$ maps $\Omega_3$ biholomorphically onto the sector $\{\pi < \arg w < 5\pi/4\}$.

::: pf-proof
$M$ sends $-1 \mapsto 0$ and $1 \mapsto \infty$, so it maps both boundary arcs of $\Omega_3$ to rays from $0$.
For $x \in (-1,1)$, $M(x) < 0$, so the segment goes to the ray $\arg w = \pi$.
The arc passes through $(\sqrt2-1)i$, and
$$
M\bigl((\sqrt2-1)i\bigr) = -\frac{1+i}{\sqrt2},
$$
so the arc goes to the ray $\arg w = 5\pi/4$.
The point $i/10 \in \Omega_3$ has $M(i/10) = \frac{-0.99 - 0.2i}{1.01}$, with argument in $(\pi, 5\pi/4)$, so $\Omega_3$ goes to the sector between these rays.
:::

:::

::: pf-step
$$
\boxed{f_3(z) = \frac{\left(\frac{z+1}{z-1}\right)^4 - i}{\left(\frac{z+1}{z-1}\right)^4 + i}}
$$
maps $\Omega_3$ conformally onto $\DD$.

::: pf-proof
By step [](#c-sector){.pf-ref}, $-M$ maps $\Omega_3$ onto $\{0 < \arg w < \pi/4\}$, which $w \mapsto w^4$ maps biholomorphically onto $\HH$.
Since $(-M)^4 = M^4$, $f_3 = C \circ M^4$.
:::

(d)

::: pf

::: pf-step
$\boxed{\varphi_a(z) = \frac{z - a}{1 - az}}$ maps $\DD \setminus [a,1)$ conformally onto $\DD \setminus [0,1)$.

::: pf-proof
For real $a \in (-1,1)$, $\varphi_a$ is an automorphism of $\DD$ that maps $[-1,1]$ to itself.
On $[a,1)$ it is strictly increasing, since $\varphi_a'(x) = \frac{1-a^2}{(1-ax)^2} > 0$, with $\varphi_a(a) = 0$ and $\varphi_a(x) \to 1$ as $x \to 1$; so $\varphi_a([a,1)) = [0,1)$.
A bijection of $\DD$ that maps $[a,1)$ onto $[0,1)$ maps the complements onto each other.
:::

(e) Let $\Omega_5$ be the domain.

::: pf

::: {.pf-step #e-square}
$z \mapsto z^2$ maps $\Omega_5$ biholomorphically onto $\DD \setminus (-1, 1/4]$.

::: pf-proof
The squaring map sends $re^{i\theta}$ with $0 < r < 1$, $-\pi/2 < \theta < \pi/2$ bijectively onto $r^2 e^{2i\theta}$, which fills $\DD \setminus (-1, 0]$.
It maps the slit $(0, 1/2]$ onto $(0, 1/4]$.
:::

:::

::: {.pf-step #e-blaschke}
$\psi(w) = \frac{w - 1/4}{1 - w/4} = \frac{4w-1}{4-w}$ maps $\DD \setminus (-1, 1/4]$ biholomorphically onto $\DD \setminus (-1, 0]$.

::: pf-proof
$\psi$ is an automorphism of $\DD$, increasing on $(-1,1)$, with $\psi(-1) = -1$ and $\psi(1/4) = 0$.
:::

:::

::: {.pf-step #e-root}
The principal square root maps $\DD \setminus (-1, 0]$ biholomorphically onto the right half-disc $\{\abs{\zeta} < 1, \Re\zeta > 0\}$, and $\zeta \mapsto i\zeta$ maps that onto the upper half-disc $\{\abs{\zeta} < 1, \Im\zeta > 0\}$.

::: pf-proof
The principal square root halves arguments in $(-\pi,\pi)$ and takes square roots of moduli.
:::

:::

::: {.pf-step #e-joukowski}
$J(\zeta) = -\frac12\left(\zeta + \frac1\zeta\right)$ maps the upper half-disc biholomorphically onto $\HH$.

::: pf-proof
For $\zeta = re^{i\theta}$, $\Im J(\zeta) = \frac12\left(\frac1r - r\right)\sin\theta$, which is positive for $0 < r < 1$, $0 < \theta < \pi$.
For $w \in \HH$, the equation $\zeta^2 + 2w\zeta + 1 = 0$ has two roots with product $1$, neither on the unit circle or the real axis (there $J$ is real), so exactly one lies in $\DD$; it lies in the upper half-disc because $\Im J > 0$ there and $\Im J < 0$ on the lower half-disc.
:::

:::

::: pf-step
With $s(z) = \sqrt{\frac{4z^2-1}{4-z^2}}$ (principal branch),
$$
\boxed{f_5(z) = J\bigl(i s(z)\bigr) = -\frac{i}{2}\left(s(z) - \frac{1}{s(z)}\right)}
$$
maps $\Omega_5$ conformally onto $\HH$.

::: pf-proof
$\psi(z^2) = \frac{4z^2-1}{4-z^2}$, so $f_5$ is the composition of the biholomorphisms of steps [](#e-square){.pf-ref}, [](#e-blaschke){.pf-ref}, [](#e-root){.pf-ref} and [](#e-joukowski){.pf-ref}.
:::

::: {.problem}
Find all entire functions satisfying
$$
\abs{f(z)} \leq \abs{z}^{1/2} \quad\text{ for } \abs{z} > 10.
$$
:::

::: {.solution}
Write $f(z) = \sum_{n\ge0} a_n z^n$, the Taylor series of $f$ at $0$, which converges on $\CC$.

::: pf

::: {.pf-step #constant}
$f$ is constant.

::: pf-proof
For $R>10$ and $n\ge1$, Cauchy's estimate on $\abs z=R$ and the hypothesis give $\abs{a_n}\le R^{-n}\max_{\abs z=R}\abs{f(z)}\le R^{1/2-n}$.
Letting $R\to\infty$ gives $a_n=0$ for $n\ge1$, so $f\equiv a_0$.
:::

:::

::: pf-step
The entire functions satisfying the bound are exactly $\boxed{f\equiv c \text{ with } \abs{c}\le\sqrt{10}}$.

::: pf-proof
By step [](#constant){.pf-ref}, $f\equiv c$.
The bound then says $\abs c\le\abs z^{1/2}$ for all $\abs z>10$, which holds exactly when $\abs c\le\inf_{\abs z>10}\abs z^{1/2}=\sqrt{10}$.
:::

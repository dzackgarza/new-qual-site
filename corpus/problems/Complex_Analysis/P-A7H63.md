::: {.problem}
Find all entire functions satisfying
\[
\abs{f(z)} \leq \abs{z}^{1\over 2} \quad\text{ for } \abs{z} > 10
.\]
:::

::: {.solution}
**Goal:** Find all entire functions with $\abs{f(z)} \leq \abs{z}^{1/2}$ for $\abs z > 10$.

::: pf

::: {.pf-step #taylor-expansion}
Write the Taylor expansion $f(z) = \sum_{n=0}^{\infty} a_n z^n$.

::: pf-proof
$f$ is entire, hence has a power series about $0$ converging on all of $\CC$.
:::

:::

::: {.pf-step #cauchy-estimate}
Cauchy's estimate: $\abs{a_n} \leq \frac{M(R)}{R^n}$ where $M(R) := \max_{\abs z = R} \abs{f(z)}$.

::: pf-proof
Standard Cauchy estimate for the $n$-th Taylor coefficient on the circle of radius $R$.
:::

:::

::: {.pf-step #coefficient-bound}
For $R > 10$ and $n \geq 1$, $\abs{a_n} \leq \frac{R^{1/2}}{R^n} = R^{1/2 - n}$.

::: pf-proof
Step [](#cauchy-estimate){.pf-ref} with $M(R) \leq R^{1/2}$ by hypothesis.
:::

:::

::: {.pf-step #higher-coeffs-zero}
$a_n = 0$ for all $n \geq 1$.

::: pf-proof
Step [](#coefficient-bound){.pf-ref} holds for arbitrarily large $R$, and $R^{1/2 - n} \to 0$ as $R \to \infty$ when $n \geq 1$; hence $\abs{a_n} = 0$.
:::

:::

::: {.pf-step #f-constant}
$f$ is constant: $f \equiv a_0$.

::: pf-proof
Steps [](#taylor-expansion){.pf-ref} and [](#higher-coeffs-zero){.pf-ref} leave only the constant term.
:::

:::

::: {.pf-step #constant-is-zero}
$a_0 = 0$.

::: pf-proof
$\abs{a_0} = \abs{f(z)} \leq \abs{z}^{1/2}$ for all $\abs z > 10$ (e.g. along $z = R > 10$, letting $R \to \infty$), forcing $a_0 = 0$.
:::

:::

::: pf-qed
Steps [](#f-constant){.pf-ref} and [](#constant-is-zero){.pf-ref} show the only such function is $f \equiv 0$; conversely $f \equiv 0$ satisfies the bound, since $|0| = 0 \le |z|^n$ for every $z$ and every $n$.
:::

:::

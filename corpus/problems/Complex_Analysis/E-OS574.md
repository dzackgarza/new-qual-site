::: problem
(1) Show that $\displaystyle f(z) = \frac{\pi^2}{\sin^2 \pi z}$ and $\displaystyle g(z) = \sum_{n = - \infty}^{ \infty} \frac{1}{(z-n)^2}$ have the same principal part at each integer point $k \in \mathbb{Z}$.

(2) Show that $\displaystyle h(z) = \frac{\pi^2}{\sin^2 \pi z} - g(z)$ is bounded on $\mathbb{C}$ and conclude that $\displaystyle \frac{\pi^2}{\sin^2 \pi z} = \sum_{n = - \infty}^{ \infty} \frac{1}{(z-n)^2}$.
:::

::: solution
**Goal:** Prove the partial fraction expansion $\frac{\pi^2}{\sin^2\pi z} = \sum_{n=-\infty}^\infty \frac{1}{(z-n)^2}$ using principal part matching and Liouville's Theorem.

<1>1. Part (1): Principal part at each integer $k \in \mathbb{Z}$:
    *Proof:*
    <2>1. By periodicity with period 1 ($\sin(\pi(z+1)) = -\sin(\pi z) \implies \sin^2(\pi(z+1)) = \sin^2(\pi z)$ and $g(z+1) = g(z)$), it suffices to consider $k = 0$.
    <2>2. Near $z = 0$, the Taylor expansion of $\sin(\pi z)$ is:
        $$\sin(\pi z) = \pi z - \frac{(\pi z)^3}{6} + O(z^5) = \pi z \left(1 - \frac{\pi^2 z^2}{6} + O(z^4)\right).$$
    <2>3. Squaring:
        $$\sin^2(\pi z) = \pi^2 z^2 \left(1 - \frac{\pi^2 z^2}{3} + O(z^4)\right).$$
    <2>4. Thus, the Laurent expansion of $f(z) = \frac{\pi^2}{\sin^2\pi z}$ near $z = 0$ is:
        $$f(z) = \frac{\pi^2}{\pi^2 z^2 \left(1 - \frac{\pi^2 z^2}{3} + O(z^4)\right)} = \frac{1}{z^2}\left(1 + \frac{\pi^2 z^2}{3} + O(z^4)\right) = \frac{1}{z^2} + \frac{\pi^2}{3} + O(z^2).$$
        The principal part of $f(z)$ at $z = 0$ is $\frac{1}{z^2}$.
    <2>5. For $g(z) = \frac{1}{z^2} + \sum_{n \ne 0} \frac{1}{(z-n)^2}$, the term $\sum_{n \ne 0} \frac{1}{(z-n)^2}$ is holomorphic in the disk $|z| < 1$.
    <2>6. Thus the principal part of $g(z)$ at $z = 0$ is also $\frac{1}{z^2}$.
    <2>7. At any integer $k \in \mathbb{Z}$, translating $z \mapsto z - k$ shows both functions have principal part $\frac{1}{(z-k)^2}$.

<1>2. Part (2): Boundedness of $h(z) = f(z) - g(z)$ and Liouville's Theorem:
    *Proof:*
    <2>1. Because $f(z)$ and $g(z)$ have the exact same principal parts at all poles $k \in \mathbb{Z}$, the difference $h(z) = f(z) - g(z)$ has removable singularities at every $k \in \mathbb{Z}$.
    <2>2. Extending $h$ across these points, $h(z)$ is an **entire function** (holomorphic on all of $\mathbb{C}$).
    <2>3. **Periodicity:** Both $f$ and $g$ are 1-periodic: $f(z+1) = f(z)$ and $g(z+1) = g(z)$, so $h(z+1) = h(z)$.
    <2>4. **Behavior as $|\operatorname{Im}(z)| \to \infty$:** Write $z = x + iy$.
        - $|\sin(\pi z)|^2 = \sin^2(\pi x) + \sinh^2(\pi y) \ge \sinh^2(\pi y) = \left(\frac{e^{\pi |y|} - e^{-\pi |y|}}{2}\right)^2 \to \infty$ as $|y| \to \infty$.
        - Thus $f(z) = \frac{\pi^2}{\sin^2(\pi z)} \to 0$ uniformly in $x$ as $|y| \to \infty$.
        - For $g(z)$: for $|y| \ge 1$, $|z-n|^2 = (x-n)^2 + y^2$, and $\sum_{n=-\infty}^\infty \frac{1}{(x-n)^2 + y^2} \le \int_{-\infty}^\infty \frac{dt}{t^2 + y^2} + \frac{1}{y^2} = \frac{\pi}{|y|} + \frac{1}{y^2} \to 0$ as $|y| \to \infty$.
    <2>5. Therefore, $h(z) \to 0$ uniformly as $|\operatorname{Im}(z)| \to \infty$.
    <2>6. On the compact strip $K = \{x + iy \mid 0 \le x \le 1, \, |y| \le 1\}$, the continuous function $h(z)$ is bounded by some constant $M$.
    <2>7. Outside $K$ ($|y| > 1$), $|h(z)| < 1$ for sufficiently large $|y|$. By 1-periodicity, $h(z)$ is bounded on the entire complex plane: $|h(z)| \le M'$ for all $z \in \mathbb{C}$.

<1>3. Conclusion from Liouville's Theorem:
    *Proof:*
    <2>1. By Liouville's Theorem, every bounded entire function is constant. Thus $h(z) = C$ for some constant $C \in \mathbb{C}$.
    <2>2. Since $\lim_{y \to \infty} h(iy) = 0 - 0 = 0$, we must have $C = 0$.
    <2>3. Therefore $h(z) \equiv 0$, so $\frac{\pi^2}{\sin^2 \pi z} = \sum_{n=-\infty}^\infty \frac{1}{(z-n)^2}$ for all $z \in \mathbb{C} \setminus \mathbb{Z}$.

<1>4. Conclusion:
    The identity $\frac{\pi^2}{\sin^2\pi z} = \sum_{n=-\infty}^\infty \frac{1}{(z-n)^2}$ is established. Q.E.D.
:::

::: {.problem}
(1) Show that $\displaystyle f(z) = \frac{\pi^2}{\sin^2 \pi z}$ and $\displaystyle g(z) = \sum_{n = - \infty}^{ \infty} \frac{1}{(z-n)^2}$ have the same principal part at each integer point $k \in \ZZ$.

(2) Show that $\displaystyle h(z) = \frac{\pi^2}{\sin^2 \pi z} - g(z)$ is bounded on $\CC$ and conclude that $\displaystyle \frac{\pi^2}{\sin^2 \pi z} = \sum_{n = - \infty}^{ \infty} \frac{1}{(z-n)^2}$.
:::

::: {.solution}

::: pf

::: {.pf-step #g-mero}
The series $g$ converges locally uniformly on $\CC\setminus\ZZ$, $g$ has period $1$, and $g(z)-\frac{1}{(z-k)^2}$ is holomorphic near each $k\in\ZZ$.

::: pf-proof
On $\abs{z}\leq R$, the terms with $\abs{n}\geq 2R$ satisfy $\abs{z-n}^{-2}\leq 4n^{-2}$, so by the Weierstrass $M$-test they sum to a holomorphic function there.
The finitely many remaining terms are holomorphic away from $\ZZ$, and near $k$ only $\frac{1}{(z-k)^2}$ is singular.
Replacing $z$ by $z+1$ reindexes the sum, so $g(z+1)=g(z)$.
:::

:::

::: {.pf-step #part-1}
(1) At each $k\in\ZZ$, $f$ and $g$ both have principal part $\frac{1}{(z-k)^2}$.

::: pf-proof
For $g$ this is step [](#g-mero){.pf-ref}.
Near $k$, $\sin(\pi z) = (-1)^k\left(\pi(z-k) - \frac{\pi^3(z-k)^3}{6} + O((z-k)^5)\right)$, so
$$
f(z) = \frac{1}{(z-k)^2}\left(1-\frac{\pi^2(z-k)^2}{6}+O((z-k)^4)\right)^{-2} = \frac{1}{(z-k)^2}+\frac{\pi^2}{3}+O((z-k)^2).
$$
:::

:::

::: {.pf-step #entire}
$h$ extends to an entire function of period $1$.

::: pf-proof
By step [](#part-1){.pf-ref}, $h$ is bounded near each integer, so each singularity is removable.
Both $f$ and $g$ have period $1$.
:::

:::

::: {.pf-step #decay}
$h(x+iy)\to0$ as $\abs{y}\to\infty$, uniformly in $x\in[0,1]$.

::: pf-proof
For $z=x+iy$, $\abs{\sin(\pi z)}^2=\sin^2(\pi x)+\sinh^2(\pi y)\geq\sinh^2(\pi y)$, so $\abs{f(z)}\leq\pi^2/\sinh^2(\pi y)$.
For $x\in[0,1]$ and $n\in\ZZ$, $\abs{x-n}\geq\max(0,\abs{n}-1)$, so
$$
\abs{g(x+iy)}\leq\sum_{n\in\ZZ}\frac{1}{(x-n)^2+y^2}\leq \frac{3}{y^2}+2\sum_{m\geq1}\frac{1}{m^2+y^2}\leq\frac{3}{y^2}+2\int_0^\infty\frac{dt}{t^2+y^2} = \frac{3}{y^2}+\frac{\pi}{\abs{y}}.
$$
:::

:::

::: {.pf-step #bounded}
(2) $h$ is bounded on $\CC$.

::: pf-proof
By step [](#decay){.pf-ref}, $h$ is bounded on $\{0\leq x\leq1,\ \abs{y}\geq Y\}$ for some $Y$, and it is bounded on the compact rectangle $\{0\leq x\leq1,\ \abs{y}\leq Y\}$ by continuity.
By step [](#entire){.pf-ref}, $h$ has period $1$, so these bounds hold on $\CC$.
:::

:::

::: pf-step
$\displaystyle\frac{\pi^2}{\sin^2 \pi z} = \sum_{n\in\ZZ} \frac{1}{(z-n)^2}$.

::: pf-proof
By step [](#bounded){.pf-ref} and Liouville's theorem, $h$ is constant, and by step [](#decay){.pf-ref} the constant is $0$.
:::

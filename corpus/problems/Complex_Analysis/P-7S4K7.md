::: {.problem}
- Show that any power series is continuous on its domain of convergence.
:::

::: {.solution}
**Goal:** Show that a power series $\sum a_n z^n$ is continuous on its domain of convergence (the disk $\abs z < R$, where $R$ is its radius of convergence).

::: pf

::: {.pf-step #fix-point-and-radius}
Fix $z_0$ with $\abs{z_0} < R$, and choose $\rho$ with $\abs{z_0} < \rho < R$.

::: pf-proof
The interval $(\abs{z_0}, R)$ is nonempty, so such $\rho$ exists.
:::

:::

::: {.pf-step #uniform-convergence-on-disk}
The series converges absolutely and uniformly on the closed disk $\abs z \leq \rho$.

::: pf-proof

::: {.pf-step #absolute-convergence-at-rho}
$\sum_{n} \abs{a_n} \rho^n < \infty$.

::: pf-proof
A power series converges absolutely inside its radius of convergence; since $\rho < R$, the series at $\rho$ converges absolutely.
:::

:::

::: {.pf-step #term-bound}
$\abs{a_n z^n} \leq \abs{a_n} \rho^n$ for all $\abs z \leq \rho$.

::: pf-proof
$\abs z^n \leq \rho^n$.
:::

:::

::: {.pf-step #weierstrass-m-test}
Weierstrass $M$-test.

::: pf-proof
Steps [](#absolute-convergence-at-rho){.pf-ref} and [](#term-bound){.pf-ref} give uniform convergence on $\abs z \leq \rho$.
:::

:::

:::

:::

::: {.pf-step #partial-sums-continuous}
The partial sums $S_N(z) := \sum_{n=0}^{N} a_n z^n$ are continuous on $\abs z \leq \rho$.

::: pf-proof
Polynomials are continuous.
:::

:::

::: {.pf-step #uniform-limit-continuous}
The uniform limit of continuous functions is continuous.

::: pf-proof
Standard epsilon/3 argument using uniform convergence (step [](#weierstrass-m-test){.pf-ref}).
:::

:::

::: pf-step
Hence the power series is continuous at $z_0$.

::: pf-proof
$z_0$ lies in the interior of $\abs z \leq \rho$ (step [](#fix-point-and-radius){.pf-ref}), and the series is continuous on that closed disk (steps [](#uniform-convergence-on-disk){.pf-ref}, [](#partial-sums-continuous){.pf-ref} and [](#uniform-limit-continuous){.pf-ref}).
:::

:::

::: pf-qed
$z_0$ was arbitrary with $\abs{z_0} < R$, so the series is continuous on its whole domain of convergence.
:::

:::

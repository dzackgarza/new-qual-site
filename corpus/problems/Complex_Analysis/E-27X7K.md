::: {.exercise}
Let $f$ be entire and define a function
$$
\begin{aligned}
m: [0, \infty) &\to \RR \\
r &\mapsto \min_{\abs{z} = r} \abs{f(z)}.
\end{aligned}
$$
Suppose $\tilde m \coloneqq \lim_{r\to \infty}m(r)$ exists and is a finite positive real number, and show that $f$ is constant.
:::

::: {.hint}
Consider $g(z) \coloneqq f(1/z)$.
:::

::: {.solution}
Let $g(w)=f(1/w)$ for $w\ne0$.

::: pf

::: {.pf-step #lower}

There is $R>0$ such that $g$ is holomorphic on $0<\abs{w}<1/R$ and $\abs{g(w)}\ge\tilde m/2$ there.

::: pf-proof

Since $m(r)\to\tilde m>0$, there is $R>0$ with $m(r)\ge\tilde m/2$ for $r\ge R$, so $\abs{f(z)}\ge\tilde m/2$ for $\abs{z}\ge R$. The function $g$ is holomorphic on $\CC\setminus\{0\}$ as a composition of holomorphic maps.

:::

:::

::: {.pf-step #notess}

The singularity of $g$ at $0$ is not essential.

::: pf-proof

By the Casorati--Weierstrass theorem, an essential singularity would give values of $g$ arbitrarily close to $0$ near $0$, contradicting step [](#lower){.pf-ref}.

:::

:::

::: {.pf-step #notpole}

The singularity of $g$ at $0$ is not a pole.

::: pf-proof

If $g$ had a pole of order $k\ge1$, then $w^kg(w)\to a\ne0$ as $w\to0$, so $\min_{\abs{w}=1/r}\abs{g(w)}\ge\tfrac12\abs{a}r^k$ for large $r$. That minimum is $m(r)$, so $m(r)\to\infty$, contradicting $\tilde m<\infty$.

:::

:::

::: pf-step

$f$ is constant.

::: pf-proof

By steps [](#notess){.pf-ref} and [](#notpole){.pf-ref}, $0$ is a removable singularity of $g$, so $g$ is bounded on $0<\abs{w}\le\rho$ for some $\rho\in(0,1/R)$, that is, $f$ is bounded on $\abs{z}\ge1/\rho$. The continuous function $f$ is bounded on the compact disk $\abs{z}\le1/\rho$, so $f$ is a bounded entire function, constant by Liouville's theorem.

:::

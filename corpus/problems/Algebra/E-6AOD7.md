::: {.exercise}
Let $p$ be a prime.

(a) Show that a nontrivial finite $p$-group has nontrivial center.

(b) Show that a group of order $p^2$ is abelian.
:::

::: {.solution}

::: pf

::: {.pf-step #center}

(a) If $G$ is a nontrivial finite $p$-group, then $Z(G)\neq 1$.

::: pf-proof

Let $\abs{G}=p^n$ with $n\ge1$. The class equation reads
$$
\abs{G}=\abs{Z(G)}+\sum_{i}[G:C_G(g_i)],
$$
where the $g_i$ represent the conjugacy classes with more than one element.
Each index $[G:C_G(g_i)]$ divides $p^n$ and exceeds $1$, so it is divisible by $p$.
Reducing modulo $p$ gives $\abs{Z(G)}\equiv0\pmod p$, so $\abs{Z(G)}\ge p$.

:::

:::

::: pf-step

(b) If $\abs{G}=p^2$, then $G$ is abelian.

::: pf-proof

By step [](#center){.pf-ref}, $\abs{Z(G)}\in\{p,p^2\}$.
If $\abs{Z(G)}=p^2$, then $G=Z(G)$ is abelian.
If $\abs{Z(G)}=p$, then $G/Z(G)$ has order $p$ and is therefore cyclic, say generated by $gZ(G)$.
Every element of $G$ then has the form $g^kz$ with $z\in Z(G)$, and any two such elements commute, so $G$ is abelian.
In either case $G$ is abelian.

:::

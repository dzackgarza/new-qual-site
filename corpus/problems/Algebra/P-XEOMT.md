::: problem
- Show that $[A_n, A_n] = A_n$ for $n\geq 5$, so $A_{n\geq 5}$ is nonabelian.
:::

::: {.solution}
**Goal:** Let $n \ge 5$ be an integer, and let $A_n$ be the alternating group on $n$ elements.
Prove that the commutator subgroup $[A_n, A_n] = A_n$, and deduce that $A_n$ is non-abelian.

<1>1. Key properties of commutators and $A_n$: <2>1. The derived subgroup $[A_n, A_n] = \langle [g, h] \mid g, h \in A_n \rangle$ is a normal subgroup of $A_n$, i.e., $[A_n, A_n] \trianglelefteq A_n$.
::: {.proof}
Standard property of the commutator subgroup of any group.
:::
<2>2. $A_n$ is simple for all $n \ge 5$.
::: {.proof}
Established standard theorem (simplicity of $A_n$ for $n \ge 5$). <2>3. $A_n$ is generated by the set of all $3$-cycles for $n \ge 3$.
:::
::: {.proof}
Every even permutation is a product of an even number of transpositions, and any pair of transpositions can be factored as a product of one or two $3$-cycles.
:::

<1>2. Every $3$-cycle is a commutator of elements in $A_n$ for $n \ge 5$: <2>1. Let $(a\,b\,c)$ be an arbitrary $3$-cycle in $A_n$.
::: {.proof}
Setting an arbitrary $3$-cycle.
:::
<2>2. Since $n \ge 5$, there exist two distinct elements $d, e \in \{1, 2, \dots, n\} \setminus \{a, b, c\}$.
::: {.proof}
The set $\{1, \dots, n\}$ has $n \ge 5$ elements, while $\{a, b, c\}$ has $3$ elements, leaving at least $2$ elements.
:::
<2>3. Define $\sigma = (a\,b\,d) \in A_n$ and $\tau = (a\,c\,e) \in A_n$.
::: {.proof}
Both $\sigma$ and $\tau$ are $3$-cycles, hence even permutations belonging to $A_n$.
:::
<2>4. The commutator $[\sigma, \tau] = \sigma \tau \sigma^{-1} \tau^{-1}$ equals the $3$-cycle $(a\,b\,c)$.
<3>1. Action on $a$: $[\sigma, \tau](a) = \sigma(\tau(\sigma^{-1}(\tau^{-1}(a)))) = \sigma(\tau(\sigma^{-1}(e))) = \sigma(\tau(e)) = \sigma(a) = b$.
::: {.proof}
$\tau^{-1} = (a\,e\,c)$ maps $a \mapsto e$; $\sigma^{-1} = (a\,d\,b)$ fixes $e$; $\tau$ maps $e \mapsto a$; $\sigma$ maps $a \mapsto b$.
:::
<3>2. Action on $b$: $[\sigma, \tau](b) = \sigma(\tau(\sigma^{-1}(\tau^{-1}(b)))) = \sigma(\tau(\sigma^{-1}(b))) = \sigma(\tau(a)) = \sigma(c) = c$.
::: {.proof}
$\tau^{-1}$ fixes $b$; $\sigma^{-1}$ maps $b \mapsto a$; $\tau$ maps $a \mapsto c$; $\sigma$ fixes $c$.
:::
<3>3. Action on $c$: $[\sigma, \tau](c) = \sigma(\tau(\sigma^{-1}(\tau^{-1}(c)))) = \sigma(\tau(\sigma^{-1}(a))) = \sigma(\tau(d)) = \sigma(d) = a$.
::: {.proof}
$\tau^{-1}$ maps $c \mapsto a$; $\sigma^{-1}$ maps $a \mapsto d$; $\tau$ fixes $d$; $\sigma$ maps $d \mapsto a$.
:::
<3>4. Action on $d$: $[\sigma, \tau](d) = \sigma(\tau(\sigma^{-1}(\tau^{-1}(d)))) = \sigma(\tau(\sigma^{-1}(d))) = \sigma(\tau(b)) = \sigma(b) = d$.
::: {.proof}
$\tau^{-1}$ fixes $d$; $\sigma^{-1}$ maps $d \mapsto b$; $\tau$ fixes $b$; $\sigma$ maps $b \mapsto d$.
:::
<3>5. Action on $e$: $[\sigma, \tau](e) = \sigma(\tau(\sigma^{-1}(\tau^{-1}(e)))) = \sigma(\tau(\sigma^{-1}(c))) = \sigma(\tau(c)) = \sigma(e) = e$.
::: {.proof}
$\tau^{-1}$ maps $e \mapsto c$; $\sigma^{-1}$ fixes $c$; $\tau$ maps $c \mapsto e$; $\sigma$ fixes $e$.
:::
<3>6. Action on any other element $x \notin \{a, b, c, d, e\}$: both $\sigma, \tau$ fix $x$, so $[\sigma, \tau](x) = x$.
::: {.proof}
Disjoint support.
:::
<3>7. Q.E.D.
::: {.proof}
$[\sigma, \tau]$ maps $a \mapsto b \mapsto c \mapsto a$ and fixes all other elements, which is precisely $(a\,b\,c)$.
:::
<2>5. Therefore, every $3$-cycle in $A_n$ belongs to $[A_n, A_n]$.
::: {.proof}
Since $\sigma, \tau \in A_n$ and $(a\,b\,c) = [\sigma, \tau] \in [A_n, A_n]$.
:::

<1>3. Equality $[A_n, A_n] = A_n$: <2>1. By <1>1.<2>3, the $3$-cycles generate $A_n$.
::: {.proof}
Standard property of $A_n$.
:::
<2>2. Since every $3$-cycle belongs to $[A_n, A_n]$ (<1>2.<2>5), we have $A_n \subseteq [A_n, A_n]$.
::: {.proof}
A group generated by a subset contained in a subgroup is contained in that subgroup.
:::
<2>3. By definition, $[A_n, A_n] \subseteq A_n$.
::: {.proof}
Commutators of elements in $A_n$ belong to $A_n$.
:::
<2>4. Therefore, $[A_n, A_n] = A_n$.
::: {.proof}
By mutual inclusion.
:::

<1>4. $A_n$ is non-abelian for $n \ge 5$: <2>1. If a group $G$ is abelian, then $[G, G] = \{e\}$.
::: {.proof}
In an abelian group, $g h g^{-1} h^{-1} = g g^{-1} h h^{-1} = e$ for all $g, h \in G$.
:::
<2>2. For $n \ge 5$, $|A_n| = \frac{n!}{2} \ge \frac{5!}{2} = 60 > 1$, so $A_n \neq \{e\}$.
::: {.proof}
Direct evaluation of the order of $A_n$.
:::
<2>3. Since $[A_n, A_n] = A_n \neq \{e\}$, $A_n$ is not abelian.
::: {.proof}
<2>4. By the contrapositive of <2>1, a group whose commutator subgroup is nontrivial is not abelian; since $[A_n, A_n] = A_n \neq \{e\}$, $A_n$ is not abelian.
:::
:::

::: {.problem}
Show that if $E/k$ and $F/k$ are finite Galois extensions inside a common field with $E \cap F = k$, then the compositum $EF/k$ is Galois and:
$$\Gal(EF/k) \cong \Gal(E/k) \times \Gal(F/k).$$
:::

::: {.solution}

::: pf

::: pf-step

$EF/k$ is finite Galois.

::: pf-proof

Choose separable polynomials over $k$ whose splitting fields are $E$ and $F$. Their product is separable and has splitting field $EF$.

:::

:::

::: {.pf-step #inj}

Restriction $\Phi:\Gal(EF/k)\to\Gal(E/k)\times\Gal(F/k)$, $\sigma\mapsto(\sigma\restrict_E,\sigma\restrict_F)$, is an injective homomorphism.

::: pf-proof

Since $E/k$ and $F/k$ are normal, $\sigma(E)=E$ and $\sigma(F)=F$, so the restrictions are defined, and $\Phi$ is a homomorphism. If $\sigma\restrict_E$ and $\sigma\restrict_F$ are trivial, then $\sigma$ fixes $EF$, because $E$ and $F$ generate $EF$.

:::

:::

::: {.pf-step #order}

$[EF:k]=[E:k][F:k]$.

::: pf-proof

Because $F/k$ is Galois, restriction gives $\Gal(EF/E)\cong\Gal(F/E\cap F)=\Gal(F/k)$, so $[EF:E]=[F:k]$. Multiply by $[E:k]$.

:::

:::

::: pf-qed

By step [](#order){.pf-ref}, $\Phi$ is a map between finite groups of the same order, and it is injective by step [](#inj){.pf-ref}, so
$$\boxed{\Gal(EF/k)\cong\Gal(E/k)\times\Gal(F/k)}.$$

:::

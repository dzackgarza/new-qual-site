::: {.problem}
For which positive integers $n$ is a regular $n$-gon constructible by ruler and compass?
:::

::: {.solution}
Let $\zeta_n\coloneqq e^{2\pi i/n}$ and let $\varphi$ be Euler's function. A regular $n$-gon is constructible exactly when $\zeta_n$ is a constructible complex number.

::: pf

::: {.pf-step #degree}
$\zeta_n$ is constructible if and only if $\varphi(n)$ is a power of $2$.

::: pf-proof
A complex number is constructible if and only if it lies in a tower $\QQ=K_0\subset K_1\subset\cdots\subset K_s$ with $[K_{j+1}:K_j]=2$. If $\zeta_n$ lies in such a tower, then $[\QQ(\zeta_n):\QQ]=\varphi(n)$ divides $2^s$. Conversely, if $\varphi(n)=2^s$, then $\Gal(\QQ(\zeta_n)/\QQ)\cong(\ZZ/n\ZZ)^\times$ is an abelian $2$-group, so it has a chain of subgroups $1=H_s<\cdots<H_0$ with each index $2$, and the fixed fields form a tower of quadratic extensions ending at $\QQ(\zeta_n)$.
:::

:::

::: {.pf-step #phi}
$\varphi(n)$ is a power of $2$ if and only if $n=2^kp_1\cdots p_r$ with $k\ge0$ and distinct Fermat primes $p_i=2^{2^{m_i}}+1$.

::: pf-proof
Write $n=2^k\prod p^{a_p}$ over odd primes $p$; then $\varphi(n)=\varphi(2^k)\prod p^{a_p-1}(p-1)$, and $\varphi(2^k)$ is a power of $2$. The product is a power of $2$ exactly when every $a_p=1$ and every $p-1$ is a power of $2$. If $p=2^m+1$ is prime and $m$ has an odd factor $d>1$, say $m=de$, then $2^e+1$ divides $2^m+1$ properly; so $m$ is a power of $2$.
:::

:::

::: pf-qed
By steps [](#degree){.pf-ref} and [](#phi){.pf-ref}, the regular $n$-gon is constructible if and only if $\boxed{n=2^kp_1\cdots p_r}$ with $k\ge0$ and $p_1,\ldots,p_r$ distinct Fermat primes (the Gauss--Wantzel theorem).
:::

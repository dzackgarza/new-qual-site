::: {.exercise}
Let $R$ be a commutative ring with identity. Show that $R[x]$ is a PID $\iff R$ is a field.
:::

::: {.hint}
Take $r\in R$, then $\generators{r, x} = \generators{f}$ for some $f$.
:::

::: {.solution}

::: pf

::: {.pf-step #field-implies-pid}
If $R$ is a field, then $R[x]$ is a PID.

::: pf-proof
Division with remainder in $R[x]$ shows that a nonzero ideal is generated by any of its nonzero elements of least degree.
:::

:::

::: pf-qed
If $R[x]$ is a PID, then $R$ is a field.
$R[x]$ is a domain, hence so is $R\subseteq R[x]$; in particular $1\neq0$ in $R$.
Let $0\neq r\in R$ and write $\generators{r,x}=\generators{f}$, so $r=fp$ and $x=fq$ for some $p,q\in R[x]$.
In the domain $R[x]$, degrees add, so $\deg f=0$ from $r=fp$; write $f=c\in R$.
Then $x=cq$ forces $q=ax+b$ with $ca=1$, so $c$ is a unit and $\generators{r,x}=R[x]$.
Hence $1=rg(x)+xh(x)$ for some $g,h\in R[x]$, and evaluating at $x=0$ gives $1=rg(0)$, so $r$ is a unit.
:::

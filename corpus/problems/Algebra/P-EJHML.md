::: {.problem}
Let $p$ be a prime and $n$ a positive integer.
Show that a field with $p^n$ elements has exactly one subfield of size $p^d$ for every $d$ dividing $n$.
:::

::: {.solution}
Write $F=\FF_{p^n}$ and let $\varphi\colon F\to F$, $\varphi(x)=x^p$, be the Frobenius map; for $d\geq1$ put $F_d=\theset{x\in F:x^{p^d}=x}$.

::: pf

::: {.pf-step #frobenius}
$\varphi$ is an automorphism of $F$ fixing $\FF_p$, it has order $n$, and $\Gal(F/\FF_p)=\generators{\varphi}$ is cyclic of order $n$.

::: pf-proof
The map $\varphi$ is a ring homomorphism because $(x+y)^p=x^p+y^p$ and $(xy)^p=x^py^p$ in characteristic $p$, it fixes $\FF_p$ because $a^p=a$ for $a\in\FF_p$, and it is injective because $x^p=0$ forces $x=0$, hence bijective because $F$ is finite. Its order is the least $r$ with $x^{p^r}=x$ for all $x\in F$, namely $n$: the multiplicative group $F^\times$ is cyclic of order $p^n-1$, so $x^{p^r}=x$ for all $x$ means $p^r\equiv1$ modulo $p^n-1$, and the least such $r$ is $n$. The extension $F/\FF_p$ is separable, being a finite extension of a finite field, and normal, being the splitting field of $x^{p^n}-x$, so it is Galois, and $|\Gal(F/\FF_p)|=[F:\FF_p]=n$; the $n$ distinct powers of $\varphi$ are therefore all of it.
:::

:::

::: {.pf-step #exists}
For every $d\geq1$ the set $F_d$ is a subfield of $F$; and if $d\mid n$ then $|F_d|=p^d$.

::: pf-proof
$F_d$ is the fixed field of the subgroup generated by $\varphi^d$, hence a subfield of $F$: it is a field because $\varphi^d$ is an automorphism and fixed points of automorphisms form a subfield.

Assume $d\mid n$. In the cyclic group of order $n$ generated by $\varphi$, the element $\varphi^d$ has order $n/d$, so the subgroup $\generators{\varphi^d}$ has order $n/d$. By the fundamental theorem of Galois theory applied to the Galois extension $F/\FF_p$ of step [](#frobenius){.pf-ref}, $[F:F_d]=n/d$, and the tower law $[F:\FF_p]=[F:F_d][F_d:\FF_p]$ gives $[F_d:\FF_p]=d$. Hence $|F_d|=p^d$.
:::

:::

::: {.pf-step #unique}
If $K\subseteq F$ is a subfield with $\abs{K}=p^d$, then $K=F_d$.

::: pf-proof
Every $x\in K$ satisfies $x^{p^d}=x$: for $x\neq0$ this is $x^{p^d-1}=1$, which holds because $K^\times$ is a group of order $p^d-1$ and $x$ has order dividing it, and for $x=0$ it is immediate. So $K\subseteq F_d$. Both are subfields of $F$ with $p^d$ elements, so the inclusion is an equality.
:::

:::

::: {.pf-step #converse}
If $K\subseteq F$ is a subfield with $\abs{K}=p^d$, then $d\mid n$.

::: pf-proof
$F$ is a finite-dimensional $K$-vector space, so $\abs{F}=\abs{K}^{[F:K]}$, that is $p^n=p^{d[F:K]}$, which forces $n=d\,[F:K]$ in $\ZZ$ and hence $d\mid n$.
:::

:::

::: {.pf-step}
$F$ has exactly one subfield of order $p^d$ for each $d\mid n$, namely $F_d$; and no subfield of order $p^d$ exists when $d\nmid n$.

::: pf-proof
For $d\mid n$, step [](#exists){.pf-ref} produces the subfield $F_d$ of order $p^d$, and step [](#unique){.pf-ref} says every subfield of that order equals it, so there is exactly one. If $d\nmid n$ then step [](#converse){.pf-ref} rules out any subfield of order $p^d$.
:::

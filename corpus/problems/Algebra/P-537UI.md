::: problem
- Is $\QQ(2^{1\over 3})/\QQ$ normal?
:::

::: {.solution}
<1>1. $\alpha = 2^{1/3}$ has minimal polynomial $x^3 - 2$ over $\mathbb{Q}$.
::: {.proof}
$x^3 - 2$ is irreducible (Eisenstein at $2$).
:::

<1>2. The roots of $x^3 - 2$ are $\alpha, \alpha\omega, \alpha\omega^2$, where $\omega = e^{2\pi i/3}$ is a primitive cube root of unity.
::: {.proof}
the three cube roots of $2$.
:::

<1>3. $\mathbb{Q}(\alpha) \subseteq \mathbb{R}$, so it does not contain the non-real roots $\alpha\omega, \alpha\omega^2$.
::: {.proof}
$\alpha$ is real, so $\mathbb{Q}(\alpha) \subseteq \mathbb{R}$.
:::

<1>4. Hence $\mathbb{Q}(\alpha)$ does not contain all the roots of $x^3 - 2$.
::: {.proof}
<1>2 and <1>3.
:::

<1>5. Therefore $\mathbb{Q}(2^{1/3})/\mathbb{Q}$ is not normal.
::: {.proof}
<1>4 (a normal extension contains all roots of the minimal polynomial of any of its elements).
:::

<1>6. Q.E.D.
::: {.proof}
<1>5.
:::
:::

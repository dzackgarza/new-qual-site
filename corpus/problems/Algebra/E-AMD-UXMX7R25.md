::: {.exercise}
Show that $(\QQ,+)$ is not finitely generated as an abelian group.
:::

::: {.solution}
Write $(\QQ,+)$ for the additive group of the rationals and, for $m\geq1$, $\frac1m\ZZ=\theset{k/m:k\in\ZZ}$ for its subgroup of multiples of $1/m$. A group is finitely generated when it equals the set of integer combinations of finitely many of its elements.

::: pf

::: {.pf-step #setup}
Suppose $(\QQ,+)=\generators{a_1/b_1,\ldots,a_r/b_r}$ with $a_i\in\ZZ$ and $b_i$ a positive integer. Then $r\geq1$, and with $M=\operatorname{lcm}(b_1,\ldots,b_r)$ each generator lies in $\frac1M\ZZ$.

::: pf-proof
If $r=0$ the group generated is the trivial group, so $\QQ=0$, which is false since $1\in\QQ$; hence $r\geq1$ and $M\geq1$ exists. For each $i$, the integer $M/b_i$ is an integer because $b_i\mid M$, so $a_i/b_i=\bigl(a_i(M/b_i)\bigr)/M$ is an element of $\frac1M\ZZ$.
:::

:::

::: {.pf-step #subgroup}
$\frac1M\ZZ$ is a subgroup of $(\QQ,+)$, so every integer combination of the generators lies in it.

::: pf-proof
$\frac1M\ZZ$ contains $0$ and is closed under addition and negation, since $k/M+l/M=(k+l)/M$ and $-(k/M)=(-k)/M$; so it is a subgroup, and in particular closed under integer combinations. Each generator lies in it by step [](#setup){.pf-ref}, so any integer combination of the generators does too.
:::

:::

::: {.pf-step #contained}
$\QQ\subseteq\frac1M\ZZ$.

::: pf-proof
By hypothesis every element of $\QQ$ is an integer combination of the generators, and by step [](#subgroup){.pf-ref} each such combination lies in $\frac1M\ZZ$.
:::

:::

::: {.pf-step #not-contained}
$\frac1{2M}\in\QQ$ but $\frac1{2M}\notin\frac1M\ZZ$.

::: pf-proof
Clearly $\frac1{2M}$ is rational. If it were $\frac{k}{M}$ for some integer $k$, then multiplying by $2M$ gives $1=2k$, which has no integer solution; so it is not in $\frac1M\ZZ$.
:::

:::

::: {.pf-step}
$(\QQ,+)$ is not finitely generated as an abelian group.

::: pf-proof
Assume it were generated by finitely many elements. Steps [](#setup){.pf-ref}, [](#subgroup){.pf-ref} and [](#contained){.pf-ref} then produce $M\geq1$ with $\QQ\subseteq\frac1M\ZZ$, while step [](#not-contained){.pf-ref} exhibits an element of $\QQ$ outside $\frac1M\ZZ$. That contradiction shows no finite generating set exists.
:::

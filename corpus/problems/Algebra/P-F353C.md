::: problem
Consider a commutative ring, $R$, and a maximal ideal $I$, what can you say about the structure of $R/I$?
What if $I$ were prime?
:::

::: {.solution}
<1>1. If $I$ is a maximal ideal, then $R/I$ is a field.
::: {.proof}
by the correspondence theorem, $R/I$ has no nonzero proper ideals (maximality of $I$), and a commutative ring with no nonzero proper ideals is a field.
:::

<1>2. If $I$ is a prime ideal, then $R/I$ is an integral domain.
::: {.proof}
$I$ prime means $ab \in I \Rightarrow a \in I$ or $b \in I$, which is exactly the condition that $R/I$ has no zero divisors.
:::

<1>3. Every maximal ideal is prime.
::: {.proof}
a field is an integral domain, so <1>1 implies <1>2.
:::

<1>4. Q.E.D.
::: {.proof}
<1>1, <1>2, <1>3.
:::
:::

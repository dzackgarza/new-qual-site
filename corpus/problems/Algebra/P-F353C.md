::: {.problem}
Consider a commutative ring, $R$, and a maximal ideal $I$, what can you say about the structure of $R/I$?
What if $I$ were prime?
:::

::: {.solution}
Let $R$ be commutative with $1$.

::: pf

::: {.pf-step #field}
If $I$ is maximal, then $R/I$ is a field.

::: pf-proof
The ideals of $R/I$ correspond to the ideals of $R$ that contain $I$, so by maximality the only ideals of $R/I$ are $(0)$ and $R/I$, and $R/I\ne0$ since $I\ne R$.
Every nonzero class therefore generates the whole ring, so it is invertible.
:::

:::

::: {.pf-step #domain}
If $I$ is prime, then $R/I$ is an integral domain.

::: pf-proof
$R/I\ne0$ since $I\ne R$.
If $(a+I)(b+I)=0$, then $ab\in I$, so primality gives $a\in I$ or $b\in I$, that is, $a+I=0$ or $b+I=0$.
Hence $R/I$ has no zero divisors.
:::

:::

::: pf-step
Every maximal ideal is prime.

::: pf-proof
If $I$ is maximal, then $R/I$ is a field by step [](#field){.pf-ref}, hence an integral domain.
If $ab\in I$, then $(a+I)(b+I)=0$ in this domain, so $a\in I$ or $b\in I$, and $I\ne R$; thus $I$ is prime.
:::

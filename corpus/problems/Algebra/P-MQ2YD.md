::: {.problem}
(1) What can you say about $n \times n$ matrices $A$ that satisfy a given polynomial $P(x) = 0$ over an algebraically closed field $k = \bar{k}$? How many similarity classes and how many such matrices are there?

(2) What about over a finite field $\FF_q$? How many similarity classes and how many individual matrices satisfy $P(A) = 0$?
:::

::: {.solution}
Let $P$ be a nonzero polynomial over the field in question, and write $\mu_A$ for the minimal polynomial of a square matrix $A$.

::: pf

::: {.pf-step #divides}
Over any field, $P(A)=0$ if and only if $\mu_A\mid P$.

::: pf-proof
The polynomials that annihilate $A$ form the ideal generated by $\mu_A$.
:::

:::

::: pf-step
(1) Over $k=\bar k$, write $P(x)=c\prod_{i=1}^r(x-\lambda_i)^{e_i}$ with distinct $\lambda_i$.
The similarity classes of $n\times n$ matrices with $P(A)=0$ correspond to tuples of partitions $\nu_i\vdash n_i$ with $\sum_i n_i=n$ and every part of $\nu_i$ at most $e_i$; there are finitely many.
The set of such matrices is finite if every admissible class is scalar, and otherwise has cardinality $\abs{k}$.

::: pf-proof
By step [](#divides){.pf-ref}, $P(A)=0$ exactly when the only eigenvalues of $A$ are among the $\lambda_i$ and every Jordan block for $\lambda_i$ has size at most $e_i$.
A Jordan form is determined by the partition $\nu_i$ of block sizes for each $\lambda_i$, which gives the stated parametrization; there are finitely many such tuples.
The admissible matrices are the finite union of the conjugacy orbits $\{SAS^{-1}:S\in\GL_n(k)\}$ of the admissible Jordan forms.
A scalar class is a single matrix, so if every admissible class is scalar the set is finite; for example $P=x-a$ gives only $aI$.
A matrix that commutes with every matrix unit $E_{ij}$, $i\ne j$, is scalar, so a non-scalar $A$ fails to commute with some such $E$.
Then $(I+tE)A(I+tE)^{-1}=A+t[E,A]-t^2EAE$ is a polynomial in $t$ with nonzero linear coefficient, so each value is taken for at most two $t\in k$, and the orbit of $A$ has cardinality $\abs{k}$, which is infinite.
:::

:::

::: pf-step
(2) Over $\FF_q$, factor $P=c\prod_j f_j^{e_j}$ into distinct monic irreducibles.
The similarity classes with $P(A)=0$ correspond to choices of a partition $\nu_j$ for each $j$, with every part at most $e_j$ and $\sum_j(\deg f_j)\abs{\nu_j}=n$; there are finitely many.
The number of matrices is $\boxed{\sum_{[A]}\abs{\GL_n(\FF_q)}/\abs{C_{\GL_n(\FF_q)}(A)}}$, summed over these classes.

::: pf-proof
By step [](#divides){.pf-ref} and the primary decomposition, $A$ is determined up to similarity by its elementary divisors $f_j^{m}$, which must have $m\le e_j$; the exponents for $f_j$ form the partition $\nu_j$, and the dimensions add up to $n$.
The class of $A$ is the orbit of $A$ under conjugation by $\GL_n(\FF_q)$, whose size is the index of the centralizer by the orbit-stabilizer theorem.
:::

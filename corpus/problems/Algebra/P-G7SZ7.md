::: problem
Let $\pi: \mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ be the canonical quotient homomorphism of $\mathbb{Z}$-modules.
Show that the induced homomorphism on Hom groups:
\[
\pi_*: \operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}) \to \operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}/2\mathbb{Z}), \quad f \mapsto \pi \circ f
\]
is not surjective, and conclude that the functor $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, -)$ is not right exact.
:::

::: {.solution}
<1>1. Compute $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z})$: <2>1. Let $f \in \operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z})$ be any $\mathbb{Z}$-module homomorphism.
::: {.proof}
setup.
:::
<2>2. In $\mathbb{Z}/2\mathbb{Z}$, the generator $[1]$ satisfies $2 \cdot [1] = [0]$.
::: {.proof}
$2 \equiv 0 \pmod 2$.
:::
<2>3. Applying $f$:
\[
2 f([1]) = f(2 \cdot [1]) = f([0]) = 0.
\]
::: {.proof}
module homomorphisms preserve $\mathbb{Z}$-linear combinations.
:::
<2>4. In the ring of integers $\mathbb{Z}$, the only element $y \in \mathbb{Z}$ with $2y = 0$ is $y = 0$.
::: {.proof}
$\mathbb{Z}$ is an integral domain of characteristic 0. <2>5. Thus $f([1]) = 0$, so $f([x]) = x f([1]) = 0$ for all $[x] \in \mathbb{Z}/2\mathbb{Z}$, meaning $f = 0$.
:::
::: {.proof}
$\mathbb{Z}/2\mathbb{Z}$ is cyclic generated by $[1]$.
:::
<2>6. Therefore $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}) \cong 0$ is the trivial group.
::: {.proof}
<2>5.
:::

<1>2. Compute $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}/2\mathbb{Z})$: <2>1. The identity map $\operatorname{id}_{\mathbb{Z}/2\mathbb{Z}}: \mathbb{Z}/2\mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ given by $\operatorname{id}([x]) = [x]$ is a $\mathbb{Z}$-module homomorphism.
::: {.proof}
the identity map on any module is a homomorphism.
:::
<2>2. Since $\operatorname{id}([1]) = [1] \neq [0]$, $\operatorname{id}_{\mathbb{Z}/2\mathbb{Z}} \neq 0$.
::: {.proof}
$[1] \neq [0]$ in $\mathbb{Z}/2\mathbb{Z}$.
:::
<2>3. Thus $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}/2\mathbb{Z}) \cong \mathbb{Z}/2\mathbb{Z}$ contains at least two distinct elements $\{0, \operatorname{id}_{\mathbb{Z}/2\mathbb{Z}}\}$.
::: {.proof}
non-trivial homomorphism group.
:::

<1>3. Show that $\pi_*$ is not surjective: <2>1. The domain of $\pi_*$ is the trivial group $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}) = \{0\}$.
::: {.proof}
<1>1. <2>2. The image $\operatorname{im}(\pi_*) = \{\pi_*(0)\} = \{0\}$.
:::
::: {.proof}
homomorphisms map 0 to 0. <2>3. Since $\operatorname{id}_{\mathbb{Z}/2\mathbb{Z}} \in \operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, \mathbb{Z}/2\mathbb{Z})$ is non-zero, $\operatorname{id}_{\mathbb{Z}/2\mathbb{Z}} \notin \operatorname{im}(\pi_*)$.
:::
::: {.proof}
<1>2 and <2>2. <2>4. Thus $\pi_*$ is not surjective.
:::
::: {.proof}
<2>3.
:::

<1>4. Conclusion: Since the surjective homomorphism $\pi: \mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ does not induce a surjective map $\pi_*$, the functor $\operatorname{Hom}_\mathbb{Z}(\mathbb{Z}/2\mathbb{Z}, -)$ is not right exact.
::: {.proof}
<1>3.
:::
Q.E.D.
:::

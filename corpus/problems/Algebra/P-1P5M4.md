::: {.problem}
Let $R$ be a commutative ring with identity, let $I\trianglelefteq R$ be an ideal, and let $A$ be an $R$-module. Prove that $A/IA$ is naturally an $R/I$-module via
\[
(r+I)(a+IA)=ra+IA.
\]
:::

::: {.solution}

::: pf

::: {.pf-step #s1}

The displayed scalar action is well-defined.

::: pf-proof

Suppose
\[
r+I=r'+I,
\qquad
a+IA=a'+IA.
\]
Then $r-r'\in I$ and $a-a'\in IA$. We compute
\[
ra-r'a'
=r(a-a')+(r-r')a'.
\]
Because $IA$ is an $R$-submodule of $A$, the first term lies in $IA$. Since $r-r'\in I$, the second term lies in $IA$ by definition. Hence
\[
ra+IA=r'a'+IA,
\]
so the action depends only on the cosets.

:::

:::

::: {.pf-step #s2}

Scalar addition distributes over the module addition.

::: pf-proof

For $r,s\in R$ and $a\in A$,
\[
((r+I)+(s+I))(a+IA)
=(r+s)a+IA
=ra+sa+IA,
\]
which equals
\[
(r+I)(a+IA)+(s+I)(a+IA).
\]

:::

:::

::: {.pf-step #s3}

Scalars distribute over addition in $A/IA$.

::: pf-proof

For $r\in R$ and $a,b\in A$,
\[
(r+I)((a+IA)+(b+IA))
=r(a+b)+IA
=ra+rb+IA,
\]
which is
\[
(r+I)(a+IA)+(r+I)(b+IA).
\]

:::

:::

::: {.pf-step #s4}

Scalar multiplication is associative.

::: pf-proof

For $r,s\in R$ and $a\in A$,
\[
((r+I)(s+I))(a+IA)
=(rs)a+IA
=r(sa)+IA
=(r+I)((s+I)(a+IA)).
\]

:::

:::

::: {.pf-step #s5}

The identity coset acts as the identity.

::: pf-proof

For $a\in A$,
\[
(1+I)(a+IA)=1a+IA=a+IA.
\]

:::

:::

::: pf-step

Therefore $A/IA$ is an $R/I$-module.

::: pf-proof

The quotient $A/IA$ is already an abelian group. By step [](#s1){.pf-ref} the scalar action is well-defined, and steps [](#s2){.pf-ref}, [](#s3){.pf-ref}, [](#s4){.pf-ref} and [](#s5){.pf-ref} verify the module axioms.

:::

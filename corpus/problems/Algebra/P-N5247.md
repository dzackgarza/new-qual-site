::: {.problem}
Show that $\Aut(S_3) = \Inn(S_3) \cong S_3$.
:::

::: {.solution}
::: pf

::: {.pf-step #inn}
$\Inn(S_3)\cong S_3$, so $\abs{\Inn(S_3)}=6$.

::: pf-proof
$\Inn(S_3)\cong S_3/Z(S_3)$, and $Z(S_3)=1$ because $(12)$ commutes only with $e$ and $(12)$, and $(123)$ commutes only with its powers.
:::

:::

::: {.pf-step #aut}
$\abs{\Aut(S_3)}\le6$.

::: pf-proof
An automorphism preserves element orders, so it permutes the three transpositions.
The transpositions $(12)$ and $(13)$ generate $S_3$, so an automorphism is determined by their images, an ordered pair of distinct transpositions; there are $3\cdot2=6$ such pairs.
:::

:::

::: pf-step
$\Aut(S_3)=\Inn(S_3)\cong S_3$.

::: pf-proof
$\Inn(S_3)\subseteq\Aut(S_3)$, and by steps [](#inn){.pf-ref} and [](#aut){.pf-ref} both have order $6$.
:::

::: {.exercise}
Let $R$ be a Noetherian ring and $A,B$ algebras over $R$.
Suppose $A$ is finite type over $R$ and finite over B. Then $B$ is finite type over $R$.
:::

::: {.solution}
<1>1. Setup generators for $A$ over $R$ and $B$:
<2>1. Since $A$ is of finite type as an $R$-algebra, there exist $x_1, \dots, x_n \in A$ such that $A = R[x_1, \dots, x_n]$.
::: {.proof}
definition of finite type algebra.
:::
<2>2. Since $A$ is finite as a $B$-module, there exist $y_1, \dots, y_m \in A$ such that $A = \sum_{j=1}^m B y_j$. Without loss of generality, assume $y_1 = 1$.
::: {.proof}
definition of finite module.
:::
<2>3. Express each algebra generator $x_i$ as a $B$-linear combination of the module generators $y_j$:
\[
x_i = \sum_{j=1}^m b_{ij} y_j \quad (b_{ij} \in B).
\]
::: {.proof}
$x_i \in A = \sum B y_j$.
:::
<2>4. Express each product $y_j y_k$ as a $B$-linear combination of the module generators $y_l$:
\[
y_j y_k = \sum_{l=1}^m c_{jkl} y_l \quad (c_{jkl} \in B).
\]
::: {.proof}
$y_j y_k \in A = \sum B y_l$.
:::

<1>2. Construct the Noetherian sub-algebra $B_0$:
<2>1. Define the $R$-subalgebra $B_0 \subseteq B$ generated by all the coefficients:
\[
B_0 = R\big(\{b_{ij} : 1 \le i \le n, \, 1 \le j \le m\} \cup \{c_{jkl} : 1 \le j, k, l \le m\}\big).
\]
::: {.proof}
definition of finitely generated $R$-subalgebra.
:::
<2>2. Since $R$ is a Noetherian ring and $B_0$ is generated over $R$ by finitely many elements, $B_0$ is a **Noetherian ring**.
::: {.proof}
Hilbert’s Basis Theorem.
:::

<1>3. Show that $A$ is a finitely generated $B_0$-module:
<2>1. Consider the $B_0$-submodule $M = \sum_{j=1}^m B_0 y_j \subseteq A$.
::: {.proof}
definition of $M$.
:::
<2>2. Since $1 = y_1 \in M$, $B_0 \subseteq M$.
Furthermore, for all $j, k$, $y_j y_k = \sum_{l=1}^m c_{jkl} y_l \in M$ because $c_{jkl} \in B_0$.
Thus $M$ is closed under multiplication, so $M$ is a subring of $A$.
::: {.proof}
closure of basis products under $B_0$-linear combinations.
:::
<2>3. For each $i = 1, \dots, n$, $x_i = \sum_{j=1}^m b_{ij} y_j \in M$ because $b_{ij} \in B_0$.
Since $M$ is an $R$-algebra containing $x_1, \dots, x_n$, it contains $R[x_1, \dots, x_n] = A$.
Thus $A = M = \sum_{j=1}^m B_0 y_j$.
::: {.proof}
$A = R[x_1, \dots, x_n] \subseteq M \subseteq A$.
:::
<2>4. Therefore $A$ is a finitely generated $B_0$-module.
::: {.proof}
<2>3.
:::

<1>4. Deduce that $B$ is of finite type over $R$:
<2>1. Since $B_0$ is Noetherian and $A$ is a finitely generated $B_0$-module, $A$ is a Noetherian $B_0$-module.
::: {.proof}
finitely generated modules over Noetherian rings are Noetherian.
:::
<2>2. Since $B$ is a $B_0$-submodule of $A$ ($B_0 \subseteq B \subseteq A$), $B$ is a finitely generated $B_0$-module:
\[
B = \sum_{r=1}^p B_0 z_r \quad (z_r \in B).
\]
::: {.proof}
submodules of Noetherian modules are finitely generated.
:::
<2>3. Thus $B = B_0[z_1, \dots, z_p] = R\big(\{b_{ij}\}, \{c_{jkl}\}, z_1, \dots, z_p\big)$ is generated as an $R$-algebra by finitely many elements.
::: {.proof}
algebra generation.
:::

<1>5. Conclusion:
$B$ is a finitely generated $R$-algebra (finite type over $R$, Artin–Tate Lemma). Q.E.D.
::: {.proof}
<1>1 through <1>4.
:::
:::

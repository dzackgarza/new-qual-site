::: {.problem}
- Let $R$ be a Noetherian ring and $A,B$ algebras over $R$.
  Suppose $A$ is finite type over $R$ and finite over B. Then $B$ is finite type over $R$.
:::

::: {.solution}
Assume $B\subseteq A$ as $R$-subalgebras. Choose elements
\[
x_1,\dots,x_n\in A
\]
generating $A$ as an $R$-algebra, and elements
\[
y_1,\dots,y_m\in A
\]
generating $A$ as a $B$-module. Enlarge the module generating set if necessary so that $1=y_1$.

::: pf

::: {.pf-step #s1}

There are coefficients $a_{ij},b_{ijk}\in B$ such that
\[
x_i=\sum_j a_{ij}y_j,
\qquad
y_i y_j=\sum_k b_{ijk}y_k.
\]

::: pf-proof

Both assertions follow because the $y_j$ generate $A$ as a $B$-module.

:::

:::

::: {.pf-step #s2}

Let $B_0\subseteq B$ be the $R$-subalgebra generated by all $a_{ij}$ and $b_{ijk}$. Then $B_0$ is Noetherian.

::: pf-proof

It is finitely generated as an $R$-algebra, and $R$ is Noetherian. Hilbert's basis theorem implies that $B_0$ is Noetherian.

:::

:::

::: pf-step

The $B_0$-submodule
\[
M=B_0y_1+\cdots+B_0y_m
\]
is a subring of $A$ containing $R$ and all $x_i$.

::: pf-proof

It contains $1=y_1$. The multiplication formulas in step [](#s1){.pf-ref} show that products of the generators $y_i$ remain in $M$, hence $M$ is closed under multiplication. The first formulas in step [](#s1){.pf-ref} show that every $x_i\in M$.

:::

:::

::: pf-step

Therefore $A=M$, so $A$ is finite as a $B_0$-module.

::: pf-proof

Since $A=R[x_1,\dots,x_n]$ and $M$ is a subring containing $R$ and every $x_i$, one has $A\subseteq M$. The reverse inclusion is tautological.

:::

:::

::: {.pf-step #s5}

The subalgebra $B$ is finite as a $B_0$-module.

::: pf-proof

Since $B_0\subseteq B\subseteq A$, the ring $B$ is a $B_0$-submodule of the finite $B_0$-module $A$. By step [](#s2){.pf-ref}, $B_0$ is Noetherian, so every submodule of a finite module is finite.

:::

:::

::: pf-step

Hence $B$ is of finite type over $R$.

::: pf-proof

The algebra $B_0$ is finite type over $R$, and $B$ is finite as a $B_0$-module by step [](#s5){.pf-ref}. A finite module algebra over a finite-type algebra is finite type over the base.

:::

::: {.problem}
Let $F \subseteq K \subseteq L$ be a tower of field extensions. Prove that if $K/F$ is algebraic and $L/K$ is algebraic, then $L/F$ is algebraic.
:::

::: {.solution}
Let $\alpha\in L$. Since $L/K$ is algebraic, $\alpha$ is a root of a nonzero polynomial $p(x)=c_0+c_1x+\cdots+c_nx^n\in K[x]$. Let $E=F(c_0,\ldots,c_n)\subseteq K$.

::: pf

::: {.pf-step #base}
$[E:F]<\infty$.

::: pf-proof
Each $c_i$ is algebraic over $F$ because $K/F$ is algebraic, and a field generated by finitely many algebraic elements is a finite extension.
:::

:::

::: {.pf-step #top}
$[E(\alpha):E]<\infty$.

::: pf-proof
$\alpha$ is a root of the nonzero polynomial $p\in E[x]$.
:::

:::

::: pf-step
$L/F$ is algebraic.

::: pf-proof
By steps [](#base){.pf-ref} and [](#top){.pf-ref} and the tower law, $[E(\alpha):F]=[E(\alpha):E][E:F]<\infty$.
A finite extension is algebraic, so $\alpha$ is algebraic over $F$; since $\alpha\in L$ was arbitrary, $L/F$ is algebraic.
:::

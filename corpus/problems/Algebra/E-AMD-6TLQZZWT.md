::: {.exercise}
Show that $A_n$ is simple for $n\geq 5$
:::

::: {.solution}
**Goal:** Prove that the alternating group $A_n$ is a simple group for all integers $n \ge 5$.

<1>1. Key Lemmas on $A_n$: <2>1. For $n \ge 3$, $A_n$ is generated by the set of all $3$-cycles.
::: {.proof}
Any permutation in $A_n$ is a product of an even number of transpositions.
:::
A product of two transpositions $(a\,b)(c\,d)$ equals $(a\,c\,b)$ if $|\{a,b,c,d\}|=3$, or $(a\,c)(c\,b) = (a\,c\,b)$ if they overlap, or $(a\,b)(b\,c)(b\,c)(c\,d) = (a\,b\,c)(b\,c\,d)$ if disjoint.
Thus every element of $A_n$ is a product of $3$-cycles.
<2>2. For $n \ge 5$, all $3$-cycles are conjugate in $A_n$.
::: {.proof}
Let $(a\,b\,c)$ and $(u\,v\,w)$ be two $3$-cycles in $A_n$.
:::
Since $n \ge 5$, there exist two distinct elements $x, y \in \{1,\dots,n\} \setminus \{a,b,c\}$.
In $S_n$, there exists $\sigma \in S_n$ mapping $(a,b,c,x,y) \mapsto (u,v,w,x',y')$.
If $\operatorname{sgn}(\sigma) = 1$, then $\sigma \in A_n$ conjugates $(a\,b\,c)$ to $(u\,v\,w)$.
If $\operatorname{sgn}(\sigma) = -1$, the permutation $\sigma' = \sigma \circ (x\,y) \in A_n$ also maps $a \mapsto u, b \mapsto v, c \mapsto w$ and satisfies $\sigma' (a\,b\,c) (\sigma')^{-1} = (u\,v\,w)$.
<2>3. If $N \trianglelefteq A_n$ ($n \ge 5$) contains at least one $3$-cycle, then $N = A_n$.
::: {.proof}
Since $N$ is normal in $A_n$, $N$ contains all conjugates in $A_n$ of that $3$-cycle.
:::
By <1>1.<2>2, $N$ contains all $3$-cycles in $A_n$.
By <1>1.<2>1, the $3$-cycles generate $A_n$, so $N = A_n$.

<1>2. Base Case: $A_5$ is simple.
<2>1. The conjugacy classes in $A_5$ (of order $|A_5| = 60$) have sizes: the identity $\{e\}$ (size $1$), the class of products of two disjoint transpositions of shape $(a\,b)(c\,d)$ (size $15$), the class of $3$-cycles $(a\,b\,c)$ (size $20$), and two conjugacy classes of $5$-cycles of size $12$ each.
::: {.proof}
In $S_5$, there are $15$ permutations of shape $(2,2)$, $20$ $3$-cycles, and $24$ $5$-cycles.
:::
In $A_5$, the centralizer of a $5$-cycle has order $5$, so its $A_5$-orbit has size $60/5 = 12$, splitting the $24$ into two classes of $12$.
The centralizer sizes for the other classes remain odd/allow full $A_5$-conjugacy.
<2>2. Any normal subgroup $N \trianglelefteq A_5$ is a union of conjugacy classes containing the identity $\{e\}$, so its order $|N| = 1 + \sum k_i$ with $k_i \in \{12, 12, 15, 20\}$ and $|N|$ must divide $60$.
::: {.proof}
Standard property that normal subgroups are unions of conjugacy classes and Lagrange's Theorem.
:::
<2>3. No proper non-trivial sum of the class sizes $\{12, 12, 15, 20\}$ plus $1$ divides $60$.
::: {.proof}
The possible sums are $1+12=13$, $1+15=16$, $1+20=21$, $1+12+12=25$, $1+12+15=28$, $1+12+20=33$, $1+15+20=36$, $1+12+12+15=40$, $1+12+12+20=45$, $1+12+15+20=48$, none of which divides $60$ except $1$ and $1+12+12+15+20=60$.
:::
<2>4. Therefore, $A_5$ has no non-trivial proper normal subgroups, so $A_5$ is simple.
::: {.proof}
Follows from <2>2 and <2>3.
:::

<1>3. Induction Step: If $A_{n-1}$ is simple for $n \ge 6$, then $A_n$ is simple.
<2>1. Let $n \ge 6$, and assume $A_{n-1}$ is simple.
Let $N \trianglelefteq A_n$ be a non-trivial normal subgroup.
::: {.proof}
Inductive hypothesis and setting.
:::
<2>2. For each $i \in \{1, \dots, n\}$, let $H_i = \{\sigma \in A_n \mid \sigma(i) = i\}$ be the stabilizer of $i$.
Then $H_i \cong A_{n-1}$.
::: {.proof}
Permutations fixing $i$ act as the alternating group on the remaining $n-1 \ge 5$ elements.
:::
<2>3. For each $i$, $N \cap H_i \trianglelefteq H_i$.
::: {.proof}
The intersection of a normal subgroup with any subgroup is normal in that subgroup.
:::
<2>4. Since $H_i \cong A_{n-1}$ is simple by induction hypothesis, either $N \cap H_i = \{e\}$ or $N \cap H_i = H_i$.
::: {.proof}
A simple group has only trivial normal subgroups.
:::
<2>5. If $N \cap H_i = H_i$ for some $i$, then $N = A_n$.
::: {.proof}
If $N \cap H_i = H_i$, then $H_i \subseteq N$.
:::
Since $n \ge 6 \ge 5$, $H_i \cong A_{n-1}$ contains a $3$-cycle.
Thus $N$ contains a $3$-cycle, which implies $N = A_n$ by <1>1.<2>3. <2>6. It is impossible that $N \cap H_i = \{e\}$ for all $i \in \{1, \dots, n\}$.
<3>1. Choose $\sigma \in N$ with $\sigma \neq e$.
::: {.proof}
$N$ is non-trivial by hypothesis.
:::
<3>2. If $\sigma$ fixes some element $i$, then $\sigma \in N \cap H_i$, which implies $N \cap H_i \neq \{e\}$.
::: {.proof}
Definition of $H_i$.
:::
<3>3. If $\sigma$ does not fix any element, write $\sigma$ in disjoint cycle notation.
::: {.proof}
Every permutation has a unique disjoint cycle decomposition.
:::
<3>4. If $\sigma$ contains a cycle of length $\ge 3$, say $\sigma = (a_1\,a_2\,a_3\dots)\dots$, let $\tau = (a_3\,a_4\,a_5) \in A_n$ (valid since $n \ge 6$). Then the commutator $\rho = \sigma^{-1} \tau \sigma \tau^{-1} \in N$ because $N \trianglelefteq A_n$.
Moreover, $\rho(a_1) = \sigma^{-1}\tau\sigma(a_1) = \sigma^{-1}\tau(a_2) = \sigma^{-1}(a_2) = a_1$.
Thus $\rho$ fixes $a_1$, so $\rho \in N \cap H_{a_1}$.
Also, $\rho(a_3) = \sigma^{-1}\tau\sigma(a_5) \neq a_3$, so $\rho \neq e$.
Thus $N \cap H_{a_1} \neq \{e\}$.
::: {.proof}
Explicit computation of cycle action on $a_1$ and $a_3$.
:::
<3>5. If $\sigma$ is a product of disjoint $2$-cycles, say $\sigma = (a_1\,a_2)(a_3\,a_4)\dots$, let $\tau = (a_1\,a_2)(a_3\,a_5) \in A_n$ (valid since $n \ge 6$). Then $\rho = \sigma^{-1} \tau \sigma \tau^{-1} \in N$.
Computation gives $\rho(a_1) = a_1$, so $\rho$ fixes $a_1$, and $\rho(a_3) = a_4 \neq a_3$, so $\rho \neq e$.
Thus $\rho \in N \cap H_{a_1}$ with $\rho \neq e$, meaning $N \cap H_{a_1} \neq \{e\}$.
::: {.proof}
Explicit computation of cycle action.
:::
<3>6. Q.E.D.
::: {.proof}
In all cases, $N$ contains a non-identity element fixing some point $i$, so $N \cap H_i \neq \{e\}$.
:::
<2>7. Therefore, $N = A_n$.
::: {.proof}
By <2>4 and <2>6, $N \cap H_i = H_i$ must hold for some $i$, which gives $N = A_n$ by <2>5. <2>8. Q.E.D.
::: {.proof}
Any non-trivial normal subgroup of $A_n$ is all of $A_n$, so $A_n$ is simple.
:::
:::

<1>4. Conclusion: $A_n$ is simple for all $n \ge 5$.
::: {.proof}
The base case $n = 5$ holds by <1>2, and the induction step holds by <1>3.
:::
:::

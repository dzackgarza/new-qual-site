::: {.problem}
What is a Noetherian ring?
If $I$ is an ideal in a Noetherian ring with a unit, what is the intersection of $I^n$ over all positive integers $n$?
:::

::: {.solution}
Throughout, $R$ is a commutative ring with $1$ and $I\trianglelefteq R$ is an ideal; write $J=\bigcap_{n\geq1}I^n$ and let $\Jac(R)$ be the Jacobson radical, the intersection of the maximal ideals.

::: pf

::: {.pf-step #noetherian}
$R$ is Noetherian if and only if every ideal of $R$ is finitely generated, if and only if every ascending chain $I_1\subseteq I_2\subseteq\cdots$ of ideals stabilizes.

::: pf-proof
Suppose every ideal is finitely generated, and let $I_1\subseteq I_2\subseteq\cdots$ be an ascending chain. Its union $U$ is an ideal, hence generated by finitely many elements $u_1,\ldots,u_m$; each $u_j$ lies in some $I_{n_j}$ by the definition of the union, so all of them lie in $I_N$ with $N=\max_j n_j$, and then $U\subseteq I_N\subseteq U$, so the chain is constant from $N$ on. Conversely, if some ideal $I$ is not finitely generated, choose $a_n\in I$ outside the ideal generated by $a_1,\ldots,a_{n-1}$ for each $n\geq1$; the ideals generated by $a_1,\ldots,a_n$ then form a strictly ascending chain.
:::

:::

::: {.pf-step #fg}
$J$ is an ideal and, since $R$ is Noetherian, it is finitely generated.

::: pf-proof
$J$ is an intersection of ideals, hence an ideal, and each $I^n$ is an ideal because $I$ is. The first part of step [](#noetherian){.pf-ref} then gives that $J$ is finitely generated.
:::

:::

::: {.pf-step #artin-rees}
There is an integer $k\geq1$ such that $I^n\cap J=I^{n-k}\,(I^k\cap J)$ for every $n\geq k$.

::: pf-proof
This is the Artin--Rees lemma, applied to the ring $R$, the ideal $I$, the finitely generated $R$-module $R$ and its submodule $J$: for a Noetherian ring, an ideal $I$ and finitely generated modules $N\subseteq M$, there is $k$ with $I^nM\cap N=I^{n-k}(I^kM\cap N)$ for all $n\geq k$. The conclusion here is that statement with $M=R$ and $N=J$.
:::

:::

::: {.pf-step #stable}
$J=IJ$.

::: pf-proof
Since $J\subseteq I^n$ for every $n$, taking $n=k+1$ in step [](#artin-rees){.pf-ref} gives $J=I^{k+1}\cap J=I\,(I^k\cap J)$. Now $I^k\cap J\subseteq J$, so $I(I^k\cap J)\subseteq IJ$, whence $J\subseteq IJ$; and $IJ\subseteq J$ because $J$ is an ideal. Hence $J=IJ$.
:::

:::

::: {.pf-step #det}
There is $x\in I$ with $(1-x)J=0$, so every $a\in J$ satisfies $(1-x)a=0$ for that single $x$.

::: pf-proof
Let $m_1,\ldots,m_r$ generate $J$, which step [](#fg){.pf-ref} licenses. Since $J=IJ$ by step [](#stable){.pf-ref}, for each $i$ there are $a_{ij}\in I$ with $m_i=\sum_j a_{ij}m_j$, that is $\sum_j(\delta_{ij}-a_{ij})m_j=0$ for each $i$, where $\delta_{ij}$ is $1$ if $i=j$ and $0$ otherwise. Let $A$ be the $r\times r$ matrix $(\delta_{ij}-a_{ij})$ and let $\operatorname{adj}(A)$ be its adjugate, so that $\operatorname{adj}(A)\,A=\det(A)\cdot\Id_r$. Multiplying the system by $\operatorname{adj}(A)$ gives $\det(A)\,m_k=0$ for every $k$, hence $\det(A)J=0$. Expanding the determinant, $\det(A)=1-x$ where $x$ is a finite sum of products of the entries $a_{ij}$, each of which lies in $I$; so $x\in I$. Thus $(1-x)J=0$, and a single $x$ annihilates all of $J$.
:::

:::

::: {.pf-step #forward}
$J\subseteq\theset{a\in R:(1-x)a=0\text{ for some }x\in I}$.

::: pf-proof
Let $a\in J$ and take the $x\in I$ of step [](#det){.pf-ref}; then $(1-x)a=0$ because $(1-x)$ annihilates every element of $J$.
:::

:::

::: {.pf-step #backward}
If $a\in R$ satisfies $(1-x)a=0$ for some $x\in I$, then $a\in J$.

::: pf-proof
The equation gives $a=xa$. Multiplying by $x$ repeatedly, $a=xa=x^2a=\cdots=x^na$ for every $n\geq1$, so $a\in I^n$ for every $n\geq1$ and hence $a\in J$.
:::

:::

::: {.pf-step}
$\bigcap_{n\geq1}I^n=\theset{a\in R:(1-x)a=0\text{ for some }x\in I}$; in particular the intersection is $0$ when $I\subseteq\Jac(R)$, and when $R$ is a domain and $I\neq R$.

::: pf-proof
Steps [](#forward){.pf-ref} and [](#backward){.pf-ref} give the equality.

If $I\subseteq\Jac(R)$ and $x\in I$, then $x\in\Jac(R)$, so $1-x$ is a unit; from $(1-x)a=0$ we get $a=0$. Hence each $a$ in the intersection is $0$.

If $R$ is a domain and $I\neq R$, then $1-x\neq0$ for $x\in I$, since $1-x=0$ would give $x=1\in I$ and hence $I=R$; a product in a domain with a nonzero factor and zero result forces $a=0$, so again the intersection is $0$.
:::

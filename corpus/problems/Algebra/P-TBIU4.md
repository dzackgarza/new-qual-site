::: {.problem}
What is a PID? Give an example of a UFD that is not a PID. Is $k[x]$ a PID when $k$ is a field?
:::

::: {.solution}
Let $k$ be a field.

::: pf

::: pf-step
A principal ideal domain is an integral domain in which every ideal is generated by one element.

::: pf-proof
This is the definition.
:::

:::

::: pf-step
$k[x]$ is a PID.

::: pf-proof
Division with remainder gives, for $f,g\in k[x]$ with $g\neq0$, polynomials $q,r$ with $f=qg+r$ and $r=0$ or $\deg r<\deg g$.
Thus $k[x]$ is a Euclidean domain with Euclidean function $\deg$, and every Euclidean domain is a PID.
:::

:::

::: {.pf-step #ufd}
$k[x,y]$ is a UFD.

::: pf-proof
$k[x]$ is a UFD, and by Gauss's lemma a polynomial ring over a UFD is a UFD, so $k[x,y]=k[x][y]$ is a UFD.
:::

:::

::: {.pf-step #not-principal}
The ideal $(x,y)\subseteq k[x,y]$ is not principal.

::: pf-proof
Suppose $(x,y)=(f)$. Then $f$ divides both $x$ and $y$.
Since $x$ and $y$ are non-associate irreducibles, their only common divisors are units, so $f$ is a unit and $(x,y)=k[x,y]$.
This is false, since every element of $(x,y)$ has zero constant term, so $1\notin(x,y)$.
:::

:::

::: pf-step
$k[x,y]$ is a UFD that is not a PID.

::: pf-proof
This follows from step [](#ufd){.pf-ref} and step [](#not-principal){.pf-ref}.
:::

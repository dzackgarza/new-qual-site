::: {.problem}
Classify all groups of order $p^3$ for $p$ prime up to isomorphism.
:::

::: {.solution}
Let $G$ be a group of order $p^3$.

::: pf

::: pf-step

The abelian groups of order $p^3$ are $C_{p^3}$, $C_{p^2}\times C_p$ and $C_p^3$.

::: pf-proof

This is the structure theorem for finite abelian groups applied to the partitions $3$, $2+1$ and $1+1+1$ of $3$.

:::

:::

::: {.pf-step #center}

If $G$ is nonabelian, then $\abs{Z(G)}=p$, $G/Z(G)\cong C_p\times C_p$, and $[G,G]=Z(G)$.

::: pf-proof

The center of a nontrivial $p$-group is nontrivial, and $Z(G)\ne G$. If $\abs{G/Z(G)}=p$, then $G/Z(G)$ is cyclic, which forces $G$ to be abelian. Hence $\abs{Z(G)}=p$, and $G/Z(G)$ has order $p^2$ and is not cyclic, so $G/Z(G)\cong C_p\times C_p$. Since $G/Z(G)$ is abelian, $[G,G]\subseteq Z(G)$; since $G$ is nonabelian, $[G,G]\ne1$, so $[G,G]=Z(G)$.

:::

:::

::: pf-step

If $p=2$, the nonabelian groups of order $8$ are $D_4=\langle r,s\mid r^4=s^2=1,\ srs=r^{-1}\rangle$ and $Q_8$, and these are not isomorphic.

::: pf-proof

A group of exponent $2$ is abelian, and a group with an element of order $8$ is cyclic, so a nonabelian $G$ of order $8$ has an element $a$ of order $4$. The subgroup $\langle a\rangle$ has index $2$, so it is normal. Choose $b\notin\langle a\rangle$. Then $G=\langle a,b\rangle$, and conjugation by $b$ is a nontrivial automorphism of $\langle a\rangle\cong C_4$, so $bab^{-1}=a^{-1}$. Also $b^2\in\langle a\rangle$ commutes with $b$, so $b^2$ is fixed by inversion, that is, $b^2\in\{1,a^2\}$. If some element outside $\langle a\rangle$ has order $2$, take it as $b$; then $G\cong D_4$. Otherwise $b^2=a^2$ for every choice of $b$, and $G\cong Q_8=\langle a,b\mid a^4=1,\ b^2=a^2,\ bab^{-1}=a^{-1}\rangle$. The group $D_4$ has five elements of order $2$ and $Q_8$ has one, so they are not isomorphic.

:::

:::

::: {.pf-step #power-map}

If $p$ is odd and $G$ is nonabelian, then $\pi:G\to G$, $x\mapsto x^p$, is a homomorphism with image in $Z(G)$.

::: pf-proof

By step [](#center){.pf-ref}, commutators are central, so induction on $n$ gives $(xy)^n=x^ny^n[y,x]^{n(n-1)/2}$. Since $[y,x]\in Z(G)$ has order dividing $p$ and $p$ divides $p(p-1)/2$ for odd $p$, $(xy)^p=x^py^p$. Since $G/Z(G)$ has exponent $p$, $x^p\in Z(G)$.

:::

:::

::: pf-step

If $p$ is odd and $G$ is nonabelian with an element of order $p^2$, then $G\cong\langle a,b\mid a^{p^2}=b^p=1,\ bab^{-1}=a^{1+p}\rangle$.

::: pf-proof

Let $a$ have order $p^2$. Then $1\ne a^p\in\pi(G)\subseteq Z(G)$, and $\abs{Z(G)}=p$, so $\pi(G)=Z(G)$ and $\ker\pi$ has order $p^2$ by step [](#power-map){.pf-ref}. Since $a\notin\ker\pi$, there is $b\in\ker\pi\setminus\langle a\rangle$; it has order $p$. The subgroup $\langle a\rangle$ has index $p$ in a $p$-group, so it is normal, $\langle a\rangle\cap\langle b\rangle=1$, and $G=\langle a\rangle\rtimes\langle b\rangle$. Conjugation by $b$ is an automorphism of $\langle a\rangle$ of order $p$, nontrivial because $G$ is nonabelian. The group $\Aut(C_{p^2})\cong(\ZZ/p^2\ZZ)^\times$ is cyclic of order $p(p-1)$, so its unique subgroup of order $p$ is generated by $a\mapsto a^{1+p}$. Replacing $b$ by a suitable power $b^j$ with $p\nmid j$ gives $bab^{-1}=a^{1+p}$. This semidirect product exists and has order $p^3$.

:::

:::

::: pf-step

If $p$ is odd and $G$ is nonabelian of exponent $p$, then $G\cong\langle x,y,z\mid x^p=y^p=z^p=1,\ [x,y]=z,\ [x,z]=[y,z]=1\rangle$, the Heisenberg group $UT_3(\FF_p)$.

::: pf-proof

By step [](#center){.pf-ref}, choose $x,y\in G$ whose images form a basis of $G/Z(G)\cong C_p^2$ and set $z=[x,y]$. If $z=1$, then $G=\langle x,y,Z(G)\rangle$ would be abelian, so $z$ generates $Z(G)=[G,G]$. The listed relations hold in $G$, and they let every element of the group they present be written as $x^iy^jz^k$ with $0\le i,j,k<p$, so that group has order at most $p^3$. It surjects onto $G$, which has order $p^3$, so the surjection is an isomorphism. The group $UT_3(\FF_p)$ of upper unitriangular matrices satisfies the same relations with the elementary matrices $x=I+E_{12}$, $y=I+E_{23}$ and $z=I+E_{13}$, which generate it, and it has order $p^3$.

:::

:::

::: pf-step

There are exactly $\boxed{5}$ groups of order $p^3$ up to isomorphism.

::: pf-proof

Each case above contributes three abelian and two nonabelian groups. The abelian groups are pairwise nonisomorphic by the uniqueness in the structure theorem. For odd $p$, the two nonabelian groups have exponents $p^2$ and $p$, so they are not isomorphic.

:::

::: {.exercise}
Show that if $R$ is Noetherian then every ideal is finitely generated.
:::

::: {.solution}
A ring $R$ is Noetherian when every ascending chain $I_1\subseteq I_2\subseteq\cdots$ of ideals stabilizes: there is $N$ with $I_n=I_N$ for all $n\geq N$. Write $(a_1,\ldots,a_n)$ for the ideal generated by finitely many elements, and note that the zero ideal is generated by the empty family.

::: pf

::: {.pf-step #chain}
If $I\trianglelefteq R$ is not finitely generated, then there is an infinite strictly ascending chain $I_0\subsetneq I_1\subsetneq I_2\subsetneq\cdots$ of ideals contained in $I$.

::: pf-proof
Since $I\neq0$ — the zero ideal is finitely generated — choose $x_1\in I$ and set $I_1=(x_1)$. Inductively, having chosen $x_1,\ldots,x_n$ and set $I_n=(x_1,\ldots,x_n)$: the ideal $I_n$ is generated by $n$ elements, so $I_n\neq I$, because $I$ is not finitely generated; hence there is $x_{n+1}\in I\setminus I_n$, and putting $I_{n+1}=(x_1,\ldots,x_{n+1})$ gives $I_n\subseteq I_{n+1}$ and $x_{n+1}\in I_{n+1}\setminus I_n$, so the inclusion is strict. This recursion produces the chain, and every $I_n$ is contained in $I$ because $I$ is an ideal containing each $x_j$.
:::

:::

::: {.pf-step #contradiction}
That chain does not stabilize, contradicting the Noetherian hypothesis.

::: pf-proof
Each inclusion $I_n\subsetneq I_{n+1}$ is strict by construction, so there is no index $N$ beyond which the chain is constant; a Noetherian ring admits no such chain.
:::

:::

::: {.pf-step}
Every ideal of a Noetherian ring is finitely generated.

::: pf-proof
Suppose $I$ is an ideal of the Noetherian ring $R$ that is not finitely generated. Step [](#chain){.pf-ref} produces a strictly ascending chain in $I$, and step [](#contradiction){.pf-ref} says that contradicts the hypothesis. So no such $I$ exists.
:::

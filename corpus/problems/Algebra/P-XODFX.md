::: {.problem}
Suppose $D$ is an integral domain and the fundamental theorem holds for finitely-generated modules over $D$ (i.e. they are all direct sums of finitely many cyclic modules).

Does $D$ have to be a PID?
:::

::: {.solution}

::: pf

::: {.pf-step #s1}
The answer is **yes**: $D$ must be a Principal Ideal Domain (PID).

::: pf-proof
statement of the claim.
:::

:::

::: {.pf-step #s2}
Show that every finitely generated ideal $I \subseteq D$ is principal:

::: pf-proof

::: pf-step
Let $I \subseteq D$ be any finitely generated ideal of $D$.

::: pf-proof
setup.
:::

:::

::: {.pf-step #s2-2}
By hypothesis, the finitely generated $D$-module $I$ decomposes as a direct sum of cyclic modules:
\[
I \cong C_1 \oplus C_2 \oplus \cdots \oplus C_k,
\]
where each $C_i \cong D / J_i$ for some ideal $J_i \subseteq D$.

::: pf-proof
hypothesis on finitely generated modules over $D$.
:::

:::

::: pf-step
Since $I \subseteq D$ and $D$ is an integral domain, $I$ is torsion-free: for any $r \in D \setminus \{0\}$ and $x \in I \setminus \{0\}$, $rx \neq 0$ in $D$.

::: pf-proof
integral domains have no zero divisors.
:::

:::

::: {.pf-step #s2-4}
Each direct summand $C_i \subseteq I$ is torsion-free, so $J_i = \{0\}$ for all $i$.
Thus $C_i \cong D$.

::: pf-proof
if $r \in J_i \setminus \{0\}$, then $r \cdot (1 + J_i) = 0$, giving a non-zero torsion element unless $J_i = (0)$.
:::

:::

::: pf-step
Thus $I \cong D^k$ for some integer $k \ge 0$.

::: pf-proof
step [](#s2-2){.pf-ref} and step [](#s2-4){.pf-ref}.
:::

:::

:::

:::

::: {.pf-step #s3}
Show that $k \le 1$:

::: pf-proof

::: pf-step
If $k = 0$, $I = (0)$, which is principal.

::: pf-proof
the zero ideal is generated by $0$.
:::

:::

::: {.pf-step #s3-2}
Suppose for contradiction that $k \ge 2$.
Then $I$ contains two non-zero submodules $M_1, M_2 \subseteq I \subseteq D$ such that $M_1 \cap M_2 = \{0\}$.

::: pf-proof
definition of direct sum $I \cong D^k$ with $k \ge 2$.
:::

:::

::: {.pf-step #s3-3}
Choose non-zero elements $x_1 \in M_1$ and $x_2 \in M_2$.

::: pf-proof
$M_1, M_2 \neq \{0\}$.
:::

:::

::: {.pf-step #s3-4}
Since $D$ is commutative, consider the product $x_1 x_2 \in D$:
\[
x_1 x_2 = x_2 x_1 \in M_1 \quad (\text{since } x_1 \in M_1 \text{ and } M_1 \text{ is an ideal/submodule}),
\]
\[
x_1 x_2 \in M_2 \quad (\text{since } x_2 \in M_2 \text{ and } M_2 \text{ is an ideal/submodule}).
\]

::: pf-proof
ideal absorption property in commutative rings.
:::

:::

::: {.pf-step #s3-5}
Thus $x_1 x_2 \in M_1 \cap M_2 = \{0\}$, so $x_1 x_2 = 0$.

::: pf-proof
step [](#s3-2){.pf-ref} and step [](#s3-4){.pf-ref}.
:::

:::

::: {.pf-step #s3-6}
Since $D$ is an integral domain and $x_1 \neq 0, x_2 \neq 0$, this is a contradiction.

::: pf-proof
integral domains have no non-zero zero divisors.
:::

:::

::: pf-step
Thus $k \le 1$, which forces $k = 1$ when $I \neq (0)$.

::: pf-proof
steps [](#s3-2){.pf-ref} through [](#s3-6){.pf-ref}.
:::

:::

::: pf-step
Therefore $I \cong D$ as a $D$-module, which means $I = (d)$ is generated by a single element $d \in D$.

::: pf-proof
rank 1 free submodules of $D$ are principal ideals.
:::

:::

:::

:::

::: {.pf-step #s4}
Show that every ideal of $D$ is principal:

::: pf-proof

::: pf-step
From step [](#s2){.pf-ref} and step [](#s3){.pf-ref}, every finitely generated ideal is principal, so $D$ is a Bézout domain.

::: pf-proof
step [](#s2){.pf-ref} and step [](#s3){.pf-ref}.
:::

:::

::: pf-step
Let $I \subseteq D$ be an arbitrary ideal.
If $I = (0)$, it is principal.

::: pf-proof
case $I = (0)$.
:::

:::

::: {.pf-step #s4-3}
If $I \neq (0)$, let $a \in I \setminus \{0\}$.
For any $b \in I$, the ideal $(a, b) \subseteq I$ is finitely generated, hence principal by step [](#s3){.pf-ref}, say $(a, b) = (d)$.

::: pf-proof
step [](#s3){.pf-ref}.
:::

:::

::: {.pf-step #s4-4}
If $I$ is not finitely generated, one could construct an infinite strictly ascending chain of principal ideals $(d_1) \subsetneq (d_2) \subsetneq \cdots$.
But every submodule of $D$ in a Bézout domain where all fg modules are cyclic is finitely generated.

::: pf-proof
structure theorem for finitely generated modules implies Noetherianity.
:::

:::

::: pf-step
Thus every ideal of $D$ is principal.

::: pf-proof
step [](#s4-3){.pf-ref} and step [](#s4-4){.pf-ref}.
:::

:::

:::

:::

::: pf-qed
Conclusion: $D$ is a PID.
steps [](#s1){.pf-ref} through [](#s4){.pf-ref}.
:::

::: {.exercise}
Show that $S_n$ is generated by each of the following sets:

(a) Transpositions $\{(a\,b) \mid 1 \le a < b \le n\}$.

(b) Adjacent transpositions $\{(i\,i+1) \mid 1 \le i \le n-1\}$.

(c) $\{(1\,2), (1\,2\,\dots\,n)\}$ for $n\ge 2$.

(d) $\{(1\,2), (2\,3\,\dots\,n)\}$ for $n\ge 3$.

(e) $\{(a\,b), (1\,2\,\dots\,n)\}$ where $1\le a<b\le n$ iff $\gcd(b-a, n) = 1$.

(f) Any arbitrary transposition and any arbitrary $p$-cycle in $S_p$ ($p$ prime).
:::

::: {.solution}
Write $S_n$ for the symmetric group on $\{1,\ldots,n\}$, $(a\ b)$ for the transposition exchanging $a$ and $b$, and $c=(1\ 2\ \cdots\ n)$; conjugation is written $g\tau g^{-1}$, and products are composed right to left.

::: pf

::: {.pf-step #all-transpositions}
(a) The transpositions generate $S_n$.

::: pf-proof
Every permutation is a product of disjoint cycles, and a cycle $(a_1\ a_2\ \cdots\ a_m)$ equals $(a_1\ a_m)(a_1\ a_{m-1})\cdots(a_1\ a_2)$: the right-hand product sends $a_1\mapsto a_2$, $a_j\mapsto a_{j+1}$ for $2\leq j\leq m-1$, and $a_m\mapsto a_1$, as one checks factor by factor, and it fixes everything else. Each $(a_1\ a_j)$ is a transposition, so every permutation is a product of transpositions.
:::

:::

::: {.pf-step #adjacent}
(b) The adjacent transpositions $s_i=(i\ i+1)$, $1\leq i\leq n-1$, generate $S_n$.

::: pf-proof
For $i<j$ one has $(i\ j)=s_i\,s_{i+1}\cdots s_{j-1}\,s_{j-2}\cdots s_i$.
The right-hand product sends $i\mapsto i+1\mapsto\cdots\mapsto j$ along the increasing chain, sends $j\mapsto j-1\mapsto\cdots\mapsto i$ along the decreasing chain, fixes the symbols outside $\{i,\ldots,j\}$ and fixes every $k$ with $i<k<j$, which travels up the chain and back down. So each transposition is a product of adjacent ones, and step [](#all-transpositions){.pf-ref} finishes the argument.
:::

:::

::: {.pf-step #cycle-and-transposition}
(c) $\generators{(1\ 2),c}=S_n$ for $n\geq2$.

::: pf-proof
Conjugation relabels a transposition: for any permutation $g$ and any $x,y$ one has $g(x\ y)g^{-1}=(g(x)\ g(y))$, because $g(x\ y)g^{-1}$ sends $g(x)\mapsto g(y)$ and fixes the rest. Taking $g=c^k$, which sends $1\mapsto 1+k$ and $2\mapsto 2+k$ with indices taken modulo $n$, gives $c^k(1\ 2)c^{-k}=(1+k\ \ 2+k)$. For $k=0,\ldots,n-2$ these are exactly the adjacent transpositions $(1\ 2),(2\ 3),\ldots,(n-1\ n)$, so $\generators{(1\ 2),c}$ contains all adjacent transpositions and hence, by step [](#adjacent){.pf-ref}, is all of $S_n$.
:::

:::

::: {.pf-step #long-cycle}
(d) $\generators{(1\ 2),d}=S_n$ for $n\geq3$, where $d=(2\ 3\ \cdots\ n)$.

::: pf-proof
The cycle $d$ fixes $1$, so by the relabelling rule of step [](#cycle-and-transposition){.pf-ref}, $d^k(1\ 2)d^{-k}=(1\ d^k(2))$. As $k$ runs over the powers of the $(n-1)$-cycle $d$, the elements $d^k(2)$ run over all of $\{2,\ldots,n\}$, so the subgroup contains every transposition $(1\ j)$ with $j\geq2$. For $2\leq i<j\leq n$ we have $(i\ j)=(1\ i)(1\ j)(1\ i)$: the right-hand product sends $i\mapsto j$, $j\mapsto i$ and fixes $1$ and everything else. So the subgroup contains all transpositions and equals $S_n$ by step [](#all-transpositions){.pf-ref}.
:::

:::

::: {.pf-step #criterion}
(e) For $1\leq a<b\leq n$, $\generators{(a\ b),c}=S_n$ if and only if $\gcd(b-a,n)=1$.

::: pf-proof
Put $\tau=(a\ b)$ and let $d$ be the residue of $b-a$ modulo $n$, so $1\leq d\leq n-1$ and $\gcd(d,n)=\gcd(b-a,n)$.

::: {.pf-step #conjugates}
The conjugates $c^k\tau c^{-k}$ are the transpositions joining $x$ to $x+d$ in $\ZZ/n\ZZ$, and together they generate the full symmetric group on each connected component of the graph on $\ZZ/n\ZZ$ whose edges are those pairs.

::: pf-proof
By the relabelling rule of step [](#cycle-and-transposition){.pf-ref}, $c^k\tau c^{-k}=(c^k(a)\ c^k(b))$; since $c$ is the $n$-cycle $x\mapsto x+1$ on $\ZZ/n\ZZ$, this is the transposition joining $x=c^k(a)$ to $x+d$ with $d\equiv b-a$. For the second assertion, let $\sim$ be the equivalence relation generated by the edges; the transpositions along edges move every point inside its class, so the subgroup they generate lies in $\prod_{C}\operatorname{Sym}(C)$. Conversely, if $x=v_0,\ldots,v_m=y$ is a path, then $(x\ y)=(v_{m-1}\ v_m)\cdots(v_1\ v_2)(v_0\ v_1)(v_1\ v_2)\cdots(v_{m-1}\ v_m)$, the telescoping identity obtained by conjugating $(v_0\ v_1)$ repeatedly, so every transposition inside a class is a product of edge transpositions and the two subgroups coincide.
:::

:::

::: {.pf-step #connected}
If $\gcd(d,n)=1$ then that graph is connected, so the conjugates of $\tau$ alone generate $S_n$.

::: pf-proof
If $\gcd(d,n)=1$ the residues $0,d,2d,\ldots$ run through all of $\ZZ/n\ZZ$, so the edges $\{x,x+d\}$ connect the graph: from $0$ one reaches $d,2d,\ldots$, and translating by $x$ reaches every vertex from every other in finitely many steps. Hence there is one component and, by step [](#conjugates){.pf-ref}, the conjugates of $\tau$ generate the full symmetric group on it, that is $S_n$.
:::

:::

::: {.pf-step #imprimitive}
If $\gcd(d,n)>1$ then $\generators{\tau,c}$ preserves a nontrivial block system, so it is a proper subgroup of $S_n$.

::: pf-proof
Let $g=\gcd(d,n)>1$. Since $d\equiv0\pmod g$, every edge $\{x,x+d\}$ joins two points congruent modulo $g$, so $\tau$ preserves each residue class modulo $g$; and $c$ sends a class to the next one, since $x\mapsto x+1$ changes the residue by $1$ and $g\geq2$. So $\generators{\tau,c}$ permutes the $g$ classes among themselves and hence preserves the partition into them, which is a block system with at least two blocks of size $n/g$ each; that size exceeds $1$ because otherwise $g=n$ and $d\equiv0$, contradicting $1\leq d\leq n-1$. A subgroup of $S_n$ preserving a nontrivial block system is proper, since $S_n$ is $2$-transitive for $n\geq2$ and a $2$-transitive group is primitive, while this block system is not the trivial one.
:::

:::


The three substeps give the two implications: when $\gcd(d,n)=1$ the conjugates of $\tau$ already generate $S_n$, and when the gcd exceeds $1$ the subgroup lies in the group preserving that block system and so is not $S_n$. Since $\gcd(b-a,n)=\gcd(d,n)$, the criterion follows.
:::

:::

::: {.pf-step #prime}
(f) In $S_p$ with $p$ prime, any transposition together with any $p$-cycle generates $S_p$.

::: pf-proof
Let $\sigma$ be the $p$-cycle and $\tau$ the transposition. Choose a bijection of $\{1,\ldots,p\}$ sending the cycle notation of $\sigma$ to $(1\ 2\ \cdots\ p)$ and let $h$ be the corresponding permutation; conjugating both generators by $h$ gives $\generators{\sigma,\tau}^h=\generators{c,\tau'}$ with $\tau'$ a transposition $(a\ b)$, and conjugate subgroups are equal in size, so it suffices to treat that case. Relabelling so that $1\leq a<b\leq p$ we get $1\leq b-a\leq p-1$; since $p$ is prime, $\gcd(b-a,p)=1$, so $\generators{\tau',c}=S_p$ by the criterion of step [](#criterion){.pf-ref}. Hence $\generators{\sigma,\tau}=S_p$ as well.
:::

:::

::: {.pf-step}
$S_n$ is generated by each of the six sets listed in (a)–(f).

::: pf-proof
Parts (a), (b), (c), (d), (e) and (f) are steps [](#all-transpositions){.pf-ref}, [](#adjacent){.pf-ref}, [](#cycle-and-transposition){.pf-ref}, [](#long-cycle){.pf-ref}, [](#criterion){.pf-ref} and [](#prime){.pf-ref} respectively, and each of them proves the corresponding generating statement with the stated hypotheses on $n$: (c) needs $n\geq2$ so that $(1\ 2)$ exists, (d) needs $n\geq3$ so that $d$ is a cycle of length at least $2$, (e) is vacuous when the stated gcd fails, and (f) requires $p$ prime exactly so that every difference $b-a$ with $1\leq b-a\leq p-1$ is coprime to $p$.
:::

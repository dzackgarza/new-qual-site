::: problem
- Show that the centralizer $C_G(H)$ of a subgroup is again a subgroup.
:::


::: {.solution}
Recall
\[
C_G(H)=\{g\in G:gh=hg\text{ for every }h\in H\}.
\]

<1>1. The identity lies in $C_G(H)$.
::: {.proof}
For every $h\in H$, one has $eh=he=h$.
:::

<1>2. If $x,y\in C_G(H)$, then $xy^{-1}\in C_G(H)$.
::: {.proof}
Fix $h\in H$. Since $y$ commutes with $h$, so does $y^{-1}$. Therefore
\[
xy^{-1}h=xhy^{-1}=hxy^{-1},
\]
using first that $y^{-1}h=hy^{-1}$ and then that $xh=hx$. Hence $xy^{-1}$ commutes with every element of $H$.
:::

<1>3. Therefore $C_G(H)\le G$.
::: {.proof}
By <1>1 the centralizer is nonempty, and <1>2 verifies the one-step subgroup criterion.
:::
:::

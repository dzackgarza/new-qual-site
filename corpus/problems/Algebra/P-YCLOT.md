::: {.problem}
Let $p$ be a prime. Classify all groups of order $p^2$.
:::

::: {.hint}
The group is abelian because $G/Z(G)$ cannot be a nontrivial cyclic group.
If there is no element of order $p^2$, take $a\ne1$, take $b\notin\generators{a}$, and recognize $G$ as the internal direct product $\generators{a}\times\generators{b}$.
:::

::: {.solution}
Let $G$ be a group of order $p^2$.

::: pf

::: {.pf-step #abelian}
$G$ is abelian.

::: pf-proof

::: {.pf-step #center}
$Z(G)\ne1$.

::: pf-proof
In the class equation $\abs{G}=\abs{Z(G)}+\sum_i[G:C_G(x_i)]$, over representatives $x_i$ of the noncentral classes, each index is a power of $p$ greater than $1$, so $p$ divides $\abs{Z(G)}$.
:::

:::

::: pf-step
$Z(G)=G$.

::: pf-proof
Otherwise $\abs{Z(G)}=p$ by step [](#center){.pf-ref} and Lagrange, so $G/Z(G)$ has order $p$ and is generated by some $gZ(G)$.
Then every element of $G$ has the form $g^mz$ with $z\in Z(G)$, and any two such elements commute, so $G$ is abelian and $Z(G)=G$, a contradiction.
:::

:::

:::

:::

::: pf-step
$G\cong C_{p^2}$ or $G\cong C_p\times C_p$, and these two groups are not isomorphic.

::: pf-proof
Element orders divide $p^2$.
If some $a$ has order $p^2$, then $G=\generators{a}\cong C_{p^2}$.
Otherwise every element other than $1$ has order $p$.
Take $a\ne1$, let $H=\generators{a}$, take $b\notin H$, and let $K=\generators{b}$; both have order $p$.
Since $H\cap K$ is a proper subgroup of $K$ of order dividing $p$, it is trivial, so $\abs{HK}=p^2$ and $HK=G$.
By step [](#abelian){.pf-ref}, $(h,k)\mapsto hk$ is a homomorphism $H\times K\to G$; it is injective because $H\cap K=1$ and surjective because $HK=G$, so $G\cong C_p\times C_p$.
The two groups differ because only $C_{p^2}$ has an element of order $p^2$.
:::

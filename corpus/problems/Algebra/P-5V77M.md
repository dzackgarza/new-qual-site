::: problem
Give an example of a ring where unique factorization fails, and prove the failure.
:::

::: solution
**Goal:** Exhibit the ring $R = \mathbb{Z}[\sqrt{-5}]$ and prove that unique factorization into irreducible elements fails.

<1>1. The Ring and its Norm Function:
    *Proof:*
    <2>1. Consider $R = \mathbb{Z}[\sqrt{-5}] = \{a + b\sqrt{-5} \mid a, b \in \mathbb{Z}\}$.
    <2>2. Define the multiplicative norm $N: R \to \mathbb{Z}_{\ge 0}$ by:
        $$N(a + b\sqrt{-5}) = (a + b\sqrt{-5})(a - b\sqrt{-5}) = a^2 + 5b^2.$$
    <2>3. Multiplicativity: $N(\alpha \beta) = N(\alpha) N(\beta)$ for all $\alpha, \beta \in R$.
    <2>4. **Units in $R$:** $\alpha \in R^\times \iff N(\alpha) = 1 \iff a^2 + 5b^2 = 1 \iff (a, b) = (\pm 1, 0)$.
        Thus $R^\times = \{1, -1\}$.

<1>2. Two Distinct Factorizations of 6:
    *Proof:*
    <2>1. In $R$, the number 6 can be factored in two distinct ways:
        $$6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}).$$
    <2>2. The norms of these factors are:
        - $N(2) = 2^2 = 4$.
        - $N(3) = 3^2 = 9$.
        - $N(1 + \sqrt{-5}) = 1^2 + 5(1)^2 = 6$.
        - $N(1 - \sqrt{-5}) = 1^2 + 5(-1)^2 = 6$.

<1>3. Irreducibility of the Factors:
    *Proof:*
    <2>1. We first observe that no element in $R$ has norm 2 or 3, because $a^2 + 5b^2 = 2$ and $a^2 + 5b^2 = 3$ have no integer solutions (if $b \ne 0$, $a^2 + 5b^2 \ge 5 > 3$).
    <2>2. **2 is irreducible:** If $2 = \alpha \beta$, then $N(\alpha)N(\beta) = N(2) = 4$. If neither $\alpha$ nor $\beta$ is a unit ($N \ne 1$), then $N(\alpha) = N(\beta) = 2$, which is impossible. Thus 2 is irreducible.
    <2>3. **3 is irreducible:** If $3 = \alpha \beta$, then $N(\alpha)N(\beta) = 9$. Non-trivial factors would require $N(\alpha) = 3$, which is impossible. Thus 3 is irreducible.
    <2>4. **$1 \pm \sqrt{-5}$ are irreducible:** If $1 \pm \sqrt{-5} = \alpha \beta$, then $N(\alpha)N(\beta) = 6$. Non-trivial factors would require $N(\alpha) \in \{2, 3\}$, which is impossible. Thus $1 \pm \sqrt{-5}$ are irreducible.

<1>4. Non-Associate Factors:
    *Proof:*
    <2>1. The only associates of 2 are $2 \cdot (\pm 1) = \pm 2$.
    <2>2. Neither $1 + \sqrt{-5}$ nor $1 - \sqrt{-5}$ is in $\{2, -2\}$.
    <2>3. Thus, the factorization $6 = 2 \cdot 3$ cannot be obtained by reordering and multiplying factors of $(1+\sqrt{-5})(1-\sqrt{-5})$ by units.

<1>5. Conclusion:
    The element $6 \in \mathbb{Z}[\sqrt{-5}]$ has two genuinely distinct factorizations into irreducible elements, so $\mathbb{Z}[\sqrt{-5}]$ is not a Unique Factorization Domain (UFD). Q.E.D.
:::

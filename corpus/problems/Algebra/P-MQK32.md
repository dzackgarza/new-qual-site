::: {.problem}
Prove that the symmetric group $S_n$ is generated by each of the following sets of permutations:
(1) All transpositions: $\{(i \, j) \mid 1 \le i < j \le n\}$.

(2) Adjacent transpositions: $\{(1 \, 2), (2 \, 3), \ldots, (n-1 \, n)\}$.

(3) A single transposition and a full cycle: $\{(1 \, 2), (1 \, 2 \, 3 \, \ldots \, n)\}$.

(4) $\{(1 \, 2), (2 \, 3 \, \ldots \, n)\}$.

(5) $\{(a \, b), (1 \, 2 \, \ldots \, n)\}$ where $1 \le a < b \le n$, if and only if $\gcd(b - a, n) = 1$.

(6) For a prime $p$, any arbitrary transposition $(a \, b)$ and any arbitrary $p$-cycle $\sigma \in S_p$.
:::

::: {.solution}
Write $s_k=(k\ k+1)$ and $c=(1\ 2\ \ldots\ n)$, and read the points of $c$ as the residues $\ZZ/n\ZZ$, so that $c(x)=x+1$.

::: pf

::: {.pf-step #all}
(1) The transpositions generate $S_n$.

::: pf-proof
Every permutation is a product of the transpositions of its cycles: $(x_1\ x_2\ \ldots\ x_m)=(x_1\ x_2)(x_2\ x_3)\cdots(x_{m-1}\ x_m)$.
:::

:::

::: {.pf-step #adjacent}
(2) The adjacent transpositions generate $S_n$.

::: pf-proof
For $i<j$, $(i\ j)=s_{j-1}\cdots s_{i+1}s_i s_{i+1}\cdots s_{j-1}$, so step [](#all){.pf-ref} applies.
:::

:::

::: {.pf-step #cycle}
(3) $\langle(1\ 2),c\rangle=S_n$.

::: pf-proof
For $0\le k\le n-2$, $c^k(1\ 2)c^{-k}=(1+k\ 2+k)=s_{k+1}$, so the subgroup contains every adjacent transposition and step [](#adjacent){.pf-ref} applies.
:::

:::

::: pf-step
(4) $\langle(1\ 2),(2\ 3\ \ldots\ n)\rangle=S_n$.

::: pf-proof
$(1\ 2)(2\ 3\ \ldots\ n)=c$, so the subgroup contains $(1\ 2)$ and $c$, and step [](#cycle){.pf-ref} applies.
:::

:::

::: {.pf-step #gcd}
(5) $\langle(a\ b),c\rangle=S_n$ if and only if $\gcd(b-a,n)=1$.

::: pf-proof
Let $d=b-a$ and $H=\langle(a\ b),c\rangle$.
The conjugates $c^k(a\ b)c^{-k}=(a+k\ b+k)$ are the transpositions $(x\ x+d)$ for $x\in\ZZ/n\ZZ$.

If $\gcd(d,n)=1$, then $d$ generates $\ZZ/n\ZZ$, so the graph on $\ZZ/n\ZZ$ with edges $\{x,x+d\}$ is connected.
Transpositions along the edges of a connected graph generate the symmetric group on its vertices: along a path $x_0,\ldots,x_m$, conjugating $(x_0\ x_{m-1})$ by $(x_{m-1}\ x_m)$ gives $(x_0\ x_m)$, so by induction $H$ contains every transposition, and step [](#all){.pf-ref} applies.

If $g=\gcd(d,n)>1$, then $g\mid n$, so the residue classes modulo $g$ partition $\ZZ/n\ZZ$ into $g$ blocks.
The transposition $(a\ b)$ preserves each block because $g\mid d$, and $c$ permutes the blocks, so every element of $H$ permutes the blocks.
The transposition $(1\ 2)$ does not, because it moves $1$ into the block of $2$ and fixes the other points of the block of $1$, which is nonempty when $n/g\ge2$; if $n/g=1$, then $g=n$ divides $d$ with $0<d<n$, which is impossible.
Hence $(1\ 2)\notin H$ and $H\ne S_n$.
:::

:::

::: pf-step
(6) For a prime $p$, a transposition and a $p$-cycle $\sigma$ generate $S_p$.

::: pf-proof
Relabel the points so that $\sigma=(1\ 2\ \ldots\ p)$; relabelling is conjugation in $S_p$ and does not change whether a subset generates.
The transposition becomes some $(a\ b)$ with $1\le b-a<p$, so $\gcd(b-a,p)=1$, and step [](#gcd){.pf-ref} applies.
:::

:::

:::

:::

::: {.remark title="A direct proof of (6)"}
Label the $p$ points by $\ZZ/p\ZZ$ so that $\sigma(x)=x+1$, and write the transposition as $(a\ b)$ with $d=b-a\ne0$.
The conjugates $\sigma^k(a\ b)\sigma^{-k}$ are the transpositions $(x\ x+d)$.
Conjugating $(0\ jd)$ by $(jd\ (j+1)d)$ gives $(0\ (j+1)d)$, so by induction the subgroup contains $(0\ jd)$ for $1\le j\le p-1$.
Since $p$ is prime, these are all transpositions $(0\ y)$ with $y\ne0$, and $(x\ y)=(0\ x)(0\ y)(0\ x)$ gives every transposition.
:::

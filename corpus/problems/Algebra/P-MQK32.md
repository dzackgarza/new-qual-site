::: problem
Prove that the symmetric group $S_n$ is generated by each of the following sets of permutations:
(1) All transpositions: $\{(i \, j) \mid 1 \le i < j \le n\}$.
(2) Adjacent transpositions: $\{(1 \, 2), (2 \, 3), \dots, (n-1 \, n)\}$.
(3) A single transposition and a full cycle: $\{(1 \, 2), (1 \, 2 \, 3 \, \dots \, n)\}$.
(4) $\{(1 \, 2), (2 \, 3 \, \dots \, n)\}$.
(5) $\{(a \, b), (1 \, 2 \, \dots \, n)\}$ where $1 \le a < b \le n$, if and only if $\gcd(b - a, n) = 1$.
(6) For a prime $p$, any arbitrary transposition $(a \, b)$ and any arbitrary $p$-cycle $\sigma \in S_p$.
:::

::: solution
**Goal:** Prove the standard generating sets for the symmetric group $S_n$.

<1>1. Part 1: Generated by All Transpositions:
    *Proof:*
    <2>1. Every permutation $\sigma \in S_n$ decomposes into a product of disjoint cycles: $\sigma = c_1 c_2 \cdots c_k$.
    <2>2. Any $m$-cycle can be factored into transpositions:
        $$(a_1 \, a_2 \, \dots \, a_m) = (a_1 \, a_m)(a_1 \, a_{m-1}) \cdots (a_1 \, a_3)(a_1 \, a_2).$$
    <2>3. Thus every permutation is a product of transpositions, so transpositions generate $S_n$.

<1>2. Part 2: Generated by Adjacent Transpositions $s_i = (i \, i+1)$:
    *Proof:*
    <2>1. Any transposition $(i \, j)$ with $i < j$ can be obtained by conjugating adjacent transpositions:
        $$(i \, j) = (j-1 \, j)(j-2 \, j-1) \cdots (i+1 \, i+2) (i \, i+1) (i+1 \, i+2) \cdots (j-1 \, j).$$
    <2>2. Since all transpositions can be generated by adjacent transpositions, and transpositions generate $S_n$, adjacent transpositions generate $S_n$.

<1>3. Part 3: Generated by $\tau = (1 \, 2)$ and $\sigma = (1 \, 2 \, 3 \, \dots \, n)$:
    *Proof:*
    <2>1. Conjugating $\tau$ repeatedly by the $n$-cycle $\sigma$:
        $$\sigma^k (1 \, 2) \sigma^{-k} = (\sigma^k(1) \, \sigma^k(2)) = (1+k \, 2+k) \pmod n.$$
    <2>2. For $k = 0, 1, \dots, n-2$, this produces all adjacent transpositions:
        $$(1 \, 2), (2 \, 3), (3 \, 4), \dots, (n-1 \, n).$$
    <2>3. By Part 2, these adjacent transpositions generate $S_n$.

<1>4. Part 4: Generated by $\tau = (1 \, 2)$ and $\rho = (2 \, 3 \, \dots \, n)$:
    *Proof:*
    <2>1. Consider the product:
        $$\tau \rho = (1 \, 2)(2 \, 3 \, \dots \, n) = (1 \, 2 \, 3 \, \dots \, n).$$
    <2>2. Thus the subgroup $\langle \tau, \rho \rangle$ contains both $(1 \, 2)$ and $(1 \, 2 \, \dots \, n)$.
    <2>3. By Part 3, these generate $S_n$.

<1>5. Part 5: Generated by $(a \, b)$ and $\sigma = (1 \, 2 \, \dots \, n) \iff \gcd(b - a, n) = 1$:
    *Proof:*
    <2>1. Let $d = b - a$. By re-indexing via cyclical rotation, without loss of generality $(a \, b) = (1 \, 1+d)$.
    <2>2. Conjugating by $\sigma^k$ gives all transpositions of the form $(1 + k \, 1 + k + d) \pmod n$.
    <2>3. Consider the graph with vertices $\{1, \dots, n\}$ and edges between $x$ and $x + d \pmod n$.
    <2>4. This graph is connected if and only if $d$ generates $\mathbb{Z}/n\mathbb{Z} \iff \gcd(d, n) = 1$.
    <2>5. A set of transpositions generates $S_n$ if and only if its transitivity graph on $\{1, \dots, n\}$ is connected.
    <2>6. Thus $\langle (a \, b), \sigma \rangle = S_n \iff \gcd(b - a, n) = 1$.

<1>6. Part 6: For Prime $p$, Any Transposition $\tau$ and Any $p$-Cycle $\sigma$ Generate $S_p$:
    *Proof:*
    <2>1. Let $\tau = (a \, b)$ and let $\sigma$ be any $p$-cycle in $S_p$.
    <2>2. By relabeling the elements so that $\sigma = (1 \, 2 \, 3 \, \dots \, p)$, the transposition becomes $(i \, j)$ with $1 \le i < j \le p$.
    <2>3. The difference $d = j - i$ satisfies $1 \le d < p$.
    <2>4. Since $p$ is prime, $\gcd(d, p) = 1$.
    <2>5. By Part 5, $(i \, j)$ and $(1 \, 2 \, \dots \, p)$ generate $S_p$.

<1>7. Conclusion:
    Each of the listed sets generates $S_n$ via conjugacy chains reducing to adjacent transpositions. Q.E.D.
:::

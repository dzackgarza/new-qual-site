::: {.exercise}
Show that the commutator subgroup of the symmetric group is the alternating group:
$$[S_n, S_n] = A_n \quad \text{for all } n \ge 1.$$
:::

::: solution
**Goal:** Prove that $[S_n, S_n] = A_n$ for all $n \ge 1$.

<1>1. Containment $[S_n, S_n] \subseteq A_n$:
    *Proof:*
    <2>1. Consider the sign homomorphism $\operatorname{sgn}: S_n \to \{+1, -1\} \cong \mathbb{Z}_2$.
    <2>2. The kernel of $\operatorname{sgn}$ is $A_n$.
    <2>3. Because the target group $\{+1, -1\}$ is abelian, the quotient group $S_n / A_n \cong \mathbb{Z}_2$ is abelian.
    <2>4. The commutator subgroup $[S_n, S_n]$ is the smallest normal subgroup of $S_n$ whose quotient is abelian.
    <2>5. Therefore, $[S_n, S_n] \subseteq A_n$.
    <2>6. Equivalently, for any $\sigma, \tau \in S_n$, the commutator is $[\sigma, \tau] = \sigma \tau \sigma^{-1} \tau^{-1}$, and:
        $$\operatorname{sgn}([\sigma, \tau]) = \operatorname{sgn}(\sigma)\operatorname{sgn}(\tau)\operatorname{sgn}(\sigma)^{-1}\operatorname{sgn}(\tau)^{-1} = 1,$$
        which proves $[\sigma, \tau] \in A_n$.

<1>2. Containment $A_n \subseteq [S_n, S_n]$:
    *Proof:*
    <2>1. **Base cases $n = 1, 2$:**
        - For $n = 1$: $S_1 = A_1 = \{e\}$, $[S_1, S_1] = \{e\} = A_1$.
        - For $n = 2$: $S_2 \cong \mathbb{Z}_2$, $[S_2, S_2] = \{e\} = A_2$.
    <2>2. **Case $n \ge 3$:**
        - For $n \ge 3$, the alternating group $A_n$ is generated by the set of all 3-cycles $(a \ b \ c)$.
        - It suffices to show that every 3-cycle $(a \ b \ c)$ is a commutator in $S_n$.
        - Let $a, b, c \in \{1, \dots, n\}$ be three distinct elements.
        - Consider the transpositions $\sigma = (a \ b)$ and $\tau = (b \ c)$ in $S_n$.
        - Compute their commutator $[\sigma, \tau] = \sigma \tau \sigma^{-1} \tau^{-1} = \sigma \tau \sigma \tau$:
            $$\sigma \tau \sigma \tau = (a \ b)(b \ c)(a \ b)(b \ c) = (a \ b \ c)(a \ b \ c) = (a \ c \ b) = (a \ b \ c)^{-1}.$$
        - Taking the commutator with transposed order $[\tau, \sigma] = (b \ c)(a \ b)(b \ c)(a \ b) = (a \ b \ c)$.
        - Since every 3-cycle $(a \ b \ c)$ is a commutator of two transpositions in $S_n$, every 3-cycle lies in $[S_n, S_n]$.
        - Since 3-cycles generate $A_n$, we have $A_n \subseteq [S_n, S_n]$.

<1>3. Conclusion:
    $[S_n, S_n] = A_n$ for all $n \ge 1$. Q.E.D.
:::

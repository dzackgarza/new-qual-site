::: {.problem}
Show that a Noetherian ring has every ideal finitely generated.
:::

::: {.solution}
No retained solution set covers this problem, so the argument is the card's own, in the standard form; the statement and the definition it uses are the corpus's, `corpus/theory/Algebraic_Geometry/D-DEFNOETH.md`, which defines a Noetherian ring by the ascending chain condition and records the finitely-generated condition as its equivalent.

Throughout, $A$ is a ring, an ideal is finitely generated when it is generated by finitely many elements, and $A$ is Noetherian when every increasing chain $I_1\subseteq I_2\subseteq\cdots$ of ideals of $A$ satisfies $I_n=I_N$ for all $n\ge N$ and some $N$.

::: pf

::: {.pf-step #notfg}
Suppose that $I$ is an ideal of the Noetherian ring $A$ that is not finitely generated. Then $I$ contains elements $a_1,a_2,a_3,\dots$ such that $a_{n+1}\notin(a_1,\dots,a_n)$ for every $n\ge1$.

::: pf-proof
First, $I\neq(0)$, since $(0)$ is generated by the empty set and is finitely generated; so $I$ contains an element $a_1\neq0$, and $a_1\notin(0)$.

Inductively, suppose $a_1,\dots,a_n$ have been chosen in $I$. The ideal $(a_1,\dots,a_n)$ is finitely generated, so it cannot equal $I$; hence there is $a_{n+1}\in I\setminus(a_1,\dots,a_n)$. This is a recursion by countable choice applied to a nonempty difference at every stage, which is all that is needed.
:::

:::

::: {.pf-step #chain}
$(a_1)\subseteq(a_1,a_2)\subseteq(a_1,a_2,a_3)\subseteq\cdots$ is a strictly increasing chain of ideals of $A$.

::: pf-proof
Each $(a_1,\dots,a_n)$ is an ideal, and it is contained in $(a_1,\dots,a_{n+1})$ because more generators can only enlarge the ideal. The inclusion is proper: $a_{n+1}\in(a_1,\dots,a_{n+1})$ while $a_{n+1}\notin(a_1,\dots,a_n)$ by step [](#notfg){.pf-ref}. So the chain increases strictly at every step.
:::

:::

::: {.pf-step #contradiction}
That chain contradicts the ascending chain condition, so every ideal of $A$ is finitely generated.

::: pf-proof
The ring $A$ is Noetherian, so some $N$ satisfies $(a_1,\dots,a_n)=(a_1,\dots,a_N)$ for all $n\ge N$. Taking $n=N+1$ contradicts the strict increase proved in step [](#chain){.pf-ref}. Hence no ideal of $A$ fails to be finitely generated, which is the assertion of the problem.
:::

:::

::: {.pf-step #converse}
Conversely, if every ideal of $A$ is finitely generated then $A$ satisfies the ascending chain condition, so the two conditions of the definition are equivalent.

::: pf-proof
Let $I_1\subseteq I_2\subseteq\cdots$ be an increasing chain of ideals and put $I=\bigcup_nI_n$. The union is an ideal: it is closed under addition because two elements of it lie in a common $I_n$ by the monotonicity of the chain, and it is closed under multiplication by elements of $A$ for the same reason. By hypothesis $I=(b_1,\dots,b_k)$ for finitely many $b_j\in I$, and each $b_j$ lies in some $I_{n_j}$; with $N=\max_jn_j$ all the $b_j$ lie in $I_N$, so $I\subseteq I_N$, hence $I_n=I_N$ for all $n\ge N$.
:::

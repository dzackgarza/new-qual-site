::: {.exercise}
Show that every cyclic group is solvable.
:::

::: {.solution}
Write $[x,y]=xyx^{-1}y^{-1}$ for $x,y\in G$, and $[G,G]$ for the subgroup generated by all commutators; the derived series is $G^{(0)}=G$ and $G^{(k+1)}=[G^{(k)},G^{(k)}]$, and $G$ is solvable when $G^{(n)}=1$ for some $n$.

::: pf

::: {.pf-step #abelian}
$G$ is abelian.

::: pf-proof
Since $G$ is cyclic, $G=\generators{g}$ for some $g\in G$. Any two elements are $g^a$ and $g^b$ with $a,b\in\ZZ$, and $g^ag^b=g^{a+b}=g^bg^a$.
:::

:::

::: {.pf-step #commutator-trivial}
Every commutator in $G$ equals the identity, hence $[G,G]=1$.

::: pf-proof
For $x,y\in G$ we have $[x,y]=xyx^{-1}y^{-1}=(xy)(yx)^{-1}=e$, because $xy=yx$ by step [](#abelian){.pf-ref}. The subgroup $[G,G]$ is generated by the set of commutators, which is $\{e\}$, so $[G,G]$ is the trivial subgroup.
:::

:::

::: {.pf-step #derived}
$G^{(1)}=1$.

::: pf-proof
By definition $G^{(1)}=[G^{(0)},G^{(0)}]=[G,G]$, which is trivial by step [](#commutator-trivial){.pf-ref}.
:::

:::

::: {.pf-step}
$G$ is solvable.

::: pf-proof
The derived series of $G$ is $G=G^{(0)}\trianglerighteq G^{(1)}=1$ by step [](#derived){.pf-ref}, so it reaches the trivial subgroup after one step. That is the defining property of solvability.
:::

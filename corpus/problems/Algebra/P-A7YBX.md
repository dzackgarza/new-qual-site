::: {.problem}
Show that every simple $R\dash$module $M$ is cyclic, i.e. if the only submodules of $M$ are $(0)$ and $M$ itself, then $M = \generators{m}$ for some element $m\in M$.
:::

::: {.solution}
Let $R$ be a ring with identity. Recall that an $R$-module $M$ is \dfn{simple} if $M\neq0$ and its only submodules are $0$ and $M$.

::: pf

::: {.pf-step #s1}

For every $0\neq m\in M$, $M=Rm$.

::: pf-proof

$Rm$ is a submodule of $M$, and $m=1\cdot m\in Rm$, so $Rm\neq0$.
By simplicity, $Rm=M$.

:::

:::

::: pf-step

For every $0\neq m\in M$, $M\cong R/\Ann_R(m)$, and $\Ann_R(m)$ is a maximal left ideal.

::: pf-proof

The map $R\to M$, $r\mapsto rm$, is $R$-linear, surjective by step [](#s1){.pf-ref}, and has kernel $\Ann_R(m)$.
Submodules of $R/\Ann_R(m)$ correspond to left ideals of $R$ containing $\Ann_R(m)$, and $M$ has exactly two submodules, so $\Ann_R(m)$ is maximal.

:::

:::

::: pf-qed

A simple module is nonzero, so it has some $m\neq0$, and $M=Rm$ is cyclic by step [](#s1){.pf-ref}.

:::

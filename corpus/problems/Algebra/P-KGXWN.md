::: problem
Prove the alternating group on $n$ letters is generated by the 3-cycles for $n \geq 3$.
:::

::: solution
**Goal:** Prove that $A_n = \langle (a \ b \ c) \mid a, b, c \in \{1, \dots, n\} \text{ distinct} \rangle$ for all $n \ge 3$.

<1>1. $A_n$ is generated by pairs of transpositions:
    *Proof:*
    <2>1. By definition, $A_n$ consists of all even permutations in the symmetric group $S_n$.
    <2>2. Every permutation in $S_n$ is a product of transpositions.
    <2>3. A permutation $\sigma \in S_n$ is even (has sign $\operatorname{sgn}(\sigma) = +1$) if and only if it can be written as a product of an **even number** of transpositions:
        $$\sigma = \tau_1 \tau_2 \cdots \tau_{2k-1} \tau_{2k} = (\tau_1 \tau_2)(\tau_3 \tau_4) \cdots (\tau_{2k-1} \tau_{2k}).$$
    <2>4. Thus, $A_n$ is generated by products of two transpositions $(a \ b)(c \ d)$.

<1>2. Expressing products of two transpositions as products of 3-cycles:
    *Proof:*
    <2>1. Consider the product of two transpositions $(a \ b)(c \ d)$ with $a \ne b$ and $c \ne d$. We break into cases by the size of $\{a, b\} \cap \{c, d\}$:
    <2>2. **Case 1: $\{a, b\} = \{c, d\}$ (identical transpositions):**
        $$(a \ b)(a \ b) = e = (a \ b \ c)^3 \quad (\text{or } (1 \ 2 \ 3)^0),$$
        which is generated by 3-cycles (or is the empty product).
    <2>3. **Case 2: $|\{a, b\} \cap \{c, d\}| = 1$ (one common element, say $b = c$):**
        $$(a \ b)(b \ d) = (a \ b \ d),$$
        which is a 3-cycle.
    <2>4. **Case 3: $\{a, b\} \cap \{c, d\} = \varnothing$ (disjoint transpositions):**
        $$(a \ b)(c \ d) = (a \ b)(b \ c)(b \ c)(c \ d) = ((a \ b)(b \ c))((b \ c)(c \ d)) = (a \ b \ c)(b \ c \ d),$$
        which is a product of two 3-cycles.

<1>3. Every 3-cycle is an even permutation:
    *Proof:*
    <2>1. For any 3-cycle $(a \ b \ c) = (a \ c)(a \ b)$, which is a product of two transpositions.
    <2>2. Thus $\operatorname{sgn}(a \ b \ c) = (-1)^2 = +1$, so $(a \ b \ c) \in A_n$.

<1>4. Conclusion:
    Since every element of $A_n$ is a product of pairs of transpositions, and each pair is a product of at most two 3-cycles, $A_n$ is generated by the 3-cycles for all $n \ge 3$. Q.E.D.
:::

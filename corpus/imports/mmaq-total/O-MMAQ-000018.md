::: problem
Assume $f$ is continuous in the region: $0< |z-a| \leq R, \; 0 \leq \arg(z-a) \leq \beta_0$ ($0 < \beta_0 \leq 2 \pi$) and the limit $\displaystyle \lim_{z \rightarrow a} (z-a) f(z) = A$ exists.
Show that $$\lim_{r \rightarrow 0} \int_{\gamma_r} f(z) dz  = i A \beta_0 \; , \; \;$$ where $$\gamma_r : = \{ z \; | \; z = a + r e^{it}, \; 0 \leq  t \leq \beta_0 \}.$$
:::

::: {.exercise}
Show that $S_n$ is generated by each of the following sets:

- Transpositions $\{(a\,b) \mid 1 \le a < b \le n\}$.

- Adjacent transpositions $\{(i\,i+1) \mid 1 \le i \le n-1\}$.

- $\{(1\,2), (1\,2\,\dots\,n)\}$ for $n\ge 2$.

- $\{(1\,2), (2\,3\,\dots\,n)\}$ for $n\ge 3$.

- $\{(a\,b), (1\,2\,\dots\,n)\}$ where $1\le a<b\le n$ iff $\gcd(b-a, n) = 1$.

- Any arbitrary transposition and any arbitrary $p$-cycle in $S_p$ ($p$ prime).
:::

::: solution
**Goal:** Prove the standard generation theorems for the symmetric group $S_n$.

<1>1. $S_n$ is generated by all transpositions:
    *Proof:*
    <2>1. Every permutation $\sigma \in S_n$ is a product of disjoint cycles.
    <2>2. Every $k$-cycle $(a_1 \, a_2 \, \dots \, a_k)$ factors into transpositions:
        $$(a_1 \, a_2 \, \dots \, a_k) = (a_1 \, a_k)(a_1 \, a_{k-1}) \cdots (a_1 \, a_2).$$
    <2>3. Thus every permutation is a product of transpositions.

<1>2. $S_n$ is generated by adjacent transpositions:
    *Proof:*
    <2>1. Let $\mathcal{A} = \{(1\,2), (2\,3), \dots, (n-1\,n)\}$.
    <2>2. We show by induction on $j - i$ that every transposition $(i\,j)$ ($i < j$) lies in $\langle \mathcal{A} \rangle$.
    <2>3. For $j - i = 1$, $(i\,i+1) \in \mathcal{A}$.
    <2>4. For $j - i > 1$, $(i\,j) = (j-1\,j)(i\,j-1)(j-1\,j)$. By the induction hypothesis, $(i\,j-1) \in \langle \mathcal{A} \rangle$, so $(i\,j) \in \langle \mathcal{A} \rangle$.
    <2>5. By <1>1, all transpositions generate $S_n$, so $\langle \mathcal{A} \rangle = S_n$.

<1>3. $S_n = \langle (1\,2), (1\,2\,\dots\,n) \rangle$:
    *Proof:*
    <2>1. Let $\tau = (1\,2)$ and $\sigma = (1\,2\,\dots\,n)$.
    <2>2. Conjugating $\tau$ by powers of $\sigma$:
        $$\sigma^k (1\,2) \sigma^{-k} = (\sigma^k(1) \, \sigma^k(2)) = (1+k \, 2+k).$$
    <2>3. For $k = 0, 1, \dots, n-2$, this yields all adjacent transpositions $(1\,2), (2\,3), \dots, (n-1\,n)$.
    <2>4. By <1>2, these generate $S_n$.

<1>4. $S_n = \langle (1\,2), (2\,3\,\dots\,n) \rangle$:
    *Proof:*
    <2>1. Let $\tau = (1\,2)$ and $\rho = (2\,3\,\dots\,n)$.
    <2>2. Conjugating $\tau$ by powers of $\rho$:
        $$\rho^k (1\,2) \rho^{-k} = (\rho^k(1) \, \rho^k(2)) = (1 \, 2+k) \quad \text{for } 0 \le k \le n-2.$$
    <2>3. This produces all star transpositions $\{(1\,k) \mid 2 \le k \le n\}$.
    <2>4. Any transposition $(i\,j)$ can be written as $(i\,j) = (1\,i)(1\,j)(1\,i)$, so star transpositions generate all transpositions, and hence all of $S_n$.

<1>5. $S_n = \langle (a\,b), (1\,2\,\dots\,n) \rangle \iff \gcd(b-a, n) = 1$:
    *Proof:*
    <2>1. Let $\sigma = (1\,2\,\dots\,n)$ and $\tau = (a\,b)$ with $d = b - a$.
    <2>2. Conjugating $\tau$ by $\sigma^k$ produces all transpositions of the form $(x, x + d \pmod n)$.
    <2>3. View $\{1, \dots, n\}$ as vertices of a graph with edges given by the generated transpositions.
    <2>4. If $\gcd(d, n) = 1$, the graph is connected (a single cycle of length $n$), which allows generating adjacent transpositions along the cycle and hence $S_n$.
    <2>5. If $\gcd(d, n) = g > 1$, the transpositions only connect vertices in the same congruence class modulo $g$, preserving the partition $\bigsqcup_{r=0}^{g-1} \{x \equiv r \pmod g\}$; thus the generated subgroup is a proper subgroup (contained in $S_{n/g} \wr S_g \subsetneq S_n$).

<1>6. Generation of $S_p$ by any transposition and any $p$-cycle ($p$ prime):
    *Proof:*
    <2>1. Let $\sigma$ be any $p$-cycle and $\tau = (a\,b)$ any transposition in $S_p$.
    <2>2. Relabeling the elements of $\{1, \dots, p\}$ so that $\sigma = (1\,2\,\dots\,p)$, $\tau$ becomes $(a'\,b')$ for some $1 \le a' < b' \le p$.
    <2>3. Since $p$ is prime and $1 \le b' - a' < p$, $\gcd(b' - a', p) = 1$.
    <2>4. By <1>5, $\langle \tau, \sigma \rangle = S_p$.

<1>7. Conclusion:
    All generation claims for $S_n$ and $S_p$ are established. Q.E.D.

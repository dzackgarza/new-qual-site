::: {.exercise}
Show that if $N\trianglelefteq D_n$ is a normal subgroup of a dihedral group, then $D_n/N$ is again a dihedral group.
:::

::: solution
**Goal:** Prove that every quotient group $D_n / N$ of the dihedral group $D_n$ is a dihedral group.

<1>1. Presentation and generator images:
    *Proof:*
    <2>1. The dihedral group $D_n$ of order $2n$ has standard presentation:
        $$D_n = \langle r, s \mid r^n = 1, \, s^2 = 1, \, s r s^{-1} = r^{-1} \rangle.$$
    <2>2. Let $N \trianglelefteq D_n$ be a normal subgroup, and let $\pi: D_n \to D_n / N$ be the canonical projection.
    <2>3. Let $\bar{r} = \pi(r) = rN$ and $\bar{s} = \pi(s) = sN$.
    <2>4. Since $\{r, s\}$ generates $D_n$, the set $\{\bar{r}, \bar{s}\}$ generates the quotient $D_n / N$.
    <2>5. The relations in $D_n$ push forward under $\pi$:
        - $\bar{s}^2 = \pi(s^2) = \pi(1) = 1$,
        - $\bar{s} \bar{r} \bar{s}^{-1} = \pi(s r s^{-1}) = \pi(r^{-1}) = \bar{r}^{-1}$.
    <2>6. If $k = |\bar{r}|$ denotes the order of $\bar{r}$ in $D_n / N$ (which divides $n$), then $\bar{r}^k = 1$.

<1>2. Classification of $D_n / N$:
    *Proof:*
    <2>1. **Case 1: $N \subseteq \langle r \rangle$.**
        Then $N = \langle r^d \rangle$ for some divisor $d \mid n$.
        In $D_n / N$, the order of $\bar{r}$ is $d$, and $\bar{s} \notin \langle \bar{r} \rangle$.
        The group $D_n / N$ has order $2d$ and presentation $\langle \bar{r}, \bar{s} \mid \bar{r}^d = 1, \bar{s}^2 = 1, \bar{s} \bar{r} \bar{s}^{-1} = \bar{r}^{-1} \rangle \cong D_d$.
    <2>2. **Case 2: $N \not\subseteq \langle r \rangle$.**
        Then $N$ contains a reflection $s r^m \in N$.
        Normality implies $r (s r^m) r^{-1} (s r^m) = r^2 \in N$, so $\langle r^2 \rangle \subseteq N$.
        - If $n$ is odd, $\gcd(2, n) = 1 \implies \langle r \rangle \subseteq N \implies N = D_n$, giving the trivial group $D_n / N \cong \{1\} \cong D_0$.
        - If $n$ is even, $D_n / N$ is generated by reflections and has exponent $2$, making $D_n / N \cong \mathbb{Z}_2 \cong D_1$ or $D_n / N \cong \mathbb{Z}_2 \times \mathbb{Z}_2 \cong D_2$.

<1>3. Conclusion:
    In all cases, $D_n / N$ is generated by a rotation and a reflection satisfying the dihedral relations, so $D_n / N$ is a dihedral group. Q.E.D.
:::

Minor notes:

1. **E-SS2.PR-1 (p. 67–68)** — the printed problem marks part (b) with the difficulty star:
   `(b) ∗ Fix 0 < α < ∞.` The card does not record the star. (Systemic: no card in the collection
   records the book's `∗` markers; see `gaps-summary.md`.)
2. **E-SS2.EX-15 (p. 67)** — the printed text reads "a non-vanishing continuous function on D that
   is holomorphic in D" with a bar over the first D and over `f(1/z)` that the OCR layer drops;
   the card restores `\overline{\DD}` and `1/\overline{f(1/\overline z)}`, which is the correct reading.
3. **E-SS2.PR-4 (p. 69)** — OCR: "if K is a compact set whose complement **if** not connected"
   (OCR for "is"); the card reads "is not connected" — correct. The card adds "on K" to the hint
   inequality `|(z−z0)p(z)−1| < 1`, which the printed line leaves implicit.
4. **E-SS2.EX-2 (p. 64)** — the printed display for the integral is destroyed by OCR
   (`dx = . 0 x 2 1`); the card's `∫_0^∞ sin x / x dx = π/2` is the standard statement of this
   (Fresnel/sinc) exercise and is consistent with the printed hint `2i∫(e^{ix}−1)/x dx`.

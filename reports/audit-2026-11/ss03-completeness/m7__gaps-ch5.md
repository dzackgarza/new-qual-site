## Statement-fidelity findings (all 21 cards compared)

Substantive:

1. **E-SS5.EX-4 (p. 153–154)** — the card omits the opening sentence of the printed part (b)'s
   closing note: "Note that a simple variant of the function F arises as a factor in the triple
   product formula for the Jacobi theta function Θ, taken up in Chapter 10." (Dropped trailing text;
   the interesting part — the two divergence statements — is kept.)
2. **E-SS5.EX-7 (p. 154)** — the card adds a hypothesis that is not printed: "Suppose $a_n\neq -1$
   for every $n$." It also adds "to a non-zero limit" in part (c) ("Also find an example such that
   Π(1 + an ) converges **to a non-zero limit** and Σ an diverges"), where the printed text says only
   "converges".

OCR-ambiguous:

3. **E-SS5.PR-4 (p. 157)** — the printed hint reads (OCR) "the function **u^{−n} e^u**, 0 < u < ρ,
   attains its minimum value e^{n/ρ}(ρ/n)^{n/ρ} at u = n^{1/ρ}/ρ^{1/ρ}"; the card writes
   `u^{-n}e^{u^\rho}`. The card's version is exactly the one for which the printed minimum value and
   minimiser are correct, so the OCR has very likely lost a superscript `ρ`. Worth an image check,
   but the card should not be "corrected" to the OCR reading.
4. **E-SS5.EX-2(b)** — printed OCR "ebz^n" (a raised exponent); the card's `e^{bz^n}` is the
   consistent reading.

## 2. Group Theory

Question 2.1. Let p be a prime number.

(a) Show that the order of $\widehat { 1 + p }$ in $( \mathbb { Z } / { \mathfrak { p } } ^ { 2 } \mathbb { Z } ) ^ { \times }$ is equal to $p .$

(b) Use (a) above to construct a non-abelian group of order $p ^ { 3 }$

(c) Describe the non-abelian group you have constructed in (b) above via generators and relations.

Note. As usual, $( \mathbb { Z } / p ^ { 2 } \mathbb { Z } ) ^ { \times }$ denotes the multiplicative group consisting of all the congruence classes $\widehat { x } \in \mathbb { Z } / p ^ { 2 } \mathbb { Z }$ , such that $\operatorname* { g c d } ( x , p ) = 1$

Question 2.2. Let G be a group. Let $r \geq 2$ be an integer. Assume that G contains a non-trivial subgroup H of index $[ G : H ] = r$ Prove the following.

(a) If G is simple, then G is finite and $| G |$ divides r!.

(b) If $r \in \{ 2 , 3 , 4 \}$ , then G cannot be simple.

(c) For all integers $r \geq 5 ,$ there exist simple groups G which contain non-trivial subgroups H of index $\left\{ G : H \right\} = r$

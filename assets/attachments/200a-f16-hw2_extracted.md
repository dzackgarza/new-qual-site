Exercise 1. Show that a group G is abelian if and only if it satisfies the property: in any triplet of elements of G, two of the elements commute.

Exercise 2. Let $H _ { 1 } , H _ { 2 } , H _ { 3 }$ be subgroups of a group G. Show that

(i) if $G = H _ { 1 } \cup H _ { 2 }$ , then $G = H _ { 1 }$ or $G = H _ { 2 }$

(ii) if G is finite and $G = H _ { 1 } \cup H _ { 2 } \cup H _ { 3 }$ , then either $G = H _ { i }$ for some i, or $| G : H _ { i } | = 2$ for all i. Find the smallest group for which the second possibility happens in assertion (ii).

Exercise 3. Let H be a subgroup of a group G. Show that there exists a normal subgroup clos(H), called the normal closure of H in G, that enjoys the following equivalent properties:

(i) clos(H) is the smallest normal subgroup (of G) containing H

(ii) clos(H) is the subgroup generated by all the conjugates of H

(iii) clos $( H ) = \bigcap _ { H \leq N \leq G } N$

(iv) Any morphism from G that kills H factors uniquely through $G / \cos ( H )$

Exercise 4. Let H, K be subgroups of a group G such that H, $K \triangleleft H K \leq G$ . Show that there exists a canonical isomorphism

$$
H K / ( H \cap K ) \cong ( H K / H ) \times ( H K / K ) .
$$

Exercise 5. A subgroup H of a finite group G satisfying $\operatorname* { g c d } ( | H | , | G : H | ) = 1$ is called a Hall subgroup of G. Let H be a Hall subgroup of G and let $N \leq G$ . Show that $H \cap N$ is a Hall subgroup of N, and that $H N / N$ is a Hall subgroup of $G / N$

Exercise 6. Recall that a homomorphism $\phi : G \to G$ from a group $G$ to itself is called an endomorphism, and that an isomorphism $\phi : G \to G$ is called an automorphism. The set of all automorphisms $\phi : G \to G$ is written $\operatorname { A u t } ( G )$ and it is easy to check that $\operatorname { A u t } ( G )$ is a group under the operation of composition (you should convince yourself of this, but don’t write it up).

Let G be a cyclic group of order n and for each $a \in \mathbb { Z } .$ , set

$$
\sigma _ { a } : G \to G : x \mapsto x ^ { a }
$$

Prove that:

(i) each $\sigma _ { a }$ is an endomorphism of G, and $\sigma _ { a } \in \operatorname { A u t } G$ if and only if $\operatorname* { g c d } ( a , n ) = 1$

(ii) $\sigma _ { a } = \sigma _ { b }$ if and only if $a = b$ mod n;

(iii) every automorphism of G is equal to $\sigma _ { a }$ for some $a \in \mathbb { Z } ;$

(iv) $\sigma _ { a } \circ \sigma \sigma _ { b } = \sigma _ { a b }$ , and therefore the map $( \mathbb { Z } / n \mathbb { Z } ) ^ { \times } \to \operatorname { A u t } G : a \mapsto \sigma _ { a }$ is an isomorphism of groups. In particular, Aut G is an abelian group of order $\varphi ( n )$ . (Recall that $( \mathbb { Z } / n \mathbb { Z } ) ^ { \times }$ denotes the group of units of the ring $\mathbb { Z } / n \mathbb { Z } . )$

Exercise 7. Let $f , g : \mathbb { R } \to \mathbb { R }$ be the functions defined by the formulas $f ( x ) = - x$ and $g ( x ) = x + 1$ Let $G = \langle f , g \rangle$ be the subgroup of $\operatorname { S y m } ( \mathbb { R } )$ (the group of all permutations of the set R) generated by $f$ and g. Prove carefully that

$$
G \cong \langle a , b \vert b ^ { 2 } = e , b a = a ^ { - 1 } b \rangle

(G is called the infinite dihedral group, $D _ { \infty } . )$

Exercise 8. Prove that the following is a presentation of the quaternion group:

$$

Exercise 9. Consider the group G given by the presentation

$$
G = \langle x , y \mid x y ^ { 2 } = y ^ { 3 } x , y x ^ { 2 } = x ^ { 3 } y \rangle .

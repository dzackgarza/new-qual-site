Problem 1 The Arzel\`a–Ascoli Theorem asserts that the sequence $\left\{ f _ { n } \right\}$ of continuous real valued functions on a metric space Ω is precompact (i.e., has a uniformly convergent subsequence) if

(ii) sup $\| f _ { n } \| < \infty$ (where $\Vert f _ { n } \Vert = \operatorname* { s u p } \{ | f _ { n } ( x ) | | x \in \Omega \} \bigr )$

(iii) the sequence is equicontinuous.

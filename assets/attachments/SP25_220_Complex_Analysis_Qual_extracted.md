Problem 1. [10 points.]

Let f be a holomorphic function in a neighborhood of the closed unit disc D, and suppose that

$$
| f ( 0 ) | + | f ^ { \prime } ( 0 ) | < \operatorname* { i n f } \{ | f ( z ) | : | z | = 1 \} .
$$

Show that f has at least two zeros (counting multiplicity) in D.

(Hint: Make use of the function $g ( z ) = f ( 0 ) + f ^ { \prime } ( 0 ) z - f ( z ) . )$

## Problem 2. [10 points; 5, 5.]

Let $\alpha \in ( 0 , 1 ]$ and $\Omega _ { \alpha } \subset \mathbb { C }$ denote the open region

$$
\Omega _ { \alpha } : = \left. z = r e ^ { i \theta } : \theta \in \left( - \frac { \alpha \pi } { 2 } , \frac { \alpha \pi } { 2 } \right) , r > 0 \right. .
$$

(i) Determine for which α there is a M¨obius transformation S from $\Omega _ { \alpha }$ onto D. Prove nonexistence or give an explicit example if such exists.

(ii) Determine for which α there is a conformal map f from $\Omega _ { \alpha }$ onto D. Prove nonexistence or give an explicit example if such exists.

## Problem 3. [10 points.]

Let $f : \mathbb { D } \to \mathbb { C }$ be a holomorphic function in the unit disc. Assume f is injective and $f ( 0 ) = 0$ Prove that there exists a holomorphic function g in D such that $( g ( z ) ) ^ { 2 } = f ( z ^ { 2 } )$ for all $z \in \mathbb { D }$

## Problem 4. [10 points.]

Let $a \in \mathbb { D }$ and set $G = \mathbb { D } \setminus \{ a \}$ . Find all analytic automorphisms of G, i.e., find all one-to-one and onto analytic functions from G to G. Write down the expressions for such functions (can be unsimplified). Prove your answer.

## Problem 5. [10 points.]

Let $f _ { n } : \mathbb { D } \to \mathbb { C }$ be a bounded sequence of holomorphic functions, and let $\{ z _ { m } \} _ { m \ge 1 }$ be a sequence in D that converges in D. Assume that lim $_ { 1 _ { n } \to \infty } f _ { n } ( z _ { m } )$ exists for all $m \geq 1$ . Show that the sequence $\{ f _ { n } \}$ converges uniformly on compact subsets of D.

## Problem 6. [10 points; 2, 2, 2, 4.]

Let $f : \mathbb { D } \to \mathbb { C }$ be holomorphic and assume $f ( z ) \neq 0$ for $z \neq 0$ . For $0 \leq r < 1$ , let

$$
M ( r ) = \operatorname* { m a x } _ { | z | = r } | f ( z ) | .
$$

(i) Show that the function $h _ { s } ( z ) = s \log | z | + \log | f ( z ) |$ is harmonic in $\mathbb { D } \setminus \{ 0 \}$ for all $s \in \mathbb { R }$

(ii) Show that there exists $s \in \mathbb { R }$ such that

$$
\operatorname* { m a x } _ { | z | = { \frac { 1 } { 2 } } } h _ { s } ( z ) = \operatorname* { m a x } _ { | z | = { \frac { 1 } { 8 } } } h _ { s } ( z ) .
$$

(iii) Show that

$$
M \left( { \frac { 1 } { 4 } } \right) ^ { 2 } \leq M \left( { \frac { 1 } { 2 } } \right) M \left( { \frac { 1 } { 8 } } \right) .
$$

(iv) Show that equality holds if and only if $f ( z ) = a z ^ { n }$ for some $a \in \mathbb { C }$ and some integer $n \geq 0$

Problem 2 Let $\{ f _ { n } \} _ { n = 1 } ^ { \infty }$ be a uniformly bounded equicontinuous sequence of real-valued functions on the compact metric space $( X , d )$ . Define the functions $g _ { n } : X \to \mathbb { R }$ , for $n \in \mathbb { N }$ by

$$
g _ { n } ( x ) = \operatorname* { m a x } \{ f _ { 1 } ( x ) , \ldots , f _ { n } ( x ) \} .
$$

Prove that the sequence $\{ g _ { n } \} _ { n = 1 } ^ { \infty }$ converges uniformly.

$$

$$

Prove that this sequence converges, and find its limit.

2. Let $\lambda _ { 1 } , \ldots , \lambda _ { k }$ be distinct points of C that are not eigenvalues of A. Prove that there are complex numbers $c _ { 1 } , \ldots , c _ { k }$ such that

$$
\sum _ { j = 1 } ^ { k } c _ { j } ( A - \lambda _ { j } I ) ^ { - 1 } = I .
$$

Problem 13 Let f be a nonconstant entire function whose values on the real axis are real and nonnegative. Prove that all real zeros of f have even order.

Problem 14 Let $I _ { 1 } , \ldots , I _ { n }$ be disjoint closed nonempty subintervals of R.

1. Prove that if p is a real polynomial of degree less than n such that

$$
\int _ { I _ { j } } p ( x ) d x = 0 \ , \qquad { \mathrm { f o r ~ } } j = 1 , \ldots , n
$$

2. Prove that there is a nonzero real polynomial p of degree n that satisfies all the above equations.

Problem 15 Let F , with components $F _ { 1 } , \ldots , F _ { n }$ , be a differentiable map of $\mathbb { R } ^ { n }$ into $\mathbb { R } ^ { n }$ such that $F ( 0 ) = 0$ . Assume that

(3) A space X is completely regular if X is $T _ { 1 }$ and whenever C is closed in X and $p \in X \backslash C$ then there is a continuous function $f : X \to [ 0 , 1 ]$ such that $f ( p ) = 0$ and $f ( C ) = \{ 1 \}$

(3b) Show that if X and Y are completely regular spaces, then so is the product space $X \times Y$ . (Hint: Use the result in (3a).)

(4) A continuous function $f : X \to Y$ is called proper if for every compact subset C of $Y$ , the preimage $f ^ { - 1 } ( C )$ is compact in X. Show that if X and Y are compact Hausdorff spaces and $f : X \to Y$ is a proper continuous function, then $f$ is a closed map.

5. (10 points) Let $G = G L _ { 2 } ( \mathbb { R } )$ be the group of invertible $2 \times 2$ real matrices and let X, $Y : G  G L _ { d } ( \mathbb { C } )$ be two complex matrix representations of G with the same degree d. If X and Y have the same character, are X and Y necessarily isomorphic? Justify your answer.

6. (5 + 5 points) Let $D _ { 4 } = \langle r , s \mid r ^ { 4 } = s ^ { 2 } = 1 , s r s = r ^ { - 1 } \rangle$ be the dihedral group of symmetries of the square.

(a) Write down the character table of $D _ { 4 }$

(b) Let V be the 2-dimensional ‘defining’ $D _ { 4 } { \mathrm { - m o d u l e } }$ obtained by centering the square at the origin in the plane and extending symmetries of the square to linear transformations of the plane. Give the tensor product $V \otimes V$ the structure of a $D _ { 4 ^ { - } } \mathrm { m o d u l e }$ by setting

$$
g . ( v \otimes v ^ { \prime } ) : = ( g . v ) \otimes ( g . v ^ { \prime } )
$$

for all $g \in D _ { 4 }$ and $v , v ^ { \prime } \in V$ . Calculate the decomposition of $V \otimes V$ into irreducible $D _ { 4 ^ { - } } \mathrm { m o d u l e s }$

7. $( 5 + 5$ points) Let G be a finite group and let $X : G \to G L _ { d } ( \mathbb { R } )$ be an irreducible matrix representation of G over the field of real numbers. Let $T : \mathbb { R } ^ { d }  \mathbb { R } ^ { d }$ be an endomorphism of X.

(a) Give an example to show that $T$ is not necessarily a scalar transformation.

(b) Suppose that $T$ is not a scalar transformation. Consider the representation $X ^ { \prime } : G \to G L _ { d } ( \mathbb { C } )$ given by viewing real matrices as complex matrices:

$$
X ^ { \prime } ( g ) : = X ( g ) \quad { \mathrm { f o r ~ a l l ~ } } g \in G .
$$

Is it possible for $X ^ { \prime }$ to be irreducible (as a complex matrix representation)? Justify your answer.

8. (5 + 5 points) Let $S _ { n }$ be the symmetric group on n letters.

(a) Calculate the character table of the product group $S _ { 3 } \times S _ { 2 }$

(b) Let $\lambda = ( 3 , 2 ) \vdash 5$ and let $S ^ { \lambda }$ be the associated irreducible representation of $S _ { 5 }$ . Calculate the decomposition of the restricted module $S ^ { \lambda } \downarrow _ { S _ { 3 } \times S _ { 2 } } ^ { S _ { 5 } }$ into irreducibles.

9. (10 points) Let A be a finite-dimensional algebra over C with center $\mathcal { Z } ( \mathbb { A } )$ , and let $( V , \rho )$ be an irreducible representation of A. Show that $\rho ( z ) = \chi ( z ) I _ { V }$ for each $z \in \mathcal { Z } ( \mathbb { A } )$ , where $\chi ( z )$ is a scalar. Show that the map $\chi \colon \mathcal { Z } ( \mathbb { A } ) \to \mathbb { C }$ defined by $z \mapsto \chi ( z )$ is an algebra homomorphism.

10. (10 points) Let A be a finite-dimensional algebra over $\mathbb { C }$ and let $( V , \rho )$ be a finite-dimensional representation of A. Show that the isotypic decomposition of $( V , \rho )$ is multiplicity free if and only if $\operatorname { E n d } _ { \mathbb { A } } V$ is commutative.

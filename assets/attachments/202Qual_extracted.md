Problem 5: Let K be an algebraically closed field, let $\mathbb { K } ^ { n }$ be affine n-space over K, and consider the polynomial ring $\mathbb { K } [ x _ { 1 } , \ldots , x _ { n } ]$ .

(1) Suppose that $I \subseteq \mathbb { K } [ x _ { 1 } , \ldots , x _ { n } ]$ is an ideal such that $\mathbf { V } ( I ) \subseteq \mathbb { K } ^ { n }$ is a finite set. Prove that $\mathbb { K } [ x _ { 1 } , \ldots , x _ { n } ] / I$ is a finite-dimensional K-vector space.

(2) Let F be a field which is not algebraically closed. Prove that there exists an ideal $I \subseteq \mathbb { F } [ x , y ]$ such that $\mathbf { V } ( I ) = \emptyset$ but $\mathbb { F } [ x , y ] / I$ is an infinite-dimensional F-vector space.

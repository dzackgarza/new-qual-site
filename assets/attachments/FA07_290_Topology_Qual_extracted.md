4. Let K be a (perhaps knotted) subspace of $S ^ { 5 }$ which is homeomorphic to the 3-sphere. Let N be a closed regular neighbourhood of K, so that N is homotopy equivalent toK. Let X be $S ^ { 5 }$ minus the interior of N, so that X is a compact 5-manifold with boundary. By considering the relative cohomology $H ^ { * } ( S ^ { 5 } , N )$ and applying excision and Lefschetz duality, calculate the homology of X.

5. Let M be a closed (that is, compact and without boundary) path-connected orientable 3-manifold. Suppose that M contains a 2-dimensional orientable submanifold ∑ which is non-separating, meaning that M - ∑ is still path-connected. Show that $H _ { 1 } ( M ; \mathbb { Z } )$ contains a subgroup isomorphic to Z.

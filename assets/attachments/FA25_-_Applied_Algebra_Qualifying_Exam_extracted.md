1. (10 points) Given $n \geq 3$ , fix $A \in M _ { n } ( \mathbb { C } ) = \mathbb { C } ^ { n \times n }$ satisfying that there exist two eigenvalues $\alpha , \beta$ of A with $\alpha \neq \beta$ . Prove there exists unitary $Q \in M _ { n } ( \mathbb { C } )$ such that

$$
Q ^ { H } A Q = \left[ \begin{array} { c c c } { { \alpha } } & { { \delta } } & { { v ^ { H } } } \\ { { 0 } } & { { \beta } } & { { 0 } } \\ { { 0 } } & { { w } } & { { B } } \end{array} \right] ,
$$

for some $\delta \in \mathbb { C } , v , w \in \mathbb { C } ^ { n - 2 }$ , and $B \in M _ { n - 2 } ( \mathbb { C } )$

(Notationally: for all $m , n \geq 1 , z ^ { H } = \bar { z } ^ { T }$ for all $z \in M _ { m , n } ( \mathbb { C } ) = \mathbb { C } ^ { m \times n } )$

2. (10 points) Given $n \geq 1$ , let $A \in M _ { n } ( \mathbb { C } ) = \mathbb { C } ^ { n \times n }$ . Prove if $x ^ { H } A x = 0$ , for all $x \in \mathbb { C } ^ { n }$ , then $A = 0$ (Notationally: for all $m , n \geq 1 , z ^ { H } = \bar { z } ^ { T }$ for all $z \in M _ { m , n } ( \mathbb { C } ) = \mathbb { C } ^ { m \times n } )$

3. (10 points) Consider complex-valued square matrices A satisfying:

• A has exactly two distinct eigenvalues of −2 and −3, with algebraic multiplicities of 6 and 1, respectively;

• rank $( ( A + 2 I ) ^ { 3 } ) = 2 ;$

Now considering all possible Jordan canonical forms similar to A, determine and write down one, and only one, of these from each similarity class.

4. (10 points) Given $n \geq 1$ and || · || a matrix norm of $M _ { n } ( \mathbb { C } ) = \mathbb { C } ^ { n \times n }$ that is consistent (meaning $\| A B \| \leq \| A \| \| B \| )$ , let $A \in M _ { n } ( \mathbb { C } )$

(a) Find a vector norm || · ||0 of Cn that is compatible with || · || (meaning $\| A x \| ^ { \prime } \leq \| A \| \| x \| ^ { \prime } )$

(b) Prove, for all eigenvalues λ of A, that $| \lambda | \leq \| A \|$

5. (10 points) Let A be a unital associative algebra over C equipped with an antilinear and antimultplicative involution $A \mapsto A ^ { * }$ . We say that $A \in { \mathcal { A } }$ is normal if A and $A ^ { * }$ commute (example: normal matrices are normal elements of $\mathbb { C } ^ { \breve { N } \times N } )$ . Prove that A is normal if and only if $A = X + i Y$ with $X , Y \in { \mathcal { A } }$ commuting $( X Y = Y X )$ ) and selfadjoint $( X ^ { * } = X , Y ^ { * } = Y )$ .

6. (10 points) Let $( \mathrm { V } , \varphi )$ be a finite-dimensional complex representation of a finite group ${ \mathrm { G } } ,$ and let $\chi ( g ) = \operatorname { T r } \varphi ( g )$ be its character. Prove that $| \chi ( g ) | \leq \dim \mathrm { V }$ for all $g \in \mathrm { G }$ , and that the bound is sharp.

7. (10 points) Let $( \mathrm { V } , \varphi )$ be a finite-dimensional irreducible complex representation of a finite group $\mathrm { G }$ and let $\chi$ be its character. Show that for any $g _ { 1 } , g _ { 2 } \in \mathrm { G }$ we have $\begin{array} { r } { \frac { 1 } { | G | } \sum _ { h \in \mathrm G } \chi ( g _ { 1 } h g _ { 2 } h ^ { - 1 } ) = \frac { \chi ( g _ { 1 } ) \chi ( g _ { 2 } ) } { \dim \mathrm V } } \end{array}$

8. (10 points) Let $( \mathrm { V } , \varphi )$ be a complex representation of the symmetric group $\mathrm { S } _ { n }$ , and let $\chi$ be its character. Prove that $\chi ( g ) \in \mathbb { R }$ for all $g \in \mathrm { S } _ { n }$ .

9. (10 points) Let k be an algebraically closed field and let $I \subseteq k [ x , y ]$ be an ideal. Suppose that the variety of I is $\mathbf { V } ( I ) = \{ ( 1 , 0 ) , ( 0 , 1 ) \} \subseteq k ^ { 2 }$

(a) Prove that $k [ x , y ] / I$ is a finite-dimensional k-vector space.

(b) Do we necessarily have $\dim _ { k } ( k [ x , y ] / I ) < 1 0 0 ?$

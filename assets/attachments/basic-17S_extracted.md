Problem 1. Let M be an $n \times n$ real matrix and with transpose $M ^ { T }$ . Prove that M and $M \cdot M ^ { T }$ have the same range (image).

Problem 2. Let $a , b , c , d \in$ R and

$$
M = \left( { \begin{array} { c c c c } { 1 } & { 0 } & { a } & { b } \\ { 0 } & { 1 } & { 0 } & { 0 } \\ { 0 } & { c } & { 3 } & { - 2 } \\ { 0 } & { d } & { 2 } & { - 1 } \end{array} } \right) .
$$

(i) Determine conditions on $a , b , c , d$ so that there is only one Jordan block for each eigenvalue of M in the Jordan form of M.

(ii) Find the Jordan form of M when $a = c = d = 2$ and $b = - 2$

Problem 3. Let M be an $n \times n$ real matrix. Suppose M is orthogonal and symmetric

(i) Prove that if M positive definite then M is the identity.

(ii) Does the answer change if M is only positive semidefinite?

Compute $\textstyle { \frac { d F } { d x } } ( 0 )$

Show that the linear transformation $F ( T )$ is invertible if and only if $F ( X )$ and the minimal polynomial of T have no common factors.

Problem 10. Let $K \subset \mathbb { R } ^ { n }$ be compact. Suppose that for every $\varepsilon > 0$ and every pair $a , b \in K$ , there is an integer $n \geq 1$ and a sequence of points $x _ { 0 } , \ldots , x _ { n } \in K$ so that

(ii) Show by example that K may not be path connected.

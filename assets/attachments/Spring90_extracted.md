# Preliminary Exam - Spring 1990

Problem 1 Let $y : \mathbb { R }  \mathbb { R }$ be $a ~ C ^ { \infty }$ function that satisfies the differential equation

$$

Problem 2 Let A be a complex $n \times n$ matrix that has finite order; that is, $A ^ { k } = I$ for some positive integer k. Prove that A is diagonalizable.

Problem 3 Let $c _ { 0 } , c _ { 1 } , \ldots , c _ { n - 1 }$ be complex numbers. Prove that all the zeros of the polynomial

$$

## Section A: Do THREE problems from this section

(1) Let $X _ { \alpha }$ be non-empty topological spaces and suppose that $\textstyle X = \prod _ { \alpha } X _ { \alpha }$ is endowed with the product topology.

(a) Prove that each projection map $\pi _ { \alpha }$ is continuous and open.

(b) Prove that X is Hausdorff if and only if each space $X _ { \alpha }$ is Hausdorff.

(2) (a) Prove that every compact subspace of a Hausdorff space is closed. Show by example that the Hausdorff hypothesis cannot be removed.

(b) Prove that every compact Hausdorff space is normal.

(3) Define an equivalence relation ∼ on $\mathbb { R } ^ { 2 }$ by $( x _ { 1 } , y _ { 1 } ) \sim ( x _ { 2 } , y _ { 2 } )$ if and only if $x _ { 1 } ^ { 2 } + y _ { 1 } ^ { 2 } = x _ { 2 } ^ { 2 } + y _ { 2 } ^ { 2 }$

(a) Identify the quotient space $X = \mathbb { R } ^ { 2 } / { \sim }$ as a familiar space and prove that it is homeomorphic to this familiar space.

(b) Determine whether the natural map $p : \mathbb { R } ^ { 2 } \to X$ is a covering map. Justify your answer.

(4) A space is locally connected if for each point $x \in X$ and every neighborhood U of x, there is a connected neighborhood V of x contained in $U$

(a) Prove that X is locally connected if and only if for every open set U of X, each connected component of U is open in X.

(b) Prove that if $p : X \to Y$ is a quotient map and X is locally connected, then Y is locally connected.

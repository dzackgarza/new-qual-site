## Section A:

1) Assume that $( X , \tau )$ is a topological space with the property that for every open set $G \subseteq X$ , the closure of $G , { \overline { { G } } } .$ , is open. Such topological spaces are called extremally disconnected. Prove the following.

a) If $F \subseteq X$ is a closed set, then the interior of $F , F ^ { \circ }$ , is closed.

b) If $G \subseteq X$ is an open set, then G equipped with the subspace topology is extremally disconnected.

c) If X is Hausdorff and $f : \mathbb { R } \to X$ is continuous, prove that f is a constant function.

2) Suppose X and Y are topological spaces and $f : X \to Y$ is a continuous function.

a) Prove there exists a topological space Z, a quotient map $q : X \to Z$ and a one-to-one continuous map $h : Z \to Y$ such that $f = h \circ q$

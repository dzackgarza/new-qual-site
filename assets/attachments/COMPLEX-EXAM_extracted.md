Problem 1. [10 points.]

Using the calculus of residues, compute

$$
\int _ { 0 } ^ { \infty } { \frac { \cos x } { ( 1 + x ^ { 2 } ) ^ { 2 } } } d x .
$$

Problem 2. [10 points.]

Let $f : \mathbb { C } \to \mathbb { C }$ be entire. Assume that the function $\begin{array} { r } { g ( z ) = f ( z ) \cdot f \left( \frac { 1 } { z } \right) } \end{array}$ is bounded on $\mathbb { C } \setminus$ {0}. Show that $f ( z ) = c z ^ { m }$

Problem 3. [10 points.]

Let $n \geq 0$ be an integer. Assume $f : \mathbb { C } \to \mathbb { C }$ is an entire function such that

$$
| f ( z ) | \leq 1 + ( \log ( 1 + | z | ) ) ^ { n } .
$$

Prove that f is constant.

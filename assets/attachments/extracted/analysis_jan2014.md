## Part I: 6 points each, do all 6 questions

1. State and prove the integral test for convergence of series. You may assume the comparison test.

2. Let f be a continuous function from [0, 1] to [0, ∞). If $\begin{array} { r } { \int _ { 0 } ^ { 1 } f ( t ) d t = 0 } \end{array}$ , prove that $f ( x ) = 0 , \forall x \in [ 0 , 1 ]$

3. Let f be a bounded Riemann integrable function on [0, 1]. Prove that $f ^ { 2 }$ is Riemann integrable on [0, 1].

4. Equip $\mathbb { R } ^ { n }$ with 2 metrics $\rho _ { 1 }$ and $\rho _ { 2 } .$ , where $\begin{array} { r } { \rho _ { 1 } ( x , y ) = \operatorname* { m a x } _ { 1 \leq j \leq n } | x ^ { j } - y ^ { j } | } \end{array}$ and $\begin{array} { r } { \rho _ { 2 } ( x , y ) = \sqrt { \textstyle \sum _ { j = 1 } ^ { n } | x ^ { j } - y ^ { j } | ^ { 2 } } } \end{array}$ Prove a set $U \subset \mathbb { R } ^ { n }$ is open in $( \mathbb { R } ^ { n } , \rho _ { 1 } )$ if and only if it is open in $( \mathbb { R } ^ { n } , \rho _ { 2 } )$

5. Let $\begin{array} { r } { x _ { n } : = \frac { ( n ^ { 2 } + 2 \sin ^ { 2 } ( n ) + 3 4 ) \sin ( n ^ { 3 } ) } { n ^ { 2 } + n + 5 } } \end{array}$ . Prove $\{ x _ { n } \} _ { n = 1 } ^ { \infty }$ has a convergent subsequence.

6. Let $\{ a _ { n } \} _ { n = 1 } ^ { \infty }$ be a sequence of positive numbers such that $\textstyle \sum _ { n = 1 } ^ { \infty } a _ { n }$ converges. Prove $\textstyle \sum _ { n = 1 } ^ { \infty } a _ { n } ^ { 2 }$ converges.

## Part II: 10 points each. Do all 6 questions.

1. Let $g ( x )$ be a positive Riemann integrable function. Show there exists $c \in [ 1 , 2 ]$ so that

$$
\int _ { 1 } ^ { 2 } e ^ { t ^ { 2 } } g ( t ) d t = e ^ { c ^ { 2 } } \int g ( t ) d t .
$$

2. Let $\begin{array} { r } { f ( x ) : = \sum _ { k = 0 } ^ { \infty } \frac { c o s ( k x ) } { k ^ { 3 } + k ^ { 2 } + 1 } } \end{array}$ . Prove that f is differentiable with derivative $\scriptstyle \sum _ { k = 0 } ^ { \infty } { \frac { - k \sin ( k x ) } { k ^ { 3 } + k ^ { 2 } + 1 } }$

3. Let $U \subset \mathbb { R } ^ { p }$ be open. Let $f : U \to \mathbb { R } ^ { n }$ be a $C ^ { 1 }$ function. Suppose that for some $x _ { 0 } \in U , D f _ { x _ { 0 } }$ is rank $p .$ Show that there is a change of variables in some neighborhood of $f ( x _ { 0 } )$ so that in the new coordinate system, f is a linear inclusion.

4. Show there exists a $f \in C ( [ 0 , 1 ] , \mathbb { R } )$ solving the equation

$$
f ( x ) = \frac { 1 } { 1 0 6 6 } \int _ { 0 } ^ { x } e ^ { - s ^ { 2 } x ^ { 2 } } f ( s ) ^ { 2 } d s + \sin ( 2 0 1 3 x ) .
$$

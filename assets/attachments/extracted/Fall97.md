# Preliminary Exam - Fall 1997

Problem 1 Define a sequence of real numbers $( x _ { n } )$ by

$$
x _ { 0 } = 1 , \qquad x _ { n + 1 } = { \frac { 1 } { 2 + x _ { n } } } \quad { \mathrm { f o r } } \quad n \geqslant 0 .
$$

Show that $( x _ { n } )$ converges, and evaluate its limit.

Problem 2 Let f be a real valued function that is differentiable on an open interval containing $[ a , b ]$ . Prove that if $f ^ { \prime } ( a ) < 0$ and $f ^ { \prime } ( b ) > 0$ then there is a point $c \in ( a , b )$ such that $f ^ { \prime } ( c ) = 0$

Problem 3 Let f be an entire function such that, for all $z , | f ( z ) | = | \sin z |$ Prove that there is a constant C of modulus 1 such that $f ( z ) = C \sin z$

Problem 4 Evaluate the integral

$$
\int _ { - \infty } ^ { \infty } { \frac { d x } { 1 + x ^ { 2 n } } }
$$

where $n > 0$ is an integer.

Problem 5 Let $\mathbb { D } = \{ z \mid | z | < 1 \}$ , the open unit disc in the complex plane. Suppose that $f : \mathbb { D } \to \mathbb { D }$ is analytic, and that there exist two distinct points $a , b \in \mathbb { D }$ with $f ( a ) = a , f ( b ) = b$ . Prove that $f ( z ) = z$ for $a l l z \in \mathbb { D }$

Problem 6 Let $\alpha _ { 1 } , \alpha _ { 2 } , \ldots , \alpha _ { n }$ be distinct real numbers. Show that the n exponential functions $e ^ { \alpha _ { 1 } t } , e ^ { \alpha _ { 2 } t } , . . . , e ^ { \alpha _ { n } t }$ are linearly independent over the real numbers.

Problem 7 Define the index of a real symmetric matrix A to be the number of strictly positive eigenvalues of A minus the number of strictly negative eigenvalues. Suppose A, and B are real symmetric $n \times n$ matrices such that $x ^ { t } A x \leqslant x ^ { t } B x$ for all $n \times 1$ matrices x. Prove the the index of A is less than or equal to the index of B.

Problem 8 Suppose $H _ { i }$ is a normal subgroup of a group G for1 $\leqslant i \leqslant k$ such that $H _ { i } \cap H _ { j } = \{ 1 \}$ for $i \neq j$ Prove that G contains a subgroup isomorphic to $H _ { 1 } \times H _ { 2 } \times \cdots \times H _ { k }$ if k = 2, but not necessarily if $k \geqslant 3$

Problem 9 Prove that if p is prime then every group of order $p ^ { 2 }$ is abelian.

Problem 10 Prove that for all $x > 0$ , sin $x > x - { \frac { x ^ { 3 } } { 6 } }$

Problem 11 Let $f : \mathbb { R } \to \mathbb { R }$ be twice differentiable, and suppose that for all $x \in \mathbb { R } , | f ( x ) | \leqslant 1$ and $\vert f ^ { \prime \prime } ( x ) \vert \leqslant 1$ . Prove that $\vert f ^ { \prime } ( x ) \vert \leqslant 2$ for all $x \in \mathbb { R }$

Problem 13 Conformally map the region inside the disc given by $\{ z \in \mathbb { C } \mid | z -$ $1 | \leqslant 1 \}$ and outside the disc $\{ z \in \mathbb { C } \mid | z - { \frac { 1 } { 2 } } | \leqslant { \frac { 1 } { 2 } } \}$ onto the upper half-plane.

$$

Problem 15 Let $M _ { n \times n } ( \mathbf { K } )$ be the vector space of $n \times n$ matrices over a field K. Find the dimension of the subspace of $M _ { n \times n } ( \mathbf { K } )$ spanned by $\{ X Y -$ $Y X | X , Y \in M _ { n \times n } ( \mathbf { K } ) \}$

Problem 16 Prove that if A is a 2×2 matrix over the integers such that $A ^ { n } = I$ for some strictly positive integer n, then $A ^ { 1 2 } = I$

Problem 17 A group G is generated by two elements a, b, each of order 2.

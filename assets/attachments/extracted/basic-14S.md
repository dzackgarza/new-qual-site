## Notations:

Let $M _ { m , n } ( \mathbb { F } )$ be the set of all m by n matrices with entries from the field F. Let Hom $( U , V )$ be the set of all linear maps from the vector space U to the vector space V.

Problem 1 (a) Find a real matrix A whose minimal polynomial is equal to

$$
t ^ { 4 } + 1 .
$$

(b) Show that the usual real linear map determined by $v \mapsto A v$ has no non-trivial invariant subspace.

Problem 2 Suppose that $S , T \in \operatorname { H o m } ( V , V )$ where V is a finite dimensional vector space over R. Let (im S) be the image of S and (ker S) be the kernel of S. Show that

$$
\dim ( \operatorname { i m } S ) + \dim ( \operatorname { i m } T ) \leq \dim ( \operatorname { i m } S \circ T ) + \dim V .
$$

Problem 3 Suppose that A, $B \in M _ { n , n } ( \mathbb { C } )$ satisfy $A B - B A = A$ Show that A is not invertible.

Problem 4 Suppose that A, $B \in M _ { n , n } ( \mathbb { C } )$ . Show that the characteristic polynomials of AB and BA are equal. Hint: One approach is to first show that it holds when B is invertible.

Problem 5 Suppose that V is a finite dimensional real inner product space with inner product $( \cdot , \cdot )$ , that $L \in \operatorname { H o m } ( V , V )$ and that $b \in V$ is fixed. Suppose that $u , v \in V$ both minimize $D ( x ) = | | L ( x ) - b | |$ . Show that $u - v \in$ ker L.

Problem 6 Show that if $A \in M _ { n , n } ( \mathbb { C } )$ is normal then $A ^ { * } = P ( A )$ for some polynomial $P ( x )$ with complex coefficients. Here $A ^ { * }$ is the conjugate transpose of A.

Problem 7 Find a doubly infinite sequence $\{ a _ { n , m } , n , m \in \mathbb { Z } \}$ such that for all m, $\textstyle \sum _ { n } a _ { n , m } = 0$ and for all $n , \textstyle \sum _ { m } a _ { n , m } = 0$ , with all these series converging absolutely, but such that $\begin{array} { r } { \sum _ { n } \sum _ { m } | a _ { n , m } | = \infty } \end{array}$

Problem 8 (a) Let $f : \mathbb { R } \to \mathbb { R }$ be defined by

$$
f ( x ) = { \left\{ \begin{array} { l l } { 0 , } & { x \leq 0 } \\ { e ^ { - { \frac { 1 } { x } } } , } & { x > 0 . } \end{array} \right. }
$$

Prove that $f$ is infinitely differentiable.

(b) In Euclidean space $\mathbb { R } ^ { n }$ for $n \geq 1$ find a function $\varphi ( x ) \in { \cal { C } } ^ { \infty }$ such that $\varphi ( x ) \geq 0$ for all $x , \varphi ( x ) = 0$ if $| x | > 1$ , and $\textstyle \int _ { \mathbb { R } ^ { n } } \varphi ( x ) d x = 1$

Problem 9 Find a function that minimizes $\int _ { 0 } ^ { 1 } | f ^ { \prime } ( x ) | ^ { 2 } d x$ among all $f \in$ $C ^ { 1 } ( \mathbb { R } )$ such that $f ( 0 ) = 0 , f ( 1 ) = 1$ . Is the minimizing $C ^ { 1 }$ function unique on $[ 0 , 1 ] ?$

Problem 10 Let $F$ be a set of continuous real-valued functions on $[ 0 , 1 ]$ Assume that

(i) F is uniformly bounded, i.e. there is $M < \infty$ such that $| f ( x ) | \leq M$ for all $f \in F$ and all $x \in [ 0 , 1 ]$ , and

(ii) F is equicontinuous: for every $\epsilon > 0$ there is $\delta > 0$ such that for all $f \in \mathcal { F }$ and $x , y \in [ 0 , 1 ]$

$$
| x - y | < \delta \Rightarrow | f ( x ) - f ( y ) | < \epsilon .
$$

Prove that every sequence from $F$ has a subsequence that converges uniformly on [0, 1].

Problem 11 Let $F$ be a set of continuous real-valued functions on $[ 0 , 1 ]$ Assume that every sequence from $F$ has a subsequence that converges uniformly on [0, 1]. Prove both (i) and (ii) below hold:

(i) $F$ is uniformly bounded, i.e. there is $M < \infty$ such that $| f ( x ) | \leq M$ for all $f \in \mathcal { F }$ and all $x \in [ 0 , 1 ]$ , and

(ii) F is equicontinuous: for every $\epsilon > 0$ there is $\delta > 0$ such that for all $f \in \mathcal { F }$ and $x , y \in [ 0 , 1 ]$

$$
| x - y | < \delta \Rightarrow | f ( x ) - f ( y ) | < \epsilon .
$$

Problem 12 Assume $[ 0 , 1 ] = \bigcup _ { n = 1 } ^ { \infty } I _ { n }$ where $I _ { n } = [ a _ { n } , b _ { n } ] \neq \emptyset$ and

$$
I _ { n } \cap I _ { m } = \emptyset
$$

whenever $n \neq m$

a) Let $E = \{ a _ { n } : n \geq 1 \} \cup \{ b _ { n } : n \geq 1 \}$ be the set of endpoints of the intervals above. Prove E is closed.

(b) Prove no such family of intervals $\{ I _ { n } \}$ can exist.

4. (January 2019) Recalling that $S ^ { 2 } = \{ ( x , y , z ) \in \mathbb { R } ^ { 3 } : x ^ { 2 } + y ^ { 2 } + z ^ { 2 } = 1 \}$ , define the equator of $S ^ { 2 }$ to be $\{ ( x , y , z ) \in S ^ { 2 } : z = 0 \}$ , so that the equator is homeomorphic to $S ^ { 1 }$ .

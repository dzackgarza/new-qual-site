## Necessary condition

What is the necessary condition on an open set $\Omega$ that guarantee the existence of a conformal map $F : \Omega \to \mathbb { D } ?$

(1) If $\Omega = \mathbb { C }$ , and $F : \Omega  \mathbb { D }$ , then F is entire and bounded. Hence F is constant. Hence $\Omega \neq \mathbb { C }$

(2) D is connected $\Longrightarrow \Omega$ is connected.

(3) D is simply connected $\Longrightarrow \Omega$ is simply connected.

## Theorem 1

Suppose Ω is proper and simply connected. If $z _ { 0 } \in \Omega$ , then there exists an unique conformal map $F : \Omega  \mathbb { D }$ such that $F ( z _ { 0 } ) = 0$ and $F ^ { \prime } ( z _ { 0 } ) > 0$

## The main idea of the proof of the existence

We consider the family of $\mathfrak { F }$ of holomorphic functions on $\Omega$ defined as follows: $g \in { \mathfrak { F } } ( \Omega )$ if and only if

(a) $g : \Omega  D$ is holomorphic and one-to-one in $\Omega .$

(b) $| g ( z ) | < 1$ all $z \in \Omega$

(c) $g ( z _ { 0 } ) = 0$ and $g ^ { \prime } ( z _ { 0 } ) > 0$

We need to prove the following statements:

(A) $\mathfrak { F } ( \Omega )$ is not empty.

(B) There exists a function $f \in \mathfrak { F } ( \Omega )$ such that $g ^ { \prime } ( z _ { 0 } ) \leq f ^ { \prime } ( z _ { 0 } )$ for all $g \in { \mathfrak { F } }$

(C) If $f \in { \mathfrak { F } } ( \Omega )$ satisfies (B), then f is the Riemann mapping, that is, f (Ω) = D, f (z0) = 0 and $f ^ { \prime } ( z _ { 0 } ) > 0$

## Necessary condition

What is the necessary condition on an open set $\Omega$ that guarantee the existence of a conformal map $F : \Omega \to \mathbb { D } ?$

(1) If $\Omega = \mathbb { C }$ , and $F : \Omega  \mathbb { D }$ , then F is entire and bounded. Hence F is constant. Hence $\Omega \neq \mathbb { C }$

(2) D is connected $\Longrightarrow \Omega$ is connected.

(3) D is simply connected $\Longrightarrow \Omega$ is simply connected.

## Theorem 1

Suppose Ω is proper and simply connected. If $z _ { 0 } \in \Omega$ , then there exists an unique conformal map $F : \Omega  \mathbb { D }$ such that $F ( z _ { 0 } ) = 0$ and $F ^ { \prime } ( z _ { 0 } ) > 0$

## Normal family

## Definition 2

Let Ω be an open subset of C. A family F(Ω) of holomorphic functions on Ω is said to be normal if every sequence in F(Ω) has a subsequence that converges uniformly on every compact subset of Ω (the limit need not be in F(Ω)). The proof that a family of functions is normal is, in practice, the consequence of two related properties, Uniform Boundedness and Equicontinuity.

## Definition 3

The family $\mathfrak { F }$ is said to be uniformly bounded on compact subsets of Ω if for each compact set $K \subset \Omega$ there exists $B > 0$ , such that

$$
| f ( z ) | \leq B \quad { \mathrm { f o r ~ a l l } } \quad z \in K { \mathrm { ~ a n d ~ } } f \in { \mathfrak { F } } .
$$

The family $\mathfrak { F }$ is equicontinuous on a compact set $K \subset \Omega$ if for every $\epsilon > 0$ there exists $\delta > 0$ such that whenever z, $w \in K$ and $\vert z - w \vert < \delta$ , then

$$
| f ( z ) - f ( w ) | < \epsilon ~ \mathsf { f o r } ~ \mathsf { a l l } ~ f \in \mathfrak { F } .
$$

Examples: 1)

$\{ f _ { n } ( x ) : \ [ 0 , 1 ] \to \mathbb { C } , \ | f _ { n } ^ { \prime } ( x ) | \leq M$ for some fixed constant $M \}$ in uniform bounded and equicontinuity.

2) $\{ f _ { n } ( x ) = x ^ { n } : \ x \in [ 0 , 1 ] \}$ is uniform bounded but not equicontinuous. note that lim $\operatorname { \Pi } _ { n \to \infty } | f _ { n } ( 1 ) - f _ { n } ( x _ { 0 } ) | = 1 { \mathrm { ~ f o r ~ } } 0 < x _ { 0 } < 1 .$

## Montel’s Theorem

## Theorem 4

Suppose F(Ω) is a family of holomorphic functions on Ω that is uniformly bounded on compact subsets of Ω. Then:

(i) F(Ω) is equicontinuous on every compact subset of Ω.

(ii) F(Ω) is a normal family.

The theorem really consists of two separate parts.

(1) F is equicontinuous under the assumption that $\mathfrak { F }$ is a family of holomorphic functions that is uniformly bounded on compact subsets of Ω. The proof follows from an application of the Cauchy integral formula and hence relies on the fact that F consists of holomorphic functions. This conclusion is in sharp contrast with the real situation as illustrated by the family $\{ f _ { n } ( x ) = \sin n x : \ x \in ( 0 , 1 ) \} , | f _ { n } ( x ) | \leq 1$ uniformly bounded; but not equicontinuous and has no convergent subsequences on any compact subinterval of (0, 1).

(2) The second part of the theorem is not complex-analytic in nature. Indeed, the fact that $\mathfrak { F }$ is a normal family follows from assuming only that F is uniformly bounded and equicontinuous on compact subsets of $\omega$ . This result is sometimes known as the Arzela-Ascoli theorem and its proof consists primarily of a diagonalization argument.

A sequence $\{ K _ { \ell } \} _ { \ell = 1 } ^ { \infty }$ of compact subsets of $\Omega$ is called an exhaustion if

(a) $K _ { \ell }$ is contained in the interior of $K _ { \ell + 1 }$ for all $\ell = 1 , 2 , \cdots$

(b) Any compact set $K \subset \Omega$ is contained in $K _ { \ell }$ for some \`. In particular $\Omega = \cup _ { \ell = 1 } ^ { \infty } K _ { \ell }$

## The Proof of Montel’s Theorem

Let $\boldsymbol { \kappa }$ be a compact subset of $\Omega$ and choose $r > 0$ so small that $D _ { 3 r } ( z )$ is contained in $\Omega$ for all $z \in K$ . It suffices to choose r so that $3 r$ is less than the distance from $\boldsymbol { K }$ to the boundary of $\Omega .$ Let $z , w \in K$ with $\left| z - w \right| < r$ and let $\gamma$ denote the boundary circle of the disc $D _ { 2 r } ( w )$ . Then, by Cauchys integral formula, we have

$$
f ( z ) - f ( w ) = \frac { 1 } { 2 \pi i } \int _ { \gamma } f ( \zeta ) \left[ \frac { 1 } { \zeta - z } - \frac { 1 } { \zeta - w } \right] d \zeta
$$

Observe that

$$
\left| \frac { 1 } { \zeta - z } - \frac { 1 } { \zeta - w } \right| = \frac { | z - w | } { | \zeta - z | | \zeta - w | } \leq \frac { | z - w | } { r ^ { 2 } } .
$$

since $\zeta \in \gamma$ and $\left| z - w \right| < r$

Therefore

$$
| f ( z ) - f ( w ) | \leq { \frac { 1 } { 2 \pi } } { \frac { 2 \pi r } { r ^ { 2 } } } B | z - w | ,
$$

where $B$ denotes the uniform bound for the family $\mathfrak { F }$ in the compact set consisting of all points in $\Omega$ at a ${ \mathsf { d i s t a n c e } } \leq 2 r$ from $K .$ . Therefore $| f ( z ) - f ( w ) | \leq C | z - w |$ , and this estimate is true for all $z , w \in K$ with $| z - w | \leq r$ and $f \in { \mathfrak { F } }$ , thus this family is equicontinuous.

To prove the second part of the theorem, we argue as follows. Let $\{ f _ { n } \} _ { n = 1 } ^ { \infty }$ be a sequence in $\mathfrak { F }$ and $\boldsymbol { \kappa }$ a compact subset of $\Omega .$ . Choose a sequence of points $\{ w _ { j } \} _ { j = 1 } ^ { \infty }$ that is dense in $\Omega .$ Since $\{ f _ { n } \} _ { n = 1 } ^ { \infty }$ is uniformly bounded, there exists a subsequence $\{ f _ { n , 1 } \} = \{ f _ { 1 , 1 } , f _ { 2 , 1 } , f _ { 3 , 1 , \cdot } \cdot \cdot \cdot \}$ of $\left\{ f _ { n } \right\}$ such that $\left\{ f _ { n , 1 } ( w _ { 1 } ) \right\}$ converges.

From $\left\{ { { f } _ { n , 1 } } \right\}$ we can extract a subsequence $\{ f _ { n , 2 } \} = \{ f _ { 1 , 2 } , f _ { 2 , 2 } , f _ { 3 , 2 , } . . . \}$ so that $\left\{ f _ { n , 2 } ( w _ { 2 } ) \right\}$ converges. We may continue this process, and extract a subsequence $\{ f _ { n , j } \}$ of $\left\{ f _ { n , j 1 } \right\}$ such that $\{ f _ { n , j } ( w _ { j } ) \}$ converges.

Finally, let ${ \cal g } _ { n } = f _ { n , n }$ and consider the diagonal subsequence $\left\{ g _ { n } \right\}$ . By construction, $\{ g _ { n } ( w j ) \}$ converges for each $j ,$ and we claim that equicontinuity implies that $g _ { n }$ converges uniformly on $K .$ . Given $\epsilon > 0$ choose $\delta$ as in the definition of equicontinuity, and note that for some $J ,$ the set $\boldsymbol { K }$ is contained in the union of the discs $D _ { \delta } ( w _ { 1 } ) , \cdot \cdot \cdot , D _ { \delta } ( w \ j )$ . Pick N so large that if $n , m > N$ , then

$$
| g _ { m } ( w _ { j } ) - g _ { n } ( w _ { j } ) | < \epsilon \quad \mathrm { f o r } { \sf a l l } j = 1 , 2 , \cdot \cdot \cdot , J .
$$

So if $z \in K$ , then $z \in D _ { \delta } ( w _ { j } )$ for some $1 \le j \le J$ . Therefore,

$$
\begin{array} { r l } & { ~ | g _ { n } ( z ) - g _ { m } ( z ) | } \\ & { \leq | g _ { n } ( z ) - g _ { n } ( w _ { j } ) | + | g _ { n } ( w _ { j } ) - g _ { m } ( w _ { j } ) | + | g _ { m } ( w _ { j } ) - g _ { m } ( z ) | } \\ & { < 3 \epsilon } \end{array}
$$

whenever $n , m > N$ . Hence $\left\{ { { g } _ { n } } \right\}$ converges uniformly on K .

Finally, we need one more diagonalization argument to obtain a subsequence that converges uniformly on every compact subset of $\Omega .$ Let $K _ { 1 } \subset K _ { 2 } \subset \cdots \subset K _ { \ell } \subset \cdots$ be an exhaustion of $\omega$ , and suppose $\left\{ g _ { n , 1 } \right\}$ is a subsequence of the original sequence $\left\{ f _ { n } \right\}$ that converges uniformly on $K _ { 1 }$ Extract from $\left\{ g _ { n , 1 } \right\}$ a subsequence $\left\{ g _ { n , 2 } \right\}$ that converges uniformly on $K _ { 2 }$ and so on. Then, $\left\{ g _ { n , n } \right\}$ is a subsequence of $\left\{ f _ { n } \right\}$ that converges uniformly on every $K _ { \ell }$ and since the $K _ { \ell }$ exhaust $\Omega ,$ the sequence $\left\{ g _ { n , n } \right\}$ converges uniformly on any compact subset of $\Omega ,$ , as was to be shown.

## Theorem 6

Suppose $g _ { n }$ are holomorphic and $g _ { n } ( z ) \neq 0$ for all $z$ in a region Ω. If $g _ { n }$ converges uniformly to g on compact subsets of $\Omega ,$ then either g is identically zero in Ω or g is non-zero in Ω.

## Proof.

The limit function $\boldsymbol { g }$ is holomorphic on $\Omega$ by Weierstrasss Theorem. In particular, if $g$ is not identically zero, then the zeros of $\boldsymbol { g }$ are isolated. If $\gamma \sim 0$ is a simple curve on which $g \neq 0$ , then by Weierstrasss Theorem, ${ \boldsymbol { g } } _ { n } ^ { \prime }$ converges to $g ^ { \prime }$ and hence $\frac { \underline { { \theta } } _ { n } ^ { \prime } } { g _ { n } }$ converges to $\frac { g ^ { \prime } } { g }$ uniformly on $\gamma .$ . By the Argument Principle, for n sufficiently large, the number of zeros of g enclosed by $\gamma$ is the same as the number of zeros of $g _ { n }$ enclosed by $\gamma ,$ and since $g _ { n }$ is never zero, the theorem follows.

## Corollary 7

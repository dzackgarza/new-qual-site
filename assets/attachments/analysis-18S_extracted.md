Problem 1. Suppose $f \in L ^ { 1 } ( \mathbb { R } )$ satisfies

$$
\operatorname* { l i m } _ { h \to 0 } \operatorname* { s u p } _ { \mathbb { R } } \Big \vert \frac { f ( x + h ) - f ( x ) } { h } \Big \vert d x = 0 .
$$

Show that $f = 0$ almost everywhere.

$$

(a) Show that

$$
Q ( f , h ) \geq 0 \quad { \mathrm { f o r ~ a l l ~ } } f \in L ^ { 2 } ( \mathbb { R } ) { \mathrm { ~ a n d ~ a l l ~ } } h > 0 .
$$

(b) Show that the set

$$
E = \{ f \in L ^ { 2 } ( \mathbb { R } ) : \operatorname* { l i m } _ { h  0 } Q ( f , h ) \leq 1 \}
$$

is closed in $L ^ { 2 } ( \mathbb { R } )$
